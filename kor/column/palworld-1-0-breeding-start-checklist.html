작성·검토일: 2026-09-08

첫 답변: 목표를 하나 정한 뒤 부모 팰을 고르세요

먼저 목표 팰, 원하는 패시브, 물려줄 액티브 스킬 가운데 이번 교배에서 가장 중요한 한 가지를 정하세요. 목표를 섞으면 어떤 부모를 남겨야 하는지 판단하기 어렵습니다. 1.0에서는 교배 조합과 유전 규칙이 조정됐으므로 2024년 조합표를 그대로 적용하지 말고 현재 버전용 자료인지 확인해야 합니다.

교배 시작 순서

1. 목표 정의
전투, 거점 작업, 이동 또는 도감 확보 중 목적을 하나 선택합니다.
2. 현재 버전 조합 확인
1.0에서 전체 교배 조합이 재검토됐습니다. 오래된 계산기 결과는 현재 게임 결과와 다를 수 있습니다.
3. 부모 팰 정리
남길 패시브와 부모의 액티브 스킬 슬롯을 기록합니다. 공식 기록에 따르면 1.0의 액티브 스킬 유전은 부모에게 설정된 세 슬롯에서 무작위로 선택됩니다.
4. 케이크 목적 선택
기본 생산인지, 능력치·알 수·돌연변이·패시브 유전 보조가 필요한지에 맞춰 1.0 신규 케이크 효과를 확인합니다.
5. 소량 시험 후 확대
첫 결과에서 종, 패시브, 액티브 스킬을 확인한 뒤 같은 부모 조합을 계속 돌릴지 결정합니다.

1.0 케이크 효과 비교

종류공식 변경 기록의 역할
버섯 케이크태어난 팰이 더 높은 능력치를 가질 가능성을 조금 높임
채소 케이크한 번에 알 두 개 생산
고급 채소 케이크돌연변이 가능성과 능력치 성장 가능성을 높임
특제 케이크부모 팰의 여러 패시브를 물려받을 확률을 높임

돌연변이는 낮은 확률로 일반 결과보다 강한 팰과 고유 패시브를 만들 수 있지만 확정 결과가 아닙니다.

실패를 줄이는 기록표

  • 목표 팰
  • 교배 자료 버전
  • 부모 팰 두 마리
  • 부모 패시브
  • 설정된 액티브 스킬
  • 사용한 케이크
  • 태어난 팰
  • 유전 결과

결과가 다를 때 확인 순서

  1. 조합표가 1.0 기준인지 확인
  2. 선택한 부모 팰과 아종을 다시 확인
  3. 부모에게 설정한 액티브 스킬 세 슬롯 확인
  4. 확률 요소와 돌연변이를 확정 규칙으로 오해하지 않았는지 확인
  5. 패치 뒤라면 최신 공식 변경 기록 재확인

공식 자료와 적용 범위

이 페이지의 조합 변경, 액티브 스킬 유전, 돌연변이와 신규 케이크 설명은 Pocketpair의 1.0 공식 변경 기록을 기준으로 작성했습니다.
