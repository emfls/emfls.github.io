작성·검토일: 2026-09-08

첫 답변: 세이브 백업 후 오래된 모드를 완전히 제거하세요

게임이 1.0 업데이트 뒤 실행되지 않거나 세이브 로드가 실패한다면 세이브 백업부터 하고, 과거 모드 파일과 모드 로더를 수동으로 제거한 뒤 Steam 무결성 검사를 실행하세요. Pocketpair는 모드 관리 도구에서 비활성화만으로는 남은 파일의 로드를 막지 못할 수 있다고 안내합니다.

공식 권장 해결 순서

1. 세이브 백업
원본 세이브를 별도 위치에 복사합니다. 모드 전용 아이템이나 팰이 포함된 세이브는 모드 제거 뒤 정상 작동하지 않을 수 있습니다.
2. Workshop 구독 해제
설치한 Steam Workshop 모드의 구독을 해제합니다. 이것만으로 남은 로컬 파일이 모두 제거된다고 가정하지 마세요.
3. 오래된 모드·로더 수동 제거
공식 모드 가이드에서 안내하는 설치 폴더를 확인해 이전 모드 파일과 로더 잔여물을 제거합니다. 게임 본체 파일을 임의로 추측해 삭제하지 않습니다.
4. Steam 무결성 검사
Steam 라이브러리에서 Palworld 우클릭 → 속성 → 설치된 파일 → 게임 파일 무결성 검사를 실행합니다.
5. 모드 없는 상태로 실행
아무 모드도 다시 설치하지 않은 상태에서 게임과 세이브가 열리는지 확인합니다.
6. 호환 모드만 하나씩
제작자가 1.0 호환을 확인한 모드만 하나씩 설치하고 매번 실행 여부를 시험합니다.

증상으로 원인 범위 줄이기

증상판단다음 행동
게임 시작 즉시 종료잔여 모드·로더 가능성완전 제거 후 무결성 검사
새 월드는 열리지만 기존 세이브 실패세이브가 모드 콘텐츠에 의존할 수 있음백업본 보존, 해당 모드 호환판 확인
특정 모드 재설치 뒤 다시 오류그 모드와 현재 버전 충돌 가능성해당 모드 제거 후 제작자 공지 확인
모드 없이도 계속 오류모드 외 원인 가능성최신 패치·드라이버·공식 지원 확인

삭제 전에 꼭 지킬 것

  • 세이브 백업이 열리는지 확인
  • 모드 목록과 버전을 기록
  • 한 번에 하나의 변수만 변경
  • 확인하지 않은 폴더나 게임 본체 파일을 무작정 삭제하지 않기

모드 의존 콘텐츠가 저장된 세이브는 모드 제거 후 손상되거나 열리지 않을 수 있습니다. 원본 백업을 덮어쓰지 마세요.

공식 자료와 적용 범위

백업, 오래된 모드 수동 제거, Steam 무결성 검사, 무모드 실행, 호환 모드의 개별 재설치는 Pocketpair의 1.0 공식 안내 순서를 따릅니다.
