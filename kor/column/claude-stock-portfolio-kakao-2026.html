왜 '자동 매매'가 아니라 '자동 브리핑'인가

AI 자동화 콘텐츠가 넘쳐납니다. "주식 자동 매매", "포트폴리오 자동 운영" 같은 이야기들이요. 하지만 이건 개인적으로 추천하지 않습니다. AI가 주식 판단을 대신할 수 있다면, AI를 쓰는 사람들 모두가 이미 부자가 됐겠죠.

정작 AI가 잘하는 건 반복적인 정보 수집과 정리입니다. 아침마다 앱을 열어 주가를 확인하고, 네이버 뉴스와 인베스팅 같은 해외 사이트를 뒤져 관련 뉴스를 번역하는 10분짜리 루틴 — 이 부분을 AI에게 맡기는 것입니다.

💡 이 가이드에서 만드는 것

① 포트폴리오 종목의 당일 주가 수집 → ② 국내·해외 관련 뉴스 수집 및 한글 요약 → ③ 브리핑으로 묶어 카카오톡 전송 → ④ 매일 아침 7시 자동 실행

투자 결정은 사람이 합니다. AI는 그 판단을 위한 준비를 대신해줍니다.

준비물 — 클로드 데스크톱과 코워크(co-work)

STEP 0

이 자동화 시스템의 핵심 도구는 Claude 데스크톱 앱과 그 안의 코워크(co-work) 기능입니다. 코워크는 Claude가 인터넷 검색, 파일 조작, 외부 서비스 연동 등을 직접 수행할 수 있는 에이전트 모드입니다.

준비 순서는 간단합니다. 구글에서 '클로드'를 검색해 공식 사이트에서 데스크톱 앱을 다운로드합니다. 앱을 실행하면 왼쪽 위 메뉴에 코워크 항목이 보입니다. 여기에 원하는 작업을 설명하면 Claude가 실제로 실행해줍니다.

항목내용비용
Claude 데스크톱anthropic.com에서 다운로드무료 (Claude 구독 필요)
코워크(co-work)데스크톱 앱 왼쪽 위 메뉴에서 접근구독에 포함
pykrx국내 주식 가격 수집 라이브러리무료, 회원가입 없음
yfinance해외 주식 가격·뉴스 수집 라이브러리무료, 증권 계좌 불필요
Play MCP카카오톡 연동 커넥터무료

STEP 1 — 주가 실시간 수집 (pykrx + yfinance)

STEP 1

국내 주식은 pykrx, 해외 주식은 yfinance를 통해 정확한 주가를 가져옵니다. 두 라이브러리 모두 무료이고 회원가입이나 증권 계좌가 필요 없습니다. 가격은 항상 오류 없이 정확해야 하기 때문에 이 조합이 가장 안정적입니다.

코워크에 이렇게 입력합니다:

예시 프롬프트

"pykrx와 yfinance를 활용하여 주식의 가격을 정확히 가져와줘. 내가 가지고 있는 주식은 삼성전자, SK하이닉스, 엔비디아야."

엔터를 누르면 Claude가 두 라이브러리를 자동으로 설치하고 각 종목의 현재가를 가져옵니다. 삼성전자·하이닉스(국내)는 pykrx로, 엔비디아(해외)는 yfinance로 처리합니다. 종목은 본인 포트폴리오에 맞게 자유롭게 바꾸면 됩니다.

✅ 이 단계 완료 시

국내·해외 종목 구분 없이 당일 종가를 정확하게 받아볼 수 있습니다. 이후 뉴스·브리핑 단계와 연결해 하나의 대화 세션으로 이어갑니다.

STEP 2 — 오늘자 뉴스 수집 (구글 뉴스 + yfinance)

STEP 2

주가를 가져온 같은 세션에서 이어서 뉴스를 수집합니다. 프롬프트 예시는 다음과 같습니다:

예시 프롬프트

"내 포트폴리오 종목 관련 뉴스를 가져올 거야. 국내 뉴스와 해외 뉴스 모두 오늘자로 각각 세 개씩 가져와줘. 아까 활용한 툴들을 이용할 수 있으면 이용하고 안 되면 웹서치를 이용해."

여기서 주의할 점이 있습니다. 국내 종목 뉴스를 웹서치로만 긁어오면 오늘자가 아닌 날짜의 기사가 섞일 수 있습니다. 이를 해결하는 방법은 두 가지입니다.

방법특징추천 대상
구글 뉴스 날짜 필터링URL 파라미터로 오늘 날짜 강제 지정빠르게 시작하고 싶은 분
네이버 검색 API정확도 높음, 개발자센터 API 키 필요완성도를 높이고 싶은 분
yfinance 뉴스해외 종목 전용, 트레이딩 관점 강함해외 주식 비중이 높은 분

날짜가 어긋난 뉴스가 포함되면 신뢰도가 떨어집니다. Claude에게 "한국 종목은 구글 뉴스에서 오늘자 날짜로 가져와, 해외 종목은 yfinance에서 가져와"라고 명확히 지시하면 Claude가 각 방법을 조합해서 처리합니다.

STEP 3 — 브리핑 완성 & 카카오톡 전송 (Play MCP)

STEP 3

주가와 뉴스를 모두 수집했다면 이제 하나의 브리핑으로 묶습니다:

예시 프롬프트

"포트폴리오 종목들의 오늘자 종가와 관련 뉴스를 깔끔하게 정리해서 하나의 브리핑으로 만들어줘. 영어 뉴스는 한글로 번역해서 정리해."

Claude는 각 종목별로 주가 요약 → 오늘 뉴스 3개 → 핵심 요약 형태로 브리핑을 작성합니다. 링크도 함께 포함되어 원문 기사로 바로 넘어갈 수 있습니다. 해외 뉴스는 자동으로 한글 번역됩니다.

브리핑이 완성되면 이제 카카오톡으로 전송합니다. 카카오톡 연동은 Play MCP라는 커넥터를 활용합니다.

Play MCP 연동 방법

① Claude 데스크톱 왼쪽 위 메뉴 → 커스터마이즈 → 커넥터 → 추가 → 커스텀 둘러보기

② 검색창에 'Play MCP' 입력 → 카카오 관련 항목 선택 → 도구함에 추가

③ 카카오 계정 인증 → '나챗방' 도구 선택 → 항상 허용으로 승인

④ Claude에게 "이 브리핑을 Play MCP를 활용해서 나한테 카톡으로 보내줘" 입력

카카오톡 나와의 채팅(메모)으로 브리핑이 전송됩니다. 단, 카카오톡 메모는 200자 제한이 있어 긴 브리핑은 잘릴 수 있습니다. 전체 내용을 받고 싶다면 Gmail MCP를 같은 방식으로 연동해 이메일로 받는 것도 가능합니다.

STEP 4 — 매일 아침 7시 자동 스케줄 등록

STEP 4

수동으로 매일 실행하는 건 자동화가 아닙니다. 이제 스케줄을 등록합니다:

예시 프롬프트

"가격과 종목 뉴스를 브리핑으로 묶어서 카카오톡으로 보내주는 작업을 매일 오전 7시에 스케줄 등록해줘."

Claude가 스케줄을 생성하면 왼쪽 위 메뉴 → 스케줄 항목에서 확인할 수 있습니다. 등록 직후 한 번 수동 실행해두는 것이 좋습니다. 권한 승인을 미리 처리해야 내일 아침 자동 실행 시 중간에 막히지 않기 때문입니다.

⚠️ 반드시 지켜야 할 두 가지

① 절전 모드 방지 ON: 스케줄 작업은 "컴퓨터가 깨어 있는 동안에만 실행"됩니다. 시스템 설정에서 절전 모드 방지를 켜두세요.

② Claude 데스크톱 앱 유지: 앱이 실행 중이어야 스케줄이 동작합니다. 집 컴퓨터를 항상 켜두거나, 외출 전 앱이 실행 중인지 확인하세요.

실제 테스트 결과, 오전 7시 트리거 이후 주가 조사 → 뉴스 분석 → 브리핑 생성까지 약 3~4분이 걸렸습니다. 7시 4분에 카카오톡이 도착한 것입니다. 앞으로는 매일 아침 카톡을 열기만 하면 포트폴리오 브리핑이 기다리고 있습니다.

이 시스템의 한계와 활용 팁

이 자동화 시스템은 강력하지만 몇 가지 현실적인 한계가 있습니다.

항목한계대안
카카오톡 메모 글자 수200자 제한으로 브리핑 잘림Gmail MCP 연동으로 전체 내용 수신
국내 뉴스 날짜 정확도구글 뉴스 필터링도 간혹 오늘자 아닌 기사 포함네이버 검색 API 발급 후 교체
컴퓨터 상태 의존성절전 모드 진입 시 스케줄 미실행절전 모드 방지 설정 + 항상 켜두기
투자 판단 불가AI는 정보 수집만, 매수·매도 판단은 본인이브리핑을 판단 근거 자료로만 활용

브리핑 형식은 취향에 맞게 커스터마이즈할 수 있습니다. "전문가 의견도 함께 찾아줘", "내용을 더 압축해서 짧게 보내줘" 등 프롬프트를 추가하면 Claude가 그에 맞게 조정합니다. 종목을 바꾸고 싶을 때도 코워크 세션에서 다시 지시하면 됩니다.

📌 핵심 요약 — 오늘 만든 것

코딩을 몰라도 Claude 코워크 하나로 주가 수집(pykrx + yfinance) → 뉴스 요약(구글 뉴스 + yfinance) → 브리핑 생성 → 카카오톡 전송(Play MCP) → 매일 오전 7시 자동 실행 파이프라인을 완성할 수 있습니다.

저는 이게 AI 시대에 일하는 방식이라고 생각합니다. 정보를 모으는 노동은 AI에게, 투자 결정이라는 진짜 중요한 판단은 사람이 하는 것. 매일 아침 앱을 뒤지는 10분을 아끼는 대신, 그 시간에 브리핑을 읽고 오늘의 시장을 나만의 시각으로 해석하는 데 씁니다.

사용한 프롬프트와 네이버 API 관련 정보는 원본 영상 댓글에 공개되어 있습니다. 직접 만들어보고 싶다면 댓글을 참고하세요.
