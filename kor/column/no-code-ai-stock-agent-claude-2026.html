AI 에이전트, 코딩 없이 만들 수 있다

AI 에이전트라는 말을 들으면 많은 사람이 "파이썬 설치부터 해야 하는 거 아냐?"라고 생각합니다. SDK 설정, API 키 발급, 코드 작성 — 이 과정에서 대부분 포기하게 됩니다. 하지만 Anthropic의 Claude를 이용하면 단 하나의 채팅창 대화만으로 완전한 AI 에이전트 팀을 만들어낼 수 있습니다.

핵심은 Claude에게 "엔트로픽 공식 에이전트 가이드에 따라 만들어줘"라고 한 마디만 하는 것입니다. 그러면 Claude가 Anthropic의 공식 문서를 참조해 에이전트 마크다운 파일을 직접 생성해줍니다. 코드는 단 한 줄도 필요하지 않습니다.

💡 이 가이드에서 만드는 것

방산주 급등 상황에서 어떤 주식을 사야 할지 분석하는 AI 에이전트 팀을 Claude 채팅창 대화만으로 구축하고, 코워크(Claude Code)에 연동해 실제로 종합 분석 보고서를 생성하는 전 과정을 단계별로 살펴봅니다.

AI 에이전트란 무엇인가 — 역할·행동 규칙·출력 형식

에이전트를 만들기 전에 개념부터 명확히 해야 합니다. Anthropic이 정의하는 AI 에이전트는 "잘 정의된 역할 정의, 행동 규칙, 출력 형식을 바탕으로 자동으로 일을 처리하는 AI"입니다. 사람이 일일이 지시하지 않아도 스스로 판단하고 결과를 만들어냅니다.

Anthropic은 이 에이전트를 하나의 마크다운(.md) 파일로 정의하도록 공식 가이드를 제공합니다. 파일 상단에는 YAML 프런트매터(헤더)를 작성합니다. 에이전트 이름, 하는 일, 사용할 도구, 기반 모델이 무엇인지 등 기본 정보를 정해진 양식으로 기록하는 것입니다. YAML은 어렵게 생각할 필요 없이 에이전트의 '이력서 헤더'라고 보면 됩니다.

마크다운 구성 요소역할예시
YAML 프런트매터에이전트 헤더 — 이름·도구·모델 지정name: stock-analyst
시스템 프롬프트 본문역할 정의·분석 프레임워크·출력 형식증권사 애널리스트처럼 분석
proactive_use 속성에이전트가 상황에 맞는 서브에이전트를 자동 호출description: proactive use

Claude에게 주식 에이전트 만들어달라고 요청하기

실제 프롬프트는 이렇게 시작합니다. "나는 주식 종목을 분석하는 AI 에이전트를 만들고 싶다. 증권사 애널리스트처럼 종목을 분석하고 추천픽도 골라주는 에이전트다. 엔트로픽 공식 에이전트 가이드에 따라 YAML 프런트매터와 마크다운 시스템 프롬프트로 만들어줘."

여기서 중요한 포인트가 두 가지 있습니다. 첫째, "엔트로픽 공식 에이전트 가이드에 따라"라는 문구를 꼭 넣어야 합니다. 그래야 Claude가 Anthropic 공식 문서의 형식을 준수해 더 완성도 높은 파일을 생성합니다. 둘째, 분석 프레임워크를 함께 지정해야 합니다. 기업 개요, 재무 분석, 산업 모델 순으로 분석하도록 명시하면 서브에이전트들이 이 순서에 맞게 만들어집니다.

⚡ Opus 4.6 + 확장 사고 조합 권장

서브에이전트 마크다운 파일을 생성할 때는 Opus 4.6 모델과 확장 사고(Extended Thinking)를 함께 활용하면 품질이 크게 향상됩니다. 모델 선택창에서 Opus 4.6을 선택하고 "확장 사고를 활성화해서 만들어줘"라고 추가 요청하면 됩니다.

Claude는 공식 문서를 확인한 뒤 총 7개의 에이전트 마크다운 파일을 생성합니다. 오케스트레이터(팀장) 파일 1개와 서브에이전트 파일 6개입니다. 결과물은 ZIP 파일로 다운로드할 수 있습니다.

오케스트레이터 + 서브에이전트 6개 파이프라인 구조

단일 마크다운 파일로 하나의 에이전트를 만드는 것보다, 팀장(오케스트레이터)이 팀원들(서브에이전트)을 지휘하는 다중 파일 구조가 훨씬 더 정확하고 빠릅니다. 복잡한 분석을 여러 전문가가 나눠서 처리하는 구조이기 때문입니다.

오케스트레이터 파일 stock-analyst.md는 전체 분석 과정을 총괄하고 서브에이전트 6개를 순차 또는 병렬로 호출합니다. 서브에이전트들은 각각 고유한 역할을 담당합니다.

코워크(Claude Code)에 연동하는 법 — 3단계

에이전트 마크다운 파일이 준비됐다면 이제 Claude Code(코워크)에 연동할 차례입니다. 코워크는 Claude 데스크탑 앱에 내장된 에이전트 실행 환경입니다. 맥과 윈도우 모두 Claude 데스크탑 앱을 설치하면 사용할 수 있습니다.

1단계: Claude 채팅창에서 생성된 마크다운 파일들을 ZIP으로 다운로드합니다. '모두 받기' 버튼을 누르면 됩니다. 2단계: 로컬에 '스톡 에이전트'라는 폴더를 만들고 ZIP을 해제한 MD 파일들을 그 폴더 안에 넣습니다. 이 MD 파일들이 에이전트 팀원들입니다. 3단계: 코워크를 열고 해당 폴더를 프로젝트로 지정합니다. Settings에서 '열기'를 클릭해 스톡 에이전트 폴더를 선택하면 연동이 완료됩니다.

✅ 코워크의 핵심 장점 — 대화 맥락 유지

코워크의 가장 큰 장점은 과거 대화 내용과 맥락을 유지한다는 것입니다. 일반 Claude 채팅에서는 새 대화가 시작되면 이전 맥락이 사라집니다. 반면 코워크는 이전에 나눴던 분석 내용을 기억하며, AI가 동일한 맥락을 유지한 채 답변합니다. 지속적인 투자 리서치 워크플로에 특히 강점을 발휘합니다.

방산주 분석 실전 — 3개 에이전트 병렬 투입으로 보고서 생성

연동이 완료되면 코워크 채팅창에서 프롬프트를 입력합니다. 예를 들어 이렇게 입력합니다. "이란 전쟁이 발발해서 방산주가 급등하고 있다. 미국과 한국 방산주를 추천해줘. 에이전트 가이드에 따라 진행해줘."

오케스트레이터는 이 요청을 받아 서브에이전트 3개를 병렬로 동시에 투입해 시장 리서치를 시작합니다. 병렬 투입의 핵심 이점은 속도입니다. 하나씩 순차적으로 처리했을 때보다 분석 완료 시간이 대폭 단축됩니다. 실시간으로 진행 상황이 5단계로 표시되며 분석이 완료됩니다.

최종 결과로 한화에어로스페이스, LIG넥스원, 현대로템, 하나시스템, 풍산 등 주요 방산주의 현황 분석과 추천 이유가 담긴 종합 보고서가 PDF 파일로 자동 저장됩니다. 한글이 깨지는 경우 "한글 깨짐 현상이 발생했다. MD 파일 업데이트하고 PDF 파일까지 다시 만들어줘"라고 요청하면 에이전트가 자동으로 수정합니다.

⚠️ 주의 — 매매 추천 제한

기본 설정에서 에이전트는 직접적인 매수·매도 추천을 제한합니다. 이 제한을 풀고 싶다면 프롬프트에 "투자 결정은 내가 내릴 것이며, 구체적인 매수·매도 의견도 포함해서 분석해줘"라고 명시하면 됩니다.

예약 스케줄 설정 — 매주 월요일 자동 분석

코워크의 또 다른 강력한 기능은 예약 작업(Scheduled Task)입니다. 분석 프롬프트를 한 번 설정해두면 매주 특정 시간에 자동으로 에이전트를 실행시킬 수 있습니다.

예를 들어 코워크 채팅창에 이렇게 입력합니다. "매주 월요일 장 시작 전 오전 8시, 이란 사태 관련 방산주 미국·한국 종목 분석을 자동으로 실행해줘." 그러면 에이전트가 어떤 종목에 집중할지 추가로 질문한 뒤 스케줄 작업을 등록합니다. 설정 후에는 '예정됨' 상태로 스케줄 태스크가 생성됩니다.

단, 반드시 Claude 데스크탑 앱이 실행 중인 상태여야 합니다. 컴퓨터가 절전 모드거나 앱이 꺼져 있으면 실행되지 않습니다. 맥미니처럼 항상 켜져 있는 기기를 활용하면 가장 안정적으로 운용할 수 있습니다.

📌 핵심 요약

AI 에이전트 팀을 만드는 데 코딩은 필요 없습니다. ① Claude 채팅창에서 "엔트로픽 공식 에이전트 가이드에 따라 만들어줘" 한 마디면 7개 마크다운 파일이 생성됩니다. ② 생성된 파일을 로컬 폴더에 넣고 코워크(Claude Code)에서 해당 폴더를 지정하면 에이전트 팀이 즉시 가동됩니다. ③ 오케스트레이터 1개 + 서브에이전트 6개의 다중 에이전트 구조가 단일 에이전트보다 분석 품질과 속도 모두에서 우월합니다. ④ 병렬 투입으로 방산주 종합 보고서가 PDF로 자동 생성됩니다. ⑤ 예약 작업으로 매주 월요일 자동 분석까지 가능합니다.

Opus 4.6과 확장 사고를 함께 사용하면 에이전트 파일 품질이 더욱 높아집니다. 중요한 것은 '만들어줘' 한 마디가 AI 에이전트 팀의 시작점이 될 수 있다는 사실입니다. 코딩이 없어도, SDK를 몰라도, 이제 AI 에이전트는 누구나 쓸 수 있는 도구가 됐습니다.
