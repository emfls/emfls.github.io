주민등록등본이나 건강보험 관련 증명서를 발급받으려고 정부24에 접속했는데, 간편인증을 마쳐도 다시 로그인 화면으로 돌아가거나 인증 팝업이 계속 뜨는 일이 있습니다. 이런 경우 인증 앱을 무작정 재설치하거나 공동인증서를 삭제하기 전에 문제가 발생한 단계를 구분하는 편이 빠릅니다.

먼저 확인할 핵심: 정부24는 공식 주소인 www.gov.kr에서 새로 접속하세요. 간편인증 창이 반복된다면 팝업 차단 및 사이트의 브라우저 데이터를 확인합니다. 실제로 정부24는 '간편인증 창 반복되는 경우 조치 방법' 공지에서 팝업 차단 해제와 검색 기록 정리를 안내한 바 있습니다. 다만 이 공지는 2021년 자료라 현재 브라우저의 메뉴 이름은 다를 수 있습니다.

이 글은 2026년 11월 기준 공식 안내와 일반적인 브라우저 진단 원칙을 함께 정리한 것입니다. 특정 오류의 원인은 기기·인증 제공업체·서비스 점검 상황에 따라 다를 수 있습니다.

1. 증상별로 먼저 확인할 것

지금 보이는 증상우선 확인피해야 할 행동
간편인증 창이 계속 다시 뜬다팝업 허용, 쿠키, 인증 후 원래 탭 전환여러 번 연속 신청
휴대폰에 인증 요청이 오지 않는다인증 앱 알림·네트워크·등록된 휴대전화출처 불명의 인증 문자 링크 클릭
인증은 완료됐는데 로그인 화면으로 되돌아간다원래 브라우저 탭, 사이트 데이터, 확장 프로그램무작정 모든 비밀번호 삭제
공동인증서가 보이지 않는다인증서 저장 위치, 유효기간, 인증 방식인증서 삭제·초기화부터 실행
로그인 뒤 증명서 발급만 실패한다민원 신청 상태, 출력·발급 프로그램, 제출 방식로그인 오류로 단정
접속 대기·이용 불가 안내가 나온다공식 공지, 트래픽·점검 상황새로고침을 수십 번 반복

3분 점검 순서: ① 주소 확인 → ② 브라우저 팝업 차단 확인 → ③ 인증 앱 알림 확인 → ④ 해당 사이트 데이터만 정리 → ⑤ 다른 브라우저로 재시도. 첫 단계에서 원인을 찾으면 뒤의 조치를 건너뛰어도 됩니다.

2. 정부24 로그인 사이트 주소부터 확인

검색 결과나 문자메시지의 링크를 누른 상태라면 주소 표시줄을 먼저 살펴보세요. 공식 정부24 주소는 https://www.gov.kr입니다. 정부24는 사칭 앱과 가짜 민원 안내 문자를 주의하라는 공지를 낸 바 있으며, 실제 콜센터 번호를 발신번호로 위장한 사례도 경고했습니다.

  • 주소를 직접 입력하거나 기존 즐겨찾기 대신 공식 사이트에서 다시 접속합니다.
  • '과태료', '민원 신고', '인증 실패'를 이유로 앱 설치를 요구하는 문자 링크는 열지 않습니다.
  • 공동인증서 비밀번호, 계좌 비밀번호, 인증번호를 다른 사람에게 알려주지 않습니다.
  • 원격제어 앱 설치를 요구하는 비공식 안내는 거절하고 정부24 공식 고객센터에 확인합니다.

이는 단순 접속 오류뿐 아니라 피싱을 막기 위한 첫 번째 확인입니다.

출처: 정부24 — 피싱 문자 및 공공기관 위장 사이트 주의 안내

3. 간편인증 창이 무한반복될 때: 팝업 차단부터 확인

인증업체를 선택했는데 창이 뜨지 않거나, 확인을 마친 뒤 다시 간편인증 선택 화면으로 돌아오는 경우가 있습니다. 정부24의 공식 문제 해결 공지에서도 팝업 차단 해제 후 재시도를 먼저 안내합니다.

크롬에서 확인하는 방법

  1. 정부24 페이지를 연 채 주소창 오른쪽에 '팝업 차단' 아이콘이 있는지 확인합니다.
  2. 차단 표시가 있다면 해당 사이트의 팝업과 리디렉션을 허용합니다.
  3. 아이콘이 없다면 설정 → 개인정보 보호 및 보안 → 사이트 설정 → 팝업 및 리디렉션으로 이동합니다. 메뉴명이 다르면 설정 검색창에 '팝업'을 검색하세요.
  4. 모든 사이트를 무조건 허용하는 대신 정부24 인증에 필요한 공식 도메인만 예외로 등록합니다.
  5. 페이지를 새로 열어 인증을 한 번 더 진행합니다.

마이크로소프트 엣지에서 확인하는 방법

설정 → 쿠키 및 사이트 권한(또는 사이트 사용 권한) → 팝업 및 리디렉션에서 해당 사이트가 차단돼 있는지 살펴봅니다. 기업·학교 PC는 관리자가 정책으로 제한했을 수 있습니다.

주의: 팝업 차단을 아예 꺼둔 상태로 이용하지 마세요. 정상 인증이 끝나면 불필요하게 허용한 권한을 다시 점검하세요.

공식 근거: 정부24 — 간편인증 창 반복되는 경우 조치 방법

4. PASS·카카오·네이버 등 인증 요청이 휴대폰에 오지 않을 때

간편인증 업체별 앱 화면은 다르지만 공통적으로 점검할 부분이 있습니다.

  1. PC에서 선택한 인증업체와 휴대폰에서 실제로 사용 중인 앱이 같은지 확인합니다.
  2. 휴대폰의 와이파이 또는 모바일 데이터가 정상인지 확인합니다.
  3. 해당 앱의 알림이 꺼져 있다면 다시 허용하고 앱을 직접 실행해 인증 요청 내역을 찾습니다.
  4. 휴대전화 명의, 입력한 이름·생년월일·휴대전화 번호가 인증 서비스의 등록 정보와 일치하는지 확인합니다.
  5. 요청이 유효하지 않거나 시간이 지났다면 기존 창을 닫고 새로 한 번 요청합니다.

인증 완료 후에도 PC가 그대로라면 원래 정부24 탭을 확인하세요. 인증 앱에서 성공했다고 표시되는 것과 정부24 웹 세션이 최종 로그인되는 과정은 별개일 수 있습니다. 모바일 브라우저와 PC 브라우저에서 각각 시도해 결과가 달라지는지 확인하면 원인 범위를 좁힐 수 있습니다.

무작정 인증 요청을 반복하지 마세요. 이용 제한 또는 시간 초과가 발생하면 해당 인증업체의 안내를 먼저 확인합니다.

5. 인증은 성공했는데 로그인 화면으로 되돌아갈 때

인증 성공 직후 로그인 페이지로 돌아온다면 인증서 자체보다 브라우저에 남아 있는 세션·쿠키 또는 확장 기능을 의심해 볼 수 있습니다. 원인 진단을 위한 순서이지, 모든 로그인 실패가 쿠키 문제라는 뜻은 아닙니다.

  • 먼저 현재 열려 있는 정부24 탭을 종료하고 공식 주소를 새 탭에 직접 입력합니다.
  • 이어서 해당 사이트의 쿠키와 캐시를 정리한 뒤 다시 로그인합니다. 쿠키를 지우면 로그아웃될 수 있습니다.
  • 크롬이나 엣지의 광고 차단·추적 방지·스크립트 제어 확장 프로그램을 일시적으로 꺼서 비교합니다. 점검 후 다시 켭니다.
  • 시크릿·InPrivate 모드에서만 작동한다면 기존 프로필의 사이트 데이터나 확장 프로그램이 영향을 주는지 확인합니다.
  • 다른 브라우저 또는 다른 기기에서 성공하는지도 비교합니다.

전체 방문 기록·저장 비밀번호를 한꺼번에 삭제할 필요는 없습니다. 먼저 정부24 관련 사이트 데이터만 정리하세요. 다만 인증 연동에 사용되는 다른 공식 도메인의 쿠키 설정 때문에 문제가 발생할 수도 있으므로, 특정 사이트 예외만으로 해결되지 않을 수 있습니다.

브라우저를 최신 상태로 업데이트하는 것도 도움이 됩니다. 오래된 인터넷 익스플로러 기준으로 작성된 과거 안내를 그대로 따라 하지 말고, 현재 사용하는 브라우저의 메뉴를 기준으로 설정하세요.

6. 공동인증서·금융인증서 로그인 오류 해결

공동인증서와 금융인증서는 서로 다른 인증 방식입니다. 인증서를 찾을 수 없거나 비밀번호 오류가 발생할 때는 다음을 확인합니다.

  1. 로그인 화면에서 실제 보유한 인증 방식이 선택됐는지 확인합니다.
  2. 공동인증서는 PC·USB 등 저장한 위치를, 금융인증서는 해당 인증 절차를 확인합니다.
  3. 인증서의 유효기간과 본인 명의 여부를 확인합니다.
  4. 정부24의 공식 인증센터에서 필요한 등록·관리 절차가 있는지 살펴봅니다.
  5. 공식 보안센터에서 필요한 발급·보안 프로그램을 안내하는지 확인합니다.

인증서가 목록에 나타나지 않는다고 파일을 함부로 삭제하지 마세요. 인증서 백업이나 다른 금융서비스에 필요한 자료가 사라질 수 있습니다. 공용 PC라면 민감한 인증서를 새로 저장하기 전에 더 안전한 개인 기기에서 진행하는 편이 좋습니다.

공식 안내: 정부24 홈페이지 — 인증센터·보안센터

7. 휴대폰에서는 되는데 PC에서만 실패할 때

같은 계정이 휴대폰에서는 로그인되지만 PC에서만 실패한다면 PC 브라우저 환경을 우선 확인할 근거가 생깁니다.

테스트확인할 수 있는 점
PC 크롬만 실패, PC 엣지 성공특정 브라우저의 설정·확장 기능 차이
PC 실패, 휴대폰 성공PC 팝업·쿠키·보안 프로그램 문제 가능성
둘 다 인증 앱 알림이 안 옴인증 제공업체·명의·네트워크 문제 가능성
모든 기기에서 서비스 접속 불가서버 점검·서비스 과부하 여부 확인 필요

이 표는 문제 범위를 좁히기 위한 진단 예시입니다. 원인을 확정하는 검사 결과가 아닙니다.

회사나 공공기관 PC에서는 보안 정책으로 사이트 설정 변경이 불가능할 수 있습니다. 조직 보안 정책을 우회하기보다 관리 담당자에게 공식 인증 사이트 접속 가능 여부를 확인하세요.

8. 로그인은 되는데 '민원신청' 또는 '문서출력'이 안 될 때

로그인 성공과 증명서 발급 성공은 별개의 단계입니다. 화면에 따라 아래처럼 나눠서 확인합니다.

  • 신청 중 오류: 입력 항목 누락, 신청자 자격, 해당 민원의 온라인 처리 가능 여부를 확인합니다.
  • 신청 완료인데 문서가 안 보임: 정부24의 신청·처리 내역과 발급·출력 단계가 어디까지 진행됐는지 확인합니다.
  • 출력창이 열리지 않음: 팝업 차단, 문서출력 관련 프로그램, 브라우저 설정을 확인합니다.
  • PDF를 저장했는데 제출이 반려됨: 제출기관이 PDF 저장본을 인정하는지, 전자증명서 방식이 필요한지 확인합니다.
