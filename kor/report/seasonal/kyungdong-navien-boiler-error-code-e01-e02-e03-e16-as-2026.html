E01·E16 과열 표시가 떴을 때

E01은 열교환기 과열 감지입니다. 모델 설명서가 즉시 가동 중단과 서비스 접수를 안내하면 그 지시를 우선하세요. 외부 확인이 가능한 경우 분배기의 각 방 밸브가 모두 잠겨 있는지 살핍니다. 레버식은 보통 배관과 나란할 때 열려 있지만 밸브 모양이 다르면 설치 안내를 확인하세요.

밸브가 열려 있는데도 특정 방만 차갑거나 코드가 반복되면 편난방 증상을 AS에 알려주세요. 배관 막힘에 따른 난방수 순환 저하나 순환펌프 이상은 기사 점검이 필요합니다. E16은 과열로 안전차단장치가 작동한 상태이므로 가동을 중단하고 재시동을 반복하지 마세요.

숫자 02(구형 E02) 물보충과 E302 모델별 구분

아래 1~3단계는 실내온도조절기에 숫자 02(구형 E02 표기) 또는 물보충 램프가 뜬 지원 가스보일러 모델 기준입니다. 3자리 코드 E302가 뜬 경우에는 수동 물보충 절차를 따르지 말고 아래 E302 모델별 기준을 먼저 확인하세요.

  1. 찬물도 안 나오는지 확인하세요 (02 표시 기준). 싱크대·욕실에서 찬물과 온수가 모두 멈췄다면 단수 여부를 먼저 확인합니다. 자동 물보충 모델은 단수가 해제되면 자동으로 물보충이 진행됩니다.
  2. 온수 쪽 유량과 직수밸브 열림을 비교하세요 (02 표시 기준). 찬물은 정상인데 온수 쪽만 물이 나오지 않는다면 보일러 하단 직수(냉수)배관 밸브가 배관과 나란히 일자로 열려 있는지 확인하고, 한파 뒤라면 직수관 결빙을 의심합니다.
  3. 급수가 정상이라면 모델별 보충 방식을 확인하세요 (02 표시 기준). KDB-GOM·ACE 시리즈 등 수동 물보충 모델만 설명서 절차대로 보충하고(외장형 팽창탱크 모델은 물탱크 수위 확인), 자동 물보충 모델의 밸브는 임의로 조작하지 마세요.

E302는 02 물보충 코드와 별도로 구분해야 합니다. 나비엔 하우스 공식 자가진단(Er302/E302)과 제품 설명서 기준으로 콘덴싱 솔로 등 밀폐형 모델의 E302는 저수압(서비스센터 점검 대상)이며, NCB354 등 대기 차단식 모델의 E302는 저수위 이상(재가동 후 동일 증상 지속 시 고객상담센터 점검 대상)입니다(직수밸브 잠김에 따른 물 보충 이상은 일부 3자리 모델에서 E351로 별도 표시). 급수가 정상인데도 02 표시가 반복되거나 분배기·배관 주변에 물자국이 보이면 누수나 수위·수압 감지 계통 점검을 요청하세요.

E03 불착화와 응축수 호스 결빙

E03은 점화되지 않았거나 불꽃이 감지되지 않았다는 뜻입니다. 가스 냄새가 없을 때만 보일러 가스 중간밸브가 열린 상태인지 겉에서 확인합니다. 한파에 콘덴싱 모델이 멈췄다면 외부 응축수 호스가 꺾이거나 얼어 배수가 막혔는지도 확인하세요. 직수관은 수돗물을 들여보내고, 응축수 호스는 연소 중 생긴 물을 내보냅니다.

호스가 얼었다면 모델 설명서나 상담원이 안내하는 방법으로 접근 가능한 외부 응축수 호스만 해동하세요. 본체 안쪽이나 높은 곳에 있거나 파손·누수가 보이면 AS를 받으세요. 끓는 물과 불꽃을 사용하지 말고, 가스와 배수 상태를 확인한 뒤에도 점화가 실패하면 반복 재시동을 피하세요.

E09·E10과 연통 막힘, 어디까지 볼 수 있나요?

E09는 송풍기 회전 이상이고 E10은 급배기나 풍압 이상입니다. 지상처럼 안전한 위치에서만 연통 끝이 고드름이나 이물질로 막혔는지, 연결이 빠지거나 찌그러졌는지 살피세요. 연통을 떼거나 높은 곳에 올라가 고드름을 제거하지 마세요. 막힘이나 이탈이 보이면 사용을 중단하고 설치업체 또는 제조사에 연락하세요.

자주 묻는 질문

경동나비엔 E01과 E16은 어떻게 다른가요?

E01은 과열을 감지한 표시이고, E16은 과열로 안전차단장치가 작동한 경우입니다. E01은 분배기 밸브가 모두 잠겼는지 겉에서 확인하고, E16은 사용을 중단하고 AS를 접수하세요. 해당 모델 설명서에서 즉시 사용 중단을 안내하면 그 지시를 우선하세요.

숫자 02(구형 E02)와 E302는 조치 방법이 어떻게 다른가요?

숫자 02(구형 조절기 E02 표기)는 저수위·물보충 표시이므로 찬물·온수 출수와 직수밸브 열림 상태를 먼저 확인하고, GOM·ACE 등 수동 물보충 모델만 설명서 절차대로 보충합니다. 반면 3자리 코드 E302는 수동 물보충 절차가 아니라 콘덴싱 솔로 등 밀폐형에서는 저수압(서비스 점검 대상), NCB354 등 대기 차단식에서는 저수위 이상(설명서 기준 재가동 후 지속 시 AS 점검 대상)이므로 모델 설명서에 따라 점검을 요청하세요.

E03이 한파에 뜨면 응축수 호스가 언 건가요?

E03은 불착화입니다. 가스 냄새가 없을 때 가스 중간밸브의 열림 상태를 확인하고, 콘덴싱 모델이면 노출된 응축수 호스의 결빙·막힘 여부를 살피세요. 가스 공급과 배수에 이상이 없어도 같은 코드가 반복되면 AS가 필요합니다.

E09나 E10이 뜨면 연통을 빼서 확인해도 되나요?

연통은 분리하지 마세요. 안전한 위치에서 실외 연통 끝의 고드름·막힘·이탈만 살피세요. 막힘이나 이탈이 보이거나 코드가 계속 뜨면 사용을 중단하고 설치업체 또는 경동나비엔에 점검을 요청하세요.

경동나비엔 보일러 AS는 어디로 접수하나요?

경동나비엔 행복나눔센터 1588-1144 또는 나비엔 하우스에서 접수할 수 있습니다. 본체 모델명, 조절기 화면의 코드 전체, 난방·온수 출수 여부와 누수 흔적을 알려주면 증상을 전달하기 쉽습니다.
