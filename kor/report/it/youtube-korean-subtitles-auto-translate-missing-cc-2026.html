영어 유튜브 영상을 한국어 자막으로 보려고 했는데 자막(CC) 버튼이 없거나, 자막을 켜도 영어만 표시될 때가 있습니다. 어떤 영상에서는 '자동 번역'을 선택할 수 있는데 다른 영상에서는 해당 항목 자체가 나타나지 않기도 합니다.

이때 가장 중요한 것은 자막을 켜는 문제, 번역할 원본 자막이 없는 문제, 표시 언어를 바꾸는 문제를 서로 구분하는 것입니다. 이 글은 갤럭시·아이폰·PC에서 실제로 확인할 순서를 제시하고, 해결할 수 없는 조건까지 정확하게 설명합니다.

YouTube 공식 도움말은 자막이 제공되는 영상에서만 CC 기능을 사용할 수 있다고 안내합니다. 또한 음성 인식으로 자동 자막을 만들 수 있지만, 영상의 음질이나 언어·처리 상태 등에 따라 자동 자막이 생성되지 않을 수 있습니다. 따라서 모든 영상에 한국어 자동번역을 강제로 켜는 만능 설정은 없습니다.

CC는 켜지지만 영어로만 표시설정 → 자막 → 자동 번역한국어 자막 언어를 선택하지 않음
자동 번역 항목이 보이지 않음원본 자막 트랙 유무번역할 자막이 없거나 해당 환경에서 선택 불가
한국어 선택했는데 글자가 부정확원본 자막 품질자동 음성 인식·기계 번역의 정확도 한계

핵심 질문: 한 영상에서만 안 되나요, 아니면 여러 영상에서 똑같이 안 되나요? 이 질문에 대한 답이 원인 파악 시간을 크게 줄여 줍니다.

2. 먼저 '서로 다른 영상 2개'로 비교하세요

문제가 생긴 영상 A를 그대로 둔 채, 평소 자막이 정상적으로 표시되던 영상 B를 하나 더 열어 보세요.

  1. 영상 A에서 자막(CC) 아이콘과 자막 언어 목록을 확인합니다.
  2. 영상 B에서도 동일한 위치를 확인합니다.
  3. B에서는 한국어 자동 번역이 되는데 A에서만 안 된다면, 기기 전체 고장보다는 A 영상의 자막 제공 상태부터 살펴봅니다.
  4. 두 영상 모두 안 된다면 앱 설정, 현재 로그인 환경, 브라우저·앱 상태를 비교합니다.

이 비교는 이 글에서 제안하는 2영상 비교 진단법입니다. 공식 기능 이름이나 YouTube가 보장하는 검사법은 아닙니다. 그러나 원본 자막 유무와 기기 설정 문제를 분리하는 데 유용합니다.

3. PC에서 영어 자막을 한국어로 바꾸는 순서

크롬이나 엣지 등 PC 브라우저로 YouTube 영상을 시청 중이라면 먼저 영상 플레이어 자체의 자막 설정을 확인합니다. 브라우저의 웹페이지 번역 기능과 YouTube의 영상 자막 번역은 다릅니다.

  1. 유튜브에서 원하는 영상을 재생합니다.
  2. 영상 오른쪽 아래의 CC 아이콘이 있다면 눌러 자막을 켭니다.
  3. 톱니바퀴(설정) → 자막 메뉴를 엽니다.
  4. 이미 제공되는 언어 목록에 한국어가 있다면 직접 선택합니다.
  5. 한국어가 없다면 메뉴에 자동 번역 항목이 제공되는지 확인합니다.
  6. 자동 번역을 선택할 수 있는 경우 한국어를 고릅니다.
  7. 선택 후 실제 대사가 한국어 자막으로 표시되는지 짧은 구간에서 확인합니다.

일부 동영상은 게시자가 직접 만든 한국어 자막을 이미 제공합니다. 이런 경우 자동 번역보다 제작자가 검토한 자막을 우선 시도하는 편이 좋습니다. 단, 직접 만든 자막도 정확성은 개별 영상에 따라 다릅니다.

자동 번역이 없다면? 새 브라우저를 설치하기 전에 같은 영상에 영어 또는 다른 언어의 원본 자막이 제공되는지부터 확인합니다. 영상 자체에 자막 트랙이 없으면 자동번역 메뉴를 사용할 수 없을 수 있습니다.

자막 크기만 문제라면? PC YouTube에서는 설정 → 자막 → 옵션을 열어 글꼴과 크기, 배경 색상 등을 조절할 수 있습니다. 자막의 표시 설정을 바꾼다고 자막이 없던 영상에 새 트랙이 만들어지지는 않습니다.

4. 갤럭시·안드로이드에서 한국어 자동번역 켜기

Android YouTube 앱에서는 영상의 자막 메뉴에서 언어를 선택할 수 있습니다. 공식 도움말에 따른 기본 원리는 다음과 같습니다.

  1. 영상을 탭해 플레이어의 버튼을 표시합니다.
  2. CC를 눌러 자막을 켭니다. CC 버튼이 없다면 이 영상에 자막이 제공되지 않는 상태일 수 있습니다.
  3. 화면의 설정 또는 더보기 → 자막을 엽니다.
  4. 제공 언어 목록에서 한국어를 찾습니다.
  5. 한국어가 없다면 자동 번역을 선택할 수 있는지 확인합니다.
  6. 자동 번역 목록에 한국어가 있다면 선택합니다.

Android 앱에서는 프로필 사진 → 설정 → 자막에서 기본 자막 표시 및 글꼴·크기 관련 옵션도 확인할 수 있습니다. 하지만 '자막을 항상 표시'하도록 설정했다고 해서 모든 영상에서 새로운 자동 자막이 생성되는 것은 아닙니다.

소리를 껐을 때만 자막이 나타난다면

YouTube는 모바일과 태블릿에서 음소거 시 표시(Show when muted) 옵션도 안내합니다. 이는 자막 표시 조건에 관한 설정입니다. 영어 자막을 한국어로 번역하는 기능과는 다르므로 두 메뉴를 혼동하지 마세요.

5. 아이폰·아이패드에서는 앱 설정과 iOS 설정을 구분

아이폰에서도 YouTube 플레이어의 CC 버튼과 자막 메뉴에서 제공 언어를 선택할 수 있습니다.

  1. YouTube 앱에서 영상을 엽니다.
  2. 화면을 탭해 자막 버튼이 나타나는지 확인합니다.
  3. 설정·더보기의 자막 메뉴를 열어 언어를 선택합니다.
  4. 한국어가 목록에 없다면 자동 번역을 선택할 수 있는지 확인합니다.
  5. 제공된다면 한국어를 선택하고 실제 출력 결과를 확인합니다.

아이폰의 설정 → 손쉬운 사용 → 자막 및 청각 장애인용 자막 메뉴는 자막의 표시 스타일과 기본 설정을 조정하는 iOS 기능입니다. 글꼴이나 크기가 불편하면 도움이 되지만, 특정 YouTube 영상에 자막 트랙이 없는 문제를 해결해 주는 것은 아닙니다.

앱 버전에 따라 메뉴 이름과 위치가 달라질 수 있습니다. 기능이 보이지 않는다고 해서 임의의 타사 APK나 비공식 프로그램을 설치할 필요는 없습니다.

6. CC 버튼이 아예 없는 이유: 설정 오류가 아닐 수도 있습니다

YouTube는 자막이 제공되는 영상에 CC 아이콘을 표시한다고 안내합니다. 즉 CC 아이콘이 없다면 먼저 '자막이 아직 생성되지 않았거나 해당 영상에서 지원되지 않는 상태'를 고려해야 합니다.

YouTube 공식 고객센터는 자동 자막이 생성되지 않을 수 있는 이유로 다음을 설명합니다.

  • 업로드 직후로, 복잡한 오디오의 자막 처리가 아직 끝나지 않음
  • 영상의 음성 언어가 자동 자막 지원 대상이 아님
  • 영상 길이가 너무 김
  • 음질이 좋지 않거나 시스템이 음성을 제대로 인식하지 못함
  • 영상 처음에 긴 무음 구간이 있음
  • 여러 화자가 동시에 말하거나 여러 언어가 뒤섞임

이 중 일부는 시청자가 설정만 바꿔 해결할 수 없는 조건입니다. 예를 들어 자막이 생성되지 않은 영상을 아무리 새로고침해도 즉시 자막이 만들어진다고 보장할 수 없습니다.

새로 올라온 영상이라면

게시자가 영상을 막 업로드했다면 자동 자막 처리가 진행 중일 수 있습니다. 일정 시간이 지난 후 다시 확인하는 것이 합리적입니다. 다만 YouTube가 모든 영상의 자막을 특정 시간 내에 완성한다고 약속하지는 않습니다.

강의 영상인데 강사의 목소리가 잘 안 들린다면

음성 인식이 어려운 구간이 많은 영상에서는 자막이 누락되거나 잘못 생성될 수 있습니다. 제작자가 직접 제공한 자막이 있는지 확인하고, 정확한 정보가 필요한 내용은 원래 음성과 함께 대조하세요.

7. 자막은 있는데 '자동 번역'이 없다면 이렇게 판단

자동 번역을 찾는 사용자가 가장 자주 혼동하는 부분은 자막의 생성과 자막의 번역입니다.

단계하는 일문제가 생길 때
① 음성 또는 제작자 제공 자료영상에 대사가 있고 별도 자막이 있거나 음성 인식 대상이 됨음질이 나쁘거나 지원 언어가 아니면 자동 자막이 없을 수 있음
② 자막 트랙 제공YouTube 플레이어가 CC와 언어 목록을 표시트랙이 없으면 CC 자체가 보이지 않을 수 있음
③ 번역 언어 선택자막의 언어를 한국어 등으로 전환자동 번역이 제공되지 않거나 선택할 자막이 없을 수 있음
④ 결과 표시번역된 자막을 영상 위에 표시자동 인식과 번역의 정확도 차이가 남을 수 있음

이 표의 ①~④는 YouTube가 공식적으로 이름을 붙인 단계가 아니라 시청자가 원인을 가려내기 위한 설명용 모델입니다.

실제 확인 순서

  1. CC 버튼이 있는지 확인합니다.
  2. CC가 있다면 어떤 언어의 자막 트랙이 있는지 확인합니다.
  3. 원본 자막을 정상적으로 보여 주는지 확인합니다.
  4. 자동 번역 메뉴가 표시되는지 확인합니다.
  5. 다른 영상에서도 동일한 현상이 나타나는지 비교합니다.

자막 트랙이 있는 영상에서도 번역 언어 선택이 안 되거나 일시적인 오류가 생길 수 있습니다. 한 영상의 자막 부재와 모든 영상에서의 앱 오류를 같은 문제로 취급하지 않는 것이 핵심입니다.

8. 영어 자막이 나온다고 자동으로 번역이 되는 것은 아닙니다

화면에 영어 자막이 보인다는 것은 영어 자막 트랙이 사용 중이라는 뜻일 수 있습니다. 음성 인식으로 영어 자막을 생성한 것과 그 자막을 한국어로 번역하는 것은 별개의 과정입니다.

'English (auto-generated)' 또는 이에 해당하는 자막을 선택했다면 우선 원어 자막이 나타납니다. 한국어로 보고 싶다면 자동 번역 기능에서 언어를 바꾸거나, 이미 제공되는 한국어 자막을 별도로 선택해야 합니다.

또한 자동 자막과 번역에는 실수가 생길 수 있습니다. YouTube는 억양·방언·배경 소음 등으로 자동 음성 인식 결과가 달라질 수 있다고 안내합니다. 의료·법률·재정·시험·업무 지시 등 의미가 중요한 문장은 번역만 믿기보다 원어 자료와 함께 확인해야 합니다.

여러 오디오 트랙이 있는 영상은?

YouTube는 여러 언어의 오디오 트랙이 있는 영상에서 자동 자막이 기본 언어에 따라 표시될 수 있다고 안내합니다. 다른 언어로 더빙된 음성이 재생된다고 반드시 그 언어의 자동 자막이 생성됐다는 뜻은 아닙니다.

원어 자막, 자동 번역 자막, 다른 언어 오디오 트랙(더빙)은 각자 기능이 다릅니다. 메뉴에서 오디오 언어를 바꾼 것인지 자막 언어를 바꾼 것인지 구분하세요.

9. 모든 영상에서 자막 메뉴가 이상하다면: 확인 순서

다른 영상에서도 자막이 갑자기 표시되지 않는다면 아래 방법을 변수 하나씩 바꿔 점검합니다.

  1. 다른 영상과 비교: 평소 자막이 보였던 영상에서도 CC가 사라졌는지 확인합니다.
  2. 플레이어 메뉴 확인: CC 버튼을 켰는지, 톱니바퀴 메뉴에서 언어가 달라지지 않았는지 확인합니다.
  3. 다른 환경 비교: 같은 영상을 PC 브라우저와 휴대폰 앱에서 각각 확인합니다. 결과가 다르면 특정 앱·브라우저 환경에 국한된 문제인지 의심할 수 있습니다.
  4. 앱 또는 브라우저 업데이트: 오래된 버전이라면 공식 앱스토어나 브라우저 업데이트 기능에서 버전을 확인합니다.
  5. 브라우저 확장 프로그램 검토: 자막을 가리는 화면 요소 변경 확장이나 사용자 스크립트를 쓰고 있다면, 해당 영향이 있는지 신중히 비교합니다.
  6. 서비스의 일시적 문제 확인: 여러 영상과 기기에서 동시에 문제가 생기면 YouTube 자체의 일시적인 상태도 가능성 중 하나입니다. 공식 도움말과 공지에서 관련 안내가 있는지 확인합니다.

주의: 업데이트나 확장 프로그램 점검은 일반적인 문제 분리 방법이지 YouTube가 이 순서만으로 자막 오류 해결을 보장하는 공식 절차는 아닙니다. 계정 로그아웃, 앱 삭제, 모든 설정 초기화부터 시도할 필요는 없습니다.

10. 자주 묻는 질문

Q. 유튜브 영상에서 CC 아이콘이 안 보이면 어떻게 하나요?

먼저 같은 기기에서 자막이 제공되는 다른 영상을 확인하세요. YouTube는 자막이 제공되는 영상에 CC 아이콘이 나타난다고 안내합니다. 특정 영상에서만 없다면 아직 자막이 준비되지 않았거나 제공되지 않을 수 있습니다.

Q. 영어 동영상에 한국어 자막을 추가할 수 있나요?

시청자가 자동 번역 기능으로 한국어를 선택할 수 있는 경우가 있습니다. 단, 해당 기능이 제공되지 않거나 원본 자막이 없는 영상이라면 항상 가능한 것은 아닙니다. 게시자가 직접 올린 한국어 자막이 있다면 그 항목을 선택할 수도 있습니다.

Q. 갤럭시에서는 되는데 아이폰에서는 자동번역이 안 보입니다.

우선 같은 영상을 비교하는지 확인하고, 각각의 자막 메뉴에 어떤 언어가 표시되는지 확인하세요. 자막의 제공 여부 자체와 앱 화면·설정 차이를 분리해 보는 것이 좋습니다. 기능 제공 상태는 앱 버전 등에 따라 달라질 수 있습니다.

Q. 영상 시작 직후에는 자막이 없고 나중에 나타납니다.

영상이 새로 업로드되어 자동 자막 처리가 끝나지 않았을 수 있습니다. 다만 YouTube는 모든 영상에 자막을 생성하는 것은 아니며 처리 시간도 영상의 오디오 특성에 따라 달라질 수 있다고 설명합니다.

Q. 외국어 영상인데 한국어 더빙은 나오고 자막은 없습니다.

더빙 음성과 화면 자막은 서로 다른 트랙입니다. 오디오 언어를 선택했다고 같은 언어의 자막이 자동으로 생기는 것은 아닙니다. 자막 메뉴에서 별도로 제공 여부를 확인하세요.

Q. 쇼츠(Shorts)에도 자동 자막이 있나요?

YouTube 공식 안내는 긴 형식 영상과 Shorts 영상 모두에서 자동 자막을 지원한다고 설명합니다. 그러나 개별 쇼츠에서 항상 생성되는 것은 아닙니다. 실제 자막의 제공 상태와 앱 표시 방식을 확인해야 합니다.

Q. 한국어 자동번역 글자가 틀리는 이유는 무엇인가요?

자동 음성 인식이 원래 말을 잘못 받아썼거나, 그 텍스트를 번역하는 과정에서 의미가 달라질 수 있습니다. 고유명사·전문 용어·짧은 문맥은 특히 원어와 대조해 확인하는 것이 좋습니다.

11. 3분 해결 체크리스트와 결론

  • ☐ 문제 영상에 CC 버튼이 있는지 확인했다.
  • ☐ 자막이 있다면 현재 선택된 언어를 확인했다.
  • ☐ 설정 → 자막 → 자동 번역 → 한국어가 제공되는지 확인했다.
  • ☐ 한국어 자막이 이미 제작되어 있는지 확인했다.
  • ☐ 같은 기기에서 다른 영상과 비교했다.
  • ☐ 모바일과 PC에서 결과가 다르다면 각 앱의 설정을 점검했다.
  • ☐ 자막이 없는 영상은 모든 설정으로 즉시 해결되지 않을 수 있음을 이해했다.

유튜브 자막 문제의 상당 부분은 '자막 생성 실패'와 '자막 언어 선택 실패'를 혼동하는 데서 복잡해집니다. 영상 두 개를 비교하고 CC 제공 여부를 먼저 확인하세요. 그런 다음 한국어 직접 자막 또는 자동 번역을 선택하면 불필요한 설정 변경을 줄일 수 있습니다.
