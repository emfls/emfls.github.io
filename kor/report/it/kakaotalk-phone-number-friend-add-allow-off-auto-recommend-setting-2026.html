먼저 결론부터: 내 번호를 저장한 사람이 나를 새 카카오톡 친구로 추가하지 못하게 하고 싶다면 '전화번호로 친구 추가 허용'을 꺼야 합니다. 내 휴대폰 주소록의 사람이 카카오톡 친구 목록에 자동으로 들어오는 것을 막으려면 '자동 친구 추가'를 꺼야 합니다. 남에게 추천되는 노출을 줄이려면 '친구 추천 허용'을 따로 확인해야 합니다.

이 글은 2026년 11월 기준으로 카카오 공식 발표와 현재 공개된 앱 설정 안내를 구분해 설명합니다. 카카오톡 업데이트와 OS·계정 상태에 따라 메뉴 위치 또는 표시 방식이 달라질 수 있습니다.

이 표의 핵심은 방향입니다. 남이 나를 번호로 추가하는 것과 내가 남을 자동으로 추가하는 것은 서로 반대쪽 동작입니다.

특히 '친구 추천 허용'을 껐을 때 내 화면의 추천친구 목록도 반드시 사라지는지는 공식 도움말의 표현과 일부 2026년 앱 실측 결과에 차이가 있습니다. 따라서 추천 허용을 껐다는 사실만으로 '추천친구 목록이 완전히 없어졌다'거나 '내 계정이 모든 경로에서 숨겨졌다'고 단정하지 않는 것이 정확합니다.

카카오가 직접 발표한 '전화번호로 친구 추가 허용'의 효과는 명확합니다. 카카오에 따르면 이 옵션을 비활성화하면 다른 사람이 내 전화번호를 저장하거나 번호로 검색해도 해당 경로로 친구를 추가할 수 없습니다. 대신 카카오톡 ID·QR코드·단체채팅방 프로필로 추가하는 방법은 남아 있습니다.

2. 내 전화번호를 저장한 사람이 나를 카톡 친구로 추가하지 못하게 하는 방법

다른 사람이 내 번호를 알더라도 새 카카오톡 친구가 되는 것을 원하지 않는 경우의 설정입니다.

  1. 스마트폰에서 카카오톡 앱을 엽니다.
  2. 설정(톱니바퀴)으로 들어갑니다. 화면 구성에 따라 더보기 또는 친구 탭에서 전체 설정으로 이동합니다.
  3. 친구 메뉴에서 친구 등록 관리가 보이면 선택합니다.
  4. 전화번호로 친구 추가 허용을 찾아 끔으로 바꿉니다.
  5. 항목이 보이지 않는 구버전·다른 UI라면 프로필 관리 안에도 같은 이름의 옵션이 있는지 확인하고, 카카오톡을 최신 버전으로 업데이트합니다.

중요한 한계: 이 스위치는 새로운 전화번호 기반 추가 시도를 제한합니다. 이전에 친구로 추가된 상대의 등록 관계를 자동으로 끊거나, 이미 만들어진 채팅방을 삭제하거나, 카카오톡 ID·QR 경로까지 모두 차단한다는 뜻은 아닙니다.

회사 연락용 번호를 거래처와 자주 교환하는 사람, 중고거래에서 휴대폰 번호를 알려준 사람에게 특히 유용한 설정입니다. 다만 번호를 교환할 때부터 이 옵션을 꺼두는 편이 좋습니다. 이미 등록된 상대는 별도로 처리해야 합니다.

3. 내 휴대폰 연락처가 카카오톡 친구에 자동으로 뜨지 않게 하는 방법

내 휴대폰에 저장된 모든 연락처를 카카오톡 친구로 만들고 싶지 않다면 '자동 친구 추가'를 확인합니다.

  1. 카카오톡 전체 설정 → 친구 → 친구 등록 관리로 이동합니다.
  2. 자동 친구 추가 옵션을 끕니다.
  3. 친구 탭으로 돌아와 현재 등록된 친구를 확인합니다.
  4. 이미 등록돼 있는 사람을 정리해야 한다면 친구 메뉴의 숨김·차단·삭제를 용도에 맞게 사용합니다.

자동 친구 추가 끄기 = 기존 친구 일괄 삭제가 아닙니다. 이미 카카오톡 친구로 등록돼 있던 사람이나 채팅방은 그대로 남을 수 있습니다.

일부 Android·iPhone에서는 앱의 연락처 접근 권한도 관리할 수 있지만, 휴대폰 OS에서 연락처 권한을 완전히 끄면 번호 기반 연락처 동기화와 관련 기능이 제한될 수 있습니다. 설정을 바꾸기 전 필요한 연락처 검색·친구 추가 기능이 무엇인지 먼저 확인하세요.

친구 추가가 필요한 경우에는?

자동 친구 추가를 꺼도 QR코드나 카카오톡 ID를 이용해 필요한 사람을 수동으로 추가할 수 있습니다. 다만 상대가 자신의 ID 검색 허용을 제한한 경우에는 검색으로 추가되지 않을 수 있습니다.

4. '친구 추천 허용'을 끄면 추천친구 목록도 없어질까?

'친구 추천 허용'은 추천과 관련된 설정이지 전화번호 친구 추가 차단 기능과 동일하지 않습니다. 이 옵션을 끄면 일반적으로 다른 사용자에게 내가 추천되는 노출을 제한하는 방향으로 작동합니다.

여기서 주의할 점이 있습니다. 공개된 카카오 고객센터 설명에는 추천 관계가 양방향으로 표현되기도 하지만, 2026년 9월 갤럭시 앱의 사용자 실측 안내에서는 해당 스위치를 꺼도 내 친구 화면의 '추천친구' 항목이 남아 있었습니다. 그러므로 추천 탭이 사라지는지는 실제 설치된 앱에서 직접 확인해야 합니다.

권장 확인 순서

  • 전체 설정 → 친구 또는 친구 등록 관리에서 '친구 추천 허용'을 끕니다.
  • 친구 탭에서 추천친구 항목이 실제로 어떻게 표시되는지 확인합니다.
  • 원치 않는 특정 추천 계정은 추천 목록에서 삭제할 수 있는지 확인합니다.
  • 상대가 이미 친구로 등록돼 있다면 친구 관리에서 숨김·차단·삭제를 별도로 검토합니다.

추천친구가 뜨는 정확한 알고리즘은 일반 사용자에게 공개돼 있지 않습니다. '나를 조회한 사람이다' 또는 '내 프로필을 훔쳐본 사람이다'라는 추측은 사실로 받아들이지 마세요. 전화번호 저장이나 기존 등록 관계 등 여러 가능성을 살펴야 합니다.

5. 목적별로 실제 필요한 조합

상황 A: 거래처에 전화번호는 알려줘야 하지만 카카오톡 친구로 추가되는 것은 싫다

전화번호로 친구 추가 허용 → 끔이 우선입니다. 거래처와 카톡 대화를 할 필요가 생기면 필요한 사람에게만 카카오톡 ID나 QR코드를 알려주는 방식으로 접근할 수 있습니다.

상황 B: 새 휴대폰으로 바꾼 뒤 저장된 연락처가 카톡 친구로 대거 들어왔다

앞으로의 자동 등록을 막으려면 자동 친구 추가 → 끔을 먼저 확인합니다. 이미 등록된 사람은 일괄 설정으로 없어지지 않으므로 친구별로 정리해야 합니다. 단순 숨김·삭제는 상대가 메시지를 보내는 것까지 막는 차단과 다릅니다.

상황 C: 내가 다른 사람의 '알 수도 있는 친구'에 추천되는 것이 싫다

친구 추천 허용 → 끔을 검토합니다. 아울러 번호 저장을 통한 직접 추가도 원하지 않으면 전화번호로 친구 추가 허용 → 끔을 추가로 적용하세요. 두 설정을 모두 껐더라도 ID·QR·단체방 경로까지 모두 사라지는 것은 아닙니다.

상황 D: 딱 한 명에게서 오는 카카오톡 메시지를 받고 싶지 않다

설정 세 가지 중 어느 것도 이미 존재하는 상대에게서 오는 메시지를 확실하게 막는 개별 차단과 같지 않습니다. 특정 대화 상대의 메시지를 받지 않으려면 별도 친구 차단 기능을 사용해야 합니다.

6. 옵션이 안 보이거나, 끄고도 친구가 생길 때 확인할 것

증상먼저 확인할 것오해하기 쉬운 부분
'전화번호로 친구 추가 허용'이 안 보임앱 업데이트, '친구 등록 관리'와 '프로필 관리' 위치 확인옛날 안내와 현재 메뉴가 다를 수 있음
자동 친구 추가를 껐는데 기존 친구가 그대로 있음이미 등록됐던 친구인지 확인해당 스위치는 기존 친구 삭제 기능이 아님
번호 추가 허용을 껐는데 상대와 채팅 중기존 친구·채팅방 관계였는지 확인기존 관계를 지우는 기능이 아님
추천 허용을 껐는데 추천친구 목록이 남아 있음실제 앱 버전과 추천 목록 표시 방식 확인추천 설정과 UI 항목 숨김은 다를 수 있음
상대의 번호를 저장해도 친구로 안 뜸상대의 번호 기반 추가 허용, 내 자동 친구 추가, 연락처 권한 확인상대가 비허용이라면 내 설정만으로 강제 추가 불가
특정 사람이 계속 연락함친구 차단 기능 확인숨김·삭제와 차단을 혼동하지 않기

설정 변경 후에는 무작정 재설치하지 마세요. 카카오톡 재설치는 메시지 백업·복원과 관련된 위험이 있습니다. 먼저 앱 업데이트, 설정 상태, 해당 인물이 기존 친구인지부터 확인하는 것이 안전합니다.

7. 30초 개인정보 설정 체크리스트

  • ☐ 상대가 내 번호로 친구 추가하는 것을 원하지 않아 '전화번호로 친구 추가 허용'을 껐다.
  • ☐ 내가 저장한 전화번호가 자동으로 카톡 친구가 되지 않게 '자동 친구 추가'를 확인했다.
  • ☐ 다른 사람에게 나를 추천하는 설정을 제한하고 싶은지 판단해 '친구 추천 허용'을 확인했다.
  • ☐ 기존 친구, 기존 채팅방, ID·QR 추가 가능성은 별도임을 이해했다.
  • ☐ 특정 인물과 메시지를 주고받지 않으려는 경우 친구 차단을 별도로 설정했다.

자주 묻는 질문

Q. 전화번호로 친구 추가 허용을 끄면 상대방의 친구 목록에서 내가 바로 없어지나요?

아닙니다. 카카오 공식 발표는 전화번호를 통한 새로운 친구 추가를 제한하는 기능이라고 설명합니다. 이미 등록된 친구나 기존 채팅 상대까지 즉시 삭제된다고 안내하지 않습니다.

Q. 내가 내 연락처에 상대를 저장하면 상대방 친구 목록에도 내가 뜨나요?

내가 상대를 연락처에 저장하는 것과 상대가 내 번호를 저장하는 것은 구별해야 합니다. 내 연락처 저장은 주로 내 카카오톡의 자동 친구 추가에 영향을 줍니다. 상대방 쪽 친구 추가는 상대방이 어떤 번호를 가지고 있는지와 나의 번호 기반 추가 허용 설정 등과 관련됩니다.

Q. 친구 추천 허용 OFF는 프로필을 완전히 비공개로 만드는 기능인가요?

아닙니다. 이는 추천 노출 관련 설정이며, 모든 카카오톡 경로에서 프로필을 숨기는 전면 비공개 기능이 아닙니다. 필요한 경우 번호 기반 추가 제한, ID 관련 설정, 개별 차단을 따로 살펴야 합니다.

Q. 모르는 사람이 내 추천친구에 뜨면 그 사람이 내 프로필을 봤다는 뜻인가요?

그렇게 단정할 수 없습니다. 추천 순서와 상대 노출의 전체 산식은 공개돼 있지 않으므로 '프로필 방문자'라고 해석하는 것은 근거가 부족합니다.

Q. 아이폰과 갤럭시의 설정 이름이 완전히 같나요?

큰 기능 이름은 유사할 수 있지만 카카오톡 앱 버전, 운영체제, UI 개편에 따라 메뉴 위치가 달라집니다. 찾을 수 없을 때는 메뉴 이름 '친구 등록 관리', '전화번호로 친구 추가 허용'을 기준으로 확인하세요.

Q. 전화번호 추가를 막은 상태에서도 다른 사람에게 카톡 ID로 친구 추가를 받을 수 있나요?

네. 카카오 공식 발표에서는 전화번호 기반 추가를 끈 사용자를 카카오톡 ID나 QR코드, 단체방 프로필을 통해 추가할 수 있다고 명시합니다. 해당 경로에도 별도 제한이 있는지는 현재 설정에서 확인해야 합니다.

핵심 정리

카카오톡 친구 문제를 해결할 때 기억할 것은 딱 세 문장입니다.

다른 사람이 내 번호로 나를 추가하는 것을 막고 싶다 → 전화번호로 친구 추가 허용 OFF.

내 연락처의 사람이 내 카톡 친구로 자동 등록되는 것을 막고 싶다 → 자동 친구 추가 OFF.

추천 노출을 줄이고 싶다 → 친구 추천 허용 OFF 후 실제 화면 확인.

이미 친구로 등록된 사람을 정리하거나 그 사람의 메시지를 차단하는 일은 또 다른 조치입니다. 위 세 가지를 구분하면 불필요한 재설치나 연락처 전체 삭제 없이 원하는 방향으로 설정할 수 있습니다.
