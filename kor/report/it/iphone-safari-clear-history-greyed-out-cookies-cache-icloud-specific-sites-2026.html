아이폰에서 Safari 방문 기록을 지우고 싶은데 '방문 기록 및 웹사이트 데이터 지우기'가 회색으로 표시되거나, 인터넷 검색 기록은 남기고 쿠키·캐시만 삭제하고 싶을 수 있습니다. 반대로 특정 사이트의 방문 기록만 골라 지우거나, 맥북·아이패드에도 검색 기록이 동기화되는지 궁금한 경우도 있습니다.

핵심은 세 기능을 구분하는 것입니다. ① 방문 기록·웹사이트 데이터 함께 지우기, ② 방문 기록은 보존하고 쿠키·캐시만 지우기, ③ Safari 방문 기록에서 특정 웹사이트만 삭제하기는 서로 다른 메뉴입니다. 또 Safari에서 기록을 지운다고 Google 계정의 검색 활동이나 Chrome 방문 기록까지 자동으로 지워지는 것은 아닙니다.

검증 기준: 2026년 11월 4일. Apple의 2026년 9월 21일 갱신 고객지원 문서와 iPhone·iCloud 사용 설명서를 기준으로 작성했습니다. iOS 버전·Safari 프로필·스크린 타임·기기 관리 정책에 따라 표시 메뉴가 다를 수 있습니다.

지난 1시간 등 기간을 지정해 기록 지우기Safari의 방문 기록 → 기록 지우기선택 기간의 방문 기록

주의: 방문 기록은 '이전에 열었던 페이지 목록'이고, 쿠키는 사이트가 로그인 상태 등을 기억하기 위해 저장하는 정보이며, 캐시는 웹사이트의 일부 데이터를 임시로 보관하는 기능입니다. 지우는 범위에 따라 로그인 상태나 웹사이트 사용 편의성이 달라질 수 있습니다.

2. 가장 빠른 방법: 설정에서 Safari 기록 지우기

최신 Apple 공식 안내는 다음 경로를 제시합니다.

  1. 아이폰의 설정 앱을 엽니다.
  2. 앱 → Safari를 선택합니다.
  3. 화면을 내려 '방문 기록 및 웹사이트 데이터 지우기'를 누릅니다.
  4. 화면에 표시되는 삭제 기간을 확인합니다.
  5. 필요한 기간을 선택한 뒤 '방문 기록 지우기'를 누릅니다.
  6. Safari를 다시 열어 실제 방문 기록이 정리됐는지 확인합니다.

놓치기 쉬운 점: iOS 버전에 따라 인터넷의 오래된 안내처럼 설정 첫 화면에 Safari가 바로 나타나지 않을 수 있습니다. 이때는 설정 → 앱 → Safari 경로를 확인하세요.

Apple은 이 방법으로 기록을 지워도 자동 완성 정보는 변경되지 않는다고 설명합니다. 하지만 쿠키와 웹사이트 데이터가 제거되면 사용 중인 사이트에서 다시 로그인을 요구할 수 있습니다. 따라서 'Safari 기록 삭제 = 저장된 모든 비밀번호 삭제'와 동일한 의미로 설명하면 안 됩니다.

공식 근거: Apple 고객지원 — 설정 앱에서 방문 기록 지우기

3. 지난 1시간만 삭제하거나 특정 기간을 선택하기

과거의 모든 기록을 지우고 싶지 않다면, Apple이 제공하는 기간 선택 기능을 이용하세요.

Safari 앱에서 기간 지정

  1. Safari를 엽니다.
  2. 시작 페이지에서 방문 기록 메뉴를 엽니다. 탭 구성에 따라 북마크 보기 → 방문 기록 순서가 필요할 수 있습니다.
  3. 더 보기(점 세 개) 메뉴를 선택합니다.
  4. 기록 지우기를 누릅니다.
  5. 표시된 옵션에서 지난 1시간 등 지우려는 기간을 확인합니다.
  6. Safari 프로필을 사용한다면 해당 프로필 또는 모든 프로필 중 적절한 범위를 선택합니다.
  7. 삭제를 실행한 뒤 기록 목록에서 결과를 확인합니다.

삭제 범위 확인: Safari의 전체 기록을 정리할 필요 없이 특정 시간에 열었던 웹페이지 기록만 없애려는 경우에는 삭제 기간과 프로필을 확인한 뒤 실행하는 것이 중요합니다.

Apple의 최신 iPhone 사용 설명서는 기간 및 프로필을 선택해 Safari 방문 기록을 지우는 방법을 안내합니다.

공식 근거: Apple iPhone 사용 설명서 — 캐시 및 쿠키 지우기

4. 특정 사이트 방문 기록만 골라 삭제하기

'전체 기록 지우기'를 누르면 필요했던 과거 방문 경로도 사라질 수 있습니다. 특정 웹사이트 방문 기록만 삭제하고 싶다면 Apple이 안내하는 웹사이트 선택 기능을 먼저 확인하세요.

특정 사이트 삭제 순서

  1. Safari 앱을 엽니다.
  2. 시작 페이지에서 방문 기록 아이콘을 엽니다.
  3. 오른쪽의 더 보기 메뉴를 선택합니다.
  4. '웹사이트 선택'을 누릅니다.
  5. 삭제할 사이트의 방문 기록을 한 개 이상 선택합니다.
  6. 휴지통 버튼을 눌러 삭제합니다.
  7. 방문 기록 목록에 해당 항목이 남아 있는지 확인합니다.

중요한 차이: 이 방법은 Safari의 방문 기록 목록에서 특정 항목을 정리하는 것입니다. 해당 사이트의 계정 서버에 저장된 검색기록이나 개인 프로필·구매 이력을 삭제한다고 보장하지 않습니다.

또한 특정 사이트 기록을 선택해 지우는 기능과 사이트의 쿠키·로그인 정보만 삭제하는 기능은 다릅니다. 목적에 따라 메뉴를 구분하세요.

공식 근거: Apple — 방문 기록에서 특정 웹사이트 삭제

5. '방문 기록 및 웹사이트 데이터 지우기' 버튼이 회색일 때

사파리 기록을 지우려는데 버튼이 회색으로 비활성화돼 있다면, Apple은 다음 두 가지를 주요 점검 대상으로 제시합니다.

  • 삭제할 방문 기록·웹사이트 데이터가 없는 경우
  • 스크린 타임의 웹 콘텐츠 제한이 설정된 경우

1단계 — 지울 기록이 있는지 확인

Safari를 열고 방문 기록 목록을 확인합니다. 이미 지운 직후이거나 Safari에서 일반 브라우징 기록이 없는 상태라면 버튼이 비활성화될 수 있습니다.

2단계 — 스크린 타임 제한 확인

  1. 설정 → 스크린 타임을 엽니다.
  2. 콘텐츠 및 개인정보 보호 제한이 설정돼 있는지 확인합니다.
  3. 웹 콘텐츠 관련 제한 항목을 확인합니다.
  4. 가족 공유·자녀 계정이라면 보호자 정책이 적용 중인지 확인합니다.
  5. 변경 권한이 있는 경우에만 제한을 조정하고 Safari 설정으로 돌아가 다시 확인합니다.

안전·권한 주의: 자녀의 기기나 회사·학교가 관리하는 기기에서는 제한이 의도적으로 설정됐을 수 있습니다. 본인이 관리 권한이 없다면 정책을 우회하려고 시도하기보다 보호자나 담당 관리자에게 문의하세요.

Apple이 '버튼이 회색이면 무조건 오류'라고 안내하는 것은 아닙니다. 삭제할 데이터가 없는 정상 상태일 가능성도 먼저 확인하세요.

공식 근거: Apple — Safari 기록 지우기 버튼이 회색인 경우

6. 방문 기록은 남기고 쿠키·캐시만 삭제하기

'어제 열었던 웹페이지는 남겨두되 사이트 로그인이 꼬여서 쿠키만 정리하고 싶다'면 전체 기록 삭제 대신 Apple의 별도 메뉴를 이용하세요.

Apple 공식 경로

  1. 설정을 엽니다.
  2. 앱 → Safari를 선택합니다.
  3. 아래로 내려 고급을 엽니다.
  4. 웹사이트 데이터를 선택합니다.
  5. '모든 웹사이트 데이터 제거'를 누릅니다.
  6. 지금 제거를 눌러 확인합니다.

Apple은 이 작업이 추적 등에 쓰이고 사이트 로그인 상태를 유지하는 데 사용되는 데이터를 제거한다고 설명합니다. 따라서 웹사이트에서 다시 로그인해야 하거나 일부 개인 설정이 초기화될 수 있습니다.

7. 쿠키를 모두 차단하면 개인정보 보호에 더 좋을까?

쿠키는 로그인 유지와 사이트 기본 기능에도 활용됩니다. 무조건 모든 쿠키를 차단하면 정상적인 웹페이지조차 사용하기 어려워질 수 있습니다.

Apple의 설정 경로는 설정 → 앱 → Safari → 고급 → 모든 쿠키 차단입니다. 그러나 Apple은 이 설정을 켜면 일부 사이트에서 다음 문제가 발생할 수 있다고 경고합니다.

  • 정확한 아이디와 비밀번호를 입력해도 로그인되지 않을 수 있음
  • 쿠키를 허용하라는 메시지가 반복됨
  • 사이트의 쇼핑·예약 등 일부 기능이 정상 작동하지 않을 수 있음
  • 기존 쿠키와 웹사이트 데이터가 제거될 수 있음

권장 원칙: 단지 방문 기록을 정리하는 목적이라면 '모든 쿠키 차단'을 켜는 것과 기록 삭제를 혼동하지 마세요. 문제를 일으키는 사이트가 있는 경우도 먼저 기본적인 데이터 정리와 사이트 지원 안내를 확인하는 편이 낫습니다.

공식 근거: Apple — Safari에서 모든 쿠키 차단 시 영향

8. 사파리 기록을 지웠는데 맥북·아이패드에 기록이 남을까?

iCloud의 Safari 동기화 설정에 따라 여러 기기에 브라우징 정보가 연동될 수 있습니다.

Apple은 iCloud의 Safari 기능이 방문 기록·북마크·읽기 목록·열려 있는 탭·탭 그룹·프로필 등을 기기 간 최신 상태로 유지한다고 안내합니다.

iCloud Safari 설정 확인

  1. 아이폰 설정을 엽니다.
  2. 본인의 Apple 계정 이름을 선택합니다.
  3. iCloud로 이동합니다.
  4. 전체 보기/모두 보기에서 Safari를 찾습니다.
  5. Safari의 iCloud 동기화가 켜져 있는지 확인합니다.
  6. 동일한 Apple 계정으로 로그인한 Mac·iPad에서도 Safari 설정을 비교합니다.

해석에 주의하세요. iCloud Safari가 활성화돼 있다면 기록 변경이 기기 간 반영될 수 있습니다. 하지만 동기화 상태·오프라인 기기·프로필·다른 브라우저 사용 등에 따라 표시가 다를 수 있으므로 실제 각 기기의 기록 목록을 확인하는 것이 좋습니다.

'아이폰에서 삭제하면 모든 기기의 모든 브라우저 기록이 즉시 지워진다'고 설명하면 부정확합니다.

9. 기록 삭제와 개인정보 보호 브라우징은 다릅니다

방문 기록을 사후에 지우는 것과 앞으로 새로운 기록을 Safari에 남기지 않도록 비공개로 탐색하는 것은 목적이 다릅니다.

Apple은 Safari의 개인정보 보호 브라우징을 사용하면 방문 페이지·검색 내역·자동 완성 정보가 일반 방문 기록처럼 저장되지 않는다고 안내합니다.

최신 iPhone에서 개인정보 보호 탭 열기

  1. Safari 앱을 엽니다.
  2. 더 보기 메뉴를 선택합니다.
  3. 새로운 개인정보 보호 탭을 누릅니다.
  4. 주소 막대가 어두운색으로 표시되는지 확인합니다.
  5. 비공개 탐색이 끝난 뒤 필요에 따라 해당 탭을 닫습니다.

iOS 버전이 오래된 기기에서는 탭 버튼 → 개인정보 보호 탭 그룹으로 이동할 수 있습니다.

중요: 비공개 브라우징은 기기 Safari의 일반 방문 기록에 남기지 않는 기능이지 웹사이트·인터넷 제공업체·조직 네트워크에서 모든 활동이 보이지 않는다는 뜻이 아닙니다. 신원을 감추거나 인터넷에서 완전히 익명으로 만드는 기능이라고 이해하면 안 됩니다.

11. 기록 삭제 후에도 추천 사이트·자동완성이 보이는 이유

Safari의 방문 기록을 삭제한 뒤에도 웹사이트 추천·북마크·검색 엔진 제안·저장된 자동 완성 정보가 보일 수 있습니다.

Apple은 Safari 방문 기록과 웹사이트 데이터를 지우는 작업이 자동 완성 정보를 변경하지 않는다고 안내합니다. 또 iCloud Safari는 북마크·읽기 목록·탭 같은 항목을 별도로 동기화할 수 있습니다.

다음처럼 원인을 나눠 보세요.

  1. 입력창의 제안이 Safari의 실제 방문 기록 목록인지 확인합니다.
  2. 이전에 저장한 북마크·즐겨찾기 사이트인지 확인합니다.
  3. 검색 엔진에서 제공하는 검색어 제안인지 구별합니다.
  4. 같은 Apple 계정으로 동기화된 다른 기기의 Safari가 있는지 확인합니다.
  5. 특정 웹사이트의 로그인 상태라면 웹사이트 데이터 정리가 필요한지 판단합니다.

핵심: 기록을 지웠는데 추천 단어가 다시 보인다는 이유만으로 Safari가 삭제에 실패했다고 단정할 수 없습니다.

13. 한 사이트가 계속 오류를 내서 캐시를 지우려면?

Safari에서 웹사이트가 열리지 않거나 오래된 화면만 표시될 때는 웹사이트 데이터 정리가 문제 해결 과정에 포함될 수 있습니다.

먼저 할 일

  1. 같은 사이트가 다른 브라우저·기기에서는 정상인지 비교합니다.
  2. iPhone의 인터넷 연결을 확인합니다.
  3. Safari에서 해당 사이트를 다시 로드합니다.
  4. 필요하다면 설정 → 앱 → Safari → 고급 → 웹사이트 데이터를 확인합니다.
  5. 데이터 삭제 전 로그인 상태·사이트 개인 설정에 영향이 있을 수 있음을 이해합니다.
  6. 필요하다고 판단되면 웹사이트 데이터를 제거하고 다시 사이트에 접속합니다.

Apple은 Safari 로딩 오류의 점검 항목 중 하나로 방문 기록과 웹사이트 데이터 지우기를 안내합니다. 다만 특정 사이트만 접속할 수 없는 경우 사이트 자체의 장애나 계정 문제일 수도 있으므로 캐시 삭제를 만능 해결책으로 안내해서는 안 됩니다.

15. 자주 묻는 질문(FAQ)

Q1. 아이폰 Safari 방문 기록은 어디서 삭제하나요?

최신 Apple 공식 안내 기준 설정 → 앱 → Safari → 방문 기록 및 웹사이트 데이터 지우기에서 기간을 선택해 지울 수 있습니다.

Q2. 사파리 방문 기록 지우기 버튼이 회색인 이유는 무엇인가요?

Apple은 지울 데이터가 없는 경우 또는 스크린 타임의 웹 콘텐츠 제한이 적용된 경우를 점검하라고 안내합니다.

Q3. 지난 1시간 기록만 삭제할 수 있나요?

네. Safari 앱의 방문 기록에서 기록 지우기를 열어 제공되는 기간 옵션을 선택할 수 있습니다.

Q4. 특정 웹사이트 방문 기록만 지우는 방법이 있나요?

Safari의 방문 기록에서 더 보기 → 웹사이트 선택 → 삭제할 사이트 선택 → 휴지통 순서로 진행할 수 있습니다.

Q5. Safari 방문 기록을 남기고 쿠키만 지울 수 있나요?

Apple 공식 경로는 설정 → 앱 → Safari → 고급 → 웹사이트 데이터 → 모든 웹사이트 데이터 제거입니다. 사이트 로그인 상태 등에 영향이 있을 수 있습니다.

Q6. 방문 기록을 지우면 비밀번호가 전부 삭제되나요?

그렇게 단정할 수 없습니다. Apple은 기록을 지워도 자동 완성 정보는 변경되지 않는다고 설명합니다. 하지만 쿠키를 지우면 웹사이트에서 다시 로그인해야 할 수 있습니다.

Q7. 아이폰에서 지우면 맥북 Safari 기록도 지워지나요?

Safari의 iCloud 동기화가 켜져 있다면 기록 등의 변경 사항이 같은 Apple 계정의 다른 기기에 반영될 수 있습니다. 실제 각 기기의 동기화 상태를 확인하세요.

Q8. Safari 기록을 지웠는데 Google 검색 내역은 남아 있어요.

Google 계정의 웹·앱 활동은 Safari 방문 기록과 별개로 저장될 수 있기 때문입니다. Google 계정의 활동 관리에서 별도로 확인해야 합니다.

Q9. 비공개 브라우징을 사용하면 방문 기록을 삭제할 필요가 없나요?

Safari의 개인정보 보호 브라우징은 일반 방문 기록에 해당 탐색 내역을 남기지 않는 방식입니다. 하지만 모든 인터넷 활동을 완전히 익명으로 만드는 것은 아닙니다.

Q10. 기록을 삭제하면 파일 앱에 다운로드한 PDF도 지워지나요?

방문 기록 삭제와 파일 앱에 저장한 다운로드 파일 삭제는 다른 작업입니다. 저장한 PDF는 파일 앱에서 별도로 확인할 수 있습니다.

Q11. 모든 쿠키를 차단해도 되나요?

가능하지만 Apple은 웹사이트 로그인 실패·일부 기능 미작동을 경고합니다. 기록 삭제만 필요하다면 무조건 쿠키 차단까지 활성화할 필요는 없습니다.

Q12. Safari 기록을 지웠는데 예전에 방문한 사이트가 추천에 나옵니다.

북마크, 읽기 목록, 검색 엔진 제안 또는 자동 완성 등 방문 기록과 별도로 유지되는 정보일 수 있습니다. 실제 방문 기록 목록과 구분해야 합니다.

결론

아이폰 사파리 방문 기록을 지우려면 '설정 → 앱 → Safari → 방문 기록 및 웹사이트 데이터 지우기'에서 기간을 선택하세요. 특정 사이트만 지우려면 Safari 앱의 방문 기록에서 웹사이트 선택을 이용하고, 기록은 남긴 채 로그인 쿠키·캐시만 정리하려면 고급 → 웹사이트 데이터를 이용하면 됩니다.

버튼이 회색이라면 삭제할 데이터 유무와 스크린 타임의 웹 콘텐츠 제한부터 확인하세요. iCloud Safari 동기화, Google 계정 활동, Chrome 기록은 서로 저장 위치가 다를 수 있으므로 실제로 어느 데이터를 지우려는지 구분하는 것이 가장 중요합니다.
