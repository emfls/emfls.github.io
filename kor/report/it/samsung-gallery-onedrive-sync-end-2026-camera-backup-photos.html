갤럭시 스마트폰에서 삼성 갤러리를 열었는데 예전에 원드라이브에 저장한 사진이 보이지 않거나, 새로 찍은 사진이 클라우드에 올라가지 않나요? 예전처럼 삼성 갤러리의 'OneDrive에 동기화' 메뉴를 찾을 수 없어 당황한 사용자도 있을 수 있습니다.

이 현상은 휴대전화의 사진 파일이 한꺼번에 지워진 것과는 다릅니다. Microsoft는 2026년 9월 30일부터 삼성 갤러리와 원드라이브(OneDrive)의 직접 동기화가 종료된다고 공식 안내했습니다. 이미 원드라이브에 업로드한 사진과 동영상은 유지되지만, 삼성 갤러리에서 그 클라우드 사진을 이전처럼 바로 보여주는 방식은 지원되지 않습니다.

따라서 지금 할 일은 휴대전화를 초기화하는 것이 아닙니다. 원드라이브에서 기존 사진 확인 → OneDrive 앱에서 카메라 백업 활성화 → 새 사진의 업로드 상태 점검 순서로 확인하면 됩니다. 이 글에서는 Microsoft의 공식 지원 문서를 기준으로 데이터가 어디에 남는지, 어떤 설정을 바꿔야 하는지, 삭제된 파일은 어디서 복구하는지까지 정리합니다.

핵심 요약: 2026년 9월 30일 이후 무엇이 달라졌나요?

  • 변경일: 2026년 9월 30일
  • 종료된 기능: 삼성 갤러리 앱과 OneDrive 사이의 직접·양방향 사진 동기화
  • 기존 백업 파일: 이미 OneDrive에 올라간 사진과 동영상은 자동으로 삭제되거나 수정되지 않음
  • 현재 확인 경로: OneDrive 앱 또는 OneDrive 웹
  • 새 사진 자동 백업: OneDrive 앱의 '카메라 백업'을 별도로 켜야 함
  • 중요한 방식 차이: 이전 삼성 갤러리 연동은 양방향 동기화였지만, OneDrive 카메라 백업은 기기에서 클라우드로 업로드하는 백업 방식
  • 문제 해결 우선순위: Microsoft 계정, 카메라 백업 설정, 사진 접근 권한, 저장공간, 인터넷 연결 확인

삼성 갤러리에서 사진이 안 보인다는 이유만으로 OneDrive에 있던 파일까지 사라졌다고 판단하지 마세요. 같은 Microsoft 계정으로 로그인해 클라우드에 해당 파일이 남아 있는지 먼저 확인하는 것이 핵심입니다.

1. 삼성 갤러리와 OneDrive 동기화는 왜 달라졌나요?

Microsoft의 공식 안내에 따르면 2026년 9월 30일부터 Samsung Gallery는 더 이상 OneDrive와 직접 동기화하지 않습니다. 기존에 갤러리 앱에서 연동된 OneDrive 사진을 보고 새 사진까지 동기화하던 방식이 종료된 것입니다.

이번 변경은 OneDrive 서비스 전체의 종료나 Microsoft 계정의 저장 공간 폐쇄를 뜻하지 않습니다. 이미 OneDrive에 저장된 사진과 동영상은 그대로 유지되고, OneDrive 앱이나 웹사이트를 통해 계속 볼 수 있습니다.

2026년 9월 30일 이후에는 신규 이용자가 삼성 갤러리와 OneDrive를 직접 연결하는 것도 지원되지 않습니다. 기존에 해당 기능을 사용하던 이용자는 사진 백업을 지속하려면 OneDrive 앱 자체의 카메라 백업을 사용하도록 전환해야 합니다.

즉 갤럭시에서 사진 앱을 모두 바꿔야 한다는 의미는 아닙니다. 휴대전화에서 촬영·확인할 때는 삼성 갤러리를 계속 사용하면서, 클라우드에 자동 저장할 때는 OneDrive 앱의 카메라 백업 기능을 이용하는 방식입니다.

2. 삼성 갤러리에서 사라진 사진, 진짜 삭제된 걸까요?

갤러리에 예전에 보이던 사진이 없어졌다면 먼저 휴대전화에 실제로 저장된 파일인지, OneDrive 클라우드에만 저장된 사진이었는지를 구분해야 합니다.

원드라이브에 이미 업로드한 사진이라면

Microsoft는 2026년 9월 30일 이전에 OneDrive에 저장된 사진·동영상은 그대로 유지되며 삭제되거나 수정되지 않는다고 명시합니다. 하지만 삼성 갤러리에서는 OneDrive의 클라우드 사진을 더 이상 동기화해 표시하지 않습니다.

따라서 원드라이브에 있던 사진이 갤러리에서 보이지 않더라도 OneDrive 앱 또는 브라우저에서 onedrive.live.com에 접속해 확인할 수 있습니다.

휴대전화에 원본 파일이 남아 있다면

기기에 저장된 사진은 삼성 갤러리에서 계속 확인할 수 있습니다. 해당 사진이 클라우드 백업에도 들어 있는지 여부는 따로 확인해야 합니다. 앞으로 촬영한 사진은 카메라 백업을 켜지 않았다면 자동으로 OneDrive에 업로드되지 않을 수 있습니다.

직접 사진을 삭제한 적이 있다면

이것은 동기화 서비스 종료와는 별도의 문제입니다. 이미 삭제한 사진이라면 갤럭시 갤러리 휴지통, OneDrive 휴지통, 별도 백업을 확인해야 합니다. 서비스 종료 자체는 데이터 삭제 사건이 아니지만 사용자가 지운 파일은 다른 복원 절차가 필요합니다.

3. 내 사진이 OneDrive에 남아 있는지 확인하는 방법

기존 백업 사진이 사라졌다고 느낄 때는 다음 순서로 확인해 보세요.

  1. 갤럭시에서 OneDrive 앱을 엽니다. 설치되어 있지 않다면 공식 앱 스토어에서 설치합니다.
  2. 이전 삼성 갤러리 동기화에 연결했던 Microsoft 개인 계정으로 로그인합니다.
  3. 사진 보기 영역 또는 파일 목록에서 예전에 백업한 이미지를 검색합니다.
  4. 다른 계정으로 로그인된 것은 아닌지 프로필에 표시된 이메일 주소를 확인합니다.
  5. 앱에서 찾기 어렵다면 브라우저로 OneDrive 웹에 접속해 같은 Microsoft 계정으로 로그인합니다.
  6. 중요한 사진 한두 장을 직접 열어 실제로 열람 가능한지 확인합니다.

삼성 계정과 Microsoft 계정은 서로 다릅니다. 갤럭시 기기를 등록할 때 쓴 삼성 계정과 원드라이브에 사진을 저장한 Microsoft 계정이 반드시 같다고 가정해서는 안 됩니다.

여러 Microsoft 계정을 사용한다면 각 계정의 OneDrive 저장 공간을 살펴보세요. 회사나 학교 계정, 개인 계정이 혼재되어 있다면 사진 백업에 사용한 계정을 정확히 구분해야 합니다.

사진이 확인되었다면 중요한 파일은 필요한 위치에 별도 사본으로 저장할 수 있습니다. 갤러리에 다시 보이게 하려고 모든 사진을 무조건 다운로드하기 전에 휴대전화 저장 공간이 충분한지 확인하세요.

4. 앞으로 사진 자동 백업하려면: OneDrive 카메라 백업 설정

새로 찍는 갤럭시 사진을 OneDrive에 자동 저장하려면 삼성 갤러리의 옛 동기화 메뉴가 아니라 OneDrive 앱에서 카메라 백업을 켜야 합니다.

갤럭시 OneDrive 앱 설정 순서

  1. 갤럭시에서 OneDrive 앱을 실행합니다.
  2. 이전 사진이 저장된 Microsoft 계정으로 로그인합니다.
  3. 왼쪽 상단의 계정 프로필 아이콘을 탭합니다.
  4. 카메라 백업 메뉴를 엽니다.
  5. 사진을 저장할 계정이 맞는지 확인합니다.
  6. 카메라 백업을 켭니다.
  7. 사진 및 동영상에 대한 접근 권한이 요청되면 백업에 필요한 권한을 허용합니다.
  8. 새로 촬영한 사진으로 자동 업로드 여부를 확인합니다.

일부 OneDrive 앱 버전에서는 프로필 → 설정 → 카메라 백업 경로를 사용합니다. 메뉴에 '카메라 백업이 꺼져 있음'이 보이면 해당 안내에서 기능을 켤 수도 있습니다. Microsoft가 안내한 핵심 설정은 프로필에서 카메라 백업을 활성화하는 것이며, 앱 버전에 따라 버튼 배치는 달라질 수 있습니다.

5. 카메라 백업과 예전 양방향 동기화는 무엇이 다른가요?

이 차이를 모르고 갤러리에서 사진을 삭제하면 예전과 달라진 결과를 보고 혼란스러울 수 있습니다.

이전: 삼성 갤러리와 OneDrive의 직접 동기화

Microsoft는 과거 삼성 갤러리 연동을 양방향 동기화로 설명합니다. 따라서 갤러리에 동기화된 파일을 수정하거나 삭제하면 클라우드에도 변경 사항이 반영될 수 있었습니다. 반대로 OneDrive에서 수정·삭제한 경우도 기기 데이터에 영향을 주는 방식이었습니다.

현재 권장: OneDrive 카메라 백업

Microsoft의 Android용 OneDrive 공식 안내는 카메라 롤이 클라우드에 백업될 뿐, 양방향으로 사진을 동기화하는 것은 아니다라고 명시합니다. 따라서 카메라 백업이 완료된 사진을 휴대전화에서 삭제하더라도 OneDrive에 저장된 사본은 영향을 받지 않는다고 설명합니다.

다만 이 설명을 어떤 앱에서 어떤 방식으로 삭제하더라도 안전하다는 뜻으로 확대하면 안 됩니다. OneDrive 앱에서 클라우드 파일 자체를 삭제하는 것은 별개이며, 휴대전화에 있는 원본을 삭제하기 전에는 반드시 업로드 완료 상태와 클라우드 사본의 열람 가능 여부를 확인해야 합니다.

특히 기존 삼성 갤러리 동기화 방식에서 카메라 백업으로 넘어가는 경우, 일부 사진이 다시 업로드되거나 파일 정리가 필요할 수도 있으므로 서두르지 않는 것이 좋습니다.

6. 카메라 백업을 켰는데 새 사진이 안 올라갈 때 확인할 7가지

설정을 켰더라도 실제 자동 업로드에 문제가 생길 수 있습니다. 다음 항목을 하나씩 확인하세요.

① Microsoft 계정이 맞나요?

OneDrive의 카메라 백업은 한 번에 한 계정에서만 사용할 수 있다고 Microsoft는 안내합니다. 사진을 보관하려는 실제 Microsoft 개인 계정으로 로그인했는지 확인하세요. 기존 사진을 저장한 계정과 현재 백업 계정이 다르면 사진이 분리되어 보일 수 있습니다.

② 사진 및 동영상 접근 권한이 허용됐나요?

OneDrive가 촬영한 사진을 읽어야 업로드할 수 있습니다. 휴대전화의 앱 권한에서 OneDrive가 사진과 동영상에 접근할 수 있는지 확인합니다. '선택한 사진만 허용'과 같은 제한적인 권한이 적용됐다면 백업 대상이 원하는 범위와 다른지 확인하세요.

③ 저장 공간이 부족하지 않나요?

Microsoft 저장소의 사용 한도를 초과하면 새 사진을 업로드할 수 없습니다. OneDrive의 저장공간 사용량을 확인하고, 정리가 필요하다면 이미 백업한 데이터의 중요도를 먼저 검토하세요. 저장 공간 부족을 해결하기 위해 중요한 파일을 바로 영구 삭제하는 것은 피하는 것이 좋습니다.

④ 와이파이·모바일 데이터 설정은 맞나요?

OneDrive 설정에서 와이파이 연결 시에만 백업하도록 설정했으면 모바일 데이터 환경에서는 자동 업로드가 진행되지 않을 수 있습니다. 현재 연결 상태와 설정을 비교하세요. 모바일 데이터 이용량이 걱정된다면 와이파이 환경에서 백업을 진행할 수 있습니다.

⑤ 충전 중에만 백업하도록 설정돼 있나요?

'충전 시에만 업로드'와 유사한 옵션이 켜져 있다면 배터리 상태에 따라 업로드가 늦어질 수 있습니다. 실제 적용된 옵션을 확인하고 충전 상태에서 사진이 업로드되는지 시험해 보세요.

⑥ 동영상 포함 설정이 켜져 있나요?

사진은 잘 올라가는데 동영상만 누락되는 경우 OneDrive 카메라 백업 설정에서 비디오 포함 여부를 확인합니다. 동영상 파일 크기, 저장 공간, 네트워크 상황도 함께 점검해야 합니다.

⑦ 앱이 백그라운드에서 정상 작동하나요?

Microsoft는 백그라운드에서 업로드가 계속 실행되도록 필요한 권한을 부여해야 한다고 안내합니다. 앱을 강제로 종료하거나 백그라운드 실행이 제한된 경우 백업이 지연될 수 있습니다. 백업 확인 중에는 안정적인 네트워크에 연결하고 OneDrive 앱의 업로드 상태를 확인하세요.

7. 삭제한 사진은 어디서 복원하나요? 갤러리·OneDrive 휴지통 구분

동기화 종료로 사진이 보이지 않는 문제와 사용자가 직접 파일을 삭제한 문제는 구분해야 합니다. 삭제했는지 여부를 확신할 수 없다면 어느 곳에서도 휴지통 비우기를 먼저 누르지 마세요.

갤럭시 갤러리에서 삭제한 사진

삼성전자서비스는 One UI 6 기준으로 갤러리 → 메뉴 → 휴지통 → 편집 → 사진 선택 → 복원 경로를 안내합니다. 갤러리의 휴지통에 있는 사진과 동영상은 30일 보관 후 자동 삭제된다고 설명합니다. One UI 6에서는 '내 파일 → 휴지통'에서도 갤러리에서 삭제한 항목을 확인할 수 있습니다.

하지만 모든 예전 갤럭시 버전이 동일한 기간을 제공하는 것은 아닙니다. 예를 들어 오래된 일부 기기·운영체제에 관한 삼성 도움말은 15일 보관 사례를 안내합니다. 따라서 실제 기기에서 표시되는 휴지통 보관 기한을 확인해야 합니다.

공식 출처: 삼성전자서비스 - 갤러리·내 파일 휴지통 복원

OneDrive 클라우드에서 삭제한 사진

개인용 OneDrive의 휴지통은 일반적으로 삭제 후 30일 동안 파일을 보관한다고 Microsoft가 안내합니다. OneDrive 앱 또는 OneDrive 웹에서 휴지통을 열어 필요한 파일이 있는지 확인하세요.

휴지통에 남아 있는 파일은 선택 후 복원할 수 있습니다. 그러나 휴지통에서 파일을 영구 삭제한 경우에는 일반적인 복원 절차로 되돌릴 수 없다고 Microsoft는 설명합니다. 개인용과 회사·학교용 OneDrive는 정책이 다를 수 있으므로 계정 종류를 구분하세요.

8. 기존에 저장된 사진을 다시 갤럭시 갤러리에서 보고 싶다면

OneDrive에서 클라우드 사진을 찾았다면 필요한 파일을 기기에 다운로드해 갤러리에서 볼 수 있는지 확인할 수 있습니다. 다만 갤러리 앱이 더 이상 예전 방식으로 클라우드 사진을 자동 표시하는 것은 아니므로 기존과 동일한 화면이 보장되지는 않습니다.

사진을 휴대전화에 다시 저장하기 전에는 저장공간을 확인하세요. OneDrive에 대량으로 보관된 고해상도 사진과 동영상은 기기에 모두 다운로드하면 저장 공간을 빠르게 사용할 수 있습니다.

필요한 앨범이나 파일만 선택해 내려받은 뒤 갤러리에서 실제로 열리는지 시험해 보는 편이 좋습니다. 촬영 날짜와 파일 정렬 방식이 앱에 따라 달라질 수 있으므로 파일 이름·촬영 날짜를 기준으로 확인하세요.

중요한 것은 OneDrive에 남아 있는 원본을 삭제하지 않는 것입니다. 내려받기가 성공했더라도 기기와 클라우드 중 어느 곳을 기본 보관 장소로 사용할지 결정하기 전에는 원본을 보존하세요.

9. 백업 방식 변경 후 중복 사진이 생기면 어떻게 하나요?

기존 삼성 갤러리의 OneDrive 직접 동기화와 새 OneDrive 카메라 백업은 저장 방식이 다릅니다. 같은 사진을 다시 업로드하는 과정에서 파일이 중복되어 보이는지 확인할 필요가 있습니다.

Microsoft의 삼성 갤러리 연동 관련 도움말도 삼성 갤러리 방식과 OneDrive 카메라 업로드 방식 사이를 전환하면 기존 사진이 다시 업로드될 수 있다는 주의사항을 제공합니다. 따라서 사진 수가 갑자기 늘었다면 실제로 같은 파일인지 확인하세요.

파일 이름이 같다고 무조건 같은 사진은 아닙니다. 촬영 시각, 해상도, 크기, 실제 이미지 내용을 비교하는 것이 안전합니다. 실수로 원본까지 지울 수 있으므로 자동 중복 정리 도구의 '모두 삭제' 기능은 신중하게 사용하세요.

특히 가족 여행 사진이나 아이의 성장 기록처럼 다시 촬영할 수 없는 자료라면 중복을 줄이는 것보다 백업 사본을 안전하게 유지하는 것이 우선입니다.

10. 사진이 정말 없어졌는지 최종 확인하는 순서

아래 순서대로 점검하면 '앱에 표시되지 않는 것'과 '클라우드 파일이 삭제된 것'을 구분하는 데 도움이 됩니다.

  1. 삼성 갤러리에서 해당 사진이 보이는지 확인합니다.
  2. OneDrive 앱의 로그인 이메일이 사진을 백업하던 Microsoft 계정과 동일한지 확인합니다.
  3. onedrive.live.com에서 예전 사진이 존재하고 실제로 열리는지 확인합니다.
  4. 최근 삭제한 사진이라면 갤러리 휴지통을 확인합니다.
  5. 원드라이브에서 직접 삭제한 이력이 있다면 OneDrive 휴지통을 확인합니다.
  6. 새 사진이 업로드되지 않는다면 카메라 백업, 사진 접근 권한, 저장 공간, 네트워크 설정을 확인합니다.
  7. 사용하던 다른 Microsoft 계정이 있는지 확인합니다.
  8. 필요한 사진이 여전히 없다면 개인용 OneDrive의 공식 누락 파일 찾기 안내를 확인합니다.

자주 묻는 질문 FAQ

Q1. 삼성 갤러리 원드라이브 동기화는 언제 끝났나요?

Microsoft 공식 안내에 따르면 2026년 9월 30일부터 삼성 갤러리와 OneDrive의 직접 동기화가 종료되었습니다. 이 날짜 이후에는 새 사용자의 직접 연결도 지원되지 않습니다.

Q2. 삼성 갤러리에서 사진이 사라졌으면 원드라이브 파일도 삭제된 건가요?

아닙니다. Microsoft는 이미 OneDrive에 저장된 사진과 동영상은 그대로 유지되며 삭제·수정되지 않는다고 안내합니다. OneDrive 앱 또는 웹에서 기존 계정으로 로그인해 확인해 보세요.

Q3. 갤럭시에서 이제 원드라이브 사진 백업을 못 하나요?

가능합니다. 삼성 갤러리 앱의 직접 동기화가 종료된 것이며 OneDrive 앱의 카메라 백업은 계속 사용할 수 있습니다. OneDrive에서 올바른 Microsoft 계정을 선택하고 카메라 백업을 활성화하세요.

Q4. 새 사진을 찍으면 자동으로 백업되나요?

OneDrive 카메라 백업을 실제로 켰고, 접근 권한과 저장 공간, 연결 상태가 정상이어야 자동 업로드됩니다. 예전에 삼성 갤러리 동기화를 켰다는 이유만으로 지금도 계속 백업되는 것은 아닙니다.

Q5. 휴대전화에서 사진을 지우면 OneDrive에 있는 사진도 없어지나요?

OneDrive의 카메라 백업은 양방향 동기화가 아니므로, Microsoft는 기기에서 백업한 사진을 삭제해도 클라우드 사본은 영향을 받지 않는다고 설명합니다. 다만 삭제 위치와 방식에 따라 결과가 달라질 수 있으니 원드라이브 사본이 실제로 업로드되었는지 먼저 확인하세요.

Q6. 원드라이브 계정이 여러 개라면 어디를 확인해야 하나요?

이전 삼성 갤러리와 연결했던 Microsoft 개인 계정을 먼저 확인해야 합니다. OneDrive 앱의 프로필 이메일과 OneDrive 웹 로그인 계정이 같은지 비교하세요.

Q7. 삭제된 갤럭시 사진은 며칠 안에 복원할 수 있나요?

삼성전자서비스의 One UI 6 안내는 갤러리 휴지통에 30일 동안 보관된다고 설명합니다. 오래된 일부 기기에서는 보관 정책이 다를 수 있으므로 현재 기기의 휴지통에서 확인하세요.

Q8. OneDrive에서 삭제한 사진을 복원할 수 있나요?

개인용 OneDrive의 휴지통에 남아 있다면 복원할 수 있습니다. Microsoft는 개인 계정 휴지통 항목을 보통 30일 뒤 자동 삭제한다고 안내합니다. 이미 영구 삭제한 파일은 일반적인 복원 절차로 되돌릴 수 없습니다.

Q9. 백업 방식을 바꾸면 사진이 두 번 올라갈 수 있나요?

기존 삼성 갤러리 동기화에서 OneDrive 카메라 백업으로 전환할 때 재업로드가 발생할 수 있다는 주의사항이 있습니다. 파일이 중복되어 보이면 원본을 삭제하기 전에 촬영일·파일 크기·실제 내용 등을 비교하세요.

Q10. 원드라이브 카메라 백업을 켰는데 동영상만 빠집니다

OneDrive 설정에서 동영상 포함 옵션을 확인하세요. Microsoft는 비디오 포함 여부와 함께 저장 공간, 업로드 방식, 네트워크 상태를 점검하도록 안내합니다.

마무리: '동기화 종료'와 '사진 삭제'는 다릅니다

2026년 9월 30일에 종료된 것은 삼성 갤러리와 OneDrive의 기존 직접 동기화 방식입니다. 기존에 원드라이브에 저장한 사진은 보관되고 있으므로 OneDrive 앱이나 웹에서 찾을 수 있는지 먼저 확인하세요.

앞으로 새 사진을 자동 보관하려면 OneDrive 앱의 카메라 백업을 켜고, 실제로 촬영한 사진 한두 장이 업로드되는지 검증해야 합니다. 사진이 사라진 것처럼 보인다고 해서 휴대전화를 바로 초기화하거나 휴지통을 비우는 행동은 피하는 것이 좋습니다.
