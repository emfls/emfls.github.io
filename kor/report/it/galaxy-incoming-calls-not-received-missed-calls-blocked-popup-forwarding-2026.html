갤럭시 휴대전화에 상대방이 전화를 걸었다는데 벨이 울리지 않고 부재중 전화만 남거나, 전화가 왔는데 받기 버튼이 보이지 않는 경우가 있습니다. 반대로 발신·수신이 모두 안 되는 증상도 있습니다. 세 상황은 원인과 확인 방법이 다릅니다.

먼저 ① 상대방에게 통화 연결음이 들리는지 ② 내 휴대전화 통화기록에 부재중 전화가 남는지 ③ 전화 화면은 뜨는데 소리만 안 나는지를 나눠 확인하세요. 그다음 차단 번호·방해 금지·전화 화면 표시·착신전환·통신망 상태를 순서대로 점검하면 데이터 삭제 없이도 문제 범위를 좁힐 수 있습니다.

이 원고는 2026년 11월 3일 기준 삼성전자 공식 지원 자료를 확인해 작성했습니다. 일부 메뉴는 기종·One UI·통신사와 국가별 소프트웨어에 따라 다릅니다. 모든 기기에서 직접 시험한 결과는 아니며, 특정 통신사 장애가 현재 발생했다는 주장은 하지 않습니다.

1. 증상별 30초 진단표

나타나는 증상먼저 살펴볼 항목첫 조치
상대방이 전화했는데 부재중만 뜸방해 금지·벨소리·전화 팝업수신 화면 표시·소리 설정 확인
특정 사람의 전화만 받지 못함번호 차단·발신번호 숨김전화 앱의 차단 번호 목록 확인
전화는 오는데 화면이 안 뜸앱 사용 중 전화 표시 방식전화 앱 → 설정 → 앱 사용 중 전화 표시
전화벨만 울리지 않음무음·진동·방해 금지·벨소리소리 모드와 벨소리 음량 확인
전화가 계속 다른 번호로 연결됨착신전환전화 앱 → 부가 서비스 → 착신전환
수신·발신·문자 모두 안 됨비행기 모드·통신망·유심신호, SIM, 통신사 상태 점검
소프트웨어 업데이트 뒤 수신화면 지연전화 앱·시스템 업데이트최신 패치 확인, 재시작
특정 시간대에만 안 울림수면·업무 모드 자동 실행모드 및 루틴·방해 금지 예약 확인

중요: '벨이 울리지 않음'은 전화가 네트워크에서 아예 수신되지 않는 것과 다릅니다. 통화기록에 실제 부재중이 남는다면 착신 화면·알림·소리 문제부터 확인하는 편이 효율적입니다.

공식 근거: 삼성전자 — 전화를 걸거나 받을 수 없을 때, 수신 벨소리 문제 해결

2. 설정을 바꾸기 전에 두 사람으로 전화 수신 시험하기

문제를 재현할 수 있다면 내 번호로 전화를 걸어 줄 수 있는 두 사람에게 협조를 구해보세요.

  1. 한 사람은 내 연락처에 저장된 번호에서 전화를 겁니다.
  2. 다른 사람은 가능하면 연락처에 저장되지 않은 일반 번호로 전화를 겁니다.
  3. 두 경우 모두 내 스마트폰이 울리는지, 화면이 표시되는지, 통화기록에 남는지 기록합니다.
  4. 가능하면 내 스마트폰에서도 정상적인 번호로 발신 통화를 시도합니다.
  5. 문자와 모바일 데이터도 정상인지 확인합니다.
비교 결과가능한 원인 범위
저장된 번호는 정상, 낯선 번호만 실패알 수 없는 번호 차단·스팸 필터·통화 스크리닝
모든 수신은 안 되지만 발신은 정상수신 차단·착신전환·통신사 수신 설정 등
상대방 전화는 오는데 수신 화면만 늦게 표시전화 화면 표시·전화 앱·소프트웨어
발신·수신 모두 실패비행기 모드·망 상태·SIM·통신사
통화는 가능하나 벨소리만 없음소리 모드·방해 금지·볼륨·오디오 설정

결과 해석 주의: 저장되지 않은 번호가 연결되지 않았다고 상대방이 스팸으로 분류됐다고 단정하지 마세요. 실제 차단 목록과 통신사 서비스를 함께 확인해야 합니다.

3. 전화 앱의 '차단 번호'를 먼저 확인

삼성 공식 안내에 따르면, 차단된 번호 또는 알 수 없는 번호 차단 설정 때문에 특정 발신자의 전화가 들어오지 않을 수 있습니다.

차단 번호 확인 순서

  1. 갤럭시의 전화 앱을 엽니다.
  2. 오른쪽 위 더보기(점 세 개)를 선택합니다.
  3. 설정 → 수신 차단 또는 차단 번호(Block numbers)를 엽니다.
  4. 문제의 상대방 번호가 차단 목록에 있는지 확인합니다.
  5. 실수로 등록한 번호라면 본인이 원할 때만 차단을 해제합니다.
  6. 알 수 없는 번호·발신번호 표시제한 차단 항목의 동작도 확인합니다.

국가·통신사·전화 앱 버전에 따라 '수신 차단'·'차단 번호'처럼 이름이 다를 수 있습니다.

보안 주의: 스팸·피싱 피해를 막기 위해 차단을 설정했다면 무조건 전체 차단을 해제할 필요는 없습니다. 원인이 의심되는 번호에 한정해 확인하거나, 짧은 시험 후 원래 보안 설정을 복원하세요.

공식 근거: 삼성전자 — 통화·문자 차단 문제 해결, 알 수 없는 발신번호 차단 설정

4. 방해 금지 모드가 켜져 있는지 확인

방해 금지(Do not disturb)는 통화와 알림의 소리·표시를 제한할 수 있습니다. 이는 통신사의 수신 자체가 끊겼다는 의미와 다릅니다.

  1. 설정 → 알림 → 방해 금지로 이동합니다.
  2. 방해 금지가 켜져 있다면 잠시 끄고 수신 전화를 시험합니다.
  3. 방해 금지 상태에서도 특정 전화가 필요하다면 허용된 사람·통화·반복 발신 관련 예외 항목을 확인합니다.
  4. 자동 활성화 예약이 있다면 시작 시간과 종료 시간을 확인합니다.
  5. 시험이 끝나면 사용 목적에 맞게 방해 금지 설정을 되돌립니다.

삼성전자 공식 도움말은 방해 금지에 통화·메시지 예외를 설정할 수 있고, 수면 등과 연결해 자동으로 켤 수 있다고 안내합니다.

구별할 점: 다른 사람에게 정상적인 연결음이 들리고 내 휴대전화에 부재중 통화가 남았다면 방해 금지에 의해 벨이나 표시가 제한됐을 가능성을 먼저 살펴볼 수 있습니다.

공식 근거: 삼성전자 — Galaxy 소리·진동·알림과 방해 금지

5. '부재중만 뜨고 전화 화면 안 뜸' 해결: 앱 사용 중 전화 표시

게임·유튜브·웹브라우저 등 다른 앱을 사용 중일 때 전화가 오는 경우, 갤럭시는 전화 수신을 전체 화면·팝업·미니 팝업으로 표시할 수 있습니다.

전화 수신 화면 표시 방식 변경

  1. 전화 앱 → 더보기(점 세 개) → 설정을 엽니다.
  2. 앱 사용 중 전화 표시(Call display while using apps) 항목을 선택합니다.
  3. 전체 화면 또는 팝업 등 원하는 표시 방식을 선택합니다.
  4. 다른 사람에게 전화해 달라고 요청해 실제로 수신 화면이 표시되는지 확인합니다.

현재 미니 팝업으로 표시되도록 설정돼 있다면 화면 위쪽의 작은 통화 알림을 놓치기 쉽습니다. 전화가 오지 않은 것이 아니라 작은 표시를 못 본 상황인지 구분하세요.

다만 화면 표시 방식을 바꾸는 것만으로 통신망의 전화 수신 오류가 해결되는 것은 아닙니다.

삼성 공식 안내는 메뉴 이름과 제공 옵션이 통신사·단말기·소프트웨어에 따라 달라질 수 있다고 설명합니다.

공식 근거: 삼성전자 — Galaxy 전화 기능과 앱 사용 중 전화 표시, Samsung — 전화 앱 설정

6. 전화는 오지만 벨소리가 안 들린다면

다음 항목을 개별적으로 확인하세요.

  1. 설정 → 소리 및 진동에서 소리 모드가 무음 또는 진동인지 확인합니다.
  2. 설정 → 소리 및 진동 → 음량에서 벨소리 음량을 확인합니다.
  3. 평소 쓰는 벨소리가 정상적으로 재생되는지 확인합니다.
  4. 설정 → 접근성 → 청각 보조 → 모든 소리 끄기가 켜져 있는지 살펴봅니다.
  5. 모드 및 루틴에서 수면·업무 등 모드가 소리를 자동 변경하는지 확인합니다.

버튼 주의: 유튜브 영상이 재생되는 동안 볼륨 버튼을 올리면 미디어 음량만 바뀔 수 있습니다. 따라서 벨소리가 안 들릴 때는 소리 및 진동의 벨소리 항목을 직접 확인하세요.

삼성 공식 지원 문서는 방해 금지·무음·비행기 모드·사용자 지정 벨소리가 수신 벨소리에 영향을 줄 수 있다고 안내합니다.

공식 근거: 삼성전자 — Galaxy 수신 벨소리 안 들림, 모든 소리 끄기 설정 점검

7. 착신전환이 켜져 있는지 확인

착신전환이 활성화되면 내 번호로 온 전화를 다른 번호로 전달할 수 있습니다. 예전에 회사 전화·다른 휴대전화로 착신전환을 설정했다면 수신 문제를 의심할 수 있습니다.

삼성 전화 앱에서 확인하는 방법

  1. 전화 앱 → 더보기 → 설정을 엽니다.
  2. 부가 서비스(Supplementary services) 항목을 확인합니다.
  3. 제공되는 경우 착신전환(Call forwarding)을 선택합니다.
  4. 항상 착신전환·통화 중·응답 없음·연결 불가 시 착신전환 항목의 상태를 확인합니다.
  5. 본인이 사용하지 않는 착신전환이 켜져 있다면 통신사 정책과 서비스 계약을 확인한 뒤 변경합니다.

중요: 착신전환 메뉴의 제공 여부와 서비스 방식은 통신사·모델마다 다릅니다. 메뉴가 없다고 곧바로 전화 앱이 고장 난 것은 아닙니다. 이용 중인 통신사에 착신전환 부가서비스 가입·설정 여부를 문의할 수 있습니다.

공식 근거: 삼성전자 — Galaxy 착신전환·통화대기 설정

8. 비행기 모드·통신 신호·유심 문제 구분

발신과 수신이 모두 안 되는 경우라면 전화 앱의 수신 알림 설정보다 이동통신망 연결을 먼저 확인해야 합니다.

순서대로 점검

  1. 설정 → 연결 → 비행기 모드가 꺼져 있는지 확인합니다.
  2. 상태표시줄에서 통신 신호가 보이는지 확인합니다.
  3. 가능한 경우 위치를 옮겨 수신 상태가 나아지는지 확인합니다.
  4. SIM 관련 오류 메시지가 있다면 유심 또는 eSIM 활성 상태를 확인합니다.
  5. 통신 요금제·정지·개통·번호이동 등 회선 상태를 통신사에 확인합니다.

주의: Wi-Fi로 인터넷이 된다고 이동통신 전화도 반드시 정상인 것은 아닙니다. 반대로 5G/LTE 데이터가 일시적으로 느리다고 음성전화 수신까지 반드시 끊긴다고 단정할 수 없습니다. 서비스별로 실제 상태를 비교하세요.

삼성 공식 안내는 전화 수신·발신 불가 원인으로 SIM 손상·장착 문제·통신사 계정·회선 활성 상태·기기 손상을 제시합니다.

공식 근거: 삼성전자 — 전화 수신·발신 불가 진단, 통신 신호 끊김과 비행기 모드 점검

9. 스팸 전화 차단 앱·통화 스크리닝도 점검

특정 번호만 연락이 오지 않는다면 삼성 전화 앱 차단 목록 외에 통신사 스팸 서비스·제3자 발신자 식별 앱도 수신 동작에 영향을 줄 수 있습니다.

  • 삼성 전화 앱의 차단 번호 설정 확인
  • 사용하는 통신사의 스팸 차단 서비스 설정 확인
  • 별도 설치한 발신자 식별·통화 차단 앱의 차단 기록 확인
  • 최근에 전화 차단 앱을 설치하거나 설정을 바꿨는지 확인

최신 One UI 통화 스크리닝 기능 주의

삼성의 공식 지원 문서는 일부 기기에서 Call screening(통화 스크리닝) 기능을 제공하며, 자동 스크리닝으로 응답된 통화가 사용자의 화면에 일반 수신 전화와 다르게 보일 수 있다고 설명합니다.

다만 삼성 공식 문서는 이 기능의 Android 16·One UI 8.5 이상 지원 조건을 안내하고 있습니다. 한국 판매 기기에서 모든 모델이 같은 기능을 제공한다고 일반화하지 마세요. 전화 앱 설정에 해당 메뉴가 있는 경우에만 확인합니다.

보안 원칙: 전화 차단 앱을 전부 삭제하기보다 특정 발신자가 실제로 필터링됐는지 확인한 뒤 필요한 부분만 조정하세요.

공식 근거: 삼성전자 — 통화 스크리닝 기능과 수신 동작

10. 소프트웨어 업데이트 후 전화 화면이 늦게 뜨는 문제

삼성은 One UI 8.5 업데이트 이후 일부 Galaxy 기기에서 수신 화면이 늦게 나타나거나 검은 화면처럼 보이는 문제를 다룬 공식 지원 문서를 제공하고 있습니다.

따라서 최근 업데이트 이후 전화벨은 울리는데 수신 버튼이 늦게 뜨거나 화면이 비어 보인다면, 다음 항목을 먼저 확인하세요.

  1. 설정 → 소프트웨어 업데이트에서 새 패치가 있는지 확인합니다.
  2. 휴대전화를 정상 재시작합니다.
  3. 블루투스 기기와 연결된 상태에서만 증상이 재현되는지 비교합니다.
  4. 전화 앱 → 앱 사용 중 전화 표시 방식을 다시 확인합니다.
  5. 문제가 계속된다면 업데이트 버전·발생 시각·재현 상황을 기록해 삼성 고객지원에 전달합니다.

공식 문서에 문제와 수정 예정 내용이 기술됐다고 해서 모든 One UI 8.5 기기에 동일한 결함이 있다는 뜻은 아닙니다. 지역·통신사·배포 시점에 따라 소프트웨어가 다를 수 있습니다.

공식 근거: 삼성전자 — One UI 업데이트 후 수신 화면 지연

11. 모바일 네트워크 설정 초기화는 언제 할까?

기본 수신 차단·착신전환·방해 금지를 확인했는데도 발신·수신·통신 신호 문제가 계속된다면 네트워크 설정을 점검할 수 있습니다.

삼성 공식 안내에 따르면 일부 최신 기기의 경로는 다음과 같습니다.

  1. 설정 → 일반 → 초기화를 엽니다.
  2. 모바일 네트워크 설정 초기화(Reset mobile network settings)를 선택합니다.
  3. 초기화될 설정과 주의사항을 확인합니다.
  4. 필요한 정보와 통신사 설정을 확인한 뒤 실행 여부를 결정합니다.
  5. 초기화 후 정상 수신·발신 여부를 다시 시험합니다.

중요: 모바일 네트워크 설정 초기화와 휴대전화 공장 초기화는 다릅니다. 또한 OS 버전에 따라 네트워크 초기화 범위가 달라질 수 있어, 저장된 연결 정보나 개별 네트워크 설정에 영향을 주는지 확인 후 실행해야 합니다.

임의의 APN 값 입력은 권장하지 않습니다. 데이터나 네트워크 설정이 잘못될 수 있으므로, APN 관련 조치는 통신사 안내를 우선하세요.

공식 근거: 삼성전자 — 모바일 네트워크 설정 초기화

12. 안전모드로 타사 앱 영향 분리하기

전화·차단·보안 관련 앱을 설치한 뒤 수신 문제가 시작됐다면, 삼성의 안전모드(Safe mode)를 통해 다운로드한 앱의 영향을 점검할 수 있습니다.

  • 안전모드는 기본 시스템 앱 위주로 실행해 다운로드한 앱의 영향을 비교하는 진단 환경입니다.
  • 안전모드에서도 문제가 계속되면 다운로드한 앱만의 문제라고 단정하기 어려워집니다.
  • 안전모드에서 문제가 사라진다면 최근 설치하거나 설정을 변경한 앱을 점검할 이유가 있습니다.

기본적인 안전모드 진입

  1. 전원 메뉴를 엽니다.
  2. 전원 끄기 버튼을 길게 누르면 안전모드 진입 옵션이 나타나는 모델이 있습니다.
  3. 안전모드를 선택합니다.
  4. 잠금 PIN·비밀번호를 요구하면 본인이 설정한 인증 수단으로 잠금을 해제합니다.
  5. 타인의 도움을 받아 전화 수신 시험을 진행합니다.
  6. 확인 후 정상 재시작하여 안전모드에서 나옵니다.

주의: 안전모드에서 스팸 차단 앱 등 일부 다운로드 앱이 비활성화되는 것이 정상이며, 이 과정에서 일시적으로 평소와 다른 수신 필터링 상태가 될 수 있습니다.

공식 근거: 삼성전자 — 안전모드로 앱 원인 확인

13. 통신사에 문의해야 하는 경우

다음 중 하나라면 단말기 내부 설정만 계속 바꾸기보다 사용 중인 이동통신사에 문의하는 것이 합리적입니다.

  • 최근 번호이동·유심 교체·eSIM 발급 후부터 발신·수신이 모두 안 됨
  • 상대방이 전화를 걸면 반복해서 연결 불가·서비스 정지 안내음이 나옴
  • 전화 앱의 기본 설정은 정상인데 특정 회선에서 수신이 지속 실패
  • 착신전환 등 통신사 부가서비스가 잘못 설정된 것으로 의심됨
  • 같은 기기에서 다른 회선은 정상이고, 내 회선만 문제로 추정됨

삼성 공식 고객지원은 회선 활성·요금·통신사 서비스 상태를 확인하고, 유심 자체가 원인일 수 있을 때 통신사 도움을 받도록 권장합니다.

상담 시 전달할 정보: 통신사, 갤럭시 모델명, One UI 버전, 유심/eSIM 여부, 문제 시작일, 발신·수신·문자·모바일 데이터 각각의 작동 여부, 차단·방해 금지·착신전환 시험 결과.

관련 글: 갤럭시 유심 인식 안됨 해결법 — 단, 이 글과 통화 수신 오류는 완전히 같은 문제가 아닐 수 있습니다.

15. 자주 묻는 질문(FAQ)

Q1. 전화는 왔다고 하는데 갤럭시에 부재중만 뜹니다. 왜 그런가요?

우선 방해 금지·무음·벨소리·전화 앱의 팝업 표시 방식을 살펴보세요. 부재중 기록이 남는다는 사실만으로 통신망 수신 실패라고 단정할 수 없습니다.

Q2. 한 사람의 전화만 수신되지 않습니다.

전화 앱 → 설정 → 차단 번호에서 해당 번호가 차단됐는지 확인하세요. 통신사의 스팸 차단 기능도 영향을 줄 수 있으므로 필요하면 함께 확인합니다.

Q3. 다른 앱을 쓰는 동안 전화받기 화면이 안 뜹니다.

전화 앱 → 설정 → 앱 사용 중 전화 표시에서 전체 화면·팝업·미니 팝업 방식을 확인하세요. 삼성 공식 문서에 이 기능이 안내돼 있습니다.

Q4. 갤럭시 방해 금지를 켜면 전화가 아예 차단되나요?

방해 금지는 소리·알림·통화 알림 예외를 관리하는 기능입니다. 통신망 수신 실패와는 구분해야 하며, 허용 연락처 등의 예외 설정을 확인할 수 있습니다.

Q5. 수신전화가 다른 휴대전화로 갑니다.

착신전환을 확인하세요. 메뉴가 없다면 통신사 부가서비스 설정도 확인해야 하며, 통신사·모델에 따라 제공 경로가 달라질 수 있습니다.

Q6. 전화벨은 울리는데 화면이 검게 나옵니다.

업데이트 직후 발생했다면 소프트웨어 패치 확인·재시작·수신 화면 표시 설정을 먼저 점검하세요. 일부 버전에 대해 삼성 공식 지원 문서가 별도로 있습니다.

Q7. 전화 발신도 수신도 안 되는데 Wi-Fi 인터넷은 됩니다.

Wi-Fi와 이동통신 음성 회선은 별개입니다. 비행기 모드·통신망 상태·유심 또는 eSIM·통신사 회선 상태부터 확인하세요.

Q8. 갤럭시 수신 문제로 초기화해야 하나요?

공장 초기화를 첫 단계로 권장하지 않습니다. 초기화는 데이터를 삭제할 수 있으며 통신사 회선 문제가 원인이라면 해결되지 않을 수 있습니다. 기본 설정과 회선 상태를 먼저 확인하세요.

Q9. 통화 스크리닝 기능이 모든 갤럭시에 있나요?

아닙니다. 삼성 공식 안내는 일부 지원 기기의 Android 16 / One UI 8.5 이상 등 조건을 설명합니다. 통신사와 지역에 따라 제공되지 않을 수 있습니다.

Q10. 안전모드에서 전화가 정상적으로 오면 무엇을 의미하나요?

다운로드한 앱이나 최근 변경된 앱 설정이 영향을 줬을 가능성을 의미합니다. 어느 앱이 원인인지는 하나씩 추가 점검해야 하며, 바로 모든 앱을 삭제할 필요는 없습니다.

결론

갤럭시 전화가 오지 않거나 부재중만 뜬다면 차단 번호 → 방해 금지 → 전화 화면 표시 → 벨소리 → 착신전환 → 이동통신망 순서로 확인하세요. 특정 사람만 수신되지 않는 경우와 발신·수신이 모두 불가능한 경우는 구분해야 합니다.

설정 검토로 해결되지 않는다면 통신사 회선 상태와 SIM·eSIM, 그리고 삼성의 최신 소프트웨어 업데이트를 확인하세요. 공장 초기화보다 원인을 좁히는 시험이 우선입니다.
