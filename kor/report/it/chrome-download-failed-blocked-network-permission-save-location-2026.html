크롬에서 파일을 내려받는데 '실패 - 네트워크 오류', '다운로드 차단됨', '권한 부족', '디스크가 가득 참' 등의 오류가 뜨거나, 완료된 파일이 어디에 저장됐는지 찾기 어려운 경우가 있습니다. 이런 증상은 모두 같은 원인이 아닙니다. 오류 문구에 따라 인터넷 연결, 저장 폴더, 사이트 권한, 보안 차단을 구분하면 불필요한 재설치 없이 해결될 수 있습니다.

이 글은 Windows 11 및 Mac에서 사용하는 데스크톱 Chrome을 중심으로 정리했습니다. Google Chrome 고객센터와 Microsoft 공식 문서에서 확인되는 경로만 안내하며, 악성코드 방지 기능을 끄거나 의심스러운 파일을 강제로 받는 방법은 권하지 않습니다.

2. Chrome 다운로드 기록은 어디에서 확인하나요?

파일을 저장하려다 실패한 경우와 이미 다운로드했지만 파일이 안 보이는 경우를 먼저 구분하세요.

  1. Chrome을 엽니다.
  2. 키보드에서 Ctrl+J를 누릅니다. Mac에서는 메뉴의 다운로드 항목을 이용하거나 Chrome의 다운로드 화면을 열면 됩니다.
  3. 가장 최근 항목의 상태를 확인합니다.
  4. 실패, 일시중지, 완료 여부를 구별합니다.
  5. 다운로드가 일시중지됐다면 다운로드 항목에서 **다시 시작(Resume)**을 시도합니다.
  6. 완료된 파일은 저장 위치를 열어 실제 파일이 있는지 확인합니다.

주소창에 chrome://downloads/를 입력해 다운로드 화면을 여는 방법도 있습니다.

Google은 다운로드 목록에서 파일을 기록에서 삭제해도 컴퓨터에 저장된 실제 파일까지 삭제되는 것은 아니다라고 안내합니다. 다운로드 목록과 Windows 파일 탐색기·Mac Finder는 서로 다른 개념입니다.

3. '실패 - 네트워크 오류' 또는 다운로드가 중간에 멈출 때

파일 다운로드가 0%에서 멈추거나 20%, 90%처럼 불규칙한 지점에서 끊어진다면 다음 순서로 확인합니다.

3-1. 연결 상태부터 확인

  • 다른 사이트를 열어 인터넷이 정상적으로 되는지 확인합니다.
  • Wi-Fi가 불안정하다면 안정적인 연결로 바꿔 테스트합니다.
  • 회사·학교 등의 네트워크에서는 다운로드 정책에 따라 제한될 수 있습니다.
  • 파일 게시 사이트가 일시적으로 응답하지 않는다면 잠시 뒤 재시도합니다.

Google은 네트워크가 불안정하면 Chrome이 다운로드를 자동으로 다시 시작할 수 있으며, 사용자가 직접 재개할 수도 있다고 안내합니다.

3-2. 다시 시작 기능 사용

  1. Chrome 다운로드 기록으로 이동합니다.
  2. 실패 또는 일시중지된 항목의 메뉴를 엽니다.
  3. 다시 시작 가능한 경우 재개를 선택합니다.
  4. 재개 기능이 제공되지 않으면 파일의 공식 출처 페이지에서 다시 내려받습니다.

모든 다운로드가 반드시 중단 지점부터 이어지는 것은 아닙니다. 서버가 부분 다운로드를 지원하지 않는 경우 처음부터 다시 내려받아야 할 수 있습니다.

3-3. 다른 파일과 비교

  • 특정 파일 한 개만 실패: 게시 사이트·권한·파일 자체의 문제일 가능성
  • 서로 다른 정상 사이트의 다운로드가 모두 실패: 네트워크·저장 폴더·보안 설정의 문제일 가능성
  • 다른 기기에서도 동일 파일이 실패: 서버 측 문제일 가능성

이 구별은 진단 순서를 정하기 위한 것이며, 특정 원인을 확정하는 검사는 아닙니다.

4. '다운로드 차단됨'과 '위험한 파일'은 같은 뜻인가요?

꼭 같지는 않습니다. Google은 Chrome이 다음과 같은 이유로 다운로드를 차단할 수 있다고 설명합니다.

  • 위험한 파일: 악성코드 등 명백히 유해한 것으로 판단된 파일
  • 의심스러운 파일: 흔하지 않거나 출처·동작이 의심되는 파일
  • 확인되지 않은 파일: 세이프 브라우징이 꺼진 상태에서 다운로드한 파일 등
  • 안전하지 않은 다운로드: HTTPS 페이지에서 시작됐더라도 실제 다운로드 연결이 안전하지 않은 경우

또한 Windows 자체의 보안 설정이 차단을 일으킬 수 있습니다. 따라서 Chrome에서 경고가 보였다고 해서 Chrome의 기능이 고장 난 것은 아닙니다.

차단됐을 때 안전한 처리 순서

  1. 차단 메시지의 내용을 읽고, 다운로드 출처가 공식 사이트인지 확인합니다.
  2. 의도하지 않은 파일이거나 광고 배너에서 시작된 파일이면 취소합니다.
  3. 소프트웨어라면 제조사·개발사의 공식 배포처를 찾아 파일명과 게시자를 확인합니다.
  4. 다운로드를 멈춘 주체가 Windows 보안인지, Chrome인지 구분합니다.
  5. 출처를 확신할 수 없다면 다운로드하지 않습니다.
  6. 특정 업무 사이트에서만 발생한다면 IT 관리자 또는 사이트 운영자에게 문의합니다.

세이프 브라우징이나 백신을 전체적으로 꺼서 파일을 받는 방법은 권장하지 않습니다. 특히 암호가 걸린 압축파일, 출처가 불명확한 설치 파일, 금전 보상을 약속하는 파일은 더욱 주의해야 합니다.

5. '바이러스 검사 실패' 또는 '바이러스가 발견됨' 해결

Google 고객센터는 이 오류가 바이러스 검사 소프트웨어에 의해 차단됐을 가능성을 뜻한다고 안내합니다. 즉, 문제 해결을 위해 무조건 파일을 허용하는 것이 아니라, 먼저 어떤 프로그램이 차단했는지 확인해야 합니다.

Windows 11에서 검사 기록 확인

  1. Windows의 시작 메뉴에서 Windows 보안을 엽니다.
  2. 바이러스 및 위협 방지 영역과 **보호 기록(Protection history)**을 확인합니다.
  3. 다운로드한 파일과 시각이 일치하는 차단 기록이 있는지 봅니다.
  4. 탐지 이름, 조치 내용, 파일 경로를 확인합니다.
  5. 실제 악성 파일일 가능성이 있거나 판단이 어렵다면 복원·허용 대신 차단 상태를 유지합니다.

Microsoft는 Windows 보안의 보호 기록에서 Microsoft Defender가 취한 조치를 확인할 수 있다고 설명합니다. 일부 상세 정보는 관리자 권한이 필요할 수 있습니다. 관리되는 회사 PC의 경우 회사 보안 정책이 우선입니다.

6. '권한 부족'과 '시스템 사용 중' 오류 해결

Chrome이 컴퓨터에 파일을 저장할 수 없는 경우에 나타나는 메시지입니다. Google은 다운로드 위치를 바꾸거나, 링크에서 다른 이름으로 저장을 이용해 보는 방법을 안내합니다.

저장 위치 변경하는 방법

  1. Chrome 오른쪽 위의 더보기(점 3개) → 설정을 엽니다.
  2. 다운로드 메뉴를 선택합니다.
  3. 다운로드 위치 옆의 변경을 누릅니다.
  4. 본인 계정이 파일을 저장할 수 있는 일반 로컬 폴더를 선택합니다.
  5. 같은 공식 파일을 다시 내려받아 정상 저장되는지 확인합니다.

또는 주소창에서 chrome://settings/downloads를 열 수 있습니다.

이런 경우도 확인하세요

  • 저장 대상이 연결 해제된 외장 드라이브는 아닌가?
  • 폴더에 쓰기 권한이 있는가?
  • 다른 프로그램에서 같은 이름의 파일을 사용 중인 것은 아닌가?
  • 회사·학교 PC에서 관리자 정책으로 폴더 쓰기가 제한돼 있지 않은가?
  • PC의 저장 공간이 너무 적지는 않은가?

원본 파일이나 시스템 폴더의 접근 권한을 무리하게 변경하지 마세요. 우선 일반적인 다운로드 폴더에 저장되는지만 테스트하는 것이 안전합니다.

7. 다운로드 위치를 못 찾을 때: Windows와 Mac

Google 공식 안내에 따르면 기본 저장 위치를 변경하지 않은 경우 일반적인 다운로드 경로는 다음과 같습니다.

운영체제기본 위치
Windows 11C:\Users\사용자이름\Downloads
Mac/Users/사용자이름/Downloads

다만 이는 기본값입니다. 사용자가 다른 폴더를 선택했거나 브라우저 설정이 바뀌었다면 실제 위치는 다를 수 있습니다.

가장 빠른 확인 방법은 다음과 같습니다.

  1. Chrome에서 chrome://settings/downloads로 이동합니다.
  2. 위치에 표시된 폴더를 확인합니다.
  3. 다운로드 전에 각 파일의 저장 위치 확인 옵션을 점검합니다.
  4. 다운로드 기록의 파일명과 저장 위치를 비교합니다.

PDF가 다운로드되지 않고 새 탭에서만 열릴 때

Chrome에는 PDF 문서를 브라우저에서 읽는 기능이 있습니다. PDF가 새 탭으로 열렸다면 저장 오류라기보다 PDF 뷰어의 동작일 수 있습니다.

  • 현재 PDF 뷰어의 다운로드 버튼을 사용합니다.
  • 브라우저의 PDF 처리 방식을 바꾸려면 chrome://settings/content/pdfDocuments에서 설정을 확인합니다.
  • 이 설정은 PDF에 관한 것이며, 모든 파일 형식의 다운로드 오류를 해결하는 기능은 아닙니다.

출처: Google — 파일 다운로드 및 위치 변경, Google — Chrome에서 PDF 관리

8. '실패 - 금지됨', '승인 필요', '파일 없음' 오류

이 오류는 일반적으로 저장 폴더보다 서버 측의 상태와 접근 권한을 우선 확인하는 것이 합리적입니다.

실패 - 금지됨

  • 해당 웹사이트에 로그인이 필요한지 확인합니다.
  • 다운로드할 파일에 실제 접근 권한이 있는지 확인합니다.
  • 이전에 발급된 일회용 링크나 공유 링크가 만료되지는 않았는지 확인합니다.
  • 회사 내부 문서라면 파일 소유자에게 접근 승인을 요청합니다.

승인 필요

  • 파일 게시자가 허용한 계정으로 로그인했는지 확인합니다.
  • 권한이 없다면 사이트 운영자 또는 파일 소유자에게 문의합니다.

파일 없음

  • 링크 주소가 잘못됐거나 파일이 이동·삭제됐는지 확인합니다.
  • 검색 결과에 남아 있는 오래된 직접 다운로드 주소 대신 공식 게시 페이지에서 새 링크를 찾습니다.
  • 아무 사이트에서나 같은 파일명을 검색해 출처가 불분명한 대체 파일을 받지 마세요.

Google의 공식 오류 안내에서 금지됨·승인 필요·파일 없음은 각각 다른 원인으로 다루어집니다.

9. 한 사이트에서 파일을 여러 개 받으려는데 첫 번째만 다운로드될 때

어떤 사이트는 여러 파일을 연속해서 내려받으려고 합니다. 이 경우 Chrome의 자동 다운로드 권한이 관여할 수 있습니다. 단순한 저장 위치 설정과는 다릅니다.

사이트별로 확인하는 방법

  1. 파일을 내려받으려는 사이트에 접속합니다.
  2. 주소창 왼쪽의 사이트 정보 아이콘을 클릭합니다.
  3. 사이트 설정으로 이동합니다.
  4. 자동 다운로드에 관한 권한이 있는지 확인합니다.
  5. 신뢰할 수 있고 사용자가 의도한 사이트에 한해서 필요한 권한을 조정합니다.
  6. 사이트를 새로고침하고 파일 수가 예상과 일치하는지 점검합니다.

전체 웹사이트의 자동 다운로드를 무조건 허용할 필요는 없습니다. 정확한 사이트 주소와 목적을 확인한 뒤 범위를 좁혀 적용해야 합니다.

Chrome의 일반 설정에서 개인정보 및 보안 → 사이트 설정 → 추가 권한 → 자동 다운로드를 찾을 수도 있습니다. 메뉴 명칭과 배치는 버전에 따라 다를 수 있습니다.

10. 파일 다운로드 오류 5분 진단 순서

똑같은 증상으로 여러 설정을 무작정 변경하지 않도록 다음 순서로 점검하세요.

  1. 오류 문구 기록: Chrome 다운로드 기록에서 실제 표시되는 메시지를 확인합니다.
  2. 실패 파일의 출처 확인: 공식 페이지인지, 로그인이나 권한이 필요한지 확인합니다.
  3. 보안 경고 먼저 판단: 위험·의심 다운로드라면 다운로드를 중단합니다.
  4. 네트워크 확인: 서로 다른 정상 사이트도 실패하는지 비교합니다.
  5. 저장 공간 및 경로 확인: Chrome 다운로드 위치가 유효한지, PC에 공간이 있는지 확인합니다.
  6. 사이트별 권한 확인: 여러 파일 자동 다운로드 등 해당 사이트에만 영향을 주는 설정을 확인합니다.
  7. 정상 파일로 재검증: 공식 사이트의 작은 파일처럼 출처가 확실한 항목으로 테스트합니다.
  8. 문제가 지속되면 관리자 또는 사이트 운영자에게 문의합니다. 회사 PC라면 보안 정책을 임의로 우회하지 않습니다.

진단 전후의 Chrome 설정을 기록하면, 원인을 찾지 못했을 때 불필요한 설정 변경을 되돌리기 쉽습니다.

11. 자주 묻는 질문(FAQ)

Q1. Chrome에서 Ctrl+J를 눌렀는데 파일이 안 보이면 다운로드에 실패한 건가요?

꼭 그렇지는 않습니다. 다른 브라우저나 사용자 프로필로 내려받았거나 Chrome의 다운로드 기록에서 삭제했을 수 있습니다. 파일 탐색기 또는 Finder에서 실제 저장 경로를 따로 확인하세요.

Q2. 다운로드를 차단한 파일을 그냥 허용하면 되나요?

권장하지 않습니다. Google은 일부 파일이 악성코드, 사기성 프로그램, 위험한 압축파일 또는 안전하지 않은 연결 때문에 차단될 수 있다고 안내합니다. 파일 게시자의 공식 경로와 경고 사유를 먼저 확인하고, 안전성을 확신할 수 없으면 받지 마세요.

Q3. 저장할 때마다 '다른 이름으로 저장' 창이 뜹니다. 고장인가요?

아닐 수 있습니다. chrome://settings/downloads에서 다운로드 전에 각 파일의 저장 위치 확인 옵션이 켜져 있는지 확인하세요. 사용자가 매번 저장 위치를 고르도록 설정된 경우 정상적인 동작입니다.

Q4. PDF 파일은 화면에서 열리는데 PC 다운로드 폴더에는 없습니다.

Chrome의 PDF 뷰어에서 문서가 열렸을 가능성이 있습니다. PDF 뷰어의 다운로드 버튼을 사용하고, 실제 저장 경로를 확인하세요.

Q5. Windows 보안에서 '바이러스가 발견됨'이 나옵니다. 어떻게 하나요?

Windows 보안의 보호 기록에서 탐지 항목과 조치를 확인하세요. 경고를 우회하거나 백신을 끄지 말고 파일 출처와 신뢰성을 검증하는 것이 우선입니다. 회사 PC라면 관리자에게 문의하세요.

Q6. Chrome에서만 파일이 저장되지 않습니다. 다른 브라우저로 받으면 되나요?

다른 브라우저에서 동작이 달라지는지 비교하면 원인 파악에 도움이 될 수 있습니다. 하지만 악성코드 경고나 접근 권한 제한을 다른 브라우저로 우회하는 목적으로 사용해서는 안 됩니다.

Q7. Chrome 다운로드 위치를 바꿨는데 원래 파일도 자동 이동하나요?

아닙니다. 다운로드 위치 변경은 이후에 저장하는 파일의 기본 목적지를 바꾸는 설정입니다. 기존 파일은 원래 저장된 폴더에 남아 있을 수 있습니다.

12. 최종 체크리스트

  • ☐ 오류 메시지가 네트워크·권한·저장 공간·보안 차단 중 어느 범주인지 구별했다.
  • ☐ Chrome 다운로드 기록에서 실패·중단·완료 상태를 확인했다.
  • ☐ 파일 출처와 게시자를 확인했다.
  • ☐ '위험한 다운로드' 경고를 임의로 우회하지 않았다.
  • ☐ Chrome의 저장 폴더와 PC 여유 공간을 확인했다.
  • ☐ 사이트 로그인 또는 접근 권한이 필요한 파일인지 확인했다.
  • ☐ PDF 뷰어에서 열리는 것과 파일을 실제 저장하는 것을 구분했다.
  • ☐ 여러 개의 파일을 받을 때 해당 사이트의 자동 다운로드 권한을 확인했다.
  • ☐ 파일이 정상적으로 저장되고 열리는지 확인했다.

한 줄 정리: Chrome 다운로드가 안 될 때는 브라우저를 먼저 초기화할 것이 아니라, chrome://downloads/에서 정확한 오류를 확인하고, chrome://settings/downloads에서 저장 위치를 점검하세요. '다운로드 차단됨'은 단순 오류가 아니라 보안 보호 동작일 수 있으므로 원인을 확인하는 것이 먼저입니다.
