아이폰 사진을 윈도우 11 노트북이나 데스크톱으로 옮기려는데 USB를 꽂아도 사진이 안 보이거나, 몇 장만 가져와지고, 일부 동영상만 누락되는 경우가 있습니다. 이때 바로 유료 전송 앱을 설치하거나 아이폰 사진을 삭제할 필요는 없습니다. USB로 사진을 직접 가져오는 방법과 iCloud에 동기화된 사진을 내려받는 방법을 구분하면 해결이 쉬워집니다.

이 글은 Apple과 Microsoft의 공식 사용 설명서를 기준으로 작성했습니다. 기기와 운영체제의 업데이트에 따라 화면 이름은 달라질 수 있으며, 사진을 실제로 가져오고 복사본이 열리는지 확인하기 전에는 원본을 삭제하지 않는 것을 원칙으로 합니다.

2. 방법 1: USB 케이블로 아이폰 사진을 Windows 11에 옮기기

Apple은 Windows PC에서 사진을 가져올 때 Microsoft Store의 Apple 기기 앱 설치, USB 연결, 신뢰 또는 허용 메시지 확인, Microsoft 사진 앱 사용을 안내합니다. Microsoft는 파일 전송 가능한 케이블과 잠금 해제된 휴대전화를 요구합니다.

준비물

  • 아이폰과 Windows 11 PC
  • 데이터 전송을 지원하는 USB 케이블(USB-C 또는 Lightning은 아이폰 모델에 맞게)
  • PC의 사용 가능한 저장 공간
  • PC에 설치한 Apple 기기 앱 및 Microsoft 사진 앱

휴대전화를 충전할 수 있다고 해서 모든 케이블이 사진 전송을 지원하지는 않습니다. 저가형 충전 전용 케이블을 사용했다면 정상적인 데이터 케이블로 바꿔보세요.

실제 가져오기 순서

  1. Microsoft Store에서 Apple 기기 앱을 설치합니다. 필요한 경우 업데이트까지 완료합니다.
  2. 아이폰과 PC를 USB 케이블로 연결합니다.
  3. 아이폰 화면을 켜고 잠금을 해제합니다.
  4. 아이폰에서 '이 컴퓨터를 신뢰하겠습니까?' 또는 '허용'이 나타나면, 본인이 사용하는 PC임을 확인한 뒤 신뢰/허용을 선택합니다.
  5. Windows에서 시작 → 사진을 실행합니다.
  6. 사진 앱의 **가져오기(Import)**를 선택한 뒤 연결된 아이폰을 선택합니다.
  7. 목록에 표시된 사진과 동영상 중 가져올 항목을 고릅니다.
  8. 저장할 위치를 확인하고 가져오기를 시작합니다.
  9. 작업이 끝나면 Windows의 실제 저장 폴더로 이동해 사진과 동영상 파일이 정상적으로 열리는지 확인합니다.

첫 연결이나 많은 사진을 스캔하는 과정은 시간이 걸릴 수 있습니다. 전송 중에는 아이폰 잠금을 풀어 두고 연결이 끊어지지 않도록 하세요. 기기를 인식한 것과 파일의 복사가 끝난 것은 다른 상태입니다.

3. 방법 2: 케이블 없이 Windows용 iCloud로 옮기기

iCloud 사진을 사용하고 있다면 Windows PC에 Windows용 iCloud를 설치해 사진을 확인할 수 있습니다.

  1. 아이폰에서 설정 → 사용자 이름 → iCloud → 사진을 엽니다.
  2. 이 iPhone 동기화 또는 비슷한 이름의 iCloud 사진 동기화 옵션이 켜져 있는지 확인합니다.
  3. Windows 11의 Microsoft Store에서 Windows용 iCloud를 설치합니다.
  4. 아이폰과 같은 Apple 계정으로 로그인합니다.
  5. 로그인 인증을 완료한 뒤 iCloud 사진을 설정합니다.
  6. Windows에서 사진 앱 또는 파일 탐색기의 iCloud 사진 영역을 열고 사진이 나타나는지 확인합니다.
  7. 중요한 사진은 PC에 원본 파일을 다운로드한 다음, 동기화 관리 영역과 별도의 일반 폴더나 외장 저장장치에 복사해 보관합니다.

사진이 처음부터 모두 보이지 않으면 iCloud 사진 동기화가 끝났는지, 인터넷 연결과 iCloud 저장 공간이 충분한지 확인하세요. iCloud는 실시간에 가까운 동기화 서비스로, 별도의 영구 백업을 자동으로 보장하는 방식과 구분해야 합니다.

4. 방법 3: 사진 몇 장만 iCloud.com에서 다운로드하기

케이블도 설치 프로그램도 필요 없이 이미 iCloud에 올라간 일부 사진을 내려받으려면 다음 경로를 사용할 수 있습니다.

  1. Windows 브라우저에서 iCloud 사진에 접속합니다.
  2. 본인의 Apple 계정으로 로그인하고 필요한 추가 인증을 완료합니다.
  3. 사진 화면에서 원하는 사진이나 동영상을 선택합니다.
  4. 다운로드 기능을 실행합니다.
  5. 브라우저의 다운로드 폴더에서 실제 파일이 생성됐는지 확인하고, 필요한 경우 원하는 폴더로 옮깁니다.

주의: 이 방법은 iCloud에 업로드된 사진에만 적용됩니다. iCloud 사진 동기화를 사용하지 않는 아이폰에만 남아 있는 사진은 웹사이트에서 찾을 수 없습니다. 가족 공용 PC라면 계정 로그아웃과 다운로드 파일 정리도 잊지 마세요.

5. USB를 꽂았는데 아이폰이 컴퓨터에 안 뜰 때

아래 순서로 확인합니다. 문제가 해결되기 전에는 사진 보관함 초기화, 아이폰 공장 초기화, 무작정 삭제를 하지 마세요.

첫 번째: 케이블과 USB 포트

  • 충전 전용 케이블을 쓰고 있다면 데이터 전송 케이블로 교체합니다.
  • USB 허브나 도킹스테이션 대신 PC의 다른 USB 포트에 직접 연결해 봅니다.
  • USB-C 또는 Lightning 단자가 손상됐거나 이물질이 있는지 안전하게 확인합니다.
  • Windows의 사진 앱을 다시 열고 연결된 장치 목록을 새로 확인합니다.

두 번째: 아이폰 잠금과 신뢰 요청

  • 아이폰의 잠금 화면을 해제했는지 확인합니다.
  • '이 컴퓨터를 신뢰하겠습니까?'가 나오면 본인 소유 PC에서만 신뢰합니다.
  • 회사, 학교, PC방 등 공용 컴퓨터에서는 민감한 사진을 가져오기 전에 접근 권한을 고려합니다.

세 번째: Windows 앱과 기기 표시

  • Windows에서 Apple 기기 앱과 사진 앱의 업데이트 상태를 확인합니다.
  • 아이폰이 Apple 기기 앱에서 인식되는지, Windows 사진 앱의 가져오기 장치 목록에 나타나는지를 따로 확인합니다.
  • 앱에서 인식되지 않으면 장치를 다시 연결하거나 PC와 아이폰을 재시작한 후 테스트합니다.

Microsoft는 휴대전화가 잠겨 있으면 PC가 장치를 찾지 못할 수 있고, 모든 USB 케이블이 파일 전송 기능을 지원하지는 않는다고 안내합니다.

6. 아이폰 사진 1,000장인데 PC에는 일부만 보이는 이유

사진 일부가 빠진 경우에는 단순한 USB 인식 문제보다 iCloud 원본이 어디에 저장됐는지부터 확인하세요.

iCloud 사진의 '저장 공간 최적화'

iCloud 사진과 저장 공간 최적화를 사용하는 경우에는 아이폰에 사진의 작은 버전만 있고 원본은 iCloud에 있을 수 있습니다. Apple은 이런 환경에서 PC로 USB 가져오기를 하려면 원본 사진을 전체 해상도로 아이폰에 다운로드한 뒤 가져와야 한다고 안내합니다.

확인 순서는 다음과 같습니다.

  1. 아이폰에서 설정 → 사용자 이름 → iCloud → 사진을 엽니다.
  2. iCloud 사진 동기화가 켜져 있는지 확인합니다.
  3. 저장 공간 최적화 설정을 사용 중인지 점검합니다.
  4. 아이폰 저장 공간과 네트워크 연결을 확인한 뒤, 필요한 원본을 다운로드합니다.
  5. 다시 USB로 연결해 Microsoft 사진 앱의 가져오기 목록을 확인합니다.

사진이 아주 많고 아이폰 저장 공간이 부족하다면, 무리하게 모든 원본을 한꺼번에 다운로드하려 하지 말고 Windows용 iCloud 또는 iCloud.com으로 내려받는 방법을 우선 고려하세요.

7. 사진은 복사됐지만 Windows에서 열리지 않을 때: HEIC와 HEVC

전송 문제와 파일 형식 문제는 별도입니다. 사진이 PC의 저장 폴더에 존재하지만 열리지 않으면 파일 확장자부터 확인합니다.

확장자파일 종류확인할 점
.jpg / .jpeg일반적인 JPEG 사진대부분의 일반 사진 앱에서 열림
.heic / .heif고효율 이미지 형식Windows 앱의 코덱 지원 여부에 따라 열리지 않을 수 있음
.mov / .mp4동영상 컨테이너사용된 비디오 코덱에 따라 재생 가능 여부가 다름
HEVC(H.265) 기반 영상고효율 비디오필요한 디코더·앱 지원이 없으면 재생이 실패할 수 있음

Apple은 앞으로 찍을 사진과 동영상을 Windows와 호환성이 높은 형식으로 저장하려면 설정 → 카메라 → 포맷 → 높은 호환성을 선택하도록 안내합니다. 이는 이후에 촬영하는 콘텐츠에 대한 설정이며 이미 저장된 사진을 자동으로 모두 JPG로 변환하지는 않습니다.

기존 HEIC 파일을 JPG로 변환하려는 경우는 별도 문제입니다. 먼저 파일을 안전하게 복사한 뒤 변환하고, 원본은 변환 결과가 정상적으로 열리는지 확인한 후 정리하세요.

8. 사진을 옮겼다면 아이폰에서 바로 지워도 될까?

안 됩니다. 먼저 원본과 사본을 확인하세요. 특히 iCloud 사진을 사용하는 경우에는 아이폰 사진 앱에서 사진을 삭제하면 동일한 Apple 계정으로 동기화되는 다른 기기에서도 삭제될 수 있습니다. Apple은 삭제된 항목을 '최근 삭제된 항목'에서 일반적으로 30일 동안 복구할 수 있지만, 그 이후에는 영구적으로 삭제될 수 있다고 설명합니다.

안전한 확인 순서는 다음과 같습니다.

  1. Windows의 일반 로컬 폴더에 실제 사진·동영상 파일이 저장됐는지 확인합니다.
  2. 날짜별로 오래된 사진, 최근 사진, 동영상 파일을 각각 몇 개 열어봅니다.
  3. 옮길 대상의 수와 PC에 저장된 파일 수를 대략 비교하고 누락 가능성을 점검합니다. Live Photo나 편집 사본 때문에 파일 수가 일대일로 같지 않을 수 있습니다.
  4. 중요한 파일은 다른 드라이브나 외장 저장장치에 두 번째 복사본을 만듭니다.
  5. iCloud 사진 동기화가 켜져 있다면 삭제가 어디에 반영되는지 공식 안내를 먼저 읽습니다.
  6. 복사본의 정상 재생과 별도 보관을 확인한 후에만 원본 정리를 검토합니다.

특히 Windows용 iCloud에서 보이는 사진 목록과 별도 폴더에 다운로드해 독립적으로 보관한 파일을 혼동하지 마세요. 파일 탐색기에 아이콘이 보이는 것만으로 오프라인 원본이 모두 확보됐다는 뜻은 아닐 수 있습니다.

10. 자주 묻는 질문(FAQ)

Q1. 아이폰 사진을 PC로 옮기려면 iTunes를 설치해야 하나요?

Apple의 현재 Windows용 공식 안내는 Microsoft Store의 Apple 기기 앱을 설치하고 Windows의 Microsoft 사진 앱으로 가져오는 절차를 제시합니다. 과거 블로그의 iTunes 중심 설명과 다를 수 있으므로 최신 Apple 지원 문서를 우선하세요.

Q2. 아이폰 사진을 케이블 없이 무료로 옮길 수 있나요?

이미 iCloud 사진이 켜져 있고 필요한 사진이 업로드됐다면 iCloud.com이나 Windows용 iCloud에서 확인할 수 있습니다. 다만 무료 저장 공간의 여유와 사진·동영상 용량, 인터넷 사용량에 영향을 받습니다. 모든 사진이 iCloud에 자동 업로드돼 있다고 가정하면 안 됩니다.

Q3. USB로 옮긴 사진을 컴퓨터에서 삭제하면 아이폰에서도 삭제되나요?

Windows 사진 앱을 이용해 독립적인 로컬 사본으로 가져온 파일과 iCloud 동기화 보관함의 파일은 다르게 취급해야 합니다. 독립 복사본을 지우는 것과 iCloud 사진 보관함에서 동기화된 항목을 삭제하는 것은 결과가 다를 수 있으므로 저장 경로를 먼저 확인하세요.

Q4. 동영상 용량이 너무 커서 가져오기가 오래 걸리면?

긴 4K 동영상은 파일 크기가 큽니다. PC의 남은 저장 공간, USB 연결 안정성, 기기 잠금 상태를 확인하고 작은 묶음으로 나누어 가져와 보세요. 이미 가져온 파일과 가져오지 못한 파일을 구분해 중복 복사를 줄입니다.

Q5. 아이폰에서 맥북으로 옮기는 방법도 같나요?

다릅니다. Mac에서는 USB로 연결한 뒤 Mac 사진 앱 → 연결된 기기 → 가져오기로 진행하거나, iCloud 사진 또는 AirDrop을 사용할 수 있습니다. Windows에서 사용하는 Microsoft 사진 앱과 구분하세요.

11. 최종 체크리스트

  • ☐ 전송하려는 사진이 아이폰 내부에 있는지 / iCloud에 있는지 구분했다.
  • ☐ USB를 사용한다면 데이터 케이블, 아이폰 잠금 해제, 신뢰 허용을 확인했다.
  • ☐ Windows 사진 앱에서 가져오기 기능을 이용했다.
  • ☐ 일부 사진이 없다면 iCloud의 원본 다운로드 상태를 점검했다.
  • ☐ HEIC 형식 오류를 사진 전송 실패와 구분했다.
  • ☐ PC의 실제 로컬 폴더에 저장된 사진·동영상을 열어봤다.
  • ☐ 별도 저장장치에 중요한 사진의 두 번째 복사본을 만들었다.
  • ☐ 검증을 마치기 전까지 아이폰 또는 iCloud에서 사진을 지우지 않았다.

정리: 아이폰의 사진 원본이 기기에 있고 PC로 한 번만 복사하려면 USB + Apple 기기 앱 + Windows 사진 앱, 원본이 iCloud에 있고 여러 장치에서 접근하려면 Windows용 iCloud 또는 iCloud.com이 적합합니다. 사진이 일부만 보이는 현상과 HEIC 형식 문제를 혼동하지 않고, 원본과 독립 백업을 검증한 다음 정리하는 것이 가장 안전합니다.
