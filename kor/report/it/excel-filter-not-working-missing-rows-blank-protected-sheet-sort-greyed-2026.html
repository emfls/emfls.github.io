엑셀에서 데이터 → 필터를 눌렀는데 화살표가 생기지 않거나, 필터 목록에 분명히 있는 값이 보이지 않거나, 새로 입력한 행이 검색 결과에 빠질 때가 있습니다. 이때는 파일 전체를 초기화하거나 데이터를 다시 입력하기 전에 필터가 적용된 범위·다른 열의 필터 조건·원본 데이터 형식·시트 보호 설정을 먼저 확인해야 합니다.

이 글은 Microsoft 365용 Excel, Excel 2024 및 최근 데스크톱 Excel을 기준으로 작성했습니다. 2026년 11월 4일 기준 Microsoft 공식 지원 자료를 바탕으로 오류 상황을 분류하고, 데이터 손실 없이 점검할 순서를 정리했습니다. Mac·웹용 Excel은 메뉴와 단축키가 일부 다를 수 있습니다.

원본 보호가 우선입니다. 특히 정렬을 실행하면 행 순서가 바뀌고, 저장된 뒤에는 원래 순서를 자동 복원하지 못할 수 있습니다. 중요한 정산·재고·고객 명단은 원본을 복사한 뒤 아래 작업을 수행하세요.

1. 증상별로 먼저 볼 곳

엑셀에서 나타나는 증상가장 먼저 확인할 항목빠른 진단
열 제목에 ▼ 화살표가 없음필터 기능을 적용했는지표 범위 선택 → 데이터 → 필터
필터는 되는데 일부 행만 안 나옴자동 선택 범위 누락실제 마지막 행까지 범위가 포함됐는지
항목 하나를 선택해도 예상보다 적게 나옴다른 열의 필터가 동시에 적용됨데이터 → 지우기
새로 추가한 행이 검색 안 됨기존 필터 범위 밖이거나 재적용 필요범위 확인 → 다시 적용
숫자 필터 대신 텍스트 필터가 표시됨숫자와 텍스트가 섞임원본 데이터 형식 점검
날짜 필터에 예상 월·연도가 없음날짜와 날짜처럼 보이는 문자열 혼재실제 날짜 값인지 확인
필터·정렬 메뉴가 회색시트 보호·파일 권한·모드 차이검토 → 시트 보호 확인

필터를 껐는데도 행이 보이지 않음필터 외 수동 숨기기 가능성행 번호·숨기기 해제 상태 확인

구별 포인트: 행을 숨기는 필터와 데이터를 실제로 삭제하는 작업은 다릅니다. 필터 때문에 보이지 않던 행을 삭제된 것으로 오해하지 마세요.

공식 근거: Microsoft — Excel에서 범위 또는 표의 데이터 필터링, Microsoft — 필터 지우기 또는 제거

2. 엑셀 필터 적용 방법: 기본부터 확인

필터가 처음부터 설정되지 않았거나 다른 셀을 선택했다면 원하는 열의 ▼ 버튼이 나타나지 않을 수 있습니다.

  1. 원고·매출·재고 등 데이터의 머리글(제목 행)을 포함한 범위에서 아무 셀이나 선택합니다.
  2. 상단 리본 데이터 → 필터를 누릅니다.
  3. 각 열의 제목에 드롭다운 화살표가 표시되는지 확인합니다.
  4. 원하는 열의 화살표를 선택합니다.
  5. 체크박스를 이용해 값의 표시 여부를 바꾸거나 텍스트 필터·숫자 필터·날짜 필터에서 조건을 선택합니다.
  6. 결과가 예상대로 나오면 저장합니다.

Windows 단축키

Windows 데스크톱 Excel에서는 일반적으로 Ctrl + Shift + L을 사용해 자동 필터를 켜거나 끌 수 있습니다. 이 기능은 상황에 따라 필터 설정을 전환하므로, 필터가 이미 켜져 있을 때 같은 키를 누르면 필터가 꺼질 수 있습니다.

표(Table)로 만든 데이터라면?

데이터를 표로 서식 지정하거나 표로 변환하면 기본적으로 제목 행에 필터 컨트롤이 생깁니다. 단, 표 머리글을 숨기거나 필터 단추 설정을 바꾼 경우에는 표시 상태가 달라질 수 있습니다.

공식 출처: Microsoft — 범위 또는 표에서 데이터 필터링

3. 필터 화살표가 안 보일 때

3-1. 선택한 셀과 데이터 범위 확인

필터 대상 데이터와 멀리 떨어진 빈 셀을 선택한 채 필터를 적용하면 원하는 범위에 필터가 만들어지지 않을 수 있습니다.

  • 데이터 머리글과 첫 데이터 행이 포함된 실제 표 내부를 선택합니다.
  • 파일 내에 여러 데이터 영역이 따로 있다면, 필터가 필요한 범위를 드래그해 정확히 선택합니다.
  • 머리글 행을 선택하지 않은 상태에서 필터를 잘못 적용하지 않았는지 확인합니다.

3-2. 표의 머리글 표시 상태 확인

표를 사용 중이라면 표 내부 셀을 누르고 표 디자인(Table Design) 메뉴에서 머리글 행(Header Row)과 필터 컨트롤 관련 옵션을 확인합니다. 해당 탭과 옵션은 Excel 버전에 따라 달라질 수 있습니다.

3-3. 보호된 시트인지 확인

검토 → 시트 보호 해제가 보인다면 현재 시트가 보호됐을 수 있습니다. 보호된 시트는 일반적인 필터 생성·제거가 제한됩니다.

Microsoft 공식 설명: 시트 보호 설정의 '자동 필터 사용'은 보호 전에 이미 만들어진 자동 필터의 조건을 변경하도록 허용하는 옵션입니다. 보호된 시트에서 새 필터를 생성하거나 제거하도록 허용하는 기능은 아닙니다.

회사에서 받은 파일이라면 보호를 무단으로 우회하지 말고 문서 소유자에게 필터 적용 권한을 요청하세요.

공식 출처: Microsoft — 워크시트 보호

4. 필터에 특정 행이 누락되는 원인: 범위가 끊겼을 수 있습니다

업무용 데이터에서는 1행에 제목, 2~300행에 항목을 입력해 두다가 중간에 통째로 비어 있는 행을 두는 경우가 있습니다. 이때 데이터를 자동으로 선택하면 의도한 전체 범위보다 좁게 잡히는 상황이 생길 수 있습니다.

안전하게 범위 다시 지정하는 순서

  1. 먼저 파일을 다른 이름으로 저장해 복사본을 만듭니다.
  2. 실제 머리글부터 마지막 데이터 행까지 확인합니다.
  3. 데이터가 A1:F300처럼 구성돼 있다면 머리글을 포함해 A1:F300 전체를 직접 선택합니다.
  4. 이미 잘못된 범위에 필터가 적용됐다면 기존 필터를 먼저 해제합니다.
  5. 선택한 전체 범위에서 데이터 → 필터를 적용합니다.
  6. 기존에 누락됐던 마지막 행이 필터 조건에 따라 표시되는지 확인합니다.

주의: 중간에 빈 행이 있다는 이유만으로 엑셀 필터가 무조건 실패하는 것은 아닙니다. 문제는 선택되거나 자동 감지된 필터 범위에 원하는 행이 실제로 포함됐는가입니다.

표로 바꾸는 방법도 유용합니다

  1. 머리글과 데이터를 포함한 전체 범위를 선택합니다.
  2. Ctrl + T 또는 삽입 → 표를 선택합니다.
  3. 머리글 포함 여부를 확인하고 표를 생성합니다.
  4. 각 머리글의 필터 화살표를 사용합니다.

표는 관련된 데이터 행을 관리하기 편한 구조이지만, 기존 서식과 계산·참조 방식에 영향을 줄 수 있습니다. 재무·회계 자료에서는 복사본으로 표 변환 결과를 먼저 검증하세요.

공식 출처: Microsoft — 표 데이터 필터링

5. 다른 열의 필터가 이미 적용돼 있으면 검색 결과가 줄어듭니다

엑셀에서는 여러 열에 필터를 동시에 적용할 수 있습니다. 예를 들어 '지역=서울'과 '상태=완료' 조건이 동시에 걸려 있다면 서울이면서 완료인 행만 보입니다.

가장 빠른 확인 방법

  1. 각 열 제목의 화살표가 일반 ▼인지 적용된 필터 아이콘인지 확인합니다.
  2. 화면 위 데이터 → 지우기(Clear)를 선택합니다.
  3. 모든 행이 다시 표시되는지 확인합니다.
  4. 원하는 조건을 한 열씩 다시 적용합니다.

'지우기(Clear)'와 '필터(Filter) 제거'는 다릅니다.

  • 필터 지우기: 지정했던 필터 조건을 해제해 전체 행을 다시 표시합니다. 필터 화살표는 유지됩니다.
  • 필터 제거: 자동 필터 자체를 꺼서 머리글의 필터 컨트롤을 제거합니다.

데이터가 필터 때문에 숨겨진 건지 확인하려면 먼저 필터 지우기를 이용하세요. 불필요하게 범위를 다시 설정할 이유가 없습니다.

공식 출처: Microsoft — 필터 지우기 또는 제거

6. 필터 목록에 새로 입력한 값이 안 보이는 경우

새 데이터를 입력하거나 기존 셀 값을 고친 뒤에도 필터가 자동으로 최신 결과를 즉시 보여주지 않는 경우가 있습니다. Microsoft는 필터를 다시 적용(Reapply)하면 변경된 데이터를 기준으로 결과가 갱신될 수 있다고 설명합니다.

해결 순서

  1. 새 행이 필터 범위 안에 있는지 먼저 확인합니다.
  2. 값이 들어간 열의 데이터 형식이 일관적인지 확인합니다.
  3. 상단 데이터 → 다시 적용(Reapply) 또는 홈 → 정렬 및 필터 → 다시 적용을 사용합니다.
  4. 해당 열의 필터 메뉴를 다시 열어 항목이 나타나는지 확인합니다.
  5. 범위 밖의 행이라면 전체 데이터 범위를 다시 지정하거나 표로 관리합니다.

다시 적용과 초기화는 다릅니다

'다시 적용'은 필터 조건을 현재 데이터에 다시 적용하는 것입니다. 행이나 열의 데이터를 삭제하는 작업도 아니고, 엑셀 설정을 공장 초기화하는 작업도 아닙니다.

공식 자료: Microsoft — 필터 및 정렬 다시 적용

7. 숫자 필터가 안 뜨고 텍스트 필터만 나오는 이유

판매금액 열에 5000, 10000, 15000이 있는데 '숫자 필터' 대신 '텍스트 필터'가 보인다면 같은 열에 숫자와 텍스트 값이 혼합돼 있을 수 있습니다.

Microsoft 공식 문서에서는 동일 열에 숫자·텍스트·날짜 형식을 혼합하지 말라고 권고합니다. 서로 다른 형식이 섞인 경우 가장 많이 등장하는 형식을 기준으로 필터 명령이 표시될 수 있습니다.

숫자 데이터인지 확인하는 방법

예를 들어 A2 셀에 숫자로 보이는 값이 있다고 가정합니다.

  1. 빈 셀에 =ISNUMBER(A2)를 입력합니다.
  2. TRUE라면 실제 숫자로 인식됩니다.
  3. FALSE라면 숫자처럼 보이는 텍스트이거나 다른 데이터 형식일 수 있습니다.
  4. 해당 열의 값을 어떤 시스템에서 가져왔는지 확인합니다.
  5. 복사본에서 숫자 변환 방법을 결정하고 테스트합니다.

모두 숫자로 바꾸면 되는 것 아닌가요?

주의: 전화번호·상품코드·우편번호·계좌번호·주문번호는 숫자로 보이더라도 텍스트로 관리해야 하는 식별자일 수 있습니다. 이를 무조건 숫자로 변환하면 앞자리 0이 사라지거나 긴 숫자의 정확도가 떨어질 수 있습니다.

금액·수량처럼 실제 계산해야 하는 값만 적절히 숫자로 정리해야 합니다.

공식 출처: Microsoft — 혼합 데이터 형식과 필터

8. 날짜 필터가 안 되고 월별 목록이 이상할 때

'2026-11-04'라는 문자열이 셀에 보인다고 해서 반드시 Excel 내부에서 날짜 값으로 저장된 것은 아닙니다. 날짜를 직접 입력했는지, CSV에서 가져왔는지, 문자로 저장했는지에 따라 동작이 달라질 수 있습니다.

확인 순서

  1. 문제가 있는 날짜 셀을 선택합니다.
  2. 수식 입력줄에서 원래 입력값을 확인합니다.
  3. 빈 셀에서 =ISNUMBER(A2)를 시험해 날짜가 숫자 기반 값인지 확인합니다. 단, A2에는 실제 날짜 셀이 들어 있어야 합니다.
  4. 날짜열에 날짜 값과 날짜처럼 보이는 텍스트가 혼합돼 있는지 확인합니다.
  5. 데이터 정리 전 원본 파일을 복사합니다.
  6. 필요하다면 Excel의 날짜 변환 또는 가져오기 기능을 이용해 값을 통일합니다.
  7. 필터를 다시 적용해 날짜별 그룹·조건을 확인합니다.

날짜를 실제 날짜로 만들지 않고 셀 표시 형식만 날짜로 변경하는 작업으로 문제가 항상 해결되지는 않습니다. 값 자체가 텍스트라면 별도 변환이 필요할 수 있습니다.

일부 행만 필터에 안 잡히는 대표 사례

표시된 셀 내용내부 값 가능성필터 동작
2026-11-04실제 날짜 값날짜 그룹화·날짜 필터 가능
2026-11-04텍스트 문자열텍스트 필터의 대상이 될 수 있음
2026. 11. 4.실제 날짜 값 또는 문자열입력 방식·지역 설정에 따라 다름
공백빈 셀 또는 공백 문자빈칸 필터 결과가 예상과 다를 수 있음

Microsoft는 날짜·숫자·텍스트가 같은 열에서 혼합되면 필터 표시와 결과가 혼동될 수 있다고 설명합니다.

9. 분명히 항목이 있는데 필터 체크 목록에는 안 보일 때: 10,000개 제한

Microsoft Excel은 자동 필터 드롭다운 목록에 처음 10,000개의 고유 항목만 표시한다고 안내합니다.

예를 들어 고객 ID·상품코드가 수만 개이고 각 행의 값이 거의 모두 다르면, 실제 데이터에 값이 있더라도 드롭다운의 체크박스 목록에서 모든 고유값을 찾을 수 없을 수 있습니다.

해결 방향

  • 체크박스 목록에서 값을 하나씩 고르는 방식만 고집하지 않습니다.
  • 필터 메뉴의 텍스트 필터 → 같음(Equals) 또는 포함(Contains) 같은 조건을 활용합니다.
  • 숫자 범위 검색은 숫자 필터를 이용합니다.
  • 데이터량이 크면 조건을 더 좁히거나 보조 열을 구성합니다.
  • 필터 범위가 실제 전체 데이터에 적용돼 있는지 다시 확인합니다.

중요: 10,000개 제한은 필터 드롭다운에 표시하는 고유값 목록의 제한입니다. '엑셀에서 10,000행 이후의 데이터는 필터링할 수 없다'는 뜻이 아닙니다.

10. 필터 버튼이 회색으로 비활성화됐다면: 시트 보호 확인

다른 파일에서는 되는데 회사에서 받은 파일에서만 필터·정렬 버튼이 회색이라면 시트 보호 여부부터 확인하세요.

시트 보호 여부 확인하기

  1. 상단 리본의 검토(Review) 탭을 엽니다.
  2. 시트 보호 해제(Unprotect Sheet)라는 항목이 표시되는지 확인합니다.
  3. 시트가 보호된 상태라면 사용자가 변경할 수 있는 범위에 제한이 있을 수 있습니다.
  4. 업무 파일이라면 작성자나 관리자에게 필터 사용 권한을 문의합니다.

보호 시트에서 이미 만들어진 필터는 사용할 수 있나요?

네, 조건에 따라 가능합니다. Microsoft는 시트를 보호할 때 자동 필터 사용(Use AutoFilter)을 허용한 경우, 기존 필터의 드롭다운을 이용해 조건을 바꿀 수 있다고 설명합니다.

하지만 보호된 시트에서 새 필터를 적용하거나 기존 필터를 제거하는 작업은 허용하지 않는다는 제한이 있습니다. 따라서 버튼이 회색인 상황에서 비밀번호를 무단 해제하거나 비공식 보호 우회 프로그램을 사용할 필요는 없습니다.

또한 웹용 Excel·조직 공유 문서에서는 권한과 기능 지원 범위에 따른 차이가 있을 수 있으므로 파일 소유자의 안내를 먼저 확인하세요.

공식 자료: Microsoft — 워크시트 보호와 자동 필터 권한

11. 정렬이 안 되거나 병합 셀 경고가 나오는 경우

필터와 정렬은 다릅니다.

  • 필터: 조건에 맞지 않는 행을 일시적으로 감춥니다.
  • 정렬: 행의 순서를 바꿉니다.

엑셀의 데이터 범위에 병합된 셀이 있다면 정렬이 제한될 수 있습니다. Microsoft는 병합 셀이 포함된 열에서 정렬이 작동하지 않을 수 있다고 안내합니다.

병합 셀 찾기

  1. 원본 복사본에서 홈 → 찾기 및 선택 → 찾기를 선택합니다.
  2. 옵션 → 서식(Format) 메뉴를 확인합니다.
  3. 맞춤(Alignment) → 셀 병합(Merge cells) 조건을 지정합니다.
  4. 모두 찾기(Find All)로 병합된 셀 위치를 확인합니다.
  5. 필요하다면 원본의 구조를 이해한 뒤 병합 해제를 검토합니다.

병합을 해제하면 병합된 여러 셀에 각각 값이 복원되는 것이 아닙니다. 일반적으로 병합 영역의 내용 유지 방식이 달라질 수 있어 원본 백업과 수식 검증이 필요합니다.

중요: 병합 셀 때문에 정렬이 안 된다는 설명을 모든 필터 문제의 유일한 원인으로 적용할 수는 없습니다. 필터 자체가 정상이고 정렬만 실패하는지 먼저 확인하세요.

공식 자료: Microsoft — 병합된 셀 찾기

12. 필터를 해제했는데 행이 안 보인다면?

어떤 행은 필터로 숨겨진 것이 아니라 사용자가 수동으로 숨긴 행일 수 있습니다. 행 번호가 건너뛰는 경우를 확인하세요.

구분 방법

  1. 먼저 데이터 → 지우기로 필터 조건을 모두 해제합니다.
  2. 필터가 있는 열의 아이콘이 일반 드롭다운으로 돌아왔는지 확인합니다.
  3. 여전히 행 번호가 건너뛴다면 수동으로 숨긴 행일 수 있습니다.
  4. 해당 행 위아래를 선택하고 홈 → 서식 → 숨기기 및 숨기기 취소 → 행 숨기기 취소 같은 메뉴를 확인합니다.
  5. 결과가 의도한 범위인지 확인합니다.

보호된 시트나 그룹화된 데이터에서는 행 표시·숨기기 관련 설정이 달라질 수 있으므로 파일 소유자의 작업 목적을 확인하세요.

Microsoft 공식 문서는 필터를 지우면 필터에 의해 숨겨진 행을 다시 표시할 수 있다고 설명합니다. 따라서 지운 뒤에도 행이 안 보인다면 필터 외의 원인을 따로 살펴볼 가치가 있습니다.

공식 출처: Microsoft — 모든 필터 지우기

13. 필터 적용 상태에서 행을 삭제하면 왜 위험할까요?

필터가 적용되면 화면에 보이는 일부 행만 작업 대상으로 보일 수 있습니다. 이 상태에서 사용자가 행 삭제·범위 복사·정렬을 실행하면 의도하지 않은 데이터가 바뀔 수 있습니다.

특히 '중복 제거(Remove Duplicates)'는 단순 필터와 다릅니다. Microsoft는 중복 제거가 실제 값을 삭제하므로 원본 범위를 다른 시트나 파일에 복사해 두라고 권고합니다.

안전한 작업 원칙

  1. 먼저 원본 파일을 보관합니다.
  2. 필터를 적용해 원하는 값과 결과를 확인합니다.
  3. 단순 조회 목적이라면 행 삭제를 실행하지 않습니다.
  4. 데이터를 삭제해야 한다면 선택된 범위와 모든 행에 대한 영향을 확인합니다.
  5. 정렬 전에 원래 순서 번호를 가진 보조 열을 만드는 것도 좋습니다.
  6. 작업 후 필터를 해제하고 전체 행 수·합계·중요 항목이 동일한지 확인합니다.

팁: 단순히 특정 제품만 보고 싶다면 필터만으로 충분합니다. 다른 항목을 삭제할 필요가 없습니다.

공식 근거: Microsoft — 고유 값 필터링 및 중복 제거

  3. 지역 열에서 서울만 선택합니다.

16. 자주 묻는 질문(FAQ)

Q1. 엑셀 필터 버튼이 안 눌리는 이유는 무엇인가요?

먼저 시트 보호 여부를 확인하세요. 보호된 워크시트는 새 필터 적용·제거가 제한될 수 있습니다. 그 외에도 현재 편집 권한과 Excel 버전 차이가 영향을 줄 수 있습니다.

Q2. 필터 목록에 데이터가 있는데 일부 행이 빠집니다.

필터에 적용된 실제 범위, 다른 열에 걸려 있는 필터 조건, 값의 데이터 형식을 확인하세요. 새로 입력한 행이라면 다시 적용도 시도해 보세요.

Q3. 데이터가 10,000행을 넘으면 필터가 작동하지 않나요?

아닙니다. Microsoft가 안내하는 10,000개 제한은 드롭다운에 보이는 고유 항목 수입니다. 10,000행을 넘는다고 필터 기능 전체가 중지되는 것은 아닙니다.

Q4. 숫자 필터가 아니라 텍스트 필터만 보입니다.

같은 열에 숫자와 텍스트가 혼합돼 있을 수 있습니다. 실제 계산할 숫자인지, 전화번호·상품번호 등 텍스트로 보존해야 하는 값인지 구분하세요.

Q5. 날짜별로 필터가 안 됩니다.

날짜처럼 보이는 셀이 실제 Excel 날짜 값인지 확인해야 합니다. 날짜와 텍스트를 혼합해 저장하면 필터 명령이 예상과 다르게 나타날 수 있습니다.

Q6. 필터 지우기를 누르면 데이터가 삭제되나요?

아닙니다. 데이터 → 지우기는 필터 조건을 해제하는 기능입니다. 반면 중복 제거·행 삭제는 실제 데이터를 변경할 수 있으므로 구별해야 합니다.

Q7. 파일을 저장했다가 다시 열면 필터가 유지되나요?

Microsoft는 표(Table)의 경우 필터·정렬 조건을 저장하고 다시 적용할 수 있다고 안내합니다. 일반 범위에서는 정렬 기준 저장에 차이가 있으므로 반복해서 사용할 경우 표 사용을 검토하세요.

Q8. 보호된 시트에서는 필터를 절대 사용할 수 없나요?

그렇지는 않습니다. 시트 보호 전 이미 설정된 자동 필터에 대해 '자동 필터 사용' 권한이 허용된 경우, 드롭다운으로 조건을 바꿀 수 있습니다. 다만 보호된 상태에서 필터를 새로 만들거나 제거하는 작업은 제한됩니다.

Q9. 병합된 셀 때문에 필터가 안 되나요?

병합 셀은 정렬과 데이터 구조에 문제를 일으킬 수 있습니다. 특히 정렬 오류가 발생한다면 병합된 셀을 찾아보세요. 모든 필터 오류가 병합 셀 때문은 아닙니다.

Q10. 엑셀 필터와 FILTER 함수는 같은 기능인가요?

다릅니다. 자동 필터(AutoFilter)는 기존 데이터에서 조건에 맞지 않는 행을 숨겨 보는 기능입니다. FILTER 함수는 지정한 조건에 맞는 데이터를 수식 결과로 반환하는 동적 배열 함수입니다. FILTER 함수의 결과가 #SPILL! 오류를 표시하는 경우는 자동 필터의 화살표 문제와 다른 주제입니다.

17. 5분 해결 체크리스트

  • ☐ 원본 파일을 복사해 백업했다.
  • ☐ 데이터 → 필터가 실제 데이터 범위에 적용돼 있다.
  • ☐ 머리글 행에 필터 화살표가 표시된다.
  • ☐ 빠진 행이 필터 범위 안에 포함돼 있다.
  • ☐ 다른 열의 필터 조건을 모두 확인했다.
  • ☐ 필요할 때 데이터 → 지우기로 전체 행을 다시 표시했다.
  • ☐ 새 데이터가 추가됐다면 다시 적용(Reapply)을 사용했다.
  • ☐ 숫자·날짜·텍스트 값의 혼합 여부를 확인했다.
  • ☐ 드롭다운 고유 항목 10,000개 표시 제한을 이해했다.
  • ☐ 버튼이 회색이라면 시트 보호·권한을 확인했다.
  • ☐ 정렬 오류라면 병합 셀을 점검했다.
  • ☐ 필터 해제 후에도 보이지 않는 행은 수동 숨기기 여부를 확인했다.
  • ☐ 정렬·삭제 작업 전 원래 순서를 복원할 수 있는 방법을 마련했다.

정리: 엑셀 필터가 안 될 때는 필터 범위 → 다른 열의 조건 → 다시 적용 → 데이터 형식 → 시트 보호 순으로 확인하는 것이 효율적입니다. 필터 기능을 다시 켜기 전에 먼저 원본 데이터가 손실되지 않도록 복사본을 만들고, 잘못된 결과가 나온 이유를 구분하세요.
