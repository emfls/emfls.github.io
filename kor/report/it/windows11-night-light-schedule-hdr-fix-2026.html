밤에 컴퓨터 화면을 보다 보면 화면이 너무 차갑거나 밝게 느껴질 수 있습니다. Windows 11에는 화면 색을 따뜻하게 바꾸는 **야간 모드(Night light)**가 있지만, 실제로는 버튼이 회색으로 비활성화되거나 예약한 시간에 켜지지 않거나 HDR 모니터에서 색이 과도하게 붉게 보이는 문제가 생기기도 합니다.

이때 많은 사람이 화면을 어둡게 만드는 다크 모드와 야간 모드를 같은 기능으로 생각합니다. 하지만 둘은 목적부터 다릅니다. 다크 모드는 Windows와 지원 앱의 밝은 배경을 어두운 배경으로 바꾸며, 야간 모드는 화면이 표시하는 색온도를 따뜻하게 조정합니다. 색 필터, 화면 색조, HDR, 밝기 자동 조절도 각각 별도 기능입니다.

이 글은 Microsoft 공식 지원 문서를 바탕으로 오류를 ① 설정 자체가 켜지지 않는 문제 ② 예약에 맞춰 켜지지 않는 문제 ③ 켜졌지만 색이 이상해지는 문제로 나누어 진단합니다. 본문의 '세 갈래 진단표'는 설명을 위해 자체 구성한 도구이며, 특정 조치가 모든 PC에서 성공함을 보장하지 않습니다.

1. '야간 모드'와 '다크 모드'는 무엇이 다를까?

기능주요 변화설정 위치어떤 문제에 활용하나
야간 모드(Night light)화면의 색을 더 따뜻하게 표시설정 → 시스템 → 디스플레이저녁 시간 화면의 차가운 색조 조정
다크 모드(Dark mode)Windows와 지원 앱의 밝은 UI를 어둡게 변경설정 → 개인 설정 → 색밝은 배경이 불편할 때
밝기 조절(Brightness)화면 전체 밝기 조정설정 → 시스템 → 디스플레이지나치게 밝거나 어두운 화면
색 필터(Color filters)화면의 색상 팔레트 변경설정 → 접근성 → 색 필터색 구분이 어려운 환경

HDR지원 디스플레이의 밝기·색 표현 기능설정 → 시스템 → 디스플레이 → HDRHDR 콘텐츠 표시와 색 재현

Microsoft는 야간 모드를 청색광을 줄이도록 화면을 따뜻한 색으로 바꾸는 기능으로 안내합니다. 다만 특정한 의학적 효과나 불면증 치료를 보장하는 기능으로 이해해서는 안 됩니다.

특히 사진 편집·인쇄물 색상 검수처럼 정확한 색 판단이 중요한 작업을 할 때는 야간 모드·색 필터·화면 색조를 꺼서 화면 상태를 확인하는 편이 합리적입니다. 편안해 보이는 색과 색 정확도가 높은 화면은 항상 같지 않기 때문입니다.

공식 참고: Microsoft — Windows 디스플레이 밝기와 색, Microsoft — Windows 색상 개인 설정

2. 야간 모드가 정상인지 먼저 1분 점검

복잡한 드라이버 작업부터 시작할 필요는 없습니다. 수동 켜기와 강도 슬라이더가 실제로 작동하는지를 먼저 확인해 보세요.

  1. 키보드에서 Windows 키 + I를 눌러 설정을 엽니다.
  2. 시스템 → 디스플레이로 이동합니다.
  3. 야간 모드를 켭니다.
  4. 야간 모드 항목을 선택해 세부 설정을 엽니다.
  5. 강도 슬라이더를 왼쪽과 오른쪽으로 움직여 화면 색이 달라지는지 살펴봅니다.
  6. 시험이 끝나면 본인에게 맞는 강도로 되돌립니다.

Microsoft는 작업 표시줄 오른쪽의 네트워크·스피커 아이콘으로 빠른 설정을 열어 야간 모드를 켜거나 끌 수도 있다고 안내합니다. 하지만 빠른 설정에 버튼이 보이지 않더라도 설정 → 시스템 → 디스플레이에서 확인할 수 있습니다.

강도가 낮으면 야간 모드를 켜도 변화가 거의 보이지 않을 수 있습니다. 이 경우 단순히 '작동 안 함'이라고 판단하지 말고 강도 슬라이더를 조절해 비교하세요.

공식 참고: Microsoft — 야간 모드 켜기·강도 조정

여기서 회색 버튼과 예약 오류는 서로 다릅니다. 설정이 비활성화되어 있다면 시간을 변경해도 해결되지 않을 수 있고, 수동으로 정상 작동하는데 예약만 실패한다면 드라이버부터 재설치할 필요는 없습니다.

4. 야간 모드 버튼이 회색으로 비활성화될 때

Microsoft의 공식 문서는 야간 모드 스위치가 회색일 때 디스플레이 드라이버 업데이트가 필요할 수 있다고 설명합니다. 또한 DisplayLink나 기본 디스플레이 드라이버(Basic Display) 같은 특정 드라이버를 사용하는 환경에서는 야간 모드 기능을 사용할 수 없다고 안내합니다.

따라서 다음과 같이 확인하세요.

  1. 먼저 Windows Update에서 적용 가능한 Windows·드라이버 업데이트가 있는지 확인합니다.
  2. 시작 메뉴에서 장치 관리자를 검색해 엽니다.
  3. 디스플레이 어댑터를 펼칩니다.
  4. 사용 중인 그래픽 어댑터 이름을 확인합니다.
  5. 해당 장치를 오른쪽 클릭하고 드라이버 업데이트를 선택합니다.
  6. 드라이버 자동 검색을 진행합니다.
  7. 새 드라이버를 적용했다면 안내에 따라 PC를 다시 시작합니다.

업데이트가 검색되지 않으면 PC 제조사 또는 그래픽 장치 제조사의 공식 사이트에서 해당 모델과 Windows 버전에 맞는 드라이버를 확인할 수 있습니다.

주의: Windows가 표시 기능을 정상적으로 제공하고 있는데도 무작정 그래픽 드라이버를 제거하거나 레지스트리를 수정하는 것은 권장하지 않습니다. 회사·학교 관리 PC라면 먼저 관리자에게 문의하세요.

공식 참고: Microsoft — 야간 모드 제한 조건, Microsoft — 장치 관리자로 드라이버 업데이트

5. 매일 밤 자동으로 켜지게 예약하는 방법

수동 켜기가 잘 된다면 예약 기능만 따로 시험할 수 있습니다.

  1. 설정 → 시스템 → 디스플레이 → 야간 모드로 이동합니다.
  2. 야간 모드 예약을 켭니다.
  3. 일몰부터 일출까지 또는 시간 설정 중 하나를 선택합니다.
  4. '시간 설정'을 이용한다면 시작·종료 시간을 직접 입력합니다.
  5. 현재 시각과 예약 시간이 일치하는지 확인합니다.

두 가지 예약 방식의 차이는 명확합니다.

  • 일몰부터 일출까지: 사용자의 위치에 따른 일몰·일출 시각에 맞추어 작동하도록 설계된 방식입니다.
  • 시간 설정: 사용자가 특정 시작·종료 시간을 직접 정하는 방식입니다.

늦은 저녁에 PC를 켜는데 야간 모드가 예상한 대로 작동하지 않으면, 먼저 짧은 시험용 고정 시간으로 설정해 예약 자체가 작동하는지 확인하세요. 수동 기능은 정상이고 고정 시간도 정상이라면 일몰·일출 관련 설정과 장치의 위치·시간 상태를 따로 살펴볼 수 있습니다.

Microsoft의 Windows 설정 백업 안내 역시 야간 모드의 예약 방식과 시작·종료 시각이 별도 설정 항목임을 보여줍니다.

공식 참고: Microsoft — 야간 모드 예약, Microsoft Learn — Windows 설정 백업의 야간 모드 항목

6. '일몰부터 일출까지'가 이상할 때 무엇을 확인해야 할까

일몰·일출 시간은 장소와 날짜에 따라 달라집니다. 따라서 저녁 7시에 반드시 켜져야 한다고 고정해서 생각하면 예상과 차이가 생길 수 있습니다.

점검할 항목은 다음과 같습니다.

  1. 현재 PC의 날짜와 시간, 표준 시간대가 맞는지 확인합니다.
  2. 야간 모드 예약이 일몰부터 일출까지로 설정되어 있는지 확인합니다.
  3. 위치 정보를 사용한 시간 계산이 필요한 환경인지 확인합니다.
  4. 위치 설정을 바꾸기 전 개인 정보 보호 및 회사의 보안 정책을 확인합니다.
  5. 정확한 원인 구분을 위해 잠시 시간 설정 방식으로 바꾸어 비교합니다.

이 단계는 문제의 가능성을 분리하기 위한 진단입니다. 날짜·시간·위치가 잘못 설정되었다고 단정하는 것은 아닙니다. Microsoft 공식 문서에는 일출·일몰에 따른 실제 예약 시각이 장소에 따라 달라진다고 설명돼 있습니다.

위치 서비스를 켜기 꺼려지거나 회사 정책상 사용할 수 없다면, 반드시 위치 추적 기능을 켜야 한다고 생각할 필요는 없습니다. 수동 시간 지정이 더 간단하고 예측 가능한 선택일 수 있습니다.

7. 야간 모드가 켜지자 화면이 지나치게 빨갛게 변한다면

화면이 따뜻해지는 것과 과도한 붉은 색조로 내용을 읽기 어려워지는 것은 다릅니다. 특히 HDR이 켜진 일부 기기에서는 이 문제가 두드러질 수 있습니다.

Microsoft는 HDR 지원 기기에서 야간 모드가 켜지면 색이 과포화되거나 붉은 기운이 생길 수 있다고 명시합니다. 이 경우 공식적으로 안내하는 해결책은 다음과 같습니다.

  1. 설정 → 시스템 → 디스플레이 → 야간 모드로 이동합니다.
  2. 강도 슬라이더를 왼쪽으로 이동합니다.
  3. 글자와 이미지의 색이 정상적으로 보이는지 비교합니다.
  4. 필요하면 야간 모드를 잠시 꺼서 전후 차이를 확인합니다.
  5. HDR을 지원하는 기기라면 디스플레이 → HDR에서 현재 HDR 설정을 확인합니다.

HDR은 야간 모드와 별개의 화면 기능입니다. 색상이 이상하다고 해서 HDR을 영구적으로 해제해야 하는 것은 아니며, HDR 콘텐츠를 보려는 목적과 야간 모드 사용 목적에 맞게 설정을 선택해야 합니다.

공식 참고: Microsoft — HDR 설정에서 야간 모드로 색이 과포화되는 경우

8. 화면 밝기가 저절로 변하는 것은 야간 모드 때문일까

야간 모드를 꺼도 화면 밝기가 콘텐츠에 따라 달라진다면 자동 밝기 조절을 따로 확인해 보세요.

Microsoft는 일부 Windows 11 노트북에서 화면의 내용에 맞춰 밝기와 대비를 자동 조절할 수 있다고 설명합니다. 예를 들어 어두운 영상에서 밝은 영상으로 바뀔 때 화면 밝기가 달라지는 것은 기기 설정상 정상 동작일 수 있습니다.

해당 기능이 지원된다면 다음처럼 확인합니다.

  1. 설정 → 시스템 → 디스플레이를 엽니다.
  2. **밝기(Brightness)**를 선택합니다.
  3. 조명 변화에 따른 자동 밝기 또는 콘텐츠에 따라 밝기 변경 설정이 있는지 확인합니다.
  4. 필요하면 한 가지 옵션만 변경하고 결과를 비교합니다.

모든 PC에 해당 옵션이 있는 것은 아닙니다. 외부 모니터만 사용하는 데스크톱에서는 Windows 밝기 슬라이더 자체가 나타나지 않을 수 있으며, 이때는 모니터의 물리 버튼이나 OSD 메뉴로 조절해야 할 수 있습니다.

색온도를 바꾸는 야간 모드와 화면 밝기 자동 변경을 한 번에 고치려 하지 말고 따로 시험하는 것이 효율적입니다.

공식 참고: Microsoft — 콘텐츠 자동 밝기 및 외부 모니터의 밝기 조절

9. 화면이 계속 노랗다면 다른 색 기능도 확인하세요

야간 모드를 껐는데도 화면이 노랗거나 특정 색으로 물들어 보인다면 다음 기능을 살펴볼 수 있습니다.

확인할 기능경로확인할 이유
색 필터설정 → 접근성 → 색 필터화면 전체 색상 팔레트를 바꿈
화면 색조설정 → 접근성 → 화면 색조별도의 화면 덧입힘 효과
HDR설정 → 시스템 → 디스플레이 → HDR일부 디스플레이의 색·밝기 재현이 달라질 수 있음
모니터 자체 색온도모니터 버튼 또는 OSD 메뉴제조사 화면 모드가 적용될 수 있음
다크 모드설정 → 개인 설정 → 색밝고 어두운 UI를 바꾸는 기능

Microsoft는 **화면 색조(Screen Tint)**와 **색 필터(Color filters)**가 서로 동시에 활성화될 수 없다고 안내합니다. 하나를 켜면 다른 기능이 꺼지는 방식입니다. 따라서 관련 설정을 무작정 모두 켜는 것보다 어떤 기능이 현재 색을 바꾸고 있는지 먼저 확인해야 합니다.

외부 모니터에서만 화면 색이 다르다면 Windows 설정뿐 아니라 모니터의 자체 색온도 또는 사전 설정된 영상 모드도 영향을 줄 수 있습니다.

공식 참고: Microsoft — Windows 색 필터, Microsoft — 화면 색조와 야간 모드 차이

10. 다크 모드와 야간 모드를 동시에 사용해도 되나요?

가능합니다. 두 기능은 서로 다른 역할을 합니다. 예를 들어 Windows UI는 다크 모드로 표시하고, 저녁 일정에만 야간 모드의 따뜻한 색을 적용할 수 있습니다.

다크 모드 설정 방법

  1. 설정 → 개인 설정 → 색으로 이동합니다.
  2. **모드 선택(Choose your mode)**에서 어둡게(Dark)를 선택합니다.
  3. Windows 시작 메뉴·작업 표시줄·지원 앱에 적용되는 변화를 확인합니다.

Microsoft는 일부 앱이 자체 라이트·다크 모드 설정을 따로 가지며, 모든 앱이 Windows 다크 모드를 지원하지는 않는다고 안내합니다.

따라서 '다크 모드를 켰는데 어떤 웹사이트는 여전히 흰 배경이에요'라는 문제를 야간 모드 오류라고 생각할 필요는 없습니다. 그 웹사이트나 앱이 다크 테마를 따로 지원하는지 확인해야 합니다.

공식 참고: Microsoft — Windows 개인 설정의 색 모드

12. 자주 묻는 질문

Q1. 야간 모드를 켰는데도 눈으로 보면 아무 변화가 없습니다.

먼저 강도 슬라이더를 움직여 화면 색이 변하는지 확인하세요. 강도가 낮아서 변화가 미미할 수 있습니다. 버튼 자체가 비활성화돼 있다면 디스플레이 드라이버 또는 연결 장치 제한도 점검해야 합니다.

Q2. 야간 모드 버튼이 회색이면 Windows가 고장 난 건가요?

그렇게 단정할 수 없습니다. Microsoft는 일부 디스플레이 드라이버 환경에서 야간 모드를 사용하지 못할 수 있다고 안내하며, 회색 토글에 대해 드라이버 업데이트를 먼저 확인하도록 합니다.

Q3. '일몰부터 일출까지'를 선택했는데 예상 시간에 안 켜져요.

예약이 실제로 켜져 있는지 확인하고, 시간 설정으로 짧은 시험 예약을 해 보세요. 장치의 날짜·시간과 위치 관련 상태를 확인할 수 있지만, 모든 문제를 위치 서비스 오류로 단정할 수는 없습니다.

Q4. 야간 모드가 아니라 다크 모드를 켜면 청색광이 줄어드나요?

두 기능은 같지 않습니다. 다크 모드는 주로 Windows UI의 배경과 색 모드를 바꾸고, 야간 모드는 화면 색온도를 따뜻하게 조정합니다. 둘을 함께 사용할 수도 있습니다.

Q5. HDR 모니터에서 화면이 너무 빨갛게 변합니다.

Microsoft는 HDR 기기에서 야간 모드의 색 과포화 문제가 발생할 수 있다고 설명합니다. 먼저 야간 모드 강도를 낮추고 변화가 있는지 확인하세요. 필요하면 야간 모드를 꺼서 비교합니다.

Q6. 외부 모니터에서는 밝기 슬라이더가 안 보여요.

Microsoft는 외부 모니터를 사용하는 PC에서 Windows 밝기 슬라이더가 나타나지 않을 수 있다고 설명합니다. 이 경우 모니터의 물리 버튼으로 밝기를 조절하세요. 밝기 슬라이더가 없는 현상과 야간 모드 자체가 작동하지 않는 문제는 다릅니다.

Q7. 화면이 노랗게 보이는 것을 원래대로 되돌리려면?

야간 모드를 꺼 본 뒤 색이 돌아오는지 확인하세요. 그대로라면 색 필터·화면 색조·HDR·모니터 자체 색온도를 하나씩 확인하는 것이 좋습니다. 변경 전 값을 기록해 두면 되돌리기 쉽습니다.

결론: 먼저 '기능 불능·예약 문제·색상 문제'를 구분하세요

Windows 11의 야간 모드가 제대로 작동하지 않을 때는 모든 설정을 재설정하는 것보다 버튼이 켜지는지, 시간에 맞춰 켜지는지, 켜졌을 때 색이 정상인지를 나누어 보면 문제를 좁힐 수 있습니다.

버튼이 회색이면 그래픽 드라이버와 DisplayLink 같은 연결 환경을 확인하고, 수동 켜기가 되는데 예약만 실패하면 고정 시간 예약을 시험하세요. HDR 화면이 너무 붉다면 야간 모드 강도를 낮춰 비교하고, 단순히 밝기가 바뀌는 문제는 자동 밝기 설정을 별도로 확인하세요.

야간 모드·다크 모드·색 필터는 서로 대체하는 같은 기능이 아닙니다. 목적에 맞게 한 가지씩 조정하면 불필요한 드라이버 재설치와 설정 변경을 줄일 수 있습니다.
