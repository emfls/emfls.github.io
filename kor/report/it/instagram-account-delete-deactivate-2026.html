인스타그램을 그만두려고 할 때 앱을 삭제하는 것과 계정을 삭제하는 것은 전혀 다릅니다. 휴대전화에서 앱만 지우면 계정은 그대로 남습니다. 잠시 쉬려면 일시 비활성화, 프로필과 게시물을 없애려면 영구 삭제를 선택해야 합니다.

2026년 11월 기준 인스타그램 계정 삭제와 비활성화는 주로 **계정 센터(Accounts Center)**에서 진행합니다. 다만 Meta가 화면을 순차적으로 변경하고 있어 일부 사용자는 ‘Meta 계정’ 또는 ‘계정 관리’ 메뉴가 보일 수 있습니다. 아래에서 두 화면 경로를 모두 설명합니다.

1. 삭제와 비활성화, 무엇이 다를까?

구분일시 비활성화영구 삭제
목적잠시 쉬었다가 다시 사용계정을 완전히 정리
프로필·게시물다른 사용자에게 숨김삭제 절차 시작 후 접근 불가, 이후 제거
팔로워·좋아요계정 재활성화 시 유지최종 삭제 후 복구 불가
다시 사용로그인해 재활성화삭제 취소 기한 안에서만 가능
제한·주의보통 7일에 한 번만 비활성화 가능완료 후 사진·메시지 등 데이터 되돌리기 불가

판단 기준: 나중에 같은 계정을 다시 사용할 여지가 조금이라도 있다면 비활성화가 안전합니다. 온라인 활동을 끝낼 생각이라면 필요한 데이터를 내보낸 뒤 삭제하세요.

2. 인스타그램 계정 삭제 방법: 갤럭시·아이폰 공통

  1. 삭제하려는 인스타그램 계정으로 로그인합니다.
  2. 오른쪽 아래 프로필 사진을 누릅니다.
  3. 오른쪽 위 ☰ 메뉴를 연 뒤 계정 센터로 들어갑니다.
  4. 개인정보(Personal details) → 계정 소유권 및 관리(Account ownership and control) → 비활성화 또는 삭제(Deactivation or deletion) 순으로 이동합니다.
  5. 삭제할 인스타그램 프로필을 정확히 선택합니다. 여러 계정이 보이면 계정 이름을 한 번 더 확인하세요.
  6. 계정 삭제(Delete account) → **계속(Continue)**을 선택합니다.
  7. 화면의 안내에 따라 사유 선택·비밀번호 확인 등을 마치면 삭제 요청이 접수됩니다.

메뉴 이름은 앱 버전과 표시 언어에 따라 조금 다릅니다. 중요한 것은 계정센터에서 삭제할 계정을 고르고, 최종 선택지가 ‘비활성화’가 아닌 ‘삭제’인지 확인하는 것입니다.

계정센터 메뉴가 다르게 보일 때

일부 계정은 ‘개인정보 → 계정 소유권 및 관리’ 대신 아래 경로로 표시됩니다.

프로필 → ☰ → 계정 센터 → 프로필 및 개인정보(Profiles and personal details) → 계정 옆 관리(Manage) → 비활성화 또는 삭제 → 계정 선택

두 경로 모두 같은 기능으로 이어집니다. ‘계정 센터’ 대신 **‘Meta 계정’**으로 표시되는 경우에도 계정 설정에서 비활성화 또는 삭제 항목을 찾으세요.

PC에서 삭제하는 방법

PC에서는 인스타그램 웹사이트에 로그인한 뒤 더 보기(More) → 설정(Settings) → 계정 센터 → 개인정보 → 계정 소유권 및 관리 → 비활성화 또는 삭제로 이동할 수 있습니다. 모바일 화면에서 메뉴가 보이지 않을 때 다른 방법으로 시도하기 좋습니다.

3. 사진·릴스·내 정보 백업부터 하는 법

삭제 전에 가장 먼저 할 일은 사진·동영상·게시물 등 데이터를 내보내는 것입니다. 삭제 요청 후에는 해당 계정이 정보 내보내기 대상에서 제외될 수 있으므로, 압축파일을 실제로 다운로드해 열어 본 다음 삭제를 진행하세요.

  1. 계정 센터에서 **내 정보 및 권한(Your information and permissions)**으로 들어갑니다.
  2. **내 정보 내보내기(Export your information)**를 선택합니다.
  3. **내보내기 만들기(Create export)**에서 인스타그램 계정을 지정합니다.
  4. 기기로 내보내기를 선택한 뒤 기간·포함할 정보·미디어 품질·파일 형식을 설정합니다.
  5. 요청을 제출하고 준비 완료 안내를 받으면 파일을 다운로드합니다.
  6. ZIP 압축을 풀어 사진·동영상과 기록이 정상적으로 포함됐는지 확인합니다.

인스타그램 공식 도움말은 정보 내보내기 준비에 시간이 걸릴 수 있으며 준비된 다운로드 링크의 이용 기한도 제한된다고 안내합니다. 이메일이 바로 오지 않는다고 계정을 먼저 삭제하지 마세요.

추가 확인: 다른 서비스에서 인스타그램 로그인을 사용한다면 로그인 대체 수단을 확보하고, 유료 구독·광고·상점 연동 등은 별도로 종료 여부를 확인하세요.

4. 잠시 쉬고 싶다면: 인스타그램 일시 비활성화

  1. 인스타그램 프로필 → ☰ → 계정 센터로 이동합니다.
  2. 개인정보 → 계정 소유권 및 관리 → 비활성화 또는 삭제를 엽니다. 다른 화면에서는 ‘프로필 및 개인정보 → 관리’를 거칩니다.
  3. 계정을 선택한 뒤 **계정 비활성화(Deactivate account)**를 누릅니다.
  4. 안내에 따라 비밀번호 등을 확인합니다.

비활성화하면 프로필·사진·댓글·좋아요가 다른 사람에게 숨겨지고, 다시 로그인하면 재활성화됩니다. 단, 인스타그램은 비활성화를 일주일에 한 번만 허용한다고 안내합니다. 잠시 비활성화했다가 바로 해제한 경우 다시 비활성화할 때 제한이 생길 수 있습니다.

5. 삭제 요청 뒤 30일·90일은 무슨 뜻일까?

영구 삭제 버튼을 눌렀다고 모든 데이터가 그 즉시 삭제되는 것은 아닙니다.

  • 삭제 요청 직후: 일반 사용자는 프로필·게시물에 접근하기 어려워집니다.
  • 일반적으로 요청 후 30일: 인스타그램은 프로필과 정보가 영구 삭제된다고 설명합니다. 다만 삭제 취소 가능 기간은 지역에 따라 다를 수 있으므로, 신청 화면에 표시되는 최종 날짜를 우선 확인해야 합니다.
  • 최대 90일: 전체 삭제 처리가 끝나는 데 그만큼 걸릴 수 있습니다. 보안·백업·법적 의무 때문에 일부 사본이 그 이후에도 보존될 수 있습니다.

삭제 요청을 취소하고 싶다면 표시된 취소 가능 기한 전에 해당 계정으로 로그인해 안내를 확인하세요. 기한이 지난 뒤에는 동일한 계정을 복구할 수 있다고 기대해서는 안 됩니다.

또한 나중에 같은 사용자 이름을 다시 쓰는 것도 보장되지 않습니다. 다른 사람이 먼저 사용하면 다시 확보하지 못할 수 있습니다.

6. 계정 삭제 메뉴가 안 보이거나 실패한다면

증상먼저 확인할 것
‘비활성화 또는 삭제’가 없음‘계정 센터’와 ‘Meta 계정’, ‘개인정보’와 ‘프로필 및 개인정보’의 두 메뉴 경로 확인
삭제할 계정이 목록에 없음현재 로그인 계정과 계정 센터에 연결된 프로필 확인
비밀번호를 잊음공식 로그인 화면에서 비밀번호 재설정 후 다시 시도
앱에서 메뉴 오류앱 업데이트 후 재접속, PC 웹사이트에서 동일 경로 확인
해킹 때문에 로그인할 수 없음삭제를 무리하게 진행하지 말고 인스타그램 계정 복구 절차부터 시작
삭제 후 계정이 다시 보임삭제 취소 기간에 재로그인하며 취소됐는지, 선택한 프로필이 맞는지 확인

외부 ‘즉시 삭제 대행’이나 비밀번호·인증번호를 요구하는 사이트는 이용하지 마세요. 계정 보유자가 공식 절차로 진행해야 합니다.

7. 삭제 전 5분 체크리스트

  • ☐ 삭제하려는 계정의 사용자 이름을 확인했다.
  • ☐ 사진·릴스·기타 내 정보 내보내기를 완료하고 파일을 직접 확인했다.
  • ☐ 인스타그램 계정으로 로그인하던 앱이나 서비스의 대체 로그인 수단을 준비했다.
  • ☐ 광고 계정·비즈니스 페이지·Threads 등 연결된 서비스의 영향도 확인했다.
  • ☐ 삭제 취소 기한과 최종 확인 화면을 확인했다.

자주 묻는 질문

인스타그램 앱만 지우면 탈퇴되나요?

아닙니다. 앱 제거는 휴대전화에서 프로그램만 삭제하는 것입니다. 계정은 그대로 유지됩니다. 탈퇴하려면 반드시 계정 센터의 계정 삭제 절차를 진행해야 합니다.

계정을 비활성화하면 상대방이 내 게시물을 볼 수 있나요?

일반적으로 비활성화 기간에는 프로필·사진·댓글·좋아요가 숨겨집니다. 다시 로그인하면 재활성화됩니다. 다만 상대방이 예전에 저장한 스크린샷이나 외부 복사본까지 삭제되는 것은 아닙니다.

계정을 삭제하면 상대방에게 보낸 DM도 전부 지워지나요?

계정 삭제가 상대방의 받은편지함이나 이미 저장한 정보까지 즉시 제거한다는 보장은 없습니다. 다른 사람에게 전송한 자료의 완전한 삭제 수단으로 생각하지 않는 것이 안전합니다.

페이스북도 함께 삭제되나요?

계정센터에 연결되어 있더라도 삭제 과정에서 선택한 프로필이 대상입니다. 여러 프로필이 보이는 화면에서는 어떤 계정을 선택하는지 반드시 확인하세요.

삭제 후 같은 아이디로 재가입할 수 있나요?

사용자 이름이 다른 사람에게 선점되지 않았다면 가능할 수 있지만 보장되지는 않습니다. 계정의 팔로워·게시물 복원과는 별개입니다.

요약

**잠시 쉴 때는 ‘일시 비활성화’, 완전히 정리할 때는 ‘계정 삭제’**를 선택하세요. 무엇보다 데이터를 먼저 내보내고 파일을 확인한 뒤 삭제를 요청하는 순서가 중요합니다. 계정 센터의 메뉴가 예전 안내와 다르게 보인다면 ‘개인정보’와 ‘프로필 및 개인정보 → 관리’라는 두 경로를 차례로 확인하면 됩니다.
