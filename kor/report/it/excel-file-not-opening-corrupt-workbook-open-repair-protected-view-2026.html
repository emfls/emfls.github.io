엑셀 파일을 더블클릭했는데 아무 반응이 없거나 ‘파일이 손상되어 열 수 없습니다’, ‘파일 형식 또는 확장명이 올바르지 않습니다’, ‘제한된 보기’ 같은 메시지가 표시될 때는 원인에 따라 해결 방법이 달라집니다. 가장 중요한 것은 원본을 덮어쓰지 않고 복사본에서 복구 작업을 시작하는 것입니다.

이 글은 2026년 11월 기준 Microsoft의 공식 Excel·OneDrive 고객지원 자료를 토대로 Windows용 Excel과 웹용 Excel에서 발생하는 대표적인 열기 오류를 구분하고, 손상 파일의 데이터 복구, 저장하지 않은 통합 문서 찾기, 이전 버전 복원, 안전 모드 점검까지 정리했습니다. 실제 메뉴 이름은 Microsoft 365, Excel 2024, 2021 등 제품 버전에 따라 다를 수 있습니다.

파일에 고객 명단, 급여, 계약 금액 등 민감한 데이터가 있다면 무료 복구 사이트에 올리기 전에 해당 파일의 소유권과 서비스의 데이터 처리 방침을 확인하세요.

1. 먼저 증상에 따라 해결 경로부터 선택하세요

화면에 나타난 증상의심할 수 있는 원인우선 점검
특정 엑셀 파일만 안 열림파일 손상, 저장 실패, 접근 경로 오류복사본 생성 후 열기 및 복구
모든 엑셀 파일이 안 열림Excel 앱·추가 기능·설치 상태새 빈 통합 문서, 안전 모드
‘제한된 보기’로 열리고 수정이 안 됨인터넷이나 메일에서 내려받은 파일 보호발신자 확인, 보안 경고 읽기
웹용 Excel에서 확장명·손상 오류파일 내용과 형식 불일치 또는 파일 손상OneDrive 버전 기록
최근까지 열리던 파일이 갑자기 손상저장·동기화 충돌 또는 파일 변경이전 버전 복원
저장하지 않은 수정 내용이 사라짐Excel 종료·강제 종료·전원 문제자동 복구 및 저장되지 않은 통합 문서
Excel 실행 중 멈춤·응답 없음추가 기능, 시작 파일, 앱 문제excel /safe로 원인 분리
네트워크 폴더에서만 열기 실패파일 위치·접근 권한·연결 문제로컬 복사본으로 테스트

추천 순서: 원본 복사 → 파일 한 개 문제인지 앱 전체 문제인지 구분 → Excel의 공식 복구 기능 → 이전 버전/자동 복구 → 앱 안전 모드 및 업데이트 확인. 이 순서를 따르면 문제를 정확하게 좁히면서 데이터 손실 위험을 줄일 수 있습니다.

공식 자료: Microsoft 손상된 통합 문서 복구, Excel 응답 없음 해결

2. 시작하기 전에 반드시 원본부터 보호하세요

원본 파일을 다른 이름으로 복사

파일 탐색기에서 문제가 발생한 Excel 파일을 찾고 복사본을 만듭니다. 원본 이름이 ‘매출정리.xlsx’라면 ‘매출정리_복구시도.xlsx’처럼 구분되는 이름으로 저장하세요. 복구 도중 내용이 달라지거나 일부 요소가 제거되더라도 원본을 보존할 수 있습니다.

USB·공유 폴더라면 로컬로 복사

Microsoft는 디스크 또는 네트워크 오류로 파일을 열 수 없는 경우 다른 드라이브나 로컬 디스크로 옮겨 시도하는 방법을 안내합니다. 외장하드나 NAS, 사내 공유 폴더에 있는 원본을 바로 편집하지 말고 안전한 로컬 작업 폴더에 복사한 뒤 테스트하세요.

중요한 파일이면 복구 결과를 분리 저장

복구에 성공한 것처럼 보이더라도 표, 계산식, 차트, 매크로, 이름 정의가 모두 정상인지 확인하기 전에는 원본을 삭제하거나 덮어쓰지 않습니다. 암호로 보호된 파일은 암호가 필요할 수 있으며, 암호를 모르는 경우 비공식 복호화 도구에 업로드하지 마세요.

파일 이름만 바꾸는 것은 복구가 아닙니다

확장자 ‘.xls’를 ‘.xlsx’로, 또는 반대로 이름만 바꾼다고 파일 내부 형식이 변환되는 것은 아닙니다. 원래 파일 형식을 모르는 경우 발신자에게 다시 내보내거나 재전송해 달라고 요청하는 것이 안전합니다.

3. 엑셀 파일 손상 시 ‘열기 및 복구’ 사용하는 법

Microsoft Excel 데스크톱 앱은 손상된 통합 문서를 인식하면 자동으로 복구를 시도할 수 있습니다. 자동 복구 화면이 나오지 않는 경우에도 열기 및 복구(Open and Repair) 메뉴를 수동 실행할 수 있습니다.

  1. Excel을 먼저 실행하고 빈 통합 문서를 엽니다.
  2. 왼쪽 상단 파일 → 열기 → 찾아보기로 이동합니다.
  3. 문제가 있는 파일의 복사본을 선택하되 바로 더블클릭하지 않습니다.
  4. 열기 대화상자에서 열기 버튼 오른쪽의 작은 화살표를 선택합니다.
  5. 열기 및 복구를 클릭합니다.
  6. 처음에는 **복구(Repair)**를 선택해 통합 문서 복원을 시도합니다.
  7. 복구가 실패할 경우 같은 메뉴에서 **데이터 추출(Extract Data)**을 선택해 값과 수식 회수를 시도합니다.
  8. 복구된 파일을 별도의 이름으로 저장하고 각 시트의 데이터를 확인합니다.

데이터 추출과 원상복구는 다릅니다. 값이나 수식 일부를 추출했다고 모든 차트, 표 서식, 외부 연결, 매크로가 완벽하게 복원된 것은 아닐 수 있습니다. 중요한 통합 문서라면 원래 기대되는 시트 수, 수식 결과, 주요 합계와 재무 숫자를 대조하세요.

공식 출처: Microsoft — 손상된 통합 문서 복구

4. ‘복구’ 버튼도 실패했다면 다른 방법을 시도하세요

자동 계산을 수동 계산으로 바꿔 열기

Microsoft는 특정 손상 통합 문서를 열지 못할 때 Excel의 계산 설정을 수동으로 변경한 뒤 열기를 시도할 수 있다고 안내합니다. 새 통합 문서에서 파일 → 옵션 → 수식 → 통합 문서 계산 → 수동을 선택하고 문제가 있는 복사본을 열어보세요. 버전에 따라 표기가 다를 수 있습니다.

이 방법은 Excel이 열 때 통합 문서 전체를 재계산하지 않도록 해 문제를 우회하는 방식이며 성공을 보장하지 않습니다. 파일을 연 후 다른 이름으로 보존하고 결과를 점검하세요. 테스트가 끝나면 다른 통합 문서의 계산 결과에 영향을 주지 않도록 계산 방식을 원래 설정으로 되돌립니다.

이전에 정상적으로 저장했던 파일 활용

파일이 편집 중 갑자기 손상됐다면 마지막으로 정상 저장된 버전이 더 안전할 수 있습니다. 해당 버전을 별도 파일로 확보한 뒤 새로 추가된 내용만 가능한 범위에서 복구하는 방법을 검토하세요. 복원 과정에서 마지막 저장 이후의 수정 내용은 잃을 수 있습니다.

데이터만 추출한 뒤 새 파일로 재구성

숫자와 문자 데이터가 가장 중요한 경우 전체 서식이나 차트 복구보다 값과 수식 회수가 우선일 수 있습니다. 하지만 회수된 수식의 참조 범위와 계산 결과를 반드시 검증해야 합니다. 특히 외부 통합 문서를 참조하는 수식은 연결 대상을 확인하지 않은 채 업무에 사용하지 마세요.

5. ‘파일 형식 또는 확장명이 올바르지 않습니다’ 오류

이 메시지에는 여러 원인이 있을 수 있습니다. 단순히 확장자가 잘못됐을 수도 있지만 파일 저장 도중 중단되거나 손상돼 내용 구조가 바뀌었을 가능성도 있습니다.

확인할 사항은 다음과 같습니다.

  1. 파일을 내려받은 이메일·메신저·클라우드에서 원본을 다시 다운로드할 수 있는지 확인합니다.
  2. 파일 확장자가 실제로 .xlsx, .xls, .xlsm, .csv 등 무엇인지 확인합니다.
  3. 파일을 만든 프로그램과 내보내기 옵션을 알 수 있는지 발신자에게 문의합니다.
  4. 파일 용량이 비정상적으로 작거나 다운로드가 중단된 흔적은 없는지 확인합니다.
  5. OneDrive에 저장된 문서라면 버전 기록에서 이전 정상 버전을 열어봅니다.

Excel 통합 문서와 CSV는 서로 다른 파일 형식입니다. CSV 파일을 다른 형식으로 단순히 이름만 바꾸면 수식, 여러 시트, 서식이 복원되지 않습니다. 또한 웹용 Excel에서 파일 형식이나 확장명 관련 오류가 표시될 때 Microsoft는 이전 버전 복원을 공식 해결책 중 하나로 안내합니다.

6. 제한된 보기로 열릴 때는 손상과 구분하세요

‘제한된 보기(Protected View)’는 반드시 파일이 손상됐다는 뜻이 아닙니다. Microsoft는 인터넷, 이메일 첨부파일, 신뢰할 수 없는 위치에서 가져온 파일을 안전하게 열기 위해 읽기 전용 모드로 표시할 수 있다고 설명합니다.

출처를 신뢰할 수 있는 파일이라면

발신자와 문서의 출처를 직접 확인하고, 업무상 반드시 수정해야 하는 경우에만 Excel 창의 편집 사용 또는 관련 안내를 검토하세요. 파일 내용을 보기만 하면 되는 경우에는 제한된 보기 상태를 유지해도 됩니다.

보안 경고가 의심스럽다면

모르는 사람이 보낸 Excel 첨부파일, 예상하지 못한 송장, 매크로 실행을 요구하는 문서는 함부로 편집 사용이나 콘텐츠 사용을 누르지 마세요. 제한된 보기는 보호 기능이므로 오류 해결을 이유로 보안 센터 설정 전체를 해제하는 방법은 권장하지 않습니다.

회사 PC에서 제한이 유지된다면

조직에서 정책으로 관리하는 경우가 있습니다. 이때는 관리자 확인 없이 그룹 정책이나 레지스트리, 신뢰할 수 있는 위치를 임의 변경하지 않아야 합니다. 신뢰할 수 없는 파일의 차단을 풀었다가 악성 콘텐츠에 노출될 수 있습니다.

공식 출처: Microsoft — 제한된 보기의 정의

7. OneDrive 파일이라면 버전 기록으로 되돌리는 법

OneDrive 또는 SharePoint에 저장된 파일은 이전 버전이 남아 있을 수 있습니다. Microsoft는 웹용 Excel에서 파일 손상이나 확장명 오류를 만난 경우 **버전 기록(Version History)**으로 복원하는 절차를 안내합니다.

  1. OneDrive 웹사이트 또는 동기화 폴더에서 문제가 있는 파일을 찾습니다.
  2. 해당 파일을 마우스 오른쪽 버튼으로 클릭합니다.
  3. 버전 기록을 선택합니다.
  4. 저장 시각과 변경 내역을 보면서 정상적으로 열리던 버전을 찾습니다.
  5. 가능하다면 해당 버전을 먼저 확인하거나 복사본으로 보관합니다.
  6. 복원을 선택하면 이전 버전이 현재 버전으로 바뀔 수 있음을 확인합니다.
  7. 복원 후 Excel에서 열리는지, 시트와 숫자 등이 정상인지 확인합니다.

중요: 이전 버전으로 복원하면 그 버전 이후의 수정 내용이 없어질 수 있습니다. 따라서 현재 파일을 먼저 별도로 저장해 두는 것이 안전합니다. 버전 보관 기간과 사용 가능한 이전 버전 수는 계정 및 조직 정책에 따라 달라질 수 있습니다. 버전 기록이 보이지 않으면 현재 파일이 OneDrive에 있는지와 계정 권한을 확인하세요.

공식 출처: Microsoft — OneDrive 이전 버전 복원, Microsoft — Office 파일 버전 복원

8. 저장하지 않은 엑셀 파일은 어디서 복구하나요?

파일을 저장하지 않고 닫았거나 Excel이 강제 종료된 경우에는 파일 자체의 손상이 아닌 저장되지 않은 변경 내용 문제일 수 있습니다.

자동 복구 정보 확인

Excel에서 파일 → 정보로 이동해 통합 문서 관리 관련 항목을 확인합니다. 자동 복구가 설정돼 있고 복구 데이터가 남아 있다면 복구 가능한 버전이 표시될 수 있습니다.

저장되지 않은 통합 문서 복구

Excel에서 파일 → 정보 → 통합 문서 관리 → 저장되지 않은 통합 문서 복구와 같은 메뉴를 찾아봅니다. 버전에 따라 메뉴 경로는 다를 수 있습니다. 복구 목록에 파일이 표시된다면 열고 즉시 다른 이름으로 저장을 선택합니다.

자동 복구와 자동 저장은 어떻게 다른가요?

자동 복구(AutoRecover)는 Excel이 예기치 않게 종료됐을 때를 대비해 복구 정보를 남기는 기능입니다. Microsoft는 일반적인 저장과 동일하지 않다고 강조합니다. 자동 저장(AutoSave)은 지원되는 Microsoft 365 클라우드 문서에서 변경 내용을 자동으로 저장하는 방식이며, 사용 위치와 계정 조건에 따라 동작이 달라집니다.

자동 복구 파일이 반드시 존재하는 것은 아닙니다. 파일을 정상 종료했고 자동 복구 보관 조건에 해당하지 않는다면 원하는 변경 내용을 복구하지 못할 수도 있습니다.

공식 출처: Microsoft — 이전 버전의 Office 파일 복구, Microsoft — 통합 문서 저장·자동 복구

9. 파일 하나가 아니라 Excel 전체가 안 열리는 경우

다른 통합 문서를 새로 만들어도 Excel이 멈추거나 시작되지 않는다면 특정 문서 손상만 의심할 상황은 아닙니다.

새 빈 통합 문서가 열리는지 테스트

시작 메뉴에서 Excel을 직접 실행하고 새 빈 통합 문서를 만들어 보세요. 새 파일은 정상이고 특정 파일만 실패한다면 원본 데이터·파일 경로 문제를 우선 확인합니다.

Windows에서 Excel 안전 모드 실행

  1. Windows에서 Windows 키 + R을 눌러 실행 창을 엽니다.
  2. excel /safe를 입력합니다. excel 다음에 공백이 필요합니다.
  3. 안전 모드에서 Excel이 정상적으로 실행되는지 확인합니다.
  4. 정상 실행된다면 추가 기능이나 시작 파일·설정이 원인인지 단계적으로 확인합니다.

안전 모드는 엑셀의 일부 시작 설정과 추가 기능을 사용하지 않는 상태로 실행합니다. 파일의 보안 기능을 우회하거나 손상된 데이터를 자동 복구하는 기능과는 다릅니다.

공식 출처: Microsoft — Windows에서 Office 안전 모드 실행, Microsoft — Excel 응답 없음 해결

10. 추가 기능 때문에 멈추는지 확인하기

Excel이 안전 모드에서는 잘 실행되지만 일반 실행 시 멈춘다면 추가 기능을 점검할 필요가 있습니다.

  1. 안전 모드에서 Excel을 실행합니다.
  2. 파일 → 옵션 → 추가 기능을 엽니다.
  3. 하단 관리 목록에서 COM 추가 기능을 선택하고 이동을 누릅니다.
  4. 테스트 목적으로 추가 기능을 잠시 비활성화합니다.
  5. Excel을 종료하고 일반 모드로 다시 실행합니다.
  6. 문제가 사라졌다면 추가 기능을 한 번에 하나씩 다시 활성화하며 원인을 확인합니다.

회사에서 지정한 필수 추가 기능이 있을 수 있습니다. 업무용 기기라면 관리자에게 변경 가능 여부를 확인하세요. 추가 기능 목록을 스크린샷이나 메모로 남겨 복구할 수 있도록 합니다.

Microsoft는 일부 자동 문제 해결 도구가 추가 기능이나 시작 폴더, 레지스트리 설정을 변경할 수 있다고 안내합니다. 이런 도구를 사용하기 전에는 중요한 설정과 파일의 백업을 확보하는 것이 좋습니다.

공식 출처: Microsoft — Excel 중단·멈춤 문제 해결

11. Excel 프로그램 업데이트와 복구는 언제 하나요?

모든 파일에서 동일한 문제가 발생하거나 안전 모드도 실행되지 않는다면 Microsoft 365 또는 Office 프로그램 자체의 문제일 수 있습니다.

먼저 사용 중인 Excel의 업데이트 상태와 Windows 업데이트를 확인하고, 컴퓨터를 재시작한 뒤 다시 테스트하세요. 그래도 계속 실패한다면 Windows에 설치된 Office 앱의 수정·복구 기능을 검토할 수 있습니다.

단, 프로그램 복구와 손상된 데이터 파일 복구는 다른 작업입니다. Office 앱을 다시 설치했다고 해당 파일 내용이 원래대로 복원되는 것은 아닙니다. 중요한 통합 문서 파일은 앱 복구 이전에 별도로 보존하세요.

회사 관리용 Microsoft 365 설치라면 조직의 소프트웨어 배포 정책을 따라야 할 수 있으므로 IT 관리자에게 문의하는 것이 적절합니다.

12. 복구 후 꼭 검증해야 하는 항목

‘파일이 열렸다’는 이유만으로 업무에 사용할 수 있다고 판단하면 위험합니다. 특히 열기 및 복구나 데이터 추출 과정에서는 전체 내용이 그대로 유지되지 않을 수 있습니다.

확인 대상실제 검증 방법
시트 개수와 이름원본 설명, 백업 파일과 비교
매출·급여·재고 등 핵심 합계담당자가 알고 있는 결과와 대조
수식오류 표시, 참조 범위, 계산 모드 확인
표·차트·피벗값, 데이터 원본, 새로 고침 동작 확인
매크로·외부 연결업무 정책 및 원본 구조 확인
날짜·숫자 표시지역·형식 변경으로 값이 왜곡되지 않았는지
공동 작업 내용다른 사용자의 수정 사항이 남아 있는지
저장 위치복구 사본과 원본 파일이 구분되는지

실무 팁: 손상 전에 정상 처리된 보고서, 이메일 첨부본, 동료가 보유한 사본 등 별도 기준 자료가 있다면 핵심 데이터를 비교하는 것이 좋습니다. 파일 복구 결과가 겉보기에는 정상이어도 중요한 계산이 누락됐을 수 있기 때문입니다.

13. 자주 묻는 질문

Q. ‘열기 및 복구’ 버튼이 보이지 않아요.

파일을 더블클릭하지 말고 Excel 안에서 파일 → 열기 → 찾아보기 대화상자를 열어 파일을 한 번 선택하세요. 그 후 열기 버튼 옆 화살표를 눌러야 메뉴를 찾을 수 있습니다. 웹용 Excel과 데스크톱 Excel의 메뉴는 다를 수 있습니다.

Q. 확장자를 xls에서 xlsx로 바꾸면 복구되나요?

단순히 파일 이름 뒤의 글자를 바꾸는 것으로 내부 파일 형식이 변하지는 않습니다. 해당 파일을 만든 프로그램에서 올바른 형식으로 다시 저장하거나, 손상된 파일이라면 Microsoft 복구 기능을 시도하세요.

Q. 보호된 보기가 뜨면 무조건 편집 사용을 눌러도 되나요?

아닙니다. 보호된 보기는 인터넷·메일 등 신뢰하기 어려운 위치에서 가져온 파일을 안전하게 열기 위한 기능입니다. 발신자와 내용을 검증하기 전에는 편집을 활성화하지 않는 편이 안전합니다.

Q. 저장하지 않은 엑셀 문서를 100% 복구할 수 있나요?

보장할 수 없습니다. 자동 복구 정보나 별도의 백업, OneDrive의 버전 기록 등이 남아 있어야 복구 가능성이 있습니다. 저장되지 않은 변경 내용이 존재하지 않는 경우에는 해당 작업을 복원할 수 없습니다.

Q. 무료 Excel 복구 사이트에 회사 문서를 올려도 되나요?

개인정보·영업비밀이 포함됐다면 외부 서버 업로드 자체가 문제가 될 수 있습니다. 회사 문서는 내부 보안 규정과 승인된 저장·복구 도구를 먼저 확인하세요. 어떤 서비스든 100% 복구를 보장한다는 문구를 무조건 믿지 마세요.

Q. OneDrive 버전 기록이 없으면 이전 내용을 찾을 수 없나요?

OneDrive 버전 기록이 존재하지 않거나 보이지 않을 수 있습니다. 파일이 정말 OneDrive·SharePoint에 저장돼 있었는지, 올바른 계정인지, 조직의 버전 관리 정책이 무엇인지 확인해야 합니다. 로컬 백업이나 자동 복구 정보가 있다면 별도로 확인하세요.

Q. Windows의 안전 모드로 열면 손상 파일도 자동으로 고쳐지나요?

아닙니다. excel /safe는 추가 기능 등 실행 환경을 분리해 점검하는 기능입니다. 손상 통합 문서 복구는 열기 및 복구를 별도로 사용해야 합니다.

Q. 복구 후 계산 결과가 어제와 다른데 그냥 사용해도 되나요?

권장하지 않습니다. 계산이 수동으로 설정돼 있거나 수식·외부 연결이 누락됐을 수 있습니다. 복구 사본에서 계산 설정, 주요 수식, 참조 데이터와 과거 보고서를 대조한 후 사용하세요.

14. 재발을 막는 저장·백업 습관

  • 중요한 문서는 원본을 한 곳에만 두지 않고 별도의 백업을 보관합니다.
  • 긴 작업을 하면서 주기적으로 직접 저장하고, Excel의 자동 복구 정보 저장 설정도 확인합니다.
  • 공동 편집 문서는 OneDrive·SharePoint의 버전 기록 사용 가능 여부를 사전에 확인합니다.
  • 보고서 제출이나 정산 직전에는 날짜가 포함된 별도 사본을 만들어 이전 상태를 보존합니다.
  • USB·NAS에서 작업할 때 연결이 불안정하다면 로컬에서 작업하고 정상적으로 저장·동기화됐는지 확인합니다.
  • Excel의 추가 기능은 신뢰할 수 있는 공급자의 제품만 사용하고, 문제 발생 시 마지막으로 추가한 기능부터 점검합니다.
  • 문서에 개인정보나 계약 정보가 있다면 공식 프로그램과 사내 승인된 복구 경로를 우선합니다.

핵심 정리: 특정 파일만 열리지 않으면 복사본으로 열기 및 복구, OneDrive 문서라면 버전 기록, 저장되지 않은 변경 내용은 자동 복구, Excel 프로그램 전체가 멈춘다면 excel /safe와 추가 기능 순서로 점검하세요. 어떤 복구 방법이든 결과 파일의 수식과 핵심 숫자를 검증하기 전에는 정상 복원됐다고 판단하지 않아야 합니다.
