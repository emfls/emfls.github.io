윈도우11을 사용하다가 모니터 화면이 주기적으로 깜빡이거나, 바탕화면이 검게 변했다가 돌아오거나, 창을 움직일 때 화면이 번쩍이면 원인을 구분해야 합니다. 단순히 모니터 고장이라고 판단하기 쉽지만 그래픽 드라이버 충돌, 호환되지 않는 프로그램, 외부 모니터의 케이블·입력 연결, 주사율·HDR 설정이 영향을 줄 수 있습니다.

Microsoft 공식 문서에서 가장 먼저 권장하는 진단은 작업 관리자 창도 화면과 함께 깜빡이는지 확인하는 것입니다. 작업 관리자까지 깜빡이면 디스플레이 드라이버 문제가, 다른 화면만 깜빡이고 작업 관리자는 안정적이면 호환되지 않는 앱이 원인일 가능성이 높습니다. 이는 수리를 확정하는 검사가 아니라 문제 해결의 방향을 정하는 테스트입니다.

이 글은 2026년 11월 기준 Microsoft 공식 지원 문서를 바탕으로 윈도우11 화면 깜빡임·검은 화면·게임 중 모니터 신호 끊김·노트북 화면 깜박임·듀얼 모니터 한쪽 문제를 데이터 손실 위험이 적은 순서로 점검합니다. Windows 11을 기준으로 작성했으며 실제 메뉴는 PC 제조사와 Windows 버전에 따라 다를 수 있습니다.

2. 작업 관리자도 깜빡이나요? 가장 중요한 원인 분리 테스트

Microsoft는 Windows 11에서 화면이 깜빡일 때 작업 관리자(Task Manager)가 함께 깜빡이는지 확인하라고 안내합니다.

테스트 방법

  1. 화면이 깜빡이는 상태에서 Ctrl + Shift + Esc를 누릅니다.
  2. 작업 관리자 창을 화면 중앙에 배치합니다.
  3. 바탕화면과 작업 관리자 창을 동시에 바라봅니다.
  4. 작업 관리자 창까지 같이 깜빡이는지 확인합니다.
  5. 작업 관리자를 열 수 없다면 Ctrl + Alt + Delete를 누르고 작업 관리자를 선택해 봅니다.

결과 해석

A. 작업 관리자도 함께 깜빡임

Microsoft는 디스플레이 드라이버가 원인일 가능성이 높다고 설명합니다. 이 경우 그래픽 드라이버 재설정, 업데이트, 롤백을 우선 검토합니다.

B. 다른 화면은 깜빡이지만 작업 관리자는 안정적

Microsoft는 호환되지 않는 프로그램이 원인일 가능성이 높다고 설명합니다. 최근 설치·업데이트한 앱을 확인하고 공식 업데이트 또는 제거를 검토합니다.

C. 너무 심하게 깜빡여 작업 관리자를 볼 수 없음

PC 화면이 제대로 표시되지 않는 상황이라면 Microsoft의 안전 모드 또는 빈 화면 해결 절차가 필요할 수 있습니다.

중요: 이 테스트로 드라이버나 앱을 100% 확정하는 것은 아닙니다. 외부 모니터 케이블·패널·도크 등 물리적 문제도 있을 수 있으므로 다른 점검 결과와 함께 판단하세요.

공식 참고: Microsoft — 작업 관리자를 이용한 화면 깜빡임 진단

3. Win + Ctrl + Shift + B: 그래픽 드라이버 재설정 단축키

Microsoft는 일부 화면 깜빡임 문제에서 그래픽 드라이버를 다시 설정하는 단축키를 안내합니다.

사용 방법

  1. 작업 중인 파일을 가능하면 저장합니다.
  2. 키보드에서 Windows 로고 키 + Ctrl + Shift + B를 동시에 누릅니다.
  3. 화면이 잠깐 깜빡이거나 소리가 날 수 있습니다.
  4. 화면이 정상으로 돌아오는지 확인합니다.
  5. 변화가 없다면 Windows를 정상적으로 재시작합니다.

이 단축키는 화면 출력 경로에 문제가 있을 때 그래픽 드라이버를 다시 설정하는 기능입니다.

이것과 다른 작업

  • PC 전체의 공장 초기화가 아닙니다.
  • 드라이버를 삭제·재설치하는 명령이 아닙니다.
  • BIOS·UEFI 업데이트를 수행하는 것이 아닙니다.
  • 실제로 케이블이 느슨하거나 모니터 패널이 손상됐다면 해결이 보장되지 않습니다.

실용적인 확인법: 단축키로 잠시 회복됐다가 같은 문제가 반복된다면 그래픽 드라이버 업데이트·최근 변경 내역·외부 모니터 연결 상태를 이어서 확인해야 합니다.

공식 참고: Microsoft — 그래픽 드라이버 다시 설정

4. 윈도우 업데이트 후 깜빡인다면: 그래픽 드라이버 롤백

화면 깜빡임이 Windows 업데이트 또는 그래픽 드라이버 설치 직후 시작됐다면 Microsoft는 이전 드라이버로 돌아가는 롤백을 검토하라고 안내합니다.

장치 관리자에서 롤백

  1. 시작 버튼을 마우스 오른쪽 버튼으로 누릅니다.
  2. 장치 관리자를 엽니다.
  3. 디스플레이 어댑터를 펼칩니다.
  4. 사용 중인 GPU를 선택하고 마우스 오른쪽 버튼으로 속성을 엽니다.
  5. 드라이버 탭에서 드라이버 롤백을 선택합니다.
  6. 안내에 따라 이전 버전으로 되돌린 뒤 재시작합니다.
  7. 화면 깜빡임이 개선됐는지 확인합니다.

'드라이버 롤백' 버튼이 회색인 경우

Microsoft는 Windows에 이전 드라이버가 저장돼 있지 않으면 롤백할 수 없다고 안내합니다. 롤백이 안 보인다고 무조건 컴퓨터가 고장난 것은 아닙니다.

주의: 롤백과 장치 제거에는 관리자 권한이 필요할 수 있습니다. 회사·학교가 관리하는 PC에서는 IT 담당자의 지침을 확인하세요.

중요: 롤백이 항상 정답은 아닙니다. 문제가 업데이트 전부터 있었다면 Microsoft가 권장하는 드라이버 업데이트 쪽을 먼저 검토해야 합니다.

공식 참고: Microsoft — 디스플레이 드라이버 롤백

5. 업데이트 전부터 깜빡인다면: 그래픽 드라이버 업데이트

최근 업데이트가 원인이 아니라면 디스플레이 드라이버의 최신 지원 버전을 확인할 수 있습니다.

기본 점검 순서

  1. 설정 → Windows 업데이트 → 업데이트 확인을 실행합니다.
  2. 제공되는 Windows 업데이트를 확인합니다.
  3. 장치 관리자 → 디스플레이 어댑터를 엽니다.
  4. 해당 GPU를 마우스 오른쪽 버튼으로 누르고 드라이버 업데이트를 선택합니다.
  5. 자동으로 드라이버를 찾을 수 있는지 확인합니다.
  6. Windows 업데이트에서 찾을 수 없다면 노트북·PC 제조사 또는 그래픽카드 제조사 공식 홈페이지를 확인합니다.
  7. 모델과 Windows 버전에 맞는 드라이버만 설치합니다.

설치 전에 기록할 정보

  • 노트북 또는 PC 모델명
  • 그래픽카드 제조사 및 모델
  • 현재 드라이버 버전과 날짜
  • 화면 깜빡임이 처음 시작된 시점
  • 최근 Windows 또는 앱 업데이트 여부

특히 노트북은 내장 GPU와 외장 GPU가 동시에 존재할 수 있습니다. Microsoft도 장치 관리자에 여러 디스플레이 어댑터가 나올 수 있다고 설명합니다.

보안 주의: 출처가 불명확한 '드라이버 자동 수리 프로그램'이나 무작위 다운로드 사이트를 이용할 필요는 없습니다. Windows 업데이트 또는 제조사 공식 사이트를 이용하세요.

공식 참고: Microsoft — 디스플레이 드라이버 업데이트, Microsoft — 기본 디스플레이 어댑터

6. Microsoft 기본 디스플레이 어댑터로 보이는 경우

장치 관리자의 디스플레이 어댑터 목록에 'Microsoft 기본 디스플레이 어댑터'가 표시될 수 있습니다.

이는 Windows에 기본으로 제공되는 일반 디스플레이 드라이버를 사용 중이라는 뜻입니다. Microsoft는 제조사 전용 드라이버가 제공된다면 이를 사용하는 것이 일반적으로 더 낫다고 설명합니다.

확인 방법

  1. 시작 버튼을 마우스 오른쪽 클릭합니다.
  2. 장치 관리자 → 디스플레이 어댑터를 엽니다.
  3. 해당 장치가 Microsoft 기본 디스플레이 어댑터인지 확인합니다.
  4. PC 제조사와 GPU 모델에 맞는 공식 드라이버가 제공되는지 살펴봅니다.
  5. 먼저 Windows 업데이트를 확인하고, 필요하면 제조사에서 드라이버를 설치합니다.

잘못 이해하기 쉬운 점: Microsoft 기본 디스플레이 어댑터가 표시됐다는 사실 하나만으로 그래픽카드 고장이라고 판단해서는 안 됩니다. 단순히 제조사 드라이버가 아직 설치되지 않았을 수도 있습니다.

공식 참고: Microsoft — Windows의 Microsoft 기본 디스플레이 어댑터

7. 작업 관리자는 안정적인데 화면만 깜빡이면 앱 충돌 점검

Microsoft는 작업 관리자가 깜빡이지 않는데 바탕화면·앱 창 등이 깜빡일 때 호환되지 않는 앱이 원인일 가능성이 높다고 안내합니다.

원인 분리 순서

  1. 최근 설치 또는 업데이트한 앱이 있는지 확인합니다.
  2. 해당 앱이 실행되는 동안만 화면이 깜빡이는지 비교합니다.
  3. Microsoft Store 앱이라면 Microsoft Store에서 업데이트를 확인합니다.
  4. 일반 프로그램이라면 제조사 공식 사이트의 업데이트를 확인합니다.
  5. 문제가 계속되면 설정 → 앱 → 설치된 앱에서 해당 프로그램 제거를 검토합니다.
  6. 앱을 한 개씩 조정한 뒤 재시작하고 결과를 비교합니다.

주의: 중요한 프로그램을 제거하기 전에는 로그인 정보·라이선스·프로젝트 파일·설정 백업 여부를 확인하세요. 그래픽카드 유틸리티나 업무용 프로그램을 무작정 대량 삭제해서는 안 됩니다.

특정 앱을 닫았더니 증상이 사라지더라도 원인을 확정하지 말고 같은 조건에서 다시 나타나는지 확인하는 편이 좋습니다.

공식 참고: Microsoft — 호환되지 않는 앱 업데이트 또는 제거

8. 외부 모니터만 깜빡일 때: HDMI·DisplayPort·USB-C 먼저 확인

노트북 내부 화면은 정상인데 외부 모니터만 주기적으로 꺼졌다 켜진다면, 먼저 연결 경로를 확인하는 것이 효율적입니다.

연결 점검

  1. 모니터 전원이 켜져 있는지 확인합니다.
  2. 사용 중인 HDMI·DisplayPort(DP)·USB-C 케이블이 양쪽 포트에 제대로 연결됐는지 확인합니다.
  3. 가능하면 전원을 끈 상태에서 케이블을 다시 단단하게 연결합니다.
  4. USB-C 허브·도킹스테이션을 사용 중이라면, 모니터를 PC에 직접 연결할 수 있는지 비교합니다.
  5. 정상 동작하는 다른 케이블이나 다른 포트로 테스트합니다.
  6. 가능하면 다른 모니터 또는 다른 PC와 연결해 증상이 어느 장치를 따라가는지 확인합니다.

Microsoft는 빈 화면·외부 디스플레이 문제에서 케이블 연결을 확인하고 다른 케이블이나 모니터로 비교하는 방법을 안내합니다.

결과 해석

비교 결과우선 점검할 범위
특정 HDMI 케이블에서만 발생케이블·단자·전송 규격
도크를 거칠 때만 발생도크·허브·펌웨어·전원
특정 모니터에서만 발생모니터 설정·입력 단자·패널
모든 모니터에서 동일하게 발생PC GPU·드라이버·출력 설정
노트북 내장 화면에서만 발생노트북 내부 패널·케이블·드라이버

이는 원인 분리를 위한 비교표이지 하드웨어 불량을 확정하는 기준은 아닙니다.

공식 참고: Microsoft — Windows에서 빈 화면 문제 해결

9. 144Hz·165Hz 모니터가 깜빡이면 주사율을 바꿔 비교

고주사율 모니터를 사용할 때 특정 주사율에서만 화면이 끊기거나 깜빡인다면 현재 설정과 모니터·케이블의 지원 범위를 확인할 필요가 있습니다.

Windows 11 주사율 확인

  1. 바탕화면 빈 곳을 마우스 오른쪽 버튼으로 누릅니다.
  2. 디스플레이 설정으로 이동합니다.
  3. 고급 디스플레이를 선택합니다.
  4. 다중 모니터 환경이라면 문제가 있는 모니터를 먼저 선택합니다.
  5. 새로 고침 빈도 선택에서 현재 Hz 값을 확인합니다.
  6. 모니터가 공식 지원하는 다른 주사율을 선택해 짧게 비교합니다.
  7. 변경 전 설정을 기록하고, 문제가 개선되지 않으면 원래 설정으로 되돌립니다.

예를 들어 144Hz에서 깜빡이지만 60Hz에서는 안정적이라면 주사율·케이블 대역폭·모니터 설정·GPU 출력 경로를 추가로 점검할 단서가 됩니다. 반대로 60Hz에서도 동일하게 깜빡이면 주사율만의 문제라고 단정하기 어렵습니다.

중요: 모든 모니터가 144Hz·165Hz·240Hz를 지원하지 않습니다. Windows에서 제공하는 값과 모니터 제조사의 공식 지원 사양을 기준으로 비교해야 하며, 지원하지 않는 모드를 강제로 적용하지 마세요.

공식 참고: Microsoft — Windows에서 모니터 새로 고침 빈도 변경

10. 동적 새로 고침 빈도·HDR 설정도 원인 분리에 활용

지원되는 노트북과 모니터에서는 동적 새로 고침 빈도(DRR) 또는 HDR 옵션을 사용할 수 있습니다.

동적 새로 고침 빈도 확인

  1. 설정 → 시스템 → 디스플레이 → 고급 디스플레이를 엽니다.
  2. 지원되는 경우 동적 새로 고침 빈도 설정을 확인합니다.
  3. 원인 분리 목적이라면 일시적으로 고정된 지원 주사율과 비교할 수 있습니다.
  4. 결과를 확인한 뒤 원하는 설정으로 되돌립니다.

Microsoft는 동적 새로 고침 빈도가 작업 상황에 따라 화면의 주사율을 조정해 배터리를 절약하는 기능이라고 설명합니다.

HDR 사용 시 확인

  1. 설정 → 시스템 → 디스플레이 → HDR을 엽니다.
  2. 해당 모니터가 HDR을 실제 지원하는지 확인합니다.
  3. HDR을 켤 때만 문제가 생긴다면 잠시 꺼서 비교합니다.
  4. HDR 관련 문제에서는 연결 케이블·지원 모드·주사율·그래픽 드라이버도 함께 점검합니다.

주의: HDR이나 DRR이 모든 화면 깜빡임의 원인은 아닙니다. 특히 일반적인 화면 깜빡임에 대해 Microsoft가 가장 먼저 제시하는 공식 판단 기준은 작업 관리자와 그래픽 드라이버·앱 진단입니다.

공식 참고: Microsoft — Windows의 HDR 설정, Microsoft — Windows 11 전원 설정과 동적 주사율

11. 듀얼 모니터에서 한쪽만 깜빡일 때

듀얼 모니터에서는 전체 PC 그래픽 문제와 한 모니터의 연결 문제를 구별해야 합니다.

  1. 설정 → 시스템 → 디스플레이에서 각 모니터가 정상 인식되는지 확인합니다.
  2. 문제가 발생하는 모니터를 선택합니다.
  3. 해당 모니터의 해상도·새로 고침 빈도를 확인합니다.
  4. Windows + P를 눌러 화면 복제·확장 등 출력 모드를 확인합니다.
  5. 두 모니터를 하나씩 연결해 어느 모니터에서 재현되는지 비교합니다.
  6. HDMI·DP 포트를 서로 바꿔 연결할 수 있다면 연결 경로를 비교합니다.
  7. 필요하다면 케이블·도크·그래픽 드라이버 점검으로 이어갑니다.

주의: 다중 모니터 환경에서는 화면마다 지원되는 주사율이 다를 수 있습니다. 144Hz 모니터와 60Hz 모니터를 함께 쓰는 경우, 각 화면의 설정을 별도로 확인해야 합니다.

Microsoft는 Windows 11의 여러 모니터 환경에서 개별 디스플레이 설정과 Windows + P 출력 모드를 지원합니다.

공식 참고: Microsoft — Windows에서 여러 모니터 사용

12. 게임할 때만 검은 화면이 되거나 화면이 깜빡이면

게임 실행·전체 화면 전환·해상도 변경 중에만 문제가 발생한다면, 해당 게임의 그래픽 설정과 GPU·모니터 출력 조건을 비교할 수 있습니다.

확인할 순서

  1. 게임을 종료하고 바탕화면에서도 같은 증상이 발생하는지 확인합니다.
  2. 게임이 실행되는 동안 작업 관리자 화면도 깜빡이는지 비교합니다.
  3. 게임과 그래픽 드라이버의 공식 업데이트 여부를 확인합니다.
  4. 게임 설정의 전체 화면 / 창 모드를 바꿔 증상이 달라지는지 확인합니다.
  5. 문제가 있는 모니터의 해상도·주사율이 지원 범위에 있는지 확인합니다.
  6. 외부 모니터라면 케이블·도크 연결을 점검합니다.

구별할 상황: 게임 창 자체가 깜빡이는 것과 모니터에 '신호 없음'이 나타나는 것은 원인 범위가 다를 수 있습니다. 후자는 연결 케이블·출력 모드·하드웨어도 확인해야 합니다.

게임 중 깜빡임이 있다는 이유만으로 GPU를 고장이라고 판정하거나, 검증되지 않은 오버클록·전압 설정을 권장하지 않습니다.

13. 드라이버 제거·재설치는 왜 마지막에 해야 하나요?

Microsoft 공식 화면 깜빡임 해결 문서는 문제가 지속될 경우 그래픽 드라이버 제거 후 재설치도 안내합니다. 다만 이 작업은 앞선 조치보다 영향이 크기 때문에 관리자 권한과 복구 수단을 준비한 뒤 진행해야 합니다.

진행 전 체크리스트

  • 현재 그래픽카드·노트북 모델을 확인했나요?
  • 해당 모델의 공식 드라이버 설치 파일을 받을 수 있나요?
  • Windows 업데이트로 먼저 해결을 시도했나요?
  • 업데이트 직후 문제가 시작됐다면 롤백부터 검토했나요?
  • 중요한 작업 파일을 저장했나요?
  • 회사·학교 관리 PC라면 관리자 승인을 받았나요?

Microsoft가 제시하는 절차 요약

  1. 장치 관리자 → 디스플레이 어댑터를 엽니다.
  2. 해당 어댑터 속성 → 드라이버 탭으로 이동합니다.
  3. 필요 시 디바이스 제거를 선택합니다.
  4. 안내에 따라 드라이버 제거를 진행합니다.
  5. PC를 다시 시작합니다.
  6. Windows가 드라이버를 다시 설치하는지 확인합니다.
  7. 재설치가 원활하지 않다면 제조사의 공식 드라이버를 사용합니다.

Microsoft는 화면이 심하게 왜곡되거나 정상 작업이 어려운 경우 안전 모드에서 진행해야 할 수 있다고 설명합니다.

중요: 일부 드라이버 제거 옵션은 안전 모드에서만 표시될 수 있습니다. 장치 관리자 항목이 보이지 않거나 제거 단계를 이해하기 어렵다면 임의로 드라이버 파일을 직접 삭제하지 말고 제조사·Microsoft 공식 지원을 이용하세요.

공식 참고: Microsoft — 화면 깜박임 시 드라이버 제거·재설치

14. Windows 로그인 화면도 보이지 않는다면: 안전 모드와 복구

깜빡임을 넘어 화면이 계속 검거나 로그인할 수 없다면 일반적인 화면 설정을 바꾸기 어렵습니다.

Microsoft는 빈 화면 문제에서 다음 단서를 안내합니다.

  • 커서는 보이는데 화면이 검은 경우: 중단된 Windows 프로세스·드라이버 문제 가능성
  • 업데이트 후 검은 화면: 호환되지 않는 드라이버·불완전한 업데이트 가능성
  • 외부 모니터만 검음: 케이블·전원·디스플레이 출력 모드 확인
  • 로그인도 어려움: Windows 복구 환경 또는 안전 모드에서 문제 해결

화면이 보일 때 가능한 기본 조치

  1. Windows + Ctrl + Shift + B로 그래픽 드라이버를 재설정해 봅니다.
  2. Windows + P로 출력 모드가 잘못 바뀌지 않았는지 확인합니다.
  3. 외부 모니터의 전원과 케이블을 확인합니다.
  4. Ctrl + Alt + Delete가 열리는지 확인합니다.

고급 복구가 필요한 경우

Microsoft의 Windows 빈 화면 문제 해결 문서에는 안전 모드, 탐색기 다시 시작, 드라이버 롤백, 시스템 복원 등의 절차가 있습니다.

주의: 화면이 안 보인다고 전원 버튼을 여러 번 강제로 누르거나 Windows를 임의로 초기화하는 것은 데이터 손실과 다른 장애를 유발할 수 있습니다. 정상적인 종료가 가능한지 먼저 확인하고, 복구 환경 진입은 공식 절차를 따라야 합니다.

회사 PC·BitLocker 사용 PC라면 복구 키와 관리자 접근이 필요한 상황이 생길 수 있으므로 IT 담당자의 도움을 받는 편이 안전합니다.

공식 참고: Microsoft — Windows에서 빈 화면 문제 해결

15. 해결됐는지 확인하는 10분 비교 테스트

설정을 바꾼 직후 화면이 멀쩡하다고 문제가 완전히 해결됐다고 단정하기는 어렵습니다. 같은 작업과 연결 조건에서 다시 증상이 나타나는지 확인해야 합니다.

확인 항목결과 기록
작업 관리자와 화면이 함께 깜빡임예 / 아니요
Windows + Ctrl + Shift + B 후개선 / 동일 / 잠시 개선
최근 드라이버 업데이트 또는 변경있음 / 없음
특정 앱 실행 시에만 깜빡임예 / 아니요
내장 디스플레이에서는 정상예 / 아니요
외부 모니터에서만 재현예 / 아니요
다른 케이블·포트에서도 재현예 / 아니요
지원되는 낮은 주사율에서개선 / 동일
재시작 후개선 / 동일

진단의 목적: 무엇을 바꿨을 때 결과가 달라졌는지 기록해 원인 범위를 줄이는 것입니다. 여러 설정을 한꺼번에 변경하면 결과를 해석하기 어렵습니다.

16. 자주 묻는 질문

Q1. 윈도우11 화면 깜빡임은 그래픽카드가 고장 났다는 뜻인가요?

그렇게 단정할 수 없습니다. Microsoft는 그래픽 드라이버 문제와 호환되지 않는 앱을 대표적인 원인으로 안내합니다. 먼저 작업 관리자도 함께 깜빡이는지 확인해야 합니다.

Q2. 화면 깜빡임에서 작업 관리자를 확인하는 이유는 뭔가요?

작업 관리자도 함께 깜빡이면 드라이버 문제, 다른 화면만 깜빡이고 작업 관리자는 안정적이면 호환되지 않는 앱 문제일 가능성이 높다고 Microsoft가 안내하기 때문입니다.

Q3. Windows + Ctrl + Shift + B는 무엇을 하나요?

Windows의 그래픽 드라이버를 다시 설정하는 단축키입니다. 화면이 순간적으로 깜빡이거나 신호음이 들릴 수 있으며, 드라이버 파일을 삭제하거나 PC를 초기화하지는 않습니다.

Q4. 윈도우 업데이트 직후부터 깜빡여요.

Microsoft는 이 경우 장치 관리자 → 디스플레이 어댑터 → 속성 → 드라이버 → 드라이버 롤백을 검토하도록 안내합니다. 롤백 버튼이 없다면 이전 드라이버가 저장되지 않았을 수 있습니다.

Q5. 게임할 때만 화면이 깜빡이는 이유는 무엇인가요?

게임의 전체 화면 모드, 그래픽 드라이버, 모니터 주사율, 연결 케이블 등에 따라 영향을 받을 수 있습니다. 바탕화면에서도 발생하는지, 창 모드에서도 발생하는지를 비교해 원인 범위를 좁히세요.

Q6. 144Hz 모니터를 60Hz로 바꾸면 해결될 수 있나요?

일부 연결·설정 문제의 원인을 분리하는 데 도움이 될 수 있습니다. 설정 → 시스템 → 디스플레이 → 고급 디스플레이에서 모니터가 지원하는 주사율로 비교하세요. 원인을 해결하지 못했다면 원래 설정으로 되돌릴 수 있습니다.

Q7. 노트북은 정상인데 HDMI로 연결한 모니터만 깜빡여요.

HDMI·DP·USB-C 케이블, 허브·도크, 모니터 입력 포트, 각 모니터의 주사율을 먼저 확인하세요. 다른 케이블·모니터·PC와 비교하면 어떤 경로에서 문제가 생기는지 구분하기 쉽습니다.

Q8. 작업 관리자는 안 깜빡이는데 바탕화면만 깜빡입니다.

Microsoft는 호환되지 않는 앱이 원인일 가능성이 높다고 설명합니다. 최근 설치·업데이트한 프로그램을 점검하고 공식 업데이트를 확인하세요.

Q9. 드라이버 롤백 버튼이 회색인데 어떻게 하나요?

Microsoft에 따르면 이전 드라이버가 저장되어 있지 않으면 롤백할 수 없습니다. Windows 업데이트나 PC·GPU 제조사 공식 드라이버를 확인하고 필요하면 지원을 받으세요.

Q10. 화면이 계속 검어서 설정을 열 수 없어요.

Microsoft의 Windows 빈 화면 문제 해결 절차를 따르세요. 출력 모드·케이블·그래픽 드라이버 단축키를 확인하고, 계속 실패하면 안전 모드·복구 절차를 이용할 수 있습니다. 무작정 공장 초기화하지 마세요.

17. 최종 체크리스트

  • ☐ Ctrl + Shift + Esc로 작업 관리자를 열고 함께 깜빡이는지 확인했다.
  • ☐ Windows + Ctrl + Shift + B로 그래픽 드라이버를 다시 설정해 봤다.
  • ☐ Windows를 정상적으로 재시작했다.
  • ☐ 최근 Windows 또는 그래픽 드라이버 업데이트가 있었는지 확인했다.
  • ☐ 업데이트 직후 문제가 시작됐다면 드라이버 롤백을 검토했다.
  • ☐ 이전부터 문제가 있었다면 Windows 업데이트·공식 GPU 드라이버를 확인했다.
  • ☐ 작업 관리자가 안정적이라면 최근 설치·업데이트한 앱을 점검했다.
  • ☐ 외부 모니터는 HDMI·DP·USB-C 케이블과 도크 연결을 비교했다.
  • ☐ 다중 모니터 환경에서는 문제가 있는 모니터를 각각 확인했다.
  • ☐ 지원되는 다른 주사율로 변경해 결과를 비교했다.
  • ☐ HDR·동적 주사율은 지원 여부와 설정을 확인한 뒤 비교했다.
  • ☐ 드라이버 제거·안전 모드·시스템 복원은 마지막 단계로 남겼다.
  • ☐ 증상이 지속된다면 PC·모니터 제조사 또는 Microsoft 공식 지원을 이용한다.

결론: 윈도우11 화면 깜빡임에서는 작업 관리자 진단 → 그래픽 드라이버 재설정 → 드라이버 롤백·업데이트 또는 앱 충돌 확인 → 케이블·주사율 비교 순서가 가장 실용적입니다. 깜빡이는 위치와 발생 조건을 구분하면 불필요한 Windows 초기화와 부품 교체를 피하는 데 도움이 됩니다.
