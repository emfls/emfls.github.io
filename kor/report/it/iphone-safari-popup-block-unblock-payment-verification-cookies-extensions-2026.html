아이폰에서 쇼핑몰 결제를 하거나 은행·공공기관의 본인인증을 진행하는데 새 창이 열리지 않는다면, Safari 팝업 차단 설정부터 확인해 볼 필요가 있습니다. 다만 팝업 차단·쿠키 차단·광고 차단 확장 프로그램·사이트 접속 오류는 서로 다른 문제입니다. 팝업 차단을 해제했는데도 결제창이 열리지 않는다면 원인을 하나씩 구분해야 합니다.

2026년 11월 4일 기준 Apple 공식 안내에서 iPhone Safari 팝업 허용·차단 경로는 설정 → 앱 → Safari → 팝업 차단입니다. 사이트 이용이 끝난 뒤에는 차단을 다시 켜는 것이 안전합니다. 일부 결제·본인인증 사이트를 위해 모든 사이트의 팝업을 계속 허용한 상태로 두면 광고나 사기성 창에도 노출될 수 있습니다.

이 글은 Apple의 한국어 Safari 공식 고객지원 문서를 검토해 작성한 방법 안내입니다. 특정 은행·쇼핑몰에서 결제를 직접 완료했다고 주장하지 않으며, 사이트별 인증 과정과 iOS 버전에 따라 추가 원인이 있을 수 있습니다.

1. 먼저 결론: 아이폰 Safari 팝업 차단 해제 5단계

  1. 아이폰 설정 앱을 엽니다.
  2. 앱 메뉴로 들어갑니다.
  3. 앱 목록에서 Safari를 선택합니다.
  4. 팝업 차단 항목을 찾습니다.
  5. 팝업 차단을 끕니다. 스위치가 꺼진 상태이면 Safari가 팝업을 차단하지 않도록 설정된 것입니다.

그다음 결제나 본인인증을 진행하던 Safari 탭으로 돌아가 새로고침 후 버튼을 다시 누릅니다. 새 창이 정상적으로 뜬다면 작업을 마친 후 다시 설정 → 앱 → Safari → 팝업 차단 켜기로 되돌리세요.

주의할 점: Safari의 '팝업 차단'은 팝업을 허용하려면 꺼야 하는 설정입니다. 이름만 보고 '팝업 차단 켜기'를 누르면 오히려 결제창이 차단될 수 있습니다.

3. 설정에서 Safari가 안 보일 때: 최신 메뉴와 예전 메뉴 구별

예전 인터넷 안내에는 설정 → Safari로 바로 이동하라고 적힌 경우가 많습니다. 그러나 Apple의 현재 공식 사용 설명서는 설정 → 앱 → Safari 경로를 안내합니다.

아래 순서로 확인하면 됩니다.

  1. 설정 앱을 엽니다.
  2. 메뉴를 아래로 스크롤해 앱을 선택합니다.
  3. Safari를 찾아 누릅니다.
  4. Safari 설정 안의 팝업 차단 스위치를 확인합니다.

본인 아이폰에서 위 경로가 아니라 다른 위치에 Safari가 보인다면 설치된 iOS의 실제 화면을 따르세요. 기기와 소프트웨어 버전에 따라 메뉴 구성이 다를 수 있습니다.

Safari 설정을 찾았지만 팝업 차단 항목이 안 보인다면

  • 현재 열고 있는 것이 Safari 설정 페이지인지 확인하세요.
  • 기기의 소프트웨어 버전이 너무 오래되지 않았는지 점검합니다.
  • Safari 대신 Chrome·삼성 인터넷 등 다른 앱 설정을 열고 있지는 않은지 확인합니다.
  • 개인 소유 기기가 아닌 학교·회사 관리 기기라면 일부 설정에 관리 정책이 있을 수 있습니다.

4. 쇼핑몰 결제창·카드인증창이 안 열릴 때 순서

온라인 쇼핑·항공권 결제·유료 서비스 신청 중 결제 버튼을 눌렀는데 새 창이 없으면, 먼저 안전한 사이트인지 확인한 뒤 팝업 설정을 바꿉니다.

  1. Safari에서 결제를 진행하려는 공식 웹사이트 주소인지 확인합니다.
  2. 설정 → 앱 → Safari → 팝업 차단을 끕니다.
  3. Safari로 돌아와 현재 결제 페이지를 다시 불러옵니다.
  4. 결제하기·본인인증·카드인증 버튼을 다시 누릅니다.
  5. 새 탭·새 창·외부 앱 전환 알림이 나타나는지 확인합니다.
  6. 결제가 정상적으로 끝났다면 Safari 설정으로 돌아와 팝업 차단을 켭니다.

중복 결제 주의: 결제 버튼을 눌렀을 때 화면 반응이 없더라도 이미 결제가 진행됐을 수 있습니다. 같은 버튼을 여러 번 누르기 전에 주문 내역과 카드 승인 여부부터 확인하세요.

결제창 대신 앱 설치 안내나 가짜 고객센터 페이지가 표시된다면 결제 진행을 중단하고 사업자의 공식 앱·웹사이트·고객센터를 통해 확인합니다. 팝업을 허용했다는 이유만으로 그 창이 안전하다고 판단하면 안 됩니다.

Apple은 팝업 중 일부가 경고·경품·소프트웨어 설치 안내를 가장해 개인정보나 금융정보를 요구하는 피싱 수단일 수 있다고 경고합니다.

5. 정부24·학교·은행 본인인증 창이 안 뜨는 경우

공공기관이나 금융기관 사이트에서도 새 창으로 인증 화면을 띄우는 경우가 있습니다. 하지만 모든 인증 서비스가 팝업으로 작동하는 것은 아닙니다. 브라우저 자체 인증, 외부 인증 앱, 새 탭 전환, 전자서명 모듈 등 다양한 구현이 있을 수 있습니다.

다음 순서대로 확인하세요.

  1. 본인인증을 요청한 주소가 실제 공식 사이트인지 확인합니다.
  2. Safari 팝업 차단을 잠시 해제하고 인증 버튼을 다시 누릅니다.
  3. '인증 앱으로 이동' 요청이 뜨는지 확인합니다.
  4. Safari가 아닌 카카오톡·문자 앱 안에서 열었다면 Safari 브라우저에서 직접 접속해 비교합니다.
  5. 팝업은 열리지만 로그인 상태가 유지되지 않으면 쿠키 차단을 확인합니다.
  6. 확장 프로그램의 콘텐츠 차단이 의심되면 해당 설정을 점검합니다.
  7. 사이트가 공식적으로 지원하는 모바일 브라우저와 인증 방식을 확인합니다.

주의: Safari에서 팝업 해제 후에도 작동하지 않는다고 해서 무조건 아이폰의 모든 보안 기능을 꺼야 하는 것은 아닙니다. 사이트가 모바일 Safari를 지원하지 않을 수 있으며, 이 경우 해당 기관이 안내하는 공식 대체 경로를 이용해야 합니다.

6. 팝업 차단을 껐는데도 인증창이 안 열릴 때: 쿠키 설정

웹사이트는 로그인 세션이나 본인인증 상태를 유지하기 위해 쿠키를 사용할 수 있습니다. Apple도 일부 사이트는 쿠키가 활성화돼 있어야 정상적으로 작동한다고 설명합니다.

Safari에서 쿠키 차단 상태 확인하는 방법

  1. 아이폰 설정을 엽니다.
  2. 앱 → Safari로 이동합니다.
  3. 아래쪽 고급을 선택합니다.
  4. 모든 쿠키 차단 항목을 확인합니다.
  5. 서비스 이용에 쿠키가 필요하다면 모든 쿠키 차단을 끈 상태에서 다시 확인합니다.

이 경로는 팝업 차단 설정과 별개입니다. 팝업 차단을 끄는 것과 쿠키를 허용하는 것은 동일한 작업이 아닙니다.

이미 모든 쿠키 차단이 꺼져 있다면 다시 바꿀 필요가 없습니다. 쿠키 설정을 점검했는데도 문제가 계속되면 사이트의 로그인 과정·브라우저 지원 환경을 확인하세요.

개인정보 유의: 웹사이트에서 쿠키를 사용하면 사이트 설정이나 일부 활동 내역이 저장될 수 있습니다. 보안·개인정보 보호 설정을 목적 없이 광범위하게 해제하지 마세요.

7. 광고 차단 앱·Safari 확장 프로그램 때문에 새 창이 안 열릴 때

팝업 차단을 껐지만 여전히 버튼이 작동하지 않는다면 콘텐츠 차단기의 영향을 확인할 수 있습니다.

Apple은 Safari에서 타사 콘텐츠 차단 앱·확장 프로그램이 쿠키, 이미지, 리소스, 팝업 등을 제한할 수 있다고 안내합니다.

설치된 확장 프로그램 확인

  1. 설정 → 앱 → Safari로 이동합니다.
  2. 확장 프로그램을 엽니다.
  3. 설치된 콘텐츠 차단 확장 프로그램이 있는지 확인합니다.
  4. 문제를 일으킬 것으로 의심되는 확장을 일시적으로 비활성화해 테스트합니다.
  5. 공식 사이트에서 인증·결제 기능이 복원되는지 확인합니다.
  6. 확인이 끝나면 사용하던 보호 기능을 다시 활성화합니다.

무작정 모든 광고 차단 앱을 삭제하거나 기기의 보안 설정을 끄지 마세요. 문제가 사라지는지 비교하기 위한 일시적인 테스트만 권합니다. 보안에 민감한 인증 과정에서 출처가 불분명한 확장 프로그램의 사용은 특히 신중해야 합니다.

8. iPhone에서 특정 사이트만 팝업 허용할 수 있나요?

혼동하기 쉬운 점입니다.

Apple이 안내하는 iPhone Safari 팝업 설정은 '설정 → 앱 → Safari → 팝업 차단'의 스위치입니다. 현재 확인한 Apple 공식 iPhone 안내에는 Mac Safari처럼 웹사이트별로 팝업 허용을 관리하는 동일한 절차가 명시돼 있지 않습니다.

반면 Mac Safari에서는 Safari → 설정 → 웹사이트 → 팝업 윈도우로 이동해 사이트별 허용·차단을 설정할 수 있습니다.

따라서 iPhone에서 특정 사이트의 인증 때문에 팝업이 필요하다면 신뢰할 수 있는 사이트에서 작업하는 동안만 팝업 차단을 끄고, 작업 후 다시 켜는 방식이 실용적입니다.

주의: 앱별 추적 허용이나 쿠키를 설정할 수 있다는 것이 곧 iPhone Safari의 사이트별 팝업 예외 목록을 뜻하지는 않습니다.

9. 카카오톡·네이버 앱 안에서 열었는데 설정이 안 먹힌다면

메신저나 다른 앱 안에서 링크를 열면 앱 자체 내장 브라우저가 사용될 수 있습니다. 이때 모든 화면이 독립된 Safari 앱과 동일하게 동작한다고 가정하기는 어렵습니다.

  1. 현재 웹페이지가 Safari 앱인지, 메신저·포털 앱 안의 웹뷰인지 확인합니다.
  2. 앱 메뉴에 Safari에서 열기·기본 브라우저에서 열기·외부 브라우저로 열기가 있는지 확인합니다.
  3. 가능하면 해당 기능을 이용해 공식 사이트를 Safari에서 직접 엽니다.
  4. Safari 설정에서 팝업 차단을 일시 해제합니다.
  5. 동일한 인증·결제 과정을 Safari에서 다시 확인합니다.

왜 구분해야 하나요? Safari 설정을 변경했는데 앱 내부 화면에는 변화가 없는 경우, 처음부터 Safari가 아니라 앱 내부 브라우저의 문제였을 수 있기 때문입니다.

단, 브라우저를 바꿔도 결제 사이트가 허용하지 않는 접속 환경이면 오류가 계속될 수 있습니다. 해당 서비스 고객센터의 모바일 지원 조건을 확인하세요.

10. 쿠키·방문 기록을 지우기 전에 알아둘 점

팝업이 안 열린다고 방문 기록·모든 쿠키를 무조건 삭제할 필요는 없습니다. Apple은 Safari에서 방문 기록과 웹사이트 데이터를 제거할 수 있다고 안내하지만, 이 과정에서 로그인이 풀리거나 일부 사이트 환경이 초기화될 수 있습니다.

방문 기록과 웹사이트 데이터 정리가 필요한지 판단하기

  • 여러 사이트에서 팝업이 열리지 않는다: 먼저 Safari 팝업 차단 설정을 확인합니다.
  • 특정 사이트에서 로그인만 반복된다: 쿠키와 사이트 세션 문제를 확인합니다.
  • 특정 웹사이트가 오래된 화면으로 멈춘다: 해당 사이트의 저장 데이터 오류 가능성을 검토합니다.
  • 광고 경고창만 계속 나타난다: 가짜 팝업에 반응하지 말고 탭을 닫고 차단 설정을 확인합니다.

Apple의 현재 Safari 데이터 정리 기능은 설정 → 앱 → Safari에서 방문 기록과 웹사이트 데이터를 관리하는 방향으로 제공됩니다. 삭제를 진행한다면 로그인 상태나 과거 이용 기록에 미치는 영향을 먼저 이해하세요.

결제 내역이나 신청서가 중요하다면 페이지를 초기화하기 전에 해당 사이트에서 접수·결제 완료 여부부터 확인하세요.

11. 사기성 팝업과 정상 인증창을 구별하는 방법

Apple은 일부 팝업이 Apple의 보안 경고, 경품 당첨, 무료 업데이트 안내처럼 보이도록 꾸며 사용자의 금융·개인정보를 빼낼 수 있다고 경고합니다.

신뢰를 의심해야 하는 상황

  • '아이폰에 바이러스가 7개 발견됐다'며 즉시 결제를 요구합니다.
  • 'Apple 계정이 차단됐다'면서 비밀번호를 직접 입력하라고 요구합니다.
  • 닫기(X)처럼 생긴 버튼을 누르자 다른 광고 사이트가 열립니다.
  • 공식 기관과 무관한 낯선 주소로 이동합니다.
  • 공식 앱스토어가 아닌 곳에서 앱·설치 파일을 내려받게 합니다.
  • 갑자기 카드번호·보안코드·인증번호를 요구합니다.

이런 경우는 창 안의 버튼에 반응하지 말고 Safari 탭을 직접 닫거나 주소창에서 안전한 사이트로 이동하세요. Apple은 가짜 닫기 버튼이 있을 수 있다는 점도 안내합니다.

팝업 차단을 일시 해제했다고 해서 모든 팝업을 허용해야 한다는 의미는 아닙니다. 용도가 확인된 공식 사이트에서 필요한 인증을 완료한 뒤에는 차단을 다시 켜세요.

12. 자주 묻는 질문

Q1. 2026년 아이폰 사파리 팝업 차단 해제는 어디에서 하나요?

Apple 공식 안내 기준 설정 → 앱 → Safari → 팝업 차단 끄기입니다. 팝업을 허용하려면 '팝업 차단' 스위치를 끈 상태여야 합니다.

Q2. Safari에서 결제창이 안 뜨면 팝업 차단만 끄면 되나요?

항상 그렇지는 않습니다. 팝업 설정 외에도 쿠키 차단, 콘텐츠 차단 확장 프로그램, 앱 내부 브라우저, 결제 사이트 오류 등이 원인일 수 있습니다. 순서대로 구분해 확인하세요.

Q3. iPhone에서 사이트별로 팝업을 허용할 수 있나요?

Apple 공식 iPhone 안내는 Safari 전체 팝업 차단 스위치를 설명합니다. Mac Safari는 사이트별 허용·차단 기능을 별도로 제공하므로 두 기기의 메뉴를 혼동하지 마세요.

Q4. Safari에 광고 창이 계속 뜰 때는 팝업 차단을 꺼야 하나요?

아닙니다. 광고 창을 줄이려면 팝업 차단을 켜는 방향을 확인하세요. 의심스러운 팝업은 누르지 말고 탭을 닫으세요.

Q5. 팝업 차단을 껐는데 본인인증이 계속 실패합니다.

설정 → 앱 → Safari → 고급 → 모든 쿠키 차단 여부를 확인하세요. 또 Safari 확장 프로그램이나 앱 내부 브라우저 문제인지 구분해야 합니다.

Q6. Safari와 Chrome 팝업 차단 설정이 같은가요?

아닙니다. iPhone에서 Safari와 Chrome은 서로 다른 브라우저 앱과 설정을 사용합니다. 현재 어느 앱에서 열었는지 먼저 확인하세요.

Q7. Safari 방문 기록을 지우면 팝업 차단도 해제되나요?

방문 기록·웹사이트 데이터 정리는 Safari 팝업 차단 스위치 변경과 다른 작업입니다. 기록 삭제를 먼저 할 이유는 없으며, 로그인이 풀리는 등 부작용이 있을 수 있습니다.

Q8. 정부24나 은행 결제창만 열리지 않습니다.

공식 웹사이트인지 확인한 뒤 Safari 팝업 차단을 일시 해제해 보세요. 계속 실패한다면 서비스의 모바일 Safari 지원 여부, 쿠키·확장 프로그램, 인증 앱 전환 문제를 확인하세요.

Q9. 팝업 차단을 꺼 둬도 안전한가요?

팝업이 필요한 신뢰할 수 있는 사이트에서 잠시 사용할 수 있지만, 차단을 계속 해제한 상태로 두는 것은 권하지 않습니다. 작업이 끝나면 팝업 차단을 다시 켜세요.

Q10. '위조된 웹사이트 경고'도 꺼야 인증창이 열리나요?

Apple은 '팝업 차단'과 '위조된 웹사이트 경고'를 별도 설정으로 안내합니다. 정상 인증 때문에 피싱 경고까지 끌 필요가 있다고 단정하지 마세요. 의심스러운 사이트에서는 보안 경고를 무시하지 않는 것이 안전합니다.

13. 아이폰 Safari 팝업 차단 문제 해결 체크리스트

  • ☐ 지금 사용 중인 브라우저가 Safari인지 다른 앱인지 확인했다.
  • ☐ 설정 → 앱 → Safari → 팝업 차단 항목을 찾았다.
  • ☐ 공식 결제·인증 사이트에서 필요한 동안만 팝업 차단을 껐다.
  • ☐ 결제 버튼을 반복 누르기 전에 주문·카드 승인 여부를 확인했다.
  • ☐ 팝업은 뜨지만 로그인이 안 되면 모든 쿠키 차단 상태를 확인했다.
  • ☐ 광고 차단·콘텐츠 차단 확장 프로그램의 영향 여부를 점검했다.
  • ☐ 메신저 내부 브라우저라면 Safari에서 직접 열어 비교했다.
  • ☐ 무조건 캐시·방문 기록을 모두 지우거나 공장 초기화하지 않았다.
  • ☐ 의심스러운 팝업의 가짜 닫기 버튼·경고문을 누르지 않았다.
  • ☐ 필요한 인증·결제가 끝나면 팝업 차단을 다시 켰다.

최종 정리: 아이폰 Safari에서 팝업이 열리지 않으면 ① 설정 → 앱 → Safari → 팝업 차단 끄기 → ② 공식 사이트에서 재시도 → ③ 쿠키·확장 프로그램·앱 내부 브라우저 점검 → ④ 작업 후 팝업 차단 다시 켜기 순서가 효율적입니다.
