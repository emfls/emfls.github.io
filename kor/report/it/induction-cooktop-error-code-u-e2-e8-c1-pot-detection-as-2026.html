인덕션 에러코드 U·C1·E2·E8·H·Loc 해결 가이드

2026-11-27 · emfls

U는 용기, H는 잔열, Loc·L은 잠금을 먼저 확인하세요. C·E 코드는 모델별로 다릅니다.

U가 깜빡일 때는 냄비 바닥을 확인하세요

LG 디오스 공식 안내의 U·u, 삼성전자서비스의 밑줄 U, SK매직 IHR-B310E 설명서의 U는 용기가 없거나 적합한 용기가 감지되지 않았을 때 확인할 표시입니다.

  1. 재질과 평탄도: 냄비를 식힌 뒤 IH 표시를 확인하고, 바닥의 여러 부분에 자석이 잘 붙는지 보세요. 바닥이 휘었거나 자석이 일부에만 붙으면 인식이 어려울 수 있습니다.
  2. 바닥 지름: 상판과 닿는 자성 바닥의 지름을 재고, 사용하려는 화구의 설명서에 나온 범위와 비교하세요. 예를 들어 SK매직 IHR-B310E의 소화구는 평평한 바닥 지름 12~16cm를 안내합니다.
  3. 위치: 용기를 화구 한가운데 놓고 내용물이 담긴 정상 IH 용기로 비교해 보세요. 같은 화구에서 규격에 맞는 용기를 바꿔도 인식이 안 되면 해당 화구와 용기 정보를 AS에 전달하세요.

삼성 비스포크 NZ63B6657·NZ63B6527·NZ63B6507 계열은 삼성전자서비스가 용기 적합도 확인 기능의 예로 든 모델입니다. 진입 방법과 점수 표기는 보유 모델의 설명서를 확인하세요.

H 잔열과 Loc·L 잠금 구분

H·h는 조리 직후 상판에 열이 남았다는 표시입니다

LG 디오스와 삼성전자서비스는 H·h를, SK매직 IHR-B310E는 H를 잔열 표시로 안내합니다. 조리 직후 이 표시만 뜨는 것은 정상입니다. 표시가 사라져도 상판에 열이 남을 수 있으니 손으로 확인하지 말고 충분히 식은 뒤 청소하세요. LG는 일부 상황에서 전원을 처음 연결하거나 복구한 직후에도 H·h가 나타날 수 있다고 안내합니다. 오래 식은 상태에서도 표시가 계속되면 모델별 안내를 확인하세요.

잠금 버튼과 누르는 시간은 모델별로 확인하세요

  • LG 디오스: LG 안내 예시에서는 잠금 표시등이 켜져 있을 때 [잠금] 또는 [Lock]을 3초간 누릅니다.
  • 삼성 비스포크: 삼성전자서비스의 L 표시 안내 예시는 자물쇠 버튼을 3초간 누르는 방식입니다. 보유 모델의 잠금 해제 절차를 우선하세요.
  • SK매직 IHR-B310E: 잠금 표시가 ch로 나타나며 잠금 스위치를 다시 3초간 누르면 해제됩니다.
  • Loc 또는 LOC: 밀레 KM 7678·7697·7878·7897 설명서에서는 시스템·안전 잠금 표시입니다. 같은 Loc라도 다른 모델에서는 지정 버튼과 버튼 조합을 설명서에서 확인하세요.

잠금 안내대로 해제되지 않으면 상판이 식은 뒤 조작부의 물기·이물질을 닦고 다시 확인하세요. 표시가 계속되고 조작이 안 되면 공식 AS에 문의하세요.

C1·E2·E8은 모델별 오류표로 확인하세요

C1: 삼성전자서비스 전기레인지 안내에는 과열 보호로 가열이 중단되는 예가 있습니다. 가열을 멈추고 자연 냉각하세요. 식은 뒤에도 반복되면 코드 사진을 남기고 점검을 요청하세요. 삼성 비스포크도 모델 번호를 기준으로 설명서를 확인해야 합니다.

E2: SK매직 IHR-B310E 설명서는 E1·E2에 전원 이상 여부를 확인하라고 안내합니다. 용기 온도가 높은 경우는 별도로 E3·E4, 제품 냉각이 필요한 경우는 E5·E6으로 구분합니다. 반면 InvisaCook 유럽용 설치 설명서에서는 E2가 조리면의 온도 초과를 뜻합니다.

E8: InvisaCook 유럽용 설명서는 E7·E8을 공급 전압 이상이나 전원 연결 상태와 관련된 표시로 안내합니다. LG 디오스·삼성 비스포크·SK매직에 이 정의를 적용하려면 해당 모델 설명서에서 확인해야 합니다.

설명서에 과열로 나오면 가열을 멈추고 자연 냉각하세요. 온도 센서 이상으로 나오면 내부를 열지 말고 제조사 점검을 받으세요. 전압·전원 이상으로 나오면 외부 전원 상태만 살피고 배선·전압 점검은 전문가에게 맡기세요.

화면이 꺼졌을 때 전용 누전차단기 확인

  1. 집의 다른 조명이나 기기도 꺼졌는지 보고 정전과 인덕션 회로 문제를 구분하세요.
  2. 분전반 외부에서 인덕션 전용으로 표시된 누전차단기의 손잡이가 내려갔거나 중간에 걸렸는지 확인하세요. 어떤 회로인지 모르면 관리사무소나 전기기사에게 확인하세요.
  3. 플러그형은 안전하게 보이는 범위에서 접지된 전용 벽면 콘센트 연결을 확인하세요. 직결형은 단자함을 열거나 배선을 만지지 마세요.
  4. 차단기가 반복해서 트립하거나 상판 균열, 탄 냄새, 스파크, 전기부 물 유입이 보이면 전원을 다시 넣지 말고 사용을 중단하세요. 차단기나 배선 문제는 관리사무소·전기기사, 제품 오류는 제조사 AS에 점검을 요청하세요.

AS 접수에 필요한 정보: 설치 서류나 제품 등록 화면에서 전체 모델명을 확인하고 표시 사진, 해당 화구, 발생 시점, 다른 IH 용기로 확인한 결과, 차단기 상태를 함께 알려 주세요. 빌트인 제품을 들어 올려 라벨을 찾을 필요는 없습니다.

자주 묻는 질문

IH 냄비인데 인덕션에 U가 뜨는 이유는 무엇인가요?

IH 표시가 있어도 자성이 약하거나 바닥이 휘었거나 해당 화구에서 감지할 수 있는 바닥 지름보다 작으면 인식이 어려울 수 있습니다. 규격을 확인하고 용기를 화구 중앙에 놓으세요.

인덕션을 껐는데 H가 뜨면 고장인가요?

조리 직후의 H는 잔열 경고입니다. 상판이 충분히 식을 때까지 만지지 마세요. 충분히 식은 뒤에도 계속 뜨면 모델별 안내를 확인하세요.

인덕션 Loc나 L 잠금은 어떻게 푸나요?

보유 모델의 설명서에서 잠금 표시와 해제 버튼을 확인하세요. 삼성전자서비스의 L 표시 예시는 자물쇠 버튼을 3초간 누르는 방식이며, Loc 모델은 지정 버튼과 누르는 시간이 다를 수 있습니다.

인덕션 C1·E2·E8은 모두 과열인가요?

삼성전자서비스는 C1을 과열 보호의 예로 안내하고, SK매직 IHR-B310E 설명서는 E2에 전원 이상 여부 확인을 안내합니다. E8을 포함한 정확한 뜻은 보유 모델의 오류표를 확인하세요.

인덕션 전용 차단기가 계속 내려가면 어떻게 하나요?

사용을 중단하고 차단기를 반복해서 올리지 마세요. 관리사무소나 전기기사에게 회로 점검을 요청하고, 표시된 코드나 특정 화구에서 재현된 증상이 있으면 제조사 AS에도 전달하세요.
