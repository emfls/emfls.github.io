윈도우11에서 영상을 인코딩하거나 대용량 파일을 내려받은 후 1시간 뒤 PC를 끄고 싶거나, 매일 특정 시각에 컴퓨터를 종료하고 싶을 때는 별도 유료 프로그램 없이도 기본 명령어와 작업 스케줄러를 이용할 수 있습니다.

다만 자동 종료 예약과 절전 모드는 다르며, 종료가 실행되면 저장하지 않은 문서·프로그램 작업이 손실될 수 있습니다. 특히 Microsoft 공식 문서에는 shutdown /t에 0보다 큰 대기 시간을 지정하면 /f가 암묵적으로 적용된다고 명시되어 있습니다. 따라서 시간만 넉넉하게 주면 데이터가 반드시 보호된다는 생각은 위험합니다.

이 글에서는 1시간·2시간·3시간 뒤 자동 종료, 예약 취소, 매일 같은 시간 종료, 종료가 안 되는 이유, 절전·화면 끄기와의 차이를 Microsoft 공식 명령어를 기준으로 정리합니다.

확인 기준: 2026년 11월 4일. Windows 11의 기본 기능을 중심으로 설명하며, 회사·학교 관리 PC와 보안 정책이 적용된 기기는 일부 기능이 제한될 수 있습니다.

1. 바로 찾는 명령어: 1시간·2시간·3시간 후 종료

시간 계산의 기준은 명령을 입력한 시점부터 지난 초입니다.

종료 예약입력할 명령어실제 대기 시간
10분 뒤 종료shutdown /s /t 600600초
30분 뒤 종료shutdown /s /t 18001,800초
1시간 뒤 종료shutdown /s /t 36003,600초
2시간 뒤 종료shutdown /s /t 72007,200초
3시간 뒤 종료shutdown /s /t 1080010,800초
예약 취소shutdown /a실행 전 대기 중인 종료 중단

가장 중요한 주의사항: 위와 같이 /t를 0보다 크게 지정하면 실행 중인 프로그램을 강제로 닫는 /f 동작이 암묵적으로 포함됩니다. 작업이 저장되지 않았다면 데이터를 잃을 수 있으므로, 문서를 모두 저장하고 필요한 백그라운드 작업이 끝날 것으로 확신할 때만 사용하세요.

공식 근거: Microsoft Learn — shutdown 명령어의 /s·/t·/a·/f 정의.

2. 윈도우11에서 자동 종료 예약하는 가장 쉬운 방법

방법 1. Windows + R 실행창 사용

  1. 먼저 Word·Excel·편집 프로그램 등에서 문서를 저장합니다.
  2. 키보드에서 Windows 키 + R을 누릅니다.
  3. 실행창에 아래 명령을 입력합니다.
shutdown /s /t 3600
  1. 확인 또는 Enter를 누릅니다.
  2. Windows에 예약된 종료 관련 안내가 표시될 수 있습니다.
  3. 종료 예정 시각과 진행 중인 작업이 충돌하지 않는지 점검합니다.

위 명령은 입력한 순간부터 1시간 뒤 PC 종료를 시도합니다. 예를 들어 오후 9시에 입력하면 오후 10시가 목표 시각입니다. 매일 오후 10시에 반복 실행한다는 의미는 아닙니다.

방법 2. 명령 프롬프트·터미널 사용

  1. 작업 표시줄에서 터미널 또는 명령 프롬프트를 검색해 실행합니다.
  2. 다음 명령을 입력합니다.
shutdown /s /t 7200
  1. Enter를 누르면 2시간 뒤 종료가 예약됩니다.
  2. 종료 전까지 예약을 변경해야 한다면 먼저 취소하고 새로운 명령을 입력하는 편이 안전합니다.

관리자 권한으로 실행하는 것이 항상 필요한 것은 아닙니다. 일반 PC에서는 현재 계정으로 실행할 수 있지만 조직 정책이 제한하면 권한 오류가 발생할 수 있습니다.

3. 자동 종료 예약 취소: shutdown /a

종료까지 남은 시간이 아직 끝나지 않았다면 대기 중인 종료를 취소할 수 있습니다.

  1. Windows + R을 누릅니다.
  2. 아래 명령어를 입력합니다.
shutdown /a
  1. Enter를 누릅니다.
  2. 취소됐다는 안내가 표시되는지 확인합니다.
  3. 원하는 시간으로 다시 예약할 때는 기존 예약이 취소됐는지 확인한 다음 새 명령을 입력합니다.

Microsoft에 따르면 /a는 종료가 대기 중인 시간 제한 기간에 실행해야 합니다. 즉 이미 전원이 꺼진 뒤에 이 명령을 입력해 종료를 되돌리는 것은 불가능합니다.

예약 취소가 안 되는 대표적인 상황

  • 이미 종료 실행이 진행된 상태
  • 현재 Windows에 취소할 대기 중 종료 예약이 없는 상태
  • 작업 스케줄러 등에서 별도로 생성한 미래의 예약 작업을 삭제·비활성화해야 하는 상태
  • 조직 관리 정책이나 업데이트 등 다른 주체가 종료를 실행하는 상태

중요한 구별: shutdown /a는 현재 대기 중인 종료 요청을 취소하는 명령입니다. 작업 스케줄러에 저장된 매일 밤 종료 예약 자체를 지우는 명령은 아닙니다.

공식 근거: Microsoft Learn — shutdown /a.

4. 명령어의 의미: /s, /t, /r, /a, /f

옵션의미알아둘 점
/s컴퓨터 종료지정 시 종료 대상으로 동작
/t 36003,600초 기다림0보다 크면 /f가 암묵 적용
/a대기 중 종료 중단대기 시간 중 별도 명령으로 실행
/r종료 후 다시 시작자동 종료가 아니라 재부팅
/f실행 앱 강제 종료저장하지 않은 데이터 손실 가능
/h최대 절전 모드종료와 다르며 지원·설정 여부 확인 필요

shutdown /s /t 0은 어떤 명령인가요?

shutdown /s /t 0

이 명령은 대기 시간 없이 바로 종료를 시도하므로, 예약 취소를 연습하려는 경우에는 사용하지 마세요. 위의 양수 /t 값과 달리 대기 시간을 주지 않는 명령입니다.

shutdown /r /t 3600은요?

shutdown /r /t 3600

이 명령은 1시간 뒤 재시작하는 것으로, PC 전원을 끄고 계속 꺼진 상태로 두려는 목적과 다릅니다. 다운로드가 끝난 뒤 PC를 완전히 꺼 두려는 상황이라면 /s와 /r를 혼동하지 마세요.

공식 근거: Microsoft Learn — shutdown 전체 매개변수.

5. 매일 밤 11시에 종료하려면? 작업 스케줄러 사용

shutdown /s /t 3600은 명령을 실행한 시점부터 한 번만 대기합니다. 매일 같은 시간에 종료하려면 작업 스케줄러(Task Scheduler)에서 반복 작업을 만듭니다.

그래픽 화면에서 설정하기

  1. Windows 검색창에 작업 스케줄러를 입력해 실행합니다.
  2. 오른쪽 메뉴에서 기본 작업 만들기를 선택합니다.
  3. 작업 이름을 매일_자동종료처럼 구별하기 쉽게 지정합니다.
  4. 트리거는 매일을 선택합니다.
  5. 실행 시각을 예를 들어 오후 11:00으로 지정합니다.
  6. 동작은 프로그램 시작을 선택합니다.
  7. 프로그램/스크립트에 다음 값을 입력합니다.
shutdown.exe
  1. 인수 추가 칸에는 아래와 같이 입력합니다.
/s /t 0
  1. 작업 요약을 확인한 다음 마침을 누릅니다.
  2. 작업 스케줄러 라이브러리에서 방금 만든 작업을 선택해 트리거·조건·다음 실행 시간을 확인합니다.

주의: 위 작업은 시간이 되면 즉시 종료를 시도합니다. 실행 시 열린 프로그램과 저장되지 않은 파일은 상황에 따라 종료를 막거나 데이터 손실 위험을 만들 수 있습니다. 작업 실행 시간에 자료를 잃지 않도록 사전 저장·업무 종료 확인이 필요합니다.

매일 종료 예약을 멈추려면?

작업 스케줄러에서 매일_자동종료 작업을 선택해 사용 안 함 또는 삭제를 선택합니다.

  • 사용 안 함: 일정은 남기고 실행만 중단
  • 삭제: 해당 예약 작업을 제거
  • shutdown /a: 이미 실행되어 대기 중인 종료 요청에 대한 별도 취소

이 세 기능은 서로 다릅니다. 반복 예약을 지우려면 작업 스케줄러 자체에서 처리해야 합니다.

공식 근거: Microsoft Learn — schtasks와 작업 스케줄러, Microsoft Learn — schtasks create.

6. 명령어로 반복 작업을 관리하는 방법

숙련자라면 Windows의 schtasks 명령으로 예약 작업을 만들고 확인할 수도 있습니다.

다만 매일 반복되는 작업은 이미 같은 이름의 예약이 있는지 확인하고, 실행할 계정과 컴퓨터가 켜져 있을 조건을 검토해야 합니다.

먼저 예약된 작업 확인하기

schtasks /query /tn "매일_자동종료"

작업이 없다면 등록되지 않았다는 안내가 나타날 수 있습니다.

특정 작업 예약 삭제하기

schtasks /delete /tn "매일_자동종료"

삭제 확인 메시지가 나타나면 정확한 작업 이름인지 확인하고 진행합니다.

절대 주의: schtasks /delete /tn * /f처럼 모든 작업을 삭제하는 명령을 복사해 실행하지 마세요. 이는 PC의 다른 예약 작업까지 삭제할 수 있습니다. 이름을 지정해 필요한 작업 하나만 관리하는 것이 안전합니다.

공식 근거: Microsoft Learn — schtasks query, Microsoft Learn — schtasks delete.

7. 실제 종료 시간이 맞지 않거나 실행되지 않는 이유

자동 종료 예약이 작동하지 않는다면 명령이 실행됐는지, 예약 방식이 무엇인지, 컴퓨터가 당시 켜져 있었는지부터 구별하세요.

증상의심할 항목먼저 확인할 일
명령 입력 후 아무 변화가 없음실행 실패·권한 제한·명령 오타명령 프롬프트에서 입력 결과 확인
지정한 시각에 꺼지지 않음작업 스케줄러 트리거·조건다음 실행 시각·실행 기록 확인
예약 시각 전에 PC가 이미 절전 상태절전·작업 깨우기 조건작업의 조건 탭과 전원 설정 점검
예약 취소 명령이 실패대기 중 종료가 없거나 이미 실행됨예약 종류부터 확인
종료 대신 다시 켜짐/r 또는 업데이트·전원 설정사용한 명령과 이벤트 기록 확인
업무용 PC에서 실행 안 됨관리자·그룹 정책 제한IT 관리 부서에 문의

컴퓨터가 꺼져 있어도 작업 스케줄러가 자동으로 켜 주나요?

일반적인 예약 작업을 만든 것만으로 전원이 완전히 꺼진 PC가 정해진 시각에 자동으로 켜지는 것을 보장하지 않습니다. 절전 상태에서 깨울 수 있는지와 전원이 꺼진 상태에서 켜지는지는 다른 문제입니다.

또한 작업 스케줄러의 '작업을 실행하기 위해 컴퓨터 깨우기' 옵션은 하드웨어·전원 설정의 지원 여부에 따라 동작이 달라질 수 있습니다.

예약 시각이 지나도 실행이 안 된다면?

  1. 작업 스케줄러에서 트리거 시작 시각 확인
  2. 조건 탭의 전원·유휴 조건 확인
  3. 마지막 실행 결과 확인
  4. 기록 탭에서 실행 여부 확인
  5. 컴퓨터가 해당 시각에 켜져 있었는지 또는 절전 상태였는지 확인

작업 실행 결과가 성공으로 기록돼도 실제로 안전하게 작업이 종료됐는지까지 보장하는 것은 아니므로, 원인을 구분해 봐야 합니다.

8. 절전·최대 절전·종료는 무엇이 다른가요?

기능일반적인 목적특징
디스플레이 끄기모니터만 꺼 두기PC 작업이 계속 실행될 수 있음
절전사용 중이던 작업을 빠르게 이어서 하기소비전력 감소, 앱 실행 상태 보존에 초점
최대 절전장시간 사용하지 않으면서 세션을 보존지원되는 기기에서 디스크 기반으로 작업 상태 보존
종료PC 사용을 끝내고 전원 끄기실행 중이던 앱과 작업 세션이 종료될 수 있음
재시작업데이트·오류 해결을 위한 재부팅다시 켜서 운영체제 실행

대용량 파일 다운로드나 영상 렌더링이 끝나기를 기다리는 상황이라면 컴퓨터가 먼저 절전 상태로 들어가 작업이 멈추지 않는지도 확인해야 합니다.

다만 무조건 절전을 해제한 채 컴퓨터를 밤새 켜 두는 방식은 전력 소비·발열·장비 상태를 고려해야 합니다. 컴퓨터나 프로그램 자체에 작업 완료 후 종료 옵션이 있다면 그 기능을 우선 검토할 수도 있습니다.

9. 데이터 손실을 막는 5가지 체크리스트

자동 종료는 편리하지만 다음 상황에서는 신중해야 합니다.

  1. 열린 문서 저장: Excel, Word, 그림 편집 프로그램, 영상 프로젝트 등
  2. 작업 완료 예상 시간 확인: 다운로드·백업·파일 복사가 남아 있는지
  3. 외장 저장장치 작업 종료: 쓰기 작업 중 자동 종료 방지
  4. 다른 사용자 확인: 가족이나 직장 동료가 동일 PC를 사용 중인지
  5. 취소 방법 확보: 일회성 예약은 shutdown /a, 반복 예약은 작업 스케줄러에서 중지

특히 명령어에 /t 3600처럼 양수 대기 시간을 지정하면 /f가 암묵적으로 포함될 수 있다는 Microsoft 설명은 놓치기 쉽습니다.

자동 종료는 작업이 끝났다는 사실을 확인해 주는 기능이 아닙니다. 지정한 시간에 종료를 시도할 뿐입니다.

10. 자주 묻는 질문

Q. 1시간 뒤 자동 종료는 어떤 명령인가요?

shutdown /s /t 3600

명령 실행 시점부터 3,600초 후 종료를 예약합니다. 다만 저장하지 않은 파일의 손실 가능성을 확인한 후 사용하세요.

Q. 예약을 취소하려면 어떻게 하나요?

shutdown /a

대기 중인 종료가 실행되기 전에 입력하세요. 작업 스케줄러에 등록된 미래의 반복 예약은 별도로 비활성화·삭제해야 합니다.

Q. 2시간 뒤 종료하려면 숫자만 바꾸면 되나요?

네. 2시간은 7,200초이므로 shutdown /s /t 7200을 사용합니다. 단, 컴퓨터가 여전히 켜져 있고 예약 명령을 정상적으로 받아들였다는 전제가 있습니다.

Q. 컴퓨터 자동 종료 시간이 지난 뒤에도 꺼지지 않습니다.

명령이 제대로 실행됐는지, 예약 취소 여부, PC 상태, 작업 스케줄러의 조건과 기록을 확인하세요. 특히 절전 상태·전원 설정·조직 관리 정책이 영향을 줄 수 있습니다.

Q. 매일 특정 시각에 종료하려면 명령을 매번 입력해야 하나요?

아닙니다. 작업 스케줄러의 '매일' 트리거를 이용하면 반복 예약을 설정할 수 있습니다.

Q. shutdown /s /t 0도 취소할 수 있나요?

대기 시간이 없으므로 취소할 여유가 없습니다. 취소 시험용으로 사용하지 마세요.

Q. 컴퓨터를 종료하면 다운로드가 끝까지 완료되나요?

아닙니다. 종료 시각까지 다운로드가 끝나지 않았다면 중단될 수 있습니다. 다운로드 프로그램의 종료 후 동작 설정이 있다면 작업 완료 조건을 지원하는지 확인하세요.

Q. 자동 종료와 화면 자동 꺼짐은 같은가요?

아닙니다. 화면만 꺼지는 것과 운영체제를 종료하는 것은 전혀 다른 동작입니다. 사용 목적에 맞춰 별도로 설정하세요.

11. 마무리: 목적에 따라 명령을 선택하세요

한 번만 1시간 뒤 종료하고 싶다면 shutdown /s /t 3600, 취소하려면 shutdown /a, 매일 같은 시각에 종료하고 싶다면 Windows 작업 스케줄러를 사용합니다.

가장 중요한 점은 양수 /t 값이 /f를 암묵적으로 적용할 수 있다는 Microsoft의 공식 설명입니다. 따라서 영상 편집·문서 작성·백업 중인 PC에서는 종료 예약보다 작업 저장과 완료 여부 확인을 우선해야 합니다.

자주 묻는 질문 (FAQ)

윈도우11에서 자동 종료 예약을 어떻게 하나요?

Windows + R 실행창이나 명령 프롬프트에서 shutdown /s /t [초] 명령어를 입력하면 지정한 시간(초) 후에 자동 종료가 예약됩니다.

자동 종료 예약을 취소하려면 어떻게 해야 하나요?

shutdown /a 명령어를 실행하면 대기 중인 종료 예약을 취소할 수 있으나, 이미 종료가 진행 중이거나 예약이 없으면 취소가 불가능합니다.

작업 스케줄러로 매일 같은 시간에 자동 종료하려면 어떻게 설정하나요?

작업 스케줄러에서 기본 작업 만들기를 선택해 매일 반복 트리거와 shutdown.exe /s /t 0 명령어를 입력하면 매일 지정한 시각에 자동 종료가 실행됩니다.
