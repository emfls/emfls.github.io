2. 아이폰 기본 화면 녹화 방법: 3초 카운트다운부터

Apple은 제어 센터의 '화면 기록' 버튼으로 화면을 비디오로 저장하는 방법을 공식 안내합니다.

Face ID가 있는 아이폰에서

  1. 화면 오른쪽 위 모서리에서 아래로 쓸어내려 제어 센터를 엽니다.
  2. 동그라미 안에 작은 원이 있는 화면 기록 버튼을 찾습니다.
  3. 버튼을 한 번 탭합니다.
  4. 3초 카운트다운이 끝날 때까지 기다립니다.
  5. 제어 센터를 닫고 기록하려는 화면을 조작합니다.
  6. 화면 상단의 기록 표시를 누르거나 제어 센터의 빨간 기록 버튼을 눌러 녹화를 마칩니다.

홈 버튼이 있는 구형 아이폰에서

모델에 따라 화면 아래쪽 가장자리에서 위로 쓸어올려 제어 센터를 엽니다. 이후 화면 기록 버튼을 사용하는 방식은 같습니다.

중요: 화면 기록 버튼을 탭한 직후부터 곧바로 기록이 시작되는 것이 아닙니다. 3초 카운트다운 뒤 화면 기록이 시작됩니다.

3. '화면 기록' 버튼이 제어 센터에 없을 때

Apple의 최신 iPhone 사용 설명서는 제어 센터 제어 항목을 추가·재정렬·제거할 수 있다고 안내합니다.

버튼 추가하기

  1. 제어 센터를 엽니다.
  2. 화면의 추가(+) 버튼을 눌러 제어 항목 편집을 시작합니다.
  3. '제어 항목 추가'를 선택합니다.
  4. 항목 목록에서 '화면 기록'을 찾아 선택합니다.
  5. 기록 버튼을 원하는 위치로 배치합니다.
  6. 편집을 마친 다음 기록 버튼을 탭해 3초 카운트다운이 시작되는지 확인합니다.

제어 센터에 여러 페이지·그룹이 있다면 버튼이 다른 그룹에 이미 추가된 상태인지도 살펴보세요.

메뉴 차이 주의: 오래된 iOS 안내에는 설정 → 제어 센터에서 제어 항목을 추가하는 방법이 나올 수 있습니다. 최신 iOS는 제어 센터 안에서 직접 편집하는 흐름을 공식 설명하므로, 내 기기 화면을 기준으로 확인하세요.

4. 아이폰 화면 녹화에 내 목소리를 넣는 방법

화면 영상과 함께 본인이 설명하는 목소리나 주변 소리를 기록하고 싶다면 화면 녹화 시작 전에 마이크를 켜야 합니다.

Apple 공식 설정 순서

  1. 제어 센터를 엽니다.
  2. 화면 기록 버튼을 길게 누릅니다.
  3. 녹화 옵션 화면에서 마이크 버튼을 찾습니다.
  4. 마이크를 켬 상태로 설정합니다.
  5. '기록 시작'을 누릅니다.
  6. 3초 카운트다운 후 설명하면서 화면을 조작합니다.
  7. 종료 후 사진 앱에서 영상을 열어 본인의 목소리가 담겼는지 확인합니다.

5. 아이폰 화면 녹화 소리 안 남: 무엇부터 확인할까?

'녹화 소리가 없다'는 말에는 크게 세 가지 상황이 있습니다.

  • 내 목소리가 없음: 마이크가 꺼져 있었을 가능성을 먼저 확인
  • 앱 소리가 없음: 앱의 기록 허용 여부, 소리·재생 상태 확인
  • 녹화는 정상인데 재생할 때 들리지 않음: 재생 음량·블루투스 출력 장치 확인

가장 쉬운 원인 분리 테스트

  1. 조용한 장소에서 화면 기록 버튼을 길게 눌러 마이크를 켭니다.
  2. 메모 앱 등 일반 화면을 열고 5~10초 정도 설명하며 녹화합니다.
  3. 화면 기록을 종료한 뒤 사진 앱에서 재생합니다.
  4. 녹화 영상에 설명한 목소리가 들리는지 확인합니다.
  5. 다음으로 문제가 발생한 앱에서 같은 방법으로 녹화해 결과를 비교합니다.
비교 결과해석
일반 화면에서는 목소리가 녹음됨기본 마이크·화면 기록 기능이 동작할 가능성
특정 앱에서만 소리가 없음앱별 오디오 기록 제한 가능성
모든 녹화에서 목소리가 없음마이크 설정·실제 마이크 상태 점검 필요
사진 앱 재생에서만 소리가 안 들림재생 음량·오디오 출력 장치 확인

기본 마이크가 고장 났다고 단정하지 마세요. 다른 앱의 오디오 기록 시험과 통화·음성 메모 등의 결과를 비교한 뒤 공식 지원을 이용하는 것이 맞습니다.

6. 화면은 찍혔는데 넷플릭스·영상 앱은 검은 화면으로 녹화됐다면

Apple은 공식 화면 기록 문서에서 일부 앱은 오디오 또는 비디오 콘텐츠 기록을 허용하지 않을 수 있다고 명시합니다.

따라서 특정 동영상 서비스·유료 콘텐츠 앱에서 영상만 검게 기록되거나 소리가 누락됐다고 해서 아이폰 화면 기록 기능 자체가 고장 난 것은 아닐 수 있습니다.

구별 방법

  1. Safari의 일반 페이지 또는 설정 화면을 짧게 녹화합니다.
  2. 해당 일반 화면은 정상 녹화되는지 확인합니다.
  3. 문제가 된 영상 앱의 목록·메뉴 화면은 기록되는지 비교합니다.
  4. 앱의 특정 콘텐츠 재생 화면에서만 검게 저장된다면 해당 앱의 콘텐츠 기록 제한 가능성을 확인합니다.

주의: 콘텐츠 보호 제한을 우회하는 출처 불명의 녹화 앱·브라우저 확장 프로그램을 설치할 필요는 없습니다. 영상·오디오 기록 가능 여부는 이용 중인 앱의 정책과 콘텐츠 보호 설정을 따라야 합니다.

7. 화면 녹화는 어디에 저장되나요?

Apple의 iPhone 사용 설명서에 따르면 기본 화면 기록은 사진 보관함에 자동 저장됩니다.

사진 앱에서 찾는 방법

  1. 사진 앱을 엽니다.
  2. 모음을 누릅니다.
  3. 아래로 스크롤해 미디어 유형 영역을 찾습니다.
  4. '화면 기록'을 선택합니다.
  5. 저장된 화면 녹화 동영상을 열어 확인합니다.

아이폰의 사진 앱 구성은 iOS 버전에 따라 다를 수 있습니다. 최신 Apple 사용 설명서에서는 사진 → 모음 → 미디어 유형 → 화면 기록 경로를 안내합니다.

화면 녹화는 기본적으로 파일 앱의 다운로드 폴더에 자동 저장된다고 단정해서는 안 됩니다. 나중에 다른 앱으로 공유하거나 파일 앱에 별도로 내보낼 수는 있지만, 기본 저장 위치는 사진 보관함입니다.

8. 녹화가 끝났는데 영상이 안 보일 때

화면 녹화를 마친 직후 보관함에서 파일이 보이지 않는다면 다음 순서로 확인하세요.

  1. 사진 앱의 모음 → 미디어 유형 → 화면 기록에서 확인합니다.
  2. 녹화 도중 상단 기록 표시 또는 제어 센터의 버튼을 통해 정상 종료했는지 떠올려봅니다.
  3. 시험용으로 5초짜리 일반 화면 녹화를 새로 수행합니다.
  4. 시험 파일은 보이는지, 문제 상황에서만 저장되지 않았는지 비교합니다.
  5. 설정 → 일반 → iPhone 저장 공간에서 저장 공간이 매우 부족한지 확인합니다.
  6. 문제가 반복되면 정상 재시동 후 동일한 시험을 진행합니다.

해석 주의: 저장 공간이 부족할 경우 영상 저장에 영향을 줄 수 있지만, '파일이 보이지 않는다'는 사실만으로 저장 공간 부족을 원인으로 확정할 수는 없습니다.

중요한 파일 보호: 저장 공간을 확보하려고 동영상을 무작정 삭제하지 마세요. iCloud 사진을 사용하면 동기화된 기기에서도 삭제가 반영될 수 있습니다.

10. 화면 녹화 중 화면 미러링이 안 되는 이유

Apple은 화면 기록과 화면 미러링을 동시에 수행할 수 없다고 안내합니다.

따라서 TV·모니터로 화면을 전송하는 화면 미러링이 진행 중이라면, 기본 화면 기록이 정상적으로 시작되지 않거나 반대로 미러링을 진행하지 못할 수 있습니다.

확인 순서

  1. 제어 센터의 화면 미러링 사용 여부를 확인합니다.
  2. 화면 미러링이 켜져 있다면 연결을 종료합니다.
  3. 기기 화면에서 화면 기록을 시작합니다.
  4. 정상적으로 기록된다면 기능의 동시 사용 제한을 원인 후보로 판단할 수 있습니다.

주의: 화면 미러링을 끄면 TV·외부 화면과의 연결이 중단됩니다. 사용 목적에 맞게 화면 기록과 미러링 중 하나를 선택하세요.

11. 영상 앞뒤 자르기: 사진 앱에서 녹화 길이 다듬기

주의: 영상의 길이를 자르는 기능이 녹화되지 않았던 소리를 복구하는 기능은 아닙니다. 원래 파일에 소리가 없다면 오디오 녹음 단계부터 다시 점검해야 합니다.

12. 화면 녹화에서 개인정보가 노출되지 않게 하려면

화면 기록에는 녹화 중 표시된 화면 내용이 포함될 수 있습니다. 다른 사람에게 공유할 예정이라면 녹화 자체보다 무엇이 화면에 나오는지가 더 중요합니다.

녹화 전 다음을 확인하세요.

  • 화면 상단 알림에 문자·메신저 내용이나 인증번호가 나타나지 않도록 준비합니다.
  • 녹화 과정에서 은행 계좌정보·주소·이메일·전화번호를 불필요하게 열지 않습니다.
  • 비밀번호 입력·보안코드 확인 과정은 화면 녹화로 보여주지 않는 것이 안전합니다.
  • 업무용 계정이나 다른 사람의 대화 내용을 공유하기 전 동의 및 내부 규정을 확인합니다.
  • 외부 공개 전에 사진 앱에서 녹화 영상을 처음부터 끝까지 재생해 민감정보가 있는지 검토합니다.

예시: 앱 사용법을 설명하는 영상이라면 실제 개인정보 대신 테스트용 데이터·빈 화면을 준비한 뒤 녹화하는 편이 좋습니다.

단순히 영상을 잘라낸 것만으로 화면에 노출된 모든 개인정보가 제거되는 것은 아닙니다. 공유 전 반드시 결과물을 확인하세요.

13. 화면 녹화 버튼은 있지만 녹화가 시작되지 않을 때

Apple 공식 문서로 확인할 수 있는 기본 기능을 먼저 시험하세요.

  1. 화면 기록 버튼 → 3초 카운트다운이 표시되는지 확인합니다.
  2. 화면 미러링 중이라면 종료한 뒤 재시험합니다.
  3. 녹화하려는 앱을 벗어나 일반 설정 화면에서 짧게 시험합니다.
  4. 저장 공간이 매우 부족한 상태인지 확인합니다.
  5. 정상 재시동 후 다시 시도합니다.
  6. 필요한 경우 설정 → 일반 → 소프트웨어 업데이트에서 공식 업데이트 여부를 확인합니다.

모든 화면에서 시작되지 않는다면 특정 앱의 콘텐츠 기록 제한과 구별해야 합니다. 반대로 일반 화면은 정상 녹화되는데 하나의 동영상 앱에서만 녹화가 실패한다면 해당 앱의 제한일 수 있습니다.

하지 말아야 할 일: 문제를 해결하려고 기기를 곧바로 공장 초기화하거나, 다른 사람의 계정으로 로그인하거나, 검증되지 않은 화면 녹화 도구를 설치하지 마세요.

14. 5분 테스트: 마이크·앱 소리·저장 위치를 따로 확인

하나의 긴 동영상을 녹화하기보다 짧은 시험 파일을 만들면 문제를 더 쉽게 분리할 수 있습니다.

순서테스트판단 기준
1화면 기록 버튼을 눌러 3초 카운트다운 확인녹화 시작 기능
2일반 메모 화면을 5초간 녹화화면이 기록되는지
3사진 앱 → 모음 → 화면 기록 확인파일 저장 위치
4마이크를 켜고 짧게 설명하면서 녹화본인 목소리 기록 여부
5문제 앱에서 동일 방식으로 비교앱별 영상·음성 기록 제한
6필요 시 영상 시작과 끝 다듬기편집·저장 동작

결과 예시: 일반 메모 화면과 본인 목소리는 정상 녹화되는데 특정 앱 영상이 검게 나온다면, 기본 화면 기록 기능의 고장보다 해당 앱의 기록 제한 가능성을 살펴볼 이유가 있습니다.

이 시험에서 검은 화면이 나온다고 곧바로 카메라 고장으로 연결해서는 안 됩니다. 화면 기록 기능과 카메라 촬영 기능은 다른 기능입니다.

15. 자주 묻는 질문(FAQ)

Q1. 아이폰 화면 녹화는 어디서 하나요?

제어 센터 → 화면 기록 버튼 → 3초 카운트다운 순서입니다. 녹화한 동영상은 기본적으로 사진 앱에 저장됩니다.

Q2. 화면 녹화 버튼이 없어요. 어떻게 추가하나요?

제어 센터의 편집 → 제어 항목 추가 → 화면 기록에서 추가하세요. 다른 제어 항목 그룹에 이미 배치됐는지도 확인하세요.

Q3. 아이폰 화면 녹화할 때 내 목소리를 넣으려면?

화면 기록 버튼을 길게 누른 뒤 '마이크'를 켜고 '기록 시작'을 선택하세요. 녹화 후 사진 앱에서 음성이 들어갔는지 확인합니다.

Q4. 아이폰 화면 녹화 소리가 안 나요.

내 목소리인지, 앱 자체 소리인지, 저장한 영상을 재생할 때의 소리인지 먼저 구분하세요. 일부 앱은 영상·음성 기록을 허용하지 않을 수 있습니다.

Q5. 넷플릭스 등에서 녹화하면 검은 화면이 나옵니다.

Apple은 일부 앱에서 콘텐츠 기록을 제한할 수 있다고 명시합니다. 일반 화면이 녹화되는지 비교하고 앱의 콘텐츠 보호 정책을 확인하세요.

Q6. 녹화한 화면 기록 파일이 사진 앱에 없어요.

최신 iPhone 사용 설명서 기준 사진 → 모음 → 미디어 유형 → 화면 기록을 확인하세요. 새 시험용 녹화를 만들어 정상 저장되는지 비교하세요.

Q7. 녹화 중지 버튼은 어디에 있나요?

상단의 빨간 기록 표시를 눌러 중단하거나, 제어 센터의 빨간 화면 기록 버튼을 누르세요. Dynamic Island 지원 여부에 따라 표시 위치가 다릅니다.

Q8. 화면 녹화와 TV 화면 미러링을 동시에 할 수 있나요?

Apple 공식 안내는 화면 기록과 화면 미러링을 동시에 사용할 수 없다고 명시합니다. 화면 미러링을 종료하고 기록을 시험하세요.

Q9. 녹화한 영상의 앞뒤를 자를 수 있나요?

가능합니다. 사진 앱 → 동영상 선택 → 편집 → 타임라인 양끝 조절 → 완료 순서입니다. 원본을 보존하려면 새로운 클립으로 저장하는 옵션을 확인하세요.

Q10. 아이폰 화면 녹화를 위해 유료 앱을 설치해야 하나요?

일반적인 화면 기록 목적이라면 Apple 기본 화면 기록 기능이 제공됩니다. 다만 특정 앱의 콘텐츠 기록 제한까지 해제해 주는 것은 아닙니다.

Q11. 아이폰 화면 녹화로 전화 통화를 녹음할 수 있나요?

일반 화면 기록이 통화 오디오까지 녹음할 수 있다고 가정해서는 안 됩니다. 통화 기록 기능은 별도로 지원·지역·상대방 알림 조건이 다를 수 있습니다. 화면 기록 문서가 통화 녹음을 보장하는 것은 아닙니다.

Q12. 화면 녹화 오류 때문에 초기화해도 되나요?

공장 초기화는 첫 단계가 아닙니다. 버튼 추가, 앱별 제한 여부, 마이크, 사진 앱 저장 위치, 화면 미러링 사용 여부를 먼저 확인하세요.

결론

아이폰 화면을 동영상으로 저장하려면 제어 센터의 '화면 기록' 버튼을 누른 후 3초 기다리면 됩니다. 본인 목소리를 녹음하려면 버튼을 길게 눌러 마이크를 켜고, 완성된 파일은 사진 앱 → 모음 → 미디어 유형 → 화면 기록에서 찾으세요.

특정 앱에서만 검은 화면이나 소리 누락이 발생한다면 일부 앱이 콘텐츠 기록을 제한할 수 있다는 Apple 공식 안내를 확인하세요. 녹화한 파일을 공유하기 전에는 개인 정보가 노출되지 않았는지 검토하는 것이 좋습니다.
