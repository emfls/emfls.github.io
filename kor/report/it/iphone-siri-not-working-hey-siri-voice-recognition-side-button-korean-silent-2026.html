아이폰에서 “Siri야”라고 불러도 반응하지 않거나, 측면 버튼을 길게 눌러도 Siri가 나타나지 않는 경우가 있습니다. Siri 화면은 나타나는데 말을 알아듣지 못하거나 소리 대신 글자만 표시되는 문제도 발생합니다.

이때 모든 증상을 '마이크 고장'으로 판단하는 것은 정확하지 않습니다. 인터넷 연결, Siri 활성화, 목소리 재인식, 버튼 설정, 음성 응답, 스크린 타임 제한을 구분해서 확인해야 합니다.

이 글은 2026년 11월 4일 기준 Apple의 최신 Siri 문제 해결 문서와 iPhone 사용 설명서를 토대로 작성했습니다. 2026년에는 iOS 버전과 Siri 버전에 따라 설정 메뉴가 달라졌기 때문에 예전의 'Siri 및 검색' 경로만 찾지 않아도 되도록 최신·구버전 메뉴를 함께 설명합니다.

가장 빠른 해결 순서: 인터넷 연결 확인 → 설정 → Siri(또는 Apple Intelligence 및 Siri)에서 활성화 확인 → “Siri” 또는 “Siri야” 듣기 옵션을 껐다 다시 켜 목소리 재등록 → 측면 버튼으로 테스트 → 소리 설정 확인.

2. 인터넷부터 확인해야 하는 이유

Apple은 Siri를 사용하려면 인터넷 연결이 필요하다고 안내합니다. 기기가 오프라인이면 Siri가 보통 “연결에 문제가 있습니다”라고 응답할 수 있습니다.

다음 순서대로 확인해 보세요.

  1. 아이폰에서 설정 → Wi-Fi를 열어 연결 상태를 확인합니다.
  2. Wi-Fi가 연결돼 있어도 실제 인터넷이 되는지 Safari에서 일반 웹사이트를 열어 봅니다.
  3. Wi-Fi에 문제가 있다면 모바일 데이터로 전환해 테스트합니다. 요금제와 데이터 사용 가능 상태를 확인하세요.
  4. 비행기 모드가 켜져 있지 않은지 확인합니다.
  5. 회사·학교 Wi-Fi라면 네트워크 정책이 서비스 접속을 제한하는지 확인합니다.
  6. 인터넷이 정상인 상태에서 다시 “Siri야, 지금 몇 시야?”라고 말해 봅니다.

웹사이트도 안 열리면?

Siri만의 문제가 아니라 인터넷 연결 문제일 수 있습니다. Wi-Fi 공유기나 이동통신 네트워크 상태를 먼저 해결해야 합니다.

웹사이트는 열리는데 Siri만 연결 오류가 난다면?

인터넷이 완전히 끊긴 것은 아닐 수 있습니다. 아이폰 재시동, Siri 설정, 소프트웨어 버전을 확인하고, 기기에서 사용 중인 VPN 또는 관리 프로필 여부를 살펴보세요.

주의: 일반적인 Siri 오류 때문에 곧바로 네트워크 설정 재설정이나 기기 초기화를 수행하지 마세요. Wi-Fi 정보·VPN 구성 등 다른 설정에도 영향을 줄 수 있으므로 초기화는 마지막에 검토합니다.

3. 2026년 아이폰에서 Siri 켜는 방법

Siri의 설정 경로는 iOS 버전별로 다를 수 있습니다.

최신 iOS 27에서 Siri 켜기

  1. 설정 앱을 엽니다.
  2. Siri를 선택합니다.
  3. Siri가 꺼져 있다면 Siri 켜기를 누릅니다.
  4. 화면에 표시되는 설정 절차를 완료합니다.
  5. “Siri야” 또는 지원되는 호출 방법으로 요청해 봅니다.

Apple의 iOS 27 사용 설명서는 Siri를 처음 켤 때 설정 → Siri → Siri 켜기 경로를 안내합니다.

iOS 26 등 다른 버전에서는?

  • 설정 → Siri
  • 설정 → Apple Intelligence 및 Siri
  • 버전과 기기에 따라 Siri에게 말하기, Siri와 대화 및 입력, 요청 등

이름이 서로 다르게 표시될 수 있습니다. 검색 결과에서 오래된 경로를 따라가다가 메뉴가 보이지 않으면 설정 앱의 검색창에 'Siri'를 입력해 찾아보세요.

Siri AI(베타)와 기본 Siri는 구별하세요

2026년 iOS 27부터는 일부 지원 기기·언어·지역에서 새로운 Siri AI(베타)가 제공됩니다. 그러나 모든 아이폰이 같은 Siri 버전을 사용하는 것은 아니며, Apple Intelligence 지원 여부와 Siri 활성화는 별개의 조건입니다.

Siri AI가 지원되지 않는 구형 기기라도 해당 모델이 지원하는 기본 Siri는 사용할 수 있습니다. 따라서 최신 Siri AI 메뉴가 없다는 사실만으로 일반 Siri까지 고장났다고 판단해서는 안 됩니다.

4. “Siri야”에 반응하지 않을 때 목소리 다시 등록하기

Apple 공식 지원 문서가 직접 안내하는 핵심 조치입니다. Siri가 켜져 있어도 음성 호출 설정을 껐다 켜면서 목소리를 다시 인식시키는 절차가 도움이 될 수 있습니다.

  1. 설정 → Siri로 이동합니다. 일부 버전에서는 Apple Intelligence 및 Siri입니다.
  2. 요청, Siri에게 말하기, 또는 Siri와 대화 및 입력과 같은 항목을 엽니다.
  3. “Siri” 또는 “Siri야” 듣기가 켜져 있는지 확인합니다.
  4. 이미 켜져 있다면 한 번 끔으로 바꿉니다.
  5. 다시 “Siri” 또는 “Siri야” 사용 옵션을 켭니다.
  6. 음성 설정 화면이 나타나면 계속을 누릅니다.
  7. 화면에 표시된 문장들을 실제 목소리로 읽습니다.
  8. 완료를 누르고 잠시 뒤 “Siri야, 지금 몇 시야?”로 테스트합니다.

중요: 'Siri야'와 짧은 호출어 'Siri'는 지원 범위가 완전히 같지 않습니다. Apple은 'Siri'만 말하는 옵션이 일부 언어·지역·기기 모델에서만 가능하다고 설명합니다. 따라서 짧은 호출어를 못 알아듣는다고 바로 고장으로 판단하지 말고 'Siri야'로 먼저 테스트하세요.

재등록 시 도움이 되는 점검

  • 조용한 장소에서 진행합니다.
  • 입과 마이크 사이를 케이스나 손으로 가리지 않습니다.
  • 음성 입력 화면에 안내된 문장을 끝까지 읽습니다.
  • 재설정 후에는 Siri 호출과 측면 버튼 호출을 따로 테스트합니다.

공식 출처: Apple — Siri 음성 인식 재설정 절차, Apple — Siri 호출 방법 사용자화

5. 측면 버튼을 눌러도 Siri가 안 나올 때

'Siri야' 호출이 안 되는 경우와 버튼으로도 Siri가 실행되지 않는 경우는 원인이 다를 수 있습니다.

먼저 측면 버튼 호출 확인

  1. 설정 → Siri 또는 Apple Intelligence 및 Siri를 엽니다.
  2. 요청이나 음성·버튼 활성화 설정을 확인합니다.
  3. 측면 버튼 눌러서 Siri 사용 기능이 있는지 확인하고 활성화합니다.
  4. Face ID 지원 아이폰에서는 측면 버튼을 길게 눌러 Siri가 나타나는지 테스트합니다.
  5. 홈 버튼이 있는 지원 기기는 홈 버튼을 길게 눌러 호출할 수 있습니다.

손쉬운 사용에서 버튼 동작을 변경했는지 확인

버튼을 길게 눌러도 아무 반응이 없다면 Apple은 손쉬운 사용 → 측면 버튼(또는 홈 버튼) → 길게 눌러서 말하기에서 반응할 기능을 선택할 수 있다고 안내합니다.

  1. 설정 → 손쉬운 사용으로 이동합니다.
  2. 기기에 따라 측면 버튼 또는 홈 버튼을 엽니다.
  3. 길게 눌러서 말하기 설정을 확인합니다.
  4. Siri로 지정할 수 있는 경우 원하는 동작을 선택합니다.
  5. 버튼을 길게 눌러 테스트합니다.

해석: 음성 호출만 실패하고 버튼 호출은 성공한다면 음성 인식·마이크·호출어 설정을 우선 살펴봅니다. 버튼과 음성 모두 실패한다면 Siri 활성화와 인터넷 연결·시스템 제한 설정을 함께 확인해야 합니다.

공식 출처: Apple — Siri를 버튼으로 활성화, Apple — 측면·홈 버튼 설정 조절

6. Siri 화면은 뜨는데 말이 안 들리거나 대답이 없을 때

Siri가 작동은 하지만 음성으로 대답하지 않고 화면에 글자만 표시할 수 있습니다. 이 경우 통신 장애나 마이크 고장이 아니라 응답 방식 설정 때문일 수 있습니다.

Siri가 말하도록 설정하기

  1. 설정 → Siri 또는 Apple Intelligence 및 Siri를 엽니다.
  2. 응답을 선택합니다.
  3. 음성 응답 선호 또는 음성 입력에 음성으로 응답을 선택합니다.
  4. Siri AI가 켜져 있다면 음성 응답 관련 선택지를 확인합니다.
  5. Siri에게 간단한 질문을 해 실제 소리를 확인합니다.

Apple 공식 지원은 Siri가 소리 내어 답하도록 하려면 '음성 응답 선호'를 선택하라고 설명합니다.

무음 모드와 호출 방법도 확인하세요

Apple의 Siri 사용 설명서에서는 버튼으로 Siri를 활성화했을 때 아이폰이 무음 모드라면 소리 없이 반응할 수 있다고 안내합니다. 반면 음성으로 Siri를 호출하면 음성으로 응답하는 동작이 제공됩니다. 실제 동작은 현재 응답 설정과 Siri 버전에 따라 달라질 수 있습니다.

따라서 볼륨만 반복해서 조정하기보다 Siri 응답 설정과 무음 모드, 호출 방식을 먼저 비교하세요.

7. “Siri야”는 안 되는데 버튼 호출은 된다면: 마이크 검사

버튼으로 Siri를 호출하면 화면은 나타나는데 목소리로는 Siri가 실행되지 않거나 말이 잘 인식되지 않는 경우, 하드웨어 마이크 상태를 확인해 볼 수 있습니다.

단, 이것만으로 마이크 고장을 확정할 수는 없습니다. Siri 호출 설정 오류·주변 소음·케이스 간섭도 가능한 원인이기 때문입니다.

Apple 공식 마이크 테스트 A: 음성 메모

  1. 아이폰의 음성 메모 앱을 엽니다.
  2. 녹음을 시작합니다.
  3. 휴대폰 하단에 대고 짧게 말합니다.
  4. 녹음을 중지합니다.
  5. 재생하여 본인의 목소리가 명확하게 들리는지 확인합니다.

Apple 공식 마이크 테스트 B: 카메라 동영상

  1. 카메라 앱을 실행합니다.
  2. iPhone 상단을 향해 말하면서 짧은 영상을 촬영합니다.
  3. 전면·후면 카메라를 전환해 다시 촬영합니다.
  4. 두 영상을 재생해 음성이 명확하게 들리는지 확인합니다.

마이크가 잘 안 들리면?

  • 케이스·보호필름이 마이크를 가리지 않는지 확인합니다.
  • 마이크 개방부에 이물질이 없는지 살펴봅니다.
  • 부품 손상을 유발할 수 있는 날카로운 도구를 삽입하지 마세요.
  • 음성 메모·영상 녹화·통화에서도 문제가 지속되면 Apple 지원 또는 공인 서비스 제공업체를 통해 점검을 검토합니다.

구분: 음성 메모 녹음은 정상인데 'Siri야' 호출만 실패한다면 Siri 음성 호출 옵션 재설정부터 다시 확인하는 것이 합리적입니다.

8. Siri 한국어 설정이 잘못됐을 때

Siri가 영어 등 다른 언어로 설정돼 있다면 한국어로 요청할 때 인식 결과가 달라질 수 있습니다.

Siri 언어 확인 순서

  1. 설정 → Siri를 엽니다.
  2. 언어를 선택합니다.
  3. 현재 선택된 언어를 확인합니다.
  4. 한국어로 Siri를 사용하려면 한국어가 지원 목록에 있는지 확인하고 선택합니다.
  5. 다시 “Siri야, 오늘 날짜 알려줘”라고 말해 봅니다.

Apple은 Siri 언어 설정이 지도, 턴 바이 턴 안내, Safari의 페이지 듣기 등 관련 기능에도 사용될 수 있다고 설명합니다.

Siri 목소리를 바꾸고 싶다면?

설정의 Siri → 음성에서 지원되는 음성·방언 옵션을 확인합니다. 단, 목소리 종류와 음성 인식 언어는 서로 다른 개념입니다. 단지 Siri의 소리가 마음에 들지 않는다는 이유로 언어까지 바꿀 필요는 없습니다.

“Siri”만 부르는 호출어가 한국어에서도 되나요?

Apple은 'Siri' 단독 호출이 일부 언어와 지역에서만 지원된다고 안내합니다. 한국어 환경에서 원하는 선택지가 보이지 않는다면 지원 범위 차이일 수 있습니다. 가장 먼저 'Siri야' 호출을 테스트하세요.

9. 잠금 화면에서만 Siri가 작동하지 않을 때

아이폰 잠금을 해제한 상태에서는 Siri가 되는데 잠금 화면에서는 불러도 동작하지 않는다면, 잠금 상태에서 Siri 접근을 허용했는지 확인해야 합니다.

  1. 설정을 엽니다.
  2. Face ID 지원 모델은 Face ID 및 암호, Touch ID 지원 모델은 Touch ID 및 암호를 선택합니다.
  3. 휴대폰 암호를 입력합니다.
  4. 잠겨 있는 동안 접근 허용 항목을 찾습니다.
  5. Siri가 항목으로 제공되는 경우 허용 상태인지 확인합니다.
  6. 잠금 화면에서 “Siri야” 또는 버튼 호출을 다시 시험합니다.

보안 관련 주의: 잠금 화면에서 Siri 사용을 허용하면 일부 기능을 잠금을 풀지 않고 실행할 수 있습니다. 누구나 쉽게 접근할 수 있는 공용 공간에서 쓰는 기기라면 편의성과 개인정보 보호를 함께 고려하세요.

기기의 Siri 버전과 iOS 버전에 따라 제한 화면이 달라질 수 있으므로 실제 표시되는 메뉴를 기준으로 확인하세요.

가장 먼저 간단한 명령으로 테스트

  • “지금 몇 시야?”
  • “타이머 1분 설정해 줘.”
  • “오늘 날짜 알려줘.”
  • “손전등 켜 줘.”

이런 기본 요청은 Apple의 Siri 사용 설명서에 소개된 형태입니다.

기본 명령은 되는데 특정 앱에서만 실패한다면?

  • 요청을 실행할 앱이 설치돼 있는지 확인합니다.
  • Siri의 언어·지역·버전에서 해당 기능이 지원되는지 확인합니다.
  • 해당 작업에 필요한 앱 권한이나 계정 로그인이 정상인지 확인합니다.
  • 특정 명령이 실제로 그 앱에서 지원되는지 확인합니다.
  • 앱을 업데이트한 뒤 다시 시도합니다.

예를 들어 Siri 자체는 작동하지만 다른 서비스의 앱에서 작업을 완료하지 못한다면 Siri 음성 재등록보다는 그 앱과 작업 지원 여부를 확인하는 것이 맞습니다.

16. 초기화와 수리 전에 확인할 10분 진단 순서

문제가 여전히 해결되지 않았다면 순서를 지키는 것이 중요합니다.

1단계: 인터넷

Wi-Fi·모바일 데이터에서 Safari 웹사이트가 정상적으로 열리는지 확인합니다.

2단계: Siri 활성화

설정에서 Siri가 켜져 있는지 확인합니다.

3단계: “Siri야” 재인식

음성 호출 설정을 껐다 다시 켜고 안내된 문장을 읽습니다.

4단계: 측면 버튼

측면 버튼 또는 홈 버튼을 길게 눌러 Siri가 실행되는지 확인합니다.

5단계: 음성 응답

Siri의 응답 → 음성 응답 선호를 확인합니다.

6단계: 마이크

음성 메모·카메라 동영상으로 목소리가 또렷하게 녹음되는지 확인합니다.

7단계: Siri 언어

설정된 언어가 실제 사용하는 언어와 일치하는지 확인합니다.

8단계: 잠금 화면·스크린 타임

잠금 상태 접근과 보호자·조직의 사용 제한 여부를 확인합니다.

9단계: 소프트웨어와 VPN

아이폰을 재시동하고 지원 iOS 버전, VPN·관리 프로필을 확인합니다.

10단계: Apple 지원

기본 테스트를 마쳤는데도 음성 입력·버튼 호출·Siri 설정이 계속 실패하면 Apple 공식 지원을 통해 진단을 받습니다.

피해야 할 행동: Siri가 잠깐 응답하지 않는다는 이유로 아이폰 전체 데이터 삭제, 공장 초기화, 비공식 'Siri 복구 앱' 설치부터 진행하지 마세요.

17. 자주 묻는 질문(FAQ)

Q1. “Siri야”라고 해도 아무 반응이 없어요. 어떻게 하나요?

먼저 인터넷을 확인하고, 설정 → Siri → 요청/듣기에서 “Siri” 또는 “Siri야” 활성화 상태를 확인하세요. 켜져 있다면 껐다 다시 켜고 목소리 재등록을 진행합니다.

Q2. 측면 버튼을 길게 눌러도 Siri가 안 떠요.

Siri의 측면 버튼 호출 설정과 설정 → 손쉬운 사용 → 측면 버튼 → 길게 눌러서 말하기를 확인합니다. 해당 기기에서 지원되는 호출 방법도 점검하세요.

Q3. Siri가 화면에는 뜨지만 목소리로 답하지 않아요.

설정 → Siri → 응답에서 음성 응답 선호를 선택하고, 아이폰의 무음 모드와 출력 음량을 확인하세요.

Q4. 'Siri'만 말해도 되고, 'Siri야'라고 해야 하나요?

'Siri' 단독 호출은 일부 언어·지역·지원 모델에서만 가능합니다. 한국어를 쓰는 아이폰이라면 실제 Siri 설정 화면의 지원 옵션을 확인하고 'Siri야'부터 테스트하세요.

Q5. Siri 언어를 한국어로 바꾸는 방법은?

설정 → Siri → 언어에서 한국어를 선택합니다. 일부 기능의 지원 범위는 모델·지역·Siri 버전에 따라 달라질 수 있습니다.

Q6. Siri가 '연결에 문제가 있습니다'라고 말해요.

Apple은 Siri 사용에 인터넷 연결이 필요하다고 안내합니다. Safari에서 일반 웹사이트가 열리는지 확인하고 Wi-Fi·모바일 데이터 상태를 점검하세요.

Q7. 마이크가 고장 나서 Siri가 안 되는 건가요?

반드시 그렇지는 않습니다. Siri 호출 설정이나 음성 인식 문제일 수도 있습니다. 음성 메모·카메라 동영상에서 목소리가 선명하게 녹음되는지 테스트하세요.

Q8. 잠금 화면에서만 Siri가 안 되면?

설정 → Face ID 및 암호/Touch ID 및 암호 → 잠겨 있는 동안 접근 허용을 확인하고, 필요하면 스크린 타임의 Siri 제한도 확인하세요.

Q9. Siri 설정 자체가 없어졌어요.

아이폰을 재시동한 뒤 설정에서 Siri를 검색합니다. Apple은 Siri 메뉴가 나타나지 않으면 VPN 설정·프로필을 확인하라고 안내합니다.

Q10. 자녀 아이폰에서 Siri 사용이 차단돼 있어요.

설정 → 스크린 타임 → 콘텐츠 및 개인정보 보호 제한 → Siri 설정을 확인합니다. 가족 관리 기기라면 보호자의 허용 여부를 확인하세요.

Q11. iOS 27이 아니면 Siri를 못 쓰나요?

아닙니다. 기본 Siri는 이전부터 지원되는 기기에서 사용할 수 있습니다. iOS 27의 Siri AI(베타) 지원 요건과 기본 Siri의 지원 여부는 다릅니다.

Q12. AirPods에서는 안 되지만 아이폰에서는 정상이에요.

이어폰 연결 또는 해당 AirPods 모델의 Siri 호출 지원 방식을 확인하세요. 아이폰 자체 Siri가 정상이라면 먼저 이어폰의 연결·마이크 상태를 점검합니다.

Q13. Siri를 초기화하면 아이폰 사진과 메시지가 삭제되나요?

이 글에서 안내한 Siri 음성 호출 설정을 껐다 다시 켜는 작업은 아이폰 전체 데이터를 삭제하는 공장 초기화와 다릅니다. 다만 Siri 문제해결을 이유로 모든 콘텐츠 및 설정 지우기를 진행하지 마세요.

Q14. Siri 대신 글자로 명령을 입력할 수 있나요?

지원되는 기기·버전에서는 설정 → 손쉬운 사용 → Siri → 타이핑으로 Siri 사용 등을 이용할 수 있습니다. Apple Intelligence가 활성화된 환경에서는 별도 입력 방법이 제공될 수 있습니다.

18. 최종 점검 체크리스트

  • ☐ Wi-Fi 또는 모바일 데이터의 실제 인터넷 연결을 확인했다.
  • ☐ 설정 → Siri(또는 Apple Intelligence 및 Siri)에서 Siri 활성화 여부를 확인했다.
  • ☐ “Siri” 또는 “Siri야” 듣기 설정을 껐다 다시 켜서 목소리를 재등록했다.
  • ☐ 측면 버튼/홈 버튼으로 Siri 호출을 테스트했다.
  • ☐ Siri의 음성 응답 선호와 무음 모드를 확인했다.
  • ☐ 음성 메모와 카메라로 마이크 동작을 테스트했다.
  • ☐ Siri 언어가 한국어 등 사용하려는 언어인지 확인했다.
  • ☐ 잠금 화면에서만 문제라면 잠겨 있는 동안 접근 허용 설정을 확인했다.
  • ☐ 자녀·회사 기기라면 스크린 타임·관리 정책을 확인했다.
  • ☐ Siri 메뉴 자체가 없으면 소프트웨어·VPN·프로필을 확인했다.
  • ☐ Siri AI(베타)의 지원 요건과 기본 Siri 사용 여부를 혼동하지 않았다.
