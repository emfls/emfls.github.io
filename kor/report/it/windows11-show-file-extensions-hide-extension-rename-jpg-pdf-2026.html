윈도우11에서 다운로드한 사진이나 문서의 끝에 jpg, pdf, docx 같은 글자가 보이지 않아 파일 형식을 구별하기 어려울 때가 있습니다. 반대로 확장명이 보이게 바꿨다가 실수로 삭제하면 파일을 열 수 없게 될까 걱정하기도 합니다.

가장 빠른 해결 방법은 파일 탐색기 → 보기 → 표시 → 파일 이름 확장명을 켜는 것입니다. 다만 확장명을 표시하는 것, 확장명을 바꾸는 것, 파일 형식을 변환하는 것은 서로 다른 작업입니다. 이 글은 Microsoft의 Windows 11 공식 안내를 기준으로 세 가지의 차이와 실제 문제 해결 순서를 정리합니다.

1. 30초 요약: 상황별 해결 방법

현재 문제먼저 할 일주의할 점
파일명 끝에 .jpg·.pdf가 안 보임보기 → 표시 → 파일 이름 확장명 켜기파일의 내용은 바뀌지 않음
확장명이 계속 표시돼 불편함같은 메뉴의 체크 해제표시만 숨기는 것
.jpg를 .png로 바꾸고 싶음사진 앱 등에서 PNG로 다시 저장이름만 바꾸면 변환되지 않음
PDF가 엣지로 열려 불편함설정 → 앱 → 기본 앱에서 .pdf 연결 변경확장명 변경은 필요 없음
파일명 끝에 .pdf.exe처럼 두 개가 보임실제 마지막 확장명 확인실행 파일을 문서로 오해하지 않기
이름 변경 뒤 파일이 안 열림실제 파일 형식과 확장명 확인원본 파일 복사본으로 작업
확장명과 숨김 파일을 혼동함보기 → 표시 메뉴 구분숨긴 항목과 확장명은 별도 옵션

핵심: 파일의 형식을 알아보려면 우선 확장명을 표시해야 합니다. 무작정 이름을 바꾸는 것은 해결책이 아닙니다.

2. 윈도우11 파일 확장자 보이게 하는 방법

Windows 11의 파일 탐색기에서 설정하는 기본적인 방법입니다.

  1. 키보드에서 Windows 키 + E를 눌러 파일 탐색기를 엽니다.
  2. 상단 메뉴에서 보기를 선택합니다.
  3. 표시 항목을 엽니다.
  4. 파일 이름 확장명에 체크합니다.
  5. 다운로드 폴더 등에서 파일 이름 끝에 .pdf, .jpg, .xlsx가 나타나는지 확인합니다.

Microsoft의 Windows 파일 탐색기 공식 설명에서도 동일한 표시 기능을 안내하고 있습니다.

예시: 기존에 회사보고서라고만 보이던 파일이 설정 후 회사보고서.xlsx로 보일 수 있습니다. 실제 파일의 데이터는 그대로이며, 탐색기에서 파일명의 확장명 부분을 드러낸 것입니다.

3. 파일 확장자를 다시 숨기는 방법

반대로 확장명을 표시하지 않고 파일명만 간단하게 보고 싶다면 다음과 같이 설정합니다.

  1. Windows 키 + E로 파일 탐색기를 엽니다.
  2. 보기 → 표시 → 파일 이름 확장명을 선택합니다.
  3. 항목에 표시된 체크를 해제합니다.
  4. 파일 이름 끝의 확장명이 숨겨졌는지 확인합니다.

이 작업은 파일에서 확장명을 제거하는 것이 아닙니다. 표시 여부만 바꾸는 설정입니다. 다시 체크하면 원래 확장명이 나타납니다.

일반적으로 파일 형식이나 안전성을 직접 확인할 일이 많은 사용자라면 확장명을 표시해 두는 것이 유용합니다. 공유받은 첨부파일이 이미지인지, 문서인지, 실행 파일인지 파악하기 쉬워지기 때문입니다.

4. 파일 확장명이란? 자주 보는 파일 형식 비교

Microsoft는 파일 이름의 마침표 뒤에 오는 부분이 파일 형식을 구분하는 단서라고 설명합니다.

확장명일반적인 파일 종류사용 예시
.jpg / .jpegJPEG 이미지휴대전화 사진, 상품 사진
.pngPNG 이미지로고, 배경 투명 이미지
.pdfPDF 문서제출용 문서, 영수증
.docxWord 문서보고서, 기획서
.xlsxExcel 통합 문서거래처 명단, 재고표

확장명만으로 파일의 내용과 안전성이 100% 보장되는 것은 아닙니다. 실제 형식과 확장명이 맞지 않을 수도 있으며, 악성 파일이 정상 문서를 흉내 낼 수도 있습니다.

5. JPG를 PNG로 바꾸고 싶을 때: 이름 변경만으로는 안 됩니다

확장명 설정에서 가장 많이 혼동하는 부분입니다.

예를 들어 photo.jpg의 이름을 photo.png로 바꿨다고 해서 이미지 데이터가 PNG 형식으로 변환되지는 않습니다. Microsoft도 확장명 변경은 파일 형식 변환이 아니며, 파일 이름을 제외한 파일의 내용은 변경하지 않는다고 설명합니다.

실제로 변환하려면

  1. 변환할 이미지를 이미지 편집 프로그램이나 지원되는 사진 앱에서 엽니다.
  2. 다른 이름으로 저장 또는 내보내기 메뉴를 찾습니다.
  3. 파일 형식 옵션에서 PNG를 선택합니다.
  4. 새로운 파일로 저장합니다.
  5. 파일 확장명을 표시한 뒤 .png로 저장됐는지 확인합니다.
  6. 변환한 파일을 다시 열어 이미지가 정상인지 확인합니다.

앱마다 지원하는 저장 형식이 다르므로 PNG 내보내기 메뉴가 없다면 해당 형식을 지원하는 다른 프로그램을 사용해야 합니다.

주의: JPG를 PNG로 바꿔도 원본 JPG에서 손실된 화질 정보가 자동으로 복구되는 것은 아닙니다. 이미지를 무조건 선명하게 만들어 주는 기능으로 오해하지 마세요.

6. PDF를 Word로 바꾸려는데 확장명만 바꿨다면

보고서.pdf를 보고서.docx로 이름만 바꿔도 Word 문서가 새로 생성되는 것은 아닙니다. 이름의 마지막 문자열만 달라질 뿐 실제 파일 내용은 PDF 그대로일 수 있습니다.

실제로 변환하려면 Word 또는 PDF 변환을 지원하는 신뢰할 수 있는 도구에서 파일 내용 자체를 변환해야 합니다. 변환된 뒤에는 글꼴·표·이미지·페이지 배치가 원본과 같은지 확인하세요.

특히 주민등록번호·계좌번호·계약서 등 민감한 문서라면 무작정 온라인 변환 사이트에 올리기보다 해당 문서의 개인정보와 보안 요구사항을 먼저 확인하는 것이 좋습니다.

구별법:

  • 확장명 표시: 보고서.pdf의 끝글자를 보이게 함
  • 확장명 변경: 보고서.pdf의 이름을 보고서.docx로 바꿈
  • 파일 변환: 실제 PDF 내용을 Word 문서 형식으로 다시 저장함

이 세 작업을 혼동하면 제출한 파일이 열리지 않는 문제로 이어질 수 있습니다.

7. 더블클릭할 때 엉뚱한 앱이 열리면: 기본 앱 변경

PDF 파일을 더블클릭할 때 Microsoft Edge 대신 다른 PDF 앱으로 열고 싶거나, JPG 사진을 특정 이미지 뷰어로 열고 싶은 경우에는 확장명을 바꾸지 말고 기본 앱 설정을 사용합니다.

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 앱 → 기본 앱으로 이동합니다.
  3. 검색창에 .pdf, .jpg처럼 파일 확장명을 입력합니다.
  4. 해당 파일 형식의 현재 연결 앱을 선택합니다.
  5. 사용할 다른 앱이 표시된다면 선택하고 저장합니다.
  6. 파일 탐색기에서 해당 형식의 파일을 다시 열어 동작을 확인합니다.

필요한 앱이 목록에 없다면 해당 파일 형식을 지원하는 앱이 설치돼 있는지 먼저 확인해야 합니다.

중요: PDF가 Edge로 열리는 이유는 보통 확장명이 잘못돼서가 아니라 현재 기본 앱 연결이 그렇게 지정돼 있기 때문입니다.

8. 확장명 변경 후 '파일을 사용할 수 없게 될 수 있습니다' 경고가 뜰 때

Windows는 파일 이름에서 확장명을 바꾸면 파일을 제대로 사용할 수 없을 수 있다는 취지의 경고를 표시할 수 있습니다. 이 경고가 나온다는 것은 단순한 표시 설정 변경이 아니라 실제 파일 이름의 확장명 부분을 수정하고 있다는 의미입니다.

실수로 바꿨다면

  1. 해당 파일을 더블클릭해 열리지 않는지 확인합니다.
  2. 파일 이름을 다시 바꿔 기존 확장명으로 복구할 수 있는지 확인합니다.
  3. 원래 확장명이 확실하지 않으면 원본 파일·전송 기록·백업 사본을 찾아봅니다.
  4. 파일이 업무상 중요하다면 새 이름 변경을 반복하기 전에 사본을 만들어 두세요.

일부 파일은 확장명이 바뀌었더라도 원래 프로그램에서 열 수 있지만, 이를 모든 형식에 일반화해서는 안 됩니다.

예를 들어 .xlsx 파일을 이름만 .xls로 바꾸는 행위는 구버전 Excel 형식으로 제대로 변환하는 방법이 아닙니다.

9. '파일 이름.pdf.exe' 같은 두 개의 확장명을 조심하세요

파일을 안전하게 확인하는 관점에서도 확장명 표시는 중요합니다.

예를 들어 파일 이름이 계약서.pdf.exe인데 확장명을 숨기는 설정을 사용하고 있다면 마지막 .exe가 화면에서 보이지 않아 문서처럼 오인할 여지가 있습니다.

이 경우 실제로는 마지막 확장명이 .exe인 실행 파일입니다. 이미지나 PDF 문서라고 생각하고 실행하면 위험할 수 있으므로 출처를 확인하기 전에는 열지 않는 것이 안전합니다.

파일 이름실제 마지막 확장명점검 사항
계약서.pdf.pdfPDF 문서인지 확인
계약서.pdf.exe.exe문서로 위장한 실행 파일 가능성
사진.jpg.jpg이미지 파일인지 확인
사진.jpg.bat.bat배치 명령 파일 실행 주의
매출현황.xlsx.xlsxExcel 통합 문서인지 확인

확장명 표시만 켜도 모든 악성 파일을 탐지할 수 있는 것은 아닙니다. 의심스러운 첨부파일은 전송자·요청 맥락을 확인하고 Windows 보안 검사 결과를 살펴보세요.

10. 파일 확장명 표시와 '숨긴 항목'은 다른 설정입니다

Windows 11 파일 탐색기의 보기 → 표시 메뉴에는 ‘파일 이름 확장명’ 외에도 ‘숨긴 항목’ 같은 설정이 있습니다.

  • 파일 이름 확장명: 이름 끝에 .docx, .jpg 같은 문자열을 표시할지 결정합니다.
  • 숨긴 항목: 숨김 속성이 있는 파일과 폴더를 표시할지 결정합니다.

따라서 확장명이 안 보이는데 '숨긴 항목'을 켠다고 문제가 해결되는 것은 아닙니다. 반대로 숨긴 폴더를 찾기 위해 확장명만 켜도 그 폴더가 자동으로 보이지는 않습니다.

실무 팁: 먼저 자신이 찾으려는 것이 파일 형식인지, 숨겨진 파일인지 구별한 다음 해당 메뉴만 변경하세요.

11. 확장명이 보이지 않거나 변경이 안 될 때 점검표

증상점검 방법다음 조치
메뉴를 켰는데도 특정 파일명이 그대로임실제 확장명 유무 확인다른 정상 파일과 비교
일부 폴더에서만 다르게 보임표시 옵션 적용 상태 재확인탐색기 창을 새로 열어 비교
파일명이 두 번 표시되는 듯함실제 이름에 마침표가 여러 개 있는지 확인확장명과 이름 구분
확장명을 바꿨더니 열리지 않음실제 파일 형식 확인원래 이름으로 복구·정상 변환
PDF가 원하지 않는 앱에서 열림기본 앱 연결 상태 확인앱 → 기본 앱에서 형식별 지정
파일명이 회색이나 흐리게 보임숨김 항목 표시 및 파일 속성 확인확장명 옵션과 구분
파일 탐색기 메뉴 자체가 작동하지 않음다른 폴더·새 탐색기 창 확인재시작·Windows 업데이트 점검

파일 탐색기 자체가 열리지 않거나 시작되지 않는다면 Microsoft는 Windows 업데이트 확인과 PC 다시 시작 같은 일반적인 점검 방법을 안내합니다. 다만 단지 확장명이 숨겨진 문제라면 PC 초기화는 필요하지 않습니다.

12. 자주 묻는 질문

Q. 윈도우11에서 파일 확장자를 보이게 하려면?

파일 탐색기에서 보기 → 표시 → 파일 이름 확장명을 켜면 됩니다.

Q. 확장명을 숨기면 파일이 다른 형식으로 바뀌나요?

아닙니다. 표시만 숨기며 파일 데이터와 형식 자체는 그대로입니다.

Q. PDF를 DOCX로 이름만 바꿔도 워드 파일이 되나요?

아닙니다. PDF 내용을 Word 형식으로 실제 변환해야 합니다.

Q. JPG를 PNG로 이름만 변경해도 되나요?

일반적인 파일 형식 변환 방법이 아닙니다. 이미지 편집 도구의 다른 이름으로 저장·내보내기 기능으로 실제 PNG 파일을 만들어야 합니다.

Q. 파일 이름 뒤에 마침표가 여러 개 있으면 어느 것이 확장자인가요?

Windows에서 파일 형식을 구별할 때는 일반적으로 마지막 확장명이 중요합니다. 파일.pdf.exe는 PDF라고 단정할 수 없습니다.

Q. PDF를 열 때 사용하는 앱을 바꾸고 싶어요.

설정 → 앱 → 기본 앱에서 .pdf를 검색해 원하는 앱과 연결하세요. 파일 확장명을 바꿀 이유는 없습니다.

13. 최종 체크리스트

  • ☐ 파일 탐색기에서 파일 이름 확장명 표시를 켰다.
  • ☐ 파일의 마지막 확장명이 무엇인지 확인했다.
  • ☐ 이름 변경과 실제 파일 변환을 혼동하지 않았다.
  • ☐ 확장명을 바꾸기 전 원본 사본을 확보했다.
  • ☐ 기본 프로그램 문제라면 ‘앱 → 기본 앱’에서 해결했다.
  • ☐ 확장명 뒤에 .exe·.bat 등이 숨겨져 있지 않은지 살펴봤다.
  • ☐ 출처가 불분명한 파일은 확장명만 믿고 실행하지 않았다.

결론: 윈도우11에서 확장명을 확인하려면 파일 탐색기 → 보기 → 표시 → 파일 이름 확장명으로 이동하면 됩니다. .jpg와 .pdf 등 파일명을 바꾸는 일은 실제 형식 변환과 다르다는 사실을 기억하세요. 파일을 안전하게 분류하고 열기 위해서도 확장명을 표시해 두는 것이 도움이 됩니다.
