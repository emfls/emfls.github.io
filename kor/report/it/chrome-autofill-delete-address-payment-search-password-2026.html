핵심 결론: 배송지·카드 제안은 크롬의 '자동완성 및 비밀번호' 메뉴에서 관리합니다. 비밀번호는 Google 비밀번호 관리자에서 따로 삭제하고, 과거에 방문한 사이트가 주소창에 뜨는 현상은 방문 기록을 확인해야 합니다. Google 계정이나 Google 월렛에 저장된 정보는 크롬의 자동완성 양식 데이터만 지운다고 모두 삭제되지 않습니다.

자료 확인일: 2026년 11월 4일. Google Chrome·Google 계정 공식 도움말을 기준으로 작성했습니다. 메뉴 이름과 위치는 운영체제·브라우저 버전·지역에 따라 조금씩 다를 수 있습니다.

1. 먼저 증상에 따라 삭제 대상을 구분하세요

크롬에서 나타나는 현상데이터 종류먼저 이동할 곳
쇼핑몰 배송지에 예전 집 주소·전화번호가 나옴주소 및 연락처 자동완성설정 → 자동완성 및 비밀번호 → 주소 및 기타
카드번호 끝 4자리·예전 결제카드가 제안됨결제수단 자동완성설정 → 자동완성 및 비밀번호 → 결제수단
로그인 아이디와 비밀번호가 자동으로 나타남저장된 계정 정보Google 비밀번호 관리자
주소창에 예전에 방문한 사이트가 뜸방문 기록·북마크 등에 기반한 제안방문 기록 확인 및 개별 삭제
검색창에 과거 검색어가 나타남검색 제안·검색 기록·Google 계정 활동Chrome 주소창 제안과 Google 검색 활동을 각각 확인
자동완성 제안을 앞으로 받기 싫음저장·자동입력 기능 설정해당 범주에서 '저장 및 자동 입력' 끄기

'저장 및 자동 입력' 기능을 끄는 것은 기존 데이터를 삭제하는 작업과 다릅니다. 예전 기록까지 없애려면 저장 항목도 별도로 점검하세요.

2. PC에서 주소·연락처 자동완성 삭제하기

  1. 크롬 오른쪽 상단의 점 세 개(⋮) → 설정을 엽니다.
  2. 자동완성 및 비밀번호에서 주소 및 기타(또는 주소 및 연락처에 해당하는 메뉴)를 선택합니다.
  3. 오래된 주소·이름·전화번호가 저장되어 있는지 확인합니다.
  4. 삭제할 항목의 더보기 메뉴에서 삭제를 선택합니다. 수정만 필요하면 수정을 선택합니다.
  5. 앞으로 새 주소가 자동 저장되는 것이 싫다면 주소 저장 및 자동 입력 관련 스위치를 끕니다.

예시: 이사 전 주소가 결제창에 두 개 뜬다면 모든 데이터를 삭제할 필요 없이 오래된 주소 한 건만 지우는 편이 낫습니다. 회사 주소와 집 주소를 함께 쓰는 경우에도 이 방법이 효율적입니다.

저장 주소가 보이지 않는데 제안만 계속되면 사이트가 자체적으로 기억한 배송지이거나, Google 계정의 주소 정보가 사용되는 경우도 있습니다. 해당 쇼핑몰 계정의 배송지 관리 메뉴와 Google 계정 개인정보를 확인하세요.

3. 결제카드 자동완성이 없어지지 않는다면

카드 정보는 크롬 기기에만 저장된 카드인지, Google 월렛에 저장된 카드인지부터 구별해야 합니다.

  1. 크롬 설정에서 자동완성 및 비밀번호 → 결제수단으로 이동합니다.
  2. 사용하지 않는 결제수단을 찾아 삭제 또는 수정 메뉴를 확인합니다.
  3. Google 월렛에서 수정이 표시되면 연결된 Google 월렛의 결제수단 관리 페이지에서 삭제해야 합니다.
  4. 카드 제안을 아예 끄려면 결제수단의 저장 및 자동 입력 설정을 끕니다.
  5. 카드 보안코드 저장 기능을 사용했다면 보안코드 저장 여부도 별도로 확인합니다.

공용 PC에서 실수로 카드를 저장했다면 해당 기기 기록뿐 아니라 로그인 중이던 Google 계정의 결제수단도 확인하는 것이 좋습니다.

중요한 차이: 크롬의 '인터넷 사용 기록 삭제 → 자동완성 양식 데이터'만 선택해 지워도 Google 월렛에 저장된 카드까지 삭제되는 것은 아닙니다. 실제 결제수단을 없애려면 Google 월렛을 확인하세요.

4. 주소·카드 자동완성 양식 데이터를 한 번에 지우는 법

개별 삭제보다 전체 정리가 필요하다면 다음 순서를 따릅니다.

  1. PC 크롬의 점 세 개 → 인터넷 사용 기록 삭제를 엽니다.
  2. 필요하다면 고급 탭을 선택합니다.
  3. 기간을 전체 기간으로 설정합니다. 일부 기간만 지울 때는 기간을 조정합니다.
  4. 자동완성 양식 데이터를 선택합니다.
  5. 다른 항목이 필요하지 않다면 방문 기록·쿠키·비밀번호 등의 체크 여부를 확인하고 데이터 삭제를 누릅니다.

주의: 인터넷 사용 기록 삭제 화면에서 필요 없는 다른 항목까지 선택하면 사이트 로그인 상태가 바뀌거나 방문 기록이 없어질 수 있습니다. '자동완성 양식 데이터'만 정리하려는 경우 체크박스를 세심하게 확인하세요. Google 계정에 저장된 주소·카드 정보는 별도로 남을 수 있습니다.

5. 비밀번호 자동완성은 별도 메뉴에서 삭제하세요

로그인 비밀번호는 주소·결제카드 자동완성과 별도로 관리합니다.

  1. 크롬의 점 세 개 → 자동완성 및 비밀번호 → Google 비밀번호 관리자를 엽니다.
  2. 삭제할 웹사이트나 계정 항목을 검색합니다.
  3. 해당 항목을 열고 본인 인증이 요구되면 인증합니다.
  4. 삭제를 선택합니다.
  5. 자동 저장 제안 자체를 끄려면 비밀번호 관리자 설정에서 저장 제안 항목을 확인합니다.

또는 Google 비밀번호 관리자에서 저장된 항목을 확인할 수 있습니다.

'모든 Google 비밀번호 관리자 데이터 삭제'는 권장하지 않습니다. 필요 없는 로그인 하나를 지우려다가 다른 사이트의 저장 비밀번호와 패스키까지 잃을 수 있습니다. 특히 더 이상 비밀번호를 기억하지 못하는 계정이 있다면 삭제 전에 복구수단부터 확인하세요.

6. 검색어·주소창 자동완성이 계속 뜰 때

주소창에서 글자를 입력할 때 뜨는 추천은 쇼핑몰 주소 자동입력과 다릅니다. 방문 기록, 북마크, 열린 탭, 검색엔진의 검색 제안 등 여러 출처가 섞일 수 있습니다.

  • 예전에 방문한 사이트가 뜬다면: 크롬 방문 기록에서 해당 사이트 기록을 찾아 삭제합니다. 전체 방문 기록 삭제가 필요한지 먼저 판단하세요.
  • 북마크로 저장한 사이트라면: 방문 기록을 삭제해도 해당 북마크가 추천될 수 있으므로 북마크 목록을 따로 확인합니다.
  • Google 검색창의 검색어 제안이라면: Chrome의 자동완성 양식 데이터가 아니라 Google 내 활동에 저장된 검색 활동이 관련될 수 있습니다. Google 검색 설정의 추천 기능도 별개입니다.
  • 웹사이트 자체 검색창이라면: 해당 사이트 계정의 최근 검색어·검색 기록 설정을 확인해야 할 수 있습니다.

구분법: 쿠팡·쇼핑몰의 '배송지 주소'가 자동 입력되는 것은 양식 자동완성이지만, 크롬 주소창에 '예전에 방문한 사이트'가 뜨는 것은 기록 기반 제안입니다. 두 문제의 해결 메뉴는 다릅니다.

7. 갤럭시·안드로이드 크롬에서 삭제하기

특정 주소·카드 삭제

  1. 크롬 앱을 열고 점 세 개 → 설정으로 들어갑니다.
  2. 주소 및 기타 또는 결제수단을 선택합니다.
  3. 저장된 항목을 열고 수정·삭제 메뉴를 사용합니다.
  4. Google 월렛에 저장된 카드라면 월렛에서 별도로 제거합니다.

자동완성 양식 데이터 일괄 삭제

  1. 크롬 → 설정 → 개인정보 보호 및 보안 → 인터넷 사용 기록 삭제로 이동합니다.
  2. 기간을 고릅니다.
  3. 고급 → 자동완성 양식 데이터를 선택합니다.
  4. 체크 항목을 확인한 후 삭제합니다.

삼성 인터넷·네이버 앱 등의 자체 브라우저에 입력한 정보는 크롬 설정으로 삭제되지 않습니다. 어떤 앱에서 자동완성이 뜨는지 먼저 확인하세요.

8. 아이폰 크롬에서 삭제하기

  1. 아이폰의 Chrome 앱 → 점 세 개 → 설정으로 이동합니다.
  2. 결제수단 또는 주소 및 기타에서 저장된 항목을 확인합니다.
  3. 항목을 왼쪽으로 밀어 삭제하거나, 편집 기능으로 여러 주소를 선택해 삭제합니다.
  4. 전체 양식 정보를 지우려면 점 세 개 → 인터넷 사용 기록 삭제 → 고급 → 자동완성 양식 데이터를 선택합니다.

아이폰의 Safari 자동완성과 Chrome 자동완성은 관리 위치가 다릅니다. Safari에서만 발생하는 문제라면 Chrome을 정리해도 해결되지 않습니다. 또한 키보드 자체의 예측 텍스트 문제라면 iPhone 키보드 설정을 따로 확인하세요.

9. 지웠는데 다시 나타나는 이유 5가지

다시 나타나는 상황우선 확인할 점
크롬 카드 목록에 보이지 않는데 카드가 추천됨Google 월렛 저장 여부
다른 기기에서도 같은 주소가 보임동일 Google 계정의 주소·동기화 정보
특정 쇼핑몰에서만 예전 주소가 뜸쇼핑몰 계정의 배송지 목록
크롬 주소창에서 특정 사이트가 계속 나옴방문 기록 이외에 북마크·검색 제안 여부
비밀번호가 계속 자동 입력됨Google 비밀번호 관리자와 다른 비밀번호 관리자 사용 여부

확인 순서는 증상이 나타나는 앱 → 추천되는 정보의 종류 → 기기 저장 여부 → Google 계정 저장 여부 → 해당 웹사이트 계정 저장 여부입니다. 이 순서로 보면 불필요한 전체 초기화를 피할 수 있습니다.

10. 자주 묻는 질문

Q. 크롬 자동완성을 끄면 기존 주소와 카드가 삭제되나요?

아닙니다. 대부분의 경우 자동입력을 사용하지 않도록 설정할 뿐 저장 데이터는 남을 수 있습니다. 기존 항목을 삭제하려면 주소·결제수단 목록에서 별도로 제거하세요.

Q. 인터넷 사용 기록을 삭제하면 저장 비밀번호도 없어지나요?

무조건 그렇지는 않습니다. 삭제 창에서 선택한 데이터 범주에 따라 결과가 달라집니다. Google 비밀번호 관리자의 저장 항목은 별도 관리되므로 삭제 전 어떤 체크박스가 선택됐는지 확인하세요.

Q. 크롬에서 카드를 삭제했는데 결제창에 또 뜹니다.

Q. 검색어 자동완성과 주소 자동완성은 같은 기능인가요?

다릅니다. 배송지·연락처·결제수단을 채워주는 자동완성과 주소창 검색 제안은 데이터 출처가 달라 삭제 방법도 다릅니다.

Q. 다른 휴대전화의 자동완성에도 영향이 있나요?

같은 Google 계정으로 로그인해 정보가 저장·동기화되는 구성이라면 변경이 다른 기기에 반영될 수 있습니다. 삭제하기 전에 계정과 데이터 저장 위치를 확인하세요.
