2. PC에서 넷플릭스 시청기록 삭제(숨기기) 하는 방법

윈도우·맥을 가리지 않고 웹 브라우저에서 같은 흐름으로 처리할 수 있습니다.

  1. 브라우저에서 Netflix에 로그인합니다.
  2. 계정(Account) 페이지로 이동합니다.
  3. 프로필(Profiles) 항목에서 기록을 정리할 프로필을 선택합니다.
  4. 해당 프로필의 시청 기록(Viewing activity)을 엽니다.
  5. 숨길 영화·에피소드를 찾습니다.
  6. 항목 옆의 숨기기 아이콘(금지 표시 모양)을 누릅니다.
  7. 드라마 에피소드를 숨겼다면 나타나는 시리즈 전체를 숨길지 여부도 확인합니다.

핵심: 한 에피소드만 숨겼는데 다른 회차가 계속 목록에 남아 있다면 오류라고 단정하지 마세요. 해당 회차만 숨겼는지 시리즈 전체를 숨겼는지가 다릅니다.

시청 기록 목록에 원하는 콘텐츠가 보이지 않는다면 현재 선택한 프로필이 맞는지 먼저 확인하고, 페이지에 더 보기가 있는지도 확인하세요.

공식 근거: 넷플릭스 고객센터 — 시청 기록 숨기기.

3. 넷플릭스 시청기록 전체 삭제: '모두 숨기기' 활용

특정 영화가 아니라 프로필의 시청기록 전체를 한꺼번에 정리하고 싶다면 다음 순서를 따르세요.

  1. 넷플릭스 웹 계정에서 프로필 → 시청 기록으로 들어갑니다.
  2. 시청 기록 페이지 하단으로 이동합니다.
  3. 모두 숨기기를 선택합니다.
  4. 확인 화면에서 적용 범위를 읽은 뒤 진행합니다.
  5. 다른 기기에서도 표시가 바뀌는지 확인합니다.

넷플릭스에 따르면 숨긴 항목은 이미 본 작품으로 표시되지 않으며, 다시 보지 않는 한 추천 콘텐츠를 만들 때 해당 시청이 참고 자료로 사용되지 않습니다. 또한 시청 중인 콘텐츠 줄에서도 제거됩니다.

따라서 전체 숨기기는 단순히 홈 화면을 깨끗하게 보이게 하는 것보다 개인화 추천에도 넓게 영향을 주는 작업입니다. 다른 가족이 같은 계정을 사용하더라도 어느 프로필을 선택했는지에 주의하세요.

전체 숨기기를 서두르지 말아야 할 경우: 시청했던 드라마 회차를 나중에 찾거나, 고객지원 문의를 위해 시청 이력이 필요한 경우입니다. 가능하다면 6번의 CSV 전체 다운로드를 먼저 검토하세요.

4. 갤럭시·아이폰에서 '이어보기' 목록만 지우기

휴대전화에서 가장 자주 원하는 것은 시청기록 전체 정리가 아니라 홈의 '시청 중인 콘텐츠' 줄에서 특정 작품 하나만 치우는 것입니다. 최신 넷플릭스 앱에서는 다음 순서로 처리할 수 있습니다.

  1. 갤럭시 또는 아이폰에서 넷플릭스 앱을 엽니다.
  2. 홈 화면의 시청 중인 콘텐츠 줄을 찾습니다.
  3. 없애려는 영화나 시리즈의 더보기 메뉴를 누릅니다.
  4. 줄에서 삭제를 선택합니다.
  5. 해당 항목이 더 이상 목록에 나타나지 않는지 확인합니다.

이 작업은 시청기록 페이지의 '숨기기'와 다릅니다. 시청 이력을 숨기는 것이 목적이라면 휴대전화 브라우저에서 넷플릭스 계정 페이지를 열어 프로필 → 시청 기록으로 이동해야 합니다.

메뉴가 안 보인다면: 넷플릭스 공식 고객센터는 최신 앱 버전에서 이 기능을 지원한다고 안내합니다. 구형 앱에서는 이어보기 줄에서 직접 제거할 수 없을 수 있으므로, 앱 업데이트 여부를 확인한 뒤 웹 시청기록 숨기기를 이용하세요.

공식 근거: 넷플릭스 고객센터 — 시청 중인 콘텐츠 줄에서 콘텐츠 삭제.

5. 스마트TV에서 이어보기 콘텐츠 삭제하는 방법

스마트TV에서도 '시청 중인 콘텐츠' 줄을 정리할 수 있습니다.

  1. TV의 넷플릭스 앱에서 정리할 프로필을 선택합니다.
  2. 시청 중인 콘텐츠 줄에서 해당 영화 또는 시리즈를 찾습니다.
  3. 작품의 상세 정보 페이지를 엽니다.
  4. 메뉴에 있는 시청 중인 콘텐츠에서 삭제를 선택합니다.

이 기능이 보이지 않는 구형 기기에서는 PC나 휴대전화 브라우저에서 시청기록을 숨기는 방법을 이용할 수 있습니다. 단, 숨긴 기록이 TV에 반영되기까지 시간이 걸릴 수 있습니다.

구분해야 할 점: TV에서 이어보기 줄을 정리하는 방법과, 넷플릭스 계정의 전체 시청기록을 관리하는 웹 화면은 별도입니다. TV에서 전체 시청기록 삭제 메뉴를 무조건 찾을 필요는 없습니다.

6. 시청기록을 지우기 전 CSV로 다운로드하는 방법

넷플릭스는 프로필별 시청기록 목록을 CSV 파일로 다운로드하는 기능도 안내합니다. 어떤 콘텐츠를 언제 봤는지 스스로 보관할 필요가 있다면 먼저 활용할 수 있습니다.

  1. 넷플릭스 웹 계정 → 프로필 → 시청 기록으로 이동합니다.
  2. 목록 아래로 내려 전체 다운로드를 누릅니다.
  3. CSV 파일을 컴퓨터에 저장합니다.
  4. Excel·Google Sheets 또는 다른 CSV 지원 프로그램으로 열어 확인합니다.

넷플릭스는 화면에 일부 기록만 보일 경우 더 보기를 이용할 수 있다고 안내합니다. 전체 다운로드는 시청기록을 보관하는 기능이지 숨기기 작업을 자동으로 취소하거나 되돌리는 기능은 아닙니다.

또한 CSV 파일에는 개인의 시청 취향이 담길 수 있으므로 공유 PC에 그대로 남기거나 공개 클라우드 링크로 배포하지 않는 편이 좋습니다.

공식 근거: 넷플릭스 — 시청 내역 및 디바이스 활동 확인.

넷플릭스 공식 안내에 따르면 숨긴 콘텐츠가 모든 사용 디바이스에서 사라지기까지 최대 24시간이 걸릴 수 있습니다. 따라서 PC에서 숨긴 직후 TV에 같은 항목이 남아 있다고 무조건 실패한 것으로 판단하지 마세요.

8. 삭제하면 추천 알고리즘도 초기화될까요?

일부 추천 신호에는 영향을 주지만 전체 추천 시스템을 초기화하는 것과 같지는 않습니다.

넷플릭스는 숨긴 콘텐츠를 다시 시청하지 않는 한 추천의 참고 자료로 사용하지 않는다고 안내합니다. 하지만 추천에는 다른 콘텐츠에 대한 평가, 시청 습관, 취향이 비슷한 다른 이용자의 반응 등 여러 정보도 활용됩니다. 따라서 시청기록을 숨겼다고 앞으로 추천되는 작품이 전부 초기 상태로 바뀐다고 단정할 수 없습니다.

9. 자주 묻는 질문

Q. 넷플릭스 시청기록은 휴대전화 앱에서 전부 삭제할 수 있나요?

전체 기록 숨기기는 웹 브라우저의 계정 → 프로필 → 시청 기록에서 처리하는 것이 공식 안내 경로입니다. 모바일 앱에서는 주로 시청 중인 콘텐츠 줄에서 삭제 기능을 사용할 수 있습니다. 목적을 먼저 구분하세요.

Q. '이어보기' 삭제하면 시청기록도 없어지나요?

같은 작업이 아닙니다. 이어보기 줄에서 제거하면 홈 화면 목록을 정리하는 데는 도움이 되지만, 시청기록 자체를 숨기려면 프로필의 시청 기록 페이지에서 숨기기를 실행해야 합니다.

Q. 넷플릭스 기록 하나만 지우는 것도 되나요?

가능합니다. 웹의 시청기록 페이지에서 해당 콘텐츠 옆의 숨기기 아이콘을 선택합니다. 드라마는 특정 회차만 숨길지 시리즈 전체를 숨길지 확인할 수 있습니다.
