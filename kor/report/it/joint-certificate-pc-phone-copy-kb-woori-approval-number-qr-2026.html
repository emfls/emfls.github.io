PC에서 인터넷뱅킹에 쓰던 공동인증서(옛 공인인증서)를 새 갤럭시나 아이폰으로 옮기고 싶은데, 인증서 목록이 비어 있거나 승인번호를 어디에 입력해야 하는지 몰라 막히는 경우가 있습니다. 반대로 휴대폰에만 있는 인증서를 PC에 복사해야 하는 일도 있습니다.

이 글은 은행과 인증기관의 공식 안내를 바탕으로 PC → 스마트폰, 스마트폰 → PC, USB → PC, 그리고 인증번호 오류·인증서가 안 보일 때의 해결 순서를 정리했습니다.

핵심: 인증서 복사는 이미 발급받은 인증서를 다른 기기에서도 사용하도록 옮기는 절차입니다. 인증서 발급·재발급과는 다릅니다. 메뉴는 은행·인증기관·개인/기업뱅킹 여부에 따라 달라집니다.

보안 주의: 인증서 파일이나 암호, 승인번호를 문자·메신저·이메일로 제3자에게 보내지 마세요. 반드시 본인이 직접 접속한 은행 공식 앱과 공식 인증센터에서만 진행하세요.

3. PC에서 스마트폰으로 복사하는 기본 순서

대부분의 은행에서 복사 절차는 아래처럼 보내는 쪽(PC)과 받는 쪽(스마트폰) 두 개의 화면을 함께 이용합니다.

  1. PC에서 해당 은행 공식 홈페이지에 접속합니다.
  2. 인증센터 → 공동인증서 → 스마트폰 인증서 복사로 이동합니다.
  3. PC → 스마트폰 또는 PC에서 내보내기를 선택합니다.
  4. 복사할 공동인증서를 선택하고 인증서 비밀번호를 입력합니다.
  5. 스마트폰의 해당 은행 앱에서 인증센터 → 공동인증서 → PC에서 가져오기를 엽니다.
  6. PC 화면의 승인번호/인증번호를 스마트폰에 입력하거나 QR코드를 촬영합니다.
  7. 복사 완료 화면을 확인합니다.
  8. 스마트폰에서 공동인증서 목록이 보이는지 확인하고, 필요하면 해당 은행에서 실제 로그인·인증을 시험합니다.

어느 화면에서 번호가 생성되는지는 은행과 선택한 복사 방식에 따라 다릅니다. PC와 스마트폰 화면에 실제로 표시된 순서에 따르세요.

또한 복사에 성공하는 것과 타행 인증서를 다른 은행에서 사용할 수 있는 것은 별개입니다. 타행 발급 인증서의 경우 해당 은행의 타기관 인증서 등록 절차가 추가로 필요할 수 있습니다.

공식 근거: KB국민은행 — KB스타뱅킹 인증서 복사, 우리은행 — PC에서 스마트폰으로 복사

4. KB국민은행: PC → KB스타뱅킹 가져오기

KB국민은행의 공식 안내를 기준으로 설명합니다.

스마트폰에서 먼저 준비

  1. KB스타뱅킹을 실행합니다.
  2. 전체메뉴 → 인증센터로 이동합니다.
  3. 공동인증서(구 공인인증서) → 인증서 가져오기 → PC에서 가져오기를 선택합니다.
  4. PC의 승인번호를 입력하거나 QR코드를 촬영할 수 있는 화면을 준비합니다.

PC에서 내보내기

  1. PC의 KB국민은행 개인 인증센터에 접속합니다.
  2. 스마트폰 인증서 복사 → KB스타뱅킹용 메뉴를 찾습니다.
  3. PC → 스마트폰 인증서 복사하기를 선택합니다.
  4. 인증서 복사 기능을 실행하고 원본 공동인증서를 선택합니다.
  5. 인증서 비밀번호를 입력합니다.
  6. 화면에 생성된 13자리 승인번호를 스마트폰에 입력하거나 QR코드를 촬영합니다.
  7. 앱에서 인증서 복사 완료 메시지를 확인합니다.

포인트: KB국민은행 공식 안내의 KB스타뱅킹 절차에는 13자리 승인번호가 명시되어 있습니다. 다른 은행 안내에 나온 번호 길이를 국민은행 화면에 억지로 적용하지 마세요.

공식 출처: KB국민은행 — 스마트폰 인증서 복사 상세 안내, KB국민은행 인증서 복사 메뉴

5. 우리은행: PC → 우리WON뱅킹 복사

우리은행은 QR코드·인증번호 등 여러 복사 방식을 공식 지원합니다. 다음은 일반적인 개인 고객용 절차를 기준으로 작성했으며 기업뱅킹과 앱 업데이트에 따라 메뉴가 달라질 수 있습니다.

PC에서

  1. 우리은행 공식 웹사이트의 개인 인증센터로 이동합니다.
  2. 스마트폰 공동인증서 복사를 선택합니다.
  3. PC → 스마트기기 보내기에서 QR코드 또는 인증번호 방식을 선택합니다.
  4. 복사할 공동인증서를 선택하고 비밀번호를 입력합니다.
  5. PC 화면에 표시된 QR코드 또는 승인번호를 준비합니다.

스마트폰에서

  1. 우리WON뱅킹 앱을 실행합니다.
  2. 전체메뉴 → 인증/보안 → 인증 → 공동인증서 → PC에서 가져오기로 이동합니다.
  3. PC와 같은 QR코드 또는 인증번호 방식을 선택합니다.
  4. 화면의 안내대로 QR코드를 촬영하거나 인증번호를 입력합니다.
  5. 완료 메시지와 인증서 목록을 확인합니다.

우리은행 공식 페이지에는 QR코드·인증번호 방식과 전용 프로그램 keysharp CertRelay 관련 설치 안내가 있습니다.

주의: 우리은행의 서비스에는 12자리 인증번호라고 안내된 화면이 있습니다. 실제 입력 자리수는 현재 이용하는 개인/기업, 복사 방식, 해당 화면을 기준으로 확인하세요.

6. 스마트폰에 있는 공동인증서를 PC로 복사하기

스마트폰에서 사용하던 인증서를 새 노트북으로 옮기는 경우도 있습니다. 스마트폰이 보내는 쪽, PC가 받는 쪽이라는 점만 다릅니다.

기본 순서

  1. PC에서 은행 공식 인증센터의 스마트폰 → PC 메뉴를 엽니다.
  2. 인증서 가져오기를 선택하고 PC 화면에 표시되는 승인번호·인증번호를 확인합니다.
  3. 스마트폰 은행 앱에서 인증센터 → 공동인증서 → PC로 내보내기를 선택합니다.
  4. 내보낼 인증서를 선택하고 비밀번호를 입력합니다.
  5. PC에서 받은 승인번호를 스마트폰 화면에 입력합니다.
  6. 전송 완료 후 PC의 인증서 저장장치를 선택합니다.
  7. PC의 공동인증서 목록에 복사한 인증서가 보이는지 확인합니다.

KB국민은행 공식 안내에는 KB스타뱅킹 전체메뉴 → 인증센터 → 공동인증서 → 인증서 내보내기 → PC로 내보내기, 이후 스마트폰에서 생성된 13자리 승인번호를 PC에 입력하는 순서가 제시돼 있습니다.

우리은행은 스마트폰에서 인증/보안 → 공동인증서 → PC로 내보내기를 선택하고 PC의 가져오기 화면에 표시된 인증번호를 스마트폰에 입력하도록 안내합니다. 즉, 번호가 어느 기기에서 생성되는지도 두 은행의 안내가 다를 수 있습니다.

공식 출처: KB국민은행 — 스마트폰에서 PC로 내보내기, 우리은행 — 스마트폰에서 PC로 복사

7. USB에 있는 공동인증서를 PC로 복사하는 방법

인증서가 USB에 있는 경우에는 스마트폰 QR코드가 아닌 저장매체 복사 기능을 이용할 수 있습니다.

  1. USB를 본인이 신뢰하는 PC에 연결합니다.
  2. 인증서가 발급된 은행·인증기관의 공식 인증센터로 이동합니다.
  3. 공동인증서 관리 → 인증서 복사 또는 인증서 가져오기를 선택합니다.
  4. 원본 저장매체로 이동식 디스크(USB)를 선택합니다.
  5. 복사할 인증서의 이름·발급자·만료일을 확인합니다.
  6. 저장할 대상(PC 등)을 선택하고 인증서 비밀번호를 입력합니다.
  7. 복사 완료 후 PC의 인증서 선택창에서 동일한 인증서가 보이는지 확인합니다.

KB국민은행 기업 인증센터는 이동식디스크 → PC 인증서 복사 절차에서 원본 저장매체를 선택하고 인증서 암호를 입력하는 순서를 공식적으로 안내합니다.

권장: USB의 보안 인증서 폴더를 모르는 상태에서 임의로 잘라내기·삭제·압축해 옮기는 대신, 금융기관의 인증서 복사 기능을 이용하는 편이 안전합니다.

공식 출처: KB국민은행 — 이동식디스크에서 PC로 인증서 복사

8. 은행 앱에서 '공동인증서가 없습니다'가 뜰 때

모바일 은행 앱에서 "인증서 없음"이나 "사용 가능한 인증서가 없습니다"라고 나오면, 인증서가 발급되지 않은 것인지, 복사되지 않은 것인지, 해당 은행에 등록되지 않은 것인지부터 구분합니다.

점검 순서

  1. 예전에 이용하던 PC 또는 USB에 공동인증서가 있는지 확인합니다.
  2. 기존 휴대폰의 은행 앱에서 인증서 목록이 보이는지 확인합니다.
  3. 은행이 제공하는 PC → 스마트폰 복사 또는 스마트폰 → 스마트폰 간 이동 지원 절차를 확인합니다.
  4. 신규 스마트폰의 앱에서 PC에서 가져오기 기능으로 복사합니다.
  5. 다른 은행에서 발급받은 인증서라면 타기관 인증서 등록이 필요한지 확인합니다.
  6. 만료된 인증서라면 해당 발급기관의 갱신·재발급 방법을 확인합니다.

우리은행 FAQ는 PC/USB에 인증서가 있다면 복사, 스마트폰에 저장되어 있지 않다면 인증서 발급 또는 복사가 필요하다고 안내합니다.

주의: 발급기관이 다른 인증서를 앱에 복사했다고 해서 이용 기관의 등록 절차가 자동으로 끝나는 것은 아닙니다.

공식 출처: 우리은행 — 스마트뱅킹 인증서가 없을 때 FAQ, SignKorea — 타 이용기관 복사 안내

9. 승인번호·인증번호가 틀리다고 나올 때

가장 흔히 혼동하는 부분은 번호 길이와 입력 방향입니다. 은행과 방법이 다르기 때문에 하나의 숫자 규칙으로 해결할 수 없습니다.

발생 상황가능한 원인해결 방향
13자리를 요구하는데 12자리가 표시됨서로 다른 은행·복사 방식을 열어둠PC와 앱에서 같은 금융기관·같은 방향 선택
번호가 보이지만 전송 실패입력 시간이 경과했거나 연결이 끊김처음부터 새 번호를 생성해 다시 시도
PC에 인증서가 표시되지 않음다른 사용자 PC·저장매체 선택 오류인증서 원본 저장매체 다시 확인
QR코드를 인식하지 못함앱 권한 또는 복사 화면 불일치공식 인증번호 방식으로 변경
복사 도중 설치창이 반복됨인증서 복사 프로그램 설치 오류해당 은행 공식 설치 안내 확인
비밀번호 오류공동인증서 비밀번호와 로그인 비밀번호를 혼동해당 공동인증서 암호 확인
전송 완료인데 로그인 안 됨타기관 등록·인증서 종류·만료 문제복사와 이용등록을 구분해 점검

실제 사례: KB국민은행 스타뱅킹 화면에 나온 13자리 승인번호와 우리은행의 12자리 안내 화면을 서로 바꿔 입력하면 절차가 맞지 않습니다. 인증번호 자리수를 임의로 늘리거나 줄여 입력하지 말고 양쪽 화면 모두 같은 은행·같은 복사 절차인지 확인하세요.

10. 복사 프로그램 설치 오류 해결

공동인증서 복사 페이지에서 버튼이 눌리지 않거나 보안 프로그램 설치가 반복될 수 있습니다.

우선 점검

  1. 현재 이용 중인 은행의 공식 인증센터인지 주소를 확인합니다.
  2. 은행이 안내하는 지원 운영체제·브라우저를 확인합니다.
  3. 복사 프로그램이 필요한 경우 공식 페이지에서 설치합니다.
  4. 설치 후 브라우저를 종료하고 다시 실행해야 하는지 안내를 확인합니다.
  5. 은행 공식 안내에 명시된 경우에만 기존 관련 프로그램을 정상 제거한 후 다시 설치합니다.
  6. 기업 PC라면 사내 보안정책에 따라 IT 관리자에게 문의합니다.

우리은행은 스마트폰 공동인증서 복사에 keysharp CertRelay 프로그램을 사용하며, 설치 문제가 있을 때 공식 페이지의 재설치 방법을 따르도록 안내합니다.

한국전자인증의 스마트폰 복사 서비스는 별도의 통합인증센터 앱을 요구합니다. 한국전자인증은 해당 방식에 대해 Mac·Linux 미지원도 별도로 안내하므로, 다른 은행의 복사 서비스를 모든 운영체제에 그대로 적용할 수는 없습니다.

보안 경고: '보안 프로그램 설치 오류 해결'을 이유로 출처가 불분명한 다운로드 링크를 누르거나, 인터넷 검색 결과에 나온 원격제어 프로그램을 설치하지 마세요.

공식 출처: 우리은행 — 인증서 복사 프로그램 안내, 한국전자인증 — 인증서 관리와 스마트폰 복사

11. 인증서 비밀번호가 틀릴 때

인증서 복사 시 요구하는 암호는 해당 은행의 인터넷뱅킹 로그인 비밀번호, 계좌 비밀번호, 휴대폰 잠금 PIN과 동일하다고 볼 수 없습니다.

  • 인증서 암호: 발급받은 공동인증서에 설정한 비밀번호
  • 은행 앱 비밀번호: 은행 앱 로그인·인증에 이용하는 별도 비밀번호
  • 간편비밀번호: 앱별 간편인증용 PIN
  • 승인번호: PC와 스마트폰 복사 화면을 연결할 때 생성되는 일회성 번호

복사가 실패하면 오류가 난 쪽이 PC인지 은행 앱인지, 인증서 선택 전인지 승인번호 입력 후인지만 적어 두세요. 상담에 인증서 암호나 승인번호를 전달할 필요는 없습니다.

인증서 암호가 기억나지 않는 경우, 복사 기능이 암호를 찾아주지는 않습니다. 인증서를 발급한 기관에서 비밀번호 변경 가능 조건과 재발급 절차를 확인해야 합니다. 비공식 '인증서 비밀번호 복구 도구'에 인증서 파일을 업로드하지 마세요.

12. 공동인증서가 만료됐거나 갱신한 직후라면?

복사를 시도한 인증서가 이미 만료됐거나, 예전 기기에 갱신 전 인증서가 남아 있다면 사용 시 문제가 생길 수 있습니다.

확인 방법

  1. 기존 기기에서 인증서 선택창을 엽니다.
  2. 인증서의 발급기관·유효기간·사용자 이름을 확인합니다.
  3. 새 기기의 인증서 정보와 비교합니다.
  4. 갱신·재발급했다면 현재 유효한 인증서를 새 기기에 다시 복사합니다.
  5. 필요한 경우 이용 기관에서 타기관 인증서 등록을 다시 확인합니다.

갱신과 재발급은 다른 절차입니다. 발급기관별 유효기간·갱신 가능 기간·재발급 조건이 달라질 수 있으므로, 특정 은행의 안내를 모든 인증서에 적용하지 마세요.

13. 아이폰과 갤럭시에서 방식이 다르나요?

은행 공식 안내는 안드로이드와 iOS 모두 스마트폰 공동인증서 복사 대상으로 안내하는 경우가 있습니다. KB국민은행의 KB스타뱅킹과 우리은행 모두 Android/iPhone을 대상으로 하는 복사 절차를 제공합니다.

다만 다음 사항은 확인이 필요합니다.

  • 운영체제별 앱 최신 버전
  • 은행 앱의 카메라 접근 권한(QR코드 사용 시)
  • 앱 안에 공동인증서가 제대로 저장됐는지
  • PC에서 쓰는 브라우저와 보안 프로그램 호환성
  • 인증서 발급기관과 은행별 서비스의 지원 범위

갤럭시의 인증서를 파일 앱으로 옮겨 아이폰에 넣으면 자동 인식된다고 생각하면 안 됩니다. 은행이 제공하는 스마트폰 인증서 복사·가져오기 절차를 이용해야 합니다.

코스콤 SignKorea는 PC→스마트폰 및 스마트폰→PC 복사 경로를 안내하며, 해당 기관의 방식으로 이동되지 않는 경우 이용할 금융기관의 웹사이트에서 진행하라고 설명합니다.

공식 출처: SignKorea — 스마트폰 인증서 복사, KB국민은행 — 안드로이드·iOS용 인증서 복사

14. 타행 인증서 복사 후 다른 은행에서 로그인하려면?

다른 은행에서 발급받은 공동인증서를 가져왔다면 그 은행에서의 이용등록 절차가 필요할 수 있습니다.

예를 들어 A은행에서 발급받은 공동인증서를 B은행 앱에 복사해도 B은행이 그 인증서를 이미 고객의 인증수단으로 등록했다고 판단하는 것은 별개입니다.

우리은행은 공식 스마트뱅킹 FAQ에서 타은행에서 발급한 인증서는 타기관 인증서 등록 후 이용하도록 안내합니다.

따라서 다음 순서로 확인합니다.

  1. 복사 대상이 올바른 공동인증서인지 확인합니다.
  2. 사용하는 B은행 앱에서 인증서가 보이는지 확인합니다.
  3. 해당 은행의 타기관 인증서 등록 메뉴를 찾습니다.
  4. 본인확인·등록 절차를 진행합니다.
  5. 등록 완료 후 실제 로그인 또는 필요한 업무를 테스트합니다.

등록을 위해 필요한 본인확인 절차와 메뉴는 이용 기관별로 다릅니다. 은행마다 동일하다고 단정하지 마세요.

공식 출처: 우리은행 — 타행 인증서 이용·등록 FAQ

15. 새 휴대폰으로 교체했다면 체크할 것

스마트폰을 교체하면서 공동인증서를 이전할 계획이라면 다음 순서가 안전합니다.

  1. 새 휴대폰의 공식 은행 앱을 설치합니다.
  2. 기존 PC 또는 기존 휴대폰에 유효한 공동인증서 원본이 있는지 확인합니다.
  3. 해당 은행이 지원하는 PC → 스마트폰 또는 다른 복사 방식을 이용합니다.
  4. 새 휴대폰에서 인증서 목록에 표시되는지 확인합니다.
  5. 기존에 사용하던 금융기관에서 실제 인증 및 업무 처리가 가능한지 테스트합니다.
  6. 필요한 경우 타행 인증서 등록을 완료합니다.
  7. 새 기기에서 모든 필수 업무가 확인된 후 기존 기기의 초기화·처분을 진행합니다.

주의: 휴대폰 전체 데이터 복원 기능을 사용했다는 이유로 은행 공동인증서가 해당 앱에 정상적으로 이전됐다고 보장할 수 없습니다. 은행별 공동인증서 목록과 인증 성공 여부를 직접 확인해야 합니다.

16. 보안상 꼭 피해야 할 행동

공동인증서는 본인확인과 전자서명에 사용되므로 복사 과정의 보안이 중요합니다.

  • 메신저로 인증서 파일 전송: 파일과 암호가 유출될 위험이 있습니다.
  • 인증번호를 상담원에게 전달: PC·스마트폰 복사 연결에 사용하는 값은 본인에게만 필요한 정보입니다.
  • 검색 광고 링크만 보고 인증센터 접속: 공식 은행 도메인을 직접 확인하세요.
  • 은행 앱 대신 출처가 불명확한 앱 설치: 앱스토어 게시자의 정확한 명칭을 확인하세요.
  • 공용 PC에 인증서 복사: 다른 사람이 이용하는 PC에 개인용 인증서를 보관하지 않는 편이 안전합니다.
  • 복사 완료 전 기존 기기 초기화: 유효한 인증서를 다시 구하기 어려울 수 있습니다.
  • 암호를 일반 텍스트 파일로 저장: 인증서와 암호가 함께 유출될 수 있습니다.

인증서가 도용됐다고 의심되면 발급기관의 폐지·재발급·신고 절차를 확인하세요. 한국전자인증 등 인증기관은 인증서 분실·도용에 따른 폐지·발급차단 관련 안내를 제공합니다.

공식 출처: 한국전자인증 — 인증서 관리, 코스콤 SignKorea 인증서 관리

17. 복사 완료 여부를 확인하는 방법

복사 도중 '완료' 메시지가 한 번 떴다고 해도 최종 확인이 필요합니다.

  1. 받는 기기에서 해당 은행의 공식 앱·인증서 선택창을 엽니다.
  2. 이전한 공동인증서가 이름·발급기관·만료일과 함께 나타나는지 확인합니다.
  3. 정상적인 은행 인증절차를 진행할 수 있는지 확인합니다.
  4. 다른 은행에서 사용할 계획이라면 타기관 인증서 등록이 필요한지 확인합니다.
  5. 가능하다면 원본 PC에서도 같은 인증서가 정상 사용되는지 확인합니다.
  6. 모두 정상인 것이 확인될 때까지 원본 기기의 인증서를 임의로 삭제하지 않습니다.

복사와 이동을 혼동하지 마세요. 은행은 같은 공동인증서를 PC와 스마트폰에서 함께 사용할 수 있다고 안내합니다. 복사 단계에서 PC의 원본을 지울 필요가 있다고 가정하지 마세요.

18. 자주 묻는 질문(FAQ)

Q1. 공동인증서를 PC에서 스마트폰으로 복사하려면 어디로 들어가나요?

일반적으로 발급받았거나 이용 중인 은행의 공식 홈페이지 → 인증센터 → 공동인증서 → 스마트폰 인증서 복사에서 시작합니다. 스마트폰에는 해당 은행 앱의 PC에서 가져오기를 엽니다.

Q2. 공동인증서 복사 승인번호는 몇 자리인가요?

은행과 복사 서비스에 따라 다릅니다. KB국민은행 KB스타뱅킹 공식 안내에는 13자리, 우리은행의 일부 인증번호 복사 페이지에는 12자리가 안내됩니다. 현재 열려 있는 화면에 맞춰 입력하세요.

Q3. 국민은행 공동인증서 PC에서 스마트폰으로 복사하는 방법은?

KB스타뱅킹에서 인증센터 → 공동인증서 → 인증서 가져오기 → PC에서 가져오기를 열고 PC의 PC→스마트폰 인증서 복사 화면에서 생성한 번호·QR코드를 이용합니다.

Q4. 우리은행 PC에 있는 인증서를 휴대폰으로 옮기려면?

우리은행 개인 인증센터의 스마트폰 공동인증서 복사와 우리WON뱅킹의 인증/보안 → 인증 → 공동인증서 → PC에서 가져오기를 이용합니다. QR코드·인증번호 방식이 제공됩니다.

Q5. 스마트폰에 공동인증서가 없다고 나옵니다.

PC·USB·예전 휴대폰에 유효한 공동인증서 원본이 있는지 확인하세요. 원본이 있으면 복사, 없다면 발급기관의 발급·재발급 절차를 확인합니다.

Q6. 공동인증서를 USB에서 PC로 옮겨도 되나요?

은행이나 인증기관이 제공하는 이동식디스크 → PC 인증서 복사 메뉴를 이용할 수 있습니다. 원본 저장매체와 저장할 PC를 정확히 선택하세요.

Q7. 금융인증서도 같은 방식으로 복사하나요?

아닙니다. 공동인증서와 금융인증서는 구별해야 합니다. 금융인증서는 해당 금융인증 서비스의 이용 안내를 확인하세요.

Q8. QR코드가 인식되지 않으면 어떻게 하나요?

양쪽 화면이 같은 은행·같은 복사 방향인지 확인하고, 가능하다면 공식 인증번호 방식으로 변경합니다. QR코드 촬영이 필요할 경우 은행 앱의 카메라 권한도 확인하세요.

Q9. 공동인증서가 만료됐는데 복사하면 사용할 수 있나요?

기존 인증서가 만료됐다면 복사만으로 유효기간이 늘어나지 않습니다. 발급기관의 갱신·재발급 절차를 확인하세요.

Q10. 아이폰도 공동인증서를 복사할 수 있나요?

KB국민은행과 우리은행 등은 iOS용 스마트폰 인증서 복사를 안내합니다. 단, 지원 기기·앱 버전·인증서 종류는 확인이 필요합니다.

Q11. 타은행에서 발급한 공동인증서를 복사했는데 로그인되지 않아요.

인증서 복사 후 이용할 은행에서 타기관 인증서 등록이 필요한지 확인하세요. 복사 완료가 곧 이용기관 등록 완료를 의미하지는 않습니다.

Q12. 스마트폰에서 PC로 옮기면 휴대폰 인증서가 사라지나요?

은행 공식 안내는 여러 기기에서 같은 공동인증서를 사용하기 위한 복사 절차를 제공합니다. 다만 실제 서비스에서 복사 완료 후 양쪽 기기의 인증서 목록을 각각 확인하세요.

19. 최종 체크리스트

  • ☐ 내 인증서가 공동인증서인지 확인했다.
  • ☐ 인증서 원본이 있는 기기와 받는 기기를 구분했다.
  • ☐ 은행·인증기관 공식 사이트 및 공식 앱을 이용했다.
  • ☐ 공동인증서 발급자·사용자·만료일을 확인했다.
  • ☐ PC와 스마트폰에서 같은 은행·같은 복사 방향을 선택했다.
  • ☐ 승인번호 자리수를 현재 화면 기준으로 확인했다.
  • ☐ QR코드 방식이 안 되면 공식 인증번호 방식을 검토했다.
  • ☐ 프로그램 설치는 공식 은행 안내로만 진행했다.
  • ☐ 복사 후 받는 기기에서 인증서 목록과 실제 로그인을 확인했다.
  • ☐ 필요한 경우 타기관 인증서 등록을 확인했다.
  • ☐ 원본 기기는 새 기기 인증을 확인하기 전까지 초기화하지 않았다.
  • ☐ 인증서 파일·암호·승인번호를 타인에게 보내지 않았다.
