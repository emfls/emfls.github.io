2. 가장 확실한 방법: USB로 갤럭시 사진 PC에 복사하기

처음 옮기는 경우에는 PC에서 파일 탐색기로 복사하는 방법을 권장합니다. 원본과 사본을 직접 비교하기 쉽기 때문입니다.

  1. 데이터 전송이 가능한 USB 케이블로 갤럭시와 Windows PC를 연결합니다. 충전 전용 케이블은 파일 전송이 안 될 수 있습니다.
  2. 갤럭시 화면의 잠금을 해제합니다.
  3. 휴대전화에 '휴대전화 데이터에 접근 허용' 알림이 나타나면 허용을 누릅니다.
  4. 갤럭시 화면 맨 위에서 아래로 내려 알림창을 연 뒤 'USB로 휴대전화 충전' 또는 USB 설정 알림을 누릅니다.
  5. USB 사용 용도를 **'파일 전송/Android Auto'**로 바꿉니다.
  6. Windows에서 파일 탐색기 → 내 PC → 휴대전화 이름 → 내장 저장공간을 엽니다.
  7. 일반 카메라 사진은 DCIM → Camera에서 찾습니다.
  8. 필요한 파일을 선택해 마우스 오른쪽 단추를 누르고 복사를 선택합니다.
  9. PC의 '사진 백업/2026-11' 같은 새 폴더에서 붙여넣기합니다.
  10. 복사가 끝난 후 PC에서 파일 수, 용량, 실제 사진·동영상 재생 상태를 확인합니다.

여기서 '이동'보다 '복사'를 우선하는 이유가 있습니다. 케이블이 중간에 끊기거나 PC 저장공간이 부족할 때 원본을 곧바로 삭제하면 복구가 어려워질 수 있기 때문입니다. PC 사본을 확인하기 전에는 휴대전화 원본을 삭제하지 마세요.

3. One UI 8부터 '충전만 됨'이 자주 발생하는 이유

삼성전자서비스는 One UI 8부터 보안 강화를 위해 USB 연결 시 기본 사용 용도가 '휴대전화 충전만'으로 설정될 수 있다고 안내합니다. 이전 기기에서 파일 전송 모드로 자동 연결되던 경험만 믿으면 PC가 고장 난 것처럼 느껴질 수 있습니다.

해결 경로는 다음과 같습니다.

  1. 휴대전화와 PC를 USB로 연결합니다.
  2. 갤럭시 잠금을 해제합니다.
  3. 화면 상단 알림창을 내려 USB 충전 관련 알림을 선택합니다.
  4. 파일 전송/Android Auto를 선택합니다.
  5. 필요한 경우 지문·PIN·패턴으로 사용자 인증을 마칩니다.
  6. Windows 파일 탐색기에서 휴대전화 저장공간이 보이는지 다시 확인합니다.

개발자 옵션을 켜거나 USB 디버깅을 활성화할 필요는 없습니다. 일반적인 사진 전송은 삼성전자가 안내하는 표준 USB 파일 전송 기능으로 처리합니다.

4. 갤럭시 사진 저장 위치: DCIM뿐 아니라 다른 폴더도 확인

PC에서 DCIM/Camera가 비어 있다고 갤럭시 사진이 모두 사라졌다는 뜻은 아닙니다. 갤러리에서 보는 사진은 촬영 앱, 스크린샷, 다운로드한 이미지, 메신저에서 저장한 파일, 클라우드 사진 등 여러 위치에서 모여 표시될 수 있습니다.

5. Windows 11 사진 앱의 '가져오기' 기능으로 옮기기

파일 탐색기 대신 Windows 사진 앱으로 가져오는 방법도 있습니다. 여러 장을 선택하고 저장 위치를 지정하고 싶은 경우에 편리합니다.

  1. 갤럭시와 PC를 데이터 케이블로 연결하고 휴대전화 잠금을 해제합니다.
  2. 갤럭시에서 파일 전송 및 데이터 접근 허용을 확인합니다.
  3. PC에서 시작 → 사진 앱을 실행합니다.
  4. 가져오기 → 연결된 장치를 선택합니다.
  5. 검색된 사진·동영상 중 가져올 항목을 선택합니다.
  6. 저장할 PC 폴더를 정한 뒤 가져오기를 실행합니다.
  7. 종료 후 PC에서 사진을 열어 전송 결과를 확인합니다.

Microsoft는 연결된 Android 휴대전화에서 사진을 가져오려면 파일을 전송할 수 있는 케이블과 휴대전화의 잠금 해제가 필요하다고 안내합니다. 검색이 끝나기까지 다소 시간이 걸릴 수 있습니다. 사진 앱에 사진이 없다면 먼저 2~4장의 USB 파일 탐색기 복사가 정상 작동하는지 확인하세요.

공식 출처: Microsoft — 휴대폰에서 PC로 사진 및 비디오 가져오기

6. 케이블 없이 Quick Share로 전송하는 방법

USB 케이블이 없거나 소량의 사진을 빠르게 공유할 때는 Quick Share를 검토할 수 있습니다.

  1. PC에서 지원되는 Quick Share 앱을 준비합니다.
  2. 갤럭시의 갤러리에서 전송할 사진·동영상을 선택합니다.
  3. 공유 → Quick Share를 누릅니다.
  4. 주변 기기 검색에서 자신의 PC를 선택합니다.
  5. PC에 수신 요청이 표시되면 내용을 확인하고 승인합니다.
  6. 전송이 끝난 후 PC의 다운로드 또는 지정된 저장 폴더를 확인합니다.

삼성은 갤럭시 북용 Quick Share를 제공하며, 다른 제조사 PC에는 Google의 Quick Share 사용을 안내합니다. PC에서 Wi-Fi와 Bluetooth를 지원하는지 확인하고 앱 설치 및 기기 검색 요구 조건을 충족해야 합니다.

근처 기기 공유와 QR 코드·연락처 공유는 사용 조건과 제한이 다릅니다. 삼성 공식 안내에 따르면 근처 기기 공유에는 공유 파일 개수·용량 제한이 없지만, QR·연락처 방식에는 파일당 10GB·하루 10GB 제한이 명시돼 있습니다. 대용량 전송 시에는 방식별 조건을 확인하세요.

7. Windows '휴대폰과 연결'은 USB 복사와 무엇이 다를까요?

Windows의 **휴대폰과 연결(Phone Link)**도 Android 스마트폰의 사진을 보고 PC에 저장할 수 있습니다. 하지만 USB로 저장공간 전체를 복사하는 기능과 완전히 같지는 않습니다.

Microsoft는 이 기능에서 최근 사진을 확인하고 사본을 PC에 저장할 수 있다고 안내합니다. 일부 사진 접근 기능은 최근 항목 위주이며, 공식 사진 가져오기 안내에서는 해당 방식이 동영상 가져오기 수단이 아님을 명시합니다. 따라서 휴대전화의 사진·동영상 전체를 장기 보관하려면 USB 파일 복사 또는 공식 클라우드 백업 내보내기가 더 적합할 수 있습니다.

PC에서 설정할 때는 Windows의 휴대폰과 연결 앱과 Android의 Windows와 연결 기능을 열고 안내에 따라 기기 연결과 권한을 설정합니다. 지원하는 앱 버전과 기능은 휴대전화·PC별로 다릅니다.

8. 'PC에서 갤럭시를 인식하지 못합니다' 해결 순서

아래 순서는 데이터를 삭제하거나 시스템을 초기화하지 않고 시도할 수 있는 항목부터 정리했습니다.

① 케이블이 충전 전용인지 확인

충전은 되지만 PC에서 파일이 보이지 않는다면 데이터 전송을 지원하는 다른 케이블을 먼저 사용합니다. 케이블의 모양이 USB-C라고 해서 모든 케이블이 같은 기능을 제공하지는 않습니다.

② PC USB 포트 변경

USB 허브 대신 PC 본체의 다른 USB 포트에 직접 연결해 봅니다. 삼성전자서비스는 데스크톱에서 전면 포트·허브를 사용했을 때 인식 문제가 있으면 본체 뒤쪽 포트에 직접 연결하는 방법을 안내합니다.

③ 휴대전화 잠금 해제 후 권한 확인

파일 탐색기에 스마트폰 이름만 보이고 폴더가 비어 있다면 잠금 화면을 해제하고 데이터 접근 허용을 선택합니다. '허용 안 함'을 누르면 저장공간 내용이 표시되지 않을 수 있습니다.

④ USB 사용 용도를 파일 전송으로 변경

갤럭시 알림창의 USB 설정에서 파일 전송/Android Auto를 다시 선택합니다. One UI 8의 충전 전용 기본 연결 상태를 놓치지 마세요.

⑤ Windows 장치 관리자 확인

Windows 장치 관리자에서 휴대용 장치 또는 USB 관련 항목의 인식 상태를 확인합니다. 인식 문제가 계속되면 삼성전자서비스의 통합 USB 드라이버 안내를 이용하고, 장치·케이블·포트를 교차 점검합니다. 인터넷의 출처 불명 드라이버 다운로드 사이트는 피하세요.

⑥ 한두 장으로 테스트하고 대량 복사는 나눠 진행

몇 장은 복사되는데 수백 장에서 멈춘다면 우선 소량으로 나눠 복사합니다. 전송 도중 케이블을 건드리지 않고 PC 저장공간과 파일명 중복 여부를 확인하세요.

공식 출처: 삼성전자서비스 — 휴대전화와 PC 연결 문제 해결, 삼성전자서비스 — MTP 및 USB 드라이버 확인

9. 옮긴 뒤 PC에 사진이 일부만 보이는 이유

전송에 성공했는데 전체 사진 수가 다르다면 다음을 구분해야 합니다.

  • 폴더 누락: DCIM/Camera 외에 Screenshots·Download·앱별 폴더에 사진이 존재할 수 있습니다.
  • 클라우드 원본: 사진이 Google 포토 등 클라우드에만 있고 휴대전화 로컬 파일은 없을 수 있습니다. 이 경우 해당 서비스에서 원본을 별도로 다운로드해야 합니다.
  • 동영상 누락: '휴대폰과 연결'의 최근 사진 보기 기능은 전체 동영상 백업 기능이 아닙니다.
  • 파일 형식 차이: PC 프로그램이 HEIC·HEIF 등 일부 형식을 바로 표시하지 못할 수 있습니다. 파일이 없다는 뜻과 열 수 없다는 뜻은 다릅니다.
  • SD 카드 위치: 기기가 SD 카드를 지원하고 촬영 저장 위치를 바꿨다면 내장 저장공간 외 위치를 확인해야 합니다.
  • 복사 중단: 대용량 전송이 중간에 중지됐다면 마지막으로 복사된 파일 이후 항목이 빠졌을 수 있습니다.

여러 폴더에 분산된 사진을 옮기는 경우 한 번에 '모든 사진이 이전됐다'고 단정하지 말고 폴더별로 파일 수와 날짜 범위를 확인하세요.

10. 사진을 안전하게 옮겼는지 검증하는 5분 체크리스트

전송 후 중요한 것은 단순히 파일이 보이는지가 아니라 PC에서 실제로 열리는 사본이 존재하는지입니다.

  1. 새로 만든 PC 백업 폴더의 파일 수를 확인합니다.
  2. 원본 폴더와 대조해 파일 수가 크게 다른 경우 누락된 폴더가 있는지 조사합니다.
  3. 오래된 사진·최근 사진·대용량 동영상을 각각 골라 PC에서 열고 재생합니다.
  4. 중요한 사진 몇 개는 PC에서 크기·해상도 등을 확인합니다.
  5. 가능하면 외장 저장장치나 다른 신뢰할 수 있는 백업 공간에도 별도의 사본을 만들어 둡니다.

PC 복사가 확인되기 전에는 갤럭시의 원본을 삭제하지 마세요. Windows 사진 앱이나 파일 탐색기에서 원본 '이동' 작업을 선택하는 것보다는 복사 후 검증을 권장합니다.

11. 자주 묻는 질문

Q. 갤럭시에서 USB로 사진을 옮길 때 충전만 됩니다. 고장인가요?

반드시 고장은 아닙니다. One UI 8에서는 기본적으로 충전 전용 상태일 수 있습니다. 잠금 해제 후 USB 설정에서 파일 전송/Android Auto를 선택하고 데이터 전송 가능한 케이블인지 확인하세요.

Q. USB 디버깅을 켜야 갤럭시 사진을 복사할 수 있나요?

일반적인 MTP 파일 전송에 USB 디버깅은 필요하지 않습니다. 먼저 삼성의 표준 파일 전송 절차를 사용하세요.

Q. DCIM 폴더에 카카오톡에서 저장한 사진이 없어요.

사진을 저장한 앱에 따라 DCIM이 아닌 다른 폴더를 사용할 수 있습니다. 갤럭시 내 파일 앱에서 해당 사진의 실제 저장 위치를 확인하세요.

Q. 삼성 갤럭시 북이 아니어도 Quick Share를 쓸 수 있나요?

삼성은 다른 제조사 Windows PC용 Google Quick Share 사용을 안내합니다. Bluetooth·Wi-Fi 등 지원 조건을 확인하세요.

Q. 모든 사진을 옮기려면 휴대폰과 연결을 쓰면 되나요?

최근 사진 확인과 개별 저장에는 편리하지만 전체 사진·동영상 원본 백업을 보장하지 않습니다. 용도에 따라 USB 파일 복사나 공식 클라우드 내보내기를 이용하세요.

Q. PC에서 파일이 보이면 갤럭시 사진을 바로 삭제해도 되나요?

권장하지 않습니다. PC에 복사된 파일이 실제 열리고 재생되는지 확인하고, 중요한 자료는 사본을 하나 더 만든 뒤에 삭제 여부를 결정하세요.

Q. 스마트 스위치로 백업하면 사진을 바로 확인할 수 있나요?

Smart Switch의 기기 백업·복원과 일반 JPG·MP4 파일을 PC 폴더에 복사하는 작업은 목적이 다릅니다. 바로 열어보고 폴더별로 보관할 파일이 필요하다면 파일 탐색기나 사진 앱으로 별도 복사하세요.
