메타 설명: 엑셀 파일 열기 암호 걸기와 해제 방법을 Windows Excel 기준으로 안내합니다. 시트 보호·통합 문서 보호·읽기 전용 차이와 비밀번호 분실 시 대처까지 확인하세요.

기준일: 2026년 11월 4일. Microsoft 365용 Excel 및 Excel 2024·2021 등 데스크톱 앱 기준이며, 버전과 운영체제에 따라 버튼명이 다를 수 있습니다.

엑셀로 정산표, 급여내역, 거래처 명단을 보내기 전에 비밀번호를 걸려는 사람이 많습니다. 그런데 Excel에는 이름이 비슷한 보호 기능이 세 가지 있습니다. 잘못 선택하면 파일을 여는 것은 막지 못하고 셀 수정만 제한할 수 있습니다. 먼저 누가 파일을 열지 못하게 할 것인지, 누가 내용을 고치지 못하게 할 것인지를 정해야 합니다.

1. 먼저 구별하세요: 파일 암호·시트 보호·통합 문서 보호

원하는 결과선택할 기능실제로 막는 동작
비밀번호 없이는 엑셀 파일 자체를 못 열게 하기파일 > 정보 > 통합 문서 보호 > 암호로 암호화파일 내용 열기
셀이나 수식을 실수로 수정하지 못하게 하기검토 > 시트 보호선택한 워크시트의 수정 작업
시트 추가·삭제·이름 변경 등을 막기검토 > 통합 문서 보호통합 문서의 시트 구조 변경
다른 사람에게 내용을 보여주되 수정은 가급적 피하게 하기읽기 전용 또는 권한 설정수정 방식 또는 접근 권한(방식별 차이 존재)

핵심: 검토 탭의 ‘통합 문서 보호’는 파일을 여는 비밀번호와 같은 기능이 아닙니다. 시트 보호도 암호화된 파일을 만드는 기능이 아닙니다.

공식 근거: Microsoft — Excel 파일 보호, Microsoft — Excel의 보호 및 보안.

2. 윈도우 Excel에서 파일 열기 비밀번호 걸기

계속 사용할 원본을 보존하려면 먼저 복사본을 만들고 다음 순서로 진행하세요.

  1. 암호를 설정할 .xlsx 파일을 Excel 데스크톱 앱에서 엽니다.
  2. 왼쪽 위 파일 > 정보 메뉴로 이동합니다.
  3. 통합 문서 보호 > 암호로 암호화를 선택합니다. 검토 탭에서 같은 이름처럼 보이는 메뉴를 누르는 것이 아닙니다.
  4. 설정할 비밀번호를 입력하고 확인을 누릅니다.
  5. 같은 비밀번호를 다시 입력해 확인합니다.
  6. 저장(Ctrl+S)합니다.
  7. 파일을 닫은 다음 다시 열어 비밀번호 입력창이 나타나는지 시험합니다.

테스트할 때는 암호를 모르는 사람의 관점에서 새로 열어야 합니다. 단순히 메뉴에 보호 표시가 있다고 해서 파일 배포에 필요한 확인이 끝난 것은 아닙니다.

암호를 정할 때 주의할 점

대소문자를 구별하므로 입력 언어와 Caps Lock을 확인하세요. 이름·생일·휴대폰 번호처럼 추측하기 쉬운 암호 대신 길고 고유한 암호를 사용하고, 신뢰할 수 있는 비밀번호 관리자 등에 별도 보관하세요. Microsoft는 분실한 파일 암호를 대신 찾아줄 수 없다고 명시합니다. 암호가 걸린 파일과 비밀번호를 같은 메시지에 함께 보내는 방식도 피하는 편이 좋습니다.

3. 기존 비밀번호 해제 또는 변경하기

암호를 알고 있고, 이미 파일을 열 수 있는 경우에만 다음 방법을 이용할 수 있습니다.

  1. 현재 비밀번호를 입력해 파일을 엽니다.
  2. 파일 > 정보 > 통합 문서 보호 > 암호로 암호화를 차례로 선택합니다.
  3. 비밀번호 입력 상자에 기존 암호가 표시된다면 내용을 모두 지우고 빈칸으로 둡니다. 암호를 바꾸려면 새 암호를 입력합니다.
  4. 확인을 누르고 파일을 저장합니다.
  5. 파일을 닫았다 다시 열어, 해제된 경우에는 비밀번호를 묻지 않는지, 변경된 경우에는 새 암호가 적용됐는지 확인합니다.

조직의 정보보호 정책이나 권한 관리가 별도로 적용된 파일은 암호를 지우는 것만으로 모든 접근 제한이 없어지지 않을 수 있습니다. 공유한 기존 파일과 별개로 저장된 사본도 있는지 확인하세요.

4. 특정 셀만 수정 가능하게 하려면 ‘시트 보호’

예를 들어 직원에게 신청서의 이름·금액 입력칸만 열어 주고 나머지 계산식을 보호하고 싶을 때 파일 열기 암호보다 시트 보호가 적합합니다.

  1. 수정해도 되는 입력 셀을 먼저 선택합니다.
  2. 셀 서식 > 보호에서 해당 셀의 잠금을 해제합니다.
  3. 검토 > 시트 보호로 이동합니다.
  4. 사용자가 허용받을 작업을 선택하고, 필요하면 시트 보호 해제용 비밀번호를 설정합니다.
  5. 보호 후 입력 셀은 수정되고 계산 셀은 수정되지 않는지 검증합니다.

셀을 모두 잠근 채 시트 보호만 켜면 정작 사용자가 써야 할 입력칸까지 편집하지 못할 수 있습니다. 시트 보호는 실수로 수식을 덮어쓰는 일을 줄이는 기능이지, 민감정보를 안전하게 숨기는 암호화 기능이 아닙니다.

공식 근거: Microsoft — 워크시트 보호.

5. 시트 이름 변경·삭제를 막으려면 ‘통합 문서 보호’

시트가 여러 개인 월별 매출 파일에서 누군가 시트 이름을 바꾸거나 삭제하면 집계 구조가 깨질 수 있습니다. 이때는 검토 > 통합 문서 보호에서 통합 문서의 구조를 보호할 수 있습니다. 암호를 설정했다면 해제할 때도 그 암호가 필요합니다.

다만 시트 구조를 잠그는 것과 파일을 열지 못하게 하는 것은 별개입니다. 외부에 보내는 파일의 내용을 숨겨야 한다면 파일 수준 암호화를 따로 검토하세요.

공식 근거: Microsoft — 통합 문서 보호.

6. 비밀번호를 걸었는데 파일이 그대로 열린다면?

문제를 다음 순서로 나누어 살펴보세요.

  • 시트가 편집되지 않을 뿐, 파일은 열린다: 검토 > 시트 보호 또는 통합 문서 보호만 적용했을 가능성이 있습니다. 파일 > 정보의 ‘암호로 암호화’ 설정을 확인하세요.
  • 암호 설정 직후 다른 PC에서 그냥 열린다: 암호 입력 뒤 파일을 저장하지 않았거나 다른 복사본을 열었을 수 있습니다. 실제 전달할 파일 이름·저장 경로를 확인하세요.
  • 읽기 전용으로만 열린다: 파일 열기 암호와 다른 문제일 수 있습니다. 편집 권한, 파일을 사용 중인 사람, OneDrive 동기화 상태 등을 별도로 확인하세요.
  • 암호를 맞게 쳤는데 실패한다: 대소문자·한영 입력·앞뒤 공백을 점검하고, 파일 소유자에게 정확한 암호나 최신 사본을 요청하세요.
  • 웹용 Excel에서 암호 메뉴를 찾을 수 없다: 웹용 Excel은 파일의 암호를 추가·변경·삭제하는 기능에 제한이 있습니다. 이러한 작업은 데스크톱 Excel에서 진행하는 것이 적절합니다.

참고: Microsoft — 편집을 위해 잠긴 Excel 파일, Microsoft — 통합 문서 보호와 웹용 Excel.

7. 암호를 잊어버렸다면 어떻게 하나요?

정식 암호 없이 파일을 해제할 수 있다고 가정하면 안 됩니다. Microsoft는 파일 수준 비밀번호를 분실하면 암호를 복구해 주지 못한다고 안내합니다.

소유한 문서라면 먼저 이전 버전, 암호를 걸기 전의 별도 백업, 원본 작성자가 보관한 복사본, 조직에서 허용한 복원 절차를 확인하세요. 제3자 ‘암호 해제 사이트’에 급여·계좌번호가 포함된 문서를 업로드하면 정보가 노출될 위험이 있습니다. 암호 분실과 파일 손상은 다른 문제이므로 무작정 ‘열기 및 복구’를 반복하는 것도 해결책이 아닙니다.

8. 자주 묻는 질문

Q. 검토 탭에서 통합 문서 보호만 눌렀는데 왜 열기 암호가 없나요?

검토 탭의 통합 문서 보호는 주로 시트 구조 변경을 제한합니다. 파일을 열 때 암호를 요구하려면 파일 > 정보 > 통합 문서 보호 > 암호로 암호화를 선택하세요.

Q. 시트 보호를 걸어도 셀 내용을 다른 사람이 볼 수 있나요?

일반적인 시트 보호는 편집을 제한할 뿐 파일의 내용을 비밀로 만드는 기능이 아닙니다. 내용을 열람할 수 없게 해야 하면 파일 암호화나 별도의 적절한 접근권한 설정이 필요합니다.

Q. 암호를 해제했는데 공유받은 사람은 계속 암호 입력창을 봅니다.

서로 다른 파일 복사본을 사용 중일 수 있습니다. 현재 저장된 파일을 다시 열어 확인한 뒤, 권한이 있는 상대방에게 올바른 최신 사본을 전달하세요. 조직 공유 드라이브는 버전·동기화 상태도 확인해야 합니다.

Q. 휴대폰이나 웹용 Excel에서도 같은 메뉴가 보이나요?

기기·앱 버전에 따라 지원되는 보호 기능과 메뉴 위치가 다릅니다. 암호 추가·변경·제거는 데스크톱 Excel에서 수행하고 결과를 확인하는 방법이 가장 명확합니다.

Q. Mac도 방법이 똑같나요?

Mac용 Excel은 메뉴와 암호 관리 방법이 다를 수 있습니다. Mac에서 작업한다면 Microsoft — 통합 문서 암호 변경 또는 제거 문서를 확인하세요. 특히 공식 문서에 Mac 버전의 암호 길이와 호환성 주의사항이 안내되어 있습니다.
