외장 SSD나 USB 메모리에 파일을 복사하고 분리하려는데 Windows 11에서 “이 장치는 현재 사용 중입니다”라는 메시지가 나타나는 경우가 있습니다. 파일 탐색기 창을 닫았는데도 오류가 계속되거나, 작업 표시줄에서 안전 제거 아이콘이 보이지 않는 경우도 있습니다.

이때 무조건 케이블을 뽑거나, 장치를 포맷해 해결하려는 것은 적절하지 않습니다. 문제의 원인은 파일을 사용 중인 프로그램, 완료되지 않은 저장·동기화 작업, 외장 저장 장치의 제거 정책 등으로 나뉘기 때문입니다.

이 글에서는 Microsoft의 공식 Windows 11 도움말과 Microsoft Learn, Sysinternals 설명을 바탕으로 파일 저장 확인 → 안전 제거 재시도 → 사용 프로그램 확인 → 제거 정책 점검 → 복사 결과 검증이라는 순서로 해결합니다. 데이터 보존을 우선으로 하는 독자적인 실전 진단 가이드입니다.

1. 우선 증상을 구별하세요

파일 복사 직후 꺼내기 실패후속 파일 작업·동기화대상 파일 열림 여부 확인
안전 제거 아이콘이 안 보임숨겨진 시스템 트레이 아이콘작업 표시줄의 ∧ 표시 확인

USB 드라이브가 처음부터 안 보임인식·케이블·포트 문제안전 제거가 아닌 장치 인식 점검

핵심은 장치가 보이지만 분리할 수 없는 상황과, 장치가 아예 인식되지 않는 상황을 구별하는 것입니다. 두 문제를 같은 해결책으로 다루면 원인을 놓치게 됩니다.

2. Windows 11 기본 안전 제거 절차

Microsoft 지원 문서는 데이터 손실을 방지하기 위해 USB 플래시 드라이브와 외장 하드 드라이브 등을 분리할 때 안전 제거 기능을 사용하도록 안내합니다.

  1. 외장 드라이브에서 실행 중인 파일 복사·이동·저장 작업이 없는지 봅니다.
  2. 외장 드라이브에서 직접 연 문서·사진·영상 파일을 닫습니다.
  3. 작업 표시줄 오른쪽 아래에서 하드웨어 안전하게 제거 및 미디어 꺼내기 아이콘을 찾습니다.
  4. 보이지 않는다면 **숨겨진 아이콘 표시(∧)**를 눌러 봅니다.
  5. 연결된 장치 이름 가운데 제거할 드라이브를 정확히 선택합니다.
  6. 꺼내기를 선택합니다.
  7. 안전하게 제거할 수 있다는 안내가 나타나면 장치를 분리합니다.

외장 드라이브를 여러 개 연결했다면 파일 탐색기의 드라이브 문자와 표시 이름을 먼저 확인하세요. 비슷한 이름의 장치를 선택하면 실제로 사용하려는 저장 장치와 혼동할 수 있습니다.

공식 자료: Microsoft — Windows에서 하드웨어를 안전하게 제거

3. “이 장치는 현재 사용 중입니다”가 표시된다면

사용 중 안내가 뜬다는 사실만으로 어떤 프로그램이 원인인지 알 수는 없습니다. 먼저 안전하게 종료할 수 있는 작업을 점검합니다.

  1. 복사 창 확인: 파일을 외장 SSD로 복사하거나 외장 SSD에서 PC로 이동하는 작업이 끝났는지 확인합니다.
  2. 열린 문서 저장 및 닫기: Word·Excel·PDF 리더·사진 편집·영상 프로그램에서 해당 드라이브 파일을 열어 두었는지 확인합니다.
  3. 탐색기 창 닫기: 해당 드라이브를 보여 주는 파일 탐색기 창과 미리보기를 닫습니다.
  4. 백업·동기화 확인: 외장 드라이브를 대상으로 하는 백업, 파일 동기화, 백신 검사가 진행 중인지 점검합니다.
  5. 안전 제거 재시도: 관련 작업이 정상 종료된 뒤 다시 꺼내기를 선택합니다.

일부 프로그램은 창이 닫혀 있어도 백그라운드에서 파일을 사용할 수 있습니다. 따라서 파일 탐색기만 닫았는데 해결되지 않았다고 곧바로 시스템 오류로 결론 내릴 필요는 없습니다.

피해야 할 행동: 저장 중인 프로그램을 아무렇게나 강제 종료하거나, 오류가 난 상태에서 외장 드라이브 케이블을 급히 빼지 마세요.

4. 파일을 잡고 있는 프로그램을 찾는 공식 방법

Microsoft의 Sysinternals Process Explorer는 현재 프로세스가 열어 둔 파일·디렉터리 등의 핸들을 확인하는 진단 도구입니다. 어떤 프로그램이 특정 파일이나 폴더를 사용 중인지 찾는 기능도 제공합니다.

일반 사용자가 먼저 할 일은 모든 프로그램을 강제로 종료하는 것이 아니라, 원인을 확인하는 것입니다.

  1. Microsoft 공식 Process Explorer 설명서를 엽니다.
  2. 외장 드라이브의 문자와 폴더 이름을 확인합니다.
  3. Process Explorer의 찾기 기능으로 해당 파일 또는 경로를 검색합니다.
  4. 관련 프로세스가 발견되면 어떤 앱과 작업인지 확인합니다.
  5. 정상적인 앱이라면 앱 내부에서 작업을 끝내고 종료합니다.
  6. 그다음 안전 제거를 다시 시도합니다.

프로세스 이름을 모르는 경우에는 종료하거나 핸들을 강제로 닫지 않는 것이 안전합니다. 시스템 프로세스, 백업 도구 또는 보안 프로그램이 파일을 쓰는 중일 수 있기 때문입니다.

특히 회사 PC에서는 관리자 정책과 연결된 프로그램일 가능성이 있으므로 IT 담당자의 도움을 받는 편이 적절합니다.

공식 자료: Microsoft Sysinternals — Process Explorer

5. 안전 제거 아이콘이 없다면

아이콘이 없다고 반드시 외장 SSD에 오류가 생긴 것은 아닙니다. Microsoft는 먼저 시스템 트레이의 숨겨진 아이콘 영역을 확인하라고 안내합니다.

또한 Windows 11 도움말에는 설정 → Bluetooth 및 장치 → 장치에서 지원되는 외부 장치를 선택해 제거하는 경로도 제시돼 있습니다. 다만 장치의 유형에 따라 설정 화면에 나타나는 메뉴가 다를 수 있습니다.

확인 순서:

  1. 작업 표시줄 오른쪽 아래에서 숨겨진 아이콘을 확인합니다.
  2. 안전 제거 아이콘이 보이면 연결된 드라이브를 선택합니다.
  3. 그래도 아이콘이 없다면 Microsoft의 장치 설정 안내를 확인합니다.
  4. 해당 USB가 일반 저장 드라이브인지, 스마트폰·프린터 같은 다른 USB 장치인지 구별합니다.
  5. Windows 설정의 장치 제거를 드라이버 제거·포맷과 혼동하지 않습니다.

장치 관리자에서 드라이버를 삭제하는 행동은 일반적인 외장 드라이브 안전 제거 과정과 다릅니다. 단순히 안전 제거 아이콘이 없다는 이유로 드라이버를 지우지 마세요.

6. 빠른 제거와 향상된 성능은 무엇이 다른가요?

Microsoft Learn은 Windows의 외장 스토리지 제거 정책을 두 가지로 설명합니다.

**빠른 제거(Quick removal)**는 장치를 분리하기 쉽도록 관리하며, Microsoft 문서에 따르면 Windows 10 버전 1809 이후 기본 정책입니다. 이 정책에서는 디스크의 쓰기 캐싱이 사용되지 않도록 관리되기 때문에 공식 설명상 안전 제거 절차 없이 제거할 수 있도록 설계됐습니다.

**향상된 성능(Better performance)**은 쓰기 캐싱을 이용할 수 있으며, 이 정책에서는 반드시 하드웨어 안전 제거 과정을 거쳐야 합니다. 캐시에 남아 있는 작업이 끝나도록 보장하기 위해서입니다.

정책공식 설명의 특징제거할 때 주의점
빠른 제거쓰기 캐싱을 하지 않도록 관리진행 중인 실제 파일 작업은 중단하지 않아야 함
향상된 성능외장 드라이브에 쓰기 캐시 사용 가능안전 제거 절차 필수
현재 정책을 모름장치별로 선택·변경 가능추측하지 말고 해당 장치의 정책 확인

빠른 제거는 ‘파일을 저장하는 중에도 뽑아도 안전하다’는 말이 아닙니다. 저장·동기화 중인 작업을 끊는 것은 별도 위험을 만들 수 있습니다. Microsoft의 일반 사용자 안내는 안전 제거를 계속 권장하고 있으므로, 일상에서는 안전 제거 기능을 사용하는 습관이 이해하기 쉽고 안전합니다.

7. 내 외장 SSD의 제거 정책 확인 방법

Microsoft Learn의 공식 설명을 바탕으로 한 확인 순서입니다.

  1. USB 또는 외장 SSD를 컴퓨터에 연결합니다.
  2. 파일 탐색기에서 장치 이름과 드라이브 문자(예: E:)를 확인합니다.
  3. 시작 버튼을 마우스 오른쪽 클릭하고 디스크 관리를 엽니다.
  4. 창의 아래쪽에서 해당 장치의 디스크 레이블을 정확히 찾습니다.
  5. 해당 디스크의 속성을 엽니다.
  6. 정책(Policies) 탭에서 빠른 제거 또는 향상된 성능을 확인합니다.

일부 최신 버전에서는 정책 탭이 다른 위치에 있을 수 있습니다. Microsoft는 이런 경우 하드웨어 탭에서 외장 장치를 선택한 뒤 속성을 열면 정책을 찾을 수 있다고 설명합니다.

디스크 관리에서는 파티션 삭제·포맷·초기화 기능도 제공됩니다. 제거 정책을 확인하려고 데이터를 지우는 기능을 실행해서는 안 됩니다. 시스템 디스크와 외장 디스크를 혼동하지 않도록 주의하세요.

장치마다 정책이 다를 수 있으므로 다른 컴퓨터 또는 다른 저장 장치의 설정을 그대로 가정하지 않습니다.

8. 파일 복사 완료 표시가 떴는데 바로 빼도 될까요?

복사 완료 표시가 나타났다면 진행 상태를 확인하는 중요한 단계입니다. 다만 파일이 완전하게 보관됐는지와 장치에 접근하는 다른 작업이 모두 끝났는지는 별도로 확인할 필요가 있습니다.

특히 외장 SSD에 사진이나 영상, 중요한 계약 문서를 복사했다면 다음과 같이 확인해 보세요.

  • 원본 폴더와 대상 폴더의 파일 수를 비교합니다.
  • 중요한 파일 몇 개의 크기를 확인합니다.
  • 복사한 문서나 영상을 대상 외장 드라이브에서 직접 열어 봅니다.
  • 원본 파일을 지우기 전에 다른 저장소에 백업 사본이 있는지 확인합니다.
  • 안전 제거 후 다시 연결해 주요 파일을 열어 봅니다.

이는 Windows 안전 제거 기능과는 별개의 백업 검증 방법입니다. 안전 제거가 성공했다고 해서 저장된 모든 파일이 원본과 완전히 동일하다는 뜻은 아닙니다.

9. 백신 검사나 클라우드 동기화가 진행 중이라면

백신 프로그램이 외장 드라이브에서 파일을 검사하거나, 백업 프로그램이 파일을 읽고 쓸 수 있습니다. 특정 프로그램이 원인이라는 사실은 해당 PC를 진단해야 확인할 수 있습니다.

확인 순서는 다음과 같습니다.

  1. 외장 저장 장치를 대상으로 한 검사·백업·동기화 작업이 있는지 확인합니다.
  2. 진행 중인 작업을 안전하게 마칠 수 있다면 완료될 때까지 둡니다.
  3. 프로그램 자체의 정상 종료 메뉴를 사용합니다.
  4. 다시 안전 제거를 시도합니다.
  5. 해결되지 않으면 공식 진단 도구 또는 관리자 도움으로 어떤 프로그램이 파일을 사용 중인지 확인합니다.

회사의 보안·백업 정책이 적용된 장치라면 설정을 임의로 변경하거나 보안 기능을 강제 종료하지 마세요.

10. 안전 제거가 끝까지 실패하면 어떻게 하나요?

문제 원인을 찾지 못했고 Windows가 계속 장치 사용 중이라는 메시지를 표시한다면, 데이터가 저장 중이지 않은지 확인하고 정상적으로 컴퓨터를 종료한 다음 분리하는 방법을 고려할 수 있습니다.

이때 주의할 점은 세 가지입니다.

  1. 일반적인 정상 종료와 절전·최대 절전, 강제 전원 차단은 다릅니다.
  2. 시스템 종료가 진행 중인 상태에서 케이블을 급히 분리하지 않습니다.
  3. 종료 뒤에도 외장 드라이브 자체에 전원이 남아 있거나 제조사에서 별도 안전 절차를 안내한다면 해당 지침을 확인합니다.

저장 장치에 이상 소음, 연결 끊김, 접근 오류가 반복된다면 같은 방법을 무한히 시도하지 말고 장치 상태를 점검해야 합니다.

11. 절대로 먼저 하지 말아야 할 행동

외장 SSD 초기화 또는 포맷: 안전 제거 실패 원인을 확인하는 일반적인 첫 단계가 아닙니다. 중요한 자료를 잃을 수 있습니다.

불분명한 시스템 프로세스 강제 종료: 파일을 사용 중인 시스템 구성요소를 종료하면 데이터나 컴퓨터에 영향을 줄 수 있습니다.

장치 관리자에서 드라이버 삭제: 장치 연결 문제를 추가로 만들 수 있으며, 일반적인 안전 제거와 다릅니다.

제거 정책 확인을 위한 레지스트리 변경: Microsoft는 디스크 속성에서 정책을 확인·변경하는 절차를 안내하므로 임의의 인터넷 레지스트리 조작을 먼저 할 이유가 없습니다.

백업 없이 오류 복구 도구 실행: 실제 디스크 손상 여부가 확인되지 않았다면 추가 작업을 늘리기보다 데이터부터 보호해야 합니다.

12. 외장 HDD·SSD·USB 메모리의 차이

외장 HDD, 외장 SSD, USB 메모리는 모두 저장 장치이지만 기기 내부 구조와 연결 방식이 다를 수 있습니다. Microsoft는 USB 메모리와 Thunderbolt 외장 저장 장치를 외부 매체 제거 정책의 적용 예시로 듭니다.

하지만 모든 USB 연결 기기가 같은 저장 드라이브로 인식되는 것은 아닙니다. 예를 들어 스마트폰의 MTP 연결과 일반 이동식 드라이브는 Windows에서 표시·관리되는 방식이 다를 수 있습니다.

장치 모델을 확인하고, 필요한 경우 제조사의 사용 설명서를 참고하세요. 물리적 연결 방식만 보고 정책이 동일하다고 단정하지 않는 것이 좋습니다.

13. 안전 제거 실패 이후 파일이 손상됐다면

강제로 분리한 뒤 외장 드라이브의 문서가 열리지 않는 경우, 반복해서 새 파일을 쓰거나 포맷하기 전에 원본과 데이터 복구 가능성을 확인해야 합니다.

  1. 복사 전 원본이 PC의 다른 드라이브에 남아 있는지 확인합니다.
  2. 중요한 파일이라면 외장 장치에 새로운 데이터를 쓰는 작업을 줄입니다.
  3. 케이블·포트·기기의 물리적 이상 여부를 점검합니다.
  4. 장치를 인식하더라도 오류 메시지를 기록하고 임의의 수리 명령을 반복하지 않습니다.
  5. 데이터가 매우 중요하다면 전문적인 복구 지원을 검토합니다.

이미 손상된 파일을 제거 정책만 변경해 복원할 수는 없습니다. 문제 원인과 필요한 복구 과정은 별도입니다.

14. 사례로 보는 해결 순서

사례 A. 외장 SSD로 20GB 영상을 복사한 직후 ‘사용 중’이 뜬다

복사가 끝났는지와 파일이 정상적으로 열리는지를 확인합니다. 동영상 편집기나 미리보기 프로그램이 외장 SSD에 접근하는지 살펴보고 관련 앱을 정상 종료합니다. 그다음 안전 제거를 재시도합니다.

사례 B. 사진을 미리보기로 본 후 장치를 꺼낼 수 없다

사진 앱이나 파일 탐색기의 미리보기가 파일을 열어 두었을 가능성이 있습니다. 관련 창을 닫고 재시도합니다. 계속 오류가 나면 Process Explorer 같은 도구로 접근 중인 프로세스를 확인할 수 있습니다.

사례 C. 회사 PC에서는 매번 안전 제거가 안 된다

업무용 백업 또는 보안 프로그램이 저장 장치에 접근하고 있을 수 있습니다. 프로그램을 강제로 중지하지 않고 오류 문구, 장치명, 발생 시간을 IT 담당자에게 전달합니다.

사례 D. ‘빠른 제거’ 설정을 발견했다

빠른 제거 정책의 의미를 확인한 뒤, 현재 저장 중인 작업이나 열린 파일이 없는지 점검합니다. Microsoft는 이 정책에서 안전 제거 절차 없이 제거할 수 있다고 설명하지만, 실제 파일 작업까지 중단해도 된다는 뜻은 아닙니다.

15. 자주 묻는 질문

Q1. Windows 11은 USB를 그냥 뽑아도 되나요?

빠른 제거 정책에는 안전 제거 절차를 생략할 수 있는 동작이 설명돼 있습니다. 그러나 진행 중인 저장 작업을 중단해서는 안 됩니다. 정책을 모르겠다면 안전 제거를 이용하는 편이 좋습니다.

Q2. 장치 사용 중 메시지가 반복되면 무조건 바이러스 때문인가요?

아닙니다. 문서 편집, 미리보기, 백업, 동기화 등 여러 프로그램이 원인이 될 수 있습니다. 실제 프로세스를 확인해야 합니다.

Q3. 안전 제거 아이콘이 없으면 드라이버를 다시 설치해야 하나요?

대개 가장 먼저 할 일은 숨겨진 시스템 트레이를 확인하는 것입니다. 장치 제거 아이콘이 없다는 이유만으로 드라이버를 삭제할 필요는 없습니다.

Q4. 향상된 성능과 빠른 제거는 어느 쪽이 더 안전한가요?

두 정책은 쓰기 캐싱과 분리 방식에 차이가 있습니다. 향상된 성능에서는 안전 제거가 반드시 필요합니다. 실제 장치 사용 목적과 정책을 확인하세요.

Q5. 안전 제거가 성공하면 복사한 파일은 100% 정상인가요?

그렇지 않습니다. 중요한 파일은 대상 드라이브에서 직접 열어 보고 원본과 비교하는 별도 검증이 필요합니다.

Q6. 외장 SSD를 분리할 때도 안전 제거를 해야 하나요?

외장 SSD 역시 저장 작업이 진행 중일 수 있습니다. Windows에서 표시되는 정책과 제조사 안내를 확인하고, 일반적으로 안전 제거 기능을 사용하는 습관을 권합니다.

Q7. 강제로 뺐다가 파일이 열리지 않는다면?

새로운 쓰기 작업을 최소화하고 원본 및 다른 백업을 확인하세요. 무작정 포맷하면 복구 가능성에 영향을 줄 수 있습니다.

16. 5분 최종 점검표

  • ☐ 제거하려는 외장 장치의 이름과 드라이브 문자를 확인했다.
  • ☐ 파일 복사·이동·저장 작업이 끝났는지 확인했다.
  • ☐ 외장 장치에 열린 문서와 앱을 정상 종료했다.
  • ☐ 백업·동기화·검사 프로그램의 진행 상황을 확인했다.
  • ☐ 작업 표시줄의 안전 제거 아이콘을 찾아 사용했다.
  • ☐ 계속 실패하면 원인을 확인하고 시스템 프로세스를 함부로 종료하지 않았다.
  • ☐ 내 외장 저장 장치의 빠른 제거·향상된 성능 정책을 확인했다.
  • ☐ 데이터가 중요하다면 원본과 사본을 별도 보관했다.
  • ☐ 포맷과 디스크 초기화를 문제 해결 첫 단계로 사용하지 않았다.
  • ☐ 주요 파일을 실제로 열어 복사 결과를 검증했다.

핵심 요약: USB 안전 제거 오류는 드라이브를 포맷해서 해결하는 문제가 아닙니다. 파일을 어떤 프로그램이 사용 중인지 확인하고, 외장 저장 장치의 제거 정책을 이해한 다음 정상적인 안전 제거를 시도하는 것이 먼저입니다. 특히 빠른 제거 정책과 ‘저장 중 강제 분리’는 같은 의미가 아닙니다.
