64GB USB 메모리에 남은 공간이 30GB인데 5GB짜리 동영상을 복사하자 '대상 파일 시스템에 비해 파일이 너무 큽니다'라는 메시지가 뜨는 경우가 있습니다. 저장 공간이 넉넉한데도 파일이 들어가지 않는 이유는 무엇일까요?

원인은 USB의 전체 용량이 아니라 파일 시스템이 한 개 파일에 허용하는 최대 크기일 수 있습니다. 특히 FAT32 형식의 USB에는 약 4GiB에 이르는 단일 파일을 저장할 수 없습니다. 그렇다고 USB를 바로 포맷하면 중요한 사진과 문서가 삭제될 수 있습니다.

이 글은 Microsoft의 파일 시스템 비교와 Windows 포맷 문서, Apple의 외장 드라이브 지원 안내를 기반으로 현재 형식 확인 → 포맷 없는 대안 검토 → 백업 검증 후 변경이라는 순서로 정리했습니다. 이 3단계 흐름은 독자를 위해 구성한 자체 설명 체계입니다. 검토 기준일은 2026년 11월 1일입니다.

1. USB 공간이 남았는데 큰 파일만 복사되지 않는 이유

USB 전체 용량과 한 개 파일에 허용되는 크기는 서로 다른 개념입니다. 5GB 파일을 저장하려면 USB에 5GB 이상의 공간이 남아야 하지만 그것만으로 충분하지 않을 수 있습니다. 해당 USB의 파일 시스템도 그 크기의 파일을 허용해야 합니다.

Microsoft의 파일 시스템 비교표에 따르면 FAT32의 최대 단일 파일 크기는 약 4GiB이고, exFAT 및 NTFS는 훨씬 큰 개별 파일을 지원합니다. 참고로 4GiB는 4,294,967,296바이트로, 광고나 탐색기 화면에서 흔히 쓰는 '4GB'와 단위가 정확히 일치하지는 않습니다. 따라서 경계 부근의 파일은 반올림된 표시 숫자보다 실제 크기와 오류 문구를 확인하세요.

2. Windows 11에서 USB 파일 시스템 확인하기

이 단계는 파일을 삭제하거나 포맷하지 않는 조회 작업입니다.

  1. USB 메모리 또는 외장 SSD를 연결합니다.
  2. Windows 키 + E를 눌러 파일 탐색기를 엽니다.
  3. 왼쪽 메뉴의 내 PC를 선택합니다.
  4. 대상 USB 드라이브를 마우스 오른쪽 버튼으로 클릭합니다.
  5. 속성을 엽니다.
  6. 일반 탭의 파일 시스템 항목을 확인합니다.
  7. FAT32, exFAT, NTFS 가운데 무엇인지 기록합니다.
  8. 같은 창에서 남은 저장 공간도 확인합니다.

먼저 USB가 FAT32인지 확인하는 것이 중요합니다. 같은 64GB USB라도 FAT32로 준비했을 수 있고 exFAT이나 NTFS로 준비했을 수 있기 때문입니다.

주의: 파일 탐색기에는 내부 디스크와 다른 외장 드라이브도 함께 표시됩니다. USB 이름만 믿지 말고 용량·드라이브 문자·실제 연결 장치가 일치하는지 확인하세요.

3. Mac에서는 어디에서 확인하나요?

Apple의 공식 안내에 따르면 Finder에서 다음과 같이 확인할 수 있습니다.

  1. Mac의 Finder에서 외장 드라이브를 선택합니다.
  2. 메뉴에서 파일 → 정보 가져오기를 선택합니다.
  3. 또는 Command + I를 누릅니다.
  4. 정보 창의 포맷 항목을 확인합니다.
  5. 남은 저장 공간도 함께 확인합니다.

Apple은 macOS에서 NTFS 드라이브를 읽을 수는 있지만 기본적으로 쓰지 못할 수 있다고 설명합니다. 따라서 Windows에서는 정상적으로 저장한 USB가 Mac에서 읽기 전용처럼 동작한다면, FAT32의 4GiB 제한과 별개로 NTFS의 쓰기 지원 여부를 살펴봐야 합니다.

무조건 exFAT이나 NTFS가 더 좋다는 뜻은 아닙니다. 오래된 기기가 FAT32만 지원할 수도 있으며, 특정 제조사가 정해 놓은 조건이 있을 수 있습니다. 어느 파일 시스템이 적합한지는 USB를 연결할 기기와 파일 용도에 따라 결정됩니다.

Microsoft 비교표에는 exFAT이 NTFS와 달리 메타데이터 전용 저널링을 제공하지 않는다는 차이도 설명됩니다. 이것은 즉시 고장이 난다는 뜻이 아니라 파일 시스템의 기능 차이를 말합니다.

5. USB를 포맷하지 않고 해결하는 방법부터 검토하기

USB에 중요한 자료가 있으면 새 포맷을 하기 전에 다른 전송 방법을 먼저 알아보는 편이 안전합니다.

첫 번째 방법: 이미 exFAT이나 NTFS로 된 다른 저장 장치 사용. Windows PC나 Mac 등 실제 사용 장치에서 지원하는 형식이라면 기존 자료를 손대지 않고 큰 파일을 복사할 수 있습니다.

두 번째 방법: 신뢰할 수 있는 다른 전송 경로 이용. 두 컴퓨터 사이에서 파일만 옮기려는 목적이라면 네트워크 파일 공유나 적절한 클라우드 저장소를 사용할 수 있습니다. 다만 민감한 파일은 개인정보와 접근 권한에 주의해야 합니다.

세 번째 방법: 파일 분할. 받는 쪽에서 다시 결합할 수 있고 사용하는 도구를 충분히 이해한다면, 하나의 파일을 제한보다 작은 여러 조각으로 나눌 수 있습니다. 다만 일부 조각이라도 누락되면 복원할 수 없을 수 있으므로 테스트 후 사용하세요.

네 번째 방법: 지원 형식으로 다시 포맷. 앞으로 계속 큰 파일을 USB로 옮겨야 한다면 exFAT으로 바꾸는 방안을 고려할 수 있지만, 반드시 기존 데이터를 다른 곳에 백업한 뒤 진행해야 합니다.

자주 하는 실수: ZIP으로 압축하기만 하면 5GB 영상이 무조건 4GB 이하로 줄어든다고 생각하는 것입니다. 이미 압축된 영상 파일은 압축 효율이 낮을 수 있으며, 결과 파일 하나가 제한보다 크면 FAT32에서는 여전히 복사되지 않습니다.

6. 포맷 전에 반드시 확인해야 할 안전 조건

포맷은 단순히 파일 시스템 이름을 바꾸는 작업이 아닙니다. Microsoft의 공식 포맷 안내는 새 파일 시스템을 만드는 과정에서 저장된 데이터가 삭제될 수 있다고 경고합니다.

포맷을 결정하기 전에 다음을 확인하세요.

  • USB가 실제로 FAT32이며 문제가 단일 파일 크기 제한과 관련되는가?
  • USB 안의 모든 중요한 사진·문서·영상·백업 파일을 다른 장치로 복사했는가?
  • 백업본을 실제로 열어 내용을 확인했는가?
  • 포맷할 USB와 컴퓨터 내장 저장소를 용량과 드라이브 문자로 구별했는가?
  • USB가 Windows 설치·복구용 장치가 아닌가?
  • TV·차량·게임기 등의 사용 기기가 변경하려는 형식을 지원하는가?

특히 빠른 포맷도 데이터를 안전하게 보존하는 기능이 아닙니다. 파일을 다른 곳에 옮기지 않은 상태에서는 빠른 포맷 역시 진행하지 마세요.

자료가 사라져 복구가 필요한 상태라면 새 파일을 쓰거나 포맷을 시도하지 말고, 데이터 복구 가능성을 먼저 검토해야 합니다. 포맷 후에는 이전 데이터의 복구를 보장할 수 없습니다.

공식 자료: Microsoft — Windows format 명령의 데이터 삭제 위험

7. Windows 11에서 exFAT으로 포맷하는 안전한 절차

백업 파일이 정상인지 확인한 뒤에만 다음 작업을 진행하세요. 기존 USB 파일은 삭제될 수 있습니다.

  1. USB를 PC에 연결하고 파일 탐색기를 엽니다.
  2. 내 PC에서 해당 USB를 찾습니다.
  3. 이름, 드라이브 문자, 용량으로 올바른 장치인지 재확인합니다.
  4. USB 드라이브를 마우스 오른쪽 버튼으로 클릭합니다.
  5. 포맷을 선택합니다.
  6. 파일 시스템 목록에서 exFAT을 선택합니다.
  7. 일반적인 파일 저장 용도라면 할당 단위 크기를 기본값으로 둡니다.
  8. 볼륨 이름을 정한 후 데이터 삭제 경고를 확인합니다.
  9. 시작을 눌러 포맷을 진행합니다.
  10. 완료 뒤 USB 속성에 exFAT이 표시되는지 확인합니다.
  11. 작은 테스트 파일을 복사해 실제로 정상 작동하는지 확인합니다.
  12. 백업한 기존 파일을 USB로 다시 복사합니다.

파일 시스템 옵션은 기기의 크기와 종류에 따라 다르게 제공될 수 있습니다. 만약 해당 형식이 나타나지 않거나 포맷 과정에서 오류가 발생하면, 무턱대고 파티션을 삭제하거나 정체를 알 수 없는 포맷 도구를 설치하기보다는 장치 제조사의 공식 지원 자료를 확인하세요.

주의: 내장 시스템 드라이브, 복구 파티션, 부팅용 USB는 일반 자료 보관용 USB와 다릅니다. 잘못된 드라이브 포맷은 Windows 자체나 복구 환경에 영향을 줄 수 있습니다.

공식 자료: Microsoft — format 명령과 파일 시스템 종류

8. Mac에서 exFAT으로 변경하는 방법

Apple은 Mac과 Windows에서 함께 사용할 외장 드라이브를 디스크 유틸리티에서 지우고 포맷하는 공식 절차를 제공합니다.

데이터를 백업하고 복구 가능성을 검증한 다음 아래 단계를 진행하세요.

  1. Mac에서 **디스크 유틸리티(Disk Utility)**를 엽니다.
  2. 보기 → 모든 기기 보기를 선택합니다.
  3. 왼쪽 목록에서 대상 외장 USB를 선택합니다.
  4. 내부 SSD나 다른 외장 저장 장치를 선택하지 않았는지 확인합니다.
  5. **지우기(Erase)**를 선택합니다.
  6. 이름을 지정하고 형식에서 exFAT을 선택합니다.
  7. 필요한 경우 연결할 기기의 요구에 맞는 파티션 방식을 선택합니다.
  8. 데이터 삭제 경고를 확인한 뒤 진행합니다.
  9. 완료 후 Finder에서 포맷 정보를 다시 확인합니다.
  10. 테스트 파일을 넣어 정상적으로 쓰고 읽을 수 있는지 확인합니다.

Apple은 Windows 컴퓨터와 파일을 주고받는 장치에 대해 MS-DOS(FAT) 또는 exFAT 형식을 안내합니다. 그러나 이는 사용 목적에 따른 안내이며, 모든 구형 장치가 exFAT을 지원한다는 보장은 아닙니다.

9. TV·차량·게임기에서는 왜 exFAT USB가 인식되지 않을까?

파일 시스템은 PC뿐 아니라 USB를 읽는 기기에서도 지원해야 합니다. 구형 TV, 자동차 오디오, 게임기, 인화기, 산업용 장비 등에서는 지원 목록이 다를 수 있습니다.

포맷하기 전에 기기의 설명서에서 다음을 확인하세요.

  • 지원 파일 시스템이 FAT32·exFAT·NTFS 중 무엇인가?
  • 지원하는 USB 저장 용량에 제한이 있는가?
  • MBR·GPT처럼 파티션 형식에 요구 조건이 있는가?
  • 영상 파일이 목적이라면 지원하는 코덱과 확장명은 무엇인가?

예를 들어 USB가 인식되는데 동영상만 재생되지 않는다면 파일 시스템이 아니라 영상 코덱의 문제일 수 있습니다. 반대로 파일은 정상인데 기기가 USB를 아예 읽지 못한다면 지원 저장 형식도 확인할 필요가 있습니다.

이 경우에는 '큰 파일을 옮기려면 무조건 exFAT이 정답'이라고 결론 내리기보다 장치의 공식 요구 형식을 우선해야 합니다. 서로 다른 용도에 맞는 USB를 별도로 사용하는 편이 간단할 수도 있습니다.

10. 실제로는 다른 원인일 수 있는 경우

파일 복사가 실패한다고 언제나 FAT32 때문은 아닙니다.

증상먼저 확인할 문제
5GB 동영상만 복사 실패, USB는 FAT32단일 파일 크기 한계
USB가 exFAT인데도 5GB 파일이 실패남은 공간·장치 상태·실제 대상 경로
500MB 파일도 복사 실패쓰기 방지·저장 용량·오류·연결
Mac에서 읽을 수 있지만 저장 불가NTFS 기본 쓰기 제한 등
복사는 됐는데 파일이 열리지 않음파일 손상·원본 문제·복사 검증
다른 PC에서도 USB가 보이지 않음저장 장치 이상·파티션·연결 문제

현재 파일 시스템이 exFAT으로 표시된다면 FAT32 제한을 고치기 위해 다시 포맷할 이유는 없습니다. 특히 모든 작은 파일조차 복사할 수 없다면 실제 원인을 먼저 좁혀야 합니다.

11. 포맷 후에도 꼭 해야 할 파일 검증

새 USB에 대용량 파일 복사가 성공했다면 중요한 자료를 옮기기 전에 정상적으로 읽을 수 있는지 확인하세요.

  1. USB 속성에서 exFAT으로 포맷됐는지 확인합니다.
  2. 원본을 보존한 상태에서 테스트할 큰 파일을 복사합니다.
  3. 복사가 완전히 끝날 때까지 기다립니다.
  4. Windows의 안전한 하드웨어 제거 또는 Mac의 추출 기능을 사용합니다.
  5. USB를 다시 연결합니다.
  6. 파일 이름과 크기를 원본과 비교합니다.
  7. 동영상이라면 시작 부분과 끝부분을 재생합니다.
  8. 문서라면 실제로 열어 내용을 확인합니다.
  9. 중요한 데이터는 필요하면 체크섬·해시값 비교도 검토합니다.

파일 크기가 같다고 파일 내용까지 완전히 같다는 사실이 증명되지는 않습니다. 중요한 파일은 실제 열기와 추가 검증까지 마친 뒤 원본 삭제 여부를 결정하세요.

exFAT은 NTFS와 같은 메타데이터 저널링 기능을 제공하지 않습니다. 따라서 USB가 기록 작업 중일 때 임의로 분리하지 않고 파일 복사 완료를 확인하는 습관이 중요합니다.

공식 자료: Microsoft — 파일 시스템 저널링 기능 비교

12. FAT32와 32GB 제한을 혼동하지 마세요

FAT32에 관해 '4GB 제한'과 '32GB 제한'이라는 설명을 함께 보게 됩니다. 그러나 뜻이 다릅니다.

약 4GiB 제한은 개별 파일 하나의 최대 크기와 관련됩니다. 반면 '32GB 이하면 MS-DOS(FAT), 초과하면 exFAT'이라는 설명은 Apple이 Windows와 함께 사용할 디스크를 디스크 유틸리티에서 포맷할 때 제공하는 선택 가이드입니다.

따라서 '64GB USB이니까 FAT32일 리 없다'고 판단하는 것은 잘못입니다. 실제 파일 시스템은 탐색기 또는 Finder에서 직접 확인해야 합니다.

또한 exFAT으로 포맷된 64GB USB라고 해서 언제나 60GB가 넘는 파일 하나를 넣을 수 있는 것은 아닙니다. 그 순간 남아 있는 실제 저장 공간과 장치의 상태를 확인해야 합니다.

공식 자료: Apple — Windows용 포맷 형식 선택, Microsoft — 파일 시스템 기능 비교

13. 자주 묻는 질문

Q. USB에 20GB가 남았는데 5GB 파일을 복사하지 못합니다.

FAT32일 수 있습니다. 드라이브 속성에서 파일 시스템을 확인하세요. FAT32라면 개별 파일 크기 한계가 원인일 가능성이 있습니다.

Q. FAT32를 exFAT으로 바꾸면 USB 안에 있던 사진도 남나요?

일반적인 재포맷 작업에서는 기존 파일이 삭제될 수 있습니다. 백업하고 파일을 실제로 열어 확인한 뒤 변경해야 합니다.

Q. ZIP 압축으로 5GB 영상을 4GB 이하로 만들 수 있나요?

반드시 그렇지는 않습니다. 압축 후 파일 하나가 FAT32 제한보다 작아져야 합니다. 영상처럼 이미 압축된 파일은 용량이 거의 줄지 않을 수 있습니다.

Q. Windows와 Mac에서 같이 쓰려면 무엇이 좋나요?

일반적인 파일 교환에는 exFAT이 실용적인 후보입니다. 하지만 연결할 TV·게임기·회사 장비 등의 호환 조건을 확인해야 합니다.

Q. NTFS로 포맷하면 Mac에서도 자유롭게 파일을 넣을 수 있나요?

Apple은 macOS가 NTFS에서 읽기는 가능하지만 기본적으로 쓰기를 지원하지 않는다고 안내합니다. Windows와 Mac 양쪽에서 기록하려는 목적이라면 exFAT 등을 고려하세요.

Q. 빠른 포맷은 안전하게 파일만 정리하는 것 아닌가요?

아닙니다. 빠른 포맷도 기존 데이터에 접근하지 못하게 만들 수 있으며 파일을 보존하는 기능이 아닙니다. 반드시 백업이 필요합니다.

Q. exFAT으로 바꾼 뒤 TV에서 USB가 보이지 않습니다.

TV가 exFAT을 지원하지 않을 수 있습니다. TV 제조사 설명서에서 지원 파일 시스템과 파티션 방식을 확인하세요.

Q. 작은 파일도 복사되지 않는데 포맷해야 할까요?

FAT32의 4GiB 제한과는 다른 문제일 가능성이 큽니다. 쓰기 방지·남은 공간·오류 메시지·장치 상태부터 확인하세요.

결론: 포맷보다 먼저 원인을 구분하세요

USB에 큰 파일이 들어가지 않을 때는 전체 용량과 개별 파일 크기 제한을 구별하는 것이 핵심입니다. USB가 FAT32라면 약 4GiB 이상 파일에서 제한을 만날 수 있습니다. Windows와 Mac 사이에 큰 파일을 자주 옮긴다면 exFAT이 합리적인 선택일 수 있지만, 목적 기기의 호환성을 반드시 확인해야 합니다.

그리고 어떤 형식을 선택하든 포맷 전 백업과 백업 파일 검증을 생략하지 마세요. USB의 기존 자료를 잃을 위험을 감수하면서까지 서둘러 포맷할 필요는 없습니다.
