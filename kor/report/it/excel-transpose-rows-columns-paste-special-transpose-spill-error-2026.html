엑셀에서 세로로 정리된 이름·점수를 가로로 바꾸거나, 가로로 나열된 월별 매출을 세로 표로 바꾸고 싶다면 행/열 바꿈 기능을 사용하면 됩니다. 가장 쉬운 방법은 복사 → 선택하여 붙여넣기 → 행/열 바꿈입니다. 반면 원본 값이 바뀔 때 결과도 자동으로 바뀌어야 한다면 TRANSPOSE 함수가 적합합니다.

두 방법은 결과가 비슷해 보여도 실제 동작이 다릅니다. 특히 원본 데이터와 붙여넣기 범위가 겹치는 경우, 엑셀 표(Table)를 그대로 붙여넣으려는 경우, TRANSPOSE 결과 자리에 값이 있어서 #SPILL!이 발생하는 경우에는 해결 순서가 중요합니다.

이 글은 2026년 11월 4일 기준 Microsoft 공식 Excel 문서를 바탕으로 작성했습니다. Excel 버전과 Windows·Mac·웹 환경에 따라 메뉴 이름이 일부 다를 수 있습니다.

1. 엑셀 행·열 바꾸기, 어떤 방법을 선택해야 할까?

목적권장 방법원본 수정 시 결과가 바뀌나?
일회성으로 가로·세로 표를 뒤집고 싶음선택하여 붙여넣기 → 행/열 바꿈아니요
원본의 값을 계속 참조하고 싶음TRANSPOSE 함수예, 수식이 계산되는 경우

그룹별 집계·요약이 목적피벗 테이블 검토단순 행·열 전환과 별개

핵심: 선택하여 붙여넣기는 원본의 복사본을 만드는 방식입니다. 새 복사본을 만들고 난 뒤 원본 값이 바뀌어도 자동으로 따라 바뀌지 않습니다. TRANSPOSE는 셀 범위를 참조하는 수식이므로 결과가 원본 변화에 맞춰 갱신될 수 있습니다.

2. 예제로 이해하는 가로·세로 전환

아래와 같은 표가 A1:B4에 있다고 가정합니다.

A열 이름B열 점수
김민준92
이서연85
박지호78

실제 셀은 다음과 같습니다.

  • A1 = 이름, B1 = 점수
  • A2 = 김민준, B2 = 92
  • A3 = 이서연, B3 = 85
  • A4 = 박지호, B4 = 78

이 데이터를 행·열 바꿈하면 2행 4열로 전환됩니다.

구분123
이름김민준이서연박지호
점수928578

원본의 4행 2열이 결과에서는 2행 4열이 됩니다. 이름은 가로로, 각 이름에 대응하는 점수는 그 아래로 이동합니다. 데이터의 내용 자체를 바꾸는 것이 아니라 행과 열의 방향을 서로 맞바꾸는 것입니다.

3. 방법 ① 복사·선택하여 붙여넣기로 행 열 바꾸기

Microsoft 공식 도움말에서 안내하는 기본 방식입니다. 한 번만 배치를 바꾸면 되는 표에서 가장 간단합니다.

  1. 원본 범위 A1:B4를 선택합니다.
  2. Ctrl + C로 복사합니다. Mac에서는 Command + C를 사용할 수 있습니다.
  3. 원본과 겹치지 않는 빈 영역(예: D1)을 선택합니다.
  4. 홈 → 붙여넣기 메뉴 → 행/열 바꿈(Transpose)을 선택합니다.
  5. D1부터 2행 4열 결과가 나타나는지 확인합니다.
  6. 새 표가 정상인지 검토한 뒤 필요하다면 원본을 정리합니다.

메뉴의 아이콘이나 명칭은 Excel 버전에 따라 다를 수 있습니다. 복사 후 마우스 오른쪽 클릭 → 선택하여 붙여넣기 관련 옵션에서도 행/열 바꿈을 찾을 수 있는 버전이 있습니다.

주의: 자르기(Ctrl + X)가 아니라 **복사(Ctrl + C)**를 사용해야 합니다. Microsoft Mac 지원 문서는 행·열 전환에 대해 잘라내기 대신 복사를 이용하도록 명시합니다.

왜 D1처럼 떨어진 셀을 골라야 하나요?

원본 영역 A1:B4와 결과 영역이 겹치면 정상적으로 행·열 바꿈을 수행하기 어렵습니다. Microsoft는 행·열 바꿈 대상 영역이 원본 범위와 겹쳐서는 안 된다고 안내합니다.

다른 빈 영역에 전환한 다음, 결과를 확인하고 나서 원본을 정리하는 것이 안전합니다. 이미 데이터가 있는 위치에 붙여넣으면 기존 데이터가 덮어써질 수 있으므로 빈 범위인지 확인하세요.

4. 방법 ② TRANSPOSE 함수로 원본과 연결하기

원본에서 값 하나를 바꿔 결과도 따라 바뀌어야 한다면 TRANSPOSE 함수를 사용하세요. 복사해 붙인 값은 원본과 독립적으로 남습니다.

Microsoft가 안내하는 기본 구문은 다음과 같습니다.

=TRANSPOSE(범위)

앞선 예제의 A1:B4를 전환하고 싶다면 결과가 들어갈 D1 셀에 다음 수식을 입력합니다.

=TRANSPOSE(A1:B4)

Microsoft 365와 최신 동적 배열 지원 Excel에서는 D1 하나에 수식을 입력하고 Enter를 누르면 결과가 주변 빈 셀로 확장될 수 있습니다.

  • 원본 크기: 4행 × 2열
  • 결과 크기: 2행 × 4열
  • 결과가 차지하는 셀: D1:G2

원본 이름이나 점수를 바꾸면 어떻게 되나요?

예를 들어 B2의 점수를 92에서 95로 바꾸면, TRANSPOSE(A1:B4)로 생성된 결과도 수식 계산에 따라 해당 값이 갱신됩니다. 반면 선택하여 붙여넣기로 만든 표는 자동 갱신되지 않습니다.

다른 점: TRANSPOSE는 데이터 값과 배열 방향을 반환하는 수식입니다. 원본의 셀 채우기 색·글꼴 같은 서식을 그대로 복제하는 기능은 아닙니다. 서식이 중요하다면 결과 범위의 서식을 따로 지정하거나 복사·붙여넣기 방식을 검토하세요.

5. Excel 2016·2019처럼 구버전을 사용한다면?

Microsoft의 TRANSPOSE 공식 설명에 따르면 동적 배열을 지원하는 최신 Excel과 이전 방식의 배열 수식은 입력 방법이 다릅니다.

구버전의 경우 다음과 같이 진행할 수 있습니다.

  1. 원본 A1:B4가 4행 × 2열인지 확인합니다.
  2. 결과 영역으로 2행 × 4열 범위(예: D1:G2)를 먼저 선택합니다.
  3. 수식 입력줄에 다음을 입력합니다.
=TRANSPOSE(A1:B4)
  1. 단순히 Enter만 누르는 대신 Ctrl + Shift + Enter로 배열 수식을 확정합니다.
  2. 결과 범위 전체에 값이 나타나는지 확인합니다.

일부 오래된 Excel에서는 배열 수식에 **중괄호 { }**가 자동으로 표시됩니다. 중괄호를 직접 입력하는 것이 아니라, 해당 버전의 배열 수식 입력 방법으로 확정해야 합니다.

버전 안내: Microsoft 365 및 최신 동적 배열 기능이 있는 Excel에서는 수식을 한 셀에 입력한 뒤 Enter를 누르는 방식이 기본입니다. 동일한 수식을 사용하는데 결과가 한 셀에만 나타나거나 입력이 안 된다면 Excel 버전과 배열 수식 지원 여부를 확인하세요.

6. TRANSPOSE 함수 #SPILL! 오류 해결법

TRANSPOSE를 입력한 뒤 #SPILL! 또는 #분산!과 같은 오류가 나타나면 수식이 결과를 표시하려는 영역에 장애물이 있을 수 있습니다. Microsoft는 특히 분산 범위가 비어 있지 않음 및 병합된 셀을 대표적인 원인으로 안내합니다.

① 결과 범위에 기존 데이터가 들어 있는지 확인

예를 들어 D1에 =TRANSPOSE(A1:B4)를 입력하면 결과는 D1:G2 영역으로 확장되어야 합니다. 이때 F2 등 결과에 포함되는 셀에 기존 값이 있으면 결과를 펼칠 수 없습니다.

  1. 오류가 표시된 셀을 선택합니다.
  2. Excel이 표시하는 점선 테두리로 예상 결과 영역을 확인합니다.
  3. 오류 검사에서 장애 셀을 확인할 수 있다면 해당 셀을 찾습니다.
  4. 기존 값이 필요한 경우 다른 위치로 옮기고, 불필요한 값일 때만 삭제합니다.
  5. 수식이 정상적으로 펼쳐지는지 다시 확인합니다.

중요: 오류 해결을 위해 범위를 무조건 지우지 말고, 지우려는 셀에 보존할 원본 데이터가 없는지부터 확인하세요.

② 결과 영역에 병합된 셀이 있는지 확인

동적 배열은 병합된 셀을 가로질러 결과를 펼칠 수 없습니다. 결과 영역의 셀 병합을 해제하거나 병합이 없는 다른 빈 영역에 수식을 입력하세요.

③ Excel 표(Table) 안에서 수식이 펼쳐지지 않는 경우

동적 배열 수식은 Excel 표의 내부에서 일반적인 셀 범위처럼 결과를 펼칠 수 없는 경우가 있습니다. Excel 표 바깥의 일반 셀 영역에서 TRANSPOSE를 입력해 결과를 확인하세요.

7. 엑셀 표(Table)에서 '행/열 바꿈' 버튼이 안 될 때

Excel의 표로 서식 지정이나 삽입 → 표로 만든 Table과, 단순히 테두리와 색을 칠한 일반 셀 범위는 다릅니다.

Microsoft는 Excel 표 데이터에 대해 행/열 바꿈 옵션을 직접 사용할 수 없는 상황이 있다고 안내합니다. 이럴 때는 다음 중 하나를 선택합니다.

  • 방법 A: 필요한 표 데이터를 일반 범위로 변환한 뒤 선택하여 붙여넣기 → 행/열 바꿈을 실행합니다.
  • 방법 B: 원본 표는 그대로 두고 표 바깥의 셀에 TRANSPOSE 함수로 값을 표시합니다.

주의: Table을 범위로 변환하면 표의 구조화된 참조·자동 확장 등 표 기능에 영향이 생길 수 있습니다. 기존 통합 문서에 연결된 수식과 후속 작업이 있다면 사본을 만들어 확인하는 것이 안전합니다.

8. 가로로 된 월별 매출을 세로로 바꾸는 실무 예제

월별 매출이 A1:D2에 다음처럼 들어 있다고 가정합니다.

항목1월2월3월
매출120000150000170000

이 표를 아래처럼 세로형으로 바꾸려면 2행 × 4열인 A1:D2를 복사하여 행/열 바꿈하거나, 빈 셀에서 다음 수식을 사용합니다.

=TRANSPOSE(A1:D2)

결과는 4행 × 2열로 출력됩니다.

구분금액
1월120000
2월150000
3월170000

위 예시는 제목 행을 포함한 2행 × 4열 범위를 전환하는 것으로, 실제 출력에는 맨 윗줄에 '항목'과 '매출'이 놓이고 그 아래로 각 월과 금액이 나옵니다. 표시용 제목인 '구분'·'금액'은 필요에 맞게 별도로 변경할 수 있습니다.

복사한 결과를 차트나 보고서에 사용할 계획이라면, 숫자가 문자열이 아닌 실제 숫자로 저장돼 있는지 확인하세요. 행과 열을 바꾸는 기능 자체가 텍스트 숫자를 자동으로 올바른 숫자형으로 변환해 주는 것은 아닙니다.

9. 빈칸이 0으로 표시될 때의 해결 방향

수식으로 행·열을 전환했을 때 원본의 빈칸이 0으로 보이는 경우가 있습니다. 단순 데이터 복사와 수식 참조 결과의 차이 때문에 나타날 수 있는 현상입니다.

Microsoft 365처럼 동적 배열을 지원하는 Excel에서는 필요에 따라 빈 문자열을 출력하는 IF 조건을 함께 사용할 수 있습니다.

=IF(TRANSPOSE(A1:B4)="","",TRANSPOSE(A1:B4))

다만 이 수식은 원본 셀이 비어 있는 경우의 표시를 제어하기 위한 예시입니다. 원본에 실제 숫자 0이 들어 있는 경우와 빈 문자열을 반환하는 수식이 있는 경우는 데이터 조건에 따라 다르게 해석해야 합니다.

주의: 결과의 ""는 화면상 빈칸처럼 보이게 하는 빈 문자열이지, 반드시 물리적으로 비어 있는 셀과 같은 의미는 아닙니다. 이후 COUNTA 등 함수로 셀 개수를 계산하는 경우 차이가 발생할 수 있습니다.

10. 수식·서식까지 완벽히 그대로 뒤집고 싶다면?

행/열 바꿈은 외형을 바꾸는 기능이지만 모든 원본 요소가 어떤 상황에서도 그대로 유지된다고 보장할 수는 없습니다.

  • 일반 데이터 값: 붙여넣기와 TRANSPOSE 모두 전환에 사용할 수 있습니다.
  • 셀 서식: 복사·붙여넣기 방식에서 가져갈 수 있는 반면, TRANSPOSE 수식은 기본적으로 서식 복사 기능이 아닙니다.
  • 수식: 붙여넣을 때 참조 방식이 바뀔 수 있으므로 절대 참조와 상대 참조를 점검해야 합니다.
  • 엑셀 표(Table): 표 구조 때문에 직접 행/열 바꿈이 제한될 수 있습니다.
  • 원본과 결과의 연결: 복사한 값은 일반적으로 독립적인 사본, TRANSPOSE는 참조 기반 결과입니다.

수식이 많은 업무 문서라면 작업 전 파일을 별도 이름으로 저장하고, 전환 후 중요한 합계·참조·차트가 기대한 값을 가리키는지 확인하는 것이 좋습니다.

12. 자주 묻는 질문(FAQ)

Q. 엑셀에서 행을 열로 바꾸는 단축키가 있나요?

가장 확실한 기본 절차는 Ctrl+C로 복사 → 붙여넣기 메뉴에서 행/열 바꿈 선택입니다. 일부 Excel 버전에서는 선택하여 붙여넣기 대화상자의 키보드 조작을 사용할 수 있지만, 버전에 관계없이 고정된 하나의 단축키라고 안내하기는 어렵습니다.

Q. TRANSPOSE 수식을 넣으면 원본이 삭제되나요?

아닙니다. 원본 셀을 참조하는 수식 결과를 다른 범위에 표시하는 방식입니다. 원본 데이터를 그대로 유지하고 다른 방향으로 표시할 수 있습니다.

Q. 엑셀 행 열 바꿈 후 원본을 수정하면 결과도 수정되나요?

선택하여 붙여넣기로 만든 결과는 일반적으로 자동 갱신되지 않습니다. TRANSPOSE 함수로 만든 결과는 원본 값과 연결되므로 수식이 정상 계산되면 변경이 반영됩니다.

Q. #SPILL! 오류는 무엇인가요?

수식이 여러 셀에 결과를 표시하려는데 출력 영역에 장애물이 있을 때 발생할 수 있는 오류입니다. 이미 값이 들어 있는 셀과 병합된 셀이 대표적인 원인입니다.

Q. 엑셀 표의 행과 열을 바로 바꿀 수 있나요?

Excel Table에서는 행/열 바꿈 붙여넣기 옵션에 제한이 있을 수 있습니다. 먼저 일반 셀 범위로 변환하거나, 표 밖에서 TRANSPOSE 함수를 사용하는 방법을 고려하세요.

Q. '한 셀 텍스트 나누기'와 행·열 바꾸기는 같은가요?

다릅니다. 텍스트 나누기는 하나의 셀에 들어 있는 '김민준,92' 같은 문자열을 구분해 여러 셀로 나누는 작업입니다. 행·열 바꾸기는 이미 여러 셀로 정리된 데이터의 가로·세로 방향을 전환하는 작업입니다.

Q. Mac에서도 같은 방법으로 할 수 있나요?

Mac용 Excel에서도 복사 → 홈의 붙여넣기 → 행/열 바꿈 기능과 TRANSPOSE 함수를 사용할 수 있습니다. 단, 플랫폼에 따라 아이콘·메뉴 표시가 다르고, 구버전 배열 수식 입력 방식도 확인해야 합니다.

최종 요약

일회성 전환이면 복사 → 행/열 바꿈, **원본을 계속 따라가는 표가 필요하면 TRANSPOSE(범위)**를 사용하세요. 작업 전에는 원본과 대상 범위가 겹치지 않는지 확인하고, 수식 결과가 #SPILL!로 막힌다면 출력 영역의 값·병합 셀·Excel 표 내부 여부부터 점검하세요.
