이 글은 불필요하게 Face ID를 초기화하거나 기기를 지우지 않고, 상황별로 원인을 구별하는 실전 점검표입니다. 일반적인 5~10분 점검은 가능하지만, 하드웨어 수리나 보안 지연의 해결 시간이 그 안에 끝난다는 뜻은 아닙니다.

Apple이 2026년 10월 27일 갱신한 공식 도움말과 Face ID 관련 기술 안내를 기준으로 작성했습니다.

1. 첫 질문: '암호를 요구하는 것'과 '인식이 고장 난 것'은 다르다

Face ID가 항상 동작하지 않는다고 무조건 고장이라는 뜻은 아닙니다. 기기를 재시동한 직후나 일정 보안 조건에서는 iPhone이 암호를 입력하도록 요구할 수 있습니다. 이런 상황에서는 먼저 본인이 설정한 기기 암호를 입력해 정상 사용 상태로 돌아온 뒤 다시 확인해야 합니다.

2. 1분: Face ID가 해당 기능에 켜져 있는지 확인

  1. 설정 → Face ID 및 암호를 엽니다.
  2. 기기의 기존 암호를 입력합니다.
  3. Face ID가 설정돼 있는지 확인합니다.
  4. 'iPhone 잠금 해제' 또는 문제가 생긴 앱 관련 사용 옵션이 활성화됐는지 확인합니다.
  5. 앱 자체의 로그인 설정에서 Face ID 사용이 꺼져 있지 않은지도 살펴봅니다.

아이폰 잠금 해제는 정상인데 특정 은행 앱에서만 인증이 안 된다면, 처음부터 TrueDepth 카메라 고장으로 단정하지 마세요. 해당 앱이 Face ID 인증을 허용하는지, 앱 업데이트나 추가 본인확인이 필요한지 따로 확인해야 합니다.

3. 2분: TrueDepth 카메라가 가려지지 않았는지 점검

Face ID에는 전면의 TrueDepth 카메라 시스템이 사용됩니다. Apple은 얼룩, 케이스, 화면 보호 필름 등이 카메라를 가리고 있는지 확인하라고 안내합니다.

  • 전면 카메라 부근의 먼지나 얼룩을 부드럽게 제거합니다.
  • 센서 영역을 가리는 케이스나 잘못 부착된 보호필름이 없는지 확인합니다.
  • 휴대전화를 잡을 때 손가락으로 센서 영역을 가리지 않는지 점검합니다.
  • 얼굴과 iPhone 사이의 거리를 대략 25~50cm로 조정합니다.
  • 카메라를 마주 보도록 기기를 움직이고 과도한 역광을 피합니다.

주의: 센서 부품을 직접 분해하거나 세정액을 구멍에 넣는 방식으로 점검하지 마세요. 내부 부품과 안전 기능에 영향을 줄 수 있습니다.

기기 모델별 센서 배치는 다를 수 있습니다. 화면 윗부분의 특정 위치만 고집하기보다 제조사의 해당 모델 그림을 참고하세요.

4. 3분: 마스크·안경·선글라스 문제를 구분하기

Apple은 iOS 15.4 이상을 설치한 iPhone 12 이후 모델에서 '마스크를 쓴 상태로 Face ID 사용' 기능을 지원한다고 안내합니다. 단, 마스크가 눈 부근까지 올라오거나 눈 주위가 가려져 있다면 인식이 어려워질 수 있습니다.

확인 순서는 다음과 같습니다.

  1. 먼저 마스크와 선글라스를 벗고 얼굴 인식이 되는지 시험합니다.
  2. 정상 인식된다면 착용물과 Face ID 설정의 관련성을 확인합니다.
  3. 설정 → Face ID 및 암호 → 마스크를 쓴 상태로 Face ID 사용 항목이 있는지 확인합니다.
  4. 지원 모델이고 필요하다면 기능을 설정하고, 눈을 가리지 않는 상태로 다시 시험합니다.

마스크를 쓴 상태의 Face ID는 가로 방향에서 작동하지 않습니다. 또한 마스크와 선글라스를 동시에 착용하는 상황은 해당 기능이 지원하도록 설계된 조건이 아닙니다.

안경을 바꾸거나 외모가 크게 달라진 뒤 인식이 자주 실패한다면 Apple이 안내하는 '대체 외모' 설정을 검토할 수 있습니다. 다만 무조건 Face ID를 재설정하는 것보다 기존 설정에서 대체 외모가 적절한지 먼저 판단하는 것이 좋습니다.

6. 5분: 재시동 후 암호를 입력하고 다시 시험

Apple의 Face ID 문제 해결 안내는 기기를 재시동한 뒤 암호를 입력하고 Face ID를 다시 사용해 보라고 설명합니다.

  1. 일반적인 방법으로 iPhone을 껐다가 다시 켭니다.
  2. 부팅 직후 Face ID 대신 기기 암호를 요구하면 정상적인 보안 절차에 따라 암호를 입력합니다.
  3. 잠금 화면을 다시 잠갔다가 평소처럼 얼굴 인식을 시도합니다.
  4. 같은 증상이 계속되는지, 마스크를 벗은 상태에서도 동일한지 확인합니다.

여기서 중요한 점은 재시동 직후 암호를 입력하라는 메시지만으로 Face ID 고장을 판정하면 안 된다는 것입니다. Apple은 재시동 등 보안 조건에서 암호를 요구하는 경우를 별도로 설명합니다.

오류가 계속된다면 iOS 업데이트가 있는지도 확인할 수 있습니다. 단, 중요한 데이터가 있고 저장 공간이나 전원 상태에 문제가 있다면 업데이트 전에 백업과 현재 기기 상태를 확인하는 것이 좋습니다.

7. Face ID를 재설정하기 전에 '도난당한 기기 보호' 확인

Face ID가 안 될 때 무조건 설정을 초기화하라는 팁은 위험할 수 있습니다. Apple의 도난당한 기기 보호 기능이 켜져 있고 익숙하지 않은 장소에 있다면, 특정 보안 작업은 기기 암호만으로 대체할 수 없는 생체 인증을 요구합니다.

이 기능은 일부 작업에서 Face ID 또는 Touch ID 인증을 요구하고, Apple 계정 암호 변경 같은 민감한 작업은 1시간의 보안 지연과 추가 인증이 필요할 수 있습니다. 설정에 따라 익숙한 장소에서도 추가 보호가 적용될 수 있습니다.

따라서 얼굴 인식에 문제가 생겼다면 먼저 다음을 구분하세요.

  • 잠금 화면에서 암호로 정상 진입 가능한가? → 일반적인 잠금 해제 문제일 수 있습니다.
  • 암호는 알지만 특정 계정·보안 변경이 차단되는가? → 도난당한 기기 보호의 추가 인증 요건일 수 있습니다.
  • Face ID 자체를 새로 설정할 수 없는가? → 센서나 설정에 대한 별도 점검이 필요할 수 있습니다.

보안 지연을 우회한다는 명목으로 인터넷의 임의 프로그램을 설치하거나, 낯선 사람에게 Apple 계정 암호나 기기 암호를 넘기지 마세요. 해당 보호 기능은 분실·도난 상황에서 계정 탈취를 막기 위한 장치입니다.

8. 재설정은 마지막 소프트웨어 점검 단계에서

카메라 가림, 각도, 마스크, 기본 Face ID 설정, 재시동 등을 확인했는데도 문제가 계속된다면 Apple이 안내하는 재설정을 시도할 수 있습니다.

  1. 설정 → Face ID 및 암호로 이동합니다.
  2. Face ID 재설정을 선택합니다.
  3. 이어서 Face ID 설정을 선택합니다.
  4. 화면의 안내에 따라 얼굴 정보를 다시 등록합니다.
  5. 등록 후 잠금 해제와 필요한 앱 인증을 시험합니다.

Face ID 재설정은 얼굴 인증 설정을 다시 만드는 작업입니다. '모든 콘텐츠 및 설정 지우기'와 다르며, 이 문제를 해결하려고 iPhone 전체를 무작정 초기화할 필요는 없습니다.

다만 Face ID 설정 절차 자체가 시작되지 않거나, 얼굴을 프레임에 맞추라는 메시지만 반복된다면 더 이상 같은 재설정을 반복하지 말고 수리 필요 여부를 검토하는 편이 좋습니다.

9. 언제 서비스 센터로 가야 할까?

Apple은 Face ID 설정 과정이 계속 진행되지 않거나, 얼굴을 화면 프레임에 맞추라는 메시지가 반복되고 카메라가 제대로 동작하지 않아 설정을 마칠 수 없다면 서비스가 필요할 수 있다고 설명합니다.

다음 상황이라면 소프트웨어 설정을 계속 바꾸는 것보다 공식 점검을 고려하세요.

  • TrueDepth 카메라 관련 경고가 나타난다.
  • 설정을 시도할 때 같은 얼굴 위치 안내가 반복되며 완료되지 않는다.
  • 전면 카메라 주변에 충격이나 손상이 발생한 뒤 문제가 시작됐다.
  • 보호필름·케이스를 확인하고 재시동했는데도 Face ID 설정 자체가 되지 않는다.

주의: 일반 셀피 촬영이 된다는 사실만으로 Face ID에 필요한 TrueDepth 기능 전체가 정상이라고 판정할 수 없습니다. 반대로 Face ID가 가끔 실패했다고 곧바로 부품 교체가 필요하다는 뜻도 아닙니다.

Apple은 잘못된 수리나 개조가 Face ID의 안전 메커니즘에 영향을 줄 수 있다고 안내하므로, 하드웨어 문제가 의심되면 교육받은 기술자의 점검을 받는 것이 적절합니다. 수리 전에 중요한 자료를 백업하고, 서비스 과정에서 데이터가 지워질 가능성과 수리 범위를 먼저 확인하세요.

10. 자주 묻는 질문

Q. iPhone을 껐다 켜면 Face ID 대신 암호만 나오는 게 고장인가요?

아닙니다. 재시동 이후 등 특정 보안 조건에서는 정상적으로 암호를 요구합니다. 기존 기기 암호를 입력한 후 Face ID가 다시 작동하는지 확인해 보세요.

Q. Face ID가 마스크를 쓰면 안 되는 이유가 무엇인가요?

지원되는 iPhone에서는 마스크를 쓴 상태의 Face ID 기능을 설정할 수 있습니다. 다만 눈 주변이 가려져 있거나, 마스크와 선글라스를 함께 쓰거나, 가로 방향으로 사용하면 동작하지 않을 수 있습니다. 기능 지원 모델과 소프트웨어 버전도 확인해야 합니다.

Q. 잠금 해제는 되는데 앱 로그인만 안 됩니다.

설정의 Face ID 사용 항목과 해당 앱 자체의 인증 설정을 따로 확인하세요. 앱별 인증 정책이나 업데이트에 따라 추가 확인이 필요한 경우가 있습니다. 처음부터 카메라 고장으로 단정할 필요는 없습니다.

Q. Face ID를 다시 등록하면 사진과 앱이 삭제되나요?

Face ID 재설정과 iPhone 전체 콘텐츠 삭제는 다른 기능입니다. Apple의 안내에서 Face ID 재설정은 얼굴 인증 정보를 다시 설정하는 절차입니다. 다만 기기 전체 초기화 메뉴와 혼동하지 않도록 설정 이름을 정확히 확인하세요.

Q. 아이폰 12에서도 가로 화면에서 Face ID가 되나요?

Apple은 일반 Face ID의 가로 방향 작동을 iOS 16 이상이 설치된 iPhone 13 이후 모델에 대해 안내합니다. iPhone 12는 세로 방향에서 확인하세요. 특히 마스크를 쓴 상태의 Face ID는 지원 모델에서도 가로 방향으로 동작하지 않습니다.

Q. 암호가 있는데도 Face ID를 요구하며 설정 변경이 막힙니다.

도난당한 기기 보호가 활성화돼 있으면 일부 중요한 작업에 암호 대체를 허용하지 않는 생체 인증이 요구될 수 있습니다. Apple 공식 도움말에서 적용 조건을 확인하고, 우회 도구를 사용하지 마세요.

11. 최종 5분 체크리스트

  • ☐ 재시동 직후 등 암호 입력이 정상인 상황인지 구별했다.
  • ☐ 설정 → Face ID 및 암호에서 해당 기능이 켜져 있는지 확인했다.
  • ☐ TrueDepth 카메라를 가리는 필름·케이스·얼룩을 확인했다.
  • ☐ 마스크·선글라스를 벗고 비교 시험했다.
  • ☐ 모델에 맞는 화면 방향과 약 25~50cm 거리를 확인했다.
  • ☐ 필요하면 기기를 재시동하고 암호를 입력해 다시 시험했다.
  • ☐ 도난당한 기기 보호의 추가 인증 요건을 확인했다.
  • ☐ 재설정이 필요하다면 'Face ID 재설정'을 정확히 선택했다.
  • ☐ 등록 자체가 실패하거나 경고가 지속되면 수리 상담을 고려했다.

Face ID 문제는 '얼굴을 못 알아봄'이라는 한 문장으로 뭉뚱그리기보다 정상적인 암호 요구 → 사용 설정 → 카메라·얼굴 가림 → 기기 방향 → 재시동 → 재설정 → 서비스 순서로 나누는 편이 효율적입니다.
