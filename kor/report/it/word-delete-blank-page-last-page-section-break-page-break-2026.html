Word 문서에서 보고서·자기소개서·계약서를 작성하다 보면 아무 글자도 없는 페이지가 중간이나 맨 뒤에 생길 때가 있습니다. Delete와 Backspace를 여러 번 눌러도 지워지지 않거나, 겨우 없앴더니 앞뒤 페이지의 머리글·바닥글·쪽 번호가 달라지기도 합니다.

워드 빈 페이지는 원인에 따라 삭제 방법이 다릅니다. 빈 단락이 여러 개 생긴 것인지, 수동 페이지 나누기가 삽입된 것인지, 구역 나누기가 새 페이지를 만든 것인지, 문서 마지막의 필수 단락 표시 때문인지 먼저 구별해야 합니다.

이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 Microsoft 365 Word·Word 2024의 메뉴를 중심으로 설명합니다. Mac과 웹용 Word의 차이도 구분합니다. 서식이 중요한 문서는 먼저 다른 이름으로 저장해 사본을 만든 뒤 작업하세요.

1. 원인별 빠른 해결표

마지막 페이지에 단락 기호 하나만 있음문서 끝 필수 단락이 밀려남마지막 단락 글꼴 크기를 1pt로 조정
표 바로 뒤에 빈 마지막 페이지표 뒤 필수 단락이 다음 페이지로 이동단락 표시 확인 후 글꼴 1pt
구역 구분 뒤 빈 페이지다음 페이지·홀수·짝수 페이지 구역 나누기구역 서식을 확인한 다음 연속 구역으로 변경 검토
페이지 삭제 뒤 쪽 번호·머리글이 바뀜구역 나누기를 무심코 삭제실행 취소 후 원래 구역 구조 확인

특정 콘텐츠가 들어 있는 한 페이지를 지우고 싶음실제 텍스트·그림·표가 포함됨해당 페이지 내용 선택 후 삭제

가장 안전한 첫 단계는 편집 기호 표시입니다. 원인이 보이지 않을 때 무작정 Enter나 Delete를 누르는 방식은 피하세요.

참고: Microsoft — Word에서 페이지 삭제 또는 빈 페이지 제거

2. 먼저 Ctrl+Shift+8로 숨은 단락 표시를 켜세요

Word에는 일반 보기에서는 보이지 않는 단락 기호(¶), 페이지 나누기, 구역 나누기 같은 편집 요소가 있습니다. 빈 페이지가 생겼다면 이를 먼저 드러내는 것이 가장 빠릅니다.

  1. 문제가 있는 문서를 엽니다.
  2. Windows에서는 Ctrl+Shift+8을 누릅니다.
  3. Mac용 Word에서는 Command(⌘)+8을 누릅니다.
  4. 빈 페이지 주변에 ¶ 단락 기호, ‘페이지 나누기’, ‘구역 나누기’가 있는지 확인합니다.
  5. 문서를 수정한 후 같은 단축키로 편집 기호를 다시 숨길 수 있습니다.

리본 메뉴의 홈 → ¶(표시/숨기기) 버튼을 이용할 수도 있습니다. ¶가 보인다고 해서 문서에 글자 ‘¶’가 실제로 인쇄되는 것은 아닙니다. 편집용 표시입니다.

예시: 빈 페이지에 ¶가 여섯 개 보인다면, 그중 불필요한 빈 단락을 지워서 페이지가 줄어드는지 확인할 수 있습니다. 반면 ‘구역 나누기(다음 페이지)’가 보인다면 별도 방법이 필요합니다.

공식 근거: Microsoft — Word에서 페이지 삭제 또는 빈 페이지 제거

3. 문서 중간에 생긴 빈 페이지: 빈 단락 제거

문서에서 Enter 키를 반복해서 눌렀을 때 원치 않는 빈 단락이 생길 수 있습니다. 이를 모두 실제 본문으로 취급해 삭제하면 내용과 서식이 함께 바뀔 수 있으므로, 빈 페이지에 있는 불필요한 ¶ 기호만 선택하세요.

작업 순서

  1. 먼저 문서를 다른 이름으로 저장합니다.
  2. Ctrl+Shift+8을 눌러 단락 표시를 켭니다.
  3. 삭제하려는 빈 페이지에서 ¶ 기호가 연속으로 표시되는지 확인합니다.
  4. 불필요한 빈 단락만 선택하고 Delete 또는 Backspace를 누릅니다.
  5. 앞쪽과 뒤쪽 문단이 정상적으로 이어졌는지 확인합니다.

주의: 빈 페이지라고 생각한 곳에 도형·표·그림·텍스트 상자가 있거나 편집 기호가 보인다면 무조건 범위 전체를 지우지 마세요. 객체의 위치나 머리글·쪽 번호 설정에 영향을 줄 수 있습니다.

본문의 줄 간격 또는 단락 간격이 너무 커서 페이지가 밀려났다면 단락 설정을 검토하는 편이 적절합니다. Microsoft는 홈 → 단락 설정 → 들여쓰기 및 간격 등에서 단락 앞뒤 간격을 변경하는 방법을 안내합니다.

참고: Microsoft — Word에서 들여쓰기 및 간격 조정

4. '페이지 나누기' 때문에 생긴 빈 페이지 삭제

워드에서 수동 페이지 나누기는 문서를 지정한 위치부터 다음 페이지에 배치하게 합니다. 이전 페이지가 비어 있거나 별도 빈 페이지가 생겼다면 페이지 나누기 기호가 원인일 수 있습니다.

  1. Ctrl+Shift+8로 편집 기호를 표시합니다.
  2. 빈 페이지 앞이나 안쪽에서 페이지 나누기 표시를 찾습니다.
  3. 불필요한 수동 페이지 나누기를 선택합니다.
  4. Delete 키를 눌러 제거합니다.
  5. 내용이 이전 페이지로 당겨졌는지 확인합니다.

중요한 차이: 수동 페이지 나누기는 사용자가 넣은 구분입니다. 반면 Word가 문서 내용을 배치하면서 자동으로 다음 페이지로 넘기는 경우에는 별도의 ‘페이지 나누기’ 표시가 삭제 대상으로 나타나지 않을 수 있습니다.

따라서 단순히 페이지 경계가 보인다고 모든 페이지를 나누기 기호로 삭제할 수 있는 것은 아닙니다.

공식 근거: Microsoft — Word에서 페이지 삭제 또는 빈 페이지 제거

5. 마지막 빈 페이지가 안 지워지는 이유와 1pt 해결법

여러 번 Delete를 눌러도 문서 맨 뒤의 빈 페이지 하나가 계속 남는 경우가 있습니다. Word는 문서 마지막에 필수 단락을 유지하는데, 이 단락이 앞 페이지에 들어갈 공간이 부족하면 별도의 빈 페이지로 밀려날 수 있습니다.

Microsoft는 이런 상황에서 마지막 단락의 글꼴 크기를 1pt(1포인트)로 줄이는 방법을 안내합니다.

마지막 단락 1pt로 줄이기

  1. 문서 끝으로 이동합니다.
  2. Ctrl+Shift+8을 눌러 단락 표시(¶)를 켭니다.
  3. 마지막 빈 페이지의 마지막 ¶ 기호를 선택합니다.
  4. 홈 탭에서 글꼴 크기 상자를 클릭합니다.
  5. 크기를 1로 변경하고 Enter를 누릅니다.
  6. 마지막 빈 페이지가 사라지는지 확인합니다.
  7. 필요하면 Ctrl+Shift+8을 다시 눌러 편집 기호를 숨깁니다.

왜 마지막 ¶를 삭제하지 않나요? Word는 문서 끝의 필수 단락 표시를 유지해야 하기 때문입니다. 따라서 없애려고 반복적으로 지우는 것보다 앞 페이지에 들어갈 정도로 작게 만드는 방법이 실용적입니다.

Microsoft 공식 문서는 마지막 단락을 1pt로 줄여도 여전히 페이지가 남는다면 페이지 아래쪽 여백을 조절하는 방법도 설명합니다. 다만 제출용 문서는 규정 여백이 정해져 있을 수 있으므로, 여백 변경 전에 양식 규정을 확인하세요.

공식 근거: Microsoft — Word에서 페이지 삭제 또는 빈 페이지 제거

6. 표 뒤에 붙은 빈 페이지: 표가 아니라 마지막 ¶를 확인

계약서 서명란이나 견적서 표가 마지막 페이지를 꽉 채운 뒤에 빈 페이지가 생성되는 경우가 있습니다. 표 뒤의 단락 표시를 위한 공간이 부족한 것이 원인일 수 있습니다.

먼저 표 자체를 삭제하면 안 됩니다. 표 뒤쪽에 있는 ¶가 다음 페이지로 밀려난 것인지 확인하세요.

  1. 문제가 있는 문서를 사본으로 저장합니다.
  2. Ctrl+Shift+8을 눌러 기호를 표시합니다.
  3. 표 다음 빈 페이지에 있는 단락 기호가 하나인지 확인합니다.
  4. 문서 끝 필수 단락이라면 앞 절의 글꼴 크기 1pt 방법을 시험합니다.
  5. 결과가 달라지지 않으면 단락의 앞뒤 간격과 페이지 아래쪽 여백을 검토합니다.
  6. PDF 인쇄 미리 보기에서 빈 페이지가 사라졌는지 확인합니다.

표가 마지막 페이지의 거의 모든 공간을 차지할 때는 눈에 보이는 빈 공간이 조금 있어도 단락 높이가 들어갈 자리가 모자랄 수 있습니다. 표의 행·열과 테두리를 건드리기 전에 단락을 점검하는 것이 핵심입니다.

이 항목은 Microsoft의 ‘마지막 필수 단락’ 설명을 표가 끝에 있는 문서 상황에 적용한 문제 해결 사례입니다.

7. 구역 나누기로 생긴 빈 페이지: 삭제 전 반드시 확인

구역 나누기는 문서를 서로 다른 레이아웃 구간으로 나눕니다. 페이지 번호를 새로 시작하거나, 앞장과 뒷장의 머리글·바닥글을 다르게 하거나, 일부 페이지만 가로 방향으로 배치할 때 사용합니다.

구역 나누기에는 다음과 같은 종류가 있습니다.

구역 나누기 종류새 구역 시작 위치빈 페이지 발생 가능성
다음 페이지바로 다음 페이지있음
연속현재 페이지다른 설정에 따라 달라짐
홀수 페이지다음 홀수 번호 페이지중간에 빈 페이지가 생길 수 있음
짝수 페이지다음 짝수 번호 페이지중간에 빈 페이지가 생길 수 있음

서식을 유지하면서 수정하는 방법

  1. Ctrl+Shift+8로 편집 기호를 표시합니다.
  2. 빈 페이지 앞의 구역 나누기를 찾습니다.
  3. 해당 구역이 페이지 번호·머리글·방향을 다르게 설정하는 데 쓰였는지 확인합니다.
  4. 구역 나누기 또는 대상 구역을 선택한 뒤 레이아웃 → 페이지 설정 대화 상자에서 구역의 시작 형식을 살펴봅니다.
  5. 빈 페이지를 만들 필요가 없다면 구역 시작: 연속으로 변경하는 방식을 검토합니다.
  6. 수정 후 쪽 번호·머리글·바닥글·페이지 방향이 그대로 유지되는지 확인합니다.

주의: 구역 나누기를 무턱대고 삭제하면 서로 다른 구역의 서식이 합쳐져 문서 모양이 달라질 수 있습니다. Microsoft도 문서 중간의 구역 나누기 삭제가 서식 문제를 만들 수 있다고 경고합니다. 그래서 삭제보다 연속 구역으로 변경하는 접근이 먼저입니다.

공식 근거: Microsoft — 구역 나누기 삽입, Microsoft — 구역 나누기 변경

8. 구역 나누기 때문에 쪽 번호가 갑자기 바뀌었다면

구역 나누기를 없앤 뒤부터 페이지 번호가 1로 다시 시작하거나 표지 머리글이 전체 문서에 반복되는 문제가 생길 수 있습니다.

이런 경우에는 Ctrl+Z로 가장 최근의 잘못된 변경을 되돌린 뒤 원래 구역 구조를 확인하세요. 특정 구역에 적용돼 있던 설정을 유지한 채 빈 페이지 하나만 제거하려면 구역 나누기의 종류를 바꾸는 것이 더 적합할 수 있습니다.

확인할 항목

  • 각 구역의 페이지 번호 시작 값
  • 머리글·바닥글의 이전 구역과 연결 여부
  • 가로·세로 방향과 여백 차이
  • 각 구역의 첫 페이지 다르게 설정한 부분
  • 표지와 목차 뒤의 구분 위치

실무 조언: 학위논문·제안서처럼 섹션이 많은 문서에서는 빈 페이지 하나를 없애기 위해 구역 나누기 전체를 삭제하는 것은 위험합니다. 문서 복사본에서 순서대로 시험한 뒤 최종본에 적용하세요.

참고: Microsoft — 한 페이지에서 머리글 또는 바닥글 변경·삭제

9. 빈 페이지가 아니라 실제 내용이 있는 페이지 전체를 삭제하려면

표나 그림 등 내용이 포함된 한 페이지를 삭제하려는 작업은 원치 않는 빈 페이지를 없애는 작업과 다릅니다. Microsoft는 특정 페이지의 콘텐츠를 선택해 삭제하는 방법을 안내합니다.

Windows용 Word에서는 다음과 같이 진행할 수 있습니다.

  1. 삭제하고 싶은 페이지 안쪽을 클릭합니다.
  2. Ctrl+G를 눌러 이동 대화 상자를 엽니다.
  3. 페이지 번호 입력 칸에 \page를 입력합니다.
  4. Enter를 누른 뒤 대화 상자를 닫습니다.
  5. 해당 페이지 내용이 올바르게 선택되었는지 반드시 확인합니다.
  6. 삭제할 내용이 맞을 때만 Delete를 누릅니다.

이 방법은 빈 페이지를 만드는 원인인 구역 나누기 등의 복잡한 서식을 자동으로 안전하게 정리해 주는 기능은 아닙니다. 선택 범위에 필요한 내용이나 서식 기호가 포함돼 있다면 삭제하기 전에 다시 확인하세요.

Mac용 Word는 페이지 이동 단축키가 달라질 수 있으므로 Microsoft 지원 문서의 Mac 설명을 참고합니다.

10. 웹용 Word에서 빈 페이지 지우기: 가능한 것과 불가능한 것

브라우저에서 문서를 여는 웹용 Word는 데스크톱 프로그램과 지원 기능이 다릅니다.

Microsoft는 웹용 Word에서 빈 단락과 수동 페이지 나누기는 삭제할 수 있지만, 구역 나누기 삭제·수정은 데스크톱 Word가 필요하다고 안내합니다.

웹용 Word에서 할 수 있는 작업

  1. Word 파일을 웹 브라우저에서 열고 편집 상태로 전환합니다.
  2. 불필요한 빈 단락을 찾아 선택 후 삭제합니다.
  3. 불필요한 수동 페이지 나누기가 있다면 선택해 삭제합니다.
  4. 문서를 저장하고 페이지 배치를 다시 확인합니다.

웹에서 구역 나누기를 수정할 수 없다면

웹용 Word 상단의 데스크톱 앱에서 열기와 비슷한 명령을 사용해 설치된 Word에서 문서를 연 뒤 수정해야 할 수 있습니다. 회사·학교 계정이라면 권한 및 프로그램 설치 여부를 먼저 확인하세요.

공식 근거: Microsoft — 웹용 Word 빈 페이지 삭제

11. Mac용 Word에서 빈 페이지 삭제하기

Mac도 기본 원칙은 같습니다. 먼저 편집 기호를 보여 빈 페이지의 원인을 찾으세요.

  • Command(⌘)+8을 눌러 단락 표시를 켭니다.
  • 빈 단락이나 수동 페이지 나누기는 필요한 부분만 선택해 삭제합니다.
  • 문서 마지막 필수 단락으로 생긴 빈 페이지라면 마지막 단락 글꼴 크기를 1pt로 조정하는 방식을 검토합니다.
  • 구역 나누기가 원인이면 서식이 바뀌지 않도록 종류를 확인하고 변경합니다.

Mac용 Word의 메뉴 위치와 단축키는 Windows용 Word와 다를 수 있습니다. 먼저 문서 사본을 저장하고, 수정 결과를 인쇄 미리 보기에서 확인하는 것이 좋습니다.

공식 근거: Microsoft — Word에서 페이지 삭제 또는 빈 페이지 제거

12. 삭제해도 빈 페이지가 계속 생길 때 점검할 네 가지

① 단락에 ‘앞에서 페이지 나누기’가 설정되어 있음

페이지 나누기 표시가 없어도 단락 설정에서 앞에서 페이지 나누기 옵션이 켜져 있으면 해당 단락부터 새 페이지가 시작될 수 있습니다.

빈 페이지 다음에 있는 단락을 선택하고 홈 → 단락 설정 → 줄 및 페이지 나누기를 열어 ‘앞에서 페이지 나누기’ 옵션을 확인하세요. 의도치 않은 설정이라면 해제 후 결과를 검토합니다.

② 아래쪽 여백이 지나치게 큼

문서 마지막 단락이 여백 때문에 이전 페이지에 들어가지 못할 수 있습니다. 레이아웃 → 여백에서 아래쪽 여백을 확인할 수 있지만, 제출 규정이 있는 문서에서는 임의로 여백을 줄이지 마세요.

③ 구역이 ‘홀수 페이지’ 또는 ‘짝수 페이지’로 시작함

새 구역이 특정 홀수·짝수 페이지에서 시작하도록 설정돼 있다면 그 사이에 빈 페이지가 배치될 수 있습니다. 이러한 구조는 책자·양면 인쇄에서 의도된 설정일 수 있으므로 수정 목적을 확인해야 합니다.

④ 표 바로 뒤에 필수 단락이 있음

문서의 맨 마지막이 표라면 뒤쪽 필수 단락 표시가 빈 페이지로 밀려날 수 있습니다. 이때는 표를 지우지 말고 마지막 ¶의 글꼴 크기 1pt를 먼저 검토하세요.

13. 자주 묻는 질문

Q. Word에서 빈 페이지 지우는 가장 빠른 방법은 무엇인가요?

Ctrl+Shift+8로 단락 표시를 켜고, 빈 페이지에 표시된 요소가 단순 빈 단락인지, 페이지 나누기인지, 구역 나누기인지 먼저 확인하세요. 원인에 맞는 부분만 제거하면 됩니다.

Q. 마지막 빈 페이지에서 Delete를 눌러도 왜 안 지워지나요?

문서 끝 필수 단락이 다음 페이지로 밀려났을 수 있습니다. Microsoft는 이 경우 마지막 단락을 글꼴 크기 1pt로 줄이는 방법을 안내합니다.

Q. Ctrl+Shift+8을 누르니 ¶가 보이는데 잘못된 건가요?

아닙니다. 편집 기호를 표시한 것입니다. 같은 키를 다시 눌러 숨길 수 있습니다.

Q. 구역 나누기를 지우면 무조건 빈 페이지가 없어지나요?

그렇지 않습니다. 구역 나누기를 삭제하면 문서 서식이 바뀔 수 있습니다. 가능하면 먼저 구역의 시작 형식을 연속으로 바꿔도 되는지 검토하세요.

Q. Word 온라인에서 구역 나누기를 없앨 수 있나요?

Microsoft 공식 안내에 따르면 웹용 Word에서 구역 나누기를 삭제하거나 수정하려면 데스크톱 Word가 필요합니다.

Q. PDF로 저장했더니 빈 페이지가 함께 나옵니다.

원본 Word의 인쇄 미리 보기와 페이지 배치를 먼저 확인하세요. 불필요한 빈 페이지가 Word 문서 자체에 있다면 원인을 정리한 뒤 PDF로 다시 저장하는 것이 좋습니다.

Q. 글이 있는 1페이지만 통째로 삭제하고 싶어요.

Windows용 Word의 Ctrl+G → \page 방식으로 해당 페이지 내용을 선택할 수 있습니다. 반드시 선택 범위를 확인한 뒤 삭제하세요.

14. 1분 점검 체크리스트

  • ☐ 문서 원본을 복사해 두었다.
  • ☐ Ctrl+Shift+8(맥은 ⌘+8)로 편집 기호를 켰다.
  • ☐ 원인이 빈 단락·페이지 나누기·구역 나누기 중 무엇인지 확인했다.
  • ☐ 문서 끝 필수 단락이라면 글꼴 1pt를 시험했다.
  • ☐ 구역 나누기를 삭제하기 전 쪽 번호·머리글·페이지 방향을 확인했다.
  • ☐ 웹용 Word의 편집 기능 제한을 구분했다.
  • ☐ 삭제 후 문서 전체와 인쇄 미리 보기를 다시 확인했다.

결론: 워드의 빈 페이지는 한 가지 방법으로 모두 해결되지 않습니다. 편집 기호 표시 → 원인 구분 → 필요한 요소만 수정하는 순서가 핵심입니다. 특히 맨 뒤의 지워지지 않는 빈 페이지는 마지막 필수 단락을 1pt로 줄이는 방법이 유용하며, 구역 나누기 문제는 서식을 보존하면서 처리해야 합니다.
