2026 아이폰 앱 잠금·숨기기 방법: Face ID 요구·가려짐 폴더·홈 화면 복구

핵심 요약 (Key Takeaways)
  • iOS 18 이후 아이폰에서는 별도 앱 없이 기본 기능으로 앱 잠금과 숨기기가 가능하며, Face ID 또는 Touch ID 인증을 요구할 수 있습니다.
  • 앱 잠금은 앱 실행 시 인증을 요구하고, 가리기는 앱 아이콘을 홈 화면에서 숨겨 앱 보관함의 '가려짐' 폴더로 이동시킵니다.
  • 가려진 앱은 앱 보관함의 '가려짐' 폴더에서 인증 후 복구 가능하며, 홈 화면 복구는 수동으로 아이콘을 다시 배치해야 합니다.

아이폰을 다른 사람에게 잠깐 빌려줄 때 특정 앱을 열 수 없게 하거나, 홈 화면에서 민감한 앱을 보이지 않게 하고 싶을 수 있습니다. iOS 18 이후 버전에서는 기본 기능으로 앱을 잠그거나 가릴 수 있습니다. 별도의 유료 앱 잠금 프로그램을 설치할 필요가 없습니다.

아이폰을 다른 사람에게 잠깐 빌려줄 때 특정 앱을 열 수 없게 하거나, 홈 화면에서 민감한 앱을 보이지 않게 하고 싶을 수 있습니다. iOS 18 이후 버전에서는 기본 기능으로 앱을 잠그거나 가릴 수 있습니다. 별도의 유료 앱 잠금 프로그램을 설치할 필요가 없습니다.

다만 앱 잠그기, 앱 가리기, 홈 화면에서 제거, 앱 삭제는 서로 다릅니다. 잠긴 앱은 Face ID·Touch ID·암호 인증을 요구하고, 가린 앱은 홈 화면과 일반 검색에서 사라져 앱 보관함의 '가려짐' 폴더로 이동합니다. 홈 화면에서 제거한 앱은 단지 아이콘만 없어지는 것이며, 앱을 삭제하면 기기의 앱과 데이터가 제거됩니다.

이 글은 2026년 11월 4일 Apple 공식 지원 문서 기준으로 설정부터 복구, 보안 한계, 자주 발생하는 오류까지 설명합니다. iOS 버전과 기종에 따라 메뉴 이름이 조금 다를 수 있습니다.

공식 근거: Apple — iPhone에서 앱 잠그기 또는 가리기, Apple — 앱 제거 또는 삭제.

2. 아이폰 앱에 Face ID 잠금 거는 방법

아이폰을 잠금 해제한 상태여도 선택한 앱을 열 때 한 번 더 인증하도록 설정할 수 있습니다.

  1. 아이폰 홈 화면에서 잠글 앱을 찾습니다.
  2. 앱 아이콘을 길게 터치해 빠른 동작 메뉴를 엽니다.
  3. 'Face ID 요구'를 탭합니다. 기기에 따라 'Touch ID 요구' 또는 '암호 요구'로 표시될 수 있습니다.
  4. 확인 화면에서 다시 'Face ID 요구'를 선택합니다.
  5. Face ID·Touch ID·기기 암호로 인증을 완료합니다.
  6. 앱을 닫았다가 다시 열어 인증을 요구하는지 확인합니다.

어떤 효과가 있나요? Apple은 잠긴 앱의 정보가 알림 미리보기, 검색, Siri 제안, CarPlay, 통화 기록 등 일부 위치에 표시되지 않도록 제한된다고 설명합니다. 앱을 종료하면 다시 잠기며, 한 번 인증했다고 잠금 설정이 영구 해제되지는 않습니다.

주의: Face ID를 사용하는 기기라도 기기 암호를 아는 사람의 접근까지 절대 차단하는 기능이라고 이해하지 마세요. Apple의 기본 잠금은 Face ID·Touch ID 또는 암호 인증 방식입니다.

공식 근거: Apple — 앱 잠그기·잠긴 앱 열기.

3. 아이폰 앱 숨기기: '가리기 및 Face ID 요구'

홈 화면에서 앱 아이콘도 보이지 않게 하고 싶다면 단순한 홈 화면 제거가 아니라 가리기를 이용합니다.

  1. 숨기려는 앱이 있는 홈 화면으로 이동합니다.
  2. 앱 아이콘을 길게 누릅니다.
  3. 'Face ID 요구'를 선택합니다.
  4. 다음 메뉴에서 '가리기 및 Face ID 요구'를 선택합니다.
  5. Face ID·Touch ID·암호로 인증합니다.
  6. 확인 창에서 '앱 가리기'를 선택합니다.
  7. 홈 화면에서 앱 아이콘이 사라졌는지 확인합니다.

가려진 앱은 앱 보관함 하단의 '가려짐' 폴더로 이동합니다. 일반 앱 목록과 검색에서 찾기 어려워질 수 있으니, 복구할 때는 가려짐 폴더부터 확인하세요.

가리기 메뉴가 없는 앱은 왜 그럴까요?

모든 앱에 가리기 기능이 제공되지는 않습니다.

  • Apple은 기기에 처음부터 설치된 기본 앱은 가릴 수 없다고 안내합니다. 원칙적으로 App Store에서 별도로 다운로드한 앱을 대상으로 합니다.
  • 기본 웹 브라우저 등 일부 특정 역할로 설정한 앱도 가릴 수 없습니다.
  • 앱에 따라 잠금 자체가 허용되지 않을 수도 있습니다. 예를 들어 Apple은 카메라·계산기·시계·연락처·지도·설정 등을 잠글 수 없는 기본 앱의 예시로 제시합니다.
  • iOS 버전이 오래되었으면 기능이 표시되지 않을 수 있습니다. 본문의 기능은 iOS 18 이후를 대상으로 합니다.

무조건 버그라고 단정하지 말고 앱 종류·OS 버전·기기 관리 정책을 먼저 점검해야 합니다.

공식 근거: Apple — 앱 잠금·가리기 지원 조건, Apple — 개인 안전 가이드.

4. 가려진 앱 어디에 있나요? 앱 보관함에서 찾기

앱이 사라졌다고 삭제된 것은 아닐 수 있습니다. 다음 순서대로 확인하세요.

  1. 홈 화면에서 왼쪽으로 계속 쓸어넘겨 가장 마지막의 앱 보관함으로 이동합니다.
  2. 화면 하단에서 '가려짐' 폴더를 찾습니다.
  3. 폴더를 탭합니다.
  4. Face ID·Touch ID·암호로 인증합니다.
  5. 나타난 앱을 선택해 실행합니다.

다른 확인 방법: 설정 → 앱 → 가려진 앱 경로로도 목록을 확인할 수 있습니다. 인증이 필요하며, 기기의 메뉴 구성에 따라 표시가 달라질 수 있습니다.

검색에서 앱이 보이지 않는 것은? 가리기 기능은 일반 검색 및 앱 보관함의 다른 카테고리에 나타나지 않게 하는 기능이므로 고장이라고 볼 필요는 없습니다.

공식 근거: Apple — 가려진 앱 열기.

5. 아이폰 앱 숨기기 해제와 홈 화면 복구

가린 앱을 다시 일반 앱처럼 보이게 하려면 다음 절차를 진행합니다.

  1. 앱 보관함 → 가려짐 폴더로 이동합니다.
  2. 인증 후 복구할 앱 아이콘을 길게 누릅니다.
  3. 'Face ID 요구 안 함' 또는 해당 기기의 인증 요구 해제 메뉴를 누릅니다.
  4. Face ID·Touch ID·암호로 인증합니다.
  5. 앱이 앱 보관함의 일반 영역으로 돌아왔는지 확인합니다.
  6. 홈 화면에 아이콘이 아직 없다면 앱 보관함에서 앱을 길게 누르고 홈 화면 쪽으로 드래그해 배치합니다.

중요: 가리기 해제 후에도 원하는 홈 화면 페이지에 자동으로 나타나는지 여부는 기기의 배치 상태에 따라 다를 수 있습니다. 앱 보관함에 돌아왔는지와 홈 화면에 아이콘이 배치됐는지를 별개로 확인하세요.

잠금만 해제하려면?

홈 화면에서 잠긴 앱 아이콘을 길게 터치 → Face ID 요구 안 함 → 인증하면 됩니다. 숨긴 앱을 복구하는 것과 잠금만 해제하는 것은 구분하세요.

공식 근거: Apple — 가리기 중단·앱 잠금 해제, Apple — 앱 보관함의 앱을 홈 화면으로 이동.

6. '홈 화면에서 제거'했더니 앱이 사라졌어요

앱 아이콘을 길게 누른 뒤 앱 제거 → 홈 화면에서 제거를 선택한 경우, 대부분 앱이 실제로 삭제된 것은 아닙니다.

이 경우에는 다음 순서로 복구합니다.

  1. 홈 화면을 왼쪽으로 쓸어넘겨 앱 보관함을 엽니다.
  2. 앱 보관함 위쪽 검색창에서 앱 이름을 입력합니다.
  3. 해당 앱을 길게 누른 상태로 홈 화면으로 드래그합니다.
  4. 원하는 위치에 배치하고 완료합니다.

검색에서도 찾을 수 없을 때

  • 앱 보관함의 '가려짐' 폴더를 먼저 확인합니다.
  • 홈 화면 자체가 숨겨진 것이라면 홈 화면의 빈 공간 길게 누르기 → 페이지 편집으로 페이지 표시 상태를 확인합니다.
  • 앱이 설치되지 않았다면 App Store의 설치 여부를 확인할 수 있습니다. 단, 앱이 삭제되면 기존 데이터까지 복구된다고 보장할 수 없습니다.

앱이 없어졌다고 곧바로 '모든 설정 재설정' 또는 초기화를 시도하지 마세요. 홈 화면 표시 상태와 앱 보관함에서 먼저 해결할 수 있습니다.

공식 근거: Apple — 홈 화면에서 앱 찾을 수 없는 경우, Apple — 홈 화면 및 앱 보관함 정리하기.

7. 앱이 완전히 비밀로 숨겨지는 것은 아닙니다

Apple의 앱 가리기 기능은 일반적인 홈 화면 노출과 접근을 줄이는 데 유용하지만 앱이 설치됐다는 사실을 모든 위치에서 완전히 삭제하는 기능은 아닙니다.

Apple의 개인 안전 안내에 따르면 가려진 앱 정보가 다음 위치 등에서 표시될 수 있습니다.

확인 위치주의할 내용
설정 → 앱 → 가려진 앱인증 후 가려진 앱 목록 확인 가능
스크린 타임앱 설치·사용 관련 정보가 표시될 수 있음
설정의 배터리 사용 내역앱 이름이나 사용 정보가 나타날 수 있음
App Store 구입 내역설치·구입 기록을 확인할 수 있음
다른 Apple 기기앱 잠금·가리기 상태가 iCloud로 자동 동기화되지 않음

따라서 앱이 숨겨졌다는 이유만으로 기기의 모든 사용 기록과 구입 흔적이 사라진다고 오해하지 않는 것이 중요합니다.

또한 숨기기 기능은 보안 목적으로 유용하지만 기기 암호와 Apple 계정 자체의 보안도 함께 관리해야 합니다. 계정 암호 공유나 기기 암호 노출이 우려된다면 앱 아이콘을 가리는 것만으로 충분하지 않을 수 있습니다.

공식 근거: Apple — 개인 안전 및 앱 잠금·가리기의 한계.

8. iOS 18 미만·자녀 계정·회사 관리 기기에서의 차이

iOS 18 이전 버전

이 글의 앱 잠금·가리기 기능은 iOS 18 이후 기본 기능을 기준으로 합니다. 이전 버전에서는 같은 메뉴가 표시되지 않을 수 있습니다. 사용 중인 iOS 버전을 설정 → 일반 → 정보에서 확인하세요. 업데이트 전에는 기기 호환성과 백업 상태를 점검합니다.

자녀가 가족 공유 그룹에 속한 경우

Apple은 가족 공유 그룹에서 13세 미만 자녀의 앱 잠금·가리기에 제한이 있다고 설명합니다. 13~17세 구성원은 일부 기능을 사용할 수 있어도 부모 또는 보호자가 다운로드·사용 시간 정보를 확인하고 스크린 타임으로 접근을 제한할 수 있습니다. 적용되는 연령은 국가·지역에 따라 다릅니다.

회사·학교 기기

조직 관리 정책이나 제한된 기기 환경에서는 일반 개인 기기와 메뉴·설정이 달라질 수 있습니다. 업무용 장치라면 임의로 관리 설정을 우회하려 하기보다 기기 관리자에게 확인하는 것이 안전합니다.

공식 근거: Apple — 앱 잠금·가리기 연령 제한.

10. 자주 묻는 질문

Q. 아이폰에서 카카오톡·인스타그램 같은 앱을 Face ID로 잠글 수 있나요?

지원되는 iOS에서 앱 자체의 잠금 메뉴가 제공된다면 앱 아이콘 길게 누르기 → Face ID 요구를 이용할 수 있습니다. 앱마다 제공 범위와 알림·설정 상태는 달라질 수 있으므로 실제 메뉴 표시 여부를 확인하세요.

Q. 앱을 잠그면 홈 화면에서 사라지나요?

아니요. 잠금만 설정하면 아이콘은 홈 화면에 남습니다. 아이콘까지 숨기고 싶다면 가리기 및 Face ID 요구를 사용해야 합니다.

Q. '가려짐' 폴더가 안 보여요.

먼저 홈 화면을 끝까지 왼쪽으로 넘겨 앱 보관함으로 이동했는지 확인합니다. 가려진 앱이 실제로 있는지, 사용 중인 iOS 버전이 기능을 지원하는지 점검하세요.

Q. Face ID 대신 비밀번호를 이용할 수 있나요?

Apple은 잠긴 앱을 Face ID, Touch ID 또는 기기 암호로 인증할 수 있다고 안내합니다. Face ID만으로 모든 형태의 암호 접근을 차단하는 기능으로 이해하면 안 됩니다.

Q. 숨긴 앱은 App Store 구입 내역에서도 보이지 않나요?

그렇지 않을 수 있습니다. Apple은 앱 가리기를 해도 App Store 구입 내역 등 일부 위치에서 설치한 앱의 정보가 표시될 수 있다고 명시합니다.

Q. 홈 화면에서 제거하면 앱 데이터가 삭제되나요?

아니요. 홈 화면에서 제거하면 앱은 앱 보관함에 남습니다. 앱을 완전히 삭제하는 동작과 다릅니다.

Q. 앱 숨기기를 다른 아이폰에도 적용할 수 있나요?

Apple에 따르면 앱 잠금·가리기 상태는 기기별 설정이며 iCloud에 자동 동기화되지 않습니다. 다른 아이폰에서는 별도 설정이 필요합니다.

11. 설정을 끝내기 전 체크리스트

  • ☐ 앱을 잠글지, 가릴지, 홈 화면에서만 제거할지 결정했다.
  • ☐ iOS 버전과 앱의 지원 여부를 확인했다.
  • ☐ 앱을 다시 열어 Face ID·Touch ID·암호 인증이 필요한지 확인했다.
  • ☐ 가린 앱은 앱 보관함의 가려짐 폴더에서 찾을 수 있다.
  • ☐ 앱이 완전히 삭제된 것이 아닌지 확인했다.
  • ☐ App Store 구입 내역·스크린 타임 등 설치 흔적이 남을 수 있다는 점을 이해했다.
  • ☐ 다른 기기에 자동으로 잠금이 적용되지 않는다는 점을 확인했다.

최종 정리: 아이폰에서 앱 내용에 접근하지 못하게 하려면 Face ID 요구, 아이콘까지 보이지 않게 하려면 가리기 및 Face ID 요구를 사용하세요. 앱이 사라졌다면 먼저 앱 보관함 → 가려짐을 확인하고, 단순히 홈 화면에서 제거한 앱인지 구별하면 불필요한 재설치나 데이터 삭제를 예방할 수 있습니다.

자주 묻는 질문 (FAQ)

아이폰에서 앱을 잠그는 방법은 무엇인가요?

홈 화면에서 잠글 앱 아이콘을 길게 터치해 'Face ID 요구'를 선택하고 인증하면 앱 실행 시 추가 인증이 필요합니다.

앱을 숨기면 어디에서 찾을 수 있나요?

숨긴 앱은 앱 보관함 하단의 '가려짐' 폴더에 이동하며, 인증 후 다시 실행하거나 복구할 수 있습니다.

홈 화면에서 앱 아이콘만 제거하는 것과 앱을 삭제하는 것은 어떻게 다른가요?

홈 화면에서 제거는 아이콘만 숨기고 앱은 보관함에 남아있지만, 삭제하면 앱과 데이터가 기기에서 완전히 삭제됩니다.
