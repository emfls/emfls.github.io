한 가지 메뉴만 껐는데 문제가 그대로라면 설정을 잘못한 것이 아니라 다른 종류의 자동재생을 보고 있는 것일 수 있습니다.

2. 갤럭시·안드로이드에서 다음 영상 자동재생 끄기

유튜브 앱에서 다음 관련 영상이 자동으로 나오는 것을 막으려면 다음 순서로 확인합니다.

  1. YouTube 앱을 실행합니다.
  2. 아무 일반 동영상이나 재생합니다.
  3. 동영상 화면을 한 번 터치해 플레이어의 제어 버튼을 표시합니다.
  4. 플레이어 상단의 자동재생 전환 버튼을 찾아 '사용 안함'으로 바꿉니다.
  5. 다른 동영상을 한 편 재생한 뒤 종료 시 자동으로 다음 영상으로 넘어가는지 확인합니다.

앱 설정에서도 변경할 수 있습니다.

  1. 프로필 사진을 탭합니다.
  2. 설정 → 자동재생으로 이동합니다.
  3. 자동재생 기능을 사용 중지합니다.

메뉴의 위치나 아이콘은 앱 버전·화면 크기에 따라 조금 다를 수 있습니다. 플레이어에서 보이지 않을 때는 앱 설정을 먼저 확인하세요.

공식 근거: YouTube 고객센터 — 동영상 자동재생.

3. 아이폰·아이패드에서 다음 영상 자동재생 끄기

iPhone과 iPad에서도 원리는 같습니다.

  1. YouTube 앱에서 일반 동영상을 엽니다.
  2. 재생 화면 상단의 자동재생 전환 버튼을 찾아 끕니다.
  3. 또는 프로필 사진 → 설정 → 자동재생으로 이동해 끕니다.
  4. 동영상 한 편이 끝났을 때 다른 관련 동영상으로 넘어가는지 확인합니다.

앱에서 다음 영상 자동재생을 꺼도 홈 화면 썸네일이 움직일 수 있습니다. 그 현상은 아래 '피드에서 재생'을 따로 꺼야 합니다.

또한 iPhone에서 설정을 바꾼 뒤 Windows PC에서 YouTube를 열면 여전히 다음 영상이 재생될 수 있습니다. YouTube는 기기별 자동재생 설정이 서로 다를 수 있다고 안내합니다.

공식 근거: YouTube 고객센터 — 동영상 자동재생.

4. 홈 화면 썸네일이 저절로 움직일 때: '피드에서 재생' 끄기

동영상을 누르지도 않았는데 홈 화면이나 검색 결과를 내리면서 미리보기가 재생된다면 자동재생보다 피드에서 재생 메뉴를 찾아야 합니다.

갤럭시·아이폰·태블릿 공통

  1. YouTube 앱을 엽니다.
  2. 프로필 사진 → 설정 → 일반으로 이동합니다.
  3. 피드에서 재생을 선택합니다.
  4. 다음 중 원하는 옵션을 선택합니다.
옵션동작권장 상황
항상 사용Wi-Fi와 모바일 데이터에서 인라인 재생탐색 중 미리보기를 자주 보는 경우
Wi-Fi 전용Wi-Fi 연결 시 인라인 재생모바일 데이터 사용을 줄이고 싶은 경우
사용 안함인라인 재생 사용하지 않음화면에서 움직이는 썸네일이 불편한 경우

'사용 안함'을 설정해도 일부 동영상에서 짧은 미리보기 방식이 나타날 수 있으며, 구체적인 표시 방식은 기기·브라우저·화면에 따라 다릅니다. 모바일 앱에서 홈 미리보기 동작을 제어하려면 이 메뉴부터 확인하는 것이 정확합니다.

YouTube 고객센터는 탐색 중 일정 시간 시청한 영상이 시청 기록에 남을 수 있다고 설명합니다. 자동 재생 미리보기를 원치 않는 사람에게 중요한 차이입니다.

공식 근거: YouTube 고객센터 — 인라인 플레이어 사용(iPhone/iPad), Android 인라인 플레이어 안내.

5. PC에서 자동재생 끄는 법: Chrome·Edge 모두 같은 원리

PC에서는 다음 영상 자동재생과 썸네일 인라인 재생의 설정 위치가 서로 다릅니다.

A. 다음 영상 자동재생 중지

  1. 브라우저에서 youtube.com에 접속합니다.
  2. 일반 동영상을 엽니다.
  3. 동영상 플레이어 하단의 자동재생 전환 버튼을 클릭합니다.
  4. '사용 안함' 상태로 바꿉니다.

B. 썸네일에 마우스를 올렸을 때 재생되지 않게 하기

  1. YouTube의 프로필 사진 → 설정으로 이동합니다.
  2. 재생 및 성능을 엽니다.
  3. 인라인 재생을 사용 중지합니다.

인라인 재생을 끄더라도 컴퓨터에서는 일부 동영상의 3초 미리보기가 나타날 수 있습니다. 이 차이 때문에 '껐는데도 썸네일이 움직인다'는 상황이 발생할 수 있습니다.

공식 근거: YouTube 고객센터 — 인라인 플레이어 사용(컴퓨터), 동영상 미리보기.

6. 스마트 TV·게임 콘솔에서 유튜브 자동재생 끄기

TV에서 YouTube를 켜두면 영상이 끝나도 다음 영상이 이어서 나오는 경우가 있습니다. 스마트폰 설정과 별도로 확인해야 합니다.

  1. 스마트 TV 또는 콘솔에서 YouTube 앱을 실행합니다.
  2. 설정으로 이동합니다.
  3. 자동재생 항목을 찾습니다.
  4. 사용 안함을 선택합니다.
  5. 일반 동영상 한 편이 끝났을 때 다음 영상이 자동으로 시작되는지 확인합니다.

TV 홈 화면의 소리 나는 미리보기를 끄고 싶은 경우에는 TV의 자동재생과 별도로 미리보기 사운드 관련 설정을 확인하세요. YouTube 고객센터는 스마트 TV의 '사운드가 포함된 미리보기' 사용 중지 방법도 안내합니다.

공식 근거: YouTube 동영상 자동재생 — 스마트 TV, 동영상 미리보기 — TV 사운드.

7. 휴대전화에서 TV로 전송할 때 자동재생 끄기

크롬캐스트나 TV 연결 기능을 사용해 휴대전화에서 TV로 동영상을 전송 중이라면, 실제 동영상은 TV에서 재생되더라도 전송 재생목록 설정은 휴대전화에서 관리할 수 있습니다.

  1. 휴대전화나 태블릿을 TV 기기에 연결합니다.
  2. 전송할 동영상을 하나 선택합니다.
  3. 휴대전화 화면 아래의 전송 제어 막대를 탭합니다.
  4. 현재 재생목록을 펼칩니다.
  5. 표시되는 자동재생 전환 버튼을 끕니다.

일반 휴대전화 앱의 자동재생과 TV로 전송 중인 재생목록의 자동재생을 구분해 확인하세요.

공식 근거: YouTube 고객센터 — TV로 전송할 때 자동재생.

8. 쇼츠(Shorts)가 자동 실행되거나 계속 반복될 때

유튜브 쇼츠는 일반 동영상과 다른 플레이어를 사용합니다. 따라서 다음 세 가지를 구분해야 합니다.

  • 홈 화면에서 쇼츠 미리보기가 움직임: 우선 '피드에서 재생' 설정을 확인합니다.
  • 쇼츠를 열자마자 재생됨: 쇼츠 플레이어의 일반 동작일 수 있으며, 일반 동영상의 '자동재생' 설정과 동일하게 제어된다고 보장할 수 없습니다.
  • 쇼츠 한 편이 끝나면 같은 영상이 다시 시작됨: 일반 동영상의 다음 관련 영상 자동재생과 다른 현상입니다.

2026년 9월 YouTube 커뮤니티에서도 쇼츠 한 편의 종료 후 자동으로 다음 쇼츠로 넘기는 별도 설정이 확인되지 않는다는 안내가 나왔습니다. 커뮤니티 답변은 공식 기능 명세와 동일한 수준의 근거는 아니므로, 모든 계정에 똑같은 기능이 제공된다고 단정하지 않습니다.

주의: '자동재생 끄기만 하면 쇼츠가 절대 실행되지 않는다'고 안내하는 글은 주의해야 합니다. 공식 자동재생 문서는 일반 동영상의 다음 영상 재생을 설명합니다. 앱을 켜자마자 쇼츠 화면이 뜨는 현상은 앱 상태·테스트 기능 등에 따라 다를 수 있으므로, 필요하면 프로필 사진 → 고객센터·의견 보내기를 통해 해당 버전의 동작을 문의하세요.

참고: YouTube 커뮤니티 — 쇼츠 반복 재생 질문(2026년 9월), YouTube 의견 보내기.

설정을 바꿨는데도 문제가 재현된다면 어떤 기기에서, 어떤 화면에서, 다음 영상이 시작되는지를 먼저 기록하세요. 앱 삭제나 계정 초기화보다 문제를 더 정확하게 좁힐 수 있습니다.

10. 모바일 데이터와 배터리 사용량을 줄이는 설정

실제로 데이터 사용량을 줄이고 싶다면 다음 영상 자동재생과 피드 인라인 재생을 함께 점검하세요.

예를 들어 홈 피드 자동재생을 'Wi-Fi 전용'으로 하면 모바일 데이터 환경에서는 인라인 재생을 제한할 수 있습니다. 반대로 완전히 방지하려면 '사용 안함'이 적절합니다.

유튜브 시청 중 화질 설정, 네트워크 조건, 영상 길이에 따라서도 데이터 사용량이 달라집니다. 자동재생을 꺼도 사용자가 직접 누른 동영상의 데이터 사용까지 0이 되는 것은 아닙니다.

YouTube의 자동재생은 장시간 활동하지 않을 때 자동으로 멈출 수 있습니다. 공식 문서에서는 모바일 네트워크에서 30분 동안 비활동, Wi-Fi에서 4시간 후 자동 중지되는 조건을 설명합니다. 하지만 이 제한만 믿고 장시간 실행해 두기보다는 자동재생을 명시적으로 꺼두는 편이 확실합니다.

11. 자주 묻는 질문

Q1. 유튜브 자동재생을 껐는데 홈 화면은 왜 계속 움직이나요?

다음 영상 자동재생과 피드에서 재생이 다른 설정이기 때문입니다. 모바일에서는 프로필 사진 → 설정 → 일반 → 피드에서 재생을 확인하세요.

Q2. 갤럭시에서 끄면 PC와 스마트 TV도 같이 꺼지나요?

그렇다고 보장할 수 없습니다. YouTube 공식 도움말은 기기마다 자동재생 설정이 다를 수 있다고 설명합니다.

Q3. 아이폰 YouTube 앱에서 자동재생 버튼은 어디에 있나요?

일반 동영상 재생 화면 상단의 전환 버튼 또는 프로필 사진 → 설정 → 자동재생을 확인합니다.

Q4. 자동재생을 끄면 쇼츠도 전부 멈추나요?

아닙니다. 쇼츠 플레이어의 시작·반복 동작을 일반 동영상의 다음 영상 자동재생 설정과 동일하게 취급해서는 안 됩니다.

Q5. 미리보기만 Wi-Fi에서 실행되게 할 수 있나요?

모바일 YouTube의 피드에서 재생 → Wi-Fi 전용을 사용하면 됩니다. 제공 메뉴는 앱 버전과 기기에서 확인하세요.

Q6. TV에서만 자동재생을 끄고 싶은데 가능한가요?

가능합니다. TV YouTube 앱의 설정 → 자동재생에서 조절할 수 있습니다.

Q7. PC에서 인라인 재생을 꺼도 왜 3초 미리보기가 있나요?

YouTube 공식 안내에 따르면 컴퓨터에서 인라인 재생을 끄면 자격 요건을 충족하는 동영상의 3초 미리보기가 대신 나올 수 있습니다.

Q8. 청소년 계정에서 자동재생 설정이 안 보입니다.

YouTube는 만 13~17세 사용자의 자동재생이 기본적으로 꺼져 있다고 안내합니다. 감독 대상 계정이라면 보호자 설정에 따라 해당 옵션이 제한될 수 있습니다.

12. 1분 최종 체크리스트

  • ☐ 일반 영상 종료 후 다음 동영상이 시작되지 않도록 자동재생을 껐다.
  • ☐ 홈·검색 썸네일이 움직이지 않도록 피드에서 재생을 껐다.
  • ☐ PC라면 설정 → 재생 및 성능 → 인라인 재생을 확인했다.
  • ☐ TV라면 TV YouTube 앱의 자동재생을 별도로 껐다.
  • ☐ TV로 전송 중이라면 전송 재생목록의 자동재생을 확인했다.
  • ☐ 쇼츠 재생 문제를 일반 자동재생과 혼동하지 않았다.
  • ☐ 모바일 데이터 사용이 걱정된다면 피드에서 재생 → 사용 안함 또는 Wi-Fi 전용을 선택했다.
  • ☐ 실제 사용 중인 기기별로 설정 후 동작을 확인했다.

정리: 일반 동영상이 이어서 재생되면 '자동재생', 홈 썸네일이 저절로 움직이면 '피드에서 재생', PC 썸네일의 움직임이라면 '인라인 재생', TV에서 계속 재생되면 TV의 자동재생을 확인하세요. 이 네 가지를 분리하면 불필요하게 앱을 삭제하거나 다시 설치할 필요 없이 대부분의 설정 문제를 해결할 수 있습니다.

자주 묻는 질문 (FAQ)

유튜브에서 영상이 끝난 뒤 자동으로 다음 영상이 재생되는 것을 어떻게 끌 수 있나요?

동영상 플레이어 상단의 자동재생 전환 버튼을 '사용 안함'으로 변경하거나, 앱 설정에서 자동재생 기능을 꺼서 설정할 수 있습니다.

홈 화면에서 썸네일 영상이 자동으로 재생되는 현상을 멈추려면 어떻게 해야 하나요?

유튜브 앱 설정의 '일반' 메뉴 내 '피드에서 재생' 옵션에서 '사용 안함'을 선택하면 홈 피드 썸네일 자동 재생을 끌 수 있습니다.

스마트 TV에서 유튜브 자동재생을 끄는 방법은 무엇인가요?

TV용 유튜브 앱의 설정 메뉴에서 '자동재생' 항목을 찾아 '사용 안함'으로 설정하면 영상 종료 후 다음 영상 자동재생을 중지할 수 있습니다.
