핵심 요약: 사진을 숨기고 싶다면 갤러리 → 사진 선택 → 더보기 → 보안 폴더로 이동을 확인하세요. 옮긴 사진을 되돌리려면 보안 폴더 안의 갤러리 또는 내 파일 → 더보기 → 보안 폴더에서 내보내기를 사용합니다. 보안 폴더 아이콘 숨기기는 그 안의 파일을 삭제하는 기능이 아닙니다. 다만 보안 폴더 신규 클라우드 백업은 현재 지원되지 않으며, 폴더 삭제·기기 초기화 전에는 데이터 이전 방법을 반드시 점검해야 합니다.

자료 검증 기준: 2026년 11월 4일. 삼성전자 공식 고객지원과 제품 설명을 확인해 작성했습니다. 메뉴명은 기종·One UI·보안 폴더 버전에 따라 달라질 수 있습니다. 직접 모든 기기에서 시험했다거나 데이터 복구를 보장하는 내용은 포함하지 않았습니다.

2. 보안 폴더 처음 설정하는 방법

삼성 공식 설명에 따르면 보안 폴더를 처음 사용하려면 별도의 잠금 방식을 지정해야 할 수 있습니다.

  1. 설정을 엽니다.
  2. 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더를 찾습니다.
  3. 화면에서 요구하는 경우 삼성계정으로 로그인합니다.
  4. 보안 폴더용 PIN·비밀번호·패턴을 설정합니다.
  5. 지원 기기에서는 지문 잠금 해제도 설정할 수 있습니다.
  6. 삼성계정으로 재설정(Reset with Samsung account) 옵션이 표시된다면, 암호 분실 시의 복구 가능성과 보안상 영향을 이해한 후 사용 여부를 결정합니다.
  7. 보안 폴더 앱을 열 수 있는지 확인합니다.

매우 중요한 주의: 삼성 공식 지원은 보안 폴더 초기 설정 때 '삼성계정으로 재설정'을 켜지 않았다면 암호를 잊었을 때 해당 재설정 기능을 사용할 수 없다고 안내합니다. 보안 폴더용 PIN을 절대 잊지 않도록 관리하세요.

메뉴는 기기마다 '보안 폴더'가 직접 표시되거나 '기타 보안 설정' 안에 있을 수 있습니다. 보안 폴더가 지원되지 않는 기종에는 기능이 제공되지 않을 수 있습니다.

출처: Samsung — Use the Secure Folder on your Galaxy phone or tablet

3. 갤러리 사진·동영상을 보안 폴더로 옮기기

가장 직접적인 방법입니다.

  1. 갤럭시의 일반 갤러리 앱을 엽니다.
  2. 숨길 사진 또는 동영상을 길게 눌러 선택합니다.
  3. 필요하면 여러 항목을 추가로 선택합니다.
  4. 더보기(점 세 개) 메뉴를 누릅니다.
  5. '보안 폴더로 이동'을 선택합니다.
  6. 보안 폴더 잠금 인증을 요구하면 본인의 인증 정보를 입력합니다.
  7. 보안 폴더 앱을 열어 내부 갤러리에 사진이 있는지 확인합니다.

삼성 공식 지원은 이 작업을 일반 갤러리에서 보안 폴더로 파일을 이동하는 절차라고 설명합니다. 따라서 원본 위치의 사진이 사라지는 것처럼 보일 수 있으며, 이동이 완료됐는지는 반드시 내부 갤러리에서 확인하세요.

한 번에 많은 사진을 옮길 때: 중요한 사진이라면 소수의 사진으로 먼저 시험하고, 올바르게 이동하는 것을 확인한 뒤 나머지를 옮기는 편이 안전합니다.

출처: 삼성 캐나다 — 갤러리에서 보안 폴더로 이동

4. 보안 폴더 앱 안에서 직접 파일 추가하기

갤러리에서 '보안 폴더로 이동' 메뉴가 보이지 않을 때는 보안 폴더 내부의 파일 추가 기능을 이용할 수도 있습니다.

  1. 보안 폴더를 엽니다.
  2. 잠금 방식으로 인증합니다.
  3. 더보기 → 파일 추가(Add files)를 선택합니다.
  4. 이미지·동영상·오디오·문서·내 파일 등 제공되는 범주를 선택합니다.
  5. 숨길 항목을 선택합니다.
  6. 이동(Move) 또는 복사(Copy) 중 원하는 방식을 확인하고 실행합니다.

5. '보안 폴더로 이동' 메뉴가 안 보일 때

삼성은 갤러리나 내 파일에 'Move to Secure Folder' 항목이 나타나지 않는 문제를 다룬 공식 문제 해결 문서를 제공합니다. 여기서 점검하도록 안내하는 항목은 잠금 상태에서 백그라운드 활동 허용(Allow background activity while locked)입니다.

공식 해결 순서

  1. 보안 폴더 앱을 엽니다.
  2. 더보기(점 세 개) → 설정으로 이동합니다.
  3. '잠긴 상태에서 백그라운드 활동 허용' 또는 영문 Allow background activity while locked 항목을 찾습니다.
  4. 해당 옵션을 켭니다.
  5. 일반 갤러리 또는 내 파일로 돌아갑니다.
  6. 사진을 선택하고 더보기 → 보안 폴더로 이동이 다시 나타나는지 확인합니다.

보안·배터리 설정 주의: 이 옵션은 잠금 상태에서 보안 폴더가 작동하는 범위에 영향을 줄 수 있습니다. 원하는 기능이 제공되는지 확인한 후 개인정보 보호와 사용성 요구에 맞게 설정을 유지하세요.

메뉴가 여전히 없으면 기기의 소프트웨어 업데이트와 보안 폴더 앱 버전을 확인하고, 보안 폴더 내부의 파일 추가로 시험해 볼 수 있습니다.

6. 보안 폴더에 넣은 사진이 안 보이면 어디에서 찾을까?

보안 폴더로 이동한 파일은 일반 갤러리와 별도로 보관됩니다.

  1. 보안 폴더를 엽니다.
  2. 보안 폴더 잠금 정보를 입력합니다.
  3. 안에 있는 갤러리 앱을 선택합니다.
  4. 옮긴 사진·동영상이 있는지 확인합니다.
  5. 파일 위치를 잘 모르겠다면 보안 폴더의 내 파일(My Files)에서도 이미지·동영상 유형별로 확인합니다.

확인할 점: 일반 갤러리에서 항목이 사라졌다는 사실만으로 삭제됐다고 판단하지 마세요. 보안 폴더 안으로 이동했을 가능성을 먼저 확인해야 합니다.

반대로 파일이 일반 갤러리와 보안 폴더 갤러리에 모두 있다면 복사 작업을 했거나 별도의 사본·동기화 자료가 남아 있을 수 있습니다.

출처: 삼성전자 — 보안 폴더 안의 갤러리·내 파일

7. 보안 폴더 사진을 일반 갤러리로 복구하는 방법

다시 일반 갤러리로 사진을 옮기려면 보안 폴더에서 내보내기(Move out of Secure Folder)를 이용합니다.

  1. 보안 폴더를 엽니다.
  2. 잠금 정보를 입력합니다.
  3. 내부 갤러리 또는 내 파일을 엽니다.
  4. 밖으로 내보낼 사진이나 동영상을 선택합니다.
  5. 더보기 → 보안 폴더에서 내보내기를 선택합니다.
  6. 일반 갤러리에 사진이 다시 나타나는지 확인합니다.

삼성은 내부 내 파일에서 선택한 파일을 길게 눌러 'Move out of Secure Folder'를 실행하는 공식 방법도 안내합니다.

SD 카드 관련 주의: 삼성 공식 문서에 따르면 과거 SD 카드에 저장된 파일은 보안 폴더에서 내보낼 때 휴대전화 내부 저장소의 새로운 폴더로 이동할 수 있습니다. 이때 원래 SD 카드 경로에 없어도 내부 저장소를 확인하세요.

8. 보안 폴더 아이콘 숨기기와 다시 표시하기

보안 폴더 아이콘을 앱스 화면에서 숨기는 것과 실제 보안 폴더 데이터를 삭제하는 것은 다릅니다.

아이콘 숨기기

  1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더로 이동합니다.
  2. 잠금 정보로 인증합니다.
  3. '앱스 화면에 보안 폴더 추가' 항목을 확인합니다.
  4. 아이콘을 표시하지 않으려면 해당 항목을 끕니다.

삼성의 공식 안내는 빠른 설정 패널에 있는 '보안 폴더' 항목으로도 숨기기·표시를 전환할 수 있다고 설명합니다.

아이콘 다시 표시하기

  1. 설정에서 같은 보안 폴더 화면을 엽니다.
  2. '앱스 화면에 보안 폴더 추가'를 켭니다.
  3. 앱스 화면에서 보안 폴더를 찾아 잠금 인증으로 들어갑니다.

중요: 아이콘을 숨기는 것은 접근 경로를 간소하게 감추는 설정일 뿐, 보안 폴더 자체를 삭제하거나 파일을 일반 갤러리로 내보내는 작업이 아닙니다.

출처: 삼성전자 — 보안 폴더 아이콘 숨기기

9. 보안 폴더 아이콘이 갑자기 사라졌을 때

보안 폴더가 앱스 화면에 보이지 않는 경우는 아이콘 숨김 설정부터 확인해야 합니다.

  1. 빠른 설정 패널에서 보안 폴더 아이콘이 보이는지 확인합니다.
  2. 빠른 설정의 편집 기능에서 보안 폴더 버튼을 추가할 수 있는지 확인합니다.
  3. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더를 엽니다.
  4. 앱스 화면에 보안 폴더 추가가 꺼져 있는지 확인합니다.
  5. 보안 폴더 잠금 인증 후 내부 자료가 남아 있는지 확인합니다.

주의: 아이콘이 없다는 이유만으로 보안 폴더를 다시 설치하거나 초기화하지 마세요. 기존에 저장된 사진이 있다면 데이터 손실 위험이 있는 조치를 먼저 피해야 합니다.

삼성 공식 문제 해결 문서도 보안 폴더를 찾을 수 없을 때 빠른 설정 또는 보안 설정 메뉴에서 확인하라고 안내합니다.

출처: Samsung — Unable to access Secure Folder

10. 보안 폴더 암호를 잊어버렸을 때

보안 폴더의 PIN·패턴·비밀번호는 휴대전화 잠금 화면용 암호와 다를 수 있습니다. 별도 잠금을 사용하도록 설정했다면 이를 알아야 보안 폴더에 접근할 수 있습니다.

삼성 공식 고객지원에 따르면 보안 폴더를 설정할 때 'Samsung account로 재설정'을 켰다면, 암호 분실 시 해당 기능을 이용해 재설정을 시도할 수 있습니다.

확인 순서

  1. 보안 폴더에 진입합니다.
  2. 설정한 잠금 방식으로 인증을 시도합니다.
  3. 'PIN 찾기' 등 공식 복구 선택지가 나타나는지 확인합니다.
  4. 삼성계정 재설정 옵션을 사전에 켰다면 안내되는 본인 인증 절차를 따릅니다.
  5. 복구 선택지가 없다면 삼성 공식 고객지원에 데이터 보존 가능성을 문의합니다.

경고: 삼성은 사전에 Samsung account 재설정 옵션을 켜지 않았다면 잠금 정보 분실 시 해당 복구 기능을 이용할 수 없으며, 보안 폴더 제거 후 재설정이 필요할 수 있다고 안내합니다. 제거하면 자료를 잃을 수 있으므로 중요한 사진이 있다면 임의 삭제·초기화하지 마세요.

11. 보안 폴더 사진은 삼성 클라우드에 자동 백업될까?

2026년 기준 특별히 주의해야 하는 부분입니다. 삼성 공식 고객지원은 보안 폴더의 새로운 백업 기능은 더 이상 제공되지 않는다고 명시합니다.

예전 제품 뉴스·설명서에는 삼성 클라우드에서 보안 폴더를 백업할 수 있다고 나올 수 있습니다. 하지만 과거 설명과 현재 지원 정책은 다릅니다.

상황2026년 삼성 공식 안내

과거에 이미 백업한 보안 폴더 데이터지원 조건에 따라 기존 백업 복원 가능

12. 스마트 스위치로 새 폰에 보안 폴더 이전하기

삼성은 보안 폴더 신규 백업이 지원되지 않는 대신, 기존 갤럭시에서 새 갤럭시로 데이터를 이전하는 경우 Smart Switch를 이용할 수 있다고 안내합니다.

이전 전 확인할 내용

  1. 기존 휴대전화에서 보안 폴더를 정상적으로 열 수 있는지 확인합니다.
  2. 사진·문서 등 중요한 자료가 어디에 저장됐는지 확인합니다.
  3. 기존·새 기기의 Smart Switch 지원 여부 및 데이터 이전 항목을 확인합니다.
  4. Smart Switch를 통해 보안 폴더 데이터 이전 항목이 제공되는지 확인합니다.
  5. 전송이 완료됐더라도 새 기기 보안 폴더를 직접 열어 자료가 실제로 옮겨졌는지 확인합니다.
  6. 확인이 끝나기 전에는 기존 휴대전화를 초기화하지 않습니다.

안전한 원칙: 새 기기에서 사진·동영상을 실제로 확인하기 전까지 기존 휴대전화의 원본 보안 폴더를 유지하세요. 기기 모델·One UI 버전 및 이전 방식에 따라 일부 항목의 지원 범위가 다를 수 있습니다.

주의: 일반 갤러리 파일을 USB 케이블로 복사하는 방법이 보안 폴더 내부 사진에 그대로 적용된다고 생각하면 안 됩니다. 보안 폴더 데이터는 별도의 보호 영역에 있으며 삼성도 일반 파일 전송 안내에서 이를 구분합니다.

출처: 삼성 — 보안 폴더 기존 백업·Smart Switch 이전, 삼성 — 보안 폴더 파일은 일반 USB 이전과 구분

13. 보안 폴더 삭제 전 반드시 사진을 밖으로 옮겨야 하는 이유

삼성 공식 도움말은 보안 폴더를 제거(Uninstall)하는 기능을 안내하면서, 제거 전 미디어 파일을 보안 폴더 밖으로 이동하는 선택지도 제공한다고 설명합니다.

삭제 작업 전에 다음을 확인하세요.

  1. 보안 폴더를 열 수 있는지 확인합니다.
  2. 보존해야 하는 사진·동영상·문서의 목록과 개수를 확인합니다.
  3. 필요한 파일은 '보안 폴더에서 내보내기'로 일반 저장소로 이동합니다.
  4. 일반 갤러리·내 파일에 실제로 나타나는지 확인합니다.
  5. 필요한 경우 다른 안전한 저장 위치에 별도 백업합니다.
  6. 그다음에야 보안 폴더의 삭제 여부를 결정합니다.

절대 혼동하지 말 것: 앱스 화면에서 아이콘 숨기기는 단지 표시 설정이며, 보안 폴더 제거는 데이터에 영향을 줄 수 있는 작업입니다. 중요한 사진을 보안 폴더에만 저장한 상태라면 제거·공장 초기화를 서둘러 실행하지 마세요.

비슷한 이름 때문에 기능을 혼동하기 쉽습니다.

기능목적가장 중요한 차이

실용적인 예시: 사진이 가족에게 보이지 않게 하려는 것이라면 보안 폴더로 이동을 선택할 수 있습니다. 단순히 갤러리 목록을 정리하려는 경우라면 앨범 숨기기 기능의 목적이 다릅니다. 사진을 잃지 않는 것이 우선이라면 백업·이전 가능 여부를 먼저 확인하세요.

15. 사진을 보안 폴더로 옮겼는데 Google 포토·OneDrive에서 보일까?

보안 폴더로 파일을 이동했다고 해서 이전에 다른 서비스에 동기화·업로드한 사진까지 자동으로 삭제됐다고 볼 수는 없습니다.

다음과 같이 저장 위치를 나누어 확인하세요.

  • 일반 갤러리에 남아 있는 사본
  • 보안 폴더 내부 갤러리의 이동된 파일
  • 과거에 Google 포토·OneDrive 등 클라우드에 이미 업로드한 사진
  • 메신저 대화방이나 다른 앱에 전송해 놓은 사진
  • USB·PC·외장하드로 미리 복사한 파일

개인정보 보호 관점: 보안 폴더로 옮긴 사진이 외부 서비스에서 자동 삭제되는 것은 아닙니다. 숨김 여부를 정확히 확인하려면 일반 저장소·클라우드·공유 앱을 각각 점검해야 합니다.

반대로 클라우드에 저장된 원본을 임의로 지우면 다른 기기에서도 사진이 삭제될 수 있으므로, 백업과 동기화의 차이를 이해하고 필요한 데이터를 보존한 후 정리하세요.

삼성 공식 도움말은 클라우드에 있는 파일을 바로 보안 폴더로 이동할 수 없고, 내부 저장소 또는 SD 카드에 저장된 파일이어야 한다고 설명합니다.

16. 보안 폴더 공유 메뉴에 보이지 않을 때

파일을 공유하면서 공유 패널에 보안 폴더가 없다면 삼성은 보안 폴더 자체의 표시·백그라운드 활동·공유 패널 설정을 확인하도록 안내합니다.

  1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더로 이동합니다.
  2. 보안 폴더를 잠금 해제해 엽니다.
  3. 더보기 → 설정에서 잠긴 상태에서 백그라운드 활동 허용을 확인합니다.
  4. 기타 보안 설정 또는 공유 관련 설정을 확인합니다.
  5. 해당 옵션이 제공되면 '공유 패널에 보안 폴더 앱 표시'를 사용할지 판단합니다.
  6. 다시 공유 화면에서 보안 폴더가 표시되는지 확인합니다.

삼성 공식 지원 문서에 따르면 공유 패널 표시 옵션은 기본적으로 꺼져 있을 수 있으며, 보안 폴더를 숨기거나 백그라운드 활동을 제한했다면 잠긴 상태에서 보이지 않을 수 있습니다.

주의: 개인정보 노출을 최소화하려는 경우에는 굳이 공유 패널에 보안 폴더를 항상 노출하도록 설정할 필요가 없습니다. 필요하면 보안 폴더 앱 안에서 파일 추가를 이용할 수 있습니다.

18. 자주 묻는 질문(FAQ)

Q1. 갤럭시 갤러리 사진을 완전히 숨기는 방법은 무엇인가요?

갤러리 → 사진 선택 → 더보기 → 보안 폴더로 이동을 이용하세요. 이동 뒤 보안 폴더의 갤러리에 있는지 확인해야 합니다. 이미 클라우드·다른 앱으로 공유된 사본은 따로 확인해야 합니다.

Q2. 보안 폴더로 이동한 사진은 어디 있나요?

보안 폴더 앱 → 갤러리에서 찾을 수 있습니다. 파일 종류에 따라 보안 폴더 안의 내 파일도 확인하세요.

Q3. '보안 폴더로 이동' 버튼이 없어요.

삼성 공식 안내는 보안 폴더 설정 → 잠긴 상태에서 백그라운드 활동 허용 옵션을 확인하도록 권장합니다. 이후 갤러리·내 파일에서 메뉴가 다시 보이는지 시험하세요.

Q4. 보안 폴더 안의 사진을 원래 갤러리로 되돌릴 수 있나요?

네. 보안 폴더 → 갤러리 또는 내 파일 → 사진 선택 → 더보기 → 보안 폴더에서 내보내기를 이용합니다.

Q5. 보안 폴더 앱이 안 보여요. 삭제된 건가요?

반드시 그렇지는 않습니다. 빠른 설정의 보안 폴더 버튼 또는 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더에서 아이콘 숨김 설정을 확인하세요.

Q6. 보안 폴더 아이콘을 숨기면 사진도 사라지나요?

아이콘 숨김은 표시 설정이므로 사진 삭제와 다릅니다. 보안 폴더를 실제로 제거하는 작업과 혼동하지 마세요.

Q7. 보안 폴더 사진은 삼성 클라우드에 자동으로 백업되나요?

현재 보안 폴더 신규 백업은 지원되지 않습니다. 기존 백업의 복원 가능 여부도 One UI 버전에 따라 다르며, 삼성 공식 안내는 Android 16 / One UI 8 이상에서 보안 폴더 내 기존 백업 복원을 제공하지 않는다고 설명합니다.

Q8. 새 갤럭시로 보안 폴더 사진을 옮길 수 있나요?

삼성은 지원 기기에서 Smart Switch로 데이터 이전할 수 있다고 안내합니다. 실제 이전 항목과 지원 범위를 확인하고, 새 기기에서 파일을 확인하기 전에는 이전 폰을 초기화하지 마세요.

Q9. 보안 폴더 암호를 잊었을 때 삼성계정으로 풀 수 있나요?

초기 설정에서 '삼성계정으로 재설정' 기능을 켜 둔 경우 공식 재설정 옵션을 이용할 수 있습니다. 미리 활성화하지 않았다면 같은 방법으로 복구할 수 없습니다.

Q10. 보안 폴더에 복사한 뒤 일반 갤러리 사진을 지워도 되나요?

먼저 보안 폴더 안의 파일이 정상적으로 열리는지 확인하고, 클라우드 동기화·원본 보존 여부를 검토해야 합니다. 중요한 파일은 보안 폴더에만 한 벌 보관하지 않는 것이 안전합니다.

Q11. 보안 폴더는 USB로 연결하면 PC에서 바로 보이나요?

삼성은 보안 폴더 안의 미디어 파일을 일반 USB 파일 전송 방식과 구분한다고 안내합니다. 필요한 파일은 공식 보안 폴더에서 내보내기 또는 지원되는 Smart Switch 이전 방법을 확인하세요.

Q12. 보안 폴더를 삭제하면 사진을 복원할 수 있나요?

자료 손실 위험이 있습니다. 삼성은 제거 전에 보안 폴더의 미디어 파일을 밖으로 이동할 수 있는 옵션을 안내합니다. 삭제 전에 반드시 사진을 내보내고 보존 상태를 확인하세요.

결론

갤럭시 사진을 보안 폴더에 숨기려면 '갤러리 → 사진 선택 → 보안 폴더로 이동'이 기본 방법입니다. 갤러리에서 메뉴가 안 보인다면 잠긴 상태에서 백그라운드 활동 허용을 확인하고, 이동된 사진은 보안 폴더 내부 갤러리에서 찾으세요. 일반 갤러리로 복구하려면 보안 폴더에서 내보내기를 사용하면 됩니다.

가장 중요한 데이터 보호 원칙은 '보안 폴더 = 자동 백업'이라고 생각하지 않는 것입니다. 보안 폴더 신규 클라우드 백업은 지원되지 않으며, 기존 백업 복원도 Android·One UI 버전에 따라 제한됩니다. 휴대전화 교체·폴더 삭제·공장 초기화 전에는 Smart Switch 지원 여부와 실제 원본 파일 보존 상태를 반드시 확인하세요.
