인스타그램을 잠깐 열었을 뿐인데 상대방이 ‘활동 중’ 표시를 보고 답장을 기다릴 때가 있습니다. 온라인 상태를 공개하고 싶지 않다면 계정을 비공개로 바꾸거나 앱을 삭제할 필요 없이 활동 상태 표시 설정부터 확인하면 됩니다.

핵심 답변: 인스타그램 앱에서 프로필 → 오른쪽 위 ≡ 메뉴 → 메시지 및 스토리 답장(Messages and story replies) → 활동 상태 표시(Show activity status) → 끄기 순서로 이동합니다. 활동 상태를 끄면 다른 사람이 내 현재 접속 및 최근 활동 상태를 확인할 수 없지만, 나도 다른 사람의 활동 상태를 볼 수 없게 됩니다.

혼동 주의: 온라인 초록점을 숨기는 기능과 DM을 읽었을 때 뜨는 읽음(Seen) 표시를 숨기는 기능은 별도입니다. 하나를 꺼도 다른 기능까지 함께 꺼지는 것은 아닙니다.

작성·검토일: 2026년 11월 4일. 인스타그램 공식 도움말, Meta 공식 발표, 소비자보호기관 안내를 토대로 작성했습니다. 앱 화면을 직접 조작해 확인한 체험기는 아닙니다.

1. 인스타그램 활동 상태 끄기: 바뀌는 것과 바뀌지 않는 것

활동 상태(Activity Status)는 메시지함과 대화 화면 등에서 사용자가 인스타그램에 접속해 있는지 또는 언제 마지막으로 활동했는지를 보여 주는 기능입니다. 초록색 점과 '활동 중' 또는 '몇 분 전 활동' 같은 문구로 나타날 수 있습니다.

궁금한 항목활동 상태를 끄면
내 온라인 초록점다른 사용자에게 내 활동 상태로 표시되지 않도록 설정
내 최근 활동 시간표시되지 않도록 설정
다른 사람의 온라인 상태나도 볼 수 없음
이미 주고받은 DM 대화삭제되지 않음
DM 읽음(Seen) 표시별도 설정이므로 자동으로 숨겨지지 않음
스토리 조회자 목록활동 상태 끄기와 다른 기능
계정 공개·비공개변경되지 않음
특정 사람에게만 숨기기기본 활동 상태 스위치에 개별 대상 선택 기능은 없음

공식 도움말은 내가 팔로우하거나 메시지를 주고받는 계정에 활동 상태가 표시될 수 있다고 설명합니다. 이는 모든 인스타그램 이용자가 내 활동 상태를 볼 수 있다는 뜻이 아닙니다.

공식 설명: Instagram Help Center - 활동 상태 설정.

2. 아이폰에서 인스타그램 활동 상태 끄는 방법

  1. 인스타그램 앱을 실행합니다.
  2. 오른쪽 아래 내 프로필 사진을 누릅니다.
  3. 프로필 화면 오른쪽 위 ≡ 메뉴를 누릅니다.
  4. '다른 사람이 나와 소통하는 방법'과 관련된 설정에서 메시지 및 스토리 답장(Messages and story replies)을 선택합니다.
  5. 활동 상태 표시(Show activity status)를 누릅니다.
  6. 활동 상태 표시 스위치를 끔으로 변경합니다.
  7. 같은 화면으로 다시 들어가 현재 스위치가 꺼져 있는지 확인합니다.

인스타그램 업데이트와 언어 설정에 따라 상위 메뉴의 명칭이 '설정 및 활동' 또는 '설정 및 개인정보' 등으로 다르게 표시될 수 있습니다. 설정 검색창이 보인다면 '활동 상태' 또는 'Activity status'로 검색해 보세요.

이 기능은 인스타그램을 로그아웃하거나 앱을 삭제하지 않고도 사용할 수 있습니다. 스위치를 바꾼 뒤 다른 사람의 온라인 표시도 사라질 수 있는데, 이는 공식적으로 안내된 상호 적용 효과입니다.

3. 갤럭시에서 인스타그램 온라인 초록점 숨기기

갤럭시를 비롯한 안드로이드에서도 핵심 설정 경로는 같습니다.

  1. 인스타그램 → 내 프로필로 이동합니다.
  2. 오른쪽 위 ≡ 메뉴를 누릅니다.
  3. 메시지 및 스토리 답장을 선택합니다.
  4. 활동 상태 표시를 열어 스위치를 끕니다.
  5. 다시 설정 화면을 열어 상태가 유지되는지 점검합니다.

메뉴가 보이지 않는다고 계정이 고장 난 것은 아닙니다. 앱 버전 및 화면 구성의 차이일 수 있으므로 먼저 앱 업데이트 여부를 확인하고 설정 검색 기능을 이용해 보세요.

계정 전환 주의: 인스타그램을 여러 계정으로 사용한다면 내가 현재 선택한 계정에서 변경했는지 확인해야 합니다. 한 계정의 설정값을 다른 계정에도 동일하게 적용했다고 단정하지 마세요.

4. PC에서도 활동 상태를 끌 수 있나요?

PC 웹에서 해당 설정이 제공되는 경우에는 다음 순서로 확인할 수 있습니다.

  1. 인스타그램 공식 웹사이트에 로그인합니다.
  2. 왼쪽 아래 더 보기(More) 또는 설정 메뉴를 선택합니다.
  3. 설정(Settings)으로 이동합니다.
  4. 메시지 및 스토리 답장을 찾습니다.
  5. 활동 상태 표시를 열어 스위치를 끕니다.
  6. 변경 후 모바일 앱에서도 같은 계정의 설정을 확인해 보세요.

웹과 앱의 메뉴 배치는 다를 수 있습니다. PC에서 관련 메뉴가 나타나지 않으면 모바일 앱으로 설정하는 방법이 가장 직접적입니다.

5. 온라인 표시와 DM 읽음 표시를 구별해야 합니다

활동 상태를 껐는데도 상대방이 내가 메시지를 읽었다는 것을 알아차린다면 다른 설정을 확인해야 합니다.

기능무엇을 보여 주나설정 경로
활동 상태 표시현재 온라인·최근 활동 시간메시지 및 스토리 답장 → 활동 상태 표시
읽음 확인 표시메시지를 읽었는지메시지 및 스토리 답장 → 읽음 확인 표시
스토리 조회 기록누가 스토리를 확인했는지온라인 활동 상태와 별개
계정 비공개게시물 등의 공개 범위계정 개인정보 설정
제한하기·차단특정 계정과의 상호작용각 계정의 별도 관리 기능

Meta는 2024년 3월 공식 발표에서 인스타그램 DM의 읽음 확인을 전체 대화 또는 특정 대화별로 설정할 수 있다고 안내했습니다. Meta가 공개한 전체 대화의 읽음 확인 설정 경로는 다음과 같습니다.

  1. 프로필에서 ≡ 메뉴를 누릅니다.
  2. 메시지 및 스토리 답장(Messages and story replies)으로 이동합니다.
  3. 읽음 확인 표시(Show read receipts)를 선택합니다.
  4. 표시 여부를 원하는 상태로 변경합니다.

특정 대화에 개별 설정이 적용되어 있다면 계정 전체 설정과 결과가 다를 수 있습니다. 또한 활동 상태 표시를 꺼도 DM을 읽었는지를 숨기는 기능이 자동으로 활성화되는 것은 아닙니다.

공식 출처: Meta - 인스타그램 DM 읽음 확인 설정 발표.

6. 특정 친구 한 명에게만 활동 상태를 숨길 수 있을까?

기본 활동 상태 표시 설정은 특정 친구를 선택하는 목록이 아니라 계정 전체를 대상으로 켜고 끄는 기능입니다. A에게만 숨기고 B에게는 보이도록 만드는 기능으로 이해해서는 안 됩니다.

특정 계정의 상호작용 자체가 불편하다면 인스타그램의 '제한하기'나 '차단'을 검토할 수 있습니다. 그러나 이는 DM과 댓글 등에서 다른 효과도 발생할 수 있으므로 단순 온라인 표시 숨기기와 구별해야 합니다.

  • 모든 사람에게 내 온라인·최근 활동 표시를 숨기고 싶다면 활동 상태 끄기
  • 특정 계정의 댓글과 DM 상호작용을 제한하고 싶다면 제한하기
  • 특정 계정과의 연락을 차단하고 싶다면 차단
  • 내 게시물의 공개 범위를 조절하고 싶다면 계정 공개 범위 변경

상대방이 내 활동 상태를 볼 수 없는 것만으로는 상대가 차단되었다고 판단할 수 없습니다. 활동 상태가 꺼져 있거나 다른 공개 조건이 충족되지 않았을 수도 있습니다.

7. 활동 상태를 껐는데도 초록점이 보인다면?

① 다른 계정에서 설정한 것은 아닌지 확인하세요

여러 계정 간 전환을 사용한다면 원하는 계정의 프로필로 이동한 후 다시 활동 상태 표시 설정을 확인하세요.

② 읽음 표시를 초록점과 혼동하지 마세요

DM 하단의 '읽음'은 메시지 확인 여부에 관한 표시입니다. 활동 상태가 꺼졌다고 해도 그 표시가 자동으로 꺼지지는 않습니다.

③ 앱을 다시 열고 현재 설정값을 확인하세요

이전에 열어 둔 메시지 화면이 그대로 표시될 수 있습니다. 화면을 새로 열고, 설정의 스위치가 실제로 꺼져 있는지 확인하세요. 표시 갱신이 늦어지는 것과 설정이 저장되지 않은 것은 구별해야 합니다.

④ 설정 메뉴가 검색되지 않는다면 앱 업데이트 여부를 확인하세요

앱스토어 또는 플레이스토어에서 인스타그램 업데이트를 확인하고, '활동 상태'와 'Activity status'를 각각 검색해 보세요. 계정이나 앱 버전에 따라 메뉴명이 다르게 보일 수 있습니다.

⑤ 상대방의 활동 상태가 안 보인다면 내 설정도 살펴보세요

인스타그램에서는 내 활동 상태를 끄면 다른 사람의 활동 상태도 볼 수 없게 됩니다. 내 화면에 상대방의 최근 활동 시간이 보이지 않는다는 이유만으로 상대가 나를 차단했다고 결론 낼 수 없습니다.

⑥ Threads·Facebook·Messenger의 온라인 표시도 함께 꺼질까요?

인스타그램 활동 상태 표시를 끄는 것과 다른 앱의 온라인 상태 설정은 동일하지 않습니다. 다른 Meta 앱에서의 상태가 걱정된다면 해당 서비스의 개인정보 설정을 별도로 확인해야 합니다.

8. 자주 묻는 질문

Q1. 활동 상태를 끄면 상대방에게 알림이 가나요?

활동 상태를 변경했다는 특별한 알림을 상대방에게 보내는 기능으로 안내되지는 않습니다. 다만 이전에 보이던 내 온라인 표시가 사라지는 것은 알아차릴 수 있습니다.

Q2. 활동 상태를 끄면 다른 사람의 초록점도 사라지나요?

네. 인스타그램은 자신의 활동 상태를 끄면 타인의 활동 상태도 볼 수 없다고 안내합니다. 이 점은 개인정보 설정을 바꾸기 전 반드시 알아야 할 부분입니다.

Q3. 활동 상태를 꺼도 DM이 오나요?

네. 이 기능은 접속 여부를 표시하는 방식을 변경하는 기능이지, 기존 대화를 삭제하거나 모든 DM 수신을 차단하는 설정이 아닙니다. 알림 설정과 차단 여부는 별도입니다.

Q4. 활동 상태를 끄면 스토리를 익명으로 볼 수 있나요?

아닙니다. 온라인 활동 표시와 스토리 조회 기록은 다른 기능입니다. 활동 상태 끄기를 익명 스토리 보기 기능으로 오해하지 마세요.

Q5. 상대방이 내 DM을 읽었다는 사실만 숨기고 싶다면?

활동 상태가 아니라 읽음 확인 표시 설정을 확인해야 합니다. 읽음 확인은 계정 전체 또는 특정 대화별로 관리할 수 있으며 사용 가능한 화면은 앱 버전에 따라 다를 수 있습니다.

Q6. 나를 팔로우하는 사람 모두에게 내 활동 상태가 보이나요?

반드시 그렇지는 않습니다. 인스타그램 공식 도움말은 내가 팔로우하는 계정과 메시지를 주고받는 계정을 대상으로 설명합니다. 활동 상태 표시의 공개 대상을 단순히 전체 팔로워로 해석하면 안 됩니다.

Q7. 앱 삭제나 로그아웃을 해야 온라인 초록점을 숨길 수 있나요?

필요하지 않습니다. 활동 상태 표시 설정을 끄면 됩니다. 앱 삭제를 개인정보 설정 변경의 대체 방법으로 안내하는 것은 적절하지 않습니다.

9. 결론: 온라인 초록점과 읽음 확인은 각각 설정하세요

인스타그램에서 온라인 초록점과 최근 접속 시간을 숨기는 가장 직접적인 방법은 프로필 → ≡ 메뉴 → 메시지 및 스토리 답장 → 활동 상태 표시 → 끄기입니다. 아이폰과 갤럭시 모두 이 설정을 확인하면 됩니다.

다만 이 기능을 끄면 내 활동 상태뿐 아니라 다른 사람의 활동 상태도 볼 수 없게 된다는 점을 기억하세요. 또한 온라인 숨기기·DM 읽음 확인·스토리 조회 기록·특정 계정 제한은 모두 다른 기능입니다. 원하는 개인정보 보호 수준에 따라 해당 설정을 구분해서 변경하는 것이 좋습니다.

자주 묻는 질문 (FAQ)

인스타그램에서 활동 상태를 끄면 어떤 점이 바뀌나요?

활동 상태를 끄면 내 온라인 초록점과 최근 활동 시간이 다른 사람에게 표시되지 않으며, 나도 다른 사람의 활동 상태를 볼 수 없게 됩니다. 다만 이미 주고받은 DM 대화나 읽음 표시에는 영향을 주지 않습니다.

온라인 초록점 숨기기와 DM 읽음 표시 숨기기는 같은 기능인가요?

아니요, 온라인 초록점 숨기기와 DM 읽음 표시 숨기기는 별도의 기능입니다. 하나를 꺼도 다른 기능은 자동으로 꺼지지 않으므로 각각 따로 설정해야 합니다.

특정 친구 한 명에게만 활동 상태를 숨길 수 있나요?

기본 활동 상태 설정은 계정 전체를 대상으로 하며 특정 친구만 선택해 숨기는 기능은 없습니다. 특정 계정과의 상호작용을 제한하려면 '제한하기'나 '차단' 기능을 이용해야 합니다.
