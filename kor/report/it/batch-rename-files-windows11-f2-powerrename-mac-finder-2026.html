2026 파일 이름 일괄 변경 방법: 윈도우11 F2·PowerRename·맥 Finder, 사진 번호 붙이기

핵심 요약 (Key Takeaways)
  • 윈도우11에서는 파일 탐색기에서 여러 파일 선택 후 F2 키로 기본 이름과 번호를 빠르게 붙일 수 있습니다.
  • 파일 이름 일부를 정교하게 바꾸거나 번호, 날짜, 메타데이터를 활용하려면 Microsoft PowerToys의 PowerRename 기능을 사용하세요.
  • 맥 사용자는 Finder의 여러 항목 이름 변경 기능을 활용해 추가 프로그램 없이 일괄 이름 변경이 가능합니다.

사진 300장, 거래명세서 50개, 스캔 문서 100개의 파일 이름을 하나씩 바꾸려면 시간이 오래 걸립니다. 그런데 원하는 작업에 따라 추가 프로그램 없이 몇 초 만에 처리할 수도 있고, 파일 이름의 특정 글자만 바꾸는 Microsoft PowerToys PowerRename이 필요할 수도 있습니다.

사진 300장, 거래명세서 50개, 스캔 문서 100개의 파일 이름을 하나씩 바꾸려면 시간이 오래 걸립니다. 그런데 원하는 작업에 따라 추가 프로그램 없이 몇 초 만에 처리할 수도 있고, 파일 이름의 특정 글자만 바꾸는 Microsoft PowerToys PowerRename이 필요할 수도 있습니다.

핵심 요약: 여러 파일에 같은 기본 이름과 번호를 붙이려면 Windows 파일 탐색기에서 여러 개 선택 → F2를 사용하세요. 파일 이름의 일부를 일괄 치환하거나 날짜·번호를 세밀하게 관리하려면 PowerToys PowerRename, Mac에서는 Finder의 여러 항목 이름 변경 기능을 사용하면 됩니다.

이 글은 2026년 11월 4일 기준 Microsoft Learn과 Apple 공식 도움말을 대조해 작성했습니다. 특정 컴퓨터에서 수백 개 파일을 실제 변경한 사용 후기가 아니며, 메뉴 위치와 결과 정렬은 OS 설정에 따라 달라질 수 있습니다.

2. 윈도우11에서 파일 이름 여러 개 한 번에 바꾸기: F2

파일 이름을 '여행사진 (1).jpg', '여행사진 (2).jpg'처럼 같은 이름과 번호로 정리할 때 적합합니다.

  1. 먼저 대상 사진·문서 파일을 새 폴더에 복사해 둡니다. 중요한 원본은 그대로 유지합니다.
  2. Windows 11의 파일 탐색기를 엽니다.
  3. 파일이 있는 폴더에서 변경할 파일을 선택합니다.
  4. 연속된 파일은 첫 파일 클릭 → Shift를 누른 채 마지막 파일 클릭, 떨어져 있는 파일은 Ctrl을 누른 채 클릭합니다.
  5. 파일 여러 개가 선택됐으면 F2를 누릅니다. 일부 노트북은 Fn + F2가 필요할 수 있습니다.
  6. 새 이름으로 여행사진을 입력하고 Enter를 누릅니다.
  7. 선택한 파일들이 여행사진 (1).jpg처럼 번호가 붙은 이름으로 변경됐는지 확인합니다.

이는 가장 간단한 일괄 번호 붙이기 방법입니다. 단, 실제 번호가 매겨지는 순서는 파일 탐색기의 선택 상태·정렬 등에 따라 달라질 수 있습니다. 사진 촬영순에 반드시 맞춰 번호가 붙는다고 단정하지 마세요.

연속 선택과 개별 선택의 차이

  • Ctrl + A: 현재 폴더의 파일과 폴더를 모두 선택할 수 있습니다. 원치 않는 항목까지 포함되지 않게 주의하세요.
  • Shift + 클릭: 연속된 범위를 선택합니다.
  • Ctrl + 클릭: 떨어져 있는 특정 항목만 추가하거나 제외합니다.

실무 팁: 이름을 바꿀 파일만 새 폴더에 복사해 정리하면 다른 파일을 실수로 바꿀 위험을 크게 줄일 수 있습니다.

3. 파일 이름을 바꿨는데 번호 순서가 뒤죽박죽이면?

예를 들어 IMG_0500.jpg, IMG_0501.jpg, IMG_0502.jpg가 촬영 시간과 다르게 표시되는 경우가 있습니다. 파일 탐색기에서 이름·수정한 날짜·만든 날짜 등 어떤 기준으로 정렬했는지 확인하세요.

다만 다음을 혼동하면 안 됩니다.

  • 파일 생성 날짜: 현재 파일 시스템에 생성된 시각일 수 있습니다.
  • 파일 수정 날짜: 마지막으로 수정한 시각입니다.
  • 사진 촬영 날짜: 사진에 EXIF 촬영 시각이 저장된 경우 확인할 수 있습니다.
  • 파일 이름: 위 날짜와 관계없이 사람이 임의로 수정할 수 있는 문자입니다.

휴대폰에서 사진을 복사하면 만든 날짜와 촬영 날짜가 다를 수 있습니다. 촬영순 파일명을 만들어야 한다면 탐색기의 단순 F2보다 EXIF 사진 메타데이터를 확인할 수 있는 기능을 검토하는 편이 정확합니다.

4. Windows에서 PowerRename으로 파일 이름 일괄 바꾸기

Microsoft의 무료 오픈소스 도구 PowerToys에는 PowerRename 기능이 포함돼 있습니다. 파일명 일부 치환, 대소문자 변경, 정규식, 번호 부여, 변경 결과 미리보기를 지원합니다.

PowerToys 설치

  1. Microsoft 공식 PowerToys 설치 안내에 접속합니다.
  2. 안내에 따라 Microsoft Store 또는 공식 GitHub 릴리스에서 설치합니다.
  3. PowerToys를 실행해 PowerRename 기능이 활성화되어 있는지 확인합니다.

공식 다운로드와 요구 사항은 Microsoft PowerToys 설치에서 확인할 수 있습니다.

검색·바꾸기로 'IMG_'를 '여행_'으로 변경하기

예를 들어 다음처럼 변경하고 싶다고 가정합니다.

변경 전변경 후
IMG_001.jpg여행_001.jpg
IMG_002.jpg여행_002.jpg
IMG_003.jpg여행_003.jpg

실행 순서:

  1. 파일 탐색기에서 대상 파일을 여러 개 선택합니다.
  2. 마우스 오른쪽 버튼을 클릭하고 PowerRename으로 이름 바꾸기(Rename with PowerRename)를 실행합니다.
  3. 메뉴가 바로 보이지 않으면 추가 옵션 표시 안을 확인합니다.
  4. 검색 대상(Search for)에 IMG_를 입력합니다.
  5. 바꿀 내용(Replace with)에 여행_을 입력합니다.
  6. 파일 이름만(Filename only)을 변경하도록 적용 대상을 확인합니다.
  7. 오른쪽 미리보기(Preview)에서 모든 이름이 기대한 결과인지 확인합니다.
  8. 문제가 없을 때만 적용(Apply)을 누릅니다.

미리보기는 실제 변경 전에 의도치 않은 수정·확장자 손상·중복된 이름을 발견하는 데 유용합니다.

PowerRename 메뉴가 없을 때

  • PowerToys가 설치돼 있는지 확인합니다.
  • PowerToys 설정에서 PowerRename을 활성화했는지 살펴봅니다.
  • 탐색기 오른쪽 클릭 메뉴의 추가 옵션 표시를 확인합니다.
  • 회사·학교 PC라면 관리자 설치 제한 또는 보안 정책을 확인합니다.

Microsoft의 공식 사용 설명서는 PowerRename 기능 안내에서 볼 수 있습니다.

5. 파일명 맨 앞 또는 맨 뒤에 글자 추가하기

정리할 파일의 원래 번호는 유지하면서 모든 파일 앞에 프로젝트명을 붙이고 싶을 수 있습니다.

예: 001.jpg → 행사_001.jpg

PowerRename에서는 정규식 사용(Use regular expressions)을 켜고 특정 위치를 찾는 방법을 활용할 수 있습니다.

  • 검색 대상: ^
  • 바꿀 내용: 행사_
  • 적용 대상: 파일 이름만

정규식 ^는 파일 이름의 시작 위치를 의미합니다. 따라서 파일명 앞에 일정한 글자를 추가할 수 있습니다. 결과는 반드시 미리보기로 확인하세요.

마지막 부분에 글자를 추가하는 경우에는 정규식 $가 파일 이름 끝 위치를 의미할 수 있습니다. 이때 파일 이름만 적용을 선택하지 않으면 확장자를 포함한 전체 문자열의 끝에 붙어 예상하지 못한 이름이 생길 수 있으므로 주의해야 합니다.

정규식 기능이 처음이라면 작은 복사본 폴더에서 3개 파일로 먼저 연습하는 것이 좋습니다.

6. 연속 번호·날짜·사진 촬영 날짜 붙이기

PowerRename은 번호를 매기거나 파일 생성 날짜·시간을 활용한 변경 기능을 제공합니다.

Microsoft 문서에 따르면 항목 번호 매기기(Enumerate items) 옵션을 통해 번호를 붙일 수 있고, 번호 시작·증가 간격·자릿수 같은 사용자 정의 패턴도 지원합니다.

또한 파일 생성 날짜·시간에 대응하는 변수와 EXIF·XMP 사진 메타데이터를 활용해 이름을 구성할 수 있습니다.

원하는 기준PowerRename에서 확인할 기능주의사항
001, 002, 003처럼 순서 번호Enumerate items실제 번호 순서는 미리보기 확인

사진을 실제 촬영일 기준으로EXIF 촬영 날짜 변수사진에 EXIF 데이터가 있어야 함
파일 이름의 대소문자 정리텍스트 서식 옵션한글은 대소문자 대상이 아님

핵심 차이: 파일 생성 날짜와 사진 촬영 날짜는 다른 정보입니다. 여행 사진을 촬영 날짜로 정렬하려면 원본 사진에 올바른 EXIF 촬영 시각이 저장돼 있는지 확인하세요. 메신저에서 다시 저장한 이미지나 캡처 화면에는 원래 촬영정보가 없을 수 있습니다.

7. Mac에서 사진·파일 여러 개 이름 바꾸기

macOS에서는 별도 앱 없이 Finder에서 일괄 이름 변경을 할 수 있습니다. Apple 공식 설명에 따르면 세 가지 주요 방식이 제공됩니다.

  1. Finder에서 파일 여러 개를 선택합니다.
  2. 선택된 파일을 Control-클릭하거나 마우스 오른쪽 버튼으로 클릭합니다.
  3. 이름 변경(Rename)을 선택합니다.
  4. 옵션에서 텍스트 대치(Replace Text), 텍스트 추가(Add Text), 포맷(Format) 중 목적에 맞는 항목을 선택합니다.
  5. 변경 전 미리보기를 확인한 뒤 이름 변경을 누릅니다.

Mac Finder의 세 가지 모드

모드용도예시

텍스트 추가기존 이름 앞 또는 뒤에 공통 문자 삽입원본 파일명 앞에 제출용_ 추가
포맷새 기본 이름과 번호·카운터·날짜 구성행사사진 1, 행사사진 2 등

Apple 공식 문서에서는 파일 이름 형식(Format)을 사용할 때 번호·카운터·날짜의 위치와 시작 숫자를 설정할 수 있다고 안내합니다. Apple Finder에서 여러 파일 이름 변경을 참고하세요.

Mac에서도 시스템 폴더·앱 구성 파일·라이브러리 안의 항목은 함부로 이름을 바꾸지 마세요. Apple은 시스템과 함께 제공된 항목 이름 변경을 피하도록 안내합니다.

8. 고급 사용자용: PowerShell로 특정 글자만 일괄 치환하기

수백 개 파일을 반복적으로 처리해야 하고 명령어를 이해한다면 Windows의 PowerShell을 이용할 수 있습니다. 다만 파일이 많은 폴더에서 명령 실행 전 미리보기가 필수입니다.

예를 들어 현재 폴더 안의 .jpg 파일 이름에서 IMG_를 여행_으로 바꿀 계획이라면, 먼저 PowerShell을 대상 폴더에서 열고 아래의 미리보기 명령(-WhatIf)만 실행합니다.

Get-ChildItem -File -Filter "*.jpg" |
  Rename-Item -NewName { $_.Name -replace "IMG_", "여행_" } -WhatIf

PowerShell에서 출력되는 예정 작업을 검토하고, 전혀 엉뚱한 파일이 포함되지 않았는지 확인합니다. -WhatIf는 실제 이름 변경 없이 예정 동작을 표시합니다.

파일이 중요하거나 복잡한 규칙이 필요하다면 우선 PowerRename의 시각적 미리보기를 쓰는 편이 실수 방지에 도움이 됩니다. Microsoft는 Rename-Item이 파일 내용은 바꾸지 않고 이름만 바꾸며, 이미 존재하는 같은 이름으로 덮어쓸 수 없다고 설명합니다. PowerShell Rename-Item 공식 문서를 참고하세요.

PowerShell을 사용할 때 금지할 실수

  • -WhatIf를 확인하지 않고 곧바로 실제 파일에 대량 적용하기
  • 원본 백업 없이 업무용 공유 폴더에서 실행하기
  • 파일명을 바꾸면서 확장자를 임의로 교체하기
  • 정규식으로 점(.)이나 괄호를 의도와 다르게 해석하기
  • 이름이 겹치는 문제를 무시하고 재실행하기

9. 파일 이름을 바꿨더니 사진이나 문서가 안 열릴 때

대량 이름 변경 후 파일이 안 열린다면 다음을 순서대로 확인하세요.

  1. 파일 탐색기의 보기 → 표시 → 파일 확장명을 켜 현재 확장자를 확인합니다.
  2. 원래 파일이 .jpg, .pdf, .docx 중 무엇이었는지 백업과 비교합니다.
  3. PowerRename에서 확장명까지 포함해서 이름을 변경했는지 확인합니다.
  4. 일괄 변경 작업 직후라면 탐색기에서 Ctrl + Z로 실행 취소를 시도합니다.
  5. 실행 취소가 제대로 되지 않거나 시간이 지난 경우에는 백업 원본과 비교해 복구합니다.

Microsoft PowerRename은 탐색기의 Ctrl + Z를 통한 이름 변경 실행 취소를 설명하지만, 실행 취소 이력은 상황에 따라 유지되지 않을 수 있습니다. Ctrl + Z를 영구적인 백업 수단처럼 믿지 마세요.

10. 이름 변경이 안 되는 대표적인 이유

증상가능한 원인확인 사항
파일 이름을 바꿀 수 없다고 나옴파일 사용 중, 접근 권한 부족해당 파일을 연 프로그램 닫기
'같은 이름이 이미 있습니다'동일한 폴더에 같은 이름의 파일 존재중복 이름 발생 여부 미리보기
PowerRename 결과가 이상함정규식 옵션 또는 적용 범위 오류정규식 끄기·파일 이름만 적용
확장자가 바뀌어 파일이 안 열림파일명과 확장명 혼동원래 확장자 복원·백업 비교
OneDrive에서 이름이 다시 바뀜다른 기기 동기화·공유 충돌클라우드 동기화 상태 및 변경 이력 확인
파일이 탐색기에서 순서대로 보이지 않음파일 탐색기 정렬 기준 문제이름 기준 정렬 확인
회사 공유폴더에서만 실패접근 권한·관리 정책공유 폴더 담당자에게 확인

특히 동기화 중인 클라우드 폴더에서 대량으로 파일명을 변경하면 다른 기기나 공동 작업자에게도 이름 변경 결과가 반영될 수 있습니다. 공유 업무용 폴더라면 작업 시간과 영향 범위를 미리 확인하세요.

11. 실제 정리 사례: 사진 300장과 거래명세서 50개

사례 A. 사진 300장을 '가족여행_001.jpg' 형식으로 정리

  • 원본 사진을 별도 폴더에 복사합니다.
  • 원본의 촬영일 정보가 보존돼 있는지 확인합니다.
  • 파일 탐색기 F2로 단순 번호를 붙일지, PowerRename에서 번호·날짜를 구성할지 선택합니다.
  • 최소 5개 파일을 먼저 처리한 뒤 순서가 기대한 대로인지 검토합니다.
  • 모든 파일을 적용하고 실제로 이미지가 열리는지 확인합니다.

중요: 사진을 나중에 다시 정렬할 계획이라면 1, 2, 10보다 001, 002, 010처럼 일정한 자릿수를 쓰는 편이 이름 기준 정렬에 유리합니다.

사례 B. 거래명세서 50개에서 '2025'를 '2026'으로 교체

연도만 바꾸는 것은 단순한 파일명 수정이지만 실제 문서의 거래 연도와 다른 파일명이 될 위험이 있습니다. 회계·법률·보험 증빙 파일은 편의를 위해 연도를 무조건 바꾸지 마세요.

파일명에 잘못 입력된 연도만 정정하는 작업이라면:

  1. 실제 문서 안의 거래일을 확인합니다.
  2. 수정 대상만 별도 폴더로 모읍니다.
  3. PowerRename의 검색·바꾸기로 대상 부분만 바꿉니다.
  4. 미리보기에서 수정할 파일 수를 확인합니다.
  5. 처리 후 파일명과 실제 문서 내용의 날짜가 일치하는지 표본 검증합니다.

사례 C. 스캔 문서 100개에 프로젝트명 접두어 붙이기

기존 문서 번호를 보존하려면 모든 파일명을 하나의 공통 이름으로 바꾸는 F2보다 PowerRename의 접두어 추가가 적합합니다.

예: A001.pdf → 계약서_A001.pdf

이때 원래 문서 번호와 확장자를 유지하도록 미리보기로 확인하세요.

12. 자주 묻는 질문

Q1. 윈도우11에서 파일 이름 일괄 변경은 프로그램 설치 없이 가능한가요?

네. 같은 기본 이름에 번호를 붙이는 작업은 파일 탐색기에서 여러 파일을 선택한 뒤 F2를 누르면 됩니다. 복잡한 일괄 치환과 날짜 규칙은 PowerRename이 편리합니다.

Q2. 파일명 앞에만 같은 글자를 붙이려면 어떻게 하나요?

PowerRename에서 정규식 사용, 검색값 ^, 바꿀 값에 원하는 접두어를 입력하는 방법이 있습니다. 작업 전 파일 이름만 적용인지 확인하고 미리보기를 검토하세요.

Q3. 파일 이름을 변경하면 사진 촬영 날짜도 바뀌나요?

일반적으로 파일명 변경은 사진에 저장된 EXIF 촬영 날짜를 직접 편집하는 작업이 아닙니다. 다만 파일 시스템의 일부 날짜나 클라우드 동기화 정보는 환경에 따라 달라질 수 있습니다.

Q4. JPG 파일 이름을 PDF로 바꾸면 PDF가 되나요?

아닙니다. 확장자 이름을 바꾸는 것은 파일 포맷 변환이 아닙니다. PDF가 필요하면 적절한 변환·인쇄·내보내기 기능을 사용해야 합니다.

Q5. 이름 변경 후 원래대로 되돌릴 수 있나요?

PowerRename과 탐색기에서는 직후에 Ctrl + Z로 실행 취소를 시도할 수 있습니다. 하지만 상황에 따라 이력이 사라지므로 사전에 복사해 둔 원본 폴더가 더 안전한 복원 수단입니다.

Q6. Mac에서 파일 이름 100개를 한 번에 바꾸려면 별도 앱이 필요한가요?

아닙니다. Finder에서 여러 파일을 선택한 후 오른쪽 클릭 → 이름 변경으로 텍스트 대치, 추가, 번호·카운터·날짜 형식을 적용할 수 있습니다.

Q7. 사진 촬영 날짜를 자동으로 이름에 넣을 수 있나요?

PowerRename은 EXIF·XMP 사진 메타데이터 사용을 지원합니다. 단, 사진에 촬영일 정보가 실제로 저장돼 있어야 하며, 파일 생성일과 촬영일을 혼동하지 않아야 합니다.

Q8. 회사 PC에 PowerToys를 설치해도 되나요?

Microsoft 공식 PowerToys는 Windows용 유틸리티이지만, 조직의 보안·설치 정책을 우선 확인해야 합니다. 설치가 제한되면 탐색기 F2나 사내 승인 도구를 사용하세요.

마무리: 어떤 방식을 고르는 것이 좋을까?

Windows 탐색기 F2는 단순 번호 부여, PowerRename은 일괄 치환·접두어·번호·날짜 처리, Mac Finder는 프로그램 설치 없는 파일명 대량 변경에 적합합니다.

한 번에 수백 개 파일의 이름을 바꾸기 전에 원본 복사 → 3~5개 테스트 → 미리보기 → 전체 적용 → 실제 파일 열기 검증 순서를 지키는 것이 실수로 문서를 잃는 일을 줄이는 가장 실용적인 방법입니다.

자주 묻는 질문 (FAQ)

윈도우11에서 여러 파일 이름을 한 번에 바꾸는 가장 쉬운 방법은 무엇인가요?

파일 탐색기에서 변경할 파일을 여러 개 선택한 후 F2 키를 눌러 새 이름을 입력하면 자동으로 번호가 붙어 일괄 변경됩니다.

PowerRename을 사용하려면 어떻게 해야 하나요?

Microsoft PowerToys를 설치하고 PowerRename 기능이 활성화되어 있는지 확인한 후, 파일 탐색기에서 여러 파일을 선택하고 마우스 오른쪽 버튼 클릭 메뉴에서 PowerRename을 실행하면 됩니다.

파일 이름 변경 시 주의해야 할 점은 무엇인가요?

파일 확장자(.jpg, .pdf 등)는 파일 형식을 나타내므로 변경 과정에서 확장자를 지우거나 바꾸면 파일 내용이 변환되지 않으니 주의해야 합니다.
