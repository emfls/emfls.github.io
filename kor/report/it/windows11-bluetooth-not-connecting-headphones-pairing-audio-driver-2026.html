1. '페어링', '연결됨', '소리 출력'은 서로 다릅니다

Bluetooth 연결을 해결할 때 가장 자주 혼동하는 개념부터 구분해야 합니다.

페어링: PC와 장치가 서로 등록되는 단계

Bluetooth 이어폰을 페어링 모드로 전환한 뒤 Windows에서 장치 추가를 실행해 서로 등록하는 과정입니다. 페어링했다고 해서 반드시 음악 재생이 바로 시작되는 것은 아닙니다.

연결: 실제 사용을 위한 Bluetooth 연결 상태

이전에 등록한 장치는 목록에 남아 있어도 현재 다른 스마트폰에 연결됐거나 전원이 꺼져 있으면 Windows에서 연결되지 않을 수 있습니다.

소리 출력: Windows가 어느 스피커로 재생하는지 결정

이어폰이 실제로 연결돼 있어도 Windows의 오디오 출력이 노트북 내장 스피커나 모니터로 설정돼 있으면 이어폰에서 소리가 나지 않습니다.

결론: '페어링됨' 상태에서 음악이 들리지 않는다고 무조건 Bluetooth 하드웨어 불량인 것은 아닙니다. 실제 연결 상태와 출력 장치 선택을 따로 확인하세요.

공식 출처: Microsoft - Bluetooth 연결 문제, Microsoft - 연결은 됐지만 소리 없음

2. 윈도우11 Bluetooth 켜기와 비행기 모드 확인

문제 해결은 가장 간단한 설정부터 시작하는 편이 좋습니다.

빠른 설정에서 켜기

  1. 작업 표시줄 오른쪽의 네트워크·소리·배터리 아이콘 영역을 누릅니다.
  2. Bluetooth 항목이 표시되는지 확인합니다.
  3. 꺼져 있다면 눌러 켭니다.
  4. **'연결되지 않음'**이 표시되면 켜져 있지만 현재 연결된 장치가 없다는 뜻일 수 있습니다.

Windows 설정 앱에서 확인

  1. Windows 키 + I로 설정을 엽니다.
  2. Bluetooth 및 장치를 선택합니다.
  3. 상단의 Bluetooth 스위치를 켭니다.
  4. 기기 목록이나 장치 추가 버튼이 나타나는지 확인합니다.

비행기 모드 끄기

  1. Windows 키 + A로 빠른 설정을 엽니다.
  2. 비행기 모드가 꺼져 있는지 확인합니다.
  3. 필요하면 Bluetooth를 다시 켭니다.

일부 노트북에는 제조사 전용 무선 기능 스위치나 단축키가 있을 수 있습니다. Bluetooth 버튼이 없는 경우 Windows의 설정 오류라고 단정하기 전에 PC 자체에 Bluetooth 어댑터가 탑재돼 있는지 확인하세요.

공식 출처: Microsoft - Bluetooth 켜기 및 끄기

3. 이어폰이 검색되지 않으면 '페어링 모드'부터 확인

무선 이어폰은 충전 케이스에서 꺼냈다고 해서 항상 다른 장치와 새로 연결할 수 있는 페어링 모드가 되는 것은 아닙니다.

확인 순서

  1. 이어폰과 충전 케이스의 배터리 잔량을 확인합니다.
  2. 이어폰 또는 헤드셋의 제조사 공식 설명서에 따라 페어링 모드로 전환합니다.
  3. 기존 스마트폰 등 다른 기기에 자동 연결돼 있는지 확인합니다.
  4. 노트북과 이어폰을 가까이 둡니다.
  5. Windows 11 설정 → Bluetooth 및 장치 → 장치 추가 → Bluetooth로 이동합니다.
  6. 목록에서 이어폰 이름을 선택하고 안내에 따라 연결합니다.

기종에 따라 케이스 버튼을 길게 누르거나 이어버드의 터치 영역을 조작하는 등 페어링 방법이 다릅니다. 모든 브랜드에 똑같은 버튼 누르는 시간이 적용된다고 생각하면 안 됩니다.

다른 장치가 이어폰을 먼저 잡는 경우

이어폰이 휴대전화에 자동 연결돼 있다면 PC에서 검색되거나 연결되는 데 방해가 될 수 있습니다. 본인 기기에서 현재 이어폰 연결을 확인하고, 필요하면 스마트폰과의 연결을 해제한 뒤 PC에서 다시 시험하세요.

무선 마우스·키보드도 같습니다

블루투스 마우스는 별도 페어링 버튼 또는 채널 선택 버튼이 있을 수 있습니다. USB 수신기 전용 무선 마우스라면 Windows Bluetooth 검색만으로 연결할 수 없습니다. Bluetooth 지원 모델인지 USB 동글 전용 모델인지 제품 사양을 확인해야 합니다.

공식 출처: Microsoft - 페어링 모드·배터리·범위 확인

4. 장치 검색 설정을 '고급'으로 바꾸는 방법

이어폰이 페어링 모드인데도 Windows 11 장치 추가 목록에 보이지 않는다면 Bluetooth 장치 검색 옵션을 살펴볼 수 있습니다.

Microsoft는 검색 설정에 **기본값(Default)**과 고급(Advanced) 옵션을 안내합니다. 일반적으로 기본값은 흔한 장치 유형을 표시하고, 고급은 더 다양한 Bluetooth 장치 유형을 검색합니다.

장치 검색 고급 설정 순서

  1. 설정 → Bluetooth 및 장치 → 장치로 이동합니다.
  2. 장치 설정 영역을 찾습니다.
  3. Bluetooth 장치 검색 항목을 엽니다.
  4. 기본값에서 고급으로 변경합니다.
  5. 이어폰을 다시 페어링 모드로 전환합니다.
  6. 장치 추가 → Bluetooth에서 검색 결과를 확인합니다.

해당 메뉴는 Windows 버전·빌드에 따라 표시되지 않을 수 있습니다. 고급으로 바꾸면 모든 장치가 무조건 연결된다는 뜻도 아닙니다. 장치가 페어링 상태가 아니거나 Bluetooth 하드웨어 호환성이 없으면 검색되지 않을 수 있습니다.

다른 Bluetooth 장치도 검색이 안 될 때

이어폰 한 개만 나타나지 않는지, 다른 Bluetooth 마우스·키보드도 검색되지 않는지 구분하세요. 모든 장치가 안 보인다면 PC의 어댑터·드라이버·서비스 문제를 점검할 필요가 있습니다.

공식 출처: Microsoft - Bluetooth 장치 검색을 고급으로 변경

5. '페어링됨'인데 연결이 안 된다면 장치를 제거하고 다시 등록

Bluetooth 목록에 이어폰 이름은 있지만 '연결되지 않음'으로 나오거나 연결이 실패하는 경우에는 기존 페어링 정보를 지우고 다시 등록하는 방법이 도움이 될 수 있습니다.

Windows 11에서 장치 제거·재등록

  1. 설정 → Bluetooth 및 장치를 엽니다.
  2. 문제가 있는 이어폰·마우스·스피커를 찾습니다.
  3. 장치 옆 **점 세 개(기타 옵션)**를 선택합니다.
  4. 장치 제거를 선택합니다.
  5. 이어폰 등을 껐다가 다시 켭니다.
  6. 제조사 설명서대로 페어링 모드를 활성화합니다.
  7. Windows에서 장치 추가 → Bluetooth로 이동합니다.
  8. 장치 이름을 선택해 다시 연결합니다.

Microsoft 공식 도움말은 장치가 목록에는 보이지만 연결되지 않는 경우 이 방법을 안내합니다.

장치 제거와 드라이버 제거는 다릅니다

여기서 장치 제거는 등록된 이어폰 등 주변기기의 페어링 정보를 삭제하는 것입니다. 장치 관리자에서 PC Bluetooth 어댑터 드라이버를 제거하는 작업과는 다릅니다.

먼저 이어폰 등 해당 장치의 등록 정보만 다시 만드는 것이 상대적으로 부담이 적습니다. 아직 단순 페어링 문제인지 확인되지 않았다면 무선랜·Bluetooth 드라이버를 임의 삭제하지 마세요.

'연결'을 눌렀더니 PIN 입력이 나옵니다

키보드·일부 오디오 액세서리는 페어링할 때 PIN 확인이나 화면의 숫자 일치 확인을 요구할 수 있습니다. 장치 또는 Windows 화면에 제시된 공식 절차를 따르세요. 출처가 확인되지 않은 임의 숫자를 반복 입력하는 것은 권장하지 않습니다.

공식 출처: Microsoft - Bluetooth 장치 제거 및 다시 추가

6. Bluetooth가 켜져 있는데 연결 안 될 때 10초 재시작

Bluetooth 하드웨어가 정상적으로 표시되지만 연결 과정만 실패한다면 전원을 잠시 껐다 켜는 것만으로 일시적인 오류가 해결될 수 있습니다.

Bluetooth 기능 재시작

  1. 설정 → Bluetooth 및 장치로 이동합니다.
  2. Bluetooth 스위치를 끔으로 바꿉니다.
  3. 10초 정도 기다립니다.
  4. Bluetooth를 다시 켭니다.
  5. 이어폰·스피커의 전원을 다시 켜거나 페어링 모드를 활성화합니다.
  6. 연결을 다시 시도합니다.

Microsoft의 Bluetooth 연결 안 됨 공식 안내는 Bluetooth를 끈 뒤 10초 기다렸다 켜는 과정을 제공합니다.

PC 재시작도 별도로 확인

Bluetooth 토글 재시작으로 문제가 해결되지 않았다면 Windows의 시작 → 전원 → 다시 시작을 이용해 PC를 재시작합니다.

잠자기 모드로 들어갔다가 다시 켜는 것과 시스템을 실제로 재시작하는 동작은 다를 수 있습니다. 저장되지 않은 문서·작업은 재시작 전에 저장하세요.

Bluetooth 연결이 끊겼다 다시 붙는다면

이런 현상이 반복된다면 단순 페어링 외에 배터리 부족, 절전 설정, 주파수 간섭, 드라이버 문제가 있을 수 있습니다. 다음 단락을 통해 원인을 분리하세요.

공식 출처: Microsoft - Bluetooth 끄고 10초 후 다시 켜기

7. '연결됨'인데 이어폰에서 소리가 안 나면 오디오 출력 선택

Bluetooth 이어폰이 연결됐는데도 소리가 노트북 스피커에서 나온다면 Windows의 오디오 출력 장치가 잘못 선택됐을 수 있습니다.

Windows 11에서 출력 장치 변경

  1. 이어폰이 Bluetooth로 연결된 상태인지 확인합니다.
  2. 작업 표시줄 오른쪽의 스피커 아이콘을 클릭합니다.
  3. 음량 조절 슬라이더 옆의 오디오 출력 선택 버튼을 누릅니다.
  4. 목록에서 실제 사용하려는 Bluetooth 이어폰·헤드셋을 선택합니다.
  5. 음량이 0이거나 음소거 상태인지 확인합니다.
  6. 음악이나 동영상을 짧게 재생해 시험합니다.

설정 앱에서 확인

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 출력 항목에 있는 장치 목록을 확인합니다.
  3. 이어폰을 선택하고 음량을 점검합니다.
  4. 출력 장치가 사용 안 함 상태로 나타난다면 표시되는 안내를 확인합니다.

음악은 되는데 특정 앱에서만 소리가 안 나면

Windows 전체 출력이 정상이라면 화상회의·게임·브라우저 앱의 앱별 오디오 출력 장치 설정을 확인해야 할 수 있습니다. 일부 앱은 기본 출력 장치와 별도로 사용할 스피커를 지정할 수 있습니다.

연결됐지만 소리가 나지 않는 문제를 해결하기 위해 Bluetooth 어댑터를 처음부터 제거할 필요는 없습니다. 출력 장치가 맞는지 먼저 확인하는 것이 더 간단합니다.

공식 출처: Microsoft - Bluetooth 연결됐지만 소리가 안 날 때, Microsoft - Windows 오디오 출력 확인

8. Bluetooth 오디오가 작거나 끊기고 지직거린다면

이어폰에서 소리가 나오더라도 자꾸 끊기거나 잡음이 생기면 연결 품질, 오디오 설정, 배터리 상태, 전파 간섭, 드라이버를 검토할 수 있습니다.

먼저 확인할 여섯 가지

  1. 이어폰·헤드셋·충전 케이스 배터리를 충분히 충전합니다.
  2. PC와 Bluetooth 장치 사이 거리를 줄여 시험합니다.
  3. Bluetooth 이어폰을 껐다가 다시 켭니다.
  4. 다른 스마트폰에서 같은 이어폰의 음질도 이상한지 확인합니다.
  5. Windows 설정 → 시스템 → 소리 → 출력에서 올바른 장치를 선택합니다.
  6. 이어폰과 PC의 공식 드라이버·펌웨어 업데이트가 있는지 확인합니다.

USB 3.0 장치 근처에서만 불안정하다면

Microsoft는 차폐가 불충분한 USB 3.0 장치가 Bluetooth 연결을 방해할 수 있다고 설명합니다. USB 장치가 꽂힌 곳 가까이에서만 문제가 생긴다면 연결 장치를 잠시 멀리 두고 비교할 수 있습니다.

오디오 향상 기능 점검

Windows의 설정 → 시스템 → 소리 → 해당 출력 장치에서 제공되는 경우 오디오 향상 기능을 끄고 비교해 보세요. Microsoft는 일부 오디오 장치에서 향상 설정이 왜곡이나 잡음 원인이 될 수 있다고 안내합니다.

소리가 끊긴다는 이유만으로 코덱이나 장치 하드웨어의 결함이 확정되는 것은 아닙니다. 다른 PC·휴대전화에서도 재현되는지 비교하면 원인을 좁히는 데 도움이 됩니다.

공식 출처: Microsoft - Bluetooth 연결 불안정과 USB 간섭, Microsoft - 오디오 왜곡 및 잡음 해결

9. 화상회의에서만 음질이 낮아지는 이유: 마이크·LE 오디오 확인

Bluetooth 헤드셋을 음악 감상할 때는 잘 쓰다가 Teams·Zoom 같은 화상회의에서 마이크를 켜면 음질이 갑자기 낮아질 수 있습니다.

원인은 이어폰 고장만이 아닙니다. Bluetooth의 오디오 전송 방식과 PC·헤드셋의 호환성에 따라 마이크를 사용하는 동안 재생 음질이 달라질 수 있습니다.

Windows 11 Bluetooth LE Audio란?

Microsoft는 Bluetooth LE Audio를 저전력 Bluetooth 연결로 오디오를 전송하는 기술로 설명합니다. 지원 장치에서는 마이크 사용 시에도 더 나은 음질을 제공할 수 있습니다.

그러나 Windows 11을 쓴다고 모든 PC가 Bluetooth LE Audio를 지원하는 것은 아닙니다. PC 하드웨어, 제조사 드라이버, 이어폰 모두 호환돼야 합니다.

마이크 사용 중 스테레오 지원 조건

Microsoft 공식 안내는 다음을 모두 요구합니다.

  • Windows 11 버전 24H2 이상
  • Bluetooth LE Audio를 공장에서 통합 지원하는 PC
  • 제조사의 필요한 Bluetooth 드라이버
  • LE Audio를 지원하는 헤드폰·이어버드
  • 마이크 사용 중 스테레오를 지원하는 해당 PC·이어폰의 기능 조합

일부 Windows 11 빌드 26100.4484 이상에서 지원되는 PC는 마이크 사용 중 스테레오 재생이 가능하다고 Microsoft는 설명합니다.

LE Audio 오디오 설정 변경

  1. 이어폰이 LE Audio로 연결되고 호환성 조건을 충족하는지 확인합니다.
  2. 설정 → 시스템 → 소리로 이동합니다.
  3. 출력의 Bluetooth LE Audio 장치를 선택합니다.
  4. 출력 설정 → 형식에서 마이크 사용 중 형식을 확인합니다.
  5. 실제로 메뉴가 제공된다면 **스테레오(2채널)**와 모노(1채널) 옵션을 살펴봅니다.
  6. 마이크를 켰을 때 소리가 끊기는 경우 Microsoft 안내에 따라 모노로 비교 시험할 수 있습니다.

해당 메뉴가 없으면 현재 하드웨어·드라이버에서 지원되지 않을 수 있습니다. 메뉴가 없다는 이유로 비공식 드라이버나 코덱 변경 프로그램을 설치하지 마세요.

공식 출처: Microsoft - Bluetooth LE Audio 호환성·마이크·스테레오

10. 블루투스 버튼·아이콘 자체가 사라졌을 때

어제까지 보였던 Bluetooth가 Windows 빠른 설정에서 사라지거나, 설정 앱에서 스위치를 켤 수 없게 되는 경우가 있습니다. Microsoft는 이를 Windows가 Bluetooth 하드웨어를 감지하거나 활성화하지 못하는 문제로 설명합니다.

먼저 비행기 모드 확인

  1. Windows 키 + A로 빠른 설정을 엽니다.
  2. 비행기 모드가 켜져 있다면 끕니다.
  3. 설정 → Bluetooth 및 장치에서 스위치가 나타나는지 확인합니다.

장치 관리자에서 실제 하드웨어 인식 확인

  1. 시작 버튼을 오른쪽 클릭합니다.
  2. 장치 관리자를 엽니다.
  3. Bluetooth 항목이 있는지 확인합니다.
  4. Bluetooth 어댑터를 찾아 경고 표시가 있는지 살펴봅니다.
  5. 장치가 사용 안 함이라면 디바이스 사용을 검토합니다.
  6. 이름·오류 코드가 있으면 기록해 둡니다.

완전 종료 후 다시 켜기

Microsoft는 Bluetooth가 사라진 상황에서 Shift 키를 누른 채 전원 → 종료를 선택해 PC를 완전히 끈 다음 약 1분 기다렸다 다시 켜는 방법을 안내합니다.

이때 문서 작업을 저장하고, 회사 컴퓨터처럼 종료 과정에 별도 정책이 있는 기기는 관리자 안내를 따르세요.

장치 관리자에서 Bluetooth 자체가 없다면?

해당 PC에 Bluetooth 어댑터가 없거나, 하드웨어가 인식되지 않거나, 필요한 드라이버가 설치되지 않았을 수 있습니다. 컴퓨터가 처음부터 Bluetooth를 지원했는지 제조사 사양을 확인하세요.

데스크톱 PC 중에는 Bluetooth 기능이 없는 모델이 있습니다. 이런 PC에서는 소프트웨어 설정만으로 기능을 만들어낼 수 없으며 지원되는 Bluetooth 어댑터가 필요할 수 있습니다.

11. 장치 관리자에서 Bluetooth 드라이버 업데이트하는 방법

Bluetooth가 켜지지만 연결이 불안정하거나 장치를 감지하지 못한다면 PC의 Bluetooth 어댑터 드라이버를 확인할 수 있습니다.

장치 관리자에서 업데이트

  1. 시작 메뉴에서 장치 관리자를 검색합니다.
  2. Bluetooth 항목을 펼칩니다.
  3. Bluetooth 어댑터를 오른쪽 클릭합니다.
  4. 드라이버 업데이트를 누릅니다.
  5. 드라이버 자동 검색을 선택합니다.
  6. 안내되는 업데이트가 있다면 설치합니다.
  7. 설치 후 PC를 다시 시작합니다.

Windows 업데이트에서 드라이버 확인

  1. 설정 → Windows 업데이트를 엽니다.
  2. 업데이트 확인을 누릅니다.
  3. 이용 가능한 Windows 및 장치 관련 업데이트를 검토합니다.
  4. 제공되는 경우 고급 옵션 → 선택적 업데이트도 확인합니다.
  5. 필요한 공식 드라이버·펌웨어 업데이트를 설치한 뒤 재시작합니다.

Microsoft는 Windows가 '최적 드라이버가 이미 설치됨'이라고 표시해도 제조사 공식 지원 페이지에는 더 새로운 드라이버가 있을 수 있다고 안내합니다.

제조사 공식 드라이버가 중요한 이유

노트북에 내장된 무선랜·Bluetooth 칩은 제조사별 펌웨어와 하드웨어 조합이 다릅니다. 따라서 인터넷에서 무작위로 받은 '드라이버 자동 수리 프로그램'보다 실제 노트북 모델 번호에 맞는 제조사 공식 드라이버를 사용하는 것이 좋습니다.

업데이트 중 PC 전원을 강제로 차단하지 마세요. 특히 BIOS·UEFI 같은 펌웨어 업데이트는 실패 시 기기 부팅에 영향을 줄 수 있으므로 제조사 지침을 정확히 따라야 합니다.

공식 출처: Microsoft - Windows Bluetooth 드라이버 업데이트

12. 드라이버 제거·롤백은 언제 해야 하나요?

일반적인 Bluetooth 연결 문제는 페어링 모드, 장치 제거·재등록, 문제 해결사, 업데이트 등 기본 조치부터 진행합니다. 어댑터 드라이버 제거는 그보다 영향이 큰 작업입니다.

Windows 업데이트 뒤부터 작동하지 않았다면 롤백 확인

  1. 장치 관리자 → Bluetooth에서 PC의 Bluetooth 어댑터를 선택합니다.
  2. 오른쪽 클릭해 속성을 엽니다.
  3. 드라이버 탭으로 이동합니다.
  4. 드라이버 롤백이 활성화됐는지 확인합니다.
  5. 해당 문제가 업데이트 직후 시작됐고 롤백 조건이 맞는다면 이전 드라이버로 돌아가는 방법을 검토합니다.
  6. 표시되는 지침에 따라 진행합니다.

롤백 버튼은 이전 드라이버가 저장돼 있지 않으면 사용할 수 없을 수 있습니다. 회색 버튼을 활성화하기 위해 출처가 불명확한 파일을 설치하지 마세요.

어댑터 드라이버를 제거해 재설치할 때

  1. 노트북·PC 제조사의 공식 지원 사이트에서 정확한 모델의 Windows 11용 Bluetooth 드라이버를 미리 확인합니다.
  2. 인터넷 접속이 어려워질 것에 대비해 필요한 설치 파일을 저장합니다.
  3. 장치 관리자 → Bluetooth → 해당 어댑터 → 장치 제거를 선택합니다.
  4. 안내사항을 확인하고 제거합니다.
  5. PC를 다시 시작합니다.
  6. Windows가 자동으로 드라이버를 설치했는지 확인합니다.
  7. 자동 복원이 안 되면 미리 준비한 제조사 공식 드라이버를 사용합니다.

Microsoft는 Windows가 재시작 후 드라이버를 자동으로 다시 설치할 수 있다고 안내하지만 모든 PC에서 재설치가 반드시 성공한다는 보장은 없습니다.

회사·학교 컴퓨터라면

Bluetooth 장치·드라이버 사용이 보안 정책으로 제한됐을 수 있습니다. 관리자 승인 없이 드라이버를 제거하거나 보안 정책을 우회하지 마세요.

공식 출처: Microsoft - Bluetooth 드라이버 제거·재설치·롤백

13. Bluetooth 연결이 몇 분마다 끊길 때: 전원 절약과 서비스 확인

이어폰이나 마우스가 잘 연결되다가 몇 분 뒤 끊기거나 절전 모드 이후 반복적으로 해제된다면 Windows의 전원 관리와 Bluetooth 서비스를 확인할 수 있습니다.

전원 절약 설정 확인

  1. 장치 관리자 → Bluetooth에서 사용하는 어댑터를 찾습니다.
  2. 해당 장치의 속성을 엽니다.
  3. 전원 관리 탭이 제공되는지 확인합니다.
  4. '전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음' 옵션이 있다면 해제해 비교합니다.
  5. 변경 후 일정 시간 실제로 연결이 유지되는지 확인합니다.

모든 PC와 드라이버에서 전원 관리 탭이 제공되는 것은 아닙니다. 옵션이 없다면 무리하게 레지스트리를 수정하지 말고 제조사 공식 도움말을 확인하세요.

Bluetooth 지원 서비스 다시 시작

  1. Windows 키 + R을 누릅니다.
  2. services.msc를 입력합니다.
  3. 목록에서 **Bluetooth 지원 서비스(Bluetooth Support Service)**를 찾습니다.
  4. 서비스를 오른쪽 클릭한 뒤 다시 시작을 선택합니다.
  5. 장치를 다시 연결하고 동일 문제가 반복되는지 확인합니다.

Microsoft는 끊김 문제의 공식 점검 방법으로 전원 절약 해제, Bluetooth 지원 서비스 재시작, 드라이버 업데이트를 제시합니다.

노트북 배터리 절약 모드도 확인

배터리 절약 모드가 켜져 있다면 전원 사용 정책의 영향을 받을 수 있으므로 일시적으로 껐을 때 차이가 있는지 비교할 수 있습니다. 연결 문제가 없어졌다면 무조건 영구적으로 배터리 절약을 꺼야 한다는 뜻은 아니며, 전력 소모와 안정성을 비교해 결정하세요.

14. Bluetooth 문제 해결사 실행: Windows 11 도움말 보기

설정과 페어링을 확인했는데도 오류가 반복된다면 Windows 11의 Bluetooth 자동 문제 해결사를 이용할 수 있습니다.

Microsoft의 최신 공식 문서는 도움말 보기(Get Help) 앱에서 Bluetooth 자동 진단을 실행하는 방법을 우선 안내합니다.

실행 순서

  1. 시작 메뉴에서 도움말 보기를 검색합니다.
  2. Microsoft의 도움말 보기 앱을 엽니다.
  3. Bluetooth 문제 해결을 검색하거나 관련 자동 진단 항목을 선택합니다.
  4. 화면의 질문과 진단 절차를 따라갑니다.
  5. 문제 해결사가 제시하는 조치를 수행합니다.
  6. 종료 후 이어폰·마우스·키보드를 다시 연결해 봅니다.

일부 Windows 버전에서는 설정 → 시스템 → 문제 해결 → 기타 문제 해결사에서 Bluetooth 관련 항목을 볼 수도 있습니다. 다만 최신 공식 고객지원은 도움말 보기 기반 자동 문제 해결사로 연결하는 경우가 있으므로 현재 표시되는 경로를 기준으로 진행하세요.

진단 결과를 기록해 두세요

문제 해결사에서 어댑터가 없다고 나오거나 드라이버 오류가 확인되면 PC 제조사 서비스센터에 전달할 수 있습니다. 같은 단계를 반복하기보다 실제 오류 코드·장치 모델명을 기록하는 편이 효율적입니다.

15. 한쪽 이어폰에서만 소리가 나올 때: LE Audio·재페어링

양쪽 이어폰 모두 충전돼 있지만 왼쪽 또는 오른쪽 한쪽에서만 소리가 나오는 상황은 Windows 11에서 일부 Bluetooth LE Audio 장치의 페어링이 올바르게 완료되지 않았을 때 발생할 수 있습니다.

우선 점검

  1. 좌우 이어버드와 충전 케이스의 배터리를 확인합니다.
  2. 이어폰 제조사에서 제공하는 초기 연결·동기화 방법을 확인합니다.
  3. Windows 11에서 기존 이어폰의 장치 제거를 실행합니다.
  4. 제조사 지침에 따라 이어폰을 올바른 페어링 모드로 전환합니다.
  5. 설정 → Bluetooth 및 장치 → 장치 추가에서 다시 연결합니다.
  6. 음악을 재생해 좌우 출력이 정상인지 확인합니다.

Microsoft는 LE Audio 이어버드가 페어링 과정에서 한쪽만 정상 연결되는 경우 한 채널 출력 문제가 발생할 수 있다고 설명합니다.

Windows 접근성 모노 오디오 확인

  1. 설정 → 접근성 → 오디오로 이동합니다.
  2. 모노 오디오 설정을 확인합니다.
  3. 스테레오 출력이 필요한 경우 현재 설정이 적절한지 살펴봅니다.

모노 오디오는 일반적으로 좌우 소리를 하나의 신호로 합치는 접근성 기능입니다. 모노 오디오 설정이 켜져 있다는 사실만으로 실제 이어버드 한쪽이 끊기는 하드웨어 문제를 확정할 수는 없습니다.

다른 스마트폰에서도 한쪽만 들린다면 이어폰 자체의 배터리·연결 동기화·고장 가능성을 제조사에 문의하세요.

16. 데스크톱 PC에 Bluetooth가 아예 없는 경우

조립 데스크톱 PC나 일부 사무용 PC는 Wi-Fi는 물론 Bluetooth 하드웨어도 기본으로 탑재하지 않았을 수 있습니다.

하드웨어 지원 여부 확인

  1. 컴퓨터 모델명 또는 메인보드 모델명을 확인합니다.
  2. 제조사 사양표에서 Bluetooth 지원 여부를 확인합니다.
  3. 장치 관리자 → Bluetooth 항목이 있는지 살펴봅니다.
  4. 기본 Bluetooth 하드웨어가 존재한다면 제조사의 공식 드라이버가 설치됐는지 확인합니다.
  5. 기능 자체가 없다면 Windows 설정만으로 Bluetooth를 활성화할 수 없다는 점을 이해합니다.

이 경우 필요한 연결 방식에 따라 정식 호환 Bluetooth USB 어댑터나 Bluetooth가 포함된 무선 모듈을 검토할 수 있습니다. 실제 제품을 구입할 때는 Windows 11 지원 여부와 드라이버 제공, 사용하려는 이어폰·키보드와의 호환성을 확인하세요.

USB 수신기 전용 장치와 혼동하지 마세요

일부 무선 마우스·키보드는 독립적인 2.4GHz USB 수신기를 사용하며 Windows의 Bluetooth 장치 추가에서 검색되지 않습니다. 제품에 동봉된 수신기를 사용하거나 제조사 설명서에서 Bluetooth 모드로 전환 가능한지 확인하세요.

17. 정상 연결을 유지하기 위한 관리 습관

Bluetooth 오류를 한 번 해결했다면 다음 관리 방법으로 문제 재발 가능성을 줄일 수 있습니다.

드라이버·운영체제 업데이트

Windows 업데이트와 제조사 공식 지원 사이트를 통해 Bluetooth 드라이버를 확인합니다. 무조건 최신이라는 이유로 비공식 드라이버를 설치하지 않고 PC 모델과 Windows 11 버전에 맞는지 검토하세요.

배터리 관리

배터리가 부족하면 Bluetooth 장치가 페어링 모드에 진입하지 못하거나 연결을 유지하지 못할 수 있습니다. 이어폰·마우스·키보드의 배터리 잔량을 확인하세요.

전파 간섭 줄이기

PC의 무선 어댑터와 액세서리를 너무 멀리 두지 마세요. 특정 USB 3.0 주변에서만 끊기는지 비교하는 것도 도움이 됩니다.

불필요한 페어링 정보 정리

오래전에 사용하던 장치가 목록에 남아 있다면 설정 → Bluetooth 및 장치에서 장치를 정확히 확인한 뒤 불필요한 등록 정보를 제거할 수 있습니다.

주의: 연결 문제 없이 정상 사용 중인 업무용 키보드나 마우스를 무작정 제거하지 마세요. 다시 페어링할 수단이 없으면 입력 장치를 사용할 수 없게 될 수 있습니다.

자주 묻는 질문 FAQ

Q1. 윈도우11에서 블루투스 이어폰이 검색되지 않는 이유는?

이어폰이 페어링 모드가 아니거나, 배터리가 부족하고 다른 스마트폰에 이미 연결됐을 수 있습니다. PC의 설정 → Bluetooth 및 장치 → 장치 → Bluetooth 장치 검색에서 고급 옵션이 제공되는지도 확인하세요.

Q2. '페어링됨'인데 이어폰이 연결되지 않습니다. 어떻게 하나요?

설정 → Bluetooth 및 장치에서 해당 이어폰을 장치 제거한 뒤 제조사 설명서대로 페어링 모드에 진입해 장치 추가로 다시 연결하세요.

Q3. Bluetooth는 연결됐는데 이어폰에서 소리가 안 나옵니다

작업 표시줄의 소리 아이콘에서 출력 장치 선택을 열고 실제 Bluetooth 이어폰을 선택하세요. 설정 → 시스템 → 소리 → 출력에서도 확인할 수 있습니다.

Q4. 윈도우11 블루투스 버튼이 아예 사라졌습니다

비행기 모드와 장치 관리자를 확인하세요. Microsoft는 문제가 계속되면 Shift를 누른 채 종료 후 약 1분 기다렸다 전원을 켜는 방법, 드라이버·제조사 펌웨어 점검도 안내합니다.

Q5. Bluetooth를 껐다 켜려면 몇 초 기다려야 하나요?

Microsoft 공식 Bluetooth 연결 문제 해결 문서는 스위치를 끈 뒤 10초 기다렸다 다시 켜기를 안내합니다. 이어폰도 껐다 켜고 연결을 다시 시험하세요.

Q6. 블루투스 드라이버는 어디에서 업데이트하나요?

장치 관리자 → Bluetooth → 해당 어댑터 오른쪽 클릭 → 드라이버 업데이트 → 자동 검색을 이용합니다. Windows 업데이트 및 PC 제조사 공식 지원 페이지에서도 확인할 수 있습니다.

Q7. Windows 업데이트 뒤 블루투스가 고장 났다면 이전 드라이버로 돌아갈 수 있나요?

장치 관리자 → Bluetooth 어댑터 → 속성 → 드라이버 → 드라이버 롤백에서 확인합니다. 이전 드라이버가 저장돼 있지 않으면 버튼이 비활성화될 수 있습니다.

Q8. 이어폰이 자꾸 끊기고 몇 분마다 재연결됩니다

배터리·거리·주변 USB 간섭·Windows 절전 모드를 확인하세요. 장치 관리자 전원 관리가 제공된다면 절전 설정을 점검하고, services.msc의 Bluetooth 지원 서비스 재시작도 검토할 수 있습니다.

Q9. 블루투스 이어폰 마이크를 켜면 음질이 나빠지는 이유는?

Bluetooth 오디오 전송 방식과 장치 호환성 때문일 수 있습니다. Bluetooth LE Audio 및 마이크 사용 중 스테레오 지원은 PC·이어폰·Windows 빌드와 제조사 드라이버 조건을 충족해야 합니다.

Q10. 데스크톱 PC의 장치 관리자에 Bluetooth가 없으면?

PC가 원래 Bluetooth를 지원하지 않는 모델이거나 드라이버가 설치되지 않았고 하드웨어가 인식되지 않는 상태일 수 있습니다. 제조사 사양을 먼저 확인하고, Bluetooth 기능이 없다면 Windows 11 호환 어댑터 등 별도 하드웨어가 필요할 수 있습니다.

  • 드라이버를 제거하기 전 제조사 공식 복구 수단을 준비했나요?

마무리: 장치 페어링과 드라이버 문제를 구분하세요

Windows 11에서 Bluetooth가 안 될 때는 장치가 목록에 보이는지가 가장 중요한 첫 번째 기준입니다. 보이지 않으면 페어링 모드와 배터리·검색 설정을 확인하고, 목록에는 있지만 연결되지 않는다면 해당 장치만 제거한 뒤 다시 등록해 보세요.

연결됐는데 소리가 안 나면 출력 장치 선택, Bluetooth 자체가 사라졌다면 어댑터 인식과 드라이버, 반복적으로 끊기면 절전 설정과 서비스 상태가 우선 점검 대상입니다.

특히 드라이버 제거·펌웨어 변경은 기본 조치보다 위험이 클 수 있으므로 Microsoft와 제조사 공식 안내를 확인해 복구 수단을 마련한 뒤 진행하세요.
