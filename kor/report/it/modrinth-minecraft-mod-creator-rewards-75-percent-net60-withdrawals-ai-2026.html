1. 모드린스(Modrinth)는 어떤 서비스인가요?

Modrinth는 마인크래프트의 모드, 리소스팩, 데이터팩, 셰이더, 모드팩, 플러그인 등의 제작물을 이용자에게 배포하는 서비스입니다. 각 프로젝트에는 소개, 사용 가능한 게임 버전, 파일, 라이선스, 다운로드 정보가 표시됩니다.

처음 접하는 이용자가 혼동하기 쉬운 것부터 구분해 보겠습니다.

  • 모드(Mod): 게임에 기능을 추가하거나 동작을 수정하는 프로그램
  • 리소스팩(Resource Pack): 텍스처, 사운드 등 게임 표현을 변경하는 파일 모음
  • 데이터팩(Data Pack): 마인크래프트의 일부 게임 규칙과 데이터를 변경하는 콘텐츠
  • 셰이더(Shader): 조명과 시각적 효과를 바꾸는 구성
  • 모드팩(Modpack): 여러 모드를 호환성에 맞게 묶어 제공하는 구성

실제로 수익을 얻으려면 무조건 복잡한 개발만 해야 하는 것은 아닙니다. 자신이 제작할 수 있는 범위의 프로젝트를 만들고, 실제 사용자에게 도움이 되는 기능과 완성도, 업데이트를 제공해야 합니다. 단순히 남의 파일을 모아 자신이 만들었다고 표시하거나, 다른 사람의 유료 자산을 허락 없이 재배포하면 수익 이전에 권리 문제가 생깁니다.

2. 광고수익 75%는 무슨 뜻인가요?

Modrinth의 Rewards Program Information은 웹사이트와 앱에서 발생한 광고 매출을 바탕으로 창작자에게 75%, 플랫폼에 25%를 분배한다고 설명합니다. 플랫폼은 광고 수익을 모아 창작자 전체의 활동량에 따라 나눕니다.

여기서 75%는 전체 수익 풀에 대한 비율입니다. 내가 하루 동안 100번 다운로드되었다고 100 × 고정 달러 단가가 자동으로 정해지는 방식이 아닙니다.

모드린스가 안내하는 주요 활동 지표는 다음과 같습니다.

  1. 프로젝트 페이지를 실제 브라우저에서 확인한 유효 페이지 조회
  2. 로그인한 이용자가 Modrinth App으로 수행한 적격 앱 다운로드
  3. 모드팩에 포함된 프로젝트의 앱 다운로드 활동

공식 수익 계산에서는 유효 페이지 조회와 적격 앱 다운로드를 점수(Point)로 집계한 뒤 창작자 수익 풀을 해당 점수 비중으로 배분합니다. 전체 플랫폼 수익과 모든 프로젝트의 합산 점수가 변하면 같은 다운로드 수라도 달러 수익이 달라질 수 있습니다.

따라서 ‘마인크래프트 모드 1,000다운로드당 얼마’ 같은 단일 고정 시급표는 정확한 공식 설명이 아닙니다. 자신의 대시보드에 확정된 실제 금액을 확인해야 합니다.

3. 조회수와 다운로드가 돈으로 계산되는 공식 예시

공식 문서에 나온 구조를 이해하기 위해 가상의 수치로 계산해 보겠습니다.

어느 날 플랫폼의 광고 매출이 100달러 발생했고 창작자 수익 풀은 75달러라고 가정합니다. 그날 전체 적격 점수가 1,000점이며, 내 프로젝트의 합산 점수가 20점이라면 내 배분액은 75달러 × 20 ÷ 1,000 = 1.50달러가 됩니다.

이는 수학적인 설명일 뿐 실제 Modrinth의 하루 광고 수익이나 이용자의 평균 다운로드 실적을 나타내는 수치가 아닙니다. 다음 날 전체 창작자의 점수 합계가 2,000점이거나 광고 매출이 50달러라면 같은 20점의 수익이 달라집니다.

예를 들어 아래 세 숫자가 동시에 변동한다고 생각하면 이해하기 쉽습니다.

  • 해당 날짜 플랫폼의 실제 광고 수익
  • 자신의 프로젝트가 벌어들인 유효 점수
  • 모든 참여 프로젝트가 획득한 총 유효 점수

개별 수익 = 창작자 수익 풀 × 자신의 인정 점수 비중이라는 것이 핵심입니다.

공식 수익배분 문서에는 여러 프로젝트의 조회·다운로드 합계 및 공동 창작자 배분을 예시로 보여주고 있습니다.

4. 모든 다운로드가 보상에 포함되나요?

공식 문서는 프로젝트가 관련된 실제 페이지 조회와 Modrinth App 내 적격 다운로드를 설명합니다. 아무 외부 사이트에서 이루어진 파일 다운로드나 자동화 프로그램이 발생시킨 요청까지 모두 동일하게 수익을 지급한다고 해석하면 안 됩니다.

특히 Modrinth는 봇으로 발생시킨 다운로드·조회수를 적극적으로 제거하며, 적발 시 영구적으로 서비스에서 차단할 수 있다고 명시합니다.

이와 함께 계정 프로필 조회는 프로젝트 성과 점수에 포함되지 않는다고 안내합니다. 단순히 내 프로필에 사람들이 들어왔다는 사실을 수익 계산에 더하면 안 됩니다.

실적을 늘리겠다며 페이지 새로고침 봇을 운영하거나, 여러 계정으로 반복 다운로드하고, 실제 이용할 의사가 없는 사람을 동원해 숫자를 조작하는 방식은 사용하지 마세요.

정상적인 개선 방법은 구체적인 기능 설명, 정확한 지원 버전, 오류 감소, 지속적인 업데이트와 사용자가 찾기 쉬운 문서입니다.

5. 모드린스 보상 프로그램 가입은 별도로 해야 하나요?

Modrinth의 공식 FAQ에 따르면 프로젝트를 업로드한 창작자는 별도의 수익화 가입 절차 없이 수익을 배분받을 수 있지만, 실제 출금을 하려면 계정에 지급 정보를 등록해야 합니다.

이 말은 새 프로젝트를 게시한 순간 현금이 통장으로 들어온다는 뜻이 아닙니다. 수익 집계와 인출 준비를 구분해야 합니다.

  • 1단계: 창작자로 프로젝트 게시 — 자신이 제작·배포할 권리를 가진 콘텐츠를 업로드합니다.
  • 2단계: 프로젝트 공개 및 활동 집계 — 프로젝트의 정상적인 페이지 조회와 앱 다운로드 등이 집계됩니다.
  • 3단계: 보상 대시보드 확인 — 실제로 발생한 광고수익 분배 내역을 확인합니다.
  • 4단계: 출금 정보 등록 — 자신의 국가에서 지원되는 출금 수단과 요구 정보를 입력합니다.
  • 5단계: 인출 가능한 수익만 출금 — 정산 대기 기간이 끝난 금액으로 요청합니다.

프로젝트의 공개 가능 여부와 광고보상 산정 여부는 플랫폼의 운영·콘텐츠 규정을 충족해야 한다는 점도 중요합니다.

16. 프로젝트의 AI·광고·유료 기능 공개 항목은 어디까지 작성하나요?

Modrinth의 콘텐츠 공개(Content Disclosures) 시스템은 이용자가 콘텐츠를 다운로드하기 전 알아야 할 사항을 프로젝트에 표시하도록 설계되었습니다.

2026년 안내가 설명하는 대표적인 공개 항목은 다음과 같습니다.

  • AI-generated content: AI가 실질적인 코드를 만들거나 에셋·설명 작성에 참여한 경우
  • Contains advertising: 프로젝트 안에 홍보나 협찬, 다른 콘텐츠에 관한 광고가 있는 경우
  • Contains paid features: 실제 화폐를 지급해야 이용할 수 있는 기능이 있는 경우
  • Contains telemetry: 이용자의 데이터가 외부로 전송되는 경우, 수집 내용과 동의 방식
  • Contains derivative content: 다른 프로젝트를 포크하거나 상당한 내용을 이용한 경우
  • Photosensitivity warning: 심한 깜박임 등 광과민성 위험이 있는 경우
  • External system interactions: 게임 외부의 사용자 파일이나 시스템에 접근하는 기능이 있는 경우

이러한 공개 항목을 설정했다고 모든 금지 활동이 허용되는 것은 아닙니다. 예를 들어 유료 기능이 있는 프로젝트는 구매로 무엇이 열리는지 설명해야 하지만, 프로젝트 전체를 유료 장벽 뒤에 두는 방식이 허용되는지는 별도 콘텐츠 규칙을 따져야 합니다.

개발자라면 프로젝트를 처음 공개할 때뿐 아니라 업데이트 과정에서도 해당 공개 항목을 유지·수정해야 합니다.

Q1. 모드린스에 모드를 무료로 올려도 돈을 받을 수 있나요?

공식 광고수익 배분 프로그램이 있으므로 조건에 맞는 프로젝트에서 유효한 페이지 조회와 앱 다운로드가 발생하면 수익이 집계될 수 있습니다. 단순 등록만으로 고정 수익을 보장하는 것은 아닙니다.

아닙니다. 75%는 창작자 전체가 나눠 가지는 수익 풀의 비율입니다. 개별 창작자는 자신의 프로젝트가 획득한 유효 점수 비중에 따라 해당 풀을 배분받습니다.

Q3. 마인크래프트 모드 1,000다운로드면 몇 달러인가요?

Modrinth는 고정된 다운로드당 지급액을 약속하지 않습니다. 광고수익 풀, 유효 조회수와 다운로드 수, 플랫폼 전체 프로젝트의 점수에 따라 달라집니다.

Q4. 수익을 받기 위해 별도 수익화 승인을 신청해야 하나요?

공식 설명에 따르면 적격 프로젝트를 공개한 창작자는 별도의 수익화 가입 없이 보상 배분 대상이 될 수 있습니다. 그러나 현금 지급을 신청하려면 계정에 출금 정보를 등록하고 관련 요건을 충족해야 합니다.
