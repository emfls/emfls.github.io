엑셀에서 숫자를 바꿨는데 합계가 그대로이거나, =SUM(A1:A10)을 입력했는데 결과가 아니라 수식이 통째로 보인다면 원인부터 구분해야 합니다. 자동 계산이 꺼진 문제, 수식 표시 보기, 텍스트 서식으로 저장된 수식, 수식 자체에 발생한 오류는 겉으로 비슷해 보여도 해결 방법이 서로 다릅니다.

이 글은 Microsoft Excel 2024·Microsoft 365 및 Windows 데스크톱 Excel의 공식 지원 문서를 기반으로 작성했습니다. 다른 버전이나 Mac·웹용 Excel에서는 메뉴·단축키가 일부 다를 수 있습니다.

먼저 원본 파일을 복사해 백업하고, 아래 진단표에서 자신의 증상을 찾은 다음 필요한 단계만 실행하세요. 특히 업무용 정산표나 재무 자료에서는 오류가 사라져도 계산 결과가 정확한지 다시 확인해야 합니다.

1. 엑셀 수식 계산 안됨: 30초 증상별 진단표

증상가장 먼저 확인할 원인해결 위치
원본 숫자를 바꿔도 합계가 예전 숫자로 남음계산 옵션이 수동수식 → 계산 옵션 → 자동
셀에 =SUM(A1:A10) 식 자체가 표시됨수식 표시 모드 또는 텍스트 서식수식 → 수식 표시 / 셀 서식 확인
특정 셀 한두 개에서만 =A1+B1이 글자로 표시됨셀이 텍스트 형식이거나 앞에 작은따옴표가 있음표시 형식 → 일반, F2 → Enter
SUM 대신 #NAME? 표시함수 이름 오타·인식 불가능한 이름함수 철자·엑셀 버전 확인
계산 결과가 #VALUE!참조 데이터 형식이나 연산 문제문자열·숫자·공백 확인

진단의 핵심: 수식이 전혀 계산되지 않는 문제와 계산했지만 오류값이 나오는 문제를 먼저 나누세요. 둘을 구분하지 않고 모든 셀에 일괄 서식 변경을 적용하면 오히려 원본 데이터가 손상될 수 있습니다.

2. 숫자를 바꿨는데 합계가 안 바뀐다면: 자동 계산 켜기

엑셀에서 수동 계산(Manual)이 선택되어 있으면 수식의 참조값을 바꿔도 결과가 즉시 갱신되지 않을 수 있습니다. Microsoft는 자동 계산(Automatic)이 일반적인 기본 계산 모드라고 설명합니다.

Windows Excel에서 확인 순서

  1. 계산이 갱신되지 않는 통합 문서를 엽니다.
  2. 상단 리본의 수식 탭을 누릅니다.
  3. 계산 옵션을 선택합니다.
  4. 자동으로 설정합니다.
  5. 수식에서 참조하는 숫자를 한 번 변경해 결과가 따라 바뀌는지 확인합니다.

리본에서 메뉴를 찾기 어렵다면 파일 → 옵션 → 수식 → 통합 문서 계산 → 자동 경로를 이용할 수 있습니다.

수동 계산이 설정되어 있는 이유는 무엇인가요?

수식과 데이터가 아주 많은 대형 통합 문서에서는 처리 속도를 관리하기 위해 작성자가 의도적으로 수동 계산을 설정하기도 합니다. 다른 사람이 만든 재무·재고·정산 파일에서 이러한 설정이 발견되면 설정을 바꾸기 전에 원본을 백업하고 담당자와 확인하는 것이 좋습니다.

또한 Excel의 계산 옵션은 열려 있는 다른 통합 문서의 설정과 상호작용할 수 있습니다. 한 파일에서 문제를 해결한 뒤에는 해당 파일의 저장·재열기 동작까지 확인하세요.

공식 출처: Microsoft — Excel에서 수식 재계산·반복 계산·정밀도 변경

3. F9를 눌러 수식만 재계산하기: 자동과 수동의 차이

현재 파일의 계산 옵션을 바로 바꿀 수 없거나, 원인이 계산 갱신 문제인지 시험하려면 F9 키를 이용할 수 있습니다.

키 또는 메뉴하는 일
F9열려 있는 통합 문서의 다시 계산이 필요한 수식 계산
Shift + F9현재 워크시트 계산
Ctrl + Alt + F9마지막 계산 이후 변경 여부와 관계없이 열려 있는 통합 문서의 수식을 강제로 전체 계산
Ctrl + Alt + Shift + F9수식 종속 관계를 다시 검사한 뒤 전체 계산
수식 → 지금 계산메뉴에서 재계산 실행

노트북에서 F9가 미디어 키로 작동한다면, 키보드 모델에 따라 Fn 키를 함께 눌러야 할 수 있습니다.

F9를 눌렀더니 결과가 바뀌었다면?

수동 계산 또는 재계산 지연이 원인일 가능성이 있습니다. 다음에는 계산 옵션이 자동으로 설정되어 있는지 확인하세요. 단, F9로 값이 바뀌었다는 사실만으로 모든 수식이 정확하다고 보장하지는 않습니다.

F9로도 안 바뀐다면?

수식이 아예 텍스트로 저장돼 있거나, 수식 자체에 오류가 있을 수 있습니다. 다음 장의 수식 표시 모드와 텍스트 서식을 먼저 확인하세요.

공식 출처: Microsoft — Excel 바로 가기 키

4. =SUM(A1:A10)이 결과 대신 그대로 표시될 때

수식을 입력했는데 셀에서 계산 결과가 아니라 =SUM(A1:A10)처럼 수식이 그대로 보인다면 먼저 수식 표시(Show Formulas) 기능을 확인하세요.

방법 A. 수식 표시 끄기

  1. 상단 수식 탭을 엽니다.
  2. 수식 표시가 선택돼 있다면 한 번 더 눌러 해제합니다.
  3. 셀의 수식이 계산 결과로 표시되는지 확인합니다.

Windows 데스크톱 Excel에서는 **Ctrl + (억음 악센트)** 키로 이 표시를 전환할 수도 있습니다. 키보드 배열에 따라 키의 위치가 다를 수 있으므로, 단축키가 어렵다면 리본의 수식 → 수식 표시 메뉴가 더 확실합니다.

구별법: 여러 셀의 계산식이 갑자기 한꺼번에 수식 글자로 보인다면 '수식 표시' 기능을 먼저 의심하세요. 반대로 일부 셀 한두 개만 수식 글자로 보인다면 텍스트 서식을 먼저 확인합니다.

공식 자료: Microsoft — 수식 표시 또는 숨기기

5. 특정 셀만 계산이 안 된다면: 텍스트 서식과 F2·Enter

엑셀에서 셀 서식이 텍스트(Text)인 상태로 수식을 입력하면 Excel이 이를 계산하지 않고 글자로 처리할 수 있습니다. Microsoft는 이 문제를 해결하기 위해 일반(General) 서식으로 바꾼 뒤 F2 → Enter를 사용하라고 안내합니다.

한 개 셀 해결하기

  1. 문제가 있는 셀을 선택합니다.
  2. 홈 → 표시 형식에서 현재 서식이 '텍스트'인지 확인합니다.
  3. 일반을 선택합니다. 필요하면 Ctrl + 1로 셀 서식 창을 엽니다.
  4. 해당 셀을 선택한 채 F2를 눌러 편집 상태로 들어갑니다.
  5. Enter를 눌러 수식을 다시 확정합니다.
  6. 결과값이 표시되는지 확인합니다.

중요: 텍스트 → 일반 서식 변경만으로 기존 셀 내용이 즉시 재계산되지 않을 수 있습니다. 그래서 Microsoft가 F2 → Enter를 별도로 안내합니다.

수식 앞에 작은따옴표가 붙어 있는 경우

셀의 실제 내용이 '=A1+B1처럼 작은따옴표로 시작하면 Excel은 이를 텍스트로 취급합니다. 작은따옴표가 의도적으로 입력된 것인지 확인하고, 실제 수식으로 계산하려는 경우에만 해당 입력을 수정하세요.

여러 셀을 일괄 변환하기 전 주의

전화번호·우편번호·상품코드·긴 숫자 식별자는 텍스트 형식으로 보존해야 할 수 있습니다. 열 전체를 무작정 숫자로 바꾸면 앞자리 0이 사라지거나 긴 숫자가 달라질 위험이 있습니다. 수식이 들어 있는 범위만 따로 선택해 처리하세요.

공식 근거: Microsoft — Excel에서 수식 깨짐 현상을 방지하는 방법

6. 직접 만들어 확인하는 1분 테스트

원래 업무 파일을 변경하지 않고, 빈 새 통합 문서에서 간단한 수식을 시험하세요.

셀직접 입력할 값
A110
B120
C1=SUM(A1:B1)

정상이라면 C1에는 30이 표시됩니다.

  1. A1에 10을 입력합니다.
  2. B1에 20을 입력합니다.
  3. C1에 =SUM(A1:B1)을 입력합니다.
  4. C1에 30이 보이는지 확인합니다.
  5. A1을 40으로 변경합니다.
  6. 자동 계산이 정상이라면 C1은 60으로 변경됩니다.

결과별 해석

  • C1이 30에서 60으로 변함: Excel의 기본 수식 계산은 정상일 가능성이 높습니다. 기존 파일의 수식·서식을 추가 점검하세요.
  • C1이 30에 멈춰 있음: 계산 옵션이 수동인지 확인하고 F9를 시험합니다.
  • C1에 =SUM(A1:B1)이 그대로 보임: 수식 표시 모드 또는 텍스트 서식을 확인합니다.
  • C1에 오류값이 표시됨: 함수·인수·데이터 형식·버전 호환성을 확인합니다.

이 테스트는 문제를 분류하는 용도이며, 실제 파일 전체가 안전하거나 수식이 정확함을 보장하는 기능은 아닙니다.

7. SUM인데 0만 나오는 경우: 참조 범위와 숫자·텍스트 구분

수식 자체는 실행되지만 합계가 0으로 나오는 경우는 자동 계산 문제가 아닐 수도 있습니다.

참조 범위부터 확인하기

예를 들어 A1부터 A5까지 숫자가 있는데 =SUM(B1:B5)를 입력했다면 다른 열을 더하고 있을 수 있습니다. 수식 입력줄에서 참조 범위가 의도한 셀인지 확인하세요.

숫자가 텍스트로 저장되어 있는 경우

엑셀에서 겉보기에는 100, 200처럼 보이더라도 문자열로 저장된 숫자일 수 있습니다. 데이터 입력 방식과 함수에 따라 계산 결과에 영향을 줄 수 있습니다.

  1. A1에 직접 100을 입력합니다.
  2. 별도 셀에서 =ISNUMBER(A1)을 시험합니다.
  3. TRUE라면 숫자로 인식하고, FALSE라면 해당 값이 숫자 형식이 아닐 수 있습니다.
  4. 문제가 있는 데이터는 원본을 복사한 뒤 올바른 형식으로 변환합니다.

주의: ISNUMBER가 FALSE라고 해서 모든 수식이 반드시 0으로 계산된다는 뜻은 아닙니다. SUM·덧셈 연산자·데이터 형식에 따라 동작이 다를 수 있습니다. 실제 계산식과 데이터 유형을 함께 확인해야 합니다.

소수점과 천 단위 구분 기호

외부 시스템에서 CSV를 가져온 데이터는 운영체제 지역 설정, 쉼표, 마침표 때문에 숫자가 텍스트로 인식될 수 있습니다. 원본 데이터의 숫자 형식을 확인하고, 필요하면 Excel의 데이터 가져오기 단계에서 데이터 형식을 지정하세요.

8. #NAME?, #VALUE!, #REF!, #DIV/0! 오류별 해결

수식이 계산되어 특정 오류값을 표시한다면 자동 계산을 켜는 것만으로 해결되지 않을 수 있습니다. 각 오류의 원인을 구분해야 합니다.

오류주된 의미먼저 확인할 것
#NAME?함수 또는 정의된 이름을 인식하지 못함함수 철자·따옴표·이름 정의·버전
#VALUE!연산·인수에서 데이터 형식 불일치 등텍스트·공백·참조 데이터 형식
#REF!잘못되거나 삭제된 셀 참조삭제·이동한 행·열과 수식 참조
#DIV/0!0 또는 빈 값으로 나눔분모 셀의 값
#N/A필요한 값이나 일치 항목을 찾지 못함조회 키·자료 범위·일치 방식
#NUM!부적절한 숫자 값 또는 계산 불능함수 인수·반복 계산
#####열 너비 부족 또는 일부 날짜·시간 표시 문제열 너비와 값 형식

예시: #DIV/0!을 숫자 0으로 덮어쓰면 될까요?

무조건 권장하지 않습니다. 예를 들어 =A1/B1에서 B1이 0이라면 나눗셈을 수행할 수 없습니다. B1이 왜 0인지 확인하고, 업무상 0을 반환하도록 정의된 경우에만 =IF(B1=0,0,A1/B1) 같은 조건식을 사용할 수 있습니다. 단, 이런 방식은 실제 오류를 감출 수 있어 용도와 회계·통계 계산의 의미를 먼저 검토해야 합니다.

예시: #REF! 오류는 어떻게 고치나요?

삭제한 행이나 열을 다른 수식이 참조하면 오류가 발생할 수 있습니다. 삭제 직후라면 Ctrl + Z로 되돌린 뒤 수식 참조를 수정하는 방법을 고려하세요. 이미 저장·종료했다면 백업이나 버전 기록을 확인합니다.

공식 출처: Microsoft — Excel에서 수식 오류 감지, Microsoft — #REF! 오류, Microsoft — #VALUE! 오류

9. #SPILL! 오류: 동적 배열 수식이 확장되지 않는 경우

Microsoft 365 등 동적 배열 수식이 지원되는 Excel에서는 FILTER·SORT·UNIQUE·SEQUENCE 같은 함수가 여러 셀로 결과를 확장할 수 있습니다. 결과가 확장될 공간에 다른 값이나 병합 셀이 있으면 #SPILL! 오류가 나타날 수 있습니다.

가장 먼저 해볼 점검

  1. #SPILL! 오류가 난 셀을 선택합니다.
  2. Excel에서 표시하는 점선 테두리의 예상 결과 범위를 확인합니다.
  3. 그 범위에 입력된 값·보이지 않는 공백·병합된 셀이 있는지 확인합니다.
  4. 업무 데이터를 지우지 말고, 안전한 사본에서 방해 요소를 옮겨봅니다.
  5. 수식 결과가 정상적으로 확장되는지 확인합니다.

오류 옵션에 방해 셀 선택(Select Obstructing Cells) 항목이 표시되는 경우 이를 이용할 수 있습니다. 원본 문서의 다른 계산을 망가뜨릴 수 있으므로 방해 셀의 데이터를 무조건 삭제하지 마세요.

또한 수식이 워크시트 범위 밖까지 확장되려 하거나, 동적 배열 계산 크기가 안정적이지 않을 때도 #SPILL!이 발생할 수 있습니다. 즉, 모든 #SPILL!이 단순히 빈칸 부족 때문만은 아닙니다.

공식 근거: Microsoft — #SPILL! 오류 해결

10. 수식이 자기 자신을 참조한다면: 순환 참조 확인

순환 참조(Circular reference)는 계산식이 직접 또는 간접적으로 자기 자신을 참조하는 상황입니다.

예를 들어 C1에 =C1+1을 넣는 경우가 대표적입니다. 일부 복잡한 수식은 여러 셀을 거쳐 순환할 수도 있습니다.

찾는 방법

  1. 수식 탭으로 이동합니다.
  2. 오류 검사 메뉴를 엽니다.
  3. 순환 참조(Circular References) 항목을 확인합니다.
  4. 표시된 셀로 이동해 어떤 수식이 서로 참조하는지 확인합니다.
  5. 실수라면 의도한 입력 셀을 참조하도록 수정합니다.

일부 재무 모델은 의도적으로 반복 계산을 사용하는 경우도 있습니다. 이런 파일에서 반복 계산 옵션을 임의로 꺼버리면 결과가 바뀔 수 있으므로 먼저 작성 목적을 확인하세요.

공식 근거: Microsoft — Excel 수식이 깨지는 원인과 순환 참조, Microsoft — 재계산·반복 계산

11. 일부 셀만 다른 값이 나오는 경우: 수식 복사·상대 참조 확인

엑셀의 합계가 일부 행에서만 틀리다면 계산 엔진보다 수식을 복사하면서 참조 범위가 달라졌는지 확인해야 합니다.

예를 들어 C2의 =A2+B2를 아래로 복사하면 보통 C3에는 =A3+B3이 들어갑니다. 하지만 특정 셀이 실수로 =A2+B3처럼 입력됐다면 값이 계산되어도 잘못된 결과가 나올 수 있습니다.

비교 방법

  1. 정상 결과가 나오는 셀을 선택합니다.
  2. 오류가 의심되는 인접 셀의 수식과 비교합니다.
  3. 수식 → 수식 표시를 이용해 주변 행의 수식 패턴을 한꺼번에 확인합니다.
  4. 어떤 행이나 열 참조가 예상과 다른지 찾습니다.
  5. 수식 참조를 수정한 뒤 기대값과 실제값을 비교합니다.

추가로 수식 → 선행 셀 추적(Trace Precedents) 등을 사용하면 수식이 어느 셀을 참조하는지 시각적으로 확인할 수 있습니다.

공식 근거: Microsoft — 일치하지 않는 수식 수정, Microsoft — 수식과 셀의 관계 표시

12. 회사에서 받은 엑셀 파일일 때 주의할 점

다른 사람이 만든 정산 파일, 급여 계산표, 세금 신고 기초 자료 등에는 외부 연결·사용자 지정 함수·의도적인 수동 계산이 포함될 수 있습니다. 단순히 '계산이 안 된다'는 이유로 파일의 보안 경고를 모두 해제하거나 알 수 없는 매크로를 활성화하지 마세요.

  • 원본을 별도로 보관하고 복사본에서 시험합니다.
  • 파일의 작성자·담당자가 있다면 계산 옵션의 의도된 설정을 확인합니다.
  • 함수 이름을 인식하지 못하는 경우 사용 중인 Excel 버전이 해당 함수를 지원하는지 확인합니다.
  • 외부 데이터와 연결된 수식이라면 원본 파일·네트워크 연결·접근 권한을 확인합니다.
  • 수식을 수정했으면 대표 행 몇 개를 계산기 또는 별도 검증 방식으로 대조합니다.
  • 전체 범위에 무분별한 찾기 및 바꾸기·형식 변환을 사용하지 않습니다.

특히 #REF! 같은 오류가 나타났을 때 원본 구조를 잘 모른 채 수식을 임의로 제거하거나 숫자 결과를 직접 입력하면 오류가 눈에 보이지 않게 되더라도 계산의 신뢰성은 더 나빠질 수 있습니다.

13. Mac용·웹용 Excel은 메뉴가 같나요?

기본 수식 원리는 비슷하지만 메뉴와 단축키는 다를 수 있습니다.

Mac용 Excel

Mac용 Excel에서도 수식 표시 및 수식 결과 전환 기능이 제공됩니다. Microsoft 문서에는 Ctrl + ` 단축키가 안내돼 있지만, 키보드 배열과 언어 설정에 따라 동작이 달라질 수 있다고 설명합니다. 단축키를 찾기 어렵다면 리본의 수식 표시 메뉴를 사용하세요.

수식 계산 옵션과 환경설정의 위치도 Windows 데스크톱과 다릅니다. 자신의 Mac Excel 버전에 맞는 Microsoft 지원 문서를 확인하는 것이 정확합니다.

웹용 Excel

웹용 Excel에서도 수식 편집과 표시가 가능하지만, 데스크톱 버전과 계산 설정·지원 함수·외부 연결 기능이 달라질 수 있습니다. PC 설치형 Excel의 메뉴를 웹용 Excel 화면에 그대로 적용하지 마세요.

공식 자료: Microsoft — Mac용 Excel 수식 표시

14. 5분 실전 해결 순서

1단계 — 새 파일로 시험 빈 통합 문서에서 A1=10, B1=20, C1=SUM(A1:B1)을 입력해 30이 나오는지 확인합니다.

2단계 — 값이 갱신되지 않으면 계산 옵션 확인 수식 → 계산 옵션 → 자동을 선택하고 원본 셀의 값을 바꿔봅니다. 필요하면 F9로 다시 계산합니다.

3단계 — 수식 자체가 보이면 수식 표시 확인 수식 → 수식 표시를 끕니다. 전체 셀이 아니라 특정 셀만 그렇다면 텍스트 서식을 확인합니다.

4단계 — 텍스트 서식이면 일반 + F2 → Enter 수식이 들어 있는 셀만 일반 형식으로 바꾸고 F2→Enter로 입력을 다시 확정합니다.

5단계 — 오류코드가 있다면 종류별로 해결 #NAME?은 함수 이름, #REF!는 셀 참조, #SPILL!은 확장할 범위 등을 우선 확인합니다.

6단계 — 결과가 나와도 검산 전체 집계값과 샘플 행을 별도로 검증합니다. 오류 표시가 없다는 이유만으로 정확성이 보장되는 것은 아닙니다.

15. 자주 묻는 질문(FAQ)

Q1. 엑셀 숫자를 수정했는데 합계가 자동으로 바뀌지 않습니다.

수식 → 계산 옵션 → 자동이 선택되어 있는지 확인하세요. 수동 계산이면 F9로 값이 바뀔 수 있습니다. Microsoft는 자동 계산을 기본 설정으로 안내합니다.

Q2. SUM 함수를 입력했는데 수식 글씨 그대로 나옵니다.

여러 셀에서 동시에 보이면 수식 표시 모드를 확인하세요. 일부 셀만 그렇다면 해당 셀을 일반 서식으로 바꾸고 F2 → Enter를 눌러 수식을 다시 확정합니다.

Q3. 엑셀에서 F9를 누르면 무엇이 달라지나요?

F9는 수식의 재계산을 요청하는 기능입니다. 수식이 텍스트로 들어 있는 문제나 잘못된 셀 참조까지 자동으로 고쳐주는 기능은 아닙니다.

Q4. 엑셀 계산 옵션이 수동으로 자꾸 돌아갑니다.

작성자가 의도적으로 수동 계산을 지정한 파일이거나 열려 있는 통합 문서 사이에서 계산 설정이 영향을 주는 경우를 확인해야 합니다. 원본을 백업하고 파일을 닫았다가 다시 열어 설정이 유지되는지도 살펴보세요.

Q5. 엑셀 수식이 #SPILL!이라고 나옵니다.

동적 배열 수식의 결과가 여러 셀로 확장될 자리를 확보하지 못했을 수 있습니다. 점선으로 표시되는 결과 범위와 방해 셀·병합 셀을 먼저 확인하세요.

Q6. SUM은 작동하는데 값이 0으로 나옵니다.

참조 범위가 올바른지 확인하고, 더하려는 데이터가 실제 숫자인지 검사하세요. 데이터가 텍스트이거나 범위를 잘못 참조하면 예상과 다른 결과가 나올 수 있습니다.

Q7. 오류가 ######으로 나오면 수식이 잘못된 건가요?

반드시 그렇지는 않습니다. 열 너비가 좁아 값을 표시할 수 없거나 일부 날짜·시간 형식 문제일 수 있습니다. 먼저 열 너비를 늘리고 셀의 형식을 확인하세요.

Q8. 수식 오류를 그냥 IFERROR로 0으로 바꿔도 되나요?

업무상 0을 반환해야 한다는 규칙이 명확한 경우에만 신중하게 사용하세요. IFERROR로 오류 표시를 가리면 데이터 참조나 계산 문제를 놓칠 수 있으므로 원인을 먼저 해결하는 편이 좋습니다.

Q9. 회사 엑셀 파일의 수동 계산을 자동으로 바꿔도 될까요?

파일이 매우 크거나 의도적으로 재계산을 제어하도록 설계됐을 수 있습니다. 원본을 복사하고 작성자에게 확인한 뒤 변경하세요.

Q10. 엑셀 수식 문제를 해결한 다음 무엇을 확인해야 하나요?

대표 셀을 직접 계산해 대조하고, 관련 차트·집계값·외부 연결 자료를 확인하세요. 오류값이 사라진 뒤에도 계산 결과가 업무상 기대값과 맞는지 반드시 검증해야 합니다.

16. 최종 체크리스트

  • ☐ 계산이 갱신되지 않는 문제인지, 수식이 문자로 보이는 문제인지 구분했다.
  • ☐ 빈 파일에서 =SUM(A1:B1)을 실행해 기본 계산이 가능한지 확인했다.
  • ☐ 수식 → 계산 옵션 → 자동을 확인했다.
  • ☐ F9로 수식 재계산을 시험했다.
  • ☐ 수식 표시 기능이 켜져 있지 않은지 확인했다.
  • ☐ 일부 셀의 수식이 글자로 보이면 텍스트 서식 → 일반 → F2 → Enter를 시험했다.
  • ☐ 0이 나올 때 참조 범위와 문자열로 된 숫자를 확인했다.
  • ☐ #NAME?, #VALUE!, #REF!, #DIV/0!, #SPILL!을 구별했다.
  • ☐ 순환 참조와 수식 복사 패턴을 확인했다.
  • ☐ 회사 파일에서 매크로나 보안 경고를 무작정 해제하지 않았다.
  • ☐ 수식 수정 후 실제 결과를 검산했다.

정리: 엑셀 수식이 계산되지 않을 때 가장 먼저 확인할 세 가지는 자동 계산 설정, 수식 표시 모드, 셀의 텍스트 서식입니다. 이 세 가지를 정상화해도 해결되지 않으면 오류 코드와 셀 참조·데이터 형식을 살펴보세요. 숫자가 다시 표시된 뒤에도 수식이 참조하는 데이터와 계산 결과가 맞는지 검증하는 것이 중요합니다.
