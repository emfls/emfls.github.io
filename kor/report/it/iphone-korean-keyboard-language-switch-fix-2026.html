가장 먼저 확인할 곳은 '설정 → 일반 → 키보드 → 키보드'입니다. 이 목록에 한국어가 없으면 '새로운 키보드 추가'에서 한국어를 등록하고, 입력 화면에서 지구본 또는 키보드 전환 키를 길게 눌러 한국어로 바꿀 수 있습니다. 두벌식과 10키의 차이, 자동 수정 문제, 키보드 전체가 나타나지 않는 문제는 따로 확인해야 합니다.

핵심: 한글 키보드가 삭제됨, 선택되지 않음, 배열이 바뀜, 자동 수정됨은 전혀 다른 문제입니다. 어느 경우인지 확인하고 필요한 설정만 변경하세요.

2. 영어만 나오면 한국어 키보드 등록 여부부터 확인

Apple이 안내하는 공식 키보드 추가 경로는 다음과 같습니다.

  1. iPhone의 설정 앱을 엽니다.
  2. 일반 → 키보드 → 키보드 순서로 들어갑니다.
  3. 설치된 키보드 목록에 한국어가 있는지 확인합니다.
  4. 없다면 '새로운 키보드 추가'를 누릅니다.
  5. 언어 목록에서 한국어를 찾습니다.
  6. 한국어의 제공되는 입력 방식을 선택해 추가합니다.
  7. 메모 또는 메시지 앱으로 이동해 실제로 한글을 입력해 봅니다.

확인 포인트: 한국어를 추가한 뒤에는 한국어가 키보드 목록에 등록되어 있어야 합니다. 언어 및 지역에서 기기의 표시 언어만 한국어로 변경하는 것은 입력 키보드 추가와 같은 작업이 아닙니다.

Apple의 공식 설명에 따르면 여러 언어 키보드를 등록할 수 있으며, 추가된 언어는 선호하는 언어 목록에도 자동으로 반영될 수 있습니다.

3. 지구본 버튼이 없거나 한영 전환이 안 될 때

한국어 키보드를 추가했는데 실제 입력창에 영어 자판만 나타나면 키보드 전환 메뉴를 확인합니다.

한영 전환 방법

  1. 메모 또는 메시지처럼 일반 텍스트 입력이 가능한 앱을 엽니다.
  2. 텍스트 입력칸을 누릅니다.
  3. 키보드 아래쪽의 지구본 모양 키 또는 이모지·키보드 전환 키를 확인합니다.
  4. 해당 키를 길게 터치합니다.
  5. 나타나는 목록에서 한국어 키보드를 선택합니다.
  6. 한글을 입력할 수 있는지 확인합니다.

Apple 공식 iPhone 사용 설명서는 이모지 또는 키보드 전환 키를 길게 터치해 사용하려는 키보드를 고르는 방법을 안내합니다.

전환 키가 아예 보이지 않는다면

  • 먼저 설정 → 일반 → 키보드 → 키보드에서 한국어가 실제로 등록돼 있는지 확인합니다.
  • 다른 텍스트 입력 앱에서도 전환 키가 보이지 않는지 비교합니다.
  • 외장 키보드가 연결돼 있거나 특정 입력 형식·앱이 키보드 구성을 다르게 표시하는지 확인합니다.
  • 전환 키를 못 찾는다고 무작정 전체 기기를 초기화하지 마세요.

주의: iOS의 아이콘·키 배치는 버전이나 설치한 키보드에 따라 다를 수 있습니다. 반드시 특정 위치에 지구본이 있어야 한다고 단정할 수는 없습니다.

4. 한글 키보드를 두벌식 또는 10키로 변경하기

갤럭시와 아이폰의 한글 자판 형태가 달라 불편하다면 한국어 키보드의 레이아웃을 확인하세요. Apple의 제품 기술 사양은 한국어 QuickType 입력 방식으로 두벌식과 10키를 명시합니다.

자판 배열 변경 순서

  1. 설정 → 일반 → 키보드 → 키보드를 엽니다.
  2. 목록에 등록된 한국어 키보드를 누릅니다.
  3. 제공되는 레이아웃 목록에서 두벌식 또는 10키를 확인합니다.
  4. 원하는 형태를 선택합니다.
  5. 일반 텍스트 입력창으로 돌아가 자판이 달라졌는지 확인합니다.

한국어 10키적은 수의 키로 한글을 조합하는 형태휴대전화형 자판에 익숙한 사용자

표현 주의: 10키가 어떤 기기에서 '천지인'과 비슷하게 느껴질 수는 있지만, 삼성 키보드의 특정 레이아웃 명칭과 Apple 한국어 10키를 완전히 동일한 제품 기능이라고 설명해서는 안 됩니다.

Apple은 키보드 언어를 선택한 뒤 대체 레이아웃을 지정할 수 있다고 안내합니다. 정확한 선택지는 사용 기기의 메뉴에 실제로 표시되는 항목을 따르세요.

5. 키보드 순서가 바뀌었다면 목록 재정렬

여러 언어를 사용하는 경우 영어·한국어·이모지가 원하는 순서와 다르게 나올 수 있습니다.

  1. 설정 → 일반 → 키보드 → 키보드로 이동합니다.
  2. 오른쪽 위의 편집을 선택합니다.
  3. 각 키보드 옆의 재정렬 핸들을 길게 눌러 원하는 순서로 이동합니다.
  4. 완료를 누릅니다.
  5. 텍스트 입력창에서 전환 메뉴를 열어 순서를 확인합니다.

Apple의 공식 설명서는 키보드 목록에서 삭제 및 재정렬을 지원한다고 안내합니다.

주의: 순서를 바꾸는 작업과 언어 키보드를 삭제하는 작업은 다릅니다. 한국어를 지우면 나중에 다시 추가해야 할 수 있으므로, 목적이 순서 변경이라면 편집 → 재정렬만 진행하세요.

아이폰의 메뉴가 영어로 보인다고 해서 한국어 키보드까지 반드시 영어만 되는 것은 아닙니다. 반대로 시스템 표시 언어가 한국어여도 한국어 키보드가 등록되지 않을 수 있습니다.

7. 입력한 문장이 멋대로 바뀌면 '자동 수정' 확인

한글이 정상 입력되지만 단어가 다른 문구로 변하는 문제는 한영 전환 오류가 아니라 자동 수정일 수 있습니다.

자동 수정 켜기·끄기

  1. 설정 → 일반 → 키보드로 이동합니다.
  2. 자동 수정을 찾습니다.
  3. 문제를 비교하려면 자동 수정을 잠시 끔으로 변경합니다.
  4. 메모 앱에 같은 문장을 입력해 결과를 비교합니다.
  5. 원래 사용하던 기능이 필요하면 다시 켭니다.

Apple은 자동 수정이 키보드 사전을 이용해 입력된 단어의 맞춤법을 검사하고 수정하는 기능이라고 설명합니다.

구별할 점: 입력 전부터 한글 자판이 보이지 않는 문제라면 자동 수정을 꺼도 해결되지 않습니다. 먼저 한국어 키보드가 등록돼 있는지 확인해야 합니다.

8. 특정 글자를 입력하면 문장이 바뀌는 경우: 텍스트 대치

ㅈㄱㅈ처럼 짧은 입력이 특정 문구로 바뀌거나, 사용하지 않는 문장이 자동으로 입력된다면 텍스트 대치(Text Replacement)를 확인하세요.

설정 확인과 삭제

  1. 설정 → 일반 → 키보드 → 텍스트 대치를 엽니다.
  2. 등록된 문구와 단축키를 확인합니다.
  3. 문제가 되는 단축키가 있으면 수정 메뉴에서 해당 항목을 제거합니다.
  4. 새로운 단축키를 만들려면 추가(+)를 누릅니다.
  5. 문구와 단축키를 입력해 저장합니다.

텍스트 대치는 자주 쓰는 문구를 빠르게 입력하는 편리한 기능이지만, 의도하지 않은 단축키가 등록돼 있으면 오타나 자동 입력 오류처럼 보일 수 있습니다.

중요: 텍스트 대치의 특정 항목을 삭제하는 작업과 키보드 사전 전체를 재설정하는 작업은 범위가 다릅니다. 원하는 단축키 하나만 문제라면 그 항목만 수정하세요.

9. 카카오톡에서만 키보드가 안 보이면 앱별 문제인지 비교

아이폰의 모든 앱에서 한글 키보드가 작동하지 않는 것과 카카오톡·인스타그램 등 특정 앱에서만 입력창이 나타나지 않는 현상은 구별해야 합니다.

3단계 비교

  1. Apple 기본 메모 앱에서 일반 텍스트 입력칸을 선택합니다.
  2. 한국어 키보드가 나타나고 문장이 정상 입력되는지 확인합니다.
  3. 문제가 발생한 앱에서 같은 방식으로 비교합니다.
결과먼저 확인할 범위
메모는 정상, 특정 앱만 실패해당 앱 상태·업데이트
모든 앱에서 영어만 입력한국어 키보드 등록 및 전환
모든 앱에서 키보드가 아예 없음외장 키보드·시스템·터치 상태
모든 앱에서 자동으로 문장이 바뀜자동 수정·텍스트 대치

특정 앱에서만 발생한다면

  1. 문제 앱의 입력창을 다시 선택합니다.
  2. 해당 앱을 정상적으로 종료한 후 다시 실행합니다.
  3. App Store에서 앱 업데이트가 있는지 확인합니다.
  4. 문제가 계속된다면 앱 개발자의 공식 고객지원 안내를 확인합니다.

주의: 앱 삭제·재설치는 해당 앱의 로컬 데이터에 영향을 줄 수 있습니다. 특히 메신저는 대화 복원 조건을 확인하지 않은 채 삭제하면 안 됩니다.

10. 화면 키보드가 안 뜨면 블루투스·외장 키보드부터 확인

iPhone이 Magic Keyboard 등 외장 키보드와 연결된 상황에서는 키보드 표시·입력 방식이 일반적인 화면 키보드와 달라질 수 있습니다.

  1. 설정 → Bluetooth에서 연결된 키보드나 입력 장치가 있는지 확인합니다.
  2. 별도의 외장 키보드를 사용 중이라면 잠시 연결을 해제해 봅니다.
  3. 메모 앱의 입력창을 다시 선택합니다.
  4. 화면 키보드가 표시되는지 비교합니다.
  5. 외장 키보드에서만 한국어 입력에 문제가 있다면 설정 → 일반 → 키보드 → 하드웨어 키보드의 제공 항목을 확인합니다.

하드웨어 키보드의 언어 전환과 화면 키보드의 지구본 버튼은 반드시 같은 방식으로 동작하지 않습니다. 외장 키보드에서 Command-Space는 Apple 공식 설명서상 검색을 여는 단축키이므로, 모든 외장 키보드에서 한영 전환 단축키라고 단정하면 안 됩니다.

11. 키보드가 느리거나 터치가 안 먹는다면

키보드가 뜨지만 눌러도 반응하지 않거나 글자가 늦게 입력된다면 키보드 언어 설정 문제와 터치·앱 반응 문제를 구별해야 합니다.

점검 순서

  1. 메모 앱에서 여러 키를 천천히 눌러 봅니다.
  2. 키보드뿐 아니라 화면의 다른 버튼도 반응하지 않는지 확인합니다.
  3. 화면 보호필름·케이스·액체·오염이 터치에 영향을 주는지 점검합니다.
  4. 기기를 정상 재시작합니다.
  5. 설정 → 일반 → 소프트웨어 업데이트에서 공식 iOS 업데이트 여부를 확인합니다.
  6. 키보드가 아닌 화면 전체에 문제가 있다면 Apple의 터치스크린 문제 해결 안내를 이용합니다.

주의: 글자가 늦게 입력되는 문제가 항상 키보드 언어 때문에 생기는 것은 아닙니다. 저장 공간 상태, 특정 앱의 과부하, 외장 입력 장치, 화면 터치 문제도 함께 비교해야 합니다.

기기가 멈추지 않았는데 무리하게 공장 초기화를 진행하는 것보다 정상 재시작과 앱별 비교가 우선입니다.

12. 이모지 키보드나 영어 키보드를 제거하면 해결될까?

불필요한 키보드를 줄이면 전환 메뉴가 단순해질 수 있지만 한국어 키보드 자체가 없는 문제는 삭제보다 추가가 먼저입니다.

키보드 삭제·정리

  1. 설정 → 일반 → 키보드 → 키보드를 엽니다.
  2. 사용하지 않는 언어의 키보드를 찾습니다.
  3. 해당 항목을 왼쪽으로 쓸어넘겨 삭제합니다.
  4. 필요한 한국어·영어 키보드는 남겨둡니다.
  5. 실제 입력창에서 전환 가능한 키보드를 확인합니다.

주의: Apple 공식 설명서는 언어 키보드를 제거하면 입력에 사용할 수 있는 언어 선택지가 달라진다고 안내합니다. 사용 중인 다국어 입력 환경을 확인하고 정리하세요.

특정 서드파티 키보드를 사용한다면 Apple 기본 키보드와 해당 키보드의 동작을 비교한 뒤, 문제가 있는 키보드 앱의 공식 안내를 확인하세요.

13. 키보드 사전 재설정은 언제 해야 하나요?

자동 수정이나 예측 단어 추천에 문제가 있고 한국어 키보드 등록·자동 수정·텍스트 대치 설정을 확인했는데도 해결되지 않은 경우에만 검토할 수 있습니다.

Apple 공식 문서는 다음 경로를 안내합니다.

  1. 설정 → 일반을 엽니다.
  2. 전송 또는 iPhone 재설정 → 재설정을 선택합니다.
  3. 키보드 사전 재설정을 선택합니다.
  4. 기기 암호 등 요구되는 본인 인증을 진행합니다.
  5. 확인 화면의 설명을 읽고 실행 여부를 결정합니다.

무엇이 지워지나요?

Apple은 키보드 사전 재설정이 사용자가 입력하면서 키보드 사전에 추가한 단어를 제거하고 사전을 기본 상태로 복원한다고 안내합니다. 다른 공식 설명서는 사용자 지정 단어 및 텍스트 대치 단축키가 삭제될 수 있음도 설명하므로, 중요한 텍스트 대치 항목은 먼저 확인하세요.

중요: '키보드 사전 재설정'은 '모든 설정 재설정'이나 '모든 콘텐츠 및 설정 지우기'와 다릅니다. 키보드 문제 때문에 사진·앱·로그인 설정까지 영향을 주는 광범위한 재설정을 첫 단계로 진행하지 마세요.

15. 따라 하기 쉬운 5분 점검표

시간은 확인 순서를 설명하기 위한 예시이며 모든 문제가 5분 안에 해결된다는 보장은 아닙니다.

순서할 일확인할 결과
1분일반 → 키보드 → 키보드한국어 등록 여부
2분없으면 한국어 추가한국어 선택 가능
3분입력창에서 전환 키 길게 누르기한영 전환 정상 여부
4분한국어 두벌식·10키 레이아웃 확인원하는 자판 형태
5분자동 수정·텍스트 대치 확인임의 단어 교정 여부

이 다섯 단계로 해결되지 않는다면 문제 앱만 그런지, 외장 키보드가 연결돼 있는지, 화면 전체 터치도 이상한지를 추가로 확인하세요.

16. 자주 묻는 질문(FAQ)

Q1. 아이폰에서 한글이 안 나오고 영어만 입력됩니다.

설정 → 일반 → 키보드 → 키보드에서 한국어가 추가돼 있는지 확인하세요. 없다면 새로운 키보드 추가 → 한국어로 등록합니다. 이후 입력창에서 전환 키를 길게 눌러 한국어를 선택하세요.

Q2. 아이폰 한영 전환 지구본 버튼이 없어졌어요.

먼저 키보드 목록에 한국어·영어가 등록돼 있는지 확인하세요. 키보드에 보이는 이모지 또는 키보드 전환 키를 길게 눌러 다른 입력 언어를 선택할 수 있는지 살펴보세요.

Q3. 아이폰 한국어 키보드를 10키로 변경하려면?

설정 → 일반 → 키보드 → 키보드 → 한국어에서 제공되는 레이아웃을 확인하고 10키를 선택하세요. 지원 레이아웃은 iOS와 기기 화면을 기준으로 확인해야 합니다.

Q4. 10키를 두벌식으로 바꿀 수 있나요?

Apple은 한국어 입력에서 두벌식·10키를 지원합니다. 같은 한국어 키보드 레이아웃 메뉴에서 두벌식을 선택하세요.

Q5. 한글 키보드를 추가하면 아이폰 메뉴 언어도 한국어로 바뀌나요?

입력 키보드와 기기의 표시 언어는 서로 다른 설정입니다. iPhone 메뉴 언어는 설정 → 일반 → 언어 및 지역에서 별도로 관리합니다.

Q6. 글자가 자동으로 이상한 단어로 바뀝니다.

설정 → 일반 → 키보드 → 자동 수정을 확인하고, 특정 약어가 긴 문구로 바뀐다면 텍스트 대치도 확인하세요.

Q7. 카카오톡에서만 키보드가 안 뜹니다.

먼저 메모 앱에서 키보드가 정상 작동하는지 비교하세요. 메모는 정상이라면 카카오톡 앱 상태·업데이트·해당 앱의 입력창 문제를 확인하는 편이 적절합니다.

Q8. 외장 키보드를 연결한 뒤 화면 키보드가 안 나타납니다.

설정 → Bluetooth에서 외장 키보드 연결 여부를 확인하고, 연결을 잠시 해제한 뒤 메모 앱에서 화면 키보드가 나타나는지 비교하세요.

Q9. 키보드 사전을 재설정하면 사진이나 연락처가 삭제되나요?

키보드 사전 재설정은 기기 전체를 공장 초기화하는 작업과 다릅니다. 다만 사용자가 학습시킨 단어와 개인 사전·텍스트 대치 설정은 영향을 받을 수 있으므로 재설정 전에 확인하세요.

Q10. 아이폰 iOS 업데이트 후 키보드가 달라졌다면?

한국어 키보드 등록·전환·두벌식/10키 레이아웃을 먼저 확인하세요. 문제가 특정 앱에 한정된다면 앱 업데이트를 확인하고, 여러 앱에서 지속되면 Apple 공식 지원을 이용하세요.

Q11. 한글 키보드를 추가했는데 자동으로 한영이 함께 입력되나요?

Apple은 일부 지원 언어 조합에서만 키보드를 바꾸지 않고 두 언어로 입력할 수 있다고 설명합니다. 이를 모든 한국어·영어 조합에 공통으로 적용되는 기능이라고 단정하지 말고, 필요하면 전환 키로 직접 변경하세요.

Q12. 한글 자판 문제가 있으면 모든 설정 재설정을 해야 하나요?

우선 필요하지 않습니다. 한국어 키보드 추가 → 전환 → 레이아웃 → 자동 수정·텍스트 대치 → 앱별 비교가 먼저입니다. 모든 설정 재설정은 Wi-Fi·Bluetooth·보안·접근성 등 훨씬 광범위한 설정에 영향을 줄 수 있습니다.

결론

아이폰에서 한글 키보드가 안 나오면 '설정 → 일반 → 키보드 → 키보드'에서 한국어 등록 여부를 먼저 확인하세요. 영어만 선택돼 있다면 지구본·키보드 전환 키를 길게 눌러 한국어를 선택하면 됩니다. 자판 배열이 낯설면 한국어 두벌식·10키 메뉴에서 원하는 형태로 바꿀 수 있습니다.

한글은 정상적으로 입력되지만 문장이 바뀌면 자동 수정·텍스트 대치, 특정 앱에서만 입력이 안 되면 앱별 오류, 화면 키보드 자체가 나타나지 않으면 외장 키보드·화면 터치·시스템 상태를 구분해 점검하세요. 필요 이상의 설정 초기화는 피하고, 키보드 사전 재설정도 후순위로 검토하는 것이 좋습니다.
