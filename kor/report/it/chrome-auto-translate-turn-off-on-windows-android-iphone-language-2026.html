2026 크롬 자동번역 끄기·다시 켜기: PC·갤럭시·아이폰 언어 설정과 번역 안됨 해결

핵심 요약 (Key Takeaways)
  • 2026년 크롬 자동번역 기능은 PC, 갤럭시, 아이폰에서 각각 설정 경로가 다르며 자동번역, 번역 제안, 특정 언어 번역 안 함은 별도 설정입니다.
  • PC에서는 설정 → 언어 → Google 번역에서 자동 번역할 언어 목록에서 영어를 제거하거나 Google 번역 사용을 끄면 자동번역을 중지할 수 있습니다.
  • 번역 기능을 다시 켜려면 동일 경로에서 Google 번역 사용을 켜고 번역 제안하지 않을 언어 목록에서 해당 언어를 제거해야 하며, 2026년 11월 기준 최신 크롬 버전 기준입니다.

영어 웹사이트를 열 때마다 크롬이 한국어로 자동번역하거나 번역 알림이 반복해서 뜨면 불편할 수 있습니다. 반대로 해외 사이트를 열어도 번역 버튼이 나타나지 않아 난감한 경우도 있습니다. 크롬(Chrome)의 ‘자동번역’, ‘번역 제안’, ‘특정 언어 번역 안 함’은 서로 다른 설정입니다. 원하는 동작에 따라 설정을 구분해야 불필요하게 언어 환경을 전부 바꾸지 않을 수 있습니다.

영어 웹사이트를 열 때마다 크롬이 한국어로 자동번역하거나 번역 알림이 반복해서 뜨면 불편할 수 있습니다. 반대로 해외 사이트를 열어도 번역 버튼이 나타나지 않아 난감한 경우도 있습니다. 크롬(Chrome)의 ‘자동번역’, ‘번역 제안’, ‘특정 언어 번역 안 함’은 서로 다른 설정입니다. 원하는 동작에 따라 설정을 구분해야 불필요하게 언어 환경을 전부 바꾸지 않을 수 있습니다.

먼저 확인할 핵심 경로

  • PC 전체 번역 제안 끄기: 크롬 → 설정 → 언어 → Google 번역 → Google 번역 사용 끄기.
  • PC 영어 페이지만 자동번역 해제: 설정 → 언어 → Google 번역 → 자동 번역할 언어 목록에서 영어 제거.
  • 갤럭시·안드로이드: 크롬 → 더보기(점 3개) → 설정 → 언어 → 다른 언어 페이지 번역 제안 관련 설정을 끄거나, 자동 번역 언어 목록을 수정.
  • 아이폰·아이패드: 크롬 → 더보기 → 설정 → 언어 → 페이지 번역(Translate pages) 끄기.
  • 특정 페이지만 번역: PC에서는 주소창의 번역 아이콘, 스마트폰에서는 크롬 메뉴의 번역을 이용합니다.

작성 및 사실 확인: 2026년 11월 4일. Google Chrome 공식 고객센터의 컴퓨터·Android·iPhone 안내를 기준으로 작성했습니다. 크롬 버전·운영체제·설정 언어에 따라 한글 메뉴 명칭과 위치가 조금 달라질 수 있습니다.

1. ‘자동번역 끄기’가 의미하는 세 가지 설정

원하는 결과바꿀 설정사용 예시
외국어 웹페이지에서 번역 알림이 뜨지 않게전체 Google 번역 사용/페이지 번역 제안 끄기영어 사이트를 원문으로 읽고 싶을 때
영어는 원문으로 보고 다른 언어는 번역 가능하게번역 제안하지 않을 언어에 영어 추가영어는 읽을 수 있지만 일본어·프랑스어는 번역할 때
영어 웹페이지가 열자마자 한국어가 되는 현상만 중지자동 번역할 언어 목록에서 영어 제거번역 기능은 남겨두고 자동 실행만 끄고 싶을 때

세 기능은 같은 버튼이 아닙니다. 전체 기능을 끄지 않고 자동번역만 중지하고 싶은 사람은 두 번째 또는 세 번째 방법을 우선 확인하세요.

2. PC 크롬 자동번역 완전히 끄기: 윈도우11·맥

Google 공식 Chrome 도움말에 따른 컴퓨터용 설정 경로입니다.

  1. Chrome을 실행합니다.
  2. 오른쪽 위 점 3개(더보기)를 클릭합니다.
  3. 설정을 선택합니다.
  4. 왼쪽 메뉴에서 언어(Languages)를 엽니다.
  5. Google 번역(Google Translate) 항목을 찾습니다.
  6. Google 번역 사용(Use Google Translate) 스위치를 끕니다.
  7. 영어 등 외국어 웹페이지를 다시 열어 번역 제안이 나타나는지 확인합니다.

주소창에 chrome://settings/languages를 입력해 언어 설정으로 직접 이동할 수도 있습니다. 단, 실제 옵션 이름은 크롬 업데이트와 표시 언어에 따라 달라질 수 있습니다.

주의: 이 설정은 웹페이지 자동번역 제안에 영향을 주는 항목입니다. 크롬 전체 메뉴 언어를 영어·한국어로 변경하는 기능과는 다릅니다.

3. 영어 페이지만 자동번역 중지하고 다른 언어는 유지하기

영어 기사나 개발 문서를 읽는 사람이라면 모든 번역을 꺼둘 필요가 없을 수 있습니다.

  1. PC 크롬에서 설정 → 언어로 이동합니다.
  2. Google 번역 → 자동 번역할 언어(Automatically translate these languages)를 찾습니다.
  3. 영어 또는 자동번역을 멈추고 싶은 언어가 등록돼 있는지 확인합니다.
  4. 목록에서 해당 언어 옆 삭제(Remove)를 선택합니다.
  5. 영어 웹사이트를 다시 열어 자동번역이 멈췄는지 확인합니다.

중요: 자동 번역 목록에서 영어를 제거하는 것과 영어 번역 제안을 아예 받지 않는 것은 다릅니다. 자동으로 번역되지 않더라도 번역 아이콘이나 제안이 남을 수 있습니다.

영어 번역 제안까지 없애려면?

같은 Google 번역 설정에서 번역 제안하지 않을 언어(Never offer to translate these languages)에 영어를 추가하세요. 이후 일본어·프랑스어 등 다른 언어는 필요에 따라 번역을 제안받을 수 있습니다.

예를 들어 ‘영어는 원문, 일본어는 한국어 번역’으로 쓰고 싶다면 다음 구성이 적합합니다.

자동 번역할 언어제외필요하면 추가
번역 제안하지 않을 언어추가추가하지 않음

4. PC에서 크롬 자동번역 다시 켜는 방법

번역 기능을 다시 사용하고 싶다면 앞에서 변경한 설정을 되돌립니다.

  1. 설정 → 언어 → Google 번역을 엽니다.
  2. Google 번역 사용을 켭니다.
  3. 번역하고 싶은 언어가 번역 제안하지 않을 언어 목록에 있으면 제거합니다.
  4. 매번 번역 버튼을 누르기 싫다면 자동 번역할 언어에 해당 언어를 추가합니다.
  5. 번역할 언어(Translate into this language)가 한국어인지 확인합니다.
  6. 외국어 웹페이지를 열어 실제 번역 동작을 확인합니다.

번역 대상 언어가 영어로 되어 있으면 영어 웹페이지가 영어로 유지되거나 예상과 다른 결과처럼 보일 수 있으니 한국어 설정도 함께 확인하세요.

5. 갤럭시·안드로이드에서 크롬 번역 끄기

갤럭시의 삼성 인터넷이 아니라 Google Chrome 앱을 기준으로 합니다.

  1. 휴대전화에서 Chrome 앱을 엽니다.
  2. 주소창 근처의 점 3개(더보기)를 누릅니다.
  3. 설정 → 언어(Languages)로 이동합니다.
  4. 번역 설정(Translation settings) 아래에서 다른 언어 페이지를 Google 번역으로 전송하도록 제안(Offer to send pages in other languages to Google Translate) 관련 스위치를 찾습니다.
  5. 번역 제안을 원하지 않으면 끕니다.
  6. 다시 사용하려면 같은 스위치를 켭니다.

Google의 Android 공식 안내에는 설정 → 언어 → 고급(Advanced) 아래에 자동 번역할 언어(Automatically translate these languages)와 번역 제안하지 않을 언어(Don't offer to translate these languages) 목록이 따로 표시됩니다.

메뉴가 보인다면 자동 번역할 언어에서 영어를 제거하는 방식으로 영어 페이지만 자동번역하지 않도록 조절할 수 있습니다. 특정 언어의 번역 제안까지 없애려면 ‘번역 제안하지 않을 언어’ 목록을 이용합니다.

갤럭시에서 번역 버튼이 사라졌다면?

외국어 웹페이지를 연 뒤 Chrome 더보기 → 번역(Translate)을 직접 선택하세요. Google 공식 안내에 따르면 자동 번역 안내가 표시되지 않을 때도 메뉴에서 번역을 요청할 수 있습니다.

6. 아이폰·아이패드 크롬에서 자동번역 끄기

아이폰 Safari 설정이 아닌 Chrome 앱 자체 설정입니다.

  1. 아이폰에서 Chrome을 엽니다.
  2. 더보기 → 설정으로 이동합니다.
  3. 언어(Languages)를 엽니다.
  4. 페이지 번역(Translate pages) 스위치를 끕니다.
  5. 다시 번역 기능을 사용하려면 스위치를 켭니다.

Google 공식 iPhone 안내에서는 이미 특정 언어를 ‘항상 번역’하도록 설정했다면, 해당 언어의 웹페이지를 다시 열고 페이지 상단의 번역 설정에서 [언어] 번역 안 함(Never translate [language])을 선택해 자동번역 기본 설정을 해제할 수 있다고 설명합니다.

반대로 번역을 제안하지 않는 언어가 있다면 Chrome 설정 → 언어에서 해당 언어를 선택하고 번역 제안(Offer to translate)으로 변경할 수 있습니다.

주의: 아이폰의 기본 브라우저가 Safari여도 Chrome을 직접 열었다면 Chrome의 번역 설정이 적용됩니다. Safari에서의 '페이지 번역' 동작과 혼동하지 마세요.

7. 특정 웹사이트만 원문으로 보고 싶다면?

웹페이지가 자동번역되지만 딱 한 번만 원문을 확인하고 싶을 때는 번역 설정 전체를 초기화할 필요가 없습니다.

  • PC: 주소창 오른쪽 번역 아이콘을 클릭해 현재 페이지의 번역 언어 또는 원문 표시 옵션을 확인합니다.
  • 안드로이드: 페이지 위쪽에 나타난 번역 안내의 설정에서 현재 번역 언어와 동작을 조절합니다.
  • 아이폰: 페이지 상단의 번역 안내에서 언어와 번역 동작을 선택합니다.

사이트별로 가능한 옵션이 버전마다 다를 수 있어, '이 사이트는 항상 번역 안 함' 메뉴가 모든 크롬 버전에 동일한 이름으로 존재한다고 가정하면 안 됩니다. 특정 언어 전체를 번역하지 않게 하는 공식 설정은 Chrome 언어 메뉴에서 관리할 수 있습니다.

8. 영어 사이트가 자동으로 번역되지 않는 이유

자동번역이 안 된다고 바로 오류로 판단할 필요는 없습니다. 다음 항목을 순서대로 확인합니다.

증상확인할 설정우선 조치
영어 페이지를 열어도 번역 제안이 없음전체 번역 사용 여부Google 번역 사용 켜기
영어만 번역이 안 됨번역 제안하지 않을 언어영어가 목록에 있는지 확인
번역 버튼은 있는데 자동으로 실행되지 않음자동 번역할 언어영어를 목록에 추가할지 결정
한국어가 아닌 다른 언어로 번역됨번역할 언어한국어 선택
번역 메뉴 자체가 보이지 않음페이지 언어 인식·지원 여부새로고침 후 메뉴에서 번역 요청
모바일에서 안내 막대가 안 보임브라우저 앱·버전Chrome에서 연 페이지인지 확인
회사 PC에서 설정 변경이 제한됨조직 정책·관리 브라우저관리자에게 확인

Google은 번역이 동작하지 않으면 새로고침을 시도하고, 지원하지 않는 언어는 번역할 수 없을 수 있다고 공식 안내합니다.

9. 크롬 번역이 안 될 때 5분 점검 순서

  1. 실제로 Chrome을 사용 중인지 확인합니다. Edge·Safari·삼성 인터넷은 별도 설정이 적용됩니다.
  2. 외국어 문장이 포함된 일반 웹페이지에서 문제를 재현합니다.
  3. 새로고침으로 번역 기능이 다시 제안되는지 확인합니다.
  4. 설정 → 언어에서 Google 번역 사용, 자동 번역 언어, 번역 제안 제외 언어를 구분해 확인합니다.
  5. 수동 번역 기능을 실행해 자동화만 문제인지, 번역 자체가 동작하지 않는지 확인합니다.
  6. 다른 외국어 사이트에서도 문제가 생기는지 비교합니다.
  7. 특정 사이트에서만 실패한다면 해당 페이지의 구성·언어 인식·접근 제한 문제일 수 있습니다.
  8. 회사·학교 PC에서만 실패한다면 관리 정책이 영향을 주는지 담당자에게 확인합니다.

권하지 않는 방법: 번역 버튼 하나를 복구하려고 크롬 전체 설정을 초기화하거나, 방문 기록·암호·확장 프로그램을 무조건 삭제하는 것은 우선순위가 아닙니다.

10. ‘크롬 언어 변경’과 ‘웹페이지 번역’은 다른 기능

설정 → 언어 화면에는 비슷해 보이는 항목이 여러 개 있습니다.

항목바뀌는 것예시
Chrome 표시 언어브라우저 메뉴·설정 글자'Settings'를 '설정'으로
번역할 언어외국어 웹페이지 번역 결과영어 기사 → 한국어
선호 언어다국어 웹사이트의 언어 우선순위한국어 버전이 있으면 우선 표시 가능
자동 번역할 언어웹페이지 자동번역 여부일본어 기사를 자동으로 한국어 번역
번역 제안하지 않을 언어특정 언어 번역 제안 차단영어 원문 그대로 보기

Google은 Windows용 Chrome에서는 브라우저 표시 언어를 직접 변경할 수 있지만, Mac·Linux용 Chrome의 메뉴 표시 언어는 운영체제 기본 언어를 따른다고 안내합니다.

즉 Mac Chrome의 웹페이지 자동번역을 끄기 위해 macOS 시스템 언어를 바꿀 필요는 없습니다.

11. 보안과 개인정보: 자동번역을 끌 이유도 있습니다

Chrome Android 공식 설정 명칭에는 다른 언어 페이지를 Google 번역으로 보내도록 제안한다는 표현이 포함되어 있습니다. 번역을 사용할 때는 서비스가 웹페이지 내용을 처리할 수 있다는 점에 유의해야 합니다.

  • 공개 뉴스·여행 안내 등 일반 웹페이지는 필요에 따라 번역할 수 있습니다.
  • 사내 문서·계약서·건강정보·개인정보가 포함된 페이지라면 조직의 번역 서비스 사용 정책을 먼저 확인합니다.
  • 출처를 알 수 없는 '자동번역 확장 프로그램'을 설치하기 전에 접근 권한과 데이터 처리 안내를 확인합니다.
  • Chrome 번역 사용을 끄는 것만으로 이미 외부에 공유한 문서나 이전 접속 기록이 삭제되는 것은 아닙니다.

12. 자주 묻는 질문(FAQ)

Q1. 크롬에서 영어 사이트 자동번역만 끌 수 있나요?

네. PC에서는 설정 → 언어 → Google 번역 → 자동 번역할 언어에서 영어를 제거하세요. 영어 번역 제안까지 끄고 싶다면 번역 제안하지 않을 언어에 영어를 추가합니다.

Q2. PC 크롬 번역 설정은 어디에 있나요?

더보기 → 설정 → 언어 아래 Google 번역 항목에서 확인할 수 있습니다. 주소창에 chrome://settings/languages를 입력해도 됩니다.

Q3. 크롬을 껐다 켜도 영어 페이지가 한국어로 바뀝니다.

자동 번역할 언어 목록에 영어가 들어 있는지 먼저 확인하세요. 단순히 현재 탭의 번역을 한 번 되돌린 것과 자동번역 설정을 해제한 것은 다릅니다.

Q4. 아이폰에서 번역을 다시 켜려면?

Chrome 앱의 더보기 → 설정 → 언어 → 페이지 번역을 다시 켭니다. 특정 언어를 ‘번역 안 함’으로 지정했다면 해당 언어의 번역 제안 설정도 확인합니다.

Q5. 안드로이드 Chrome에 번역 표시가 아예 없으면?

Google 공식 안내에 따라 더보기 → 번역을 선택해 수동 번역을 요청합니다. 그래도 작동하지 않으면 페이지 새로고침과 언어 지원 여부를 확인하세요.

Q6. 구글 번역 확장 프로그램을 설치해야 하나요?

일반적인 웹페이지 번역에는 Chrome의 기본 번역 기능이 제공되므로 별도 확장 프로그램이 반드시 필요한 것은 아닙니다. 수동 번역 기능부터 확인하세요.

Q7. Chrome 표시 언어를 영어로 바꾸면 사이트도 영어로 번역되나요?

반드시 그렇지 않습니다. 브라우저 메뉴 표시 언어와 웹페이지 번역 대상 언어는 별개 설정입니다.

Q8. YouTube 자막 자동번역도 함께 꺼지나요?

Chrome의 웹페이지 번역 설정과 YouTube 동영상 자막·자동번역 기능은 목적과 적용 대상이 다릅니다. YouTube 자막 문제라면 동영상 플레이어의 자막 설정을 따로 확인해야 합니다.

13. 설정 변경 후 최종 점검표

  • ☐ 지금 사용 중인 앱이 Chrome인지 확인했다.
  • ☐ 번역 제안 전체 끄기 / 자동번역만 끄기 / 특정 언어 제외 중 원하는 목적을 선택했다.
  • ☐ PC의 설정 → 언어 → Google 번역을 확인했다.
  • ☐ 모바일에서는 Chrome 설정 → 언어를 확인했다.
  • ☐ 한국어가 필요한 경우 번역 대상 언어를 점검했다.
  • ☐ 번역 버튼이 안 보인다면 수동 번역 및 새로고침을 시험했다.
  • ☐ Chrome 메뉴 언어 변경과 웹페이지 번역 설정을 혼동하지 않았다.
  • ☐ 회사·학교 관리 기기라면 조직의 보안 정책을 확인했다.

결론

크롬 자동번역을 전부 끄려면 PC에서는 ‘Google 번역 사용’, 안드로이드·아이폰에서는 각각 Chrome의 언어·페이지 번역 설정을 확인하세요. 영어 사이트만 원문으로 보고 싶다면 ‘자동 번역할 언어’에서 영어를 제거하거나 ‘번역 제안하지 않을 언어’ 목록을 조정하면 됩니다. 번역이 필요할 때만 수동 버튼을 눌러 사용하는 방식도 가능합니다.

자주 묻는 질문 (FAQ)

크롬에서 자동번역을 완전히 끄려면 어떻게 해야 하나요?

PC 크롬에서 설정 → 언어 → Google 번역 항목에서 'Google 번역 사용' 스위치를 꺼서 자동번역 제안을 완전히 끌 수 있습니다.

영어 페이지만 자동번역을 중지하고 다른 언어는 유지하려면 어떻게 설정하나요?

설정 → 언어 → Google 번역 → 자동 번역할 언어 목록에서 영어를 제거하고, 번역 제안하지 않을 언어 목록에 영어를 추가하면 영어는 자동번역 없이 원문으로 볼 수 있습니다.

갤럭시 크롬에서 번역 제안이 사라졌을 때 해결 방법은 무엇인가요?

갤럭시 크롬 앱에서 설정 → 언어 → 번역 설정에서 '다른 언어 페이지를 Google 번역으로 전송하도록 제안' 스위치를 켜거나, 자동 번역할 언어 목록을 확인해 영어 등 필요한 언어가 포함되어 있는지 점검하세요.
