LG OE·삼성 5C가 뜨면 배수필터와 호스를 확인하세요

배수 동작이 끝난 뒤 필터 아래쪽에만 고인 물은 정상 잔수일 수 있습니다. 필터 위 세척통 바닥까지 물이 차 있고 OE 또는 5C가 뜬다면 다음 순서로 확인하세요.

  1. 세척통을 식힙니다. 전원을 끄고 작동이 완전히 멈춘 뒤 내부가 식을 때까지 기다리세요. LG는 필터 분리 전 약 30분을 안내합니다.
  2. 설명서에 나온 배수필터만 뺍니다. 하단 바구니를 꺼내고, 모델별 분리 방향을 확인하세요. 음식물 찌꺼기를 제거하고 흐르는 물로 씻은 뒤 필터를 제자리에 잠그세요. 깨진 유리 조각이 보이면 맨손을 넣지 마세요.
  3. 싱크대 아래 보이는 배수호스를 봅니다. 전용 급수밸브를 잠근 뒤 호스가 수납물에 눌렸는지, 눈에 보이는 부분이 꺾였는지 확인하세요. 연결부는 풀지 말고, 빌트인 본체 뒤쪽이나 배수 높이를 확인해야 하면 설치기사에게 맡기세요. 누수가 없고 정상 세척을 재개할 때는 잠갔던 급수밸브를 다시 여세요.
  4. 누수와 거품이 없을 때만 설명서의 배수 절차를 한 번 따릅니다. 삼성은 일부 비스포크 DW60·DW50 계열에 시작 버튼을 약 3초 누른 뒤 문을 닫는 방식을 안내합니다. 내 모델의 버튼과 절차를 먼저 확인하세요.
필터 청소와 배수 조치 후에도 필터 위까지 물이 고이거나 같은 코드가 반복되면 AS를 받으세요.

LG IE·삼성 4C가 뜨면 싱크대 냉수부터 확인하세요

IE와 4C는 세척통으로 들어오는 물의 공급에 문제가 있을 때 표시됩니다. 누수나 거품이 없다면 다음 세 곳을 순서대로 확인하세요.

  1. 싱크대 냉수: 다른 수도꼭지에서도 냉수가 안 나오면 단수나 건물 급수 상태를 확인하세요.
  2. 식기세척기 전용 급수밸브: 냉수가 나오면 싱크대 안쪽에서 식기세척기로 이어지는 급수호스를 따라가 전용 밸브가 열려 있는지 확인하세요. 누수 흔적이 없고 전용 밸브가 잠겨 있다면 밸브 형태에 맞는 열림 방향으로 여세요. 이사나 설치 직후 특히 확인할 곳입니다.
  3. 노출 급수호스: 수납물에 눌리거나 접혔는지 보세요. 젖은 연결부나 파손이 보이면 밸브를 안전하게 잠그고 사용을 멈추세요.

급수가 정상인데 코드가 계속되면 호스를 분리하거나 제품을 빼내기 전에 제조사에 문의하세요. 설치 직후부터 증상이 이어졌다면 설치 상태도 함께 알려주세요.

LG AE·E1과 삼성 LC는 누수 흔적부터 확인하세요

LG는 AE(일부 표시창 RE)를 내부 누수 감지와 관련된 코드로 안내합니다. D1228MB 등 일부 구형 LG 모델의 설명서는 E1을 누수로 표시합니다. 삼성전자서비스는 E03·FE·LC를 모델별 누수 관련 표시로 안내합니다. 계열과 연식에 따라 표시가 달라질 수 있으므로 모델 설명서에서 확인하세요.

일반 주방세제를 넣었거나 거품이 넘칠 때

손설거지용 주방세제를 넣으면 거품이 과하게 생겨 문틈 밖으로 밀려 나오거나 하부로 흘러 누수 감지를 일으킬 수 있습니다. 운전을 멈추고, 전원부와 손이 마른 상태에서 안전하게 접근할 수 있을 때 전원을 차단하세요. 외부 누수가 보이면 안전하게 접근 가능한 전용 급수밸브를 잠그세요. 이후에는 식기세척기 전용 세제를 모델 권장량에 맞춰 사용하세요.

하부 누수받이의 물기 제거와 원인 점검은 AS로

눈에 보이는 외부 물기는 전원을 안전하게 차단한 뒤 닦으세요. 바닥이 말라도 하부 누수받이에 물기가 남을 수 있습니다. 누수 코드가 계속되거나 다시 뜨면 하부 누수받이의 물기 제거, 누수 센서 및 실제 누수 원인 점검을 서비스 기사에게 맡기세요. 본체를 기울이거나 하판을 열거나 드라이어로 말리는 방법은 피하세요.

전원부 주변이 젖었으면 플러그를 만지지 마세요. 마른 곳에서 해당 회로의 차단기를 안전하게 내릴 수 있을 때 차단하고, 접근이 어렵다면 제품에 손대지 말고 서비스에 연락하세요.

LG는 바닥에 물이 보이지 않아도 AE 또는 RE가 뜨면 전원을 안전하게 차단하고 서비스를 신청하도록 안내합니다. 삼성은 누수·거품 흔적이 없고 전원부 접근이 안전할 때 전원을 한 번 재연결하는 점검을 안내합니다. LC가 다시 뜨면 재가동을 중단하고 엔지니어 점검을 받으세요.

LG LE·HE는 서비스 점검, CL은 잠금 해제

  • LE: 세척 모터가 정상적으로 작동하지 않을 때 나타날 수 있습니다. 전원을 끄고 코드와 발생 시점을 기록해 AS를 신청하세요.
  • HE: 세척수가 가열되지 않을 때 나타날 수 있습니다. 히터 등 가열 계통을 전문 기사에게 점검받으세요.
  • CL: 버튼 잠금 상태입니다. 예를 들어 LG의 DFB 계열 안내는 부분세척과 안심헹굼을 함께 약 3초 누르는 방식을 설명합니다. 다른 모델은 버튼 이름과 조합이 다를 수 있으니 설명서를 확인하세요.

AS 접수 기준과 전화번호

제품 밖으로 물이 샜거나, 하부 누수 감지가 반복되거나, LG LE·HE가 떴다면 공식 서비스에 문의하세요. 급수·배수 오류는 위의 외부 점검 후 다시 표시되거나 물이 그대로 남을 때 AS로 넘어가세요.

접수할 때는 모델명, 화면 코드 사진, 오류가 나온 단계, 물이나 거품이 보인 위치, 사용한 세제, 이미 확인한 항목을 알려주세요. 출장비와 보증 적용 여부는 접수할 때 확인하세요.

자주 묻는 질문

LG OE나 삼성 5C가 뜨고 세척통 안에 물이 남으면 무엇부터 확인하나요?

제품 밖으로 물이 샜다면 사용을 멈추고 누수 안내를 따르세요. 물이 세척통 안에만 남았다면 배수필터와 노출 배수호스를 확인하세요. 필터 아래쪽에만 남은 물은 정상일 수 있습니다. 청소와 모델별 배수 조치 후에도 필터 위까지 물이 고이거나 코드가 반복되면 AS를 받으세요.

LG IE와 삼성 4C가 뜨면 급수밸브부터 열어야 하나요?

누수 흔적이 없다면 싱크대 냉수가 나오는지 먼저 확인하고, 식기세척기 전용 급수밸브가 잠겼는지와 노출 급수호스가 꺾였는지 살펴보세요. 물이 새면 밸브를 열지 말고 안전하게 잠근 뒤 상담하세요.

일반 주방세제를 넣은 뒤 LG AE·E1 또는 삼성 LC가 뜨면 어떻게 하나요?

사용을 멈추세요. 안전하게 접근할 수 있으면 전원을 차단하고 전용 급수밸브를 잠그세요. 바닥 물기나 거품이 사라져도 누수 코드가 계속되거나 다시 뜨면 하부 누수받이와 센서 점검을 받으세요.

LG 식기세척기 LE·HE·CL은 모두 AS를 불러야 하나요?

LE는 세척 모터, HE는 세척수 가열 계통의 이상 가능성이 있어 서비스 점검 대상입니다. CL은 버튼 잠금 표시이며, 잠금 해제 버튼이나 조합은 모델 설명서에서 확인하세요.

삼성 LC가 뜨는데 바닥이 마르면 다시 돌려도 되나요?

바닥이 말라도 제품 하부에 물기가 남을 수 있습니다. 누수와 거품 흔적이 전혀 없고 전원부 접근이 안전할 때만 삼성의 전원 재연결 안내를 따르세요. LC가 반복되면 재가동을 중단하고 1588-3366에 문의하세요.
