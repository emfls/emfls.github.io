거래처 명단·재고표·출석부처럼 행이 긴 엑셀 파일을 아래로 스크롤하다 보면 맨 위의 ‘이름·날짜·금액’ 제목이 사라져 어느 열이 무엇인지 헷갈립니다. 이때 필요한 기능이 틀 고정입니다. 첫 행 하나만 고정할 수도 있고, 원하는 여러 행과 왼쪽 열을 함께 고정할 수도 있습니다.

핵심은 고정할 마지막 행의 바로 아래, 고정할 마지막 열의 바로 오른쪽 셀을 선택하는 것입니다. 예를 들어 1~2행과 A~C열을 함께 고정하려면 D3 셀을 선택하면 됩니다. 이 글은 Microsoft 공식 지원 문서를 바탕으로 Windows용 Excel 2024·Microsoft 365 중심으로 설명하며, Mac 및 웹용 Excel은 메뉴가 다를 수 있습니다.

1. 엑셀 틀 고정, 원하는 결과별 셀 선택표

원하는 고정 범위먼저 선택할 셀실행 메뉴
첫 번째 행(1행)만 고정셀 선택 불필요보기 → 틀 고정 → 첫 행 고정
첫 번째 열(A열)만 고정셀 선택 불필요보기 → 틀 고정 → 첫 열 고정
1~2행 고정A3보기 → 틀 고정 → 틀 고정
1~3행 고정A4보기 → 틀 고정 → 틀 고정
A~B열 고정C1보기 → 틀 고정 → 틀 고정
1행과 A열 고정B2보기 → 틀 고정 → 틀 고정
1~2행과 A~C열 고정D3보기 → 틀 고정 → 틀 고정
1~4행과 A~C열 고정D5보기 → 틀 고정 → 틀 고정

위 표는 선택한 셀보다 위쪽의 행과 왼쪽의 열이 고정되는 규칙에 따라 구성했습니다. ‘선택한 셀 자체를 고정한다’고 생각하면 한 행 또는 한 열씩 어긋나기 쉽습니다.

공식 출처: Microsoft — 틀을 고정하여 행과 열 잠그기

2. 첫 행 고정: 제목이 스크롤해도 보이게 하기

가장 흔한 상황은 1행에 ‘날짜, 거래처, 품목, 금액’ 제목이 들어 있는 목록입니다.

  1. 고정할 엑셀 워크시트를 엽니다.
  2. 리본 메뉴의 보기 탭을 선택합니다.
  3. 틀 고정 메뉴를 펼칩니다.
  4. 첫 행 고정을 선택합니다.
  5. 마우스 휠이나 스크롤바로 아래로 이동해 1행이 그대로 남는지 확인합니다.

고정이 적용되면 1행 아래쪽에 경계선이 표시될 수 있습니다. 첫 행 고정은 일반적인 셀 편집을 막는 기능이 아닙니다. 화면에서 해당 행이 스크롤되지 않도록 하는 기능입니다.

주의: 제목이 2행에 있는데 1행만 고정하면 제목은 그대로 사라질 수 있습니다. 이런 경우에는 다음의 ‘여러 행 고정’ 방식을 사용해야 합니다.

3. 여러 행 고정: 2행·3행까지 함께 고정하는 방법

제목이 두 줄이거나 1행에 문서명, 2행에 표의 제목이 있는 파일에서 유용합니다.

첫 두 행(1~2행) 고정

  1. 해당 워크시트에서 A3 셀을 클릭합니다.
  2. 보기 → 틀 고정 → 틀 고정을 선택합니다.
  3. 아래로 스크롤해 1행과 2행이 화면 위쪽에 계속 남는지 확인합니다.

첫 세 행(1~3행) 고정

같은 방식으로 A4 셀을 선택한 뒤 틀 고정을 실행합니다. 여기서 A열은 열 고정을 피하기 위해 선택한 것입니다. A열의 왼쪽에 다른 열이 없으므로 열은 추가로 고정되지 않습니다.

제목 구성올바른 선택
1행만 제목‘첫 행 고정’ 명령
1~2행이 제목A3
1~3행이 제목A4
1~5행에 안내와 제목이 있음A6

실무 팁: 필요 이상으로 많은 행을 고정하면 실제 데이터를 볼 수 있는 화면 높이가 줄어듭니다. 고정할 행은 가능한 한 핵심 제목 영역으로 제한하는 것이 좋습니다.

4. 왼쪽 열 고정: 이름·사번·제품코드 항상 표시하기

가로로 긴 엑셀 표를 오른쪽으로 스크롤할 때 왼쪽의 식별자가 사라지는 문제를 해결할 수 있습니다.

A열만 고정

보기 → 틀 고정 → 첫 열 고정을 선택합니다.

A열과 B열을 함께 고정

  1. C1 셀을 클릭합니다.
  2. 보기 → 틀 고정 → 틀 고정을 선택합니다.
  3. 오른쪽으로 스크롤해 A열과 B열이 보이는지 확인합니다.

C1을 선택하면 왼쪽에 있는 A·B열만 고정되고, 1행 위에 다른 행이 없으므로 행은 고정되지 않습니다.

자주 사용하는 고객 관리표라면 A열은 고객번호, B열은 고객명으로 배치하고 두 열을 고정하면 오른쪽의 수십 개 속성을 보면서도 누구의 정보인지 구분하기 편합니다.

5. 행과 열을 동시에 고정: B2·D3 셀을 활용

‘제목도 보고 싶고, 왼쪽 이름도 계속 보이게 하고 싶다’면 행과 열을 함께 고정합니다.

1행과 A열을 동시에 고정

  1. B2 셀을 선택합니다.
  2. 보기 → 틀 고정 → 틀 고정을 실행합니다.
  3. 아래 및 오른쪽으로 각각 스크롤해 두 방향의 고정 상태를 확인합니다.

1~2행과 A~C열을 동시에 고정

  1. D3 셀을 클릭합니다.
  2. 보기 → 틀 고정 → 틀 고정을 선택합니다.
  3. 아래로 스크롤할 때 1~2행이, 오른쪽으로 스크롤할 때 A~C열이 유지되는지 확인합니다.

이 규칙을 외우면 다른 조합에도 적용할 수 있습니다. 예를 들어 E6을 선택하면 1~5행과 A~D열이 고정됩니다.

6. 틀 고정 해제·고정 위치 바꾸기

현재 위치가 마음에 들지 않거나 다른 행을 고정하려면 기존 설정을 먼저 해제하는 편이 명확합니다.

  1. 보기 탭을 선택합니다.
  2. 틀 고정 메뉴에서 틀 고정 취소를 선택합니다.
  3. 다시 고정할 위치의 셀을 선택합니다.
  4. 틀 고정을 실행합니다.

예시: 1행만 고정되어 있는데 1~3행을 고정하고 싶다면, 기존 고정을 취소하고 A4를 선택하여 다시 적용합니다. 이미 고정된 상태에서 다른 셀만 클릭한다고 고정 위치가 자동으로 변경되는 것은 아닙니다.

7. '틀 고정 안됨' 또는 메뉴가 회색일 때 확인할 것

아래 순서로 확인하면 무조건 파일을 새로 만들지 않고도 원인을 좁힐 수 있습니다.

증상먼저 확인할 사항권장 조치
틀 고정 버튼이 비활성화현재 보기 모드보기 → 기본/보통 보기로 변경
고정이 엉뚱한 위치에 적용선택한 셀 좌표고정 취소 후 B2·A3·D3 등 올바른 셀 선택
기존 고정 위치만 보임기존 고정 설정틀 고정 취소 후 재설정
제목이 스크롤할 때 사라짐첫 행만 고정했는지제목이 여러 행이면 A3 또는 A4 방식 사용
위쪽 행을 두고 가운데 행만 고정하고 싶음틀 고정의 구조적 제한제목 구조를 바꾸거나 다른 보기 방식 검토
파일 일부 메뉴가 사용 불가보호된 보기·시트 제한편집 가능 여부와 파일 권한 확인

Microsoft의 Mac용 Excel 도움말은 고정 단추가 회색이면 보기 → 보통으로 전환하도록 안내합니다. Windows에서도 페이지 레이아웃·페이지 나누기 미리 보기 상태인지 확인하고 기본 보기에서 다시 시험하는 방법이 유용합니다.

외부에서 받은 파일에 보호된 보기가 적용돼 있다면 일부 편집 기능이 제한될 수 있습니다. 출처를 신뢰할 수 없는 파일은 기능을 사용하려고 무조건 보호를 해제하지 마세요. 먼저 파일 출처와 문서 권한을 확인해야 합니다.

공식 출처: Microsoft — Mac용 Excel 틀 고정, Microsoft — 보호된 보기란?

8. 특정 중간 행만 고정할 수 있나요?

예를 들어 1~4행은 계속 스크롤되지만 5행만 상단에 남겨두고 싶다는 요구는 일반적인 틀 고정 기능으로 직접 구현하기 어렵습니다. 이 기능은 시트의 맨 위 행부터 연속으로 고정하는 구조이기 때문입니다.

이럴 때는 다음과 같은 대안을 고려할 수 있습니다.

  • 중요한 열 제목을 1행으로 옮겨 첫 행만 고정합니다.
  • 문서 안내 문구와 제목이 섞여 있다면 제목용 행을 위쪽에 따로 배치합니다.
  • 다른 구간을 동시에 비교하려면 보기 탭의 분할 기능을 검토합니다. 다만 분할은 틀 고정과 작동 방식이 다르므로 완전히 같은 기능은 아닙니다.

실제 데이터의 순서와 수식을 바꾸면 안 되는 업무용 파일에서는 행을 이동하기 전에 반드시 복사본에서 시험해야 합니다.

9. 화면에서 고정한 제목이 인쇄할 때도 반복되나요?

아닙니다. 틀 고정은 엑셀 화면의 스크롤을 위한 기능입니다. 종이에 출력할 때 페이지마다 제목 행을 표시하려면 인쇄 제목을 별도로 설정해야 합니다.

인쇄할 때 1행을 모든 페이지에 반복하는 방법

  1. 페이지 레이아웃 → 인쇄 제목을 선택합니다.
  2. 페이지 설정 창의 시트 탭에서 ‘반복할 행’ 또는 ‘반복할 행(위쪽)’ 항목을 찾습니다.
  3. 첫 행만 반복하려면 $1:$1을 입력합니다.
  4. 첫 두 행을 반복하려면 $1:$2를 입력합니다.
  5. 확인을 누른 뒤 파일 → 인쇄 미리 보기에서 2페이지 이후에도 제목이 나타나는지 확인합니다.

반대로 왼쪽의 A열을 매 페이지에 반복하고 싶다면 ‘반복할 열’에 $A:$A를 지정할 수 있습니다.

중요: 인쇄 제목 메뉴가 회색이라면 셀 편집 중인지, 차트가 선택됐는지, 프린터가 설정돼 있는지 확인하세요. 여러 시트를 그룹 선택한 상태에서는 일부 인쇄 제목 옵션을 사용할 수 없습니다. 웹용 Excel의 인쇄 제목 기능은 데스크톱과 차이가 있을 수 있습니다.

공식 출처: Microsoft — 인쇄하는 모든 페이지에 특정 행 또는 열 반복, Microsoft — 모든 페이지에 열 머리글 행 인쇄

10. Mac과 웹용 Excel에서는 어떻게 하나요?

Mac용 Excel

Mac에서는 보기 → 틀 고정 메뉴를 사용합니다. B2를 선택하면 첫 행과 첫 열, D5를 선택하면 1~4행과 A~C열을 고정할 수 있다는 기본 원칙은 동일합니다. 고정 메뉴가 회색으로 나오면 보통 보기를 선택한 뒤 다시 확인합니다.

웹용 Excel

웹용 Excel에서도 지원되는 틀 고정 메뉴를 사용할 수 있지만 리본 메뉴 구성과 사용 가능한 기능은 데스크톱 버전과 다를 수 있습니다. 특히 화면 고정과 출력물에 제목 반복은 별개이므로, 출력 목적이라면 데스크톱 Excel의 인쇄 제목 설정을 확인하는 편이 정확합니다.

공식 출처: Microsoft — Mac용 Excel 틀 고정, Microsoft — 모든 페이지에 열 머리글 행 인쇄

11. 자주 묻는 질문

Q. 엑셀 첫 두 행을 고정하려면 어떤 셀을 눌러야 하나요?

A3을 선택하고 보기 → 틀 고정 → 틀 고정을 누르면 됩니다.

Q. A열과 B열을 동시에 고정하려면요?

C1을 선택한 다음 틀 고정을 실행합니다.

Q. 1행과 A열을 동시에 고정하려면요?

B2를 선택합니다.

Q. 고정했는데 제목이 계속 사라집니다.

제목이 실제로 몇 행에 들어 있는지 먼저 확인하세요. 2행까지 제목이라면 첫 행 고정이 아니라 A3을 이용한 틀 고정을 사용해야 합니다.

Q. 고정된 검은 선을 없애려면요?

보기 → 틀 고정 → 틀 고정 취소를 선택합니다. 경계선이 고정 때문이 아니라 셀 테두리로 지정된 것이라면 셀 서식을 별도로 확인해야 합니다.

Q. 인쇄할 때 첫 행을 반복하려면 틀 고정을 사용하나요?

아닙니다. 페이지 레이아웃 → 인쇄 제목에서 $1:$1을 지정해야 합니다.

12. 최종 체크리스트

  • ☐ 고정할 행과 열이 정확히 무엇인지 먼저 정했다.
  • ☐ 첫 행·첫 열만 고정할지, 여러 행·열을 함께 고정할지 결정했다.
  • ☐ 다중 고정이라면 고정 영역의 바로 아래·오른쪽 셀을 선택했다.
  • ☐ 아래로, 오른쪽으로 각각 스크롤하며 결과를 확인했다.
  • ☐ 위치가 틀리면 기존 고정을 취소하고 다시 설정했다.
  • ☐ 출력물에 제목이 필요하다면 인쇄 제목을 별도로 지정했다.

요약: 첫 행 고정은 ‘보기 → 틀 고정 → 첫 행 고정’으로 충분합니다. 여러 행이나 열을 동시에 고정하려면 고정하려는 행 바로 아래와 열 바로 오른쪽이 만나는 셀을 선택하세요. 예를 들어 1~2행과 A~C열을 고정할 셀은 D3입니다.
