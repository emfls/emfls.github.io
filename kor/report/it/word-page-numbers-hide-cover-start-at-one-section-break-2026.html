워드(Word)에서 보고서·논문·제안서를 작성할 때 페이지 번호를 넣는 것은 쉽지만, 표지에만 번호를 숨기거나 목차 다음 본문부터 1페이지로 다시 시작하려면 설정 방법이 달라집니다. 특히 표지 한 장만 제외하는 방법과 표지·목차 등 여러 장을 제외하는 방법을 혼동하면 페이지 번호가 2로 시작하거나 모든 페이지의 번호가 함께 사라지는 문제가 생깁니다.

이 글은 Microsoft 365 Word 및 Word 2024의 공식 사용법을 기준으로 기본 번호 삽입 → 첫 페이지 숨기기 → 둘째 페이지를 1로 시작 → 구역별 페이지 번호 재설정 → 오류 해결 순서로 설명합니다. Windows용 Word를 중심으로 하되 Mac·웹용 Word의 차이를 별도로 정리했습니다.

주의: 논문이나 회사 공통 양식처럼 서식이 중요한 파일이라면 작업 전에 다른 이름으로 저장해 원본을 보관하세요.

1. 원하는 번호 형태에 따라 기능부터 선택하세요

목표핵심 기능핵심 숫자

1쪽 표지 숨김, 2쪽에는 2 표시첫 페이지를 다르게 지정기본 번호 유지
1쪽 표지 숨김, 2쪽에는 1 표시첫 페이지를 다르게 지정 + 번호 서식시작 번호 0
1~2쪽은 표지·목차, 3쪽 본문에 1 표시구역 나누기 + 이전과 연결 해제본문 구역 시작 1
목차는 i, ii, iii / 본문은 1, 2, 3구역별 번호 서식구역마다 지정

공식 출처: Microsoft — 나중에 문서에서 페이지 번호 매기기 시작

2. 모든 페이지에 번호 넣는 가장 기본적인 방법

  1. Word 문서를 열고 상단 삽입 탭을 선택합니다.
  2. 페이지 번호를 클릭합니다.
  3. 페이지 위쪽 또는 페이지 아래쪽 등 위치를 선택합니다.
  4. 왼쪽·가운데·오른쪽 정렬 등 원하는 형식을 선택합니다.
  5. 문서 전체에 1, 2, 3으로 번호가 들어갔는지 확인합니다.
  6. 머리글/바닥글 닫기 또는 Esc를 눌러 마무리합니다.

머리글과 바닥글은 일반 본문과 분리된 편집 영역입니다. 번호가 안 보이면 문서의 위쪽·아래쪽 여백을 더블클릭해 편집 상태를 확인할 수 있습니다.

자주 하는 실수: 매 페이지마다 숫자를 직접 적으면 문서 중간에 페이지를 추가했을 때 숫자가 자동으로 바뀌지 않습니다. 반드시 Word의 페이지 번호 기능을 사용하세요.

공식 출처: Microsoft — 페이지 번호 삽입

3. 표지에만 페이지 번호가 보이지 않게 하는 방법

문서가 표지 1쪽, 본문 2쪽부터 구성돼 있을 때 사용합니다.

  1. 먼저 삽입 → 페이지 번호에서 원하는 위치에 번호를 넣습니다.
  2. 첫 페이지의 머리글 또는 바닥글을 더블클릭합니다.
  3. 표시된 편집 메뉴에서 첫 페이지를 다르게 지정을 체크합니다.
  4. 첫 페이지에 번호가 남아 있다면 해당 번호만 선택하고 Delete를 누릅니다.
  5. 머리글/바닥글 편집을 닫습니다.
  6. 표지에 번호가 보이지 않는지, 두 번째 페이지에 번호가 표시되는지 확인합니다.

이 경우 시작 번호를 바꾸지 않았다면 2쪽에는 숫자 2가 표시되는 것이 정상일 수 있습니다. 표지에서 숫자가 보이지 않는 것과 표지를 번호 계산에서 제외하는 것은 다릅니다.

또한 문서에 구역이 여러 개 있다면 각 구역의 첫 페이지에도 '첫 페이지를 다르게 지정' 옵션이 적용될 수 있으므로 전체 문서를 확인하세요.

공식 출처: Microsoft — 나중에 문서에서 페이지 번호 매기기 시작

4. 표지 숨기고 2페이지부터 숫자 1로 시작하는 방법

이 방법은 구역 나누기를 추가하지 않아도 되는 대표적인 상황입니다.

원하는 화면은 다음과 같습니다.

문서상의 위치화면에 보이는 번호
1쪽 표지없음
2쪽 본문1
3쪽 본문2
4쪽 본문3

설정 절차

  1. 3번 절에 따라 첫 페이지를 다르게 지정합니다.
  2. 삽입 → 페이지 번호 → 페이지 번호 서식을 엽니다.
  3. 페이지 번호 매기기에서 시작 번호를 선택합니다.
  4. 숫자 0을 입력합니다.
  5. 확인한 뒤 두 번째 페이지로 이동합니다.
  6. 2쪽에 1, 3쪽에 2가 표시되면 성공입니다.

왜 시작 번호를 0으로 하나요? 표지는 번호가 보이지 않지만 내부 번호 계산의 첫 페이지로 남아 있기 때문입니다. 첫 페이지를 0부터 계산하게 하면 그다음 페이지가 1로 표시됩니다.

이 설정은 Microsoft 공식 문서에서 명시적으로 안내하는 방법입니다.

공식 출처: Microsoft — 페이지 번호 삽입

5. 표지와 목차를 제외하고 3페이지 본문부터 1 시작하기

보고서에서 표지 1쪽과 목차 2쪽은 페이지 번호를 표시하지 않고, 3쪽부터 1·2·3으로 번호를 시작해야 한다면 구역 나누기가 필요합니다.

실제 페이지문서 내용원하는 번호
1표지없음
2목차없음
3본문 첫 장1
4본문 다음 장2

1단계: 목차 다음에 새 구역 만들기

  1. Word 원본을 복사한 파일을 엽니다.
  2. 목차 마지막 글자 뒤에 커서를 놓습니다.
  3. 레이아웃 → 나누기 → 다음 페이지(구역 나누기)를 선택합니다.
  4. 본문이 새 페이지의 새로운 구역에서 시작하는지 확인합니다.
  5. 홈 → ¶(표시/숨기기)를 켜면 구역 나누기 위치를 확인할 수 있습니다.

단순 페이지 나누기는 본문을 다음 장으로 보내지만 새로운 머리글·바닥글 번호 체계를 만들지는 않습니다. 이 작업에는 구역 나누기가 필요합니다.

2단계: 본문 구역의 이전과 연결 끄기

  1. 3쪽 본문 시작 페이지의 바닥글을 더블클릭합니다. 번호를 위쪽에 넣는다면 머리글을 엽니다.
  2. 머리글/바닥글 리본에서 이전과 연결을 찾습니다.
  3. 선택돼 있다면 해제합니다.
  4. 변경할 구역이 본문 구역이 맞는지 확인합니다.

주의: 머리글과 바닥글은 서로 별도로 연결됩니다. 번호를 바닥글에 넣는 경우 바닥글의 이전과 연결을 해제해야 합니다. 머리글 연결만 해제하고 바닥글 번호를 수정하면 의도와 다른 결과가 나올 수 있습니다.

3단계: 본문 번호를 1부터 시작

  1. 본문 구역의 머리글·바닥글에서 페이지 번호 위치를 정합니다.
  2. 삽입 → 페이지 번호 → 페이지 번호 서식을 엽니다.
  3. 시작 번호를 선택하고 1을 입력합니다.
  4. 표지·목차에 남아 있는 번호가 있다면 앞 구역에서만 제거합니다.
  5. 3쪽이 1, 4쪽이 2로 표시되는지 확인합니다.

절대 주의할 점: 본문의 '이전과 연결'을 해제하기 전에 앞 구역에서 페이지 번호를 삭제하면 본문 번호도 함께 없어질 수 있습니다. 연결 해제를 먼저 확인하세요.

공식 출처: Microsoft — 구역별 페이지 번호 및 형식 사용자 지정, Microsoft — 이전과 연결

6. 목차는 i·ii, 본문은 1·2로 구분하기

일부 논문과 보고서는 서론·목차를 로마 숫자, 본문을 아라비아 숫자로 표시합니다.

  1. 앞부분과 본문 사이에 다음 페이지 구역 나누기를 삽입합니다.
  2. 본문 구역에서 번호가 들어갈 머리글·바닥글의 이전과 연결을 해제합니다.
  3. 목차가 속한 앞 구역을 선택해 페이지 번호 서식 → 번호 서식을 엽니다.
  4. 로마자 i, ii, iii를 선택합니다.
  5. 본문 구역에서는 번호 서식을 1, 2, 3으로 변경합니다.
  6. 본문 시작 번호를 1로 설정합니다.
  7. 모든 페이지에 원하는 번호가 나타나는지 확인합니다.

실무 팁: 표지에 번호를 숨기는 설정까지 필요하다면 앞 구역의 첫 페이지 표시 여부를 별도로 확인해야 합니다. 구역별로 번호 서식을 바꾸는 것과 표지 숨김은 독립적인 작업입니다.

7. 구역을 나눴는데 '이전과 연결'이 회색일 때

Microsoft는 '이전과 연결' 버튼이 비활성화돼 있을 경우 구역 나누기가 제대로 삽입됐는지 확인하라고 안내합니다.

점검 순서는 다음과 같습니다.

  1. 홈 → ¶를 눌러 편집 기호를 표시합니다.
  2. 본문이 시작되는 위치 앞에 구역 나누기(다음 페이지)가 있는지 확인합니다.
  3. 단순 페이지 나누기만 있다면 구역을 별도로 나눠야 하는지 검토합니다.
  4. 두 번째 구역의 머리글 또는 바닥글 안에 커서가 있는지 확인합니다.
  5. 다시 '이전과 연결' 메뉴가 활성화되는지 살펴봅니다.

여러 구역에 첫 페이지를 다르게 지정 또는 홀수·짝수 페이지 다르게 지정이 들어 있다면 같은 종류의 머리글·바닥글끼리 연결됩니다. 번호가 어느 영역에 있는지 구분해야 합니다.

공식 출처: Microsoft — 이전과 연결

8. 페이지 번호가 모든 페이지에 1로 반복될 때

번호가 1, 2, 3으로 늘어나지 않고 특정 위치마다 다시 1이 된다면 다음을 확인하세요.

증상가능한 이유조치
매 장 숫자 1이 반복됨페이지 번호를 일반 텍스트로 입력함삽입 → 페이지 번호 기능 사용
새 장부터 다시 1이 됨별도 구역 시작 번호 1 지정연속 번호 여부 확인
표지만 숨겼는데 2쪽이 2로 나옴시작값 기본 12쪽을 1로 하려면 시작값 0
본문 번호 수정했는데 목차도 바뀜이전과 연결 활성화본문 구역의 연결 해제
중간 페이지의 번호만 안 보임새 구역·첫 페이지 다르게 지정구역별 머리글·바닥글 확인
번호가 아래쪽 아닌 위쪽에 보임머리글에 삽입됨페이지 번호 위치 변경

중요한 문서는 번호가 맞는지 문서 중간·마지막 페이지까지 확인하세요. 첫 두 페이지만 맞다고 끝내면 새 구역에서 번호가 다시 시작되는 문제를 놓칠 수 있습니다.

9. 페이지 번호를 오른쪽·가운데로 옮기는 방법

  1. 번호가 있는 머리글 또는 바닥글을 더블클릭합니다.
  2. 삽입 → 페이지 번호에서 위치와 서식 선택 기능을 확인합니다.
  3. 페이지 아래쪽 가운데 또는 오른쪽 등 원하는 번호 스타일을 적용합니다.
  4. 기존 페이지 번호가 중복 삽입되지 않았는지 확인합니다.
  5. 전체 문서에서 표시 위치가 일관적인지 검토합니다.

학교·회사에서 지정한 여백이나 쪽번호 위치가 있다면 그 규정을 우선하세요. 임의로 여백을 줄이면 인쇄할 때 번호가 잘릴 수 있습니다.

10. '3 / 20'처럼 전체 쪽수 함께 넣기

Word는 페이지 번호에 전체 페이지 수를 함께 넣는 Page X of Y 형식을 지원합니다.

  1. 번호를 넣을 머리글 또는 바닥글을 엽니다.
  2. 삽입 → 페이지 번호를 선택합니다.
  3. 현재 위치 또는 원하는 표시 위치를 고릅니다.
  4. 목록에서 Page X of Y와 비슷한 형식을 선택합니다.
  5. 실제 문서에서 현재 쪽수와 전체 쪽수가 맞는지 확인합니다.

주의: 표지·목차를 제외해 본문 번호를 1부터 시작하더라도 총 페이지 수에는 문서 앞부분이 포함될 수 있습니다. 예를 들어 본문 첫 페이지가 '1 / 20'이라고 표시되더라도 실제 문서의 물리적 페이지는 3쪽일 수 있으니 제출 양식에서 요구하는 기준을 확인해야 합니다.

11. 번호가 사라졌거나 일부 구역에만 남아 있을 때

전체 제거 방법

  1. 삽입 → 페이지 번호 → 페이지 번호 제거를 선택합니다.
  2. 번호가 모두 사라졌는지 확인합니다.
  3. 남아 있는 구역이 있다면 머리글·바닥글을 열어 번호를 직접 선택해 삭제합니다.

주의: Microsoft는 일부 상황에서 페이지 번호 제거 명령이 머리글이나 바닥글 자체까지 지울 수 있다고 경고합니다. 회사 로고나 문서 제목을 유지해야 하는 경우, 머리글·바닥글을 직접 열고 페이지 번호만 선택해 제거하는 편이 더 안전합니다.

특정 구역에서만 번호를 지울 때는 그 구역의 이전과 연결 상태를 확인해야 합니다. 연결된 상태라면 다른 구역까지 함께 변경될 수 있습니다.

12. Mac용 Word와 웹용 Word의 차이

Mac용 Word

Microsoft는 Mac용 Word에서도 페이지 번호 삽입, 첫 페이지를 다르게 지정, 시작 번호 변경을 지원한다고 안내합니다.

  • 삽입 → 페이지 번호에서 번호를 추가합니다.
  • 표지를 숨기려면 첫 페이지를 다르게 지정합니다.
  • 둘째 페이지를 1로 시작하려면 번호 형식의 시작값을 확인합니다.
  • 본문 번호를 새 구역에서 시작하려면 구역 나누기·연결 설정을 사용합니다.

메뉴의 정확한 위치나 대화 상자 구성은 Windows와 다를 수 있으므로 현재 표시되는 리본을 기준으로 진행하세요.

웹용 Word

웹용 Word에서도 기본적인 페이지 번호 삽입·제거 기능이 제공됩니다. 다만 복잡한 구역별 머리글·바닥글 분리를 편집하는 기능은 사용 중인 서비스·버전에 따라 제한될 수 있습니다.

웹에서 원하는 구역 설정을 찾을 수 없다면 데스크톱 Word에서 수정하고 웹에서 결과를 검토하는 방법이 적절합니다.

13. 표지·목차·본문 예제로 최종 결과 검산하기

다음과 같이 8페이지짜리 보고서가 있다고 가정해 보겠습니다.

물리적 페이지내용표시할 페이지 번호
1표지없음
2목차없음
3사업 개요1
4사업 현황2
5시장 분석3
6실행 계획4
7예산5
8결론6

검산 절차

  1. 2쪽 끝에 다음 페이지 구역 나누기가 있는지 확인합니다.
  2. 3쪽 바닥글의 이전과 연결이 꺼져 있는지 확인합니다.
  3. 3쪽 구역 시작 번호가 1인지 확인합니다.
  4. 1~2쪽 번호가 숨겨져 있는지 확인합니다.
  5. 4~8쪽은 2~6으로 이어지는지 검토합니다.
  6. 파일 → 인쇄에서 출력 미리 보기까지 확인합니다.

이 예제에서 본문 마지막 페이지의 숫자가 6인 것은 정상입니다. 표지와 목차 두 장을 제외한 본문 분량이 여섯 페이지이기 때문입니다.

14. 자동 목차가 있다면 쪽번호 설정 뒤 갱신하세요

페이지 번호 설정을 바꾸면 이미 만든 자동 목차의 페이지 번호가 이전 상태로 남을 수 있습니다.

  1. 구역별 페이지 번호를 먼저 확정합니다.
  2. 자동 목차 영역을 클릭합니다.
  3. 목차 업데이트 또는 필드 업데이트를 실행합니다.
  4. 항목 자체는 동일하다면 페이지 번호만 업데이트해도 됩니다.
  5. 제목을 추가하거나 수정했다면 전체 목차 업데이트를 선택합니다.
  6. 최종 인쇄 미리 보기에서 목차의 번호와 본문 번호를 비교합니다.

이 절차는 기존 자동 목차를 만드는 방법과는 다릅니다. 이 글은 구역별 페이지 번호의 설정 및 출력 검증에 초점을 맞춥니다.

15. 자주 묻는 질문

Q. 워드에서 쪽번호는 어디에 있나요?

삽입 → 페이지 번호에서 위치와 스타일을 선택하면 됩니다.

Q. 표지 한 장만 번호를 숨기려면요?

머리글·바닥글에서 첫 페이지를 다르게 지정을 체크하고, 필요하면 첫 페이지 번호만 삭제하세요.

Q. 2페이지부터 1로 시작하는 이유가 뭔가요?

시작 번호를 0으로 설정하면 표지는 숨겨진 0이 되고 다음 장에 1이 표시됩니다. Microsoft의 공식 안내에 있는 설정입니다.

Q. 3페이지부터 1로 시작하려면요?

2페이지 끝에 다음 페이지 구역 나누기를 넣은 뒤 본문 구역의 이전과 연결을 해제하고 시작 번호 1을 지정합니다.

Q. 구역을 나눴는데 이전과 연결 버튼이 회색입니다.

현재 위치에 구역 나누기가 있는지, 본문 쪽인 두 번째 구역의 머리글·바닥글을 편집 중인지 확인하세요.

Q. 번호를 지웠더니 다른 페이지에서도 사라졌어요.

구역의 머리글·바닥글이 이전 구역과 연결된 상태일 수 있습니다. 원본 사본이나 실행 취소를 통해 되돌리고 연결 설정부터 확인하세요.

Q. 본문은 1페이지인데 전체 페이지가 10으로 나와도 정상인가요?

가능합니다. 전체 쪽수는 표지·목차가 포함된 물리적 문서 페이지를 기준으로 표시될 수 있습니다. 제출 규정에 맞는지 확인해야 합니다.

16. 최종 체크리스트

  • ☐ 파일 원본을 보관한 상태에서 작업했다.
  • ☐ 표지만 숨길지, 표지·목차까지 제외할지 구분했다.
  • ☐ 둘째 페이지를 1로 시작하려면 시작 번호 0을 확인했다.
  • ☐ 셋째 페이지부터 1로 시작하려면 구역 나누기를 사용했다.
  • ☐ 번호가 있는 머리글 또는 바닥글에서 이전과 연결을 해제했다.
  • ☐ 본문 번호를 1부터 다시 시작하도록 지정했다.
  • ☐ 중간 구역이나 홀수·짝수 페이지에 번호 누락이 없는지 확인했다.
  • ☐ 인쇄 미리 보기와 최종 PDF에서 번호가 일치하는지 검토했다.

결론: Word의 쪽번호 문제는 표지 한 장만 숨기기 = 첫 페이지를 다르게 지정, 본문에서 새로 1부터 시작하기 = 구역 나누기 + 이전과 연결 해제 + 번호 시작값으로 구분해 해결하면 됩니다. 페이지마다 숫자를 직접 수정하지 말고, 최종적으로 전체 페이지를 확인하세요.
