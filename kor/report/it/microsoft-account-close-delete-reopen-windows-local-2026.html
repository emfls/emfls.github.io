  • 계정 삭제 전 Outlook 메일, OneDrive 파일, 구독, Xbox 구매 내역 등 중요한 데이터를 반드시 백업하고 복구 수단을 확인해야 한다.

Microsoft 계정을 없애고 싶은데 Windows 11에 로그인할 때 쓰고 있거나 Outlook·OneDrive 자료가 남아 있다면 계정 폐쇄 전에 무엇이 함께 사라지는지 확인해야 한다. Microsoft 계정 전체를 폐쇄하는 것과 PC에서 로그인 계정만 바꾸는 것은 전혀 다른 작업이다.

이 글은 Microsoft의 공식 고객지원 안내를 바탕으로 계정을 삭제하지 않고 해결할 수 있는 경우 → 삭제 전 체크리스트 → 실제 폐쇄 신청 → 유예기간 내 복구 순서로 정리했다.

핵심 요약: Microsoft 개인 계정 폐쇄를 신청할 때 30일 또는 60일의 복구 유예기간을 선택한다. 이 기간 안에는 본인 확인을 거쳐 다시 열 수 있지만, 기간이 지나면 계정과 관련 데이터가 영구 삭제될 수 있다. 단순히 Windows PC에서 로그아웃하거나 Microsoft 365 자동결제만 중단하고 싶은 사람은 계정 폐쇄가 필요 없다.

1. Microsoft 계정 삭제와 Windows 계정 제거는 다르다

하고 싶은 일알맞은 방법주의할 점
Outlook.com·OneDrive·Xbox에 쓰는 개인 Microsoft 계정 자체를 없애고 싶다Microsoft 계정 폐쇄 절차 진행계정에 연결된 여러 서비스와 데이터에 영향을 준다
Windows 11에서 Microsoft 계정 대신 로컬 계정으로 로그인하고 싶다설정 → 계정 → 사용자 정보에서 로컬 계정으로 로그인개인 Microsoft 계정 자체는 유지된다
Microsoft 365 자동결제만 끊고 싶다Microsoft 구독 페이지에서 취소 또는 반복 청구 끄기계정을 폐쇄할 필요가 없다
다른 사람이 쓰던 Windows 사용자 프로필만 PC에서 빼고 싶다관리자 권한으로 해당 장치 사용자 계정 제거장치 안 해당 사용자 데이터가 삭제될 수 있어 백업 필요
회사·학교 계정을 정리하고 싶다소속 조직의 관리자·IT 담당자에게 문의개인 Microsoft 계정 폐쇄 절차와 다르다

가장 먼저 할 일: 지금 로그인한 계정이 개인 Microsoft 계정인지, 회사·학교 계정인지 확인한다. 화면에 보이는 이메일 주소가 같아 보여도 조직 계정과 개인 계정은 별도 계정일 수 있다.

2. 삭제 전 반드시 확인할 8가지

Microsoft가 안내하는 핵심은 '나중에 필요할 자료를 남겨두지 않았는가'를 확인하는 것이다. 다음 항목 중 하나라도 해당하면 폐쇄 버튼을 누르기 전에 정리하자.

  1. Outlook.com·Hotmail 메일: 필요한 이메일, 연락처, 일정, 다른 사이트의 비밀번호 재설정 이메일 수신처를 확인한다.
  2. OneDrive 파일: 사진·문서·업무 파일을 별도 저장장치에 내려받고 파일이 실제로 열리는지 검사한다. 동기화된 파일의 온라인 전용 표시도 점검한다.
  3. BitLocker 복구 키: Windows 장치의 복구 키가 Microsoft 계정에 저장돼 있다면, PC 암호화 복구에 대비해 키를 안전한 별도 위치에 보관한다.
  4. Microsoft 365 구독: Word·Excel·OneDrive 유료 플랜, 구독 갱신일, 구독 공유 중인 가족 구성원의 이용 상태를 확인한다.
  5. Xbox·Microsoft Store 구매: 게임·앱 구매 이력, Xbox 프로필, 게임 진행 상황, 계정 잔액과 포인트의 영향을 확인한다. 개인 Microsoft 계정 간 구매 이력이나 게임 진행률을 단순 이전할 수는 없다.
  6. 다른 사이트 로그인: 'Microsoft로 로그인'을 연동한 외부 서비스 계정의 로그인 수단을 바꾸고, 복구 이메일을 다른 주소로 변경한다.
  7. Windows PC 로그인: 해당 계정이 현재 PC의 유일한 관리자라면, 먼저 계속 사용할 다른 관리자 로그인 수단을 마련한다. 중요한 로컬 파일도 따로 백업한다.
  8. 보안 정보: 휴대전화 번호·복구 이메일로 본인확인 코드를 받을 수 있는지 확인한다. 로그인 정보를 모두 재설정한 상황이면 계정 폐쇄 신청 전 별도 대기기간이 필요할 수 있다.

특히 Outlook 메일함만 없애고 싶은 경우에도 유의해야 한다. Microsoft는 Outlook.com 계정을 영구 폐쇄하려면 연결된 Microsoft 계정 자체를 폐쇄해야 한다고 안내한다. 단순 앱 로그아웃과는 다르다.

3. Microsoft 계정 삭제 신청 방법

개인 계정을 폐쇄하려면 먼저 본인 계정에 로그인할 수 있어야 한다.

  1. Microsoft 공식 '계정 사용 중지' 안내를 연다.
  2. 안내 페이지에서 계정 닫기를 선택해 Microsoft 계정에 로그인한다.
  3. 로그인한 계정의 이메일 주소가 정말 삭제하려는 계정인지 확인한다. PC를 함께 쓰는 경우 타인의 계정인지도 점검한다.
  4. Microsoft가 표시하는 주의사항을 하나씩 읽고 확인란을 체크한다.
  5. 30일 또는 60일의 계정 다시 열기 유예기간을 선택한다.
  6. 계정을 닫는 이유를 선택한다.
  7. 계정을 닫힌 상태로 표시하는 버튼을 눌러 신청을 완료한다.

메뉴의 한국어 번역과 버튼 위치는 바뀔 수 있으므로, 출처가 불명확한 계정 삭제 링크보다 Microsoft 공식 고객지원 페이지에서 시작하는 것이 안전하다.

신청 즉시 모든 데이터가 사라지는가? 폐쇄 신청과 영구 삭제는 같은 시점이 아니다. Microsoft는 선택한 유예기간이 지난 뒤 계정과 관련 콘텐츠가 영구 삭제되는 절차를 안내한다. 그러나 폐쇄 신청 후에는 정상적인 서비스 이용이 제한될 수 있으므로, 유예기간을 평소처럼 이용할 수 있는 '무료 보관 기간'으로 생각해서는 안 된다.

4. 30일과 60일 중 무엇을 선택해야 하나?

선택적합한 상황확인할 점
30일백업과 연동 서비스 변경을 끝냈고 비교적 빨리 폐쇄하려는 경우30일이 지나면 되돌릴 수 없을 수 있다
60일이메일이나 구독·게임 구매 내역을 다시 확인할 가능성이 있는 경우60일 유예기간을 선택해도 구독료 등이 자동으로 보존·환불되는 것은 아니다

Microsoft 고객지원은 30일 또는 60일의 유예기간이 제공된다고 명시한다. 이 기간을 놓치면 해당 계정을 다시 열 수 없을 수 있다. 따라서 Outlook 주소나 OneDrive 파일에 조금이라도 의존한다면 자료를 다른 곳으로 이전하고 복구 수단을 준비한 뒤 진행한다.

5. 마음이 바뀌었다면 닫힌 Microsoft 계정 복구하기

유예기간이 남아 있다면 계정을 다시 열 수 있다.

  1. Microsoft 계정 사이트로 이동한다.
  2. 폐쇄를 신청했던 이메일 주소·계정으로 로그인한다.
  3. 화면에서 본인 확인을 위한 보안 코드를 요청한다.
  4. 이메일이나 휴대전화 등 본인에게 허용된 수단으로 코드를 받아 입력한다.
  5. 재개통이 완료됐는지 확인하고 Outlook·OneDrive·구독 현황을 확인한다.

Microsoft 안내에 따르면 유예기간 안에 계정을 다시 열면 기존 계정에 연결됐던 구독·프로필·콘텐츠에 다시 접근할 수 있다. 다만 중간에 별도로 취소한 구독이나 이미 기간이 끝난 구독을 무조건 되살리는 것은 아니며, 폐쇄 보류 중 지나간 구독 기간도 되돌려주지 않는다.

30일 또는 60일이 지나면? Microsoft는 선택한 기간 후 계정이 영구적으로 삭제돼 다시 열 수 없다고 안내한다. 폐쇄 보류 상태와 서비스 장애를 혼동하지 않으려면 정확한 신청일·선택한 유예기간을 기록해 둔다.

6. 계정을 지우지 않고 Windows 11 로그인만 변경하는 방법

'윈도우에서 Microsoft 계정 삭제'를 검색한 사람 가운데는 실제로 계정을 폐쇄할 필요가 없는 경우가 많다. PC 로그인을 로컬 계정으로 전환하면 개인 Microsoft 계정은 계속 유지할 수 있다.

Windows 11에서 일반적인 경로는 다음과 같다.

  1. 시작 → 설정 → 계정 → 사용자 정보로 이동한다.
  2. 현재 Microsoft 계정으로 로그인했다면 대신 로컬 계정으로 로그인을 선택한다.
  3. 새 로컬 계정 사용자 이름, 비밀번호, 암호 힌트를 설정한다.
  4. 안내에 따라 로그아웃한 뒤 로컬 계정으로 다시 로그인한다.
  5. 이후 OneDrive, Microsoft Store, Office와 같은 앱이 기존 Microsoft 계정에 계속 연결돼 있는지 각 앱에서 확인한다.

전환 전에는 암호화 복구 키, 중요 파일, 로컬 계정 암호 복구 방법을 준비한다. Windows의 일부 설정과 클라우드 동기화 기능에 영향을 줄 수 있다.

주의: 로컬 계정 전환은 Microsoft 계정 폐쇄와 달리, 해당 개인 계정 자체의 Outlook 메일이나 OneDrive 데이터를 삭제하려는 작업이 아니다.

7. Microsoft 365 구독 해지만 하려면

Microsoft 365·OneDrive·Clipchamp 등의 결제만 멈추고 싶다면 계정 폐쇄 대신 구독 설정을 이용한다.

  1. Microsoft 서비스 및 구독에 로그인한다.
  2. 실제 결제하는 계정인지 확인한다.
  3. 원하는 구독에서 관리를 선택한다.
  4. 취소 또는 반복 청구 끄기를 선택해 화면 안내를 따른다.
  5. 다음 결제일, 만료일, 취소 확인 메시지를 직접 확인한다.

구독을 앱 스토어·소매 판매처 등 제3자를 통해 결제했다면 그 판매처에서 청구를 관리해야 할 수 있다. 반복 청구를 끄는 것과 당장 사용권이 끝나는 것은 다르다. 또한 구독을 취소하면 무료 저장공간 한도로 돌아갈 수 있으므로, OneDrive와 Outlook.com 저장 용량을 반드시 먼저 확인한다.

보안 코드를 받지 못한 상태에서 여러 번 계정 삭제를 재신청하거나, 타인에게 원격 접속을 허용해 처리하는 것은 권하지 않는다. 공식 도움말에 따른 본인확인이 우선이다.

9. 자주 묻는 질문

Q1. Microsoft 계정을 삭제하면 Outlook 이메일도 삭제되나요?

그렇다. Microsoft 공식 안내는 Outlook.com 계정을 영구적으로 폐쇄하려면 Microsoft 계정 자체를 닫아야 한다고 설명한다. 계정 폐쇄로 메일·연락처 및 연결된 서비스 접근에 영향을 받으므로 필요한 자료를 먼저 백업한다.

Q2. Microsoft 계정 삭제 후 60일 안에 다시 로그인하면 복구되나요?

폐쇄 신청 때 60일 유예기간을 선택했고 아직 그 기간 안이라면, Microsoft 계정에 로그인해 보안코드를 입력하여 다시 열 수 있다. 30일을 선택했다면 30일 기준으로 판단해야 한다.

Q3. 원드라이브만 삭제하고 계정은 유지할 수 있나요?

OneDrive 파일 정리, 동기화 해제, 구독 취소 등은 Microsoft 계정 폐쇄와 다른 작업이다. 저장공간을 비우는 것이 목표라면 전체 계정을 폐쇄하기 전에 이 방법들을 검토한다.

Q4. Windows 11에서 Microsoft 계정을 제거하면 이메일 계정도 사라지나요?

PC에서 계정을 로컬 계정으로 전환하는 것만으로 Microsoft 개인 계정이 폐쇄되지는 않는다. 다만 장치에서 사용자 프로필을 제거하는 경우 그 프로필과 관련된 로컬 데이터에 영향을 줄 수 있어 작업을 구분해야 한다.

Q5. 회사·학교 Microsoft 계정도 같은 페이지에서 삭제하나요?

아니다. 학교·회사 계정은 소속 조직이 관리하는 계정일 수 있다. 개인 Microsoft 계정 폐쇄 페이지가 아니라 담당 관리자와 먼저 상의해야 한다.

Q6. 계정을 닫으면 Microsoft 365 구독료가 자동 환불되나요?

자동 환불된다고 가정하면 안 된다. 구독 취소와 계정 폐쇄는 별개다. 구독 종류, 구매처, 환불 정책을 확인해 결제 중단 또는 환불을 신청한다.

자주 묻는 질문 (FAQ)

Microsoft 계정 삭제와 Windows 계정 제거는 어떻게 다른가요?

Microsoft 계정 삭제는 Outlook, OneDrive, Xbox 등 연결된 모든 서비스와 데이터를 영구적으로 삭제하는 절차이며, Windows 계정 제거는 PC에서 로그인 계정을 로컬 계정으로 변경하거나 사용자 프로필만 삭제하는 별도의 작업입니다.

Microsoft 계정을 삭제하기 전에 무엇을 확인해야 하나요?

Outlook 메일, OneDrive 파일, BitLocker 복구 키, Microsoft 365 구독, Xbox 구매 내역, 외부 사이트 로그인 연동, Windows PC 관리자 계정 여부, 보안 정보 등을 반드시 확인하고 필요한 데이터는 백업해야 합니다.

삭제한 Microsoft 계정을 다시 복구할 수 있나요?

네, 계정 폐쇄 신청 후 30일 또는 60일의 유예기간 내에는 본인 확인 절차를 거쳐 계정을 다시 열 수 있으나, 유예기간이 지나면 계정과 데이터가 영구 삭제됩니다.
