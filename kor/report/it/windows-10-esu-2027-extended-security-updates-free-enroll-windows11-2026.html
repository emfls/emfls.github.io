윈도우10 지원이 끝났다고 해서 노트북을 당장 버려야 할까요? 2026년 10월 현재 Windows 10을 사용하는 PC에서 '지원 종료' 경고가 뜨고, 인터넷에는 확장 보안 업데이트(ESU)가 2026년 10월 13일에 끝났다는 설명도 남아 있습니다.

2026년 10월 24일 기준 Microsoft의 최신 한국어 공식 발표는 개인용 Windows 10 ESU 프로그램이 2027년 10월 12일까지 연장됐다고 안내합니다. 기존의 2026년 10월 13일 종료 설명은 이전 일정입니다. 다만 이것은 Windows 10의 일반 기술 지원이 되살아났다는 뜻이 아닙니다. Windows 10의 일반 지원은 이미 2025년 10월 14일 종료됐고, ESU에 등록한 적격 PC만 추가적인 긴급·중요 보안 업데이트를 받는 방식입니다.

이 글에서는 내 컴퓨터가 ESU 대상인지, 비용을 추가로 내지 않고 등록할 수 있는지, '지금 등록' 버튼이 안 뜨면 무엇을 확인할지, Windows 11 무료 업그레이드가 가능한지까지 Microsoft 공식 자료를 바탕으로 정리했습니다.

1. 윈도우10 지원 종료일이 2025년인데 왜 2027년까지 업데이트되나요?

Windows 10의 기본적인 지원 종료일과 ESU 종료일을 구분해야 합니다.

① 일반 지원: 2025년 10월 14일 종료

Microsoft는 Windows 10 일반 지원을 2025년 10월 14일 종료했습니다. 따라서 일반적인 Windows 10에는 더 이상 무료 기능 업데이트, 운영체제 보안 수정, 일반 기술 지원이 제공되지 않습니다.

② ESU: 특정 PC에 추가 보안 업데이트 제공

ESU는 Extended Security Updates, 즉 확장 보안 업데이트입니다. Microsoft가 지정한 긴급 및 중요 보안 업데이트를 적격 PC에 제공해 Windows 11로 전환하는 기간의 위험을 줄이는 제도입니다.

ESU를 사용하더라도 Windows 10이 Windows 11처럼 새 기능을 계속 받거나 모든 버그 수정과 기술 지원을 제공받는 것은 아닙니다.

③ 최신 일정: 개인용 ESU는 2027년 10월 12일까지

일부 오래된 Microsoft 영어 페이지나 과거 검색 결과에는 2026년 10월 13일 종료라는 내용이 남아 있습니다. 그러나 Microsoft가 최신으로 게시한 한국어 'Windows 10 확장 보안 업데이트' 페이지와 지원 종료 FAQ는 2027년 10월 12일을 새로운 개인용 ESU 종료일로 명시합니다.

이 날짜는 개인용 소비자 ESU 프로그램의 안내입니다. 회사나 학교가 관리하는 상업용 ESU는 다른 자격·과금·지원 연차가 적용됩니다. 회사 PC에 개인용 무료 등록 방법을 무작정 적용하지 마세요.

2. 내 PC가 무료 또는 유료 ESU에 등록할 수 있는 조건

Microsoft 공식 사이트는 개인용 ESU 등록 전제 조건을 다음과 같이 설명합니다.

  • Windows 10 22H2 버전이며 Home, Professional, Pro Education 또는 Workstations 등의 대상 에디션을 사용하는 PC
  • 필요한 최신 Windows 업데이트가 설치된 상태
  • 등록에 사용할 Microsoft 계정이 관리자 권한을 보유하고 있는 상태
  • 등록 Microsoft 계정이 자녀 계정이 아닌 경우
  • 개인용으로 사용하며, 조직에서 중앙 관리하는 상업용 기기가 아닌 경우

Active Directory 도메인이나 일부 Microsoft Entra·모바일 기기 관리(MDM) 환경에 속한 기기는 개인용 소비자 ESU에 등록할 수 없습니다. 다만 Microsoft는 Entra에 '등록'된 기기는 별도 조건에 따라 대상이 될 수 있다는 예외를 안내하므로, 회사 계정이 보인다는 이유만으로 자격을 단정하지 않아야 합니다.

내 Windows 10 버전 확인법

  1. 키보드에서 Windows 키 + R을 누릅니다.
  2. 실행 창에 winver를 입력합니다.
  3. Windows 정보 창에 표시된 운영체제 이름과 버전을 확인합니다.
  4. Windows 10 버전 22H2인지 확인합니다.
  5. 다른 버전이라면 Windows 업데이트에서 제공되는 업데이트를 확인하고, ESU 적격 여부를 다시 점검합니다.

버전만 22H2라고 해서 모든 PC가 반드시 등록에 성공하는 것은 아닙니다. 업데이트 설치 여부, 관리자 계정 및 관리 정책 등의 조건도 충족해야 합니다.

3. 비용 없이 등록하는 방법과 유료 선택지 비교

Microsoft는 적격 개인용 Windows 10 PC에서 ESU를 등록할 때 세 가지 옵션을 안내합니다.

방법 A. PC 설정 동기화 또는 백업으로 추가 비용 없이 등록

Microsoft 계정으로 Windows 설정을 동기화·백업하는 방식을 선택하면 ESU 등록에 별도의 요금이 청구되지 않는 옵션을 이용할 수 있습니다. 등록 마법사에서 PC 설정 백업과 관련한 안내를 확인하고 진행하세요.

이는 'Microsoft 365 구독을 새로 결제해야 무료'라는 뜻이 아닙니다. Microsoft 공식 ESU 페이지는 PC 설정을 동기화하는 경우 추가 비용 없음이라고 명시합니다.

단, 설정 백업 여부와 사용자 계정·관리자 권한에 따라 등록 화면의 선택지가 달라질 수 있습니다. 무료 옵션이 보이지 않으면 자격 요건과 PC 설정 백업 상태부터 확인하세요.

방법 B. Microsoft Rewards 포인트 1,000점 사용

Microsoft 계정에 보유한 Microsoft Rewards 1,000포인트를 이용하는 경로도 공식적으로 안내됩니다. 사용 가능한 포인트·국가별 정책·계정 조건은 실제 등록 화면을 확인해야 합니다.

방법 C. 한 번 결제하여 등록

Microsoft는 미화 30달러 또는 해당 지역 통화 상당액(세금 별도)의 일회성 구매를 선택지로 제시합니다. 2026년 현재 한국에서 얼마가 청구되는지는 환율·세금·결제 조건에 따라 달라질 수 있으므로 정확한 원화 금액을 임의로 확정하지 않습니다.

세 방법 모두 같은 개인용 ESU 종료일인 2027년 10월 12일까지 보안 업데이트를 받을 수 있는 등록 수단입니다. 더 비싼 옵션이 다른 옵션보다 오래 업데이트되는 방식은 아닙니다.

중요: 이미 유료로 ESU를 등록했다면 이번 연장 때문에 다시 결제할 필요가 있는지 공식 등록 상태를 확인하세요. Microsoft는 기존 등록자의 보장이 자동 연장되며 별도 조치가 필요 없다고 안내합니다.

4. 윈도우10 ESU 신청 방법: 설정에서 '지금 등록' 찾기

다음 절차는 개인용 Windows 10 22H2 PC에 대한 Microsoft의 최신 공식 안내를 기준으로 합니다.

PC에서 등록하기

  1. 컴퓨터의 시작 메뉴에서 설정을 엽니다.
  2. 업데이트 및 보안을 선택합니다.
  3. Windows 업데이트로 들어갑니다.
  4. 사용 가능한 최신 업데이트를 확인해 필요한 항목을 설치합니다.
  5. 적격 PC라면 화면에 표시되는 '지금 등록' 링크를 선택합니다.
  6. 로컬 계정으로 로그인돼 있다면 Microsoft 계정 로그인이 요청될 수 있습니다.
  7. 등록 화면에 나타난 PC 설정 백업·Rewards 1,000포인트·일회성 구매 등의 선택지 중 본인에게 맞는 방식을 고릅니다.
  8. 화면의 안내를 따라 등록을 완료합니다.
  9. 다시 Windows 업데이트 화면에서 ESU 등록 상태를 확인합니다.

PC 설정을 이미 백업했다면 등록 마법사에서 관련 등록 절차로 바로 넘어갈 수 있습니다. 아직 백업하지 않았다면 Windows 설정 백업을 시작할지, Rewards 포인트를 사용할지, 결제를 진행할지 선택하는 안내가 나타날 수 있습니다.

이미 작년에 등록한 사람이라면?

Microsoft는 기존 소비자 ESU 등록자의 보호가 2027년 10월 12일까지 자동으로 연장되며 추가 조치가 필요하지 않다고 명시합니다. 같은 PC에서 다시 등록 비용을 내야 한다고 생각하지 말고 Windows 업데이트 화면의 ESU 등록 상태를 먼저 확인하세요.

여러 컴퓨터에 적용할 수 있나요?

Microsoft 안내에 따르면 한 ESU 등록 라이선스는 최대 10개 장치에 사용할 수 있습니다. 추가 PC도 각각 적격 요건을 충족해야 하며 Windows 업데이트에서 '지금 등록'을 선택한 후 첫 장치 등록에 사용한 Microsoft 계정으로 추가하면 됩니다.

이는 계정 하나로 무조건 모든 PC가 지원 대상이라는 의미는 아닙니다. 각 PC의 버전·업데이트·관리자 권한 및 상업용 관리 상태를 확인해야 합니다.

5. '지금 등록' 버튼이 안 보일 때 해결 순서

Windows 업데이트를 열어도 ESU 등록 링크가 보이지 않으면 무작정 비공식 설치 파일을 검색하거나 레지스트리를 수정하지 마세요. 먼저 공식 전제 조건을 확인하는 것이 우선입니다.

점검 1. Windows 10 버전이 22H2인가요?

Windows 키 + R을 누르고 winver를 입력해 버전을 확인합니다. 소비자 ESU의 기본 대상은 Windows 10 22H2입니다.

점검 2. Windows 업데이트가 최신인가요?

설정 → 업데이트 및 보안 → Windows 업데이트에서 업데이트 확인을 누르고 필요한 업데이트를 설치합니다. Microsoft는 ESU 등록 전에 최신 Windows 업데이트가 필요하다고 안내합니다.

점검 3. Microsoft 관리자 계정을 사용하나요?

ESU는 Microsoft 계정과 등록 라이선스가 연결됩니다. 로컬 Windows 계정을 쓰는 경우에도 등록 단계에서는 Microsoft 계정 로그인이 요구될 수 있습니다. 해당 계정에 관리자 권한이 있는지 확인하고 자녀 계정으로는 등록할 수 없다는 제한도 점검하세요.

점검 4. 회사나 학교가 관리하는 PC인가요?

조직이 관리하는 Active Directory 도메인, 일부 Entra 가입·MDM 등록 기기는 소비자 ESU 대상이 아닙니다. 관리자 정책으로 등록이 막혔을 수 있으므로 회사 PC에서는 IT 담당자에게 상업용 ESU 지원 여부를 문의해야 합니다.

점검 5. 기존에 ESU가 이미 등록돼 있나요?

등록 링크가 보이지 않는 이유가 이미 등록이 완료됐기 때문일 수도 있습니다. Microsoft는 Windows 업데이트 화면에서 ESU 등록 상태를 확인할 수 있다고 안내합니다. 유료 구매를 했다면 Microsoft 계정 주문 내역에서도 확인할 수 있습니다.

위 사항이 충족됐는데도 버튼이 나타나지 않는다면 Windows 업데이트 화면에 표시된 오류 안내, Microsoft 계정 로그인 상태, 제조사 지원 여부를 살펴보세요. 온라인에서 공유되는 임의의 'ESU 우회 툴'이나 불법 활성화 프로그램을 설치하는 행동은 피하는 것이 좋습니다.

6. ESU를 쓰면 Windows 10을 2027년까지 안전하게 계속 쓸 수 있나요?

위험을 줄일 수 있지만 완전한 보안이나 일반 지원을 보장하는 것은 아닙니다. ESU는 Microsoft가 '긴급' 또는 '중요'로 분류하는 보안 업데이트를 적격 PC에 제공하는 제도입니다.

ESU로 받을 수 있는 항목

  • Microsoft의 보안 기준에 따른 긴급·중요 보안 업데이트
  • ESU 적격 기기에서 Windows 업데이트를 통해 제공되는 관련 보호 업데이트
  • Windows 11로 전환하기까지의 한시적 위험 완화

ESU에 포함되지 않는 항목

  • Windows 10의 새로운 기능이나 사용자 화면 개선
  • 일반적인 기능 요청이나 보안과 무관한 개선
  • 일반 Windows 10 기술 지원 전체
  • 모든 타사 프로그램의 보안 문제 해결

따라서 ESU를 등록했다고 해서 기존 운영체제가 최신 Windows 11과 동일한 지원 상태가 된 것은 아닙니다. 장기간 인터넷 뱅킹·업무·학교 과제를 수행하는 PC라면 Windows 11 적합성도 함께 확인하는 것이 좋습니다.

또한 백신 프로그램이 최신 상태라고 해도 운영체제 자체의 보안 업데이트를 대신할 수는 없습니다. Microsoft는 Windows 10의 일반 지원 종료 후 백신만 사용하는 것으로 새로운 위협을 충분히 차단할 수 없다고 경고합니다.

기업·교육기관용 ESU와 날짜가 다른 이유

기업용 Windows 10 ESU는 별도 라이선스 체계에서 최대 3년 동안 제공될 수 있습니다. Microsoft 수명 주기 안내는 상업용 Windows 10 ESU의 3년 차 종료일을 2028년 10월 10일로 제시합니다.

이는 소비자 ESU와 자격, 비용, 기기 관리 방식이 다른 체계입니다. 일반 가정용 Windows 10 PC가 2028년까지 무료 보안 업데이트를 받는다는 뜻이 아닙니다.

7. 윈도우11 무료 업그레이드 가능한지 확인하는 방법

Microsoft는 Windows 11 시스템 요구 사항을 충족하는 Windows 10 PC의 Windows 11 업그레이드가 무료라고 안내합니다. 다만 PC가 호환되는지, 업그레이드가 실제로 제공되는지는 확인해야 합니다.

방법 1. PC 상태 검사 앱

  1. Windows 10 시작 메뉴에서 PC 상태 검사를 검색합니다.
  2. 앱이 설치돼 있다면 실행합니다.
  3. 없다면 Microsoft의 PC 상태 검사 앱 공식 안내에서 다운로드 경로를 확인합니다.
  4. '지금 확인' 또는 Windows 11 적합성 검사를 선택합니다.
  5. Windows 11을 실행할 수 있는지 확인합니다.
  6. 요구 사항을 충족하지 않는다면 표시된 원인을 기록합니다.

Microsoft는 이 앱이 Windows 11 최소 시스템 요구 사항을 충족하는지 종합적으로 평가하고 호환 불가 이유를 보여준다고 설명합니다.

방법 2. Windows 업데이트에서 확인

  1. 설정 → 업데이트 및 보안 → Windows 업데이트로 이동합니다.
  2. 업데이트 확인을 선택합니다.
  3. 'Windows 11 업그레이드 준비' 또는 관련 호환성 안내가 표시되는지 확인합니다.
  4. 실제로 업그레이드가 제공되면 화면의 설치 안내를 따릅니다.

특정 PC는 하드웨어 요구 사항을 충족하더라도 일부 드라이버나 앱 충돌 때문에 배포가 일시 보류될 수 있습니다. Microsoft는 이러한 호환성 보호 보류가 있을 때 문제를 해결할 때까지 업그레이드를 미룰 수 있다고 안내합니다.

따라서 PC 상태 검사에서 지원된다고 나오는데 Windows 업데이트에는 아직 설치 버튼이 없다면 무조건 오류라고 판단하지 마세요.

8. 윈도우11 최소 사양: TPM 2.0·보안 부팅·RAM 확인

Windows 11은 Windows 10이 정상 작동한다는 사실만으로 설치할 수 있는 운영체제가 아닙니다. Microsoft의 공식 최소 사양에는 다음과 같은 항목이 포함됩니다.

항목Windows 11 기본 요구 사항
프로세서호환되는 64비트 프로세서 또는 SoC, 1GHz 이상, 2코어 이상
메모리RAM 4GB 이상
저장 공간64GB 이상의 저장 장치
시스템 펌웨어UEFI 및 보안 부팅 지원
TPMTPM 2.0
그래픽DirectX 12 이상 및 WDDM 2.0 드라이버 호환

초기 설정개인용 Windows 11 Home 및 Pro는 인터넷과 Microsoft 계정이 필요

여기서 흔히 놓치는 부분은 '2코어 이상 CPU면 무조건 된다'가 아니라는 점입니다. Microsoft가 지원하는 CPU 모델과 하드웨어 요구 사항을 모두 충족해야 하므로, 실제 업그레이드 가능 여부는 PC 상태 검사 앱 결과로 확인하는 것이 정확합니다.

TPM 2.0 확인

  1. 키보드의 Windows 키 + R을 누릅니다.
  2. 실행 창에 tpm.msc를 입력합니다.
  3. 신뢰할 수 있는 플랫폼 모듈 관리 화면을 확인합니다.
  4. 사양 버전이 2.0인지 살펴봅니다.

TPM이 보이지 않는다고 실제 하드웨어에 없는 것은 아닐 수 있습니다. Microsoft는 일부 PC에서 TPM 2.0이 지원되지만 펌웨어 설정에서 사용 안 함 상태일 수 있다고 설명합니다.

보안 부팅 확인

  1. Windows 키 + R을 누릅니다.
  2. msinfo32를 입력해 시스템 정보를 엽니다.
  3. BIOS 모드가 UEFI인지 확인합니다.
  4. 보안 부팅 상태를 확인합니다.

Microsoft는 보안 부팅이 UEFI 펌웨어 설정과 관련된 기능이라고 안내합니다. BIOS·UEFI 설정을 바꿔야 한다면 PC 제조사의 공식 안내를 확인하세요.

중요: TPM 초기화나 부팅 모드 변경, BIOS 설정 임의 수정은 BitLocker 암호화·부팅에 영향을 줄 수 있습니다. 복구 키를 확보하지 않은 상태에서 TPM을 지우거나 저장 장치 파티션을 변환하는 작업을 따라 하는 것은 위험합니다. 이 글에서는 데이터 손실 가능성이 있는 우회 절차를 권장하지 않습니다.

9. 윈도우11 업그레이드 전에 반드시 백업할 데이터

호환되는 PC라면 일반적인 Windows 11 업그레이드 경로를 검토할 수 있습니다. 하지만 업그레이드 가능하다는 사실과 데이터가 반드시 완벽하게 보존된다는 보장은 다릅니다.

우선 보존할 파일

  • 바탕화면·문서·다운로드·사진 폴더의 중요한 파일
  • 업무용 프로젝트, 회계·세금 자료, 학교 과제와 개인 기록
  • 브라우저 즐겨찾기와 중요한 로그인·복구 정보
  • 외부 프로그램에서만 접근 가능한 로컬 메일·계정 설정
  • 유료 프로그램의 라이선스 정보나 설정 파일
  • BitLocker 등 암호화 사용 시 필요한 복구 키

가능하다면 별도 외장 저장장치 또는 신뢰할 수 있는 클라우드에 중요 파일의 독립적인 사본을 두고 실제로 열리는지 확인하세요. 단순히 OneDrive 앱을 설치해 두었다는 이유만으로 모든 로컬 파일이 백업됐다고 생각하면 안 됩니다.

Windows 백업과 ESU의 무료 등록 연결

Microsoft의 소비자 ESU 안내는 Windows 설정 동기화·백업을 통해 추가 비용 없이 등록하는 방법을 제공합니다. 이 과정에서 Microsoft 계정에 PC 설정이 동기화될 수 있지만, ESU 무료 등록에 사용하는 PC 설정 백업이 모든 파일의 완전한 백업과 동일한 뜻은 아닙니다.

즉 무료 ESU 등록을 완료한 뒤에도 중요 사진·문서·동영상의 실제 저장 위치와 별도 복사본을 확인해야 합니다.

업그레이드 도중 갑자기 전원을 끄지 마세요

노트북은 전원 어댑터를 연결하고, 디스크 여유 공간과 네트워크 상태를 확인한 뒤 Windows 업데이트에서 제공하는 정상 업그레이드 절차를 따르세요. 업무용 PC라면 보안 프로그램과 필수 앱의 호환성을 IT 담당자에게 확인하는 것도 좋습니다.

10. 윈도우11로 업그레이드할 수 없는 PC라면?

Windows 11 PC 상태 검사에서 지원되지 않는다고 나올 수 있습니다. 이런 경우에는 무조건 새 PC를 바로 구매하거나, 비공식 설치 우회를 진행하는 것보다 다음 선택지를 비교하세요.

선택 A. 개인용 ESU에 등록해 전환 시간을 확보

Windows 10 22H2와 Microsoft 계정 등 조건을 충족한다면 ESU를 등록해 2027년 10월 12일까지 중요 보안 업데이트를 받을 수 있습니다.

이 방법은 기존 프로그램과 PC 사용 환경을 유지하면서 전환을 준비할 시간을 확보하는 데 도움이 됩니다. 하지만 ESU가 모든 기술 지원을 제공하는 것은 아니므로 장기 대안은 아닙니다.

선택 B. TPM 또는 보안 부팅을 지원하지만 꺼져 있는지 확인

일부 PC는 실제 하드웨어가 요구 사항을 충족하지만 TPM·UEFI 등의 설정이 비활성화돼 있을 수 있습니다. Microsoft의 PC 상태 검사 앱과 공식 TPM·보안 부팅 도움말을 참고해 제조사에 설정 변경 가능 여부를 문의하세요.

복구 키 확보 없이 TPM 초기화·보안 부팅 변경을 무작정 실행하지 마세요. PC가 잠기거나 부팅되지 않는 상황이 발생할 수 있습니다.

선택 C. 운영체제를 지원하는 PC로 교체

하드웨어가 지원 대상이 아니고 장기간 사용해야 하는 개인·업무용 PC라면 Windows 11을 정식으로 지원하는 장치로 교체하는 방안도 고려할 수 있습니다. 비용은 기기별로 다르므로 무조건 가장 저렴한 장치가 모든 업무에 맞는다고 볼 수 없습니다.

선택 D. 다른 운영체제 전환 검토

용도와 필수 프로그램에 따라 다른 운영체제로 이동하는 선택도 가능할 수 있습니다. 다만 학교 프로그램, 금융 사이트, 게임, 프린터·스캐너 드라이버 등의 호환성이 달라질 수 있으므로 실제 필요한 프로그램을 먼저 확인해야 합니다.

11. ESU 등록 중 비용을 아끼려다 피해야 할 실수

무료 등록 자격이 있는데 먼저 유료 결제하기

Microsoft는 PC 설정 동기화를 통한 추가 비용 없는 ESU 등록을 안내합니다. 등록 마법사에 무료 옵션이 있는지 확인한 뒤 필요할 때만 포인트나 구매 옵션을 선택하세요.

오래된 블로그의 '2026년 10월 종료'만 믿기

Microsoft의 최신 개인용 ESU 종료일은 2027년 10월 12일입니다. 검색 결과의 날짜가 오래됐다면 Microsoft 공식 소비자 ESU 페이지에서 변경 내용을 확인하세요.

ESU가 Windows 10 일반 지원을 부활시킨 것으로 오해하기

ESU는 긴급·중요 보안 업데이트를 제공할 뿐 Windows 10에 새 기능이나 일반 기술 지원을 모두 되돌려 주는 제도가 아닙니다.

회사에서 쓰는 PC를 개인 Microsoft 계정으로 등록 시도하기

회사·학교가 관리하는 PC는 상업용 ESU 정책을 따라야 할 수 있습니다. 업무 장비에 개인 계정을 임의로 연결하기 전에 관리자에게 문의하세요.

등록을 했으니 백신과 백업은 필요 없다고 생각하기

ESU는 중요한 보안 위험을 줄이는 업데이트 프로그램입니다. 피싱 사이트·악성 첨부파일·파일 삭제·기기 고장까지 해결하는 것이 아닙니다. 정기적인 데이터 백업과 기본 보안 습관은 여전히 필요합니다.

Windows 11 비공식 우회 설치 파일 받기

TPM 및 지원 CPU 조건을 무시하도록 유도하는 비공식 도구는 지원되지 않는 설치 상태나 보안 문제를 야기할 수 있습니다. Microsoft가 공식적으로 제공하는 업그레이드 경로와 제조사 안내를 우선 확인하세요.

자주 묻는 질문 FAQ

Q1. 윈도우10은 2026년 10월에 완전히 지원 종료됐나요?

Q2. 2026년에 윈도우10 ESU를 새로 신청할 수 있나요?
