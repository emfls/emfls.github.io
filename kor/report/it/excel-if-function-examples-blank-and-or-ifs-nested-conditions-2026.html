엑셀에서 점수에 따라 합격·불합격을 자동으로 표시하거나, 판매액에 따라 수당을 계산하고, 입력하지 않은 셀에는 '미입력'을 나타내고 싶을 때 가장 먼저 배울 함수가 IF 함수입니다. IF는 조건에 따라 두 결과 중 하나를 선택합니다. 단, 여러 조건을 섞거나 빈칸·문자·숫자를 잘못 처리하면 예상과 다른 결과가 나올 수 있습니다.

이 글에서는 실제 업무에 바로 적용할 수 있도록 IF 기본 수식 → 실무 예제 7개 → AND·OR → 중첩 IF와 IFS → 빈칸·오류 처리 → 자주 틀리는 부분 순서로 설명합니다. 모든 예제는 원본 데이터 열과 결과 열을 구분해, 직접 엑셀에 입력해 볼 수 있도록 작성했습니다.

검토 기준: 2026년 11월 4일. Microsoft 365·Excel 2024·Excel 2021 등 버전에 따라 일부 함수의 지원 범위가 다를 수 있습니다.

1. 엑셀 IF 함수 기본 형식

IF 함수의 기본 구조는 다음과 같습니다.

=IF(조건, 참일_때_결과, 거짓일_때_결과)

Microsoft 공식 문서의 함수 원형은 IF(logical_test, value_if_true, [value_if_false])입니다. 조건이 TRUE면 두 번째 인수, FALSE면 세 번째 인수에 해당하는 결과를 반환합니다. 세 번째 인수는 선택 사항이지만, 예상치 못한 결과를 줄이려면 명시적으로 입력하는 편이 읽기 쉽습니다.

예를 들어 B2에 시험 점수가 있을 때 60점 이상은 합격, 미만은 불합격이라고 표시하려면:

=IF(B2>=60,"합격","불합격")
  • B2 = 85라면 합격
  • B2 = 60이라면 합격
  • B2 = 59라면 불합격

문자 결과는 큰따옴표로 감싸지만, 숫자 결과는 보통 큰따옴표 없이 입력합니다. "100"은 텍스트, 100은 숫자여서 후속 계산에 영향을 줄 수 있습니다.

2. 가장 많이 사용하는 비교 연산자 6개

연산자의미IF 조건의 예
=같다A2="완료"
<>같지 않다A2<>"완료"
>크다B2>100
>=크거나 같다B2>=100
<작다B2<100
<=작거나 같다B2<=100

주의: 시험의 합격 기준이 60점 이상이라면 >60이 아니라 >=60입니다. 이 차이로 정확히 60점인 사람을 불합격 처리하는 오류가 발생할 수 있습니다.

3. 예제 ① 합격·불합격 자동 표시

표의 A열은 이름, B열은 점수, C열은 결과라고 가정합니다.

A열B열C열 수식 결과
김하늘85합격
이도윤59불합격
박서아60합격

C2에 아래 수식을 입력합니다.

=IF(B2>=60,"합격","불합격")

C2의 수식 입력을 완료한 뒤 셀 오른쪽 아래의 채우기 핸들을 드래그하거나 더블클릭하면, C3에서는 B3, C4에서는 B4처럼 행 참조가 자동 변경됩니다. 여러 사람의 점수를 반복 계산할 때 유용합니다.

60점 미만은 빨간색으로 표시하고 싶다면?

IF 함수는 값을 계산하는 함수이지, 셀의 글자색을 직접 바꾸는 함수는 아닙니다. 색을 바꾸려면 엑셀의 홈 → 조건부 서식에서 '불합격' 셀을 강조하는 별도 규칙을 만드세요.

4. 예제 ② 빈칸이면 '미입력', 점수가 있으면 합격 여부 표시

가장 흔한 실수는 빈칸을 숫자 0처럼 판정하여 아직 입력하지 않은 사람까지 불합격 처리하는 것입니다. 입력 여부부터 분기하면 이런 오류를 피할 수 있습니다.

=IF(B2="","미입력",IF(B2>=60,"합격","불합격"))

읽는 순서는 다음과 같습니다.

  1. B2="": 빈칸이면 미입력
  2. 빈칸이 아니고 B2>=60: 합격
  3. 둘 다 아니면 불합격

빈칸에는 아무 글자도 표시하지 않으려면 아래처럼 작성합니다.

=IF(B2="","",IF(B2>=60,"합격","불합격"))

여기서 ""는 빈 문자열입니다. 수식이 들어간 셀이 정말 빈 셀이 되는 것은 아니므로, 나중에 데이터 수나 빈 셀 수를 계산할 때 차이가 생길 수 있다는 점을 알아두세요.

또한 점수 열에 글자가 잘못 입력되어도 수식이 의도와 달리 동작할 수 있습니다. 실제 업무용 표라면 데이터 → 데이터 유효성 검사로 점수 입력 범위를 제한하는 방법이 더 안전합니다.

5. 예제 ③ 숫자로 결과 반환하기: 성과급 계산

A2에 매출액이 입력되어 있고 매출 100만 원 이상이면 5만 원, 그렇지 않으면 0원을 지급한다면:

=IF(A2>=1000000,50000,0)

이 수식의 반환값은 숫자입니다. 다른 셀에서 합계·평균 계산을 할 때도 사용할 수 있습니다.

반면 다음처럼 값을 큰따옴표로 감싸면 문자열 결과가 됩니다.

=IF(A2>=1000000,"50000","0")

겉으로 숫자처럼 보여도 계산에서 혼동이 생길 수 있으므로, 후속 산술 계산이 필요한 결과에는 숫자를 반환하도록 만드는 것이 권장됩니다.

목표액을 다른 셀에서 관리할 때

E1에 '1000000'이라는 목표액이 있다면 다음처럼 고정 참조를 사용합니다.

=IF(A2>=$E$1,50000,0)

$E$1은 수식을 아래로 복사하더라도 목표액 셀을 바꾸지 않는 절대 참조입니다. 목표액이 매달 달라진다면 E1 값만 변경하면 됩니다.

6. 예제 ④ AND 함수: 두 조건 모두 만족해야 통과

필기 점수 B2가 60점 이상이고 면접 점수 C2도 80점 이상이어야 한다면 AND를 사용합니다.

=IF(AND(B2>=60,C2>=80),"최종합격","불합격")
  • 필기 70점, 면접 90점 → 최종합격
  • 필기 70점, 면접 79점 → 불합격
  • 필기 59점, 면접 95점 → 불합격

AND는 지정된 조건이 모두 TRUE일 때만 TRUE를 반환합니다. 어느 하나라도 기준을 충족하지 않으면 IF의 거짓 결과가 반환됩니다.

잘못된 예 =IF(B2>=60,C2>=80,"합격","불합격")는 IF 함수에 필요한 인수 구조가 맞지 않습니다. 여러 논리 조건은 AND(...)로 묶어 전달해야 합니다.

7. 예제 ⑤ OR 함수: 조건 하나만 충족하면 혜택 적용

회원 등급 B2가 VIP이거나 주문 금액 C2가 10만 원 이상이면 혜택을 지급한다고 가정합니다.

=IF(OR(B2="VIP",C2>=100000),"혜택","일반")
  • VIP / 주문 30,000원 → 혜택
  • 일반 / 주문 150,000원 → 혜택
  • 일반 / 주문 50,000원 → 일반

OR은 조건 하나 이상이 TRUE면 TRUE를 반환합니다. 따라서 AND와 OR를 잘못 바꾸면 혜택 대상자가 완전히 달라질 수 있습니다.

8. 예제 ⑥ 중첩 IF: A·B·C·D 학점 표시

한 번의 IF는 두 갈래로 분기합니다. 학점처럼 세 갈래 이상 구분하려면 IF 함수 안에 IF 함수를 넣는 중첩 IF를 사용할 수 있습니다.

B2의 점수를 다음 기준으로 평가한다고 가정합니다.

점수학점
90점 이상A
80~89점B
70~79점C
70점 미만D
=IF(B2>=90,"A",IF(B2>=80,"B",IF(B2>=70,"C","D")))

큰 기준부터 작은 기준 순서로 검사하는 것이 핵심입니다. 예컨대 B2>=70을 맨 앞에 놓으면 95점도 70점 조건을 먼저 통과하여 C가 될 수 있습니다.

예제 결과:

  • B2 = 95 → A
  • B2 = 82 → B
  • B2 = 74 → C
  • B2 = 61 → D

Microsoft는 IF 함수의 과도한 중첩이 수식 오류와 유지 관리 문제를 일으킬 수 있다고 안내합니다. 조건이 많아지면 아래 IFS 함수가 더 읽기 쉬울 수 있습니다.

9. 예제 ⑦ IFS 함수: 중첩 IF를 간단히 쓰기

같은 학점 기준을 IFS로 쓰면 다음과 같습니다.

=IFS(B2>=90,"A",B2>=80,"B",B2>=70,"C",TRUE,"D")

IFS는 조건을 차례대로 검사하고 처음 TRUE가 된 조건에 해당하는 결과를 반환합니다. 마지막의 TRUE,"D"는 위 조건을 하나도 충족하지 않는 나머지 경우에 D를 표시하기 위한 기본값 역할을 합니다.

지원 버전: Microsoft 공식 문서에서는 Microsoft 365 및 Excel 2019 이상 계열에서 IFS 지원을 안내합니다. 오래된 버전에서는 함수를 인식하지 못할 수 있으므로 사용하는 엑셀 버전부터 확인하세요.

중요한 차이: IFS에서 마지막 기본 조건 없이 모든 조건이 거짓이면 #N/A 오류가 나타날 수 있습니다. TRUE 조건을 마지막에 추가하면 의도된 기본값을 처리할 수 있습니다.

10. IF와 IFERROR·SUMIF·COUNTIF의 차이

이름이 비슷하지만 기능은 다릅니다.

함수하는 일적합한 사례
IF조건에 따라 결과를 두 갈래로 선택합격/불합격, 수당 지급
IFS여러 조건을 순서대로 평가4단계 등급 분류
IFERROR수식 결과에 오류가 있을 때 대체값 반환#DIV/0!, #N/A 등 오류 처리
SUMIF조건에 맞는 값의 합계를 계산특정 부서 매출 총합
COUNTIF조건에 맞는 셀 수를 계산합격자 수 세기

IF가 합격 여부를 표시한다고 해서 합격자 수까지 직접 세는 함수는 아닙니다. 합격자 수를 구하려면 결과 범위에 COUNTIF 등을 사용할 수 있습니다.

=COUNTIF(C2:C101,"합격")

IFERROR와 IF는 같은 함수가 아닙니다. 예를 들어 A2를 B2로 나눌 때 0으로 나누는 오류를 처리하려면:

=IFERROR(A2/B2,"확인 필요")

하지만 IFERROR는 의도치 않은 오류도 숨길 수 있습니다. 수식의 오류 원인을 먼저 확인한 뒤, 사용자에게 대체 메시지를 보여줘야 하는 경우에만 적용하는 것이 좋습니다.

11. IF 함수가 안 될 때 가장 흔한 오류 6가지

① 텍스트 결과에 큰따옴표를 넣지 않음

잘못된 예:

=IF(B2>=60,합격,불합격)

올바른 예:

=IF(B2>=60,"합격","불합격")

문자열을 큰따옴표로 감싸지 않으면 엑셀이 이름 또는 정의된 범위로 해석하려고 하며 #NAME? 등의 오류가 생길 수 있습니다.

② 60점 이상을 >60으로 작성함

>60은 60을 제외하고, >=60은 60을 포함합니다. 경계값을 정확히 정하세요.

③ 조건이 길어져 닫는 괄호가 빠짐

중첩 IF를 작성하면 열리는 괄호와 닫히는 괄호의 수가 맞아야 합니다. 먼저 IF 한 단계씩 정상 작동하는지 확인한 후 다음 조건을 추가하세요.

④ 숫자인 줄 알았는데 텍스트로 저장됨

수식이 예상과 다르게 평가될 경우 셀의 형식을 확인하세요. 외부 시스템에서 붙여 넣은 값에는 공백이나 숫자처럼 보이는 텍스트가 섞일 수 있습니다. 서식만 숫자로 바꿨다고 이미 입력된 모든 텍스트 숫자가 자동 변환되는 것은 아닙니다.

⑤ 결과 셀에 수식이 아니라 수식 문자가 그대로 표시됨

셀 표시 형식이 텍스트이거나 수식 표시 기능이 활성화되어 있을 수 있습니다. 먼저 `Ctrl+`` 단축키(수식 표시 토글)나 수식 → 수식 표시를 확인하고, 셀 형식을 일반으로 바꾼 뒤 필요한 경우 수식을 다시 입력하세요.

⑥ 빈칸을 구분하지 않아 미입력 행이 불합격 처리됨

처음부터 =IF(B2="","미입력",IF(...))처럼 입력 여부 검사를 앞에 추가하세요. 단, 0점이 실제 유효한 점수라면 빈칸과 0을 다른 값으로 다뤄야 합니다.

12. 실무에서 바로 복사해 쓰는 IF 함수 6개

상황복사할 수식
합격·불합격=IF(B2>=60,"합격","불합격")
빈칸이면 미입력=IF(B2="","미입력",IF(B2>=60,"합격","불합격"))
재고 10개 미만 경고=IF(C2<10,"발주 필요","정상")
목표 매출 달성 여부=IF(B2>=$E$1,"달성","미달성")
두 조건 모두 충족=IF(AND(B2>=60,C2>=80),"합격","불합격")
VIP 또는 구매액 조건=IF(OR(B2="VIP",C2>=100000),"혜택","일반")

표의 셀 주소는 예시 데이터 구조를 기준으로 하므로 실제 파일의 열 위치에 맞게 수정해야 합니다. $E$1은 비교 기준을 한 셀에서 고정하려는 경우에 사용하는 절대 참조입니다.

자주 묻는 질문(FAQ)

Q. 엑셀 IF 함수에서 빈칸이면 공백으로 표시하려면?

=IF(A2="","",IF(A2>=60,"합격","불합격"))처럼 빈 문자열 ""을 결과에 사용하세요. 다만 수식이 입력된 셀은 실제로 완전히 비어 있는 셀과 구분될 수 있습니다.

Q. 엑셀 IF 조건을 3개 이상 설정하려면?

중첩 IF 또는 IFS를 사용합니다. 하나의 판단에서 조건을 모두 충족해야 한다면 AND, 하나 이상 만족하면 된다면 OR을 IF의 논리식에 사용할 수 있습니다.

Q. IF 함수로 글자색도 바꿀 수 있나요?

IF는 결과 값 반환이 목적입니다. 색상은 조건부 서식을 사용하세요. IF 결과를 기준으로 규칙을 만들 수도 있습니다.

Q. IF 함수와 SUMIF 함수 차이는?

IF는 조건 분기, SUMIF는 조건에 맞는 숫자의 합계입니다. 매출의 합계가 필요하다면 SUMIF, 개별 직원의 목표 달성 판정이 필요하다면 IF가 알맞습니다.

Q. IFS 함수에서 #N/A가 나타납니다.

모든 조건이 거짓인데 기본값을 정하지 않았을 수 있습니다. =IFS(조건1,결과1,조건2,결과2,TRUE,"기타")처럼 마지막에 기본 분기를 설정해 보세요. 단, 수식 안의 참조 자체에 오류가 있다면 그것도 별도로 확인해야 합니다.

핵심 요약

엑셀 IF 함수는 =IF(조건,참일때,거짓일때) 형태로 시작합니다. 처음에는 합격·불합격처럼 단순한 조건으로 익힌 뒤, 빈칸 체크와 AND·OR를 추가하세요. 등급이 여러 개일 때는 중첩 IF 또는 IFS를 검토하고, 수식 오류는 무조건 숨기지 말고 먼저 원인을 확인해야 합니다.
