아이폰 화면을 잠깐 내려놓기만 해도 30초 만에 꺼지거나, 반대로 화면이 계속 켜져 있어 배터리가 빨리 닳는다면 자동 잠금 설정부터 확인하세요. 아이폰에서 자동 잠금 시간은 보통 설정 → 디스플레이 및 밝기 → 자동 잠금에서 변경할 수 있습니다. 그러나 저전력 모드가 켜져 있으면 자동 잠금이 30초로 설정될 수 있어, 시간을 바꾸려 해도 뜻대로 되지 않을 수 있습니다.

또한 화면이 어두워지는 현상, 잠금 화면에 시계만 남는 화면 상시표시, 잠금 해제된 상태로 계속 켜져 있는 현상은 같은 문제가 아닙니다. 증상을 먼저 구분하면 불필요하게 모든 설정을 초기화하는 일을 줄일 수 있습니다.

이 글은 2026년 11월 4일 기준 Apple의 iPhone 공식 지원 문서를 대조해 작성했습니다. 기종·iOS 버전·회사 관리 정책에 따라 일부 메뉴 또는 선택 가능한 시간은 다를 수 있습니다.

1. 10초 요약: 증상에 따라 먼저 열어볼 곳

증상가장 먼저 확인할 곳핵심
화면이 너무 빨리 꺼짐디스플레이 및 밝기 → 자동 잠금원하는 시간 선택
자동 잠금이 30초로 고정배터리 → 저전력 모드저전력 모드 상태 확인
자동 잠금 시간이 회색으로 보임저전력 모드, 관리 제한 여부원인부터 구분
화면은 잠겼는데 시계가 계속 표시됨디스플레이 및 밝기 → 화면 상시표시지원 모델에서 별도 기능
화면을 바라볼 때 잘 안 꺼짐Face ID 및 암호 → 주시 지각 기능시선 감지로 화면 유지 가능
특정 앱에서만 화면이 계속 켜짐해당 앱·전체 화면·재생 상태앱별 작동 차이 확인

먼저 구분할 것: 화면이 잠긴 뒤 흐릿하게 시계가 보이는지, 아니면 실제 앱을 계속 조작할 수 있는 상태로 유지되는지를 확인하세요. 전자는 화면 상시표시, 후자는 자동 잠금 동작과 더 관련이 있을 수 있습니다.

2. 아이폰 자동 잠금 시간 변경 방법

Apple 공식 안내에 따른 경로는 다음과 같습니다.

  1. 아이폰에서 설정 앱을 엽니다.
  2. 디스플레이 및 밝기를 선택합니다.
  3. 자동 잠금을 누릅니다.
  4. 화면에 표시된 시간 중 원하는 시간을 선택합니다.
  5. 설정을 종료한 뒤 홈 화면에서 손을 떼고 실제 잠금까지 걸리는 시간을 시험합니다.

일부 기기에서는 30초, 1분, 2분, 3분, 4분, 5분, 안 함 등의 선택지가 표시될 수 있습니다. 이는 예시이며 실제 기기에 보이는 옵션을 기준으로 선택하세요.

1분·2분·5분 중 무엇을 고를까?

  • 30초~1분: 자리를 자주 비우거나 배터리를 아끼고 싶을 때 고려할 수 있습니다.
  • 2~3분: 메모나 자료를 읽다가 잠시 터치하지 않는 경우에 중간 선택이 될 수 있습니다.
  • 5분 이상: 레시피·설명서처럼 손을 쓰면서 화면을 오래 참고할 때 편할 수 있습니다.
  • 안 함: 지원되는 경우 화면이 자동으로 잠기지 않도록 설정합니다. 공공장소나 공유 공간에서는 주의하세요.

화면을 오래 켜두면 전력 소비가 늘고, 잠금이 늦어지면 기기에 표시된 개인 정보가 타인에게 노출될 가능성도 커집니다. Apple도 자동 잠금을 지연하거나 사용하지 않도록 하면 전력 소비가 늘 수 있다고 설명합니다.

3. 아이폰 자동 잠금이 30초로 고정되는 가장 흔한 이유

저전력 모드(Low Power Mode)는 배터리 사용 시간을 늘리기 위해 여러 기능의 전력 소비를 줄입니다. Apple의 공식 지원 문서에 따르면 저전력 모드에서 자동 잠금이 30초로 설정됩니다.

따라서 30초가 계속 선택되거나 다른 시간으로 바꿔도 유지되지 않는 상황에서는 가장 먼저 저전력 모드가 켜져 있는지 확인하세요.

아이폰 15 이후 모델

  1. 설정 → 배터리를 엽니다.
  2. 전력 모드로 들어갑니다.
  3. 저전력 모드가 켜져 있으면 상태를 확인합니다.
  4. 배터리 사용 시간에 여유가 있다면 잠시 꺼 둔 뒤 디스플레이 및 밝기 → 자동 잠금으로 돌아가 선택이 가능한지 확인합니다.

아이폰 14 이전 모델

  1. 설정 → 배터리로 이동합니다.
  2. 저전력 모드가 켜져 있는지 확인합니다.
  3. 필요하다면 잠시 끄고 자동 잠금 시간을 다시 확인합니다.

참고: 지원되는 기종에서는 제어 센터에도 저전력 모드 버튼을 추가할 수 있습니다. 저전력 모드가 켜졌을 때는 상태 막대의 배터리 아이콘이 노란색으로 보일 수 있습니다.

30초 고정이면 무조건 고장일까?

아닙니다. 배터리 절약 설정으로 발생할 수 있는 정상적인 동작부터 확인해야 합니다. 반대로 저전력 모드를 껐는데도 설정이 회색으로 남아 있다면 다른 제한이나 시스템 상태를 점검해야 합니다. 원인 확인 없이 기기를 공장 초기화할 필요는 없습니다.

4. '자동 잠금' 메뉴가 회색으로 눌리지 않을 때

자동 잠금 항목을 눌러도 선택이 안 된다면 다음 순서로 확인하는 편이 안전합니다.

  1. 저전력 모드가 켜져 있는지 확인합니다.
  2. 저전력 모드를 껐는데도 회색이라면 아이폰을 재시동하고 다시 확인합니다.
  3. 설정 → 일반 → VPN 및 기기 관리 등에서 회사·학교가 설치한 관리 프로파일이 있는지 확인합니다. 기기나 iOS 버전에 따라 해당 항목의 표시가 달라질 수 있습니다.
  4. 회사·학교 관리 기기라면 관리자가 일부 설정을 제한하는지 IT 관리자에게 문의합니다.
  5. 개인 소유 기기이며 제한 원인을 찾지 못했다면 iOS 업데이트 가능 여부를 확인하고 Apple 지원을 통해 추가 점검합니다.

중요: 관리 프로파일이 있다는 이유만으로 그것이 자동 잠금 회색 버튼의 원인이라고 확정할 수는 없습니다. 또한 업무용·학교용 기기의 프로파일을 임의로 삭제하면 이메일·VPN·인증서 및 접근 권한에 문제가 생길 수 있습니다.

5. 화면이 계속 켜져 있는데 자동 잠금 설정이 문제일까?

아이폰에서는 다음 세 상황을 구분하는 것이 좋습니다.

① 홈 화면과 앱 화면이 계속 켜져 있음

먼저 자동 잠금 시간을 '안 함'으로 설정했는지 확인하세요. 잠금 시간이 설정되어 있다면, 특정 앱에서만 문제가 나타나는지 홈 화면과 비교합니다.

지도 내비게이션, 영상 재생, 일부 특정 앱은 사용 중 화면 동작이 다르게 보일 수 있습니다. 앱의 동작을 바로 운영체제 고장으로 판단하기보다는, 홈 화면에 나온 뒤 입력하지 않은 상태에서 다시 테스트하세요.

② 잠긴 화면에 시계와 알림만 어둡게 표시됨

이는 지원 기기의 화면 상시표시(Always-On Display) 기능일 수 있습니다. 자동 잠금이 실행됐더라도 잠금 화면의 일부 정보를 어둡게 표시하는 별도 기능입니다.

화면 상시표시를 끄려면 지원 모델에서 다음과 같이 설정합니다.

  1. 설정 → 디스플레이 및 밝기를 엽니다.
  2. 화면 상시표시 메뉴가 있는지 확인합니다.
  3. 해당 기능을 끄면 잠금 화면이 계속 어둡게 표시되는 동작을 변경할 수 있습니다.

이 메뉴가 없다면 기기가 해당 기능을 지원하지 않을 수 있습니다. Apple은 화면 상시표시가 켜져 있어도 휴대전화를 뒤집어 두거나 저전력 모드·수면 집중 모드가 활성화된 상황 등에서는 화면이 자동으로 꺼질 수 있다고 설명합니다.

③ 사용자가 화면을 보고 있을 때만 잘 안 꺼짐

Face ID용 TrueDepth 카메라가 있는 지원 iPhone에서는 주시 지각 기능(Attention Aware Features)이 사용자의 주시 여부를 감지해, 화면을 보고 있는 동안 디스플레이가 어두워지지 않도록 동작할 수 있습니다.

문제를 비교하기 위해 설정 → Face ID 및 암호 → 주시 지각 기능의 상태를 확인하세요. 다만 개인의 편의와 사용 습관에 맞게 선택할 기능이며, 반드시 꺼야 한다는 뜻은 아닙니다.

6. 화면이 너무 빨리 어두워질 때 확인할 3가지

화면이 어두워지는 것과 화면이 잠기는 것은 별개의 단계일 수 있습니다.

  • 자동 잠금 시간: 실제로 기기가 잠기기 전까지의 시간 설정입니다.
  • 저전력 모드: 디스플레이 밝기를 낮추고 자동 잠금을 30초로 조정할 수 있습니다.
  • 주시 지각 기능: 지원되는 기기에서 화면을 바라보는 동안 화면을 계속 밝게 유지하는 데 영향을 줄 수 있습니다.

밝기만 낮아지고 터치하면 정상으로 돌아오는 경우, 곧바로 잠금 기능 고장이라고 단정하지 마세요. 다른 문제인 발열·자동 밝기 조절·화면 표시 문제도 가능하므로 실제로 잠금 화면으로 넘어가는지 관찰하는 것이 중요합니다.

7. 30초 고정·화면 안 꺼짐을 구분하는 5분 점검 절차

다음은 실제로 어느 설정이 영향을 주는지 구분하는 간단한 테스트입니다.

1단계 — 현재 상태 기록

  • 자동 잠금이 30초·1분·안 함 중 무엇으로 설정됐는지 확인합니다.
  • 저전력 모드가 켜져 있는지, 배터리 아이콘 색상이 노란색인지 봅니다.
  • 화면 상시표시 지원 기기인지 확인합니다.

2단계 — 저전력 모드 확인

  • 배터리 절약이 꼭 필요한 상황이 아니라면 저전력 모드를 잠시 꺼 봅니다.
  • 자동 잠금 메뉴에서 다른 시간을 선택할 수 있는지 확인합니다.

3단계 — 홈 화면에서 비교

  • 게임·지도·영상 앱을 종료하거나 홈 화면으로 나옵니다.
  • 화면을 만지지 않고 일정 시간 관찰합니다.
  • 화면이 어두워지는 것과 실제로 잠금 상태가 되는 것을 구분합니다.

4단계 — 주시 여부 비교

  • 주시 지각 기능이 있는 모델이라면 정면을 바라볼 때와 내려놓았을 때의 동작을 비교합니다.
  • Face ID 암호 설정을 임의로 지울 필요는 없습니다.

5단계 — 여전히 해결되지 않을 때

  • 중요한 작업을 저장한 뒤 아이폰을 재시동합니다.
  • iOS 업데이트를 확인하고, 관리 기기라면 관리자에게 문의합니다.
  • 변화가 없다면 Apple 지원에 기종, iOS 버전, 선택된 자동 잠금 시간, 저전력 모드 상태를 알려 정확히 상담받습니다.

8. '자동 잠금 안 함' 설정은 안전할까?

안 함을 선택할 수 있는 기기에서는 편리함이 있지만 주의할 점도 있습니다.

  • 개인정보: 잠금이 늦어지면 주변 사람이 메시지·알림·사진·앱 내용을 볼 가능성이 커질 수 있습니다.
  • 배터리: 화면이 오래 켜져 있을수록 전력 사용이 증가할 수 있습니다.
  • 장시간 화면 유지: 정적인 화면을 불필요하게 오래 켜 두는 것은 피하는 편이 좋습니다.
  • 사용 상황: 집에서 잠깐 요리법을 확인할 때와 대중교통·사무실에서 기기를 두는 상황을 구분해야 합니다.

가능하면 필요한 시간에만 길게 조정하고 평소에는 자신의 사용 습관에 맞는 적절한 자동 잠금 시간을 선택하세요.

9. 자동 잠금·화면 상시표시·스크린 타임은 다릅니다

10. 자주 묻는 질문

Q. 아이폰 자동 잠금 시간을 5분으로 바꾸려면?

설정 → 디스플레이 및 밝기 → 자동 잠금으로 이동한 뒤, 기기에 표시되는 시간 중 원하는 항목을 선택하면 됩니다. 저전력 모드가 활성화돼 있다면 먼저 그 상태를 확인하세요.

Q. 왜 아이폰 자동 잠금이 30초로 돌아가나요?

가장 먼저 저전력 모드를 확인해야 합니다. Apple은 저전력 모드가 자동 잠금을 30초로 설정한다고 안내합니다. 항상 같은 이유라고 단정할 수는 없으므로 다른 제한이 있는지도 확인하세요.

Q. 아이폰 자동 잠금 '안 함'이 없거나 선택할 수 없어요.

기종·iOS 버전과 저전력 모드, 회사·학교의 기기 관리 제한 여부를 살펴보세요. 모든 기기에서 '안 함'이 동일하게 제공된다고 가정하지 말고, 실제 기기에 표시되는 선택지를 확인해야 합니다.

Q. 화면은 잠긴 것 같은데 시계가 계속 보이는 이유는?

지원되는 iPhone의 화면 상시표시 기능일 수 있습니다. 설정에서 해당 기능을 조절할 수 있으며, 자동 잠금과 동일한 기능은 아닙니다.

Q. 아이폰이 제가 쳐다볼 때는 화면이 잘 안 꺼집니다.

Face ID를 지원하는 일부 모델의 주시 지각 기능 때문일 수 있습니다. 해당 기능은 기기를 바라보는 동안 화면이 어두워지지 않도록 돕습니다.

Q. 자동 잠금을 안 함으로 두면 배터리가 더 빨리 닳나요?

Apple은 자동 잠금을 지연하거나 사용하지 않도록 하면 전력 소비가 증가할 수 있다고 설명합니다. 따라서 화면을 오랫동안 켜둘 필요가 없다면 시간을 너무 길게 설정하지 않는 편이 좋습니다.

11. 결론과 최종 확인표

아이폰 자동 잠금 문제의 기본 해결 경로는 설정 → 디스플레이 및 밝기 → 자동 잠금입니다. 30초 고정이라면 저전력 모드를 우선 확인하고, 잠긴 화면에 시계가 계속 표시된다면 화면 상시표시 기능을 확인하세요. 화면을 바라볼 때만 유지된다면 주시 지각 기능이 관련될 수 있습니다.

  • ☐ 자동 잠금 메뉴에서 실제 선택된 시간을 확인했다.
  • ☐ 저전력 모드가 켜져 있는지 확인했다.
  • ☐ 잠금 후 시계가 남는 화면 상시표시와 구분했다.
  • ☐ Face ID 주시 지각 기능이 있는 기기인지 확인했다.
  • ☐ 홈 화면에서 실제 잠금 여부를 테스트했다.
  • ☐ 관리 기기라면 프로파일을 임의 삭제하지 않았다.
  • ☐ 필요할 때만 긴 자동 잠금 시간을 사용한다.
