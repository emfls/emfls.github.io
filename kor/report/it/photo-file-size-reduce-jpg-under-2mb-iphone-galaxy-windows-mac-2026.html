증명사진이나 신청서에 사진을 첨부하려는데 “파일 크기는 2MB 이하만 등록할 수 있습니다”라는 메시지가 뜰 수 있습니다. 사진이 5MB 또는 10MB라고 해서 무조건 유료 앱을 설치하거나 낯선 웹사이트에 업로드할 필요는 없습니다. 갤럭시는 갤러리 편집, 아이폰은 단축어, 윈도우는 그림판 또는 Microsoft PowerToys, 맥은 미리보기로 먼저 파일 크기를 줄여보세요.

이 글에서는 JPG·JPEG 사진의 용량을 줄이면서 글자나 얼굴이 심하게 흐려지지 않도록 조절하는 순서를 설명합니다. 사진을 잘못 저장해 원본을 잃거나, 단순히 파일 이름을 바꾸는 실수를 피하는 방법도 함께 다룹니다.

2026년 11월 4일 기준 공식 지원 문서를 참고했습니다. 실제 메뉴는 휴대전화 모델·운영체제 및 앱 버전에 따라 달라질 수 있습니다.

먼저 확인: 사진 용량과 사진 크기는 서로 다릅니다

  • 파일 용량(MB, KB): 업로드 사이트가 제한하는 파일 크기입니다. 탐색기·파일 앱의 ‘정보’에서 확인합니다.
  • 사진 크기(픽셀): 예를 들어 가로 4000 × 세로 3000픽셀처럼 이미지 자체의 가로·세로 해상도를 의미합니다.
  • 압축 품질: 주로 JPEG 저장 과정에서 화질과 파일 용량을 조절하는 선택입니다.
  • 파일 형식: JPG, PNG, HEIC는 서로 다른 형식입니다. 파일 이름 끝의 확장자만 바꾼다고 실제 형식이 변하지는 않습니다.

가로 4000픽셀인 사진을 2000픽셀로 줄이고 세로 비율을 유지하면 4000×3000 → 2000×1500픽셀이 됩니다. 총 픽셀 수는 4분의 1로 감소하지만 파일 용량이 정확히 4분의 1이 되는 것은 아닙니다. 사진 내용과 저장 품질, 형식에 따라 결과가 달라집니다.

1. 갤럭시 사진 용량 줄이기: 삼성 갤러리

삼성전자 공식 안내에서는 갤러리의 이미지 크기 변경 기능을 제공합니다. 지원 여부와 메뉴 위치는 모델마다 다를 수 있습니다.

  1. 갤러리 앱을 열고 줄일 사진을 선택합니다.
  2. 아래쪽의 연필 모양 편집 버튼을 누릅니다.
  3. 편집 화면의 더보기(점 세 개)를 누릅니다.
  4. 크기 변경(Resize)이 나타나면 선택합니다.
  5. 제공되는 비율 중 원본보다 작은 값을 고른 뒤 완료를 누릅니다.
  6. 저장하기 전에 다른 이름으로 저장·사본 저장 메뉴가 있다면 이용해 원본을 남겨둡니다.
  7. 저장된 사진의 상세정보에서 실제 용량을 확인합니다.

삼성은 일부 기기에서 ‘저장’ 시 원본이 변경될 수 있으므로, 원본을 보존하려면 사본 저장을 이용하라고 안내합니다. 편집을 취소할 수 있는 기종이라도 중요한 증빙 사진은 미리 복제해 두는 편이 안전합니다.

‘크기 변경’이 없으면? 기기·소프트웨어 버전에서 해당 기능을 지원하지 않을 수 있습니다. 편집 화면의 다른 메뉴를 확인하거나, 원본을 PC로 옮겨 윈도우·맥 방법을 사용하세요. 메뉴가 없다는 이유만으로 전체 휴대전화를 초기화하지 마세요.

2. 아이폰 사진 용량 줄이기: 단축어 앱

아이폰에서는 단축어(Shortcuts) 앱의 이미지 크기 조절 같은 이미지 변환 동작을 조합할 수 있습니다. 단축어는 iOS 버전에 따라 동작의 번역과 배열이 달라질 수 있습니다.

  1. 아이폰에서 단축어 앱을 실행하고 새로운 단축어를 만듭니다.
  2. 동작 추가에서 사진 선택을 검색해 추가합니다. 여러 사진을 일괄 처리하려면 ‘여러 항목 선택’ 옵션이 있는지 확인합니다.
  3. 다음 동작으로 이미지 크기 조절(Resize Image)을 추가합니다.
  4. 가로 폭을 예컨대 1600픽셀로 설정하고, 세로는 원본 비율을 유지하도록 둡니다.
  5. 마지막 동작으로 사진 앨범에 저장을 추가합니다.
  6. 단축어를 실행해 사진을 선택하고 결과 사진을 저장합니다.
  7. 사진 앱에서 새 파일의 정보 화면을 열어 크기를 비교합니다.

이 방식은 픽셀 수를 줄이는 기능이지, 정확히 2MB로 고정하는 기능이 아닙니다. 첫 결과가 제한보다 크다면 가로 크기를 다시 줄여 실행하거나, JPEG 품질을 조절할 수 있는 다른 방법을 사용해야 합니다. 원본과 결과가 구별되도록 파일을 정리하세요.

HEIC 사진이라면? 일부 사이트는 HEIC 업로드를 지원하지 않습니다. 해당 사이트가 JPG를 요구하는 경우 단축어에 이미지 변환 동작을 추가해 JPEG로 출력한 뒤 저장할 수 있습니다. 변환 후 용량이 늘 수도 있으므로 결과 파일을 반드시 확인해야 합니다.

3. 윈도우11에서 JPG 파일 크기 줄이기: 그림판

사진 한 장이라면 별도 프로그램을 설치하지 않고 그림판(Paint)에서 시작할 수 있습니다.

  1. 사진 파일을 복사해 원본을 보관합니다.
  2. 복사한 사진을 그림판으로 엽니다.
  3. 상단의 크기 조정(Resize) 메뉴를 선택합니다.
  4. 단위를 픽셀로 바꿔 가로 크기를 1600~2000픽셀 정도로 조절합니다. 가로·세로 비율 유지 옵션을 활성화합니다.
  5. 파일 → 다른 이름으로 저장 → JPEG 그림 등으로 저장합니다.
  6. 파일을 오른쪽 클릭하여 속성 → 크기를 확인합니다.

가로·세로 비율을 유지하지 않으면 사진이 눌리거나 길게 늘어질 수 있습니다. 그림판 버전마다 메뉴와 동작이 달라질 수 있으니 미리 복사본으로 시험하세요.

사진 10장 이상 한꺼번에 줄이는 방법

여러 장을 처리한다면 Microsoft가 제공하는 무료 PowerToys의 Image Resizer가 편리합니다.

  1. 공식 문서의 안내를 통해 Microsoft PowerToys를 설치합니다.
  2. PowerToys 설정에서 Image Resizer 기능이 활성화되어 있는지 확인합니다.
  3. 파일 탐색기에서 사진 여러 개를 선택하고 마우스 오른쪽 버튼을 누릅니다.
  4. Image Resizer로 크기 조정 메뉴를 고릅니다. Windows 11에서는 ‘추가 옵션 표시’에 있을 수 있습니다.
  5. 크기 사전 설정 또는 사용자 지정 픽셀을 선택합니다.
  6. 원본을 대체하는 옵션은 피하고 새 사본으로 저장해 결과를 검증합니다.

특히 Image Resizer의 Fit(맞춤)은 사진 비율을 유지하면서 지정한 크기 안에 배치하는 데 적합합니다. Stretch(늘이기)는 비율이 달라져 사진이 왜곡될 수 있으므로 신청서용 인물 사진에서는 사용하지 않는 편이 좋습니다.

4. 맥북 사진 용량 줄이기: 미리보기

맥의 미리보기(Preview)는 사진 크기 조정과 JPEG 품질 설정을 모두 지원합니다.

  1. 원본 사진을 복제한 다음 복제본을 미리보기로 엽니다.
  2. 메뉴에서 도구 → 크기 조절(Adjust Size)을 선택합니다.
  3. 비율 유지와 이미지 리샘플링(Resample image) 옵션을 확인합니다.
  4. 원하는 픽셀 너비 또는 비율을 입력합니다. 파일 용량 축소가 목적이라면 리샘플링이 실제로 적용되는지 확인하세요.
  5. 파일 → 내보내기를 선택하고 JPEG를 고릅니다.
  6. 제공되는 품질 조절 기능으로 용량과 선명도를 비교하면서 저장합니다.
  7. Finder의 정보 가져오기에서 결과 파일의 실제 크기를 확인합니다.

사진이 여러 장이면 미리보기의 축소판 사이드바에서 여러 이미지를 선택해 도구 → 크기 조절을 일괄 적용할 수도 있습니다. 다만 이미지를 한꺼번에 편집할 때는 원본이 수정되지 않도록 복제한 파일로 작업하는 편이 안전합니다.

5. 2MB 이하로 맞추는 실전 순서

업로드 사이트의 “2MB 이하” 조건은 사진의 가로가 2,000픽셀이라는 뜻이 아니라 파일 자체의 크기 제한입니다. 다음처럼 차례로 조절하면 불필요한 화질 저하를 줄일 수 있습니다.

  1. 원본 복제: 파일을 복사하고 이름에 _original을 붙입니다.
  2. 업로드 규격 확인: 허용 형식(JPG·PNG), 권장 픽셀, 파일 최대 크기를 먼저 확인합니다.
  3. 첫 시도: 장축(가로·세로 중 긴 쪽)을 약 2000픽셀 수준으로 맞춰 저장합니다. 이는 예시값으로 사이트가 요구하는 최소 해상도가 더 크면 그 기준을 우선합니다.
  4. 파일 크기 확인: 2MB를 넘으면 장축을 1600픽셀 등으로 더 줄이거나 JPEG 저장 품질을 조절합니다.
  5. 선명도 확인: 인물 얼굴, 글자, 문서번호가 있는 사진은 결과 파일을 실제 크기로 열어 확인합니다.
  6. 업로드 최종 확인: 형식이 맞고 실제 용량이 제한을 충족하는지 확인한 뒤 제출합니다.

일부 사이트는 MB를 1,000,000바이트, 일부 프로그램은 1MiB를 1,048,576바이트로 표기합니다. 경계에 딱 맞추기보다 약간의 여유를 두는 편이 안전합니다. 크기를 줄이더라도 증명사진의 필수 픽셀·비율 규격을 어기면 접수에 실패할 수 있습니다.

6. JPG·PNG·HEIC 중 어떤 형식이 유리할까?

형식특징선택 기준
JPG·JPEG사진에 흔히 사용하는 손실 압축사이트가 JPG를 요구하거나 일반 사진 크기를 줄일 때
PNG투명도와 그래픽의 세부 정보를 보존하는 무손실 계열로고·도표·텍스트가 많은 이미지
HEIC같은 품질에서 높은 압축 효율을 기대할 수 있음지원되는 Apple 기기 간 보관·전송에 편리하지만 업로드 사이트 호환성 확인 필요

PNG를 JPG로 바꾸면 무조건 좋아질까요? 아닙니다. 배경이 투명한 이미지나 로고는 투명도가 사라질 수 있습니다. 반대로 복잡한 일반 사진은 JPEG 저장이 용량 축소에 유리할 수 있습니다. 최종 선택은 사이트 지원 형식과 실제 결과 파일을 기준으로 해야 합니다.

7. 자주 실패하는 이유

사진을 줄였는데 용량이 그대로입니다

사진 화면에서 확대·축소하는 보기 배율만 변경한 경우 파일 자체는 달라지지 않습니다. 실제 픽셀 크기나 JPEG 저장 품질을 수정하고 새 파일로 저장했는지 확인하세요.

이미지 크기는 줄었는데 2MB 이하가 안 됩니다

픽셀과 파일 용량은 1대1로 대응하지 않습니다. JPG로 내보낼 때 품질을 조금 낮추거나 장축 픽셀을 한 단계 더 줄여 보세요. 반복 저장으로 화질이 누적 저하되지 않도록 항상 원본에서 다시 작업하는 것을 권장합니다.

아이폰 HEIC 파일이 업로드되지 않습니다

업로드 사이트가 HEIC를 지원하지 않는 경우일 수 있습니다. JPG로 실제 형식 변환한 복사본을 만들고 다시 업로드하세요. 확장자를 .jpg로 이름만 바꾸는 것은 변환이 아닙니다.

용량은 맞는데 사진이 흐립니다

픽셀을 너무 작게 줄였거나 JPEG 압축률이 과도한 경우입니다. 원본에서 다시 시작해 픽셀 크기 또는 품질을 높이세요. 민감한 서류·증빙용 사진은 제출처가 요구하는 해상도를 먼저 충족해야 합니다.

여권·운전면허증·얼굴사진·계약서처럼 개인정보가 포함된 파일이라면 우선 기기 기본 앱이나 오프라인 도구를 사용하세요. 온라인 서비스를 사용할 때는 파일이 서버로 전송되는지, 저장·삭제 정책이 무엇인지 직접 확인해야 합니다.

8. 브라우저에서 여러 장을 압축하고 싶다면
