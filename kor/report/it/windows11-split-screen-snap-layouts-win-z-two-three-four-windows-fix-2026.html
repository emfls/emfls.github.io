윈도우11에서 엑셀을 보면서 인터넷 검색을 하거나, 화상회의와 메모장을 동시에 열고 싶을 때는 별도 분할 프로그램 없이 '창 스냅(Snap)' 기능을 이용할 수 있습니다. 창을 화면 가장자리로 끌거나 Windows 키 + Z(Win+Z)를 누르면 2분할·3분할·4분할 등 지원되는 레이아웃을 선택할 수 있습니다.

다만 3개·4개 창을 나눌 수 있는 레이아웃은 화면 크기·해상도·방향 등에 따라 달라질 수 있으며, 일부 앱은 자체 창 구조나 최소 크기 제한 때문에 원하는 칸에 들어가지 않을 수 있습니다. 분할 버튼이 안 보인다고 바로 Windows가 고장 났다고 판단하지 마세요.

이 글은 창 2개를 좌우 반반 나누기, 3개·4개 배치, Win+Z 단축키, 스냅 그룹 복원, 설정 켜기·끄기, 최대화 버튼에 레이아웃이 안 뜨는 문제, 듀얼 모니터 활용을 Microsoft 공식 문서를 기준으로 정리했습니다.

정보 확인일: 2026년 11월 4일. Windows 11을 기준으로 했으며 설치된 버전·모니터 크기·앱 종류에 따라 보이는 레이아웃은 다를 수 있습니다.

1. 윈도우11 화면 분할: 단축키부터 확인

하고 싶은 작업가장 빠른 방법알아둘 점
창 2개를 좌우 반반 배치Win+← 또는 Win+→첫 창을 붙이고 다른 창을 선택
2·3·4분할 레이아웃 보기Win+Z가능한 레이아웃은 화면 크기에 따라 다름
현재 창을 왼쪽 절반에 배치Win+←화살표는 왼쪽 방향키
현재 창을 오른쪽 절반에 배치Win+→반대쪽은 스냅 도우미로 채울 수 있음
마우스로 4분할하기창을 화면 모서리로 끌기다른 창에도 반복
마우스로 레이아웃 선택하기최대화 버튼에 마우스 올리기스냅 플라이아웃 표시
창을 화면 맨 위로 끌어서 분할스냅 막대(Snap bar)사용 설정에 따라 표시
스냅을 켜거나 끄기설정 → 시스템 → 멀티태스킹 → 창 스냅세부 옵션 확장 가능
다른 모니터로 창 이동Win+Shift+← / →다중 모니터 연결 환경

Microsoft는 창을 가장자리·모서리로 드래그하는 방법, Win+화살표, Win+Z 레이아웃 선택을 모두 공식적으로 안내합니다.

공식 출처: Microsoft — 창 스냅, Microsoft — Windows 키보드 단축키.

2. 가장 쉬운 2분할: 인터넷 창과 엑셀을 반반 나누기

예를 들어 왼쪽에는 Chrome, 오른쪽에는 Excel을 띄워 놓고 가격표를 작성하려는 상황입니다.

방법 A: 마우스로 화면 반반 배치

  1. Chrome과 Excel을 모두 실행합니다.
  2. Chrome의 제목 표시줄을 마우스로 잡습니다.
  3. 화면 왼쪽 가장자리로 끌어 반투명 배치 영역이 보일 때 놓습니다.
  4. Chrome이 왼쪽 절반에 배치됩니다.
  5. 오른쪽에 뜨는 스냅 도우미(Snap Assist)의 축소판에서 Excel을 선택합니다.
  6. 두 창이 나란히 배치됐는지 확인합니다.

Microsoft는 첫 번째 창을 화면 한쪽에 배치하면 다른 열린 창의 축소판을 보여주는 스냅 도우미를 설명합니다. 축소판이 나타나지 않는다면 해당 옵션이 꺼져 있을 수 있습니다.

방법 B: 키보드로 2분할

  1. Chrome을 선택합니다.
  2. Win+←를 누릅니다.
  3. 나머지 창 목록에서 Excel을 선택하거나 Excel을 활성화합니다.
  4. 필요하면 Excel에 Win+→를 적용합니다.

이 방법은 마우스 드래그가 불편한 노트북 사용자에게도 유용합니다.

주의: 화면을 나눴다고 해서 두 앱의 문서가 자동 저장되는 것은 아닙니다. Excel 파일이나 웹 입력 내용을 개별적으로 저장하세요.

3. Win+Z 스냅 레이아웃 사용법

윈도우11에서 가장 편리한 화면 분할 기능은 스냅 레이아웃(Snap layouts)입니다.

단계별 사용

  1. 원하는 앱 창을 먼저 활성화합니다.
  2. Windows 키 + Z를 누릅니다.
  3. 화면에 나타나는 여러 창 배치 모양을 확인합니다.
  4. 현재 창을 놓을 분할 구역을 선택합니다.
  5. 스냅 도우미가 나타나면 나머지 빈 칸을 채울 다른 앱을 고릅니다.
  6. 창 사이 경계를 드래그해 크기를 조정합니다.

또 다른 진입 방법: 최대화 단추(창 오른쪽 위 네모 모양)에 마우스를 올리면 스냅 레이아웃이 표시될 수 있습니다.

Microsoft는 최대화 버튼 위에 마우스를 올리기와 Win+Z를 공식 진입 방법으로 안내합니다.

Win+Z를 눌렀는데 아무것도 안 나오나요?

이후 항목의 설정 → 시스템 → 멀티태스킹 → 창 스냅을 확인하세요. 또한 모든 앱이 동일한 맞춤 메뉴를 지원하는 것은 아닙니다.

공식 출처: Microsoft — Windows 11 스냅 레이아웃, Microsoft Learn — 데스크톱 앱의 스냅 레이아웃 지원.

4. 3분할 화면 만들기: 왼쪽 큰 창 + 오른쪽 두 창

자료를 보면서 메모를 남기는 작업에는 3분할이 편할 수 있습니다.

예를 들어:

  • 왼쪽: Excel
  • 오른쪽 위: 웹 브라우저
  • 오른쪽 아래: 메모장

적용 방법

  1. Excel·Chrome·메모장을 모두 실행합니다.
  2. Excel에서 Win+Z를 누릅니다.
  3. 3개의 칸이 있는 레이아웃이 보인다면 원하는 구역을 선택합니다.
  4. 나머지 구역에 Chrome과 메모장을 순서대로 배치합니다.
  5. 각 창이 잘리지 않도록 경계선을 조절합니다.

중요: Microsoft는 화면의 크기와 방향에 맞게 미리 정의된 레이아웃이 달라질 수 있다고 설명합니다. 특히 더 넓은 가로형 화면에서 3개의 창을 나란히 배치하는 선택지가 나타날 수 있습니다.

노트북의 좁은 화면에서 다른 사람의 화면과 똑같은 3분할 모양이 보이지 않더라도, 반드시 오류라는 뜻은 아닙니다.

3분할이 선택 목록에 없다면

  • 표시 가능한 다른 레이아웃을 확인합니다.
  • 창의 최소 너비가 넓은 앱이 있는지 확인합니다.
  • 외부 모니터를 쓰는 경우 해상도·화면 배율을 확인합니다.
  • 창을 하나씩 화면 가장자리·모서리로 끌어 부분 배치할 수 있는지 확인합니다.

반드시 3개의 창을 정확히 같은 너비로 만들 수 있다고 보장하지는 않습니다.

공식 출처: Microsoft Learn — 스냅 레이아웃은 화면 크기·방향에 따라 달라짐.

5. 4분할 만들기: 화면 네 모서리 활용

4분할은 각각의 창을 화면의 4분의 1 구역에 배치하는 방식입니다.

마우스로 네 칸 만들기

  1. 서로 다른 창 4개를 엽니다.
  2. 첫 번째 창을 왼쪽 위 모서리로 끌어 놓습니다.
  3. 두 번째 창을 오른쪽 위 모서리로 끌어 놓습니다.
  4. 세 번째 창을 왼쪽 아래 모서리로 끌어 놓습니다.
  5. 네 번째 창을 오른쪽 아래 모서리로 끌어 놓습니다.
  6. 네 칸에 필요한 내용이 보이는지 확인합니다.

Microsoft는 창을 화면 모서리로 끌면 해당 화면의 4분의 1에 맞춰지는 동작을 안내합니다.

레이아웃으로 네 칸 배치하기

Windows 11에서 Win+Z를 눌렀을 때 4개의 칸이 있는 레이아웃이 제공된다면 이를 선택하는 편이 더 간편합니다.

참고: 4분할은 특히 가로·세로 해상도가 작은 화면에서는 창 안의 내용이 지나치게 작아질 수 있습니다. 무조건 4개의 창을 배치하기보다 업무 목적에 맞춰 2분할 + Alt+Tab이 효율적인지 비교해 보세요.

6. 위쪽으로 창을 끌면 나타나는 '스냅 막대'란?

Windows 11의 스냅 막대(Snap bar)는 창을 화면 맨 위로 끌 때 나타나는 배치 안내입니다.

사용 방법

  1. 창 제목 표시줄을 잡습니다.
  2. 화면 상단으로 드래그합니다.
  3. 사용 가능한 레이아웃이 표시되면 원하는 칸에 놓습니다.
  4. 다른 창을 선택해 빈 구역을 채웁니다.

Microsoft의 Windows 11 관리자 문서는 Windows 11 버전 22H2부터 창을 화면 위쪽으로 끌어 스냅 레이아웃을 활성화할 수 있다고 설명합니다.

주의: 스냅 막대 기능이 꺼져 있다면 이 동작이 나타나지 않을 수 있습니다. 설정에서 '창을 화면 맨 위로 끌 때 스냅 레이아웃 표시'와 같은 항목을 확인하세요.

공식 출처: Microsoft — 스냅 막대 설정, Microsoft Learn — Windows 11 스냅 막대.

7. 분할한 두 창의 크기·비율 조정하기

2분할을 실행했다고 해서 두 창의 너비를 반드시 50:50으로 유지할 필요는 없습니다.

경계선 끌어서 조정

  1. 화면에 두 개 이상의 창을 스냅합니다.
  2. 두 창의 경계 부분으로 마우스를 이동합니다.
  3. 커서가 크기 조절 모양으로 바뀌면 경계를 잡습니다.
  4. 왼쪽 또는 오른쪽으로 끌어 원하는 너비로 조절합니다.
  5. 창 내용이 충분히 보이는지 확인합니다.

Microsoft는 스냅된 창의 구분선을 드래그하면 이웃 창의 크기도 연동해 조정될 수 있다고 설명합니다.

다만 앱이 요구하는 최소 창 크기에 따라 더 작게 줄어들지 않을 수 있습니다. 이때는 화면 분할이 실패한 것이 아니라 앱 자체의 크기 제한일 수 있습니다.

8. 스냅이 안 될 때: 설정 → 시스템 → 멀티태스킹

화면 가장자리로 창을 끌어도 분할이 되지 않거나, 최대화 버튼 위에 마우스를 올려도 분할 레이아웃이 안 보일 수 있습니다.

기본 설정 확인

  1. Windows 시작 → 설정을 엽니다.
  2. 시스템 → 멀티태스킹으로 이동합니다.
  3. 창 스냅이 켬인지 확인합니다.
  4. 항목을 확장해 세부 옵션을 확인합니다.
  5. 필요한 기능을 켠 뒤 다시 Win+Z를 누르거나 창을 가장자리로 끌어 봅니다.

Windows 11 화면에서는 일부 문구가 조금 다를 수 있지만, Microsoft는 공식 문서에서 이러한 세부 옵션을 설명합니다.

우선순위: 기본 '창 스냅'이 켜져 있어도 최대화 버튼에서 스냅 레이아웃 표시 옵션이 꺼져 있다면 마우스로 레이아웃을 여는 경험은 달라질 수 있습니다.

공식 출처: Microsoft — 스냅 설정 구성.

9. Win+Z가 안 되거나 레이아웃 버튼이 안 보이는 이유

Win+Z가 작동하지 않는 원인은 한 가지가 아닙니다.

① 키보드 자체의 문제

  • Win 키가 정상 동작하는지 Win+E로 파일 탐색기 열기를 시험합니다.
  • Z 키가 정상 입력되는지 확인합니다.
  • 게임용 키보드의 Windows 키 잠금 기능이 켜져 있는지 확인합니다.
  • 회사에서 사용하는 특수 키보드·원격 접속 환경이라면 단축키가 다른 프로그램에 전달될 수 있습니다.

② 스냅 설정이 꺼져 있음

  • 설정 → 시스템 → 멀티태스킹 → 창 스냅을 확인합니다.
  • 최대화 버튼의 레이아웃 표시 옵션을 확인합니다.
  • Win+Z와 마우스 최대화 버튼 양쪽에서 재현되는지 비교합니다.

③ 특정 프로그램에서만 안 됨

Microsoft Learn에 따르면 일부 데스크톱 앱은 자체 창 테두리·제목 표시줄을 구현해 최대화 버튼 위의 스냅 레이아웃이 예상대로 표시되지 않을 수 있습니다.

중요: 특정 앱에만 문제가 나타나고 메모장·파일 탐색기처럼 기본 앱에서는 정상이라면, Windows 전체를 초기화하기 전에 해당 앱의 창 구현·업데이트 여부를 점검하세요.

④ 화면 크기·창 최소 크기 제한

앱 창이 너무 작게 줄어들 수 없거나, 화면이 좁고 해상도가 낮으면 선택할 수 있는 레이아웃이 제한될 수 있습니다.

⑤ 회사·학교 관리 환경

조직 정책이나 원격 데스크톱 환경에서 일부 UI가 다르게 동작할 수 있습니다. 관리자 권한 우회나 무작정 레지스트리 편집을 시도하기보다 기본 기능과 장치 정책부터 확인하세요.

공식 출처: Microsoft Learn — 특정 앱에서 스냅 레이아웃이 안 뜨는 이유.

10. 창 스냅 그룹 복원: 여러 앱을 한꺼번에 다시 열기

문서 작업 중 Chrome·Excel을 좌우로 배치했는데 다른 창을 열었다면, 여러 앱을 하나씩 다시 찾아 배치해야 할까요?

Microsoft는 여러 창을 함께 스냅하면 스냅 그룹(Snap group)이 만들어질 수 있고, 작업 표시줄·작업 보기·Alt+Tab에서 관련 그룹을 다시 선택할 수 있다고 설명합니다.

그룹 복원 확인 순서

  1. Chrome과 Excel을 나란히 스냅합니다.
  2. 다른 앱을 실행하거나 다른 창을 활성화합니다.
  3. 작업 표시줄에서 스냅 그룹의 앱 아이콘에 마우스를 올립니다.
  4. 해당 앱 하나만 선택할지, 함께 배치한 그룹을 선택할지 확인합니다.
  5. 그룹을 선택해 이전 배치로 돌아갈 수 있는지 확인합니다.

그룹이 보이지 않는다면?

설정 → 시스템 → 멀티태스킹 → 창 스냅에서 작업 표시줄·작업 보기·Alt+Tab에 스냅 그룹 표시 옵션을 확인하세요.

주의: 스냅 그룹은 창 배치 편의를 위한 기능이지 파일의 저장·백업 기능은 아닙니다. 앱이 닫히거나 재부팅한 상황에서 작업 문서가 자동 복원되는 것으로 이해하면 안 됩니다.

공식 출처: Microsoft — 그룹 스냅.

11. 듀얼 모니터에서 다른 화면으로 창 이동하기

화면 두 대를 사용한다면 한 모니터에서 2분할하고 다른 모니터에서는 작업 자료를 전체 화면으로 보는 방식도 좋습니다.

창을 다른 모니터로 이동하는 단축키

  • Win+Shift+→: 활성 창을 오른쪽 모니터로 이동
  • Win+Shift+←: 활성 창을 왼쪽 모니터로 이동

Microsoft 공식 Windows 단축키 문서에는 이 동작이 안내되어 있습니다.

추천 배치 예시

모니터권장 구성
첫 번째 모니터Excel + 브라우저 2분할
두 번째 모니터화상회의 화면 또는 큰 PDF 문서
첫 번째 모니터(와이드)레이아웃이 지원된다면 3개 창 나란히
두 번째 모니터(세로)메신저·긴 문서 등 위아래 분할

주의: 듀얼 모니터를 쓴다고 모든 창이 자동으로 동일한 레이아웃으로 구성되지는 않습니다. 각각의 모니터에서 화면 해상도·배율·방향에 따라 제공되는 레이아웃이 달라질 수 있습니다.

공식 출처: Microsoft — Windows 단축키 전체.

12. 화면 분할이 갑자기 풀리는 이유

스냅 레이아웃으로 창을 정리했어도 다른 프로그램을 실행하거나, 전체 화면 영상을 열거나, 앱을 최대화하면 화면 배치가 달라 보일 수 있습니다.

증상별 점검표

증상가능한 이유권장 조치
스냅한 창이 사라진 것처럼 보임다른 창이 앞에 떠 있음Alt+Tab 또는 작업 표시줄에서 창 선택
레이아웃이 예전과 달라짐화면 해상도·방향 변경현재 모니터의 배치 다시 선택
한 앱만 분할 구역을 벗어남앱의 최소 크기·자체 창 동작다른 기본 앱으로 비교
빈 칸에 다른 창 추천이 없음스냅 도우미 세부 옵션 비활성화창 스냅의 옵션 확인
레이아웃 플라이아웃만 안 보임최대화 버튼 옵션 비활성화Win+Z와 설정 비교
재부팅 후 그룹이 없음그룹 기능을 영구 저장으로 오해문서 저장·앱 재실행과 별개로 이해

권장 순서: 창이 사라진 듯해도 먼저 Alt+Tab이나 작업 표시줄에서 앱이 실제 실행 중인지 확인하고, 그다음 스냅 기능을 조정하세요.

13. 스냅 레이아웃과 가상 데스크톱은 뭐가 다른가요?

윈도우11의 멀티태스킹 기능에는 스냅, Alt+Tab, 작업 보기, 가상 데스크톱이 있습니다.

기능목적대표 사용
스냅하나의 화면에 여러 앱을 동시에 보이게 배치Excel과 Chrome 좌우 분할
Alt+Tab열린 앱·창 사이를 전환문서·메신저 빠르게 전환
작업 보기(Win+Tab)여러 창·데스크톱을 시각적으로 탐색열려 있는 작업 정리
가상 데스크톱작업 공간 자체를 여러 개로 구분업무용·개인용 창을 분리

Microsoft는 이를 모두 별도 멀티태스킹 기능으로 안내합니다. 따라서 창을 4개 보이게 하고 싶다면 스냅, 많은 앱을 용도별로 나누고 싶다면 가상 데스크톱이 적합합니다.

공식 출처: Microsoft — Windows 멀티태스킹.

14. 5분 실습: Chrome·Excel·메모장 3개를 정리해 보기

실제로 사용할 때 문제가 생기는 지점을 확인할 수 있는 간단한 실습입니다.

첫 번째 단계: 기본 2분할

  1. Chrome과 Excel을 실행합니다.
  2. Chrome을 선택해 Win+←를 누릅니다.
  3. 오른쪽에 Excel을 선택합니다.
  4. 화면의 양쪽이 정상 배치됐는지 확인합니다.

두 번째 단계: 3분할 레이아웃 확인

  1. 메모장을 추가로 실행합니다.
  2. Win+Z를 누릅니다.
  3. 3개 창을 담는 레이아웃이 있는지 확인합니다.
  4. 지원되는 구역을 선택해 세 앱을 배치해 봅니다.
  5. 해당 레이아웃이 없다면 모니터 크기·해상도 제약을 기록해 둡니다.

세 번째 단계: 레이아웃 복원 확인

  1. 분할된 앱 중 하나의 작업 표시줄 아이콘에 마우스를 올립니다.
  2. 그룹으로 복원할 수 있는 선택지가 있는지 확인합니다.
  3. 보이지 않는다면 설정 → 시스템 → 멀티태스킹에서 스냅 그룹 관련 항목을 확인합니다.

네 번째 단계: 안 되는 앱 구별

Chrome·Excel·메모장 중 어느 앱에서 문제가 있는지 비교합니다. 기본 앱에서는 정상인데 한 앱에서만 최대화 버튼의 스냅 메뉴가 나타나지 않는다면 해당 앱의 창 특성을 의심할 수 있습니다.

15. 자주 묻는 질문

Q1. 윈도우11 화면을 2개로 나누는 단축키는 무엇인가요?

현재 창에서 Win+← 또는 Win+→를 누르면 왼쪽이나 오른쪽에 맞출 수 있습니다. 다른 창을 반대쪽에 배치하면 됩니다.

Q2. 윈도우11 화면을 3개로 나눌 수 있나요?

예, 지원되는 레이아웃에서 3개 창을 배치할 수 있습니다. 단 모니터 크기·방향·앱의 최소 창 크기에 따라 선택지가 다를 수 있습니다.

Q3. 윈도우11 화면 4분할은 어떻게 하나요?

Win+Z에서 4칸 레이아웃을 선택하거나, 창을 각각 화면의 네 모서리로 끌어 배치할 수 있습니다.

Q4. Win+Z를 눌렀는데 레이아웃이 안 보입니다.

설정 → 시스템 → 멀티태스킹 → 창 스냅이 켜져 있는지 확인하세요. 특정 앱에서만 안 된다면 해당 앱의 최대화 버튼·창 구조 문제일 수 있습니다.

Q5. 화면 맨 위로 창을 끌면 레이아웃이 뜨는데 끌 때마다 방해됩니다.

설정 → 시스템 → 멀티태스킹 → 창 스냅의 세부 옵션에서 화면 맨 위로 끌 때 레이아웃 표시를 끌 수 있습니다. 스냅 기능 전체를 끄는 것과는 다릅니다.

Q6. 화면 분할한 창의 너비를 다르게 조절할 수 있나요?

예. 스냅된 창 사이의 구분선을 드래그하면 인접한 창의 크기도 함께 변할 수 있습니다. 다만 앱의 최소 크기 제한이 있을 수 있습니다.

Q7. 분할했던 두 창을 한 번에 다시 불러올 수 있나요?

Windows 11의 스냅 그룹을 이용해 작업 표시줄·작업 보기 등에서 복원할 수 있는 경우가 있습니다. 스냅 그룹 표시 옵션이 켜져 있는지 확인하세요.

Q8. 듀얼 모니터에서 창을 옮기는 단축키는 무엇인가요?

Win+Shift+왼쪽/오른쪽 화살표를 이용할 수 있습니다. 이 기능은 화면 분할 자체가 아니라 다른 모니터로 활성 창을 이동하는 기능입니다.

Q9. 윈도우10도 Win+Z 스냅 레이아웃이 되나요?

Windows 11의 Win+Z 스냅 레이아웃 기능을 Windows 10과 동일하게 생각하면 안 됩니다. Windows 10에도 창 스냅 기능은 있지만 UI와 제공 기능은 다를 수 있습니다.

16. 마무리: 어떤 방식이 가장 쉬울까?

2분할은 Win+←/→, 3분할·4분할은 Win+Z, 마우스 4분할은 화면 네 모서리로 창 끌기부터 시도하세요.

분할이 안 되면 설정 → 시스템 → 멀티태스킹 → 창 스냅의 기본 스위치와 세부 옵션을 확인합니다. 특정 앱에서만 안 된다면 Windows를 초기화하기 전에 기본 앱과 비교하는 것이 좋습니다.

마지막으로 3분할·4분할의 표시 여부는 모니터와 앱 조건에 따라 달라질 수 있다는 점을 기억하세요. 목표는 정해진 칸 수를 억지로 채우는 것이 아니라, 현재 화면에서 필요한 자료를 가장 편하게 함께 보는 것입니다.

3분할(왼쪽+오른쪽 2칸) Win+Z, 화면 해상도 1920×1080 이상 권장 무료(윈도우11 기본) 노트북 등 작은 화면에서는 레이아웃이 제한될 수 있음
4분할(네 모서리) 마우스 모서리 드래그, Win+Z 무료(윈도우11 기본) 앱 최소 크기 제한, 해상도 1920×1080 이상 권장

⚠️ 놓치면 손해보는 2026 핵심 실행 체크리스트
  • 화면 분할이 안 될 때는 먼저 윈도우11 버전과 최신 업데이트 적용 여부, 창 스냅 설정(설정→시스템→멀티태스킹→창 스냅)이 켜져 있는지 반드시 확인하세요.
  • 스냅 레이아웃이 일부 앱에서 동작하지 않거나 최소 크기 제한으로 배치가 안 될 수 있으니, 여러 앱을 테스트하고 필요한 경우 창 크기를 조정하세요.
  • 작업 중인 문서(예: 엑셀, 웹 입력 등)는 화면 분할과 무관하게 자동 저장되지 않으므로, 분할 전후 반드시 수동 저장을 습관화해 데이터 손실을 방지하세요.

화면 분할 전후의 작업 시간 단축률이나 생산성 증가율을 직접 시뮬레이션하면, 실제 업무 효율 개선 효과를 수치로 확인할 수 있습니다.

자주 묻는 질문 (FAQ)

윈도우11에서 2분할 화면을 가장 쉽게 만드는 방법은 무엇인가요?

Win+← 또는 Win+→ 키를 사용해 현재 창을 화면 좌우 절반에 배치하고, 스냅 도우미에서 다른 창을 선택하면 2분할 화면을 쉽게 만들 수 있습니다.

Win+Z 스냅 레이아웃이 작동하지 않을 때 어떻게 해야 하나요?

설정 → 시스템 → 멀티태스킹 → 창 스냅 기능이 켜져 있는지 확인하고, 일부 앱은 스냅 레이아웃을 지원하지 않을 수 있으니 참고하세요.

3분할 또는 4분할 화면 배치는 어떤 조건에서 제한될 수 있나요?

화면 크기, 해상도, 방향, 그리고 앱의 최소 창 크기 제한 때문에 원하는 분할 레이아웃이 보이지 않거나 적용되지 않을 수 있습니다.
