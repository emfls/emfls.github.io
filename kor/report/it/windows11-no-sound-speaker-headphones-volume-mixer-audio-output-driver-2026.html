유튜브 영상을 재생해도 소리가 나오지 않거나, 이어폰을 꽂았는데도 노트북 스피커에서만 소리가 나나요? Windows 11 작업 표시줄의 음량이 정상인데 게임·크롬·화상회의 중 특정 프로그램에서만 소리가 나지 않는 경우도 있습니다.

이런 상황에서 오디오 드라이버를 바로 삭제하거나 Windows를 초기화할 필요는 없습니다. 전체 컴퓨터에서 소리가 나지 않는 문제, 출력 장치가 잘못 선택된 문제, 특정 앱만 음소거된 문제, 업데이트 후 드라이버가 동작하지 않는 문제는 해결 순서가 다르기 때문입니다.

이 글은 2026년 10월 26일 기준 Microsoft의 Windows 11 오디오 공식 고객지원을 바탕으로 스피커·이어폰 출력 선택, 기본 재생 장치, 볼륨 믹서, HDMI 모니터, 오디오 향상 기능, 형식 변경, Windows Audio 서비스, 드라이버 업데이트·롤백을 단계별로 정리했습니다.

1. '마이크 안됨'과 '스피커 소리 안남'은 다른 문제입니다

Windows에는 **소리 입력 장치(Input)**와 **소리 출력 장치(Output)**가 따로 있습니다.

입력: 내 목소리를 상대에게 전달

마이크·헤드셋 마이크·웹캠 마이크가 내 목소리를 PC에 입력합니다. Teams에서 상대방이 내 말을 듣지 못하는 문제는 대개 마이크·입력 권한·앱 음소거부터 확인해야 합니다.

출력: 음악과 상대방 목소리를 듣기

노트북 스피커, 유선 이어폰, USB 헤드셋, Bluetooth 헤드폰, HDMI 모니터 등이 출력 장치가 될 수 있습니다. 유튜브나 시스템 알림이 들리지 않으면 출력 장치와 재생 설정이 우선입니다.

상황별 판단

  • 상대방 목소리는 들리는데 내 말만 안 들림: 입력 마이크
  • 내 말은 전달되는데 상대방 소리가 안 들림: 출력 스피커
  • 유튜브는 되는데 Teams만 안 들림: 앱별 출력·음소거
  • Bluetooth는 연결됐는데 오디오만 안 들림: 출력 선택·Bluetooth 오디오 상태
  • 전체 프로그램에서 소리가 안 들림: Windows 출력·하드웨어·드라이버

문제 위치를 구분하지 않고 모든 오디오 장치를 지우는 것은 피해야 합니다. 입력 설정을 조절해도 출력 문제는 해결되지 않을 수 있습니다.

공식 출처: Microsoft - 오디오 입력·출력 문제 해결

2. 스피커·이어폰 음소거와 물리적 연결 먼저 확인

Windows 설정을 바꾸기 전에 소리를 재생할 장치가 실제로 연결돼 있는지 점검하세요.

노트북 내장 스피커라면

  1. 키보드의 스피커 음소거 키가 눌려 있지 않은지 살펴봅니다.
  2. 작업 표시줄 오른쪽 스피커 아이콘을 확인합니다.
  3. 음량 슬라이더가 0이 아닌지 확인합니다.
  4. Windows에서 다른 출력 장치가 선택돼 있는지 살펴봅니다.
  5. 간단한 동영상이나 오디오로 소리를 테스트합니다.

유선 헤드폰·이어폰이라면

  1. 이어폰 케이블이 완전히 꽂혀 있는지 확인합니다.
  2. USB-C·USB 이어폰이라면 PC가 해당 오디오 기기를 지원하는지 확인합니다.
  3. 제품에 음량 다이얼이나 음소거 스위치가 있는지 살펴봅니다.
  4. 가능하면 다른 정상 이어폰으로 비교합니다.
  5. 이어폰을 분리하고 노트북 스피커 소리가 다시 나오는지 확인합니다.

외장 스피커라면

  • 전원 케이블과 장치의 전원 스위치 확인
  • 외장 스피커 자체의 음량 다이얼 확인
  • 3.5mm·USB·HDMI 등 연결 방식 확인
  • USB 전원이 필요한 기기의 공급 상태 확인

Microsoft는 케이블·잭·커넥터·음량·전원을 공식적인 첫 점검 항목으로 제시합니다.

연결 자체가 잘못돼 있다면?

데스크톱 PC에서 마이크 입력 잭과 스피커 출력 잭이 분리돼 있으면 엉뚱한 단자에 꽂아도 소리가 들리지 않을 수 있습니다. 기기 제조사의 사양·포트 표시를 확인하세요.

공식 출처: Microsoft - 스피커·헤드폰 출력 점검

3. Windows 11에서 출력 장치 바꾸기: 소리가 어디로 가고 있나요?

컴퓨터에 출력 장치가 둘 이상 있으면 소리가 현재 듣고 있는 기기가 아닌 다른 장치로 전달될 수 있습니다.

Windows 설정에서 출력 장치 선택

  1. Windows 키 + I로 설정을 엽니다.
  2. 시스템 → 소리로 이동합니다.
  3. 출력에서 사용할 장치 목록을 확인합니다.
  4. 노트북 내장 스피커·헤드폰·모니터·USB 오디오 가운데 실제 사용할 장치를 선택합니다.
  5. 볼륨과 음소거를 확인합니다.
  6. 해당 장치로 음악·영상이 재생되는지 시험합니다.

Microsoft의 최신 안내는 설정 → 시스템 → 소리 → 출력에서 올바른 기기를 선택하는 것을 기본 해결책으로 제시합니다.

빠른 설정에서 출력 장치 바꾸기

  1. 작업 표시줄의 스피커·네트워크·배터리 아이콘 영역을 클릭합니다.
  2. 음량 옆의 출력 장치 선택 버튼이 제공되는지 확인합니다.
  3. 올바른 이어폰 또는 스피커를 선택합니다.
  4. 실제로 소리가 이동하는지 확인합니다.

모니터 이름이 여러 개 표시된다면?

HDMI나 DisplayPort 연결된 모니터가 오디오 장치로 표시될 수 있습니다. 모니터에 스피커가 없다면 해당 장치를 출력으로 선택해도 소리가 들리지 않을 수 있습니다.

Bluetooth 이어폰이 보이지만 연결되지 않았다면?

Windows에 예전에 등록한 장치가 목록에 남아 있어도 실제 연결이 끊겼을 수 있습니다. 설정 → Bluetooth 및 장치에서 연결 상태를 먼저 확인해야 합니다.

공식 출처: Microsoft - 오디오 출력 장치 선택

4. 기본 재생 장치 설정: 이어폰·스피커를 기본값으로 고정

Windows에서 매번 다른 출력 장치를 선택하게 된다면 **기본 재생 장치(Default Playback Device)**를 확인하세요.

Windows 11 기본 출력 지정

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 아래의 추가 사운드 설정을 선택합니다.
  3. 새로 열린 사운드 창에서 재생 탭을 선택합니다.
  4. 사용할 스피커 또는 이어폰을 오른쪽 클릭합니다.
  5. 기본 장치로 설정을 선택합니다.
  6. 적용·확인을 누릅니다.
  7. 음성·음악 재생 앱을 다시 시험합니다.

Microsoft는 오디오 출력 장치가 여러 개 있는 경우 기본 재생 장치를 올바르게 설정하도록 안내합니다.

통신 장치 기본값도 별개일 수 있습니다

일부 오디오 앱과 장치에서는 기본 통신 장치가 일반 재생 장치와 별도로 관리될 수 있습니다. 음악은 스피커로 들리는데 회의 앱에서 헤드셋을 사용하는 등의 상황에서는 각 앱 설정도 확인해야 합니다.

출력 장치를 바꿨는데도 특정 앱에서 그대로라면?

해당 앱이 자체 출력 장치를 선택했을 수 있습니다. 다음 단계의 볼륨 믹서를 확인하세요.

주의: 업무용 방송·녹음 시스템, 가상 오디오 케이블을 이용하는 PC는 기본 출력 변경이 다른 앱에도 영향을 줄 수 있습니다. 바꾸기 전에 원래 값을 기록해 두는 것이 좋습니다.

공식 출처: Microsoft - 기본 오디오 재생 장치 설정

5. 유튜브·게임·Chrome만 소리 안 남: 볼륨 믹서 확인

Windows 시스템 알림은 들리지만 특정 앱의 소리만 안 나오는 문제는 앱별 설정을 점검해야 합니다.

Microsoft 공식 도움말은 이 상황에서 볼륨 믹서의 앱별 음소거와 출력 장치를 우선 확인하도록 안내합니다.

Windows 11 볼륨 믹서 열기

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 시스템 → 소리를 선택합니다.
  3. 볼륨 믹서를 엽니다.
  4. 앱 목록에서 소리가 나지 않는 Chrome·게임·미디어 플레이어 등을 찾습니다.
  5. 해당 앱이 음소거 상태인지 확인합니다.
  6. 앱별 볼륨 슬라이더를 올려 봅니다.
  7. 앱에 지정된 출력 장치를 확인합니다.
  8. 영상·음악을 다시 재생해 봅니다.

앱이 목록에 없을 때

볼륨 믹서의 앱 목록은 실행 중인 오디오 세션에 따라 달라질 수 있습니다. 문제가 있는 앱을 실행하고 실제로 소리를 재생한 뒤 다시 확인해 보세요.

출력 장치가 앱마다 다를 수 있습니다

예를 들어 Windows 기본 출력은 노트북 스피커인데 Chrome은 이전에 사용한 USB 헤드셋으로 설정돼 있을 수 있습니다.

이때 전체 음량을 100%로 올려도 Chrome에서는 계속 소리가 들리지 않을 수 있습니다. Chrome의 개별 출력 장치를 실제 사용할 스피커로 다시 선택해야 합니다.

시스템 소리는 나오는데 게임만 안 되면?

게임 내부의 마스터 볼륨·음악·효과음·대화 음량을 확인하세요. 앱 자체 볼륨이 0으로 설정됐을 가능성도 있습니다. Windows 볼륨 믹서와 게임 설정 양쪽을 비교하면 원인을 좁히기 쉽습니다.

Teams·Zoom도 같은 원리입니다

Windows가 선택한 기본 스피커와 회의 앱의 실제 출력 장치가 다를 수 있습니다. 회의 앱의 스피커 설정까지 확인해야 합니다.

공식 출처: Microsoft - 시스템 소리는 정상인데 앱에서만 소리 안 날 때

6. 소리가 너무 작다면: 시스템 음량과 앱 음량을 나눠 확인

스피커에서 소리가 조금 들리지만 유독 작다면 스피커 자체 음량, Windows 시스템 음량, 앱 음량을 각각 확인하세요.

권장 확인 순서

  1. 외장 스피커·헤드셋의 물리적 볼륨 다이얼이 있는지 확인합니다.
  2. 작업 표시줄 스피커 아이콘을 누릅니다.
  3. Windows 음량을 적절한 수준으로 조절합니다.
  4. 설정 → 시스템 → 소리 → 볼륨 믹서로 이동합니다.
  5. 문제가 있는 앱의 음량과 음소거를 확인합니다.
  6. 앱에 자체 볼륨 설정이 있다면 함께 확인합니다.
  7. 소리를 테스트하면서 지나치게 큰 음량으로 설정하지 않도록 주의합니다.

Windows가 큰데 유튜브는 작을 때

Windows 전체 음량과 별개로 웹 영상 플레이어의 볼륨이 낮을 수 있습니다. 플레이어 볼륨, 브라우저 탭 음소거, 볼륨 믹서의 Chrome 값을 차례로 확인하세요.

특정 프로그램만 계속 낮다면

Microsoft는 장치 출력에 적용된 오디오 향상 기능과 잘못된 기본 형식도 저음량의 원인이 될 수 있다고 설명합니다. 아래에서 각각 확인하는 방법을 안내합니다.

볼륨을 무조건 최대로 올리는 것은 피하세요

이어폰·헤드폰에서 고음량으로 장시간 듣는 습관은 청력에 부담이 될 수 있습니다. 갑작스러운 큰 소리가 재생될 수 있으므로 낮은 수준에서 시작해 필요한 만큼만 올리는 방식이 좋습니다.

공식 출처: Microsoft - Windows 소리가 작거나 조용할 때

7. 이어폰을 꽂았는데 스피커에서 소리가 나는 이유

유선 이어폰을 꽂았는데도 노트북 스피커에서 소리가 나오는 경우에는 단자 연결·출력 장치 자동 전환·드라이버 감지 등을 확인할 수 있습니다.

유선 이어폰 점검

  1. 이어폰을 연결한 단자가 오디오 출력용 단자인지 확인합니다.
  2. 이어폰 플러그가 끝까지 들어갔는지 확인합니다.
  3. 노트북의 설정 → 시스템 → 소리 → 출력을 엽니다.
  4. 이어폰이나 헤드폰 장치가 표시되는지 확인합니다.
  5. 해당 장치를 선택하고 소리를 재생합니다.
  6. 다른 정상 이어폰이 있다면 연결해 비교합니다.

이어폰이 출력 목록에 안 보일 때

일부 노트북은 유선 이어폰을 꽂아도 스피커와 헤드폰을 같은 오디오 컨트롤러 이름으로 표시할 수 있습니다. 목록에 '헤드폰'이라는 이름이 따로 없다고 바로 고장으로 볼 수는 없습니다.

단자 감지 기능과 실제 출력 전환은 기기 제조사·오디오 드라이버 방식에 따라 다를 수 있으므로 제조사 지원 앱과 공식 드라이버도 확인하세요.

USB-C 이어폰은 다를 수 있습니다

USB-C는 플러그 모양일 뿐이고, 해당 이어폰이 Windows 오디오 장치로 호환되는지는 별도 문제입니다. 정상적인 USB-C 충전이나 다른 USB 기기 연결이 가능하더라도 이어폰 출력까지 지원한다고 확정할 수 없습니다.

다른 기기에서 이어폰 테스트

동일 이어폰을 지원되는 다른 기기에 연결했을 때도 소리가 나지 않는다면 이어폰 자체 문제 가능성을 검토할 수 있습니다. 반대로 다른 이어폰은 내 노트북에서 정상이라면 케이블·플러그·이어폰의 호환성을 먼저 살펴보세요.

공식 출처: Microsoft - 헤드폰 출력과 기본 장치 선택

8. HDMI 모니터 연결 후 소리가 사라질 때

노트북을 외부 모니터에 연결한 뒤 기존 스피커 소리가 갑자기 사라지는 현상은 출력 장치가 모니터 쪽으로 전환됐기 때문일 수 있습니다.

HDMI·DisplayPort와 소리 출력

HDMI와 일부 DisplayPort 연결은 영상뿐 아니라 디지털 오디오 신호도 전달할 수 있습니다. 따라서 Windows가 외부 모니터를 별도 오디오 출력 장치로 표시할 수 있습니다.

하지만 모니터에 내장 스피커가 없는 경우 모니터로 오디오를 보내더라도 실제로 들을 수 있는 소리가 없습니다. Microsoft가 공식적으로 주의하라고 안내하는 상황입니다.

해결 순서

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 출력 장치 목록을 살펴봅니다.
  3. 모니터 이름이나 디스플레이 오디오로 표시된 장치가 선택됐는지 확인합니다.
  4. 노트북에서 듣고 싶다면 내장 스피커를 선택합니다.
  5. 외장 모니터 스피커를 쓰려면 실제 모니터에 오디오 출력 하드웨어가 있는지 확인합니다.
  6. 모니터 자체 음량과 외부 스피커 연결을 점검합니다.
  7. 음악이나 동영상을 재생해 출력 경로를 비교합니다.

TV에 연결했는데 TV에서 소리가 안 날 때

TV 자체의 음소거·볼륨, PC 출력 선택, HDMI 연결 상태를 각각 확인해야 합니다. TV에 다른 HDMI 입력이 연결돼 있거나 외부 사운드바로 출력을 지정했을 가능성도 있습니다.

모니터 연결을 해제해도 소리가 안 나면?

외부 출력 장치가 기본으로 남아 있거나 앱이 이전 장치를 기억할 수 있습니다. Windows 기본 출력과 볼륨 믹서의 앱별 출력을 다시 확인하세요.

공식 출처: Microsoft - 모니터를 연결한 뒤 소리가 나지 않을 때

9. Bluetooth 이어폰은 연결됐는데 소리가 안 들릴 때

Bluetooth 헤드폰이 Windows에서 연결됨으로 표시되는데도 소리가 재생되지 않을 수 있습니다. 이 경우는 페어링 문제뿐 아니라 선택된 오디오 출력 장치도 확인해야 합니다.

확인 순서

  1. 설정 → Bluetooth 및 장치에서 이어폰이 실제 연결 상태인지 확인합니다.
  2. 이어폰·충전 케이스의 배터리 잔량을 확인합니다.
  3. 다른 스마트폰이나 태블릿에 자동 연결돼 있지 않은지 살펴봅니다.
  4. 설정 → 시스템 → 소리 → 출력에서 Bluetooth 이어폰을 선택합니다.
  5. Windows 음소거와 이어폰 자체 음량을 확인합니다.
  6. 문제가 발생한 앱의 볼륨 믹서에서 출력 장치를 확인합니다.
  7. 필요하면 Windows 도움말 보기의 Bluetooth 자동 문제 해결사를 이용합니다.

연결됐는데 음질이 나쁘고 끊기는 경우

기기 사이 거리·전파 간섭·배터리 부족·드라이버 호환성이 영향을 줄 수 있습니다. 마이크를 동시에 사용하는 헤드셋은 지원되는 Bluetooth 오디오 방식에 따라 재생 품질이 달라질 수 있습니다.

페어링 정보부터 삭제해야 하나요?

권장 순서는 아닙니다. Bluetooth 연결 자체가 정상이고 단지 재생 장치만 잘못 선택됐다면 출력 장치 변경만으로 해결될 수 있습니다.

이어폰이 아예 연결되지 않거나 기기 등록이 정상적으로 작동하지 않는 경우에만 제조사 공식 페어링 절차와 Windows의 장치 제거·재등록을 검토하세요.

공식 출처: Microsoft - Bluetooth 연결됨, 소리 안 남

10. 오디오 향상 기능 때문에 소리가 나지 않을 수 있습니다

Windows 11에는 출력 장치에 소리 보정 효과를 적용하는 오디오 향상(Audio enhancements) 기능이 있습니다. 일부 장치에서는 이 기능이 소리를 왜곡하거나, 너무 작게 만들거나, 정상 재생을 방해할 수 있습니다.

Microsoft 공식 문제 해결 문서는 오디오 향상 기능을 끈 뒤 다시 테스트하는 방법을 안내합니다.

오디오 향상 기능 끄는 방법

  1. 설정 → 시스템 → 소리로 이동합니다.
  2. 출력 목록에서 실제 사용하는 스피커·헤드폰을 선택합니다.
  3. 해당 장치의 속성 화면을 엽니다.
  4. 오디오 향상 항목을 찾습니다.
  5. 표시되는 경우 드롭다운에서 끔을 선택합니다.
  6. 영상이나 음악을 다시 재생합니다.
  7. 소리가 돌아오는지, 품질이 좋아지는지 비교합니다.

예전 Windows 화면과 경로가 다를 수 있습니다

일부 드라이버는 추가 사운드 설정 → 재생 → 장치 속성 → 향상 기능에서 비슷한 옵션을 제공합니다. 드라이버에 따라 메뉴가 없거나 제조사 전용 앱에서 제공될 수 있습니다.

오디오 향상을 끄면 무조건 음질이 좋아지나요?

그렇지 않습니다. 일부 출력 장치는 제조사의 오디오 보정 기능이 정상적으로 동작할 때 좋은 음질을 낼 수 있습니다. 문제를 해결하기 위한 비교 테스트로 활용하고 실제 차이가 있는지 확인하는 것이 좋습니다.

설정이 없거나 회색이라면

지원되지 않는 장치이거나 제조사 드라이버가 별도 처리하는 기능일 수 있습니다. 없는 메뉴를 만들려고 레지스트리나 시스템 설정을 무리하게 수정하지 마세요.

공식 출처: Microsoft - 오디오 향상 끄기, Microsoft - 음질이 지직거리거나 왜곡될 때

11. 소리가 지직거리거나 느리게 재생되면 기본 오디오 형식 변경

전체적으로 소리가 나오긴 하지만 잡음이 들리거나 일부 프로그램에서 소리가 왜곡된다면 오디오 장치에 설정된 **기본 형식(Default format)**을 확인할 수 있습니다.

Microsoft는 일부 장치에서 지원되지 않거나 적절하지 않은 오디오 형식이 낮은 음량·잡음·왜곡을 일으킬 수 있다고 설명합니다.

기본 형식 확인 순서

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 출력에서 문제가 있는 오디오 장치를 선택합니다.
  3. 고급 또는 기본 형식 항목을 찾습니다.
  4. 현재 설정된 형식을 기록합니다.
  5. 장치가 지원하는 다른 형식이 있다면 선택합니다.
  6. 오디오 파일을 재생해 변화가 있는지 확인합니다.
  7. 문제가 해결되지 않았다면 이전 설정으로 돌아갑니다.

24비트·48kHz가 항상 좋을까요?

오디오 장치의 지원 사양, 드라이버, 앱 요구 사항에 따라 적합한 형식이 다릅니다. 숫자가 높다고 모든 장치에서 무조건 정상 재생되거나 음질이 개선되는 것은 아닙니다.

외장 오디오 인터페이스를 사용한다면

음악 제작·녹음용 외장 오디오 장치는 Windows 기본 형식 외에도 제조사 드라이버·전용 앱·DAW의 샘플 레이트 설정을 사용할 수 있습니다.

작업 중인 오디오 프로젝트가 있다면 원래 설정값을 기록하고 작업을 저장한 뒤 형식 변경을 시험하세요.

게임에서만 깨지는 경우

게임 자체의 오디오 설정, Windows 볼륨 믹서, 출력 장치와 형식을 비교할 수 있습니다. 시스템 전체 소리가 정상이라면 특정 게임·앱에서만 발생하는 문제인지 확인하는 것이 우선입니다.

공식 출처: Microsoft - 오디오 형식 변경으로 왜곡 해결, Microsoft - 소리가 작을 때 기본 형식 확인

12. Windows 11 오디오 자동 문제 해결사 실행하기

출력 장치·음량·볼륨 믹서를 확인했는데도 소리가 나지 않는다면 Windows 11의 오디오 자동 문제 해결사를 실행할 수 있습니다.

도움말 보기(Get Help)에서 실행

  1. 시작 메뉴에서 도움말 보기를 검색합니다.
  2. Microsoft 도움말 보기(Get Help) 앱을 엽니다.
  3. 오디오 또는 소리 문제 해결 항목을 찾습니다.
  4. 자동 진단이 제공되면 실행합니다.
  5. 현재 문제가 있는 스피커·헤드폰을 정확히 지정합니다.
  6. 문제 해결사가 제안하는 조치를 확인합니다.
  7. 필요하다면 재시작 전에 열려 있는 파일을 저장합니다.
  8. 진단 뒤 실제 소리 재생 여부를 다시 시험합니다.

Microsoft는 Windows 11 기기에서는 도움말 보기의 자동 오디오 문제 해결사를 우선 실행하도록 안내합니다.

문제 해결사에서 아무 문제도 발견하지 못하면?

그렇다고 오디오 장치 자체가 무조건 정상이라는 뜻은 아닙니다. 외장 스피커 전원·케이블, 특정 앱 설정, 드라이버 오류 등이 그대로 남아 있을 수 있습니다.

진단을 반복하는 대신 기록할 것

문제가 해결되지 않았다면 출력 장치 이름·오류 코드·업데이트 직후인지·Windows 빌드·어느 앱에서 재현되는지를 기록해 두세요.

관리형 PC는 조직 보안 정책에 따라 일부 자동 변경이 제한될 수 있으므로, 관리자 권한이 필요한 조치는 사내 IT 담당자에게 문의하세요.

공식 출처: Microsoft - Windows 11 오디오 자동 문제 해결사

13. Windows Audio·Endpoint Builder 서비스 다시 시작하기

Windows 오디오 서비스가 제대로 동작하지 않으면 스피커와 드라이버가 있어도 소리가 재생되지 않을 수 있습니다.

Microsoft는 오디오가 작동하지 않거나 업데이트 후 멈춘 상황에서 Windows Audio 및 Windows Audio Endpoint Builder 서비스의 재시작을 안내합니다.

서비스 재시작 순서

  1. Windows 키 + R을 누릅니다.
  2. 다음을 입력하고 Enter 키를 누릅니다.
services.msc
  1. 서비스 목록에서 Windows Audio를 찾습니다.
  2. 해당 서비스를 오른쪽 클릭하고 다시 시작을 선택합니다.
  3. Windows Audio Endpoint Builder를 찾습니다.
  4. 마찬가지로 다시 시작을 선택합니다.
  5. 문제가 있는 앱을 다시 실행하거나 소리 재생을 테스트합니다.

재시작하면 무엇이 달라지나요?

Windows의 오디오 서비스를 새로 실행해 일시적인 서비스 오류를 해결할 수 있습니다. 설치된 프로그램이나 개인 파일을 삭제하는 작업은 아닙니다.

그러나 현재 진행 중인 영상회의·녹음·방송이나 가상 오디오 장치에는 일시적인 영향을 줄 수 있습니다. 중요한 업무 작업은 먼저 저장·종료한 뒤 시험하세요.

'다시 시작'이 회색이거나 관리자 권한이 없다면?

관리자 정책·서비스 상태에 따라 선택할 수 없을 수 있습니다. 회사·학교 기기에서 임의로 서비스를 강제 종료하거나 보안 정책을 변경하지 마세요.

서비스가 시작되지 않는다면?

오류 코드 또는 화면의 자세한 문구를 기록하세요. 오디오 드라이버, 장치 상태, Windows 구성 요소 문제가 관련될 수 있으므로 반복적으로 서비스만 재시작하기보다 공식 드라이버 점검으로 넘어갑니다.

14. '오디오 출력 장치가 설치되지 않았습니다' 해결법

작업 표시줄의 스피커 아이콘에 오류가 표시되거나 **'오디오 출력 장치가 설치되지 않았습니다(No audio output device is installed)'**라는 메시지가 나온다면 Windows가 오디오 출력 장치를 정상 감지하지 못하는 상황일 수 있습니다.

Microsoft는 장치 비활성화·누락·오래된 드라이버·드라이버 로딩 실패 등을 원인으로 제시합니다.

장치 관리자에서 확인

  1. 시작 메뉴에서 장치 관리자를 검색합니다.
  2. 소리, 비디오 및 게임 컨트롤러를 펼칩니다.
  3. 오디오 장치가 표시되는지 확인합니다.
  4. 장치가 사용 안 함 상태라면 디바이스 사용 메뉴가 제공되는지 확인합니다.
  5. 장치가 없다면 보기 → 숨겨진 장치 표시를 확인합니다.
  6. 동작 → 하드웨어 변경 사항 검색을 실행해 봅니다.
  7. 노란색 경고 표시가 있으면 속성 → 장치 상태에서 오류 코드를 기록합니다.
  8. 제조사 공식 지원에서 해당 모델의 드라이버를 확인합니다.

장치 자체가 아예 보이지 않으면?

하드웨어가 BIOS·UEFI 설정에서 비활성화됐거나, 내부 오디오 장치에 결함이 있거나, 드라이버가 설치되지 않은 상태일 수 있습니다. 그러나 장치 목록에 없다는 사실만으로 물리적 고장을 확정할 수는 없습니다.

사운드 카드 드라이버를 임의로 설치해도 될까요?

다른 제조사 장치에 맞는 드라이버를 무작정 설치하면 정상 동작하지 않을 수 있습니다. 노트북·메인보드 정확한 모델명을 확인하고 제조사 공식 지원 페이지에서 Windows 11 호환 드라이버를 이용하는 것이 좋습니다.

'숨겨진 장치 표시'를 켰는데 회색 장치가 보인다면?

과거 연결됐던 장치가 비활성 상태로 남아 있을 수도 있습니다. 회색 아이콘을 발견했다는 이유만으로 반드시 사용할 수 있는 오디오 하드웨어가 있다는 뜻은 아닙니다.

공식 출처: Microsoft - 오디오 출력 장치가 감지되지 않을 때

15. 오디오 드라이버 업데이트·롤백·재설치할 때 주의

오디오 출력 장치가 감지되지만 소리가 나지 않거나 Windows 업데이트 뒤 갑자기 문제가 발생했다면 드라이버 상태를 점검할 수 있습니다.

Windows 업데이트부터 확인

  1. 설정 → Windows 업데이트를 엽니다.
  2. 업데이트 확인을 선택합니다.
  3. 공식 업데이트가 있다면 내용과 재시작 필요 여부를 확인합니다.
  4. 제공되는 경우 고급 옵션 → 선택적 업데이트에서 오디오 관련 드라이버를 살펴봅니다.
  5. 호환되는 업데이트를 적용한 뒤 PC를 재시작합니다.
  6. 설정 → 시스템 → 소리 → 출력에서 장치가 정상인지 확인합니다.

장치 관리자에서 드라이버 업데이트

  1. 장치 관리자 → 소리, 비디오 및 게임 컨트롤러를 엽니다.
  2. 실제 오디오 장치를 오른쪽 클릭합니다.
  3. 드라이버 업데이트 → 드라이버 자동 검색을 선택합니다.
  4. 설치 후 재시작하고 테스트합니다.

업데이트 후부터 소리가 안 나면 드라이버 롤백

  1. 장치 관리자에서 문제 장치를 선택합니다.
  2. 속성 → 드라이버 탭을 엽니다.
  3. 드라이버 롤백 버튼이 활성화됐는지 확인합니다.
  4. 업데이트 직후 문제가 시작됐다면 이전 버전으로 되돌리는 방법을 검토합니다.
  5. 재시작 후 소리가 복구됐는지 확인합니다.

Microsoft는 이전 드라이버 버전이 저장된 경우에만 롤백 버튼이 사용 가능하다고 설명합니다.

드라이버 제거는 언제?

출력 선택·볼륨 믹서·오디오 향상·서비스·업데이트를 확인해도 오류가 남을 때 검토할 수 있습니다.

드라이버 제거 전에 노트북·메인보드 제조사의 공식 설치 파일과 복구 방법을 준비하세요. Windows가 재시작 후 드라이버를 자동으로 다시 설치할 수 있지만 모든 기기에서 성공한다고 보장할 수는 없습니다.

권장하지 않는 방법: 출처 불명 드라이버 자동 수리 앱 설치, 모든 오디오 장치 일괄 삭제, 회사 PC에서 관리자 승인 없이 시스템 드라이버 강제 변경

공식 출처: Microsoft - 업데이트 후 오디오가 멈춘 문제, Microsoft - 전체 오디오 드라이버 문제 해결

16. 소리는 정상인데 Teams·Zoom에서 상대방 목소리만 안 들릴 때

Windows의 유튜브나 음악은 정상 재생되는데 영상회의 앱에서 상대방 목소리만 안 들린다면 Windows 전체 설정과 회의 앱 설정을 나눠 확인하는 것이 중요합니다.

회의 앱에서 스피커를 별도로 선택

  1. Windows 설정 → 시스템 → 소리 → 출력에서 실제 사용할 스피커를 확인합니다.
  2. 회의 앱의 설정 또는 오디오 설정을 엽니다.
  3. 스피커·출력 장치 항목에서 같은 장치를 선택합니다.
  4. 앱 자체 음량과 음소거 여부를 확인합니다.
  5. Windows 볼륨 믹서에서 해당 앱이 음소거돼 있지 않은지 점검합니다.
  6. 회의 앱에 테스트 스피커가 제공된다면 짧게 시험합니다.

내 목소리는 정상인데 상대가 안 들린다면?

이 상황은 출력 장치 문제일 수 있습니다. 다른 참석자에게 내 마이크 입력이 정상이라고 확인됐다고 해서 스피커 설정도 정상이라는 뜻은 아닙니다.

헤드셋을 회의 중에 연결했다면

USB·Bluetooth 헤드셋을 회의 도중 연결하면 앱이 이전 출력 장치를 계속 사용할 수 있습니다. 회의 앱의 장치 선택을 다시 확인하세요.

원격 데스크톱·가상 PC라면

회의 소리가 원격 PC 쪽으로 설정되거나 조직의 오디오 전달 정책이 적용될 수 있습니다. 업무용 PC는 원격 오디오 설정과 회사 IT 정책을 확인하세요.

앱 문제인지 Windows 문제인지 결정하기

  • 유튜브·Windows 테스트도 모두 안 들림: 출력 장치·드라이버·서비스 우선
  • 다른 소리는 모두 들리지만 Teams만 안 들림: Teams 앱 음량·출력 장치 우선
  • 이어폰으로는 들리고 스피커로는 안 들림: 장치 전환·물리 스피커 점검
  • 특정 회의에 입장한 뒤에만 안 들림: 회의 앱 오디오 참가 설정 확인

공식 출처: Microsoft - 앱 오디오만 동작하지 않을 때, Microsoft - 오디오 출력 진단

17. 소리 문제 해결 후 재발 방지: 5분 점검 순서

한 번 소리가 복구됐더라도 출력 기기를 자주 바꾸거나 외부 모니터를 사용하는 컴퓨터라면 동일한 문제가 다시 발생할 수 있습니다.

출력 장치 목록 정리

Windows 설정 → 시스템 → 소리 → 출력에서 평소 사용할 장치를 확인해 두세요. 외부 모니터·USB DAC·Bluetooth 이어폰 등이 많다면 실제 어떤 기기가 소리를 내는지 알아두는 것이 좋습니다.

볼륨 믹서의 앱별 설정 확인

특정 브라우저·게임이 예전에 음소거됐거나 다른 장치로 고정됐다면 다음 사용에서도 소리가 나지 않는 것처럼 느껴질 수 있습니다. 볼륨 믹서에서 앱별 출력 장치와 음량을 점검하세요.

Windows 업데이트 뒤 문제 여부 기록

Windows 업데이트 직후 소리가 사라졌다면 설치 시각, Windows 빌드, 오디오 드라이버 버전 등을 기록해 두세요. 문제 해결을 위한 드라이버 롤백 여부를 판단할 때 도움이 됩니다.

지원되는 드라이버만 사용

노트북·메인보드·오디오 인터페이스 제조사가 공식 지원하는 Windows 11 드라이버를 우선하세요. 인터넷에서 찾은 드라이버가 단순히 모델명이 비슷하다는 이유만으로 호환된다고 단정하면 안 됩니다.

소리가 복구됐다면 실제 앱에서도 확인

Windows 테스트음이나 시스템 알림이 들렸다면 유튜브, 음악 플레이어, 게임, 영상회의처럼 평소 사용하는 앱에서도 소리가 정상인지 비교하세요.

핵심: Windows 오디오가 작동하는 것과 모든 앱이 같은 출력 장치를 사용한다는 것은 별개입니다.

자주 묻는 질문 FAQ

Q1. Windows 11에서 소리가 갑자기 안 나면 가장 먼저 무엇을 해야 하나요?

설정 → 시스템 → 소리 → 출력에서 실제로 듣는 스피커·이어폰이 선택됐는지 확인하고 음소거·시스템 음량을 점검하세요. 외장 스피커 전원과 유선 연결도 확인해야 합니다.

Q2. 스피커 음량이 100인데도 아무 소리가 안 나는 이유는?

다른 출력 장치가 선택됐거나 앱별 음소거·오디오 향상·드라이버 오류가 있을 수 있습니다. 출력 장치 선택 → 볼륨 믹서 → 오디오 향상 끄기 순서로 확인하세요.

Q3. 유튜브·Chrome만 소리가 안 나오면 어디서 설정하나요?

설정 → 시스템 → 소리 → 볼륨 믹서에서 Chrome의 음소거·음량·출력 장치를 확인하세요. 동영상 자체 플레이어의 음소거와 브라우저 탭 음소거도 확인해야 합니다.

Q4. HDMI 모니터 연결 후 노트북 소리가 사라졌습니다

Windows가 HDMI·DisplayPort로 연결한 모니터를 기본 오디오 출력 장치로 선택했을 수 있습니다. 설정 → 시스템 → 소리 → 출력에서 노트북 스피커나 원하는 장치로 다시 변경하세요.

Q5. 이어폰을 꽂았는데 스피커에서 소리가 나는 이유는?

유선 단자 연결, 실제 출력 선택, 오디오 장치 자동 감지, 드라이버와 관련이 있을 수 있습니다. USB-C 이어폰은 별도 호환성도 확인해야 하므로 제조사 설명서를 참고하세요.

Q6. Windows 11의 볼륨 믹서는 어디에 있나요?

설정 → 시스템 → 소리 → 볼륨 믹서에서 열 수 있습니다. 앱별 음소거와 음량, 출력 장치를 확인할 수 있으며, 작업 표시줄의 볼륨 아이콘을 오른쪽 클릭하는 방법도 있습니다.

Q7. 오디오 향상 기능을 끄면 소리가 다시 나올 수 있나요?

그럴 수 있습니다. Microsoft는 일부 장치에서 오디오 향상 기능이 소리 재생을 방해하거나 왜곡할 수 있다고 안내합니다. 설정 → 시스템 → 소리 → 출력 장치 → 오디오 향상 → 끔으로 시험해 보세요.

Q8. '오디오 출력 장치가 설치되지 않았습니다'는 무슨 뜻인가요?

Windows가 사용 가능한 오디오 출력 하드웨어를 정상 감지하지 못할 수 있다는 뜻입니다. 장치 관리자 → 소리, 비디오 및 게임 컨트롤러에서 장치 활성화·오류 코드와 제조사 공식 드라이버를 확인하세요.

Q9. 윈도우 업데이트 후 소리가 안 나면 드라이버를 삭제해야 하나요?

바로 삭제할 필요는 없습니다. Microsoft는 추가 Windows 업데이트 확인, 드라이버 업데이트, 가능한 경우 이전 드라이버로 롤백, Windows Audio 서비스 재시작을 안내합니다. 드라이버 제거는 복구 수단을 확보한 뒤 검토하세요.

Q10. Windows Audio 서비스를 다시 시작하면 파일이 삭제되나요?

일반적인 Windows Audio 및 Windows Audio Endpoint Builder 서비스 재시작은 개인 파일을 삭제하는 작업이 아닙니다. 다만 실행 중인 회의·녹음·오디오 프로그램에는 일시적인 영향을 줄 수 있으므로 저장·종료 후 시도하세요.

최종 체크리스트: 소리 안 나는 컴퓨터를 점검하는 순서

먼저 확인할 기본 항목

  • 외장 스피커·이어폰에 전원이 공급되고 올바르게 연결돼 있나요?
  • Windows 작업 표시줄에서 음소거가 해제돼 있나요?
  • 설정 → 시스템 → 소리 → 출력에서 실제 사용할 장치가 선택됐나요?
  • 추가 사운드 설정 → 재생에서 기본 장치를 확인했나요?
  • 외부 HDMI 모니터를 잘못 선택하지 않았나요?

특정 프로그램만 소리가 없다면

  • Windows 볼륨 믹서에서 앱별 음량·음소거를 확인했나요?
  • 앱별 출력 장치가 다른 기기로 고정돼 있지 않나요?
  • 브라우저 영상의 자체 음소거·탭 음소거를 확인했나요?
  • Teams·Zoom의 스피커 선택이 Windows와 일치하나요?

전체 소리가 나지 않는다면

  • 도움말 보기 오디오 문제 해결사를 실행했나요?
  • 오디오 향상을 껐을 때 달라지는지 시험했나요?
  • 기본 오디오 형식 변경 전 원래 값을 기록했나요?
  • Windows Audio·Endpoint Builder 서비스 상태를 확인했나요?
  • 장치 관리자에 출력 장치나 오류 코드가 나타나나요?
  • Windows 업데이트·제조사 공식 드라이버를 확인했나요?
  • 드라이버 제거 전 복구용 설치 파일을 확보했나요?

마무리: 소리가 안 나면 볼륨보다 출력 장치와 앱 설정부터 구분하세요

Windows 11에서 스피커나 이어폰의 소리가 나지 않을 때는 출력 장치 선택과 음소거가 가장 먼저 확인할 항목입니다. 외장 모니터에 연결한 뒤 소리가 사라졌다면 HDMI 출력으로 바뀌었는지, 유튜브·게임에서만 소리가 없다면 볼륨 믹서와 앱별 출력 장치를 확인하세요.

모든 프로그램에서 소리가 안 나거나 출력 장치 자체가 보이지 않는다면 도움말 보기 문제 해결사, 오디오 향상·기본 형식, Windows Audio 서비스, 드라이버 순서로 점검하는 것이 좋습니다.

업데이트 직후 발생한 문제는 드라이버 롤백이 도움이 될 수도 있지만, 롤백이 모든 장치에서 가능한 것은 아닙니다. 오디오 드라이버를 삭제하거나 운영체제를 초기화하기 전에 정확한 PC 모델과 제조사 공식 복구 경로를 확인하면 불필요한 설정 변경을 줄일 수 있습니다.

정보 확인일: 2026년 10월 26일. 이 글은 Microsoft 공식 고객지원의 Windows 11 전체 오디오 오류, 스피커·헤드폰 무음, 앱별 볼륨 믹서, 출력 장치 누락, 낮은 음량, 음질 왜곡, Windows 업데이트 후 오디오 드라이버·서비스 복구 안내를 근거로 작성했습니다. Windows 11 빌드, PC 제조사, 오디오 장치 유형·연결 방식과 관리 정책에 따라 설정 메뉴와 복구 방법은 달라질 수 있습니다.
