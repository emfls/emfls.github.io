노트북에서 데스크톱으로 사진을 보내려고 Windows의 '근거리 공유'를 켰는데 상대 PC가 나타나지 않는 경우가 있습니다. 갤럭시에는 'Quick Share' 버튼이 보이니 Windows에서도 같은 기능일 거라고 생각하기 쉽지만, Windows에 기본 제공되는 근거리 공유와 Android용 Quick Share는 별도의 전송 기능입니다.

이 차이를 모르고 블루투스를 반복해서 연결하거나, 파일 공유 때문에 네트워크 보안을 무리하게 바꾸면 문제를 해결하지 못할 수 있습니다. 먼저 보내는 기기와 받는 기기가 무엇인지 구분하면 필요한 설정이 훨씬 명확해집니다.

이 글은 Microsoft와 Google의 공식 지원 문서를 바탕으로 Windows 11 기준의 기능을 정리했습니다. '4갈래 실패 진단표'와 '1분 시험 전송'은 독자 이해를 위해 새로 설계한 점검 방법이며, 실제 문제 해결 시간이 보장된다는 뜻은 아닙니다. 검토 기준일은 2026년 11월 1일입니다.

Microsoft의 '근거리 공유(Nearby sharing)'는 Windows PC끼리 문서·사진·웹 링크를 보내는 기능입니다. 반면 Google의 'Quick Share'는 가까운 Android 기기와 Windows PC 사이에서 파일을 주고받기 위해 Windows용 전용 앱을 사용합니다. 기능 이름이 비슷해도 무조건 서로 발견되는 것은 아닙니다.

Google의 공식 안내에서는 Windows PC 종류에 따라 앱 제공자가 다르다고 설명합니다. 일반 Windows PC에는 Google에서 제공하는 Quick Share를, 삼성 PC에는 Microsoft Store에서 제공되는 삼성 Quick Share 앱을 사용하도록 안내합니다. 설치 전에 PC 제조사를 확인하세요.

공식 근거: Microsoft — Windows에서 주변 장치와 콘텐츠 공유, Google — Android와 Windows 사이에서 Quick Share 사용

2. PC끼리 보내기: Windows 11 근거리 공유를 켜는 정확한 순서

먼저 두 컴퓨터 모두에서 아래 설정을 확인합니다. 보내는 쪽만 켜고 받는 쪽은 꺼 둔 상태가 가장 쉽게 놓치는 부분 중 하나입니다.

  1. 시작 → 설정 → 시스템 → 근거리 공유를 엽니다.
  2. '끔', '내 장치만', '주변의 모든 사용자' 중 필요한 공개 범위를 선택합니다.
  3. 두 컴퓨터가 자신의 Microsoft 계정으로 로그인돼 있는지 확인합니다.
  4. 두 PC 모두 Bluetooth와 Wi-Fi가 켜져 있는지 확인합니다.
  5. 테스트할 파일이 있는 컴퓨터에서 파일 탐색기를 엽니다.
  6. 파일을 선택해 상단의 공유 버튼 또는 파일의 마우스 오른쪽 클릭 메뉴의 공유를 누릅니다.
  7. 근거리 공유 대상 목록에 나타난 상대 PC의 이름을 클릭합니다.
  8. 받는 PC에서 알림이 나타나면 저장 또는 저장 및 열기를 선택합니다.

공유 메뉴에 앱·OneDrive·근거리 기기가 함께 표시될 수 있습니다. OneDrive 공유 링크 만들기와 근거리 PC로 직접 전송하기는 다르므로 상대 PC의 이름을 선택했는지 확인해야 합니다.

기기에 따라 메뉴 번역이 '주변 공유' 또는 '근거리 공유'처럼 나타날 수 있습니다. 실제 위치는 설정 → 시스템에서 찾아보세요.

공식 근거: Microsoft — 근거리 공유 설정과 전송, Microsoft — Windows 파일 공유 방법

3. '내 장치만'으로 했더니 상대 노트북이 안 보이는 이유

Windows 근거리 공유에서는 공개 범위 설정이 중요합니다.

  • 내 장치만(My devices only): 동일한 Microsoft 계정으로 로그인한 자신의 장치들끼리 공유하려는 경우에 적합합니다.
  • 주변의 모든 사용자(Everyone nearby): 근처의 다른 사람 PC와 공유할 때 필요할 수 있습니다.

예를 들어 회사 노트북과 개인 노트북에 서로 다른 Microsoft 계정을 사용한다면 '내 장치만'으로는 상대 장치가 검색되지 않을 수 있습니다. 이때 공유 목적과 신뢰 관계를 확인한 후 일시적으로 '주변의 모든 사용자'로 바꿔 시험해 볼 수 있습니다.

개인정보 주의: Microsoft는 '주변의 모든 사용자'를 선택하면 PC 이름과 Bluetooth MAC 주소가 근처 장치에 공개될 수 있으며, 이를 이용해 해당 PC와 사용자를 연결할 가능성이 있다고 설명합니다. 공유를 마친 뒤에는 공개 범위를 다시 제한하거나 기능을 끄는 것이 좋습니다.

업무용 PC에서는 관리자 정책으로 설정 변경이 막혀 있을 수 있습니다. 관리자가 차단한 보안 정책을 임의로 우회하지 말고 IT 담당자에게 문의하세요.

공식 근거: Microsoft — 공유 대상 선택과 개인정보 안내

4. PC 이름이 목록에 아예 없으면 '발견 단계'부터 진단

파일 전송이 실패하는 지점을 다음처럼 네 갈래로 나눠 보세요.

현재 증상먼저 확인할 항목다음 조치
A. 공유 메뉴에 '근거리 공유' 자체가 없음Windows 버전·Bluetooth LE 지원·기능 활성화시스템 요구 사항 확인
B. 근거리 공유는 있지만 상대 PC가 안 보임상대 PC 설정·공개 범위·Bluetooth·Wi-Fi양쪽 설정 맞추기
C. 상대 PC는 보이는데 '수신 대기 중'에서 멈춤받는 쪽 알림·계정·절전 상태알림 확인 및 재시작
D. 전송되다가 끊기거나 매우 느림연결 방식·거리·전원·대용량 파일작은 파일과 Wi-Fi로 비교

A. 근거리 공유 항목이 아예 보이지 않는 경우

Windows의 근거리 공유에는 지원되는 Bluetooth 하드웨어가 필요합니다. Microsoft의 문제 해결 문서는 Bluetooth 4.0 이상과 Bluetooth Low Energy(LE) 지원을 확인하라고 안내합니다.

  1. 시작 메뉴에서 **장치 관리자(Device Manager)**를 검색해 실행합니다.
  2. Bluetooth 목록을 펼칩니다.
  3. Bluetooth 무선 어댑터를 마우스 오른쪽 버튼으로 누르고 속성을 엽니다.
  4. 자세히(Details) 탭으로 이동합니다.
  5. 속성 목록에서 Bluetooth radio supports Low Energy Central Role을 선택할 수 있다면 해당 값이 True인지 확인합니다.

메뉴 명칭과 표시되는 속성은 드라이버에 따라 다를 수 있습니다. 'True'가 아니거나 관련 기능이 표시되지 않는다면 제조사의 Bluetooth 사양과 최신 호환 드라이버를 확인하세요. 무작정 출처가 불분명한 드라이버 파일을 설치하지 않는 것이 좋습니다.

공식 근거: Microsoft — 근거리 공유 문제 해결: 시스템 요구 사항

B. 근거리 공유는 켜졌는데 상대 PC가 안 보이는 경우

다음 순서를 따르는 것이 효율적입니다.

  1. 두 PC 모두 설정 → 시스템 → 근거리 공유가 켜져 있는지 확인합니다.
  2. 두 장치의 공개 범위를 확인합니다. 서로 다른 계정이면 '내 장치만'이 원인인지 점검합니다.
  3. Bluetooth와 Wi-Fi를 양쪽에서 모두 켜 봅니다.
  4. 장치를 가까이 놓고 파일 공유를 다시 실행합니다.
  5. Bluetooth 또는 Wi-Fi를 껐다 켜고 검색을 다시 시도합니다.
  6. 그래도 인식이 되지 않으면 PC를 다시 시작합니다.

Bluetooth 이어폰이 연결된다고 반드시 근거리 공유를 지원하는 Bluetooth 기능까지 정상적이라는 뜻은 아닙니다. Bluetooth LE 지원과 근거리 공유 설정을 별개로 확인하세요.

5. 느린 전송의 핵심: 같은 '신뢰할 수 있는 개인 Wi-Fi'인지 확인

최근 Windows 11에서 근거리 공유를 사용할 때, Microsoft는 받는 PC도 동일한 개인(Private) Wi-Fi 네트워크에 연결된 경우 Wi-Fi로 공유할 수 있고, 그렇지 않은 경우 Bluetooth를 사용할 수 있다고 설명합니다.

Bluetooth 전송은 큰 영상 파일이나 여러 장의 고해상도 사진을 보내기에는 느릴 수 있습니다. 같은 이름처럼 보이는 Wi-Fi에 연결했다고 해도 게스트 네트워크나 기기 간 통신 차단 정책 때문에 연결되지 않을 수 있습니다.

점검 순서

  1. 각 PC의 설정 → 네트워크 및 인터넷 → Wi-Fi를 엽니다.
  2. 실제 연결된 Wi-Fi 이름을 확인합니다.
  3. 집이나 믿을 수 있는 사무실 네트워크인지 확인합니다.
  4. 연결된 네트워크의 속성에서 네트워크 프로필이 개인 네트워크인지 확인합니다.
  5. 작은 파일부터 전송해 정상 동작을 시험합니다.

보안상 중요한 주의: 카페·공항·호텔의 공용 Wi-Fi를 파일 공유 때문에 무조건 '개인 네트워크'로 바꿔서는 안 됩니다. 공용망에서는 노출 범위가 달라질 수 있으니, 보안 정책을 유지한 채 다른 안전한 전송 방법을 선택하세요.

Microsoft 문서도 개인 Wi-Fi 네트워크에서 전송 조건과 속도가 달라진다고 설명하지만, 동일한 Wi-Fi에 접속하면 모든 환경에서 자동으로 고속 전송이 보장된다는 뜻은 아닙니다. 기기·드라이버·네트워크 정책에 따라 차이가 있습니다.

공식 근거: Microsoft — Wi-Fi와 Bluetooth 근거리 공유 조건, Microsoft — 근거리 공유가 느릴 때

6. '수신 대기 중'에서 멈출 때: 받는 PC를 먼저 살펴보세요

보내는 PC에는 상대 이름이 표시되지만 전송이 끝나지 않는 경우, 받는 쪽에서 저장 요청 알림을 확인하지 못했을 가능성부터 점검하세요.

  1. 받는 컴퓨터를 잠금 해제하고 화면을 켭니다.
  2. Windows 알림 센터에 파일 수신 요청이 있는지 확인합니다.
  3. 방해 금지·집중 모드 등 알림 표시 상태를 점검합니다.
  4. 두 장치의 '근거리 공유' 공개 범위가 적절한지 다시 확인합니다.
  5. 양쪽 Bluetooth를 껐다 켭니다.
  6. 동일 증상이 반복되면 두 PC를 다시 시작해 재시도합니다.

수신 요청이 있는 경우 파일을 받을 의사가 있는지 확인한 후 저장 또는 저장 및 열기를 선택해야 합니다. 낯선 사람의 파일 수신 요청은 승인하지 마세요.

Microsoft는 수신 알림이 화면에 보이지 않아도 알림 센터에 남아 있을 수 있으며, 수신 대기 문제가 반복되면 Bluetooth 재시작과 PC 재부팅을 시도하라고 안내합니다.

공식 근거: Microsoft — 알림이 없거나 수신 대기 중일 때

7. 전송이 중간에 끊기면: 거리·절전·파일 크기를 나눠 검사

전송을 시작한 뒤 중간에 실패하는 문제는 발견 단계의 오류와 다릅니다. 이미 서로 검색은 됐으므로 연결이 유지되는 조건부터 확인해야 합니다.

  • 거리: 두 PC를 가까이 놓습니다. Microsoft의 문제 해결 문서는 특히 Bluetooth 환경에서 약 10m 이내를 권합니다. 장애물과 전파 간섭에 따라 실제 거리는 달라집니다.
  • 절전: 전송 도중 PC가 절전 상태로 들어가지 않도록 잠시 설정을 확인합니다. 장시간 절전 제한이 필요하지 않다면 시험 후 원래 값으로 복원합니다.
  • 파일 크기: 처음에는 작은 텍스트 파일로 시험하고 다음에 사진·동영상으로 확장합니다.
  • 연결 경로: 두 PC가 신뢰 가능한 동일 개인 Wi-Fi를 이용할 수 있다면 Bluetooth 전송과 속도를 비교합니다.
  • 보안 소프트웨어: 연결을 방해하는지 검토할 수 있으나 보안을 유지한 채 관리자 안내와 소프트웨어 설정을 확인하는 것이 우선입니다.

공식 문서에 방화벽을 일시적으로 꺼 보는 문제 해결법이 등장하더라도, 실무에서는 보안 제품을 무턱대고 끄지 않는 편이 안전합니다. 특히 회사 PC에서 정책 우회나 무단 방화벽 해제는 피하세요.

8. 전송 완료인데 파일이 어디에 있는지 모르겠다면

전송이 완료돼도 받은 파일의 저장 위치를 바로 찾지 못하는 경우가 있습니다. 다운로드 폴더만 뒤지기 전에 받는 PC의 근거리 공유 저장 경로를 확인하세요.

  1. 파일을 받은 PC에서 설정 → 시스템 → 근거리 공유를 엽니다.
  2. 받은 파일 저장 위치(Save files I receive to) 항목을 확인합니다.
  3. 설정된 폴더를 파일 탐색기에서 엽니다.
  4. 파일 이름 또는 수정 시간을 기준으로 확인합니다.
  5. 필요하면 해당 설정에서 **변경(Change)**을 눌러 다음부터 사용할 폴더를 선택합니다.

파일이 안 보인다고 즉시 다시 전송하기보다 수신 결과와 저장 경로를 먼저 확인하면 중복 파일 생성을 줄일 수 있습니다.

공식 근거: Microsoft — 받은 파일의 저장 폴더 변경

9. 갤럭시에서 Windows로 보낼 때는 왜 근거리 공유에 안 뜰까

갤럭시의 사진 앱에서 공유 → Quick Share를 눌러도, Windows 11의 설정 → 시스템 → 근거리 공유만 켠 PC가 자동으로 수신 대상이 되는 것은 아닙니다. 서로 다른 시스템을 사용하기 때문입니다.

Google이 안내하는 Android와 Windows 간 공유의 기본 준비는 다음과 같습니다.

  1. Windows PC에 해당 제조사에 맞는 Quick Share 앱을 설치합니다.
  2. 앱을 열고 기기 이름과 수신 공개 범위를 설정합니다.
  3. 갤럭시 등 Android 스마트폰에서 공유할 사진·문서를 선택합니다.
  4. 공유 메뉴의 Quick Share를 선택합니다.
  5. PC가 검색되는지 확인하고 파일을 보냅니다.
  6. PC에 수신 요청이 나타나면 발신 기기를 확인한 후 수락합니다.

Google 도움말은 Android 6.0 이상 기기를 지원 대상으로 안내하며, Windows 쪽에서는 지원되는 버전·하드웨어와 Bluetooth, Wi-Fi 또는 이더넷 사용 조건을 확인해야 한다고 설명합니다. 두 기기를 5m 이내에 두고 같은 네트워크에 연결하도록 권고합니다.

또한 최근 공식 도움말은 삼성 PC에서는 Microsoft Store의 삼성 Quick Share, 일반 PC에서는 Google의 Windows용 Quick Share를 사용하라고 구분합니다. 내 PC의 제조사와 실제 설치 앱을 먼저 확인하세요. ARM 기반 Windows 지원 등 세부 호환성은 안내 페이지와 앱 버전에 따라 차이가 있을 수 있으므로 해당 기기용 최신 안내를 따르는 것이 정확합니다.

공식 근거: Google — Windows용 Quick Share 설정·지원 조건, Android — Windows PC와 Quick Share

11. 최소 위험 '1분 시험 전송'으로 문제 범위를 줄이기

고장 원인을 몰라서 모든 설정을 한꺼번에 바꾸는 것보다, 가장 단순한 상황에서 한 번 성공해 보는 편이 효과적입니다. 아래 방법은 사용자에게 권하는 진단용 실험이며 실제 1분 이내 완료를 보장하지 않습니다.

  1. 두 Windows PC를 가까이 두고 화면을 켭니다.
  2. 양쪽에서 근거리 공유와 Bluetooth를 켭니다.
  3. 개인 PC 두 대이고 동일 Microsoft 계정이라면 '내 장치만', 다른 계정이라면 공개 범위를 검토해 알맞게 설정합니다.
  4. 테스트 용도로 빈 텍스트 파일을 만듭니다. 민감한 자료는 사용하지 마세요.
  5. 해당 파일을 파일 탐색기에서 공유하고 대상 PC를 선택합니다.
  6. 상대 PC에 수신 요청이 표시되는지 확인합니다.
  7. 승인 후 받은 파일의 저장 위치를 확인합니다.
  8. 시험이 성공하면 사진·문서, 그 다음에 큰 파일 순으로 테스트합니다.

12. 자주 묻는 질문

Q. Windows 11 근거리 공유는 인터넷이 없어도 되나요?

근거리 공유는 Bluetooth 또는 Wi-Fi를 이용하는 PC 간 공유 기능입니다. 인터넷을 통한 클라우드 업로드가 필수인 공유 방식과는 다릅니다. 다만 실제 연결 방식과 기기 조건이 맞아야 하므로 네트워크 설정과 Bluetooth 지원 여부를 확인해야 합니다.

Q. 근거리 공유를 켰는데 갤럭시가 안 보이는 이유는 무엇인가요?

Windows 기본 근거리 공유는 Windows PC 간 전송 기능이기 때문입니다. Android와 Windows 사이에서는 별도의 Quick Share 앱과 설정을 확인해야 합니다.

Q. Windows 10과 Windows 11끼리도 가능한가요?

Microsoft는 Windows 10 버전 1803 이상의 지원 기기에서 Windows 근거리 공유를 이용할 수 있다고 설명합니다. 다만 Windows 10은 2025년 10월 14일 일반 지원이 종료됐으므로, 보안 업데이트 지원 상태도 별도로 확인하세요.

Q. 같은 Wi-Fi인데 파일 전송 속도가 매우 느립니다.

실제로 Wi-Fi 전송으로 연결됐는지, 네트워크가 신뢰할 수 있는 개인 프로필인지, 두 PC의 Bluetooth·Wi-Fi 드라이버가 정상인지 확인하세요. 환경에 따라 Bluetooth 전송을 사용하면 속도가 더 느릴 수 있습니다.

Q. 상대 PC와 Bluetooth 설정에서 먼저 페어링해야 하나요?

근거리 공유 설정과 Bluetooth 하드웨어 지원부터 확인하세요. Microsoft의 문제 해결 문서에 페어링 문제에 대한 별도 조치가 있지만, 무조건 수동 페어링부터 반복하는 것이 첫 해결책은 아닙니다. 공개 범위·근거리 공유 설정·연결 상태를 먼저 점검하는 편이 낫습니다.

Q. '주변의 모든 사용자'를 켜 두어도 안전한가요?

Microsoft는 이 설정에서 PC 이름과 Bluetooth MAC 주소가 다른 가까운 기기에 노출될 수 있다고 안내합니다. 필요할 때만 사용하고 공유 후 제한하는 것이 좋습니다. 알 수 없는 파일 수신 요청도 승인하지 마세요.

결론: 문제 해결의 첫 질문은 '누가 누구에게 보내는가'

두 Windows PC끼리 파일을 보내는 문제라면 Windows 근거리 공유 설정, 공개 범위, Bluetooth LE, 동일한 개인 Wi-Fi 조건을 확인해야 합니다. 갤럭시·Android와 Windows 사이에서 보내려는 경우에는 Quick Share 앱 설치와 기기 공개 범위, 제조사에 맞는 앱 선택이 먼저입니다.

두 기능을 구별한 뒤 검색되지 않음 → 수신 대기 → 느린 전송 → 저장 위치 순으로 나누어 보면 불필요한 재설치나 설정 초기화를 피할 수 있습니다. 공개 범위를 임시로 넓혔다면 시험 후 다시 줄이고, 개인 파일은 신뢰하는 기기에만 전송하세요.
