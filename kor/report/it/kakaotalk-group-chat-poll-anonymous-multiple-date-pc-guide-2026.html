2. 갤럭시·아이폰에서 단톡방 투표 만드는 순서

  1. 카카오톡에서 투표를 올릴 단체 채팅방을 엽니다.
  2. 오른쪽 위 메뉴(≡)를 누릅니다.
  3. 투표 또는 톡게시판 → 투표 메뉴를 엽니다.
  4. 투표 올리기, 글쓰기(연필 모양)를 선택합니다.
  5. 제목과 후보 항목을 입력합니다.
  6. 필요하면 익명·복수선택·마감 시간을 설정합니다.
  7. 완료·등록 버튼을 누릅니다.
  8. 채팅방에 투표 카드가 공유됐는지 확인합니다.

버전에 따라 입력창 왼쪽 + 메뉴에서 진입하는 사례도 있습니다. 메뉴를 찾을 수 없다면 채팅방 상단의 톡게시판을 우선 살펴보세요.

공식 근거: 카카오 Windows 투표 기능 안내. 모바일 메뉴는 카카오톡 버전에 따라 다를 수 있습니다.

3. PC 카카오톡 투표 만들기: Windows 공식 근거와 메뉴

Windows PC에서도 게시판 투표를 작성할 수 있다는 공식 기록이 있습니다. 카카오가 2023년 2월 21일 게시한 3.4.7 버전 업데이트 공지는 '날짜 투표 작성 화면'과 '종료된 투표 복제하기'를 소개합니다. 과거 설명 중 "PC에서는 투표 참여만 가능하다"는 내용은 이 공식 기록과 충돌합니다.

PC에서 직접 해보려면 다음 순서로 확인합니다.

  1. 카카오톡 PC 앱에서 해당 단체 채팅방을 엽니다.
  2. 오른쪽 위 채팅방 메뉴(≡)를 선택합니다.
  3. 톡게시판 → 투표 또는 게시판 안의 투표 탭을 찾습니다.
  4. 새 투표 작성/글쓰기 버튼을 선택합니다.
  5. 제목과 선택지를 입력하고 옵션을 설정합니다.
  6. 등록한 뒤 같은 방에 투표가 올라왔는지 확인합니다.

Mac에서는 주의: 위 공식 업데이트는 Windows 기준입니다. Mac 앱에서 같은 화면을 제공한다고 확정하지 말고 현행 Mac 앱의 메뉴·업데이트 안내를 확인해야 합니다.

PC 설치 주의: 카카오는 자사 기업 사이트와 Microsoft Store 이외의 비공식 카카오톡 설치 파일에 대한 주의를 당부합니다. 투표 메뉴가 없다는 이유로 출처가 불분명한 설치 파일을 받지 마세요.

공식 출처: 카카오 Windows 3.4.7 게시판 투표 업데이트, 카카오 공식 PC 설치 경로 안내

4. 익명투표 설정: 누가 투표했는지 보일까?

익명투표는 각 후보에 누가 선택했는지 공개하지 않는 방식입니다. 개인적인 선호나 민감하지 않은 만족도 조사를 진행할 때 사용할 수 있습니다.

  • 익명 ON: 개별 참가자의 선택을 드러내지 않고 결과를 집계합니다. 전체 득표 수 자체가 숨겨지는 것은 아닙니다.
  • 익명 OFF: 참여자별로 선택 사항을 확인할 수 있는 화면이 제공될 수 있습니다. 실제 참석자 명단 확보 등 목적에 맞습니다.
  • 주의: 익명이라고 해도 채팅방에 누가 참여했는지까지 사라지는 것은 아닙니다. 투표 참여자 총수나 별도의 채팅 기록과는 다른 문제입니다.

예시: 회식 메뉴를 정한다면 익명을 켜도 좋지만, 실제 버스 좌석을 예약해야 하는 행사라면 누가 참석하는지 확인할 수 있도록 비익명 방식이 나을 수 있습니다.

익명 설정을 투표 시작 후에도 마음대로 바꿀 수 있다고 가정하면 안 됩니다. 등록 전에 설정과 참여자 공개 범위를 검토하세요.

5. 복수선택은 언제 켜야 하나요?

단일선택과 복수선택의 구분은 답변의 의미 자체를 바꿉니다.

질문추천실수 방지
4개 메뉴 중 오늘 먹을 음식 하나단일선택한 사람당 하나만 고름
참석 가능한 날짜를 모두 선택복수선택가능한 날짜를 빠짐없이 반영
가장 마음에 드는 후보 한 명단일선택투표의 목적을 명시
관심 있는 학습 주제를 모두 선택복수선택여러 후보 선호 파악
참석/불참/미정 중 하나단일선택서로 배타적인 상태 선택

예를 들어 A 날짜와 B 날짜 모두 참석 가능한 사람에게 하나만 선택하게 하면 실제로는 가능한 날짜가 적게 집계될 수 있습니다. 이런 상황에서는 복수선택이 적절합니다.

집계 해석 주의: 복수선택은 전체 득표 수가 투표 참여자 수보다 많아질 수 있습니다. 8명이 투표에 참여해 A 6표, B 5표, C 4표를 기록했다면 득표 수 총합은 15표지만 15명이 참여한 것이 아닙니다. 숫자는 설명을 위한 가상 사례입니다.

6. 날짜 투표 만들기: 모임 날짜를 정할 때

카카오 공식 Windows 업데이트에서는 날짜 후보를 달력에서 편리하게 선택하는 날짜 투표 작성 화면 개선을 소개합니다. 모임 날짜를 정할 때 유용한 기능입니다.

  1. 단톡방의 투표 만들기 화면을 엽니다.
  2. 화면에서 날짜형 투표 또는 날짜 항목을 선택할 수 있는지 확인합니다.
  3. 후보가 될 날짜를 서로 다른 일정으로 추가합니다.
  4. 참가자가 가능한 날짜를 모두 고를 수 있도록 복수선택을 고려합니다.
  5. 날짜가 확정되기 전에 필요한 응답 마감 시간을 설정합니다.
  6. 투표를 등록한 뒤 참가자가 실제로 선택 가능한 상태인지 확인합니다.
  7. 마감 후 가장 많이 선택한 날짜를 참고하고 최종 일정을 별도 공지합니다.

권장 제목 예시: "11월 정기모임 날짜 — 가능한 날을 모두 고르세요(마감 11월 8일 오후 8시)".

주의: 달력에서 날짜를 고르는 기능이 Windows 업데이트에 소개되었다고 해서 모든 모바일 버전·Mac 버전에서 화면이 완전히 동일하다는 뜻은 아닙니다.

7. 투표 종료 시간 설정 및 조기 종료

주최자가 투표를 올렸다면 언제까지 응답할지를 명확히 공지하는 것이 중요합니다. 투표 옵션에 종료 시간을 지정하는 기능이 제공될 경우, 회의·예약·구매처럼 실제 결정을 내려야 하는 시점보다 미리 마감 시간을 잡습니다.

조기 종료가 필요하다면 해당 투표의 관리 화면 또는 더보기(⋮) → 투표 종료 같은 메뉴가 있는지 확인하세요. 모든 사용자에게 종료 권한이 표시되는 것은 아니며, 작성자나 관리자에게 제공되는 기능이 다를 수 있습니다.

마감 전 점검: 남은 참여자가 있는지, 동률이 발생했는지, 응답을 바꾸겠다고 요청한 사람이 있는지 확인하세요. 투표가 끝났다고 해서 가장 많이 선택된 후보를 자동으로 최종 일정으로 확정해야 하는 것은 아닙니다.

운영 팁: 응답이 비슷하게 나온 경우에는 "동률 후보만 재투표", "참석 인원을 별도로 확정", "장소 예약 가능 여부 확인" 중 무엇이 필요한지 구분합니다.

8. 투표 수정·삭제·복제 방법

투표 작성자는 투표 상세에서 수정·종료·삭제·복제 등 관리 기능이 제공되는지 확인할 수 있습니다. 다만 투표가 이미 진행 중이라면 문항 변경이 기존 응답을 왜곡할 수 있습니다.

단순 오타: 작성자에게 수정 메뉴가 제공된다면 오탈자만 바로잡고 채팅방에 변경 사실을 알립니다.

후보 자체가 변경됨: 기존 투표를 조기 종료하거나 삭제한 뒤, 변경된 후보로 새 투표를 만들고 이유를 공지하는 방법이 더 명확할 수 있습니다.

완료된 투표의 재활용: 카카오의 Windows 3.4.7 공지에는 종료된 투표 복제하기가 공식적으로 소개돼 있습니다. 반복하는 월례 회의나 정기 모임이라면 복제 기능으로 형식을 재사용하되, 과거 날짜·마감시각·후보를 그대로 두지 않도록 확인하세요.

삭제 전 필수 확인: 결과가 필요한 투표를 삭제하면 이후 확인하기 어려울 수 있습니다. 최종 결과와 주요 결정사항을 먼저 기록합니다.

9. 투표 결과 확인: 득표 수와 참여 인원 구분

투표를 등록하면 채팅방에 나타난 투표 카드나 톡게시판의 투표 목록을 통해 결과를 확인할 수 있습니다.

익명 설정을 끈 투표에서는 항목별 참여자 명단이나 멤버별·미참여자 화면을 볼 수 있는 경우가 있습니다. 반면 익명투표에서는 어떤 사람이 특정 항목에 표를 줬는지 공개하지 않는 방식으로 결과를 집계합니다.

투표 결과를 읽을 때 확인할 사항은 세 가지입니다.

  1. 실제 참여 인원: 투표에 응답한 사람이 몇 명인가?
  2. 항목별 득표 수: 어떤 선택지가 가장 많이 선택됐는가?
  3. 투표 방식: 단일선택인지 복수선택인지?

복수선택이면 득표 총합이 실제 참여자 수보다 많을 수 있습니다. 또한 최다 득표 항목이라도 예약 가능한 장소가 없거나 인원 확인이 부족하면 다시 조정해야 할 수 있습니다.

결과 공지 예시: "응답자 12명 중 11월 14일 선택 9표, 11월 21일 선택 7표입니다. 11월 14일로 확정하겠습니다. 참석이 어려운 분은 오늘 밤까지 알려주세요." 위 숫자는 사용법을 설명하기 위한 가상의 사례입니다.

10. 투표 메뉴가 안 보일 때: 모바일·PC별 점검

"카카오톡에서 투표가 사라졌다"는 질문이 생길 때는 먼저 다른 메뉴 경로를 확인합니다.

  1. 일반적인 단체 채팅방인지 확인합니다. 개인 1:1 채팅의 기능과 같지 않을 수 있습니다.
  2. 채팅방 오른쪽 위 ≡ 메뉴에서 톡게시판을 찾습니다.
  3. 게시판에 들어가면 투표 탭이 있는지 확인합니다.
  4. 모바일에서는 입력창 근처 + 메뉴도 점검합니다.
  5. Windows PC에서는 채팅방 메뉴의 톡게시판·투표 경로를 점검합니다.
  6. 앱 업데이트가 필요한지 확인합니다.
  7. 오픈채팅방이면 작성자·방장 권한 차이를 확인합니다.
  8. 그래도 메뉴가 없다면 현재 버전의 공식 도움말과 업데이트 공지를 참고합니다.

인터넷 글 중에는 "PC 버전은 투표 생성이 불가능하다"고 단정하는 안내도 있으나, 카카오 공식 Windows 3.4.7 공지에는 PC 투표 날짜 항목 작성과 복제 기능이 확인됩니다. 서로 다른 시점의 설명을 섞지 않는 것이 중요합니다.

보안 주의: PC 카카오톡의 버전을 확인하려고 비공식 다운로드 사이트에서 설치 프로그램을 받지 마세요. 카카오는 자사 기업 사이트와 Microsoft Store를 공식 설치 경로로 안내합니다.

공식 출처: PC 투표 업데이트, PC 설치 경로 안내

11. 오픈채팅에서도 투표를 만들 수 있나요?

오픈채팅은 일반 단톡방과 권한과 메뉴가 다를 수 있습니다. 다만 오픈채팅에는 투표 기능 자체가 없다고 말하는 것도 정확하지 않습니다. 카카오 운영정책은 오픈채팅 그룹채팅방의 공지·일정·투표 게시판을 명시합니다.

실제 사용에서는 다음을 확인하세요.

  • 현재 방이 일반 단톡방인지 오픈채팅방인지
  • 작성자가 방장·부방장인지 일반 참여자인지
  • 관리자가 투표 작성 권한을 제한했는지
  • 해당 채팅방의 게시판·투표 메뉴가 표시되는지
  • 응답자 이름 공개나 익명 설정 등 어떤 옵션이 지원되는지

중요: 운영정책에 투표 게시판이 언급된다고 해서 모든 오픈채팅방에서 모든 참여자가 새 투표를 만들 수 있다는 보장은 아닙니다. 실제 채팅방의 운영 권한을 먼저 확인하세요.

12. 단톡방 투표를 다시 공유하고 공지하려면?

채팅방에서 새 메시지가 많이 오가면 투표 카드가 위로 밀릴 수 있습니다. 이때는 톡게시판에 등록된 투표를 다시 찾아 공유할 수 있는지 살펴봅니다.

  1. 채팅방의 톡게시판 → 투표를 엽니다.
  2. 다시 안내할 투표를 선택합니다.
  3. 더보기 → 현재 채팅방에 공유하기 또는 비슷한 메뉴가 있는지 확인합니다.
  4. 참여 마감 시간을 포함한 짧은 안내 메시지를 별도로 보냅니다.
  5. 마감 후 최종 결정을 채팅방 공지로 다시 알립니다.

현재 앱에서 투표 자체를 공지로 등록하는 메뉴가 있다면 사용할 수 있지만, 게시판 글과 투표에 제공되는 기능은 달라질 수 있으므로 실제로 표시되는 메뉴를 확인하세요.

투표를 공유했다고 해서 모든 사람이 참여했거나 내용을 확인했다는 뜻은 아닙니다. 참석 확정이 중요한 모임은 투표 결과뿐 아니라 참가자의 최종 의사를 별도로 확인하세요.

13. 목적별 투표 템플릿 3가지

템플릿 A: 동호회 모임 날짜

  • 제목: 11월 정기모임 참석 가능한 날짜 선택
  • 항목: 11월 14일 / 11월 21일 / 11월 28일
  • 설정: 복수선택 켬, 익명 끔, 종료 시간 설정
  • 안내: "참석 가능한 날짜를 모두 고른 뒤 제출해 주세요."
  • 마감 후: 최다 선택 날짜를 기준으로 실제 참석 인원 재확인

템플릿 B: 회식 메뉴 결정

  • 제목: 금요일 회식 메뉴 하나 선택
  • 항목: 삼겹살 / 샤브샤브 / 중식 / 파스타
  • 설정: 단일선택, 익명 켬, 종료 시간 설정
  • 안내: "선호하는 메뉴 하나만 선택해 주세요."
  • 마감 후: 결과를 보고 예약 가능한 음식점 여부 확인

템플릿 C: 스터디 주제 수요 조사

  • 제목: 다음 스터디에서 다뤘으면 하는 주제 선택
  • 항목: 엑셀 자동화 / AI 업무 활용 / 데이터 분석 / 발표 자료 제작
  • 설정: 복수선택, 익명 켬
  • 안내: "관심 있는 주제를 모두 선택해 주세요."
  • 마감 후: 가장 선호가 높은 주제부터 일정에 반영

세 사례는 독자에게 투표 설계 방법을 설명하기 위해 작성한 가상 템플릿입니다. 실제 사용자 조사 결과나 카카오가 제공하는 기본 템플릿이 아닙니다.

14. 자주 묻는 질문 FAQ

Q. 카카오톡 단톡방에서 투표를 만드는 가장 기본적인 경로는 무엇인가요?

채팅방 오른쪽 위 메뉴(≡) → 톡게시판 → 투표 → 투표 만들기 흐름을 확인하세요. 앱 버전에 따라 항목 이름과 위치가 달라질 수 있습니다.

Q. PC 카카오톡에서는 투표에 참여만 가능하나요?

그렇게 단정할 수 없습니다. 카카오는 Windows 3.4.7 업데이트에서 날짜 투표 작성과 투표 복제 기능을 공식적으로 안내했습니다. Windows PC의 게시판 투표 메뉴를 확인하세요.

Q. 익명투표를 켜면 참여 인원까지 안 보이나요?

익명은 누가 특정 항목을 선택했는지를 비공개로 처리하는 기능입니다. 전체 참여 인원이나 득표 수를 모두 감추는 것과는 다릅니다.

Q. 참석 가능한 날짜를 여러 개 고르게 하려면?

투표 등록 전에 복수선택 허용을 확인하세요. 단일선택으로 등록하면 여러 날짜를 고를 수 없습니다.

Q. 날짜형 투표는 어떤 차이가 있나요?

날짜를 텍스트로 나열하는 대신 달력에서 후보 날짜를 선택할 수 있는 방식입니다. 카카오의 Windows 공식 업데이트에 날짜 투표 작성 화면 개선 내용이 있습니다.

Q. 이미 올린 투표를 수정할 수 있나요?

투표 상세의 수정 메뉴가 제공되는지 확인합니다. 이미 응답이 쌓인 질문을 크게 바꿔야 한다면 이전 결과와 섞이지 않도록 새 투표를 생성하는 편이 안전합니다.

Q. 투표를 일찍 종료할 수 있나요?

작성자에게 투표 종료 관련 메뉴가 제공되는지 확인합니다. 작성 권한과 관리자 권한에 따라 선택지가 다를 수 있습니다.

Q. 종료된 투표를 그대로 다시 만들 수 있나요?

카카오는 종료된 투표 복제 기능을 Windows 업데이트에서 공식적으로 안내했습니다. 다만 복제할 때 날짜·후보·마감 시각을 꼭 갱신하세요.

Q. 오픈채팅에서는 투표를 만들 수 없나요?

오픈채팅에는 공지·일정·투표 게시판이 존재한다는 공식 운영정책 근거가 있습니다. 다만 채팅방 유형과 관리자 권한에 따라 새 투표를 작성할 수 있는 사람은 다를 수 있습니다.

Q. 복수선택 결과 득표 합이 참여자 수보다 큰데 오류인가요?

오류라고 단정할 수 없습니다. 한 사람이 여러 항목에 투표했을 수 있기 때문입니다. 참여 인원과 선택지별 득표 수를 별도로 보세요.

15. 게시 전 최종 체크리스트

  • ☐ 투표 질문이 무엇을 결정하려는지 명확하다.
  • ☐ 후보가 서로 중복되지 않는다.
  • ☐ 한 가지만 골라야 하는지 복수선택이 필요한지 결정했다.
  • ☐ 응답자 이름이 필요한지 익명 설정을 확인했다.
  • ☐ 가능하면 마감 시간을 설정했다.
  • ☐ 투표를 올릴 채팅방과 참가자가 정확하다.
  • ☐ Windows PC라면 톡게시판 → 투표 기능을 확인했다.
  • ☐ 오픈채팅이라면 작성 권한을 확인했다.
  • ☐ 마감 후 최종 선택과 참석 여부를 별도 공지할 계획이다.

한 줄 요약: 카카오톡 단톡방 투표는 톡게시판 → 투표 만들기 → 제목·항목 → 익명·복수선택·마감 설정 → 등록 순서로 진행합니다. 참석 가능한 날짜를 묻는다면 복수선택, 솔직한 선호도가 목적이라면 익명을 고려하세요. Windows PC도 카카오 공식 공지에 투표 작성·복제 관련 기능이 확인됩니다.
