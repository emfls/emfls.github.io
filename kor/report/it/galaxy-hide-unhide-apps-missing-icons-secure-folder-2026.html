1. 갤럭시 앱 숨기는 방법: 삼성 공식 경로

앱을 그대로 설치해 두고 홈 화면과 앱스 화면에서만 보이지 않게 하려면 다음과 같이 진행합니다.

  1. 갤럭시 홈 화면의 빈 공간을 길게 누릅니다.
  2. 설정 또는 홈 화면 설정을 선택합니다.
  3. 홈 및 앱스 화면에서 앱 숨기기 메뉴로 들어갑니다.
  4. 목록에서 숨길 앱을 선택합니다. 여러 앱을 선택할 수도 있습니다.
  5. 완료를 누르고 홈 화면과 앱스 화면에서 아이콘이 숨겨졌는지 확인합니다.

삼성전자서비스가 소개한 또 다른 공식 경로도 있습니다.

앱스 화면 → 하단 검색창 옆 더보기(점 세 개) → 설정 → 홈 및 앱스 화면에서 앱 숨기기

앱스 화면을 여는 일반적인 방법은 홈 화면에서 위로 스와이프하는 것입니다. 일부 기종은 앱스 버튼이나 다른 화면 설정이 적용돼 있을 수 있습니다.

이 기능으로 숨긴 앱은 설치가 유지되므로 앱 자체와 저장 데이터가 삭제되지 않습니다. 다른 메뉴에서 보이는 '설치 삭제'와 혼동하지 마세요.

2. 숨긴 앱 다시 표시하는 방법

카카오톡, 네이버, 은행 앱처럼 전에 숨겨 둔 앱을 다시 사용하려면 앱을 새로 설치하지 말고 다음 순서로 확인합니다.

  1. 홈 화면 빈 공간 길게 누르기 → 설정으로 이동합니다.
  2. 홈 및 앱스 화면에서 앱 숨기기를 선택합니다.
  3. 화면에 표시된 숨긴 앱 목록을 확인합니다.
  4. 다시 표시하려는 앱의 마이너스(-) 아이콘이나 선택 상태를 눌러 숨김 목록에서 제거합니다.
  5. 완료를 누릅니다.
  6. 앱스 화면으로 돌아가 해당 아이콘이 다시 나타났는지 확인합니다.

삼성 공식 안내에 따르면 숨긴 앱 목록에서 앱을 해제한 뒤 완료를 누르면 다시 앱스 화면에 나타납니다. 단, 앱스 화면에 돌아온 아이콘이 홈 화면에도 자동으로 다시 배치되는 것은 별개입니다.

홈 화면에 바로가기가 필요하면 앱스 화면의 앱을 길게 눌러 홈 화면에 추가하세요.

3. 아이콘이 사라진 다섯 가지 원인 구별

앱이 보이지 않는다고 삭제된 것은 아닙니다. 어느 단계에서 사라졌는지부터 확인하는 것이 더 빠릅니다.

구분앱 설치 상태특징
홈 화면 바로가기만 제거대체로 그대로 설치앱스 화면에서 찾아 실행 가능
홈 및 앱스 화면에서 숨김설치 유지아이콘만 보이지 않도록 설정
앱 사용 중지설치 파일은 남을 수 있음앱 실행이 제한되고 화면에서 사라질 수 있음
앱 설치 삭제앱 설치 제거재설치·계정 복구·데이터 복원 여부 확인 필요
보안 폴더 내부에 앱 존재보호 공간에 별도 앱이 있을 수 있음일반 앱 목록과 구별해야 함

예를 들어 홈 화면에 있던 아이콘만 사라졌고 앱스 화면에서는 검색된다면 먼저 바로가기를 추가하세요. 이 상황에서 설치 삭제나 앱 데이터 초기화를 할 이유가 없습니다.

반대로 앱스 화면에서도 없으면 숨김 메뉴 → 애플리케이션 메뉴 순서로 점검하면 됩니다.

4. 홈 화면에만 앱이 사라졌을 때

앱스 화면에 앱이 보인다면 홈 화면 바로가기만 제거됐을 가능성이 있습니다.

  1. 홈 화면에서 위로 쓸어 앱스 화면을 엽니다.
  2. 앱 목록 또는 검색창에서 원하는 앱을 찾습니다.
  3. 아이콘을 길게 누릅니다.
  4. 홈 화면에 추가 항목이 있으면 선택합니다. 모델에 따라 직접 아이콘을 끌어놓을 수도 있습니다.
  5. 홈 화면에 아이콘이 나타나는지 확인합니다.

앱스 화면 검색창이 위쪽에서 아래쪽으로 옮겨져 앱을 못 찾는 경우도 있습니다. 삼성전자서비스에 따르면 One UI 7은 앱스 검색창을 화면 하단에 배치했으며, '가나다 순' 정렬에서는 세로 스크롤을 지원합니다.

예전처럼 가로로 넘기며 앱을 찾다가 찾지 못했다면 검색창과 정렬 상태를 먼저 확인하세요. 화면 정렬 방식이 달라진 것은 앱이 삭제됐다는 뜻이 아닙니다.

5. 숨긴 앱에도 없다면 '앱 사용 중지' 확인

일부 갤럭시 기본 앱은 삭제할 수 없지만 사용 중지할 수 있습니다. 삼성전자서비스는 사용 중지된 앱이 앱스 화면에서 보이지 않을 수 있다고 안내합니다.

사용 중지된 앱을 다시 켜는 순서

  1. 설정 → 애플리케이션으로 이동합니다.
  2. 앱 이름을 검색하거나 목록에서 선택합니다.
  3. 앱 상세 화면에 사용 버튼이 표시되면 누릅니다.
  4. 앱스 화면으로 돌아가 아이콘이 다시 나타나는지 확인합니다.

모든 앱에서 사용 중지·사용 기능이 제공되는 것은 아닙니다. 사용 버튼이 보이지 않으면 이미 활성화된 앱일 수도 있으므로 무작정 다른 메뉴를 누르지 마세요.

기본 전화, 메시지, 연락처, 갤러리, 내 파일처럼 필수 앱은 기능에 영향을 줄 수 있습니다. 불필요한 시스템 앱 변경은 피하고 단순히 화면을 정리하려는 목적이라면 앱 숨기기를 우선 검토하세요.

6. 앱 숨기기 vs 보안 폴더, 무엇이 다를까?

갤럭시의 앱 숨기기와 보안 폴더는 같은 기능이 아닙니다.

비교일반 앱 숨기기보안 폴더
주된 목적아이콘을 목록에서 숨김별도의 보호 공간에서 앱·파일 관리
잠금앱 숨기기 자체에는 별도 인증 없음별도 PIN·패턴·암호 또는 지원되는 생체인증
앱 데이터일반 설치 영역에 남음보호 공간 내 데이터가 일반 영역과 구분됨
화면 표시선택한 앱 아이콘 숨김보안 폴더 자체의 아이콘을 숨길 수 있음
주의점보안 기능으로 오해하지 않기설정·삭제·잠금 복구 방식을 먼저 확인

Samsung Knox 보안 폴더는 지원 모델에서 앱·사진·파일을 별도 잠금으로 보호할 수 있습니다. 하지만 모든 갤럭시에서 보안 폴더가 제공되는 것은 아닙니다.

지원 모델에서는 일반적으로 다음 경로를 확인할 수 있습니다.

설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더

설정 단계에서 잠금 해제 방법과 삼성 계정 기반 복구 가능 여부를 주의 깊게 확인하세요. 보안 폴더를 삭제하거나 초기화하면 내부 데이터에 영향을 줄 수 있으므로 아이콘만 사라진 문제를 해결하려고 보안 폴더 자체를 삭제해서는 안 됩니다.

7. 보안 폴더 아이콘이 안 보일 때

보안 폴더 안의 사진과 앱을 사용해야 하는데 보안 폴더 아이콘이 보이지 않을 경우 다음 순서를 따릅니다.

  1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안 폴더로 들어갑니다.
  2. 본인 인증이 필요하면 진행합니다.
  3. 앱스 화면에 보안 폴더 추가 또는 이에 해당하는 표시 옵션을 찾습니다.
  4. 옵션을 활성화하고 앱스 화면을 다시 확인합니다.

지원하는 기기에서는 빠른 설정 패널에서 보안 폴더 표시를 전환할 수도 있습니다. 빠른 설정에 아이콘이 없으면 설정 앱 경로로 이동하세요.

보안 폴더 아이콘을 숨기는 것과 보안 폴더의 내용이 삭제되는 것은 구별해야 합니다. 별도 공간 내부에 있는 앱이나 사진을 찾으려면 우선 그 보호 공간을 열어야 합니다.

공식 근거: Samsung — 보안 폴더 아이콘 숨김·복구

8. 앱이 실제로 삭제됐는지 확인하는 순서

숨김 해제와 사용 중지 해제를 확인했는데도 앱이 보이지 않으면 설치 상태를 점검합니다.

  1. 설정 → 애플리케이션 목록에서 앱 이름을 검색합니다.
  2. 목록에 있다면 앱의 사용 상태를 확인합니다.
  3. 목록에 없다면 Google Play 스토어나 Galaxy Store에서 앱을 검색합니다.
  4. 현재 스토어 화면에 열기·설치 같은 어떤 버튼이 나타나는지 확인합니다.
  5. 실제 재설치가 필요하다고 판단될 때만 진행합니다.

스토어에 표시되는 상태는 계정, 국가, 기기 호환성 등에 따라서도 달라질 수 있습니다. 앱이 스토어에서 바로 검색되지 않는다고 해서 반드시 삭제됐거나 영구적으로 사라졌다고 단정하지 마세요.

특히 금융 앱과 메신저는 재설치 후 인증 수단, 기존 계정, 대화·파일 백업이 필요할 수 있으므로 앱을 삭제하기 전에 확인하는 편이 안전합니다.

9. 상황별 선택: 숨김·사용 중지·삭제 중 어떤 방법이 좋을까?

앱을 나중에도 사용할 예정이고 홈 화면만 깔끔하게 만들고 싶다면 앱 숨기기가 간단합니다. 사용법도 되돌리기 쉽고 앱을 새로 설치할 필요가 없습니다.

기본 앱을 사용하지 않으며 실행도 제한하고 싶다면 해당 앱이 지원하는 경우 사용 중지를 검토하세요. 단, 시스템 기능에 필요한 앱은 함부로 중지하지 않는 것이 좋습니다.

저장공간을 확보하려는 목적이라면 앱 숨기기만으로는 해결되지 않습니다. 사용하지 않는 앱의 삭제 가능 여부와 데이터 보존 상태를 먼저 살펴보세요.

민감한 앱·파일에 별도의 잠금이 필요하다면 일반 아이콘 숨김보다는 보안 폴더처럼 인증을 제공하는 기능이 적절할 수 있습니다. 기기 지원 여부를 먼저 확인해야 합니다.

앱이 갑자기 사라져 복구하는 중이라면 새로 설치하기 전에 바로가기·숨김·사용 중지 상태를 순서대로 확인하세요.

10. 3분 자가진단: 실제로 무엇이 문제인지 확인하기

다음 방법은 삼성 공식 설명을 바탕으로 사용자가 직접 따라 할 수 있도록 구성한 실전 점검 순서입니다.

테스트 A — 홈 화면과 앱스 화면 비교

홈 화면에 없는 앱을 앱스 화면에서 검색합니다. 앱스 화면에 있다면 홈 화면 바로가기 문제인지 먼저 살핍니다.

테스트 B — 숨김 목록 점검

홈 화면 설정 → 홈 및 앱스 화면에서 앱 숨기기를 열고 대상 앱이 선택돼 있는지 확인합니다. 선택됐다면 숨김을 해제하고 앱스 화면에 나타나는지 봅니다.

테스트 C — 사용 중지 여부 확인

설정 → 애플리케이션에서 앱 이름을 찾아 '사용' 또는 비활성화된 상태가 나타나는지 확인합니다. 숨김과 사용 중지를 혼동하지 않는 것이 핵심입니다.

테스트 D — 보안 폴더 구분

보안 폴더를 사용한다면 일반 앱 영역과 보안 폴더 안의 앱 목록을 별도로 확인합니다. 일반 앱을 숨기는 기능과 보안 폴더에서 앱을 사용하는 것은 다른 설정입니다.

테스트 E — 최종 결과 확인

바뀐 설정을 한 번에 여러 개 적용하지 말고 하나씩 변경하며 앱의 표시 상태를 확인합니다. 그래야 어느 설정이 원인인지 구별할 수 있습니다.

이 체크리스트는 직접 기기를 조작해 수행한 실험 결과가 아닌 공식 가이드를 바탕으로 재구성한 점검 절차입니다.

자주 묻는 질문

Q1. 갤럭시에서 앱 숨기기를 하면 앱이 삭제되나요?

아니요. 홈 및 앱스 화면에서 앱 숨기기는 아이콘을 보이지 않게 설정하는 기능입니다. 앱을 제거하거나 앱 데이터를 삭제하는 것과 다릅니다.

Q2. 숨긴 앱을 다시 표시했는데 홈 화면에는 없어요.

먼저 앱스 화면에 다시 나타났는지 확인하세요. 앱스 화면에서 보인다면 해당 앱을 길게 눌러 홈 화면에 추가할 수 있습니다. 앱스 목록 복원과 홈 화면 바로가기 복원은 별개입니다.

Q3. '앱 숨기기' 메뉴가 안 보이면요?

설정 앱에서 '앱 숨기기', **'홈 화면'**을 검색해 보세요. 앱스 화면 검색창 옆 더보기 → 설정 경로도 확인할 수 있습니다. 소프트웨어 버전과 홈 화면 앱에 따라 다를 수 있습니다.

Q4. 숨긴 앱은 비밀번호를 입력해야 실행할 수 있나요?

일반 앱 숨기기는 별도 인증을 제공하는 기능이 아닙니다. 보호가 필요하다면 기기에서 보안 폴더 지원 여부를 확인하세요.

Q5. 사용 중지된 앱은 다시 켤 수 있나요?

일부 기본 앱은 설정 → 애플리케이션 → 앱 선택 → 사용으로 다시 활성화할 수 있습니다. 다만 모든 앱에서 사용 중지 기능을 지원하지는 않습니다.

Q6. One UI 업데이트 후 앱스 화면에서 앱이 안 보여요.

앱스 화면의 검색창 위치, 정렬, 스크롤 방식을 먼저 확인하세요. One UI 7에서는 앱스 화면 UI가 달라졌습니다. 화면 구성이 변한 것과 앱이 삭제된 것은 다릅니다.

Q7. 보안 폴더를 숨기면 안에 저장한 사진이 삭제되나요?

보안 폴더의 아이콘 표시를 끄는 것은 폴더 자체를 삭제하는 동작이 아닙니다. 설정에서 보안 폴더 아이콘 표시 상태를 다시 확인하세요. 보안 폴더 삭제·초기화는 별도 문제이므로 누르지 마세요.

Q8. 기본 앱을 제거할 수 없는데 아이콘만 없앨 수 있나요?

삼성전자서비스는 설치 삭제가 지원되지 않는 일부 기본 앱의 경우 앱 숨기기 또는 지원되는 경우 앱 사용 중지를 활용할 수 있다고 안내합니다. 제거가 어렵다고 강제 삭제 수단을 사용할 필요는 없습니다.

최종 체크리스트

  • ☐ 홈 화면과 앱스 화면 양쪽에서 앱이 사라졌는지 확인했다.
  • ☐ 홈 및 앱스 화면에서 앱 숨기기 목록을 확인했다.
  • ☐ 숨긴 앱을 해제한 뒤 앱스 화면에 다시 나타나는지 봤다.
  • ☐ 필요하면 앱스 화면에서 홈 화면 바로가기를 다시 추가했다.
  • ☐ 설정 → 애플리케이션에서 사용 중지 여부를 확인했다.
  • ☐ 보안 폴더와 일반 앱 숨기기를 구별했다.
  • ☐ 설치 삭제·데이터 초기화·공장 초기화는 진행하기 전에 데이터 보존 여부를 확인한다.

결론: 갤럭시에서 앱이 갑자기 안 보이면 홈 화면 바로가기 → 앱 숨기기 → 사용 중지 → 보안 폴더 → 실제 설치 상태 순서로 확인하는 것이 효율적입니다. 앱을 감추려는 목적이라면 화면 숨김 설정을 사용하고, 개인정보 보안이 목적이라면 별도 인증 기능을 검토하세요.
