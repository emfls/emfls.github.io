파워포인트(PowerPoint)로 발표 자료를 만들다가 PPTX 파일이 30MB, 100MB 이상으로 커져 메일 첨부가 어렵거나 업로드에 시간이 걸릴 때가 있습니다. 슬라이드 수가 많지 않아도 고화질 사진과 동영상이 여러 개 들어 있으면 파일이 커질 수 있습니다.

용량을 줄이려면 무엇이 파일을 크게 만드는지 먼저 구분해야 합니다. 사진이 대부분인 파일은 그림 압축부터, 동영상이 포함된 파일은 미디어 압축부터 시도하는 편이 효율적입니다. 원본 화질과 편집 기능이 중요한 자료라면 무조건 최대한 작게 만들기보다 용량·화질·편집 가능성의 균형을 맞춰야 합니다.

이 글은 Microsoft 공식 지원 문서를 바탕으로 Windows용 Microsoft 365·PowerPoint 2024를 중심으로 설명합니다. Mac과 웹용 PowerPoint의 차이, 압축 과정에서 사라질 수 있는 데이터와 검수 방법도 함께 정리했습니다.

1. PPT 용량 줄이기, 가장 먼저 할 5가지

확인한 원인우선 해결책품질·기능상 주의점
사진·스크린샷이 많음그림 서식 → 그림 압축이미지 선명도가 낮아질 수 있음
잘라낸 사진이 많음잘린 그림 영역 삭제 검토삭제한 영역은 원상 복원 불가
영상·음성 파일 포함파일 → 정보 → 미디어 압축내장 자막·대체 오디오 트랙 손실 가능
이미지 편집을 여러 번 함이미지 편집 데이터 삭제이전 편집 상태로 되돌리기 어려움
글꼴을 많이 포함함필요하면 사용 문자만 포함다른 사람이 새로운 문구를 편집할 때 제약

권장 순서: ① 원본 복사 → ② 그림 전체 압축 → ③ 동영상 압축 → ④ 불필요한 편집 데이터 검토 → ⑤ 저장 후 실제 재생·선명도 검사입니다.

모든 자료에 통하는 고정 압축률은 없습니다. 이미 최적화된 파일이거나 글꼴·영상이 많은 PPT라면 사진 압축만으로는 용량이 크게 줄지 않을 수도 있습니다.

2. 압축 전에 파일 크기와 원본부터 확인하세요

원본이 없으면 압축 후 글자·사진이 흐려졌을 때 복구하기 어려울 수 있습니다.

  1. PPTX 파일을 열고 파일 → 다른 이름으로 저장을 선택합니다.
  2. 원본 이름 뒤에 -원본을 붙여 보관합니다.
  3. 수정용 파일 이름은 -압축본으로 저장합니다.
  4. Windows 파일 탐색기에서 파일을 선택한 뒤 속성의 크기를 기록합니다.
  5. 나중에 압축 전후의 파일 크기와 발표 화면을 비교합니다.

예시: 압축 전 80MB, 압축 후 52MB라면 감소량은 28MB이고, 감소율은 (80-52)÷80×100 = 35%입니다. 이 수치는 계산 예시일 뿐, 실제 PPT에서 35%가 줄어든다는 뜻은 아닙니다.

업로드 사이트에 10MB나 20MB 제한이 있다면 먼저 해당 사이트의 정확한 제한을 확인하세요. 제한을 맞추느라 중요한 글자·이미지를 읽기 어렵게 만드는 것은 바람직하지 않습니다.

3. 가장 많이 쓰는 방법: PPT 사진 전체 압축

사진이 많은 PPT라면 이 방법부터 시작하세요.

Windows PowerPoint에서 전체 사진 압축하기

  1. 복사해 둔 PPTX 압축본을 엽니다.
  2. 슬라이드 안의 사진 한 장을 선택합니다.
  3. 상단 그림 서식 탭을 클릭합니다.
  4. 조정 → 그림 압축을 누릅니다.
  5. '이 그림에만 적용'의 체크를 해제합니다.
  6. 해상도에서 발표·메일·인쇄 목적에 맞는 설정을 선택합니다.
  7. 확인을 누르고 파일을 다시 저장합니다.
  8. 사진과 그래프가 흐려지지 않았는지 여러 슬라이드를 확인합니다.

여기서 가장 중요한 설정은 '이 그림에만 적용' 체크 해제입니다. 체크가 남아 있으면 선택한 사진만 압축될 수 있습니다. Microsoft는 전체 그림에 적용하려면 해당 체크를 해제하라고 안내합니다.

이미지를 선택하지 않았으면 '그림 서식' 탭이 나타나지 않을 수 있습니다. 사진을 클릭하거나 더블클릭해 실제 그림 개체를 선택했는지 확인하세요. 아이콘만 표시되는 좁은 창에서는 '그림 압축'이라는 글자가 생략될 수 있습니다.

공식 근거: Microsoft — PPT 파일 크기 줄이기, Microsoft — Office에서 그림의 파일 크기 축소

4. 어느 해상도를 선택해야 할까? 150ppi와 화질의 관계

PowerPoint에서는 이미지 압축 시 선택 가능한 해상도 설정을 제공합니다. 해상도를 낮추면 저장 용량이 줄어들 수 있지만 작은 글씨·복잡한 도표·정밀한 제품 사진이 흐려질 수 있습니다.

용도권장 접근
이메일로 빠르게 공유할 화면용 자료낮춘 해상도의 사본에서 글자 선명도 확인
일반 회의용 슬라이드화면·프로젝터에서 실제 크기로 테스트
사진·제품 상세 이미지가 중요한 발표이미지 선명도를 우선하고 필요한 것만 압축
고품질 인쇄·대형 출력용충분한 해상도 유지, 무조건 150ppi 이하로 낮추지 않기
수정·재활용할 회사 원본원본 이미지가 남은 파일 별도 보관

Microsoft는 파일 크기를 줄이는 방법으로 기본 해상도를 150ppi 이하로 설정하는 방법을 소개합니다. 다만 이는 모든 자료의 최적값이라는 뜻이 아닙니다. 화면에서 충분히 선명해 보이는지 직접 확인하고, 인쇄용이면 더 높은 해상도가 필요할 수 있습니다.

기본 이미지 해상도를 변경하려면

  1. 파일 → 옵션 → 고급으로 이동합니다.
  2. 이미지 크기 및 품질 영역을 찾습니다.
  3. 적용할 프레젠테이션이 맞는지 확인합니다.
  4. '파일에서 이미지 압축 안 함' 설정이 켜져 있지 않은지 확인합니다.
  5. 기본 해상도를 필요한 값으로 조정합니다.
  6. 저장하고 이미지·텍스트의 선명도를 검토합니다.

주의: 해상도를 낮추기 전에 복사본을 만들고, 그래프 축 숫자·스크린샷의 작은 메뉴 글씨처럼 흐려지기 쉬운 부분을 우선 확인하세요.

5. 잘린 사진 영역 삭제: 효과는 있지만 복원이 어려움

슬라이드에 사진을 삽입한 뒤 필요한 부분만 남도록 자르기(Crop)하면 잘려 보이지 않는 영역의 정보가 파일에 남아 있을 수 있습니다. Microsoft는 '잘린 그림 영역 삭제'가 파일 크기 감소에 도움이 된다고 설명합니다.

진행 방법

  1. 먼저 PPTX 원본을 별도 보관합니다.
  2. 사진을 선택하고 그림 서식 → 그림 압축을 엽니다.
  3. 필요한 경우 '잘린 그림 영역 삭제'를 체크합니다.
  4. 압축 범위와 해상도를 확인하고 적용합니다.
  5. 다시 사진을 자르거나 확장해야 하는 요구가 없는지 점검합니다.

복구 위험: 잘린 그림 영역을 삭제하면 나중에 사진 자르기를 취소해 숨겨졌던 영역을 다시 보여 줄 수 없게 됩니다. 사진 구도를 다시 바꾸는 작업이 예정돼 있다면 체크하지 않는 편이 안전합니다.

기업 제안서처럼 이미지 구도 수정 가능성이 높은 원본과 최종 배포용 압축본은 따로 관리하세요.

공식 근거: Microsoft — PPT 파일 크기 줄이기

6. 이미지 편집 데이터 삭제와 자동 압축 설정 확인

사진의 색상·밝기·잘라내기 효과를 수정하면 이전 상태로 되돌리기 위해 이미지 편집 정보가 저장될 수 있습니다. 이 데이터도 일부 파일의 용량을 늘리는 원인이 됩니다.

  1. 파일 → 옵션 → 고급을 엽니다.
  2. 이미지 크기 및 품질 영역을 찾습니다.
  3. 해당 프레젠테이션에 대한 설정인지 확인합니다.
  4. 편집 데이터 삭제를 사용할지 결정합니다.
  5. 필요하면 해상도 설정도 검토하고 저장합니다.

중요: '편집 데이터 삭제'는 앞으로 사진을 원래 편집 상태로 되돌릴 수 없도록 할 수 있습니다. 나중에 색상·자르기·효과를 다시 수정해야 하는 자료라면 원본 파일을 반드시 보관해야 합니다.

또한 '파일에서 이미지 압축 안 함'이 선택된 상태라면 이미지 압축을 제한합니다. 파일 크기 축소가 목적이라면 이 옵션이 켜져 있는지 확인하세요. Microsoft는 압축을 끄면 사진의 품질을 높게 유지할 수 있지만 파일이 커질 수 있다고 안내합니다.

공식 근거: Microsoft — 이미지 크기 및 품질 옵션

7. 동영상이 포함된 PPT 용량 줄이기: 미디어 압축

PPTX에 동영상이나 음성 파일이 포함되어 있다면 이미지 압축보다 미디어 압축이 더 큰 영향을 줄 수 있습니다. 실제 감소량은 삽입된 미디어의 형식·길이·기존 압축 상태에 따라 다릅니다.

Windows PowerPoint 미디어 압축 순서

  1. 원본 파일을 보관하고 압축본을 엽니다.
  2. 파일 → 정보로 이동합니다.
  3. 멀티미디어 영역에서 미디어 압축을 선택합니다.
  4. 제공되는 화질 옵션 중 용도에 맞는 수준을 선택합니다.
  5. 압축 작업이 끝난 후 새 이름으로 저장합니다.
  6. 동영상이 재생되는지, 음성과 화면이 맞는지, 자막이 남아 있는지 확인합니다.

Microsoft의 최신 안내에서는 환경에 따라 다음 해상도 옵션을 제공합니다.

압축 옵션성격
Full HD (1080p)전반적인 화질과 음질을 유지하면서 용량 감소 시도
HD (720p)더 낮은 영상 해상도로 파일 크기 절감
Standard (480p)이메일 전송 등 용량 제한이 큰 상황에 적합할 수 있음

버전에 따라 '프레젠테이션 품질·인터넷 품질·저품질'로 표시될 수도 있습니다.

매우 중요한 주의점: Microsoft는 미디어 압축 시 삽입된 자막과 대체 오디오 트랙이 손실될 수 있다고 명시합니다. 자막·접근성·다국어 음성이 중요한 자료는 압축본을 반드시 검사하고, 원본 동영상도 별도로 보관하세요.

지원 범위: PowerPoint의 이 미디어 압축 기능은 Windows에서 지원되며, Mac용 PowerPoint와 웹용 PowerPoint에서는 지원되지 않습니다.

공식 근거: Microsoft — 미디어 파일 압축

8. Mac·웹용 PowerPoint: 사용할 수 있는 압축 기능이 다릅니다

Mac과 웹용 PowerPoint에서는 Windows와 완전히 같은 메뉴가 제공되지 않습니다.

Mac용 PowerPoint의 그림 압축

Microsoft Office의 그림 압축 안내에 따르면 Mac에서는 파일 → 그림 압축을 통해 전체 그림을 압축하거나, 사진을 선택한 다음 그림 서식 → 그림 압축을 사용할 수 있습니다.

  1. 압축할 프레젠테이션 복사본을 만듭니다.
  2. 파일 → 그림 압축을 사용하거나 그림을 선택해 압축 메뉴를 엽니다.
  3. 압축 품질을 결정합니다.
  4. 선택된 그림만 또는 이 파일의 모든 그림을 압축할지 선택합니다.
  5. 잘린 그림 영역을 삭제할지 신중히 결정합니다.
  6. 저장 후 Mac에서 슬라이드의 선명도를 확인합니다.

Mac에서 미디어 압축이 보이지 않는 것은 버전 문제라기보다 Microsoft가 Windows 전용 기능으로 안내하는 항목이기 때문일 수 있습니다. 별도로 동영상을 적절히 인코딩한 뒤 삽입하는 방법을 검토할 수 있지만, 원본 비디오와 자막도 유지해야 합니다.

웹용 PowerPoint

Microsoft는 Office의 그림 압축 기능이 웹용 Microsoft 365에서 지원되지 않는다고 안내합니다. 웹에서 필요한 압축 메뉴를 찾을 수 없다면 데스크톱 PowerPoint에서 작업해야 합니다.

공식 근거: Microsoft — Office에서 그림 파일 크기 줄이기, Microsoft — 미디어 파일 압축

9. 그림을 줄였는데 PPT 용량이 그대로일 때

이미지 압축을 했는데 파일 크기가 거의 변하지 않는다면 다음 사항을 구별하세요.

가능한 원인점검할 내용다음 단계
사진 한 장에만 압축 적용'이 그림에만 적용' 체크전체 적용 여부 재확인
영상·음성이 파일의 대부분 차지포함된 미디어 존재Windows에서 미디어 압축 검토
원본 사진이 이미 최적화됨압축 전후 파일 크기화질 저하 없이 더 줄이기 어려울 수 있음
이미지 압축이 꺼져 있음고급 옵션의 압축 비활성화'파일에서 이미지 압축 안 함' 확인

원인 분리가 중요합니다. 만약 동영상이 파일 크기의 대부분을 차지한다면 이미지 해상도를 과도하게 낮춰도 용량이 원하는 만큼 줄지 않을 수 있습니다.

10. 글꼴 포함 옵션도 파일 크기에 영향을 줍니다

Microsoft는 PPTX에 글꼴을 포함할 경우 파일 크기가 커질 수 있다고 안내합니다. 이때 Windows용 PowerPoint에서는 파일 → 옵션 → 저장 → 파일에 글꼴 포함에서 글꼴 포함 방식과 용도를 확인할 수 있습니다.

  • 사용된 문자만 포함: 수정 필요가 적은 배포본에서 파일 크기 증가를 줄이는 데 유리합니다.
  • 모든 문자 포함: 다른 사람이 내용을 수정·추가해야 할 때 더 적합할 수 있습니다.

다만 글꼴 포함을 무조건 해제하면 받은 사람의 PC에서 글꼴이 대체되어 줄바꿈이나 슬라이드 배치가 깨질 수 있습니다. 파일을 줄이는 것과 디자인을 유지하는 것 사이의 균형을 고려하세요.

참고: Microsoft — PowerPoint 프레젠테이션의 파일 크기 줄이기

11. 동영상은 링크로 넣으면 무조건 더 좋을까요?

동영상을 파일에 삽입하면 인터넷이 없는 환경에서도 해당 파일을 직접 재생하기 쉬워지지만 PPTX 크기가 커집니다. 반대로 외부 링크를 사용하면 PPTX 크기를 줄일 수 있는 대신 네트워크 연결이나 원본 파일 위치가 바뀌면 재생에 실패할 수 있습니다.

Microsoft는 미디어를 삽입하면 파일 크기가 증가할 수 있고, 외부 미디어를 연결하면 발표 장소에서 연결 상태를 점검해야 한다고 설명합니다.

용도더 적합할 수 있는 방식
인터넷이 불안정한 강의실·회의실영상 포함 + 미디어 압축
팀 내부에서 안정적인 네트워크 공유링크 방식 검토
발표자가 여러 장소로 PPT를 옮김영상이 정상 재생되는지 실제 장치에서 점검
동영상 자막이 중요한 접근성 발표압축 후 자막·대체 오디오 트랙 검증

주의: 연결 방식의 미디어는 링크 주소만 PPTX에 보관하는 경우가 있어 파일을 다른 사람에게 보내더라도 원본 동영상이 자동으로 따라오지 않을 수 있습니다. 중요한 발표 자료라면 반드시 다른 PC에서 사전 테스트하세요.

공식 근거: Microsoft — PowerPoint 오디오 및 비디오 재생 호환성

12. 이메일 20MB 제한에 맞춰야 할 때 권장 순서

다음은 이메일 서비스 자체의 제한을 단정하는 설명이 아니라, 첨부 용량 제한이 20MB인 상황을 가정한 절차입니다.

  1. 먼저 해당 이메일 서비스가 정한 정확한 첨부 제한을 확인합니다.
  2. PPTX의 현재 용량을 확인합니다.
  3. PPTX 원본과 압축본을 분리합니다.
  4. 사진 전체 압축을 먼저 시험합니다.
  5. 동영상이 들어 있다면 Windows용 미디어 압축을 검토합니다.
  6. 자막·편집 데이터·글꼴 사용 상태를 점검합니다.
  7. 압축본이 용량 제한 이하로 줄었는지 확인합니다.
  8. 슬라이드를 전체 화면으로 열어 글자와 사진·영상 재생을 점검합니다.

그래도 한도를 초과한다면: Microsoft는 큰 파일을 클라우드에 저장하고 OneDrive 공유 링크로 전달하는 방법을 안내합니다. 다만 회사 자료라면 공유 권한을 '링크가 있는 모든 사람'으로 무턱대고 넓히지 말고 승인된 사용자만 접근하도록 설정하세요.

13. 압축 후 품질 검사: 이 6개는 반드시 확인

압축 작업이 끝났다면 다음을 검증하세요.

  • ☐ PPTX 파일 크기가 실제로 감소했는지 확인했다.
  • ☐ 사진과 도표 속 작은 숫자가 읽히는지 확인했다.
  • ☐ 슬라이드 전체의 줄바꿈·텍스트 상자 배치가 유지되는지 확인했다.
  • ☐ 동영상과 음성이 처음부터 끝까지 재생되는지 확인했다.
  • ☐ 자막이나 대체 오디오 트랙이 필요하다면 압축 후에도 유지되는지 확인했다.
  • ☐ 원본 PPTX와 압축된 배포본을 구분해 보관했다.

특히 주의할 지점은 '비가역적인 압축'입니다. 잘린 사진 영역이나 이미지 편집 데이터를 삭제한 뒤 원래대로 복구해야 할 때 원본이 없으면 작업을 처음부터 다시 해야 할 수 있습니다.

14. 자주 묻는 질문

Q. 파워포인트 사진 여러 장을 한 번에 압축할 수 있나요?

가능합니다. 그림 한 장을 선택해 그림 서식 → 그림 압축을 열고, '이 그림에만 적용'을 해제하면 모든 그림에 설정을 적용할 수 있습니다.

Q. 그림 압축 버튼이 안 보이는 이유는?

일반 텍스트 상자를 선택하면 그림 서식 탭이 보이지 않을 수 있습니다. 실제 사진 개체를 선택하고, 창이 좁다면 조정 그룹의 아이콘을 찾아보세요.

Q. PPT 용량을 줄이면 화질이 무조건 나빠지나요?

이미지를 다시 압축하거나 해상도를 낮추면 세부 정보가 손실될 수 있습니다. 파일 상태와 설정에 따라 차이가 있으므로 대표 슬라이드에서 먼저 시험하는 편이 좋습니다.

Q. 미디어 압축 기능이 Mac에 없는 이유는?

Microsoft 공식 문서에 따르면 PowerPoint의 미디어 압축 기능은 Windows 전용이며 Mac·웹용 PowerPoint에서는 지원되지 않습니다.

Q. 동영상 자막이 사라질 수 있나요?

네. Microsoft는 미디어 압축 시 내장 자막과 대체 오디오 트랙이 손실될 수 있다고 안내합니다. 원본 보관과 압축 후 검증이 필요합니다.

Q. 편집 데이터를 삭제하면 사진을 다시 원래대로 복구할 수 있나요?

압축본 안에 남아 있던 이전 편집 데이터가 삭제되면 원래 편집 상태로 되돌리기 어려울 수 있습니다. 수정 가능성이 있는 자료는 원본 PPTX를 반드시 보관하세요.

Q. 글꼴 포함을 끄면 파일이 작아지나요?

경우에 따라 파일 크기를 줄일 수 있지만, 다른 컴퓨터에서 글꼴이 대체되면서 디자인이 달라질 수 있습니다. 편집 및 공유 목적에 맞춰 결정하세요.

Q. PPTX 파일을 PDF로 바꾸면 항상 더 작아지나요?

그렇지 않습니다. 포함된 사진·글꼴·내보내기 설정에 따라 PDF가 더 커질 수도 있습니다. PPTX와 PDF 크기를 각각 확인해야 합니다. 또한 PDF는 편집이나 애니메이션 유지 목적의 대안이 아닙니다.

15. 결론: 어떤 파일인지에 따라 압축 순서가 다릅니다

사진이 많은 PPT라면 먼저 그림 전체 압축과 잘린 그림 영역 정리를 검토하세요. 동영상이 포함된 PPT라면 Windows용 PowerPoint의 미디어 압축이 더 중요할 수 있습니다. 단, 압축 과정에서 자막·대체 오디오 트랙이 손실될 수 있다는 점을 반드시 확인해야 합니다.

화질이 중요한 사진·도표는 무조건 낮은 해상도로 바꾸기보다 최종 사용 환경에서 직접 확인해야 합니다. 원본을 보관하고, 압축 전후 용량과 재생·선명도 결과를 함께 비교하는 것이 가장 안전한 방법입니다.
