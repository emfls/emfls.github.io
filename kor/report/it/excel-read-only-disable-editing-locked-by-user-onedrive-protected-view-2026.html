엑셀 파일을 열었는데 제목에 '읽기 전용'이 표시되고, 셀을 수정하거나 저장하려고 하면 오류가 발생하는 경우가 있습니다. 인터넷에서 받은 파일의 '편집 사용' 버튼이 보이기도 하고, '다른 사용자가 편집 중이라 잠겼습니다'라는 메시지가 나오거나, OneDrive·회사 공유파일에서 보기만 허용되는 상황도 있습니다.

모두 같은 '읽기 전용'은 아닙니다. 파일 자체의 속성, Microsoft Office의 보호된 보기, 원본 작성자가 설정한 읽기 전용 권장, 다른 사용자의 파일 잠금, 공동 작업 권한, 시트 보호와 통합 문서 보호는 각각 해결 방법이 다릅니다.

2026년 11월 기준 Microsoft 공식 도움말을 바탕으로 데이터 손실·보안 위험을 줄이는 순서로 설명합니다. 먼저 중요한 파일을 별도 복사본으로 보관한 뒤, 실제로 어느 유형의 보호인지 확인하세요.

2. 가장 먼저 원본 파일을 안전하게 보관하세요

읽기 전용 문제를 해결하기 전에 작성 중이던 내용을 잃지 않도록 하는 것이 중요합니다.

  1. 중요한 원본 Excel 파일의 경로와 파일명을 확인합니다.
  2. 수정 가능한 상태라면 파일 → 다른 이름으로 저장 / 복사본 저장 기능을 확인합니다.
  3. 원본과 별도로 문서명_작업용.xlsx 같은 복사본을 만들어 두는 것이 좋습니다.
  4. 회사·학교 공동 작업 문서라면 무단으로 권한을 바꾸거나 보호를 제거하지 않습니다.
  5. 편집 전에 원본의 마지막 수정 일시·작성자·공유 위치를 확인합니다.

주의: OneDrive에서 자동 저장이 켜져 있다면 수정 내용이 공동 작업 파일에 반영될 수 있습니다. Microsoft는 원본을 유지하고 별도 수정을 하려면 미리 '복사본 저장'을 이용하라고 안내합니다.

공식 참고: Microsoft — 자동 저장에서 알아둘 사항.

3. 윈도우에서 엑셀 파일 속성의 '읽기 전용' 해제하기

Windows 파일 자체에 읽기 전용 특성이 설정돼 있다면 Excel을 종료한 후 파일 탐색기에서 확인할 수 있습니다.

따라 하기

  1. 엑셀에서 작업 중인 파일을 닫습니다.
  2. 파일 탐색기에서 해당 .xlsx 또는 .xls 파일을 찾습니다.
  3. 파일을 마우스 오른쪽 버튼으로 클릭하고 속성을 선택합니다.
  4. 일반 탭에서 읽기 전용 체크박스를 확인합니다.
  5. 체크되어 있다면 체크 해제 → 적용 → 확인을 선택합니다.
  6. 파일을 다시 Excel로 열어 내용을 수정·저장할 수 있는지 확인합니다.

Microsoft 공식 도움말은 파일의 속성 → 읽기 전용을 확인하고 선택 해제하는 방법을 안내합니다.

체크박스가 없거나 해제해도 해결되지 않으면?

  • 파일이 Windows 파일 특성 때문이 아니라 OneDrive·회사 서버의 보기 권한으로 제한됐을 수 있습니다.
  • 다른 사용자가 해당 파일을 잠그고 있을 수 있습니다.
  • Excel의 제한된 보기·암호·워크시트 보호 같은 별도 조건이 적용됐을 수 있습니다.
  • 네트워크 드라이브 등에서는 관리자·소유자 권한이 필요한 경우가 있습니다.

읽기 전용 특성을 해제했다고 공유 문서의 편집 권한까지 얻는 것은 아닙니다.

공식 출처: Microsoft — 파일이 읽기 전용으로 열리는 이유.

4. '제한된 보기'와 '편집 사용'은 언제 눌러야 하나요?

인터넷·이메일 첨부파일 등에서 받은 Excel 문서는 보안상 제한된 보기(Protected View)로 열릴 수 있습니다. 이때는 대부분의 편집 기능이 잠시 비활성화됩니다.

안전한 파일인지 확인한 뒤 진행

  1. 파일의 발신자·다운로드 사이트·예상한 내용이 맞는지 확인합니다.
  2. Excel 상단의 노란 보안 메시지 막대를 확인합니다.
  3. 실제로 신뢰할 수 있는 파일이라면 편집 사용(Enable Editing)을 선택할 수 있습니다.
  4. 편집 기능이 활성화된 후 파일을 수정하고 사본으로 저장합니다.
  5. 모르는 발신자나 예상하지 못한 첨부파일이라면 편집 사용을 누르지 않고 발신자에게 별도로 확인합니다.

Microsoft는 인터넷에서 받은 문서가 바이러스·웜·맬웨어 위험 때문에 제한된 보기로 열릴 수 있다고 설명합니다.

빨간색 경고 막대라면?

일부 보호된 보기 경고에서는 파일 → 그래도 편집과 같은 경로가 안내될 수 있습니다. 다만 Microsoft도 파일의 출처와 내용이 신뢰할 수 있을 때만 제한을 해제하라고 강조합니다.

회사 컴퓨터에서 버튼이 비활성화돼 있다면?

회사·학교의 관리자가 설정한 보안 정책으로 인해 제한된 보기를 해제할 수 없는 상황도 있습니다. 조직 정책을 무력화하기보다 관리자에게 문의하세요.

공식 출처: Microsoft — 제한된 보기란?.

5. '다른 사용자가 편집을 위해 파일을 잠갔습니다' 해결

Microsoft는 이 오류의 '다른 사용자'가 실제로는 나 자신일 수도 있다고 설명합니다. 다른 컴퓨터에서 파일을 열어 둔 경우, Excel이 비정상 종료된 경우, 공동 작성에 맞지 않는 환경인 경우 등이 원인입니다.

내가 잠근 파일이라면

  1. 내 PC의 다른 Excel 창에서 같은 파일이 열려 있는지 확인합니다.
  2. 회사 PC·노트북·태블릿 등 다른 장치에서도 동일 파일을 닫습니다.
  3. 파일이 있는 폴더가 OneDrive·SharePoint라면 서버가 잠금을 해제할 때까지 잠시 기다립니다.
  4. 파일을 다시 열어 읽기 전용 경고가 없어졌는지 확인합니다.
  5. 계속되면 원본을 보존한 상태에서 Excel을 정상 종료·재시작합니다.

다른 사람이 잠갔다면

  1. 화면에 표시된 사용자 또는 파일 담당자에게 연락합니다.
  2. 작업을 마치고 파일을 닫아 달라고 요청합니다.
  3. 급하게 작업해야 한다면 별도 복사본을 작성할 수 있는지 확인합니다.
  4. 공동 편집 문서라면 OneDrive·SharePoint와 지원되는 Excel 버전을 이용할 수 있는지 검토합니다.

주의: 공유 서버의 파일 잠금이나 임시 파일을 임의로 삭제하면 다른 사람의 수정 내용을 잃을 수 있습니다. 우선 정상적인 종료·동기화 확인·소유자 협의를 진행하세요.

공식 출처: Microsoft — Excel 파일이 편집을 위해 잠겨 있음.

6. OneDrive 공유 파일이 보기 전용이라면

OneDrive나 SharePoint에서 파일이 열리지만 수정 버튼이 보이지 않는다면 파일 자체 오류보다 공유 권한 문제일 수 있습니다.

확인 순서

  1. 파일을 열고 Excel 상단의 보기(Viewing) / 편집(Editing) 표시를 확인합니다.
  2. 보기 전용으로 제공됐다면 파일 소유자가 편집을 허용했는지 확인합니다.
  3. Excel에 추가 액세스 요청 기능이 보이면 편집 요청을 선택합니다.
  4. 해당 기능이 없으면 소유자에게 직접 편집 가능한 공유 권한을 요청합니다.
  5. 권한 변경 후 파일을 다시 열어 편집이 가능한지 확인합니다.

Microsoft는 Excel 파일이 읽기 전용 권한으로 공유된 경우 '보기 → 추가 액세스 요청 → 편집 요청' 흐름을 안내합니다. 조직 설정과 Excel 버전에 따라 버튼 이름·제공 여부가 달라질 수 있습니다.

다른 사람이 링크를 보내 줬다면?

  • 보기 권한 링크로는 원본을 수정할 수 없습니다.
  • 파일을 다운로드해 내 PC에서 편집하는 것은 가능할 수 있지만 원본 공유 문서가 자동 수정되는 것은 아닙니다.
  • 업무 문서라면 소유자의 권한과 회사 정책을 따르세요.
  • 편집 요청을 받은 소유자가 권한을 승인해야 원본에 수정사항을 반영할 수 있습니다.

공식 출처: Microsoft — Excel 파일 편집 잠금과 추가 액세스 요청, Microsoft — Excel 공유.

7. 여러 사람이 동시에 편집할 수 없는 이유

파일이 공동 작업에 맞지 않는 환경에서 열리면 서로 편집을 잠그는 문제가 발생할 수 있습니다. Microsoft는 모든 참여자가 공동 작성(Co-authoring) 지원 버전을 이용하고, 파일을 OneDrive·SharePoint의 지원되는 위치에 저장할 것을 권장합니다.

Microsoft는 Excel for Microsoft 365, 웹용 Excel 등을 공동 작성 지원 환경으로 안내합니다. 오래된 Excel 버전이 참여하면 다른 사용자에게 잠금 오류가 발생할 수 있습니다.

이 표는 모든 회사에 공동 편집 설정을 바꾸라고 권하는 것이 아닙니다. 문서의 보안·감사·기록 관리가 우선이라면 조직 관리자의 승인하에 협업 환경을 변경해야 합니다.

공식 출처: Microsoft — Excel 공동 작성, Microsoft — Excel 파일 편집 잠금.

8. 특정 셀만 수정되지 않으면 '시트 보호'를 확인하세요

파일 전체가 읽기 전용인 것은 아닌데 일부 셀만 입력이 안 되는 경우, 해당 워크시트의 보호 기능 때문일 수 있습니다.

확인 방법

  1. Excel에서 문제가 있는 시트를 엽니다.
  2. 상단 검토 탭을 선택합니다.
  3. 시트 보호 해제 버튼이 있는지 확인합니다.
  4. 버튼이 있으면 현재 시트에 보호가 설정됐을 가능성이 있습니다.
  5. 시트 소유자로부터 수정 권한을 받았다면 시트 보호 해제를 선택합니다.
  6. 암호가 설정돼 있다면 정상적인 암호를 입력합니다.
  7. 수정해야 할 범위를 다시 확인합니다.

Microsoft는 워크시트 보호는 특정 셀의 변경을 제한하는 기능이라고 설명합니다. 전체 Excel 파일이 인터넷에서 받은 제한된 보기인지와는 다릅니다.

암호가 없으면?

암호로 보호된 시트는 소유자에게 암호 또는 수정 가능한 버전을 요청하는 것이 정상적인 방법입니다. 알려지지 않은 암호를 해제한다며 외부 해제 사이트에 회사 자료를 업로드하지 마세요.

Microsoft 공식 문서도 암호를 잊으면 Microsoft가 원래 암호를 복구해 줄 수 없다고 안내합니다.

공식 출처: Microsoft — 워크시트 보호 및 해제.

9. 시트 추가·삭제가 안 되면 '통합 문서 보호' 확인

셀 편집은 되는데 시트를 새로 만들거나 이름을 바꿀 수 없는 경우는 워크시트 보호가 아니라 통합 문서의 구조 보호일 수 있습니다.

구분표

기능보호 대상주로 제한되는 작업
시트 보호워크시트의 셀·수식·영역 등잠긴 셀 값 변경, 서식 변경 등
통합 문서 보호통합 문서의 구조시트 추가·삭제·이동·이름 변경 등
파일 수준 암호화파일 자체열기·수정 권한 등
보호된 보기신뢰할 수 없는 출처의 파일편집·저장 등 일부 작업
파일 잠금동시에 열려 있는 파일원본 파일의 동시 수정

원본 작성자가 통합 문서 구조를 보호한 경우, 검토 → 통합 문서 보호에서 상태를 확인할 수 있습니다. 암호가 필요하면 정당한 소유자·담당자에게 문의해야 합니다.

공식 출처: Microsoft — 통합 문서 보호 및 해제, Microsoft — Excel의 보호와 보안.

10. 파일이 항상 읽기 전용으로 열리도록 설정된 경우

일부 통합 문서는 작성자가 실수로 수정되는 일을 방지하려고 항상 읽기 전용으로 열기(Always Open Read-Only) 설정을 사용합니다. 암호로 파일을 열지 못하게 하는 것과는 다른 목적입니다.

파일 소유자라면 확인할 것

  1. 본인이 관리하는 통합 문서를 Excel 데스크톱 앱으로 엽니다.
  2. 파일 → 정보 → 통합 문서 보호 메뉴를 확인합니다.
  3. 항상 읽기 전용으로 열기 항목이 켜져 있는지 확인합니다.
  4. 변경할 권한이 있고 해당 기능을 해제하려면 동일한 메뉴를 다시 선택합니다.
  5. 저장하고 파일을 다시 열어 상태를 확인합니다.

Microsoft는 원본의 불필요한 수정을 방지하기 위해 이 설정을 권장하기도 합니다. 따라서 남의 공유 문서에 이런 설정이 보인다고 반드시 해제해야 하는 오류는 아닙니다.

암호 또는 조직 정책으로 강제된 보호와는 다릅니다. 항목이 보이지 않거나 비활성화됐다면 제품 버전·권한을 확인하세요.

공식 출처: Microsoft — Excel 공동 작성에서 읽기 전용 설정, Microsoft — 자동 저장과 읽기 전용.

11. 수정은 되는데 저장이 안 되는 경우

'읽기 전용'과 '저장 실패'는 같은 문제가 아닐 수 있습니다. Microsoft는 OneDrive 저장 공간 부족, 정품 인증 문제 등도 편집·저장 장애의 원인으로 안내합니다.

우선 순서

  1. 다른 이름으로 저장 / 복사본 저장이 가능한지 확인합니다.
  2. OneDrive 저장 위치라면 사용 가능한 저장 공간을 확인합니다.
  3. 동기화 앱이 일시 중지되거나 오류를 표시하는지 확인합니다.
  4. 네트워크 드라이브라면 파일 저장 권한과 연결 상태를 확인합니다.
  5. Excel 상단의 제품 정품 인증 오류가 표시되는지 확인합니다.
  6. 다른 앱에서 동일 파일이 열려 잠긴 상태인지 확인합니다.
  7. 원본 사본을 확보한 뒤 Office 업데이트·다시 시작 등을 검토합니다.

OneDrive 용량이 가득 찼다면, 읽기 전용 표시를 해제하는 것만으로 원래 클라우드 문서에 저장할 수 있는 것은 아닙니다. 필요한 저장 공간을 확보해야 합니다.

공식 출처: Microsoft — 읽기 전용 파일이 열리는 이유.

12. 이메일로 받은 Excel 파일만 읽기 전용으로 열립니다

이메일 첨부파일이나 외부 인터넷에서 받은 Excel 파일은 제한된 보기로 열릴 수 있습니다. 이는 파일 손상과 다른 현상입니다.

확인 순서

  1. 파일을 보낸 사람의 이메일 주소와 요청한 내용을 확인합니다.
  2. 첨부파일을 예상하지 못했다면 별도 채널로 발신자에게 확인합니다.
  3. 파일을 열었을 때 Excel 상단에 보안 경고 또는 제한된 보기가 표시되는지 봅니다.
  4. 신뢰할 수 있는 문서라면 편집 사용을 선택할 수 있습니다.
  5. 원본 첨부파일은 보관하고 작업용 사본을 저장해 편집합니다.

보안 위험 경고를 일괄적으로 끄면 안 됩니다. 인터넷에서 받은 모든 파일에 대해 제한된 보기를 비활성화하는 것은 악성코드 감염 위험을 높일 수 있습니다.

공식 출처: Microsoft — 제한된 보기란?.

13. Mac용 Excel에서 읽기 전용으로 열릴 때

맥북에서도 읽기 전용 원인을 나눠 봐야 합니다.

Mac 증상확인할 것
열 때 읽기 전용 권장 메시지Excel의 읽기 전용 권장 설정 여부

OneDrive에서 보기만 가능계정·공유 권한

Microsoft는 Mac용 Excel의 '파일 → 암호 → 읽기 전용 권장' 옵션을 안내합니다. 읽기 전용 권장은 다른 사람이 수정하지 않도록 상기시키는 기능이며, Microsoft는 강한 보호 기능 자체는 아니라고 설명합니다.

또한 Mac용 Excel에서 파일을 암호로 보호하는 기능과 시트 보호·통합 문서 보호는 구분해야 합니다.

14. 암호가 걸린 Excel 파일은 어떻게 해야 하나요?

이 부분은 특히 오해가 많습니다. 읽기 전용 해제 방법과 알 수 없는 암호를 우회하는 방법은 별개입니다.

Microsoft는 Excel에서 파일·시트·통합 문서 수준으로 보호를 설정할 수 있으며, 암호를 모르는 경우에는 Microsoft가 암호를 복구해 줄 수 없다고 명시합니다.

보호별 안전한 접근

  • 파일 열기 암호: 문서 소유자에게 올바른 암호 또는 열람 가능한 사본을 요청
  • 파일 수정 암호: 원본 수정 권한이 있는지 확인하고 담당자에게 문의
  • 시트 보호 암호: 시트 소유자에게 수정 권한 또는 암호 요청
  • 통합 문서 구조 보호: 관리자가 허용한 경우 공식 메뉴에서 해제
  • 보기 전용 공유 링크: 파일 소유자에게 편집 권한 요청

웹에 있는 '엑셀 잠금 해제 사이트'에 급여명세서·고객명단·계약정보를 업로드하지 마세요. 승인되지 않은 암호 우회는 접근권한과 보안정책을 침해할 수 있습니다.

공식 출처: Microsoft — Excel의 보호 및 보안, Microsoft — 워크시트 보호.

16. 자주 묻는 질문(FAQ)

Q1. 엑셀 읽기 전용을 가장 빨리 해제하는 방법은?

원인에 따라 다릅니다. Windows 파일 속성의 읽기 전용이라면 파일을 닫고 마우스 오른쪽 클릭 → 속성 → 읽기 전용 체크 해제로 해결할 수 있습니다. 그러나 다른 사용자 잠금·공유 권한·시트 보호는 다른 절차가 필요합니다.

Q2. 파일을 열었더니 '편집 사용' 버튼이 나옵니다. 눌러도 되나요?

Excel이 제한된 보기로 열었을 가능성이 있습니다. 보낸 사람과 파일 출처를 신뢰할 수 있는지 확인한 뒤 편집 사용 여부를 판단하세요. 모르는 발신자의 파일은 보안 경고를 해제하지 마세요.

Q3. 엑셀에 '다른 사용자가 편집 중'이라고 나오지만 아무도 안 쓰고 있습니다.

내 다른 기기나 Excel의 이전 프로세스가 파일을 열어 둔 것으로 인식될 수 있습니다. 다른 기기의 파일을 닫고, OneDrive·SharePoint 사용 중이면 잠금 해제 반영까지 기다린 다음 다시 확인하세요.

Q4. OneDrive 공유 Excel 파일에서 편집 버튼이 없습니다.

원본 파일의 보기 전용 공유 권한일 수 있습니다. 파일 소유자에게 편집 권한을 요청하세요. 일부 Excel 환경에서는 보기 → 추가 액세스 요청을 제공합니다.

Q5. 엑셀의 특정 셀만 수정할 수 없습니다.

시트 보호가 설정됐을 수 있습니다. 검토 → 시트 보호 해제가 보이는지 확인하고, 암호가 필요하면 담당자에게 요청하세요.

Q6. 시트를 새로 만들거나 이름을 바꾸지 못합니다.

통합 문서의 구조 보호 때문일 수 있습니다. 셀 편집을 제한하는 시트 보호와 구분해서 검토 → 통합 문서 보호를 확인하세요.

Q7. Windows에서 파일 속성의 읽기 전용을 해제해도 여전히 안 됩니다.

파일 속성 외에 보호된 보기·OneDrive 권한·다른 사용자 잠금·워크시트 보호가 적용됐을 수 있습니다. 정확한 Excel 메시지를 기준으로 다음 원인을 점검하세요.

Q8. 엑셀 파일 읽기 전용 상태에서도 다른 이름으로 저장할 수 있나요?

상황에 따라 사본 저장은 가능할 수 있습니다. 그러나 암호·조직 권한 정책 등으로 제한된 경우도 있어, 소유자의 허가와 제품의 실제 제공 기능을 확인해야 합니다.

Q9. Mac용 Excel에서도 읽기 전용 권장 설정을 해제할 수 있나요?

Mac용 Excel에는 파일 → 암호 → 읽기 전용 권장 관련 옵션이 있습니다. 파일 소유자라면 설정을 검토할 수 있으며, 암호·권한 보호와 구분해야 합니다.

Q10. 읽기 전용 파일을 공동 편집하려면 어떻게 해야 하나요?

편집 권한이 있는 OneDrive·SharePoint의 지원되는 저장 위치와 공동 작성을 지원하는 Excel 버전을 사용해야 합니다. 파일 소유자와 조직의 협업 규칙을 확인하세요.

Q11. OneDrive 저장 공간이 부족하면 엑셀 파일이 읽기 전용처럼 되나요?

Microsoft는 OneDrive 저장 공간이 가득 차면 문서를 저장할 수 없는 문제가 발생할 수 있다고 안내합니다. 파일의 읽기 전용 표시와 별개로 용량·동기화 상태를 확인해야 합니다.

Q12. 시트 보호 암호를 잊어버렸습니다. Microsoft가 복구해 주나요?

Microsoft는 잊어버린 암호를 복구해 줄 수 없다고 안내합니다. 문서 소유자·관리자에게 권한이 있는 사본이나 암호를 요청하세요. 무단 우회는 피해야 합니다.

17. 제출·공유 전 최종 체크리스트

  • ☐ 파일이 열리지 않는 문제와 열리지만 편집이 안 되는 문제를 구분했다.
  • ☐ 원본 Excel 파일을 별도 보관했다.
  • ☐ Windows 파일의 읽기 전용 특성을 확인했다.
  • ☐ 제한된 보기라면 신뢰할 수 있는 출처인지 먼저 확인했다.
  • ☐ 다른 사용자가 잠금이라고 표시되면 다른 기기·공동 작업자를 확인했다.
  • ☐ OneDrive·SharePoint의 원본 편집 권한이 있는지 확인했다.
  • ☐ 특정 셀만 수정 안 되면 시트 보호를 확인했다.
  • ☐ 시트 구조를 바꿀 수 없으면 통합 문서 보호를 확인했다.
  • ☐ 정식 암호를 모를 때 무단 우회를 시도하지 않았다.
  • ☐ 저장 실패 시 OneDrive 용량·동기화·계정 인증 상태를 확인했다.
