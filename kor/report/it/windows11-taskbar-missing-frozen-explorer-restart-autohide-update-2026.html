Windows 11에서 작업 표시줄이 갑자기 사라지거나 시작 버튼이 눌리지 않는다면 곧바로 윈도우를 초기화할 필요는 없습니다. 자동 숨김 설정, Windows 탐색기(Explorer) 프로세스, 외부 모니터 배치, 최근 Windows 업데이트처럼 서로 다른 원인을 구분하면 자료를 삭제하지 않고 해결할 수 있는 경우가 있습니다.

이 글은 2026년 11월 1일 기준 Microsoft 공식 고객지원과 Windows 문제 해결 문서를 확인해 작성했습니다. 특히 Windows 11 24H2·25H2의 일부 기업 관리용 기기에서 나타났던 작업 표시줄·시작 메뉴 오류는 별도 공식 문서(KB5072911)가 있으며, Microsoft는 2026년 6월 23일 이후 업데이트에서 수정이 제공됐다고 설명합니다. 해당 사례를 모든 개인용 PC의 원인으로 확대 해석하지 않는 것이 중요합니다.

문제가 발생한 컴퓨터에 저장하지 않은 작업이 있다면 먼저 가능한 파일을 저장하고 진행하세요. 탐색기 재시작과 컴퓨터 재부팅은 일반적으로 문서 파일을 삭제하는 절차가 아니지만, 저장되지 않은 작업 상태까지 보장하지는 않습니다.

1. 증상별로 먼저 확인할 순서

나타나는 증상가능한 원인첫 번째 점검
작업 표시줄이 평소에는 안 보이다가 마우스를 대면 나타남자동 숨김 활성화작업 표시줄 동작의 자동 숨김 해제
시작 메뉴·아이콘·시계가 모두 사라짐Windows 탐색기 또는 셸 일시 오류작업 관리자로 Windows 탐색기 재시작
작업 표시줄은 보이나 클릭에 반응하지 않음탐색기 응답 중단, 앱 충돌Ctrl+Shift+Esc, Explorer 재시작
보조 모니터에서만 작업 표시줄이 없음여러 디스플레이 표시 옵션모든 디스플레이에 표시 설정
시작 버튼만 눌리지 않음시작 메뉴 구성 요소 또는 최근 변경탐색기 재시작, 업데이트 확인
업데이트 이후 계속 재발운영체제·드라이버·앱 충돌업데이트 기록, 공식 알려진 문제 확인
화면 전체가 검게 보이고 커서만 움직임디스플레이·셸 등 복합 원인Ctrl+Alt+Del, 탐색기 재시작
회사·학교 PC에서 최초 로그인 이후 발생관리 환경, 정책 또는 특정 XAML 오류관리자에게 Windows 버전·KB 전달

추천 해결 순서: 자동 숨김·모니터 확인 → 탐색기 재시작 → Windows 재시작 → 업데이트 확인 → 시스템 파일 검사 → 지원되는 복구 기능. 명령어나 레지스트리 편집은 나중 단계에서 검토하고, 출처가 불분명한 복구 스크립트는 실행하지 않는 편이 안전합니다.

공식 자료: Microsoft Windows 작업 표시줄 사용자 지정, Microsoft Windows 빈 화면 문제 해결

2. 가장 먼저 확인할 것: 작업 표시줄 자동 숨김

마우스를 화면 아래쪽 가장자리로 가져갔을 때 작업 표시줄이 나타난다면 시스템 고장보다 자동 숨김 기능이 켜져 있을 가능성부터 확인해야 합니다. Microsoft 공식 안내에 따르면 작업 표시줄은 사용하지 않을 때 자동으로 숨기도록 설정할 수 있습니다.

  1. Windows 키+I를 눌러 설정을 엽니다.
  2. 개인 설정 → 작업 표시줄로 들어갑니다.
  3. 아래쪽의 작업 표시줄 동작을 펼칩니다.
  4. 작업 표시줄 자동 숨기기 옵션을 확인합니다.
  5. 계속 표시하고 싶다면 해당 옵션의 선택을 해제합니다.
  6. 바탕화면으로 돌아가 작업 표시줄이 유지되는지 확인합니다.

작업 표시줄 위에서 마우스 오른쪽 버튼을 누를 수 있다면 작업 표시줄 설정으로 바로 이동할 수도 있습니다. 그러나 작업 표시줄 자체가 보이지 않으면 Windows+I 단축키가 더 편리합니다.

기기 및 Windows 빌드에 따라 작업 표시줄 위치나 크기 관련 옵션이 다를 수 있습니다. 문제 해결을 위해 레지스트리로 작업 표시줄 위치를 강제 변경하는 방법은 권장하지 않습니다.

공식 자료: Microsoft — 작업 표시줄 자동 숨김 설정

3. 작업 표시줄이 완전히 사라졌다면 Windows 탐색기 다시 시작

작업 표시줄과 시작 메뉴가 응답하지 않는 경우 Windows 탐색기(Windows Explorer)를 다시 시작하면 셸 관련 일시 오류가 해결될 수 있습니다. Microsoft는 검은 화면에 마우스 커서가 나타나는 문제 해결 과정에서 작업 관리자를 통한 Windows Explorer 재시작을 공식 안내합니다.

  1. Ctrl+Shift+Esc를 눌러 작업 관리자를 엽니다.
  2. 필요한 경우 프로세스 탭으로 이동합니다.
  3. 목록에서 **Windows 탐색기(Windows Explorer)**를 찾습니다.
  4. 해당 항목을 선택하거나 마우스 오른쪽 버튼으로 클릭합니다.
  5. **다시 시작(Restart)**을 선택합니다.
  6. 바탕화면과 작업 표시줄이 잠시 사라졌다가 다시 나타나는지 확인합니다.
  7. 시작 버튼과 시계, 실행 중인 프로그램 아이콘을 눌러 정상 동작을 확인합니다.

탐색기를 재시작하면 열린 파일 탐색기 창이 영향을 받거나 화면 구성이 잠깐 새로 그려질 수 있습니다. 업무 중인 파일을 가능한 한 저장한 뒤 진행하세요.

주의: 작업 관리자에서 여러 시스템 프로세스를 무작정 종료하지 마세요. 정확한 이름이 Windows 탐색기인지 확인하고, 일반적인 앱 프로세스나 알 수 없는 시스템 항목은 건드리지 않는 편이 좋습니다.

공식 자료: Microsoft — 작업 관리자로 Windows Explorer 다시 시작

4. 작업 관리자에 Windows 탐색기 항목이 없을 때

프로세스 목록에 Windows 탐색기가 표시되지 않는다면 Microsoft가 안내하는 방법으로 새 작업을 실행해 explorer.exe를 시작할 수 있습니다.

  1. Ctrl+Shift+Esc로 작업 관리자를 엽니다.
  2. Windows 11 작업 관리자 상단 또는 메뉴에서 **새 작업 실행(Run new task)**을 찾습니다.
  3. 실행할 프로그램 이름에 explorer.exe를 입력합니다.
  4. 확인 또는 Enter 키를 누릅니다.
  5. 작업 표시줄과 바탕화면이 다시 표시되는지 확인합니다.

임의로 인터넷에서 내려받은 같은 이름의 실행 파일을 실행할 필요가 없습니다. Windows에 포함된 탐색기 프로그램을 시작하도록 하는 절차입니다.

만약 작업 관리자 자체가 열리지 않는다면 Ctrl+Alt+Delete를 눌러 보안 화면에서 작업 관리자를 선택할 수 있는지 확인하세요. Microsoft의 빈 화면 문제 해결 안내에도 이 경로가 포함돼 있습니다.

추가 확인: 여러 차례 explorer.exe를 실행해도 곧바로 다시 종료된다면 단순한 자동 숨김 문제보다 운영체제 구성 요소나 최근 변경과 관련된 문제일 수 있습니다. 뒤의 업데이트·시스템 파일 점검 항목으로 넘어가세요.

공식 자료: Microsoft — 빈 화면에서 탐색기 다시 시작

5. 시작 메뉴와 작업 표시줄이 동시에 먹통일 때

시작 버튼을 클릭해도 반응이 없고 검색창·작업 표시줄의 앱 아이콘까지 멈춘다면 다음 순서로 범위를 좁혀 볼 수 있습니다.

  1. Ctrl+Shift+Esc로 작업 관리자가 열리는지 확인합니다.
  2. 작업 관리자가 열리면 Windows 탐색기를 다시 시작합니다.
  3. Windows 키+I로 설정이 열리는지 테스트합니다.
  4. 프로그램을 종료할 수 있다면 필요한 파일을 저장한 후 컴퓨터를 정상 재시작합니다.
  5. 재시작 후 시작 버튼, 검색, 작업 표시줄의 아이콘을 차례대로 눌러 봅니다.
  6. 로그인 직후에만 문제가 생기는지, 특정 프로그램을 실행한 후 발생하는지 기록합니다.

시작 메뉴만 안 되는 현상과 전체 Windows 인터페이스가 멈추는 현상은 정확히 같은 원인이라고 볼 수 없습니다. 로그인 직후인지, 업데이트 직후인지, 특정 앱 설치 이후인지가 진단에 도움이 됩니다.

Microsoft는 일부 기업용 Windows 11 환경에서 Explorer, 시작 메뉴, 작업 표시줄, 검색 등 XAML 의존 구성 요소가 동시에 시작되지 않을 수 있는 문제를 문서화했습니다. 그러나 이 문제는 제한된 기업·관리 환경에서 주로 발생하며 일반 개인용 장치에서는 가능성이 매우 낮다고 설명합니다.

공식 자료: Microsoft KB5072911 — 특정 기업 관리 환경의 시작 메뉴·작업 표시줄 오류

6. 모니터 두 대를 쓴다면 표시 설정을 따로 확인

두 개 이상의 모니터를 쓰는 경우 기본 모니터에는 작업 표시줄이 있지만 다른 화면에는 보이지 않는 현상이 있을 수 있습니다. 이것이 모든 화면의 작업 표시줄이 고장 났다는 뜻은 아닙니다.

  1. Windows 키+I를 눌러 설정을 엽니다.
  2. 개인 설정 → 작업 표시줄 → 작업 표시줄 동작으로 들어갑니다.
  3. 모든 디스플레이에 작업 표시줄 표시에 해당하는 옵션을 확인합니다.
  4. 여러 디스플레이에서 표시하도록 원하는 설정을 선택합니다.
  5. 설정 → 시스템 → 디스플레이에서 모니터 번호와 배열도 확인합니다.
  6. Windows 키+P로 화면 확장·복제 등 현재 투영 모드를 확인합니다.

Microsoft 공식 고객지원은 여러 디스플레이에 작업 표시줄을 표시하는 설정을 별도로 안내합니다. 옵션 이름이나 제공 범위는 Windows 버전·디스플레이 구성에 따라 달라질 수 있습니다.

구별 방법: 마우스를 특정 모니터의 화면 경계로 이동했을 때만 나타난다면 자동 숨김 또는 해당 디스플레이의 작업 표시줄 표시 정책을 의심할 수 있습니다. 반면 기본 모니터에서도 시작 버튼·시계가 전부 사라졌다면 탐색기 재시작을 우선 검토하세요.

공식 자료: Microsoft — 여러 디스플레이에 작업 표시줄 표시

7. 실행 중인 프로그램 아이콘만 사라진 경우

작업 표시줄 자체는 있고 시계도 보이지만 특정 프로그램의 아이콘만 없다면 다른 문제일 수 있습니다.

앱이 실행되지 않았는지 확인

Alt+Tab으로 열려 있는 창을 확인합니다. 실행되지 않은 프로그램이라면 작업 표시줄에 표시되지 않는 것이 정상일 수 있습니다.

작업 표시줄에 고정한 앱이 해제됐는지 확인

시작 메뉴에서 해당 앱을 찾아 마우스 오른쪽 버튼을 누른 뒤 **작업 표시줄에 고정(Pin to taskbar)**을 선택할 수 있습니다. 프로그램을 자주 쓰지만 고정이 해제됐을 뿐이라면 재설치할 필요가 없습니다.

검색·위젯 등 특정 기능만 없는 경우

설정 → 개인 설정 → 작업 표시줄 → 작업 표시줄 항목에서 검색·위젯·작업 보기 같은 개별 항목의 표시 여부를 확인합니다. 항목이 숨김으로 설정됐다면 Windows 탐색기를 재설치하거나 시스템을 복구할 이유가 없습니다.

오른쪽의 작은 아이콘만 안 보이는 경우

시계 근처의 시스템 트레이에는 앱과 시스템 아이콘을 표시하거나 숨기는 별도 설정이 있습니다. 네트워크·오디오·클라우드 앱 아이콘이 안 보인다면 알림 영역 설정이나 확장 목록을 확인하세요.

공식 자료: Microsoft — 작업 표시줄 고정 및 시스템 트레이 사용자 지정

8. 작업 표시줄이 검은 화면과 함께 사라졌다면

바탕화면 전체가 검게 변하고 마우스 커서만 움직이는 경우에는 단순한 작업 표시줄 문제뿐 아니라 디스플레이 드라이버나 로그인 구성 요소 오류도 고려해야 합니다.

Microsoft의 공식 안내에 따르면 다음과 같은 순서로 확인할 수 있습니다.

  1. 연결된 모니터와 케이블, 전원을 확인합니다.
  2. Windows 키+Ctrl+Shift+B를 눌러 그래픽 드라이버를 다시 설정해 봅니다.
  3. Ctrl+Alt+Delete를 눌러 보안 화면이 표시되는지 확인합니다.
  4. 작업 관리자를 열 수 있다면 Windows 탐색기를 다시 시작합니다.
  5. 탐색기가 실행 중이 아니면 새 작업 실행 → explorer.exe를 검토합니다.
  6. 최근 그래픽 드라이버나 Windows 업데이트 이후 증상이 생겼다면 해당 변경을 확인합니다.
  7. 화면이 계속 비어 있다면 Microsoft의 공식 Windows 복구 절차로 넘어갑니다.

강제 종료는 우선 조치가 아닙니다. 작업 중인 데이터가 저장되지 않았거나 Windows 업데이트가 진행 중인 경우에는 손실 위험이 있습니다. Windows가 전혀 응답하지 않고 정상 종료 방법을 사용할 수 없을 때 마지막 수단으로 검토하세요.

공식 자료: Microsoft — Windows 빈 화면 문제 해결

9. 2026년 최신 공식 사례: 일부 기업 PC에서의 작업 표시줄 오류

Microsoft는 KB5072911 문서에서 Windows 11 버전 24H2·25H2의 일부 관리 환경에 영향을 준 Explorer·작업 표시줄·시작 메뉴의 비정상 동작을 설명합니다.

누가 영향을 받을 수 있었나요?

Microsoft 설명에 따르면 문제가 주로 관찰된 환경은 기업용 관리 PC, 특히 Windows 업데이트가 사용자 첫 로그인 전에 적용되거나, 매 로그인 때 앱 패키지 등록이 필요한 비영구 가상 데스크톱(VDI) 등입니다. Microsoft는 일반 개인 사용자의 PC에서 이 문제가 발생할 가능성은 매우 낮다고 명시합니다.

어떤 증상이 나타났나요?

해당 공식 문서에 기록된 예시는 작업 표시줄 미표시, 시작 메뉴 실행 실패, Explorer 비정상 종료, 로그인 이후 검은 화면 및 시스템 설정 앱 실행 실패 등입니다.

2026년 11월 기준 해결 상태

Microsoft는 2026년 6월 23일 배포 업데이트(KB5095093)부터 수정이 제공됐으며, 이후 월간 Windows 업데이트를 통해 점진적으로 적용된다고 설명합니다. 따라서 2026년 11월 기준으로 오래된 인터넷 게시글의 수동 PowerShell 명령을 그대로 복사하기보다 먼저 해당 장치에 최신 누적 업데이트가 설치됐는지 확인하는 것이 적절합니다.

기업용 PC에서만 검토할 점

조직의 Windows 이미지 배포, XAML 패키지 등록, 가상 데스크톱 정책은 관리자가 점검해야 하는 영역입니다. 해당 KB에 포함된 패키지 재등록 명령은 일반 사용자에게 일괄 적용할 해결책이 아닙니다. 회사·학교 장치라면 Windows 버전과 설치된 KB를 확인해 IT 관리자에게 전달하세요.

공식 자료: Microsoft KB5072911 — 2026년 수정 내역

10. Windows 업데이트 확인과 업데이트 기록 보기

탐색기 재시작으로 해결되지 않거나 재부팅 때마다 같은 문제가 반복된다면 Windows의 최신 업데이트 상태와 최근 변경 사항을 확인하세요.

  1. Windows 키+I로 설정을 엽니다.
  2. Windows 업데이트로 이동합니다.
  3. 업데이트 확인을 선택합니다.
  4. 제공된 업데이트의 이름과 설명, 설치 요구 사항을 확인합니다.
  5. 중요한 업무가 진행 중이라면 저장과 백업을 마친 뒤 업데이트합니다.
  6. 필요에 따라 재시작하고 작업 표시줄 동작을 다시 확인합니다.
  7. 증상이 특정 업데이트 이후 시작됐다면 업데이트 기록에서 설치 날짜와 KB 번호를 기록합니다.

Microsoft는 업데이트 오류에 대한 공식 문제 해결 페이지에서 Windows 업데이트 문제 해결사와 시스템 파일 검사 등을 안내합니다. 다만 Windows 업데이트를 실행했다고 모든 작업 표시줄 오류가 자동으로 해결된다고 보장할 수 없습니다.

업데이트 제거를 바로 실행하지 마세요. 보안 업데이트를 삭제하면 수정됐던 취약점에 다시 노출될 수 있습니다. 특정 업데이트가 원인이라는 근거가 있는지 공식 알려진 문제 문서와 복구 옵션을 먼저 확인하세요.

공식 자료: Microsoft — Windows 업데이트 오류 문제 해결

11. DISM과 SFC로 시스템 파일 검사하는 방법

작업 표시줄·시작 메뉴 관련 문제가 반복되고 일반 설정으로 해결되지 않을 때 Windows 기본 복구 도구인 DISM과 **시스템 파일 검사기(SFC)**를 사용할 수 있습니다. Microsoft는 시스템 파일 손상이 의심되는 경우 DISM을 먼저 실행한 뒤 SFC를 실행하도록 안내합니다.

실행 전 준비

  • 중요한 문서를 저장하고 가능한 범위에서 백업합니다.
  • 인터넷 연결과 전원이 안정적인지 확인합니다.
  • 회사 관리 장치라면 관리자 권한 사용 정책을 확인합니다.
  • 다른 복구 프로그램이나 출처 불명 스크립트는 실행하지 않습니다.

관리자 권한으로 명령 프롬프트 열기

  1. 시작 메뉴가 사용 가능하면 검색에서 명령 프롬프트를 찾고 관리자 권한으로 실행합니다.
  2. 시작 메뉴가 동작하지 않으면 Ctrl+Shift+Esc로 작업 관리자를 열고 새 작업 실행에서 cmd를 입력한 뒤, 사용 가능한 경우 관리자 권한 옵션을 선택합니다.
  3. 먼저 Windows 이미지 복구 명령을 입력합니다.

DISM.exe /Online /Cleanup-image /Restorehealth

완료 메시지가 나타난 후 시스템 파일 검사기를 실행합니다.

sfc /scannow

  1. SFC 검사가 100% 완료될 때까지 기다립니다.
  2. 표시된 결과를 기록하고, 필요한 경우 정상적으로 재시작합니다.
  3. 작업 표시줄과 시작 메뉴의 동작을 확인합니다.

이 두 도구는 시스템 파일 문제를 검사·복구하는 데 도움이 될 수 있지만 특정 원인의 작업 표시줄 오류를 무조건 해결하는 만능 명령은 아닙니다. 결과 메시지에 복구할 수 없는 오류가 남거나 계속 재발하면 다음 복구 방법을 검토하세요.

공식 자료: Microsoft — 시스템 파일 검사기를 사용해 손상 파일 복구

12. 탐색기 재시작과 재부팅이 계속 반복될 때

매번 Windows 탐색기를 다시 시작해야 작업 표시줄이 나타난다면 단순한 일시 응답 중단을 넘어 반복적인 충돌 원인을 좁혀야 합니다.

발생 시점을 기록하세요

  • Windows에 로그인하자마자 작업 표시줄이 사라지는가?
  • 화면 잠금을 해제할 때만 나타나는가?
  • 특정 보안 프로그램·원격 데스크톱·디스플레이 관리 앱을 실행한 직후인가?
  • 새 Windows 업데이트를 설치한 직후인가?
  • 외부 모니터를 연결하거나 해제한 직후인가?
  • 회사의 관리 계정에서만 발생하는가?

이런 기록이 있으면 무작정 레지스트리 수정 명령을 적용하는 것보다 문제 원인을 좁히는 데 유용합니다.

앱 충돌이 의심된다면

최근 설치한 앱과 업데이트 날짜를 비교하세요. 특히 작업 표시줄의 위치·모양·아이콘을 변경하는 비공식 프로그램을 사용 중이라면 해당 프로그램의 공식 호환성 정보를 확인해야 합니다. 개인 PC에서 문제를 진단하기 위해 설정을 임시 변경했다면, 테스트 후 원래 상태로 복원하세요.

회사·학교 PC에서는 보안 프로그램이나 조직 관리 에이전트를 임의로 제거하지 마세요. IT 담당자에게 재현 조건과 Windows 빌드 번호, 관련 오류를 전달하는 편이 안전합니다.

13. 그래도 안 되면 Windows의 복구 설치를 검토

Microsoft는 Windows 11에 Windows 업데이트를 사용한 문제 해결(Fix problems using Windows Update) 복구 옵션을 제공합니다. 지원되는 PC에서는 현재 설치된 Windows 버전을 다시 설치해 시스템 파일과 구성 요소를 복구하고, 앱·개인 파일·설정은 유지하도록 설계된 방식입니다.

공식 복구 경로

  1. 설정 → 시스템 → 복구로 이동합니다.
  2. Windows 업데이트를 사용하여 문제 해결에 해당하는 항목이 제공되는지 확인합니다.
  3. **지금 다시 설치(Reinstall now)**를 선택하기 전에 Microsoft 설명과 화면에 표시되는 주의사항을 읽습니다.
  4. 중요한 파일을 백업하고 전원·인터넷 연결을 확보합니다.
  5. 안내에 따라 현재 Windows 버전의 복구 설치를 진행합니다.
  6. 완료 후 PC를 재시작하고 문제가 해결됐는지 확인합니다.

모든 PC에 보이는 것은 아닙니다

Microsoft는 학교·회사에서 관리하는 기기 등에서는 이 옵션이 보이지 않을 수 있다고 설명합니다. 일부 Windows 버전과 업데이트 수준에 따라서도 제공되지 않을 수 있습니다.

복구 설치와 이 PC 초기화는 다릅니다. 초기화는 선택한 옵션에 따라 앱 또는 데이터에 영향을 줄 수 있으므로 원인을 진단하지 않은 상태에서 우선 실행할 작업이 아닙니다. 또한 공식 복구 설치도 예상치 못한 오류에 대비해 중요한 자료를 사전에 백업해야 합니다.

공식 자료: Microsoft — 현재 Windows 버전 재설치로 문제 해결

14. 시스템 복원과 초기화의 차이

최근 프로그램 설치나 시스템 설정 변경 이후 문제가 시작됐다면 **시스템 복원(System Restore)**을 검토할 수 있습니다. Microsoft는 시스템 복원이 개인 문서를 직접 대상으로 하는 복구가 아니라 시스템 파일·설정·설치 프로그램 상태를 이전 복원 지점으로 되돌리는 기능이라고 설명합니다.

시스템 복원 사용 전 확인

  1. 사용 가능한 복원 지점이 있는지 확인합니다.
  2. 문제가 생기기 전 날짜의 복원 지점을 선택할 수 있는지 살펴봅니다.
  3. 영향을 받는 프로그램 목록을 확인합니다.
  4. 중요한 파일은 별도로 백업합니다.
  5. BitLocker를 사용하는 PC라면 복구 환경에서 복구 키가 필요할 수 있으므로 준비합니다.

2026년 Windows의 다른 복구 기능

Microsoft는 일부 Windows 11 환경에 특정 시점 복원(Point-in-time restore) 기능도 안내합니다. 이 기능은 기존 시스템 복원과 달리 해당 시점의 파일과 앱까지 되돌릴 수 있어, 복원 지점 이후 변경한 작업을 잃을 수 있습니다. 따라서 명칭이 비슷하다고 동일하게 취급하면 안 됩니다.

권장 순서: 작업 표시줄 설정과 탐색기 재시작 → 업데이트·시스템 파일 점검 → 지원되는 복구 설치나 적절한 복원 방법 검토 → 초기화는 최후 수단. 복원 및 초기화 전에는 해당 기능이 개인 파일, 앱, 설정에 미치는 영향을 반드시 공식 설명에서 확인하세요.

공식 자료: Microsoft — 시스템 복원, Microsoft — 특정 시점 복원

15. 자주 묻는 질문

Q. 작업 표시줄이 갑자기 사라졌는데 파일까지 삭제된 건가요?

대부분의 경우 작업 표시줄 미표시와 개인 파일 삭제는 별개 증상입니다. 자동 숨김이나 Explorer 문제일 수 있으므로 먼저 Windows+I의 작업 표시줄 설정과 Ctrl+Shift+Esc의 탐색기 재시작을 확인하세요. 다만 다른 증상이 함께 발생했다면 저장 장치 문제 등도 별도로 점검해야 합니다.

Q. Ctrl+Shift+Esc를 눌렀는데 Windows 탐색기가 없어요.

작업 관리자의 새 작업 실행에서 explorer.exe를 입력해 Windows 탐색기를 시작하는 방법을 Microsoft가 안내합니다. 탐색기가 곧바로 다시 종료되면 업데이트나 시스템 구성 요소 문제를 추가로 점검해야 합니다.

Q. 마우스를 화면 가장자리로 가져가면 작업 표시줄이 다시 보여요.

작업 표시줄 자동 숨기기가 켜져 있는지 확인하세요. 설정 → 개인 설정 → 작업 표시줄 → 작업 표시줄 동작에서 해당 옵션을 해제할 수 있습니다.

Q. 모니터 한쪽에서만 작업 표시줄이 안 보입니다.

모든 디스플레이에 작업 표시줄 표시 설정과 Windows의 디스플레이 배열을 확인하세요. 두 모니터가 각각 다른 투영 모드를 사용하도록 설정돼 있는지도 확인해야 합니다.

Q. 시작 버튼과 검색창이 함께 먹통입니다.

Windows 탐색기 재시작과 정상 재부팅부터 시도하세요. 특히 회사에서 관리하는 Windows 11 24H2·25H2 장치라면 Microsoft의 KB5072911 관련 여부와 최신 누적 업데이트 설치 상태를 관리자와 확인할 수 있습니다.

Q. 2025년에 알려진 KB5072911 오류는 지금도 해결되지 않았나요?

Microsoft는 2026년 6월 23일 KB5095093부터 해결 업데이트가 제공됐다고 설명합니다. 이후 업데이트에도 해당 수정이 반영되도록 안내하므로, 2026년 11월 기준으로는 오래된 수동 복구 명령보다 최신 업데이트 설치 상태 확인이 먼저입니다. 이 문제는 모든 Windows PC의 공통 원인이 아닙니다.

Q. DISM과 SFC 중 어떤 것을 먼저 실행하나요?

Microsoft 공식 문서는 DISM을 먼저, 그다음 SFC를 실행하도록 안내합니다. 관리자 권한과 안정적인 실행 환경을 확보하세요. 모든 작업 표시줄 문제의 해결을 보장하지는 않습니다.

Q. 작업 표시줄이 안 보이니까 바로 이 PC 초기화를 해도 되나요?

권장하지 않습니다. 자동 숨김·탐색기 재시작·업데이트처럼 영향이 작은 점검을 먼저 실시하세요. 이후에도 문제가 계속될 때 공식 복구 기능과 초기화의 데이터·앱 보존 범위를 비교하고 중요한 자료를 백업하세요.

16. 해결 후 재발 방지 체크리스트

  • ☐ 작업 표시줄 자동 숨김 설정을 원하는 상태로 조정했습니다.
  • ☐ 작업 관리자를 통해 Windows 탐색기를 정상적으로 재시작했습니다.
  • ☐ 작업 표시줄 아이콘과 시작 메뉴, 시계가 정상 동작하는지 확인했습니다.
  • ☐ 외부 모니터를 쓴다면 여러 디스플레이 표시 설정을 확인했습니다.
  • ☐ 최근 설치한 프로그램이나 업데이트와 오류 시작 시점을 기록했습니다.
  • ☐ Windows 업데이트 및 필요한 재시작을 완료했습니다.
  • ☐ 문제 재발 시 시스템 파일 검사 결과와 오류 메시지를 보관했습니다.
  • ☐ 기업 관리용 PC의 경우 관리자에게 Windows 버전과 KB 정보를 전달했습니다.
  • ☐ 복원·복구 설치·초기화 전에 중요한 파일을 백업했습니다.
  • ☐ 출처가 불분명한 레지스트리 편집 도구나 PowerShell 스크립트를 실행하지 않았습니다.
  • ☐ 반복 오류가 있으면 날짜·발생 상황·사용자 계정·연결된 모니터 구성을 기록했습니다.

정리: 작업 표시줄이 마우스를 대면 나타나는 경우는 자동 숨김 설정, 시계와 시작 메뉴가 모두 사라진 경우는 Windows 탐색기, 업데이트 뒤 기업 PC에서만 반복되는 경우는 공식 KB와 관리 정책을 먼저 확인하는 것이 좋습니다. 초기화 전에 Microsoft가 안내하는 기본 점검부터 진행하면 불필요한 데이터 손실 위험을 줄일 수 있습니다.

  1. Microsoft — Windows 작업 표시줄 사용자 지정: 자동 숨김, 아이콘 고정, 검색·작업 보기·시스템 트레이, 여러 디스플레이 표시.
  2. Microsoft — Windows 빈 화면 문제 해결: Ctrl+Shift+Esc, Windows Explorer 다시 시작, explorer.exe 실행, 디스플레이 관련 점검.

  4. Microsoft — Windows 업데이트 문제 해결: Windows 업데이트 점검 및 시스템 파일 검사.
  5. Microsoft — 시스템 파일 검사기(SFC) 사용: DISM과 SFC의 순서 및 명령어.

  7. Microsoft — Windows 시스템 복원: 시스템 설정과 프로그램을 복원 지점으로 되돌리는 방식.
  8. Microsoft — 특정 시점 복원: 파일을 포함한 복원 범위와 변경 내용 손실 위험.
