  • 카카오톡은 2026년 기준 메시지 전송 후 24시간 이내에 상대방 채팅방에서도 메시지를 삭제하거나 수정할 수 있습니다.

1. 30초 정리: ‘수정’과 ‘삭제’ 무엇을 눌러야 할까?

상황권장 동작상대방에게 남는 것
오타·시간·장소만 틀림가능한 경우 ‘수정’바뀐 내용과 ‘수정됨’ 표시
잘못된 채팅방에 보냄24시간 이내 모두에게서 삭제원문 대신 삭제 안내 문구
나만 채팅창을 정리하고 싶음이 기기에서 삭제/나에게서만 삭제상대방 채팅 내용은 그대로
보낸 지 24시간 지남상대방 채팅 내용은 해당 일반 삭제 기능으로 제거 불가내 기기에서만 정리 가능할 수 있음
상대가 이미 메시지를 읽음24시간 이내라면 삭제 기능 확인이미 읽거나 저장한 사실까지 되돌리지는 못함

가장 흔한 실수는 ‘나에게서만 삭제’를 선택한 뒤 상대방 화면에서도 지워졌다고 생각하는 것입니다. 급하더라도 확인 창의 적용 범위를 읽고 진행하세요.

2. 카카오톡 메시지 ‘모두에게서 삭제’ 방법: 갤럭시·아이폰

카카오의 공식 쉬운 설명서에는 다음 순서가 제시돼 있습니다.

  1. 카카오톡에서 잘못 보낸 채팅방을 엽니다.
  2. 내가 보낸 메시지를 약 2초 동안 길게 누릅니다.
  3. 나타난 메뉴에서 ‘삭제’를 선택합니다.
  4. 삭제 범위 선택 화면에서 ‘모든 대화 상대에게서 삭제’를 선택합니다.
  5. 확인 창의 설명을 읽고 ‘확인’ → ‘삭제’로 완료합니다.
  6. 내 채팅방의 메시지 내용이 삭제 안내 문구로 바뀌었는지 확인합니다.

카카오 공식 안내에 따르면 이렇게 삭제한 메시지는 친구의 채팅방과 내 채팅방 모두에서 원래 내용이 사라지지만, 그 자리에 ‘삭제된 메시지입니다.’ 같은 안내가 표시됩니다. 아무 흔적도 남기지 않는 기능은 아닙니다.

공식 화면별 안내: 카카오 더 쉬운 카톡설명서 — 보낸 메시지 삭제하기.

3. 카카오톡 메시지 삭제는 5분? 24시간? 정확한 기준

예전에는 보낸 메시지를 상대방 화면에서 지울 수 있는 시간이 짧았기 때문에 ‘5분’이라는 설명이 인터넷에 많이 남아 있습니다. 현재 카카오 공식 안내는 ‘보낸 지 24시간 이내’를 기준으로 제시합니다.

  • 기준은 내가 메시지를 보낸 시각입니다.
  • 24시간이 지났다면 ‘모두에게서 삭제’ 옵션이 표시되지 않을 수 있습니다.
  • 상대방이 읽었는지 여부와 전송 시간 제한은 서로 다른 문제입니다.
  • 24시간 이내라도 채팅 유형이나 메시지 종류에 따라 메뉴 제공 여부가 다를 수 있습니다.

시간 계산 예시(가상): 11월 5일 오후 3시에 보낸 메시지라면, 11월 6일 오후 3시가 24시간 경계입니다. 경계 직전에는 앱 처리 시각에 따라 실패할 수도 있으므로 중요한 메시지는 가능한 한 즉시 삭제하는 편이 안전합니다.

출처: 카카오 공식 24시간 삭제 안내.

4. ‘모두에게서 삭제’와 ‘나에게서만 삭제’ 차이

두 기능은 전혀 다릅니다.

모두에게서 삭제

상대방까지 포함한 채팅 참여자의 화면에서 원본 메시지 내용을 제거하려는 기능입니다. 단, 삭제 안내 문구가 남고, 상대방이 이미 보거나 다른 곳에 저장한 내용을 회수하지는 못합니다.

이 기기에서 삭제 / 나에게서만 삭제

현재 사용 중인 내 기기의 채팅 화면을 정리하는 기능입니다. 상대방에게 보이는 메시지에는 영향을 주지 않습니다. 상대방에게 잘못 보낸 메시지를 지우고 싶다면 이 옵션을 선택하면 안 됩니다.

삭제 범위를 잘못 골랐다면? 먼저 해당 메시지가 아직 목록에 남아 있는지 확인하세요. 내 기기에서 이미 사라졌다면 단순히 ‘모두에게서 삭제’를 다시 누를 대상을 찾지 못할 수 있습니다. 따라서 처음부터 삭제 범위를 정확히 고르는 것이 중요합니다.

5. 메시지를 지우지 않고 ‘수정’하는 방법

카카오는 2025년 9월 카카오톡 버전 25.8.0 업데이트에서 메시지 수정 기능을 발표했습니다. 24시간 이내의 전송 메시지를 수정할 수 있으며, 수정된 메시지에는 ‘수정됨’ 표시가 붙습니다.

실제 앱에서 제공되는 경우의 기본 절차는 다음과 같습니다.

  1. 수정하고 싶은 내가 보낸 텍스트 메시지가 있는 채팅방으로 이동합니다.
  2. 메시지를 길게 눌러 ‘수정’ 메뉴가 제공되는지 확인합니다.
  3. 수정 화면이 나오면 오타나 시간·숫자를 고칩니다.
  4. 수정 내용을 다시 읽고 완료/저장 동작으로 확정합니다.
  5. 채팅 화면에서 바뀐 문구와 수정 표시를 확인합니다.

중요: 이 기능은 원래 잘못 보낸 문장을 ‘없던 일’로 만드는 기능이 아닙니다. 수정된 사실이 표시되고, 상대방이 수정 전 문구를 이미 읽었거나 알림으로 봤을 수 있습니다. 사진·첨부파일·특수 메시지에도 동일한 수정 메뉴가 있다는 뜻은 아닙니다.

카카오 공식 발표: if(kakao)25 카카오톡 메시지 수정 기능 도입.

6. 24시간 이내인데 ‘모두에게서 삭제’가 안 보일 때

아래 순서로 원인을 좁혀 보세요.

확인할 항목점검 방법
내가 쓴 메시지인가?상대방이 보낸 메시지는 상대방 화면에서 임의로 삭제할 수 없습니다.
전송 시각이 맞는가?최초 전송 시점부터 24시간이 지났는지 확인합니다.
채팅방 유형은 무엇인가?카카오가 안내하는 일반 채팅과 비밀채팅·나와의 채팅은 동작이 다릅니다.
최신 앱인가?앱스토어·구글플레이에서 카카오톡 업데이트 가능 여부를 확인합니다.
문자·첨부파일 등 특수 메시지인가?실제 화면에서 삭제 선택지가 제공되는지 확인합니다.
메시지를 ‘나에게서만 삭제’했는가?원본이 내 화면에서 이미 사라졌다면 삭제 범위를 다시 선택하지 못할 수 있습니다.

해결 순서: 메시지 전송 시각 → 내가 보낸 메시지인지 → 채팅방 유형 → 앱 업데이트 → 해당 메시지 길게 누르기 순으로 확인하세요. 그래도 메뉴가 없다면 카카오 고객센터의 카카오톡 도움말에서 현재 제공 조건을 확인합니다.

7. ‘수정’ 버튼이 안 보이면 어떻게 하나요?

먼저 24시간이 지났는지 확인합니다. 수정 기능은 2025년 9월에 도입됐으며 일부 메시지와 환경에서는 메뉴 구성이 다를 수 있습니다.

  • 오래된 메시지라면 새 메시지로 정정하는 방법을 검토하세요.
  • 사진이나 파일은 문자와 수정 기능이 같다고 가정하지 마세요.
  • 단체 채팅방이나 오픈채팅방에서는 실제 메시지 메뉴를 확인하세요.
  • 앱을 업데이트했는데도 메뉴가 없다면 계정·채팅 형태·메시지 종류에 따라 차이가 있는지 공식 도움말에서 확인하세요.

예시: ‘내일 2시 회의’를 ‘내일 3시 회의’로 바꿔야 하는 경우에는, 수정 기능이 제공된다면 원문을 수정한 뒤 ‘수정됨’ 표시가 붙었는지 살펴보면 됩니다. 이미 상대방에게 전달된 약속이라면 별도 정정 메시지를 추가하는 편이 혼선을 줄일 수 있습니다.

8. 상대방이 이미 읽은 메시지도 삭제할 수 있나요?

‘읽음 여부’만으로 24시간 이내 삭제가 불가능해지는 것은 아닙니다. 다만 메시지를 지운 뒤에도 다음 사실은 달라지지 않습니다.

  • 상대방이 수정·삭제 전에 내용을 읽었을 수 있습니다.
  • 잠금화면 알림이나 다른 알림 미리보기에서 원래 내용을 봤을 수 있습니다.
  • 상대방이 이미 저장한 캡처·사진·파일을 삭제 기능으로 원격 회수할 수는 없습니다.
  • 삭제한 메시지가 있다는 안내 표시는 남을 수 있습니다.

잘못 보낸 개인정보나 금융정보가 있었다면 메시지를 삭제하는 것만으로 사고 대응이 끝났다고 생각하지 마세요. 노출된 정보의 종류에 따라 비밀번호 변경이나 계정 보안 점검이 필요할 수 있습니다.

9. PC 카카오톡에서도 삭제·수정할 수 있나요?

PC 카카오톡에서는 모바일과 메뉴 이름이나 기능 제공 조건이 다를 수 있습니다. 실무적으로는 다음 순서로 확인하면 됩니다.

  1. PC 카카오톡에서 해당 채팅방을 엽니다.
  2. 내가 보낸 메시지를 마우스 오른쪽 버튼으로 클릭합니다.
  3. 메뉴에 삭제 또는 수정이 있는지 확인합니다.
  4. 삭제하려면 상대방까지 적용되는 범위인지 확인합니다.
  5. 메뉴가 없거나 적용 범위가 불명확하다면 같은 계정으로 로그인된 최신 모바일 카카오톡에서 확인합니다.

PC에서도 모든 모바일 기능이 동일하게 작동한다고 단정해서는 안 됩니다. 현재 사용 중인 PC 프로그램의 버전, 채팅방 종류, 메뉴 설명을 우선하세요.

10. 자주 묻는 질문

Q1. 5분이 지나면 카톡은 삭제가 안 되나요?

아닙니다. 카카오 공식 설명서는 현재 24시간 이내에 보낸 메시지의 모두에게서 삭제를 안내합니다.

Q2. 카톡을 지우면 상대방에게 아무 흔적도 안 남나요?

아닙니다. 카카오 공식 설명서에서는 원문 대신 ‘삭제된 메시지입니다.’라는 안내가 표시됩니다.

Q3. 상대가 이미 본 메시지를 지우면 본 사실도 사라지나요?

아닙니다. 채팅 화면에서 원문을 삭제하는 것과 상대방이 이미 확인한 내용을 없애는 것은 다릅니다.

Q4. 나에게서만 삭제를 선택하면 상대방도 못 보나요?

아닙니다. 카카오 공식 안내에 따르면 내 채팅 화면에서만 삭제됩니다.

Q5. 카카오톡 메시지를 수정하면 상대방이 알아차리나요?

수정된 메시지에는 ‘수정됨’ 표시가 붙습니다. 수정 전 내용을 상대방이 이미 확인했을 가능성도 고려하세요.

Q6. 24시간이 지난 메시지를 상대방 화면에서 지우는 우회 방법이 있나요?

카카오가 안내하는 일반적인 모두에게서 삭제 기능의 시간 제한은 24시간입니다. 다른 사람의 화면에 저장된 내용을 강제로 삭제할 수 있다고 홍보하는 비공식 앱이나 유료 서비스를 신뢰하지 마세요.

Q7. 예약 메시지를 취소하는 것과 이미 보낸 메시지를 삭제하는 것은 같은가요?

다릅니다. 예약 발송을 취소하는 기능은 전송 전 예약을 관리하는 것이고, 이 글의 삭제 기능은 이미 전송된 메시지에 적용됩니다.

자주 묻는 질문 (FAQ)

카카오톡에서 메시지를 모두에게서 삭제할 수 있는 시간 제한은 어떻게 되나요?

카카오톡은 메시지 전송 후 24시간 이내에만 ‘모두에게서 삭제’ 기능을 제공하며, 24시간이 지나면 이 옵션이 사라질 수 있습니다.

메시지를 삭제하지 않고 수정할 수 있나요?

네, 2025년 9월 업데이트 이후 24시간 이내에 보낸 메시지를 수정할 수 있으며, 수정된 메시지에는 ‘수정됨’ 표시가 남습니다.

‘나에게서만 삭제’와 ‘모두에게서 삭제’의 차이는 무엇인가요?

‘나에게서만 삭제’는 내 기기에서만 메시지를 지우는 기능으로 상대방 화면에는 영향을 주지 않으며, ‘모두에게서 삭제’는 상대방 포함 모든 대화 상대의 채팅방에서 메시지를 삭제합니다.
