이력서를 제출하기 전에 주민등록번호 뒷자리를 검은 상자로 덮거나 거래명세서의 계좌번호 위에 검은 네모를 올려 PDF를 저장한 적이 있나요? 화면에서 안 보인다는 것과 파일에서 삭제됐다는 것은 다릅니다. 검은 도형이 원문 위의 별도 주석이나 개체로 저장됐다면, 아래의 글자가 여전히 파일에 존재할 수 있습니다.

개인정보가 포함된 PDF를 안전하게 공유하려면 세 단계를 구분해야 합니다. **교정(Redaction)**은 보이는 민감 정보를 실제로 제거하는 작업, **정화(Sanitization)**는 메타데이터·주석 등 숨겨진 정보를 점검하고 제거하는 작업, 검증은 완성 파일에 정보가 남았는지 다시 확인하는 과정입니다.

이 글은 2026년 11월 기준 Apple·Adobe·Microsoft 공식 사용 설명서를 바탕으로 작성했습니다. 프로그램 버전과 라이선스, PDF의 텍스트·이미지 구성에 따라 메뉴가 다를 수 있습니다.

검은 박스를 올리는 방식은 화면에 보여 주는 모습을 바꾸는 데 그칠 수 있습니다. 반면 PDF 교정은 지정된 텍스트와 그래픽을 제거하도록 설계된 기능입니다. 그래서 검은색으로 보이느냐가 아니라 원본 정보가 남았느냐를 점검해야 합니다.

2. 원본은 보존하고 복사본에서 작업하세요

교정은 적용 후 되돌릴 수 없는 삭제를 수반할 수 있습니다.

  1. 원본은 별도 폴더에 보관하고 파일의 복사본을 만듭니다.
  2. 삭제 대상 정보를 정리합니다. 예: 주민등록번호, 전화번호, 이메일, 주소, 계좌번호, 서명, QR코드.
  3. 본문 외에 머리글·바닥글·표·첨부·책갈피에도 같은 정보가 등장하는지 확인합니다.
  4. 비공개 자료는 신뢰할 수 없는 온라인 PDF 편집 사이트에 업로드하지 않습니다.
  5. 작업을 완료하기 전에는 편집 중인 파일을 외부에 보내지 않습니다.

실전 예시: 3쪽짜리 계약서의 첫 페이지에서 계좌번호를 지웠더라도 마지막 페이지의 입금 안내 표에 같은 번호가 남았다면 교정이 완료되지 않았습니다. 페이지별로 검토하되 같은 정보가 반복되는 위치를 찾는 것이 핵심입니다.

3. 맥북: 미리보기의 '교정 선택' 기능

Mac의 기본 앱 **미리보기(Preview)**에는 일반 주석 도형과 구별되는 교정 선택(Redaction Selection) 도구가 있습니다.

  1. Finder에서 PDF 파일을 선택하고 Command + D로 복사본을 만듭니다.
  2. 복사본을 미리보기로 엽니다.
  3. 필요하면 마크업 도구 막대 표시를 클릭합니다.
  4. 도구 막대에서 교정 선택 도구를 선택합니다.
  5. 실제로 제거할 텍스트를 드래그해 표시합니다.
  6. 같은 단어나 번호가 다른 페이지에도 있는지 확인합니다.
  7. 저장한 뒤 문서를 닫습니다. Apple에 따르면 교정은 문서를 닫을 때 영구적으로 적용됩니다.
  8. 저장 파일을 다시 열어 교정한 텍스트가 검색·복사되지 않는지 확인합니다.

Apple은 PDF 목차의 링크가 가려진 텍스트를 가리키더라도 목차 항목 자체는 자동 삭제되지 않을 수 있다고 설명합니다. 따라서 문서 검색뿐 아니라 목차·북마크도 검토해야 합니다.

스캔 이미지로 이루어진 PDF에서는 텍스트를 선택할 수 있는지부터 확인하세요. 텍스트를 선택할 수 없다면 다른 적절한 이미지 교정 수단이 필요할 수 있습니다. 마크업에서 검은 도형을 그리는 것으로 대체하지 마세요.

4. Adobe Acrobat Pro: 텍스트와 이미지 실제 교정

Adobe의 Acrobat Pro는 PDF 교정과 숨겨진 정보 정리 기능을 제공합니다. 무료 PDF 뷰어의 주석 기능과 동일하게 취급하면 안 됩니다.

  1. Acrobat Pro에서 PDF 복사본을 엽니다.
  2. 모든 도구 → PDF 교정을 선택합니다.
  3. 텍스트 및 이미지 교정을 선택합니다.
  4. 제거할 텍스트나 이미지 영역을 지정합니다.
  5. 해당 위치가 맞는지 여러 페이지를 확인합니다.
  6. 적용 버튼을 누릅니다.
  7. 숨겨진 정보 제거 옵션이 나타나면 필요한 정화 범위를 검토합니다.
  8. 계속을 누르고 결과 파일을 새 이름으로 저장합니다.
  9. 저장된 파일을 다시 열어 검색과 복사를 시험합니다.

주의: 특정 글자 위에 교정 표시만 하고 적용을 누르지 않았다면 작업이 완료되지 않은 상태일 수 있습니다. 지정, 적용, 저장을 모두 마친 뒤 결과 파일을 검증해야 합니다.

5. 여러 페이지에 반복되는 이름과 번호는 검색 교정

30쪽짜리 계약서처럼 같은 이름·거래처명·전화번호가 여러 번 등장하면 사람이 한 줄씩 찾기 어렵습니다. Acrobat Pro에는 단어와 문구, 특정 패턴을 찾아 교정 표시하는 기능이 있습니다.

  • 제거하려는 문자열을 검색합니다.
  • 검색 결과가 실제로 삭제할 대상인지 하나씩 확인합니다.
  • 필요한 일치 항목을 교정 대상으로 표시합니다.
  • 적용하고 파일을 저장합니다.
  • 같은 문자열로 다시 검색해 잔여 항목을 확인합니다.

자동 검색은 편리하지만 이미지 안에 보이는 문자나 OCR에서 인식하지 못한 숫자까지 빠짐없이 탐지한다는 뜻은 아닙니다. 표, 사진, 서명 및 스캔 페이지는 눈으로도 검사하세요.

공식 근거: Adobe — 검색 후 교정

6. 숨겨진 정보도 별도로 확인해야 합니다

PDF에는 본문 외에 작성자 이름, 제작 프로그램, 문서 속성, 댓글·주석, 숨겨진 레이어, 첨부 파일, 스크립트와 같은 정보가 포함될 수 있습니다.

Adobe는 교정은 보이는 텍스트와 그래픽 제거에 초점을 맞추며, 숨겨진 데이터는 별도의 정화 작업이 필요하다고 설명합니다. 따라서 개인정보가 들어 있는 PDF의 본문을 교정했다고 해서 파일 속성이 전부 안전해졌다고 단정할 수 없습니다.

Acrobat Pro에서는 모든 도구 → PDF 교정 → 정화 또는 숨겨진 정보 제거 경로에서 전체·선택적 제거 기능을 확인할 수 있습니다. 메뉴의 한국어 번역은 버전에 따라 다를 수 있습니다.

정화할 때는 필요한 주석이나 기능도 삭제될 수 있습니다. 반드시 복사본을 사용하고, 최종 파일의 내용과 열람 가능 여부를 확인하세요.

공식 근거: Adobe — PDF 숨겨진 콘텐츠 제거

7. Word 원본을 PDF로 내보내기 전 '문서 검사'도 활용

Word에서 작성한 문서를 PDF로 변환할 예정이라면 **문서 검사(Document Inspector)**를 함께 활용할 수 있습니다. 이 기능은 편집 기록과 속성 등 숨겨진 정보를 점검하는 데 도움이 됩니다.

  1. Word 파일을 복사하고 복사본을 엽니다.
  2. 파일 → 정보 → 문제 확인 → 문서 검사로 이동합니다.
  3. 검사할 항목을 선택한 뒤 검사를 실행합니다.
  4. 변경 내용, 댓글, 작성자 정보, 숨겨진 텍스트 등을 확인합니다.
  5. 삭제할 항목 옆의 모두 제거를 선택합니다.
  6. 다시 검사한 뒤 PDF로 내보내고, PDF 자체에도 최종 검증을 수행합니다.

Microsoft는 문서 검사기가 모든 보이지 않는 항목을 찾아 제거할 수 있는 것은 아니라고 명시합니다. 예컨대 다른 개체에 가려진 내용이 검사에서 누락될 수 있습니다.

Word 문서 검사와 PDF 교정은 다른 작업입니다. Word에서 속성을 정리했다고 해서 PDF의 민감한 본문까지 자동으로 제거됐다고 판단하면 안 됩니다.

8. 스캔 PDF와 OCR 문서는 더 주의하세요

PDF 종류특징확인할 점
텍스트 기반 PDF글자 선택·검색·복사가 가능아래에 남은 원문 텍스트 제거
스캔 이미지 PDF종이를 촬영한 이미지가 페이지를 구성그림 속 숫자·도장·서명 영역
OCR 적용 스캔 PDF이미지와 검색 가능한 텍스트가 함께 있을 수 있음보이는 이미지와 텍스트 층 모두

문서를 스캔했다고 해서 모든 민감 정보가 보호된 것은 아닙니다. 텍스트를 인식할 수 없더라도 이미지에 그대로 드러날 수 있습니다. 반대로 이미지 부분을 가려도 OCR 텍스트 층에 정보가 남을 가능성이 있습니다.

교정 기능이 실제로 이미지와 텍스트 층 모두를 처리하는지 확인하고, 결과를 다른 PDF 뷰어로 다시 열어 검증하세요.

9. 공유 전 5분 최종 검증 체크리스트

교정한 PDF를 공유하기 전에 실제로 첨부할 그 파일을 다시 열고 아래 사항을 확인합니다.

  • ☐ 원본과 다른 이름으로 저장했는가?
  • ☐ 편집 프로그램에서 파일을 닫았다가 다시 열었는가?
  • ☐ 지웠다는 이름·주소·전화번호를 검색했을 때 남아 있지 않은가?
  • ☐ 가린 부분을 복사·붙여넣기해도 글자가 나오지 않는가?
  • ☐ 다른 PDF 뷰어에서도 같은 부분이 안전하게 처리됐는가?
  • ☐ 표, 페이지 하단, 스캔 이미지, QR코드, 서명에 잔여 정보가 없는가?
  • ☐ 문서 속성·책갈피·댓글·첨부 파일도 검토했는가?
  • ☐ 원본이나 이전 수정본을 실수로 첨부한 것은 아닌가?

이 점검을 통과하더라도 모든 보안 위험이 0이 되는 것은 아닙니다. 법률·의료·인사·기밀 문서는 별도의 조직 보안 절차를 따르세요.

11. 자주 묻는 질문

Q. PDF에 검은 네모를 올리고 저장하면 안전한가요?

안전하다고 단정할 수 없습니다. 검은 도형이 별도 개체로 남으면 원래 텍스트가 파일 안에 여전히 존재할 수 있습니다. 개인정보 제거 목적이라면 교정 기능을 사용하세요.

Q. '인쇄 → PDF로 저장'하면 안전하게 가려질까요?

주석을 평탄화하는 등의 효과는 있을 수 있지만, 원본 콘텐츠와 숨겨진 정보가 완전히 제거되는지 보장하지 않습니다. 문서 교정과 정화 기능을 우선하는 것이 좋습니다.

Q. 맥 미리보기에서 검은 사각형과 '교정 선택'은 같은가요?

다릅니다. Apple은 교정 선택을 텍스트 제거 기능으로 안내합니다. 사각형 도형은 주석 개체일 수 있습니다.

Q. Acrobat Reader 무료 버전에서도 교정할 수 있나요?

이 글의 전용 교정·정화 절차는 Acrobat Pro 공식 기능을 기준으로 합니다. 무료 뷰어의 일반 주석 기능과 혼동하지 마세요.

Q. PDF에서 민감한 이름이 검색되지 않으면 끝인가요?

아닙니다. 이미지 속 글자, OCR 텍스트, 책갈피, 문서 속성, 주석과 첨부 파일도 확인해야 합니다.

마무리: 검은색으로 보이는 것보다 삭제 여부가 중요

PDF 개인정보를 가리는 작업은 단순한 꾸미기가 아니라 원문 정보 제거 작업입니다. 원본을 복사해 보관한 뒤 전용 교정 기능으로 민감 내용을 없애고, 필요하다면 메타데이터 등을 정화한 다음, 완성된 PDF를 다시 열어 직접 검사하세요.

교정 → 숨겨진 정보 정화 → 최종 검증을 구분하면 개인정보가 남아 있는 PDF를 실수로 공유하는 위험을 줄일 수 있습니다.
