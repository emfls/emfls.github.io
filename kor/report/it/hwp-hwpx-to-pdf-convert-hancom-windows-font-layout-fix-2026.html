핵심은 한컴오피스 한/글에서 '파일 → PDF로 저장하기' 기능을 이용하는 것입니다. 한컴의 공식 도움말은 이 기능에서 문서 전체·일부 쪽 선택, 그림 품질 설정, 암호 등의 옵션을 지원한다고 안내합니다. Windows 11에는 Microsoft Print to PDF가 기본 포함되지만, 이 기능만으로 HWP 파일을 열 수 있는 것은 아닙니다. 먼저 HWP/HWPX를 정상 표시·인쇄할 수 있는 프로그램이 필요합니다.

이번 글은 실제로 해야 할 작업을 기준으로, ① 한컴오피스가 있는 경우 ② 한컴오피스가 없는 경우 ③ 맥 또는 한컴독스 이용 시 ④ 변환 후 글꼴·표·쪽수가 바뀌는 경우를 나누어 설명합니다. 2026년 11월 4일 현재 공개된 한글과컴퓨터 및 Microsoft 공식 도움말을 기준으로 작성했습니다.

3. 한컴오피스 한/글에서 PDF로 저장하는 가장 확실한 방법

한컴오피스 한/글을 사용할 수 있다면 별도의 온라인 변환 사이트를 이용할 필요가 없습니다.

기본 저장 절차

  1. 한컴오피스 한/글을 실행합니다.
  2. 파일 → 불러오기에서 .hwp 또는 .hwpx 문서를 엽니다.
  3. 표, 그림, 쪽 번호, 글꼴이 원본 화면에서 제대로 보이는지 확인합니다.
  4. 파일 → PDF로 저장하기를 선택합니다.
  5. PDF 저장 대화상자에서 저장 위치와 파일 이름을 지정합니다.
  6. 필요하다면 저장 설정에서 문서 전체·특정 쪽·그림 품질을 조절합니다.
  7. 저장을 선택합니다.
  8. 저장한 PDF를 별도 PDF 뷰어에서 다시 열어 모든 페이지가 제대로 변환됐는지 확인합니다.

이 경로는 한컴오피스 2024 한/글 공식 도움말에 명시돼 있습니다. 제품 테마가 '오피스 호환'으로 설정돼 있다면 메뉴가 PDF 인쇄로 표시되는 등 이름이 달라질 수 있습니다.

PDF로 저장하기 메뉴가 안 보일 때: 파일 메뉴에서 PDF, PDF 인쇄, PDF로 저장하기 등의 항목을 찾고, 설치된 한/글의 도움말이나 사용권을 확인하세요.

공식 출처: 한컴오피스 2024 한/글 — PDF로 저장하기, 한컴오피스 — 테마별 메뉴 비교.

4. 특정 페이지만 PDF로 변환하는 방법

전체 문서가 아니라 2~4페이지만 제출하거나 개인정보가 포함된 다른 페이지를 제외해야 하는 경우가 있습니다. 한/글의 PDF 저장 설정은 부분 저장을 지원합니다.

저장 범위별 선택

선택 항목저장되는 범위활용 예시
문서 전체첫 장부터 마지막 장까지공문서 전체 제출
현재 쪽커서가 있는 쪽특정 확인서 한 장
현재 구역커서가 있는 구역구역별 보고서
현재부터 / 현재까지현재 쪽 이후·이전 범위일부 초안 제외
일부분직접 지정한 페이지 번호1,3,5-7처럼 여러 페이지 선택

한컴의 공식 예시는 **1,3,5-7**을 입력하면 1쪽, 3쪽, 5~7쪽을 저장하는 방식입니다. 입력한 순서대로 저장 옵션이 있으면 3,1,2처럼 재배치할 수도 있습니다.

주의: 문서의 표시 쪽 번호와 실제 순서

한글 문서는 구역별 쪽 번호를 새로 시작하는 경우가 있습니다. 공식 도움말에는 '쪽 번호 기준으로 저장' 기능도 있어, 이 옵션의 설정에 따라 결과가 달라질 수 있다고 안내합니다.

따라서 '3페이지만 저장했다'고 생각했는데 엉뚱한 페이지가 들어간 경우에는 PDF 저장 설정의 쪽 번호 기준과 구역을 확인하세요.

5. 윈도우11에서 'Microsoft Print to PDF'로 저장하는 방법

Windows 11에는 Microsoft Print to PDF 가상 프린터가 제공됩니다. 한컴오피스의 직접 PDF 저장 기능을 찾지 못하더라도, 파일을 정상적으로 인쇄할 수 있는 한/글 호환 앱이라면 이 경로를 검토할 수 있습니다.

따라 하기

  1. HWP/HWPX 파일을 지원되는 앱에서 엽니다.
  2. 원본이 깨지지 않았는지 확인합니다.
  3. Ctrl + P 또는 파일 → 인쇄를 선택합니다.
  4. 프린터 목록에서 Microsoft Print to PDF를 선택합니다.
  5. 인쇄할 페이지와 용지 크기(A4 등), 방향, 여백을 확인합니다.
  6. 인쇄를 누릅니다.
  7. '인쇄 출력을 다른 이름으로 저장' 창에서 파일 이름·저장 폴더를 선택합니다.
  8. 저장된 PDF를 열어 표·이미지·글꼴·페이지 수를 확인합니다.

Microsoft는 Windows 10·11에 Microsoft Print to PDF 유틸리티가 포함되어 있고, 인쇄 메뉴에서 이를 선택해 PDF 파일로 저장할 수 있다고 설명합니다.

잘못된 기대: 'Windows 11이면 HWP 파일을 무조건 무료로 PDF 변환할 수 있다'는 말은 정확하지 않습니다. 가상 프린터는 HWP 문서 해석기·편집기가 아니므로, 파일을 열고 인쇄할 수 있는 소프트웨어가 별도로 필요합니다.

공식 출처: Microsoft — PDF로 인쇄하는 방법.

6. 한컴오피스가 설치되지 않았다면? 한컴독스 사용 시 확인할 사항

한컴독스는 한컴이 제공하는 문서 서비스입니다. 공식 고객지원 문서에 따르면 웹 한글에서 .hwp와 .hwpx 파일을 열어 편집할 수 있고, 문서 크기 제한은 100MB로 안내됩니다.

공식 서비스에서 확인할 순서

  1. 한컴독스 또는 공식 고객지원에 접속합니다.
  2. 계정이 있다면 로그인합니다.
  3. HWP/HWPX 파일을 드라이브에 업로드합니다.
  4. 해당 파일을 웹 한글에서 엽니다.
  5. 표·글꼴·쪽 설정이 원본과 맞는지 확인합니다.
  6. 제공되는 인쇄·PDF 내보내기·다운로드 항목이 있는지 확인합니다.
  7. 해당 계정·요금제에서 기능이 지원된다면 PDF로 저장한 뒤 결과물을 재확인합니다.

여기서 반드시 주의할 점

  • 한컴독스의 웹 문서 편집 지원과 PDF 저장 기능 무료 제공 여부는 같은 정보가 아닙니다.
  • 요금제·시점·웹 UI에 따라 사용 가능한 출력·다운로드 기능이 달라질 수 있습니다.
  • 한컴의 공식 고객지원은 무료 버전의 데스크톱 앱은 뷰어 기능만 제공한다고 안내합니다. 따라서 '한컴독스 무료 계정이면 데스크톱 한/글에서 누구나 PDF 변환 가능'이라는 주장은 피해야 합니다.
  • 회사 기밀·주민등록번호·계약서 등 민감한 파일은 클라우드 업로드 규정부터 확인하세요.
  • 문서가 100MB 이내여도 폰트·양식이 원본과 같다는 보장은 없습니다.

따라서 무료 사용자의 실제 PDF 출력 가능 여부를 확인하기 전에는, 한컴독스를 확정적인 '완전 무료 변환기'로 소개하지 않는 것이 정확합니다.

7. 맥북에서 HWP/HWPX를 PDF로 바꾸는 방법

Mac을 사용한다면 이미 이용할 수 있는 한/글 프로그램이 있는지 확인하는 것이 먼저입니다.

한컴오피스 한/글 for Mac 이용 시

  1. 한/글에서 문서를 엽니다.
  2. 원본 레이아웃을 확인합니다.
  3. 파일 → PDF로 저장하기를 선택합니다.
  4. 저장 위치와 이름을 지정하고 저장합니다.
  5. Mac의 미리보기 등 PDF 뷰어에서 결과를 확인합니다.

한컴의 Mac용 한/글 공식 도움말도 이 절차를 안내합니다.

Mac에서 일반 앱이 지원하는 경우 파일 → 인쇄 → PDF로 저장을 이용할 수 있으나, HWP/HWPX 문서를 정상적으로 여는 앱이 먼저 필요하다는 원칙은 Windows와 같습니다.

Mac 기본 미리보기는 PDF를 볼 수 있는 앱이라는 이유만으로 모든 HWP/HWPX 문서를 원본처럼 변환할 수 있다고 단정하면 안 됩니다. 먼저 호환 앱에서 문서가 정확히 표시되는지 점검하세요.

8. PDF 변환 후 한글 글꼴이 깨지는 이유

HWP/HWPX를 PDF로 저장했을 때 가장 흔한 문제 중 하나는 글꼴 대체입니다. 원본을 열 때 설치되지 않은 글꼴이 다른 글꼴로 바뀌면 글자 폭이나 줄바꿈도 달라질 수 있습니다.

한컴의 한글 2024 공식 도움말은 PDF 변환 시 OTF 글꼴이 다른 글꼴로 대체되어 표시될 수 있다고 명시합니다. 또한 PDF에 글꼴을 포함할 수 있는지는 해당 글꼴 제공업체의 포함 허가에 따라 달라집니다.

글꼴 깨짐 해결 순서

  1. 변환 전 원본 한/글 화면에서 글꼴부터 확인합니다.
  2. 원본 작성자가 사용한 글꼴이 설치돼 있는지 확인합니다.
  3. 변환 시 특정 OTF 글꼴만 달라지는지 점검합니다.
  4. 글꼴을 변경해야 한다면 원본 파일은 보관하고 복사본에서 수정합니다.
  5. 한/글의 PDF로 저장하기와 인쇄 방식의 결과를 비교합니다.
  6. 변환한 PDF를 다른 PDF 뷰어에서 열어 글자 누락·줄바꿈·특수문자를 확인합니다.
  7. 제출용이라면 실제 프린터 출력에서도 읽을 수 있는지 확인합니다.

중요: 단순히 PDF로 저장한다고 원본 글꼴을 반드시 100% 보존하는 것은 아닙니다. 특히 OTF 대체와 글꼴 포함 권한 문제는 한컴이 직접 설명하는 제한입니다.

공식 출처: 한컴 — PDF 변환 시 OTF 글꼴 및 포함 제한.

9. 표가 잘리거나 PDF 페이지 수가 달라지는 문제

표가 다음 페이지로 넘어가거나, 한 페이지짜리 서식이 두 장으로 나뉘는 문제는 용지 크기·여백·글꼴·변환 방식을 나누어 확인해야 합니다.

유형별 원인

증상우선 확인

실제 해결 절차

  1. 원본 한/글에서 편집 용지(F7 등) 설정을 확인합니다.
  2. A4·가로/세로·여백이 제출기관 요구사항과 같은지 확인합니다.
  3. 원본에서 인쇄 미리보기를 엽니다.
  4. 미리보기에서 이미 잘렸다면 원본 문서 레이아웃부터 수정합니다.
  5. 미리보기에서는 정상인데 PDF에서만 잘리면 PDF 저장 설정을 확인합니다.
  6. 사용자 정의 용지라면 제공되는 표준 용지 크기로 조정 가능한지 판단합니다.
  7. PDF를 다시 저장하고 첫 장·마지막 장·표가 있는 장을 중심으로 비교합니다.

예: 표가 1cm 잘렸다고 PDF 편집기로 표 이미지를 억지로 늘이기보다, 한/글 원본의 표 너비·편집 용지와 글꼴을 확인하는 편이 정확합니다.

11. 'HWPX 파일을 열 수 없습니다' 오류가 뜰 때

먼저 확장자가 맞는지 확인합니다.

  • .hwp와 .hwpx는 서로 다른 파일 형식입니다.
  • 오래된 한/글이나 호환 프로그램은 최신 HWPX 문서의 일부 기능을 완전하게 지원하지 않을 수 있습니다.
  • 파일 자체가 손상되었거나 암호가 설정돼 있을 수도 있습니다.
  • 해당 앱이 문서의 보기만 지원하고, 인쇄·PDF 저장은 제한할 수도 있습니다.

해결 순서

  1. 파일을 다운로드할 때 크기가 0KB가 아닌지 확인합니다.
  2. 확장자만 .pdf로 바꾸지 않습니다.
  3. 지원되는 최신 한/글 또는 한컴독스 웹 한글에서 여는 것을 검토합니다.
  4. 문서가 열리면 표·그림·특수문자가 제대로 보이는지 확인합니다.
  5. 원본 작성자에게 PDF 또는 해당 버전에서 읽을 수 있는 HWP/HWPX 사본을 요청할 수 있습니다.
  6. 악성코드 경고·문서 보안 제한이 표시되면 보안 경고를 무시하지 않습니다.

한컴의 공식 설명에 따르면 HWPX는 OWPML 기반 개방형 한/글 문서입니다. 하지만 '표준 형식'이라는 말이 모든 앱에서 완전한 편집·서식 재현을 보장한다는 뜻은 아닙니다.

12. PDF로 저장했는데 파일을 못 찾는 경우

변환은 끝났는데 PDF가 어디 있는지 모르는 경우도 있습니다.

  1. 파일 → PDF로 저장하기에서 지정한 폴더 이름을 확인합니다.
  2. Windows 파일 탐색기에서 최근 파일과 문서·다운로드·바탕화면을 확인합니다.
  3. Mac에서는 Finder의 최근 항목과 저장 위치를 확인합니다.
  4. 파일 이름 검색 시 .pdf 확장자를 포함해 검색합니다.
  5. 저장창에서 실제로 PDF로 저장했는지, 원본 HWP를 다시 저장한 것인지 확인합니다.
  6. 한컴독스에서 열어 편집 중이었다면 클라우드 저장소에 저장된 파일인지 확인합니다.

한컴오피스 2024 공식 PDF 저장 도움말에는 '한컴독스에서 불러온 문서는 로컬 드라이브에 저장할 수 없고 한컴독스에 저장한다'는 주의사항이 있습니다. 따라서 특정 문서가 로컬 저장창에 보이지 않는다면 처음 연 저장 위치와 제품 경로를 확인하세요.

검수 요령: 저장된 PDF를 완전히 닫았다가 다시 열어보세요. 지금 보고 있는 화면이 원본 HWP가 아닌 실제 PDF 파일인지 확인하는 것이 중요합니다.

13. PDF에 암호를 걸어야 한다면?

PDF에 들어 있는 주민등록번호·계약금액·개인 연락처 등을 보호하기 위해 열기 암호 또는 편집·인쇄 권한 제한을 요구하는 경우가 있습니다.

한컴오피스의 PDF 저장 기능은 공식 도움말상 열기 암호 및 권한 설정을 지원합니다. 다만 서류 제출처가 암호가 걸린 PDF를 거부할 수 있으므로, 암호화하기 전에 기관 요구사항을 확인하세요.

구분할 것

기능의미유의사항
열기 암호PDF를 열 때 인증 요구암호를 잊으면 제출자도 열지 못할 수 있음
편집·인쇄 제한PDF 작업의 일부를 제한상대방의 프로그램·정책에 따라 실제 적용 방식이 다를 수 있음
파일 압축용량을 줄임보안 암호와 다름
전자서명서명 의사·인증 등의 별도 절차PDF 저장만으로 생성되지 않음

중요한 개인정보가 있는 경우에는 외부 변환 사이트를 이용하기보다 신뢰할 수 있는 로컬 앱에서 작업할 수 있는지 확인하고, 파일에 포함할 필요가 없는 개인정보는 원본에서부터 제외하는 것이 좋습니다.

14. 무료 온라인 HWP PDF 변환 사이트, 써도 될까?

민감한 서류라면 처음 보는 변환 사이트에 업로드하기 전에 다음을 확인하세요.

  • 회사의 기밀 문서, 학교 지원자의 개인정보, 주민등록번호가 들어 있는지
  • 사이트가 문서를 서버에 저장하는지, 언제 삭제하는지
  • 다운로드 링크가 외부에 공개되지 않는지
  • 원본 파일에 암호·보안 제한이 있는지
  • 사이트 약관에서 업로드한 파일의 처리·재사용·보관을 어떻게 규정하는지
  • 변환 후 글꼴·표·수식이 변경되지 않았는지

'무료 웹 변환기'가 반드시 파일을 서버에 남기지 않는다는 뜻은 아닙니다. 또한 원본에서 사용한 한/글 전용 서식·글꼴이 다른 엔진에서 동일하게 보존된다고 보장할 수도 없습니다.

가능하면 한컴오피스의 PDF 저장하기 또는 신뢰할 수 있는 앱의 PDF 인쇄를 우선 검토하세요. 온라인 변환이 불가피하다면 비공개 문서의 업로드를 허용하는지 소유 기관의 정책부터 확인하는 것이 안전합니다.

15. 제출 전 확인해야 하는 PDF 검수 8단계

변환이 성공했다는 메시지만 믿고 바로 제출하면 안 됩니다.

  1. PDF 파일이 정상적으로 열리는지 확인합니다.
  2. 전체 페이지 수가 원본과 같은지 비교합니다.
  3. 첫 페이지와 마지막 페이지를 열어봅니다.
  4. 표·도장·서명·차트·이미지가 잘리지 않았는지 봅니다.
  5. 한글 특수문자·영문·숫자가 깨지지 않았는지 확인합니다.
  6. PDF에서 텍스트를 선택·검색할 수 있는지 확인합니다. 필요한 경우 원본과 맞춰봅니다.
  7. 파일 크기·암호·파일명이 제출처 조건에 맞는지 확인합니다.
  8. 파일 업로드 후 제출처 시스템의 미리보기에서 같은 결과가 나오는지 확인합니다.

중요: HWP를 PDF로 변환했다고 모든 서류가 공식적으로 유효해지는 것은 아닙니다. 제출기관에서 회사 직인·본인 서명·전자서명·원본 출력물을 따로 요구할 수 있습니다.

제출용 권장 파일명 예시

  • 지원서_홍길동_2026.pdf
  • 재직확인서_2026-11-04.pdf
  • 제출서류_원본변환본.pdf

불필요하게 주민등록번호 전체나 계좌번호를 파일명에 넣지 마세요.

16. 자주 묻는 질문(FAQ)

Q1. HWP 파일을 PDF로 가장 쉽게 바꾸는 방법은?

한컴오피스 한/글에서 문서를 연 후 파일 → PDF로 저장하기를 선택하는 방법이 가장 직접적입니다. 별도 변환 사이트 없이 저장 범위·그림 품질 등을 설정할 수 있습니다.

Q2. HWPX도 PDF로 변환할 수 있나요?

예. HWPX를 지원하는 한/글 앱에서 정상적으로 연 뒤 PDF로 저장할 수 있습니다. HWPX와 HWP는 서로 다른 문서 형식입니다.

Q3. 한컴오피스가 없어도 Windows 11에서 무료 변환되나요?

Windows 11에는 Microsoft Print to PDF가 있지만, HWP/HWPX를 열고 인쇄할 앱은 별도 필요합니다. 운영체제의 가상 프린터 기능 자체가 HWP 파일을 해석하는 것은 아닙니다.

Q4. HWP를 PDF로 바꾸면 표가 안 깨지나요?

반드시 그렇지는 않습니다. 글꼴 대체·쪽 여백·사용자 정의 용지 크기 때문에 표·문단의 위치가 달라질 수 있습니다. 원본에서 서식을 확인하고 저장된 PDF를 검수해야 합니다.

Q5. 한컴독스 무료 계정으로 PDF 변환할 수 있나요?

한컴독스 공식 안내에서 웹 한글의 HWP/HWPX 편집 지원은 확인됩니다. 다만 PDF 다운로드·내보내기가 무료 계정에 제공되는지는 현재 UI와 요금제에서 확인해야 합니다. 무료 버전 데스크톱 앱에는 뷰어만 제공된다는 제한도 있습니다.

Q6. 맥북에서도 한글 파일 PDF 저장이 되나요?

맥에서 이용 가능한 Mac용 한/글 프로그램이 있다면 공식 도움말대로 파일 → PDF로 저장하기 기능을 사용할 수 있습니다.

Q7. PDF로 저장한 뒤 글꼴이 다른 글꼴로 바뀌는 이유는?

한컴 공식 도움말은 OTF 글꼴의 PDF 변환 시 대체 표시 가능성을 명시합니다. 원본 글꼴·PDF 저장 설정·문서 레이아웃을 확인하세요.

Q8. PDF가 한 장 더 생기거나 빈 페이지가 붙는 이유는?

원본의 쪽 설정·표 끝 문단·구역 나누기·글꼴 대체 등을 먼저 확인해야 합니다. 원본 인쇄 미리보기와 PDF를 비교하면 어느 단계에서 달라졌는지 파악하는 데 도움이 됩니다.

Q9. 여러 장 중 1페이지만 PDF로 저장할 수 있나요?

예. 한컴오피스의 PDF 저장 설정에서는 현재 쪽·일부분·문서 전체 등의 범위를 선택할 수 있습니다.

Q10. PDF로 저장한 뒤 내용을 수정할 수 있나요?

PDF도 일부 도구에서 편집 가능하지만, HWP 원본과 편집 방식이 다릅니다. 계속 수정할 문서라면 HWP/HWPX 원본을 함께 보관하세요.

Q11. PDF 변환 사이트에 주민등록번호가 적힌 서류를 올려도 되나요?

사이트의 파일 보관·삭제 정책과 개인정보 처리를 확인하기 전에는 업로드를 피하는 편이 안전합니다. 기관의 보안 규정도 확인하세요.

Q12. 한/글에서 PDF 메뉴가 안 보이면 어떻게 하나요?

한컴오피스의 제품 버전·테마·설치 상태를 확인하고, 'PDF로 저장하기' 또는 'PDF 인쇄' 관련 메뉴를 찾으세요. 지원되는 경우 인쇄 메뉴의 Microsoft Print to PDF를 이용할 수도 있습니다.

17. 한눈에 보는 최종 체크리스트

  • ☐ 파일 확장자가 HWP인지 HWPX인지 확인했다.
  • ☐ 해당 파일을 정상 표시하는 호환 앱이 있다.
  • ☐ PDF로 바꿀 때 원본 파일을 보관했다.
  • ☐ 한컴오피스의 파일 → PDF로 저장하기를 먼저 확인했다.
  • ☐ 앱에서 직접 저장이 어려울 때 Microsoft Print to PDF 등 지원 인쇄 기능을 확인했다.
  • ☐ PDF 저장 범위를 문서 전체·현재 쪽·일부분 중 올바르게 선택했다.
  • ☐ OTF 글꼴·표·용지 크기가 변환 후 달라지지 않았는지 확인했다.
  • ☐ 사진·그래프의 품질과 제출처 파일 용량 제한을 확인했다.
  • ☐ PDF를 다시 열어 페이지·서명·이미지·글자를 검증했다.
  • ☐ 개인정보가 포함된 문서를 출처 불명의 웹서비스에 업로드하지 않았다.
  • ☐ 제출처가 PDF 외에 전자서명·직인·별도 서류를 요구하지 않는지 확인했다.

결론: HWP/HWPX를 PDF로 바꾸는 가장 정확한 출발점은 원본을 만든 한/글 프로그램에서 직접 PDF로 저장하는 것입니다. Windows의 무료 PDF 인쇄 기능은 보완책이지만 HWP 파일을 여는 소프트웨어까지 제공하지는 않습니다. 글꼴 대체·쪽 설정·그림 품질을 점검한 뒤 실제 PDF 결과물을 다시 열어 확인해야 서류 반려를 줄일 수 있습니다.
