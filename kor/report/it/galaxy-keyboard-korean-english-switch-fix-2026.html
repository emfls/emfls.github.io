갤럭시 스마트폰에서 갑자기 한글이 입력되지 않고 영어만 나오거나, 키보드의 한/영·지구본 버튼이 사라지거나, 스페이스바를 밀어도 입력 언어가 바뀌지 않는 문제가 발생할 수 있습니다. 이런 증상은 키보드 하드웨어 고장보다 입력 언어 설정, 언어 변경 방식, 기본 키보드 변경, Gboard와 삼성 키보드의 차이 때문인 경우가 있습니다.

가장 중요한 것은 현재 사용 중인 키보드가 삼성 키보드인지 Gboard인지 확인하는 일입니다. 두 앱의 메뉴와 언어 전환 방법은 다릅니다. 한영 전환이 안 된다는 이유로 모든 설정을 초기화하거나 키보드 데이터를 바로 지울 필요는 없습니다.

이 글은 2026년 11월 기준 삼성전자 및 Google 공식 안내를 바탕으로 한글 입력 복구, 언어 버튼 표시, 스페이스바 스와이프, 쿼티·천지인 자판, 기본 키보드 변경, Gboard 언어 전환, 키보드가 아예 나타나지 않는 경우를 순서대로 설명합니다. 실제 메뉴 명칭은 One UI·Android 버전 및 기기 모델에 따라 달라질 수 있습니다.

2. 먼저 삼성 키보드인지 Gboard인지 확인하는 법

갤럭시에서 가장 먼저 확인할 것은 현재 기본 키보드입니다.

  1. 설정 앱을 엽니다.
  2. 일반 또는 일반 관리로 이동합니다.
  3. 키보드 목록 및 기본을 찾아 누릅니다.
  4. 기본 키보드를 확인합니다.
  5. 삼성 키보드가 선택되어 있다면 삼성 키보드 절차로, Gboard라면 Google Gboard 절차로 진행합니다.

기종에 따라 설정에서 '삼성 키보드', '기본 키보드'를 검색하면 메뉴를 더 빨리 찾을 수 있습니다.

왜 이 순서가 중요할까요?

같은 갤럭시에서도 삼성 키보드와 Gboard는 언어 변경 방법이 다릅니다. 삼성 키보드에서는 '언어 및 키보드 형식'을 사용하고, Gboard에서는 '언어' 및 '환경설정'에서 입력 언어·지구본 표시를 관리합니다.

기기 전체 언어를 바꾸지 마세요. 영어 키보드만 나온다는 이유로 갤럭시 전체 시스템 언어를 영어 또는 한국어로 변경할 필요는 없습니다. 키보드 앱에서 사용하는 입력 언어는 기기의 화면 표시 언어와 별도로 관리할 수 있습니다.

공식 출처: 삼성전자 — 기본 키보드 변경, Google — 입력 언어와 기기 언어는 별개

3. 삼성 키보드: 한글이 안 나오면 한국어 입력 언어부터 켜기

삼성전자는 Galaxy 키보드에서 입력 언어를 관리하는 공식 경로를 안내합니다.

  1. 설정 → 일반(일반 관리)로 이동합니다.
  2. 삼성 키보드 설정을 엽니다.
  3. 언어 및 키보드 형식을 누릅니다.
  4. 입력 언어 관리를 선택합니다.
  5. 목록에서 한국어가 켜져 있는지 확인합니다.
  6. 영어도 사용한다면 English (US) 또는 원하는 영어 입력 언어를 활성화합니다.
  7. 입력창으로 돌아가 언어 전환 버튼 또는 스페이스바를 이용합니다.

원하는 언어가 설치되어 있지 않다면 다운로드 아이콘으로 언어 데이터를 내려받아 활성화할 수 있습니다. 다운로드가 필요할 경우 인터넷 연결 상태도 확인해야 합니다.

중요: 언어가 한 가지밖에 활성화되지 않았다면 다른 언어로 전환하는 기능이 필요하지 않아 언어 전환 버튼이 예상대로 보이지 않을 수 있습니다. 따라서 버튼 위치부터 찾는 것보다 한국어와 영어가 모두 활성화돼 있는지를 먼저 확인하는 것이 합리적입니다.

공식 출처: 삼성전자 — Manage input languages

4. 한영 버튼이 사라졌을 때: 언어 변경 방법 확인

삼성 키보드에서는 언어 버튼을 눌러 전환하거나, 스페이스바를 좌우로 밀어 전환하는 방식이 지원됩니다. 삼성전자 지원 페이지는 언어 아이콘으로 전환하는 절차를 설명하고, 삼성 공식 제품 안내에는 스페이스바 밀기 방식도 안내되어 있습니다.

삼성 키보드에서 변경 방식 찾기

  1. 메시지·메모 등 텍스트 입력이 가능한 앱을 엽니다.
  2. 키보드의 톱니바퀴(설정)를 누릅니다. 보이지 않으면 설정 → 일반 관리 → 삼성 키보드 설정으로 이동합니다.
  3. 언어 및 키보드 형식을 엽니다.
  4. 언어 변경 방법 또는 비슷한 이름의 메뉴를 찾습니다.
  5. 지원되는 옵션 중 언어 버튼, 스페이스 키 살짝 밀기, 언어 버튼 및 스페이스바 밀기 등의 방식을 선택합니다.
  6. 메모 앱에서 한글과 영어가 모두 전환되는지 확인합니다.

모든 기기에서 세 옵션이 똑같이 보이는 것은 아닙니다. 기기·One UI·삼성 키보드 버전에 따라 제공 옵션과 명칭이 다를 수 있습니다.

빠른 판단: 한/영 버튼이 없어졌는데 스페이스바 양옆에 좌우 전환 표시가 있다면 스페이스바 스와이프 방식이 선택된 상태일 가능성이 있습니다.

공식 출처: 삼성전자 — 언어 변경 방법, 삼성 키보드 담당자 안내

5. 스페이스바로 한글·영어 전환이 안 될 때

스페이스바를 좌우로 밀어도 영어 그대로라면 다음을 차례로 확인합니다.

  • 한국어와 영어가 모두 활성화되어 있나요?
  • 삼성 키보드에서 언어 변경 방법을 스페이스바 밀기로 설정했나요?
  • 실제 사용 중인 키보드가 삼성 키보드인가요?
  • 입력창에서 문자 키보드 대신 숫자 전용 키패드가 열려 있지는 않나요?
  • 스페이스바를 단순히 누르는 동작과 좌우로 미는 동작을 혼동하지 않았나요?

1분 테스트

  1. 삼성 노트 또는 메시지 앱에서 새 메모나 메시지를 엽니다.
  2. 일반 텍스트 입력창을 선택합니다.
  3. 한국어·영어 두 언어를 활성화했는지 확인합니다.
  4. 스페이스바를 좌우로 살짝 밀어 봅니다.
  5. 언어가 바뀌지 않으면 삼성 키보드 설정에서 언어 변경 방법을 다시 확인합니다.

주의: 외부 Bluetooth 키보드나 삼성 DeX 환경에서는 화면 키보드와 다른 입력 전환 방식이 적용될 수 있습니다. 이 글의 기본 해결 절차는 휴대전화 화면의 삼성 키보드를 기준으로 합니다.

공식 출처: 삼성전자 — Galaxy 키보드 언어 설정과 스페이스바

6. 삼성 키보드에서 한글 쿼티·천지인 자판이 바뀌었을 때

한글은 정상으로 입력되지만 자판 배열이 갑자기 달라졌다면 입력 언어 문제가 아니라 키보드 형식(레이아웃) 설정일 수 있습니다.

  1. 설정 → 일반 관리 → 삼성 키보드 설정으로 이동합니다.
  2. 언어 및 키보드 형식을 엽니다.
  3. 한국어를 선택합니다.
  4. 해당 기기에서 제공하는 쿼티·천지인·천지인 플러스 등 원하는 입력 형식을 선택합니다.
  5. 입력창에서 실제 배열이 바뀌었는지 확인합니다.

같은 메뉴에서 영어 키보드 형식도 별도로 설정할 수 있습니다.

헷갈리는 두 문제를 구분하세요. 영어만 입력되면 입력 언어 활성화·전환 방법부터 확인하고, 한글은 입력되지만 키 배열이 낯설면 한국어 키보드 형식부터 확인하는 것이 빠릅니다.

공식 출처: 삼성전자 — Galaxy 키보드 언어별 입력 형식 변경

7. Gboard에서 한영 전환이 안 될 때: 한국어·영어 다시 확인

기본 키보드가 Gboard라면 삼성 키보드의 메뉴를 따라가도 해결되지 않을 수 있습니다.

Gboard 입력 언어 확인

  1. 메모나 메시지 앱에서 텍스트 입력창을 누릅니다.
  2. Gboard가 열리면 설정(톱니바퀴)을 엽니다.
  3. 언어 → 키보드 추가를 누릅니다.
  4. 한국어를 선택합니다.
  5. 원하는 자판 배열을 선택하고 완료를 누릅니다.
  6. 영어도 사용하는 경우 같은 방식으로 추가하거나 활성화합니다.
  7. 키보드에서 스페이스바를 길게 누르거나 언어 전환 키를 사용해 언어를 바꿉니다.

Google은 Gboard의 입력 언어를 바꾸더라도 휴대전화 시스템 언어에는 영향이 없다고 안내합니다.

Gboard 지구본 언어 전환 키가 없다면

  1. Gboard 설정 → 환경설정을 엽니다.
  2. 언어 전환 키 표시를 확인합니다.
  3. 사용 가능한 경우 켭니다.
  4. 이 옵션이 비활성화되어 있다면 Google은 그림 이모티콘 전환 키 표시를 먼저 끄도록 안내합니다.

중요: 삼성 키보드의 지구본 버튼 설정과 Gboard의 언어 전환 키 표시는 서로 다릅니다. 현재 사용 중인 앱을 확인한 뒤 적용해야 합니다.

공식 출처: Google — 다른 언어로 입력하기, Google — Gboard 설정하기

8. 갑자기 키보드 모양이 바뀌고 한영 버튼이 없어졌다면

키보드 앱 자체가 바뀌면 언어 버튼의 위치·입력 방법·예측 입력 동작이 달라질 수 있습니다.

확인 경로: 설정 → 일반 관리 → 키보드 목록 및 기본 → 기본 키보드

  • 삼성 키보드를 쓰던 중 Gboard로 바뀌었다면 기본 키보드를 삼성 키보드로 다시 선택해 비교합니다.
  • Gboard를 계속 쓸 계획이라면 Gboard의 언어 설정을 확인합니다.
  • 새 키보드 앱을 설치한 뒤 문제가 생겼다면 어떤 키보드가 기본으로 적용됐는지 확인합니다.

삼성전자는 Galaxy에서 키보드 목록 및 기본 메뉴를 통해 기본 입력 앱을 변경할 수 있다고 안내합니다.

개인정보 유의사항: 키보드 앱은 민감한 입력과 관련이 있으므로 출처가 불명확한 키보드 앱이나 검증되지 않은 APK를 설치해 문제를 해결하려 하지 마세요.

9. 문자에서는 되는데 특정 앱에서만 한글 입력이 안 될 때

한글이 모든 앱에서 안 되는 상황과 특정 입력창에서만 안 되는 상황은 구별해야 합니다.

이렇게 비교해 보세요

  1. 삼성 노트 또는 메시지 앱에서 일반 텍스트 입력창을 엽니다.
  2. 한글과 영어가 바뀌는지 확인합니다.
  3. 문제가 있던 앱으로 돌아가 같은 테스트를 합니다.
  4. 은행·인증 앱의 비밀번호 또는 숫자 입력창이라면 숫자·보안 전용 키패드인지 확인합니다.
  5. 특정 앱에서만 발생하면 해당 앱의 업데이트와 지원 안내를 확인합니다.

중요: 숫자만 받는 입력창에서는 한영 전환 버튼이 표시되지 않는 것이 정상일 수 있습니다. 이때 삼성 키보드의 전체 설정을 초기화하면 원인을 해결하지 못하고 오히려 기존 사용자 설정을 잃을 수 있습니다.

특정 앱에서만 재현되는 문제는 키보드 자체가 아니라 해당 앱의 입력 필드 제한 때문일 수 있습니다. 여러 앱의 일반 텍스트 입력창을 비교하면 이를 빠르게 확인할 수 있습니다.

10. 키보드가 아예 나타나지 않거나 입력이 멈춘다면

한영 전환 문제를 넘어 키보드가 뜨지 않거나 터치가 반응하지 않는 경우, 우선 데이터 삭제가 없는 방법부터 시도합니다.

  1. 다른 앱의 일반 입력창에서도 같은 문제가 발생하는지 확인합니다.
  2. 오류가 발생한 앱을 닫고 다시 엽니다.
  3. 갤럭시를 정상적으로 재시동합니다.
  4. 설정 → 소프트웨어 업데이트에서 설치 가능한 업데이트가 있는지 확인합니다.
  5. 기본 키보드가 삼성 키보드인지 Gboard인지 확인합니다.
  6. Gboard에서만 문제라면 Google 공식 Gboard 문제 해결 절차를 확인합니다.

Gboard 오류에서 캐시 지우기는 언제 할까요?

Google은 Gboard 앱이 지속적으로 작동하지 않을 때 설정 → 앱 → Gboard → 저장공간 → 캐시 삭제를 안내합니다.

하지만 '데이터 삭제'는 Gboard 설정을 기본 상태로 되돌릴 수 있습니다. 캐시 삭제와 데이터 삭제는 영향 범위가 다르므로, 단순히 언어 전환이 안 되는 문제에 먼저 데이터 삭제를 적용하지 마세요.

Samsung Keyboard의 설정 초기화도 사용자별 자판·사전·환경설정에 영향을 줄 수 있으므로 기본 문제 해결 전에는 권장하지 않습니다.

11. 삼성 키보드 설정 초기화는 마지막에 검토하세요

한영 전환이 안 된다는 이유만으로 모든 키보드 설정을 초기화하는 것은 효율적이지 않습니다. 특히 사용자가 입력 언어와 자판 배열을 따로 설정해 둔 경우에는 복구가 번거로울 수 있습니다.

초기화 전에 다음을 확인하세요.

  • 삼성 키보드와 Gboard 중 실제 기본 키보드가 무엇인지
  • 한국어와 영어가 모두 활성화되어 있는지
  • 언어 버튼 방식인지, 스페이스바 밀기 방식인지
  • 원하는 한글 자판이 쿼티인지 천지인인지
  • 특정 앱만 문제인지, 모든 일반 입력창에서 문제인지
  • 키보드 자체 업데이트 또는 기기 소프트웨어 업데이트가 있는지

초기화가 꼭 필요한 상황이라면 기기 설정에서 제공하는 삼성 키보드 설정 초기화의 적용 범위를 확인하고, 현재 설정을 기록한 뒤 진행하세요.

주의: 키보드 캐시 삭제, 키보드 앱 데이터 삭제, 스마트폰 전체 공장 초기화는 서로 다른 작업입니다. 가장 영향이 큰 전체 기기 초기화를 한영 전환 오류 해결을 위해 먼저 진행해서는 안 됩니다.

지구본·한영 버튼이 없는 경우

다른 앱에서도 재현되는지 비교하고 재시동·업데이트·기본 키보드 상태를 확인합니다.

계속 문제가 발생하는 경우

모델명·One UI 버전·키보드 앱 이름·문제가 재현되는 앱을 기록해 삼성전자서비스 또는 해당 키보드 개발사의 지원 채널에 문의하는 것이 적절합니다.

14. 자주 묻는 질문

Q1. 갤럭시에서 영어만 나오고 한글 입력이 안 됩니다.

설정 → 일반 관리 → 삼성 키보드 설정 → 언어 및 키보드 형식 → 입력 언어 관리에서 한국어가 활성화되어 있는지 확인하세요. 기본 키보드가 Gboard라면 Gboard의 언어 메뉴를 확인해야 합니다.

Q2. 키보드에서 한영 전환 버튼이 사라졌어요.

삼성 키보드에서 언어 변경 방법이 스페이스바 밀기로 바뀌었을 수 있습니다. 언어 및 키보드 형식에서 전환 방식을 확인하고, 한국어·영어가 모두 활성화되어 있는지도 확인하세요.

Q3. 스페이스바를 밀어도 한글·영어 전환이 안 돼요.

삼성 키보드 설정의 언어 변경 방법에서 스페이스바 밀기를 선택했는지 확인하세요. Gboard에서는 스페이스바를 길게 눌러 언어를 전환하는 방식이 안내되어 있습니다.

Q4. Gboard에 지구본 아이콘이 안 보입니다.

Gboard 설정 → 환경설정 → 언어 전환 키 표시를 확인하세요. 해당 옵션이 회색이라면 Google은 그림 이모티콘 전환 키 표시를 끄도록 안내합니다.

Q5. 갤럭시 전체 언어를 한국어로 바꿔야 한글을 쓸 수 있나요?

아닙니다. 삼성 키보드와 Gboard는 모두 입력 언어를 별도로 설정할 수 있습니다. 스마트폰의 시스템 표시 언어와 키보드 입력 언어는 다를 수 있습니다.

Q6. 천지인 자판이 갑자기 쿼티로 바뀌었습니다.

한글 입력 언어를 다시 설치하기보다는 삼성 키보드 설정 → 언어 및 키보드 형식 → 한국어에서 원하는 자판 배열을 선택하세요.

Q7. 삼성 키보드를 쓰다가 갑자기 Gboard로 바뀌었어요.

설정 → 일반 관리 → 키보드 목록 및 기본 → 기본 키보드에서 현재 키보드를 확인하고 삼성 키보드를 선택해 보세요.

Q8. 카카오톡에서는 한글이 되는데 특정 사이트에서만 안 됩니다.

숫자·비밀번호·인증 전용 입력창인지 확인하세요. 다른 앱의 일반 텍스트 입력창에서 한글이 된다면, 해당 앱 또는 웹 입력창의 제한일 가능성이 있습니다.

Q9. Gboard 캐시를 지워도 되나요?

Gboard가 계속 오류를 일으킬 때 Google 공식 지원 문서의 캐시 삭제 절차를 검토할 수 있습니다. 다만 데이터 삭제는 사용자 설정을 초기화할 수 있으므로 먼저 실행하지 마세요.

Q10. 삼성 키보드 설정 초기화를 하면 모든 문제가 해결되나요?

보장되지 않습니다. 우선 언어 활성화·언어 변경 방식·기본 키보드·특정 앱 문제를 확인하고, 초기화는 마지막에 영향 범위를 확인한 뒤 검토하세요.

15. 최종 체크리스트

  • ☐ 현재 기본 키보드가 삼성 키보드인지 Gboard인지 확인했다.
  • ☐ 한국어와 영어가 모두 입력 언어로 활성화되어 있다.
  • ☐ 삼성 키보드의 언어 변경 방법을 확인했다.
  • ☐ 스페이스바 밀기와 지구본·언어 버튼 중 원하는 방식을 선택했다.
  • ☐ Gboard라면 언어 전환 키 표시와 그림 이모티콘 키 설정을 확인했다.
  • ☐ 원하는 한국어 자판이 쿼티·천지인 중 무엇인지 확인했다.
  • ☐ 일반 메모 입력창과 문제가 발생한 앱의 입력창을 비교했다.
  • ☐ 다른 키보드 앱이 기본으로 바뀐 것은 아닌지 확인했다.
  • ☐ 키보드가 아예 안 뜨는 경우 재시동·업데이트를 확인했다.
  • ☐ 앱 데이터 삭제나 전체 공장 초기화는 마지막 단계로 남겼다.

결론: 갤럭시의 한영 전환 오류는 삼성 키보드와 Gboard의 차이, 한국어 입력 언어 활성화, 언어 변경 방식 설정만 확인해도 원인을 상당 부분 좁힐 수 있습니다. 특히 한영 버튼이 사라졌다면 키보드 앱과 언어 전환 방식부터 확인하고, 초기화는 신중하게 검토하세요.
