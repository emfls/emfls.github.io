아이폰 데이터가 생각보다 빨리 소진되는데 어느 앱에서 사용했는지 모르겠다면 설정 → 셀룰러부터 확인하세요. 앱마다 셀룰러 데이터 사용량이 표시되고, 필요 없는 앱은 모바일 데이터만 따로 차단할 수 있습니다. 와이파이에 연결했는데도 셀룰러 데이터가 쓰였다면 예전의 'Wi-Fi 지원' 또는 최신 메뉴의 '연결 지원'을 살펴볼 필요가 있습니다.

이 글에서는 2026년 기준 Apple 공식 안내를 바탕으로 앱별 데이터 사용량 조회, 통계 재설정, 통신사 사용량과 다른 이유, 5G 저데이터 모드, 연결 지원, 듀얼 SIM을 한 번에 정리합니다. iOS 버전과 이동통신사에 따라 일부 메뉴의 명칭과 위치가 달라질 수 있습니다.

2. 아이폰 앱별 데이터 사용량 확인 방법

  1. 아이폰에서 설정 앱을 엽니다.
  2. 셀룰러를 누릅니다. 지역과 소프트웨어에 따라 '모바일 데이터'라는 이름을 사용할 수 있습니다.
  3. 아래쪽으로 스크롤해 앱 목록을 찾습니다.
  4. 각 앱 이름 아래에 표시된 셀룰러 데이터 사용량을 확인합니다.
  5. 필요하다면 목록을 더 펼치는 모두 보기 같은 항목을 선택합니다.
  6. 어떤 앱에서 사용량이 큰지 먼저 비교합니다.

Apple의 공식 설명에 따르면 이 화면에는 개별 앱이 사용한 셀룰러 데이터 통계가 나타납니다. 동영상 시청 앱, 웹 브라우저, 지도, 메신저 등이 상위에 있을 수 있지만 사용자의 실제 사용 습관에 따라 다릅니다.

여기서 보이는 숫자는 셀룰러 네트워크 사용량을 확인하는 용도입니다. 동일한 앱에서 와이파이로 사용한 데이터까지 합산한 값이라고 생각하면 안 됩니다.

3. 특정 앱의 셀룰러 데이터만 끄는 법

특정 앱이 모바일 데이터를 너무 많이 사용한다고 판단되면 앱을 지우는 대신 셀룰러 데이터 접근만 비활성화할 수 있습니다.

  1. 설정 → 셀룰러로 들어갑니다.
  2. 아래로 스크롤해 제한할 앱을 찾습니다.
  3. 해당 앱 옆의 셀룰러 데이터 스위치를 끕니다.
  4. 와이파이에 연결한 상태에서 앱이 정상 작동하는지 확인합니다.

Apple은 이 설정을 끈 앱이 셀룰러 데이터 대신 Wi-Fi만 사용하도록 제한된다고 안내합니다. 그러므로 외출 중 와이파이가 없으면 해당 앱에서 인터넷이 필요한 기능이 동작하지 않을 수 있습니다.

예를 들어 자동 동기화가 꼭 필요하지 않은 앱, 와이파이에서만 이용하려는 동영상 앱 등을 선택적으로 제한하면 관리에 도움이 됩니다. 다만 업무 연락·보안 인증·길찾기처럼 이동 중에도 연결이 필요한 앱은 무턱대고 끄지 않는 것이 좋습니다.

앱별 셀룰러 데이터 끄기와 전체 셀룰러 데이터 끄기는 다릅니다. 전체 데이터를 끄면 다른 앱과 서비스도 와이파이 연결이 없을 때 인터넷 사용에 제한을 받습니다.

4. '현재 기간'과 통신사 이번 달 사용량이 다른 이유

아이폰의 셀룰러 설정에서 보이는 데이터 사용량은 아이폰이 집계한 통계입니다. 반면 통신사 앱에 표시되는 사용량은 해당 통신사의 요금제·청구 기준에 따라 계산합니다.

따라서 아래처럼 다른 숫자를 볼 수 있습니다.

  • 아이폰은 통계를 재설정하지 않아 과거 기간의 사용량이 누적돼 있을 수 있습니다.
  • 사용자가 통계를 중간에 재설정했다면 아이폰 통계는 실제 청구 주기 전체보다 적은 기간만 포함할 수 있습니다.
  • 듀얼 SIM 사용 환경에서는 선택한 데이터 회선의 통계를 확인해야 합니다.
  • 통신사의 집계 시점과 단말기 통계의 반영 시점이 다를 수 있습니다.

이번 달 데이터 초과 여부나 추가 요금이 궁금하다면 통신사의 공식 앱·웹사이트에 표시된 사용량을 우선 확인하세요. Apple도 가장 정확한 현재 셀룰러 데이터 사용량에 대해서는 이동통신사에 문의하도록 안내합니다.

예시: 숫자가 왜 다를까?

아이폰이 60GB를 보여 주고 통신사 앱이 이번 달 8GB를 보여 준다고 가정해 보겠습니다. 아이폰의 사용량 통계가 몇 달간 재설정되지 않았을 경우 두 숫자는 서로 다른 측정 기간을 나타낼 수 있습니다.

이때 통계 재설정 버튼을 누른다고 통신사의 8GB가 사라지거나 데이터 제공량이 다시 충전되는 것은 아닙니다. 재설정 대상은 아이폰의 내부 통계입니다.

5. 데이터 사용량 통계 재설정: 무엇이 초기화되나?

아이폰에서 일정 기간의 셀룰러 데이터 사용량을 새로 측정하고 싶을 때 사용할 수 있는 기능입니다.

  1. 설정 → 셀룰러로 이동합니다.
  2. 사용량 통계 화면 아래쪽을 확인합니다.
  3. 통계 재설정을 누릅니다.
  4. 안내가 나타나면 확인합니다.
  5. 이후부터 누적되는 사용량을 다시 기록합니다.

Apple의 공식 안내에도 셀룰러 설정에서 통계 재설정을 사용하도록 명시돼 있습니다.

통계 재설정은 다음과 구분해야 합니다.

주의: '통계 재설정'과 '네트워크 설정 재설정'은 이름이 비슷하지만 전혀 다른 기능입니다. 데이터 사용량을 확인하려고 Wi-Fi 비밀번호나 네트워크 설정을 지울 필요는 없습니다.

6. 매달 데이터 사용량을 비교하려면 이렇게 기록하세요

아이폰의 통계 화면을 매월 활용하려면 비교 시작점과 종료 시점을 명확하게 기록하는 것이 중요합니다.

예를 들어 통신사 데이터 제공 기간이 매월 1일부터 말일까지라면 다음과 같이 관리할 수 있습니다.

  1. 월초에 통신사 앱에서 데이터 제공량과 청구 기간을 확인합니다.
  2. 아이폰 셀룰러 설정에서 통계를 재설정할지 결정합니다.
  3. 재설정했다면 날짜를 메모해 둡니다.
  4. 중간에 앱별 사용량을 확인해 갑자기 증가한 앱이 있는지 살펴봅니다.
  5. 월말에는 통신사 공식 집계와 아이폰 통계를 동일 기간 기준으로 가능한 만큼 비교합니다.

다만 통신사의 청구 기간은 가입 조건에 따라 다를 수 있습니다. 모든 요금제가 반드시 매월 1일에 초기화되는 것은 아닙니다.

또한 아이폰의 사용량 통계를 수동으로 재설정할 수 있다는 사실과 매달 자동으로 정확히 초기화된다는 주장은 다릅니다. 통계가 언제부터 누적되었는지 확인한 뒤 비교하세요.

7. 와이파이 켰는데 데이터가 빠지는 이유: '연결 지원'

이 부분이 특히 헷갈리기 쉽습니다.

예전 iOS 관련 안내에서는 Wi-Fi 지원(Wi-Fi Assist)이란 용어가 사용됐습니다. Apple의 최근 공식 지원 문서에서는 '연결 지원'이라는 기능이 이를 대체한다고 설명합니다.

연결 지원은 와이파이의 연결 상태가 불안정하거나 인터넷에 접근하지 못할 때 셀룰러 데이터를 함께 사용하여 연결을 유지하는 역할을 합니다.

연결 지원 끄기

  1. 아이폰에서 설정 → Wi-Fi를 엽니다.
  2. Wi-Fi가 켜져 있는지 확인합니다.
  3. 아래로 스크롤하여 연결 지원을 찾습니다.
  4. 셀룰러 데이터 사용을 줄이고 싶다면 해당 기능을 끄는 것을 고려합니다.

Apple은 소프트웨어 업데이트 전 Wi-Fi 지원이 켜져 있으면 연결 지원도 기본적으로 활성화될 수 있다고 설명합니다.

구버전 iOS를 사용하는 경우 메뉴 위치나 기능 명칭이 다를 수 있으므로 셀룰러 설정의 Wi-Fi 지원도 확인해 보세요. 두 명칭을 무조건 다른 데이터 절약 기능으로 생각할 필요는 없습니다.

연결 지원이 항상 동작하는 것은 아닙니다. Apple 공식 문서에 따르면 국제 로밍 중이거나 셀룰러 저데이터 모드가 활성화된 경우 등 특정 상황에서는 사용되지 않습니다. 따라서 와이파이에서 데이터가 사용된 원인을 연결 지원 하나로 단정해서도 안 됩니다.

8. 아이폰 데이터 절약: 저데이터 모드 설정하기

앱별 셀룰러 데이터 차단이 너무 번거롭다면 저데이터 모드를 활용할 수 있습니다. Apple은 이 모드가 네트워크 사용량을 줄이기 위해 백그라운드 작업을 제한한다고 설명합니다.

5G 환경에서 설정하기

설정 → 셀룰러 → 셀룰러 데이터 옵션 → 데이터 모드 → 저데이터 모드

LTE/4G 환경에서 설정하기

일부 환경에서는 설정 → 셀룰러 → 셀룰러 데이터 옵션 → 저데이터 모드로 표시됩니다.

와이파이에도 저데이터 모드 적용하기

설정 → Wi-Fi → 현재 연결된 네트워크 옆 정보(i) → 저데이터 모드

같은 이름의 기능이어도 셀룰러와 Wi-Fi 각각에 적용할 수 있다는 점이 중요합니다.

저데이터 모드에서 달라질 수 있는 항목은 다음과 같습니다.

  • 백그라운드 앱 새로 고침 제한
  • 자동 다운로드와 업데이트 제한
  • 스트리밍 품질 저하
  • iCloud 사진 등 일부 동기화 일시 정지
  • 자동 백업 및 기타 백그라운드 작업 제한

단, 모든 셀룰러 데이터 사용을 완전히 차단하는 기능은 아닙니다. 영상 스트리밍이나 파일 다운로드를 사용자가 직접 시작하면 데이터가 계속 사용될 수 있습니다.

중요: iCloud 사진이나 백업이 늦어지는 상황에서는 저데이터 모드가 원인일 수 있습니다. 무조건 켜 두기보다 데이터 절약과 필요한 동기화 작업 사이에서 선택하세요.

9. '5G에서 데이터 더 허용'은 무엇이 다른가?

아이폰의 셀룰러 데이터 옵션에서는 5G 환경에서 '5G에서 데이터 더 허용', 표준, 저데이터 모드 중에서 데이터 모드를 선택할 수 있습니다. 다만 모델과 회선에 따라 지원 항목이 달라집니다.

데이터 모드특징권장 상황
5G에서 데이터 더 허용고품질 FaceTime·고해상도 콘텐츠·일부 업데이트 등에 더 많은 데이터 허용데이터 제공량과 연결 조건이 충분할 때
표준일반적인 자동 업데이트·백그라운드 동작 지원별도 절약이 필요 없는 일상 사용
저데이터 모드자동 업데이트·백그라운드 작업 제한데이터 제공량이 부족하거나 절약이 필요할 때

Apple은 '5G에서 데이터 더 허용'이 일부 상황에서 더 많은 셀룰러 데이터를 사용할 수 있다고 안내합니다. 단순히 5G가 켜져 있다는 이유만으로 반드시 과도한 데이터가 사용된다고 말할 수는 없지만, 데이터 소모가 커졌다면 데이터 모드도 점검할 만합니다.

10. '시스템 서비스' 데이터가 많이 잡히는 경우

셀룰러 설정의 앱 목록에 시스템 서비스 항목이 표시될 수 있습니다. 일반 앱처럼 이름을 바로 찾을 수 없는 사용량을 확인하는 데 유용합니다.

설정 → 셀룰러 → 시스템 서비스

Apple은 이 화면에서 개별 시스템 서비스 사용량을 확인할 수 있지만, 각 시스템 서비스의 셀룰러 데이터 스위치를 따로 끄는 방식은 제공하지 않는다고 설명합니다.

시스템 서비스에서 사용량이 많다고 해서 바로 악성 앱이 있다는 뜻은 아닙니다. 먼저 최근 앱 업데이트, 소프트웨어 설정, 백업·동기화 환경, 통계 누적 기간을 확인하고 실제 통신사 집계와 비교하는 것이 좋습니다.

주의: 불확실한 인터넷 팁을 따라 필수 시스템 서비스를 강제로 제거하거나 기기를 초기화하는 방식은 권장하지 않습니다.

11. 듀얼 SIM·eSIM 사용자라면 사용 중인 데이터 회선을 확인

물리적 SIM과 eSIM을 함께 사용하거나 eSIM 두 개를 사용한다면 사용량 통계의 회선 구분이 중요합니다.

Apple은 듀얼 SIM을 지원하는 iPhone에서 현재 선택한 셀룰러 데이터 번호에 해당하는 사용량을 확인할 수 있다고 안내합니다.

  1. 설정 → 셀룰러로 이동합니다.
  2. 셀룰러 데이터에서 어떤 회선이 데이터용으로 지정되어 있는지 확인합니다.
  3. 선택한 회선의 사용량이 무엇인지 확인합니다.
  4. 통신사 앱에서도 동일한 회선의 청구 사용량을 비교합니다.

예를 들어 국내 회선과 여행용 eSIM이 함께 켜져 있다면 어느 회선으로 모바일 데이터가 연결되는지 점검해야 합니다. 해외 로밍이나 별도 eSIM을 사용 중일 때는 요금제 조건이 다르므로 설정 변경 전에 통신사 안내를 확인하세요.

12. 5분 자가진단: 왜 데이터가 빨리 없어지는지 찾기

실제 데이터가 빠르게 소모되는 원인을 구분하기 위해 다음 순서대로 점검하세요.

첫째, 통신사 사용량 확인. 통신사 공식 앱이나 웹사이트에서 이번 청구 주기의 데이터 사용량과 제공량을 확인합니다.

둘째, 아이폰 누적 기간 확인. 설정 → 셀룰러에서 앱별 사용량과 통계 재설정 여부를 확인합니다. 서로 다른 기간의 수치를 섞어 비교하지 않습니다.

셋째, 상위 앱 점검. 데이터를 많이 사용한 앱이 영상·지도·동기화 앱인지 확인합니다. 필요한 경우 해당 앱의 셀룰러 데이터만 제한합니다.

넷째, 연결 지원 확인. 와이파이 연결 중에도 셀룰러 사용이 증가했다면 최신 연결 지원 또는 구버전 Wi-Fi 지원의 상태를 확인합니다.

다섯째, 데이터 모드 확인. 저데이터 모드와 5G 데이터 모드를 확인하고, 데이터 절약이 필요한지 결정합니다.

여섯째, 듀얼 SIM 확인. 사용 중인 데이터 회선이 실제 요금제 회선과 일치하는지 확인합니다.

이 절차는 Apple 공식 설명을 토대로 독자가 직접 진단할 수 있도록 구성했습니다. 특정 아이폰을 직접 실험하거나 통신사 계정을 측정했다는 의미는 아닙니다.

13. 자주 묻는 질문

Q1. 아이폰의 현재 기간이 이번 달 데이터 사용량인가요?

항상 그렇지는 않습니다. 아이폰의 통계는 사용자가 마지막으로 재설정한 시점에 따라 누적 기간이 달라질 수 있습니다. 청구 주기별 실제 사용량은 통신사 공식 집계를 확인하세요.

Q2. 통계 재설정을 누르면 데이터가 다시 충전되나요?

아닙니다. 통계 재설정은 아이폰의 사용량 기록을 새로 시작하는 기능입니다. 통신사 요금제의 데이터 제공량이나 요금 청구 상태를 바꾸지 않습니다.

Q3. 앱의 셀룰러 데이터를 끄면 와이파이에서도 사용이 안 되나요?

Apple은 해당 앱의 셀룰러 데이터 사용을 끄면 Wi-Fi에 연결했을 때만 네트워크 데이터를 사용하게 된다고 설명합니다. 해당 앱이 오프라인에서 지원하는 기능은 별도로 작동할 수 있습니다.

Q4. 와이파이에 연결했는데 왜 데이터가 줄어들까요?

최신 버전의 연결 지원, 기존 Wi-Fi 지원이 불안정한 Wi-Fi 환경에서 셀룰러 데이터를 사용했을 수 있습니다. 다만 실제 원인은 데이터 회선 설정, 앱 사용 패턴 등과 함께 점검해야 합니다.

Q5. 연결 지원은 Wi-Fi 지원과 완전히 다른 기능인가요?

Apple의 최신 설명에 따르면 연결 지원이 기존 Wi-Fi 지원을 대체합니다. iOS 버전에 따라 기능 명칭과 메뉴 위치가 다르므로 자기 기기에서 표시되는 설정을 확인하세요.

Q6. 저데이터 모드를 켜면 데이터 사용이 0이 되나요?

아닙니다. 자동 작업과 백그라운드 네트워크 사용을 줄이는 기능입니다. 사용자가 동영상을 보거나 파일을 다운로드하면 셀룰러 데이터가 계속 소모될 수 있습니다.

Q7. 시스템 서비스 사용량을 모두 끌 수 있나요?

Apple의 공식 안내에 따르면 시스템 서비스별 사용량은 볼 수 있지만 개별 시스템 서비스의 셀룰러 데이터 사용을 직접 끄는 스위치는 제공되지 않습니다.

Q8. 5G에서 데이터 더 허용을 켜면 데이터가 더 빨리 줄어드나요?

고화질 영상과 일부 자동 업데이트 등 데이터 사용량이 높은 기능에 더 많은 데이터를 허용할 수 있습니다. 모든 사람에게 동일한 증가량이 나타나는 것은 아니지만 데이터 제공량이 적으면 표준 또는 저데이터 모드를 검토할 수 있습니다.

Q9. 듀얼 SIM인데 데이터 사용량이 다르게 표시돼요.

데이터용으로 선택된 회선과 통신사 집계의 회선이 같은지 확인하세요. 회선이 다르면 서로 다른 사용량을 비교하고 있을 수 있습니다.

Q10. 데이터 절약하려면 무조건 모든 앱의 셀룰러 데이터를 꺼야 하나요?

그럴 필요는 없습니다. 이동 중에 필요한 인증·업무·지도 앱까지 모두 끄면 불편할 수 있습니다. 사용량이 큰 앱부터 선택적으로 제한하고, 필요하면 저데이터 모드를 적용하는 편이 실용적입니다.

14. 최종 체크리스트

  • ☐ 통신사 앱에서 실제 요금제 사용량을 확인했다.
  • ☐ 아이폰 설정 → 셀룰러에서 앱별 사용량을 확인했다.
  • ☐ 아이폰의 통계 누적 기간과 통신사 청구 기간을 구분했다.
  • ☐ 필요 없는 앱만 셀룰러 데이터를 제한했다.
  • ☐ 연결 지원 또는 구버전 Wi-Fi 지원 설정을 확인했다.
  • ☐ 저데이터 모드와 5G 데이터 모드가 필요한지 판단했다.
  • ☐ 시스템 서비스 사용량을 확인하되 강제 삭제를 시도하지 않았다.
  • ☐ 듀얼 SIM을 사용한다면 데이터용 회선을 확인했다.
  • ☐ 통계 재설정과 네트워크 설정 재설정을 혼동하지 않았다.

결론: 아이폰 데이터 절약은 무조건 모든 연결을 끄는 것이 아니라 사용량을 정확히 측정하고, 많이 사용하는 앱을 선별하고, 연결 지원과 데이터 모드를 점검하는 것에서 시작합니다. 특히 아이폰의 누적 통계를 통신사의 이번 달 청구 사용량으로 착각하지 않는 것이 가장 중요합니다.
