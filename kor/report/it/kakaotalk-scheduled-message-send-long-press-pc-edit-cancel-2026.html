2. 갤럭시·아이폰 최신 방식: 전송 버튼을 길게 눌러 예약하기

최신 화면에서 간편하게 메시지 예약을 시작하려면 다음 순서를 따라 해보세요.

  1. 카카오톡을 열고 예약 메시지를 보낼 채팅방을 선택합니다.
  2. 입력창에 메시지 내용을 먼저 작성합니다.
  3. 오른쪽의 전송 버튼을 짧게 누르지 말고 길게 누릅니다.
  4. 화면에 메시지 예약하기 또는 예약 관련 팝업이 나타나는지 확인합니다.
  5. 발송할 날짜와 시간을 선택합니다.
  6. 상대방·채팅방·본문·예약 시각을 다시 확인합니다.
  7. 화면의 예약 등록 / 해당 시각에 보내기를 선택합니다.
  8. '메시지를 예약했습니다' 또는 등록 완료 안내를 확인합니다.

짧게 누르면 지금 즉시 발송될 수 있으므로 실수하지 않도록 주의하세요. 처음 사용하는 경우에는 중요한 업무 연락을 예약하기 전에 나와의 채팅에서 시험해 보는 것이 좋습니다.

일부 버전에서는 전송 버튼을 길게 누르는 대신 입력창 왼쪽의 + 버튼 → 예약 메시지에서 메시지 내용을 작성하고 날짜·시간을 선택하도록 안내합니다. 두 사용법 중 하나만 무조건 맞다고 단정하지 말고 사용 중인 카카오톡 화면을 확인하세요.

실사용 안내: 카카오톡 예약 메시지 최신 전송 방법, 카카오톡 예약 메시지 사용법

3. 전송 버튼을 길게 눌렀는데 예약 메뉴가 없어요

예약 기능이 보이지 않을 때는 휴대폰 고장이나 앱 장애로 바로 판단하지 말고 진입 경로부터 바꿔 확인하세요.

해결 순서

  1. 카카오톡이 최신 버전인지 App Store 또는 Google Play에서 확인합니다.
  2. 메시지를 전송 입력창에 실제로 작성한 상태인지 확인합니다. 글자가 없으면 전송 버튼이 비활성화될 수 있습니다.
  3. 전송 버튼을 짧게 탭한 것이 아닌지 확인합니다.
  4. 오른쪽 전송 버튼 외에 입력창 왼쪽 + → 예약 메시지 항목도 살펴봅니다.
  5. 현재 채팅방이 1:1 일반 채팅·일반 그룹 채팅인지 확인합니다. 오픈채팅 등에서는 같은 기능이 제공되지 않을 수 있습니다.
  6. 그래도 보이지 않으면 다른 일반 채팅방이나 나와의 채팅에서 해당 메뉴가 나타나는지 점검합니다.
  7. 마지막으로 앱을 완전히 종료했다가 다시 실행하고 업데이트된 버전에서 재확인합니다.

주의: 예약 기능을 찾기 위해 비공식 자동 전송 앱에 카카오 계정 비밀번호를 입력하거나 접근성 권한을 무분별하게 허용하지 마세요. 계정 보안과 개인정보 위험을 늘릴 수 있습니다.

4. PC 카카오톡에서 예약 메시지 보내는 방법

PC에서 다음 날 오전 업무 공지나 회의 안내를 작성한다면 모바일보다 긴 메시지를 수정하기 편리할 수 있습니다. 다만 PC 버전과 모바일 버전의 메뉴 위치가 같지는 않습니다.

  1. PC 카카오톡에 로그인합니다.
  2. 메시지를 보낼 개인 또는 일반 단체 채팅방을 엽니다.
  3. 채팅창 입력 영역 주변의 + 버튼, 시계 모양 아이콘 또는 '메시지 예약' 메뉴를 찾습니다.
  4. 예약 메시지 입력창이 열리면 내용을 작성합니다.
  5. 발송할 날짜·시간 및 수신 대상을 확인합니다.
  6. 필요한 경우 미리 알림 옵션이 제공되는지 확인합니다.
  7. 예약 버튼을 클릭하고 예약 목록에 등록됐는지 확인합니다.

메뉴가 보이지 않는다면 PC 카카오톡 업데이트 상태를 확인하세요. 최신 UI에서는 채팅창 아래의 + → 메시지 예약 경로로 안내되는 사례가 있습니다. 과거의 시계 아이콘 설명만 따르다가 계속 버튼을 찾는 문제를 피할 수 있습니다.

중요: 업무용 회사 PC에서 설정하는 경우, 수신자가 개인 계정인지 회사 단체방인지, 그리고 오전/오후가 올바른지 반드시 확인합니다. 여러 회사·동호회 단톡방의 이름이 비슷한 경우가 많기 때문입니다.

참고: PC 예약 메시지 설정 안내, 카카오 공식 — 예약 메시지 기능

5. 카카오톡 예약 메시지 목록 확인하는 방법

예약을 등록하고 나면 대기 중인 메시지를 실제로 확인해야 합니다. 예약 등록과 발송 완료를 구분하는 가장 중요한 단계입니다.

  1. 예약을 설정한 채팅방을 엽니다.
  2. 입력창 주변의 + 버튼 → 예약 메시지 또는 예약 관리 화면을 엽니다.
  3. 예약 목록 보기가 있으면 선택합니다.
  4. 브리핑 보드 또는 예약 목록에서 대기 중 항목을 확인합니다.
  5. 예약한 메시지의 상대방·내용·날짜·시간을 대조합니다.
  6. 이미 발송된 메시지는 발송 완료 또는 실제 채팅 내역에서 확인합니다.

확인할 세 가지: 받는 사람, 발송할 날짜와 시간, 본문이 맞는지입니다. 특히 11월 4일 오전 9시와 11월 4일 오후 9시를 혼동하는 실수가 생길 수 있습니다.

예약 목록에 없을 경우 다른 채팅방에서 예약했거나 등록 완료 단계 전에 화면을 닫은 것은 아닌지 확인해 보세요. 중복 예약을 만들지 않도록 처음 등록한 예약이 존재하는지 확인한 뒤 새로 작성합니다.

참고: 예약 목록 확인 및 관리 방법, 예약 메시지 편집·삭제 안내

6. 이미 예약한 메시지를 수정하는 방법

상대방에게 전송되기 전이라면 예약한 내용과 시각을 바꿀 수 있는지 확인할 수 있습니다.

  1. 카카오톡 예약 목록에서 수정하려는 메시지를 찾습니다.
  2. 해당 항목을 선택해 세부 화면을 엽니다.
  3. 오른쪽 위 더보기(⋮) 또는 편집 기능을 선택합니다.
  4. 메시지 본문·발송일·발송시간을 필요한 부분만 변경합니다.
  5. 저장을 선택합니다.
  6. 예약 목록으로 돌아가 수정된 내용과 시각이 반영됐는지 확인합니다.

편집 메뉴가 없을 때: 메시지가 이미 발송된 것은 아닌지 먼저 확인하고, 미발송 상태인데 편집 기능이 제공되지 않는다면 기존 예약을 취소한 뒤 새로 등록하는 방식을 검토할 수 있습니다. 이때 이전 예약을 삭제하기 전에 똑같은 메시지를 또 예약하면 중복 발송될 수 있으니 주의하세요.

중요한 공지라면 수정 전 내용과 변경 후 내용을 각각 기록해 두는 것이 좋습니다. 예약 대상 채팅방을 잘못 선택했을 때는 편집에서 대상 변경이 되는지 확인하고, 지원되지 않으면 새 채팅방에서 등록하는 편이 안전합니다.

7. 카카오톡 예약 메시지 취소·삭제 방법

잘못된 시간이나 채팅방으로 예약했거나 더 이상 보낼 필요가 없다면 예정된 전송 시각 전에 취소해야 합니다.

  1. 예약 메시지 메뉴를 열고 예약 목록 보기를 선택합니다.
  2. 삭제하려는 예약의 상대방과 시각을 확인합니다.
  3. 해당 항목을 눌러 상세 페이지를 엽니다.
  4. 더보기(⋮) → 삭제 또는 예약 메시지 삭제를 선택합니다.
  5. 확인 메시지가 나타나면 실제 취소할 예약인지 다시 읽고 실행합니다.
  6. 예약 목록에서 해당 예약이 사라졌는지 재확인합니다.

한 번 삭제한 예약 메시지를 복구할 수 있다고 가정하지 마세요. 중요한 문구는 삭제 전 별도 메모에 보관했다가 필요한 경우 다시 예약합니다.

예약 취소는 아직 전송되지 않은 예약을 취소하는 기능입니다. 이미 상대방에게 발송된 일반 메시지를 삭제하는 것과 전혀 다릅니다.

8. 예약 메시지는 상대방에게 '예약' 표시가 나올까요?

현재 카카오톡에서는 예약 전송 표시용 죠르디 아이콘을 별도로 붙이지 않습니다. 카카오는 2023년 1월 공개한 카카오톡 v10.0.5 개선 안내에서 예약 메시지의 죠르디 아이콘을 제거해 기존 메시지와 동일하게 활용할 수 있도록 했다고 설명했습니다.

이 변경의 의미는 다음과 같습니다.

  • 예약한 시각 전에는 상대방에게 예약 목록이 노출되는 것이 아닙니다.
  • 실제로 발송된 메시지는 별도의 죠르디 예약 아이콘 없이 일반 메시지와 유사하게 표시됩니다.
  • 그렇다고 반드시 상대방이 못 알아차리거나 메시지를 읽었다는 뜻은 아닙니다.
  • 대화 내용에 '어제 작성해 둔 안내입니다' 같은 표현이 들어가 있다면 상대방이 예약 메시지임을 짐작할 수 있습니다.

9. 단톡방·나와의 채팅·오픈채팅에서도 예약할 수 있나요?

카카오톡의 채팅방은 모두 동일한 종류가 아닙니다. 실제로 어떤 채팅방에서 예약 기능을 지원하는지는 채팅방 종류와 앱 버전을 함께 확인해야 합니다.

채팅 유형예약 전송 확인 포인트
일반 1:1 채팅예약 기능을 사용할 수 있는 대표적인 환경
일반 단체 채팅방일반적으로 가능하지만 참여자·채팅방을 잘못 선택하지 않도록 주의

오픈채팅방일반 예약 메시지 기능이 제한되는 경우가 있음
비밀채팅·채널 채팅별도 메시지 예약 기능 지원 여부 확인 필요

특히 오픈채팅은 일반 단톡방처럼 보이더라도 모든 채팅 기능이 같지 않습니다. 오픈채팅방에 예약 메시지 버튼이 없다면 휴대폰 전체의 오류라고 단정하지 마세요.

그룹 공지 활용 팁: 예약 시각에 메시지가 도착하더라도 단톡방 참여자가 알림을 꺼뒀다면 바로 읽지 않을 수 있습니다. 출결·업무 마감·긴급 연락처럼 확인이 중요한 내용은 카톡 예약만으로 전달 완료를 보장한다고 가정하지 않아야 합니다.

10. 사진·동영상도 예약 메시지로 보낼 수 있나요?

최신 사용법에서는 사진·동영상 선택 화면에서도 예약 전송을 이용하는 방식을 안내합니다. 다만 파일 크기, 앱 버전, 채팅방 종류 등에 따라 사용할 수 있는 첨부 유형과 개수가 달라질 수 있습니다.

사진 예약 전송을 점검하는 순서

  1. 예약할 상대방의 채팅방을 엽니다.
  2. + → 앨범에서 원하는 사진 또는 동영상을 선택합니다.
  3. 선택 화면의 전송 버튼을 길게 눌러 예약 기능이 나타나는지 확인합니다.
  4. 예약이 가능하다면 날짜·시간을 정하고 등록합니다.
  5. 예정 시각 이후 채팅방에서 원본이 정상적으로 전송됐는지 확인합니다.

주의: 텍스트 메시지를 예약하는 기능이 제공되더라도 사진·파일 예약에는 별도의 제한이 있을 수 있습니다. 사진이나 동영상이 필수인 업무 자료라면 파일 크기 및 형식을 확인하고, 전송될지 불확실한 상태에서 일정을 모두 맡기지 마세요.

11. 예약 메시지가 발송되지 않을 때 확인할 7가지

예약은 했는데 시간이 지나도 채팅방에 메시지가 없는 경우에는 아래 순서로 조사합니다.

  1. 정확한 예약 날짜와 시간을 확인합니다. 오늘/내일과 오전/오후를 혼동했는지 살펴보세요.
  2. 예약 목록에 항목이 실제 남아 있는지 확인합니다. 등록 완료 안내를 못 봤다면 저장이 끝나지 않았을 수 있습니다.
  3. 보낼 상대방이나 채팅방이 맞는지 확인합니다. 이름이 비슷한 단톡방이 여러 개 있을 수 있습니다.
  4. 카카오톡 로그인·서비스 상태를 확인합니다. 계정이나 서비스 장애가 있는지 확인해야 합니다.
  5. 사진·동영상 등 첨부파일이 제한에 걸린 것은 아닌지 검토합니다.
  6. 예약 목록의 대기·완료 상태와 실제 채팅 내역을 비교합니다.
  7. 중요한 메시지라면 상대방에게 전달 여부를 별도로 확인합니다.

기존 예약이 실제로 전송됐는지 모르는 상태에서 같은 내용을 다시 예약하면 중복 발송될 수 있습니다. 반드시 예약 목록과 채팅방을 먼저 대조하세요.

휴대폰의 화면이 꺼져 있거나 PC가 꺼졌다는 사실 하나만으로 실패했다고 단정하지 마세요. 구체적인 실패 사유는 실제 예약 상태와 서비스 환경을 확인해야 합니다.

12. 실수하기 쉬운 사례 5가지: 예약을 등록해도 확인이 필요한 이유

사례 A — 생일 날짜 착각: 11월 4일 생일인데 11월 5일 0시로 예약하면 하루 늦게 도착할 수 있습니다. 발송 전에 정확한 날짜를 다시 보세요.

사례 B — 단톡방 이름 착각: '팀 회의'와 '팀 회의(관리자)' 같은 비슷한 채팅방에 잘못 예약하면 의도하지 않은 사람에게 내부 정보를 노출할 수 있습니다. 채팅방 참여자를 확인하세요.

사례 C — 예약 내용 변경 후 저장 누락: 편집을 마치고 나가면 실제로 저장되지 않을 수 있습니다. 목록에서 다시 열어 최종 내용을 확인하세요.

사례 D — 중복 예약: 예약이 되었는지 몰라 두 번 눌렀다면 같은 내용이 두 번 발송될 수 있습니다. 예정 시각이 같은 예약이 중복되지 않았는지 확인하세요.

사례 E — 보내면 안 될 개인정보 포함: 전화번호, 계정 인증번호, 주민등록번호, 내부 계약정보 등이 잘못된 채팅방으로 예약돼 있는지 확인하고 필요한 경우 삭제하세요. 보낸 뒤 삭제하는 것보다 발송 전 차단하는 편이 안전합니다.

위 사례는 예방을 위한 가상 상황이며, 특정 이용자의 실제 예약 오류 사례나 통계가 아닙니다.

14. 자주 묻는 질문 FAQ

Q1. 카카오톡 예약 메시지 어떻게 보내나요?

채팅방에서 내용을 입력한 뒤 전송 버튼을 길게 누르기를 먼저 시도하세요. 예약 메뉴가 나타나면 날짜·시간을 지정합니다. 안 보이면 + → 예약 메시지를 찾습니다.

Q2. 카카오톡 예약 메시지 표시가 상대방에게 보이나요?

카카오는 2023년 업데이트에서 예약 메시지 죠르디 아이콘을 제거했다고 공식 발표했습니다. 따라서 현재는 별도의 죠르디 표시가 붙지 않는 것이 일반적입니다.

Q3. 예약 날짜·시간을 바꿀 수 있나요?

발송 전 예약 목록에서 해당 메시지의 편집 메뉴를 확인하세요. 메뉴가 제공되지 않는다면 기존 예약을 취소하고 새 예약을 등록하는 방법을 검토합니다.

Q4. 카톡 예약 메시지 취소하는 방법은?

예약 목록 → 해당 메시지 선택 → 더보기(⋮) → 삭제를 찾습니다. 예약 목록에서 삭제됐는지 재확인하세요.

Q5. 오픈채팅에서도 예약 메시지를 보낼 수 있나요?

일반 1:1·단톡방과 달리 오픈채팅에는 예약 기능이 제한될 수 있습니다. 해당 채팅방에 기능이 나타나는지 실제로 확인하세요.

Q6. PC 카카오톡에서도 예약이 되나요?

지원되는 PC 버전에서 예약 메시지를 사용할 수 있습니다. 채팅방의 + / 메시지 예약 메뉴를 찾고, 메뉴가 없으면 PC 앱을 업데이트하세요.

Q7. 예약 메시지는 무료인가요?

일반 카카오톡 채팅방의 기본 예약 메시지는 별도 유료 문자 예약 서비스와 다릅니다. 통신 데이터 사용이나 서비스별 별도 결제 상품은 구분해야 합니다. 카카오톡 채널 관리자센터의 유료 마케팅 예약 발송과도 다른 기능입니다.

Q8. 예약 등록 직후 상대방에게 알림이 가나요?

예약 등록은 발송 이전 단계입니다. 실제 메시지가 전송되기 전까지 일반적으로 상대방 채팅방에 메시지가 나타나지 않습니다.

Q9. 예약한 메시지는 상대방이 읽었는지 확인할 수 있나요?

예약한 시각 이후 실제로 메시지가 발송된 다음 채팅방의 일반 메시지 확인 방식을 사용해야 합니다. 예약 등록 여부와 읽음 여부는 다른 개념입니다.

Q10. 예약한 메시지를 수정했는데 예전 내용이 나가면 어떻게 하나요?

수정 후 저장 여부와 예약 목록의 최종 내용을 다시 확인하세요. 예약 전송과 일반 메시지 수정은 다른 기능이므로 목록의 실제 상태를 기준으로 판단해야 합니다.

15. 보내기 전 1분 최종 체크리스트

  • ☐ 카카오톡이 최신 버전인지 확인했다.
  • ☐ 일반 채팅방인지 오픈채팅인지 확인했다.
  • ☐ 메시지를 작성한 뒤 전송 버튼 길게 누르기를 시도했다.
  • ☐ 필요하면 + → 예약 메시지 경로도 확인했다.
  • ☐ 예약 대상 상대방·단톡방 참여자를 확인했다.
  • ☐ 예약 날짜·오전/오후·시간을 확인했다.
  • ☐ 메시지 본문과 첨부파일에 오류가 없는지 확인했다.
  • ☐ 예약 목록에서 등록 완료를 확인했다.
  • ☐ 내용 수정 시 최종본이 저장됐는지 재확인했다.
  • ☐ 더 이상 필요하지 않은 예약은 발송 전에 삭제했다.
  • ☐ 중요한 연락은 발송 후 실제 채팅방과 수신 여부를 확인하기로 했다.

결론: 카카오톡 예약 메시지는 채팅방 확인 → 전송 버튼 길게 누르기 또는 예약 메시지 메뉴 → 날짜·시간 지정 → 예약 목록 확인 순서로 사용하면 됩니다. 변경이 필요하면 예약 목록에서 편집·삭제하고, 이미 보낸 메시지의 삭제 기능과는 구분해야 합니다.
