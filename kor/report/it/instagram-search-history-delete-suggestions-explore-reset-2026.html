인스타그램 검색창을 눌렀더니 예전에 찾아본 계정이 계속 나타나거나, 검색기록을 모두 지웠는데도 같은 사람이 추천되는 경우가 있습니다. ‘최근 검색어’와 ‘추천 계정’은 같은 항목이 아닙니다. 최근 검색기록을 삭제해도 추천 콘텐츠와 자동완성 결과가 모두 사라지는 것은 아닙니다.

이 글은 아이폰과 갤럭시에서 검색기록 한 개만 삭제하기, 전체 삭제하기, 계정 센터에서 확인하기, PC에서 삭제하기를 순서대로 설명합니다. 검색기록을 삭제했는데도 추천 계정이 보일 때는 무엇을 따로 설정해야 하는지도 구분했습니다.

1분 결론: 검색창을 눌렀을 때 보이는 ‘최근 검색’ 목록을 지우려면 돋보기(검색) → 검색창 → 최근 항목 옆 X 또는 모두 지우기부터 시도하세요. 추천 계정이 계속 뜨는 문제라면 최근 검색 삭제와 별도로 콘텐츠 기본 설정·추천 콘텐츠 초기화를 확인해야 합니다. 화면 표기는 앱 버전과 계정에 따라 다릅니다.

1. 내 상황에 맞는 삭제 방법 먼저 고르기

지금 보이는 상황먼저 확인할 곳기대할 수 있는 결과
검색창을 누르자 전에 검색했던 계정이 표시됨검색 탭의 최근 검색 목록특정 항목 또는 최근 검색 전체 삭제
목록에서 한 사람만 지우고 싶음해당 최근 검색 옆 X·삭제선택한 최근 검색 항목 삭제
‘모두 지우기’ 버튼이 안 보임프로필 → 계정 센터 또는 내 활동계정별 검색기록 메뉴가 있는지 확인
검색기록은 비웠는데 같은 계정이 계속 추천됨추천 계정·자동완성 결과 구분검색기록 삭제만으로 완전히 해결되지 않을 수 있음
릴스·탐색 탭이 원치 않는 주제로 가득함콘텐츠 기본 설정의 추천 콘텐츠 초기화탐색·릴스·피드 추천을 새로 조정하는 별도 기능
PC에서 검색한 기록을 지우고 싶음instagram.com의 검색 메뉴로그인한 계정의 최근 검색 정리
인스타그램에서 열었던 웹사이트 흔적이 걱정됨링크 방문기록 또는 브라우저 기록검색기록 삭제와 별도 점검

이 표의 핵심은 ‘무엇을 지우려는지’를 먼저 결정하는 것입니다. 화면에 나타나는 모든 계정 이름이 사용자가 실제로 검색했던 기록은 아닙니다.

2. 아이폰·갤럭시: 인스타그램 최근 검색기록 한 번에 삭제하기

가장 빠른 방법은 인스타그램 검색 화면에서 지우는 것입니다. iPhone과 Android의 기본 절차는 비슷합니다.

  1. 인스타그램 앱을 열고 삭제하려는 계정으로 로그인했는지 확인합니다.
  2. 하단의 돋보기 모양 검색·탐색 탭을 누릅니다.
  3. 상단 검색창을 한 번 누릅니다.
  4. 검색창 아래에 최근 검색(Recent) 목록이 표시되면 ‘모두 보기’ 또는 ‘전체 보기’가 있는지 확인합니다.
  5. 모두 지우기(Clear all)가 보이면 눌러 삭제합니다. 확인창이 뜨면 한 번 더 확인합니다.
  6. 다시 검색창을 열어 최근 검색 목록이 비어 있는지 확인합니다.

버튼 이름은 ‘모두 지우기’, ‘전체 삭제’, ‘Clear all’ 등으로 표시될 수 있습니다. 앱 언어와 버전에 따라 ‘모두 보기’ 단계가 없거나, 바로 삭제 버튼이 나타날 수 있습니다.

주의: 이 단계는 최근 검색 목록을 정리하는 것입니다. 추천 계정, 광고, 탐색 피드 기록, 브라우저 방문기록까지 한꺼번에 초기화하는 기능은 아닙니다.

3. 검색기록 중 한 사람·한 검색어만 삭제하는 방법

전체를 지우고 싶지 않다면 개별 삭제를 시도하세요.

  1. 돋보기 탭에서 검색창을 터치합니다.
  2. 최근 검색 목록에서 삭제하려는 계정, 해시태그 또는 검색어를 찾습니다.
  3. 항목 오른쪽의 X·삭제·Remove 중 화면에 표시된 버튼을 누릅니다.
  4. 해당 항목이 사라졌는지 확인합니다.

이 방법은 자주 찾는 다른 검색어를 보존하면서 하나만 정리할 때 적합합니다.

반대로 특정 항목 옆에 삭제 버튼이 없다면 그것이 최근 검색이 아닌 추천 검색 결과일 수 있습니다. 추천 결과를 최근 검색처럼 지우려고 하면 같은 항목이 반복해서 나타날 수 있습니다.

4. 검색기록 메뉴가 안 보인다면 계정 센터에서 확인하기

인스타그램은 일부 계정에서 계정 센터(Accounts Center)의 검색기록 기능도 제공합니다. 다만 모든 계정에 똑같이 나타나는 메뉴가 아닙니다. 검색 화면에서 지울 수 없다면 다음 경로를 확인하세요.

  1. 인스타그램 오른쪽 아래 프로필 사진으로 이동합니다.
  2. 오른쪽 위 ☰ 메뉴를 누릅니다.
  3. 계정 센터 또는 Meta 계정을 찾습니다.
  4. 내 정보 및 권한(Your information and permissions)을 엽니다.
  5. 검색 내역(Search history) 항목이 있으면 들어갑니다.
  6. 인스타그램 계정이 여러 개라면 정확한 계정 이름을 선택합니다.
  7. 지원되는 삭제 옵션에 따라 개별 검색을 지우거나 전체 검색기록을 정리합니다.

검색 내역 항목이 아예 없을 때: 사용 중인 계정에 해당 메뉴가 제공되지 않을 수 있습니다. 앱이 고장 났다고 단정하거나 계정을 삭제할 필요는 없습니다. 먼저 2번의 검색창 삭제 기능을 사용하고, 앱 내 ‘내 활동 → 최근 검색’ 메뉴가 표시되는지도 확인하세요.

5. PC에서 인스타그램 검색기록 삭제하기

컴퓨터에서 사용할 때는 스마트폰과 메뉴 위치가 다릅니다.

  1. 브라우저에 **instagram.com**을 직접 입력하고 로그인합니다.
  2. 화면의 검색(Search) 메뉴를 엽니다.
  3. 최근 검색 목록이 보이면 특정 항목의 삭제·X 또는 모두 지우기를 이용합니다.
  4. 검색 메뉴에 최근 검색 항목이 없다면 설정 → 계정 센터 → 내 정보 및 권한에서 검색 내역 메뉴가 제공되는지 확인합니다.

웹 버전의 인터페이스는 변경될 수 있습니다. 특히 브라우저의 방문기록 삭제는 인스타그램 계정의 최근 검색 삭제와 다릅니다. 크롬이나 사파리 방문기록을 지웠다고 인스타그램 안의 검색 목록이 반드시 삭제되지는 않습니다.

6. 삭제했는데도 같은 계정이 계속 뜨는 이유

가장 많이 혼동하는 부분입니다.

① 최근 검색기록이 다시 쌓인 경우

삭제 뒤에 동일한 사용자 이름이나 검색어를 다시 찾아보면 최근 검색 목록에 다시 표시될 수 있습니다. 이는 삭제 실패와 다릅니다.

② 검색어 자동완성과 추천 계정을 최근 검색으로 착각한 경우

검색창에 ‘김’이나 특정 아이디의 앞글자를 입력했을 때 나타나는 계정 목록은 자동완성·추천 검색 결과일 수 있습니다. 단순히 최근 검색기록을 지웠다는 이유만으로 이러한 제안이 모두 사라지지는 않습니다.

③ 계정이나 기기 구분이 잘못된 경우

여러 인스타그램 계정을 사용한다면 계정 A에서 지운 검색기록이 계정 B에도 똑같이 적용된다고 가정하면 안 됩니다. 삭제했던 계정의 사용자 이름과 현재 로그인 계정을 먼저 비교하세요.

④ 탐색·릴스 추천을 검색기록으로 착각한 경우

탐색 탭에 특정 분야의 게시물이 계속 표시되는 현상은 최근 검색 목록 삭제만으로 설명되지 않습니다. Meta는 추천 콘텐츠가 이용자의 관심과 상호작용에 따라 다시 개인화된다고 안내합니다.

판별법: 검색창을 누르자마자 ‘최근 검색’이라는 표시 아래 나타나면 삭제 대상인 최근 검색일 가능성이 큽니다. 검색어를 입력한 후 새로 등장하는 목록이나 탐색 피드 게시물은 별개로 다뤄야 합니다.

7. 탐색 탭·릴스 추천까지 바꾸고 싶다면

특정 검색어를 지우는 것이 아니라 원치 않는 추천 콘텐츠를 줄이고 싶은 경우에는 인스타그램의 별도 추천 설정을 살펴봐야 합니다.

Meta가 공식적으로 안내한 경로는 다음과 같습니다.

  1. 프로필 화면에서 ☰ 메뉴를 엽니다.
  2. 콘텐츠 기본 설정(Content preferences)을 찾습니다.
  3. 제공되는 경우 추천 콘텐츠 초기화(Reset suggested content)를 선택합니다.
  4. 화면의 설명을 검토하고 초기화를 진행합니다.
  5. 이후 원하는 주제의 게시물에 관심 표시를 하거나, 원치 않는 게시물에는 관심 없음(Not interested)을 선택합니다.

이 기능은 최근 검색기록을 지우는 버튼과 다릅니다. Meta는 추천 초기화가 탐색(Explore)·릴스(Reels)·피드(Feed)의 추천 콘텐츠에 영향을 주고, 이후 이용자의 상호작용을 바탕으로 다시 개인화된다고 설명합니다.

따라서 ‘추천 초기화 = 앞으로 특정 계정이 절대로 안 뜸’은 아닙니다. 실제 메뉴 제공 여부도 계정·앱 버전에 따라 확인해야 합니다.

8. 검색기록·추천·링크 기록·활동 기록은 어떻게 다를까?

기록 종류무엇을 보여주나검색기록 삭제와의 관계
최근 검색내가 검색창에서 최근 찾아본 계정·키워드 등삭제 대상으로 확인 가능
추천 검색·자동완성검색어를 입력할 때 제안되는 결과최근 검색 삭제만으로 전부 없어지지 않을 수 있음
탐색·릴스 추천이용자에게 표시되는 추천 게시물별도의 추천 콘텐츠 설정 영역
내 활동좋아요·댓글·검색 등 계정 활동 관리 항목항목별 삭제 기능이 다름
인스타그램 내부 브라우저 링크 기록앱 안에서 열었던 웹 링크 관련 기록최근 검색 목록과는 별개
휴대폰 브라우저 방문기록Safari·Chrome 등에서 방문한 웹사이트인스타그램 계정 기록과 다른 저장 영역

예를 들어 “검색창에서 특정 사람 이름만 안 보이게 하고 싶다”면 3번을 먼저 보세요. “탐색 탭에 같은 주제 게시물이 계속 나온다”면 7번이 더 직접적인 해결 경로입니다.

9. ‘모두 지우기’가 안 되거나 목록이 그대로일 때

삭제 버튼을 눌렀는데 화면이 그대로라면 다음 순서로 점검합니다.

첫 번째 — 정말 최근 검색인가? 목록 위에 ‘최근 검색’이라는 표시가 있는지, 아니면 입력할 때 표시되는 추천 검색 결과인지 먼저 구분합니다.

두 번째 — 올바른 계정인가? 프로필에서 로그인 계정을 확인합니다. 계정을 전환해 다른 계정의 검색기록을 보고 있을 수 있습니다.

Q3. 특정 사람 검색기록만 삭제하고 나머지는 유지할 수 있나요?

최근 검색 목록에서 개별 항목 옆 X·삭제 버튼이 제공된다면 가능합니다. 해당 버튼이 없다면 계정 센터의 검색 내역 메뉴를 확인하세요.

Q4. 인스타그램 검색기록 삭제와 계정 삭제는 같은가요?

전혀 다릅니다. 검색기록 삭제는 최근 검색 항목을 관리하는 것이고, 계정 삭제는 계정 자체를 없애는 절차입니다. 검색어를 지우기 위해 계정을 삭제하지 마세요.

Q5. 아이폰에서 지우면 갤럭시에서도 안 보이나요?

동일한 인스타그램 계정의 최근 검색 기록을 관리하는 경우와 각 기기의 브라우저 방문기록을 지우는 경우는 구분해야 합니다. 삭제 후 다른 기기에서 동일한 계정으로 로그인하여 결과를 직접 확인하세요.

Q6. 검색기록 삭제 버튼이 정말 보이지 않습니다.

모든 계정과 앱 버전에서 동일한 메뉴를 제공하는 것은 아닙니다. 검색 탭, 내 활동, 계정 센터 순서로 확인하고 사용 중인 앱을 업데이트하세요. 어디에서도 기능이 보이지 않는다면 메뉴를 임의로 만들어 따라 할 필요는 없습니다.
