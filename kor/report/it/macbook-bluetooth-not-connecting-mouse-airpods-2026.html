2. Mac의 Bluetooth가 켜져 있는지 확인하기

macOS의 기본 경로는 Apple 메뉴() → 시스템 설정 → Bluetooth입니다.

  1. 화면 왼쪽 위 Apple 메뉴()를 누릅니다.
  2. 시스템 설정을 엽니다.
  3. 왼쪽에서 Bluetooth를 선택합니다.
  4. 상단 Bluetooth 켬/끔 상태를 확인합니다.
  5. Bluetooth를 켜고 나의 기기·근처 기기 목록을 확인합니다.
  6. 연결할 기기가 보이면 그 옆의 연결을 누릅니다.
  7. 숫자 코드 입력 또는 허용 요청이 표시되면 화면 안내에 따라 승인합니다.

다른 공식 경로: 메뉴 막대 제어 센터 → Bluetooth에서도 기기 목록 확인 및 연결이 가능합니다.

Bluetooth 스위치를 껐다 켜는 것이 불가능한 경우는 시스템 문제일 수 있으므로 Mac을 재시동한 뒤 확인합니다. Apple은 외장 USB Bluetooth 어댑터가 연결된 상황이나 Bluetooth 입력 장치만 있는 데스크톱 Mac에서는 끄기 동작이 제한될 수 있다고 안내합니다.

주의: iMac·Mac mini 등에서 Bluetooth 키보드와 마우스만 사용하는데 무작정 Bluetooth를 끄면 시스템을 조작하기 어려워질 수 있습니다. 유선 마우스나 키보드를 확보한 뒤 변경하세요.

공식: Mac Bluetooth 설정, Mac에서 Bluetooth 켜기·끄기.

3. 새 블루투스 이어폰·마우스·키보드가 검색되지 않을 때

Bluetooth를 켰는데 목록에 아무것도 없거나 원하는 제품만 보이지 않는다면, 우선 액세서리가 검색 가능한 페어링 상태인지 확인하세요.

해결 순서

  1. 액세서리의 전원을 켭니다.
  2. 배터리 잔량 또는 충전 상태를 확인합니다.
  3. 제조사 설명서에 따라 페어링 모드를 활성화합니다.
  4. 주변의 아이폰·태블릿·다른 컴퓨터에 이미 연결되어 있는지 확인합니다.
  5. 다른 기기에 연결돼 있다면 해당 기기에서 연결을 해제한 후 다시 시도합니다.
  6. Mac과 액세서리를 가까이 둡니다.
  7. 시스템 설정 → Bluetooth → 근처 기기에서 이름이 나타나는지 봅니다.
  8. 기기 이름 오른쪽 연결을 클릭합니다.
  9. 키보드에 연결 코드가 표시되면 연결하려는 그 키보드에서 숫자를 입력하고 Enter 키를 누릅니다.

오해하지 마세요: 단순히 이어폰의 전원을 켠 것과 페어링 모드로 진입한 것은 다를 수 있습니다. 제품별로 전원 버튼 길게 누르기, 충전 케이스 버튼 누르기, 별도의 연결 버튼 누르기 등 방식이 다릅니다.

또한 일부 무선 키보드·마우스는 Bluetooth가 아니라 USB 리시버 전용입니다. 제품에 '무선'이라고 적혀 있어도 Bluetooth 페어링을 지원하는지는 별도로 확인하세요.

공식: Apple — Bluetooth 기기 연결하기.

4. 기존에 연결한 장치가 계속 끊긴다면 '이 기기 지우기' 후 재페어링

한 번 연결했던 블루투스 기기가 갑자기 '연결 안 됨'으로 바뀌거나, '연결' 버튼을 눌러도 실패하는 경우가 있습니다.

안전한 재페어링 순서

  1. 해당 액세서리 전원을 껐다가 다시 켭니다.
  2. Mac의 시스템 설정 → Bluetooth로 이동합니다.
  3. 나의 기기에서 해당 제품을 찾습니다.
  4. 이미 연결된 상태면 먼저 연결 해제를 시도합니다.
  5. 문제가 반복되면 해당 기기의 세부정보 또는 Control-클릭 메뉴에서 '이 기기 지우기'를 선택합니다.
  6. 액세서리를 제조사 안내에 따라 다시 페어링 모드로 만듭니다.
  7. Mac의 근처 기기에서 제품을 선택해 연결합니다.
  8. 연결 후 실제로 타이핑·커서 이동·오디오 재생이 정상인지 확인합니다.

'연결 해제'와 '이 기기 지우기'는 다릅니다.

항목연결 해제이 기기 지우기
의미현재 연결만 끊음기존 기기 등록을 제거
이후다시 연결 가능새로 페어링해야 할 수 있음
적합한 경우일시적인 연결 오류 테스트지속적인 페어링 오류
주의자동 재연결될 수 있음유일한 입력장치라면 조작 불가 위험

Bluetooth 마우스와 키보드를 모두 지울 필요는 없습니다. 문제를 일으키는 특정 기기만 다시 연결하세요. Mac 데스크톱 사용자는 유선 입력장치를 준비하는 것이 안전합니다.

공식: Apple — Bluetooth 기기 연결·연결 해제·지우기.

5. Magic Mouse·Magic Keyboard·Magic Trackpad가 안 잡힐 때

Apple의 Magic 액세서리는 일반 무선 기기와 구별되는 공식 재연결 방법이 있습니다.

Apple 공식 순서

  1. 액세서리 전원 스위치를 끄고 다시 켭니다.
  2. 스위치에서 녹색이 보이는지 확인합니다.
  3. 액세서리에 맞는 USB-C–USB-C 또는 USB-C–Lightning 등 호환 케이블을 준비합니다.
  4. 액세서리를 Mac에 케이블로 연결합니다.
  5. 약 1분 정도 기다립니다.
  6. 케이블을 분리한 후 Bluetooth가 연결되는지 확인합니다.
  7. 제어 센터 → Bluetooth에서 액세서리의 충전 수준을 확인합니다.

Apple은 호환 케이블로 Magic Keyboard·Mouse·Trackpad를 Mac에 연결하면 페어링과 충전이 진행될 수 있다고 설명합니다.

예외: 배터리를 교체하는 오래된 Apple Wireless Keyboard·Magic Trackpad는 충전 케이블이 없는 제품도 있으므로 별도 페어링 절차를 사용해야 합니다.

사용 중인 모델이 Magic Mouse라면 USB 충전 중 사용 가능 여부는 디자인에 따라 달라집니다. 케이블을 분리한 뒤 무선 연결 여부를 확인하세요.

공식: Apple — Magic Keyboard, Magic Mouse 또는 Magic Trackpad 연결 불가, Apple — Magic 액세서리 설정하기.

6. 에어팟이 Mac에 검색되지 않는다면 모델별 페어링 방법부터 확인

에어팟을 아이폰에서 쓰다가 맥북에도 연결하려고 할 때 목록에 나타나지 않을 수 있습니다.

Mac에서 수동 연결하는 방법

  1. Mac의 시스템 설정 → Bluetooth를 엽니다.
  2. Bluetooth가 켜져 있는지 확인합니다.
  3. 양쪽 AirPods을 충전 케이스에 넣고 덮개를 엽니다.
  4. AirPods 4·5 및 AirPods Pro 3처럼 전면 터치 방식 모델은 케이스 앞면을 두 번 탭해 흰색 표시등이 깜박이게 합니다.
  5. 그 외 지원 모델은 케이스 뒷면 설정 버튼을 길게 눌러 흰색 표시등이 깜박이게 합니다.
  6. Mac의 근처 기기 목록에서 AirPods을 선택하고 연결을 누릅니다.
  7. 연결 후 제어 센터 → 사운드에서 AirPods을 출력 장치로 선택합니다.

주의: 에어팟 충전 케이스의 버튼 유무와 사용법은 모델마다 다릅니다. 모든 에어팟에서 '뒷면 버튼 15초'를 누르는 방법이 동일한 것은 아닙니다. 모델별 공식 안내를 반드시 확인하세요.

AirPods이 계속 연결되지 않으면 케이스 안 양쪽 유닛 충전 상태, Mac의 macOS 지원 버전, 페어링·재설정 절차를 확인합니다.

공식: Apple — Mac 및 기타 Bluetooth 기기에 AirPods 설정, Apple — AirPods 연결 안 됨.

7. 에어팟 '연결됨'인데 소리가 맥북 스피커로 나올 때

Bluetooth 연결 자체가 성공해도 출력 장치가 자동으로 바뀌지 않을 수 있습니다.

점검 순서

  1. Mac에서 시스템 설정 → 사운드로 이동합니다.
  2. 출력 목록을 엽니다.
  3. AirPods·블루투스 헤드폰 이름을 선택합니다.
  4. Mac의 음량과 헤드폰 자체의 음량을 확인합니다.
  5. YouTube·음악 앱을 재생해 소리 출력 위치를 확인합니다.
  6. 마이크도 필요하면 시스템 설정 → 사운드 → 입력에서 원하는 입력 장치를 별도로 선택합니다.
  7. 화상회의 앱을 쓰는 경우 앱 자체의 스피커·마이크 선택 설정도 확인합니다.

출력과 입력은 서로 다른 설정입니다. 음악 소리는 AirPods에서 듣고 회의용 마이크는 Mac 내장 마이크를 사용하도록 따로 선택할 수도 있습니다.

또한 블루투스 헤드폰을 통화용 마이크와 함께 사용하면 오디오 동작이 달라질 수 있습니다. 음질이 갑자기 나빠진 경우에는 음악 재생 앱과 통화·회의 앱을 종료한 뒤 출력·입력 장치를 확인하세요.

공식: Apple — Mac의 Bluetooth 장치를 오디오 출력·입력으로 선택.

8. 에어팟이 계속 아이폰으로 넘어가는 자동 전환 문제

Mac에서 음악을 듣다가 iPhone을 만지면 AirPods 연결이 바뀌는 것은 고장이라기보다 여러 Apple 기기 자동 전환 기능일 수 있습니다.

Apple 공식 설정 경로

  1. Mac에서 시스템 설정 → Bluetooth를 엽니다.
  2. AirPods 옆의 정보(i) 버튼을 선택합니다.
  3. 이 Mac에 연결 설정을 찾습니다.
  4. 자동으로 되어 있다면 다른 Apple 기기와의 자동 전환이 허용될 수 있습니다.
  5. Mac에서 사용 중인 AirPods 연결을 유지하고 싶다면 마지막으로 이 Mac에 연결했을 때에 해당하는 옵션을 검토합니다.
  6. AirPods을 다시 Mac에 연결해 동작을 확인합니다.

확인할 사실: 같은 Apple 계정으로 로그인한 여러 기기에서 AirPods을 사용하면 전환 동작이 발생할 수 있습니다. 단순히 Bluetooth에서 AirPods이 사라졌다 나타난다고 해서 반드시 무선 전파 불량은 아닙니다.

공식: Apple — AirPods이 Mac에 연결되는 시점 변경.

9. 마우스 커서가 끊기거나 이어폰 소리가 버벅일 때: 전파 간섭 진단

Bluetooth는 2.4GHz 무선 대역을 이용하므로 Wi-Fi·USB 허브·금속 장애물과 간섭할 수 있습니다. Apple은 USB 3 및 Thunderbolt 3 기기 주변에서도 무선 성능에 영향이 있을 수 있다고 안내합니다.

먼저 해볼 수 있는 간단한 실험

  1. Mac과 액세서리를 더 가까이 둡니다.
  2. 주변의 USB 3 외장 SSD·허브·케이블을 잠시 분리합니다.
  3. 액세서리의 동작이 정상으로 돌아오는지 확인합니다.
  4. 문제가 개선됐다면 허브·외장 SSD를 Mac과 떨어진 곳에 배치합니다.
  5. 가능하면 품질이 확인된 차폐 USB·Thunderbolt 케이블을 사용합니다.
  6. 무선 장치가 많은 환경이라면 사용하지 않는 장치를 꺼봅니다.
  7. Wi-Fi 라우터가 2.4GHz·5GHz를 모두 지원한다면, Wi-Fi 기기를 5GHz 대역으로 분산시키는 방안을 검토합니다.
  8. 금속 책상·본체 뒤쪽 등 전파가 가로막히는 위치에 수신 기기를 두지 않습니다.

증상과의 연결

현상간섭 가능성을 높이는 단서
마우스 포인터가 순간 이동·지연외장 SSD를 연결할 때만 악화됨
블루투스 스피커 소리 끊김USB 허브 가까이 있을 때 심해짐
Mac에서 멀어지면 연결 해제거리·장애물의 영향일 수 있음
특정 책상에서만 문제 발생금속 구조·무선 장치 밀집 여부 확인

USB 허브를 무조건 교체할 필요는 없습니다. 우선 분리 전후에 동일한 환경에서 증상이 개선되는지 확인해 원인을 좁히세요.

10. Mac의 Bluetooth가 아예 켜지지 않는 경우

Bluetooth 설정에서 켬/끔 상태를 바꿀 수 없거나 모든 기기가 사라졌다면 먼저 Mac 시스템과 입력장치 상태를 확인해야 합니다.

안전한 점검 순서

  1. 유선 또는 내장 키보드·트랙패드가 있는지 확인합니다.
  2. 시스템 설정 → Bluetooth로 이동해 현재 스위치 상태를 확인합니다.
  3. 지원되는 경우 Bluetooth를 꺼짐 → 켜짐으로 전환해 봅니다.
  4. Mac을 재시동합니다.
  5. 다시 Bluetooth 설정을 열어 기기를 찾습니다.
  6. 외부 Bluetooth 어댑터가 있다면 분리한 뒤 재확인합니다.
  7. macOS 업데이트와 보안·관리 정책을 확인합니다.
  8. 그래도 Bluetooth 전체가 작동하지 않으면 Apple 지원·공인 서비스센터에 진단을 요청합니다.

주의: 인터넷에 떠도는 '블루투스 PLIST 강제 삭제', '숨겨진 서비스 강제 종료', '관리자 터미널 명령어 일괄 실행'은 운영체제 버전과 개인 설정에 따라 위험할 수 있습니다. 저장되지 않은 설정·다른 Bluetooth 기기 페어링에 영향을 줄 수 있으므로 공식 설정과 재시동부터 시도하는 것이 좋습니다.

공식: Apple — Bluetooth 켜기·끄기와 Mac 재시동 안내, Apple — Magic 액세서리 연결 불가.

11. 맥북과 외장 키보드·마우스가 둘 다 끊겼을 때

MacBook의 경우 내장 트랙패드와 키보드로 Bluetooth 설정을 다시 조작할 수 있습니다. 하지만 Mac mini·iMac처럼 외장 키보드·마우스에 의존하는 기기에서는 주의해야 합니다.

복구 순서

  1. 가능하면 USB 유선 키보드 또는 유선 마우스를 연결합니다.
  2. 내장 입력장치가 있다면 그것을 사용합니다.
  3. 액세서리 전원·배터리를 확인합니다.
  4. Magic 액세서리라면 해당 모델이 지원하는 USB 케이블 페어링을 시도합니다.
  5. 시스템 설정 → Bluetooth에서 기기 연결을 다시 확인합니다.
  6. 다시 연결된 후에는 입력장치 하나씩 테스트합니다.

Apple 공식 지원 문서는 키보드를 사용할 수 있으나 마우스가 없을 경우 Spotlight 검색을 통해 Bluetooth를 다시 켜는 방법도 안내합니다. 하지만 이 방법은 키보드가 인식될 때만 가능하므로 유선 입력장치를 사전에 준비하는 것이 더 안정적입니다.

연결된 입력장치 두 개를 동시에 '이 기기 지우기' 하지 마세요. 일단 하나를 정상적으로 복구한 뒤 나머지를 처리하는 편이 안전합니다.

공식: Apple — Magic Mouse·Keyboard·Trackpad 연결 불가.

12. Magic Mouse와 일반 블루투스 마우스가 다른 점

Magic Mouse·Magic Keyboard·Magic Trackpad는 Apple의 공식 케이블 재페어링 방법을 사용할 수 있습니다. 반면 일반 Bluetooth 마우스는 제품별 페어링 버튼·멀티 기기 슬롯 선택 절차를 따릅니다.

유형연결 전 확인재연결 방법
Magic Mouse전원 스위치·충전·Mac 호환 케이블케이블 연결 약 1분 후 분리 또는 Bluetooth 다시 연결
Magic Keyboard전원·충전·연결 키 입력케이블 페어링 또는 Bluetooth 재연결
일반 Bluetooth 마우스페어링 버튼·기기 채널·배터리제조사 안내에 따라 페어링 모드
USB 수신기 전용 마우스Bluetooth 지원 여부USB 수신기를 Mac에 연결
멀티페어링 키보드선택 중인 1·2·3 채널올바른 채널로 전환 후 Mac에서 연결

멀티페어링 장치는 다른 기기 채널에 연결된 채로 Mac에서만 찾는 경우가 많습니다. 기기 스위치를 바꿔 놓은 것은 아닌지 먼저 확인하세요.

8~10분 — 시스템 재확인

  • Mac 재시동
  • Bluetooth 전체가 계속 실패하는지 확인
  • 해당 기기 제조사 또는 Apple 지원 문서 확인

시간은 자가 점검을 위한 예시이며 문제 해결을 보장하는 공식 소요시간은 아닙니다.

14. 자주 묻는 질문 FAQ

Q1. 맥북에서 블루투스 기기가 목록에 아예 안 나옵니다.

기기 전원·배터리·페어링 모드를 먼저 확인하세요. 다른 휴대폰이나 컴퓨터에 연결돼 있으면 해당 연결을 해제하고 Mac의 시스템 설정 → Bluetooth → 근처 기기를 다시 확인합니다.

Q2. Magic Mouse가 갑자기 안 됩니다. 어떻게 연결하나요?

전원을 껐다가 다시 켜고 충전 상태를 확인하세요. 지원 케이블로 Mac과 약 1분 연결한 다음 분리해 자동 페어링되는지 확인할 수 있습니다.

Q3. 에어팟은 연결됐는데 맥북 스피커에서 소리가 나옵니다.

시스템 설정 → 사운드 → 출력에서 AirPods을 선택하세요. 화상회의 앱에서만 문제가 생기면 앱의 스피커·마이크 설정도 확인합니다.

Q4. 에어팟이 아이폰으로 자꾸 자동 연결됩니다.

같은 Apple 계정의 여러 기기 간 자동 전환 기능일 수 있습니다. Mac의 Bluetooth → AirPods 정보 → 이 Mac에 연결 옵션을 확인하세요.

Q5. 블루투스 마우스가 자꾸 끊기고 커서가 튑니다.

Apple은 USB 3·Thunderbolt 3 장치, 2.4GHz 무선 간섭, 금속 장애물 등을 원인으로 안내합니다. USB 허브를 분리하거나 위치를 옮긴 뒤 증상을 비교해 보세요.

Q6. '이 기기 지우기'를 누르면 데이터가 삭제되나요?

이는 Mac의 Bluetooth 페어링 등록을 지우는 기능입니다. 일반적인 문서파일을 삭제하는 기능은 아니지만 해당 액세서리를 다시 페어링해야 할 수 있으므로 현재 유일한 입력장치를 지울 때 주의해야 합니다.

Q7. 연결 버튼을 누르면 숫자를 입력하라고 나옵니다.

Bluetooth 키보드를 처음 페어링할 때 화면의 숫자 코드를 연결하려는 키보드에서 입력하고 Enter를 눌러야 하는 경우가 있습니다. 화면의 안내를 확인하세요.

Q8. 블루투스 스위치를 껐다 켤 수 없습니다.

Mac을 재시동하고 외장 Bluetooth 어댑터 유무를 확인하세요. Apple은 Bluetooth 입력장치만 있는 데스크톱 Mac 등 일부 환경에서 Bluetooth를 끌 수 없다고 안내합니다.

Q9. AirPods 4·5도 케이스 뒷면 버튼을 눌러야 하나요?

모델마다 다릅니다. Apple 공식 안내에 따르면 AirPods 4·5와 AirPods Pro 3 등은 케이스 앞면 두 번 탭을 사용하며, 다른 모델들은 뒷면 설정 버튼을 이용할 수 있습니다.

Q10. 맥북 블루투스 문제 때문에 macOS를 초기화해야 하나요?

대부분의 초기 점검에서 초기화는 우선 조치가 아닙니다. Bluetooth 설정, 페어링, 장치 전원, 사운드 출력, 간섭, 재시동을 먼저 확인하세요. 계속 실패하면 Apple 지원에 하드웨어·시스템 진단을 요청하는 편이 안전합니다.
