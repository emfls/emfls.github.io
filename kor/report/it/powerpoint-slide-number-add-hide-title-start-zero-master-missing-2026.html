2026 PPT 슬라이드 번호 넣기: 표지 제외·2장부터 1·번호 안 보임·2/12 표시

핵심 요약 (Key Takeaways)
  • 파워포인트 2026 버전에서 슬라이드 번호는 자동 삽입 기능을 사용하며, 표지 슬라이드 번호 숨기기와 2장부터 1번 시작 설정이 가능하다.
  • 번호가 보이지 않거나 2/12 형식 표시 문제는 슬라이드 마스터의 바닥글 표시 상태와 시작 번호 설정을 반드시 점검해야 한다.
  • ‘모두 적용’ 버튼을 누르고, 디자인 → 슬라이드 크기 → 사용자 지정에서 시작 번호를 0으로 설정하면 표지 제외 후 2장부터 1번 번호 표시가 완성된다.

회사 발표자료, 수업용 강의안, 제안서에서 파워포인트(PPT) 슬라이드 번호를 일일이 입력하면 장수를 추가하거나 순서를 바꿀 때 다시 수정해야 합니다. PowerPoint에는 번호를 자동으로 삽입하는 기능이 있으며, 표지에서만 숨기거나 번호 시작값을 변경할 수 있습니다.

회사 발표자료, 수업용 강의안, 제안서에서 파워포인트(PPT) 슬라이드 번호를 일일이 입력하면 장수를 추가하거나 순서를 바꿀 때 다시 수정해야 합니다. PowerPoint에는 번호를 자동으로 삽입하는 기능이 있으며, 표지에서만 숨기거나 번호 시작값을 변경할 수 있습니다.

그런데 삽입 → 슬라이드 번호 → 모두 적용을 했는데도 숫자가 나타나지 않거나, 제목 슬라이드를 제외했는데 두 번째 슬라이드가 2로 표시되어 혼란스럽기도 합니다. 이런 경우에는 단순한 번호 삽입 설정 외에 슬라이드 마스터·레이아웃의 바닥글 표시 상태를 점검해야 합니다.

이 글은 Microsoft 공식 지원 문서를 기준으로 Windows용 Microsoft 365 PowerPoint·PowerPoint 2024를 중심으로 작성했습니다. Mac·웹용 PowerPoint에서도 가능한 기능을 구분하고, 특히 '2/12'처럼 현재 장수와 전체 장수를 함께 표시하는 작업은 전체 장수가 자동 갱신되는 기능이 아니라는 점까지 설명합니다.

2. PPT 모든 슬라이드에 자동 번호 넣는 방법

PowerPoint 데스크톱 앱에서는 다음 순서로 진행합니다.

  1. 번호를 넣을 PPTX 파일을 열고 원본을 복사해 보관합니다.
  2. 상단 메뉴의 삽입 탭을 클릭합니다.
  3. 슬라이드 번호를 선택합니다. 버전에 따라 머리글/바닥글에서 열 수도 있습니다.
  4. 나타나는 대화 상자에서 슬라이드 탭을 확인합니다.
  5. 슬라이드 번호 항목을 체크합니다.
  6. 모두 적용을 클릭합니다.
  7. 표지·중간·마지막 슬라이드를 확인해 번호가 표시되는지 검수합니다.

'적용'과 '모두 적용'의 차이를 기억하세요. '적용'은 선택한 슬라이드에 설정을 적용하며, '모두 적용'은 프레젠테이션의 모든 슬라이드에 해당 설정을 적용합니다.

슬라이드 번호를 숫자로 직접 입력한 텍스트 상자와 혼동하면 안 됩니다. PowerPoint의 자동 슬라이드 번호 자리 표시자를 사용해야 슬라이드의 순서가 바뀌어도 해당 번호가 업데이트됩니다.

공식 출처: Microsoft — 슬라이드 번호 또는 날짜와 시간 추가

3. 첫 번째 표지 슬라이드에서 번호만 숨기기

일반적인 발표자료에서는 표지에 슬라이드 번호를 표시하지 않고, 목차나 본문부터 번호를 보여 주기도 합니다.

  1. 삽입 → 슬라이드 번호를 선택합니다.
  2. 슬라이드 번호를 체크합니다.
  3. 제목 슬라이드에 표시 안 함 항목을 체크합니다.
  4. 모두 적용을 누릅니다.
  5. 첫 번째 표지에 번호가 없는지, 두 번째 슬라이드부터 번호가 보이는지 확인합니다.

주의할 점: 표지의 번호를 숨긴다고 해서 실제 첫 장이 계산에서 자동으로 빠지는 것은 아닙니다. 일반적인 기본 시작값이 1이면 두 번째 슬라이드에는 2가 나타날 수 있습니다.

또한 제목 슬라이드에 표시하지 않는 옵션은 제목 슬라이드의 표시 설정에 따라 동작하므로, 사용하는 템플릿의 레이아웃과 실제 결과를 함께 확인해야 합니다.

공식 출처: Microsoft — 시작 슬라이드 번호 변경

4. 표지는 숨기고 두 번째 장부터 1로 표시하는 방법

사용자가 자주 원하는 형태는 실제로 두 번째 슬라이드인데 화면에는 숫자 1을 표시하는 방식입니다.

실제 순서슬라이드 내용화면에 보이는 번호
1표지없음
2회사 소개1
3주요 사업2
4매출 현황3

이 결과를 만들려면 표지 번호 숨김과 첫 번째 슬라이드의 시작 번호 설정을 함께 적용합니다.

  1. 앞 절대로 제목 슬라이드에 표시 안 함을 설정합니다.
  2. 상단 디자인 → 슬라이드 크기 → 사용자 지정 슬라이드 크기로 이동합니다.
  3. 대화 상자의 슬라이드 번호 시작(Number slides from) 상자를 찾습니다.
  4. 시작값에 0을 입력할 수 있는지 확인하고 지정합니다.
  5. 확인한 뒤 전체 슬라이드에서 번호가 어떻게 표시되는지 검증합니다.
  6. 두 번째 장에서 숫자 1이 보이면 목표와 일치합니다.

설명: 시작값 0은 표지의 번호 계산을 0으로 시작하게 하며, 표지 자체는 표시하지 않도록 설정해 두었으므로 두 번째 슬라이드에 1이 나타나는 구조입니다.

버전별 주의: 시작값 입력 가능 범위나 레이아웃 설정이 다르다면 현재 앱에서 제공하는 옵션을 확인해야 합니다. 번호를 1로 맞추려고 각 슬라이드에 숫자 1·2·3을 직접 타이핑하는 방식은 권장하지 않습니다.

공식 출처: Microsoft — 시작 슬라이드 번호 변경

5. 슬라이드 번호를 넣었는데 안 보일 때: 먼저 확인할 세 가지

슬라이드 번호 체크 후 모두 적용까지 했는데 표시되지 않는다면 다음 세 가지부터 확인하세요.

① 모두 적용을 눌렀는가?

현재 한 장만 선택한 상태에서 적용을 누른 경우 다른 슬라이드에는 번호가 나타나지 않을 수 있습니다. 다시 머리글/바닥글 대화 상자를 열고 모두 적용을 선택합니다.

② 제목 슬라이드만 숨기는 상태인가?

표지에만 번호가 보이지 않는다면 제목 슬라이드에 표시 안 함을 체크했는지 확인합니다. 표지 번호만 없는 것이 의도된 결과일 수 있습니다.

③ 슬라이드 마스터에서 바닥글이 꺼져 있는가?

여러 장에서 번호가 모두 보이지 않거나 특정 레이아웃에서만 빠진다면 보기 → 슬라이드 마스터로 이동해 바닥글 자리 표시자 상태를 확인해야 합니다.

Microsoft는 슬라이드 번호·날짜를 추가했지만 보이지 않는 흔한 원인으로 슬라이드 마스터 보기에서 바닥글이 꺼져 있는 경우를 안내합니다.

공식 출처: Microsoft — PowerPoint 바닥글 문제 해결

6. 마스터 때문에 번호가 안 나올 때: 바닥글 다시 켜기

특정 슬라이드나 테마에서만 숫자가 보이지 않는다면 해당 슬라이드가 사용하는 레이아웃의 바닥글을 확인하세요.

  1. 번호가 빠진 슬라이드를 선택합니다.
  2. 보기 → 슬라이드 마스터를 엽니다.
  3. 왼쪽 목록에서 해당 슬라이드에 적용되는 레이아웃을 확인합니다.
  4. 슬라이드 마스터 탭의 마스터 레이아웃에서 바닥글(Footers) 옵션을 확인합니다.
  5. 필요하다면 바닥글 표시를 켭니다.
  6. 그래도 자리 표시자가 보이지 않으면 상위 슬라이드 마스터의 바닥글 자리 표시자도 확인합니다.
  7. 마스터 보기 닫기로 일반 보기로 돌아갑니다.
  8. 다시 삽입 → 슬라이드 번호 → 모두 적용을 확인합니다.

중요: 슬라이드 마스터에서 바닥글 자리 표시자가 보인다고 자동으로 번호가 켜지는 것은 아닙니다. Microsoft는 삽입 → 머리글/바닥글에서 번호를 활성화해야 실제 슬라이드에 표시된다고 설명합니다.

특정 레이아웃에만 누락된다면 같은 마스터를 쓰는 다른 레이아웃과 바닥글 설정을 비교하면 원인을 좁히기 쉽습니다.

공식 출처: Microsoft — 바닥글 문제 해결

7. 슬라이드 번호의 위치·글자 크기·색상 바꾸는 방법

슬라이드 번호가 너무 작거나 이미지 위에 겹쳐 잘 보이지 않는다면 마스터에서 서식을 수정하는 방법을 검토하세요.

  1. 원본 파일을 복사합니다.
  2. 보기 → 슬라이드 마스터를 엽니다.
  3. 왼쪽 맨 위의 슬라이드 마스터 또는 번호가 표시될 특정 레이아웃을 선택합니다.
  4. 숫자 자리 표시자를 선택합니다.
  5. 번호를 원하는 위치로 이동하거나 글꼴·크기·색상을 변경합니다.
  6. 마스터 보기 닫기를 누릅니다.
  7. 실제 일반 슬라이드에서 번호가 새 위치에 표시되는지 확인합니다.

전체 수정과 특정 레이아웃 수정의 차이: 상위 슬라이드 마스터에서 변경하면 해당 마스터를 따르는 레이아웃에 영향을 줄 수 있습니다. 특정 레이아웃에서 바닥글을 개별 설정했다면 그 설정이 우선할 수 있습니다.

외부 회사 템플릿처럼 여러 슬라이드 마스터를 사용하는 문서도 있습니다. 어떤 마스터에 소속된 레이아웃인지 확인해야 원하는 슬라이드에 정확하게 반영할 수 있습니다.

공식 출처: Microsoft — PowerPoint 슬라이드 바닥글의 글꼴 변경

8. 한 장만 번호를 표시하거나 특정 슬라이드만 숨기는 방법

모든 슬라이드에 번호를 표시하지 않고 일부 장에만 넣고 싶다면 적용과 모두 적용을 구분해 사용합니다.

선택한 한 장에만 표시

  1. 해당 슬라이드를 선택합니다.
  2. 삽입 → 슬라이드 번호를 엽니다.
  3. 슬라이드 번호를 체크합니다.
  4. 적용을 눌러 그 슬라이드에만 반영합니다.
  5. 다른 슬라이드에는 번호가 없는지 확인합니다.

이미 번호가 있는 특정 장에서 숨기기

  1. 숨길 슬라이드를 선택합니다.
  2. 삽입 → 슬라이드 번호를 엽니다.
  3. 슬라이드 번호 체크를 해제합니다.
  4. 적용을 누릅니다.
  5. 나머지 슬라이드의 번호 상태를 확인합니다.

제한: 마스터에 별도의 일반 텍스트 상자로 숫자를 직접 입력했다면 머리글/바닥글 대화 상자에서 숫자를 제어할 수 없을 수 있습니다. 그런 경우 마스터의 텍스트 개체를 먼저 확인하세요.

공식 출처: Microsoft — 시작 슬라이드 번호 변경

9. 슬라이드 번호 2/12 형식 만들기: 총장수는 자동이 아닙니다

발표 자료의 오른쪽 아래에 2/12, 3/12처럼 '현재 장/전체 장수'를 표시하고 싶은 경우가 있습니다.

PowerPoint는 자동 슬라이드 번호는 넣을 수 있지만, Microsoft 공식 안내에 따르면 전체 슬라이드 개수는 자동으로 표시·갱신되지 않습니다. 이 기능은 Word의 '현재 쪽/전체 쪽'과 동작 방식이 다릅니다.

Windows에서 슬라이드 마스터를 활용하는 방법

  1. 왼쪽 슬라이드 목록이나 상태 표시줄에서 전체 슬라이드 수를 확인합니다.
  2. 보기 → 슬라이드 마스터를 엽니다.
  3. 상위 마스터를 선택하고 필요한 위치에 텍스트 상자를 만듭니다.
  4. 텍스트 상자 안에 커서를 놓습니다.
  5. 삽입 → 슬라이드 번호 기능으로 자동 번호 필드를 삽입합니다.
  6. 번호 뒤에 슬래시와 전체 장수, 예를 들어 /12를 일반 문자로 입력합니다.
  7. 마스터 보기를 닫고 각 슬라이드에서 1/12, 2/12…가 표시되는지 확인합니다.

가장 중요한 제한: 나중에 슬라이드를 한 장 더 추가해 13장이 되더라도 뒤쪽의 /12는 자동으로 /13으로 바뀌지 않습니다. 반드시 마스터에서 전체 장수를 직접 수정해야 합니다.

이미 사용 중인 슬라이드 번호 자리 표시자가 있다면 새로 추가한 텍스트 상자와 번호가 중복될 수 있으니 기존 개체와 함께 확인하세요.

공식 출처: Microsoft — 모든 슬라이드에 슬라이드 번호와 전체 장수 표시

10. 웹용 PowerPoint에서 슬라이드 번호 추가하기

브라우저에서 OneDrive 파일을 편집하는 웹용 PowerPoint에서도 슬라이드 번호 기능을 사용할 수 있습니다.

Microsoft 공식 문서는 다음과 같은 흐름을 안내합니다.

  1. 웹용 PowerPoint에서 프레젠테이션을 편집 가능한 상태로 엽니다.
  2. 메뉴에서 삽입 → 바닥글 영역을 찾습니다.
  3. 슬라이드 번호를 선택하거나 바닥글 창에서 번호 옵션을 켭니다.
  4. 제목 슬라이드에 표시하지 않음 등 필요한 옵션을 설정합니다.
  5. 모두 적용을 선택합니다.
  6. 실제 슬라이드의 표시 위치와 숫자를 확인합니다.

웹용 PowerPoint는 데스크톱 앱과 메뉴의 배열이 같지 않을 수 있습니다. 어떤 디자인에서는 바닥글 자리 표시자가 슬라이드 아래가 아니라 옆쪽 등 다른 위치에 나타날 수 있다고 Microsoft가 안내합니다.

주의: 웹용에서 기본 번호 설정은 가능하지만, 복잡한 마스터 편집이나 특수한 번호 배치를 하려는 경우에는 데스크톱 PowerPoint에서 세부 레이아웃을 수정하는 편이 적합할 수 있습니다.

공식 출처: Microsoft — 웹용 PowerPoint 바닥글 및 슬라이드 번호

11. Mac용 PowerPoint에서 번호가 안 보일 때

Mac에서도 자동 슬라이드 번호를 추가하고 제목 슬라이드에서 숨기거나 위치를 바꾸는 기능을 지원합니다.

  1. Mac용 PowerPoint에서 문서를 엽니다.
  2. 삽입 → 슬라이드 번호 또는 해당 버전의 머리글/바닥글 메뉴를 찾습니다.
  3. 슬라이드 번호를 켜고 모두 적용을 선택합니다.
  4. 표지 숨김 옵션이 필요한 경우 설정합니다.
  5. 일부 슬라이드에만 누락된다면 보기 → 슬라이드 마스터에서 해당 레이아웃의 바닥글을 확인합니다.

Windows와 Mac은 리본 메뉴가 완전히 동일하지 않을 수 있습니다. 현재 사용 중인 버전의 실제 메뉴를 기준으로 진행해야 합니다.

권장 점검: 번호를 수정한 후 발표용 Mac 화면에서만 확인하지 말고, 프레젠테이션을 열 다른 컴퓨터에서도 슬라이드 번호가 표시되는지 검증하세요.

12. 슬라이드 번호와 유인물 페이지 번호는 다릅니다

화면에 표시되는 슬라이드 번호와 인쇄할 때 쓰이는 유인물 페이지 번호는 다른 개념입니다.

예를 들어 PPTX가 12장이지만 한 장의 종이에 슬라이드를 4개씩 묶어 인쇄하면, 종이는 3장이 될 수 있습니다. 발표용 슬라이드 안에 보이는 번호와 종이의 페이지 번호가 같은 방식으로 표시되는 것은 아닙니다.

두 가지를 구분하세요.

  • 슬라이드 번호: 발표 화면의 슬라이드 순서와 연관
  • 유인물 페이지 번호: 인쇄된 유인물의 페이지 구분과 연관

Microsoft 공식 도움말도 화면 슬라이드의 번호와 유인물·슬라이드 노트의 머리글/바닥글 정보를 별도로 안내합니다.

실무 팁: 교육 자료를 배포한다면 슬라이드 쇼에서 번호가 제대로 보이는지와 인쇄 미리 보기에서 유인물 페이지 정보가 어떻게 나타나는지를 각각 확인하세요.

13. 번호를 지우거나 모두 해제하는 방법

슬라이드 번호를 더 이상 사용하지 않거나 디자인을 바꿨을 때 제거하는 절차입니다.

전체 슬라이드 번호 제거

  1. 삽입 → 슬라이드 번호를 엽니다.
  2. 슬라이드 번호 체크를 해제합니다.
  3. 모두 적용을 선택합니다.
  4. 번호가 모든 슬라이드에서 사라졌는지 확인합니다.

특정 슬라이드에서만 제거

  1. 해당 슬라이드를 선택합니다.
  2. 삽입 → 슬라이드 번호를 엽니다.
  3. 슬라이드 번호 체크를 해제하고 적용합니다.
  4. 다른 장의 번호가 유지되는지 확인합니다.

예외: 마스터에서 직접 입력한 숫자나 사용자 지정 텍스트 상자는 위 메뉴로 지워지지 않을 수 있습니다. 해당 개체가 자동 번호 필드인지, 일반 텍스트인지 구별하세요.

14. 번호를 넣었는데 특정 슬라이드에서만 보이지 않을 때 체크리스트

증상먼저 점검할 것조치
표지에만 번호 없음제목 슬라이드에 표시 안 함원하면 체크 해제
일부 레이아웃만 번호 누락해당 레이아웃의 바닥글 설정슬라이드 마스터에서 바닥글 활성화
모든 장에서 번호 누락슬라이드 번호 체크·모두 적용 여부대화 상자에서 다시 활성화
번호가 다른 위치에 있음테마·마스터 자리 표시자마스터 위치 조정
번호를 지웠는데 일부 남음일반 텍스트로 넣은 숫자마스터 또는 슬라이드 텍스트 확인
번호가 0부터 표시됨슬라이드 번호 시작값디자인 → 사용자 지정 슬라이드 크기 확인

문제 해결 순서: 삽입 대화 상자 확인 → 모두 적용 → 제목 슬라이드 제외 여부 → 마스터의 바닥글 자리 표시자 → 마스터 위치 및 서식 순으로 진행하면 원인 구분에 도움이 됩니다.

15. 실제 발표 자료 10장으로 최종 검산하기

다음 10장짜리 가상 사업 발표 자료를 만든다고 가정하겠습니다.

실제 슬라이드예시 내용표지 숨김 + 0부터 시작 시 보이는 번호
1표지없음
2목차1
3회사 개요2
4사업 현황3
5시장 분석4
6경쟁사 분석5
7운영 계획6
8비용7
9기대 효과8
10결론9

이 예시의 목적은 '실제 파일에서 몇 번째 슬라이드인지'와 '화면에 표시할 숫자'가 다를 수 있다는 점을 이해하는 것입니다.

5단계 검수

  1. 표지에 번호가 없는지 확인합니다.
  2. 두 번째 슬라이드의 번호가 1인지 확인합니다.
  3. 5~6번째 슬라이드 중간에도 순서대로 표시되는지 검토합니다.
  4. 마지막 슬라이드에 번호 9가 표시되는지 확인합니다.
  5. 슬라이드를 한 장 추가해 번호가 자동으로 다시 계산되는지 시험합니다.

주의: 번호에 /10 같은 전체 장수를 함께 넣었다면 슬라이드를 추가한 뒤 /11로 직접 수정해야 합니다. 현재 슬라이드 번호가 자동으로 늘어나는 것과 전체 장수가 자동으로 반영되는 것은 별개입니다.

16. 자주 묻는 질문

Q. 파워포인트에서 슬라이드 번호를 한 번에 넣으려면?

삽입 → 슬라이드 번호 → 슬라이드 번호 체크 → 모두 적용을 선택하면 됩니다.

Q. PPT 첫 장 표지에만 번호를 숨기려면?

슬라이드 번호 설정에서 제목 슬라이드에 표시 안 함을 체크하고 모두 적용합니다.

Q. 2번째 슬라이드부터 1로 시작할 수 있나요?

표지 번호를 숨기고 디자인 → 슬라이드 크기 → 사용자 지정 슬라이드 크기에서 시작값 0을 설정하는 방법을 검토하세요.

Q. 모든 슬라이드 번호가 안 보이는 이유는?

'모두 적용' 여부를 먼저 확인하세요. 설정이 맞는데도 표시되지 않는다면 슬라이드 마스터에서 바닥글이 꺼져 있는지 확인합니다.

Q. 특정 레이아웃에만 번호가 안 보입니다.

해당 레이아웃의 바닥글 자리 표시자가 비활성화돼 있을 수 있습니다. 보기 → 슬라이드 마스터에서 그 레이아웃을 확인하세요.

Q. 2/12 형식을 자동으로 만들 수 있나요?

현재 슬라이드 번호는 자동 삽입할 수 있지만 전체 슬라이드 수 '12'는 수동으로 입력해야 합니다. 슬라이드를 추가하거나 삭제하면 전체 장수를 직접 고쳐야 합니다.

Q. 웹용 PowerPoint에서도 번호를 넣을 수 있나요?

네. Microsoft 공식 안내에 따르면 웹용 PowerPoint에서도 바닥글과 슬라이드 번호를 삽입할 수 있습니다. 다만 메뉴 위치는 데스크톱과 다를 수 있습니다.

Q. PowerPoint와 Word의 페이지 번호 설정이 같은가요?

아닙니다. PowerPoint는 슬라이드 번호와 슬라이드 마스터를 중심으로 설정하며, Word는 구역 나누기와 머리글/바닥글 페이지 번호를 다루는 방식이 다릅니다.

17. 최종 체크리스트

  • ☐ 슬라이드 번호를 직접 타이핑하지 않고 자동 번호 기능을 사용했다.
  • ☐ 적용/모두 적용을 구분했다.
  • ☐ 표지를 숨기려면 제목 슬라이드 표시 설정을 확인했다.
  • ☐ 두 번째 장을 1로 만들고 싶다면 시작값을 점검했다.
  • ☐ 번호가 사라진 경우 슬라이드 마스터의 바닥글을 확인했다.
  • ☐ 번호 위치·색상·크기를 전체 화면에서 확인했다.
  • ☐ 전체 장수 /12를 넣었다면 수동 관리가 필요함을 확인했다.
  • ☐ 최종 슬라이드 개수와 번호를 다시 대조했다.

결론: PPT 슬라이드 번호는 삽입 → 슬라이드 번호 → 모두 적용이 출발점입니다. 표지만 숨길 때는 제목 슬라이드에 표시 안 함, 번호가 안 보일 때는 슬라이드 마스터의 바닥글, 두 번째 슬라이드를 1로 시작할 때는 시작 번호 설정을 확인하세요. 2/12처럼 전체 장수를 덧붙이는 경우에는 총장수 자동 갱신을 지원하지 않는다는 제한도 반드시 기억해야 합니다.

자주 묻는 질문 (FAQ)

파워포인트에서 슬라이드 번호를 자동으로 넣는 방법은 무엇인가요?

삽입 탭에서 슬라이드 번호를 선택하고, 슬라이드 번호 항목을 체크한 뒤 '모두 적용'을 클릭하면 모든 슬라이드에 자동 번호가 삽입됩니다.

표지 슬라이드에만 번호를 숨기고 두 번째 슬라이드부터 1번으로 시작하려면 어떻게 해야 하나요?

슬라이드 번호 삽입 시 '제목 슬라이드에 표시 안 함'을 체크하고, 디자인 → 슬라이드 크기 → 사용자 지정에서 시작 번호를 0으로 설정하면 됩니다.

슬라이드 번호가 삽입되었는데 화면에 보이지 않을 때는 어떻게 해결하나요?

먼저 '모두 적용'을 눌렀는지 확인하고, 제목 슬라이드 번호 숨김 설정과 슬라이드 마스터에서 바닥글 자리 표시자가 켜져 있는지 점검해야 합니다.
