인터넷에서 ‘내 IP 주소’를 검색했는데 윈도우 설정에 보이는 숫자와 다르다면 오류가 아닐 수 있습니다. 인터넷에서 보이는 공인 IP와 집·회사 내부에서 기기에 배정된 사설 IP가 서로 다르기 때문입니다. 이 글에서는 윈도우11, 갤럭시, 아이폰에서 IP 주소를 확인하고 두 숫자가 왜 다른지 구분하는 방법을 설명합니다.

핵심만 먼저 확인

  • 공인 IP 확인: 해당 기기에서 웹브라우저를 열고 검색창에 ‘내 IP’ 또는 ‘what is my IP’를 입력합니다. 확인 페이지의 운영자·개인정보 정책을 살펴보고 이용하세요.
  • 윈도우11 사설 IP 확인: 설정 → 네트워크 및 인터넷 → Wi-Fi(또는 이더넷) → 현재 연결된 네트워크 → IPv4 주소.
  • 갤럭시·아이폰 사설 IP 확인: 설정 → Wi-Fi → 현재 연결한 네트워크의 상세정보에서 IP 주소를 확인합니다.
  • 주의: 명령 프롬프트의 ipconfig에 표시되는 IPv4 주소는 일반적인 가정용 공유기 환경에서는 공인 IP가 아니라 내부 IP입니다.

1. 공인 IP와 사설 IP, 무엇을 확인해야 할까요?

공인 IP(Public IP)는 인터넷상의 외부 서비스에 연결할 때 보이는 주소입니다. 사설 IP(Private IP)는 가정·사무실 등 내부 네트워크에서 장치끼리 구분하는 주소입니다.

확인 목적확인해야 할 주소예시주로 확인하는 위치
외부 사이트에 보이는 내 주소공인 IP인터넷 회선·VPN에 따라 다름웹브라우저의 IP 확인 서비스
집 공유기에 연결한 컴퓨터 주소사설 IP192.168.0.25윈도우 네트워크 속성
같은 Wi-Fi에 연결한 휴대전화 주소사설 IP192.168.0.37휴대전화 Wi-Fi 상세정보
공유기 설정 페이지 주소기본 게이트웨이192.168.0.1네트워크 속성·공유기 안내
사이트 접속·도메인 조회에 사용하는 서버DNS 서버 주소환경별로 다름네트워크 세부 설정

가정에서는 휴대전화와 노트북의 사설 IP가 서로 달라도, 같은 공유기를 통해 인터넷에 접속하면 외부 서비스에서는 동일한 공인 IPv4 주소로 보일 수 있습니다. 통신사가 제공하는 회선 구조, IPv6, 프록시, VPN에 따라 예외가 있습니다.

2. 내 공인 IP 주소 가장 쉽게 확인하기

컴퓨터와 스마트폰 모두 다음 순서가 간단합니다.

  1. 공인 IP를 확인할 기기와 네트워크를 먼저 정합니다.
  2. Chrome·Safari·Edge 등 브라우저를 실행합니다.
  3. 검색창에 ‘내 IP 확인’ 또는 ‘what is my IP’라고 입력합니다.
  4. 검색엔진의 표시 또는 신뢰할 수 있는 IP 확인 사이트에서 IPv4 또는 IPv6 값을 확인합니다.
  5. VPN을 사용 중이라면 VPN 연결 상태를 함께 기록합니다.

중요: IP 확인 웹사이트에는 방문자의 접속 IP가 전달됩니다. 회사 네트워크나 민감한 업무 환경이라면 검증되지 않은 IP 확인 앱을 설치하거나, 불필요한 부가 정보를 요구하는 사이트를 이용하지 마세요.

와이파이를 껐다 켜면 IP가 달라지나요?

반드시 그렇지는 않습니다. 휴대전화가 같은 공유기에 다시 연결되면 내부 IP는 그대로 유지되거나 변경될 수 있습니다. 공인 IP도 통신사 할당 정책과 회선 구성에 따라 유지되거나 바뀝니다. 단순히 Wi-Fi를 다시 켠다고 공인 IP가 반드시 변경되는 것은 아닙니다.

모바일 데이터와 Wi-Fi에서 주소가 다르게 보이는 이유

휴대전화에서 Wi-Fi 연결 상태와 5G/LTE 모바일 데이터 상태로 같은 사이트를 접속하면 통신 경로가 달라지므로 공인 IP도 달라질 수 있습니다. 다만 이동통신사는 여러 사용자가 공인 IP를 공유하는 네트워크 구성을 적용할 수 있으므로 한 IP가 특정 사용자 한 명에게 고정돼 있다고 해석하면 안 됩니다.

3. 윈도우11에서 IP 주소 확인하기: 설정 앱

Microsoft의 공식 Windows 안내에 제시된 방법입니다.

  1. 시작 → 설정을 엽니다.
  2. 네트워크 및 인터넷으로 이동합니다.
  3. 무선 인터넷이면 Wi-Fi → 현재 연결된 네트워크를 선택합니다.
  4. 랜선을 연결한 컴퓨터라면 이더넷을 선택합니다.
  5. 네트워크의 속성에서 IPv4 주소를 확인합니다.
  6. 필요하면 IPv6 주소·기본 게이트웨이·DNS 서버도 함께 살펴봅니다.

예를 들어 IPv4 주소가 192.168.0.25라면 일반적인 공유기 환경에서 사용 중인 내부 사설 IP입니다. 이 숫자를 인터넷 서비스에 노출되는 공인 IP로 혼동하지 마세요.

설정 메뉴에 Wi-Fi가 없다면?

데스크톱 PC가 랜선으로 연결되어 있다면 이더넷을 확인하세요. Wi-Fi 자체가 꺼져 있거나 무선 랜카드가 없는 PC에서는 Wi-Fi 연결 항목이 보이지 않을 수 있습니다.

4. 윈도우11 명령 프롬프트에서 ipconfig 사용하기

설정 화면이 열리지 않거나 연결 정보를 한눈에 보고 싶다면 명령어가 편리합니다.

  1. 작업 표시줄 검색에서 cmd 또는 명령 프롬프트를 찾습니다.
  2. 일반 명령 프롬프트를 실행합니다.
  3. 다음 명령을 입력하고 Enter를 누릅니다.
ipconfig
  1. 실제로 사용 중인 무선 LAN 어댑터 Wi-Fi 또는 이더넷 어댑터 아래에서 IPv4 주소를 찾습니다.
  2. 기본 게이트웨이는 해당 네트워크에서 다른 네트워크로 나갈 때 사용하는 게이트웨이 주소를 의미합니다.

더 자세한 정보가 필요하다면 다음 명령을 사용합니다.

ipconfig /all

추가 출력에는 물리적 주소(MAC), DHCP 사용 여부, DNS 정보 등이 포함될 수 있습니다.

주의: VPN·가상 머신·Bluetooth 네트워크 등 여러 어댑터가 있으면 IP가 여러 개 표시됩니다. 현재 인터넷 연결에 사용하는 어댑터를 기준으로 읽어야 합니다. 그리고 ipconfig 출력 자체로 외부 사이트에 보이는 공인 IP를 확정할 수는 없습니다.

5. 갤럭시에서 현재 Wi-Fi IP 주소 확인하기

삼성 갤럭시의 일반적인 메뉴 흐름은 다음과 같습니다.

  1. 설정 → 연결 → Wi-Fi로 이동합니다.
  2. 현재 연결된 와이파이 이름 옆의 톱니바퀴(설정)를 누릅니다.
  3. 네트워크 상세정보에서 IP 주소 또는 IP 설정 항목을 확인합니다.
  4. 일부 One UI 버전에서는 더 보기·고급 메뉴를 펼쳐야 세부 정보가 나타날 수 있습니다.

여기에서 보이는 주소는 일반적으로 해당 Wi-Fi 네트워크가 갤럭시에 배정한 IP입니다. 휴대전화가 모바일 데이터로 접속할 때의 공인 IP와 구분해야 합니다.

주의: 공유기 주소를 확인하기 위해 ‘IP 설정’을 DHCP에서 고정으로 변경할 필요는 없습니다. 확인 목적만으로 네트워크 설정값을 수정하면 오히려 인터넷 연결이 끊길 수 있습니다.

6. 아이폰에서 IP 주소 확인하기

Apple 공식 안내에 따른 진입 경로는 설정 → Wi-Fi → 연결된 네트워크의 정보(i) 버튼입니다.

  1. 아이폰에서 설정을 엽니다.
  2. Wi-Fi를 선택합니다.
  3. 현재 연결된 네트워크 옆의 ⓘ를 누릅니다.
  4. 세부 정보 화면을 아래로 내려 IP 주소·서브넷 마스크·라우터 등을 확인합니다.
  5. 공인 IP가 필요하면 사파리에서 ‘내 IP’를 별도로 검색합니다.

‘비공개 Wi-Fi 주소’가 IP 주소인가요?

아닙니다. 비공개 Wi-Fi 주소는 Wi-Fi 네트워크에서 기기 추적을 줄이기 위한 MAC 주소 관련 기능입니다. 현재 네트워크의 IPv4 주소와는 다른 항목입니다.

‘IP 주소 추적 제한’을 켜면 주소가 아예 없어지나요?

아닙니다. Apple은 이 설정을 알려진 추적자에게 IP 주소를 숨기는 개인정보 보호 기능으로 설명합니다. 인터넷 통신에서 주소가 사라지는 것은 아니며, 사이트와 네트워크 구성에 따라 외부에서 보이는 IP가 달라질 수 있습니다.

7. 192.168로 시작하면 무조건 사설 IP인가요?

사설 IPv4 주소는 특정 범위로 정의되어 있습니다.

주소 범위구분알아둘 점
10.0.0.0 ~ 10.255.255.255사설 IPv4회사·기관 내부망에서도 흔히 사용
172.16.0.0 ~ 172.31.255.255사설 IPv4172로 시작하는 주소가 전부 사설은 아님
192.168.0.0 ~ 192.168.255.255사설 IPv4가정용 공유기에서 자주 사용
169.254.x.x자동 구성 주소DHCP로 주소를 받지 못한 상황에서 나타날 수 있음
100.64.0.0 ~ 100.127.255.255통신사 공유 주소 공간(CGNAT)일반적인 가정용 사설 범위와 별도

172.20.1.5는 사설 주소이지만 172.64.1.5는 위의 사설 범위가 아닙니다. 앞의 두 숫자를 포함한 실제 범위를 확인해야 합니다.

8. IP 주소가 169.254로 나오고 인터넷도 안 된다면

Microsoft는 Windows에서 169.254.x.x 주소가 보일 경우, 공유기에서 정상적인 IP를 할당받지 못했을 가능성을 점검하라고 안내합니다.

먼저 확인할 순서

  1. Wi-Fi가 실제 공유기에 연결된 상태인지 확인합니다.
  2. 다른 휴대전화에서도 같은 와이파이를 사용할 수 있는지 비교합니다.
  3. 공유기 또는 회사 네트워크의 DHCP 할당에 문제가 없는지 확인합니다.
  4. 윈도우의 IP·게이트웨이 정보를 다시 확인합니다.
  5. 회사·학교에서 고정 IP를 사용하는 경우에는 임의로 DHCP나 수동 IP를 바꾸기 전에 담당자에게 문의합니다.

주소만 확인하려던 상황이라면 네트워크 초기화나 수동 IP 변경을 먼저 실행하지 않는 것이 안전합니다. 연결 장애가 동반되었을 때만 문제 해결 절차를 검토하세요.

9. IP 주소가 자꾸 바뀌는 이유는?

상황주소가 바뀌는 대표 원인확인 포인트
공유기를 다시 켠 뒤 내부 IP 변경DHCP가 다른 주소를 할당윈도우·갤럭시·아이폰에서 사설 IP 재확인
인터넷 회선 재연결 후 공인 IP 변경통신사 주소 재할당브라우저에서 재조회
Wi-Fi에서 LTE·5G로 전환인터넷 접속 통신망 변경Wi-Fi 연결 상태
VPN 연결 후 사이트가 다른 IP 표시VPN 출구 서버 주소가 보임VPN 연결·국가·서버
같은 공유기인데 기기별 IP가 다름기기마다 사설 IP 별도 배정기기별 Wi-Fi 세부정보
IPv4와 IPv6가 함께 표시서로 다른 인터넷 주소 체계해당 서비스에서 표시하는 주소 종류

공인 IP가 달라졌다고 즉시 보안 사고로 판단할 필요는 없습니다. VPN을 켰는지, 네트워크를 바꿨는지, 정상적인 통신사 재할당이 있었는지를 먼저 확인하세요.

10. 공인 IP와 공유기 WAN IP가 다르면 문제가 있나요?

공유기 관리 화면의 인터넷·WAN 주소와 웹에서 확인한 공인 IP가 다를 수도 있습니다. 통신사에서 여러 회선을 공유하는 CGNAT, 상위 공유기가 하나 더 있는 이중 NAT, VPN·프록시 등을 사용하면 차이가 생길 수 있기 때문입니다.

확인할 때는 다음과 같이 비교합니다.

  1. 같은 인터넷 연결 상태에서 웹의 공인 IP를 적습니다.
  2. 본인에게 관리 권한이 있는 공유기에서 WAN 주소를 확인합니다.
  3. 둘이 다르다면 상위 공유기·CGNAT·VPN 등 네트워크 구성을 확인합니다.
  4. 외부에서 집 내부 장치에 직접 접속하거나 포트포워딩을 사용해야 하는 목적이라면 통신사·공유기 제조사의 공식 안내를 참고합니다.

주의: 공유기 WAN 주소가 공인 주소와 같다는 것만으로 외부에서 내 PC에 안전하게 접속할 수 있다는 의미는 아닙니다. 원격 접속 설정·방화벽·인증 등은 별도로 검토해야 합니다.

11. 내 IP 주소를 다른 사람에게 알려줘도 되나요?

IP 주소 하나만으로 누군가의 정확한 집 주소나 개인 신원이 즉시 확인되는 것은 아닙니다. 그러나 접속 기록의 연계, 통신망·대략적 지역 추정 등 개인정보 보호 측면의 고려가 필요합니다.

  • 공인 IP를 불필요하게 게시판이나 공개 댓글에 올리지 않습니다.
  • 고객센터·회사 네트워크 관리자에게 전달할 때는 공식 상담 창구인지 확인합니다.
  • 주소를 가리겠다고 출처가 불분명한 VPN 앱을 설치하지 않습니다.
  • 공유기·NAS·원격 데스크톱 설정 정보를 IP와 함께 공개하지 않습니다.
  • 계정 보안은 IP 변경보다 강력한 비밀번호·다단계 인증을 우선합니다.

12. 자주 묻는 질문

Q1. 네이버에서 ‘내 IP’를 검색한 값과 ipconfig 값이 다른데 정상인가요?

네. 브라우저 서비스는 외부에서 보이는 주소를, ipconfig는 컴퓨터 네트워크 어댑터의 주소를 보여주기 때문에 다를 수 있습니다.

Q2. 윈도우11에서 명령어 없이 IP를 볼 수 있나요?

네. 설정 → 네트워크 및 인터넷 → 연결된 Wi-Fi 또는 이더넷 → 속성 → IPv4 주소로 확인할 수 있습니다.

Q3. 아이폰은 Wi-Fi를 꺼도 IP 주소를 확인할 수 있나요?

Wi-Fi 연결의 내부 IP는 해당 네트워크에 연결돼 있을 때 확인하는 정보입니다. 모바일 데이터로 외부에서 보이는 IP를 알고 싶다면 Wi-Fi를 끈 상태에서 사파리의 IP 확인 페이지를 이용할 수 있습니다.

Q4. IP 주소 뒤의 /24는 무엇인가요?

192.168.0.25/24처럼 붙은 표기는 네트워크 범위를 나타내는 CIDR 접두사 길이입니다. 숫자 24가 IP 주소의 마지막 자리라는 뜻은 아닙니다.

Q5. IP 주소와 MAC 주소는 같나요?

아닙니다. IP 주소는 네트워크 통신에 사용하는 논리적 주소이고 MAC 주소는 네트워크 인터페이스 식별에 쓰이는 별도의 주소입니다. 아이폰의 '비공개 Wi-Fi 주소'는 후자와 관련 있습니다.

Q6. 같은 와이파이를 쓰는 가족은 공인 IP가 모두 같나요?

일반적인 가정용 IPv4 공유기에서는 같은 공인 IP로 보일 수 있습니다. 다만 VPN·프록시·모바일 데이터·IPv6 사용 방식에 따라 다르게 나타날 수 있습니다.

Q7. 내 공인 IP가 바뀌었으면 해킹당한 건가요?

IP 변경 자체만으로 해킹을 뜻하지 않습니다. 우선 네트워크 변경, VPN 사용, 통신사 재할당을 확인하세요. 동시에 낯선 로그인 알림 등 실제 계정 이상 징후가 있다면 별도로 점검해야 합니다.

마무리: 목적에 맞는 IP를 확인하세요

인터넷 사이트에 보이는 주소가 필요하면 공인 IP, 컴퓨터·휴대전화의 와이파이 연결 주소가 필요하면 사설 IP를 확인하세요. 윈도우11에서는 설정 → 네트워크 및 인터넷, 갤럭시·아이폰에서는 연결된 Wi-Fi의 상세정보가 출발점입니다. 서로 다른 숫자가 보이는 것은 공유기와 인터넷 연결 방식 때문에 자연스러운 경우가 많습니다.

자주 묻는 질문 (FAQ)

공인 IP와 사설 IP는 무엇이 다른가요?

공인 IP는 인터넷 상에서 외부 서비스에 연결할 때 보이는 주소이고, 사설 IP는 가정이나 회사 내부 네트워크에서 기기를 구분하기 위한 내부 주소입니다.

윈도우11에서 내 사설 IP 주소를 어떻게 확인하나요?

설정 → 네트워크 및 인터넷 → Wi-Fi(또는 이더넷) → 현재 연결된 네트워크 → IPv4 주소에서 확인할 수 있습니다.

내 공인 IP 주소를 가장 쉽게 확인하는 방법은 무엇인가요?

웹브라우저에서 ‘내 IP’ 또는 ‘what is my IP’를 검색해 신뢰할 수 있는 IP 확인 사이트에서 공인 IP를 확인하면 됩니다.
