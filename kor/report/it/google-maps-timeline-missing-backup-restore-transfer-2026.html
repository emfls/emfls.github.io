구글 지도 타임라인은 기기 자체에 방문 장소와 이동 경로를 저장하는 방식으로 운영됩니다. 구글 계정에 로그인했다고 예전 휴대폰의 기록이 새 휴대폰으로 무조건 나타나는 것은 아닙니다. 구글이 제공하는 암호화 백업을 만들어 두었는지와 원래 기기에 기록이 남아 있는지가 복구 가능성을 결정합니다.

핵심 결론: 예전 휴대폰이 아직 있다면 삭제·초기화하지 말고, 그 휴대폰에서 타임라인과 백업 상태부터 확인하세요. 새 휴대폰에서는 구글 지도 → 프로필 → 내 타임라인 → 구름 모양 백업 아이콘에서 이전 기기의 백업을 선택해 가져오는 방식입니다. 예전 기기가 없고 이용 가능한 백업도 없다면 과거 기록을 되찾을 수 있다고 장담할 수 없습니다.

확인 기준: 2026년 11월 4일. 구글 지도·구글 계정 공식 도움말을 대조했습니다. 기기·앱 버전·구글의 점진적 설정 변경에 따라 메뉴 이름은 달라질 수 있습니다.

1. 타임라인이 안 보이는 이유: 증상별 30초 진단표

지금 보이는 상황우선 확인할 내용권장 행동
PC 웹 구글 지도에 타임라인이 없음현재 PC 웹에서는 타임라인 표시를 제공하지 않음휴대폰 구글 지도 앱에서 확인
새 휴대폰에서 예전 기록이 없음이전 기기 기록을 아직 가져오지 않았을 수 있음이전 폰의 백업 상태 확인 후 새 폰에서 가져오기

초기화·앱 삭제 후 기록이 사라짐기기에 보관되던 데이터가 삭제됐을 수 있음남아 있는 다른 기기·암호화 백업부터 확인

하지 말아야 할 일: 기록이 안 보인다고 구글 지도 앱 데이터 삭제, Google Play 서비스 데이터 삭제, 공장 초기화, 타임라인 전체 삭제, 모든 백업 삭제부터 하지 마세요. 복원할 수 있는 마지막 사본을 잃을 수 있습니다.

2. 2026년 구글 타임라인은 어디에 저장될까?

구글 공식 설명에 따르면 타임라인을 켜면 계정에 로그인된 각 지원 기기가 자신의 방문 장소와 이동 경로를 해당 기기에 저장합니다.

따라서 다음 세 가지를 구별해야 합니다.

  1. 휴대폰에 저장된 타임라인: 실제로 지도 앱이 표시하는 기기별 방문기록입니다.
  2. 타임라인 암호화 백업: 선택적으로 구글 서버에 암호화된 사본을 보관하는 기능입니다. 복원 시 백업에서 가져옵니다.
  3. 구글 지도 검색·웹 및 앱 활동: 타임라인과는 별도의 활동 기록입니다. 검색기록이 있다고 해서 이동 경로를 그대로 복원할 수 있는 것은 아닙니다.

또한 구글은 컴퓨터에서 타임라인을 볼 수 없으며 모바일 구글 지도 앱을 사용해야 한다고 안내합니다. PC에서 메뉴가 사라졌다는 사실만으로 타임라인 데이터가 삭제된 것은 아닙니다.

모든 계정에서 기본으로 켜져 있나요?

아닙니다. 타임라인은 기본적으로 사용 중지이며 이용자가 직접 동의해 켜는 설정입니다. 기록을 남기기 싫다면 켜지 않아도 됩니다. 타임라인을 끄더라도 위치 공유 등 다른 위치 서비스의 설정은 별개입니다.

3. 예전 폰이 있다면 먼저 할 일

예전 휴대폰에 과거 기록이 남아 있다면 그 휴대폰이 현재 가장 중요한 원본입니다. 다음 점검이 끝나기 전에는 중고 판매·반납·공장 초기화·앱 삭제를 미루는 편이 안전합니다.

  1. 예전 휴대폰에서 구글 지도(Google Maps) 앱을 엽니다.
  2. 오른쪽 위 프로필 사진 또는 이니셜 → 내 타임라인을 누릅니다.
  3. 달력에서 오래된 날짜를 몇 개 선택해 예전 방문 장소·이동 경로가 실제로 표시되는지 확인합니다.
  4. 오른쪽 위의 구름 모양 백업 아이콘을 누릅니다.
  5. 백업 기능이 켜져 있는지, 이전 기기의 백업 항목이 있는지, 백업 관련 안내가 있는지 확인합니다.
  6. 충분히 충전하고 안정적인 인터넷에 연결한 상태에서 백업이 갱신되는지 확인합니다.
  7. 가능하다면 원본 데이터 내보내기도 별도로 해 두세요. 단, 내보내기 파일과 앱의 암호화 백업은 같은 것이 아닙니다.

구글은 타임라인 변경 사항이 백업에 반영되기까지 며칠이 걸릴 수 있다고 안내합니다. 이전 기기에 기록이 충분히 남아 있는지 확인하기 전에 새 기기로 가져온 결과만 보고 원본을 지우지 마세요.

4. 새 갤럭시·안드로이드폰에서 타임라인 복원하는 방법

구글이 안내하는 공식 가져오기 경로는 다음과 같습니다.

  1. 새 휴대폰에서 구글 지도 앱을 엽니다.
  2. 오른쪽 위 프로필 사진 → 내 타임라인으로 들어갑니다.
  3. 위쪽의 구름 모양 백업 아이콘을 누릅니다.
  4. 내 백업(Your backups) 목록에서 이전 휴대폰을 찾습니다.
  5. 해당 기기 옆 더보기(점 3개) → 가져오기(Import)를 선택합니다.
  6. 가져오기 화면에서 가져오기를 다시 눌러 진행합니다.
  7. 완료 후 오래된 날짜를 선택해 원하는 기간의 방문기록이 실제로 보이는지 확인합니다.

이 과정은 같은 구글 계정의 이전 타임라인 백업을 새 기기로 가져오는 절차입니다. 새 폰에 구글 계정으로 로그인하는 것만으로 자동 복원이 완료된다고 가정하지 마세요.

이전 폰의 백업이 목록에 없으면?

  • 두 기기의 프로필 사진 아래 구글 계정 주소가 동일한지 확인합니다.
  • 예전 폰에서 실제로 과거 기록이 보이는지 확인합니다.
  • 예전 폰의 구름 아이콘에서 백업이 켜져 있는지 확인합니다.
  • 구글 지도 앱을 최신 버전으로 업데이트합니다.
  • 백업 직후라면 반영에 며칠 걸릴 수 있다는 공식 안내를 고려합니다.
  • 이전 폰에 남은 기록을 확인하기 전에는 앱 데이터 삭제나 초기화로 문제를 해결하려 하지 마세요.

주의: 이전 기기가 구글 계정의 '기기 목록'에 있다는 사실은 타임라인 암호화 백업에 그 기기가 존재한다는 보증이 아닙니다. 두 목록은 구별해야 합니다.

5. 아이폰에서 구글 지도 타임라인 복원하는 방법

아이폰·아이패드에서도 원리는 같습니다.

  1. Google Maps 앱 → 프로필 사진 → 내 타임라인을 엽니다.
  2. 우측 상단의 구름 모양 아이콘을 누릅니다.
  3. 내 백업에서 이전 기기를 선택합니다.
  4. 더보기 → 가져오기 → 가져오기를 누릅니다.
  5. 달력에서 과거 날짜를 확인합니다.

구글 공식 도움말은 아이폰에서는 Google Maps 앱 버전 6.93 이상, 안드로이드에서는 11.106 이상에서 타임라인 기능을 확인할 수 있다고 설명합니다. 앱이 오래됐다면 먼저 업데이트하세요.

아이폰의 위치 권한 때문에 새 기록이 쌓이지 않을 때

구글 지도 → 내 타임라인 → 더보기 → 위치 및 개인정보 보호 설정에서 위치 서비스 상태를 확인하세요. 필요하면 iOS 위치 설정에서 구글 지도 위치 접근 권한이 공식 안내에 맞게 설정됐는지 살펴봅니다.

이미 사라진 과거 기록을 복원하는 문제와 앞으로의 이동 기록이 저장되지 않는 문제는 다릅니다. 위치 권한을 켠다고 과거 기록이 저절로 재생성되지는 않습니다.

6. 타임라인 백업 켜는 방법과 자동 삭제 주의점

구글 지도 앱에서 프로필 → 내 타임라인 → 구름 아이콘 → 백업을 통해 기능을 확인할 수 있습니다.

공식 도움말에는 백업을 켜려면 타임라인 자동 삭제가 꺼져 있어야 한다고 명시돼 있습니다. 화면에서 자동 삭제를 끄라는 안내가 나온다면, 보존 기간과 개인정보 정책을 이해한 뒤 선택하세요.

선택얻는 점주의할 점
타임라인 백업 켜기기기 교체 때 암호화 백업을 가져올 수 있음구글 서버에 암호화된 사본을 보관하며, 반영에 시간이 걸릴 수 있음
타임라인 자동 삭제 유지오래된 위치 정보가 자동으로 정리됨백업 활성화 조건과 충돌할 수 있음
타임라인 끄기새 방문기록을 타임라인에 저장하지 않음이후 이동 경로를 타임라인에서 되돌아볼 수 없음
타임라인 데이터 삭제저장된 방문기록 정리삭제한 정보는 복구 불가능할 수 있음

타임라인은 개인 위치정보입니다. 무조건 백업을 활성화하는 것이 정답은 아닙니다. 기록 보존의 편의와 개인정보 노출 위험을 비교해 결정하세요.

7. '암호화된 데이터가 이 기기에서 잠겨 있음' 오류

새 휴대폰에서 암호화 백업을 가져오려 할 때 'Your encrypted data is locked on this device'와 같은 메시지가 나올 수 있습니다.

구글의 공식 안드로이드 도움말은 이때 백업을 처음 암호화한 기기를 찾으라고 안내합니다.

이전 휴대폰에 접근할 수 있는 경우

  1. 이전 기기에서 구글 지도를 엽니다.
  2. 프로필 → 내 타임라인 → 구름 모양 백업 아이콘으로 들어갑니다.
  3. 비밀번호 재입력 등의 확인이 요구되면 안내에 따라 본인 확인을 진행합니다.
  4. 새 휴대폰에서 백업 목록과 가져오기 화면을 다시 확인합니다.

다른 기기에 '지금 해결(Fix now)' 같은 백업 알림이 나타나면 그 기기에서 본인 확인을 진행하는 방법도 구글이 설명합니다.

이전 휴대폰에 접근할 수 없는 경우

구글 문서에는 기존 백업을 모두 삭제한 뒤 새 백업을 만들 수 있다는 안내도 있지만, 이 작업은 기존 암호화 백업을 영구 삭제합니다. 과거 방문기록 복구가 목적이라면 해결책처럼 즉시 실행해서는 안 됩니다. 먼저 다른 기기에 남은 데이터·기존 백업·지원 가능성을 확인하세요.

핵심: 백업 잠금 오류를 우회한다는 외부 앱, 암호 해제 사이트에 구글 계정 비밀번호나 위치기록 파일을 제공하지 마세요.

8. 휴대폰은 없고 백업도 안 보이면 복구 가능할까?

상황을 나누어 판단해야 합니다.

상황가능한 다음 단계기대할 수 있는 범위
예전 휴대폰이 있고 오래된 기록이 보임그 기기의 백업·가져오기 확인가장 유리한 조건
예전 휴대폰은 없지만 암호화 백업이 목록에 있음새 기기에서 백업 가져오기 시도백업에 포함된 범위 내에서 복원 가능
다른 기기에 일부 방문기록이 남음해당 기기의 데이터·백업 점검남아 있는 기록의 보존 가능성 검토
예전 폰 없음, 목록에 백업 없음기존에 내보낸 파일·기타 보관 자료 확인구글 지도 앱으로 과거 기록 전체 복원은 보장할 수 없음
기존 폰을 초기화했고 백업 여부도 모름다른 기기·백업 유무부터 확인원본 삭제 후 복구는 어려울 수 있음

구글은 휴대폰 초기화 시 타임라인 데이터가 삭제될 수 있다고 설명합니다. 안드로이드의 경우 Google Play 서비스 데이터 삭제도 타임라인에 영향을 줄 수 있습니다. 아이폰에서 구글 지도 앱 삭제·기기 초기화 역시 주의해야 합니다.

삭제된 기록을 복원할 수 있다는 무분별한 인터넷 팁보다 실제 남아 있는 원본이나 공식 백업을 확인하는 것이 우선입니다.

9. 기록을 JSON 파일로 내보내는 방법

중요한 차이: 타임라인 내보내기(export)는 방문정보를 파일로 보관하는 기능이고, 백업 가져오기(import)는 구글 지도의 암호화 백업을 새 기기로 복원하는 기능입니다. 내보낸 JSON을 구글 지도 앱에서 그대로 가져오는 공식 메뉴가 있다고 가정하지 마세요. 공식적으로 설명되는 가져오기는 타임라인의 암호화 백업을 선택하는 절차입니다.

안드로이드에서 내보내기

구글 공식 안내:

  1. 안드로이드 휴대폰의 설정 앱을 엽니다.
  2. 위치 → 위치 서비스 → 타임라인으로 이동합니다.
  3. 타임라인 데이터 내보내기를 선택합니다.
  4. 계속을 눌러 저장 위치를 지정합니다.
  5. 저장을 눌러 완료합니다.

제조사에 따라 위치 메뉴 이름이 다르거나 일부 항목을 찾기 어려울 수 있습니다.

아이폰에서 내보내기

  1. 구글 지도 → 프로필 사진 → 설정 → 위치 및 개인정보 보호를 엽니다.
  2. 타임라인 데이터 내보내기를 누릅니다.
  3. iOS 공유 화면에서 파일에 저장을 선택합니다.
  4. 저장 위치를 선택하고 저장을 누릅니다.
  5. 구글 도움말은 내보내기 파일 이름을 location-history.json으로 안내합니다.

이 파일에는 민감한 위치정보가 포함될 수 있으므로 공유 폴더, 공개 GitHub 저장소, 이메일 첨부에 무심코 업로드하지 마세요. 별도의 안전한 보관 위치를 정하는 것이 좋습니다.

10. 방문기록은 있는데 날짜가 빠져 있거나 위치가 틀리다면

타임라인 데이터가 남아 있는 상태라면 구글 지도에서 내 타임라인 → 달력을 열고 날짜를 바꿔 볼 수 있습니다. 앱 상단의 장소·도시 등 다른 보기 탭에서도 정보가 제공될 수 있습니다.

경로 또는 방문 장소가 잘못 기록된 경우 앱의 편집 기능으로 수정할 수 있습니다. 그러나 자동 기록에는 GPS 정확도, 건물 내부, 신호 상태 등으로 인한 한계가 있어 과거 이동을 완전하게 입증하는 자료로 단정해서는 안 됩니다.

기록을 삭제하면 복구가 어려울 수 있으므로 위치를 확인하기 전에 '전체 삭제' 버튼을 누르지 마세요.

11. 자주 묻는 질문

Q1. 구글 지도 타임라인 PC 버전이 없어졌나요?

구글 공식 도움말은 타임라인 데이터가 기기에서 직접 제공되므로 컴퓨터의 구글 지도에서는 타임라인을 사용할 수 없다고 안내합니다. 휴대폰의 Google Maps 앱에서 확인해야 합니다.

Q2. 새 갤럭시에 같은 구글 계정으로 로그인했는데 왜 옛 기록이 없나요?

타임라인이 각 기기에 저장되는 구조이기 때문입니다. 이전 휴대폰의 암호화 백업을 새 기기로 가져왔는지 확인하세요.

Q3. 구글 포토를 백업했으니 타임라인도 복원되나요?

그렇지 않습니다. 구글 포토 백업과 지도 타임라인 암호화 백업은 별도의 기능입니다.

Q4. 타임라인 데이터 내보내기 JSON 파일을 지도 앱으로 다시 넣을 수 있나요?

공식 타임라인 복원 안내는 구름 아이콘에서 암호화 백업을 선택해 가져오기를 설명합니다. JSON 내보내기 파일을 그 복원 절차와 혼동하지 마세요.

Q5. 타임라인을 끄면 다른 위치 서비스도 모두 꺼지나요?

아닙니다. 구글 공식 설명에 따르면 타임라인 설정과 위치 공유, 기기 찾기 등 다른 위치 관련 설정은 구별됩니다.

Q6. 백업을 켜면 기록이 즉시 복원되나요?

아닙니다. 백업은 앞으로 기기 교체에 대비해 사본을 저장하는 기능입니다. 기존 데이터가 없는 상태에서 켠다고 지워진 과거 기록이 새로 생성되지는 않습니다. 구글은 변경 사항이 백업에 반영되기까지 며칠 걸릴 수 있다고 안내합니다.

Q7. 타임라인 백업은 삭제해도 기기 원본은 남나요?

구글은 백업 삭제 자체가 기기에 저장된 타임라인 데이터를 삭제하지는 않는다고 안내합니다. 하지만 백업은 기기가 없어졌을 때 마지막 복원 수단일 수 있으므로 복원 확인 전에는 삭제하지 않는 편이 안전합니다.

Q8. 예전 폰을 팔기 전에 어떤 순서로 확인해야 하나요?

예전 폰에서 오래된 기록 확인 → 암호화 백업 상태 확인 → 새 폰으로 가져오기 → 새 폰에서 오래된 날짜 재확인 → 필요하다면 별도 내보내기 파일 보관 순서를 권합니다. 완료 전에는 예전 폰을 초기화하지 마세요.

결론: 사라진 기록을 지우지 말고 원본부터 확인

타임라인 복구 성공을 좌우하는 세 가지는 ‘예전 기기의 데이터가 남아 있는지’, ‘암호화 백업이 있는지’, ‘그 백업을 새 휴대폰에서 가져올 수 있는지’입니다.

PC에서 메뉴가 없어졌다고 데이터가 반드시 삭제된 것은 아닙니다. 반대로 구글 계정에 로그인할 수 있다고 예전 기록이 자동 복원되는 것도 아닙니다. 기기 원본을 보존하고, 백업을 확인한 다음, 새 기기에서 가져오는 순서가 가장 안전합니다.
