현재 증상우선 확인다음 단계
Wi-Fi 이름이 목록에 안 뜸공유기 전원·거리·대역다른 기기에서 같은 이름이 보이는지 확인
암호를 입력해도 연결 실패정확한 Wi-Fi 암호해당 네트워크만 지우고 다시 연결

중요: 와이파이 이름 옆의 파란색 체크 표시는 무선 네트워크에 접속했다는 뜻입니다. 인터넷 자체가 정상인지 판단하려면 Safari로 새로운 웹사이트를 실제로 열어봐야 합니다.

2. 설정 → Wi-Fi에서 가장 먼저 점검할 다섯 가지

  1. 아이폰의 설정 → Wi-Fi를 엽니다.
  2. Wi-Fi 스위치가 켜져 있는지 확인합니다.
  3. 연결할 네트워크 이름을 정확히 선택합니다.
  4. 해당 네트워크 이름 왼쪽에 파란 체크 표시가 생겼는지 봅니다.
  5. 설정 → 에어플레인 모드가 꺼져 있는지 확인하고 Safari로 새 페이지를 열어봅니다.

Apple은 Wi-Fi 연결 점검의 기본 단계로 이 상태 확인과 비행기 모드 점검을 안내합니다. 특히 Wi-Fi 연결이 불안정한 경우, 최신 iOS의 연결 지원 설정이 셀룰러 데이터를 보조 연결로 사용할 수 있어 실제 문제를 알아차리기 어려울 수도 있습니다.

원인을 구분하려면 Wi-Fi 연결 자체가 되는지와 셀룰러 데이터가 대신 쓰이고 있는지를 따로 살펴보세요.

3. 집 공유기 이름이 와이파이 목록에 안 뜰 때

목록에 이름이 없다면 암호 입력 오류가 아니라 Wi-Fi 검색·발견 단계의 문제입니다.

  • 공유기 전원: 전원이 켜져 있고 정상 작동하는지 확인합니다.
  • 거리: 공유기 근처로 이동해 네트워크가 나타나는지 확인합니다.
  • 주파수 대역: 2.4GHz·5GHz를 별도로 제공한다면 다른 대역의 SSID가 보이는지 확인합니다.
  • 다른 기기 비교: 노트북이나 다른 스마트폰에서는 같은 Wi-Fi 이름이 보이는지 확인합니다.
  • 숨김 네트워크: 관리자 설정으로 이름을 숨겼다면 정확한 SSID와 연결 방법을 확인합니다.
  • 허용 기기 제한: 학교·회사 공유기에서 등록되지 않은 기기를 차단하는지 확인합니다.

Apple은 숨김 네트워크, 기기 인증 제한, 권장 라우터 설정 미충족 등이 네트워크 검색과 연결에 영향을 줄 수 있다고 안내합니다.

주의: 남의 공유기를 임의로 초기화하거나 보안 설정을 변경해서는 안 됩니다. 학교·회사·공용 시설에서는 담당 관리자에게 확인하세요.

공식 출처: Apple — 특정 네트워크가 안 보일 때

4. 비밀번호를 맞게 입력해도 연결에 실패할 때

우선 Wi-Fi 암호, Apple 계정 암호, 아이폰 화면 잠금 암호가 서로 다르다는 점을 확인하세요.

  1. 공유기 또는 네트워크 관리자가 제공한 Wi-Fi 암호인지 확인합니다.
  2. 영문 대소문자·숫자·특수문자를 정확하게 입력합니다.
  3. 비슷한 이름의 다른 네트워크에 접속하고 있지 않은지 확인합니다.
  4. 다른 기기에서 같은 네트워크에 정상 접속되는지 비교합니다.
  5. 문제가 있는 특정 네트워크의 저장 정보를 지운 뒤 재연결하는 방법을 검토합니다.

'이 네트워크 지우기' 방법

설정 → Wi-Fi → 해당 네트워크 이름 옆 정보(i) → 이 네트워크 지우기

그다음 같은 와이파이를 다시 선택하고 정확한 암호를 새로 입력하세요.

이 기능은 지정한 네트워크의 저장 정보를 제거하는 것으로, 아이폰에 저장된 모든 네트워크 설정을 초기화하는 것과 다릅니다. 다시 연결하려면 비밀번호가 필요할 수 있으므로, 암호를 알고 있을 때 진행해야 합니다.

5. '연결됨, 인터넷 없음'이면 다른 기기와 비교하세요

이 경우 아이폰이 공유기와 Wi-Fi 연결을 맺었지만 인터넷 접속은 되지 않을 수 있습니다. 아래 세 가지 비교가 원인을 빠르게 좁혀 줍니다.

A. 다른 기기에서도 인터넷이 안 되나요?

동일한 공유기에 연결한 다른 스마트폰이나 PC에서도 웹사이트가 열리지 않는다면 공유기·모뎀·인터넷 서비스 제공업체(ISP)를 먼저 점검해야 합니다.

B. 다른 와이파이에서는 아이폰이 정상인가요?

다른 장소에서는 연결되고 집에서만 실패한다면 특정 네트워크 설정 또는 공유기 문제에 초점을 맞춥니다. 여러 네트워크에서 아이폰만 실패한다면 기기 네트워크 설정이나 VPN을 살펴봅니다.

C. 셀룰러 데이터로는 인터넷이 되나요?

Wi-Fi를 끄고 셀룰러 데이터로 새 웹페이지를 열어보세요. 셀룰러에서는 되지만 해당 Wi-Fi에서만 안 된다면 Wi-Fi 경로를 우선 진단할 수 있습니다. 셀룰러 사용 시 요금제 조건은 따로 확인하세요.

Apple은 다른 기기에서 동일 네트워크를 시험하고, 모든 기기가 인터넷에 접속하지 못한다면 ISP에 문의하도록 안내합니다.

6. 최신 iOS의 '연결 지원' 설정도 확인

2026년 Apple 공식 지원 문서에 따르면 '연결 지원'은 이전의 'Wi-Fi 지원'을 대체하는 기능입니다. Wi-Fi가 느리거나 연결되지 않을 때 셀룰러 데이터를 사용하여 연결을 유지할 수 있습니다.

확인 경로: 설정 → Wi-Fi → 아래쪽으로 스크롤 → 연결 지원

Wi-Fi 자체를 진단하려면 필요에 따라 연결 지원을 잠시 꺼서 인터넷이 되는지 비교할 수 있습니다. 이후 데이터 사용량과 편의성을 고려해 본인의 설정을 결정하세요.

주의: 연결 지원이 켜져 있다면 셀룰러 데이터 사용량이 증가할 수 있습니다. 다만 이 기능은 국제 로밍, 셀룰러 저데이터 모드 등 일부 조건에서 동작하지 않습니다. 따라서 연결 지원이 모든 인터넷 오류의 원인이라고 단정해서는 안 됩니다.

7. Wi-Fi 버튼이 회색으로 비활성화되는 경우

설정 → Wi-Fi 화면에서 스위치 자체가 회색으로 표시된다면 일반적인 비밀번호 오류와 다릅니다.

Apple은 먼저 아이폰 재시동을 안내합니다.

  1. 아이폰을 정상적으로 재시동합니다.
  2. 설정 → Wi-Fi에서 다시 켤 수 있는지 확인합니다.
  3. 사용 가능한 iOS 업데이트가 있는지도 확인합니다.
  4. 재시동 후에도 계속 회색이라면 Apple 지원을 통해 추가 점검을 받습니다.

회색 Wi-Fi 버튼만 보고 반드시 무선 칩 불량이라고 단정할 수는 없습니다. 반대로 이 증상 하나만으로 모든 콘텐츠를 삭제하는 공장 초기화를 진행할 이유도 없습니다.

공식 출처: Apple — Wi-Fi 설정이 회색으로 표시될 때

8. VPN·광고 차단·보안 소프트웨어를 사용하는 경우

VPN이나 인터넷을 필터링하는 타사 보안 소프트웨어가 설치되어 있다면 와이파이에 연결되어도 일부 사이트나 앱의 인터넷 통신이 차단될 수 있습니다.

Apple은 VPN과 보안 소프트웨어가 Wi-Fi 또는 인터넷 연결에 영향을 줄 수 있다고 안내합니다.

  • VPN이 설치되어 있는지 확인합니다.
  • 문제가 특정 VPN·보안 앱 사용 시에만 발생하는지 비교합니다.
  • 개인 기기라면 공식 공급업체 안내에 따라 앱의 오류를 확인합니다.
  • 회사·학교에서 관리하는 VPN이라면 임의로 제거하지 말고 관리자에게 문의합니다.
  • 다른 네트워크에서도 같은 문제가 재현되는지 확인합니다.

VPN이 있다고 무조건 삭제하는 것은 좋지 않습니다. 업무용 정책이나 계정 접근 권한에 영향을 줄 수 있기 때문입니다. 해당 소프트웨어를 관리하는 조직과 확인한 뒤 조치하세요.

9. '비공개 Wi-Fi 주소'는 무조건 끄지 마세요

iPhone은 와이파이 네트워크마다 서로 다른 주소를 사용해 기기 추적을 줄이는 비공개 Wi-Fi 주소 기능을 제공합니다. 일부 회사·학교 네트워크는 등록된 MAC 주소로 접근을 제한할 수 있어 연결 문제가 생길 수 있지만, 모든 사용자가 이 기능을 끌 필요는 없습니다.

확인 경로: 설정 → Wi-Fi → 네트워크 이름 옆 정보(i) → 비공개 Wi-Fi 주소

Apple 공식 안내에 따르면 iOS 18 이후 버전에서는 끔·고정식·순환식 같은 옵션을 볼 수 있습니다.

  • 끔: 기기의 하드웨어 Wi-Fi 주소 사용
  • 고정식: 네트워크별 비공개 주소를 유지
  • 순환식: 비공개 주소가 일정 간격으로 변경될 수 있음

Apple은 대부분의 네트워크에서 비공개 주소가 정상 작동하도록 설계됐으므로 개인정보 보호를 위해 기본적으로 유지하도록 권장합니다. 특정 관리형 네트워크에서만 문제가 있다면, 먼저 소프트웨어 업데이트와 네트워크 관리 정책을 확인하세요.

10. 공유기·모뎀·2.4GHz·5GHz 점검

아이폰을 설정해도 증상이 달라지지 않는다면 공유기를 점검합니다.

  1. 공유기와 모뎀 전원이 정상인지 확인합니다.
  2. 가능하면 공유기에 가까이 이동해 연결합니다.
  3. 2.4GHz와 5GHz를 분리해 제공한다면 다른 주파수 네트워크로 테스트합니다.
  4. 본인이 관리하는 라우터라면 제조사 안내에 따라 재시동합니다.
  5. 공유기 펌웨어가 최신인지 확인합니다.
  6. 다른 기기에서도 인터넷이 안 된다면 인터넷 제공업체에 장애 여부를 문의합니다.

여기서 공유기 재시동과 공장 초기화는 전혀 다른 작업입니다. 관리자 비밀번호나 인터넷 회선 인증 정보를 모르는 상태에서 초기화하면 집 전체의 인터넷 연결을 잃을 수 있습니다.

Apple은 라우터가 사용 범위 안에 있는지, 최신 펌웨어를 사용하는지, 호환되는 주파수 대역을 지원하는지 확인하도록 안내합니다.

11. 카페·호텔에서 연결됐지만 웹페이지가 안 열릴 때

일부 공공 Wi-Fi는 일반 비밀번호뿐 아니라 시설의 로그인 페이지 또는 이용 약관 동의를 요구합니다.

  1. 해당 시설에서 공식으로 제공하는 네트워크 이름을 확인합니다.
  2. 와이파이를 연결한 후 로그인·이용 약관 화면이 뜨는지 확인합니다.
  3. 시설에서 안내하는 정상적인 인증 절차를 완료합니다.
  4. 페이지가 보이지 않으면 직원이나 네트워크 관리자에게 문의합니다.
  5. 가짜 Wi-Fi나 수상한 로그인 페이지에 Apple 계정·금융정보를 입력하지 않도록 주의합니다.

Apple도 일부 네트워크는 접속을 위해 암호 또는 이용 약관 동의가 필요하다고 설명합니다.

공용 Wi-Fi 로그인 실패에 대한 세부 절차는 가정용 공유기의 일반 인터넷 장애와 구분해서 적용해야 합니다.

12. 마지막 방법: '네트워크 설정 재설정' 전 주의사항

지금까지의 설정 확인·재시동·다른 네트워크 비교를 거쳤는데도 문제가 해결되지 않을 때 Apple은 네트워크 설정 재설정을 안내합니다.

경로: 설정 → 일반 → 전송 또는 iPhone 재설정 → 재설정 → 네트워크 설정 재설정

실행하면 다음과 같은 정보가 초기화될 수 있습니다.

  • 기존에 저장한 Wi-Fi 네트워크와 암호
  • 셀룰러 설정
  • VPN 설정
  • APN 설정
  • 일부 네트워크 신뢰·연결 구성

Apple 사용 설명서에 따르면 기기 이름 등 관련 설정도 영향을 받을 수 있습니다.

실행하기 전

  1. 집·회사·학교 와이파이 암호를 다시 입력할 수 있는지 확인합니다.
  2. VPN과 특수 APN의 복구 절차를 알아둡니다.
  3. 관리형 기기라면 IT 담당자에게 먼저 문의합니다.
  4. 중요한 데이터의 백업 여부를 확인합니다.
  5. 반드시 '네트워크 설정 재설정'을 선택하고 '모든 콘텐츠 및 설정 지우기'는 선택하지 않습니다.

네트워크 재설정은 공장 초기화가 아닙니다. 그러나 여러 저장된 연결을 지우므로 특정 네트워크만 지우는 것보다 영향이 큽니다. 문제 해결의 첫 조치가 아니라 마지막 단계로 남겨두는 편이 안전합니다.

14. 자주 묻는 질문

Q1. 아이폰 와이파이 연결됨이라고 나오는데 인터넷이 안 됩니다.

연결 표시와 실제 인터넷 접속은 다릅니다. Safari에서 새 웹페이지를 열어보고 같은 공유기에 연결한 다른 기기에서도 인터넷이 되는지 확인하세요. 다른 기기에서도 안 되면 공유기나 인터넷 제공업체 쪽을 먼저 점검합니다.

Q2. 와이파이 비밀번호가 맞는데도 계속 실패해요.

정확한 네트워크와 암호를 확인한 뒤 설정 → Wi-Fi → 정보(i) → 이 네트워크 지우기로 해당 연결만 제거하고 다시 암호를 입력할 수 있습니다. 다만 암호를 모르면 다시 연결하기 어려울 수 있습니다.

Q3. Wi-Fi 버튼이 회색이라 누를 수 없습니다.

Apple은 아이폰을 먼저 재시동하도록 안내합니다. 그래도 활성화되지 않으면 Apple 공식 지원을 통해 추가 점검을 받으세요.

Q4. 아이폰만 집 와이파이 목록에 네트워크 이름이 안 보여요.

공유기 전원·거리·2.4GHz·5GHz·숨김 SSID·기기 등록 정책을 확인하세요. 다른 스마트폰에서 해당 네트워크가 보이는지도 비교하는 것이 좋습니다.

Q5. 최신 iOS의 '연결 지원'이 뭐죠?

기존의 Wi-Fi 지원을 대체하는 기능으로, Wi-Fi가 불안정할 때 셀룰러 데이터를 사용해 인터넷 연결을 보완합니다. 사용량이 늘 수 있으므로 요금제와 연결 상태에 맞춰 설정하세요.

Q6. 비공개 Wi-Fi 주소를 끄면 해결되나요?

일부 관리형 네트워크에서는 관련 설정 확인이 필요할 수 있지만, Apple은 개인정보 보호를 위해 비공개 Wi-Fi 주소를 기본적으로 유지하도록 권장합니다. 모든 Wi-Fi 문제에서 이 기능을 끄는 것은 적절하지 않습니다.

Q7. 공유기를 먼저 초기화해야 하나요?

공장 초기화보다는 일반적인 재시동과 다른 기기의 접속 확인이 먼저입니다. 공장 초기화는 기존 SSID·암호·인터넷 설정을 지울 수 있으므로 신중하게 진행해야 합니다.

Q8. 네트워크 설정 재설정을 하면 사진도 지워지나요?

네트워크 설정 재설정은 전체 기기 데이터 삭제와 다릅니다. 하지만 Wi-Fi 암호와 셀룰러·VPN·APN 등 연결 설정이 초기화될 수 있으므로, 복원 방법을 확인해야 합니다.

Q9. 카페 와이파이는 연결되는데 로그인 화면이 안 보여요.

공용 와이파이는 로그인 페이지 또는 이용 약관 동의가 필요할 수 있습니다. 해당 시설에서 공식으로 제공하는 접속 절차를 확인하고 관리자의 도움을 받으세요.

Q10. 여러 장소에서 아이폰만 계속 Wi-Fi에 연결되지 않아요.

Wi-Fi 설정과 재시동, 다른 네트워크 비교, VPN·보안 소프트웨어, iOS 업데이트를 확인한 후에도 실패한다면 Apple 지원을 통한 추가 진단이 적절합니다.

15. 마지막 점검표

  • ☐ 설정 → Wi-Fi에서 연결하려는 네트워크의 파란 체크를 확인했다.
  • ☐ Wi-Fi 연결 여부와 실제 인터넷 접속을 구별했다.
  • ☐ 비행기 모드가 꺼져 있는지 확인했다.
  • ☐ 같은 공유기를 사용하는 다른 기기로 인터넷을 테스트했다.
  • ☐ 집과 다른 장소의 Wi-Fi에서 결과를 비교했다.
  • ☐ 암호를 알고 있다면 특정 네트워크만 지운 뒤 다시 연결했다.
  • ☐ '연결 지원'이 셀룰러 데이터를 사용하고 있는지 확인했다.
  • ☐ Wi-Fi 버튼이 회색이면 아이폰을 재시동했다.
  • ☐ VPN·보안 소프트웨어·비공개 Wi-Fi 주소를 필요에 따라 점검했다.
  • ☐ 본인이 관리하는 공유기의 전원·대역·펌웨어를 확인했다.
  • ☐ 네트워크 재설정 전에 암호와 VPN 복원 방법을 확인했다.
  • ☐ 여러 와이파이에서 계속 실패하면 Apple 또는 ISP에 문의한다.

결론: 아이폰 와이파이 문제는 네트워크 이름이 안 보임, 암호 연결 실패, 연결되지만 인터넷 없음, Wi-Fi 버튼 회색을 먼저 구분해야 빠르게 해결할 수 있습니다. 위험이 낮은 설정 확인과 다른 기기 비교부터 시도하고 네트워크 설정 재설정은 마지막 단계로 남겨두세요.
