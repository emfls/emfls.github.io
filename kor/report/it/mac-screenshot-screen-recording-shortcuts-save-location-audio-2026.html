맥북이나 iMac에서 스크린샷을 찍었는데 파일을 찾을 수 없거나, 화면을 동영상으로 녹화했는데 소리가 들어가지 않았다면 어떤 단축키와 녹화 옵션을 사용했는지 먼저 확인해야 합니다. Mac은 별도 유료 프로그램을 설치하지 않아도 전체 화면·지정 영역·특정 창을 이미지로 캡처하고 화면을 동영상으로 기록할 수 있습니다.

Mac에서 자주 쓰는 단축키는 Shift-Command-3(전체 화면), Shift-Command-4(선택 영역), **Shift-Command-5(스크린샷·화면 기록 도구)**입니다. 여기에 Control을 함께 누르면 이미지 파일 대신 클립보드에 캡처할 수도 있습니다. 기본 저장 장소는 데스크탑이지만 스크린샷 앱의 옵션에서 다른 폴더로 바꿀 수 있습니다.

이 글은 2026년 11월 1일 기준 Apple 공식 고객지원 문서를 토대로 작성했습니다. macOS 버전과 Mac 모델에 따라 선택한 창 기록, 화면 기록 포맷, 시스템 소리 녹음 같은 일부 기능에 차이가 있습니다. 특히 마이크 녹음과 컴퓨터 내부 시스템 오디오 녹음은 다른 기능이라는 점을 정확히 구분해야 합니다.

2. Shift-Command-3: 전체 화면 캡처

전체 화면 캡처는 사용 중인 디스플레이에 표시된 화면 전체를 저장하고 싶을 때 적합합니다.

  1. 캡처할 화면을 준비합니다.
  2. Shift, Command, 숫자 3을 함께 누르고 손을 뗍니다.
  3. 오른쪽 아래에 미리보기 썸네일이 나타나는지 확인합니다.
  4. 썸네일을 클릭하면 편집·마크업 도구를 이용할 수 있습니다.
  5. 아무것도 누르지 않으면 기본 저장 위치에 파일이 생성되는 것을 확인합니다.

외부 모니터를 연결한 Mac에서는 여러 디스플레이의 화면이 각각 캡처될 수 있습니다. 전체 화면 대신 하나의 창만 기록할 목적이라면 아래의 창 캡처 단축키가 더 간단합니다.

주의: 스크린샷은 당시 화면에 표시된 내용이 그대로 들어갈 수 있습니다. 메신저 알림, 계정명, 개인 파일 이름과 같은 정보가 노출되지 않도록 촬영 전 확인하세요.

공식 출처: Apple — 전체 화면 스크린샷

3. Shift-Command-4: 원하는 영역만 캡처

브라우저의 설명 부분, 오류 메시지, 설정창 일부처럼 꼭 필요한 영역만 저장하고 싶다면 선택 캡처 기능을 사용하세요.

  1. Shift + Command + 4를 누릅니다.
  2. 마우스 포인터가 십자선 모양으로 바뀌는지 확인합니다.
  3. 캡처하고 싶은 범위의 시작점에서 마우스를 누릅니다.
  4. 원하는 영역까지 드래그합니다.
  5. 마우스 버튼이나 트랙패드에서 손을 떼면 캡처됩니다.

캡처 범위를 옮기고 싶을 때

드래그 도중 스페이스 바를 길게 누른 채 마우스를 움직이면 선택 영역의 크기를 유지하면서 위치를 옮길 수 있습니다. 스페이스 바에서 손을 떼면 크기를 다시 조정할 수 있습니다.

잘못 선택했을 때

캡처를 하기 전 Esc를 누르면 동작을 취소할 수 있습니다. 이미 스크린샷이 저장됐다면 Finder에서 해당 파일을 확인하고 필요에 따라 삭제하거나 다시 캡처하세요.

글자가 작아 보일 때

캡처하는 영역을 줄인다고 원본 화면의 실제 텍스트 해상도가 무조건 높아지는 것은 아닙니다. 설명을 읽을 수 있도록 앱의 확대율을 조정한 뒤 다시 캡처하는 편이 좋습니다.

공식 출처: Apple — 화면의 일부 캡처

4. 창 하나만 깔끔하게 캡처하려면 스페이스 바를 사용

열려 있는 앱 창 하나만 이미지로 저장하고 싶다면 선택 영역을 손으로 정확히 맞출 필요가 없습니다.

  1. 캡처할 앱이나 창을 화면에 띄웁니다.
  2. Shift + Command + 4를 누릅니다.
  3. 스페이스 바를 누릅니다.
  4. 포인터가 카메라 아이콘으로 바뀝니다.
  5. 캡처하려는 창 위로 카메라 포인터를 이동합니다.
  6. 해당 창을 클릭하면 창의 이미지가 저장됩니다.

창 그림자를 제외하고 싶을 때

Apple은 창을 클릭할 때 Option 키를 길게 누르면 스크린샷에서 창의 그림자를 제외할 수 있다고 안내합니다. 배경에 붙여 넣을 이미지나 문서에 맞게 편집할 때 유용합니다.

메뉴 캡처도 가능합니다. 앱 메뉴를 연 상태에서 단축키를 누르고 해당 메뉴 또는 항목을 선택해 기록하세요.

단, 일부 저작권 또는 보안 보호 콘텐츠를 표시하는 앱에서는 창의 스크린샷이 제한될 수 있습니다. 창 캡처가 되지 않는다는 이유만으로 보안 제한을 우회할 도구를 찾기보다는 앱의 공유·내보내기 기능을 먼저 확인해야 합니다.

공식 출처: Apple — 윈도우 또는 메뉴 캡처

5. Shift-Command-5: 저장 위치와 캡처 옵션 변경

스크린샷을 많이 찍는 사람에게 가장 유용한 것은 Shift + Command + 5입니다. 이 단축키는 스크린샷과 화면 기록을 한곳에서 설정할 수 있는 제어 도구를 엽니다.

  1. Shift + Command + 5를 누릅니다.
  2. 화면 하단에 나타나는 도구 막대에서 캡처 대상 아이콘을 확인합니다.
  3. 전체 화면, 창, 선택한 부분 중 원하는 캡처 방식을 선택합니다.
  4. **옵션(Options)**을 클릭합니다.
  5. 저장 위치, 타이머, 썸네일 등의 항목을 확인합니다.
  6. 필요한 설정을 선택한 후 캡처를 누릅니다.

6. 스크린샷 저장 위치를 바탕화면에서 다른 폴더로 바꾸기

기본 상태에서는 스크린샷이 데스크탑에 쌓입니다. 스크린샷이 자주 생성돼 바탕화면이 복잡해진다면 스크린샷 도구의 저장 위치 설정을 변경하면 됩니다.

  1. Finder에서 ‘스크린샷 모음’처럼 알아보기 쉬운 새 폴더를 만듭니다.
  2. Shift + Command + 5를 누릅니다.
  3. 도구 막대의 옵션을 클릭합니다.
  4. 다음으로 저장 아래의 위치 목록을 확인합니다.
  5. **다른 위치(Other Location)**를 선택합니다.
  6. 앞서 만든 ‘스크린샷 모음’ 폴더를 지정합니다.
  7. Shift-Command-3 또는 4로 시험 캡처를 수행합니다.
  8. 새 폴더에 이미지가 실제로 생성됐는지 확인합니다.

중요: 저장 위치를 새로 지정해도 이전에 데스크탑에 저장된 스크린샷 파일이 자동 이동하는 것은 아닙니다. 기존 파일은 Finder에서 직접 정리해야 합니다.

저장 위치가 여전히 바탕화면이라면

  • Shift-Command-5의 옵션 메뉴에서 선택한 폴더가 맞는지 확인합니다.
  • 폴더가 현재 존재하고 접근할 수 있는지 확인합니다.
  • 스크린샷이 파일이 아니라 클립보드에 복사되도록 Control 키를 함께 누른 것은 아닌지 확인합니다.
  • 외장 드라이브를 저장 위치로 사용했다면 실제로 연결돼 있는지 확인합니다.

터미널 명령 없이도 공식 UI에서 저장 위치를 변경할 수 있습니다. 출처가 불분명한 시스템 설정 명령을 그대로 복사할 필요는 없습니다.

7. 스크린샷이 저장되지 않고 붙여넣기만 되는 이유

스크린샷을 찍었는데 파일은 보이지 않고 메신저나 문서에 이미지를 붙여넣을 수 있다면 클립보드 복사 단축키를 사용한 것일 수 있습니다.

전체 화면을 클립보드에 복사하기

Control + Shift + Command + 3을 누르면 전체 화면 이미지가 파일 대신 클립보드에 들어갑니다. 그다음 메모, 이메일 또는 문서 앱에서 Command + V를 눌러 붙여넣습니다.

화면 일부를 클립보드에 복사하기

Control + Shift + Command + 4를 누르고 캡처 영역을 선택한 후 원하는 프로그램에서 Command+V로 붙여넣을 수 있습니다.

이미 찍은 스크린샷을 클립보드에 넣기

스크린샷 직후 나타나는 미리보기 썸네일을 Control-클릭한 다음 **클립보드에 저장(Save to Clipboard)**을 선택할 수도 있습니다.

클립보드는 장기 저장소가 아닙니다. 이후 다른 내용을 복사하면 붙여넣을 수 있는 내용이 바뀔 수 있습니다. 남겨야 하는 이미지는 파일로 저장하거나 문서에 붙여 넣은 뒤 해당 문서를 저장하세요.

8. Mac에서 화면을 동영상으로 녹화하는 방법

스크린샷은 정지 이미지이고, **화면 기록(Screen Recording)**은 화면에서 이루어지는 동작을 동영상으로 저장합니다. 메뉴 조작 설명이나 프로그램 사용 방법을 전달할 때 유용합니다.

  1. 화면에 녹화할 내용을 준비합니다.
  2. Shift + Command + 5를 누릅니다.
  3. 도구 막대에서 전체 화면 기록 또는 선택 부분 기록을 선택합니다.
  4. 필요한 경우 선택 부분의 테두리를 드래그해 범위를 조절합니다.
  5. 옵션을 열어 저장 위치, 마이크, 타이머를 확인합니다.
  6. **기록(Record)**을 클릭합니다.
  7. 녹화하려는 작업을 수행합니다.
  8. 화면 위쪽 메뉴 막대의 기록 중단(Stop) 버튼을 누릅니다.
  9. 또는 Command + Control + Esc로 녹화를 중단합니다.
  10. 저장된 동영상을 열어 화면과 소리를 확인합니다.

Apple은 macOS Tahoe 26 및 이후 버전의 지원 Mac에서 선택한 창 기록과 녹화 포맷 선택 기능도 안내합니다. 그러나 오래된 macOS에서는 같은 아이콘이나 메뉴가 없을 수 있으므로 전체 화면 기록·선택 부분 기록을 중심으로 확인하세요.

기본 저장 형식은?

Apple의 Mac 사용 설명서는 화면 기록의 대표적인 저장 형식을 MOV로 설명합니다. 단, 지원 모델에서 녹화 포맷과 품질을 변경하면 동영상 코덱이나 HDR 사용 여부가 달라질 수 있습니다.

9. Mac 화면 녹화에 내 목소리가 안 들어갈 때

화면은 정상적으로 기록되지만 자신의 설명 목소리가 저장되지 않는다면 가장 먼저 마이크 선택을 확인하세요.

마이크 옵션 확인

  1. Shift + Command + 5를 누릅니다.
  2. 도구 막대에서 화면 기록을 선택합니다.
  3. 옵션 → 마이크 항목을 확인합니다.
  4. 음성을 넣으려면 내장 마이크 또는 연결된 마이크 중 사용할 장치를 선택합니다.
  5. **없음(None)**이 선택돼 있다면 마이크 소리가 기록되지 않을 수 있습니다.
  6. 10초 정도 시험 녹화를 하고 말을 한 뒤 동영상으로 확인합니다.

녹음이 여전히 안 된다면

  • 외장 USB 마이크나 이어폰 마이크가 제대로 연결돼 있는지 확인합니다.
  • 시스템 설정 → 사운드 → 입력에서 사용할 마이크가 맞는지 확인합니다.
  • 마이크가 물리적으로 음소거돼 있지 않은지 살펴봅니다.
  • 다른 오디오 녹음 앱에서 동일 마이크가 정상 작동하는지 시험합니다.

구분할 것: 마이크는 사람의 목소리와 주변 소리를 기록합니다. Mac에서 재생되는 음악·게임·브라우저 동영상 소리 등 시스템 오디오와는 기록 경로가 다릅니다. 마이크를 켰다고 컴퓨터에서 재생되는 모든 소리가 원음 그대로 녹음된다고 기대하지 마세요.

10. 컴퓨터 내부 소리가 녹음되지 않을 때: macOS 버전 차이

화면에 보이는 게임이나 동영상은 잘 녹화됐는데 앱에서 재생되던 소리가 동영상에 포함되지 않는 경우가 있습니다. 이때 시스템 오디오 녹음과 마이크 녹음을 혼동하면 해결이 어렵습니다.

Apple은 공식 화면 기록 안내에서 macOS 27 Golden Gate 및 이후 버전에 한해 스크린샷 도구의 시스템 오디오 포함(Include System Audio) 설정을 설명합니다. 따라서 2026년 11월 현재 사용 중인 macOS Tahoe 26 등 이전 환경에서는 동일한 기본 옵션이 있다고 단정해서는 안 됩니다.

먼저 확인할 순서

  1. Apple 메뉴 → 이 Mac에 관하여에서 macOS 버전을 확인합니다.
  2. Shift + Command + 5 → 옵션을 엽니다.
  3. 마이크 외에 별도의 시스템 오디오 포함 항목이 실제로 있는지 확인합니다.
  4. 보이는 기능만 사용해 짧은 시험 녹화를 합니다.
  5. 시스템 오디오 항목이 없다면 마이크 설정으로 내부 소리를 완전히 대체할 수 있다고 생각하지 않습니다.
  6. 게임·회의·앱이 자체적으로 제공하는 공식 녹음이나 내보내기 기능이 있는지 확인합니다.

타사 화면 녹화 앱을 쓴다면

타사 앱은 화면과 오디오를 기록하려면 macOS의 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음 권한이 필요할 수 있습니다. Apple은 이 권한을 허용한 업체의 데이터 수집 방식에는 해당 앱의 개인정보 보호정책이 적용된다고 설명합니다.

따라서 권한을 허용하기 전에 앱의 신뢰성, 저장되는 화면 정보, 업무 자료 보안 규정을 먼저 검토하세요. 저작권이나 보안 정책으로 녹화가 제한된 콘텐츠를 임의로 우회하려고 해서는 안 됩니다.

11. QuickTime Player로 화면 녹화하는 방법

Mac의 QuickTime Player에서도 화면 기록을 시작할 수 있습니다. Apple에 따르면 최신 macOS의 QuickTime Player는 화면 기록을 시작할 때 스크린샷 도구를 여는 방식으로 작동할 수 있습니다.

  1. 응용 프로그램 → QuickTime Player를 실행합니다.
  2. 메뉴 막대에서 파일 → 새로운 화면 기록을 선택합니다.
  3. 단축키를 사용하려면 QuickTime Player에서 Control + Command + N을 누를 수 있습니다.
  4. 스크린샷 도구 막대가 표시된다면 앞서 설명한 전체 화면 또는 선택 부분 기록을 선택합니다.
  5. 옵션에서 마이크와 저장 위치를 확인합니다.
  6. 기록을 눌러 화면을 녹화합니다.
  7. 메뉴 막대의 기록 중단 버튼으로 종료합니다.

이전 버전의 QuickTime Player는 별도의 화면 기록 창을 보여줄 수 있습니다. Apple은 해당 경우 녹화 버튼 옆 메뉴에서 마이크를 고르고 전체 화면 또는 선택 영역을 기록하도록 안내합니다.

QuickTime으로 녹화한 뒤 할 수 있는 일

QuickTime Player에서는 동영상을 재생하고 필요한 부분을 **다듬기(Trim)**로 잘라낼 수 있습니다. 별도 편집 프로그램을 설치하기 전에 이 기본 기능을 먼저 시험해 보세요.

12. 화면 기록 파일이 어디에 저장되는지 찾는 방법

Mac의 화면 기록은 기본적으로 데스크탑에 저장될 수 있으며, 저장 위치를 바꿨다면 Shift-Command-5의 옵션에서 확인할 수 있습니다.

기본 이름으로 찾기

Apple의 공식 안내에서 자동 저장된 화면 기록의 대표적인 파일 이름은 ‘화면 기록 [날짜] [시간].mov’ 형식입니다. 저장된 스크린샷은 ‘스크린샷 [날짜] [시간]’ 형식으로 표시될 수 있습니다.

  1. Finder를 엽니다.
  2. 데스크탑 폴더에서 최근 날짜의 파일을 확인합니다.
  3. 없다면 Shift + Command + 5 → 옵션 → 다음으로 저장에서 지정된 폴더를 확인합니다.
  4. Finder에서 최근 항목을 살펴봅니다.
  5. 파일 이름에 ‘화면 기록’ 또는 ‘스크린샷’이 포함되는지 확인합니다.
  6. 녹화한 동영상을 열어 내용과 오디오를 확인합니다.

iCloud Drive와 데스크탑 동기화

Mac에서 데스크탑 및 문서 폴더를 iCloud Drive와 동기화하고 있다면 데스크탑 파일이 iCloud와 연동될 수 있습니다. 이 경우 파일 탐색 위치와 오프라인 사용 가능 여부를 함께 확인해야 합니다.

녹화 파일이 없다는 이유만으로 즉시 재촬영하지 말고 저장 위치 옵션과 iCloud 상태를 먼저 확인하면 불필요한 작업을 줄일 수 있습니다.

13. 스크린샷 단축키가 작동하지 않을 때 해결 순서

Shift-Command-3이나 4를 눌러도 화면이 저장되지 않는다면 다음 항목을 차례대로 확인하세요.

  1. 키보드에서 Command와 Shift 키가 정상 작동하는지 다른 단축키로 시험합니다.
  2. Shift + Command + 5를 눌러 스크린샷 도구가 실행되는지 확인합니다.
  3. 도구 막대의 버튼을 클릭하면 캡처할 수 있는지 시험합니다.
  4. 옵션 → 다음으로 저장에서 저장 장소가 존재하는지 확인합니다.
  5. Control 키를 함께 눌러 클립보드로 보낸 것은 아닌지 확인합니다.
  6. 캡처 대상이 특정 보안 보호 앱인지 다른 일반 앱으로 비교합니다.
  7. Mac을 정상 재시동한 후 다시 시험합니다.
  8. 시스템 설정 → 키보드 → 키보드 단축키 → 스크린샷에서 관련 단축키 상태를 확인합니다.

Apple은 키보드 단축키를 변경하거나 비활성화할 수 있다고 설명합니다. 다른 앱의 전역 단축키와 같은 조합을 사용하고 있다면 충돌이 발생할 수 있으므로 원래 키 설정을 확인하세요.

단축키를 실수로 바꿨다면

키보드 단축키 설정에서 스크린샷 항목이 비활성화됐거나 다른 조합으로 바뀌었는지 점검하세요. 필요할 경우 Apple이 안내한 기본값으로 복원 기능을 검토할 수 있습니다. 다만 이 작업은 다른 사용자 지정 단축키에도 영향을 줄 수 있으므로 먼저 현재 설정을 확인해야 합니다.

14. 특정 앱만 검게 나오거나 캡처되지 않을 때

웹페이지나 Finder는 정상적으로 캡처되지만 특정 동영상 앱의 창만 검게 나오거나 기록되지 않는 경우가 있습니다. 이는 앱이나 콘텐츠 제공자가 제한하는 보안·저작권 보호 화면일 수 있습니다.

Apple의 공식 스크린샷 안내도 Apple TV 앱 등 일부 앱의 윈도우는 캡처하지 못할 수 있다고 설명합니다.

먼저 범위를 구분하세요

  1. Finder나 일반 문서 앱에서 짧게 스크린샷을 찍어 봅니다.
  2. 정상적으로 저장된다면 기본 캡처 기능은 동작 중인 것입니다.
  3. 문제가 발생하는 앱에서만 기록이 차단되는지 비교합니다.
  4. 해당 앱의 공식 다운로드·공유·내보내기 기능을 확인합니다.
  5. 회사 관리용 앱이라면 조직의 화면 기록 허용 정책을 확인합니다.

화면을 캡처할 수 없다는 이유만으로 콘텐츠 보호 설정을 우회하는 방법을 사용하지 마세요. 기술적으로 촬영할 수 있는 화면이라도 외부 공유에는 저작권이나 개인정보 관련 제한이 있을 수 있습니다.

15. 스크린샷 썸네일을 이용해 곧바로 편집·공유

캡처 직후 오른쪽 아래에 잠깐 나타나는 플로팅 썸네일은 단순한 알림이 아닙니다. 파일이 저장되기 전에 빠르게 편집하거나 다른 앱으로 옮길 수 있는 기능입니다.

캡처 직후 편집하기

  1. Shift-Command-3 또는 4로 스크린샷을 찍습니다.
  2. 오른쪽 아래에 표시되는 썸네일을 클릭합니다.
  3. 마크업 도구가 제공된다면 화살표, 도형, 글씨 등을 추가합니다.
  4. 필요한 부분을 편집한 뒤 완료 또는 저장합니다.
  5. 결과를 열어 표시한 내용이 정확한지 확인합니다.

썸네일을 드래그해서 보내기

썸네일을 Finder 폴더나 문서 등으로 끌어다 놓을 수도 있습니다. 이메일에 스크린샷을 첨부할 목적이라면 먼저 바탕화면 파일을 찾는 과정을 줄일 수 있습니다.

미리보기 표시를 원하지 않는다면

Shift + Command + 5 → 옵션 → 미리보기 썸네일 보기의 선택 상태를 변경합니다. 썸네일을 끈다고 스크린샷 기능이 꺼지는 것은 아니며, 저장 장소에 파일이 생성되는지 별도로 확인하세요.

개인정보 보호: 스크린샷을 편집하며 모자이크나 가림 효과를 넣었다고 생각하더라도 결과 파일에 실제로 민감 정보가 보이지 않는지 반드시 열어 확인하세요.

공식 출처: Apple — 스크린샷 플로팅 썸네일과 마크업

17. 자주 묻는 질문

Q. 맥북 전체 화면 스크린샷 단축키는 무엇인가요?

Shift + Command + 3입니다. 캡처한 이미지는 기본적으로 데스크탑에 저장되지만, Shift-Command-5 옵션에서 저장 위치를 바꿀 수 있습니다.

Q. 화면 일부만 캡처하려면 어떤 키를 누르나요?

Shift + Command + 4를 누르고 원하는 부분을 드래그하세요. 창 하나만 캡처하려면 그다음 스페이스 바를 눌러 카메라 아이콘으로 바꾼 뒤 해당 창을 클릭합니다.

Q. 캡처한 사진을 파일 없이 바로 붙여넣고 싶어요.

기존 캡처 단축키에 Control을 추가하세요. 예를 들어 Control+Shift+Command+3을 누르면 전체 화면을 클립보드에 복사할 수 있습니다. 다른 앱에서는 Command+V로 붙여넣습니다.

Q. 스크린샷이 바탕화면에 저장되지 않습니다.

Shift-Command-5의 옵션에서 저장 위치를 확인하세요. 다른 폴더가 지정됐거나 Control 키를 이용해 클립보드로 복사했을 수 있습니다.

Q. Mac 화면을 동영상으로 녹화하는 단축키는 무엇인가요?

Shift + Command + 5를 누른 뒤 도구 막대에서 화면 기록 버튼을 선택합니다. 녹화 종료는 메뉴 막대의 중단 버튼 또는 Command + Control + Esc로 할 수 있습니다.

Q. 화면 녹화에 제 목소리가 안 들어갑니다.

Shift-Command-5의 옵션에서 마이크가 없음으로 설정돼 있지 않은지 확인하세요. 사용할 마이크를 선택한 뒤 짧게 시험 녹화를 해 보세요.

Q. 유튜브나 게임 소리도 기본 화면 기록으로 녹음되나요?

마이크와 시스템 오디오 녹음은 별도입니다. Apple은 macOS 27 및 이후 버전에서 시스템 오디오 포함 기능을 안내하므로, 이전 버전의 스크린샷 도구에 같은 옵션이 있다고 가정하면 안 됩니다. 콘텐츠의 보호 설정에 따라 기록 자체가 제한될 수도 있습니다.

Q. QuickTime Player로 녹화하면 별도 프로그램이 필요한가요?

QuickTime Player는 Mac에 제공되는 앱입니다. 파일 → 새로운 화면 기록으로 녹화를 시작할 수 있으며, 현대 macOS에서는 스크린샷 도구 막대가 열릴 수 있습니다.

Q. 녹화가 끝났는데 MOV 파일을 찾을 수 없습니다.

기본적으로 데스크탑의 ‘화면 기록 [날짜] [시간].mov’를 찾고, 없다면 Shift-Command-5의 다음으로 저장 설정을 확인하세요.

Q. 스크린샷 단축키가 갑자기 작동하지 않습니다.

시스템 설정 → 키보드 → 키보드 단축키 → 스크린샷에서 단축키 활성화와 변경 여부를 확인하세요. Shift-Command-5의 버튼으로 직접 캡처할 수 있는지도 시험해 보세요.

18. 맥북 스크린샷·화면 녹화 최종 점검표

  • ☐ 전체 화면, 선택 영역, 창 캡처의 단축키를 구분했습니다.
  • ☐ Shift-Command-3, Shift-Command-4, Shift-Command-5의 기능을 확인했습니다.
  • ☐ 클립보드 복사에는 Control 키를 추가해야 한다는 점을 이해했습니다.
  • ☐ 스크린샷 저장 위치를 Shift-Command-5 옵션에서 확인했습니다.
  • ☐ 바탕화면이 복잡하다면 별도 폴더를 저장 위치로 지정했습니다.
  • ☐ 예전에 저장한 파일은 새 폴더로 자동 이동하지 않는다는 점을 확인했습니다.
  • ☐ 화면 기록 시 전체 화면과 선택 부분 중 필요한 범위를 선택했습니다.
  • ☐ 녹화 종료는 메뉴 막대의 중단 버튼 또는 Command-Control-Esc로 했습니다.
  • ☐ 목소리 설명이 필요하다면 마이크를 선택했습니다.
  • ☐ 시스템 오디오 녹음은 macOS 버전과 지원 기능을 별도로 확인했습니다.
  • ☐ QuickTime Player에서는 새로운 화면 기록 기능을 확인했습니다.
  • ☐ 스크린샷은 이미지, 화면 기록은 동영상임을 구분했습니다.
  • ☐ 촬영한 파일에 개인정보와 보안 정보가 노출되지 않았는지 확인했습니다.
  • ☐ 저장된 이미지나 MOV 파일을 실제로 열어 내용과 소리를 검증했습니다.

결론: 맥북 스크린샷은 Shift-Command-3(전체), Shift-Command-4(부분·창), **Shift-Command-5(옵션·화면 기록)**만 기억해도 대부분의 작업을 할 수 있습니다. 사진이 저장되지 않으면 저장 위치와 클립보드 복사 여부를, 영상에 소리가 없으면 마이크와 시스템 오디오 녹음의 차이를 확인하세요. 특히 시스템 오디오의 기본 녹음 지원 범위는 macOS 버전별로 다르므로 실제 기기의 옵션을 확인하는 것이 중요합니다.
