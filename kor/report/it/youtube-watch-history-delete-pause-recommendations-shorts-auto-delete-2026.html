유튜브에서 여행 영상을 몇 개 봤더니 여행 콘텐츠만 계속 추천되거나, 아이와 함께 본 애니메이션이 홈 화면 대부분을 채우는 경험이 있나요? 유튜브 시청 기록을 삭제하면 추천을 처음부터 다시 시작할 수 있는지, 기록을 꺼 두면 유튜브 홈 화면이 왜 비어 보이는지도 궁금할 수 있습니다.

1. 유튜브 시청 기록과 추천 알고리즘은 어떤 관계인가요?

YouTube는 홈 화면의 맞춤 동영상 추천에 시청 기록을 주요 신호로 활용한다고 설명합니다. 최근 어떤 영상을 봤는지에 따라 홈에 나타나는 콘텐츠 주제와 추천 방식이 달라질 수 있습니다.

하지만 추천 기준이 시청 기록 하나뿐인 것은 아닙니다. YouTube는 검색 기록, 구독, 좋아요·싫어요, 관심 없음·채널 추천 안함 피드백, 기타 Google 계정 활동 등이 추천과 검색 결과에 영향을 줄 수 있다고 공식적으로 설명합니다.

시청 기록을 일부 삭제하면?

해당 콘텐츠를 나중에 다시 시청한 기록으로 찾기 어려워지고, YouTube가 향후 추천에 그 삭제된 시청 기록을 활용하지 않게 됩니다. 다만 좋아요, 구독, 다른 검색·시청 활동까지 자동으로 정리되는 것은 아닙니다.

시청 기록을 전부 삭제하면?

기존 시청 이력에서 비롯되는 추천 신호를 크게 줄일 수 있습니다. 그러나 유튜브의 다른 신호와 사용 행동은 남아 있기 때문에 추천 알고리즘이 완벽한 새 계정처럼 100% 초기화된다고 보장할 수는 없습니다.

시청 기록을 지우고 사용 중지까지 하면?

YouTube 공식 도움말은 중요한 기존 시청 기록이 없고 기록 사용도 중지한 경우 홈 화면의 맞춤 추천 동영상이 사라질 수 있다고 명시합니다. 즉 추천이 비어 있는 화면은 장애가 아니라 설정에 따른 정상 결과일 수 있습니다.

2. 갤럭시·안드로이드에서 유튜브 시청 기록 확인하기

먼저 지우려는 시청 기록이 어느 Google 계정에 저장돼 있는지 확인하세요. 휴대전화와 스마트 TV에서 서로 다른 계정을 사용한다면 기록이 다르게 보일 수 있습니다.

Android YouTube 앱 절차

  1. YouTube 앱을 실행합니다.
  2. 오른쪽 하단 또는 계정 메뉴에 있는 내 프로필을 엽니다.
  3. 설정 메뉴를 선택합니다.
  4. 전체 기록 관리를 탭합니다.
  5. 해당 Google 계정의 YouTube 기록 관리 화면을 확인합니다.
  6. 검색 아이콘을 눌러 특정 영상을 찾거나 달력 아이콘으로 날짜 범위를 살펴봅니다.

Google의 Android 공식 도움말은 프로필 사진 → 설정 → 전체 기록 관리 경로를 안내합니다. 실제 앱 버전에서는 프로필 또는 설정 메뉴의 위치가 조금 달라 보일 수 있습니다.

예전에 본 영상이 안 보인다면

다른 Google 계정에 로그인한 것은 아닌지 확인하고, 시청 당시 시청 기록 사용이 중지돼 있었는지도 살펴보세요. 기록을 끈 동안 시청한 영상은 시청 기록에 저장되지 않습니다.

또한 기록을 이미 삭제했거나 자동 삭제 설정이 적용됐다면 예전 영상이 목록에 남아 있지 않을 수 있습니다. 보이지 않는다는 사실만으로 앱 오류가 확정되는 것은 아닙니다.

3. 갤럭시에서 시청 기록 한 개만 삭제하는 방법

추천에 영향을 주는 특정 영상 하나만 없애려면 전체 기록 삭제보다 개별 기록 삭제가 적합합니다.

  1. YouTube 앱에서 프로필 → 설정 → 전체 기록 관리를 엽니다.
  2. 검색 또는 달력 기능으로 원하는 시청 기록을 찾습니다.
  3. 해당 영상 옆에 있는 X 또는 삭제 아이콘을 누릅니다.
  4. 선택한 기록이 목록에서 사라졌는지 확인합니다.
  5. 필요한 영상에 대해서만 같은 작업을 반복합니다.

개별 시청 기록을 제거하면 YouTube가 향후 맞춤 추천에 해당 시청 기록을 활용하지 않게 됩니다. 그러나 비슷한 주제의 다른 영상 시청 기록이나 좋아요·구독 등이 남아 있다면 여전히 비슷한 콘텐츠가 추천될 수 있습니다.

중요: 시청 기록에서 없애는 것은 원래 YouTube에 게시된 영상을 삭제하는 작업이 아닙니다. 영상이 내 계정의 시청 목록에서 제외되는 것이며, 원본 영상 자체나 채널을 삭제하는 것은 아닙니다.

4. 아이폰·아이패드에서 시청 기록 삭제하기

iPhone이나 iPad의 YouTube 앱에서도 기본적인 기록 관리는 Google 계정의 YouTube 기록을 통해 이루어집니다.

아이폰에서 확인할 순서

  1. iPhone에서 YouTube 앱을 엽니다.
  2. 기록을 관리할 Google 계정으로 로그인합니다.
  3. 프로필 사진 → 설정으로 이동합니다.
  4. 전체 기록 관리를 선택합니다.
  5. 특정 영상을 찾으려면 검색 아이콘이나 날짜 필터를 사용합니다.
  6. 한 개의 영상만 삭제하려면 해당 항목 옆의 삭제 아이콘을 선택합니다.
  7. 여러 기록을 한꺼번에 삭제하려면 삭제 메뉴를 눌러 기간을 확인합니다.

아이폰에 여러 Google 계정을 추가했다면 어떤 계정의 기록을 정리하는지 꼭 확인하세요. 유튜브 앱 기록은 휴대전화의 기본 사진 앱 파일과 전혀 다르며, 기록 삭제가 아이폰에 저장한 사진·동영상을 제거하는 작업은 아닙니다.

기록 전체 삭제 후에는 예전에 봤던 동영상을 시청 기록에서 다시 찾기 어려워질 수 있습니다. 과거 영상을 나중에 보고 싶다면 삭제하기 전에 별도 재생목록 등에 필요한 링크를 정리하는 편이 좋습니다.

5. PC에서 유튜브 시청 기록 전체 삭제하는 방법

컴퓨터에서는 Google 내 활동을 이용하면 관리 화면과 삭제 기간을 비교적 쉽게 확인할 수 있습니다.

PC에서 전체 또는 기간별 기록 정리

  1. 브라우저에서 Google 내 활동의 YouTube 기록으로 이동합니다.
  2. 시청 기록을 관리할 Google 계정으로 로그인합니다.
  3. YouTube 기록 → 기록 관리를 선택합니다.
  4. 화면의 삭제 메뉴를 클릭합니다.
  5. '오늘 삭제', '맞춤 기간 삭제', '모든 데이터 삭제' 등 실제로 제공되는 기간 옵션을 확인합니다.
  6. 선택한 기간에 포함된 활동이 무엇인지 검토합니다.
  7. 삭제를 확정한 뒤 기록 목록이 변경됐는지 확인합니다.

핵심 주의사항: YouTube는 '삭제'를 사용해 시청 기록을 기간별로 지우면 같은 기간의 검색 기록도 삭제된다고 설명합니다. 검색 기록은 보존하면서 특정 시청 영상만 없애고 싶은 경우에는 일괄 삭제보다 개별 영상의 X 아이콘을 이용하는 편이 목적에 가깝습니다.

'기록' 메뉴와 '내 활동' 메뉴가 다르게 보인다면

YouTube 웹사이트의 사이드바에 있는 '기록'과 Google 계정의 **'내 활동 → YouTube 기록'**은 접근 화면이 다를 수 있습니다. 기록을 찾거나 삭제할 때 계정의 내 활동 관리 화면을 기준으로 살펴보세요.

대량 삭제 이후 되돌릴 수 있나요?

Google은 기록 삭제를 추천 신호 관리 수단으로 제공하지만, 지운 모든 시청 기록을 되살리는 별도의 일반적인 '삭제 취소' 절차를 보장하지 않습니다. 삭제 전 앞으로 다시 찾아야 하는 영상이 있다면 링크를 메모하거나 적절한 재생목록에 따로 저장하세요.

6. 시청 기록 '일시중지'로 앞으로 보는 영상 기록 안 남기기

과거 영상 기록을 그대로 유지하고 이후의 시청 활동만 저장하지 않으려면 시청 기록 사용을 중지하면 됩니다.

PC에서 시청 기록 사용 중지

  1. Google 내 활동에 로그인합니다.
  2. YouTube 기록을 선택합니다.
  3. 설정 또는 제어 탭을 엽니다.
  4. YouTube 시청 기록에 관한 설정에서 '사용 중지' 또는 'YouTube에서 시청한 동영상 포함'의 선택 상태를 확인합니다.
  5. 시청 기록 저장을 중단하는 옵션을 선택합니다.
  6. 앞으로 새로 본 동영상이 시청 기록에 나타나지 않는지 확인합니다.

모바일에서 시청 기록 사용 중지

  1. YouTube 앱에서 프로필 사진을 탭합니다.
  2. 설정 → 전체 기록 관리를 엽니다.
  3. 제어 또는 설정 탭을 엽니다.
  4. 'YouTube에서 시청한 동영상 포함' 항목을 선택 해제합니다.
  5. 설정이 저장됐는지 확인합니다.

Google 공식 Android 안내는 전체 기록 관리의 제어 탭에서 'YouTube에서 시청한 동영상 포함' 선택을 해제하는 방법을 설명합니다.

기록 사용 중지와 삭제의 차이

시청 기록을 사용 중지하면 해당 상태에서 새로 시청한 영상이 기록에 저장되지 않습니다. 그러나 이전에 쌓였던 시청 기록이 자동으로 모두 지워지는 것은 아닙니다.

반대로 기존 기록을 삭제한다고 해서 앞으로 시청하는 영상의 기록 저장이 항상 중지되는 것은 아닙니다. 목적에 따라 두 설정을 따로 관리해야 합니다.

다시 맞춤 추천을 받고 싶다면 시청 기록을 다시 사용하도록 설정하세요. 기록이 꺼져 있는 동안 봤던 영상이 나중에 소급해 기록으로 자동 생성된다고 보장할 수 없습니다.

7. 시청 기록 자동 삭제 설정: 3개월·18개월·36개월

매번 기록을 수동으로 지우기 불편하다면 YouTube 기록 자동 삭제 기능을 활용할 수 있습니다.

자동 삭제 설정 방법

  1. Google 내 활동의 YouTube 기록에 접속합니다.
  2. 해당 Google 계정으로 로그인합니다.
  3. YouTube 기록 → 기록 관리로 이동합니다.
  4. **'자동 삭제'**를 선택합니다.
  5. 제공되는 보관 기간 옵션을 확인합니다.
  6. 보통 3개월, 18개월, 36개월 가운데 원하는 기간을 선택할 수 있습니다.
  7. 다음을 눌러 실제 삭제·보관 조건을 확인하고 저장합니다.

Google은 YouTube 검색 기록 공식 도움말에서 3개월·18개월·36개월 자동 삭제를 명시하고 있습니다. 다만 기존 설정이나 계정 종류, 서비스 화면에 따라 실제 선택지가 달라질 수 있으므로 현재 표시되는 옵션을 기준으로 확인하세요.

어떤 기간이 좋을까요?

  • 3개월: 오래된 시청·검색 이력을 비교적 빠르게 정리하고 싶은 사람
  • 18개월: 최근 취향에 따른 추천을 일정 기간 활용하면서 과거 기록을 정리하려는 사람
  • 36개월: 오래된 영상 기록을 나중에 찾는 일이 많은 사람

이는 공식 추천 기간이 아니라 사용 목적에 따른 선택 기준 예시입니다. 기록 삭제가 적용되면 예전 영상이나 검색어를 찾기 어려워질 수 있어 자신이 기록을 어떻게 이용하는지 먼저 생각해 보세요.

자동 삭제와 기록 일시중지를 함께 써도 되나요?

시청 기록 사용 중지는 앞으로의 기록 저장에 영향을 주고, 자동 삭제는 이미 저장된 기록의 보관 기간을 관리합니다. 기능의 목적이 다릅니다. 기록을 완전히 쌓고 싶지 않다면 사용 중지를, 기록을 활용하되 보관 기간만 제한하고 싶다면 자동 삭제를 검토하세요.

8. 검색 기록만 일시중지하거나 삭제하고 싶다면

유튜브 검색창에 입력한 단어는 시청 기록과 구분되는 검색 기록 설정으로 관리할 수 있습니다. 특정 검색어가 계속 추천 검색어로 보이거나 다른 사람이 내 검색어를 보는 것이 걱정될 때 유용합니다.

앞으로 검색 기록을 남기지 않기

  1. YouTube 앱에서 프로필 사진을 탭합니다.
  2. 설정 → 전체 기록 관리를 선택합니다.
  3. 제어 또는 설정 탭을 엽니다.
  4. 'YouTube에서 검색한 내용 포함' 항목을 선택 해제합니다.
  5. 이후 검색어가 내 YouTube 검색 기록에 저장되지 않는지 확인합니다.

Google은 검색 기록 사용 중지 상태에서 입력한 검색어가 검색 기록에 저장되지 않는다고 안내합니다.

검색어 하나만 지우기

  1. 전체 기록 관리에서 원하는 검색어를 찾습니다.
  2. 검색어나 날짜 필터로 대상을 좁힙니다.
  3. 해당 검색 항목 옆의 X 삭제 아이콘을 탭합니다.
  4. 삭제한 검색어가 기록에서 제거됐는지 확인합니다.

기간별 검색 기록 일괄 삭제 주의

검색 기록을 기간별 '삭제' 메뉴로 정리하면 선택한 기간의 시청 기록도 삭제될 수 있다는 점을 유튜브가 명확히 안내합니다. 특정 검색어 몇 개만 지우고 싶다면 전체 삭제보다는 개별 항목 삭제를 권합니다.

삭제된 검색어는 향후 검색창의 이전 검색 추천으로 나오지 않지만, 새로 검색하거나 시청한 활동에 따라 다른 추천어가 생길 수 있습니다.

9. 유튜브 추천 알고리즘 초기화: 삭제만 하면 끝일까요?

"시청 기록을 모두 지우면 유튜브 추천이 완전히 초기화되나요?"라는 질문에 대해 모든 추천 신호가 100% 사라진다고 단정할 수는 없습니다.

YouTube는 공식 고객센터에서 홈 맞춤 동영상 추천에 주로 시청 기록을 활용하지만, 좋아요·구독·검색·관심 없음 같은 다른 반응도 이용한다고 설명합니다.

추천을 바꾸고 싶을 때 권장 순서

  1. 현재 보기 싫은 주제를 유발한 시청 기록을 먼저 확인합니다.
  2. 특정 영상만 문제라면 그 영상의 시청 기록만 삭제합니다.
  3. 특정 기간에 본 영상 전체가 문제라면 기간별 삭제를 검토합니다.
  4. 현재 홈에 불필요한 동영상이 남아 있다면 **'관심 없음'**을 선택합니다.
  5. 같은 채널의 추천이 반복된다면 **'채널 추천 안함'**을 사용합니다.
  6. 새로운 주제의 영상을 꾸준히 시청하고 관련 채널을 구독하면서 추천 변화를 살펴봅니다.
  7. 정말 홈 맞춤 추천 자체를 원하지 않는다면 시청 기록 삭제와 사용 중지를 함께 검토합니다.

이 순서는 공식 기능을 사용해 추천 신호를 관리하는 실용적인 절차 제안이지 YouTube가 발표한 '알고리즘 완전 초기화 버튼'은 아닙니다.

삭제했는데도 비슷한 영상이 나오는 이유

좋아요를 표시했거나 구독 중인 채널, 현재 시청 중인 영상의 주제 같은 신호가 남아 있을 수 있습니다. 특히 YouTube는 '다음에 볼 동영상' 추천에서는 지금 재생 중인 영상을 주요 신호로 사용한다고 안내합니다.

따라서 홈 추천을 바꾸고 싶다고 모든 댓글·구독·영상 목록을 삭제해야 하는 것은 아닙니다. 필요한 추천 신호부터 정리하세요.

10. 추천 영상에 '관심 없음'·'채널 추천 안함' 설정하기

유튜브에서 관심 없는 영상 하나 때문에 시청 기록 전체를 삭제할 필요는 없습니다. 홈 화면 또는 다음 볼만한 동영상 영역에서 직접 추천 신호를 조정할 수 있습니다.

'관심 없음' 선택

  1. 유튜브 홈에서 보고 싶지 않은 동영상을 찾습니다.
  2. 제목 옆의 **점 세 개(더보기)**를 누릅니다.
  3. **'관심 없음'**을 선택합니다.
  4. 가능한 경우 **'이유를 알려주세요'**를 선택합니다.
  5. '이미 시청한 동영상입니다' 또는 '동영상이 마음에 들지 않습니다' 등 실제 이유에 맞는 응답을 선택합니다.

YouTube는 이 피드백을 추천 조정의 신호로 활용한다고 설명합니다. 하지만 특정 주제의 영상이 앞으로 절대로 나타나지 않는다는 보장은 아닙니다.

'채널 추천 안함' 선택

  1. 홈 또는 다음에 볼 동영상 목록에서 원치 않는 채널의 영상을 찾습니다.
  2. 해당 영상의 더보기를 누릅니다.
  3. **'채널 추천 안함'**을 선택합니다.
  4. 추천 목록에서 변화가 있는지 확인합니다.

이는 채널을 신고하거나 차단하는 것과 같은 기능이 아닙니다. 특정 채널을 홈·다음 볼만한 동영상 추천에 표시하지 않기를 원한다는 피드백입니다.

실수로 '관심 없음'을 눌렀다면

Google은 내 활동의 기타 Google 활동 → YouTube '관심 없음' 의견 → 삭제에서 해당 피드백을 삭제할 수 있다고 안내합니다.

다만 이 메뉴는 기존 '관심 없음' 및 '채널 추천 안함' 피드백을 일괄적으로 초기화하는 성격이 있으므로, 잘못 누른 영상 하나만 복구할 수 있다고 단정하지 말고 실제 확인 화면을 읽고 진행하세요.

11. 유튜브 쇼츠가 너무 많이 나온다면 'Shorts 동영상 적게 표시'

유튜브 쇼츠를 짧게 한두 개 봤을 뿐인데 홈 화면에 짧은 영상이 계속 나타나 불편할 수 있습니다. YouTube 공식 도움말은 'Shorts 동영상 적게 표시' 기능을 안내합니다.

12. 시청 기록을 끄면 홈 추천 동영상이 사라지는 이유

시청 기록을 모두 삭제하고 나서 기록 사용 중지까지 했더니 유튜브 홈에 예전처럼 추천 동영상이 표시되지 않는 경우가 있습니다.

Google은 유의미한 기존 시청 기록이 없고 시청 기록이 꺼져 있다면 홈 화면의 맞춤 동영상 추천이 사라진다고 공식 안내합니다. 이 경우에는 홈의 검색창과 왼쪽 탐색 메뉴만 중심적으로 표시될 수 있습니다.

홈 추천을 다시 받고 싶다면

  1. Google 내 활동의 YouTube 기록을 엽니다.
  2. YouTube 기록의 제어·설정에서 시청 기록 사용 여부를 확인합니다.
  3. 앞으로 시청한 동영상을 저장하려면 다시 시청 기록을 사용하도록 설정합니다.
  4. 본인이 관심 있는 콘텐츠를 실제로 시청합니다.
  5. 일정한 시청 활동이 쌓인 뒤 홈 추천 상태를 살펴봅니다.

시청 기록을 켰다고 해서 이전에 삭제했던 기록이 자동으로 복원되는 것은 아닙니다. 시청 기록이 거의 없다면 추천이 다시 개인화되기까지 실제 시청 활동이 필요할 수 있습니다.

오히려 추천을 없애고 싶다면

관심 없는 영상을 계속 보여 주는 홈 화면 대신 검색과 구독 채널 중심으로 이용하고 싶다면, 기록을 지우고 사용 중지하는 선택이 의도에 맞을 수 있습니다. 다만 추천 영상이 사라지는 것까지 이해하고 결정해야 합니다.

13. 스마트 TV·게임 콘솔 유튜브 기록도 관리할 수 있나요?

스마트 TV나 게임 콘솔의 YouTube 앱에서도 시청 기록을 일시중지하거나 삭제할 수 있습니다.

TV에서 시청 기록 일시중지

  1. TV에서 YouTube 앱을 실행합니다.
  2. 왼쪽 메뉴의 설정으로 이동합니다.
  3. **'시청 기록 일시중지'**를 찾습니다.
  4. 표시되는 확인 버튼으로 사용 중지를 적용합니다.

TV에서 시청 기록 삭제

  1. YouTube 앱의 설정을 엽니다.
  2. **'시청 기록 삭제'**를 선택합니다.
  3. 확인 화면에서 삭제 범위와 영향을 읽습니다.
  4. **'시청 기록 지우기'**를 실행합니다.

TV에는 가족 구성원이 서로 다른 Google 계정으로 로그인해 있을 수 있습니다. 따라서 반드시 어느 계정의 기록을 변경하는지 확인하세요.

또한 TV나 콘솔에 저장된 기록을 지웠더라도 같은 계정으로 스마트폰·PC를 사용하면 다시 시청 기록이 쌓일 수 있습니다. 계정 기록 설정과 기기별 로그인 상태를 구분해야 합니다.

① 다른 Google 계정에 로그인했나요?

② 시청 기록이 사용 중지 상태인가요?

시청 기록을 일시중지한 동안 본 영상은 시청 기록에 표시되지 않습니다. 전체 기록 관리의 제어·설정 탭에서 기록 저장 상태를 확인하세요.

3개월 등의 자동 삭제 옵션이 켜져 있다면 오래된 기록이 자동으로 정리될 수 있습니다. 원하는 기록 보관 기간이 맞는지 점검하세요.

④ 시크릿 모드로 시청했나요?

시크릿 모드에서 탐색한 활동은 일반적인 로그인 계정의 검색·시청 기록과 다르게 처리될 수 있습니다. 개인 계정의 기록에 남기고 싶다면 시크릿 모드 이용 여부를 확인하세요.

⑤ 앱 표시 문제인지 계정 기록 문제인지 확인

YouTube 앱의 일반 시청 기록 화면에서는 일부 과거 활동이 바로 보이지 않더라도 Google 내 활동 → YouTube 기록 → 기록 관리에서 날짜·검색 기준으로 다시 확인해 보세요. 다른 기기에서도 같은 계정으로 비교하면 표시 문제를 구분하는 데 도움이 됩니다.

시청 기록이 안 보인다는 이유만으로 전체 기록 삭제 버튼을 먼저 누르는 것은 피하세요. 오히려 원래 남아 있던 기록까지 삭제할 수 있기 때문입니다.

자주 묻는 질문 FAQ

Q1. 유튜브 시청 기록을 삭제하면 추천 알고리즘이 초기화되나요?

삭제한 시청 기록은 향후 맞춤 동영상 추천에 사용되지 않습니다. 다만 좋아요·검색·구독 등 다른 신호가 남을 수 있으므로 완전히 새 계정과 같은 상태가 된다고 보장할 수 없습니다.

Q2. 유튜브 시청 기록을 모두 삭제하면 검색 기록도 없어지나요?

Google은 YouTube 기록 관리에서 기간 단위 **'삭제'**를 실행하면 해당 기간의 시청 기록과 검색 기록이 함께 삭제된다고 안내합니다. 특정 영상 한 개만 없애고 싶다면 개별 항목의 삭제 기능을 이용하세요.

Q3. 유튜브 시청 기록을 일시중지하면 기존 기록도 삭제되나요?

아닙니다. 사용 중지는 앞으로 시청한 영상을 기록에 저장하지 않는 설정입니다. 기존 기록 전체를 없애는 것은 별도의 삭제 작업입니다.

Q4. 아이폰과 갤럭시에서 기록 삭제 방법이 다른가요?

유튜브 앱의 메뉴 배치는 다소 달라도 기본적으로 프로필 → 설정 → 전체 기록 관리에서 Google 계정의 YouTube 기록을 관리합니다. 계정을 정확히 확인하세요.

Q5. 유튜브 시청 기록은 몇 개월마다 자동 삭제할 수 있나요?

Google은 YouTube 기록에 3개월·18개월·36개월 등의 자동 삭제 옵션을 안내합니다. 실제 계정 화면에 제공되는 기간을 확인하고 선택하세요.

Q6. 유튜브 홈에 추천 영상이 안 나옵니다. 오류인가요?

시청 기록이 거의 없는 상태에서 시청 기록까지 사용 중지했다면 홈의 맞춤 추천이 사라질 수 있습니다. Google이 안내하는 정상적인 동작입니다. 다시 추천을 받고 싶다면 기록 저장을 켜고 관심 있는 영상을 시청하세요.

Q7. 유튜브 쇼츠를 완전히 없앨 수 있나요?

YouTube 고객센터는 'Shorts 동영상 적게 표시' 기능을 안내합니다. 이 기능은 쇼츠 노출을 줄이라는 피드백이며 모든 쇼츠를 영구적으로 차단한다고 보장하지는 않습니다.

Q8. 특정 채널 추천만 안 나오게 할 수 있나요?

홈이나 다음 볼만한 동영상에서 해당 채널 콘텐츠의 더보기 메뉴를 열고 **'채널 추천 안함'**을 선택할 수 있습니다. 필요하다면 '관심 없음' 의견도 함께 사용할 수 있습니다.

Q9. 유튜브 검색창의 예전 검색어를 없애려면 어떻게 하나요?

설정 → 전체 기록 관리에서 검색 기록을 확인하고 개별 검색어를 삭제하거나 검색 기록 저장을 중지할 수 있습니다. 기간별 삭제는 시청 기록에도 영향을 줄 수 있으므로 주의하세요.

Q10. 스마트 TV에서 본 유튜브도 시청 기록에 남나요?

TV에 로그인한 Google 계정의 YouTube 시청 기록 설정에 따라 남을 수 있습니다. TV 앱 설정에서도 일시중지·삭제를 관리할 수 있으며, 다른 가족의 계정과 혼동하지 않도록 로그인 상태를 확인해야 합니다.
