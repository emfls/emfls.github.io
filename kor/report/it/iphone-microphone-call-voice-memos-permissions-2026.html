2. 첫 번째 테스트: 음성 메모로 내장 마이크 확인하기

통화에서 상대방이 내 목소리를 못 듣는다면 Apple은 음성 메모(Voice Memos) 앱을 사용해 마이크를 확인하도록 안내합니다.

  1. 아이폰에서 음성 메모 앱을 엽니다.
  2. 녹음 버튼을 탭합니다.
  3. 아이폰 하단에 대고 평소 말하는 목소리로 말합니다.
  4. 녹음을 중지합니다.
  5. 방금 녹음한 파일을 재생합니다.
  6. 자신의 목소리가 명확하게 들리는지 확인합니다.

결과별 판단

  • 목소리가 선명함: 기본 녹음 경로는 작동하고 있을 가능성이 있습니다. 전화·통화 앱·액세서리·네트워크 등 다른 원인도 확인하세요.
  • 소리가 거의 없거나 매우 작음: 케이스·보호필름·이물질·연결된 외부 마이크 등을 점검한 뒤 다시 테스트합니다.
  • 잡음·끊김이 심함: 주변 환경을 조용하게 바꾸고 동일한 방식으로 재녹음해 비교합니다.

주의: 음성 메모에서 정상으로 들린다고 모든 통화 앱의 음성 입력이 반드시 정상인 것은 아닙니다. 반대로 음성 메모에서 이상이 있다고 해서 부품 불량으로 확정되는 것도 아닙니다. 테스트는 원인을 구분하는 첫 단계입니다.

공식 출처: Apple — 전화 통화 중 상대방이 내 말을 듣지 못하는 경우

3. 두 번째 테스트: 스피커폰·영상 녹화에서 마이크 확인

일반 통화는 되지만 스피커폰으로 통화하면 상대방이 내 목소리를 못 듣는다면, Apple은 카메라 앱에서 전면·후면 동영상을 녹화해 보라고 안내합니다.

  1. 아이폰 카메라 앱을 실행합니다.
  2. 비디오 모드로 변경합니다.
  3. 아이폰 상단에 대고 짧게 말하면서 영상을 촬영합니다.
  4. 카메라 전환 버튼을 눌러 다른 카메라로 바꿉니다.
  5. 다시 아이폰 상단에 대고 말하며 영상을 촬영합니다.
  6. 두 영상을 재생해 목소리가 모두 명확하게 녹음됐는지 비교합니다.

중요: 기종별 내부 마이크가 물리적으로 어디에 있는지를 임의로 특정해 테이프를 붙이거나 도구를 넣는 방식으로 테스트하지 마세요. Apple 공식 안내에 따라 녹음하고 재생 결과를 비교하는 것만으로도 유용한 단서를 얻을 수 있습니다.

4. 케이스·보호필름·먼지 때문에 목소리가 작을 수도 있습니다

Apple은 마이크 문제 해결의 첫 단계로 화면 보호필름과 케이스를 제거하고 개방부의 부스러기를 제거하라고 안내합니다.

  • 케이스가 마이크 부근을 가리고 있지 않은지 확인합니다.
  • 잘못 부착된 보호필름이나 부착물이 개방부를 막고 있지 않은지 확인합니다.
  • 눈에 보이는 이물질이 있는지 살펴봅니다.
  • 액체를 넣거나 금속 핀으로 개방부를 찌르는 행동은 피합니다.
  • 물기·외부 충격 후 문제가 생겼다면 무리하게 분해하지 말고 공식 서비스를 검토합니다.

왜 액세서리부터 제거할까요? 다른 설정을 바꾸지 않고 케이스를 제거한 전후의 녹음 결과만 비교하면 간단한 차단 문제인지 구분하는 데 도움이 됩니다.

다만 Apple 공식 문서의 '부스러기 제거'를 내부 마이크를 날카로운 도구로 긁으라는 뜻으로 해석해서는 안 됩니다. 안전한 방법으로 해결이 어렵다면 서비스센터에 점검을 요청하세요.

공식 출처: Apple — 마이크 개방부 점검

5. 카카오톡·인스타그램·회의 앱에서만 마이크가 안 될 때

일반 전화나 음성 메모는 정상인데 특정 앱에서만 내 목소리가 전달되지 않는다면 마이크 하드웨어보다 앱별 마이크 접근 권한을 먼저 확인하는 것이 효율적입니다.

앱별 마이크 허용 확인

  1. 설정 앱을 엽니다.
  2. 개인정보 보호 및 보안을 누릅니다.
  3. 마이크를 엽니다.
  4. 문제가 있는 앱이 목록에 있는지 확인합니다.
  5. 해당 앱의 마이크 접근이 꺼져 있다면 사용 목적을 확인하고 허용합니다.
  6. 앱을 다시 열어 음성통화·음성 녹음을 재시도합니다.

Apple은 마이크 접근 권한이 이미 켜져 있거나 해당 앱이 목록에 보이지 않는데도 문제가 지속되면 앱 개발자에게 문의하라고 안내합니다.

주의: 앱이 목록에 없다고 반드시 앱 오류라는 뜻은 아닙니다. 아직 해당 앱이 마이크 접근을 요청하지 않았을 수 있으므로 앱의 실제 음성 기능을 사용해 권한 요청이 나타나는지 확인하세요.

앱에 권한을 허용한 후에도 통화 연결 상태나 음성 입출력 장치 설정이 맞지 않으면 문제가 계속될 수 있습니다.

공식 출처: Apple — 특정 앱에서 마이크가 작동하지 않는 경우

6. 통화 중 '음성 분리·표준·자동' 마이크 모드 확인하기

Apple은 iPhone에서 음성 분리(Voice Isolation), 표준, 자동 등 마이크 모드를 지원합니다. 음성 분리는 주변 소음을 줄이고 사용자의 목소리를 우선 처리하는 방식입니다.

통화 중 마이크 모드 확인 경로

  1. 전화·FaceTime 또는 지원되는 앱의 통화 중에 제어 센터를 엽니다.
  2. 화면 상단의 전화 또는 현재 앱 제어기를 누릅니다.
  3. 오디오 및 비디오 → 마이크 모드를 찾습니다.
  4. 사용 목적에 맞게 자동·표준·음성 분리를 비교합니다.
  5. 상대방에게 목소리 전달 상태를 다시 확인합니다.

주의: 일반 셀룰러 전화 통화에서는 와이드 스펙트럼을 사용할 수 없습니다. 또한 모든 iPhone과 iOS·앱에서 모든 마이크 모드를 지원하는 것은 아닙니다.

Apple 공식 안내 기준으로 셀룰러 전화의 음성 분리는 iOS 16.4 이후, 자동 마이크 모드는 iOS 18 이후, 녹음 앱의 음성 분리는 iOS 26 이후에 제공되는 기능입니다. 음성 분리·와이드 스펙트럼의 지원 iPhone은 iPhone XR·XS 및 이후 모델입니다.

핵심: 음성 분리는 목소리 처리 방식이지 물리적인 마이크 고장을 수리하는 기능이 아닙니다. 녹음 테스트 자체가 불명확한 경우에는 모드를 바꿔도 문제가 해결되지 않을 수 있습니다.

공식 출처: Apple — 음성 분리·와이드 스펙트럼·자동 마이크 모드

7. iOS 26.1 이상: USB-C 외장 마이크 입력 게인 확인

iOS 26.1부터는 지원되는 유선 마이크와 기기에서 입력 게인(입력 음량)을 조정할 수 있습니다. Apple은 USB-C EarPods를 예로 듭니다.

설정 순서

  1. 지원되는 유선 마이크를 연결하고 통화 또는 녹음을 시작합니다.
  2. 제어 센터를 엽니다.
  3. 상단의 현재 앱 제어기를 누릅니다.
  4. 오디오 입력 영역에서 게인 조정 슬라이더가 나타나는지 확인합니다.
  5. 지원되는 경우 슬라이더로 입력 레벨을 조절한 뒤 다시 녹음합니다.

중요: 모든 유선 이어폰과 마이크에서 이 기능을 사용할 수 있는 것은 아닙니다. 지원되는 기기에서만 나타나는 기능이며, 일반적인 iPhone 내장 마이크의 물리적 감도를 무조건 높이는 설정은 아닙니다.

iOS 26.1 이전 버전에서는 이 메뉴가 표시되지 않을 수 있으므로 '슬라이더가 보이지 않음 = 기기 고장'이라고 판단하면 안 됩니다.

8. 이어폰·에어팟·외장 마이크로 통화할 때만 문제가 생긴다면

아이폰 내장 마이크에서는 정상인데 이어폰을 연결한 상태에서만 상대방이 목소리를 못 듣는다면 아이폰 내부 마이크 문제로 단정하지 마세요.

일반 유선 헤드셋 점검

Apple은 헤드폰 마이크 문제가 있을 때 다음을 확인하도록 안내합니다.

  1. 해당 헤드폰에 마이크가 실제로 내장되어 있는지 확인합니다.
  2. 마이크 부분에 이물질·보풀·비닐 등 장애물이 없는지 확인합니다.
  3. 케이블·커넥터가 손상되지 않았는지 확인합니다.
  4. 다른 헤드셋으로 비교합니다.
  5. 다른 헤드셋에서는 정상이라면 기존 헤드셋 제조사에 문의합니다.

여러 입력 기기가 연결되어 있다면

Apple은 iOS의 통화·녹음 제어기에서 오디오 입력 장치를 선택할 수 있다고 안내합니다.

통화·녹음 중 → 제어 센터 → 현재 앱 제어기 → 오디오 입력 → 사용할 마이크 선택

실제 지원 여부는 기기·액세서리·앱에 따라 달라집니다.

이 설정은 상대방의 목소리가 어느 스피커에서 출력되는지와는 다른 항목입니다. '마이크 입력'과 '스피커 출력'을 혼동하지 마세요.

9. 내가 상대방의 목소리를 못 듣는다면 마이크가 아니라 스피커 확인

전화 통화에서 상대방이 내 목소리를 잘 듣지만 나는 상대방 목소리가 안 들린다면, 먼저 수신기·스피커 출력 문제를 의심해야 합니다.

Apple이 제시하는 기본 점검은 다음과 같습니다.

  1. 통화 중 음량 버튼을 눌러 음량을 조절합니다.
  2. 스피커폰을 켰을 때 소리가 들리는지 비교합니다.
  3. 케이스·화면 보호필름을 제거해 수신기 개방부가 막혀 있는지 확인합니다.
  4. 필요하면 깨끗하고 물기가 없는 부드러운 소형 브러시를 이용해 개방부를 조심스럽게 점검합니다.
  5. 설정 → 사운드 및 햅틱에서 벨소리·알림 슬라이더로 소리 출력이 가능한지 확인합니다.
  6. 특정 장소나 통화에서만 잡음이 심하다면 네트워크·수신 상태도 비교합니다.

수신기에서 아무 소리도 나지 않거나 스피커 버튼이 회색으로 표시된다면 서비스 점검이 필요할 수 있다는 것이 Apple의 안내입니다.

중요: 이어폰이나 차량 오디오로 통화가 연결되어 소리가 그쪽으로 출력될 수도 있으므로, 연결된 Bluetooth 액세서리의 오디오 출력 상태도 확인해야 합니다.

10. 재시동·iOS 업데이트는 언제 확인할까요?

기본 녹음 테스트를 거친 뒤에도 앱·통화마다 문제가 반복된다면, 데이터 삭제를 동반하지 않는 기본 소프트웨어 점검을 진행할 수 있습니다.

  • 아이폰을 정상적인 방법으로 재시동합니다.
  • 설정 → 일반 → 소프트웨어 업데이트에서 지원되는 최신 버전이 있는지 확인합니다.
  • 중요 데이터의 백업 상태를 확인하고 필요한 업데이트를 진행합니다.
  • 앱에서만 문제가 나타나면 해당 앱의 업데이트도 확인합니다.
  • 설정을 한꺼번에 바꾸지 말고 한 단계 후 음성 메모·통화·영상 테스트를 다시 실행합니다.

Apple은 헤드폰 관련 사운드 문제에서 iOS 최신 버전과 기기 재시동을 권장합니다. 이는 진단의 보조 단계이지 모든 마이크 문제를 자동으로 해결한다는 뜻은 아닙니다.

초기화 주의: 마이크에 문제가 있다는 이유로 '모든 콘텐츠 및 설정 지우기'를 바로 실행하지 마세요. 사진·앱 데이터·계정 설정을 잃을 위험이 있고, 물리적 마이크 문제라면 기기 초기화가 해결책이 아닐 수 있습니다.

11. 10분 자가 진단: 수리를 맡기기 전 확인할 것

아래 표는 Apple 공식 테스트를 일반 사용자가 데이터 손실 없이 따라가기 쉬운 순서로 정리한 것입니다.

단계테스트결과에 따른 판단
1상대방이 내 말을 못 듣는지, 내가 상대방을 못 듣는지 구분입력과 출력 문제 분리
2이어폰·외장 마이크·케이스 제거외부 액세서리 영향 비교

4카메라 전면·후면 동영상 녹음영상·스피커폰 관련 입력 확인
5문제 앱의 마이크 접근 허용 확인앱 권한 문제 구분
6통화 중 마이크 모드 비교처리 모드 영향 확인
7연결된 외장 마이크의 입력 선택 확인다른 장치로 입력되는 문제 분리

9기기 재시동·지원 iOS 업데이트 점검소프트웨어 상태 비교
10모든 테스트가 불명확하면 Apple 지원 문의공식 서비스 진단 연결

문제 재현 기록 예시

  • 이어폰 연결: 정상 / 비정상

이렇게 기록하면 서비스를 받을 때도 증상을 구체적으로 전달하기 쉽습니다. 위 표는 공식 자료를 조합한 사용자용 진단 절차이며, 특정 아이폰의 실험 결과를 인용한 것이 아닙니다.

12. 증상별 원인 구분: 하드웨어 고장이라고 단정하지 마세요

① 음성 메모가 정상인데 카카오톡 통화만 안 됨

앱의 마이크 권한, 앱 오디오 장치 설정, 앱 자체 문제를 우선 확인합니다. Apple은 앱이 이미 권한을 갖고 있거나 목록에 없는데도 문제면 앱 개발자에게 문의하도록 안내합니다.

② 음성 메모는 정상인데 스피커폰만 문제

카메라에서 전·후면 영상을 각각 녹음해 결과를 비교합니다. Apple의 공식 스피커폰 진단 경로입니다.

③ 이어폰을 빼면 정상

해당 헤드셋의 마이크 지원 여부와 이물질·연결 상태를 점검합니다. 다른 이어폰으로 비교해 보세요.

④ 모든 녹음과 통화에서 음성이 계속 불명확

케이스·보호필름 제거, 개방부 상태 확인 후에도 지속된다면 Apple 공식 서비스를 검토합니다.

⑤ 내가 상대방 목소리를 못 들음

마이크보다 수신기·스피커·오디오 출력 장치 문제를 점검합니다. 무음·잡음 등의 증상은 통화 환경과 네트워크 상태도 비교하세요.

원인은 여러 개가 겹칠 수 있으므로 테스트 한 번으로 부품 교체 여부를 확정하지 않는 것이 중요합니다.

13. 자주 묻는 질문

Q1. 아이폰 통화에서 상대방이 제 목소리를 못 들어요.

먼저 음성 메모 앱에서 아이폰 하단에 대고 말하며 녹음한 뒤 재생해 보세요. 음성이 불명확하면 케이스·보호필름·마이크 개방부를 점검하고, 정상이라면 통화 앱·이어폰·네트워크 등 다른 원인을 확인하세요.

Q2. 카카오톡 음성통화에서만 마이크가 안 됩니다.

설정 → 개인정보 보호 및 보안 → 마이크에서 카카오톡의 접근 권한을 확인하세요. 권한이 이미 켜져 있는데도 실패하면 앱 업데이트와 해당 앱 개발사의 지원을 검토합니다.

Q3. 음성 메모는 정상인데 영상 녹음은 소리가 작아요.

Apple은 전면·후면 카메라로 영상을 각각 촬영해 녹음 결과를 비교하도록 안내합니다. 외부 마이크가 연결됐는지도 확인하고, 계속 불명확하면 공식 진단을 받는 것이 적절합니다.

Q4. iOS 26에서 음성 분리를 켜면 마이크 고장이 해결되나요?

아니요. 음성 분리는 배경 소음을 줄이는 오디오 처리 기능입니다. 물리적으로 녹음 입력이 불량한 문제를 수리하는 기능은 아닙니다. 음성 메모와 동영상 진단을 먼저 진행하세요.

Q5. 통화 중 마이크 모드 메뉴가 안 보여요.

마이크 모드 지원 여부는 iOS 버전·아이폰 모델·사용 중인 앱에 따라 다릅니다. 통화·녹음 중 제어 센터의 앱 제어기에서 찾고, 지원 조건은 Apple 공식 안내를 확인하세요.

Q6. USB-C 이어폰 마이크가 너무 작아요.

지원되는 기기와 iOS 26.1 이후에서는 통화·녹음 중 제어 센터의 앱 제어기에서 오디오 입력 게인을 조정할 수 있습니다. 모든 유선 마이크가 지원되는 것은 아니므로 해당 모델의 호환성을 확인하세요.

Q7. 블루투스 이어폰에서는 제 목소리가 안 들린다고 하는데요?

이어폰을 해제하고 아이폰 내장 마이크로 음성 메모·통화를 비교하세요. 내장 마이크만 정상이라면 이어폰 마이크·연결·입력 장치 선택을 점검해야 합니다.

Q8. 아이폰 화면 위쪽의 마이크가 고장인지 확인하려면요?

Apple은 카메라 앱에서 전면·후면 영상으로 아이폰 상단에 대고 말하면서 녹음해 비교하는 방법을 안내합니다. 각 기종의 내부 마이크 위치를 임의로 분해해서 확인하지 마세요.

Q9. 제가 상대방 목소리를 못 들으면 마이크를 교체해야 하나요?

아닐 수 있습니다. 상대방 음성이 내 아이폰에서 들리지 않는 현상은 스피커·수신기·오디오 출력·네트워크와 관련될 수 있습니다. 통화 음량·스피커폰·연결된 오디오 기기부터 비교하세요.

Q10. 초기화하면 아이폰 마이크 오류가 해결되나요?

초기화가 마이크 문제를 반드시 해결한다는 근거는 없습니다. 음성 메모·동영상 테스트·앱 권한·외부 마이크·케이스를 먼저 확인하고, 여러 환경에서 문제가 지속되면 Apple 공식 서비스로 진단받으세요.

14. 최종 체크리스트

  • ☐ 내 음성이 상대방에게 안 들리는지, 내가 상대방 음성을 못 듣는지 구분했다.
  • ☐ 케이스·화면 보호필름 등이 마이크 개방부를 막는지 확인했다.
  • ☐ 음성 메모에서 아이폰 하단에 대고 녹음했다.
  • ☐ 카메라 전면·후면 동영상에서 녹음 상태를 비교했다.
  • ☐ 특정 앱만 문제라면 마이크 접근 권한을 확인했다.
  • ☐ 통화 중 음성 분리·표준·자동 모드를 필요에 따라 비교했다.
  • ☐ 외부 이어폰·USB-C 마이크 사용 여부와 입력 장치를 확인했다.
  • ☐ 내가 상대방을 못 듣는 증상이라면 스피커·출력 문제를 점검했다.
  • ☐ 재시동과 소프트웨어 업데이트 상태를 확인했다.
  • ☐ 무리한 분해·날카로운 도구 사용·성급한 초기화를 피했다.
  • ☐ 여러 녹음 방식에서 계속 불명확하다면 Apple 공식 서비스로 연결했다.

결론: 아이폰 마이크가 작동하지 않는 것처럼 보일 때는 음성 메모 → 전·후면 동영상 → 앱별 권한 → 외부 마이크·오디오 모드 순서로 점검하면 원인을 빠르게 좁힐 수 있습니다. 특히 마이크 입력과 스피커 출력을 혼동하지 않는 것이 불필요한 초기화나 수리 비용을 피하는 첫 단계입니다.
