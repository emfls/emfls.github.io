갤럭시에서 카카오톡이나 문자로 받은 링크를 누르면 삼성 인터넷 대신 크롬으로 열고 싶은데 계속 이전 브라우저가 실행되거나, Google 메시지를 쓰고 싶은데 삼성 메시지로 열리는 경우가 있습니다. 반대로 유튜브 링크를 브라우저가 아니라 유튜브 앱에서 열고 싶을 때도 있습니다.

이런 문제는 모두 '기본 앱'과 관계가 있지만 기본 브라우저 선택, 기본 SMS 앱 선택, 특정 앱의 지원 링크 열기는 서로 다른 설정입니다. 하나만 바꿔서 해결되지 않을 때 나머지 두 설정도 구분해서 살펴봐야 합니다.

이 글은 2026년 11월 4일 기준 삼성전자와 Google 공식 도움말을 바탕으로 갤럭시 기본 앱의 변경·복구·문제 해결을 정리했습니다. One UI와 설치된 앱, 통신사, 국가에 따라 메뉴 이름과 지원 항목은 다를 수 있습니다.

바로가기: 가장 일반적인 설정 경로는 설정 → 애플리케이션(앱) → 기본 앱 선택입니다. 여기에서 기본 브라우저와 SMS 앱 등 사용 가능한 범주의 기본 앱을 변경할 수 있습니다.

1. 증상에 맞는 메뉴부터 찾기

삼성전자는 설정 → 앱 → 기본 앱 선택에서 브라우저 앱 등 범주별 기본 앱을 지정할 수 있다고 공식 안내합니다. Google도 Android에서 같은 경로를 기준으로 기본 브라우저를 바꾸는 방법을 제공합니다.

공식 자료: Samsung — 갤럭시 앱 관리 및 기본 앱 변경, Google — Android 기본 브라우저 변경

2. 갤럭시 기본 브라우저 바꾸는 방법

삼성 인터넷으로 열리던 웹 링크를 크롬으로 열거나, 반대로 크롬 대신 삼성 브라우저를 사용하려면 다음 절차를 따르면 됩니다.

  1. 갤럭시의 설정 앱을 엽니다.
  2. 애플리케이션 또는 앱을 선택합니다.
  3. 화면 상단의 기본 앱 선택을 누릅니다.
  4. 브라우저 앱을 선택합니다.
  5. 목록에서 Chrome 또는 삼성 인터넷(Samsung Browser)을 선택합니다.
  6. 설정을 닫고 메신저나 문자에서 일반 웹 링크를 열어 결과를 확인합니다.

예시: 뉴스 기사나 검색 결과가 삼성 인터넷에서 열리는 것이 불편하다면 Chrome을 기본 브라우저로 선택합니다. 주소창이 하단에 있는 삼성 인터넷 환경을 선호하면 다시 삼성 인터넷을 선택할 수 있습니다.

설정이 보이지 않나요? 갤럭시 모델에 따라 애플리케이션 → 기본 앱 선택이라는 이름 대신 '앱 → 기본 앱'처럼 표시될 수 있습니다. 설정 앱 상단 검색창에 기본 앱을 입력하는 방법도 있습니다.

공식 자료: Samsung — 기본 앱 변경하기, Google — 기본 브라우저 변경

3. 삼성 인터넷에서 크롬으로 기본 앱 변경하기

Chrome을 설치해 놓아도 설치만으로 기본 브라우저가 자동 변경된다고 가정해서는 안 됩니다. 다음과 같이 진행합니다.

  1. Play 스토어에서 Chrome이 설치되어 있는지 확인합니다.
  2. 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱으로 이동합니다.
  3. Chrome을 선택합니다.
  4. 기본 브라우저 선택 화면에 Chrome이 체크됐는지 확인합니다.
  5. 일반 웹사이트 주소가 담긴 테스트 링크를 열어 봅니다.

크롬을 선택했는데 삼성 인터넷으로 계속 열리면?

링크를 누른 위치에 따라 결과가 달라질 수 있습니다.

  • 일반 웹 링크: 기본 브라우저 설정을 따르는 경우가 많습니다.
  • 특정 앱의 내부 브라우저: 카카오톡·SNS 등 앱 안에서 자체 화면을 표시할 수 있습니다.
  • 지원 링크(App Links): 해당 도메인을 등록한 전용 앱이 열릴 수 있습니다.
  • 별도 열기 버튼: 앱 안에서 '브라우저로 열기'를 직접 누른 경우에는 앱 자체 동작이 적용될 수 있습니다.

따라서 모든 웹 링크가 예외 없이 Chrome만 열어야 한다고 보기는 어렵습니다. 기본 브라우저 선택 후에도 특정 서비스 링크만 다르게 열린다면 6번 '지원 링크 열기'를 점검하세요.

공식 자료: Samsung — 기본 브라우저 선택, Samsung — Samsung Browser 기본 앱 설정

4. 크롬에서 삼성 인터넷으로 다시 바꾸는 방법

삼성 인터넷은 일부 공식 글로벌 페이지에서 Samsung Browser라고 표기되기도 합니다.

  1. Galaxy Store 등 공식 스토어에서 삼성 인터넷/삼성 브라우저가 설치되어 있는지 확인합니다.
  2. 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱을 엽니다.
  3. 삼성 인터넷 또는 Samsung Browser를 선택합니다.
  4. 일반 웹 주소를 눌러 기본 브라우저가 바뀌었는지 확인합니다.

삼성은 자체 지원 문서에서 Settings → Apps → Choose default apps → Browser app → Samsung Browser 경로를 명시합니다.

삼성 인터넷이 목록에 없을 때

  • 앱이 설치되어 있는지 확인합니다.
  • 앱이 사용 중지되어 있지 않은지 확인합니다.
  • 최신 버전으로 업데이트 가능한지 확인합니다.
  • 설치된 앱이 해당 기기에서 브라우저 기본 역할을 지원하는지 확인합니다.

표시가 달라지더라도 기본 앱은 앱 목록이 아니라 '기본 앱 선택'의 브라우저 앱 항목에서 지정한다는 점을 기억하세요.

공식 자료: Samsung — 삼성 브라우저 사용법 및 기본 설정, 삼성 대한민국 — 삼성 브라우저 기능

5. 삼성 메시지 대신 Google 메시지를 기본 SMS 앱으로 바꾸기

새 갤럭시에서 문자 메시지 앱이 바뀌어 낯설거나, 원하는 메시지 앱으로 문자 메시지를 받으려면 SMS 앱 설정을 확인합니다.

  1. 휴대폰의 설정 → 애플리케이션으로 이동합니다.
  2. 기본 앱 선택을 누릅니다.
  3. SMS 앱을 선택합니다.
  4. 사용할 메시지 앱을 선택합니다.
  5. 해당 앱을 실행해 대화 목록과 수신 상태를 확인합니다.

Google 메시지 도움말은 설정 → 앱 → 기본 앱 → SMS 앱으로 이동해 문자 기본 앱을 변경한다고 안내합니다.

Google 메시지가 기본 앱으로 지정되어야 하는 이유

Google은 메시지 송수신 문제해결 항목에서 Google 메시지가 기본 문자 메시지 앱으로 설정돼 있는지 확인하라고 명시합니다.

SMS 앱 변경 뒤에 문제가 생기면 다음을 구분해 점검하세요.

  • 휴대폰에서 SMS·MMS를 전혀 수신하지 못하는지
  • 휴대폰은 문자를 받지만 선택하지 않은 메시지 앱만 열리는지
  • SMS는 정상인데 RCS 채팅에서만 메시지가 지연되거나 실패하는지
  • 여러 SMS 앱이 설치돼 있고 기본 SMS 앱이 의도와 다르게 선택됐는지

주의: 기본 SMS 앱을 바꾸는 작업과 메시지 대화·사진·첨부파일 삭제는 별도입니다. 메시지가 보이지 않는다고 기존 앱의 데이터를 초기화하거나 삭제하지 마세요.

공식 자료: Google — 기본 메시지 앱 변경, Google — Google 메시지 전송·수신 오류 해결

6. 유튜브·인스타그램 링크가 브라우저로만 열릴 때

기본 브라우저를 Chrome으로 지정했더라도, 유튜브 링크는 YouTube 앱으로 열고 싶을 수 있습니다. 이때 확인할 것은 기본 브라우저가 아니라 해당 앱이 지원하는 링크를 여는 방법입니다.

지원 링크 열기 확인 순서

  1. 설정 → 애플리케이션으로 이동합니다.
  2. 원하는 앱(예: YouTube)을 선택합니다.
  3. 앱 정보 화면의 기본으로 설정, 기본으로 열기, 또는 유사한 메뉴를 찾습니다.
  4. 지원되는 링크 열기가 허용되어 있는지 확인합니다.
  5. 앱이 지원하는 웹 주소가 표시된다면 해당 도메인 정보를 확인합니다.
  6. 외부에서 YouTube 링크를 눌러 실제 작동 여부를 테스트합니다.

One UI 버전에 따라 설정 → 애플리케이션 → 기본 앱 선택 → 링크 열기에서 앱별 지원 링크를 볼 수도 있습니다.

반드시 알아둘 한계

  • Android의 지원 링크 설정은 앱이 실제로 처리할 수 있는 링크 유형에만 적용됩니다.
  • 모든 사이트 주소를 임의의 앱으로 강제 연결할 수 있는 것은 아닙니다.
  • 서비스의 앱 설치 여부, 해당 도메인의 검증 상태, 링크를 누르는 앱의 내부 브라우저 정책에 따라 결과가 다를 수 있습니다.
  • 웹 브라우저의 새 탭에서 연 링크는 메신저의 링크와 동작이 같지 않을 수 있습니다.

Samsung Members의 모더레이터도 특정 앱 링크가 브라우저로 열리는 경우 설정 → 앱 → 해당 앱 → 기본으로 설정 → 지원 링크 열기를 확인하도록 안내한 바 있습니다. 다만 사용자 커뮤니티의 안내는 모델별 동작을 보장하지 않으므로 삼성의 기본 앱 공식 설정 문서와 함께 확인하는 것이 좋습니다.

공식 자료: Samsung — 앱별 기본 설정, Samsung 공식 커뮤니티 — 지원 링크 열기 안내

7. 링크가 자꾸 다른 앱으로 열릴 때 되돌리기

예를 들어 뉴스 기사 주소를 눌렀는데 특정 쇼핑 앱이나 SNS 앱이 먼저 실행되는 상황입니다. 어느 앱이 자동 실행되는지 확인하는 것이 출발점입니다.

방법 A. 기본 브라우저가 잘못 선택됐을 때

  1. 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱을 엽니다.
  2. 원래 원하던 브라우저를 다시 선택합니다.
  3. 일반 웹 링크를 눌러 결과를 확인합니다.

방법 B. 특정 서비스 링크만 설치 앱으로 열릴 때

  1. 설정 → 애플리케이션에서 자동 실행되는 앱을 찾습니다.
  2. 해당 앱의 기본으로 설정/지원되는 링크 열기 설정을 확인합니다.
  3. 관련 옵션을 끄거나 기본 설정 지우기가 제공된다면 그 동작을 검토합니다.
  4. 동일한 서비스 링크를 다시 테스트합니다.

방법 C. 선택 창이 나타나지 않을 때

예전에 열기 팝업에서 항상을 선택한 후 다음부터 선택 창이 표시되지 않는 경우가 있습니다. 이때는 관련 앱의 기본 설정을 해제하는 방법을 검토할 수 있습니다.

단, 모든 One UI 버전에서 '기본 설정 지우기'가 동일하게 표시되는 것은 아닙니다. 어떤 기기에는 지원 링크에 대한 허용 스위치만 있을 수 있습니다.

피해야 할 방법: 기본 앱이 꼬였다고 해서 휴대폰 전체 초기화나 앱 데이터 삭제부터 진행하지 마세요. 일반적으로 먼저 확인해야 할 것은 기본 앱 선택과 지원 링크 설정입니다.

공식 자료: Samsung — 기본 앱 선택, Samsung — Galaxy 앱 관리

8. '한 번만'과 '항상' 차이 알아두기

Android에서는 특정 파일이나 링크를 열 때 어떤 앱을 사용할지 선택하도록 안내할 수 있습니다.

  • 한 번만: 그 작업에 이번 한 번만 선택한 앱을 사용합니다.
  • 항상: 앞으로 같은 유형의 작업에서 선택 앱이 기본 동작으로 적용될 수 있습니다.

이 선택지는 해당 상황에서 사용할 수 있는 앱이 여러 개일 때 나타납니다. 모든 링크나 파일에서 항상 선택창이 나오는 것은 아닙니다.

'항상'을 눌렀더니 원하지 않는 앱으로 계속 연결된다면 설정의 기본 앱 선택과 자동 실행되는 앱의 기본으로 설정 항목을 점검하세요.

중요: '항상' 선택과 전화 앱·SMS 앱·브라우저 앱 등 시스템 기본 역할 변경은 항상 같은 설정이 아닙니다. 예를 들어 특정 쇼핑몰 링크에 적용한 연결 설정 때문에 기본 브라우저 전체가 바뀌었다고 단정할 수 없습니다.

9. 전화 앱도 기본 앱으로 변경할 수 있나요?

Android와 삼성 Galaxy의 기본 앱 설정에는 전화 앱 같은 범주가 나타날 수 있습니다. 다만 실제로 선택 가능한 앱은 설치 상태와 지원 기능에 따라 달라집니다.

  1. 설정 → 애플리케이션 → 기본 앱 선택으로 이동합니다.
  2. 목록에 전화 앱 항목이 있는지 확인합니다.
  3. 원하는 전화 앱이 표시된다면 선택합니다.
  4. 전화 발신·수신·통화 화면이 정상인지 점검합니다.

주의: 기본 전화 앱을 변경하는 것만으로 통화 녹음 지원 여부가 동일하게 유지된다고 볼 수 없습니다. 통화 녹음은 앱·모델·국가·버전에 따라 지원 조건이 다릅니다. 사용 중인 앱의 주요 통화 기능을 확인하세요.

반드시 제조사가 아닌 앱을 전화 앱으로 지정해야 할 이유가 없다면, 현재 정상 작동하는 기본 전화 앱을 유지하는 것도 방법입니다.

공식 근거: Samsung — Galaxy 기본 앱 관리, Samsung — 기본 앱 선택 화면

10. PDF·사진·동영상을 열 때 앱을 바꾸고 싶다면

'PDF는 계속 같은 앱에서 열림', '사진이 갤러리 대신 다른 앱으로 열림'이라는 문제는 브라우저 기본 앱과 다릅니다.

먼저 현재 열리는 앱 확인

  1. 내 파일에서 해당 파일을 찾습니다.
  2. 파일을 열 때 자동으로 실행되는 앱을 확인합니다.
  3. 그 앱이 설치되어 있는지, 다른 대체 앱을 사용할 수 있는지 확인합니다.
  4. 설정 → 애플리케이션 → 해당 앱에서 기본으로 설정 관련 항목을 확인합니다.
  5. 해당 항목에 기본 설정 지우기가 제공된다면 필요에 따라 검토합니다.
  6. 다시 파일을 열어 사용 가능한 앱 선택창이 나타나는지 확인합니다.

일부 파일에는 앱 선택이 안 나타날 수 있습니다

  • 파일 형식을 처리할 수 있는 앱이 하나만 설치되어 있을 수 있습니다.
  • 해당 파일을 열던 앱이 자체 뷰어를 사용하고 있을 수 있습니다.
  • 모든 파일 형식에 시스템 기본 앱 범주가 별도로 존재하지는 않습니다.
  • PDF의 편집·주석 등 기능은 사용하려는 앱이 실제로 지원하는지 확인해야 합니다.

권장: 앱 선택 문제만 해결하려고 기존 PDF 파일을 삭제하거나 전체 앱 데이터를 지우지 마세요. 원본 파일을 보존하고 다른 앱에서 열기가 제공되는지 먼저 확인하세요.

11. 기본 앱 선택 메뉴가 없거나 앱이 회색으로 나올 때

11-1. 설정 메뉴의 명칭이 다른 경우

One UI 버전에 따라 메뉴가 애플리케이션 / 앱 / 기본 앱 선택 등으로 표시될 수 있습니다. 설정 검색창에 기본 앱, 브라우저 앱, SMS 앱을 입력해 찾아보세요.

11-2. 원하는 앱이 설치되지 않은 경우

기본 앱 목록에는 해당 역할을 지원하는 설치 앱이 표시됩니다. Chrome이나 삼성 인터넷 등이 목록에 없다면 공식 Play 스토어·Galaxy Store에서 설치 상태부터 확인합니다.

11-3. 앱을 설치했지만 역할이 표시되지 않는 경우

앱이 해당 기본 역할(브라우저·SMS 등)을 지원하지 않을 수 있습니다. 모든 앱을 기본 브라우저나 기본 SMS 앱으로 선택할 수 있는 것은 아닙니다.

11-4. 회사에서 관리하는 휴대폰인 경우

회사·학교에서 관리하는 기기는 조직의 정책에 따라 설치 앱과 기본 앱 변경이 제한될 수 있습니다. 관리자 정책을 임의로 우회하려고 보안 설정을 해제하지 마세요.

11-5. 소프트웨어가 오래된 경우

Samsung은 갤럭시 앱 관리 가이드에서 앱 업데이트를 권장합니다. 설정 → 소프트웨어 업데이트와 공식 스토어의 앱 업데이트 상태를 확인하세요. 업데이트 전에는 중요한 파일과 설정을 안전하게 백업하는 것이 좋습니다.

공식 자료: Samsung — 앱 관리와 업데이트, Samsung — Galaxy 앱 관리 기능

12. 기본 SMS 앱을 바꾼 뒤 문자 수신이 안 될 때

Google의 공식 도움말은 Google 메시지로 SMS 앱을 변경한 후 오류가 생기면 기본 SMS 앱 설정, SMS/MMS/RCS 통신사 지원, 네트워크 상태를 확인하라고 안내합니다.

점검 순서

  1. 설정 → 애플리케이션 → 기본 앱 선택 → SMS 앱에서 실제 선택 앱을 확인합니다.
  2. 휴대폰의 신호와 비행기 모드를 확인합니다.
  3. Google 메시지 앱 업데이트 여부를 확인합니다.
  4. 일반 SMS를 보낼 수 있는지 확인합니다.
  5. 사진 등 MMS만 실패한다면 데이터 연결 및 통신사 설정을 확인합니다.
  6. RCS만 실패한다면 메시지 앱의 RCS 채팅 상태와 통신사 지원 여부를 별도로 확인합니다.
  7. 문제가 계속되면 Google 공식 문제해결 순서를 따릅니다.

중요: SMS 앱을 바꿨다는 이유로 과거 문자 기록이 곧바로 삭제됐다고 단정하지 마세요. 그러나 현재 문자 내용이 보이지 않는 상태에서 메시지 앱 데이터 삭제, 앱 초기화, 기기 초기화는 위험하므로 피해야 합니다.

Google은 iPhone에서 Android로 바꾼 이용자의 경우 이전 iMessage 등록 상태도 점검하라고 안내합니다. 이는 일반 Galaxy 내 SMS 앱 변경과 다른 문제이므로 상황에 맞게 구별해야 합니다.

공식 출처: Google — 메시지 전송·수신 문제해결

13. 앱 데이터 삭제·캐시 삭제는 서로 다릅니다

문제해결 글에서 캐시 삭제와 데이터 삭제를 한꺼번에 권장하는 경우가 있지만, 두 작업은 위험 수준이 다릅니다.

작업의미주의사항
기본 앱 변경어떤 앱을 기본으로 사용할지 선택가장 먼저 시도할 항목
지원 링크 설정 변경특정 웹사이트 링크의 앱 연결 정책 확인앱이 지원하는 링크에만 적용
캐시 삭제앱이 임시로 보관한 파일 제거앱 상태에 따라 효과가 다름
데이터 삭제앱을 초기 상태로 되돌리고 저장 데이터·설정을 삭제로그인 정보·개인 설정·앱 데이터 손실 위험
공장 초기화휴대폰을 초기화사진·문서·앱 정보 등 대규모 데이터 삭제

삼성의 2026년 공식 앱 관리 안내는 데이터 삭제가 모든 개인 설정과 앱 데이터를 영구적으로 지울 수 있다고 경고합니다.

기본 브라우저를 바꾸거나 링크 연결만 조정하려는 경우라면 앱 데이터 삭제나 휴대폰 공장 초기화까지 진행할 이유가 일반적으로 없습니다.

공식 출처: Samsung — 앱 캐시와 데이터 삭제의 차이

14. 설정이 바뀌었는지 안전하게 확인하는 테스트

기본 앱을 변경한 직후 실제로 원하는 결과가 나오는지 확인해 보세요.

테스트 A. 기본 브라우저

  1. 브라우저 앱을 Chrome으로 선택합니다.
  2. 내 메모 등에 저장된 일반 웹주소를 누릅니다.
  3. Chrome으로 열리는지 확인합니다.
  4. 이후 Samsung Browser로 바꾸고 같은 방식으로 확인해도 됩니다.

테스트 B. SMS 앱

  1. SMS 앱 항목에서 원하는 앱을 선택합니다.
  2. 메시지 앱을 열어 기존 대화 목록이 보이는지 확인합니다.
  3. 본인 소유의 다른 번호 등 안전한 테스트 상대에게 일반 SMS를 보내고 회신을 확인합니다.
  4. 필요하다면 RCS 상태도 따로 확인합니다.

테스트 C. 지원 링크

  1. 기본 브라우저 설정과 별도로 YouTube 등 앱의 지원 링크 설정을 확인합니다.
  2. 해당 앱이 지원하는 링크를 외부에서 누릅니다.
  3. 링크가 앱에서 열리는지 확인합니다.
  4. 결과가 다르면 링크를 누른 앱의 내부 브라우저 정책인지 확인합니다.

핵심: Chrome을 기본 브라우저로 설정한 결과와 YouTube 링크를 YouTube 앱에서 여는 결과는 충돌하는 것이 아닙니다. 두 동작은 서로 다른 설정의 적용 결과입니다.

15. 자주 묻는 질문(FAQ)

Q1. 갤럭시 기본 앱 변경은 어디에서 하나요?

일반적으로 설정 → 애플리케이션(앱) → 기본 앱 선택에서 변경합니다. 브라우저 앱, SMS 앱 등 기기가 제공하는 항목 중 원하는 역할을 선택합니다.

Q2. 갤럭시 기본 브라우저를 삼성 인터넷에서 Chrome으로 바꾸려면?

설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱 → Chrome을 선택합니다. 설치된 Chrome이 선택 목록에 나타나는지 확인하세요.

Q3. Chrome을 기본 앱으로 설정했는데 카카오톡 링크가 삼성 인터넷에서 열려요.

카카오톡 등 앱의 내부 브라우저를 사용하거나 기존 링크 연결 설정이 남아 있을 수 있습니다. 일반 웹 링크에서 Chrome이 열리는지 먼저 확인한 뒤 앱 내부 열기 동작을 구별하세요.

Q4. 삼성 인터넷을 다시 기본 브라우저로 바꿀 수 있나요?

네. 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱 → 삼성 인터넷(Samsung Browser)을 선택하면 됩니다.

Q5. 갤럭시 기본 문자 메시지 앱 변경 방법은?

설정 → 애플리케이션 → 기본 앱 선택 → SMS 앱으로 이동해 선택 가능한 메시지 앱 중 원하는 것을 지정합니다.

Q6. 기본 메시지 앱을 바꾸면 이전 문자들이 모두 사라지나요?

기본 SMS 앱 변경 자체와 메시지 데이터 삭제는 다른 작업입니다. 앱에 따라 메시지 표시 방식이 달라질 수 있으므로 기존 대화 목록을 확인하세요. 메시지가 보이지 않는다면 데이터를 삭제하지 말고 기본 SMS 설정부터 확인해야 합니다.

Q7. 유튜브 링크를 유튜브 앱으로 열고 싶은데 어떻게 하나요?

설정 → 애플리케이션 → YouTube → 기본으로 설정 → 지원 링크 열기와 비슷한 항목을 확인합니다. One UI 버전에 따라 기본 앱 선택 → 링크 열기에서도 확인할 수 있습니다.

Q8. 왜 '한 번만'과 '항상' 선택창이 안 나오나요?

해당 작업을 처리할 앱이 하나뿐이거나, 이전에 기본 연결이 설정됐거나, 특정 앱이 자체적으로 링크를 열고 있을 수 있습니다. 기본 앱 선택과 앱별 기본으로 설정을 점검하세요.

Q9. 기본 앱 설정을 바꾸면 카메라·사진 등 다른 데이터도 지워지나요?

기본 앱을 선택하는 것 자체는 파일 삭제 작업이 아닙니다. 다만 앱 데이터 삭제·공장 초기화는 저장 데이터를 지울 수 있으므로 구분해야 합니다.

Q10. '기본으로 설정'이나 '기본 설정 지우기'가 안 보여요.

One UI 버전, 앱별 지원 기능, 링크 형식에 따라 제공 항목이 다를 수 있습니다. 기본 앱 선택 화면이나 해당 앱 정보 화면을 확인하되, 없는 옵션을 찾으려 비공식 설정 앱을 설치하지 마세요.

Q11. 전화 앱도 바꿀 수 있나요?

사용 중인 기기에 전화 앱 기본 역할이 제공되고 해당 역할을 지원하는 앱이 설치돼 있다면 변경할 수 있습니다. 통화 녹음 등 앱별 기능은 변경 후 다시 확인하세요.

Q12. 기본 앱이 자동으로 바뀌지 않게 하려면?

어떤 앱을 누르면 어떤 작업이 열리는지 구분하고, 앱 설치·업데이트 후 기본 앱 선택을 확인하세요. 모든 앱과 링크에 대한 완전한 변경 방지 스위치가 제공된다고 가정할 수는 없습니다.

16. 3분 최종 체크리스트

  • ☐ 설정 → 애플리케이션 → 기본 앱 선택 위치를 확인했다.
  • ☐ 기본 브라우저 앱으로 원하는 앱을 선택했다.
  • ☐ Chrome과 Samsung Browser가 모두 설치돼 있는지 확인했다.
  • ☐ 기본 SMS 앱이 실제로 사용할 메시지 앱인지 확인했다.
  • ☐ 문자 오류는 SMS·MMS·RCS를 구분해서 점검했다.
  • ☐ 특정 링크만 다른 앱에서 열리면 지원 링크 열기 설정을 확인했다.
  • ☐ 앱 내부 브라우저와 시스템 기본 브라우저를 구별했다.
  • ☐ PDF·사진은 파일을 처리할 앱의 기본 설정을 따로 확인했다.
  • ☐ 앱 데이터 삭제/공장 초기화를 문제 해결 첫 단계로 사용하지 않았다.
  • ☐ 설정 변경 후 일반 웹 링크·문자·지원 링크를 각각 테스트했다.
