USB 메모리나 외장하드를 노트북에 꽂았는데 '띠링' 연결 소리만 나고 파일 탐색기에는 아무 드라이브도 보이지 않나요? 어제까지 열리던 외장 SSD에 갑자기 '이 드라이브를 사용하려면 포맷해야 합니다'라는 경고가 뜨거나, 디스크 관리에 '알 수 없음·초기화 안 됨·RAW'가 표시되는 경우도 있습니다.

이때 가장 중요한 것은 장치를 다시 보이게 만드는 일과 기존 파일을 보존하는 일을 구분하는 것입니다. 단순히 드라이브 문자가 빠진 문제는 기존 볼륨에 문자만 할당해 해결될 수 있지만, 사진·업무 문서가 들어 있던 드라이브에 포맷이나 초기화를 잘못 실행하면 데이터가 손실될 수 있습니다.

이 글은 2026년 10월 25일 기준 Microsoft Windows 고객지원 및 Microsoft Learn 공식 자료를 근거로 작성했습니다. USB 포트·케이블·전력 공급, 파일 탐색기, 디스크 관리, 장치 관리자, 드라이브 문자, RAW 파일 시스템, BitLocker, 초기화와 CHKDSK 주의사항까지 쉬운 진단부터 위험도가 큰 조치 순서로 설명합니다.

1. USB 연결 소리는 나는데 파일 탐색기에 없을 때

Windows가 USB 연결 소리를 냈다는 사실은 어떤 장치 연결 이벤트를 감지했을 수 있다는 뜻이지 저장된 파일이 정상이고 드라이브가 읽을 수 있다는 보장은 아닙니다.

먼저 할 점검

  1. Windows 키 + E를 눌러 파일 탐색기를 엽니다.
  2. 왼쪽에서 이 PC를 선택합니다.
  3. 장치 및 드라이브 목록에 USB·외장하드가 표시되는지 확인합니다.
  4. 표시되지 않는다면 다른 USB 포트에 연결해 봅니다.
  5. 케이블 분리형 외장하드라면 정상적인 호환 케이블로 비교합니다.
  6. 가능하면 USB 허브를 거치지 않고 PC 본체 포트에 직접 연결해 봅니다.
  7. 다른 Windows PC에서도 같은 장치가 보이는지 확인합니다.

Microsoft는 디스크가 나타나지 않을 때 다른 USB 포트, 케이블, 다른 PC에서의 테스트를 권장합니다. 특히 일부 허브나 포트는 저장장치에 충분한 전력을 공급하지 못할 수 있습니다.

중요한 예외: 장치에서 이상한 소리가 난다면

외장 HDD가 평소와 달리 반복적으로 딸깍거리거나 회전이 시작됐다 멈추는 소리, 타는 냄새, 비정상적인 발열이 발생한다면 단순 Windows 설정 문제만은 아닐 수 있습니다.

중요한 데이터가 있다면 연결·분리를 반복하거나 여러 복구 프로그램을 무작정 실행하지 말고 전문 진단을 검토하세요. 손상된 저장장치는 반복적인 접근만으로 상태가 악화될 수 있습니다.

파일 탐색기만 작동하지 않는다면?

USB뿐 아니라 파일 탐색기 자체가 열리지 않는 상황은 별개의 문제입니다. Microsoft는 Windows 업데이트·PC 재시작·파일 탐색기 복구를 별도로 안내합니다. 먼저 다른 정상 드라이브가 탐색기에 표시되는지 확인하세요.

2. Windows 11 디스크 관리 여는 방법 세 가지

USB가 파일 탐색기에 나타나지 않을 때 가장 유용한 도구가 **디스크 관리(Disk Management)**입니다. Windows에 내장된 도구라 별도 프로그램을 설치할 필요가 없습니다.

방법 1. 시작 버튼에서 열기

  1. Windows 작업 표시줄에서 시작 버튼을 오른쪽 클릭합니다.
  2. 디스크 관리를 선택합니다.
  3. 연결된 물리 디스크와 볼륨 목록이 나타나는지 확인합니다.

방법 2. 실행창에서 열기

  1. Windows 키 + R을 누릅니다.
  2. 실행창에 다음 명령을 입력합니다.
diskmgmt.msc
  1. 확인을 누릅니다.
  2. 디스크 관리 창이 열리면 저장장치 목록을 확인합니다.

방법 3. 검색에서 열기

  1. Windows 검색에 디스크 관리를 입력합니다.
  2. 하드 디스크 파티션 만들기 및 포맷 또는 유사한 항목을 선택합니다.
  3. 관리자 권한이 필요한 기능이라면 본인 소유의 컴퓨터인지 확인합니다.

Microsoft 공식 설명에 따르면 디스크 관리의 기본 기능과 인터페이스는 Windows 10과 Windows 11에서 동일하게 제공됩니다.

디스크 관리에서 무엇을 살펴봐야 하나요?

  • 디스크 0, 디스크 1, 디스크 2 등 물리 디스크 번호
  • 표시되는 디스크 크기(용량)
  • 온라인·오프라인·알 수 없음·초기화 안 됨 상태
  • 볼륨의 정상·RAW·할당되지 않음 상태
  • 드라이브 문자(E:, F: 등) 할당 여부

여기서는 우선 보기만 하세요. 어떤 디스크가 외장하드인지 확인하지 않고 디스크 0을 초기화하거나 파티션을 지우는 일은 매우 위험합니다. 디스크 번호는 PC마다 달라 예시 숫자를 그대로 따라서는 안 됩니다.

공식 출처: Microsoft - 디스크 관리 열기

3. 디스크 0·디스크 1 중 어느 것이 내 외장하드인지 확인

디스크 관리 화면에는 운영체제가 설치된 내부 SSD와 USB 외장 저장장치가 함께 나타납니다. 따라서 화면에 표시된 디스크 번호를 반드시 구분해야 합니다.

안전한 구분 기준

  1. 외장하드의 제품 라벨에서 정격 용량을 확인합니다.
  2. Windows 디스크 관리에서 해당 용량과 비슷한 물리 디스크를 찾습니다.
  3. 사용 중인 다른 USB 저장장치의 목록과 혼동하지 않는지 확인합니다.
  4. 드라이브를 연결하기 전후의 목록 변화를 비교해 봅니다.
  5. 운영체제가 설치된 C: 드라이브 및 복구 파티션은 건드리지 않습니다.

표시 용량은 제조사가 표시하는 GB·TB 단위와 Windows에서 보이는 값이 조금 다를 수 있습니다. 용량이 비슷하다는 이유만으로 단독 확정하지 말고 여러 기준을 함께 사용하세요.

EFI·복구 파티션은 왜 무시해야 하나요?

Microsoft는 EFI 시스템 파티션이나 복구 파티션은 Windows 시작·복구에 필요한 중요한 데이터를 담고 있으므로 임의 변경하지 말라고 안내합니다.

특히 디스크 관리에서 '문자가 없다'는 이유만으로 EFI·복구 파티션에 문자를 할당하거나 삭제하지 마세요. 이것은 일반적인 USB 드라이브 복구 방법이 아닙니다.

외장하드를 빼니 목록에서 어떤 디스크가 사라졌다면?

해당 디스크가 외장 장치일 가능성을 판단하는 단서가 될 수 있습니다. 그러나 하드웨어 오류가 의심되거나 데이터가 매우 중요한 디스크는 반복 탈착을 줄이는 것이 좋습니다.

공식 출처: Microsoft - 디스크 관리 문제 해결과 시스템 파티션 주의

4. '정상'인데 E:·F:가 없다면 드라이브 문자 확인

디스크 관리에 외장 저장장치가 온라인·정상 상태로 나타나지만 파일 탐색기에서 찾을 수 없다면, 드라이브 문자(E:, F:, G: 등)가 할당됐는지 확인하세요.

Microsoft Learn은 이 문제를 위해 드라이브 문자 및 경로 변경 기능을 안내합니다. 기존에 정상적으로 존재하는 데이터 볼륨에 문자를 지정하는 것은 새 파티션 생성이나 포맷과 다른 작업입니다.

기존 외장 볼륨에 드라이브 문자 추가

  1. Windows 키 + R → diskmgmt.msc를 실행합니다.
  2. 본인 외장하드의 실제 볼륨을 정확히 확인합니다.
  3. 해당 볼륨을 오른쪽 클릭합니다.
  4. 드라이브 문자 및 경로 변경을 선택합니다.
  5. 드라이브 문자가 없다면 추가를 누릅니다.
  6. 다음 드라이브 문자 할당을 선택합니다.
  7. 사용하지 않는 문자를 지정합니다.
  8. 확인을 누릅니다.
  9. Windows 키 + E → 이 PC에서 표시되는지 확인합니다.

추가와 변경의 차이

기존 문자 없이 정상 볼륨이 있다면 추가를 사용합니다. 이미 문자가 있는데 충돌 등의 이유로 바꿔야 한다면 변경을 이용할 수 있습니다.

주의: Microsoft는 Windows 또는 앱이 설치된 드라이브의 문자를 변경하면 프로그램 실행이나 파일 경로가 깨질 수 있다고 경고합니다. 내부 시스템 볼륨에는 이 방법을 적용하지 마세요.

메뉴가 회색이면?

Microsoft는 볼륨이 할당되지 않음, EFI·복구 파티션, 접근 권한 부족 등의 상태라면 문자 변경 메뉴가 비활성화될 수 있다고 설명합니다.

이때는 메뉴를 활성화하려고 곧바로 포맷하지 마세요. 특히 이전에 데이터가 저장돼 있던 디스크라면 기존 볼륨 손상 가능성을 따져야 합니다.

공식 출처: Microsoft - 드라이브 문자 변경 또는 할당

5. 디스크 관리에서 '오프라인'이라고 나오면 어떻게 하나요?

파일 탐색기에서 USB가 보이지 않고 디스크 관리에서 오프라인(Offline) 상태로 나타날 수 있습니다. 이는 Windows가 해당 물리 디스크를 현재 온라인 상태로 사용하지 않고 있다는 뜻입니다.

Microsoft는 디스크 관리에서 디스크가 오프라인일 때, 오프라인으로 표시된 디스크를 오른쪽 클릭해 온라인으로 변경하는 방법을 설명합니다.

온라인 전환 전 확인할 것

  1. 현재 USB·외장 SSD의 모델과 용량이 정확히 무엇인지 확인합니다.
  2. 해당 디스크가 정말 외장 저장장치인지 살펴봅니다.
  3. 디스크가 다른 컴퓨터의 공유 스토리지·서버·RAID 구성에 속해 있지 않은지 확인합니다.
  4. 오류가 있거나 중요한 데이터가 들어 있다면 우선 백업·데이터 보존 판단을 합니다.

일반 개인용 외장 디스크 온라인 전환

  1. Windows 키 + R → diskmgmt.msc를 입력합니다.
  2. 정확한 외장 디스크를 식별합니다.
  3. 디스크 이름이 표시되는 왼쪽 영역을 오른쪽 클릭합니다.
  4. 온라인을 선택할 수 있는지 확인합니다.
  5. 온라인 상태로 바뀌면 볼륨 상태·드라이브 문자 여부를 다시 살펴봅니다.

오프라인 해제가 안 된다면?

Microsoft는 디스크가 물리적으로 분리됐거나 디스크 컨트롤러·케이블·장치에 문제가 있으면 계속 오프라인으로 남을 수 있다고 설명합니다. 단순 상태 전환이 실패하는데도 초기화·포맷을 연달아 실행하지 마세요.

회사 서버나 RAID 드라이브라면 예외

서버·백업 장치·다중 디스크 볼륨 등은 일반 USB와 다르게 관리됩니다. 임의로 온라인 전환·초기화를 실행하면 공유 스토리지의 일관성이나 데이터에 영향을 줄 수 있으므로 시스템 관리자에게 맡기는 것이 안전합니다.

공식 출처: Microsoft - 디스크 온라인·오프라인 상태 관리, Microsoft - 오프라인 디스크 문제 해결

6. '알 수 없음·초기화 안 됨'을 눌러도 될까요?

디스크 관리에서 외장 저장장치가 **알 수 없음(Unknown), 초기화 안 됨(Not Initialized)**으로 표시되면 Windows가 파티션 정보를 정상적으로 확인하지 못하고 있을 수 있습니다.

여기서 결정적인 차이는 정말 아무 데이터도 없는 새 디스크인지, 아니면 전에 사용하던 파일이 들어 있는 디스크인지입니다.

새로 산 빈 SSD·HDD라면

Microsoft는 기존 데이터가 없는 새 디스크를 사용하려면 디스크 초기화 → 파티션 생성 → 포맷 → 드라이브 문자 할당이 필요할 수 있다고 설명합니다.

그러나 제품마다 USB 컨트롤러·펌웨어·공장 설정이 달라 모든 USB 메모리가 디스크 초기화 메뉴를 필요로 하는 것은 아닙니다. 일부 USB 저장장치는 이미 사용할 수 있는 파일 시스템으로 출고됩니다.

원래 사진·문서가 있던 디스크라면

초기화하지 마세요. Microsoft의 새 디스크 초기화 문서는 사용 중이던 디스크의 초기화가 데이터를 지운다고 경고하며, 문제 해결 문서는 기존 파일이 들어 있는 디스크라면 초기화·포맷을 진행하지 말라고 안내합니다.

이는 단순히 메뉴에서 확인 버튼을 누르는 문제가 아니라 원래 파일을 복구할 가능성과 관련됩니다.

기존 데이터를 보호하기 위한 순서

  1. 문제가 있는 디스크를 **'사용 중이던 외장하드'**로 분류합니다.
  2. 디스크에 중요 자료가 있다면 초기화 확인창에서 취소합니다.
  3. 다른 USB 포트·호환 케이블·전원 공급 문제를 확인합니다.
  4. 필요한 범위에서 다른 Windows PC에서 인식되는지 비교합니다.
  5. 디스크 상태가 계속 비정상이면 제조사 또는 전문 데이터 복구 서비스 상담을 고려합니다.

GPT·MBR 선택창이 나타났다면?

이 창은 초기화할 디스크의 파티션 스타일을 정하는 화면입니다. GPT 또는 MBR을 고르는 것 자체가 기존 자료를 안전하게 복원하는 방법은 아닙니다. 이전에 사용하던 디스크라면 선택창에서 빠져나오세요.

공식 출처: Microsoft - 새 디스크 초기화와 데이터 삭제 경고, Microsoft - 초기화되지 않은 디스크 문제 해결

7. USB가 RAW로 나오거나 포맷하라는 창이 뜬다면

Windows에서 외장하드가 RAW로 나타나는 것은 현재 운영체제가 해당 볼륨의 파일 시스템을 NTFS·FAT32·exFAT 등 정상적인 형식으로 인식하지 못한다는 신호일 수 있습니다.

Microsoft는 디스크 관리 문제 해결에서 RAW 파티션의 파일을 복구하려는 경우 포맷하지 말라고 명확히 안내합니다.

'이 드라이브를 사용하려면 포맷해야 합니다'가 떴을 때

  1. 현재 연결한 디스크에 기존 파일이 있었는지 떠올려 봅니다.
  2. 사진·동영상·문서가 있었다면 포맷 버튼을 누르지 않습니다.
  3. 가능하면 취소를 선택합니다.
  4. 디스크 관리에서 해당 볼륨이 RAW·할당되지 않음·정상 중 무엇인지 확인합니다.
  5. 다른 포트·케이블 등의 비파괴적 점검을 진행합니다.
  6. 중요한 데이터가 있다면 복구 가능성을 우선 검토합니다.

RAW이면 모든 파일이 삭제된 건가요?

그렇다고 단정할 수 없습니다. RAW는 Windows가 파일 시스템 구조를 제대로 해석하지 못하는 상태를 가리킬 수 있으며, 원인은 파일 시스템 손상, 파티션 정보 문제, 하드웨어 오류, 호환되지 않는 형식 등 다양합니다.

따라서 **'RAW = 파일이 모두 영구 삭제됐다'**는 설명도, **'무료 포맷으로 파일 손실 없이 고쳐진다'**는 광고성 설명도 주의해야 합니다.

복구 프로그램을 설치해도 될까요?

중요도가 낮은 디스크에 대해 검증된 복구 도구를 시험할 수도 있지만, 손상된 드라이브에 복구된 파일을 다시 저장하거나 반복적인 쓰기 작업을 하는 행위는 바람직하지 않습니다.

데이터가 대체 불가능하다면 저장장치를 더 사용하지 않고 전문 복구 업체와 상담하는 것이 안전할 수 있습니다. 복구 성공 여부는 보장할 수 없습니다.

빈 새 USB라면 상황이 다릅니다

정말 새로 구입해 아무 데이터도 없는 USB가 RAW로 표시되는 경우에는 제조사 지침과 Windows 공식 포맷 절차를 검토할 수 있습니다. 그러나 파일이 있던 USB에 같은 작업을 적용하면 안 됩니다.

공식 출처: Microsoft - RAW 볼륨 포맷 경고, Microsoft - 디스크 관리의 볼륨 서식

8. 새 외장 SSD 초기화는 언제 필요한가요? GPT·MBR 차이

정말 새 제품이고 파일이 없는 저장장치라면 Windows 디스크 관리에서 초기화·볼륨 생성이 필요할 수 있습니다.

Microsoft 공식 안내는 기존 데이터가 없는 새 디스크를 전제로 초기화 절차를 설명합니다.

기존 데이터가 없는 새 디스크만 진행

  1. 제품을 새로 개봉했고 중요한 파일이 없다는 사실을 확인합니다.
  2. Windows 키 + R → diskmgmt.msc를 엽니다.
  3. 본인 외장 디스크의 실제 모델·용량을 확인합니다.
  4. 새 디스크에 초기화 안 됨이 표시된다면 해당 디스크를 오른쪽 클릭합니다.
  5. 디스크 초기화를 선택합니다.
  6. 파티션 스타일 GPT 또는 MBR을 선택합니다.
  7. 초기화가 완료된 후 할당되지 않은 공간에서 새 단순 볼륨을 만들 수 있습니다.
  8. 볼륨 크기·드라이브 문자·파일 시스템을 사용 목적에 맞게 선택합니다.
  9. 포맷을 완료한 뒤 파일 탐색기에서 드라이브를 확인합니다.

GPT와 MBR의 차이

파티션 스타일특징
GPT현대적인 Windows 및 UEFI 기반 환경에 일반적으로 권장, 2TB 초과 디스크 지원
MBR구형 하드웨어·운영체제와의 호환성이 필요한 일부 상황에서 사용

Microsoft는 대부분의 현대 시스템에서 GPT를 사용하며, MBR은 상대적으로 오래된 장비에서 활용된다고 설명합니다.

포맷 형식은 NTFS·exFAT 중 무엇이 좋나요?

일반적인 Windows 전용 드라이브에는 NTFS를 사용할 수 있습니다. 여러 운영체제·기기에서 저장장치를 주고받아야 한다면 exFAT의 호환성을 검토할 수 있습니다.

단, 어떤 파일 시스템이 적합한지는 대상 TV·카메라·Mac·게임 콘솔의 실제 지원 여부에 따라 달라집니다. 저장장치를 포맷하면 기존 자료에 영향이 발생할 수 있으니 새 빈 디스크라는 전제를 다시 확인하세요.

이미 사용하던 디스크가 갑자기 초기화를 요구하면?

이 항목의 절차를 그대로 따라 하지 마세요. 6번의 데이터 보존 및 RAW 점검 기준으로 돌아가야 합니다.

공식 출처: Microsoft - 새 디스크 초기화 및 GPT·MBR, Microsoft - Windows 디스크 관리

9. USB-C 외장 SSD가 충전만 되거나 장치 인식이 안 될 때

USB-C는 커넥터 모양이고, 같은 모양이라도 케이블·포트·허브가 지원하는 데이터 전송·전력·USB4 등의 기능은 다를 수 있습니다.

Microsoft의 USB-C 문제 해결 문서는 지원되지 않는 케이블, 필요한 기능이 없는 포트, 부족한 전력, 호환되지 않는 도크 등을 가능한 원인으로 설명합니다.

USB-C 외장하드 점검 순서

  1. 외장 저장장치와 함께 제공된 정품 또는 제조사 권장 케이블을 사용합니다.
  2. 가능하면 USB 허브·도킹 스테이션을 빼고 PC에 직접 연결합니다.
  3. PC의 다른 USB-C 포트 또는 지원되는 다른 연결 포트를 시험합니다.
  4. 해당 케이블이 데이터 전송을 지원하는지 제품 사양을 확인합니다.
  5. 전원 어댑터가 필요한 외장 케이스라면 권장 전원을 연결합니다.
  6. Windows의 장치 관리자 및 디스크 관리에서 인식 상태를 비교합니다.
  7. USB4 장치라면 PC·케이블·도크가 USB4 호환 조건을 충족하는지 확인합니다.

충전되는 케이블이라면 데이터 전송도 되나요?

반드시 그렇지는 않습니다. 기기 충전에는 사용할 수 있지만 외장 SSD의 요구 성능이나 연결 방식에 맞지 않는 케이블일 수 있습니다.

USB-C 허브에 연결하면 안 되는 이유는?

허브가 항상 문제라는 뜻은 아닙니다. 다만 허브 전력 공급 부족, 대역폭·컨트롤러 호환성 등을 구분하기 위해 PC 직결 테스트가 유용합니다.

오류 코드가 뜬다면?

Microsoft는 USB-C 관련 'USB 장치가 인식되지 않음' 오류에서 장치 관리자에 표시되는 정확한 오류 코드를 기록해 개별 해결 방법을 확인하도록 안내합니다.

공식 출처: Microsoft - Windows USB-C 장치 문제 해결

10. 장치 관리자에서 USB 오류 코드 확인하는 방법

USB를 꽂으면 Windows 연결 소리는 나지만 파일 탐색기와 디스크 관리에서 제대로 보이지 않는 경우 장치 관리자에서 인식 상태를 확인할 수 있습니다.

장치 관리자 열기

  1. 시작 버튼을 오른쪽 클릭합니다.
  2. 장치 관리자를 선택합니다.
  3. 디스크 드라이브를 펼칩니다.
  4. 범용 직렬 버스 컨트롤러도 확인합니다.
  5. 기타 장치에 알 수 없는 USB 장치가 나타나는지 살펴봅니다.
  6. 노란색 느낌표가 있는 장치가 있다면 속성 → 일반을 선택합니다.
  7. 장치 상태와 오류 코드를 확인합니다.

Microsoft는 외장 디스크가 인식되지 않을 때 장치 관리자의 느낌표 및 장치 상태를 확인하도록 권고합니다.

USB 오류 코드 43이란?

일부 USB 장치가 문제를 보고하거나 Windows가 해당 장치의 작동을 중지하면 코드 43이 표시될 수 있습니다. 이는 USB 포트, 장치, 드라이버 등 여러 가능성을 검토해야 한다는 신호이지 특정 부품의 고장을 확정하는 숫자는 아닙니다.

드라이버 업데이트를 바로 하면 되나요?

현재 문제가 있는 디스크와 연결된 USB·저장장치 드라이버를 정확하게 식별한 뒤 Windows 업데이트 또는 PC 제조사 공식 지원을 확인할 수 있습니다.

하지만 저장장치에 중요한 데이터가 있는 상태에서 장치 제거·드라이버 강제 교체·전원 차단을 반복하는 것은 주의해야 합니다.

장치 제거 후 다시 검색은 언제 이용하나요?

Microsoft의 디스크 관리 문제 해결은 특정 장치를 제거하고 동작 → 하드웨어 변경 사항 검색으로 다시 감지하는 방법을 안내합니다. 그러나 이것은 데이터가 보존된다는 보장이나 모든 USB 오류의 해법이 아닙니다.

우선 포트·케이블·PC 비교와 오류 기록을 진행한 뒤, 필요한 경우 공식 제조사 지원을 받아 좁은 범위에서 수행하세요.

공식 출처: Microsoft - 디스크 관리 누락 장치 문제 해결, Microsoft - USB 장치 인식 오류 코드 확인

11. CHKDSK로 USB를 고칠 수 있나요? /f·/r 주의사항

검색하면 외장하드 오류를 고친다며 chkdsk X: /f 명령을 권하는 글이 많습니다. 하지만 이 명령은 단순히 연결을 다시 시도하는 작업이 아니라 파일 시스템의 오류를 수정하는 작업입니다.

CHKDSK의 역할

Microsoft Learn에 따르면 CHKDSK는 볼륨의 파일 시스템 메타데이터를 검사합니다.

  • 매개 변수가 없으면 일반적으로 상태 확인을 수행합니다.
  • **/f**는 파일 시스템 오류를 수정합니다.
  • **/r**은 문제 있는 디스크 영역을 검사하고 읽을 수 있는 데이터를 복구하려 시도합니다.
  • 수정 과정에는 파일 시스템 구조 변경과 추가적인 디스크 읽기·쓰기 작업이 수반될 수 있습니다.

왜 중요한 외장하드에는 바로 실행하면 안 될까요?

Microsoft의 CHKDSK 문서는 파일 시스템 복구 과정에서 파일 할당 정보가 변경되거나 일부 데이터가 손실될 수 있는 상황을 설명합니다.

이미 중요한 파일이 사라진 상태, RAW로 표시되는 드라이브, 물리적 고장 가능성이 있는 HDD에 /f나 /r을 무조건 실행하는 것은 권장하지 않습니다.

파일 보존이 우선이라면 드라이브 상태를 평가하고 가능한 범위에서 백업·디스크 이미지 생성·전문 복구 상담을 먼저 검토하세요.

정상적으로 접근되는 드라이브의 오류 검사

드라이브가 정상적으로 열리고 중요한 자료를 다른 저장소에 백업했다면, Microsoft 공식 문서를 참고해 해당 볼륨의 오류 검사를 이용할 수 있습니다.

다만 디스크 전체를 무작정 수정하지 말고 정확한 드라이브 문자, 파일 시스템, 백업 상태를 확인해야 합니다. 특히 외장 장치의 드라이브 문자는 PC와 연결 상태에 따라 바뀔 수 있어 예제의 X: 문자를 그대로 입력하면 안 됩니다.

RAW 드라이브에 CHKDSK가 실행되지 않는다면?

파일 시스템을 읽지 못해 CHKDSK가 해당 형식에서 사용할 수 없다고 표시할 수 있습니다. 이를 해결하려고 먼저 포맷하면 파일 복구 가능성을 낮출 수 있으므로 기존 데이터 중요도에 따라 대응하세요.

공식 출처: Microsoft - CHKDSK 명령·오류 수정의 영향, Microsoft - RAW 디스크 포맷 금지 조건

12. BitLocker 암호 때문에 USB·외장하드가 안 열리는 경우

드라이브는 파일 탐색기에 보이지만 자물쇠 아이콘과 함께 비밀번호·복구 키 입력을 요구할 수 있습니다. 이는 일반적인 USB 포트 인식 문제가 아니라 암호화된 볼륨의 잠금 해제 문제일 수 있습니다.

먼저 확인할 내용

  1. 외장 저장장치가 실제로 내 소유인지 확인합니다.
  2. 드라이브가 BitLocker 또는 BitLocker To Go로 보호되는지 살펴봅니다.
  3. 연결한 PC가 원래 해당 드라이브를 사용하던 컴퓨터인지 확인합니다.
  4. 설정했던 잠금 해제 암호를 알고 있는지 확인합니다.
  5. 복구 키가 필요한 경우 기존에 보관한 48자리 복구 키 또는 백업 기록을 확인합니다.

중요한 차이: Windows 로그인 PIN은 복구 키가 아닙니다

Windows Hello PIN, Microsoft 계정 암호, BitLocker 복구 키는 서로 다른 인증 정보입니다. 외장 드라이브에서 요구하는 방식에 맞는 실제 암호나 복구 키가 필요합니다.

다른 PC에 연결했더니 갑자기 잠겼다면?

원래 컴퓨터에서 자동으로 잠금 해제하도록 설정한 드라이브는 다른 컴퓨터에서 별도로 인증을 요구할 수 있습니다.

암호화가 되어 있다는 이유로 초기화하거나 포맷하지 마세요. 파일을 정상적으로 해독해 열기 위해서는 올바른 인증 정보가 필요합니다.

복구 키를 찾지 못한다면?

Microsoft는 복구 키가 없으면 암호화된 데이터에 접근하기 어려울 수 있다고 설명합니다. 회사 관리 저장장치라면 조직 IT 관리자에게 보관 여부를 문의하세요.

암호를 우회해 주겠다는 출처 불명 프로그램이나 웹사이트에 복구 키를 입력하지 마세요. 키를 확보한 경우에도 신뢰할 수 있는 공식 절차에서만 사용해야 합니다.

공식 출처: Microsoft - BitLocker 복구 키 찾기, Microsoft - Windows 디스크 관리

13. Mac에서 사용하던 외장하드가 Windows에 안 보이는 이유

외장 SSD를 Mac에 연결했을 때는 멀쩡한데 Windows 11에서 파일이 열리지 않는 경우에는 파일 시스템 호환성을 살펴봐야 합니다.

Mac 전용 파일 시스템일 수 있습니다

macOS에서 사용하는 APFS 또는 Mac 전용 HFS+ 등은 일반적인 Windows 11 파일 탐색기에서 기본적으로 바로 읽고 쓰도록 지원되지 않을 수 있습니다.

반면 exFAT는 여러 운영체제에서 교환용 저장장치를 사용할 때 선택되는 방식입니다. 하지만 실제로 다른 기기가 exFAT를 지원하는지 확인해야 하며, Windows와 Mac이 모두 사용 가능한 저장장치라고 해서 모든 외장 디스크에 exFAT 포맷을 권할 수는 없습니다.

기존 Mac 파일을 보존하려면

  1. 외장 SSD에 중요한 데이터가 들어 있는지 확인합니다.
  2. Windows에 '포맷해야 합니다'가 뜬다면 취소합니다.
  3. 원래 정상적으로 열리던 Mac에서 파일이 여전히 보이는지 확인합니다.
  4. 파일을 다른 안전한 저장소에 백업합니다.
  5. 필요하다면 새 빈 저장장치를 준비해 양쪽에서 지원되는 파일 시스템을 선택합니다.
  6. 데이터가 모두 안전하게 복사된 것을 확인한 뒤 새 드라이브를 이용합니다.

Mac 파일을 열려고 Windows에서 포맷해도 되나요?

아닙니다. 포맷은 Windows에서 드라이브를 새롭게 사용할 수 있도록 준비하는 작업이지, Mac 전용 파일 시스템에 저장돼 있던 파일을 Windows용으로 안전하게 변환하는 작업이 아닙니다.

사용하던 외장 SSD가 Windows에서 보이지 않는 이유가 단순히 호환되지 않는 파일 시스템일 수도 있으므로, 원래 저장장치에 쓰기·포맷을 진행하지 않는 것이 중요합니다.

공식 출처: Microsoft - 볼륨·파일 시스템 관리, Microsoft - RAW·호환되지 않는 볼륨 진단

14. 0바이트·'매체 없음'·읽을 수 없음이 표시된다면?

외장하드가 파일 탐색기에 보이지 않을 뿐 아니라 디스크 관리에서 0바이트·매체 없음·읽을 수 없음처럼 표시되는 경우에는 저장장치 자체의 이상 가능성도 고려해야 합니다.

먼저 안전하게 확인할 수 있는 항목

  1. 장치의 정상 전원 표시·작동음을 확인합니다.
  2. 허브를 제거하고 PC에 직접 연결합니다.
  3. 정격 전원이 필요한 외장 케이스라면 권장 전원을 사용합니다.
  4. 제조사 사양에 맞는 다른 케이블을 시험합니다.
  5. 중요한 데이터가 있다면 불필요한 재시도와 쓰기 작업을 줄입니다.
  6. Microsoft 디스크 관리에서 실제 보고되는 용량을 확인합니다.

디스크가 실제 용량보다 작게 표시된다면?

컨트롤러·케이스·하드웨어 문제, 파티션 표시 차이 등 원인이 다양할 수 있습니다. 용량이 다르다는 이유만으로 디스크 전체를 삭제·재파티션하지 마세요.

다른 PC에서도 0바이트로 나온다면?

원래 PC의 USB 포트만의 문제일 가능성은 줄어들지만, 그것만으로 고장 원인을 확정할 수는 없습니다. Microsoft는 다른 PC에서도 작동하지 않는 디스크에 대해서는 제조사나 데이터 복구 전문업체에 문의하는 방법을 제시합니다.

클릭 소리·과열이 반복되면?

하드웨어 오류가 의심된다면 계속 전원을 공급하고 여러 복구 명령을 실행하는 행동이 도움이 되지 않을 수 있습니다.

중요한 자료가 있는 디스크라면 임의 포맷·초기화·강제 드라이버 재설치보다 전문 진단을 통한 데이터 보존을 우선 고려하는 것이 좋습니다.

공식 출처: Microsoft - 읽을 수 없는 디스크·하드웨어 오류

15. 기존 파일이 있는 외장하드라면 멈춰야 할 상황

USB 저장장치를 다시 인식시키는 일보다 중요한 것은 기존 사진과 문서를 보호하는 일입니다. 특히 다음 상황에서는 저장장치의 상태를 더 확인하기 전까지 변경 작업을 삼가는 편이 좋습니다.

사용 중이던 디스크가 갑자기 초기화를 요구할 때

어제까지 문서를 저장하던 드라이브에 알 수 없음·초기화 안 됨이 나타났다면 새 디스크를 준비하는 절차를 그대로 따라 해서는 안 됩니다. Microsoft도 초기화가 기존 데이터에 영향을 줄 수 있다고 경고합니다.

기존 드라이브가 RAW로 표시될 때

RAW는 Windows에서 파일 시스템을 제대로 인식하지 못한다는 뜻일 수 있습니다. 해당 디스크에 필요한 파일이 있다면 포맷을 중단하고 데이터 보존을 우선하세요.

이상한 소음·과열·반복적인 연결 끊김

외장 HDD에서 평소와 다른 기계적 소음이 들리거나 지나치게 뜨겁다면 하드웨어 이상 가능성도 있습니다. 중요한 자료가 있는 경우에는 계속 연결을 반복하기보다 제조사나 전문 복구 서비스를 통한 상태 확인을 검토하세요.

BitLocker 복구 키를 요구하는 경우

저장장치에 걸린 암호화를 임의로 해제할 수는 없습니다. 올바른 잠금 해제 암호와 복구 키를 확인하는 것이 우선입니다.

장치가 어느 디스크 번호인지 확실하지 않을 때

디스크 관리의 디스크 0·디스크 1 중 어느 것이 USB인지 확인되지 않는다면 어떤 변경 작업도 실행하지 마세요. 운영체제와 복구 파티션까지 함께 표시될 수 있습니다.

핵심: 읽을 수 없는 디스크에 중요한 파일이 있다면 새로운 파일을 저장하거나 파일 시스템을 변경하기 전에 원본 보존 방법을 확인해야 합니다.

공식 출처: Microsoft - 디스크 관리 오류의 데이터 보호, Microsoft - 기존 데이터와 초기화 경고

16. USB가 다시 인식됐다면 파일 확인과 백업 먼저

외장하드가 다시 파일 탐색기에 나타났다고 해서 저장된 파일이 모두 정상적으로 복구됐다는 보장은 없습니다.

  1. Windows 키 + E → 이 PC를 열어 외장 저장장치를 찾습니다.
  2. 기존에 있던 폴더와 파일 이름이 나타나는지 확인합니다.
  3. 사진·문서 몇 개를 열어 정상적으로 읽히는지 확인합니다.
  4. 중요한 파일은 다른 저장장치나 신뢰할 수 있는 백업 위치에 복사합니다.
  5. 복사한 파일도 실제로 열리는지 확인합니다.
  6. 디스크 연결 끊김·이상 소음이 반복된다면 제조사 공식 점검을 검토합니다.

외장하드 하나에만 모든 자료를 보관하는 것은 위험할 수 있습니다. 장치에 문제가 생기더라도 다른 저장소에 사본이 있으면 피해를 줄일 수 있습니다.

복사가 진행되는 동안 케이블을 임의로 분리하지 않고 Windows의 안전한 제거 기능이나 제조사 안내를 참고하세요.

17. 데이터 손실을 피하는 원인별 점검 순서

먼저 기존 파일이 있는 디스크인지, 완전히 비어 있는 새 디스크인지 구분합니다. 이 차이에 따라 다음 조치가 달라집니다.

1단계. 연결 확인

USB 허브를 빼고 PC에 직접 연결해 보세요. 케이블·포트·정격 전원이 문제인지 확인합니다.

2단계. Windows 인식 확인

파일 탐색기에서 나타나는지 확인한 다음 diskmgmt.msc로 디스크 관리 화면을 열어 디스크와 볼륨 상태를 비교합니다.

3단계. 기존 볼륨이 정상인지 확인

볼륨이 온라인·정상인데 문자만 없다면 드라이브 문자 할당을 검토할 수 있습니다.

4단계. RAW·초기화 안 됨이라면 보존 우선

예전에 사용한 데이터가 있는 드라이브라면 새로운 볼륨 생성이나 포맷 절차를 적용하지 말고 자료 보존 방법을 확인합니다.

5단계. BitLocker·장치 관리자 상태 확인

암호화 잠금 여부와 USB 오류 코드가 있는지 확인하고 제조사 공식 지원 방법을 이용합니다.

6단계. 인식됐더라도 별도 백업

파일이 실제로 열리는지 확인하고 중요한 자료를 다른 물리 저장소에도 복사합니다.

문제 원인이 확인되지 않는 상황에서 여러 복구 절차를 한꺼번에 실행하면 진단이 어려워질 수 있습니다. 작은 범위부터 한 번에 한 단계씩 확인하세요.

자주 묻는 질문 FAQ

Q1. 윈도우11에서 USB 연결 소리는 나는데 드라이브가 안 보이는 이유는?

USB 연결 이벤트가 감지돼도 저장장치의 파일 시스템·파티션·드라이브 문자까지 정상 인식됐다는 뜻은 아닙니다. Windows 키 + E → 이 PC를 확인하고, 없다면 Windows 키 + R → diskmgmt.msc에서 디스크 상태를 살펴보세요.

Q2. 외장하드가 디스크 관리에는 있는데 파일 탐색기에 없으면?

디스크 관리에서 해당 볼륨이 온라인·정상 상태이고 드라이브 문자(E:, F: 등)가 빠져 있는지 확인하세요. 정상적인 데이터 볼륨에 문자가 없다면 드라이브 문자 및 경로 변경 → 추가를 이용할 수 있습니다. RAW·EFI·복구 파티션에는 무작정 적용하지 마세요.

Q3. '이 드라이브를 사용하려면 포맷해야 합니다'가 뜨면 바로 포맷해도 되나요?

기존 사진이나 업무 문서가 들어 있던 드라이브라면 포맷하지 마세요. Microsoft는 RAW나 기존 파일을 복구해야 하는 디스크에는 포맷을 진행하지 말라고 안내합니다. 먼저 자료의 중요도와 저장장치 상태를 확인하세요.

Q4. '알 수 없음·초기화 안 됨'을 누르면 기존 데이터가 살아나나요?

아닙니다. 초기화는 파일 복구 버튼이 아닙니다. Microsoft는 기존 데이터가 없는 새 디스크를 대상으로 초기화 절차를 설명하며, 이미 사용하던 디스크에는 데이터 손실 가능성을 경고합니다.

Q5. RAW로 표시된 USB를 NTFS로 포맷하면 원래 파일이 복구되나요?

그렇지 않습니다. 새 파일 시스템으로 포맷하면 USB를 다시 사용할 수 있는 상황은 있지만 원래 파일이 안전하게 복원되는 것이 아닙니다. 중요한 자료가 있다면 포맷을 보류하고 복구 가능성을 먼저 확인해야 합니다.

Q6. 드라이브에 E: 또는 F: 문자가 없는 경우 어떻게 하나요?

디스크 관리 → 해당 정상 볼륨 오른쪽 클릭 → 드라이브 문자 및 경로 변경 → 추가에서 문자를 지정할 수 있습니다. Windows나 프로그램이 설치된 시스템 볼륨, EFI·복구 파티션의 문자는 변경하지 마세요.

Q7. 외장하드 오류에 CHKDSK /f를 실행하면 파일이 삭제되나요?

데이터 손실 가능성을 배제할 수 없습니다. Microsoft는 CHKDSK의 /f 옵션이 파일 시스템을 수정하며 상황에 따라 파일 할당 정보에 영향을 줄 수 있다고 설명합니다. 중요한 파일이 이미 보이지 않거나 디스크 상태가 나쁘다면 백업·전문 진단을 우선 검토하세요.

Q8. USB-C 케이블로 충전이 되면 외장 SSD 데이터 전송도 되나요?

반드시 그렇지는 않습니다. 케이블·포트·허브가 지원하는 데이터 전송·전력·USB4 기능이 다를 수 있습니다. 제조사 권장 케이블을 사용하고 PC 포트에 직접 연결해 비교하세요.

Q9. 외장하드에 자물쇠 아이콘이 뜨고 암호를 요구하는 이유는?

BitLocker 암호화가 적용된 드라이브일 수 있습니다. Windows 로그인 PIN과 BitLocker 복구 키는 다른 정보입니다. 올바른 잠금 해제 암호 또는 복구 키를 확인하고, 잠금 해제를 위해 포맷하지 마세요.

Q10. 외장 SSD가 다른 PC에서도 보이지 않고 0바이트라면?

케이블·전력·외장 케이스·저장장치 자체의 문제가 있을 수 있습니다. 중요한 자료가 있는 디스크에 무리한 변경 작업을 반복하지 말고 제조사 또는 데이터 복구 전문업체의 진단을 검토하는 것이 좋습니다.

마무리: 포맷보다 디스크 상태 확인과 자료 보존이 먼저입니다

Windows 11에서 USB·외장하드가 보이지 않는다면 케이블·포트·전원 공급을 확인한 뒤 디스크 관리에서 장치가 어떤 상태로 표시되는지 살펴보세요.

온라인·정상인 볼륨에 드라이브 문자만 없는 경우에는 기존 드라이브에 문자를 추가하는 방법으로 해결할 수 있습니다. 반면 이전에 사용하던 디스크가 RAW·초기화 안 됨·할당되지 않음으로 나타난다면 새로운 파티션을 만들거나 포맷하는 것이 아니라 데이터 복구 가능성을 보존하는 일부터 고려해야 합니다.

USB가 다시 인식되더라도 문제가 완전히 해결됐다고 단정하지 말고 중요한 파일이 실제 열리는지 확인한 뒤 별도 저장소에 백업하세요. 이상이 반복되면 제조사 공식 지원 또는 전문 점검을 통해 원인을 확인하는 편이 안전합니다.
