엑셀에서 '완료'라고 입력한 행은 회색으로, 마감일이 지난 업무는 빨간색으로, 목표 점수 미달인 셀은 노란색으로 자동 표시하고 싶다면 '조건부 서식'을 사용하면 됩니다. 셀에 일일이 색을 칠하지 않아도 값이 바뀌면 정해 둔 규칙에 따라 표시가 달라집니다.

하지만 행 전체 색을 바꿀 때는 적용 범위와 달러($)가 붙은 참조를 구분해야 합니다. 특히 같은 규칙이 여러 개 겹치거나 범위가 어긋나면 조건부 서식이 안 되는 것처럼 보이는 문제가 생깁니다.

이 글에서는 기본 셀 강조 → 행 전체 색 변경 → 마감일 날짜 경고 → 빈칸 제외 → 데이터 막대·색조 → 규칙 우선순위 → 규칙 삭제·오류 해결 순서로 설명합니다.

2026년 11월 4일 기준 Microsoft 공식 Excel 지원 문서를 확인했습니다. Microsoft 365·Excel 2024·2021·2019 및 웹 버전에서 메뉴 이름이나 제공 기능은 일부 다를 수 있습니다.

1. 엑셀 조건부 서식이란?

조건부 서식은 셀 값이나 수식 결과에 따라 글꼴·채우기 색·데이터 막대·아이콘 등의 표시를 자동으로 변경하는 기능입니다.

일반 채우기 색과의 차이는 다음과 같습니다.

구분일반 셀 채우기조건부 서식
적용 방법사용자가 직접 색을 지정값·수식에 따른 규칙 지정
값이 바뀔 때색이 그대로 남음새 조건에 맞게 표시가 바뀜
활용 예제목 행 강조지연 일정, 목표 달성, 재고 부족

기억할 점: 조건부 서식은 데이터를 삭제하거나 셀의 실제 값을 변경하는 기능이 아닙니다. 화면에 보이는 서식을 조절하므로, 엑셀에서 상태 문구 자체를 바꾸려면 IF 함수 등 별도 계산이 필요합니다.

2. 가장 쉬운 예제: 60점 미만을 빨간색으로 표시하기

B2:B20에 시험 점수가 입력돼 있다고 가정합니다.

  1. B2:B20 범위를 선택합니다.
  2. 홈 → 조건부 서식 → 셀 강조 규칙 → 보다 작음을 선택합니다.
  3. 기준값에 60을 입력합니다.
  4. 빨간색 채우기 등 원하는 표시를 선택하고 적용합니다.
  5. B열의 점수를 변경하면서 조건에 따라 색상이 달라지는지 확인합니다.

다른 예로 '100 이상'인 값만 강조하려면 셀 강조 규칙 → 보다 큼을 사용할 수 있습니다. 경계값 포함 여부를 확인하세요. 예컨대 60점 미만은 60을 포함하지 않고, 60점 이하는 포함합니다.

빈칸도 빨간색으로 변한다면?

기본 규칙의 동작은 값 형식·조건에 따라 다르게 보일 수 있습니다. 빈칸을 확실히 제외하려면 뒤에서 설명하는 수식을 사용한 규칙으로 ISNUMBER를 함께 검사하는 방법이 있습니다.

3. 가장 중요한 실무 예제: '완료'인 행 전체 회색으로 만들기

아래처럼 A열 = 업무, B열 = 담당자, C열 = 상태, D열 = 마감일인 표를 가정합니다. 첫 행은 제목이고 실제 데이터는 2행부터 100행까지입니다.

A열 업무B열 담당자C열 상태D열 마감일
견적서 작성김현수완료2026-11-02
제안서 검토이수진진행중2026-11-10
계약서 제출박지훈지연2026-11-01

목표: C열에 '완료'라는 텍스트가 입력되면 A~D열 전체에 회색 배경을 적용합니다.

  1. 데이터 범위 A2:D100을 먼저 선택합니다.
  2. 홈 → 조건부 서식 → 새 규칙을 누릅니다.
  3. 수식을 사용하여 서식을 지정할 셀 결정을 선택합니다.
  4. 수식 칸에 아래 내용을 입력합니다.
=$C2="완료"
  1. 서식 → 채우기 → 연한 회색을 선택합니다.
  2. 확인을 눌러 적용합니다.
  3. C3의 '진행중'을 '완료'로 바꿔 3행 전체에 회색이 적용되는지 확인합니다.

왜 $C2라고 써야 할까?

  • $C: 항상 상태 열인 C열을 검사하라는 의미입니다.
  • 2: 규칙이 아래 행으로 이동할 때 검사할 행도 함께 바뀌도록 남겨 둡니다.
  • 적용 대상 $A$2:$D$100: 색을 칠할 전체 범위입니다.

=$C$2="완료"처럼 행 번호에도 달러를 붙이면 모든 행에서 C2만 검사하게 될 수 있습니다. 반대로 =C2="완료"처럼 열을 고정하지 않으면 여러 열에 규칙을 적용할 때 참조 열이 이동해 예상과 다른 결과가 생길 수 있습니다.

반드시 확인: A2:D100을 선택했다면 수식은 첫 번째 데이터 행인 2행을 기준으로 작성해야 합니다. 표가 5행부터 시작한다면 =$C5="완료"처럼 기준 행도 바꿉니다.

4. '마감일 지남'을 자동으로 빨간색 표시하기

업무 현황표에서 D열은 마감일, C열은 상태라고 가정합니다. 이미 완료한 업무는 제외하고, 마감일이 지난 행만 빨갛게 만들겠습니다.

선택할 범위: A2:D100

=AND(ISNUMBER($D2),$D2<TODAY(),$C2<>"완료")

이 수식은 다음 세 조건을 모두 확인합니다.

  1. ISNUMBER($D2): D열에 엑셀이 날짜로 인식한 숫자형 날짜가 입력돼 있는지 검사합니다.
  2. $D2<TODAY(): 마감일이 오늘보다 이전인지 검사합니다.
  3. $C2<>"완료": C열의 상태가 완료가 아닌지 검사합니다.

이 규칙에 빨간색 채우기를 지정하면 마감일이 지났고 아직 완료되지 않은 업무가 강조됩니다.

주의: 엑셀에서 날짜는 보통 일련번호 형태의 숫자 값으로 저장됩니다. '2026-11-01'이 날짜가 아닌 문자열로 입력됐다면 비교 결과가 잘못 나올 수 있습니다. 먼저 셀 표시 형식과 실제 데이터 값을 확인하세요.

마감일까지 7일 이하로 남은 업무는 노란색

같은 범위 A2:D100에 아래 수식을 사용하는 두 번째 규칙을 만듭니다.

=AND(ISNUMBER($D2),$D2>=TODAY(),$D2<=TODAY()+7,$C2<>"완료")

이 예제에서는 오늘부터 7일 후까지인 날짜가 노란색으로 표시됩니다. 7일이라는 기간과 완료 제외 조건은 예시이므로 자신의 업무에 맞춰 변경할 수 있습니다.

두 규칙의 날짜 조건은 지난 날짜 / 오늘 이후로 나뉘어 있으므로, 정상적인 날짜가 입력된 경우 동일한 행이 두 조건을 동시에 충족하지 않도록 설계했습니다.

5. 빈칸을 제외하고 숫자가 있을 때만 강조하기

B열에 점수가 입력되면 60점 미만을 노랗게 표시하되, 아직 점수를 입력하지 않은 행은 그대로 남기고 싶다면 수식으로 조건부 서식을 지정합니다.

선택 범위: B2:B100

=AND(ISNUMBER(B2),B2<60)

이 수식은 B2에 실제 숫자 값이 있을 때만 60 미만인지 판단합니다. 아직 점수가 비어 있는 셀을 불필요하게 강조하지 않는 데 유용합니다.

자주 발생하는 실수: 외부 시스템에서 내려받은 데이터에는 "59"처럼 숫자처럼 보이는 텍스트가 있을 수 있습니다. 그런 셀은 ISNUMBER에서 FALSE로 판정될 수 있으므로, 데이터 형식을 확인하고 필요한 경우 숫자로 변환해야 합니다. 단순히 셀 표시 형식만 '숫자'로 바꿔도 실제 값까지 모두 변환되는 것은 아닙니다.

6. 특정 단어가 포함된 셀만 색상 변경하기

고객 문의 현황표에서 '환불'이 들어간 메모를 강조하고 싶다면 텍스트 포함 규칙을 쓸 수 있습니다.

  1. 메모 범위 E2:E100을 선택합니다.
  2. 홈 → 조건부 서식 → 셀 강조 규칙 → 텍스트 포함을 선택합니다.
  3. 기준 단어에 환불을 입력합니다.
  4. 원하는 색상을 선택해 적용합니다.

'환불 요청', '환불 확인 중'처럼 같은 단어가 포함된 항목들을 한 번에 확인할 때 유용합니다.

반면 상태가 정확히 '완료'인 경우만 강조해야 한다면 앞의 =$C2="완료"처럼 동등 비교 수식을 쓰는 편이 명확합니다. '완료 예정'까지 모두 완료로 처리해서는 안 되기 때문입니다.

7. 데이터 막대·색조·아이콘 집합 차이

엑셀의 조건부 서식에는 숫자들을 비교할 때 유용한 시각화 옵션도 있습니다. Microsoft 공식 지원 문서는 데이터 막대, 색조(색 배율), 아이콘 집합을 대표적인 유형으로 설명합니다.

유형화면에서 보이는 방식적합한 예
데이터 막대셀 안에 길이가 다른 막대 표시팀별 매출·수량 비교
색조·색 배율값에 따라 연속적인 배경색 변화점수 분포, 실적 차이
아이콘 집합화살표·신호등·등급 아이콘목표 달성도, 상태 분류

데이터 막대 설정

  1. 매출이 입력된 B2:B20을 선택합니다.
  2. 홈 → 조건부 서식 → 데이터 막대를 엽니다.
  3. 단색 또는 그라데이션 스타일을 선택합니다.
  4. 값이 큰 셀에서 막대가 더 길게 표시되는지 확인합니다.

주의: 데이터 막대의 길이는 일반적으로 선택한 범위 내 값의 상대적 차이를 보여줍니다. 특정 절대 목표액을 달성했는지 판정해야 한다면 데이터 막대만으로 충분하지 않으며, 별도 기준값 규칙이 더 적절할 수 있습니다.

아이콘 집합에서 기본 기준을 그대로 써도 될까?

기본 아이콘 집합은 데이터에 따라 백분율·백분위수 등 임계값을 사용할 수 있습니다. 사용자가 생각한 '매출 100만 원 이상은 녹색' 같은 절대 기준액과 다를 수 있으므로, 규칙 관리 → 규칙 편집에서 값 유형 및 임계값을 확인하세요.

8. 조건부 서식 규칙을 수정·삭제하는 방법

조건부 서식을 바꿨는데 색이 그대로 남아 있다면 무조건 표를 다시 만들기보다 규칙 관리자를 확인하세요.

규칙 수정

  1. 조건부 서식이 있는 셀을 선택합니다.
  2. 홈 → 조건부 서식 → 규칙 관리를 선택합니다.
  3. 규칙 표시 범위를 현재 선택 영역 또는 현재 워크시트 등으로 설정합니다.
  4. 수정할 규칙을 선택하고 규칙 편집을 누릅니다.
  5. 수식·채우기 색·적용 대상 범위를 확인하고 저장합니다.

규칙 삭제

  • 일부 셀만 삭제: 해당 범위를 선택한 다음 홈 → 조건부 서식 → 규칙 지우기 → 선택한 셀에서 규칙 지우기
  • 현재 워크시트 전체: 홈 → 조건부 서식 → 규칙 지우기 → 전체 시트에서 규칙 지우기

중요: 조건부 서식을 지운다고 셀 안의 숫자·날짜·텍스트 값이 자동으로 삭제되는 것은 아닙니다. 다만 원래 사용자가 수동으로 지정한 색은 남을 수 있습니다. 적용 범위가 다른 시트에 연결되어 있지 않은지 먼저 확인하세요.

9. 규칙이 2개 이상일 때: 우선순위와 충돌

같은 셀에 '완료면 회색' 규칙과 '마감일 지났으면 빨강' 규칙이 함께 적용된다면, 두 조건이 참일 때 어느 색이 보일지 문제가 생깁니다.

Microsoft 공식 문서에 따르면 조건부 서식 규칙 관리자에서는 규칙이 위에서 아래로 우선순위를 갖습니다. 같은 속성(예: 배경색)을 서로 다르게 지정한 규칙이 충돌하면 우선순위가 높은 규칙이 적용될 수 있습니다.

해결 순서:

  1. 홈 → 조건부 서식 → 규칙 관리를 엽니다.
  2. '서식 규칙 표시'에서 현재 워크시트를 선택해 관련 규칙을 모두 확인합니다.
  3. 중복되는 규칙의 수식과 적용 범위를 확인합니다.
  4. 더 중요한 규칙을 위쪽으로 이동합니다.
  5. 필요한 경우 참일 경우 중지(Stop If True) 옵션이 적절한지 검토합니다.

추천 설계: 예제처럼 '완료한 업무는 마감일 경고에서 제외'하도록 빨간색 규칙 자체에 $C2<>"완료" 조건을 포함하면, 규칙 충돌을 줄이는 데 도움이 됩니다. 단순히 순서를 바꾸는 것보다 조건을 명확하게 설계하는 편이 유지 관리에 유리할 수 있습니다.

10. 조건부 서식이 안 되는 이유 7가지

① 적용 범위가 틀렸습니다

행 전체를 칠해야 하는데 적용 범위가 $C$2:$C$100으로 되어 있다면 상태 셀만 색칠됩니다. **전체 행 강조는 $A$2:$D$100**처럼 범위를 잡아야 합니다.

② 절대 참조($)를 잘못 사용했습니다

수식 =$C$2="완료"은 아래 행으로 내려가도 항상 C2만 검사할 수 있습니다. 행마다 상태를 확인해야 한다면 =$C2="완료"가 적합합니다.

③ 수식의 시작 행과 적용 범위의 시작 행이 다릅니다

적용 범위가 A5:D100이라면 수식도 보통 =$C5="완료"부터 시작해야 합니다. 범위와 수식의 기준 행이 맞는지 검토하세요.

④ 날짜가 날짜가 아닌 텍스트입니다

'2026-11-01'이 텍스트라면 TODAY()와의 비교가 기대한 결과를 내지 않을 수 있습니다. 날짜 데이터가 실제 날짜 값인지 확인해야 합니다.

⑤ 숫자처럼 보이는 문자가 들어 있습니다

CSV에서 들어온 "100"은 숫자가 아닐 수 있습니다. ISNUMBER를 활용하는 규칙에서 강조가 되지 않는다면 실제 데이터 형식부터 확인하세요.

⑥ 다른 규칙과 색이 충돌합니다

여러 규칙이 같은 셀의 배경색을 지정할 때는 규칙 우선순위를 확인하세요. 조건부 서식은 수동 채우기 색보다 우선 표시될 수도 있습니다.

⑦ 복사·붙여넣기 이후 규칙이 여러 개 생겼습니다

서식이 포함된 범위를 반복해서 복사하면 유사 규칙이 여러 개 생성될 수 있습니다. 규칙 관리자에서 중복 규칙의 적용 범위를 점검하고, 필요 없는 것은 제거하세요.

11. 복사해서 사용할 수 있는 실전 수식 5개

다음 예제는 모두 2행부터 시작하며, 상태는 C열, 날짜는 D열, 점수는 B열인 표를 가정합니다.

목적적용할 수식
상태가 완료인 행 전체 강조=$C2="완료"
상태가 지연인 행 전체 강조=$C2="지연"
점수가 있을 때만 60점 미만 표시=AND(ISNUMBER($B2),$B2<60)
날짜가 지났고 완료되지 않은 행=AND(ISNUMBER($D2),$D2<TODAY(),$C2<>"완료")
마감일 7일 이내이며 완료되지 않은 행=AND(ISNUMBER($D2),$D2>=TODAY(),$D2<=TODAY()+7,$C2<>"완료")

활용 팁: 수식에 한글 상태명을 넣었다면 표의 실제 텍스트와 일치하는지 확인하세요. "완료"와 "처리완료"는 동일한 문자열이 아닙니다. 앞뒤 불필요한 공백이 있으면 결과가 다르게 나타날 수 있습니다.

자주 묻는 질문

Q. 엑셀 조건부 서식으로 행 전체 색을 바꾸려면?

A2:D100 전체를 선택한 뒤 '수식을 사용하여 서식을 지정할 셀 결정'에서 =$C2="완료"처럼 기준 열만 $로 고정하는 수식을 사용하세요. 실제 상태 열이 다른 경우 수식의 열 문자도 바꿔야 합니다.

Q. 셀 값을 바꾸면 색도 자동으로 바뀌나요?

조건부 서식 규칙이 정상 적용된 상태라면 일반적으로 셀 값이나 수식 결과가 바뀔 때 표시가 갱신됩니다. 수식 계산이 수동으로 설정되어 있는 경우, TODAY() 같은 계산식은 자동 계산 설정도 확인해야 할 수 있습니다.

Q. 특정 문자만 포함해도 색을 바꿀 수 있나요?

가능합니다. 조건부 서식 → 셀 강조 규칙 → 텍스트 포함을 사용해 단어를 기준으로 강조할 수 있습니다. 단, 정확히 특정 상태명과 일치할 때만 강조하려면 수식으로 일치 여부를 비교하는 편이 명확합니다.

Q. 조건부 서식을 삭제하면 데이터도 없어지나요?

조건부 서식 규칙 삭제는 일반적으로 서식 규칙을 제거하는 기능입니다. 숫자·날짜·텍스트 데이터가 자동으로 삭제되지는 않습니다. 다만 수동으로 지정한 색은 그대로 보일 수 있습니다.

Q. 빨강과 노랑 규칙을 함께 만들었는데 하나만 보입니다.

두 규칙이 모두 참이거나 적용 범위가 겹치는지 확인하세요. 홈 → 조건부 서식 → 규칙 관리에서 순서·서식·'참일 경우 중지' 옵션을 검토하면 원인을 찾는 데 도움이 됩니다.

핵심 요약

엑셀 조건부 서식의 핵심은 적용 범위, 참조 방식, 규칙 순서입니다. 숫자 하나의 색을 바꾸려면 셀 강조 규칙으로 시작하고, 행 전체를 바꾸려면 =$C2="완료"처럼 열 고정 수식을 사용하세요. 마감일과 빈칸이 섞인 업무 표에서는 날짜의 실제 데이터 형식을 확인하고, 다른 규칙과의 충돌까지 고려하면 관리하기 쉬운 표를 만들 수 있습니다.
