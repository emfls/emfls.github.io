회사 제출용 서류가 두 개의 PDF로 나뉘어 있거나, 여러 장의 스캔 파일을 하나로 합쳐 제출해야 할 때가 있습니다. 이때 'PDF 합치기 무료'를 검색해서 아무 사이트에나 파일을 업로드하는 방법이 최선은 아닙니다. 윈도우 11에서는 무료 오프라인 프로그램을 이용하고, 맥에서는 기본 '미리보기' 앱만으로도 파일을 합칠 수 있습니다.

이 글은 2026년 11월 기준 Apple, PDFsam, Adobe의 공식 안내를 바탕으로 PDF 병합, 페이지 순서 조정, 일부 페이지만 추출하는 방법을 구분해 설명합니다. 실제 작업 시에는 파일마다 암호 설정·전자서명·문서 구조가 다를 수 있으므로, 원본 백업과 결과 파일 열람 검증이 필요합니다.

2. 윈도우 11에서 PDF 무료로 합치기: PDFsam Basic

윈도우 11에서 'Microsoft Print to PDF'로 파일을 다시 PDF로 저장하는 것과 별도의 PDF 두 개를 하나의 문서로 병합하는 것은 다릅니다. Edge 브라우저의 PDF 보기 기능만으로 파일 여러 개를 원하는 순서대로 병합한다고 생각하면 작업이 꼬일 수 있습니다.

무료 오프라인 도구가 필요한 경우 PDFsam Basic이 선택지입니다. 공식 사이트에서 Basic은 무료·오픈 소스이며 Windows, macOS, Linux를 지원한다고 안내합니다.

단계별 방법

  1. 개발사 공식 페이지 PDFsam Basic 다운로드를 엽니다.
  2. **PDFsam Basic(무료 버전)**을 선택하고 운영체제에 맞는 설치 파일을 받습니다. 'Visual'이나 'Enhanced'는 Basic과 요금 체계가 다른 제품이므로 혼동하지 마세요.
  3. 프로그램을 실행한 뒤 Merge(병합) 기능을 선택합니다.
  4. 병합할 PDF 두 개 이상을 목록에 추가하거나 끌어다 놓습니다.
  5. 목록의 위아래 순서를 조정합니다. 예를 들어 '표지.pdf → 신청서.pdf → 첨부서류.pdf' 순으로 배치합니다.
  6. 결과 파일의 저장 경로와 이름을 정합니다. 예: '제출용_통합본.pdf'.
  7. **Run(실행)**을 눌러 병합합니다.
  8. 지정한 폴더의 결과 파일을 열어 첫 페이지, 마지막 페이지, 페이지 수, 순서를 검수합니다.

원본과 같은 파일명을 결과 파일에 사용하는 것은 피하는 것이 좋습니다. 원본 보존이 필요한 업무 문서라면 '원본' 폴더와 '완료본' 폴더를 분리하세요.

PDFsam Basic이 무료인 범위

PDFsam 측의 공개 안내에 따르면 Basic은 PDF 병합·분할·페이지 추출·회전·페이지 혼합 기능을 제공합니다. 워터마크를 추가하지 않고 별도 가입과 인터넷 연결 없이 사용할 수 있으며, 제조사 설명상 파일 크기 제한이 없습니다. 다만 큰 문서는 컴퓨터의 메모리·저장장치 성능에 따라 실제 처리 시간이 달라집니다.

다운로드 시 PDFsam Basic / PDFsam Visual / PDFsam Enhanced를 혼동하지 않는 것이 핵심입니다. Visual의 시각적 페이지 편집 화면이나 Enhanced의 전체 PDF 편집 기능은 Basic과 동일한 무료 기능이라고 단정해서는 안 됩니다.

공식 출처: PDFsam Basic 소개, PDFsam 병합 안내, PDFsam 제품별 기능 차이

3. 맥북에서 PDF 합치기: 기본 '미리보기' 앱

macOS의 미리보기(Preview) 앱에서는 PDF 파일을 열고 썸네일을 드래그해 다른 PDF에 넣을 수 있습니다. 별도 앱 설치가 필요하지 않습니다.

중요: Apple은 미리보기에서 문서를 변경하면 변경 사항이 자동 저장될 수 있다고 경고합니다. 원본이 중요하다면 먼저 Finder에서 파일을 복사하거나 미리보기의 파일 → 복제로 별도 사본을 만드세요.

단계별 방법

  1. Finder에서 첫 번째 PDF를 미리보기 앱으로 엽니다.
  2. 두 번째 PDF도 미리보기로 엽니다.
  3. 두 PDF 창에서 각각 보기 → 썸네일을 선택합니다.
  4. 왼쪽 사이드바에서 PDF의 페이지 축소판이 나타나는지 확인합니다.
  5. 두 번째 PDF의 필요한 페이지 썸네일을 선택해 첫 번째 PDF의 썸네일 영역으로 끌어다 놓습니다.
  6. 넣을 위치의 앞뒤를 확인하고 드롭합니다.
  7. 썸네일을 다시 드래그해 페이지 순서를 변경합니다.
  8. 통합된 문서를 새 파일로 보관하고 페이지 수를 검수합니다.

여러 장을 연속 선택하거나 Command 키를 누른 채 특정 페이지만 선택하는 방식도 지원됩니다. 전체 PDF를 추가하려면 Finder의 PDF 파일 아이콘을 열린 PDF의 썸네일 사이드바로 드래그할 수도 있습니다.

공식 출처: Apple — Mac용 미리보기에서 PDF 결합, Apple — Mac에서 PDF 페이지 이동

4. 맥에서 PDF 여러 개를 한 번에 합치는 더 빠른 방법

단순히 파일 여러 개를 하나의 PDF로 만들고 싶다면 Finder의 빠른 동작을 이용할 수 있습니다.

  1. Finder에서 합칠 파일을 선택합니다.
  2. 선택된 파일을 Control-클릭합니다.
  3. 빠른 동작 → PDF 생성을 선택합니다.
  4. 만들어진 PDF를 열어 페이지 순서를 확인합니다.

Apple 설명에 따르면 이 방식은 선택한 순서대로 파일이 PDF에 나타나는 구조이므로, 제출 서류 순서가 정해져 있다면 생성 후 반드시 검증하세요. 일부 페이지만 끼워 넣거나 복잡하게 편집할 때는 미리보기의 썸네일 이동 방식이 더 적합합니다.

공식 출처: Apple — Mac에서 여러 파일을 PDF로 결합

5. 일부 페이지만 뽑아서 하나로 합치는 방법

예를 들어 20페이지짜리 계약서에서 1~3페이지와 16~18페이지만 별도의 증빙 파일과 합쳐야 할 수 있습니다.

PDFsam Basic은 입력 파일별로 페이지 범위를 지정해 병합할 수 있습니다. 회사의 문서 열람 권한과 제출 기준을 먼저 확인하고, 필요한 범위를 직접 고릅니다.

예시:

입력 파일가져올 페이지합칠 순서
계약서.pdf1~3, 16~181번째
영수증.pdf모든 페이지2번째
신청서.pdf1페이지3번째

이것은 예시 페이지 구성이지 모든 기관에 적용되는 제출 방식은 아닙니다. 첨부서류 제출 시에는 기관이 요구하는 전체 페이지·서명·날짜가 누락되지 않도록 확인하세요.

PDFsam의 병합 화면에서 파일별 페이지 선택 옵션을 확인해 필요한 범위만 지정합니다. 개발사는 범위 입력 예시로 1-10, 14, 25-와 같은 형태를 제공합니다. 화면에 표시된 옵션이 설치 버전과 일치하는지 확인한 후 실행하세요.

공식 출처: PDFsam Basic 페이지 범위 병합

6. 설치 없이 온라인에서 PDF 합치기: Adobe 웹용 Acrobat

학교 과제처럼 민감하지 않은 파일을 일시적으로 합칠 때는 웹 방식이 편할 수 있습니다. Adobe 공식 도움말은 웹용 Acrobat의 다음 흐름을 안내합니다.

  1. Adobe Acrobat 웹에 접속합니다.
  2. 편집 → 파일 결합 기능으로 이동합니다.
  3. 합칠 파일을 선택해 업로드합니다.
  4. 파일 또는 페이지를 끌어다 놓아 순서를 정합니다.
  5. 필요한 파일을 제거하거나 페이지 구성을 확인합니다.
  6. 결합을 선택합니다.
  7. 완성된 PDF의 저장 상태를 확인하고 내려받아 검수합니다.

주의: Adobe 공식 문서에 따르면 웹에서 결합된 파일은 Adobe 클라우드 스토리지에 자동 저장됩니다. 기능 이용 자격, 로그인 또는 사용량 제한은 계정과 제공 정책에 따라 달라질 수 있으므로, '모든 파일을 무제한·무료·로그인 없이 병합할 수 있다'고 단정해서는 안 됩니다. 민감한 파일은 로컬 도구를 우선하세요.

또한 Adobe는 보안 상태이거나 암호로 보호된 파일, 3D 파일, PDF 포트폴리오에 속한 파일은 웹 결합이 제한될 수 있다고 안내합니다.

공식 출처: Adobe — 웹용 Acrobat 파일 결합

7. PDF 합치기 후 페이지 순서가 엉켰을 때

병합 오류처럼 보이지만 실제로는 입력 파일의 배열 순서가 달랐던 경우가 흔합니다.

  • 파일 순서: A.pdf 다음 B.pdf인지 확인합니다.
  • 페이지 순서: 파일 자체에 역순으로 스캔된 페이지가 없는지 확인합니다.
  • 표지 위치: 표지가 첫 장이어야 한다면 가장 위에 배치합니다.
  • 세로·가로 방향: 결합 자체와 별개로 회전이 필요한 페이지가 있는지 확인합니다.
  • 페이지 누락: 일부 페이지만 선택한 옵션을 그대로 두지 않았는지 확인합니다.

맥 미리보기와 Acrobat의 페이지 축소판에서는 위치를 드래그해 조정할 수 있습니다. PDFsam Basic에서는 파일 배열 순서와 페이지 범위를 조정해 다시 병합하세요.

스캔본이 홀수·짝수 페이지로 나뉘어 있다면 단순 병합보다는 PDFsam Basic의 Mix 기능이 적절할 수 있습니다. 개발사 안내에 따르면 이 기능은 홀수 페이지와 짝수 페이지를 번갈아 끼우며, 뒤집어 스캔한 페이지의 역순 처리를 지원합니다.

공식 출처: PDFsam — 홀수·짝수 페이지 혼합, Adobe — 병합 문서 재정렬

8. PDF 병합 시 개인정보 유출을 피하는 방법

PDF에는 화면에 보이는 이름이나 주소뿐 아니라 작성자 정보, 주석, 첨부 파일, 전자서명, 문서 속성 등이 남아 있을 수 있습니다. 민감한 서류일수록 파일을 어디로 보내는지를 먼저 판단해야 합니다.

온라인 업로드 전에 확인할 것

  • 주민등록번호·계좌번호·진료 기록·급여 정보 등이 들어 있지는 않은가?
  • 기관이나 회사가 승인한 파일 처리 도구인가?
  • 서비스가 파일을 클라우드에 저장하는가? 저장·삭제·공유 정책을 확인했는가?
  • 링크로 공유되는 경우 접근 권한이 적절한가?
  • 로컬 오프라인 병합으로 동일 목적을 달성할 수 있는가?

검은색 사각형을 덮어 놓는 것만으로 PDF 내부 글자가 완전히 삭제된다고 보장할 수 없습니다. 개인정보 가리기와 PDF 병합은 별도 작업입니다. 주민등록번호 등의 삭제가 필요하면 전용 교정(redaction) 기능으로 처리하고, 결과 파일의 텍스트 추출 여부까지 검증해야 합니다.

관련 읽을거리: 기존 블로그의 '2026 PDF 개인정보 가리기 제대로 하는 법' 글과 함께 확인하면 좋습니다.

9. PDF 파일 결합이 안 될 때: 증상별 진단표

증상먼저 확인할 것권장 대처

10. 자주 묻는 질문

Q. 윈도우 11에서는 프로그램 없이 PDF 두 개를 합칠 수 없나요?

Windows의 기본 PDF 보기·인쇄 기능은 여러 PDF를 병합하는 전용 편집 기능과 구분해야 합니다. 모든 컴퓨터에 동일한 무료 병합 도구가 기본 설치돼 있다고 가정하기보다, 무료 오프라인 도구인 PDFsam Basic 또는 승인된 다른 솔루션을 확인하는 편이 안전합니다.

Q. PDFsam Basic에 워터마크가 생기나요?

개발사의 공식 설명에 따르면 PDFsam Basic은 워터마크를 추가하지 않는 무료 오픈 소스 버전입니다. 단, 다운로드 페이지에서 Basic이 아닌 다른 제품을 선택하지 않도록 확인하세요.

Q. Mac에서 PDF 합치기 후 원본 PDF가 바뀔 수 있나요?

Apple은 미리보기가 문서 변경 사항을 자동 저장할 수 있다고 안내합니다. 합치기 전에 파일 → 복제로 원본 사본을 만들어 놓으세요.

Q. PDF 여러 개를 순서대로 합친 후 용량을 줄이려면?

병합과 압축은 별개의 작업입니다. 원본에 고해상도 이미지가 많으면 결과 PDF도 클 수 있습니다. 제출처의 최대 파일 크기, 이미지 품질, 글자 식별 가능 여부를 확인하고 적절한 PDF 압축 기능을 사용해야 합니다.

Q. 온라인 PDF 합치기 사이트에 개인정보가 들어간 PDF를 올려도 되나요?

서비스마다 보관·삭제 정책이 다르며, Adobe 공식 문서에도 웹에서 결합한 파일을 클라우드에 저장한다고 명시돼 있습니다. 신분증·계약서·금융·의료 서류는 불필요한 온라인 업로드를 피하고, 승인된 로컬 처리 방법을 우선하는 것이 좋습니다.

Q. PDF에 비밀번호가 설정돼 있는데 합쳐도 되나요?

암호가 설정된 PDF는 도구별 지원 방식이 다를 수 있습니다. 정당한 열람·편집 권한을 가진 문서인지 확인하고, 필요한 경우 문서 제공자에게 편집 가능한 버전을 요청하세요. 암호를 우회하는 불분명한 웹사이트에 파일을 맡기지 마세요.

11. 제출 전 1분 최종 확인

  • ☐ 결과 PDF를 원본과 다른 이름으로 저장했다.
  • ☐ 첫 페이지와 마지막 페이지가 올바르다.
  • ☐ 전체 페이지 수가 예상과 일치한다.
  • ☐ 중요한 서명·날짜·첨부서류가 빠지지 않았다.
  • ☐ 글자와 표가 깨지지 않고 정상적으로 열린다.
  • ☐ 개인정보가 포함된 파일을 무심코 외부 사이트에 업로드하지 않았다.
  • ☐ 제출처의 파일 크기와 문서 형식 조건을 만족한다.
  • ☐ 원본 파일을 별도로 보존했다.

정리: 맥에서는 미리보기 앱 또는 Finder PDF 생성, 윈도우 11에서는 PDFsam Basic을 이용하면 별도 클라우드 업로드 없이 PDF를 합칠 수 있습니다. 웹용 Acrobat도 가능하지만 클라우드에 파일이 저장되는 점을 이해한 후 사용해야 합니다. 속도보다 중요한 것은 페이지 누락 방지, 원본 보존, 개인정보 보호입니다.
