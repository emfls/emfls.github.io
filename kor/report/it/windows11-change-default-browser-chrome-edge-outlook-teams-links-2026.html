윈도우11에서 이메일·메신저·문서에 포함된 웹 링크를 눌렀을 때 원하는 브라우저가 아니라 Microsoft Edge가 열리는 경우가 있습니다. 평소 Chrome(크롬)을 쓰는데 링크만 Edge로 열리거나, 기본 브라우저를 바꿨는데도 일부 앱에서는 변경 사항이 적용되지 않아 불편할 수 있습니다.

가장 먼저 확인할 곳은 Windows 설정 → 앱 → 기본 앱입니다. 여기서 Chrome을 기본 브라우저로 지정할 수 있지만, Outlook이나 Microsoft Teams 등 일부 앱은 자체 링크 열기 옵션이 있어 Windows의 기본 브라우저 설정과 앱 내부 설정을 별도로 확인해야 합니다.

이 글은 Microsoft와 Google 공식 도움말을 기준으로 Windows 11에서 Chrome을 기본 브라우저로 설정하는 순서, Edge로 다시 변경하는 방법, PDF 파일 연결과 웹 링크의 차이, Outlook·Teams 예외, 회사·학교 PC에서 변경이 제한되는 상황까지 정리했습니다.

2. 윈도우11 기본 브라우저를 Chrome으로 바꾸는 방법

가장 표준적인 설정 경로입니다. Google의 공식 Chrome 도움말과 Microsoft의 기본 앱 안내가 이 방식을 설명합니다.

  1. Chrome이 설치돼 있는지 확인합니다.
  2. 키보드에서 Windows 키 + I를 눌러 설정 앱을 엽니다.
  3. 왼쪽 메뉴에서 앱 → 기본 앱을 선택합니다.
  4. '앱의 기본값 설정' 또는 앱 검색창에서 Chrome을 검색합니다.
  5. 목록에서 Google Chrome을 선택합니다.
  6. 상단에 보이는 기본값 설정 버튼을 누릅니다.
  7. 아래쪽의 파일 형식·링크 유형 목록에서 변경 사항이 적용됐는지 확인합니다.
  8. 메모나 다른 앱의 일반 웹 링크를 클릭해 Chrome이 열리는지 시험합니다.

참고: 메뉴 이름과 화면의 정렬은 Windows 업데이트에 따라 조금 달라질 수 있습니다. Google은 Windows 11에서 Chrome을 고른 뒤 상단의 'Chrome을 기본 브라우저로 설정' 옆에서 기본값 설정을 누르도록 안내합니다.

설정이 제대로 됐는지 확인하려면 링크를 두세 종류로 테스트하는 편이 좋습니다. Windows 기본 연결과 특정 앱의 내부 링크 설정은 다를 수 있기 때문입니다.

공식 출처: Google Chrome 고객센터 — Chrome을 기본 브라우저로 지정하기

3. Chrome에서 '기본 브라우저로 설정'을 눌러도 되는가?

Chrome을 실행한 상태에서 기본 브라우저를 변경하는 기능도 있습니다. 다만 Windows 11에서는 실제 기본값 변경이 Windows 설정의 기본 앱 화면과 연결될 수 있습니다.

진행 방법은 다음과 같습니다.

  1. Chrome을 엽니다.
  2. 오른쪽 위 더보기(점 세 개) → 설정을 선택합니다.
  3. 왼쪽 메뉴에서 기본 브라우저 항목을 찾습니다.
  4. 기본 브라우저로 설정하는 버튼이 있다면 누릅니다.
  5. Windows의 기본 앱 화면이 열리면 Google Chrome → 기본값 설정을 선택합니다.
  6. 링크를 클릭해 결과를 확인합니다.

브라우저 안에서 변경을 시작했더라도 Windows 기본 앱의 연결 정보가 최종적으로 바뀌었는지 확인하는 것이 중요합니다.

Chrome 자체를 열었을 때 시작 페이지를 바꾸는 설정과, 다른 프로그램의 링크가 어떤 브라우저로 열리는지를 바꾸는 설정은 별개입니다.

4. 기본 브라우저를 Microsoft Edge로 되돌리는 방법

Chrome을 기본으로 설정했다가 다시 Edge를 사용하고 싶다면 같은 경로에서 변경할 수 있습니다.

  1. 설정 → 앱 → 기본 앱으로 이동합니다.
  2. 검색창에서 Microsoft Edge를 찾습니다.
  3. Edge를 선택합니다.
  4. Microsoft Edge를 기본 브라우저로 설정 옆의 기본값 설정을 선택합니다.
  5. 설정 후 일반 웹 링크를 열어 Edge가 실행되는지 확인합니다.

Microsoft는 Windows 11과 Windows 10의 설정 경로를 구분해 안내합니다. Windows 10에서는 기본 앱의 '웹 브라우저' 항목에서 현재 브라우저를 선택하는 방식이 사용됩니다. Windows 11 사용자라면 앱 목록에서 Edge 또는 Chrome을 선택하는 경로가 더 직접적입니다.

공식 출처: Microsoft — 새 Microsoft Edge로 업데이트 및 기본 브라우저 설정

5. Chrome을 기본으로 했는데 링크가 Edge로 열리는 이유

모든 링크가 운영체제의 기본 브라우저 설정만 따르는 것은 아닙니다.

주요 가능성은 세 가지입니다.

  1. Chrome을 기본 앱으로 지정하는 절차가 완료되지 않았습니다.
  2. 링크를 누른 Outlook·Teams 같은 앱에 별도의 링크 열기 설정이 있습니다.
  3. 조직에서 관리하는 컴퓨터이거나, Windows의 특정 기능·제한 환경이 일반적인 링크 연결과 다르게 동작합니다.

문제 원인을 빠르게 구분하려면 테스트를 두 번 해보세요.

  • 테스트 A: 메모장이나 일반 문서에 적힌 웹 주소를 클릭해 기본 브라우저로 열리는지 확인합니다.
  • 테스트 B: 문제가 발생한 앱의 웹 링크를 눌러 결과를 비교합니다.

A는 Chrome으로 열리는데 B만 Edge로 열린다면 Windows 기본 설정을 반복 변경하기보다 문제 앱의 링크 열기 옵션을 먼저 확인하는 편이 합리적입니다.

특히 Outlook·Teams 관련 동작은 Microsoft가 별도의 공식 지원 문서로 설명합니다.

공식 출처: Microsoft — Outlook 및 Teams의 웹 링크가 Edge에서 열리는 경우

6. Outlook에서 누른 링크만 Edge로 열릴 때

Microsoft는 Windows용 Outlook의 웹 링크를 Edge에서 열도록 하는 기능을 제공하며, 이 기능은 Windows 기본 브라우저 자체를 변경하지 않는다고 안내합니다.

원하지 않는 경우 Outlook의 설정에서 링크를 열 브라우저를 변경할 수 있습니다.

새 Outlook for Windows

  1. 새 Outlook을 실행합니다.
  2. 설정 → 일반 → 파일 및 링크를 엽니다.
  3. Outlook의 하이퍼링크를 열 브라우저와 같은 항목을 찾습니다.
  4. Windows 기본 브라우저를 사용하는 옵션 또는 원하는 브라우저를 선택합니다.
  5. Outlook 메시지의 웹 링크를 다시 눌러 확인합니다.

클래식 Outlook for Windows

  1. Outlook을 엽니다.
  2. 파일 → 옵션 → 고급으로 이동합니다.
  3. 파일 및 브라우저 기본 설정 항목을 찾습니다.
  4. Outlook에서 하이퍼링크 열기에 사용할 브라우저를 선택합니다.
  5. 설정 후 링크를 다시 시험합니다.

Microsoft는 Outlook에서 이 링크 열기 설정을 변경하면 관련 Teams 동작에도 반영될 수 있다고 안내합니다. 회사에서 Outlook·Teams를 함께 사용한다면 두 앱 모두 검증하는 것이 좋습니다.

주의: 실제 메뉴 이름은 Outlook 버전과 회사 정책에 따라 다를 수 있습니다. 특정 메뉴가 보이지 않는다면 사용하는 프로그램이 새 Outlook인지 클래식 Outlook인지 먼저 확인하세요.

공식 출처: Microsoft — Outlook 전자 메일 및 Teams 채팅의 웹 링크가 Microsoft Edge에서 열림

7. Microsoft Teams 채팅 링크만 Edge로 열리는 경우

Teams 데스크톱 앱도 링크 열기 기본 설정을 별도로 제공할 수 있습니다.

Microsoft가 안내하는 확인 경로는 다음과 같습니다.

  1. Windows용 Microsoft Teams 데스크톱 앱을 엽니다.
  2. 오른쪽 위 설정 또는 프로필 관련 메뉴를 엽니다.
  3. 파일 및 링크 항목을 찾습니다.
  4. 링크 열기 기본 설정을 확인합니다.
  5. Windows 기본 브라우저를 사용하도록 변경할 수 있다면 해당 옵션을 선택합니다.
  6. 채팅의 일반 웹 링크를 눌러 Chrome에서 열리는지 확인합니다.

중요: Teams 안에서 Word·Excel·PowerPoint 파일 링크를 열 때의 선택지(Teams 안에서 열기·데스크톱 앱·브라우저)와 일반 웹 링크를 어느 브라우저로 열지는 서로 다른 설정일 수 있습니다.

예를 들어 Teams 대화에 포함된 외부 뉴스 사이트 링크를 Chrome으로 여는 문제와, Teams에서 받은 Excel 문서를 데스크톱 Excel로 여는 문제는 같은 설정으로 해결되지 않을 수 있습니다.

8. 웹 링크는 Chrome으로 열리는데 PDF는 Edge로 열릴 때

이는 기본 브라우저 변경이 실패했다는 뜻이 아닐 수 있습니다.

웹 주소를 클릭했을 때 사용하는 브라우저와 PC에 저장된 PDF 파일을 더블클릭했을 때 사용하는 앱은 Windows에서 따로 연결할 수 있습니다.

PDF 기본 앱 변경

  1. 설정 → 앱 → 기본 앱을 엽니다.
  2. 파일 확장명 검색창에서 .pdf를 입력합니다.
  3. 현재 PDF에 연결된 앱을 확인합니다.
  4. 목록에서 원하는 PDF 뷰어 또는 브라우저를 선택합니다.
  5. 파일 탐색기에서 로컬 PDF 파일을 더블클릭해 결과를 확인합니다.

주의: 웹사이트 안에서 PDF 링크를 눌렀을 때 브라우저 내부의 PDF 뷰어로 열리는 동작은 로컬 PDF 파일의 기본 앱 연결과 다를 수 있습니다. Chrome 안에 표시되는 PDF와 바탕화면에 저장된 PDF 파일을 각각 구분해서 확인하세요.

파일 형식 확장명인 .pdf의 연결을 수정하는 일은 일반 웹 링크의 기본 브라우저를 변경하는 것과 목적이 다릅니다.

9. HTTP·HTTPS 링크 유형을 따로 확인해야 하나요?

Windows의 기본 앱 설정은 브라우저별 기본값뿐 아니라 파일 형식과 링크 유형(프로토콜) 별 연결도 관리할 수 있습니다.

일부 링크만 다른 프로그램에서 열릴 때는 브라우저의 앱별 기본 설정 목록을 확인하면 도움이 됩니다.

  1. 설정 → 앱 → 기본 앱 → Google Chrome을 엽니다.
  2. 상단의 기본값 설정이 완료돼 있는지 확인합니다.
  3. 아래쪽에서 웹 주소와 관련된 링크 유형을 점검합니다.
  4. HTTP·HTTPS와 같은 일반 웹 링크가 기대한 브라우저에 연결돼 있는지 확인합니다.
  5. 일반 링크를 다시 테스트합니다.

Google 공식 도움말도 Chrome을 기본 브라우저로 지정한 후 '기본 파일 형식 또는 링크 유형 설정' 목록을 검토하라고 안내합니다.

주의: 링크 유형을 일일이 수정한다고 해서 Outlook이나 Teams처럼 앱 자체가 브라우저를 선택하는 예외가 모두 없어지는 것은 아닙니다.

10. Windows 11 S 모드에서는 제한이 있습니다

Microsoft는 Windows 11의 S 모드에서 Edge가 기본 웹 브라우저로 사용되는 제한을 공식 문서에서 안내합니다.

S 모드에서는 일반적인 Windows 11과 앱 설치·기본 브라우저 선택 방식이 다를 수 있습니다. Chrome이 기본값으로 설정되지 않는다면 먼저 사용 중인 컴퓨터가 S 모드인지 확인해 보세요.

중요: Microsoft는 S 모드를 해제하면 일반 모드로 돌아오는 대신 다시 S 모드로 되돌릴 수 없다고 안내합니다. 단지 브라우저를 바꾸기 위해 충분히 검토하지 않은 상태에서 S 모드를 해제하는 것은 권장하지 않습니다.

이 제한은 S 모드에서 발생할 수 있는 특수한 사례입니다. 대부분의 일반 Windows 11 PC에는 바로 적용되는 문제가 아닙니다.

11. 회사·학교 컴퓨터에서 기본 브라우저 설정을 바꿀 수 없다면

회사·학교에서 관리하는 PC에서는 조직의 보안 정책이나 관리 설정이 적용될 수 있습니다.

다음과 같은 상황이라면 개인 PC의 해결법을 그대로 적용하기 어려울 수 있습니다.

  • 기본 앱 설정이 회색으로 표시되거나 변경을 저장할 수 없습니다.
  • Chrome 설치가 허용되지 않습니다.
  • 설정을 변경해도 회사 표준 앱으로 돌아갑니다.
  • Outlook·Teams 관련 링크 열기 옵션이 표시되지 않거나 조직에서 관리됩니다.

처리 순서

  1. Windows 설정에서 현재 기본 브라우저와 Chrome 설치 여부를 확인합니다.
  2. 개인 PC에서 같은 문제를 재현하는지 확인합니다.
  3. 회사 PC라면 관리 앱·조직 계정 정책 여부를 확인합니다.
  4. 조직 관리 정책이 의심되면 IT 담당자에게 변경 가능 여부를 문의합니다.

관리자가 적용한 정책을 우회하기 위해 레지스트리나 시스템 파일을 무작정 수정하는 것은 운영·보안 문제를 만들 수 있습니다. 정상적으로 허용된 설정 경로부터 확인하세요.

13. Chrome으로 바꾸면 북마크와 비밀번호도 자동으로 옮겨지나요?

기본 브라우저 지정과 브라우저 데이터 가져오기는 다른 작업입니다.

Windows에서 Chrome을 기본 앱으로 지정한다고 해서 Edge에 저장한 북마크·즐겨찾기·암호·방문 기록이 자동으로 모두 Chrome에 복사되는 것은 아닙니다.

  • 기본 브라우저 변경: 링크를 어떤 프로그램으로 열지 결정합니다.
  • 즐겨찾기 가져오기: 기존 브라우저의 북마크를 새 브라우저로 이동합니다.
  • 비밀번호 이전: 각 브라우저의 비밀번호 관리자 및 계정 동기화 설정에 영향을 받습니다.
  • 로그인 유지: 사이트별 쿠키·세션에 따라 달라집니다.

따라서 기본 브라우저를 바꿨는데 기존 사이트에서 로그인이 풀려 보인다면 새 브라우저에 해당 웹사이트의 쿠키·로그인 정보가 없는 상황일 수 있습니다.

보안 주의: 비밀번호를 CSV로 내보내 이동하는 방식은 민감한 계정 정보가 평문 파일로 저장될 수 있습니다. 회사 PC나 공용 컴퓨터에서는 승인된 비밀번호 이전 방식과 보안 정책을 확인하세요.

14. Windows 10과 Windows 11의 메뉴가 다른 이유

구형 블로그 글에는 설정 → 앱 → 기본 앱 → 웹 브라우저에서 현재 브라우저를 선택하라고 나올 수 있습니다. 이는 Windows 10 기준으로 작성된 안내일 수 있습니다.

운영체제일반적인 공식 설정 경로
Windows 11설정 → 앱 → 기본 앱 → Chrome 또는 Edge 선택 → 기본값 설정
Windows 10설정 → 앱 → 기본 앱 → 웹 브라우저 → 원하는 브라우저 선택

Microsoft와 Google 모두 Windows 버전에 따른 차이를 공식 문서에 명시합니다. 현재 Windows 11을 쓰고 있다면 Windows 10의 메뉴 구조를 찾느라 시간을 쓰지 않아도 됩니다.

15. 자주 묻는 질문

Q. 윈도우11에서 크롬을 기본 브라우저로 설정하려면 어디에 들어가나요?

설정 → 앱 → 기본 앱 → Google Chrome → 기본값 설정 순서로 진행합니다.

Q. 기본 브라우저를 Chrome으로 변경했는데 Edge가 열립니다.

먼저 일반 웹 링크에서도 같은 문제가 발생하는지 확인하세요. Outlook·Teams에서만 발생한다면 해당 앱의 파일 및 링크·브라우저 열기 설정을 확인합니다.

Q. Outlook 메일 링크를 클릭하면 왜 Edge가 열리나요?

Microsoft는 Windows용 Outlook 및 Teams에서 웹 링크를 Edge로 열도록 하는 옵션을 제공합니다. 이 설정은 Windows의 기본 브라우저 자체를 변경하지 않으며 앱 내부에서 원하는 브라우저로 바꿀 수 있습니다.

Q. PDF가 Edge로 열리면 Chrome 기본 설정이 잘못된 건가요?

반드시 그렇지는 않습니다. 로컬 PDF 파일은 .pdf 파일 형식의 기본 앱 연결을 따로 설정할 수 있습니다.

Q. Chrome을 기본으로 정하면 Edge를 제거해야 하나요?

아닙니다. 기본 브라우저를 바꾸는 것은 프로그램 제거가 아닙니다. Edge가 설치돼 있어도 일반 웹 링크의 기본값을 Chrome으로 지정할 수 있습니다.

Q. Chrome을 기본으로 바꾸면 즐겨찾기와 비밀번호도 자동으로 옮겨지나요?

아닙니다. 브라우저 선택 설정과 데이터 이전은 별도의 작업입니다. 필요하면 각 브라우저의 공식 가져오기 기능을 사용하고 중요한 로그인 정보를 검증하세요.

Q. Windows 11 S 모드에서도 Chrome을 기본으로 설정할 수 있나요?

Microsoft의 S 모드 FAQ에서는 S 모드에서 Edge가 기본 브라우저로 고정되는 제한을 안내합니다. S 모드 해제는 되돌릴 수 없으므로 신중하게 검토해야 합니다.

Q. Teams의 Office 파일 링크가 브라우저가 아니라 Teams 앱에서 열립니다.

Teams에는 Office 문서 링크를 Teams 내부·데스크톱 앱·브라우저 중 어디서 열지 정하는 별도 설정이 있을 수 있습니다. 일반 웹 링크의 기본 브라우저와는 구분해야 합니다.

16. 최종 체크리스트

  • ☐ Chrome이 정상 설치되어 있다.
  • ☐ Windows 설정 → 앱 → 기본 앱에서 Chrome을 기본값으로 지정했다.
  • ☐ 파일 형식·링크 유형의 웹 연결이 적절한지 확인했다.
  • ☐ 일반 웹 링크를 클릭해 Chrome이 열리는지 시험했다.
  • ☐ Outlook에서만 Edge가 열리는 경우 Outlook 링크 열기 설정을 확인했다.
  • ☐ Teams에서만 Edge가 열리는 경우 Teams 링크 열기 설정을 확인했다.
  • ☐ PDF 파일 연결과 웹 브라우저 기본값을 혼동하지 않았다.
  • ☐ 조직 관리 PC 또는 S 모드 기기의 제한을 확인했다.

결론: Windows 11의 기본 브라우저 변경은 설정 → 앱 → 기본 앱 → Chrome → 기본값 설정이 출발점입니다. 하지만 Outlook·Teams와 일부 특수한 Windows 환경에서는 자체 연결 규칙이 있을 수 있으므로, 기본 브라우저 설정을 반복 변경하기보다 어떤 앱에서 링크를 열었는지를 기준으로 문제를 구분하는 것이 효율적입니다.
