엑셀에 상품 사진을 붙여넣었는데 셀 위에 그림이 떠 있고, 표를 정렬하면 상품명과 사진이 따로 움직이는 경우가 있습니다. 사진 100장을 상품번호 옆에 일일이 맞춰 넣기도 번거롭습니다.

가장 간단한 해결책은 Excel의 ‘셀에 배치(Place in Cell)’ 기능입니다. Microsoft 365용 Excel 또는 Excel 2024에서는 삽입 → 그림 → 셀에 배치 → 이 장치를 선택해 사진을 실제 셀 안에 넣을 수 있습니다. 이미 삽입한 떠 있는 그림도 ‘셀에 배치’로 바꿀 수 있습니다. 이미지를 웹 주소에서 불러온다면 IMAGE 함수를 사용할 수 있습니다.

다만 여러 사진을 한 번에 넣으면 활성 셀부터 아래쪽으로 차례대로 들어가며 기존 셀 값을 덮어쓸 수 있으므로, 반드시 빈 열이나 복사본에서 시작하세요.

작성·검증 기준일: 2026년 11월 4일. Microsoft의 Excel 공식 사용 설명서를 검토했습니다. 메뉴 이름은 언어, Excel 버전, 업데이트 채널에 따라 달라질 수 있습니다.

2. 엑셀 2026 사진을 셀에 넣는 기본 방법

Microsoft가 안내하는 새 기능의 공식 경로입니다.

  1. Excel 통합 문서를 엽니다.
  2. 사진을 넣을 빈 셀을 선택합니다.
  3. 상단 메뉴의 삽입 탭을 클릭합니다.
  4. 일러스트레이션 → 그림 → 셀에 배치를 선택합니다.
  5. 이 장치를 선택해 PC에 저장된 사진을 찾습니다.
  6. 원하는 JPG·PNG 등 이미지 파일을 선택하고 삽입합니다.
  7. 셀 안에 사진이 들어왔는지 확인합니다.
  8. 행 높이와 열 너비를 조절해 사진이 보기 좋게 표시되는지 점검합니다.

Excel의 메뉴가 조금 다르다면 ‘그림(Pictures)’ 메뉴에서 ‘셀에 배치(Place in Cell)’를 찾아보세요. Microsoft 지원 문서가 이 기능의 적용 대상을 Microsoft 365용 Excel, Excel 2024로 안내합니다.

지원하는 이미지 형식은?

Microsoft는 셀에 그림을 직접 삽입할 때 다음 형식을 지원한다고 안내합니다.

  • JPG/JPEG
  • PNG
  • BMP
  • ICO
  • WEBP
  • TIF/TIFF
  • GIF(애니메이션이 아닌 이미지)

GIF를 넣는다고 엑셀 셀에서 애니메이션이 반드시 재생되는 것은 아닙니다. 공식 문서는 비애니메이션 GIF를 지원 대상으로 설명합니다.

3. 엑셀 여러 사진 한 번에 셀에 넣기

상품 사진 50개를 하나씩 삽입할 필요는 없습니다. 여러 파일을 한 번에 선택하여 셀에 배치할 수 있습니다.

  1. 이미지가 들어갈 빈 열을 준비합니다.
  2. 그림 삽입을 시작할 첫 번째 빈 셀을 선택합니다.
  3. 삽입 → 그림 → 셀에 배치 → 이 장치로 이동합니다.
  4. 파일 선택 창에서 여러 사진을 선택합니다. 연속 파일은 Shift, 개별 파일은 Ctrl로 선택할 수 있습니다.
  5. 삽입을 선택합니다.
  6. 첫 번째 셀부터 아래 행으로 사진이 연속 삽입됐는지 확인합니다.
  7. 상품명·사진 파일명이 올바르게 매칭됐는지 실제로 대조합니다.

중요한 원본 보호 안내: Microsoft는 여러 사진을 삽입할 때 활성 셀부터 아래쪽으로 각 사진을 삽입하며, 이미 해당 셀에 값이 있다면 덮어쓴다고 명시합니다. 실수로 가격이나 재고 수량을 지우지 않도록 기존 데이터가 없는 열에서 작업하세요.

삽입 순서가 파일 이름순으로 보장되나요?

여러 이미지를 선택하는 방식과 파일 대화상자 설정에 따라 기대한 순서와 다르게 나타날 수 있습니다. 삽입한 사진이 상품번호 순서와 자동으로 일치한다고 가정하지 말고 첫 이미지·중간 이미지·마지막 이미지를 비교하세요.

파일 이름이 001.jpg, 002.jpg, 003.jpg처럼 정리돼 있으면 작업 검수가 쉬워집니다. 하지만 파일 이름 정리만으로 삽입 순서가 항상 보장되는 것은 아닙니다.

4. 그림이 셀 위에 떠 있을 때 ‘셀에 배치’로 바꾸기

기존 엑셀 파일을 보면 사진을 클릭했을 때 셀을 덮는 큰 그림으로 선택되는 경우가 있습니다. 이 그림은 셀 위에 배치된 그림(Picture over Cells)일 수 있습니다.

그림을 다시 저장하거나 전체 삭제하기 전에 전환 기능부터 확인하세요.

  1. 워크시트에서 떠 있는 그림 자체를 클릭합니다.
  2. 상단 그림 서식(Picture Format) 탭을 엽니다.
  3. 셀에 배치(Place in Cell)를 선택합니다.
  4. 사진이 원하는 셀에 들어갔는지 확인합니다.
  5. 필요하면 행 높이와 열 너비를 조절합니다.

또는 사진을 마우스 오른쪽 버튼으로 클릭 → 셀에 배치 메뉴를 사용할 수 있습니다.

Microsoft 공식 문서는 그림이 떠 있던 위치의 왼쪽 위 모서리가 걸쳐 있는 셀에 배치된다고 안내합니다. 따라서 사진이 여러 셀을 가로질렀다면 생각한 상품 행이 아니라 다른 셀에 들어갈 수 있습니다. 전환 후 반드시 행 위치를 검수하세요.

반대로 셀 안 사진을 다시 떠 있는 그림으로 바꾸려면?

셀 안의 그림을 마우스 오른쪽 버튼으로 클릭해 셀의 그림 → 셀 위에 배치(Place over Cells)를 선택할 수 있습니다. 표 전체를 장식하는 큰 이미지나 자유로운 크기 조절이 필요할 때 유용합니다.

5. 복사·붙여넣기만 하면 왜 사진이 셀 위에 뜰까?

스마트폰에서 복사한 사진이나 다른 웹페이지의 이미지를 Ctrl+V로 붙여넣으면 대개 셀 위에 떠 있는 그림으로 들어옵니다. 이를 두고 Excel에서 셀 안 그림 기능이 고장 났다고 생각하기 쉽습니다.

Microsoft 공식 도움말은 클립보드에 그림이 있을 때 기본 붙여넣기나 Ctrl+V는 셀 위에 붙여넣는다고 안내합니다.

원하는 셀에 정확하게 붙여넣는 방법

  1. 사진을 클립보드에 복사합니다.
  2. Excel에서 원하는 셀을 클릭합니다.
  3. 해당 셀을 마우스 오른쪽 버튼으로 클릭합니다.
  4. 붙여넣기 옵션 중 셀에 그림 붙여넣기(Paste Picture in Cell)를 선택합니다.
  5. 이미지가 셀 안에 들어갔는지 확인합니다.

구분: 단축키 Ctrl+V와 셀에 그림 붙여넣기는 동일한 기능이 아닙니다.

6. 사진을 넣었는데 정렬·필터하면 순서가 꼬일 때

이 문제는 제품 사진 관리표에서 특히 중요합니다.

예를 들어 다음 표가 있다고 가정하겠습니다.

A열B열C열
상품번호상품명상품사진
A001텀블러텀블러 사진
A002손전등손전등 사진
A003보온병보온병 사진

상품명 기준으로 정렬했을 때 사진이 다른 상품 옆으로 이동하면 사진이 셀 위에 떠 있거나 정렬 범위가 일부 열만 포함됐을 가능성이 있습니다.

해결 순서

  1. 원본 파일을 복사해 백업합니다.
  2. 문제의 사진을 클릭해 셀 안 그림인지 떠 있는 그림인지 확인합니다.
  3. 떠 있는 그림이라면 셀에 배치로 전환합니다.
  4. 상품번호·상품명·사진 열을 포함한 전체 표 범위를 선택합니다.
  5. 데이터 → 정렬에서 원하는 기준을 선택합니다.
  6. 정렬 후 상품번호와 사진이 일치하는지 3~5개 행을 검수합니다.

Microsoft는 셀 안 그림을 Excel 표에서 정렬·필터하고, 셀과 함께 이동·크기 조절할 수 있다고 설명합니다.

주의: 셀 안 사진이라는 사실만으로 잘못 지정한 정렬 범위를 해결할 수는 없습니다. 사진 열만 따로 정렬하거나 상품명 열만 독립적으로 정렬하면 표의 각 행이 어긋날 수 있습니다.

7. IMAGE 함수로 인터넷 이미지를 셀 안에 불러오기

PC에 파일이 없는 경우에는 IMAGE 함수가 편리할 수 있습니다. 이 함수는 인터넷 이미지 URL에서 이미지를 가져와 셀 안에 표시합니다.

Microsoft 공식 구문은 다음과 같습니다.

=IMAGE(source, [alt_text], [sizing], [height], [width])

쉽게 말하면 다음과 같습니다.

  • source: 이미지 주소. HTTPS URL이어야 합니다.
  • alt_text: 이미지를 설명하는 대체 텍스트.
  • sizing: 크기 조정 방식. 0·1·2·3 중 선택.
  • height, width: 크기 조정 방식 3을 사용할 때 지정하는 픽셀 크기.

기본 예제

이미지 주소가 들어 있는 A2 셀에서 이미지를 가져오려면 다음과 같이 입력합니다.

=IMAGE(A2)

이미지 주소와 설명 문구를 따로 관리하고 싶다면 다음 수식을 사용할 수 있습니다.

=IMAGE(A2,B2,0)

여기서 A2에는 직접 접근 가능한 HTTPS 이미지 주소, B2에는 ‘검정색 손전등 제품 사진’과 같은 설명을 넣습니다.

혼동 금지: =IMAGE("C:\사진\제품1.jpg")처럼 컴퓨터의 로컬 파일 경로를 넣는 방법은 공식 구문에서 요구하는 HTTPS URL 조건에 맞지 않습니다. PC에 저장된 사진이라면 ‘삽입 → 그림 → 셀에 배치’가 맞습니다.

8. IMAGE 함수 크기 옵션: 0·1·2·3의 차이

옵션의미권장 상황
0이미지 비율을 유지하며 셀에 맞춤상품 사진, 인물 사진 등 일반적인 목록
1셀을 가득 채우되 비율이 왜곡될 수 있음비율 변형을 감수하는 단순 썸네일
2원본 크기 유지, 셀 밖까지 넘칠 수 있음이미지 본래 크기가 중요한 경우
3지정한 높이·너비로 크기 설정크기를 직접 제어해야 하는 양식

예를 들어 다음 수식은 A2의 이미지 URL을 B2의 대체 텍스트와 함께 불러오고, 셀에 맞춰 표시합니다.

=IMAGE(A2,B2,0)

크기 옵션 3을 사용하면 픽셀 단위 크기를 지정할 수 있습니다.

=IMAGE(A2,B2,3,100,150)

위 예제는 높이 100픽셀, 너비 150픽셀을 지정합니다. 다만 원본 사진의 비율과 다르면 이미지가 늘어나 보일 수 있습니다.

주의: sizing이 0·1·2인데 height나 width를 같이 전달하는 등 잘못된 인수 조합은 #VALUE! 오류를 발생시킬 수 있습니다. Microsoft 공식 함수 설명에 따른 구문을 그대로 확인하세요.

9. IMAGE 함수 오류 해결: #BLOCKED!, #CONNECT!, #VALUE!

① #BLOCKED! 오류

원인: Excel의 보안 설정이 이미지 파일에 대한 접근을 차단하거나, IMAGE 함수에서 허용되지 않는 URL·이미지 크기를 사용한 경우 등이 있습니다.

확인 방법:

  • 이미지 URL이 반드시 https://로 시작하는지 확인합니다.
  • URL이 직접 이미지 파일을 반환하는지 확인합니다.
  • 회사·학교의 보안·연결된 콘텐츠 정책 때문에 차단되는지 확인합니다.
  • 웹 Excel이나 모바일 Excel에서는 통합 문서 상단의 이미지 활성화 안내가 표시되는지 확인합니다.
  • 신뢰할 수 있는 이미지 주소인지 먼저 검증합니다.

Microsoft는 외부 이미지·연결 데이터가 개인 정보와 보안에 영향을 줄 수 있으므로 기본적으로 차단될 수 있다고 설명합니다. 출처를 모르는데 차단 경고를 무조건 해제하지 마세요.

② #CONNECT! 오류

원인: 인터넷 연결 장애 또는 이미지 제공 서버 문제 등이 있습니다.

확인 방법:

  1. 브라우저에서 이미지 URL이 직접 열리는지 테스트합니다.
  2. 인터넷 연결을 확인합니다.
  3. 해당 이미지 서버가 정상 작동하는지 확인합니다.
  4. 잠시 후 Excel에서 다시 계산·새로고침이 되는지 확인합니다.

참고: 이미지 URL이 로그인해야만 접근 가능하면 함수가 이미지를 표시하지 못할 수 있습니다. 브라우저에서 본인 계정으로는 열려도 Excel에서는 인증할 수 없는 상황이 있습니다.

③ #VALUE! 오류

원인: 올바르지 않은 함수 인수, 지원하지 않는 이미지 형식, 숫자가 들어가야 할 옵션에 다른 타입의 값 전달 등이 있습니다.

확인 방법:

  • =IMAGE(A2)처럼 가장 단순한 구문으로 테스트합니다.
  • 이미지 주소가 문자열인지 확인합니다.
  • 크기 옵션이 0~3 범위인지 확인합니다.
  • 크기 옵션 3에서 높이·너비 인수가 올바른지 점검합니다.
  • 지원 이미지 형식인지 Microsoft 문서에서 재확인합니다.

리디렉션 URL은 왜 안 되나요?

Microsoft는 리디렉션되는 이미지 URL이 보안 문제로 차단될 수 있다고 안내합니다. 일부 단축 URL이나 이미지 제공 서비스의 링크를 그대로 쓰면 작동하지 않을 수 있습니다.

따라서 상품 상세페이지 주소나 검색결과 페이지 주소가 아니라 접근 가능한 실제 이미지 파일 URL을 확인해야 합니다. 저작권과 접근권한도 함께 점검하세요.

10. 사진이 너무 작거나 잘려 보일 때

셀에 그림을 배치했는데 제품 형상이 잘 안 보이는 경우가 있습니다.

  1. 해당 열의 열 너비를 충분히 키웁니다.
  2. 이미지가 들어 있는 행의 행 높이를 조절합니다.
  3. IMAGE 함수를 사용했다면 크기 옵션 0으로 비율이 유지되는지 확인합니다.
  4. 사진 파일 자체가 저해상도인지 점검합니다.
  5. 인쇄 용도라면 프린터 미리보기에서도 사진이 충분히 선명한지 확인합니다.

사진을 억지로 가로세로 늘리면 제품의 비율이 왜곡될 수 있습니다. 재고 사진·부품 사진 등 정확한 형상이 중요하다면 원본 비율 유지 옵션을 우선 고려하세요.

11. 사진 파일을 여러 개 넣다가 기존 데이터가 사라졌을 때

Excel 공식 문서에서 특히 강조할 만한 위험입니다.

여러 사진을 셀에 배치하는 기능은 선택한 시작 셀 아래로 그림을 삽입하면서 그 셀에 있던 값을 덮어쓸 수 있습니다.

실수 직후라면 우선 다음을 확인하세요.

  1. 다른 작업을 더 하기 전에 실행 취소(Ctrl+Z)가 가능한지 확인합니다.
  2. Excel 파일의 이전 버전이나 OneDrive·SharePoint의 버전 기록이 있는지 확인합니다.
  3. 원본 복사본이 있다면 변경 전 데이터와 비교합니다.
  4. 복구가 끝나면 사진용 열을 빈 상태로 만들어 다시 시도합니다.

실행 취소나 버전 기록이 항상 제공되는 것은 아닙니다. 중요한 표는 반드시 사본에서 시험한 뒤 실제 원본에 적용하세요.

12. Excel 웹 버전에서도 사진을 셀 안에 넣을 수 있나요?

Microsoft는 웹용 Excel에서 삽입 → 그림 → 셀에 배치 또는 셀 위에 배치를 선택할 수 있다고 안내합니다.

기본 절차는 다음과 같습니다.

  1. 브라우저에서 Excel 파일을 엽니다.
  2. 보기 전용이라면 브라우저에서 편집으로 바꿉니다.
  3. 원하는 셀을 선택합니다.
  4. 삽입 → 그림 → 셀에 배치 → 이 장치를 선택합니다.
  5. 이미지 파일을 선택해 삽입합니다.
  6. 셀과 함께 정렬·이동되는지 간단한 표에서 테스트합니다.

파일 권한이나 회사 계정 관리 설정에 따라 편집 메뉴가 제한될 수 있습니다.

13. 셀 안 그림과 ‘그림에서 데이터’는 전혀 다른 기능

Excel에는 이름이 비슷해서 혼동하기 쉬운 기능이 있습니다.

  • 셀에 그림 배치: JPG·PNG 등 사진을 셀에 표시하는 기능.
  • IMAGE 함수: HTTPS 이미지 주소를 수식으로 불러와 셀에 표시하는 기능.
  • 그림에서 데이터(Data from Picture): 표가 찍힌 사진에서 텍스트·숫자 등의 표 데이터를 인식해 셀 데이터로 변환하는 기능.

예를 들어 거래명세서 사진 속 금액을 엑셀 숫자 표로 바꾸려면 ‘그림에서 데이터’를 검토해야 합니다. 반대로 제품 사진을 재고 표에 붙이는 목적이라면 ‘셀에 그림 배치’가 적합합니다.

Microsoft의 ‘그림에서 데이터’ 기능에는 지원 문자 집합 제한도 있으므로, 한국어 표 이미지를 정확히 변환할 수 있다고 단정하면 안 됩니다. 자동 변환 이후에는 원본과 대조해야 합니다.

13-1. 팀에서 사진이 들어 있는 엑셀 파일을 공유할 때 점검할 사항

사진이 들어 있는 상품 목록이나 인사 관리표를 다른 사람에게 전달할 때에는 파일을 보내기 전에 별도 복사본으로 검증하세요.

  1. 사진이 셀 안에 배치되었는지 확인하고 상품 코드와 사진이 같은 행에서 함께 움직이는지 정렬·필터 테스트를 합니다.
  2. 웹 이미지가 보이는 IMAGE 함수는 외부 URL 접근과 보안 정책의 영향을 받을 수 있으므로 수신자의 PC에서도 제대로 표시되는지 확인합니다.
  3. 여러 사진을 일괄 삽입한 뒤 기존의 상품번호·수식·가격 데이터가 덮어써지지 않았는지 검토합니다.
  4. 외부 이미지 링크가 유효하지 않거나 사이트에서 차단하면 #BLOCKED!·#CONNECT! 등의 오류가 발생할 수 있으므로 파일을 오프라인에서도 써야 한다면 실제로 포함된 이미지와 외부 URL 함수의 차이를 확인합니다.
  5. 인쇄와 PDF 저장까지 필요하다면 마지막 열의 잘림, 행 높이, 확대·축소 비율을 확인합니다.

14. 자주 묻는 질문

Q1. 엑셀 사진을 셀 안에 정확히 고정하려면?

Microsoft 365 Excel 또는 Excel 2024에서 삽입 → 그림 → 셀에 배치를 사용하세요. 이미 떠 있는 그림이라면 그림 서식 → 셀에 배치로 전환할 수 있습니다.

Q2. Ctrl+V로 붙여넣으면 왜 셀 밖으로 사진이 튀어나오나요?

Microsoft 설명에 따르면 일반적인 Ctrl+V는 셀 위에 그림을 붙여넣는 방식입니다. 셀 안으로 넣으려면 오른쪽 클릭 메뉴의 셀에 그림 붙여넣기를 선택합니다.

Q3. 엑셀 사진 100개를 한 번에 넣을 수 있나요?

여러 파일을 한 번에 선택해 셀에 배치할 수 있습니다. 다만 활성 셀 아래로 삽입되며 기존 데이터가 덮어써질 수 있으므로 빈 열과 백업 복사본을 먼저 준비하세요.

Q4. 엑셀 2021에서는 ‘셀에 배치’ 메뉴가 없는데 정상인가요?

Microsoft의 해당 ‘셀에 배치’ 공식 문서는 적용 대상으로 Microsoft 365 Excel 및 Excel 2024를 제시합니다. Excel 2021에서 동일한 메뉴를 전제하지 마세요. 현재 버전과 사용 가능한 기능을 확인해야 합니다.

Q5. 정렬·필터할 때 사진이 상품명과 같이 움직이게 하려면?

사진을 셀 안에 배치하고 상품명·상품번호·사진을 포함한 전체 표 범위를 함께 정렬해야 합니다. 사진 열만 별도 정렬하면 매칭이 어긋날 수 있습니다.

Q6. IMAGE 함수에서 컴퓨터 사진 경로를 쓸 수 있나요?

공식 IMAGE 함수의 source 인수는 HTTPS 이미지 URL을 요구합니다. C:\사진\sample.jpg 같은 로컬 경로는 이 조건에 맞지 않습니다.

Q7. 이미지 주소는 열리는데 #BLOCKED!가 뜹니다.

HTTPS 여부, 인증이 필요한 URL인지, 리디렉션 주소인지, Excel 보안 정책이 외부 이미지를 차단하는지 확인하세요. 보안 경고는 이미지 출처를 신뢰할 수 있는 경우에만 검토합니다.

Q8. 사진 100장을 상품코드와 정확하게 자동 매칭해 주나요?

여러 사진을 일괄 삽입할 수 있지만 파일 이름을 분석해 상품코드와 자동으로 1:1 매칭해 준다는 뜻은 아닙니다. 삽입 후 실제 제품 사진과 행 정보를 확인해야 합니다.

Q9. 셀에 넣은 그림을 다시 일반 그림으로 빼낼 수 있나요?

네. Microsoft는 셀 안 그림에서 셀 위에 배치로 되돌리는 메뉴를 공식 지원합니다. 셀 안 이미지를 오른쪽 클릭해 전환 항목을 확인하세요.

15. 작업 전 마지막 체크리스트

  • ☐ Excel 버전이 Microsoft 365 또는 Excel 2024 등 관련 기능 지원 대상인지 확인했다.
  • ☐ 상품번호와 사진 열을 포함해 원본 파일을 백업했다.
  • ☐ 사진을 삽입할 빈 열과 시작 셀을 정했다.
  • ☐ 여러 사진을 일괄 삽입할 때 기존 값 덮어쓰기 위험을 확인했다.
  • ☐ 정렬 범위에 상품번호·상품명·사진을 모두 포함했다.
  • ☐ IMAGE 함수 사용 시 HTTPS·인증·리디렉션 조건을 확인했다.
  • ☐ #VALUE!, #BLOCKED!, #CONNECT! 오류 원인을 구분했다.
  • ☐ 인쇄 미리보기와 다른 사용자 환경에서도 사진 표시를 점검했다.

결론

엑셀에서 사진이 셀 위에 떠 있는 문제는 ‘셀에 배치’ 기능으로 해결할 수 있는 경우가 많습니다. 사진 파일은 삽입 → 그림 → 셀에 배치, 이미 떠 있는 사진은 그림 서식 → 셀에 배치, 인터넷 이미지 주소는 IMAGE 함수로 구분하면 됩니다.

상품 사진 목록이나 재고 관리표처럼 정렬·필터가 중요한 경우에는 사진을 셀 데이터와 함께 관리하고, 사진 여러 개를 한 번에 넣기 전에 원본을 백업하는 것이 가장 중요합니다.
