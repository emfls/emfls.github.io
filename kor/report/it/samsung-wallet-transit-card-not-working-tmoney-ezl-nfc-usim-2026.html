삼성월렛에 신용카드를 등록해 놓고 버스에서 스마트폰을 찍었는데 “사용할 수 없는 카드”가 나오거나, 교통카드 추가 메뉴에서 후불카드를 선택해도 등록이 실패하는 사례가 있습니다. 겉으로는 모두 ‘교통카드가 안 된다’는 문제처럼 보이지만 원인은 다릅니다. 교통카드 발급 여부 → 잔액·한도 → NFC 설정 → 다른 앱 충돌 → USIM·앱 저장 방식 순서로 확인하면 불필요한 삭제·초기화를 피할 수 있습니다.

이 글은 2026년 11월 3일 기준 삼성전자 한국 공식 서비스 가이드와 삼성월렛 담당자의 공개 답변을 토대로 작성했습니다. 지원 카드와 화면 명칭은 단말기, One UI 버전, 통신사, 교통사업자 정책에 따라 달라질 수 있습니다.

1. 증상부터 구분하는 1분 진단표

현재 증상먼저 확인할 곳우선 점검 사항
교통카드 추가 단계에서 실패삼성월렛 → 전체 → 교통카드 추가티머니·이즐, 선불/후불, 지원 카드·저장 방식
카드 결제는 되는데 버스 태그가 안 됨삼성월렛 → 전체 → 교통카드결제용 카드와 모바일 교통카드 발급은 별개
“사용할 수 없는 카드” 메시지등록된 교통카드 상세 화면선불 잔액·후불 한도·연결 카드 상태
단말기에 아무 반응이 없음설정 → 연결 → NFC 및 비접촉 결제NFC 활성화·기본 월렛·다른 NFC 서비스
업데이트 후 버스에서만 오류NFC·기타 NFC 서비스 메뉴다른 교통카드 앱 충돌·태그 위치
USIM 교체 후 등록 안 됨교통카드 발급 시 저장 방식USIM 저장과 앱 저장(HCE) 지원 조합
특정 K-패스 체크카드만 등록 안 됨카드 지원 목록해당 교통사업자·카드사 제휴 조건

주의: 선불 교통카드 잔액을 확인하지 않은 채 교통카드를 삭제하거나 휴대전화를 초기화하지 마세요. 잔액 이전·환불은 사용하는 교통사업자의 절차를 따라야 합니다.

2. 삼성월렛에서 교통카드 새로 등록하는 방법

삼성전자 공식 안내에 따른 기본 경로는 다음과 같습니다.

  1. 삼성월렛 앱을 실행합니다.
  2. 전체 → 교통카드 추가를 누릅니다.
  3. 화면에 보이는 티머니 또는 이즐(캐시비) 등 교통카드 사업자를 선택합니다.
  4. 후불·선불·휴대폰 결제 중 지원되는 방식을 고릅니다.
  5. 결제수단을 선택하거나 필요한 카드 정보를 입력합니다.
  6. 약관 동의와 지문 등 본인 인증을 진행합니다.
  7. 전체 → 등록된 교통카드에서 카드가 정상 발급됐는지 확인합니다.

여기서 가장 많이 헷갈리는 지점은 삼성월렛에 일반 신용카드를 추가하는 것과 모바일 교통카드를 발급하는 절차가 다르다는 점입니다. 기존 결제카드가 삼성월렛에 있어도 교통카드 메뉴에 발급 내역이 없으면 먼저 교통카드 추가를 진행해야 합니다.

3. NFC를 켰는데 버스·지하철에서 인식이 안 되는 이유

등록된 교통카드가 보이고 잔액·한도가 정상인데도 안 찍히면 설정을 세 단계로 살펴봅니다.

① NFC 켜기와 카드 모드

화면 위에서 빠른 설정을 내리거나 설정 → 연결 → NFC 및 비접촉 결제에서 NFC를 켭니다. 삼성전자는 교통카드가 기본 모드와 카드 모드 모두에서 동작할 수 있지만 안정적인 사용을 위해 카드 모드를 권장합니다.

최근 One UI에서는 ‘NFC 태그 읽기/쓰기’ 옵션을 끄는 설정이 카드 모드에 해당하는 방식으로 안내되기도 합니다. NFC 전체 전원은 켜 둔 채 기기에 표시되는 메뉴대로 조정해야 합니다. ‘태그 읽기/쓰기 끔’을 ‘NFC 전체 끔’으로 혼동하지 마세요.

② 기본 월렛 앱 확인

설정 → 연결 → NFC 및 비접촉 결제 → 기본 월렛 앱에서 삼성월렛이 선택돼 있는지 확인합니다. 일부 버전에서는 ‘비접촉 결제 → 결제’ 탭에 표시됩니다.

③ 기타 NFC 서비스 충돌 확인

같은 휴대전화에서 신한플레이, 페이코, 카드사 앱 등 다른 교통카드 기능을 활성화하면 의도하지 않은 교통카드 서비스가 응답할 수 있습니다. 삼성월렛 담당자는 ‘기타 NFC 서비스’나 ‘비결제 NFC 서비스’ 메뉴에서 티머니 이용 시 티머니 매니저, 이즐 이용 시 교통카드를 확인하고 사용하지 않는 다른 서비스는 해제하도록 안내합니다.

먼저 이러한 설정을 점검하고, 해결되지 않을 때 다음 단계로 넘어가세요. 이 단계에서 교통카드 자체를 삭제할 필요는 없습니다.

4. “사용할 수 없는 카드”가 뜨면 잔액·한도부터 확인

이 오류는 NFC 인식뿐 아니라 결제수단 상태와도 관련될 수 있습니다. 삼성월렛에서 전체 → 등록된 교통카드 → 해당 카드를 열고 다음 항목을 확인합니다.

  • 선불: 잔액 부족, 충전 실패, 충전수단 사용 가능 여부
  • 후불: 연결된 카드의 이용정지·분실신고·한도초과·장기 미사용 여부
  • 공통: 교통카드 상세 화면에 한도나 잔액, 충전수단 정보가 정상 표시되는지
  • 최근 변화: 카드 재발급·OS 업데이트·USIM 교체·기기변경이 있었는지

실물 신용카드에 후불교통 기능이 있다고 해서 삼성월렛의 모든 모바일 교통카드 방식에서 자동으로 호환된다고 보장되지는 않습니다. 연결 카드의 지원 여부는 실제 교통카드 발급 화면과 교통사업자 안내가 기준입니다.

5. USIM·eSIM 변경 후 등록이 안 될 때

삼성월렛 교통카드는 단말기·교통사업자에 따라 USIM에 정보를 저장하는 방식과 앱 저장 방식(HCE) 등을 사용할 수 있습니다. 기존 USIM 저장 교통카드가 새 휴대전화나 일반 USIM에서도 자동으로 살아난다고 가정하면 안 됩니다. 반대로 앱 저장 방식을 지원하는 경우도 있으므로 ‘일반 유심은 전부 불가’라고 단정하는 것도 정확하지 않습니다.

교체 직후라면 다음 순서를 따르세요.

  1. 이전 기기의 교통카드가 선불인지 후불인지 확인합니다.
  2. 선불 잔액이 있다면 삭제 전 이전·환불 절차를 교통사업자에 확인합니다.
  3. 새 기기에서 선택할 수 있는 교통카드 저장 방식을 확인합니다.
  4. 해당 방식에 연결 가능한 신용·체크카드인지 확인합니다.
  5. 지원이 확인됐을 때 새 교통카드를 발급합니다.

실제로 삼성월렛 담당자는 일반 USIM에서 이즐 앱 저장 방식으로 K-패스 카드를 사용하려는 경우 특정 카드와 결제 방식 조합은 지원되지 않을 수 있다고 설명했습니다. 특히 일부 K-패스 체크카드는 소액신용한도가 있더라도 해당 방식의 충전수단 등록이 불가능한 사례가 있습니다. USIM을 다시 구매하거나 카드를 재발급하기 전에 삼성월렛 앱 공지의 ‘교통카드 및 K-패스 서비스 FAQ’에서 최신 지원 목록을 확인하는 편이 안전합니다.

6. 선불·후불·체크카드 선택 전 비교표

방식편의성확인할 위험
선불미리 충전한 잔액에서 이용잔액 부족·충전 실패·삭제 전 잔액 환불
후불결제수단을 연결해 사용카드 정지·한도·제휴 미지원
체크카드 연동지원하는 경우 체크카드 사용 가능카드 자체의 후불교통 기능과 모바일 교통 충전 연동 지원은 다를 수 있음
앱 저장 방식(HCE)일부 조건에서 USIM 저장 대신 지원지원 사업자·카드·절전 설정 등이 방식별로 다름

지원 여부는 사용 중인 삼성월렛 앱의 선택 항목과 공지사항에서 확인해야 합니다. 일반적인 카드 발급 안내만 보고 모든 조합이 동일하다고 판단하지 마세요.

7. 특정 버스에서만 안 찍힌다면

설정과 결제수단이 정상이라면 태그 환경도 살펴볼 수 있습니다.

  1. 스마트폰 뒷면의 NFC 위치를 단말기에 가까이 맞춥니다.
  2. 두꺼운 케이스나 금속 부착물, 케이스 속 다른 실물카드를 잠시 분리합니다.
  3. 특정 버스 단말기만 실패하는지, 지하철 등 다른 단말기에서도 같은지 기록합니다.
  4. 앱 저장 방식 교통카드라면 절전 모드와 삼성월렛의 백그라운드 실행 제한 여부를 확인합니다.
  5. 사용 중인 교통서비스에 필요한 설정만 변경하며 다른 앱의 권한까지 일괄 해제하지 않습니다.

삼성월렛 담당자는 일부 앱 저장 방식에 대해 절전·백그라운드 제한을 추가 확인하도록 안내했습니다. 배터리 최적화를 무조건 전부 끄라는 뜻은 아니므로 지원되는 저장 방식과 담당자 안내를 기준으로 조정하세요.

8. 삭제·초기화보다 먼저 할 일

교통카드 삭제는 마지막 단계입니다. 특히 선불 잔액이 있거나 이전 휴대전화와 연결돼 있다면 단순 재등록으로 잔액이 이전되는지 확실하지 않습니다. 교통사업자의 잔액 환불·이전 조건을 확인한 뒤 실행하세요.

휴대전화 초기화도 바로 진행하지 마세요. 기본 월렛 선택, NFC 태그 읽기/쓰기 설정, 타 교통카드 서비스 비활성화만으로 확인 가능한 항목이 많습니다. 버스 탑승 직전에 오류를 시험하느라 이동을 지연시키는 대신 대체 결제수단을 준비하는 것이 좋습니다.

9. 해결되지 않으면 오류 로그 보내기

삼성월렛 담당자는 오류가 재현된 직후 삼성월렛 → 설정/문의하기 → 질문·오류 보내기 메뉴에서 시스템 로그 데이터 보내기를 선택해 제출하도록 안내합니다. 메뉴 명칭은 업데이트에 따라 달라질 수 있습니다.

제보에는 발생 시각, 오류 메시지, 교통수단(버스·지하철), 교통사업자(티머니·이즐), 기기·One UI 버전, 최근 변경 사항을 적으면 원인 파악에 도움이 됩니다. 결제한도나 선불 잔액 문제라면 사업자에 직접 문의하세요.

10. 자주 묻는 질문

Q. 삼성월렛에 신용카드만 있으면 버스도 탈 수 있나요?

모바일 교통카드 발급이 별도로 필요합니다. 전체 → 교통카드에 정상 발급된 내역이 있는지 먼저 확인하세요.

Q. 교통카드를 쓰려면 삼성월렛 앱을 매번 켜야 하나요?

삼성전자 안내에 따르면 지원되는 교통카드는 화면이 꺼진 상태에서도 태그할 수 있습니다. 다만 구체적인 지원 조건은 단말기와 저장 방식에 따라 다릅니다.

Q. NFC 기본 모드로도 쓸 수 있나요?

삼성전자는 기본·카드 모드 모두 가능하다고 안내하면서 안정적인 사용을 위해 카드 모드를 권장합니다. 기기의 설정 명칭에 맞춰 조정하세요.

Q. K-패스 체크카드는 모두 교통카드에 연결되나요?

아닙니다. 카드사와 저장 방식별 미지원 조합이 있습니다. 최신 삼성월렛 앱 공지와 티머니·이즐의 지원 안내를 확인하세요.

Q. 휴대전화를 바꿨다면 자동 이전되나요?

기존 USIM 저장 교통카드가 자동으로 이전된다고 전제해서는 안 됩니다. 변경 전 잔액·환불·재발급 조건부터 확인해야 합니다.

Q. 교통카드 소득공제는 어떻게 신청하나요?

삼성전자는 발급 과정 또는 삼성월렛 → 등록된 교통카드 → 소득공제 신청 메뉴에서 신청하도록 안내합니다. 신청 전 이용분은 소급 적용되지 않는다고 설명합니다.

11. 출근 전에 끝내는 7가지 점검

  • ☐ 삼성월렛 교통카드 메뉴에 티머니 또는 이즐 카드가 실제로 발급돼 있다.
  • ☐ 선불 잔액 또는 후불 카드 한도·상태가 정상이다.
  • ☐ NFC가 켜져 있고 카드 모드에 해당하는 설정을 확인했다.
  • ☐ 기본 월렛 앱 및 기타 NFC 서비스 선택을 확인했다.
  • ☐ 다른 교통카드 앱과 충돌하지 않는다.
  • ☐ 유심·기기 변경 후라면 지원 저장 방식과 카드 제휴를 확인했다.
  • ☐ 삭제 전에 선불 잔액의 이전·환불 조건을 확인했다.

등록 실패와 태그 실패는 원인도 해결 경로도 다릅니다. 카드 발급 상태부터 확인하고, 그다음 결제수단·NFC·교통카드 앱 충돌 순서로 점검하는 것이 가장 효율적인 출발점입니다.
