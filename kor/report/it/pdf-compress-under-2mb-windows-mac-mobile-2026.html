입사지원서, 주민센터 제출서류, 학교 과제, 이메일 첨부파일을 올리다가 "PDF 파일 용량이 너무 큽니다"라는 메시지가 뜨면 무엇을 줄여야 할까요? 단순히 파일 이름을 바꾸거나 ZIP으로 압축하는 것만으로는 PDF 자체의 업로드 용량 제한이 해결되지 않습니다.

PDF 파일 크기를 줄일 때 가장 중요한 것은 원본이 무엇으로 만들어졌는지입니다. 스캔한 서류는 사진 해상도와 이미지 압축이 핵심이고, Word·PowerPoint로 만든 PDF는 원본 문서의 이미지와 내보내기 설정을 조정하는 편이 좋습니다. 이미 만들어진 PDF만 있고 맥을 쓴다면 별도 프로그램 없이 미리보기에서 파일을 줄일 수 있습니다. Windows와 휴대전화에서는 신뢰할 수 있는 압축 도구가 필요할 수 있습니다.

이 글은 2026년 11월 3일 기준 Apple·Adobe·Microsoft의 공식 사용법을 바탕으로 맥 무료 압축, 윈도우11의 현실적인 방법, 모바일 브라우저, 2MB 이하 제출, 민감정보 보호, 화질·글자 깨짐 점검까지 안내합니다.

1. 30초 선택표: 어떤 방법이 가장 좋을까?

상황추천 방법비용·개인정보 확인
맥에서 기존 PDF 압축미리보기 → 파일 → 내보내기 → 파일 크기 줄이기맥 기본 앱, 로컬 처리
Windows에서 원본 Word·PowerPoint 파일 보유원본 이미지 조정 후 PDF 재저장, 최소 크기 옵션 확인Office 사용권 필요할 수 있음, 로컬 처리

주민등록번호·건강기록·계약서가 포함됨가급적 신뢰할 수 있는 오프라인 프로그램외부 업로드 최소화

핵심: Microsoft Print to PDF나 PDF 다시 저장만으로 무조건 용량이 줄어드는 것은 아닙니다. 압축 기능이 있는 도구 또는 원본 이미지 최적화를 이용해야 합니다.

2. 먼저 현재 PDF 파일 크기 확인하기

Windows 11에서는 파일 탐색기에서 PDF를 선택하고 마우스 오른쪽 → 속성 → 크기를 확인합니다. macOS에서는 Finder에서 파일을 선택하고 command+I(정보 가져오기)를 누르세요. 스마트폰에서는 파일 앱 또는 내 파일에서 정보·상세정보를 확인할 수 있습니다.

압축 전에 두 가지를 기록하면 품질을 비교하기 쉽습니다.

  • 원본 크기와 페이지 수: 예를 들어 8.7MB·12페이지
  • 문서 유형: 텍스트 중심, 이미지 중심, 사진 스캔, 도면·그림·서명이 포함된 파일 등

2MB 이하 제출이라면 목표치를 딱 2.00MB로 맞추기보다 약 1.8MB 정도로 여유를 두는 것을 권합니다. 운영체제와 업로드 사이트가 단위 표시·파일 검사 방식을 다르게 사용할 수 있기 때문입니다. 다만 압축 결과가 언제나 1.8MB 이하가 된다는 보장은 없습니다.

3. 맥에서 무료로 PDF 용량 줄이기: 미리보기 사용법

Apple은 macOS 기본 앱 미리보기(Preview)에서 PDF를 압축하는 공식 절차를 안내합니다.

  1. Finder에서 PDF를 더블클릭하거나 미리보기 앱으로 엽니다.
  2. 상단 메뉴에서 파일 → 내보내기(Export)를 선택합니다.
  3. 형식을 PDF로 확인하고 Quartz 필터 메뉴를 엽니다.
  4. 파일 크기 줄이기(Reduce File Size)를 선택합니다.
  5. 저장 위치와 원본과 다른 파일 이름을 지정합니다.
  6. 저장을 누르고 Finder에서 새 파일의 용량을 비교합니다.
  7. 저장된 PDF를 다시 열어 사진·한글 글자·서명·표가 정상인지 확인합니다.

Apple은 압축 후 품질이 낮아질 수 있고 파일 크기와 화질이 옵션에 따라 달라진다고 설명합니다. 스캔한 증명서의 작은 글자나 도장이 흐릿해졌다면 원본에서 다시 작업해야 합니다.

최신 미리보기 버전에서는 '화면용 이미지 최적화', 'JPEG로 이미지 저장', '선형화 PDF 만들기' 등의 옵션이 제공될 수 있습니다. 화면에 있는 옵션으로 하나씩 비교하되, '선형화'는 웹에서 빨리 열리도록 조정하는 기능으로 압축량을 보장하지 않습니다.

공식 출처: Apple 지원 — Mac 미리보기에서 PDF 크기 줄이기.

4. 윈도우11에서 PDF 용량 줄이기: 원본 문서가 있을 때

Windows 11에는 '모든 기존 PDF의 크기를 안정적으로 압축'해 주는 범용 기본 기능이 있다고 보기 어렵습니다. 특히 Microsoft Print to PDF로 다시 인쇄하면 파일이 비슷하거나 더 커질 수 있고 링크·양식 등 문서 기능이 바뀔 수 있습니다.

Word·Excel·PowerPoint 원본을 보유 중이라면, PDF만 계속 재압축하기보다 원본에서 다음 순서로 접근하는 것이 유리합니다.

  1. Word·Excel·PowerPoint 원본을 엽니다.
  2. 큰 사진·스캔 이미지를 확인하고 가능하면 원본 해상도·크기를 줄입니다.
  3. 파일 → 다른 이름으로 저장 또는 내보내기 → PDF를 선택합니다.
  4. 화면에 표준(인쇄 및 온라인 게시)과 최소 크기(온라인 게시)가 나타나면 제출 목적에 맞게 선택합니다.
  5. 새 파일 이름으로 저장하고 실제 용량을 비교합니다.
  6. 작은 글씨·표·한글·링크가 정상인지 확인합니다.

Microsoft는 일부 Office 데스크톱 앱에서 파일 크기가 인쇄 품질보다 중요할 때 '최소 크기' 옵션을 선택할 수 있다고 안내합니다. 다만 Office 버전과 앱에 따라 위치·제공 여부가 다릅니다.

주의: Microsoft Office는 사용 중인 제품·구독·버전에 따라 이용 비용이 발생할 수 있습니다. 무료라고 단정하면 안 됩니다.

공식 출처: Microsoft 지원 — Office 앱에서 PDF로 저장·변환.

5. 이미 만들어진 PDF만 있을 때: Adobe Acrobat 웹 압축

Adobe는 웹용 Acrobat에서 PDF를 압축하는 공식 기능을 제공합니다. 설치 없이 브라우저에서 작업할 수 있지만 인터넷으로 파일을 업로드하며 계정·무료 사용량 제한이 적용될 수 있습니다.

  1. 공식 Adobe Acrobat 웹사이트에 접속합니다.
  2. 로그인한 후 상단 변환(Convert) → PDF 압축(Compress a PDF)을 선택합니다.
  3. 압축할 PDF를 선택하고 계속(Continue)을 누릅니다.
  4. 압축 수준 높음·중간·낮음 중 하나를 선택합니다.
  5. 압축(Compress)을 선택합니다.
  6. 완료 알림에서 압축 파일을 다운로드합니다.
  7. 내려받은 파일의 용량과 내용을 확인합니다.

Adobe 공식 문서에 따르면 온라인에서 압축한 결과물은 Adobe 클라우드 스토리지에 자동 저장되며, 파일 이름에 _compressed가 붙습니다. 즉, 웹 서비스에 올린 파일이 기기 안에서만 처리된다고 생각하면 안 됩니다.

2026년 4월 Adobe 공식 안내에서 확인된 압축 파일 크기 상한은 2GB입니다. 다만 복잡한 파일은 제한 이내라도 변환 실패할 수 있고 계정별 저장 공간 제한도 별도로 적용됩니다.

공식 출처: Adobe — 웹에서 PDF 압축, Adobe 클라우드 파일 제한.

6. Adobe PDF 압축은 정말 무료인가요?

'온라인 무료 PDF 압축'이라는 검색 결과만 보고 횟수·로그인·저장 방식이 모두 무제한 무료라고 생각하면 안 됩니다.

Adobe의 공식 FAQ는 비로그인 사용자의 무료 체험 및 로그인한 무료 계정의 이용량 제한을 안내합니다. 예를 들어 로그인한 무료 사용자는 PDF 압축을 24시간 동안 1회 이용하는 제한이 설명되어 있습니다. 다른 무료 거래 한도와 로그인 상태에 따라 실제 화면의 안내가 달라질 수 있습니다.

따라서 압축할 파일이 여러 개라면 먼저 무료 사용량과 로그인 필요 여부를 확인하세요. 다수 파일을 매일 처리해야 하는 업무라면 유료 도구의 비용 또는 로컬 대안을 비교하는 것이 합리적입니다.

공식 FAQ: Adobe Acrobat 온라인 서비스 무료 사용 및 횟수 제한.

7. 아이폰·갤럭시에서 PDF 용량 줄이는 방법

휴대전화에서는 PDF 파일이 파일 앱·내 파일에 저장되어 있는지 먼저 확인합니다. 메신저 미리보기 화면에서 바로 압축하려 하면 파일이 선택되지 않을 수 있습니다.

아이폰

  1. 메일·메신저에서 받은 PDF를 파일 앱에 저장합니다.
  2. Safari에서 공식 Adobe Acrobat 웹 압축 페이지를 엽니다.
  3. 파일 선택을 눌러 저장된 PDF를 선택합니다.
  4. 압축을 실행하고 결과물을 파일 앱에 저장합니다.
  5. 파일 앱에서 크기를 확인하고 PDF를 열어 내용을 점검합니다.

갤럭시

  1. PDF를 내 파일의 다운로드 폴더 등 찾기 쉬운 곳에 저장합니다.
  2. Chrome 또는 삼성 인터넷에서 공식 Adobe Acrobat 웹 압축 기능을 엽니다.
  3. 파일 선택으로 PDF를 업로드합니다.
  4. 압축 수준을 정해 실행합니다.
  5. 다운로드한 PDF가 내 파일에 제대로 저장됐는지 확인합니다.

주의: 모바일 웹의 버튼 이름과 다운로드 위치는 브라우저·OS 버전·서비스 로그인 상태에 따라 달라질 수 있습니다. 웹 압축 시 파일은 외부 서비스로 업로드되므로 주민등록번호 등이 포함된 문서는 신중하게 다루세요.

8. PDF를 2MB 이하로 줄이는 실전 순서

제출처가 2MB 이하를 요구하면 압축을 무조건 세게 하기보다 읽을 수 있는 품질을 유지하며 목표를 충족해야 합니다.

  1. 제출처가 요구하는 정확한 용량·형식·페이지·서명 조건을 읽습니다.
  2. 원본 파일을 반드시 별도로 보관합니다.
  3. PDF가 스캔 이미지 중심인지, 텍스트 문서인지 구분합니다.
  4. 가능하면 중간 수준 압축으로 먼저 시도합니다.
  5. 크기를 확인하고 2MB가 초과되면 더 강한 압축이나 원본 이미지 최적화를 시도합니다.
  6. 목표는 약 1.8MB 안팎으로 여유를 둡니다.
  7. PDF 열기, 페이지 수, 작은 한글, 도장·서명, 검색·복사 가능 여부를 최종 검사합니다.
  8. 제출 사이트에 실제 업로드하여 파일 형식·용량 검사를 통과하는지 확인합니다.

예시: 8MB짜리 사진 스캔 PDF가 압축 뒤 2.6MB라면 한 번 더 압축하거나 스캔 원본에서 해상도·색상 방식을 조정할 수 있습니다. 이미 압축된 1.9MB PDF가 제출사이트에서 거절된다면 파일의 실제 크기 표시 단위나 PDF 암호·형식·손상 여부도 확인해야 합니다.

9. 스캔 PDF가 큰 이유와 압축 우선순위

스캐너·복합기에서 PDF를 만들 때 문서마다 큰 이미지가 저장되면 페이지 수가 적어도 용량이 커질 수 있습니다.

압축 전에 다음 항목을 확인하세요.

원인개선 방법주의
고해상도 컬러 스캔글자가 충분히 읽히는 범위에서 해상도 조정작은 글자·도장·QR코드는 흐려질 수 있음
배경까지 사진으로 스캔문서 영역을 바르게 자르고 불필요한 여백 제외공식 증명서의 필요한 표시를 자르면 안 됨
사진이 많은 문서이미지 압축률 조정의료영상·도면·색상 확인 문서는 신중
페이지마다 중복 첨부제출에 불필요한 페이지가 있는지 검토필수 페이지는 제거하지 않기
Word 원본의 큰 이미지원본에서 이미지 크기 줄인 뒤 PDF 재생성레이아웃과 인쇄품질 확인

단순히 PDF 화면에 표시되는 이미지 크기를 작게 보이게 하는 것과 실제 파일에 저장된 이미지 데이터를 줄이는 것은 다릅니다. 압축 전후 파일의 실제 크기를 확인해야 합니다.

10. 압축했는데 파일 크기가 그대로이거나 더 커지는 이유

특히 다음 경우에는 압축 효과가 작거나 파일이 오히려 커질 수 있습니다.

  • PDF가 이미 충분히 압축된 이미지로 구성된 경우
  • 이미지보다 검색 가능한 텍스트·벡터 도형이 중심인 경우
  • 단순히 PDF로 다시 인쇄하며 새 메타데이터·글꼴 등이 들어간 경우
  • 높은 품질 보존 옵션을 선택한 경우
  • 압축 프로그램이 저장·출력 방식에 따라 일부 데이터를 다시 생성한 경우

해결 순서: 파일을 2~3개 도구로 반복 처리하기 전에, 원본과 압축 결과의 실제 바이트 크기를 비교합니다. 변화가 거의 없다면 압축 강도를 높이거나 원본 사진에서 크기를 줄이세요. 한글·서명·도면이 손상된다면 이전 파일로 돌아가야 합니다.

'누르면 반드시 90% 압축', '모든 문서가 1MB 이하' 같은 보장은 신뢰하기 어렵습니다.

11. 글자가 흐려짐·한글 깨짐·페이지 누락 해결법

PDF는 크기를 줄이는 것보다 제출받는 쪽에서 정상적으로 열리는지가 중요합니다.

  • 작은 글씨가 뭉개짐: 강한 이미지 압축을 취소하고 중간·낮음 압축으로 다시 생성합니다.
  • 한글 글꼴 깨짐: 원본 문서의 글꼴 포함 상태와 PDF 내보내기 설정을 점검합니다.
  • 사진·도장의 색상이 바뀜: 색상 중요도가 높은 서류는 원본 품질을 우선합니다.
  • 페이지가 없어짐: PDF 압축 결과의 페이지 수를 원본과 비교합니다.
  • 검색·복사 불가: 텍스트 PDF를 이미지화한 변환을 하지 않았는지 확인합니다.
  • 전자서명 무효: 디지털 서명이 적용된 PDF를 다시 저장·압축하면 서명 검증에 영향을 줄 수 있습니다. 제출기관에 원본 제출 또는 재서명 요건을 확인합니다.
  • QR·바코드 인식 안 됨: 코드 부분을 실제 스마트폰 카메라 등으로 점검합니다.

검수 팁: 첫 페이지뿐 아니라 가장 작은 글자가 있는 페이지, 도장이나 QR이 있는 페이지, 마지막 페이지를 확인하세요. 개인정보·계약서와 같은 중요 문서는 압축본만 남기지 말고 원본을 보존하세요.

12. 개인정보가 담긴 PDF는 온라인 압축해도 되나요?

압축 서비스로 업로드하면 문서의 복사본이 외부 업체 서버로 전송·저장될 수 있습니다. Adobe 공식 안내는 온라인으로 압축한 PDF가 Adobe 클라우드 스토리지에 자동 저장된다고 명시합니다.

다음 문서는 가능하면 로컬에서 처리하고 외부 업로드는 보안 정책과 서비스 약관을 확인한 뒤 결정하세요.

  • 주민등록증·운전면허증 사본
  • 주민등록번호·계좌번호·인감·직인이 포함된 서류
  • 의료기록, 처방전, 진료비 영수증
  • 미공개 계약서, 사업자 영업정보
  • 어린이·학생의 개인정보가 포함된 문서

별도 보안 팁: PDF 암호를 설정해 놓았다고 해서 무작정 업로드해도 안전해지는 것은 아닙니다. 서비스가 암호 해제를 요구할 수 있고, 공유·저장 정책은 업체마다 다릅니다. 원본에는 타인이 보지 말아야 할 민감정보가 있는지 먼저 확인하세요.

13. PDF 합치기·ZIP 압축과 용량 줄이기는 어떻게 다를까요?

작업목적업로드 제한 해결 효과
PDF 압축PDF 자체의 파일 크기 감소해당 PDF에 직접 적용 가능
PDF 합치기여러 PDF를 하나로 통합보통 파일이 더 커질 수 있음
ZIP 압축여러 파일 묶기·전송제출처가 PDF만 받으면 ZIP 파일을 올릴 수 없음
PDF 다시 인쇄새 PDF 생성용량 감소를 보장하지 않음
불필요 페이지 제거페이지 수 축소제출 허용 범위 내에서 크기 감소 가능

제출처가 PDF 1개, 2MB 이하라고 정했다면 'ZIP으로 올리기'는 대체 방법이 아닙니다. PDF 자체가 제한을 통과하도록 만들어야 합니다.

14. 자주 묻는 질문 10개

Q1. PDF 용량 줄이기 무료로 가능한가요?

맥의 미리보기는 기본 탑재 앱이라 추가 비용 없이 사용할 수 있습니다. 온라인 서비스는 무료 체험 횟수·로그인 제한이 있을 수 있으므로 도구별 조건을 확인하세요.

Q2. 윈도우11에는 PDF 압축 기본 기능이 있나요?

일반적인 기존 PDF를 직접 압축하는 범용 기본 기능이 있다고 단정할 수 없습니다. Microsoft Print to PDF는 인쇄·PDF 생성 기능이지 결과 파일 크기 축소를 보장하는 도구가 아닙니다.

Q3. PDF 용량 10MB를 무조건 2MB로 줄일 수 있나요?

보장할 수 없습니다. 사진이 많은 스캔 PDF는 크게 줄어들 수도 있지만, 이미 압축된 문서는 거의 줄지 않을 수 있습니다.

Q4. 맥 미리보기에서 글씨가 흐려져요.

파일 → 내보내기 → 파일 크기 줄이기 필터는 이미지 품질을 낮출 수 있습니다. 원본으로 돌아가 대체 최적화 설정이나 더 낮은 압축 강도를 검토하세요.

Q5. 아이폰에서 PDF를 줄이려면 꼭 앱을 설치해야 하나요?

반드시 그렇지는 않습니다. 공식 웹 압축 도구를 브라우저에서 이용할 수 있습니다. 다만 업로드가 필요한지, 무료 제한이 있는지를 확인하세요.

Q6. 개인정보 PDF를 온라인 사이트에 올려도 괜찮나요?

무조건 안전하다고 할 수 없습니다. 외부 서버에 전송될 수 있으므로 민감한 서류는 오프라인 작업을 우선 검토하세요.

Q7. PDF가 2MB보다 조금 작아도 사이트가 거절해요.

제출처의 실제 바이트 제한과 파일 형식·암호·손상·페이지 제한 등을 확인하세요. 표시 단위 차이를 고려해 용량에 여유를 두는 것이 좋습니다.

Q8. Adobe Acrobat 웹 압축은 무제한 무료인가요?

아닙니다. Adobe의 공식 무료 온라인 서비스 FAQ는 로그인 상태와 계정에 따라 압축 이용량 제한을 안내합니다.

Q9. 압축 후 QR코드·도장을 확인해야 하나요?

예. QR 인식, 도장 판독, 서명과 작은 글자의 가독성을 반드시 점검하세요.

Q10. PDF를 ZIP으로 묶으면 PDF 업로드 제한을 통과하나요?

제출처가 ZIP을 허용하지 않으면 통과할 수 없습니다. PDF 자체의 크기를 줄여야 합니다.

15. 제출 전 최종 체크리스트

  • ☐ PDF 원본을 별도 보관했다.
  • ☐ 제출처 요구 용량·파일 형식·페이지 조건을 확인했다.
  • ☐ 원본 PDF의 용량과 페이지 수를 기록했다.
  • ☐ 민감정보가 있어 온라인 업로드를 피해야 하는지 확인했다.
  • ☐ 맥 기본 앱, 원본 문서 최적화, 공식 Acrobat 등 적합한 방법을 선택했다.
  • ☐ 압축 후 실제 파일 크기가 제한 이하인지 확인했다.
  • ☐ 작은 한글·사진·도장·QR코드가 읽히는지 점검했다.
  • ☐ 전자서명·링크·양식 등 필요한 기능이 유지되는지 확인했다.
  • ☐ 제출 사이트에 시험 업로드해 정상 접수 여부를 확인했다.
  • ☐ 원본과 최종 제출본을 구별할 수 있도록 이름을 붙여 보관했다.

결론

PDF 용량을 줄일 때는 '맥이라면 미리보기', 'Windows에서 원본 문서가 있으면 최소 크기로 PDF 재내보내기', '기존 PDF만 있다면 신뢰할 수 있는 압축 도구'라는 기준으로 선택하세요. 휴대전화에서는 웹 압축도 가능하지만 문서를 외부 서비스에 업로드한다는 점을 반드시 인지해야 합니다.

2MB 이하 제출에서는 용량만 줄이는 것이 아니라 작은 글자·서명·QR코드가 남아 있는지 최종 검수하는 과정이 중요합니다. 제출처 요구조건이 까다로운 서류일수록 원본 파일을 안전하게 보관하고, 압축본이 실제로 정상 접수되는지 확인하세요.
