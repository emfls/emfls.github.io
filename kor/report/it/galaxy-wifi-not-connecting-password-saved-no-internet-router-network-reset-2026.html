이 글은 2026년 11월 4일 삼성전자 공식 고객지원 문서를 확인해 작성했습니다. 메뉴 이름은 갤럭시 모델·One UI 버전에 따라 다를 수 있으며, 실제 기기에서 해결률을 측정한 결과는 아닙니다.

2. 먼저 다른 기기와 비교: 공유기 문제인지 갤럭시 문제인지

초기화하기 전에 다음 교차 확인이 가장 효율적입니다.

  1. 내 갤럭시에서 집 와이파이에 연결해 봅니다.
  2. 같은 위치의 다른 휴대전화 또는 PC에서도 동일한 Wi-Fi 이름으로 연결해 봅니다.
  3. 연결만 확인하지 말고 일반 웹사이트가 열리는지 확인합니다.
  4. 내 갤럭시를 다른 신뢰할 수 있는 와이파이에 연결할 수 있다면 비교합니다.
  5. 문제가 특정 장소 또는 특정 휴대전화에서만 반복되는지 기록합니다.
비교 결과우선 점검 방향

이는 원인 범위를 좁히는 방법이지, 다른 기기 한 대가 정상이라는 이유만으로 공유기 설정의 문제가 절대 없다고 확정하는 방법은 아닙니다.

삼성전자도 공식 가이드에서 다른 기기에 Wi-Fi 네트워크가 표시되는지 확인하도록 권장합니다.

3. 설정 → 연결 → Wi-Fi가 켜져 있는지 확인하기

간단하지만 먼저 확인해야 하는 단계입니다.

  1. 갤럭시에서 설정을 엽니다.
  2. 연결 → Wi-Fi로 이동합니다.
  3. Wi-Fi 스위치가 켜짐인지 확인합니다.
  4. 주변 네트워크 이름이 나타나는지 확인합니다.
  5. 빠른 설정 패널에서도 Wi-Fi 아이콘 상태를 확인할 수 있습니다.

비행기 모드와 혼동하지 마세요. 비행기 모드는 네트워크 기능에 영향을 줄 수 있지만, 해당 모드에서 Wi-Fi가 실제로 켜져 있는지는 기기 상태에 따라 따로 확인해야 합니다. '비행기 모드만 해제하면 무조건 해결된다'고 볼 수는 없습니다.

네트워크가 검색되는데 접속에 실패한다면 다음의 비밀번호와 저장된 연결 정보를 확인하세요.

4. 비밀번호 오류가 반복될 때

와이파이 비밀번호는 공유기에 설정된 Wi-Fi 암호입니다. 공유기 관리자 페이지 비밀번호나 통신사 가입 계정 비밀번호와 다를 수 있습니다.

점검 순서

  1. 연결하려는 와이파이 이름(SSID)이 맞는지 확인합니다.
  2. 공유기 설정을 관리하는 사람에게 현재 Wi-Fi 비밀번호를 확인합니다.
  3. 대문자·소문자·숫자·특수문자를 정확하게 입력합니다.
  4. 공유기 비밀번호가 최근 변경됐다면 예전에 저장된 비밀번호가 유효하지 않을 수 있습니다.
  5. 계속 실패하면 다음 단계처럼 해당 네트워크 연결 정보를 삭제한 후 다시 연결합니다.

안전: 비밀번호를 확인한다는 이유로 공유기 측면의 초기화(RESET) 버튼을 길게 누르지 마세요. 이는 무선 설정·인터넷 설정을 공장 기본값으로 되돌려 가족과 다른 기기까지 연결이 끊어지게 할 수 있습니다.

게스트 네트워크와 기본 네트워크의 이름·비밀번호가 다를 수도 있으므로 정확히 어느 네트워크에 연결하려는지 먼저 확인하세요.

5. '저장됨'만 뜨고 연결 안 될 때: 네트워크 삭제·재연결

삼성은 공식적으로 저장된 Wi-Fi 네트워크를 '삭제(Forget)'하고 다시 연결하는 방법을 권장합니다.

저장된 네트워크 삭제 후 다시 연결

  1. 설정 → 연결 → Wi-Fi를 엽니다.
  2. 연결되지 않는 Wi-Fi 이름을 길게 누르거나, 설정 아이콘을 선택합니다.
  3. 삭제 / 네트워크 삭제(Forget network)를 선택합니다.
  4. Wi-Fi 목록에서 동일한 네트워크 이름을 다시 찾습니다.
  5. 확인한 현재 비밀번호를 다시 입력합니다.
  6. 연결 상태뿐 아니라 웹페이지가 열리는지 시험합니다.

중요: 이 조치는 선택한 와이파이에 저장된 연결 정보를 지웁니다. 다시 연결하려면 암호가 필요할 수 있습니다. 모든 Wi-Fi와 블루투스 설정을 초기화하는 작업은 아닙니다.

Wi-Fi 이름이 목록에서 사라진 상태라면 저장 정보를 삭제하기 전에 공유기의 전원·신호가 켜져 있는지부터 확인하세요.

공식 근거: 삼성전자 — 저장된 Wi-Fi 연결 정보를 삭제하고 재연결

6. '연결됨, 인터넷 없음'이면 확인할 네 가지

이 메시지는 휴대전화와 무선 공유기 사이 연결과 공유기 밖 인터넷 연결을 구별해야 합니다.

  1. 같은 와이파이에 연결한 다른 기기에서도 인터넷이 안 되는지 확인합니다.
  2. 공유기·모뎀의 전원 및 인터넷 회선 상태를 점검합니다.
  3. 공유기를 정상 재시작한 뒤 결과가 달라지는지 확인합니다.
  4. 카페·호텔·공항 같은 네트워크라면 별도의 로그인·약관 동의 화면이 필요한지 확인합니다.
상황가능성 있는 원인
집안 모든 기기의 인터넷이 안 됨회선·공유기 WAN 문제
한 갤럭시에서만 인터넷 없음저장된 설정·앱·소프트웨어
일반 앱은 되지만 특정 사이트만 안 됨사이트 자체·앱·DNS·접근 제한
공공 Wi-Fi 연결은 됐지만 웹은 막힘포털 로그인·이용약관 동의 필요

주장 주의: 원인 검증 없이 임의의 공개 DNS 주소를 입력하거나 보안 인증을 끄는 방법을 일반 해결책으로 권장하지 않습니다. 회사·학교 네트워크는 관리 정책을 따라야 합니다.

삼성 공식 문서에서도 공유기 자체의 문제와 펌웨어 상태를 확인하도록 권장합니다.

7. 공유기 재시작과 공장 초기화는 다릅니다

삼성 Wi-Fi 문제 해결 가이드는 공유기를 다시 시작한 뒤 갤럭시에서 재연결해보도록 안내합니다.

공유기 정상 재시작

  1. 공유기에 연결된 다른 가족·사용자에게 잠시 인터넷 연결이 끊길 수 있음을 알립니다.
  2. 공유기 제조사의 설명서에 따라 전원을 껐다가 다시 켭니다.
  3. 공유기가 정상적으로 부팅하고 네트워크 이름이 나타날 때까지 기다립니다.
  4. 갤럭시에서 Wi-Fi를 다시 연결합니다.
  5. 다른 기기도 인터넷에 접속되는지 확인합니다.

전원 코드를 분리할 수 없는 제품은 공유기 관리 페이지의 재시작 기능을 사용할 수 있습니다.

금지에 가까운 주의사항: 공유기의 RESET(공장 초기화) 버튼을 누르는 것은 다른 작업입니다. 관리자 설정·인터넷 인증·무선 이름·비밀번호가 초기화될 수 있어, 제조사·통신사 지침 없이는 먼저 시도하지 마세요.

8. 집 와이파이 이름 자체가 안 보일 때

와이파이 목록에 집 네트워크가 없다면 비밀번호를 다시 입력하는 작업부터 진행할 수 없습니다. 먼저 네트워크가 송출되고 있는지 확인하세요.

  1. 공유기 전원과 Wi-Fi 표시등이 정상인지 확인합니다.
  2. 같은 장소에서 다른 휴대전화에 집 와이파이 이름이 나타나는지 확인합니다.
  3. 갤럭시를 공유기 근처로 옮겨 다시 검색합니다.
  4. 공유기가 숨김 네트워크(SSID 숨김)로 설정됐는지 공유기 관리자에게 확인합니다.
  5. 공유기의 펌웨어 업데이트 상태를 제조사 공식 안내로 확인합니다.

삼성은 공식 문서에서 다른 장치에서도 네트워크가 검색되지 않는다면 공유기 제조사 지원을 받도록 안내합니다.

2.4GHz/5GHz 구분: 공유기의 주파수 대역과 기기 지원 규격에 따라 특정 네트워크가 보이지 않거나 연결 방식에 차이가 날 수 있습니다. 그러나 주파수 변경이 모든 오류를 해결한다고 단정할 수 없으므로 해당 공유기·기기 공식 설명서를 확인해야 합니다.

9. 갤럭시를 정상 재시작하기

갤럭시의 일시적인 시스템 문제가 와이파이 연결을 방해할 수 있어 삼성 공식 가이드는 기기 재시작을 권장합니다.

  1. 진행 중인 작업을 저장합니다.
  2. 빠른 설정에서 전원 아이콘을 누릅니다.
  3. 다시 시작을 선택합니다.
  4. 잠금 암호가 필요한 경우 본인의 암호로 로그인합니다.
  5. 기존 와이파이에 다시 연결하고 인터넷 접속 결과를 비교합니다.

강제 재시작과 구별: 기기가 멈춘 경우에는 기종에 따라 측면 버튼과 음량 아래 버튼을 길게 누르는 방법이 있지만, 화면이 정상 작동한다면 일반 재시작부터 진행하세요.

재시작 후에도 문제가 동일하면 네트워크 저장 정보·공유기·소프트웨어를 다음 순서로 확인합니다.

10. 최근 설치한 앱 때문에 안 될 수도 있나요? 안전모드 시험

삼성 공식 지원은 일부 다운로드 앱이 네트워크 연결에도 영향을 줄 수 있다고 설명하며, 원인 분리를 위해 안전모드(Safe mode)를 권장합니다.

안전모드의 의미

안전모드는 다운로드한 일부 앱의 작동을 제한한 상태에서 문제가 재현되는지 비교하는 진단 환경입니다. 그 자체가 일반적인 인터넷 가속 기능은 아닙니다.

기본 시험 순서

  1. 갤럭시 전원 메뉴를 엽니다.
  2. 전원 끄기 항목을 길게 눌러 안전모드 진입 선택지가 나타나는지 확인합니다.
  3. 안전모드를 선택합니다.
  4. 화면 하단의 안전모드 표시를 확인합니다.
  5. 문제가 발생한 와이파이에서 연결·인터넷 접속을 시험합니다.
  6. 시험을 마친 뒤 정상 재시작으로 안전모드에서 나옵니다.
시험 결과다음에 확인할 것
안전모드에서는 Wi-Fi가 정상최근 설치·설정 변경한 앱을 점검할 근거
안전모드에서도 동일한 오류공유기·네트워크 설정·소프트웨어·기기 상태 추가 점검

주의: 안전모드에서 Wi-Fi가 정상이라고 해서 특정 앱 하나가 원인이라고 바로 단정할 수 없습니다. 최근 설치한 보안·VPN·네트워크 앱 등의 영향을 하나씩 확인하는 것이 좋습니다.

11. 최신 One UI 업데이트 여부 확인

삼성 공식 문서는 재시작 후 문제가 계속되면 갤럭시 소프트웨어 업데이트를 확인하도록 권장합니다.

업데이트 확인

  1. 설정 → 소프트웨어 업데이트를 엽니다.
  2. 다운로드 및 설치 / 업데이트 확인에 해당하는 메뉴를 선택합니다.
  3. 업데이트가 제공되는지 확인합니다.
  4. 업데이트 전에 중요한 데이터의 백업 상태와 배터리를 확인합니다.
  5. 공식 업데이트를 적용한 후 와이파이 연결을 다시 비교합니다.

연결이 전혀 안 되는 상황: 와이파이를 사용할 수 없다면 모바일 데이터 요금이 발생할 수 있고, 삼성 공식 안내에 따라 PC용 Smart Switch 프로그램을 통한 업데이트 가능 여부를 확인할 수 있습니다. 다만 모든 기기에서 같은 방식이 제공되지는 않습니다.

업데이트는 권장 진단 항목이지만, 공유기 인터넷 회선 장애나 비밀번호 오류까지 모두 해결하는 것은 아닙니다.

  5. 필요하다면 설정 초기화를 실행합니다.

13. Samsung Members에서 Wi-Fi 기능 자가진단

삼성은 기본 연결 점검을 마친 뒤에도 해결되지 않으면 Samsung Members의 휴대전화 진단으로 Wi-Fi 상태를 확인하도록 안내합니다.

공식 진단 방법

  1. Samsung Members 앱을 엽니다.
  2. 지원(Support) 메뉴를 선택합니다.
  3. 휴대전화 진단을 시작합니다.
  4. 제공되는 항목 가운데 Wi-Fi를 선택합니다.
  5. 화면 지시에 따라 진단을 완료합니다.
  6. 결과를 기록한 뒤 문제가 계속되면 삼성 공식 지원에 문의합니다.

메뉴 차이: 기종·버전별로 전체 진단을 먼저 시작한 뒤 중지하여 개별 항목을 선택해야 할 수 있습니다. Samsung Members가 설치돼 있지 않으면 같은 경로가 제공되지 않을 수 있습니다.

해석 주의: 자가진단이 정상이어도 집 공유기 연결이 반드시 정상이라는 뜻은 아닙니다. Wi-Fi 기능 상태와 개별 네트워크의 암호·회선 문제는 다를 수 있습니다.

14. 집·회사·카페 와이파이는 해결 방향이 다릅니다

집 공유기

  • 다른 가족 기기도 인터넷이 안 되는지 확인합니다.
  • 공유기를 정상 재시작하고 펌웨어 업데이트는 제조사 지침을 따릅니다.

회사·학교 네트워크

  • IT 관리자에게 오류 문구와 기종을 알려 지원을 요청합니다.

카페·호텔·공항 와이파이

  • Wi-Fi 연결 뒤 로그인 페이지·이용약관 동의가 필요할 수 있습니다.

  • 계정·금융 정보를 입력할 때는 가짜 Wi-Fi 이름(유사 SSID)에 연결된 것은 아닌지 주의합니다.

고정된 '마법의 DNS 주소'를 입력하거나 인증서 경고를 무시하라고 안내하는 것은 안전하지 않습니다. 공공·관리형 네트워크 문제는 해당 네트워크 운영자의 안내를 우선하세요.

17. 자주 묻는 질문(FAQ)

Q1. 갤럭시 와이파이가 '저장됨'만 나오고 연결되지 않아요.

설정 → 연결 → Wi-Fi에서 해당 네트워크를 삭제한 뒤 다시 연결해 보세요. 현재 공유기 비밀번호를 먼저 확인해야 합니다. 저장됨 표시만으로 공유기 고장 여부를 확정할 수는 없습니다.

Q2. 와이파이는 연결됐는데 인터넷이 안 됩니다.

같은 Wi-Fi에 연결된 다른 기기도 인터넷에 접속하지 못하는지 확인하세요. 모든 기기가 실패한다면 공유기·인터넷 회선을 우선 점검합니다.

Q3. 비밀번호가 정확한데도 비밀번호 오류가 나와요.

선택한 Wi-Fi 이름이 맞는지 확인하고, 저장된 네트워크를 삭제한 뒤 다시 입력해 보세요. 공유기 비밀번호 변경·게스트 네트워크 등도 함께 확인해야 합니다.

Q4. 가족 휴대전화는 되는데 내 갤럭시만 안 됩니다.

내 갤럭시의 저장된 Wi-Fi 정보·소프트웨어·최근 설치 앱을 먼저 확인할 수 있습니다. 삼성 공식 가이드는 안전모드·재시작·네트워크 재연결을 안내합니다.

Q5. 와이파이 목록에 집 공유기 이름이 안 떠요.

같은 장소의 다른 기기에서도 검색되는지 확인하고, 공유기 전원·신호·펌웨어를 점검하세요. 다른 기기에도 보이지 않는다면 공유기 제조사 지원을 받는 것이 적절합니다.

Q6. 공유기를 껐다 켜는 것과 RESET 버튼을 누르는 것은 같나요?

다릅니다. 전원 재시작은 일시적으로 껐다가 켜는 작업이고, RESET 버튼은 공유기 설정을 공장 기본값으로 바꿀 수 있어 인터넷·와이파이 설정이 사라질 수 있습니다.

Q7. Wi-Fi·블루투스 설정 초기화를 하면 사진도 삭제되나요?

삼성 공식 안내 기준 이 초기화는 앱·개인 데이터를 지우는 공장 초기화와 다릅니다. 그러나 저장된 Wi-Fi 연결과 블루투스 페어링 등은 다시 설정해야 할 수 있습니다.

Q8. 안전모드에서 와이파이가 정상이라면 어떻게 하나요?

최근 설치하거나 설정을 변경한 제3자 앱이 연결에 영향을 줄 가능성을 살펴볼 수 있습니다. 특정 앱이 원인이라고 확정하려면 추가 비교가 필요합니다.

Q9. Samsung Members로 와이파이 고장을 확인할 수 있나요?

해당 기기에서 Samsung Members → 지원 → 휴대전화 진단 → Wi-Fi 항목이 제공되면 기능을 시험할 수 있습니다. 결과 하나만으로 공유기 문제와 기기 고장을 완전히 확정할 수는 없습니다.

Q10. 와이파이가 안 돼서 One UI 업데이트를 못 합니다.

삼성 공식 자료는 모바일 데이터(요금 주의) 또는 지원 기기에서 PC용 Smart Switch를 통한 공식 소프트웨어 업데이트 경로를 안내합니다. 연결 상태와 모델 지원 여부를 확인하세요.

Q11. 와이파이가 자꾸 끊길 때는 무조건 2.4GHz로 바꿔야 하나요?

아닙니다. 기종·공유기·환경에 따라 Wi-Fi 대역별 연결 특성이 다르지만 모든 끊김 현상을 2.4GHz 전환으로 해결할 수 있는 것은 아닙니다. 우선 거리·장애물·공유기 재시작 등 기본 점검을 진행하세요.

Q12. 와이파이 연결 때문에 갤럭시 공장 초기화를 해야 하나요?

일반적인 첫 조치로 권장하지 않습니다. 네트워크 삭제·재연결 → 갤럭시·공유기 재시작 → 안전모드·업데이트 → Wi-Fi·블루투스 설정 초기화 → 진단 순서로 진행하세요.

결론

갤럭시 와이파이가 안 되면 'SSID가 검색되는지', '공유기에 연결되는지', '연결 뒤 인터넷이 되는지'부터 나눠 확인하세요. 비밀번호 오류나 '저장됨' 반복이라면 해당 네트워크 삭제·재연결을, '연결됨, 인터넷 없음'이라면 다른 기기로 공유기·인터넷 회선을 비교하는 것이 우선입니다.

그래도 해결되지 않으면 갤럭시 재시작, 공식 업데이트, 안전모드, Wi-Fi·블루투스 설정 초기화, Samsung Members 진단 순서로 점검하세요. 초기화는 저장된 연결 정보에 영향을 줄 수 있으므로 마지막에 검토하고, 공장 초기화를 서둘러 진행하지 마세요.
