이 네 가지 상황은 원인이 다릅니다. 아이폰의 셀룰러 데이터 연결, 개인용 핫스팟 설정, 연결할 기기의 Wi-Fi, 통신사 요금제와 지원 여부를 나누어 확인해야 불필요한 초기화를 피할 수 있습니다. 이 글은 2026년 11월 3일 기준 Apple 공식 지원 문서에서 안내한 순서를 바탕으로 구성했습니다. 모델·iOS 버전·통신사에 따라 메뉴 표시는 다를 수 있습니다.

1. 아이폰에서 핫스팟 켜는 정확한 경로

다른 사람이나 윈도우 PC 같은 외부 기기가 연결할 때는 다음을 확인합니다.

  1. 아이폰에서 설정 → 개인용 핫스팟으로 이동합니다. 기기에 따라 설정 → 셀룰러 → 개인용 핫스팟으로 들어갈 수도 있습니다.
  2. 다른 사람의 연결 허용을 켭니다.
  3. 바로 아래의 Wi-Fi 암호를 확인합니다.
  4. 아이폰을 개인용 핫스팟 설정 화면에 둔 상태에서 다른 기기가 연결을 시도하도록 합니다.
  5. 윈도우 노트북이나 다른 스마트폰의 Wi-Fi 목록에서 아이폰 이름을 찾아 연결합니다.
  6. 암호를 입력한 뒤 인터넷 접속을 확인합니다.

Apple은 일반 Wi-Fi 연결 문제 해결 과정에서 핫스팟 설정 화면을 유지한 상태로 연결을 기다리라고 안내합니다. 검색 목록에 아이폰이 바로 보이지 않는 경우 먼저 이 방법을 적용하세요.

2. 개인용 핫스팟 메뉴가 없거나 회색인 경우

가장 먼저 설정 → 셀룰러 → 셀룰러 데이터가 켜져 있는지 확인합니다. 또한 아이폰에서 Wi-Fi를 잠시 끄고, Safari로 일반 웹사이트에 접속할 수 있는지 확인하세요.

  • 아이폰 자체에서 셀룰러 인터넷도 안 된다면: 개인용 핫스팟보다 먼저 모바일 데이터 연결 상태를 점검해야 합니다.
  • 아이폰 자체 인터넷은 되는데 핫스팟만 안 보인다면: 통신사 요금제의 테더링 지원 여부를 확인하세요.
  • 새 유심·eSIM 개통이나 번호이동 직후라면: 이동통신사에 핫스팟 기능이 회선에서 활성화됐는지 문의하세요.

Apple은 핫스팟 기능 자체를 사용할 수 없을 때 통신사의 기능 활성화 및 요금제 지원을 확인하라고 안내합니다. 알뜰폰을 포함해 실제 이용 중인 사업자 기준으로 확인하는 편이 정확합니다.

주의: 인터넷 게시글에 나온 APN 값을 그대로 복사해 입력하지 마세요. 사업자별 설정이 다를 수 있고, 잘못된 값은 데이터 통신 문제를 더 키울 수 있습니다. 통신사에서 안내한 공식 설정만 적용하세요.

3. 노트북 와이파이 목록에 아이폰 이름이 안 뜰 때

아이폰에서 다른 사람의 연결 허용을 켰는데도 이름이 안 뜬다면 다음 순서로 확인합니다.

  1. 두 기기를 가까이 놓습니다.
  2. 아이폰의 설정 → 개인용 핫스팟 화면을 계속 표시합니다.
  3. 연결하려는 노트북의 Wi-Fi를 껐다가 다시 켭니다.
  4. Windows의 사용 가능한 네트워크 목록을 다시 엽니다.
  5. 아이폰의 기기 이름과 일치하는 Wi-Fi를 선택합니다.
  6. 그래도 표시되지 않는다면 두 기기를 재시동합니다.

핫스팟의 이름은 보통 아이폰의 기기 이름을 사용합니다. 이름을 확인하거나 바꾸려면 설정 → 일반 → 정보 → 이름을 엽니다.

이름 변경은 다른 기기가 저장했던 연결 대상을 구분하는 데 영향을 줄 수 있으므로, 기존 이름을 알고 있다면 먼저 그 이름으로 검색하세요.

중요: 다른 기기에서 핫스팟 이름이 보이지 않는 현상은 암호 오류와 다릅니다. 암호를 여러 번 바꾸기보다 검색·발견 단계를 먼저 해결해야 합니다.

4. 핫스팟 비밀번호 오류: '암호가 틀림'이 계속 뜰 때

일반 Wi-Fi 핫스팟에서 암호를 요청하면 아이폰의 개인용 핫스팟 설정에 표시된 Wi-Fi 암호를 사용해야 합니다. 아이폰 잠금화면 암호나 Apple 계정 비밀번호와는 다릅니다.

  1. 아이폰에서 설정 → 개인용 핫스팟 → Wi-Fi 암호를 확인합니다.
  2. 연결 대상 기기의 Wi-Fi를 껐다 켭니다.
  3. 기존에 저장해 둔 아이폰 핫스팟 연결 설정이 잘못됐다면 대상 기기의 해당 Wi-Fi 네트워크를 지운 뒤 다시 연결합니다.
  4. 정확한 핫스팟 암호를 새로 입력합니다.

Apple은 핫스팟 암호를 8자 이상으로 설정하도록 안내합니다. 일부 특수문자나 비ASCII 문자는 호환성 문제를 일으킬 수 있으므로 Apple이 안내하는 문자 범위를 따르세요. 가능한 한 영문 대소문자·숫자·지원되는 구두점으로 구성하는 것이 좋습니다.

암호를 바꿨다면 기존에 연결됐던 노트북과 태블릿에서도 새 암호를 사용해야 할 수 있습니다.

5. '연결됨, 인터넷 없음'이 뜰 때: 아이폰부터 확인

노트북이 아이폰의 핫스팟에 연결됐다는 표시는 Wi-Fi 연결 자체가 성립했다는 의미일 뿐, 아이폰의 모바일 데이터가 정상적으로 인터넷에 접속 중이라는 보장은 아닙니다.

다음 순서로 확인해 보세요.

  1. 아이폰에서 Wi-Fi를 꺼서 셀룰러 데이터 연결만 사용합니다.
  2. Safari에서 새로운 웹사이트를 직접 열어봅니다. 이미 열린 페이지의 캐시만 보는 것은 피합니다.
  3. 아이폰 자체에서도 인터넷이 되지 않으면 셀룰러 데이터 사용 가능 상태, 통신망 품질, 요금제·데이터 소진 여부를 확인합니다.
  4. 아이폰 자체에서는 인터넷이 정상인데 노트북만 안 되면 노트북의 Wi-Fi 연결을 끊었다가 다시 연결합니다.
  5. 다른 노트북이나 태블릿이 있다면 같은 핫스팟에 연결해 문제가 아이폰 측에 공통으로 나타나는지, 특정 노트북에서만 발생하는지 구분합니다.

VPN·보안 소프트웨어가 연결에 영향을 주는 환경이라면 해당 설정을 점검할 수 있지만, 회사·학교의 보안 정책을 임의로 해제하지 마세요.

여기서도 원인 확인 전에 아이폰을 공장 초기화할 이유는 없습니다.

6. '호환성 최대화'는 언제 켜야 할까?

아이폰 12 및 이후 지원 모델에서 설정 → 개인용 핫스팟 → 호환성 최대화를 켜 볼 수 있습니다.

Apple은 Wi-Fi 연결 문제가 계속될 때 이 옵션을 켜고 다시 시도하라고 안내합니다. 특히 특정 노트북이나 오래된 Wi-Fi 장치에서만 아이폰 핫스팟을 찾지 못할 때 시도할 만한 진단 방법입니다.

하지만 항상 켜 두는 것이 최선이라는 뜻은 아닙니다. Apple은 호환성 최대화를 켜면 인터넷 성능과 Wi-Fi 보안이 저하될 수 있다고 설명합니다.

권장 순서

  • 먼저 일반 설정으로 연결을 시도합니다.
  • 특정 기기에서 검색·연결 실패가 반복되면 호환성 최대화를 켜고 테스트합니다.
  • 연결 문제가 해결되는지 확인하고, 필요하지 않으면 설정을 다시 검토합니다.

참고: 이 옵션은 모든 구형 아이폰에 표시되지 않습니다. 메뉴가 없는 것만으로 고장이라고 판단하지 마세요.

7. 윈도우11 노트북에서 아이폰 USB 테더링하는 방법

Wi-Fi 연결이 계속 불안정하다면 Apple 공식 안내에 따라 USB 케이블 연결을 시도할 수 있습니다.

  1. Windows에 Apple 기기 앱 또는 Windows용 iTunes의 최신 지원 버전이 설치돼 있는지 확인합니다.
  2. 아이폰에서 설정 → 개인용 핫스팟 → 다른 사람의 연결 허용을 켭니다.
  3. 충전뿐 아니라 데이터 전송이 가능한 USB 케이블로 아이폰을 PC에 연결합니다.
  4. 아이폰에 '이 컴퓨터를 신뢰하겠습니까?'라는 메시지가 나타나면 실제 본인이 사용하는 PC인지 확인하고 신뢰를 누릅니다.
  5. PC에 액세서리 연결 허용 메시지가 나타나면 신뢰할 수 있는 장치일 때만 허용합니다.
  6. Windows에서 네트워크 연결이 생성됐는지 확인하고 인터넷 접속을 테스트합니다.

USB 케이블을 연결했다고 해서 항상 테더링이 즉시 시작되는 것은 아닙니다. 케이블이 충전 전용이거나 필요한 Windows 구성요소가 설치되지 않았으면 기기를 인식하지 못할 수 있습니다.

Apple은 Windows USB 연결을 위해 Apple 기기 앱 또는 iTunes를 설치하도록 안내합니다. USB 연결이 작동하지 않으면 먼저 PC가 아이폰 자체를 정상 인식하는지 점검하세요.

사용을 마치면 USB 케이블을 분리하거나 아이폰의 개인용 핫스팟을 끕니다. 아이폰 충전 목적으로 연결했더라도 개인용 핫스팟이 활성화되어 있으면 PC가 셀룰러 데이터를 사용하게 될 수 있습니다.

8. 맥북에서는 연결되는데 윈도우에서는 안 되는 이유

맥북은 같은 Apple 계정 또는 가족 공유 그룹에 속한 아이폰과 Instant Hotspot으로 더 쉽게 연결할 수 있습니다. 해당 기능이 지원되는 조건에서는 다른 사람의 연결 허용을 켜거나 매번 Wi-Fi 암호를 입력하지 않고 연결할 수 있습니다.

하지만 Windows PC와 일반 외부 기기는 보통 다른 사람의 연결 허용이 켜져 있어야 합니다. 따라서 맥북에서는 되는데 윈도우에서는 안 된다는 현상만으로 아이폰 핫스팟이 완전히 정상이라고 단정할 수는 없습니다.

Apple 기기 간 연결을 확인할 때는 다음을 살펴보세요.

  • 두 기기가 서로 가까이 있는지
  • Wi-Fi와 Bluetooth가 활성화되어 있는지
  • 같은 Apple 계정 또는 허용된 가족 공유 설정인지
  • 맥북에서 원하는 아이폰 핫스팟을 선택했는지

같은 Apple 계정의 자동 연결과 일반 Wi-Fi 테더링을 구분하면 문제 원인을 더 쉽게 좁힐 수 있습니다.

9. 마지막 방법: 네트워크 설정 재설정 전에 알아야 할 것

핫스팟 설정, 재시동, 소프트웨어 업데이트 확인 후에도 해결되지 않는 경우 Apple은 네트워크 설정 재설정을 안내합니다.

설정 → 일반 → 전송 또는 iPhone 재설정 → 재설정 → 네트워크 설정 재설정

하지만 이 조치는 가볍게 시행할 작업이 아닙니다. Apple은 네트워크 설정을 재설정하면 기존 Wi-Fi 네트워크와 암호, 셀룰러 설정, VPN 및 APN 설정이 재설정된다고 명시합니다. 회사나 학교에서 별도 VPN·네트워크 구성을 사용하는 경우 복구 방법을 확인해 두세요.

주의사항

  • 현재 연결된 Wi-Fi의 비밀번호를 다시 입력해야 할 수 있습니다.
  • 특수한 통신사 APN이나 VPN 설정이 있으면 복원이 필요할 수 있습니다.
  • 네트워크 설정 재설정과 '모든 콘텐츠 및 설정 지우기'는 완전히 다른 조치입니다.
  • 핫스팟 문제 때문에 전체 기기 초기화 메뉴를 선택하지 마세요.

이 단계를 시도할지 결정하기 전에 통신사 장애나 요금제 지원 문제 가능성을 먼저 확인하면 불필요한 설정 손실을 줄일 수 있습니다.

자주 묻는 질문

Q1. 아이폰 핫스팟은 켰는데 노트북에 이름이 안 보여요.

아이폰에서 다른 사람의 연결 허용을 켜고 개인용 핫스팟 설정 화면을 유지한 상태로 노트북의 Wi-Fi를 다시 검색하세요. 연결할 기기에서도 Wi-Fi를 껐다 켜고 두 기기를 가까이 둡니다.

Q2. 아이폰 핫스팟 연결됨이라고 뜨는데 인터넷이 안 돼요.

우선 아이폰 자체에서 셀룰러 데이터로 인터넷이 되는지 확인하세요. 아이폰도 안 되면 회선·데이터 연결 문제를 먼저 살펴야 합니다. 아이폰에서는 되는데 노트북에서만 안 된다면 PC의 연결 설정을 점검합니다.

Q3. 호환성 최대화를 무조건 켜 두는 것이 좋나요?

그렇지 않습니다. Apple은 이 기능이 일부 호환성 문제를 해결할 수 있지만 연결 성능과 Wi-Fi 보안이 낮아질 수 있다고 안내합니다. 필요할 때 비교해 보는 옵션으로 이해하는 것이 좋습니다.

Q4. 개인용 핫스팟 메뉴가 아예 없는데 아이폰 고장인가요?

고장이라고 단정하기 어렵습니다. 셀룰러 데이터가 켜져 있는지, 사용하는 통신사와 요금제가 개인용 핫스팟을 지원하는지 먼저 확인해야 합니다.

Q5. 핫스팟 비밀번호는 아이폰 잠금 암호와 같은가요?

아닙니다. 설정 → 개인용 핫스팟 → Wi-Fi 암호에 표시된 암호를 사용합니다. Apple 계정 암호도 아닙니다.

Q6. 맥북은 자동 연결되는데 윈도우는 왜 안 되나요?

같은 Apple 계정에 속한 Mac은 Instant Hotspot으로 일반 외부 기기와 다른 방식으로 연결할 수 있습니다. Windows는 다른 사람의 연결 허용을 켜고 일반 Wi-Fi로 연결하는 설정을 확인해야 합니다.

Q7. USB로 연결하면 데이터가 전혀 안 드나요?

USB 테더링은 인터넷 연결 매체가 케이블로 달라지는 것일 뿐 아이폰의 셀룰러 데이터를 공유하는 점은 같습니다. 통신사 요금제의 데이터·테더링 조건을 확인해야 합니다.

Q8. 네트워크 설정을 재설정하면 사진이 삭제되나요?

네트워크 설정 재설정은 모든 콘텐츠 및 설정 지우기와 다른 작업입니다. 다만 Wi-Fi 암호와 일부 셀룰러·VPN·APN 설정이 지워질 수 있으므로 복구 방법을 확인하고 진행하세요.

Q9. 아이폰이 집 와이파이에 연결돼 있으면 그 와이파이를 노트북에 다시 공유하나요?

Apple 공식 안내에 따르면 아이폰 개인용 핫스팟은 아이폰의 셀룰러 데이터 연결을 공유합니다. 일반적으로 아이폰이 접속 중인 외부 Wi-Fi를 그대로 다시 중계하는 기능으로 이해해서는 안 됩니다.

마무리 체크리스트

  • ☐ 아이폰에서 Wi-Fi를 끄고 셀룰러 인터넷이 되는지 확인했다.
  • ☐ 개인용 핫스팟 메뉴와 다른 사람의 연결 허용을 확인했다.
  • ☐ 아이폰 핫스팟 화면을 열어 두고 대상 기기에서 Wi-Fi를 다시 검색했다.
  • ☐ 정확한 Wi-Fi 암호로 다시 연결했다.
  • ☐ 지원 기기라면 호환성 최대화를 시험해 봤다.
  • ☐ Mac의 Instant Hotspot과 Windows 일반 연결을 구분했다.
  • ☐ USB 테더링을 사용하는 경우 Apple 기기 앱·케이블·신뢰 설정을 확인했다.
  • ☐ 네트워크 설정 재설정 전 Wi-Fi·VPN·APN 설정 영향을 확인했다.

결론: 아이폰 핫스팟 연결 실패는 '핫스팟이 아예 보이지 않는지', '암호 연결이 실패하는지', '연결은 됐지만 인터넷이 없는지'부터 구분해야 합니다. 대부분의 점검은 설정 확인과 재연결로 시작할 수 있고, 네트워크 재설정은 마지막 단계로 남겨두는 편이 안전합니다.
