갤럭시에서 유튜브 영상을 보면서 메모를 하거나, 인터넷 쇼핑 가격을 비교하면서 계산기를 쓰고 싶다면 화면 분할(분할 화면 보기) 기능을 활용할 수 있습니다. 삼성 갤럭시는 지원되는 앱 두 개를 한 화면에 배치하는 멀티윈도우, 작은 창을 띄우는 팝업 화면, 자주 쓰는 조합을 저장하는 앱 페어 기능을 제공합니다.

먼저 결론: 가장 확실한 방법은 최근 앱 화면 → 앱 아이콘 누르기 → 분할 화면으로 열기 → 두 번째 앱 선택입니다. 메뉴가 없다면 앱이 멀티윈도우를 지원하는지부터 확인하세요. 기종·One UI 버전에 따라 메뉴 이름과 배치가 다를 수 있습니다.

확인 기준: 2026년 11월 4일. 삼성전자 공식 지원 문서의 공통 절차를 기준으로 작성했으며, 일부 메뉴는 모델·업데이트·통신사 설정에 따라 다릅니다.

1. 갤럭시 화면 분할하는 가장 쉬운 방법

  1. 함께 사용할 첫 번째 앱을 실행합니다. 예를 들어 삼성 인터넷을 엽니다.
  2. 하단의 최근 앱 버튼을 누르거나, 제스처 내비게이션이라면 화면 아래에서 올린 뒤 잠시 멈춰 최근 앱 목록을 엽니다.
  3. 최근 앱 카드 위쪽에 있는 앱 아이콘을 누릅니다. 앱 미리보기 전체를 누르는 것이 아닙니다.
  4. 분할 화면으로 열기 또는 이와 비슷한 이름의 메뉴를 선택합니다.
  5. 두 번째로 사용할 앱(예: 삼성 노트, 계산기)을 선택합니다.
  6. 두 앱 사이의 가운데 구분선을 위아래로 움직여 화면 비율을 조절합니다.

실용 예시: 인터넷 검색 결과를 위쪽에 놓고 삼성 노트를 아래쪽에 열면, 페이지를 계속 전환하지 않고 비교·메모할 수 있습니다. 모든 앱 조합이 지원되는 것은 아닙니다.

2. 두 손가락으로 바로 화면 나누기

One UI 6 이상 일부 갤럭시에서는 멀티윈도우 제스처를 켜서 더 빠르게 분할 화면으로 전환할 수 있습니다.

  1. 설정 → 유용한 기능 → 멀티윈도우로 들어갑니다.
  2. 분할 화면으로 전환하기 위해 밀기(메뉴 번역은 버전에 따라 다름)를 활성화합니다.
  3. 앱 사용 중 화면 아래쪽에서 두 손가락으로 위로 밀기를 시도합니다.
  4. 표시되는 앱 선택 영역에서 두 번째 앱을 고릅니다.

기기에 따라 화면 옆쪽에서 두 손가락으로 미는 방식을 지원하기도 합니다. 제스처가 반응하지 않으면 메뉴가 켜져 있는지 확인하고, 1번의 최근 앱 방식을 사용하세요. 모든 기기에 동일한 제스처가 제공되는 것은 아닙니다.

3. 분할 화면 대신 작은 창으로 여는 팝업 화면

팝업 화면은 두 앱을 위아래로 고정하지 않고, 한 앱을 작은 창으로 화면 위에 띄우는 기능입니다.

  1. 최근 앱 목록에서 원하는 앱 아이콘을 누릅니다.
  2. 팝업 화면으로 열기를 선택합니다.
  3. 팝업 상단을 잡고 움직여 위치를 변경합니다.
  4. 창 가장자리를 끌어 크기를 조절합니다.
  5. 창 위쪽의 제어 메뉴를 이용해 최소화·최대화·닫기를 실행할 수 있습니다.

일부 One UI에서는 설정 → 유용한 기능 → 멀티윈도우 → 팝업 화면으로 전환하기 위해 밀기를 켠 뒤 화면 위쪽 모서리에서 안쪽으로 미는 제스처도 사용할 수 있습니다.

4. 자주 쓰는 두 앱을 ‘앱 페어’로 저장하기

분할 화면을 자주 사용한다면 매번 두 앱을 고를 필요가 없도록 앱 페어(App pair)를 만들어 볼 수 있습니다.

  1. 원하는 두 앱을 분할 화면으로 엽니다.
  2. 두 앱 사이 구분선 가운데 점 또는 핸들을 누릅니다.
  3. 앱 페어에 추가 아이콘이 나타나면 선택합니다.
  4. 저장 가능한 위치(예: Edge 패널 또는 홈 화면)가 표시되면 원하는 곳을 선택합니다.

저장 위치와 아이콘은 모델·소프트웨어 버전에 따라 다릅니다. 해당 메뉴가 보이지 않는다고 해서 휴대전화가 고장 난 것은 아닙니다. 저장 지원 여부를 확인한 뒤, 지원되지 않으면 최근 앱이나 Edge 패널에서 두 앱을 직접 여는 방법을 사용하세요.

5. 분할 화면이 안 될 때 점검 순서

① ‘분할 화면으로 열기’ 메뉴 자체가 없다

일부 앱은 분할 화면 또는 팝업 화면을 지원하지 않습니다. 먼저 삼성 인터넷이나 삼성 노트 등 다른 지원 앱에서 동일한 메뉴가 나타나는지 비교하세요. 특정 앱에서만 보이지 않으면 앱 호환성 문제일 가능성이 큽니다. 모든 앱을 강제로 실행하도록 설정하는 방법은 안정성을 보장하지 않습니다.

② 두 번째 앱을 선택할 수 없다

두 번째 앱도 멀티윈도우를 지원해야 합니다. 다른 앱 조합으로 바꿔 보세요. 앱이나 시스템의 최신 업데이트가 있는지 확인할 수 있지만, 업데이트만으로 미지원 앱이 반드시 지원되지는 않습니다.

③ 두 손가락 제스처가 작동하지 않는다

설정 → 유용한 기능 → 멀티윈도우에서 해당 스위치가 켜져 있는지 확인하세요. One UI 버전과 기기 유형에 따라 제스처 방향이 다를 수 있으므로 최근 앱 버튼 방식으로 먼저 정상 작동 여부를 확인합니다.

④ 화면이 자꾸 작은 창으로 바뀐다

화면 상단 모서리에서 안쪽으로 미는 팝업 화면 제스처가 의도치 않게 작동했을 수 있습니다. 설정의 멀티윈도우 항목에서 팝업 전환 제스처만 끌 수 있습니다. 화면이 갑자기 분할되었다면 분할 화면 제스처도 함께 확인하세요.

⑤ 화면 비율을 바꾸기 어렵다

두 앱 사이 구분선을 잡고 이동해 보세요. 일부 앱은 최소 표시 크기 때문에 원하는 비율까지 줄어들지 않을 수 있습니다. 화면을 회전하거나 더 넓은 화면의 기기에서 시도하면 사용성이 달라질 수 있습니다.

⑥ 업데이트 이후 메뉴 위치가 달라졌다

설정 앱의 검색창에서 멀티윈도우를 검색하세요. 검색 결과가 없으면 유용한 기능 메뉴를 직접 확인하고, 최근 앱 목록에서 해당 앱 아이콘을 눌러 실행 항목이 있는지 점검합니다.

6. 분할 화면 종료 및 원래대로 되돌리기

  • 분할 화면 종료: 두 앱 사이 구분선을 한쪽 끝까지 끌어 남길 앱을 전체 화면으로 표시할 수 있습니다. 모델에 따라 홈 화면으로 돌아간 뒤 단일 앱을 다시 열 수도 있습니다.
  • 팝업 화면 종료: 창 상단 제어 메뉴에서 닫기(X) 또는 전체 화면 아이콘을 선택합니다.
  • 실수로 자꾸 열리는 경우: 설정 → 유용한 기능 → 멀티윈도우에서 분할·팝업 제스처 스위치를 꺼 두면 됩니다. 최근 앱에서 직접 선택하는 기능까지 없어지는 것은 아닙니다.

자주 묻는 질문

Q. 갤럭시 화면 분할은 앱 2개만 되나요?

일반적인 바 형태 스마트폰의 기본 분할 화면은 두 앱을 동시에 사용하는 방식입니다. 폴더블과 태블릿은 화면 크기와 모델에 따라 더 다양한 창 배치가 가능하므로 해당 기기의 공식 지원 안내를 확인하세요.

Q. 유튜브 화면만 작게 띄우는 것과 같은 기능인가요?

다릅니다. 유튜브 등에서 지원되는 PIP(Picture-in-Picture)는 동영상 창을 작게 띄우는 기능이고, 멀티윈도우 분할 화면은 두 개의 지원 앱을 하나의 화면 영역에 배치하는 기능입니다. 영상 PIP의 제공 여부는 앱·콘텐츠·이용 조건에 따라 달라질 수 있습니다.

Q. 카카오톡과 인터넷을 동시에 사용할 수 있나요?

사용 중인 카카오톡 버전과 기기에서 두 앱 모두 멀티윈도우를 지원한다면 가능합니다. 최근 앱에서 분할 메뉴가 제공되는지 먼저 확인하세요. 모델과 앱 업데이트에 따라 실제 지원 상태는 달라질 수 있습니다.

Q. 앱 페어 메뉴가 보이지 않습니다.

두 앱을 실제로 분할 화면으로 연 상태에서 가운데 구분선의 메뉴를 확인하세요. 저장 위치 옵션은 기기와 One UI에 따라 달라지며, 일부 조합에서는 표시되지 않을 수 있습니다.

핵심 정리

갤럭시 화면을 나누는 가장 안정적인 출발점은 최근 앱 → 앱 아이콘 → 분할 화면으로 열기입니다. 익숙해지면 두 손가락 제스처로 속도를 높이고, 작은 창이 필요할 때는 팝업 화면을 사용하면 됩니다. 메뉴가 보이지 않을 때는 휴대전화 전체 설정을 초기화하기보다 앱 자체의 분할 화면 지원 여부를 먼저 확인하는 편이 안전합니다.
