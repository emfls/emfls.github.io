맥북 저장 공간에 여유가 없다는 경고가 나타나거나 macOS 업데이트가 설치되지 않으면 가장 먼저 어떤 종류의 파일이 디스크를 차지하는지 확인해야 합니다. 특히 ‘시스템 데이터’가 수십 GB 이상으로 표시된다고 해서 해당 공간을 모두 지워도 된다는 뜻은 아닙니다.

Mac의 저장 공간에는 사진·동영상·문서·앱 외에 캐시, 로그, 가상 메모리(VM) 파일, 임시 파일, 앱 지원 파일, 로컬 스냅샷 등 다양한 데이터가 포함됩니다. Apple은 macOS가 필요할 때 안전하게 정리할 수 있는 일부 캐시와 로그를 자동으로 관리한다고 설명합니다.

이 글에서는 시스템 설정에서 용량 확인 → 큰 파일과 다운로드 정리 → 휴지통 점검 → iPhone 백업 확인 → iCloud 사진 최적화 → Time Machine 스냅샷 구분 순으로 정리합니다. 2026년 11월 기준 Apple 공식 지원 문서에 근거했으며, macOS 버전에 따라 화면과 메뉴가 다를 수 있습니다.

주의: 중요한 파일의 백업이 없는 상태에서 시스템 폴더나 사진 보관함을 무조건 삭제하지 마세요. 저장 공간 부족 문제를 해결하려다가 사진·문서·백업을 잃지 않는 것이 최우선입니다.

1. 증상별로 먼저 확인할 항목

나타나는 증상우선 확인할 원인가장 안전한 첫 조치
맥북 저장 공간이 가득 참문서·앱·다운로드·휴지통시스템 설정 → 일반 → 저장 공간
‘시스템 데이터’ 용량이 큼캐시·로그·VM·앱 지원 데이터 등일반 저장 공간 카테고리부터 분석
파일 삭제했는데 용량 변화가 적음휴지통에 남은 파일·저장 공간 재계산휴지통 및 저장 공간 표시 확인
동영상을 지웠는데 사진 용량이 그대로사진 보관함·최근 삭제된 항목·iCloud 동기화사진 앱의 보관함 상태 확인
iCloud를 켰는데 공간이 안 늘어남Mac에 원본이 계속 저장됨Mac 저장 공간 최적화 설정 점검
업데이트할 여유 공간이 없음설치 파일·기존 사용자 데이터큰 파일 정리 후 필요하면 안전 모드 고려
iPhone 백업이 많이 쌓임로컬 iPhone/iPad 백업저장 공간의 iOS 파일 및 Finder 백업 관리
Time Machine 스냅샷이 보임로컬 백업 스냅샷백업 상태 확인, 임의 삭제보다 자동 관리 우선

핵심: '저장 공간'의 카테고리는 분석을 위한 분류입니다. 모두 같은 방법으로 지우는 폴더가 아닙니다. 삭제하려는 항목이 사용자 파일인지, 사진 동기화 데이터인지, 운영체제가 관리하는 데이터인지 먼저 구분해야 합니다.

2. 저장 공간 확인하는 방법: macOS 최신 버전과 이전 버전

macOS Ventura 13 및 이후 버전

  1. 화면 왼쪽 위 Apple 메뉴()를 선택합니다.
  2. 시스템 설정을 엽니다.
  3. 일반 → 저장 공간으로 들어갑니다.
  4. 저장 공간 막대그래프의 응용 프로그램·문서·사진·시스템 데이터 등 항목을 확인합니다.
  5. 정보 버튼이 있는 카테고리를 열어 어떤 파일이 공간을 차지하는지 살펴봅니다.

macOS Monterey 및 이전 버전

Apple은 이전 macOS에서 Apple 메뉴 → 이 Mac에 관하여 → 저장 공간을 확인하도록 안내합니다. 버전에 따라 '관리' 버튼 또는 저장 공간 관리 화면으로 이동할 수 있습니다.

'저장 공간'과 Finder의 여유 공간이 다를 때

Apple은 여유 저장 공간(Free space)과 사용 가능한 저장 공간(Available space)이 다를 수 있다고 설명합니다.

  • 여유 저장 공간: 현재 물리적으로 비어 있는 공간
  • 사용 가능한 저장 공간: 여유 공간에 더해 시스템이 필요할 때 확보할 수 있는 삭제 가능한 저장 공간이 포함될 수 있음

따라서 저장 공간 그래프의 숫자가 다른 화면의 사용 가능 용량과 조금 다르다고 해서 곧바로 오류로 판단하지 마세요.

3. 가장 먼저 해야 할 일: 큰 파일 찾기

용량 부족일 때는 수십 KB의 캐시를 지우는 것보다 몇 GB짜리 설치 파일·동영상·압축 파일을 확인하는 편이 효과적일 수 있습니다.

macOS 저장 공간에서 큰 파일 확인

  1. 시스템 설정 → 일반 → 저장 공간을 엽니다.
  2. 문서 카테고리에 정보 버튼이 있다면 선택합니다.
  3. 대용량 파일(Large Files) 또는 파일 브라우저를 확인합니다.
  4. 파일 이름·크기·최근 사용 여부를 살펴봅니다.
  5. 정확히 무엇인지 아는 파일만 삭제하거나 다른 위치로 옮깁니다.

Apple은 문서 카테고리에서 대용량 파일을 빠르게 보고 크기·최근 접근 시각 등으로 정렬할 수 있다고 안내합니다.

확인 우선순위

  • 다운로드 폴더의 오래된 DMG·PKG 설치 파일
  • 사용하지 않는 ZIP 압축 파일
  • 편집 후 남은 동영상 원본과 임시 렌더 파일
  • 오래된 PDF·프레젠테이션·대용량 이미지
  • 외장 저장 장치로 옮긴 뒤 Mac에 복사본이 남아 있는 파일

위험한 방법: 이름이 낯설다고 'Library' 또는 'System' 폴더의 대용량 파일을 임의 삭제하는 것은 권하지 않습니다. 저장 공간 분석의 목표는 사용자가 내용을 확인하고 불필요하다고 판단할 수 있는 파일을 찾는 것입니다.

4. 다운로드 폴더 정리: 삭제하기 전에 꼭 확인할 것

다운로드 폴더에는 브라우저로 받은 PDF, 프로그램 설치 파일, 압축 파일, 이메일 첨부파일 등이 오래 쌓일 수 있습니다.

  1. Finder를 엽니다.
  2. 사이드바의 다운로드를 선택합니다.
  3. 목록 보기로 바꾸고 파일의 크기·수정 날짜 등을 확인합니다.
  4. 이미 설치가 끝났고 다시 필요하지 않은 설치 파일인지 확인합니다.
  5. 업무 자료·구매 영수증·인증서·설치용 라이선스 파일은 별도로 보관합니다.
  6. 필요 없는 파일을 휴지통으로 이동합니다.

다운로드 폴더에는 사용자의 파일이 들어 있습니다. 폴더를 통째로 비우는 방식은 권하지 않습니다. 외장하드로 파일을 옮겼다면 외장 장치에서 파일이 정상적으로 열리는지 확인한 뒤 Mac에 있는 사본을 정리하세요.

프로그램 설치 파일은 모두 지워도 되나요?

그렇지는 않습니다. 설치에 사용한 DMG는 더 이상 필요하지 않을 수 있지만, 일부 파일은 재설치·복구·오프라인 설치에 필요할 수 있습니다. 파일을 확인하고 재다운로드가 가능한지도 따져보세요.

5. 휴지통을 비웠는데도 용량이 부족한 이유

Mac에서 파일을 휴지통으로 옮겼다고 해서 즉시 저장 공간이 확보되는 것은 아닙니다. Apple에 따르면 휴지통의 파일은 비우기 전까지 Mac에 남아 있습니다.

휴지통 비우는 순서

  1. Dock의 휴지통을 엽니다.
  2. 삭제하려는 파일의 이름과 내용을 마지막으로 확인합니다.
  3. 비우기를 선택합니다.
  4. 경고 창에서 영구 삭제 여부를 확인합니다.
  5. 시스템 설정 → 일반 → 저장 공간에서 변화가 있는지 확인합니다.

중요: 휴지통 비우기는 영구 삭제 작업입니다. 복구가 필요할 수 있는 파일은 먼저 외장 디스크나 Time Machine에 백업하세요.

휴지통 30일 자동 비우기

Apple은 Finder → 설정 → 고급 → 휴지통에서 30일이 지난 항목 제거 기능을 제공합니다. 이를 켜면 오래된 휴지통 파일이 자동 삭제될 수 있습니다. 업무 자료를 자주 임시 보관하는 환경이라면 무조건 활성화하기보다 운영 방식에 맞춰 결정하세요.

6. '시스템 데이터'가 100GB라고 뜹니다. 직접 지워도 되나요?

시스템 데이터는 하나의 폴더가 아닙니다. Apple은 이 카테고리에 시스템 로그·캐시·가상 메모리(VM) 파일·임시 파일·서체·앱 지원 파일·플러그인과 기타 분류되지 않은 데이터가 포함된다고 설명합니다.

Apple의 저장 공간 설명은 시스템 데이터 카테고리에서 직접 파일을 골라 삭제할 수 없으며, macOS가 일부 콘텐츠를 관리한다고 명시합니다. 따라서 인터넷에서 발견한 '시스템 데이터 용량 50GB 즉시 삭제' 명령을 그대로 사용하면 안 됩니다.

권장하는 대응 순서

  1. 먼저 사용자가 명확히 아는 대용량 파일과 휴지통을 정리합니다.
  2. 응용 프로그램·사진·문서·iOS 파일 항목을 확인합니다.
  3. 실행 중인 작업을 저장하고 Mac을 정상적으로 재시작합니다.
  4. 저장 공간 그래프를 다시 확인합니다.
  5. Time Machine을 사용 중이면 로컬 스냅샷의 동작을 이해합니다.
  6. 계속 공간 부족 경고가 나온다면 Apple 공식 지원을 통해 진단합니다.

왜 시스템 데이터를 임의 삭제하면 위험한가요?

  • 응용 프로그램의 설정·지원 데이터가 포함될 수 있음
  • 운영체제가 사용하는 캐시·가상 메모리·시스템 리소스가 포함될 수 있음
  • 파일을 제거해도 macOS가 필요한 데이터를 다시 생성할 수 있음
  • 잘못된 삭제가 앱 오류나 사용자 데이터 손상으로 이어질 수 있음

삭제 금지 원칙: 정확한 역할을 모르는 /System, /Library, ~/Library 내부 파일을 터미널로 일괄 삭제하지 마세요.

7. iPhone·iPad 백업이 맥북 공간을 차지하는 경우

맥북을 이용해 iPhone 또는 iPad를 백업하는 경우 로컬 백업 파일이 Mac 저장 공간을 많이 차지할 수 있습니다. Apple은 저장 공간 카테고리의 iOS 파일에 iOS 기기 백업과 펌웨어가 포함된다고 안내합니다.

먼저 확인하기

  1. 시스템 설정 → 일반 → 저장 공간을 엽니다.
  2. iOS 파일(iOS Files) 항목이 표시되는지 확인합니다.
  3. 정보 버튼이 있다면 백업 및 관련 파일을 검토합니다.
  4. 최근의 중요한 기기 백업을 삭제하려는 것은 아닌지 확인합니다.

연결한 iPhone의 백업 관리

Finder에서 iPhone·iPad를 연결해 관리하는 경우, 기기를 선택해 일반(General) → 백업 관리(Manage Backups) 메뉴를 확인할 수 있습니다. 메뉴는 macOS와 기기 상태에 따라 다를 수 있습니다.

백업 날짜·대상 기기를 확인하고, 이미 사용하지 않는 기기의 오래된 백업인지 확실할 때만 삭제를 고려하세요.

중요: 로컬 iPhone 백업을 삭제하면 그 백업을 이용한 이전 기기 데이터 복원 수단도 사라집니다. 기기를 교체하거나 수리 예정이라면 백업 삭제에 특히 주의하세요. iCloud 백업과 Mac의 로컬 백업은 별도입니다.

8. iCloud 사진으로 맥북 용량 줄이기

사진과 동영상이 저장 공간을 많이 차지한다면 iCloud 사진의 'Mac 저장 공간 최적화' 기능을 검토할 수 있습니다.

Apple에 따르면 이 기능을 켜면 Mac에는 공간 절약형 사진·동영상 버전을 보관할 수 있으며, 전체 해상도 원본은 iCloud 사진에 저장됩니다. 다만 iCloud에 파일을 올리는 과정과 저장 공간 상태에 따라 실제 확보되는 용량에는 차이가 있습니다.

Mac 사진 앱에서 설정하는 방법

  1. Mac의 사진 앱을 엽니다.
  2. 메뉴 막대에서 사진 → 설정 → iCloud를 선택합니다.
  3. iCloud 사진이 활성화되어 있는지 확인합니다.
  4. Mac 저장 공간 최적화를 선택합니다.
  5. 사진 라이브러리의 동기화 상태를 확인합니다.

'원본을 이 Mac으로 다운로드'와 차이

설정의미
원본을 이 Mac으로 다운로드전체 해상도 원본을 Mac에도 저장

가장 중요한 주의사항: 사진 삭제는 동기화됩니다

iCloud 사진을 켠 상태에서 사진을 삭제하면 연결된 다른 Apple 기기의 사진에서도 삭제 내용이 반영됩니다. '맥북 용량만 줄이겠다'는 목적으로 사진 앱에서 사진 수백 개를 무작정 삭제하면 iPhone의 사진도 사라질 수 있습니다.

Apple은 iCloud 사진에서 삭제한 항목은 최근 삭제된 항목에서 30일 이내 복구할 수 있으며, 이후 영구 삭제된다고 안내합니다.

  • iCloud 사진은 백업을 완전히 대체하는 독립 보관소가 아닙니다.
  • 중요한 원본은 별도 드라이브에 백업하는 것이 안전합니다.
  • iCloud 저장 공간이 부족하면 동기화가 끝나지 않을 수 있습니다.
  • 최적화가 켜져 있다고 해서 모든 원본이 즉시 Mac에서 제거되는 것은 아닙니다.

9. iCloud Drive 파일을 지우는 것과 Mac에서 다운로드만 제거하는 것은 다릅니다

iCloud Drive를 사용하면 데스크탑·문서 폴더나 iCloud Drive 자체가 여러 기기에 동기화될 수 있습니다.

여기서 가장 중요한 것은 클라우드의 파일 삭제와 Mac에 내려받은 로컬 복사본만 제거하는 작업을 구별하는 것입니다.

iCloud에 안전하게 업로드됐는지 먼저 확인

  1. Finder → iCloud Drive로 이동합니다.
  2. 파일이 iCloud에 있음, 업로드 중, 업로드 대기 중 등 어떤 상태인지 확인합니다.
  3. 필요하면 Finder에서 보기 → 목록 → 보기 옵션 → iCloud 상태를 표시합니다.
  4. 중요한 파일은 iCloud.com에서 실제 접근되는지도 확인합니다.
  5. 로컬 공간을 확보할 때는 파일의 동기화·다운로드 상태를 이해하고 작업합니다.

Apple 공식 설명에 따르면 업로드 대기 중인 파일은 아직 iCloud에 완전히 보관되지 않은 상태일 수 있습니다. 그런 파일을 정리 목적으로 삭제하면 원본을 잃을 수 있습니다.

파일 삭제의 위험

iCloud Drive에서 파일을 일반적으로 삭제하면 다른 기기의 동기화된 파일에도 영향을 줄 수 있습니다. 따라서 '맥북 공간만 확보'가 목적이라면 무작정 삭제하지 말고, 기기에서 로컬 다운로드만 관리하는 지원 기능이 있는지 확인하세요.

10. Time Machine 로컬 스냅샷: 용량을 차지하는데 지워야 하나요?

Time Machine 로컬 스냅샷은 Mac에 저장된 파일의 과거 버전을 복구할 수 있도록 만들어진 로컬 기록입니다. Apple은 APFS 볼륨에서, 자동 백업이 설정되어 있을 때 로컬 스냅샷을 사용할 수 있다고 설명합니다.

Apple 공식 문서에 따르면 로컬 스냅샷은 보통 최대 24시간 동안 또는 디스크에 공간이 필요해질 때까지 보관되며, macOS가 필요에 따라 자동 제거합니다.

확인할 수 있는 방법

  1. 시스템 설정 → 일반 → Time Machine에서 백업 설정을 확인합니다.
  2. Time Machine 백업 디스크가 있다면 최근 백업 상태를 확인합니다.
  3. 스냅샷을 더 자세히 보려면 디스크 유틸리티를 엽니다.
  4. 보기 → APFS 스냅샷 보기를 선택합니다.
  5. 관련 APFS 볼륨을 선택하면 목록이 나타날 수 있습니다.

로컬 스냅샷이 발견됐다면?

  • 이것만으로 파일이 손상됐거나 Mac이 고장 났다고 볼 수 없습니다.
  • macOS가 공간이 필요할 때 자동으로 정리할 수 있습니다.
  • Time Machine 백업 디스크의 실제 백업과는 별개입니다.
  • 스냅샷을 없애는 명령을 인터넷에서 복사해 무작정 실행하지 마세요.
  • 중요한 데이터의 복구가 필요할 수 있으므로 독립적인 외장 백업을 유지하세요.

Apple은 로컬 스냅샷이 존재하더라도 외장 디스크 등에 별도의 일반 백업을 수행하도록 권장합니다.

11. 저장 공간이 부족해 macOS 업데이트가 안 될 때

macOS 업데이트를 다운로드하거나 설치하는 동안 일시적으로 추가 공간이 필요할 수 있습니다.

추천 점검 순서

  1. 시스템 설정 → 일반 → 저장 공간에서 실제 사용 가능한 공간을 확인합니다.
  2. 다운로드의 불필요한 대용량 파일을 정리합니다.
  3. 휴지통을 확인하고 필요한 백업을 만든 뒤 비웁니다.
  4. 오래된 앱 또는 더 이상 사용하지 않는 파일을 검토합니다.
  5. 업데이트를 다시 시도합니다.
  6. 그래도 일시적 여유 공간이 부족하면 안전 모드(Safe Mode)가 도움이 될 수 있습니다.

Apple 공식 지원은 Mac을 안전 모드로 시동하면 일부 시스템 캐시를 정리할 수 있어 업데이트 등 일시적인 용량 부족 상황에 도움이 될 수 있다고 안내합니다.

안전 모드는 모든 기기에서 같은 방법으로 진입하나요?

아닙니다. Apple silicon(M 시리즈) Mac과 Intel Mac의 진입 방식이 다릅니다. 현재 사용 중인 Mac의 프로세서를 먼저 확인하고 공식 안내에 따라 진입하세요. 단순 저장 공간 부족을 이유로 시스템 폴더를 강제로 삭제하는 것보다 안전한 선택일 수 있습니다.

12. Mac에 설치한 앱은 어떻게 정리하나요?

사용하지 않는 앱도 저장 공간을 차지하지만, 앱마다 삭제해야 할 파일이 다를 수 있습니다.

  1. 시스템 설정 → 일반 → 저장 공간을 엽니다.
  2. 응용 프로그램 카테고리를 선택합니다.
  3. 사용하지 않는 앱의 이름과 크기를 확인합니다.
  4. 앱이 중요한 파일·프로젝트·플러그인을 관리하고 있는지 검토합니다.
  5. 앱에서 전용 제거 프로그램을 제공한다면 제작사 공식 안내를 따릅니다.
  6. 안전하게 제거된 뒤 확보된 용량을 확인합니다.

주의: 동영상 편집 프로그램·음악 제작 앱·개발 도구는 프로젝트 파일이나 라이브러리를 별도로 보관할 수 있습니다. 응용 프로그램 아이콘만 삭제해도 모든 데이터가 제거되는 것은 아니며, 반대로 앱 지원 폴더를 임의로 지우면 프로젝트에 문제가 생길 수 있습니다.

Apple은 저장 공간 관리 화면의 응용 프로그램 카테고리에서 앱을 확인하고 필요한 경우 제거할 수 있다고 안내합니다.

13. 디스크를 정리하는 무료 프로그램을 반드시 설치해야 하나요?

아닙니다. Mac에는 기본적으로 저장 공간 분석과 파일 삭제, iCloud 최적화, 휴지통 관리 기능이 포함돼 있습니다.

어떤 타사 앱은 파일 목록을 보기 쉽게 정리해 줄 수 있지만, 모든 시스템 데이터가 삭제 가능한 쓰레기 파일인 것처럼 안내하거나 관리자 비밀번호를 요구하는 도구는 신중히 검토해야 합니다.

설치 전 판단 기준

  • 앱의 배포 주체와 공식 웹사이트가 확인되는가?
  • 삭제할 파일 경로와 범위를 미리 보여주는가?
  • 자동 정리 전에 백업 및 제외 목록을 확인할 수 있는가?
  • 시스템 파일 접근·전체 디스크 접근 권한을 왜 요청하는가?
  • 지운 파일을 복구할 수 있는 방법이 있는가?

저장 공간 부족을 해결하려고 개인정보·파일 접근 권한이 과도한 앱을 설치할 필요는 없습니다. 처음에는 Apple 기본 기능만으로 분석하는 것을 권장합니다.

14. 정리했는데 저장 공간 수치가 그대로라면

파일을 삭제했는데 표시가 즉시 달라지지 않거나, '사용 가능' 공간과 저장 공간 카테고리 합계가 일치하지 않아 보일 수 있습니다.

순서대로 확인

  1. 삭제한 파일이 휴지통에 남아 있는지 확인합니다.
  2. 같은 파일이 사진 보관함·동영상 편집 프로젝트·다운로드 폴더 등에 다른 복사본으로 남아 있는지 확인합니다.
  3. iCloud 사진·Drive가 동기화 중이라면 상태가 완료됐는지 점검합니다.
  4. 중요한 작업을 저장한 뒤 Mac을 정상 재시작합니다.
  5. 시스템 설정 → 일반 → 저장 공간을 다시 열어 사용 가능 공간을 확인합니다.
  6. 문제가 지속되면 디스크 유틸리티·Apple 공식 지원을 통해 상태를 확인합니다.

Apple은 저장 공간 화면에 카테고리별 사용량을 보여주고, 필요할 때 macOS가 제거 가능한 캐시 등을 자동 관리한다고 설명합니다. 시스템 데이터 수치가 변동한다는 사실만으로 파일을 임의 삭제할 근거는 아닙니다.

16. 자주 묻는 질문(FAQ)

Q1. 맥북 저장 공간은 어디서 확인하나요?

macOS Ventura 13 이후라면 Apple 메뉴 → 시스템 설정 → 일반 → 저장 공간에서 확인합니다. 이전 macOS는 이 Mac에 관하여 → 저장 공간 경로를 사용합니다.

Q2. 맥북 시스템 데이터가 100GB인데 지워도 되나요?

시스템 데이터 전체를 임의로 삭제하면 안 됩니다. Apple은 캐시·로그·VM·임시 파일·앱 지원 데이터 등이 포함된다고 설명하며 macOS가 일부 항목을 자동 관리한다고 안내합니다.

Q3. 맥북 저장 공간을 가장 빨리 확보하려면 무엇부터 해야 하나요?

대용량 사용자 파일 → 다운로드 → 휴지통 → 사용하지 않는 앱 → 오래된 iPhone 백업 순으로 확인하는 것이 좋습니다. 실제 어떤 카테고리가 큰지는 각 Mac의 사용 방식에 따라 다릅니다.

Q4. 휴지통으로 옮기기만 하면 용량이 늘어나나요?

아닙니다. Apple에 따르면 휴지통으로 이동한 항목은 휴지통을 비울 때까지 Mac에 남아 있습니다. 비우기는 영구 삭제이므로 내용을 확인해야 합니다.

Q5. iCloud 사진을 켜면 Mac 용량이 자동으로 줄어드나요?

항상 즉시 줄어드는 것은 아닙니다. 사진 앱 → 설정 → iCloud → Mac 저장 공간 최적화를 사용하면 Mac의 저장 공간을 절약할 수 있으며, 원본은 iCloud 사진에 보관됩니다. 저장 상태와 네트워크에 따라 효과가 달라집니다.

Q6. 맥북에서 사진을 삭제하면 아이폰에서도 삭제되나요?

같은 Apple 계정에서 iCloud 사진 동기화가 켜져 있다면, 한 기기에서의 사진 삭제가 다른 기기에도 반영됩니다. Mac에서만 용량을 줄이려면 사진을 무작정 삭제하는 대신 Mac 저장 공간 최적화를 먼저 검토하세요.

Q7. Time Machine 스냅샷은 왜 생기나요?

APFS 기반 Mac에서 로컬 스냅샷은 파일의 이전 상태를 복구하는 데 활용될 수 있습니다. Apple은 로컬 스냅샷이 보통 24시간 이내 또는 저장 공간이 필요할 때까지 남고 자동으로 제거된다고 안내합니다.

Q8. iPhone 백업을 삭제하면 어떤 문제가 생기나요?

삭제된 로컬 백업을 사용한 과거 iPhone 상태 복원이 불가능해질 수 있습니다. 기기 교체 전이나 수리 예정이라면 필요한 백업인지 먼저 확인하세요.

Q9. 안전 모드는 왜 저장 공간 확보에 도움이 되나요?

Apple은 안전 모드에서 일부 시스템 캐시가 정리될 수 있어 macOS 업데이트에 필요한 일시적 공간을 확보할 수 있다고 설명합니다. 하지만 모든 저장 공간 문제를 해결하는 기능은 아닙니다.

Q10. 캐시 폴더를 터미널로 전부 삭제해도 되나요?

권장하지 않습니다. 어떤 캐시와 앱 지원 파일은 다시 생성되거나 다른 기능에 영향을 줄 수 있습니다. 파일 역할을 모르면서 rm -rf 같은 일괄 삭제 명령을 실행하지 마세요.

Q11. Mac에 '사용 가능' 20GB라고 나오는데 다른 화면에는 10GB로 보입니다.

일부 화면에서 물리적 여유 공간과 삭제 가능한 캐시를 포함한 사용 가능한 저장 공간을 다르게 표시할 수 있습니다. Apple은 두 개념을 별도로 설명합니다.

Q12. 저장 공간 최적화를 켰는데 iCloud 요금이 발생하나요?

iCloud에 보관하는 파일은 iCloud 저장 공간 요금제의 용량을 사용합니다. 기본 제공 공간을 넘어가면 유료 용량이 필요할 수 있으므로 iCloud 설정에서 현재 사용량과 상품 조건을 확인하세요.

17. 최종 체크리스트

  • ☐ 시스템 설정 → 일반 → 저장 공간에서 원인 카테고리를 확인했다.
  • ☐ 실제 여유 공간과 사용 가능 공간을 구분했다.
  • ☐ 문서 카테고리에서 대용량 사용자 파일을 찾았다.
  • ☐ 다운로드 폴더의 불필요한 DMG·ZIP·동영상을 확인했다.
  • ☐ 삭제할 자료는 백업 후 휴지통으로 옮겼다.
  • ☐ 휴지통 비우기가 영구 삭제임을 알고 있다.
  • ☐ iOS 파일의 오래된 백업이 있는지 점검했다.
  • ☐ iCloud 사진의 Mac 저장 공간 최적화 여부를 확인했다.
  • ☐ iCloud 사진 삭제가 다른 기기에 동기화된다는 사실을 이해했다.
  • ☐ iCloud Drive에서 업로드 완료·로컬 다운로드 상태를 확인했다.
  • ☐ Time Machine 스냅샷과 실제 외장 백업을 구별했다.
  • ☐ 시스템 데이터 폴더를 임의로 일괄 삭제하지 않았다.
  • ☐ 업데이트 용량 문제라면 필요 시 안전 모드를 검토했다.
  • ☐ 저장 공간이 확보된 뒤 중요한 파일이 정상적으로 열리는지 확인했다.

정리: 맥북 저장 공간 부족은 큰 파일·다운로드·휴지통·로컬 기기 백업을 확인하는 것부터 시작하는 편이 안전합니다. ‘시스템 데이터’가 커 보여도 그 자체를 하나의 삭제 대상처럼 다뤄선 안 됩니다. 사진이 많다면 iCloud 사진 최적화를 검토하고, Time Machine 로컬 스냅샷은 Apple이 설명하는 자동 관리 방식과 복구 목적을 이해한 뒤 판단하세요.
