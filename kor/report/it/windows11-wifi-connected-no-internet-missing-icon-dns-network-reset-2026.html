노트북에서 와이파이는 연결됐는데 **'인터넷 없음'**이 표시되거나, Windows 11 작업 표시줄에서 Wi-Fi 아이콘 자체가 사라져 당황한 적 있나요? 같은 집에서 스마트폰 인터넷은 멀쩡한데 컴퓨터만 안 될 수도 있고, 반대로 휴대전화까지 모두 연결되지 않는 경우도 있습니다.

이럴 때 바로 '네트워크 초기화'를 누르거나 무선랜 드라이버부터 삭제하는 것은 좋은 순서가 아닙니다. 문제가 PC에만 있는지, 공유기·회선에도 있는지 먼저 구분하면 불필요하게 설정을 잃지 않고 해결할 가능성이 높습니다.

이 글은 2026년 10월 24일 기준 Microsoft 공식 Windows 고객센터의 Wi-Fi 연결 문제 해결, 인터넷 없음 진단, 무선 네트워크 보고서, 장치 관리자 및 네트워크 초기화 안내를 바탕으로 작성했습니다. 윈도우11을 중심으로 설명하며, 일부 기능은 Windows 10에도 적용될 수 있지만 설정 메뉴 경로는 다릅니다.

공식 출처: Microsoft - Windows에서 Wi-Fi 연결 문제 해결

1. '와이파이 연결됨'과 '인터넷 연결됨'은 다릅니다

Windows가 Wi-Fi 네트워크에 연결됐다고 표시해도 공유기까지 무선으로 연결된 상태일 뿐 실제 인터넷 접속이 성공했다는 뜻은 아닐 수 있습니다.

Microsoft는 PC가 로컬 네트워크에 연결되더라도 인터넷의 서버에 접속하지 못하면 **'인터넷 없음' 또는 '제한된 연결'**처럼 표시될 수 있다고 설명합니다. 연결 상태를 확인하기 위해 Windows가 작은 HTTP 요청을 보내는 진단도 사용합니다.

'연결됨, 인터넷 없음'일 때

같은 Wi-Fi에 연결된 휴대전화로 정상적인 웹사이트를 열어 보세요. 휴대전화에서도 안 된다면 공유기나 인터넷 회선 문제일 가능성이 높아집니다. 반면 스마트폰은 되고 노트북만 안 된다면 PC의 Wi-Fi 어댑터·설정·드라이버를 점검할 필요가 있습니다.

Wi-Fi 아이콘은 정상인데 브라우저만 안 될 때

인터넷 연결 자체보다 특정 사이트, 브라우저, 프록시, VPN 또는 방화벽 문제일 수 있습니다. Edge와 Chrome에서 같은 문제가 나타나는지, 다른 앱도 연결되지 않는지 확인하세요.

연결 상태 표시가 완벽한 판정은 아닙니다

Windows의 인터넷 상태 판단은 진단용 서버에 접속하는 방식의 영향을 받을 수 있습니다. 조직 네트워크·방화벽 환경에서는 실제 일부 인터넷이 되더라도 상태 표시가 제한적으로 나타날 수 있으므로 실제 웹사이트 연결과 여러 앱의 상태를 함께 확인해야 합니다.

공식 출처: Microsoft - 인터넷 없음 아이콘의 의미

2. 윈도우11에서 Wi-Fi 켜기·비행기 모드 확인

먼저 가장 간단한 설정부터 확인합니다.

빠른 설정에서 무선 연결 상태 확인

  1. 작업 표시줄 오른쪽의 네트워크·소리·배터리 아이콘 영역을 누릅니다.
  2. 빠른 설정이 열리면 Wi-Fi가 켜져 있는지 확인합니다.
  3. Wi-Fi 연결 관리 버튼으로 주변 무선 네트워크 목록을 엽니다.
  4. 본인이 사용하는 공유기 이름(SSID)을 선택합니다.
  5. 필요한 경우 비밀번호를 입력하고 연결을 누릅니다.

Microsoft는 네트워크가 목록에 표시되지 않을 때 네트워크 목록 새로고침 기능을 제공할 수 있다고 안내합니다.

비행기 모드 끄기

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 네트워크 및 인터넷 → 비행기 모드로 이동합니다.
  3. 비행기 모드가 꺼져 있는지 확인합니다.
  4. Wi-Fi를 다시 켜고 네트워크에 연결해 봅니다.

일부 노트북에는 무선 기능을 켜고 끄는 물리적 스위치 또는 기능 키가 있습니다. Wi-Fi 옵션이 보이지 않는다면 제조사 설명서를 확인하세요.

Windows 11 문제 해결사 실행

Microsoft는 Windows 11에서 도움말 보기(Get Help) 앱의 자동 네트워크·인터넷 문제 해결사부터 실행하도록 안내합니다.

  1. 시작 메뉴에서 도움말 보기를 검색합니다.
  2. 앱을 실행한 뒤 네트워크 또는 인터넷 연결 문제 해결 항목을 찾습니다.
  3. 자동 진단을 실행하고 표시되는 단계를 따릅니다.
  4. 결과에 오류 코드나 해결 제안이 나타나는지 확인합니다.

Windows 10의 과거 '설정 → 상태 → 네트워크 문제 해결사' 경로를 Windows 11의 현재 경로로 그대로 안내하는 글도 있으니 실제 운영체제에 맞는 메뉴를 사용하세요.

공식 출처: Microsoft - Windows 11 Wi-Fi 연결과 문제 해결사, Microsoft - Wi-Fi 연결 점검

3. 저장된 와이파이를 삭제하고 다시 연결하는 방법

비밀번호가 바뀌었거나 공유기를 교체한 뒤 예전에 저장된 Wi-Fi 프로필 때문에 접속이 안 될 수 있습니다. 이럴 때는 해당 네트워크만 잊어버리고 다시 연결해 보세요.

Windows 11 '알려진 네트워크 관리' 사용하기

  1. 설정 → 네트워크 및 인터넷 → Wi-Fi로 이동합니다.
  2. 알려진 네트워크 관리를 선택합니다.
  3. 문제가 있는 네트워크 이름을 찾습니다.
  4. **삭제(잊어버리기)**를 선택합니다.
  5. 작업 표시줄의 Wi-Fi 목록으로 돌아갑니다.
  6. 해당 네트워크를 다시 선택합니다.
  7. 정확한 Wi-Fi 비밀번호를 입력해 연결합니다.

이는 PC에 저장된 해당 네트워크의 프로필을 삭제하는 작업입니다. 공유기 자체를 공장 초기화하는 것과는 다릅니다.

다시 연결할 때 확인할 항목

  • SSID가 비슷한 이웃집 또는 게스트 네트워크를 선택하지 않았나요?
  • 공유기 비밀번호가 최근 변경되지 않았나요?
  • 대소문자·특수문자를 정확하게 입력했나요?
  • 회사·학교 Wi-Fi라면 별도 계정·인증서 로그인 방식이 필요한가요?

비밀번호를 확인하지 못했다면 저장된 네트워크를 삭제하기 전에 먼저 알아두세요. 재연결할 때 암호를 다시 입력해야 합니다.

공식 출처: Microsoft - Wi-Fi 네트워크를 잊어버리고 재연결

4. 공유기·모뎀 재시작: 집 안 모든 기기가 안 될 때

스마트폰과 태블릿까지 같은 Wi-Fi에서 인터넷을 사용하지 못한다면 컴퓨터의 네트워크 설정을 초기화하기 전에 공유기와 인터넷 모뎀 상태를 확인하세요.

공유기 재시작 순서

  1. 다른 가족이나 동료가 인터넷을 사용 중인지 확인하고 연결이 잠시 끊긴다고 알립니다.
  2. 공유기의 전원 케이블을 분리합니다.
  3. 별도 인터넷 모뎀을 사용한다면 모뎀의 전원도 분리합니다.
  4. 최소 30초 정도 기다립니다.
  5. 모뎀부터 다시 연결하고 상태 표시등이 안정될 때까지 기다립니다.
  6. 공유기 전원을 다시 연결합니다.
  7. 몇 분 동안 연결 상태가 정상화되는지 확인합니다.
  8. 스마트폰과 Windows 노트북에서 각각 인터넷 접속을 시험합니다.

Microsoft는 모뎀과 공유기의 전원 연결을 다시 구성하면 인터넷 서비스 공급자(ISP)와 연결을 새로 만들 수 있다고 안내합니다. 단, 공유기와 모뎀이 하나로 합쳐진 장비라면 해당 장비의 전원만 재시작하면 됩니다.

재부팅과 공장 초기화는 구분해야 합니다

전원 케이블을 뺐다가 다시 연결하는 작업과 기기 뒤쪽의 RESET 버튼을 길게 눌러 공장 초기화하는 작업은 다릅니다.

공장 초기화는 Wi-Fi 비밀번호, 포트 설정, 통신사 등록 정보 등 공유기 설정을 지울 수 있습니다. 통신사에서 설치한 임대 장비이거나 관리자 비밀번호를 모른다면 공장 초기화 버튼은 임의로 누르지 마세요.

다른 기기까지 인터넷이 안 된다면

스마트폰의 Wi-Fi를 잠시 끄고 모바일 데이터로 통신사 장애 안내를 확인하거나 인터넷 서비스 공급자 고객센터에 회선 상태를 문의하세요. 공유기의 인터넷(WAN) 표시등이 꺼져 있거나 장애가 반복된다면 ISP 또는 장비 문제일 수 있습니다.

5. 다른 Wi-Fi·휴대전화 핫스팟으로 PC 문제인지 구분하기

같은 Wi-Fi에 스마트폰은 잘 연결되는데 노트북만 인터넷이 안 된다면, 다른 네트워크로 노트북을 연결해 보는 비교 테스트가 도움이 됩니다.

권장 비교 방법

  1. 휴대전화가 현재 모바일 데이터를 사용할 수 있는지 확인합니다.
  2. 데이터 요금제에서 핫스팟 사용이 가능한지 확인합니다.
  3. 본인 휴대전화의 개인용 핫스팟 또는 모바일 핫스팟을 켭니다.
  4. Windows 11 노트북에서 그 핫스팟 네트워크를 선택합니다.
  5. 정상 웹사이트 두세 곳이 열리는지 테스트합니다.
  6. 시험을 마친 뒤 요금 발생을 막기 위해 핫스팟을 끕니다.

결과 해석

  • 집 Wi-Fi는 안 되지만 핫스팟은 됨: 집 공유기·ISP·기존 Wi-Fi 프로필 문제를 우선 점검
  • 집 Wi-Fi와 핫스팟 모두 안 됨: PC 무선 어댑터·드라이버·VPN·네트워크 설정 문제를 점검
  • 집에서는 여러 기기 모두 안 됨: 공유기·모뎀·회선 문제를 우선 확인
  • Wi-Fi 자체를 켤 수 없음: 하드웨어 스위치·드라이버·Windows 서비스 가능성 점검

이 결과는 원인 범위를 좁히는 진단이지 하드웨어 고장이나 통신사 문제를 단독으로 확정하는 검사는 아닙니다. 예를 들어 특정 핫스팟의 주파수 설정과 노트북의 무선랜 호환성이 맞지 않아 핫스팟 연결까지 실패할 수도 있습니다.

데이터 요금 주의

노트북이 핫스팟에 연결되면 Windows 업데이트·클라우드 동기화 등의 활동으로 모바일 데이터가 예상보다 많이 사용될 수 있습니다. 필요하면 Windows의 데이터 통신 연결로 설정을 확인하고 짧게 시험하세요.

6. 인터넷 없음일 때 IP 주소 확인: 169.254.x.x는 무엇인가요?

Windows가 무선 공유기에 연결됐지만 정상적인 IP 주소를 할당받지 못하면 인터넷 사용이 어려울 수 있습니다. Microsoft는 169.254로 시작하는 IPv4 주소가 표시되는 경우 공유기로부터 주소를 가져오지 못한 상황일 수 있다고 안내합니다.

내 IP 주소와 기본 게이트웨이 확인

  1. 작업 표시줄 검색에서 명령 프롬프트를 찾아 실행합니다.
  2. 다음 명령을 입력하고 Enter 키를 누릅니다.
ipconfig
  1. 출력 결과에서 무선 LAN 어댑터 Wi-Fi 또는 사용 중인 무선 네트워크를 찾습니다.
  2. IPv4 주소, 서브넷 마스크, 기본 게이트웨이를 확인합니다.
  3. IPv4 주소가 169.254.x.x 형태인지 살펴봅니다.

169.254 주소가 나타난다면?

이런 주소는 일반적인 가정용 공유기에서 자동 IP 주소를 할당받지 못할 때 Windows가 자체적으로 부여하는 주소일 수 있습니다. 이 경우 공유기의 DHCP 기능, 무선 연결 상태, IP 자동 할당 설정을 점검해야 합니다.

다만 169.254가 보인다는 사실만으로 무조건 공유기 고장이라고 단정하지 마세요. 현재 사용 중인 네트워크 어댑터와 관련된 주소를 확인해야 하고, 여러 어댑터가 있다면 사용하지 않는 장치의 값과 혼동할 수 있습니다.

회사·학교의 고정 IP 환경이면 다릅니다

회사나 연구실, 일부 업무용 네트워크는 고정 IP 주소를 사용합니다. 이 환경에서 임의로 IP를 자동으로 바꾸거나 네트워크 설정을 초기화하면 사내 시스템 접근이 끊길 수 있습니다.

관리자가 지정한 IP·DNS가 있다면 해당 값을 기록한 뒤 담당자에게 문의하세요. 공용 네트워크에도 허가 없는 주소 변경을 하지 않는 것이 좋습니다.

공식 출처: Microsoft - 인터넷 없음과 IP 주소 진단, Microsoft Learn - ipconfig 명령

7. 기본 게이트웨이 Ping 테스트로 공유기 연결 확인

IP 주소를 확인했다면 노트북에서 공유기까지 통신이 되는지 확인할 수 있습니다. Microsoft는 기본 게이트웨이 주소로 Ping 테스트하는 방법을 공식적으로 안내합니다.

기본 게이트웨이 확인

  1. 명령 프롬프트를 엽니다.
  2. ipconfig를 입력합니다.
  3. 현재 Wi-Fi 어댑터의 기본 게이트웨이 주소를 찾습니다.
  4. 예를 들어 192.168.1.1이라고 표시된다면 다음을 실행합니다.
ping 192.168.1.1

위 주소는 예시입니다. 실제 PC에 표시되는 기본 게이트웨이 IP를 입력하세요.

결과를 어떻게 해석하나요?

  • Reply(응답)와 전송·수신 패킷 결과가 정상: PC와 공유기 사이의 기본 통신은 가능할 수 있음
  • Request timed out(요청 시간 초과) 또는 응답 없음: 무선 신호, 게이트웨이 접근, 방화벽 등의 원인 점검 필요
  • 기본 게이트웨이 주소 자체가 없음: IP 할당·네트워크 연결 설정부터 재확인

Ping 응답이 된다는 것만으로 인터넷이 정상이라는 뜻은 아닙니다. 공유기까지는 통신하지만 모뎀·통신사 외부망 문제로 인터넷이 끊겼을 수도 있습니다.

또한 일부 네트워크는 ICMP(Ping) 응답을 차단할 수 있으므로 Ping 실패만으로 공유기 불량을 확정할 수 없습니다. 회사·학교 네트워크라면 관리자의 정책도 확인해야 합니다.

공식 출처: Microsoft - Wi-Fi 라우터 Ping 테스트

8. DNS 오류 의심될 때: 캐시 초기화와 IP 주소 갱신

웹사이트 주소를 입력하면 도메인을 IP 주소로 찾아 주는 DNS 과정이 필요합니다. 이름으로 사이트를 찾는 데만 문제가 있다면 DNS 설정이나 캐시를 확인할 수 있습니다.

Microsoft는 Windows 네트워크 문제 해결 단계로 TCP/IP 스택 재설정, IP 주소 해제·갱신, DNS 확인자 캐시 초기화 명령을 안내합니다.

관리자 권한으로 명령 프롬프트 열기

  1. 작업 표시줄 검색에서 cmd 또는 명령 프롬프트를 입력합니다.
  2. 결과를 마우스 오른쪽 버튼으로 눌러 관리자 권한으로 실행합니다.
  3. 사용자 계정 컨트롤 안내가 나오면 본인이 관리자 권한을 가진 PC인지 확인합니다.
  4. 아래 명령을 한 줄씩 입력한 후 Enter 키를 누릅니다.
netsh winsock reset
netsh int ip reset
ipconfig /release
ipconfig /renew
ipconfig /flushdns

Microsoft 공식 Wi-Fi 문제 해결 문서에 제시된 순서입니다. 명령이 실행되는 동안 연결이 일시적으로 끊길 수 있고, winsock reset 등을 적용하려면 PC 재시작이 필요할 수 있습니다.

각 명령의 역할

명령역할
netsh winsock resetWindows 네트워크 소켓 구성 재설정
netsh int ip resetTCP/IP 관련 설정 재설정
ipconfig /releaseDHCP가 할당한 IP 주소 해제
ipconfig /renewDHCP IP 주소 다시 요청
ipconfig /flushdns로컬 DNS 확인자 캐시 비우기

ipconfig /release와 /renew는 DHCP 자동 IP 환경을 전제로 한 명령입니다. 회사·학교의 고정 IP, 맞춤형 VPN, 원격 데스크톱으로 접속한 업무 PC에는 관리자 확인 없이 실행하지 마세요.

DNS 서버 주소를 무작정 변경해도 될까요?

DNS가 문제라고 확정하지 않은 상태에서 임의로 알 수 없는 무료 DNS 주소를 입력하면 개인정보 보호와 접속 안정성에 영향을 줄 수 있습니다.

먼저 ipconfig /all로 실제 DNS 서버가 설정돼 있는지 확인하고, 회사·학교는 해당 관리자가 지정한 설정을 유지하세요. 가정용 PC에서도 공유기·통신사 DNS 오류가 의심될 때에만 신뢰할 수 있는 공식 안내를 따라 변경하는 것이 좋습니다.

공식 출처: Microsoft - 네트워크 명령으로 Wi-Fi 연결 복구, Microsoft Learn - ipconfig, Microsoft Learn - netsh winsock

9. Wi-Fi 아이콘이 사라졌다면: 무선 어댑터와 WLAN 서비스 확인

Windows 11의 빠른 설정에서 Wi-Fi 버튼 자체가 없거나 무선 네트워크 목록이 비어 있다면 단순 인터넷 회선보다 무선 네트워크 어댑터가 Windows에 정상 인식되는지부터 확인해야 합니다.

장치 관리자에서 Wi-Fi 어댑터 찾기

  1. 시작 버튼을 마우스 오른쪽 버튼으로 누릅니다.
  2. 장치 관리자를 선택합니다.
  3. 네트워크 어댑터 항목을 펼칩니다.
  4. Wi-Fi, Wireless, WLAN 또는 무선 어댑터 제조사 이름이 포함된 항목을 찾습니다.
  5. 어댑터가 사용 안 함 상태라면 마우스 오른쪽 버튼을 누르고 디바이스 사용을 선택합니다.
  6. 느낌표나 오류 코드가 있는지 확인합니다.

장치 관리자에 무선랜 어댑터 자체가 전혀 표시되지 않는다면 드라이버가 설치되지 않았거나 Windows가 하드웨어를 감지하지 못하는 상태일 수 있습니다. 이 경우 제조사 공식 드라이버 또는 하드웨어 점검이 필요할 수 있습니다.

WLAN 자동 구성 서비스 확인

Microsoft는 Wi-Fi 옵션이 없을 때 WLAN AutoConfig(WLAN 자동 구성) 서비스를 확인하도록 안내합니다.

  1. Windows 키 + R을 누릅니다.
  2. 실행 창에 services.msc를 입력합니다.
  3. 서비스 목록에서 WLAN AutoConfig / WLAN 자동 구성을 찾습니다.
  4. 서비스가 중지돼 있다면 정책·관리자 설정을 확인한 뒤 시작 또는 다시 시작합니다.
  5. Wi-Fi 목록이 다시 나타나는지 확인합니다.

회사·학교에서 관리하는 PC에서는 서비스 설정을 임의 변경하지 마세요. 조직에서 무선랜 사용을 제한했을 수 있습니다.

하드웨어 스위치·기능 키도 확인

노트북에 따라 Fn 키 조합이나 전용 무선 버튼으로 Wi-Fi를 끌 수 있습니다. 기종에 따라 작동 방식이 다르므로 키캡의 무선 신호 아이콘과 제조사 설명서를 확인하세요.

10. 무선랜 드라이버 업데이트·재설치할 때 주의사항

Windows 업데이트 이후 인터넷 연결이 갑자기 끊기거나 Wi-Fi 어댑터가 오류로 표시된다면 드라이버 문제일 수 있습니다.

먼저 드라이버 정보를 확인하세요

  1. 장치 관리자에서 네트워크 어댑터를 펼칩니다.
  2. 사용 중인 무선랜 장치를 오른쪽 버튼으로 선택합니다.
  3. 속성 → 드라이버 탭을 엽니다.
  4. 드라이버 제공자, 버전, 날짜를 확인합니다.
  5. 기기 제조사 공식 지원 페이지에서 해당 정확한 모델과 Windows 11 버전에 맞는 드라이버가 있는지 확인합니다.

장치 관리자에 노란색 경고 표시가 있는 경우 오류 코드도 기록해 두세요. Microsoft는 이 코드가 드라이버가 로드되지 않는 이유를 찾는 데 도움이 될 수 있다고 설명합니다.

드라이버를 제거해야 할 때

Microsoft는 이전 방법으로 해결되지 않은 경우 무선 네트워크 어댑터 드라이버를 제거하고 PC를 다시 시작하는 방법을 안내합니다.

그러나 드라이버를 제거하기 전에 반드시 제조사 공식 설치 파일 또는 복구할 수 있는 수단을 준비해야 합니다. 오프라인 상태에서 드라이버가 자동 재설치되지 않으면 인터넷 접속 자체가 불가능해질 수 있기 때문입니다.

권장 순서는 다음과 같습니다.

  1. 노트북 제조사·모델명을 확인합니다.
  2. 공식 지원 사이트의 호환 드라이버를 다른 기기에서 내려받습니다.
  3. USB 저장장치 등에 복구용 드라이버를 보관합니다.
  4. 시스템의 Wi-Fi 드라이버 제거가 필요한지 다시 판단합니다.
  5. 장치 관리자에서 대상 어댑터를 선택해 제거합니다.
  6. PC를 다시 시작하고 Windows가 드라이버를 자동 설치하는지 확인합니다.
  7. 자동 설치에 실패하면 미리 준비한 공식 드라이버를 사용합니다.

드라이버를 업데이트하면 반드시 해결되나요?

그렇지는 않습니다. 공유기 주파수 설정, PC 절전, ISP 문제, VPN 설정 때문에 끊길 수도 있습니다. 따라서 증상과 오류 정보를 확인한 뒤 해당 문제에 맞는 조치를 해야 합니다.

비공식 '드라이버 자동 업데이트' 광고 프로그램이나 출처 불분명한 다운로드 사이트는 피하세요. 다른 PC를 이용할 때도 제조사 공식 지원 페이지를 우선합니다.

공식 출처: Microsoft - 무선 네트워크 어댑터 드라이버 다시 설치

11. 노트북 절전 이후 Wi-Fi가 반복해서 끊기는 경우

노트북 덮개를 닫았다 열거나 절전 모드에서 복귀할 때만 Wi-Fi 연결이 끊긴다면 무선 어댑터의 전원 절약 설정과 드라이버를 확인할 수 있습니다.

장치 관리자에서 전원 관리 확인

  1. 장치 관리자 → 네트워크 어댑터를 엽니다.
  2. 무선랜 어댑터를 오른쪽 버튼으로 선택합니다.
  3. 속성 → 전원 관리 탭이 표시되는지 확인합니다.
  4. '전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음' 항목을 찾습니다.
  5. 반복적인 절전 복귀 문제가 있을 때 이 항목을 해제할지 검토합니다.
  6. 적용 후 동일한 상황에서 연결이 유지되는지 시험합니다.

Microsoft는 Wi-Fi가 자주 끊기는 환경에서 무선 어댑터 절전 설정을 점검하도록 안내합니다.

전원 관리 탭이 보이지 않으면?

모든 장치에서 전원 관리 탭이 똑같이 제공되는 것은 아닙니다. 드라이버·전원 관리 방식·기기 제조사에 따라 메뉴가 없을 수 있습니다.

없는 메뉴를 만들기 위해 레지스트리를 임의 편집하거나 BIOS 설정을 무작정 변경하는 것은 권장하지 않습니다. 최신 제조사 드라이버와 Windows 업데이트 상태를 확인하세요.

Wi-Fi 신호가 약할 때는 별개입니다

절전 이슈와 달리 집의 특정 방이나 복도에서만 연결이 끊긴다면 공유기와의 거리, 두꺼운 벽, 다른 무선 장치 간섭 등이 원인일 수 있습니다.

Microsoft는 2.4GHz와 5GHz 등 다른 주파수 대역으로 연결 시험을 권고합니다. 일반적으로 5GHz는 가까운 거리의 성능 면에서 유리한 경우가 있고 2.4GHz는 상대적으로 벽과 거리에 강한 경우가 있으나 실제 결과는 환경에 따라 달라집니다.

공식 출처: Microsoft - 무선 어댑터 절전과 주파수 대역 점검

12. VPN·프록시·보안 프로그램 때문에 인터넷이 안 될 때

Wi-Fi 연결 표시가 정상이고 다른 프로그램은 작동하는데 특정 웹사이트 또는 브라우저만 연결되지 않는다면 VPN·프록시·방화벽·보안 프로그램을 확인하세요.

프록시 설정 확인

  1. Windows 키 + I로 설정을 엽니다.
  2. 네트워크 및 인터넷 → 프록시로 이동합니다.
  3. 수동 프록시 설정이 켜져 있는지 확인합니다.
  4. 가정용 개인 PC에서 내가 설정하지 않은 프록시가 있다면 출처를 살펴봅니다.
  5. 잘못된 수동 프록시로 판단되고 안전하게 변경할 수 있을 때만 해당 설정을 끈 뒤 다시 접속해 봅니다.

Microsoft는 'Wi-Fi 연결됨, 인터넷 없음' 문제에서 수동 프록시 설정을 확인하도록 안내합니다.

VPN 앱이 자동 연결돼 있다면?

보안용 VPN, 회사 VPN 또는 학교 VPN에서 접속 정책이 변경됐을 수 있습니다. 개인적으로 설치한 VPN이라면 앱이 연결·해제되는지 확인한 후 연결 상태에 따른 차이를 비교할 수 있습니다.

하지만 회사·학교에서 반드시 접속해야 하는 보안 VPN을 임의 해제하는 것은 조직 정책에 어긋날 수 있습니다. 해당 VPN 관리자에게 문의하세요.

방화벽을 통째로 끄지 마세요

문제를 진단한다는 이유로 Windows 방화벽이나 모든 보안 프로그램을 장기간 비활성화하면 기기가 보호되지 않을 수 있습니다. Microsoft도 네트워크 문제의 원인으로 방화벽 설정을 언급하지만, 전체 보안 기능을 무분별하게 끄라는 뜻이 아닙니다.

특정 앱에서만 접속되지 않는다면 관련 앱의 공식 지원, 사용자 계정과 정책, 방화벽 허용 규칙을 확인하세요.

공식 출처: Microsoft - 연결 상태는 정상인데 특정 앱만 안 될 때

13. 네트워크 초기화는 마지막에: 설정과 VPN 영향 주의

설정 → 네트워크 및 인터넷에 네트워크 초기화가 있지만, Microsoft는 이를 문제 해결의 마지막 단계로 권고합니다.

이 작업은 Wi-Fi를 잠시 껐다 켜는 것보다 영향 범위가 큽니다. Windows에 설치된 네트워크 어댑터와 관련 설정을 제거하고 다시 설치하며 기본값으로 되돌리기 때문입니다.

Windows 11 네트워크 초기화 경로

  1. 필요한 Wi-Fi 비밀번호와 회사 VPN 접속 설정을 먼저 확인합니다.
  2. 열려 있는 파일을 저장하고 현재 작업을 마칩니다.
  3. 시작 → 설정 → 네트워크 및 인터넷을 엽니다.
  4. 고급 네트워크 설정을 선택합니다.
  5. 네트워크 초기화를 누릅니다.
  6. 화면의 변경 사항 안내를 확인합니다.
  7. 지금 다시 설정을 누르고 예를 선택합니다.
  8. Windows가 재시작되면 Wi-Fi를 다시 연결하고 필요한 설정을 복원합니다.

어떤 문제가 생길 수 있나요?

Microsoft는 네트워크 초기화 후 VPN 클라이언트 소프트웨어 또는 Hyper-V 가상 스위치 등 네트워킹 관련 프로그램을 다시 설치하거나 설정해야 할 수 있다고 설명합니다.

또한 이전에 사설(개인) 네트워크로 지정해 두었던 연결이 공용 네트워크 프로필로 바뀔 수 있습니다. 이후 회사 공유 폴더나 프린터에 접근하지 못하는 문제가 새로 생길 수 있으므로, 필요한 설정을 사전에 기록하세요.

인터넷이 안 된다고 매번 초기화해도 되나요?

권장하지 않습니다. 모뎀이나 공유기 자체에 장애가 있으면 PC의 네트워크 초기화로 해결되지 않을 수 있습니다. 다른 기기에서도 인터넷이 안 된다면 공유기·통신사 점검이 우선입니다.

관리형 PC나 원격 접속을 통해 업무를 하는 기기에서는 네트워크 초기화로 원격 접속이 끊길 수 있으므로 관리자에게 먼저 문의하세요.

14. 연결이 자꾸 실패하면 무선 네트워크 보고서 만들기

Wi-Fi가 몇 분마다 끊기거나 특정 시간대에만 실패하는 문제는 무선 네트워크 보고서를 만들면 원인 분석에 도움이 될 수 있습니다.

Microsoft는 Windows에서 netsh wlan show wlanreport 명령을 이용해 최근 3일간의 Wi-Fi 연결 이벤트와 실패 내역을 HTML 보고서로 만들 수 있다고 안내합니다.

Windows 11 WLAN 보고서 생성

  1. 시작 메뉴 검색에서 명령 프롬프트를 찾습니다.
  2. 관리자 권한으로 실행합니다.
  3. 다음 명령을 입력합니다.
netsh wlan show wlanreport
  1. 명령 실행 결과에 표시되는 HTML 보고서 경로를 확인합니다.
  2. 저장된 보고서를 브라우저에서 엽니다.
  3. Wi-Fi 요약 차트·연결 실패·연결 끊김 원인·어댑터 오류 항목을 살펴봅니다.

보고서에서 봐야 할 것

  • 연결 시도에 성공했는지 실패했는지
  • 연결이 끊어진 시간과 빈도
  • 어떤 Wi-Fi 네트워크(SSID)에서 문제가 나타났는지
  • 장치 관리자 문제 코드가 기록돼 있는지
  • 네트워크 어댑터 드라이버의 버전과 날짜
  • 사용자 의도가 아닌 연결 종료가 반복됐는지

회사나 기관의 기술지원 담당자에게 자료를 전달할 때는 보고서에 컴퓨터 이름·사용자 이름·SSID·네트워크 식별 정보 등 민감한 환경 정보가 포함될 수 있음에 주의하세요. 전체 보고서를 공개 게시판에 올리기보다 필요한 오류 구간만 안전하게 전달하는 것이 좋습니다.

15. 다른 집 Wi-Fi는 보이는데 내 공유기만 검색되지 않는다면?

노트북의 Wi-Fi 목록에 이웃집 공유기는 나타나지만 내가 쓰는 네트워크 이름만 보이지 않는 상황도 있습니다.

주파수 대역 호환성 확인

Microsoft는 일부 무선 어댑터가 2.4GHz만 지원하는데 공유기가 5GHz만 송출하는 경우, 해당 Wi-Fi 네트워크가 보이지 않을 수 있다고 설명합니다.

  1. 공유기 제조사 또는 통신사에서 제공한 안내를 확인합니다.
  2. 공유기가 2.4GHz와 5GHz 신호를 둘 다 제공하는지 살펴봅니다.
  3. 두 주파수 대역의 이름이 별도로 표시되면 PC에서 다른 대역을 선택해 봅니다.
  4. 노트북의 무선랜 어댑터가 어떤 Wi-Fi 규격·대역을 지원하는지 확인합니다.

지원하지 않는 대역을 사용하려고 비공식 드라이버를 강제 설치하거나 공유기 보안을 임의로 약화하지 마세요. 실제 하드웨어 사양을 기준으로 맞춰야 합니다.

어댑터 고급 설정 확인

  1. 장치 관리자 → 네트워크 어댑터로 이동합니다.
  2. 무선랜 어댑터의 속성 → 고급 탭을 엽니다.
  3. 지원되는 경우 무선 모드 또는 주파수 대역 관련 옵션을 확인합니다.
  4. 현재 연결하려는 공유기의 대역과 호환되는지 제조사 안내를 참고합니다.

드라이버에 따라 고급 탭 옵션이 없거나 이름이 다릅니다. 의미를 모르는 설정을 무작정 바꾸면 다른 네트워크와 연결이 끊길 수 있습니다.

공유기에서 네트워크 이름을 숨긴 경우

공유기의 SSID 숨김 설정 때문에 일반 네트워크 목록에 표시되지 않을 수 있습니다. 숨김 네트워크는 별도 연결 설정이 필요하며, 보안을 강화한다는 이유만으로 SSID 숨김을 권장할 수는 없습니다. 공유기 관리자와 정확한 네트워크 이름·인증 방식을 확인하세요.

16. 와이파이는 연결되지만 속도가 느리고 자주 끊기는 경우

웹사이트는 열리는데 영상회의가 끊기거나 다운로드 속도가 느리다면 연결 불가와는 다른 점검이 필요합니다.

공유기와 노트북 거리 확인

무선 공유기에서 먼 방, 두꺼운 콘크리트 벽 뒤, 전파 간섭이 많은 환경에서는 신호가 약해질 수 있습니다. 노트북을 공유기 가까이 가져가 같은 작업을 시험해 보세요.

다른 기기와 비교

같은 위치에서 휴대전화도 느린지 확인합니다. 휴대전화는 빠른데 노트북만 느리다면 PC의 무선랜 성능, 드라이버, 절전 또는 백그라운드 데이터 사용량을 확인할 필요가 있습니다.

작업 관리자에서 네트워크 사용량 확인

  1. Ctrl + Shift + Esc로 작업 관리자를 엽니다.
  2. 실행 중인 프로그램의 네트워크 사용량을 확인합니다.
  3. 대용량 업로드·클라우드 동기화·게임 다운로드 등으로 대역폭이 사용되는지 살펴봅니다.
  4. 필요한 경우 본인이 제어할 수 있는 다운로드·업로드를 잠시 중단하고 비교합니다.

시스템 필수 프로세스를 임의로 종료하지 마세요. 업무용 동기화 앱을 강제로 종료하면 파일 저장이 완료되지 않을 수 있습니다.

2.4GHz와 5GHz 대역 비교

공유기가 둘 다 지원한다면 신호 강도와 속도를 비교해 보세요. 가까운 거리에서는 5GHz가 유리할 수 있고, 벽이나 거리의 영향이 큰 환경에서는 2.4GHz가 더 안정적일 수 있습니다. 이는 절대적인 성능 보장이 아니라 환경별 비교 방법입니다.

17. 윈도우 업데이트 후 와이파이가 끊겼다면?

Windows 업데이트 직후 인터넷 연결에 문제가 생겼다고 해서 업데이트 자체가 반드시 원인이라고 확정할 수는 없습니다. 하지만 네트워크 어댑터 드라이버와 업데이트 설치 시점을 함께 확인할 필요가 있습니다.

우선순위

  1. 설정 → Windows 업데이트를 열어 필요한 추가 업데이트가 있는지 확인합니다.
  2. 업데이트 설치 후 재시작이 필요한지 점검합니다.
  3. 장치 관리자 → 네트워크 어댑터에서 오류 표시와 드라이버 날짜를 확인합니다.
  4. 제조사의 최신 호환 무선랜 드라이버 제공 여부를 확인합니다.
  5. 재시작·드라이버 점검 후에도 안 되면 앞에서 설명한 IP·DNS 진단을 이용합니다.

장치 관리자에서 드라이버가 보이지 않으면

Microsoft는 장치 관리자에 무선랜 어댑터가 나타나지 않는 경우 Windows가 해당 장치를 감지하지 못하는 상태일 수 있으므로 PC 제조사가 제공하는 호환 드라이버를 확인하도록 권고합니다.

업데이트를 되돌리는 것이 항상 정답은 아닙니다. 운영체제 보안 업데이트까지 무조건 제거하면 다른 위험이 생길 수 있으므로, 정확한 원인이 확인되지 않았다면 Microsoft 및 노트북 제조사 공식 지원에 문의하세요.

자주 묻는 질문 FAQ

Q1. Windows 11에서 'Wi-Fi 연결됨, 인터넷 없음'은 무슨 뜻인가요?

노트북이 무선 공유기 등 로컬 네트워크에 연결됐지만 인터넷에 정상적으로 접속하지 못할 수 있다는 뜻입니다. 휴대전화도 같은 문제가 있는지 확인해 공유기·회선 문제와 PC 문제를 구분하세요.

Q2. 윈도우11 와이파이가 갑자기 안 될 때 가장 먼저 해야 할 일은?

Wi-Fi 켜짐, 비행기 모드 꺼짐, 다른 기기에서 인터넷이 되는지부터 확인하세요. 그다음 Wi-Fi 네트워크 삭제 후 재연결, 공유기 재부팅, 문제 해결사 순서로 진행합니다.

Q3. Windows 11에서 Wi-Fi 아이콘이 사라졌다면?

장치 관리자 → 네트워크 어댑터에서 무선랜 어댑터가 정상 인식됐는지 확인하세요. 사용 안 함 상태라면 활성화하고, services.msc의 WLAN 자동 구성 서비스도 점검할 수 있습니다.

Q4. 와이파이 저장된 비밀번호를 지우고 다시 연결하려면?

설정 → 네트워크 및 인터넷 → Wi-Fi → 알려진 네트워크 관리에서 해당 네트워크를 **삭제(잊어버리기)**하고 다시 선택해 암호를 입력하면 됩니다.

Q5. ipconfig에서 169.254로 시작하는 주소가 표시되면 고장인가요?

일반적인 DHCP 자동 IP 네트워크에서는 공유기로부터 주소를 정상 할당받지 못한 상황일 수 있습니다. 다른 어댑터가 아닌 현재 사용 중인 Wi-Fi인지 확인하고 공유기 DHCP 및 연결 상태를 점검하세요.

Q6. ipconfig /flushdns 명령만 실행하면 인터넷이 고쳐지나요?

반드시 그렇지는 않습니다. 이 명령은 Windows DNS 확인자 캐시를 비우는 기능입니다. 문제가 공유기·통신사 회선·드라이버나 IP 할당에 있다면 다른 진단이 필요합니다.

Q7. netsh winsock reset은 무엇인가요?

Windows의 네트워크 통신 관련 Winsock 구성을 재설정하는 명령입니다. Microsoft가 공식 Wi-Fi 연결 문제 해결 순서에 포함하고 있으나, 설정과 연결에 영향을 줄 수 있어 관리자 권한과 재시작 필요 여부를 확인해야 합니다.

Q8. 윈도우11 네트워크 초기화는 어디에 있나요?

설정 → 네트워크 및 인터넷 → 고급 네트워크 설정 → 네트워크 초기화에서 실행할 수 있습니다. VPN·가상 네트워크·저장된 네트워크 설정에 영향을 줄 수 있으므로 마지막 단계로 고려하세요.

Q9. 노트북에서 2.4GHz는 보이는데 5GHz 와이파이가 안 보이는 이유는?

노트북 무선랜 어댑터가 5GHz 대역을 지원하지 않거나 드라이버·공유기 설정 때문에 검색되지 않을 수 있습니다. 제조사 사양과 장치 관리자 무선 모드 설정을 확인하세요.

Q10. 와이파이가 몇 분마다 끊길 때 원인을 확인할 방법이 있나요?

관리자 권한 명령 프롬프트에서 netsh wlan show wlanreport를 실행하면 최근 3일간의 Wi-Fi 연결 이벤트와 실패 내역을 HTML 보고서로 확인할 수 있습니다. 드라이버·절전·신호 문제 분석에 활용하세요.

마무리: 네트워크 초기화보다 원인 구분이 먼저입니다

Windows 11에서 와이파이가 안 될 때 '연결됨, 인터넷 없음', Wi-Fi 아이콘이 사라짐, 비밀번호 오류, 인터넷은 되지만 속도가 느림은 각각 확인할 항목이 다릅니다.

다른 기기에서도 인터넷이 안 된다면 공유기·회선부터, 내 노트북만 연결되지 않는다면 Wi-Fi 프로필·드라이버·IP·DNS부터 확인하는 편이 효율적입니다. 특히 무선랜 드라이버 제거와 네트워크 초기화는 다른 연결 설정을 잃을 수 있으므로 가장 뒤에 배치하세요.

문제가 계속된다면 netsh wlan show wlanreport로 연결 실패 시각과 오류 기록을 확인하고, 노트북 제조사의 공식 지원 또는 이용 중인 인터넷 서비스 공급자에 문의하는 것이 좋습니다.
