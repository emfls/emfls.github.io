노트북을 쓰다가 갑자기 마우스 포인터가 움직이지 않거나, 터치패드를 눌러도 클릭이 안 되는 경우가 있습니다. 특히 Windows 11 업데이트 후 터치패드가 사라졌거나 외부 마우스를 연결할 때만 작동하고, 설정 → Bluetooth 및 장치에 '터치패드' 메뉴 자체가 없는 문제가 발생하기도 합니다.

원인은 크게 터치패드 끄기 설정·노트북의 기능키(Fn)·외부 마우스 연결 설정·터치패드 드라이버·하드웨어 이상으로 구분합니다. 무조건 드라이버를 삭제하거나 노트북을 초기화할 필요는 없습니다.

Microsoft는 Windows 11의 공식 문제 해결 문서에서 Windows 업데이트를 통한 터치패드 드라이버 갱신을 우선 권장하고, 필요하면 장치 관리자에서 업데이트·재설치하도록 안내합니다. 이 글은 Microsoft와 Dell·Lenovo의 공식 지원자료를 바탕으로 안전한 설정 확인부터 고급 복구까지 단계별로 정리했습니다.

핵심: 먼저 ① 노트북 터치패드 단축키 ② 설정의 터치패드 켜기 ③ 외부 마우스 분리 ④ 재시작을 확인하세요. 해결되지 않을 때만 드라이버를 점검합니다.

1. 증상별 1분 진단표

현재 증상우선 의심할 원인가장 먼저 할 일
터치패드가 완전히 먹통기능키로 비활성화, Windows 설정 끔터치패드 아이콘 키 확인 → 설정에서 켜기
터치패드 메뉴가 안 보임드라이버 누락·장치 인식 문제장치 관리자·Windows 업데이트 확인
USB 마우스를 꽂으면 터치패드가 멈춤외부 마우스 연결 시 끄기 설정 또는 제조사 유틸리티외부 마우스 분리 → 연결 상태별 테스트
포인터는 움직이는데 클릭이 안 됨탭·클릭 설정·손상된 드라이버·물리적 스위치설정에서 탭/버튼 점검
클릭은 되는데 두 손가락 스크롤 안 됨제스처 설정·정밀 터치패드 지원 차이설정의 스크롤·제스처 확인
Windows 업데이트 이후 먹통드라이버 호환성 문제Windows 업데이트 → 필요 시 드라이버 롤백
절전 모드에서 깬 뒤 안 됨드라이버·전원 상태·주변기기 충돌 가능작업 저장 후 정상 재시작
터치패드가 들뜨거나 케이스가 부품배터리 팽창 등 물리적 이상 가능사용·충전 중단 후 제조사 점검 상담

마지막 줄은 단순한 설정 문제로 취급하면 안 됩니다. Dell은 터치패드가 들뜨거나 케이스 틈이 벌어지는 증상을 배터리 팽창 가능성과 연결해 주의를 안내합니다. 그런 경우 무리하게 누르거나 직접 분해하지 마세요.

공식 출처: Microsoft — Windows에서 터치 패드 문제 해결, Dell — 터치패드 문제 해결.

2. 터치패드 기능키(Fn)를 잘못 눌렀는지 확인

가장 간단하지만 놓치기 쉬운 원인입니다. 일부 노트북은 키보드의 특정 기능키로 터치패드를 켜고 끌 수 있습니다.

단계별 확인

  1. 키보드 상단 F1~F12 키를 살펴봅니다.
  2. 작은 사각형 터치패드·손가락·대각선 표시와 비슷한 아이콘이 있는 키를 찾습니다.
  3. 해당 키가 보이면 그 키 단독 또는 Fn 키와 함께 눌러봅니다.
  4. 터치패드가 다시 움직이는지 확인합니다.
  5. 반응이 없다면 키를 여러 번 연속으로 누르지 말고 제조사 모델 설명서에서 동작을 확인합니다.

'Fn+F6만 누르면 된다'는 설명이 위험한 이유

Lenovo 공식 사용설명서만 비교해도 모델에 따라 터치패드 켜기·끄기 키가 다릅니다.

Lenovo의 공식 모델 설명서 예시터치패드 단축키
Lenovo V140, 일부 IdeaPad·S540 등F6 기능키
Lenovo Legion Y540 계열F11 기능키

또한 핫키 모드(Hotkey Mode) 설정에 따라 Fn 키를 함께 눌러야 하는지도 달라질 수 있습니다. 따라서 삼성·LG·HP·Lenovo·Dell 모든 노트북이 Fn+F6이라는 식으로 외우지 마세요.

공식 근거: Lenovo V140 기능키, Lenovo Legion Y540 기능키.

3. 윈도우11에서 터치패드 켜기

Windows 11에서 터치패드를 켜거나 끄는 기본 메뉴는 다음 위치입니다.

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 왼쪽 메뉴의 Bluetooth 및 장치를 선택합니다.
  3. 목록에서 터치패드를 찾습니다.
  4. 터치패드의 켬/끔 스위치를 확인합니다.
  5. 꺼져 있다면 켬으로 바꾸고 움직임을 시험합니다.
  6. 가능하다면 클릭·스크롤도 함께 확인합니다.

Microsoft 공식 안내는 Windows 11의 경로를 시작 → 설정 → Bluetooth 및 장치 → 터치패드로 안내합니다. Windows 10에서는 설정 → 장치 → 터치패드로 경로가 다릅니다.

팁: 터치패드가 먹통이지만 키보드는 작동한다면 Windows+I, Tab, 방향키, Enter를 이용해 설정 메뉴를 탐색할 수 있습니다. 사용 중인 Windows 빌드·접근성 설정에 따라 이동 횟수는 다를 수 있습니다.

공식 출처: Microsoft — Surface 터치패드 사용 및 설정.

4. 외부 마우스를 연결할 때만 터치패드가 안 된다면

일부 노트북 설정에는 외부 마우스가 연결된 동안에도 터치패드를 사용할 수 있게 하는 항목이 있습니다. 제조사 도구나 구형 드라이버가 이 동작에 관여하는 모델도 있습니다.

구별 방법

  1. 현재 연결된 USB 마우스·무선 USB 수신기를 분리합니다.
  2. Bluetooth 마우스가 있다면 연결을 잠시 해제합니다.
  3. 터치패드가 다시 움직이는지 확인합니다.
  4. 외부 마우스를 다시 연결해 같은 증상이 재현되는지 확인합니다.
  5. 설정 → Bluetooth 및 장치 → 터치패드를 열어 외부 마우스 연결 중 터치패드를 유지하는 옵션이 보이는지 확인합니다.
  6. 사용 중인 제조사 터치패드 소프트웨어가 있다면 그 안에도 관련 설정이 있는지 살펴봅니다.

주의: 모든 모델에 해당 옵션이 동일한 이름으로 표시되는 것은 아닙니다. 외부 마우스를 분리해도 전혀 동작하지 않는다면 다른 원인도 확인해야 합니다.

외부 마우스가 아예 없다면

키보드만으로 Windows 설정을 열어 기능키와 터치패드 스위치를 확인하세요. 장치 관리자의 드라이버 제거처럼 입력 수단이 더 줄어들 수 있는 조치는 가능하면 USB 마우스 등을 준비한 뒤 진행하는 편이 안전합니다.

5. 터치패드 설정 메뉴가 통째로 사라졌다면

설정 → Bluetooth 및 장치에 터치패드 항목 자체가 없는 경우를 단순한 '터치패드 끔'과 구별해야 합니다.

Microsoft는 터치패드가 동작하지 않는 원인으로 누락됐거나 오래된 드라이버를 명시하고, 장치 관리자에서 '휴먼 인터페이스 디바이스' 또는 '마우스 및 기타 포인팅 디바이스'를 확인하도록 안내합니다.

장치 관리자 확인 순서

  1. Windows 키 + X를 누른 뒤 장치 관리자를 선택합니다.
  2. 휴먼 인터페이스 디바이스(Human Interface Devices)를 확장합니다.
  3. 마우스 및 기타 포인팅 디바이스(Mice and other pointing devices)도 확장합니다.
  4. HID 규격 터치 패드, Precision Touchpad, 제조사 터치패드 등 해당 장치로 보이는 항목을 찾습니다.
  5. 해당 장치가 보이면 장치 상태·사용 여부·경고 아이콘을 확인합니다.
  6. 드라이버가 누락됐거나 비정상이라면 다음 장의 Windows 업데이트 → 장치 관리자 업데이트 순서를 진행합니다.

주의: 'HID 규격 마우스' 항목이 여러 개 있다고 해서 아무 장치나 삭제하지 마세요. 외부 USB 마우스나 다른 입력 장치일 수 있습니다.

장치 목록에도 보이지 않는다면

  • Windows 업데이트에서 해당 제조사의 드라이버가 제공되는지 확인합니다.
  • 제조사 공식 지원 홈페이지에서 정확한 모델명으로 터치패드·칩셋 관련 드라이버를 확인합니다.
  • 제조사 진단 유틸리티에서 입력장치가 감지되는지 확인합니다.
  • 소프트웨어 조치 후에도 장치가 전혀 나타나지 않으면 하드웨어 점검을 고려합니다.

메뉴가 없다는 사실만으로 즉시 메인보드 고장이라고 단정할 수는 없습니다.

공식 출처: Microsoft — 터치패드 문제 해결.

6. Windows 업데이트로 터치패드 드라이버 고치기

Microsoft가 권장하는 첫 번째 드라이버 업데이트 방법은 Windows 업데이트입니다.

  1. 먼저 열어 둔 문서와 작업을 저장합니다.
  2. Windows 키 + I를 누릅니다.
  3. Windows 업데이트 메뉴를 엽니다.
  4. 업데이트 확인을 실행합니다.
  5. 설치 가능한 중요한 업데이트가 있다면 내용을 확인하고 설치합니다.
  6. 고급 옵션 → 선택적 업데이트에 드라이버 업데이트가 제공되는지도 확인합니다. 메뉴 구성은 빌드에 따라 다를 수 있습니다.
  7. 노트북의 정확한 터치패드·칩셋 드라이버가 제공되는지 점검합니다.
  8. 설치 후 정상적으로 다시 시작하고 터치패드를 테스트합니다.

Microsoft는 일반적으로 Windows 업데이트로 최신 권장 하드웨어 드라이버를 받는 방식을 우선 안내합니다.

선택적 업데이트의 드라이버를 전부 무조건 설치할 필요는 없습니다. 현재 증상과 관련된 항목, 모델 호환성을 확인하고 진행하세요.

공식 출처: Microsoft — Windows에서 터치패드 문제 해결, Microsoft — 장치 관리자에서 드라이버 업데이트.

7. 장치 관리자에서 터치패드 드라이버 업데이트

Windows 업데이트만으로 해결되지 않으면 장치 관리자에서 터치패드 장치를 선택해 드라이버 업데이트를 진행할 수 있습니다.

  1. Windows 키 + X → 장치 관리자를 엽니다.
  2. 휴먼 인터페이스 디바이스 또는 마우스 및 기타 포인팅 디바이스를 펼칩니다.
  3. 실제 터치패드인 항목을 정확히 선택합니다.
  4. 오른쪽 클릭 → 드라이버 업데이트를 선택합니다.
  5. 드라이버 자동 검색을 선택합니다.
  6. Windows가 적절한 드라이버를 찾으면 설치합니다.
  7. 설치 후 필요한 경우 노트북을 재시작합니다.
  8. 포인터 이동·왼쪽 클릭·두 손가락 스크롤을 확인합니다.

'최적의 드라이버가 이미 설치되어 있습니다'라고 나옵니다

이 메시지가 고장 원인이 없다는 증명은 아닙니다. Windows 업데이트의 관련 업데이트나 제조사 공식 지원 페이지에서 더 적합한 드라이버가 있는지 확인할 수 있습니다.

드라이버 다운로드는 제조사 공식 홈페이지로 제한하세요. Microsoft도 알 수 없는 제3자 웹사이트에서 드라이버를 내려받지 말라고 안내합니다.

공식 출처: Microsoft — 장치 관리자에서 드라이버 업데이트.

8. 윈도우 업데이트 뒤 고장 났다면 '드라이버 롤백' 확인

문제가 시작된 시점이 드라이버 또는 Windows 업데이트 직후라면 이전 버전으로 되돌리는 방법을 검토할 수 있습니다.

  1. 장치 관리자를 엽니다.
  2. 터치패드에 해당하는 정확한 장치를 찾습니다.
  3. 해당 장치를 오른쪽 클릭하고 속성을 선택합니다.
  4. 드라이버 탭을 엽니다.
  5. 드라이버 롤백 버튼이 활성화돼 있는지 확인합니다.
  6. 활성화됐다면 현재 문제와 변경 이력을 확인한 뒤 롤백을 진행합니다.
  7. 안내에 따라 재시작합니다.
  8. 문제가 해결됐는지 확인합니다.

롤백 버튼이 회색이라면?

이전 드라이버가 저장돼 있지 않거나 현재 권한·장치 상태로 롤백할 수 없을 수 있습니다. 버튼을 활성화하려고 무작정 다른 장치를 삭제하지 마세요.

Microsoft는 드라이버 롤백을 위해 관리자 권한이 필요하고, 업데이트 후 문제가 시작된 경우 이전 드라이버로 되돌리는 조치가 도움이 될 수 있다고 설명합니다.

공식 출처: Microsoft — 장치 드라이버 롤백 절차.

9. 드라이버 재설치가 필요한 경우와 주의할 점

업데이트·롤백·설정 확인으로 해결되지 않았다면 Microsoft는 장치 관리자의 드라이버 재설치를 다음 단계로 제시합니다.

시작 전 주의사항: 장치 제거 도중에는 터치패드가 아예 입력되지 않을 수 있습니다. 작업 파일을 저장하고 외부 USB 마우스 또는 키보드 조작 방법을 확보한 뒤 진행하세요.

기본 재설치 과정

  1. 작업을 저장하고 모든 앱을 닫습니다.
  2. 장치 관리자에서 정확한 터치패드 장치를 찾습니다.
  3. 장치를 오른쪽 클릭하고 디바이스 제거를 선택합니다.
  4. 표시되는 확인 창을 주의 깊게 읽습니다.
  5. 문제의 터치패드 장치가 맞는 경우에만 제거합니다.
  6. 시작 메뉴에서 다시 시작을 선택합니다.
  7. 재부팅 후 Windows가 장치 드라이버를 자동으로 다시 설치하는지 확인합니다.
  8. 설치가 되지 않으면 Windows 업데이트 또는 제조사 공식 드라이버를 통해 해결합니다.

임의로 '이 장치의 드라이버 소프트웨어 삭제' 같은 옵션을 선택하지 마세요. Windows 빌드·드라이버 상태에 따라 복구에 추가 설치파일이 필요할 수 있습니다.

Microsoft는 드라이버 재설치 후 Windows가 드라이버를 다시 설치하려고 시도한다고 명시합니다. 항상 자동 복구된다고 보장하지는 않습니다.

공식 출처: Microsoft — 드라이버 다시 설치, Microsoft — 터치패드 재설치 안내.

10. 포인터는 움직이는데 클릭이 안 되는 경우

'터치패드 고장'이라고 검색하는 사람 중에는 포인터 이동은 되지만 탭·클릭만 안 되는 사용자도 있습니다.

해결 순서

  1. 설정 → Bluetooth 및 장치 → 터치패드를 엽니다.
  2. 탭 관련 설정을 펼칩니다.
  3. 한 손가락 탭으로 클릭 등의 옵션이 현재 활성화돼 있는지 확인합니다.
  4. 탭 대신 터치패드를 실제로 눌러 클릭했을 때 동작이 다른지 확인합니다.
  5. 오른쪽 클릭 영역이 제대로 동작하는지 점검합니다.
  6. 클릭만 안 되면 제스처 설정 초기화가 가능한 모델인지 확인합니다.
  7. 여러 앱에서 동일한지 테스트해 특정 앱의 입력 문제와 구분합니다.

Dell은 Windows 터치패드 설정에서 기본 설정 및 제스처를 초기화할 수 있는 경우를 공식 안내합니다. 버튼이 비활성화됐더라도 해당 옵션이 없거나 변경한 값이 없는 경우일 수 있습니다.

물리적인 클릭 소리가 달라졌거나 버튼이 눌리지 않는다면 드라이버 문제 외에 하드웨어 점검도 고려하세요.

공식 출처: Dell — 노트북 터치패드 FAQ.

11. 두 손가락 스크롤·확대·세 손가락 제스처가 안 되는 경우

터치패드가 완전히 고장 난 것이 아니라 일부 제스처만 동작하지 않는 경우에는 지원 기능과 설정을 확인해야 합니다.

Microsoft가 안내하는 대표적인 Windows 제스처는 다음과 같습니다.

제스처기본 동작 예시
두 손가락으로 위아래 움직이기스크롤
두 손가락을 벌리거나 오므리기확대·축소
두 손가락 탭오른쪽 클릭
세 손가락 위로 쓸기열려 있는 창 확인
세 손가락 아래로 쓸기바탕화면 표시
세 손가락 좌우로 쓸기창 전환
네 손가락 좌우로 쓸기가상 데스크톱 전환

Microsoft는 일부 제스처는 정밀 터치패드(Precision Touchpad)에서만 작동한다고 명시합니다.

점검 순서

  1. 설정 → Bluetooth 및 장치 → 터치패드를 엽니다.
  2. 스크롤 및 확대/축소 메뉴에서 두 손가락 스크롤이 켜져 있는지 확인합니다.
  3. 세 손가락 제스처·네 손가락 제스처가 제공되는지 확인합니다.
  4. 원하는 동작이 아무것도 안 함 같은 설정이 아닌지 확인합니다.
  5. 해당 제스처가 지원되는 터치패드인지 제조사 사양을 확인합니다.
  6. 설정을 변경한 뒤 테스트합니다.
  7. 모든 제스처가 갑자기 사라졌다면 드라이버 상태를 확인합니다.

중요: 특정 제스처 메뉴가 없다는 이유만으로 무조건 드라이버 오류라고 단정하면 안 됩니다. 모델이 해당 정밀 제스처를 지원하지 않을 수 있습니다.

공식 출처: Microsoft — Windows용 터치 제스처.

12. 절전 모드에서 깬 후 터치패드가 멈춘다면

절전에서 복귀한 직후 터치패드가 먹통인 경우 일시적인 드라이버 상태·외부 장치 충돌 등을 분리해 확인합니다.

  1. 작업이 가능하다면 열린 문서를 저장합니다.
  2. 정상적인 Windows 다시 시작을 수행합니다.
  3. 켜진 직후 터치패드가 작동하는지 확인합니다.
  4. USB 허브·도킹스테이션·외부 마우스가 연결돼 있다면 한 번에 하나씩 분리해 비교합니다.
  5. Windows 업데이트와 제조사 공식 터치패드·칩셋 드라이버를 확인합니다.
  6. 문제의 발생 시점이 특정 업데이트 직후라면 드라이버 롤백 가능성을 확인합니다.
  7. 반복된다면 제조사의 공식 하드웨어 진단 또는 고객지원에 문의합니다.

Dell은 절전 모드에서 복귀 후 터치패드 문제가 생기는 경우 정상 재시작, BIOS·Windows 업데이트 확인 등의 절차를 공식 제시합니다.

주의: 전원 버튼을 오랫동안 눌러 강제 종료하는 방법은 저장하지 않은 작업을 잃게 할 수 있습니다. 정상 재시작이 불가능한 최후의 상황이 아니라면 먼저 시도하지 마세요. BIOS 업데이트는 모델·전원·제조사 지침을 확인하고 신중히 진행해야 합니다.

공식 출처: Dell — 터치패드 절전 복귀 문제 해결.

검색할 때는 '모델명 + 터치패드 켜기' 또는 '모델명 + touchpad driver'처럼 정확한 모델을 포함하세요.

14. 터치패드 하드웨어 문제일 수 있는 경고 신호

다음과 같은 증상이 있다면 Windows 설정 수정만 반복하기보다 기기 안전과 실제 물리적 이상을 확인해야 합니다.

  • 터치패드 판이 비정상적으로 솟아오름
  • 하판·팜레스트에 틈이 벌어짐
  • 노트북 바닥이 평평하게 놓이지 않음
  • 터치패드를 누를 때 이상한 압력·변형이 느껴짐
  • 침수·낙하 후 터치패드가 작동하지 않음
  • 장치 관리자·제조사 진단에서도 입력장치 인식에 문제가 지속됨

특히 배터리 팽창이 의심된다면 충전과 사용을 중단하고 제조사에 점검을 요청하세요. 터치패드를 세게 누르거나 노트북을 분해해 배터리를 찌르는 행동은 위험합니다.

Dell은 터치패드가 들뜨거나 케이스가 벌어지는 현상을 배터리 팽창 가능성의 경고 신호로 공식 안내합니다.

16. FAQ — 자주 묻는 질문 12개

Q1. 노트북 터치패드가 갑자기 안 될 때 가장 먼저 무엇을 해야 하나요?

터치패드 단축키 → Windows 설정의 켜기 스위치 → 외부 마우스 분리 → 정상 재시작을 먼저 확인하세요. 그다음 Microsoft 공식 안내에 따라 Windows 업데이트를 통한 드라이버 점검을 진행합니다.

Q2. 윈도우11 터치패드 설정은 어디에 있나요?

설정 → Bluetooth 및 장치 → 터치패드입니다. Windows 10은 '설정 → 장치 → 터치패드'로 경로가 다릅니다.

Q3. 설정에 터치패드 메뉴가 아예 없습니다.

장치 관리자의 휴먼 인터페이스 디바이스·마우스 및 기타 포인팅 디바이스에서 인식 여부를 확인하세요. 터치패드 드라이버가 없거나 인식되지 않는 문제일 수 있습니다.

Q4. Fn+F6만 누르면 터치패드가 켜지나요?

모든 기기에서 그렇지는 않습니다. Lenovo 공식 문서에서도 모델에 따라 F6 또는 F11처럼 다릅니다. 터치패드 아이콘과 모델 설명서에서 정확한 키를 확인하세요.

Q5. 외부 마우스를 연결하면 터치패드가 멈춥니다.

외부 마우스를 분리했을 때 터치패드가 살아나는지 확인하고, Windows 설정 또는 제조사 유틸리티에 외부 마우스 연결 시 터치패드 사용 설정이 있는지 확인하세요.

Q6. 터치패드 포인터는 움직이는데 클릭이 안 됩니다.

탭·클릭 설정, 물리적 클릭부, 다른 앱에서의 동작을 점검하세요. 일부 모델은 터치패드 설정 초기화 기능을 지원합니다.

Q7. 두 손가락 스크롤이 안 됩니다.

설정 → Bluetooth 및 장치 → 터치패드 → 스크롤 및 확대/축소에서 관련 설정을 확인하세요. 일부 고급 제스처는 정밀 터치패드에서만 지원됩니다.

Q8. 업데이트 이후부터 터치패드가 안 됩니다.

Windows 업데이트의 후속 드라이버를 확인한 뒤, 해당 장치의 속성 → 드라이버 → 드라이버 롤백이 활성화됐는지 확인하세요. 관리자 권한이 필요할 수 있습니다.

Q9. 장치 관리자에서 터치패드를 제거해도 되나요?

Microsoft는 재설치를 복구 방법 중 하나로 안내하지만, 잘못된 장치를 제거하거나 자동 설치에 실패하면 입력이 더 어려워질 수 있습니다. 작업 저장·외부 입력장치 확보·대상 장치 확인 후 진행하세요.

Q10. 절전 모드에서 깬 뒤에만 터치패드가 먹통입니다.

정상 재시작, 연결된 주변기기 분리, Windows 업데이트·제조사 공식 드라이버 점검을 우선하세요. 지속되면 해당 제조사의 지원 절차를 확인합니다.

Q11. 터치패드가 들뜨고 눌리는 느낌이 이상합니다.

단순 설정 문제가 아니라 배터리 팽창이나 물리적 변형 가능성도 있습니다. 무리하게 누르거나 분해하지 말고 사용·충전을 중단한 뒤 제조사에 문의하세요.

Q12. 드라이버 업데이트를 해도 계속 안 됩니다. 새 터치패드를 사야 하나요?

바로 교체할 필요는 없습니다. 장치 인식·기능키·전용 유틸리티·제조사 하드웨어 진단 결과를 확인해야 합니다. 실제 부품 교체 필요성은 모델별 점검 후 판단합니다.

17. 10분 최종 체크리스트

  • ☐ 터치패드 기능키 아이콘과 Fn 키 조합을 확인했다.
  • ☐ Windows+I → Bluetooth 및 장치 → 터치패드를 확인했다.
  • ☐ 외부 USB·Bluetooth 마우스를 분리해 증상 변화를 확인했다.
  • ☐ 작업을 저장하고 정상 재시작했다.
  • ☐ 장치 관리자의 HID·포인팅 장치 목록을 확인했다.
  • ☐ Windows 업데이트의 관련 드라이버를 점검했다.
  • ☐ 업데이트 직후 고장이라면 롤백 가능 여부를 확인했다.
  • ☐ 클릭만 안 되면 탭·클릭, 스크롤만 안 되면 제스처 설정을 확인했다.
  • ☐ 드라이버 제거 전 외부 입력장치와 원본 드라이버를 확보했다.
  • ☐ 출처 불명의 드라이버 설치 프로그램을 다운로드하지 않았다.
  • ☐ 기기 외형이 들뜨거나 부풀었다면 사용 중단 및 제조사 점검을 우선했다.
  • ☐ 제조사 상담 시 모델명·오류 시작 시점·시도한 조치를 정리했다.

결론: 윈도우11 노트북 터치패드가 안 될 때는 대부분의 사용자에게 기능키·설정·연결된 마우스·재시작부터 확인하는 것이 효율적입니다. 메뉴가 사라졌거나 업데이트 후 먹통이라면 Microsoft가 권장하는 Windows 업데이트 → 장치 관리자 드라이버 확인 순서로 접근하세요. 반면 터치패드가 비정상적으로 들뜨는 등 물리적 변형이 있다면 안전 점검이 소프트웨어 수정보다 우선입니다.
