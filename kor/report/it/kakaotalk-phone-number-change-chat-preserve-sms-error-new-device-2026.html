2. 번호를 바꾸기 전에 확인할 네 가지

① 연결된 카카오계정 확인

카카오톡에서 더보기 또는 설정의 카카오계정 관련 메뉴로 들어가 현재 사용 중인 계정의 식별 정보와 로그인 가능한 상태를 확인합니다. 메뉴 이름이 달라졌다면 최신 카카오톡 설정에서 계정 관리 항목을 찾으세요.

기존 대화 복원에 사용할 계정은 백업 당시 연결된 카카오계정이어야 합니다. 이메일·비밀번호를 기억하지 못하면 미리 공식 계정 찾기 또는 비밀번호 재설정을 진행하세요.

② 중요한 대화의 백업 여부 확인

기본적인 카카오톡 대화 백업은 더보기 → 설정 → 채팅 → 대화 백업 순서로 확인할 수 있습니다. 백업이 완료됐는지, 백업 비밀번호와 복원 기한을 알고 있는지 살펴봅니다.

카카오 공식 고객센터에 따르면 일반 대화 백업은 문자 메시지 중심이며 사진·동영상, 일부 긴 메시지, 비밀채팅·오픈채팅 내용은 제외됩니다. 소중한 사진과 파일을 일반 대화 백업 하나에만 의존하지 마세요.

③ 신규 번호의 실제 SMS 인증 가능 여부

새 번호가 개통됐는지, 문자 송수신이 가능한지 먼저 확인합니다. 듀얼 SIM이나 eSIM을 쓰는 경우에는 어떤 회선으로 문자를 받을지 통신 설정을 확인하세요.

④ 기존 휴대전화를 바로 초기화·반납하지 않기

번호 변경과 기기 교체를 동시에 하면 문제가 생겼을 때 확인할 수 있는 정보가 줄어듭니다. 가급적 기존 기기의 로그인 상태, 계정 정보, 필요한 사진·파일과 대화 백업을 확인한 후 초기화를 결정하는 것이 안전합니다.

3. 기존 휴대전화에서 전화번호만 바꾸는 방법

기기를 그대로 사용한다면 앱 안의 번호 변경 기능을 먼저 찾는 것이 합리적입니다. 카카오는 기존 공식 발간 자료에서 사용 중인 카카오톡의 계정 설정을 통해 등록 전화번호를 변경할 수 있다고 설명했습니다.

최신 버전의 카카오톡에서는 다음과 같은 항목을 확인합니다.

  1. 카카오톡을 열고 더보기(…) 탭으로 이동합니다.
  2. 오른쪽 위 설정(톱니바퀴)을 누릅니다.
  3. 내 프로필 관리 또는 카카오계정 관련 메뉴를 찾습니다.
  4. 현재 등록된 전화번호가 표시된 항목을 엽니다.
  5. 전화번호 변경 버튼이 있는지 확인합니다.
  6. 카카오계정 비밀번호 또는 추가 본인확인이 요청되면 앱의 지침을 따릅니다.
  7. 새 전화번호로 인증을 진행하고, 변경 완료 화면에서 새 번호가 반영됐는지 확인합니다.
  8. 변경 후 친구 목록과 주요 채팅방이 정상적으로 표시되는지 확인합니다.

현재 앱의 메뉴 구조가 위와 다를 수 있습니다. 이 경로를 모든 2026년 버전에서 버튼 이름이 동일한 것으로 단정하지 않으며, 실제 화면과 카카오 고객센터 안내를 최종 기준으로 삼으세요.

중요: 과거 카카오 고객센터의 일부 도움말은 앱을 삭제하고 다시 설치해 새 번호를 인증하는 절차를 설명하지만, 번호만 변경하려는 이용자에게 재설치를 먼저 권하는 것은 안전하지 않습니다. 현재 앱에서 직접 변경할 수 있는지 먼저 확인하고, 재설치가 필요한 상황이라면 반드시 공식 백업·복원 절차를 사전 확인하세요.

공식 자료: 카카오 공식 발간 자료 내 번호 변경 기능 설명, 카카오 고객센터 — 번호 변경 관련 도움말

4. 새 휴대전화로 옮기면서 번호까지 바꾸는 경우

전화번호 변경과 기기 변경을 동시에 진행할 때는 대화 백업과 동일 계정 로그인 여부가 훨씬 중요합니다.

  1. 기존 휴대전화에서 카카오톡에 연결된 카카오계정을 확인합니다.
  2. 기존 카카오톡에서 대화 백업을 수행하고 완료 여부를 확인합니다.
  3. 중요한 사진·동영상과 대화방 공유 파일은 별도로 보관합니다.
  4. 새 휴대전화에 카카오톡 공식 앱을 설치합니다.
  5. 새 번호 인증 절차를 진행합니다.
  6. '새 계정 만들기'보다 기존 카카오계정 로그인 경로를 확인합니다.
  7. 백업 데이터 복원 화면이 나타난다면 백업 일자와 계정을 확인해 복원을 진행합니다.
  8. 복원 후 주요 채팅방·친구 목록·프로필과 필요한 파일을 실제로 확인합니다.

카카오 공식 고객센터는 번호 변경 후 이전 카카오계정으로 로그인해야 친구 목록·카카오톡 ID·프로필과 다른 연동 정보를 계속 이용할 수 있다고 안내합니다. 이름이 일부 다르게 보일 수 있으며, 특히 주소록에 저장되지 않은 친구의 사용자 지정 이름은 그대로 복원되지 않을 수 있습니다.

주의: 기존 계정 대신 새 카카오계정을 생성하면 이전 계정의 데이터가 그대로 이어진다고 보장할 수 없습니다. 처음 가입하는 것인지 기존 계정으로 들어가는 것인지 확인하세요.

5. 카카오톡 대화가 사라지지 않게 백업하는 방법

대화 보존이 가장 중요하다면 번호 변경 버튼보다 백업 상태부터 확인하세요.

  1. 기존 카카오톡에서 더보기 → 설정 → 채팅으로 이동합니다.
  2. 대화 백업 메뉴를 선택합니다.
  3. 화면 안내에 따라 백업을 시작합니다.
  4. 백업 데이터 암호화를 위한 백업 비밀번호를 설정합니다.
  5. 백업 진행이 끝날 때까지 기다립니다.
  6. 백업 완료일과 복원 가능 기한을 확인합니다.
  7. 다른 기기에서 복원할 때 동일한 카카오계정으로 로그인한 뒤 백업 비밀번호를 입력합니다.

카카오 고객센터가 안내한 일반 대화 백업의 복원 기한은 14일입니다. 14일이 지나면 백업 데이터가 삭제돼 복원할 수 없습니다. 또한 백업 비밀번호를 잊어버려도 복원할 수 없다는 설명이 있습니다.

6. 새 번호 인증번호가 안 올 때: 점검 순서

번호 변경 과정에서 인증 문자가 오지 않을 때는 휴대전화와 통신사 상태를 나눠 확인해야 합니다.

  1. 번호 오입력 확인: 새 전화번호 숫자를 다시 확인합니다.
  2. 개통 상태 확인: 새 회선이 실제로 개통돼 문자 수신 가능한지 확인합니다.
  3. 통신사·기기 문자 설정 확인: 스팸 차단함, 번호 차단, 메시지 수신 상태를 확인합니다.
  4. 듀얼 SIM·eSIM 확인: 문자 수신 회선이 의도한 번호인지 확인합니다.
  5. 국가·지역 환경 확인: 해외에서 인증 중이라면 통신사 및 국제문자 수신 제한 가능성을 살펴봅니다.

10. 기존 번호를 타인이 사용하게 되면 어떻게 하나요?

휴대전화 번호는 해지 후 다른 이용자에게 재배정될 수 있습니다. 따라서 새 번호로 옮겼다면 기존 번호가 카카오톡에 계속 등록돼 있지 않은지 확인하는 것이 중요합니다.

  1. 앱 안에서 현재 등록된 전화번호가 새 번호인지 확인합니다.
  2. 기존 카카오계정의 보안 설정과 로그인 가능 수단을 점검합니다.
  3. 통신사의 번호 변경·해지 절차가 완료됐는지 확인합니다.
  4. 본인이 요청하지 않은 인증 문자나 로그인 알림이 있다면 공식 카카오계정 보안 도움말을 확인합니다.
  5. 계정에 접근할 수 없거나 타인 사용이 의심된다면 카카오 고객센터에 신고·문의합니다.

단순히 기존 번호가 변경됐다는 이유만으로 누군가 계정에 들어왔다고 단정할 수는 없습니다. 그러나 계정 보안과 새로운 번호 인증 상태는 확인할 가치가 있습니다.

카카오 계정과 통신사 계정은 관리 주체가 다르므로, 통신사 번호 변경이 완료됐더라도 카카오톡 등록 번호가 자동으로 바뀌는지 여부는 앱에서 확인하세요.

11. 자주 묻는 질문

Q1. 카카오톡 전화번호를 바꾸면 대화가 전부 사라지나요?

번호 변경 자체와 대화 데이터 삭제는 같은 일이 아닙니다. 다만 기기 교체나 재설치가 수반되면 대화 백업·복원이 필요할 수 있고, 일반 백업에는 제외되는 데이터가 있습니다. 변경 전에 기존 기기와 백업 상태를 확인하세요.

Q2. 새 번호로 변경할 때 카카오톡을 삭제하고 다시 설치해야 하나요?

항상 그렇지는 않습니다. 카카오는 과거 공식 자료에서 앱 내 전화번호 변경 기능을 안내했고, 일부 오래된 고객센터 도움말에는 재설치 방식이 남아 있습니다. 현재 로그인된 카카오톡에서 번호 변경 메뉴를 먼저 확인하는 편이 안전합니다.

Q3. 전화번호를 바꿔도 같은 카카오계정을 쓸 수 있나요?

카카오 고객센터는 이전 카카오계정으로 로그인하면 친구 목록과 프로필 등 계정 연동 정보를 이어서 사용할 수 있다고 안내합니다. 새 계정을 임의로 만들지 않도록 주의하세요.

Q4. 일반 대화 백업은 언제까지 복원할 수 있나요?

카카오 공식 도움말 기준 백업 후 14일입니다. 백업 비밀번호도 필요하므로 완료 후 기한과 비밀번호를 꼭 확인하세요.

Q5. 일반 대화 백업에 사진과 동영상도 들어가나요?

아니요. 공식 도움말은 일반 대화 백업에서 사진·동영상 등을 제외한다고 안내합니다. 파일은 별도로 보관해야 합니다.

Q6. 새 번호로 인증 문자가 오지 않습니다.

번호 입력 오류, 회선 개통 상태, 통신사의 SMS 제한, 해외 수신 환경 등을 순서대로 점검하세요. 인증을 무작정 반복하지 말고 공식 고객센터의 인증 오류 안내를 확인하는 것이 좋습니다.

Q7. 옛날 번호를 모르면 복원할 수 없나요?

무조건 불가능하다고 단정할 수 없습니다. 기존 카카오계정의 로그인 수단, 본인인증 가능 여부, 백업 데이터 상태에 따라 다릅니다. 이전 기기에 아직 로그인돼 있다면 앱을 삭제하지 말고 먼저 계정 정보를 확인하세요.

Q8. 번호가 바뀌면 친구들에게 자동으로 알림이 가나요?

번호 변경 후 친구별로 어떤 알림이나 동기화가 이루어지는지는 카카오톡 버전과 상대방의 연락처 상태에 영향을 받을 수 있습니다. 모든 친구에게 자동 알림이 간다거나 전혀 가지 않는다고 단정하지 마세요. 연락이 꼭 필요한 사람에게는 별도로 새 번호를 안내하는 편이 확실합니다.
