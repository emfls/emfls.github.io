1. PDF 열기 암호와 편집·인쇄 제한 암호는 무엇이 다른가요?

열기 암호

사용자가 파일을 열 때 암호 입력을 요구합니다. 내용 자체를 볼 수 있는 사람을 제한하는 데 목적이 있습니다. 계약서나 개인정보가 포함된 PDF를 전달할 때 우선 검토할 보호 방식입니다.

권한 암호

문서 열람은 가능하도록 두면서 인쇄, 문서 변경, 내용 복사와 같은 작업에 제한을 설정할 수 있습니다. Acrobat과 미리보기는 이 종류의 권한 설정을 제공하지만, 어떤 제한이 어떤 PDF 열람 프로그램에서 강제되는지는 소프트웨어마다 다를 수 있습니다. 권한 제한만으로 문서 내용의 열람을 막을 수는 없습니다.

파일 잠금과 PDF 암호는 다른 개념

맥 Finder의 '잠김' 속성이나 폴더의 공유 권한, 클라우드 공유 링크의 접근 권한은 PDF 문서 자체에 열기 암호를 거는 것과 다릅니다. 다른 컴퓨터에 파일을 복사했을 때도 암호 입력이 필요한지를 확인해야 합니다.

공식 안내: Adobe PDF 암호화와 권한, Apple 미리보기 PDF 암호 보호

2. 맥에서 무료로 PDF 비밀번호 거는 방법: 미리보기

Apple의 미리보기(Preview)는 별도의 PDF 유료 프로그램을 설치하지 않고도 문서를 열 때 필요한 암호를 지정할 수 있습니다.

  1. Finder에서 대상 PDF를 찾아 미리보기 앱으로 엽니다.
  2. 메뉴 막대의 파일 → 내보내기를 선택합니다.
  3. 원본을 보존하려면 내보낼 파일 이름을 새 이름으로 지정합니다.
  4. 내보내기 창의 권한 버튼을 누릅니다.
  5. 문서를 열 때 암호 요구 옵션을 선택하고 암호를 두 번 입력합니다.
  6. 창에 표시되는 소유자 암호도 입력하고 확인합니다.
  7. 적용 → 저장을 선택합니다.
  8. 저장한 새 PDF를 닫고 다시 열어 암호 입력창이 실제로 나타나는지 확인합니다.

Apple의 설명에 따르면 소유자 암호는 인쇄나 변경 같은 권한을 관리하는 데 쓰이며, 문서 열기 암호와 같거나 다르게 설정할 수 있습니다. 따라서 두 암호를 혼동하지 않도록 별도로 기록해 두세요.

PDF가 원본 그대로 덮어써지면 어떻게 하나요?

암호를 넣기 전에 원본을 복사해 두거나 내보내기 단계에서 새 이름을 입력하세요. 보호된 사본을 검증한 뒤에 원본의 보관·삭제 여부를 결정하면 됩니다. 원본을 먼저 지우지 않는 것이 안전합니다.

공식 안내: Apple — 미리보기 앱에서 PDF에 암호 설정

3. 맥 미리보기에서 인쇄·복사·주석 기능도 제한하려면

파일 → 내보내기 → 권한에서 어떤 동작을 소유자 암호 없이 허용할지 선택할 수 있습니다. 프린트, 콘텐츠 변경 등 항목의 체크 상태에 따라 암호가 필요한 작업이 달라집니다.

이미 보호된 PDF의 권한을 바꾸려면 PDF를 미리보기로 연 다음 파일 → 권한 편집을 확인하세요. 기존 설정을 변경하려면 필요한 소유자 암호를 입력해야 할 수 있습니다.

단, 화면에 보이는 내용을 사진으로 촬영하는 것까지 PDF의 인쇄·복사 권한으로 완전히 막을 수 있는 것은 아닙니다. 중요 문서는 비밀번호 외에도 수신자 선정과 전달 방식이 중요합니다.

4. Adobe Acrobat에서 기존 PDF에 비밀번호 설정하는 방법

Adobe Acrobat 데스크톱의 공식 메뉴는 다음과 같습니다.

  1. Acrobat에서 보호하려는 PDF를 엽니다.
  2. 모든 도구 → PDF 보호로 이동합니다.
  3. 왼쪽 창에서 암호로 보호를 선택합니다.
  4. 암호 용도를 보기 또는 편집 중에서 선택합니다.
  5. 암호를 입력하고 확인란에 한 번 더 입력합니다.
  6. 적용을 누른 뒤 변경된 PDF를 저장합니다.
  7. 파일을 다시 열어 의도한 암호가 요구되는지 검사합니다.

보기 암호가 필요한 상황에 편집 암호만 설정하면, 문서가 열리는 것을 막으려던 원래 목적에 맞지 않을 수 있습니다. 저장하기 전 보기 제한인지, 편집 제한인지를 꼭 확인하세요.

Acrobat에는 고급 설정을 통한 암호로 암호화 메뉴도 있으며, 문서를 열 때의 암호와 인쇄·편집·복사 허용 범위를 더 세부적으로 설정할 수 있습니다. 라이선스나 설치 버전에 따라 사용 가능한 기능은 다를 수 있습니다.

공식 안내: Adobe — PDF에 암호 추가, Adobe — 고급 암호화 및 인쇄·편집 제한

5. Windows에서 Word 파일을 암호화된 PDF로 저장하는 방법

Word 원본 문서가 있을 때는 PDF로 내보내는 과정에서 암호화를 설정할 수 있습니다.

  1. Windows용 Word 데스크톱 앱에서 원본 문서를 엽니다.
  2. 파일 → 다른 이름으로 저장 또는 PDF 내보내기 메뉴로 이동합니다.
  3. 파일 형식을 PDF로 선택합니다.
  4. PDF 저장 창에서 옵션을 열고 암호로 문서 암호화(Encrypt the document with a password) 항목을 찾습니다.
  5. 해당 항목을 선택한 뒤 암호를 두 번 입력합니다.
  6. PDF를 저장하고 별도 PDF 열람 프로그램으로 다시 열어 확인합니다.

주의: Word의 파일 → 정보 → 문서 보호 → 암호 설정은 Word 문서 자체를 보호하는 기능입니다. PDF로 변환된 결과물이 자동으로 같은 암호를 요구한다고 생각하지 마세요. 반드시 PDF 저장 옵션에서 암호화가 선택됐는지 확인해야 합니다.

원래 파일이 PDF밖에 없다면?

Word로 PDF를 열어 편집 가능한 문서로 변환할 수 있지만, 복잡한 표와 서식이 원본처럼 유지되지 않을 수 있습니다. 원래 PDF의 레이아웃 보존이 중요하면 기존 PDF에 바로 암호를 적용하는 기능을 제공하는 프로그램을 사용하는 편이 적합합니다.

Word 웹 버전에서도 가능한가요?

Microsoft는 웹용 Word가 암호로 문서를 암호화할 수 없다고 안내합니다. 데스크톱 앱에서 PDF 저장·암호화 기능을 확인하세요.

공식 안내: Microsoft — Office에서 PDF로 저장 및 암호화, Microsoft — Word 문서 암호 보호

6. 설치 없이 웹에서 PDF 암호 설정하기: 편리하지만 업로드 확인 필수

Adobe Acrobat 웹의 공식 절차는 편집 → PDF 보호 → 파일 선택 → 암호 입력·확인 → 암호 설정입니다. 보호된 사본은 Adobe의 클라우드 스토리지에 저장될 수 있으며, 파일 이름에 _protected가 붙을 수 있습니다.

파일이 클라우드에 보관되는 방식이라는 점을 먼저 이해해야 합니다. 주민등록번호, 급여명세서, 의료기록, 신분증 사본, 계약상 비밀정보처럼 민감한 문서는 회사 규정과 개인정보 처리 조건을 확인한 다음 업로드 여부를 결정하세요.

사이트 이름이나 검색 광고만 보고 임의의 '무료 PDF 암호' 사이트에 파일을 올리기보다는 서비스 사업자와 파일 보관 정책, 업로드 후 삭제 방법을 먼저 확인하는 것이 좋습니다.

공식 안내: Adobe — 웹용 Acrobat으로 PDF 보호

7. PDF 비밀번호 해제하는 방법: 기존 암호를 알고 있을 때

자신이 관리할 권한이 있는 문서이고 필요한 암호를 알고 있다면, Acrobat의 PDF 보안 설정에서 암호 요구를 제거한 뒤 다시 저장할 수 있습니다.

  1. Acrobat에서 해당 PDF를 엽니다. 열기 암호가 요구되면 정상적으로 입력합니다.
  2. 모든 도구 → PDF 보호로 이동합니다.
  3. 고급 속성 → 보안 속성 설정을 찾습니다.
  4. 보안 탭에서 설정 변경을 선택합니다.
  5. 필요에 따라 문서를 열 때 암호 요구 또는 편집·인쇄 제한 옵션을 해제합니다.
  6. 권한 암호를 요구하면 적법하게 보유한 암호를 입력합니다.
  7. 확인 후 별도의 이름으로 PDF를 저장합니다.
  8. 저장된 사본을 다시 열어 더 이상 암호를 요구하지 않는지 검사합니다.

암호를 모르는 파일은 정상적인 방법으로 해제하지 못할 수 있습니다. 암호를 우회한다는 비공식 프로그램에 민감한 파일을 넣기보다는 발신자에게 암호를 재요청하거나 원본 소유자에게 보호되지 않은 사본을 요청하세요.

공식 안내: Adobe — PDF 암호 제거

8. '비밀번호 설정했는데 그냥 열림' 문제 해결

증상가장 먼저 확인할 항목
PDF가 암호 없이 바로 열림편집 암호만 설정하지 않았는지, 열기 암호를 선택했는지
저장 전에는 암호가 있었는데 다시 열면 없음저장 또는 내보내기가 완료됐는지, 원본과 사본을 혼동했는지
PDF가 인쇄는 되지만 복사가 제한됨인쇄·복사 권한이 각각 별도로 설정됐는지
암호가 맞는데 열리지 않음대소문자·키보드 배열·붙여넣기 공백·사용한 파일 버전
다른 사람만 열지 못함전달한 파일이 보호된 최신 사본인지, 암호 전달 내용이 일치하는지
Windows 기본 PDF 메뉴에서 암호화 옵션이 안 보임단순 PDF 프린터와 암호화 지원 앱의 차이 확인

암호화 여부는 같은 프로그램에서만 확인하지 말고, 가능하다면 다른 정상 PDF 열람기에서도 새 파일을 열어 테스트하는 것이 좋습니다. 암호 입력창이 뜬다는 사실뿐 아니라 내용을 정상적으로 읽을 수 있는지도 확인하세요.

9. PDF 암호를 안전하게 만드는 방법

  • 다른 사이트 로그인에 사용하는 암호를 그대로 재사용하지 않습니다.
  • 이름, 생년월일, 휴대전화 뒷자리, 파일 제목 같은 쉬운 조합을 피합니다.
  • 충분히 길고 추측하기 어려운 고유한 암호를 사용합니다.
  • 파일과 암호를 가능한 한 다른 전달 경로로 보냅니다.
  • 사내·기관 문서라면 내부 보안 규정에 맞는 암호화 수준과 파일 보관 위치를 따릅니다.
  • 암호를 기억하지 못할 경우를 대비해 신뢰할 수 있는 암호 관리자 등 안전한 장소에 기록합니다.

PDF에 암호가 있더라도 열람 권한이 있는 상대가 내용을 재전달하거나 화면을 촬영하는 위험은 남습니다. 암호 설정은 정보 보호 수단 중 하나이지 모든 유출 위험을 없애는 장치는 아닙니다.

10. 보내기 전에 마지막으로 확인할 체크리스트

  • ☐ 원본 PDF를 별도로 보관했습니다.
  • ☐ 암호를 걸 새 파일의 이름과 저장 위치를 확인했습니다.
  • ☐ 열기 암호와 편집·인쇄 권한 암호를 혼동하지 않았습니다.
  • ☐ 암호를 모르는 사용자가 파일을 열 수 없는지 직접 테스트했습니다.
  • ☐ 암호를 입력하면 본문과 표, 첨부 내용이 정상적으로 보이는지 확인했습니다.
  • ☐ 온라인 도구를 사용했다면 업로드·보관 정책을 확인했습니다.
  • ☐ 문서를 받은 사람에게 암호를 전달할 안전한 경로를 정했습니다.
  • ☐ 암호 해제를 원했다면 보호가 해제된 사본을 별도로 저장했습니다.

11. 자주 묻는 질문

Q. PDF에 무료로 비밀번호를 걸 수 있나요?

맥은 Apple의 기본 미리보기 앱에서 열기 암호를 설정할 수 있습니다. Windows에서는 이미 보유한 Word 데스크톱 앱의 PDF 내보내기 옵션을 이용할 수 있지만, 별도의 상용 앱이나 웹 서비스는 기능·계정·요금 조건이 다릅니다.

Q. Adobe Acrobat Reader만으로 설정할 수 있나요?

Acrobat의 보호 기능은 제품 종류와 구독·권한에 따라 제공 범위가 다를 수 있습니다. 설치된 제품에서 PDF 보호 메뉴가 실제로 사용 가능한지 확인하세요. Reader가 PDF를 읽을 수 있다는 사실과 암호를 새로 적용할 수 있다는 것은 별개입니다.

Q. PDF 암호와 ZIP 압축파일 암호는 같은가요?

아닙니다. ZIP 암호는 압축파일 자체를 보호하는 방식입니다. 압축을 풀어 얻은 PDF가 암호 없이 열릴 수 있으므로, 파일을 어떤 방식으로 보내는지에 따라 보호 범위가 다릅니다.

Q. 인쇄만 막고 열람은 허용할 수 있나요?

Acrobat과 미리보기의 권한 설정에서 인쇄·편집 기능을 제한할 수 있습니다. 다만 모든 종류의 뷰어에서 제한이 동일하게 강제된다고 보장할 수 없고, 문서 내용을 보는 것까지 막는 기능은 아닙니다.

Q. 암호를 잊어버렸다면 새로 설정하면 되나요?

기존 PDF를 열거나 권한을 변경하기 위해 기존 암호가 필요할 수 있습니다. 원본 문서가 남아 있다면 원본에서 보호된 PDF를 다시 만드는 방법이 가장 확실합니다. 필요한 암호를 모르는 타인의 문서라면 발신자에게 요청하세요.

Q. Google Drive에서 특정 사람에게만 공유하면 PDF 파일도 암호화되나요?

클라우드 공유 권한과 PDF 파일 자체의 열기 암호는 다른 설정입니다. 다운로드된 파일을 다른 곳으로 옮겼을 때도 암호가 필요한지 별도로 확인해야 합니다.
