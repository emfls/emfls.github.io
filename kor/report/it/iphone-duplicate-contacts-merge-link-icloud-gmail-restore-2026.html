아이폰 주소록에서 같은 사람의 이름이 두 번 뜨거나, 카카오톡·전화 앱에서 동일한 전화번호가 여러 개로 표시될 때가 있습니다. 새 아이폰으로 옮기거나 Gmail 계정을 추가한 뒤 중복이 생긴 사례도 있습니다.

아이폰에는 연락처 앱의 '중복된 항목 보기' 기능이 있습니다. 동일한 성과 이름의 연락처를 찾아 병합할 수 있고, 서로 다른 계정에 저장된 연락처는 '연락처 링크' 기능으로 목록에서 하나처럼 보이게 할 수 있습니다.

하지만 '병합'과 '링크'는 다른 작업입니다. 연락처가 iCloud와 Google 계정 양쪽에 저장된 경우, 눈에 보이는 중복을 없애려다가 원본 계정의 연락처를 삭제하면 다른 기기에도 영향이 갈 수 있습니다. 이번 글은 백업 → 중복 원인 확인 → 병합 또는 링크 → 결과 검증 → 필요 시 복원 순서로 정리했습니다.

검증 기준: 2026년 11월 3일, Apple 공식 한국어 iPhone·iCloud 사용 설명서. 실제 사용자 연락처를 병합해 성공을 측정한 후기가 아니며, iOS 버전과 등록된 계정에 따라 화면이 다를 수 있습니다.

1. 핵심 요약: 중복 연락처 유형별 해결 방법

현재 상태우선 시도할 기능주의할 점
연락처에 같은 이름이 두 번 이상 보임중복된 항목 보기 → 검토·병합동일 인물인지 직접 검토
이름 표기가 달라 자동 중복으로 안 잡힘연락처 선택 → 편집 → 연락처 링크링크는 원본 계정 데이터를 물리적으로 합치지 않음
iCloud와 Gmail에 같은 사람이 있음목록 및 계정별 저장 위치 확인 → 링크 검토계정에서 삭제하면 다른 기기에도 영향 가능
중복된 항목 보기 메뉴가 안 보임이름·계정 종류를 확인하고 수동 링크항상 오류라고 볼 수 없음
합친 뒤 연락처가 없어짐iCloud.com의 연락처 복원 조건 확인iCloud에 저장된 데이터에 한정
수백 개를 일괄 정리하려는 경우먼저 연락처 내보내기(vCard) 백업'모두 병합' 전 오류나 동명이인 검토

결론부터: 자동 중복 감지가 가능한 연락처는 '병합', 서로 다른 계정에 분리된 항목은 '링크'를 우선 검토하는 것이 안전합니다.

2. 아이폰 중복 연락처 병합 방법: '중복된 항목 보기'

Apple 공식 안내에 따르면 성과 이름이 동일한 연락처 카드가 두 개 이상 있을 때 중복 연락처를 병합할 수 있습니다.

  1. 아이폰에서 연락처 앱을 엽니다.
  2. 화면 상단 부근의 '내 카드' 아래에 표시되는 '중복된 항목 보기'를 찾습니다.
  3. 해당 메뉴를 누르면 중복 후보 목록이 나타납니다.
  4. 중요한 거래처나 가족 연락처라면 먼저 개별 항목을 선택합니다.
  5. 이름, 전화번호, 이메일 주소를 비교합니다.
  6. 같은 사람임이 확인되면 병합을 선택합니다.
  7. 나머지 후보도 검토하고, 오류가 없다는 확신이 있을 때만 '모두 병합'을 선택합니다.
  8. 연락처 검색에서 합쳐진 이름을 다시 찾고 전화번호와 이메일이 남아 있는지 확인합니다.

'모두 병합'은 빠르지만 모든 후보를 일괄 처리하므로, 회사 동료·동명이인 등 서로 다른 사람의 연락처가 섞였는지 먼저 살펴보는 것이 좋습니다.

Apple은 개별 연락처를 검토하고 병합하거나 '모두 병합'하는 두 방식 모두를 공식 안내합니다.

3. '중복된 항목 보기' 메뉴가 안 뜨는 이유

자동 중복 후보가 없다고 해서 연락처 앱이 고장 났다고 단정할 수는 없습니다.

Apple 사용 설명서에는 성과 이름이 같은 연락처 카드가 둘 이상 있는 경우 중복 연락처를 병합할 수 있다고 나옵니다. 예를 들어 아래 두 연락처는 같은 사람이지만 이름 표기만 보면 서로 다릅니다.

  • '김민수' — 010-1234-5678, Gmail 계정
  • '민수 회사' — 010-1234-5678, iCloud 계정

이처럼 이름이 다른 두 항목은 동일 인물이어도 자동 감지 후보에 반드시 나타난다고 보장할 수 없습니다.

메뉴가 없을 때 점검 순서

  1. 연락처 앱을 직접 열었는지 확인합니다.
  2. 앱 상단에서 내 카드 아래 중복 항목 안내가 있는지 살펴봅니다.
  3. 동일한 사람의 연락처 이름이 정확히 같은지 확인합니다.
  4. 이름이 다르지만 같은 인물이라면 연락처 링크를 검토합니다.
  5. 목록을 열어 iCloud와 Gmail 등 출처가 다른 연락처가 동시에 표시되는지 살펴봅니다.
  6. 연락처를 임의로 삭제하기 전에 원본이 어느 계정에 저장됐는지 확인합니다.

주의: 자동 병합 표시가 없다는 이유만으로 연락처 동기화를 모두 끄거나 계정을 삭제하지 마세요. 숨겨진 것이 아니라 다른 계정에 저장돼 있는 것일 수 있습니다.

공식 근거: Apple — 중복 연락처 해결 및 수동 링크

4. 서로 다른 이름의 연락처를 직접 하나처럼 표시하기: 수동 링크

이름이 서로 다르거나 iCloud와 Google에 따로 저장돼 있을 때는 수동으로 연락처를 링크할 수 있습니다.

  1. 연락처 앱에서 통합해서 볼 사람을 선택합니다.
  2. 오른쪽 위 편집을 누릅니다.
  3. 연락처 링크를 선택합니다.
  4. 같은 사람의 다른 연락처 카드를 찾아 선택합니다.
  5. 링크를 눌러 마무리합니다.
  6. 연락처 목록으로 돌아가 하나의 통합 카드로 표시되는지 확인합니다.

예를 들어 '엄마'라는 이름의 연락처가 iCloud에, '어머니'라는 이름의 연락처가 Google 계정에 따로 존재한다면 수동 링크로 목록에서 하나처럼 표시하도록 관리할 수 있습니다.

링크해도 원본 데이터는 합쳐지지 않습니다

Apple의 공식 설명에서 특히 중요한 부분입니다. 연락처를 링크해도 실제 원본 연락처가 병합되는 것은 아닙니다. 서로 다른 계정의 연락처는 각각 유지되면서 통합 카드 형태로 보이는 것입니다.

링크한 연락처 이름이 서로 다를 때는 통합 카드에서 어떤 이름을 표시할지 선택할 수 있습니다. Apple은 연결된 카드 중 한 항목의 이름을 선택하고 '통합된 카드에서 이 이름 사용'에 해당하는 옵션을 이용하도록 안내합니다.

주의: 통합 카드의 정보를 수정하면 해당 정보가 존재하는 원본 계정에도 변경 사항이 반영될 수 있습니다. 링크를 단순한 '미리보기'라고 생각하고 중요한 전화번호를 함부로 수정하지 마세요.

공식 근거: Apple — 연락처 수동 링크와 원본 계정 관련 주의

5. Gmail·iCloud 연락처가 동시에 보일 때 원인 확인

아이폰은 iCloud뿐 아니라 Google, Microsoft Exchange 등 여러 계정의 연락처를 표시할 수 있습니다. 같은 사람이 각 계정에 들어 있으면 연락처 목록에서 중복된 것처럼 나타날 수 있습니다.

어떤 계정이 연결돼 있는지 확인

  1. 아이폰 설정 앱을 엽니다.
  2. 앱 → 연락처로 이동합니다.
  3. 연락처 계정을 선택합니다.
  4. iCloud, Google, Exchange 등 연결된 계정을 확인합니다.
  5. 연락처 앱의 목록에서 특정 계정만 선택해 같은 이름이 여러 곳에 있는지 살펴봅니다.

여기서 해야 할 일은 계정을 삭제하는 것이 아니라, 중복이 같은 계정 내부에서 발생했는지 또는 다른 계정 사이에서 발생했는지 구분하는 것입니다.

중복 원인확인할 것일반적인 접근
같은 iCloud 계정 내부에서 동일 이름 중복두 항목이 같은 사람인가자동 병합 검토
iCloud와 Gmail 양쪽에 같은 사람 존재원본 계정 각각의 연락처 정보수동 링크 검토
회사 Exchange와 개인 연락처 겹침회사 계정의 접근·동기화 규칙임의 삭제보다 표시·링크 검토
이전 기기 연락처를 여러 번 가져옴가져오기 원본과 중복 수백업 후 후보별 병합

이 단계에서 전체 연락처 목록을 끄거나 계정을 제거하면 연락처가 사라진 것처럼 보일 수 있습니다. iCloud 연락처 동기화 역시 켜고 끄는 방식에 따라 기기에 남는 복사본이 달라질 수 있습니다.

6. 중복 정리 전에 연락처 백업하는 방법: 아이폰에서 내보내기

수십·수백 개의 중복 항목을 정리하려면 작업 전에 연락처 복사본을 만들어 두는 것을 권장합니다.

Apple 공식 iPhone 사용 설명서는 연락처 목록을 내보내는 기능을 제공합니다.

  1. 아이폰의 연락처 앱을 엽니다.
  2. 화면의 목록 버튼을 선택합니다.
  3. 기존 목록을 길게 터치합니다.
  4. 내보내기를 선택합니다.
  5. 내보낼 필드(전화번호·이메일 등)를 검토합니다.
  6. 완료를 누릅니다.
  7. 파일을 저장하거나 본인이 관리하는 안전한 위치로 공유합니다.

이 방법은 연락처 정보의 사본을 만드는 데 유용합니다. 다만 연락처가 여러 계정에 분산돼 있다면 내보낼 목록이 무엇인지 확인해야 합니다. 하나의 계정 목록만 내보냈다면 다른 계정의 연락처까지 모두 보관했다고 가정할 수 없습니다.

컴퓨터·태블릿에서 iCloud 연락처 전체 내보내기

iCloud 연락처를 사용한다면 다음 경로도 가능합니다.

  1. 컴퓨터 또는 태블릿에서 icloud.com/contacts에 로그인합니다.
  2. 연락처 목록의 동작 메뉴 → 모든 연락처 선택을 선택합니다.
  3. 공유 → vCard 내보내기를 선택합니다.
  4. 내려받은 .vcf(vCard) 파일을 안전하게 보관합니다.

vCard에는 개인정보가 포함되므로 불특정 파일 변환 사이트에 업로드하지 않는 편이 좋습니다. 또한 Apple은 iCloud.com의 연락처 기능 사용에 태블릿 또는 컴퓨터가 필요하다고 안내합니다.

공식 근거: Apple — iPhone 연락처 내보내기, iCloud.com — vCard 내보내기

7. 연락처를 합친 뒤 번호가 사라졌다면: 삭제와 동기화 문제 구별

연락처가 보이지 않는 경우 실제로 삭제됐는지 또는 다른 계정의 연락처가 표시되지 않는지부터 구분해야 합니다.

먼저 아래 순서대로 확인하세요.

  1. 연락처 앱의 목록에서 모든 계정의 연락처가 표시되는지 확인합니다.
  2. 문제의 연락처가 iCloud·Gmail·Exchange 중 어느 계정에 저장됐는지 점검합니다.
  3. 연락처를 병합 또는 링크한 직후라면 통합 카드 안에 번호와 이메일이 남아 있는지 확인합니다.
  4. iCloud 동기화가 꺼진 상태라면 기기 표시 설정을 검토합니다.
  5. 원본이 iCloud에 저장돼 있었는데 실제로 지워졌다면 iCloud.com 데이터 복구 기능을 확인합니다.

iCloud 연락처가 실제로 삭제된 경우 복원 경로

Apple은 iCloud에 저장된 연락처의 이전 아카이브 버전으로 복원하는 기능을 제공합니다.

  1. 컴퓨터 또는 태블릿에서 icloud.com/contacts에 접속합니다.
  2. Apple 계정으로 로그인합니다.
  3. 앱 런처에서 데이터 복구를 선택합니다.
  4. 연락처 복원을 선택합니다.
  5. 표시되는 백업 시각을 확인합니다.
  6. 원하는 버전 옆의 복원을 누릅니다.
  7. 복원이 완료될 때까지 연락처를 새로 편집하지 않습니다.

중요: 이는 특정 연락처 하나만 자동으로 되살리는 것과는 다릅니다. iCloud에 저장된 연락처 전체를 이전 아카이브 버전으로 되돌리는 작업이므로, 그사이 추가한 연락처·변경 사항이 영향을 받을 수 있습니다. Apple에 따르면 복원 전 현재 버전도 먼저 아카이브합니다.

방금 삭제한 연락처의 아카이브가 나타나는 데 최대 24시간이 걸릴 수 있다는 공식 설명도 있습니다. 단, 이는 iCloud에 저장된 연락처를 위한 복원 경로이며, Gmail·Exchange에만 저장된 연락처까지 복원하는 기능으로 이해하면 안 됩니다.

9. 중복 연락처 정리 전 실제 사례로 구분하기

사례 A: 이름과 번호가 동일한 친구가 두 번 저장됨

연락처 앱에서 중복된 항목 보기를 확인하고, 같은 인물인지 검토한 후 병합합니다.

사례 B: '김대리'와 '김민수'가 같은 전화번호로 두 번 뜸

자동 중복 목록에 없을 수 있습니다. 두 항목이 같은 인물임을 확인한 뒤 수동 링크를 검토합니다.

사례 C: 새 아이폰에서 모든 연락처가 두 배로 보임

처음부터 '모두 병합'을 누르기보다 iCloud와 Google 등 여러 계정이 동시에 연락처를 표시하는지 확인합니다. 서로 다른 계정에 원본이 있는 경우 삭제보다 링크를 우선 검토하세요.

사례 D: 연락처를 삭제했더니 아이패드에서도 사라짐

같은 동기화 계정에 저장된 연락처가 삭제됐을 수 있습니다. iCloud에 있던 자료라면 iCloud.com의 연락처 복원을 확인합니다. Gmail에 저장된 원본은 Google 계정의 연락처 복구 경로를 별도로 확인해야 합니다.

사례 E: 수동 링크했는데 다른 기기에서 여전히 두 개로 보임

링크는 한 아이폰의 목록에서 통합 카드로 보이게 하는 기능입니다. 원본 데이터를 단일 계정으로 완전히 합치는 작업이 아니므로 앱·기기·동기화 조건에 따라 표현이 다를 수 있습니다. 원본 계정별 상태를 확인하세요.

10. 자주 묻는 질문

Q1. 아이폰 중복 연락처는 자동으로 병합할 수 있나요?

Apple 공식 안내에서는 '내 카드' 아래 '중복된 항목 보기' → 개별 검토 또는 '모두 병합'을 제공합니다. 다만 같은 사람인지 확인하는 과정이 중요합니다.

Q2. '중복된 항목 보기'가 왜 없나요?

자동 중복 후보가 없거나 이름 표기·계정 구성이 다를 수 있습니다. Apple은 성과 이름이 같은 연락처가 둘 이상일 때 병합할 수 있다고 안내하므로, 이름이 다른 연락처는 수동 링크를 검토하세요.

Q3. iCloud와 Gmail에 저장된 연락처를 링크하면 한 계정으로 합쳐지나요?

아닙니다. Apple은 연락처 링크는 실제 원본 병합이 아니라고 설명합니다. 원본 연락처는 해당 계정에 남아 있습니다.

Q4. 두 연락처를 링크하면 어느 이름이 표시되나요?

통합 카드에 하나의 이름이 표시되며, Apple은 링크된 카드에서 통합 카드에 사용할 이름을 선택할 수 있다고 안내합니다.

Q5. 연락처를 하나 삭제하면 다른 아이폰에서도 지워지나요?

동기화된 이메일·클라우드 계정의 연락처를 삭제하면 같은 계정이 연결된 다른 기기에도 반영될 수 있습니다. 삭제 전 원본 계정을 확인하세요.

Q6. 잘못 삭제한 iCloud 연락처를 복구할 수 있나요?

Apple이 제공하는 iCloud.com → 데이터 복구 → 연락처 복원 기능을 확인할 수 있습니다. 단, 이전 버전으로 연락처 전체를 복원하는 작업이며, 사용 가능한 아카이브가 있어야 합니다.

Q7. 아이폰으로 연락처 전체를 백업할 수 있나요?

연락처 앱의 목록 길게 누르기 → 내보내기 또는 iCloud.com에서 모든 연락처 선택 → vCard 내보내기를 이용할 수 있습니다. 여러 계정에 나뉘어 있다면 모든 저장 위치가 포함됐는지 확인하세요.

Q8. 중복된 연락처를 정리하면 사진·메시지도 지워지나요?

연락처 정리와 사진·문자 기록 삭제는 별도의 기능입니다. 그러나 연락처와 연동된 앱이나 계정에서 이름 표시가 달라질 수 있으므로 중요한 대화방과 번호가 제대로 표시되는지 확인하는 것이 좋습니다.

Q9. '모두 병합'을 누르기 전에 무엇을 해야 하나요?

동명이인이나 중요한 거래처를 잘못 합치지 않도록 개별 후보를 검토하고, 가능하면 vCard 백업을 먼저 만들어 두는 것이 안전합니다.
