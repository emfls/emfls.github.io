브라우저에 광고 차단, 번역, 메모, 쇼핑 가격 비교, PDF 저장 등의 확장 프로그램을 설치하면 편리합니다. 그런데 설치할 때 지나쳤던 ‘방문하는 모든 웹사이트의 데이터를 읽고 변경’ 권한이 그대로 남아 있을 수 있습니다. 이 문구가 나타났다고 확장 프로그램이 이미 개인정보를 유출했다는 뜻은 아닙니다. 다만 어디에 접근할 수 있는 권한을 가지고 있는지 확인하고, 실제 필요한 범위로 줄이는 일은 개인정보 보호에 도움이 됩니다.

이번 글은 Google Chrome, Microsoft Edge, Mozilla Firefox의 공식 도움말을 바탕으로 구성한 ‘15분 브라우저 확장 권한 감사’ 실습입니다. 단순히 위험한 확장 프로그램을 삭제하라는 글이 아닙니다. 사용 중인 확장 기능을 유지하면서 사이트 접근 범위·시크릿 모드·파일 URL 접근·사용하지 않는 확장·문제 발생 시 원인 비교를 체계적으로 확인하는 방법을 담았습니다.

이 글의 15분 과정과 위험 분류표는 독자가 직접 적용할 수 있도록 구성한 자체 점검 방식으로, Google·Microsoft·Mozilla가 제공하는 공식 인증 검사나 보안 보증 기준은 아닙니다. 실제 점검에 걸리는 시간은 설치된 확장 수와 브라우저 종류에 따라 달라집니다. 특히 회사·학교가 관리하는 브라우저는 관리 정책이 적용될 수 있으므로 임의로 해제하지 마세요.

1. 먼저 구분하세요: 웹사이트 권한과 확장 프로그램 권한

‘사이트 권한’이라는 말이 비슷해도 웹사이트 자체에 부여한 권한과 브라우저 확장 프로그램이 사이트에서 데이터를 읽고 변경할 권한은 서로 다른 설정입니다.

구분웹사이트에 부여한 권한확장 프로그램의 사이트 접근 권한
주체방문한 웹사이트설치된 브라우저 확장 기능
예시사이트가 카메라·위치·알림 사용확장이 페이지 데이터를 읽거나 변경
Chrome 점검설정 → 개인정보 보호 및 보안 → 사이트 설정확장 프로그램 관리 → 세부정보 → 사이트 액세스
변경 목적웹사이트별 기능 제한확장이 작동하는 사이트 범위 축소
혼동 주의알림 차단이 확장 기능 제거는 아님확장 권한 변경이 사이트 알림 설정을 대신하지 않음

Chrome 공식 도움말은 웹사이트의 카메라·마이크·알림·위치 등 권한을 사이트 설정에서 관리하도록 안내합니다. 반면 확장 프로그램의 사이트 접근은 별도 확장 관리에서 설정할 수 있습니다.

실습 목표: 이번 감사에서는 ‘사이트 자체의 알림 허용’이 아니라 설치된 확장 프로그램이 어떤 웹페이지와 데이터에 접근하도록 허용됐는지를 확인합니다.

2. 15분 감사의 핵심: 확장 하나마다 세 가지 질문

확장을 삭제할지 고민하기 전에 다음 질문 세 가지를 답해 보세요.

  1. 지금도 쓰는가? 설치한 지 오래됐지만 사용 목적을 기억할 수 없는 확장인가?
  2. 어떤 사이트에서 필요한가? 한 쇼핑몰의 가격 비교에 쓰는데 모든 웹사이트 접근을 허용하고 있지는 않은가?
  3. 일반 창 밖에서도 필요한가? 시크릿 모드나 로컬 파일을 열 때도 해당 확장이 실행돼야 하는가?

예를 들어 특정 쇼핑몰 한 곳에서만 가격을 비교하는 확장이 인터넷뱅킹이나 업무용 메일 사이트에까지 자동으로 접근할 이유가 있는지 확인할 수 있습니다. 단, 확장의 기능에 따라 여러 사이트 접근이 실제로 필요할 수 있으므로 모든 사이트 권한 자체를 무조건 악성의 증거로 취급해서는 안 됩니다.

Chrome 개발자 문서는 확장이 기능을 실행하기 위해 API 권한, 호스트 권한, 콘텐츠 스크립트 권한 등을 요청할 수 있다고 설명합니다. 즉, 하나의 권한 문구만 보고 확장이 할 수 있는 일을 모두 판단할 수는 없습니다.

3. 독자 제작 ‘15분 권한 감사’ 시간표

아래 시간표는 확장 프로그램 5개 안팎을 표본으로 확인할 때의 진행 예시입니다. 확장이 많이 설치돼 있거나 관리용 브라우저라면 더 오래 걸릴 수 있습니다.

목표 시간확인 작업남겨야 할 결과
0~3분설치된 확장 목록을 열고 이름 기록사용 중·미사용 구분
3~6분각 확장의 사이트 접근 범위 확인클릭 시·특정 사이트·모든 사이트
6~9분필요한 확장 하나의 접근 범위를 좁혀 시험실제 기능 작동 여부
9~12분시크릿 모드·파일 URL·관리 정책 확인불필요한 예외 제거
12~15분미사용 확장 비활성화·결과 기록유지·제한·삭제 후보 목록

이 실습은 실제 비밀번호·개인 메시지·계좌정보를 입력해서 동작을 시험하지 않습니다. 공개된 일반 웹페이지 또는 자신이 만든 테스트 문서에서 기능이 작동하는지만 확인하세요.

실습 전 준비

브라우저를 업데이트하고 중요한 탭에 입력 중인 작업은 저장하세요. 설정을 바꾸기 전 각 확장의 이름과 기존 접근 설정을 메모하면 기능이 동작하지 않을 때 원상 복원하기 쉽습니다. 회사·학교 PC라면 정책을 우선 확인합니다.

4. Chrome: 확장 목록을 빠르게 여는 방법

Google Chrome에서는 공식 메뉴로 설치된 확장을 확인할 수 있습니다.

  1. 컴퓨터에서 Chrome을 엽니다.
  2. 오른쪽 위 **더보기(점 3개)**를 선택합니다.
  3. 확장 프로그램 → 확장 프로그램 관리로 이동합니다.
  4. 설치된 확장 프로그램의 이름과 켜짐·꺼짐 상태를 확인합니다.
  5. 검사할 확장에서 **세부정보(Details)**를 선택합니다.
  6. 사이트 접근 권한과 시크릿 모드 허용 여부 등을 확인합니다.

Chrome 주소창에 chrome://extensions를 직접 입력해 관리 화면을 여는 방법도 있습니다. 다만 화면의 정확한 명칭과 배치는 Chrome 업데이트 또는 관리 정책에 따라 조금 달라질 수 있습니다.

확장 아이콘이 안 보여도 설치돼 있을 수 있나요?

그렇습니다. 도구 모음에서 확장 아이콘을 숨겨 놓아도 설치된 상태일 수 있습니다. 주소창 옆 아이콘만 보고 설치 여부를 판단하지 말고 확장 프로그램 관리 목록 전체를 확인하세요.

5. Chrome의 세 가지 사이트 접근 권한 차이

Google은 Chrome 확장의 웹사이트 접근을 선택할 때만, 특정 사이트, 모든 사이트 등으로 관리할 수 있다고 안내합니다.

접근 방식의미어울리는 사용 예
확장을 선택할 경우해당 탭·창에서 사용자가 확장을 클릭할 때 접근가끔 쓰는 페이지 분석·번역
특정 사이트에서지정한 사이트에서 자동 접근 가능특정 업무 사이트 전용 도구
모든 사이트에서요청된 범위의 여러 사이트에서 자동 접근 가능광범위한 사이트 적용이 필요한 기능

‘확장을 선택할 경우’가 어떤 뜻인가요?

Chrome 도움말에 따르면 이 설정은 현재 열린 탭 또는 창의 사이트에서 확장을 선택했을 때 접근하도록 허용합니다. 탭이나 창을 닫으면 다음 사용 시 다시 확장을 선택해야 할 수 있습니다.

‘특정 사이트’가 무조건 정답인가요?

아닙니다. 일부 확장은 작동해야 할 사이트가 한 곳으로 제한되지 않습니다. 예를 들어 여러 사이트에서 번역하거나 콘텐츠를 처리하는 기능은 필요한 범위가 넓을 수 있습니다. 사용자에게 중요한 것은 기능 목적과 접근 범위가 일치하는지입니다.

이 설정으로 모든 유형의 권한이 차단되나요?

그렇지 않습니다. Google은 사이트 접근 설정 변경이 확장의 호스트 권한과 관련된 사이트에만 영향을 주며, VPN이나 프록시 등 더 낮은 수준의 네트워크 접근을 변경하는 확장에는 동일하게 적용되지 않을 수 있다고 명시합니다.

따라서 사이트 접근을 ‘선택할 때만’으로 변경했다고 확장이 가진 모든 종류의 권한이 없어졌다고 이해해서는 안 됩니다.

6. Chrome에서 ‘모든 사이트’를 ‘특정 사이트’로 줄여보기

다음 실습은 지금도 사용하고 있지만 한두 사이트에서만 필요한 확장을 대상으로 합니다.

  1. Chrome의 확장 프로그램 관리를 엽니다.
  2. 테스트할 확장 하나를 선택하고 세부정보로 이동합니다.
  3. ‘이 확장 프로그램이 방문하는 웹사이트의 데이터를 읽고 변경’하는 사이트 접근 항목을 찾습니다.
  4. 현재 모든 사이트에서인지 확인합니다.
  5. 이 확장 기능이 필요한 사이트가 분명하다면 특정 사이트에서로 변경합니다.
  6. 표시되는 허용된 사이트 목록에서 실제 사용 사이트를 추가합니다.
  7. 필요하지 않은 사이트는 목록에서 제거합니다.
  8. 공개된 시험 페이지에서 해당 기능이 정상 동작하는지 확인합니다.
  9. 기능이 중단된다면 해당 확장이 왜 더 넓은 사이트 권한을 필요로 하는지 개발자 설명과 공식 권한 안내를 다시 검토합니다.

Chrome 공식 도움말에 따르면 특정 사이트의 추가·삭제는 세부정보 → 권한 → 허용된 사이트에서 처리할 수 있으며, 해당 옵션은 ‘특정 사이트’ 설정을 선택해야 보일 수 있습니다.

주의: 사용하지 않는 사이트의 접근을 줄이는 실습이지, 중요한 업무 확장을 강제로 고장 내는 실습이 아닙니다. 본인 브라우저가 아니거나 관리되는 확장이라면 변경하지 마세요.

공식 자료: Google — 특정 사이트에 대한 확장 액세스 추가·삭제

7. Chrome에서 시크릿 모드 권한도 따로 확인하기

시크릿 모드는 브라우저 창을 닫은 뒤 로컬 방문 기록을 처리하는 방식과 관련된 기능이지 모든 웹 활동을 완전하게 익명으로 만드는 기능이 아닙니다. 확장 프로그램에 시크릿 창에서의 실행 권한을 따로 허용했는지도 확인해야 합니다.

  1. Chrome의 확장 프로그램 관리로 이동합니다.
  2. 확장 하나의 세부정보를 엽니다.
  3. 시크릿 모드에서 허용(Allow in incognito) 옵션을 찾습니다.
  4. 실제로 시크릿 창에서 그 확장이 필요한지 생각해 봅니다.
  5. 필요하지 않다면 시크릿 모드 허용을 끕니다.
  6. 평소 브라우저 사용에 문제가 없는지 확인합니다.

Google 공식 문서에 따르면 시크릿 창에서 확장을 사용하려면 사용자가 관련 권한을 허용해야 합니다. 따라서 일반 창에서는 확장이 잘 작동하지만 시크릿 창에서는 동작하지 않는 것이 반드시 오류는 아닙니다.

개인정보 측면: 시크릿 창에서 동작하는 확장은 해당 모드에서도 허용된 범위의 데이터에 접근할 수 있습니다. 민감한 작업에 사용하는 창이라면 확장별 필요성을 더 신중하게 검토하세요.

공식 자료: Google — Chrome 확장 프로그램의 시크릿 모드 권한

8. Chrome에서 로컬 파일 접근 권한을 확인하는 이유

일부 확장은 웹사이트뿐 아니라 컴퓨터에서 브라우저로 연 로컬 파일에 접근할 수 있도록 추가 권한을 부여받습니다. Chrome 개발자 문서는 확장이 https://app.notion.com 주소의 파일에 접근하거나 시크릿 모드에서 작동하려면 사용자 승인 설정이 필요하다고 안내합니다.

무엇을 확인하면 좋나요?

  • PDF 또는 HTML 등 로컬 파일을 처리해야 하는 확장인가?
  • 파일을 읽는 기능이 업무상 필요한가?
  • 로컬 파일 접근 권한을 내가 직접 켜 준 기억이 있는가?
  • 확장이 다루는 파일에 개인정보나 회사 문서가 포함될 수 있는가?

설정 확인

  1. 확장 프로그램 관리에서 해당 확장을 선택합니다.
  2. 세부정보에서 파일 URL에 대한 액세스 허용과 유사한 항목을 확인합니다.
  3. 사용 목적상 불필요하다면 비활성화하는 것을 검토합니다.
  4. PDF 등을 처리하는 데 꼭 필요한 확장이라면 공식 지원 설명과 사용 범위를 확인합니다.

로컬 파일 접근을 꺼도 모든 보안 위험이 완전히 없어지는 것은 아니며, 해당 권한이 있는 확장이라고 무조건 악성인 것도 아닙니다. 필요 없는 추가 접근을 줄인다는 관점이 중요합니다.

공식 자료: Chrome Developers — file URL·시크릿 모드 확장 권한

9. Microsoft Edge 확장 권한은 어디에서 변경하나요?

Microsoft Edge도 확장 프로그램이 방문하는 웹사이트의 데이터를 읽고 변경할 수 있는 범위를 관리할 수 있습니다.

  1. Edge를 엽니다.
  2. 주소창 오른쪽의 확장(Extensions) 버튼을 선택합니다.
  3. 버튼이 없다면 설정 및 기타(점 3개) → 확장으로 이동합니다.
  4. 점검할 확장의 **추가 작업(…)**을 열어 사이트 데이터 읽기·변경 권한 항목을 확인합니다.
  5. 확장을 클릭할 때, 현재 사이트, 모든 사이트 가운데 필요한 범위를 선택합니다.
  6. 확장 관리 화면에서 해당 확장의 **세부정보(Details)**를 엽니다.
  7. **사이트 액세스(Site access)**와 추가 권한을 검토합니다.

Microsoft는 Edge의 확장 사이트 접근 설정에서 InPrivate에서 허용, 파일 URL에 대한 액세스 허용도 별도로 관리할 수 있다고 설명합니다.

Chrome과 메뉴 이름이 같나요?

비슷한 기능을 제공하지만 메뉴 위치·용어는 다를 수 있습니다. Chrome에서 썼던 경로를 그대로 Edge에 적용하지 말고 Edge 공식 지원 화면의 확장 → 관리 → 세부정보를 따라 확인하세요.

공식 자료: Microsoft — Edge 확장의 사이트 접근 권한 변경

10. Edge에서 확장 기능을 끄거나 제거하는 방법

사이트 접근 범위를 줄이는 방법으로 충분하지 않거나, 기능 자체가 필요 없는 확장이라면 일시적으로 끄기와 완전히 제거하기를 구분하세요.

잠깐 끄기

  1. Edge의 확장 버튼에서 확장 관리를 엽니다.
  2. 검사할 확장을 찾습니다.
  3. 해당 확장의 켜기·끄기 토글을 끕니다.
  4. 문제가 있었던 일반 웹페이지를 다시 열어 봅니다.
  5. 다시 필요할 때만 해당 확장을 활성화합니다.

완전히 제거하기

  1. 확장 관리 또는 확장 아이콘의 추가 작업을 엽니다.
  2. Microsoft Edge에서 제거를 선택합니다.
  3. 제거 확인 메시지를 살펴보고 실행합니다.
  4. 확장이 관리 목록에서 사라졌는지 확인합니다.

Microsoft는 확장을 추가할 때 요청하는 권한을 검토하도록 권고하며, 사용 중지와 제거를 별도 작업으로 안내합니다.

주의: 확장에 저장된 개인 템플릿·메모·설정이 있다면 제거 후 되찾지 못할 수 있습니다. 필요한 자료의 내보내기 기능을 확인하고 제거하세요.

11. Firefox는 Chrome·Edge와 무엇이 다른가요?

Mozilla Firefox 역시 설치된 확장 기능의 접근 권한을 확인할 수 있지만 Chrome의 ‘모든 사이트/특정 사이트’ 메뉴와 정확히 같은 UI라고 생각해서는 안 됩니다.

Mozilla 공식 설명에 따르면 Firefox 확장은 사용자의 기기 정보나 기능에 접근하기 위해 권한을 요청할 수 있으며, 일부는 설치 이후 추가 기능을 위한 **선택적 권한(Optional permissions)**을 요청합니다.

권한 확인 경로

  1. Firefox의 메뉴 버튼을 엽니다.
  2. **확장 기능 및 테마(Extensions and themes)**를 선택합니다.
  3. 확장 기능(Extensions) 목록을 엽니다.
  4. 확인하려는 확장의 이름을 선택합니다.
  5. 권한 및 데이터(Permissions and data) 또는 이에 해당하는 탭을 확인합니다.
  6. 현재 요청된 권한과 선택적 권한이 있다면 그 상태를 확인합니다.
  7. 선택적 권한의 토글을 끄기 전에 어떤 기능에 필요한지 확인합니다.

Firefox의 권한 설정은 브라우저 버전과 확장 구현 방식에 따라 달라질 수 있으며, 선택적 권한을 끄는 것과 확장에 필요한 모든 필수 권한을 철회하는 것은 동일하지 않습니다.

공식 자료: Mozilla — Firefox 확장의 선택적 권한 관리

12. Firefox 사생활 보호 창에서도 확장이 실행되는지 확인

Firefox의 사생활 보호 창(Private Browsing)은 일반 창과 확장 실행 정책이 다를 수 있습니다.

Mozilla는 Firefox 확장이 사생활 보호 창에서 기본으로 활성화되지 않으며, 사용자가 설치 과정 또는 확장 설정에서 허용해야 한다고 설명합니다. 또 일부 확장은 사생활 보호 창에서 실행할 수 없을 수 있습니다.

점검 방법

  1. Firefox의 확장 기능 및 테마 → 확장 기능을 엽니다.
  2. 점검하려는 확장을 선택합니다.
  3. 사생활 보호 창에서 실행(Run in Private Windows) 설정을 찾습니다.
  4. 현재 허용 또는 허용하지 않음 상태를 확인합니다.
  5. 꼭 필요한 확장이 아니라면 사생활 보호 창 실행을 허용할 이유가 있는지 검토합니다.
  6. 변경 후 해당 확장의 일반 창 동작에 문제가 없는지 확인합니다.

개인정보 관련 주의점

사생활 보호 창은 네트워크 관리자나 방문 사이트로부터의 완전한 익명을 제공하는 수단이 아닙니다. 또 허용된 확장이 실행될 수 있으므로 사생활 보호 창을 열었다는 사실만으로 모든 확장 권한이 자동으로 차단된다고 생각하면 안 됩니다.

13. 확장 프로그램의 ‘권한 경고’는 어떻게 해석할까?

Chrome 개발자 문서는 확장이 다음과 같은 종류의 권한을 요청할 수 있다고 설명합니다.

권한·접근 예시잠재적으로 할 수 있는 일확인할 질문
웹사이트 데이터 읽기·변경허용된 사이트의 콘텐츠 접근·처리어떤 사이트에서 꼭 필요한가?
방문 기록 접근브라우징 활동 정보를 확인할 수 있음방문 기록 관리 기능이 핵심인가?
탭 접근특정 탭 속성·정보에 접근탭 정리 기능과 관련되는가?
클립보드 관련 권한복사·붙여넣기 데이터 처리메모·복사 기능이 필요한가?
파일 URL 접근브라우저에서 연 로컬 파일 관련 접근로컬 파일 처리 목적이 있는가?
시크릿·InPrivate 허용비공개 창에서 확장 실행비공개 창에서도 사용할 필요가 있는가?
쿠키 또는 네트워크 관련 API권한과 API에 따라 별도 네트워크·세션 데이터 처리사이트 접근 설정만으로 통제되는가?

이 표는 권한이 가질 수 있는 기능 범위를 이해하기 위한 요약입니다. 확장이 어떤 정보를 실제로 수집·전송하는지는 권한 목록만으로 확정할 수 없습니다. 구현 방식, 개인정보 처리방침, 개발사 신뢰성, 외부 데이터 전송 여부 등을 함께 확인해야 합니다.

고위험 권한이라고 해서 즉시 악성이라는 뜻은 아닙니다. 예를 들어 광고 차단 기능은 여러 웹사이트의 요청을 처리하기 위해 넓은 접근이 필요할 수 있습니다. 반대로 매우 단순한 기능인데 광범위한 권한을 요구한다면 더 자세히 확인할 이유가 있습니다.

14. 독자 제작 ‘필요성 × 접근 범위’ 의사결정표

아래 판정표는 이 글에서 만든 실무형 분류입니다. Google이나 Microsoft가 공식적으로 부여한 안전 등급이 아닙니다.

사용 여부접근 범위권장 행동
매일 사용기능에 꼭 필요한 사이트만유지, 정기 재점검
가끔 사용모든 사이트클릭 시 또는 특정 사이트로 줄여 시험

회사에서 설치조직에서 지정임의 제거하지 말고 관리자에게 문의

결정 기준은 두 가지입니다. 실제 사용 목적이 명확한가? 그 목적을 위해 접근해야 하는 사이트와 데이터의 범위가 타당한가?

예를 들어 온라인 쇼핑 가격 비교 확장이 쇼핑몰 한 곳에서만 필요하다면 사이트 범위를 줄여 볼 수 있습니다. 그러나 여러 쇼핑몰을 이동하며 가격을 비교하는 기능이라면 특정 사이트만 허용했을 때 작동이 제한될 수도 있습니다.

확장을 켰을 때 기능이 잘 되는지 확인하고, 변경 후 오류가 생긴 경우 그 확장의 공식 권한 설명을 참고하세요.

15. 5분 비교 실험: 한 번에 하나씩 끄고 확인

확장 설치 후 웹페이지가 느려지거나 버튼이 작동하지 않는다면 모든 확장을 한 번에 삭제하기보다 문제가 재현되는 조건을 비교해 볼 수 있습니다.

실험 방법

  1. 오류가 발생하는 일반적인 공개 웹페이지를 선택합니다.
  2. 어떤 버튼·메뉴·이미지가 문제인지 기록합니다.
  3. 확장 프로그램 관리 목록을 엽니다.
  4. 최근 설치했거나 관련 가능성이 큰 확장 하나만 사용 중지합니다.
  5. 페이지를 새로 고친 뒤 같은 문제가 재현되는지 확인합니다.
  6. 문제가 사라졌다면 해당 확장과 사이트 사이에 호환성 문제가 있을 가능성이 있습니다.
  7. 다른 확장까지 순서대로 비교할 필요가 있다면 기존 설정을 기록한 상태로 진행합니다.
  8. 원인이 확실해지면 해당 확장의 업데이트·설정·개발자 공식 도움말을 확인합니다.

Mozilla는 부가 기능 오류를 진단할 때 확장을 비활성화한 후 재현 여부를 확인하고 한 번에 하나씩 다시 활성화하는 방법을 공식 안내합니다.

주의: 확장을 끄고 문제가 사라졌다고 해서 개인정보를 유출하는 악성 확장임이 입증되는 것은 아닙니다. 사이트와 충돌하거나 업데이트가 필요한 일반적인 호환성 문제일 수 있습니다.

공식 자료: Mozilla — 확장 기능 문제 해결

16. 크롬 ‘안전 확인’에서 확장 위험 경고가 나오면

Google은 Chrome의 안전 확인(Safety Check) 기능이 잠재적으로 유해할 수 있는 확장 프로그램에 대한 경고를 표시할 수 있다고 안내합니다.

확인 경로

  1. Chrome 오른쪽 위 더보기 → 설정을 엽니다.
  2. 개인정보 보호 및 보안으로 이동합니다.
  3. 안전 확인(Safety Check) 항목을 엽니다.
  4. 경고가 표시되는 확장이 있는지 확인합니다.
  5. 경고가 있다면 해당 항목을 선택해 구체적인 설명을 읽습니다.
  6. Chrome이 제시하는 안내와 개발자 공식 정보를 확인한 후 후속 조치를 결정합니다.

경고가 없으면 모든 확장이 안전한가요?

그렇지는 않습니다. 안전 확인은 Google이 발견한 일부 위험에 대해 알려 주는 기능입니다. 경고가 없다는 사실은 모든 확장의 동작이 독립적으로 검증됐다는 증거가 아닙니다.

다른 보안 도구나 개발자 공식 공지에서 문제가 보고됐다면 Chrome 관리 화면에서 확장 상태를 다시 점검하고, 필요하지 않은 권한을 줄이세요.

17. 홈페이지·검색엔진이 저절로 바뀌었다면

확장 프로그램이 브라우저 설정을 변경할 수 있습니다. Google은 일부 Chrome 확장이 홈페이지, 새 탭 페이지, 기본 검색엔진 등을 바꿀 수 있다고 설명합니다.

점검 순서

  1. Chrome 설정에서 홈페이지·시작 페이지와 기본 검색엔진을 확인합니다.
  2. ‘확장 프로그램이 이 설정을 제어하고 있습니다’라는 안내가 있는지 확인합니다.
  3. 해당 확장을 직접 설치했는지, 기능 목적을 이해하는지 살펴봅니다.
  4. 원치 않는 변경이라면 해당 확장을 사용 중지하거나 제거합니다.
  5. 브라우저 설정이 원하는 상태로 돌아왔는지 확인합니다.

Google은 설정을 변경한 확장을 제거하면 기존 설정으로 돌아갈 수 있다고 안내합니다. 그러나 다른 프로그램이나 조직 정책이 별도로 관여하는 상황도 있을 수 있습니다.

검색 결과에서 이상한 사이트로 이동한다면?

리디렉션이 특정 확장 사용 여부와 관련이 있는지 비교하고, 공식 보안 도구를 이용해 악성 소프트웨어 가능성을 점검하세요. 출처가 불분명한 ‘브라우저 복구 프로그램’을 추가로 설치하는 것은 오히려 위험할 수 있습니다.

18. 권한을 줄여도 이미 유출된 정보가 자동으로 회수되지는 않습니다

확장 접근 범위를 줄이거나 제거하면 이후 동작을 제한하는 데 도움이 되지만 과거에 어떤 정보가 외부로 전송됐는지까지 확인하거나 되돌리는 기능은 아닙니다.

의심되는 경우의 대응 방향

  1. 확장의 이름, 개발사, 설치 경로, 현재 권한과 브라우저 경고를 기록합니다.
  2. 필요 없는 확장이라면 비활성화 또는 제거합니다.
  3. 브라우저와 운영체제를 최신 보안 업데이트 상태로 유지합니다.
  4. 공식 보안 프로그램으로 악성코드를 검사합니다.
  5. 실제 계정 침해 정황이 확인되면 신뢰할 수 있는 별도 기기에서 비밀번호를 변경하고 로그인 세션과 2단계 인증을 확인합니다.
  6. 금융·업무 계정의 정보 유출 정황이 있다면 해당 기관 또는 조직의 보안 담당자에게 신고합니다.

확장 프로그램에 사이트 읽기 권한이 있었다는 사실만으로 계정이 해킹됐다고 단정하거나 모든 비밀번호를 당장 변경해야 한다고 말할 수는 없습니다. 그러나 확장이 악성으로 판명됐거나 자격증명 노출의 근거가 있다면 계정 보호 조치가 필요할 수 있습니다.

중요: 회사에서 관리하는 브라우저는 증거를 지우거나 관리 확장을 임의로 제거하기 전에 조직의 사고 대응 절차를 따르세요.

20. 자주 묻는 질문

Q. ‘모든 웹사이트 데이터 읽기·변경’이면 무조건 위험한 확장인가요?

아닙니다. 이는 권한의 범위를 말하며, 실제 유출 여부를 입증하는 문구는 아닙니다. 다만 확장이 수행하는 기능에 꼭 필요한 접근인지 확인할 가치가 있습니다.

Q. Chrome에서 특정 사이트에서만 작동하도록 할 수 있나요?

지원되는 확장의 경우 확장 프로그램 관리 → 세부정보 → 사이트 액세스에서 ‘특정 사이트에서’를 선택하고 허용된 사이트를 추가·삭제할 수 있습니다.

Q. ‘확장을 선택할 경우’로 바꾸면 아예 동작하지 않나요?

Chrome 공식 설명에 따르면 해당 확장을 현재 탭에서 클릭할 때 사이트 접근을 허용하는 방식입니다. 자동 동작이 필요한 일부 기능은 제한될 수 있으므로 사용해 보고 판단하세요.

Q. 모든 사이트 접근을 끄면 VPN 확장의 네트워크 접근도 막히나요?

항상 그렇지는 않습니다. Chrome은 사이트 권한 변경이 호스트 권한에 연동되는 사이트에만 적용되며 VPN·프록시처럼 낮은 수준의 네트워크 접근을 바꾸는 확장에는 동일하게 적용되지 않을 수 있다고 안내합니다.

Q. 확장 아이콘이 브라우저 상단에 없으면 삭제된 건가요?

아닙니다. 도구 모음에서 아이콘이 숨겨진 것일 수 있습니다. 반드시 확장 관리 목록 전체를 확인하세요.

Q. 크롬 시크릿 창에서도 확장이 동작하나요?

사용자가 시크릿 모드에서 허용한 확장은 동작할 수 있습니다. Chrome 확장 세부정보에서 해당 옵션을 확인하세요. 시크릿 창 자체가 모든 활동을 완전히 숨겨주는 것은 아닙니다.

Q. Edge에도 같은 권한 설정이 있나요?

Microsoft Edge도 확장 클릭 시·현재 사이트·모든 사이트와 같은 접근 설정을 지원하고, 세부정보에서 InPrivate와 파일 URL 접근도 확인할 수 있습니다.

Q. Firefox에서는 Chrome처럼 특정 사이트를 선택하나요?

모든 확장에서 똑같은 메뉴를 제공하지는 않습니다. Mozilla는 확장의 권한 및 데이터, 선택적 권한과 사생활 보호 창 실행 여부를 별도로 관리하도록 안내합니다.

Q. 확장을 비활성화하면 저장된 데이터도 삭제되나요?

비활성화는 제거와 다른 작업입니다. 브라우저에서 실행을 멈추지만 제거 시에는 해당 확장의 저장 정보·설정에 영향이 있을 수 있으므로, 중요한 자료가 있다면 내보내기 방법을 먼저 확인하세요.

Q. 권한을 줄인 뒤 사이트가 정상 작동하지 않습니다.

원래 접근 범위를 기록했는지 확인한 후 해당 확장이 어떤 기능에 어떤 사이트 접근을 요구하는지 살펴보세요. 필요한 범위만 되돌려 시험하고, 회사 관리 확장은 관리자 지침을 따릅니다.

Q. Chrome 안전 확인에서 경고가 없으면 믿어도 되나요?

경고가 없다는 사실이 독립적인 안전 인증은 아닙니다. 설치 목적, 개발자, 권한 범위, 업데이트 상태를 함께 확인하세요.

  • ☐ 사용하지 않는 확장을 비활성화하거나 제거 여부를 검토했습니다.
  • ☐ 공식 안전 경고와 검색엔진·홈페이지 변경 여부를 확인했습니다.

  • ☐ 점검 결과와 다음 검토 시점을 기록했습니다.
