휴대전화에 'SIM PIN을 3회 잘못 입력했습니다', 'PUK 코드를 입력하세요'라는 문구가 뜨면 유심이 보안 잠금 상태일 수 있습니다. PUK를 인터넷에서 검색한 임의 숫자로 입력하지 마세요. 해당 유심을 발급한 통신사에서 정확한 PUK를 확인해야 합니다.

2026년 11월 기준 Apple·삼성전자서비스·SKT·KT·알뜰폰 공식 안내를 대조해 PIN 3회 오류 이후 복구 순서, 통신사별 조회 경로, 본인인증이 어려울 때 대처, PUK 10회 오류 시 조치를 정리했습니다. 계정·기종·앱 버전에 따라 메뉴는 달라질 수 있습니다.

2. PIN을 3번 틀렸다면 이렇게 진행하세요

  1. 숫자 입력을 멈춥니다. 기억나는 번호를 추가로 시험하지 마세요.
  2. 실제 가입 사업자를 확인합니다. SKT·KT·LG U+ 직접 가입인지, 알뜰폰 회사 가입인지 확인합니다.
  3. 유심을 떼어냈던 플라스틱 카드를 확인합니다. 일부 유심은 PUK가 카드에 기재되어 있습니다.
  4. 공식 채널에서 PUK를 조회합니다. 통신사 웹사이트·앱 또는 고객센터·매장을 이용합니다.
  5. 확인된 PUK만 입력합니다. 화면 안내에 따라 새 SIM PIN을 설정합니다. 잔여 입력 횟수도 확인하세요.

KT 공식 FAQ가 설명하는 기본 흐름은 'PIN 3회 오입력 → PUK 입력 → PIN 재설정'입니다. 정확한 PUK를 모른다면 이 흐름의 입력 단계로 바로 넘어가지 않는 것이 중요합니다.

4. 알뜰폰은 망 이름보다 '실제 가입 회사'가 중요합니다

SKT망·KT망·LG U+망을 사용하는 알뜰폰이라도 PUK 조회와 재발급 처리는 알뜰폰 사업자의 정책을 따르는 경우가 있습니다.

  • U+유모바일: 공식 FAQ는 홈페이지·앱 로그인 후 '내 정보 → 정보열람 신청 → 유심잠금해제(PUK) 번호'를 안내합니다.
  • 프리티 KT·LG U+망: 프리티 FAQ는 본인인증 후 고객센터에서 PUK를 확인할 수 있다고 설명합니다.
  • 프리티 SKT망: 같은 FAQ는 PUK 확인이 불가해 유심 재발급이 필요하다고 안내합니다.

따라서 이용 중인 알뜰폰의 요금 청구서나 가입 문자에서 회사명을 먼저 확인하세요. 망 제공 통신사에 무작정 PUK를 요청하기보다 가입 사업자의 공식 상담처에서 시작하는 것이 정확합니다.

공식 참고: U+유모바일 PUK 안내, 프리티 고객만족센터.

5. PUK를 10회 잘못 입력하면?

SKT·KT·삼성전자서비스는 PUK를 10회 잘못 입력하면 해당 유심을 더 이상 사용할 수 없어 새 유심이 필요하다고 안내합니다. 이 단계에서 휴대전화를 재시작하거나 공장초기화하는 것은 유심 잠금 해제 수단이 아닙니다.

현재 상황권장 대응
PUK를 모름더 입력하지 말고 통신사 공식 조회
카드에 기재된 코드가 안 맞음계속 시도하지 말고 발급 사업자에 유심 정보 확인
PUK 입력 횟수 초과유심 재발급 및 회선 재설정 절차 문의
eSIM에서 코드 요구임의로 eSIM 삭제하지 말고 통신사에 잠금 해제·재발급 문의

유심 교체가 필요해도 휴대전화 안의 사진·앱을 곧바로 삭제할 이유는 없습니다. 다만 저장된 연락처 위치, 통신사 서비스와 인증수단은 확인해야 합니다. 교체 수수료와 기존 번호 유지 절차는 사업자에 확인하세요.

6. 아이폰·갤럭시에서 확인할 차이

아이폰: Apple은 '설정 → 셀룰러 → SIM PIN'에서 회선의 SIM PIN을 관리하도록 안내합니다. 듀얼 SIM이라면 해당 회선을 먼저 선택합니다. 이 메뉴가 있다고 해서 모르는 PUK를 직접 알아낼 수 있는 것은 아닙니다. 코드 확인은 유심을 발급한 통신사를 통해 진행합니다.

갤럭시: One UI 버전별로 보안 및 SIM 관련 설정 이름이 다를 수 있습니다. PIN·PUK 입력 화면에서 임의 숫자를 넣는 대신 유심의 플라스틱 카드나 통신사 홈페이지·대리점을 확인하세요. 삼성전자서비스는 플라스틱 카드의 PUK 확인과 사업자 조회를 공식 해결 경로로 안내합니다.

공통: 잠긴 유심 때문에 전화·문자 인증을 못 할 수 있습니다. 필요한 경우 다른 정상 기기로 공식 홈페이지 접속 또는 고객센터 문의를 준비하세요.

7. 자주 묻는 질문

Q. 유심 초기 PIN이 0000이면 PUK에도 0000을 넣어도 되나요?

안 됩니다. 일부 사업자의 초기 SIM PIN에 0000이 안내되지만, 이것은 PUK와 다른 번호입니다. 기존 PIN이 이미 변경되었거나 PUK 화면이 뜬 상태에서 0000을 시험하는 것도 권장하지 않습니다.

Q. PUK가 모든 사람에게 공통인 8자리 번호인가요?

아닙니다. 본인 유심에 해당하는 정확한 코드를 사용해야 합니다. 온라인 게시글의 예시 숫자를 따라 입력하면 안 됩니다.

Q. PUK 오류가 나면 사진이나 앱도 삭제되나요?

PUK는 SIM 보안 잠금 문제입니다. 그 자체가 휴대전화의 사진과 앱을 삭제하는 절차는 아닙니다. 하지만 유심·eSIM 재발급 시 인증수단과 일부 서비스 재설정을 확인할 필요는 있습니다.

Q. eSIM도 SIM PIN·PUK가 있나요?

Apple은 SIM 카드뿐 아니라 eSIM에서도 SIM PIN을 사용할 수 있다고 안내합니다. 모르는 코드를 추측하지 말고 이동통신사에 문의하세요.

Q. 잠금 화면의 비밀번호도 PUK로 풀 수 있나요?

아닙니다. PUK는 SIM 잠금 해제용이고, 기기 화면 암호·Apple 계정·Google 계정은 별도 복구 절차가 필요합니다.

Q. 통신사 로그인에 필요한 인증 문자도 받지 못하면 어떻게 하나요?

다른 공식 인증수단이 제공되는지 확인하고, 어렵다면 명의자 신분확인 수단을 준비해 고객센터나 공식 매장에 문의하세요. 알뜰폰은 본인의 가입 사업자부터 확인하는 것이 좋습니다.

8. 결론: '조회 → 정확한 코드 입력 → PIN 재설정' 순서가 안전합니다

SIM PIN 3회 오류가 났다면 입력 중단 → 실제 가입 회사 확인 → 공식 PUK 조회 → 잔여 횟수 확인 → SIM PIN 재설정 순서로 접근하세요. SKT·KT·LG U+와 알뜰폰은 인증방법과 처리 방식이 같지 않습니다.

이 글은 공개된 공식 문서를 대조한 안내이며, 특정 단말기에서 PUK 잠금을 실제 재현하거나 개별 유심의 코드를 확인한 결과는 아닙니다. 실제 회선별 안내가 다를 경우 통신사 공식 답변을 우선하세요.
