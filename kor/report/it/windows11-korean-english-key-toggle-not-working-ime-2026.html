컴퓨터에서 한/영 키를 눌러도 영어만 입력되거나, 작업 표시줄에는 한국어가 선택돼 있는데 실제로는 한글이 나오지 않는 상황이 있습니다. 그런데 이 증상은 키보드 고장만의 문제가 아닙니다. Windows의 입력 언어 선택과 한국어 입력기 안의 한/영 모드가 서로 다른 단계이기 때문입니다.

Microsoft의 공식 Korean IME 설명에 따르면 Windows 키와 스페이스바를 누르면 설치된 입력 언어·키보드 레이아웃을 바꿀 수 있습니다. 하지만 한국어 Microsoft IME를 선택했어도 오른쪽 아래 입력 모드가 A라면 영문이 입력될 수 있으며, 가로 바꿔야 한글 입력이 시작됩니다.

이 글에서는 무작정 재설치하거나 레지스트리를 건드리는 대신 3분 기본 진단 → 키보드·언어 설정 → 특정 앱 문제 → 고급 입력 서비스 점검 순서로 문제를 나눠 해결합니다. 2026년 11월 1일 기준 Microsoft Support 및 Microsoft Learn의 공식 자료를 바탕으로 작성했습니다.

2. 3분 안에 해결할 수 있는 기본 방법

  1. 메모장을 열어 텍스트 입력 커서를 놓습니다.
  2. Windows 키+스페이스바로 입력 언어 목록을 표시합니다.
  3. 목록에서 한국어 Microsoft IME를 선택합니다.
  4. 작업 표시줄 오른쪽 아래의 A 또는 가 표시를 확인합니다.
  5. A가 표시되면 아이콘을 눌러 가로 바꿉니다.
  6. 메모장에 '한글 입력 테스트'를 입력해 봅니다.
  7. 정상 입력되면 원래 사용하던 프로그램으로 돌아가 같은 방법을 시험합니다.

Microsoft의 한국어 IME 공식 문서는 한국어 입력기가 선택된 후 A는 영문 모드, 가는 한글 모드라고 설명합니다. 또한 일반적인 한국어 IME 환경에서 오른쪽 Alt로 두 모드를 전환할 수 있다고 안내합니다.

모드가 제대로 바뀌었다면 운영체제 전체를 초기화할 이유가 없습니다. 다음부터는 입력 언어와 한영 모드를 구별하면 됩니다.

출처: Microsoft Learn — Korean IME

3. Windows 키+스페이스바와 한영키는 왜 다른가요?

많은 사용자가 이 두 단계를 같은 것으로 생각합니다. 하지만 다음처럼 역할이 다릅니다.

입력 언어 전환: Windows 키+스페이스바는 영어(미국), 한국어 Microsoft IME 등 Windows에 설치된 입력 레이아웃 사이를 이동합니다.

한영 모드 전환: 한국어 Microsoft IME를 선택한 뒤에는 해당 IME 안에서 A(영문)와 가(한글)를 구분합니다.

현재 상태Windows 키+스페이스바의 역할A/가의 역할
ENG 키보드한국어 Microsoft IME 등의 다른 배열 선택한국어 입력기 내부 모드가 아닐 수 있음
한국어 IME + A다른 입력 레이아웃 선택가로 변경하면 한글 입력 가능
한국어 IME + 가다른 입력 레이아웃 선택A로 변경하면 영문 입력 가능

따라서 **“입력 언어는 한국어인데 계속 영어만 나와요”**라면 먼저 A를 가로 바꾸는 것이 중요합니다.

Microsoft는 영문 Windows라도 한국어 IME를 설치하면 한글을 입력할 수 있다고 안내합니다. Windows 화면 언어를 한글로 바꾸는 것과 한글 타이핑은 별개의 설정입니다.

공식 자료: Korean IME

4. 한국어 입력기가 없다면 추가하는 방법

작업 표시줄에서 ENG만 보이거나 한국어 Microsoft IME가 목록에 없다면 설정을 확인합니다.

  1. 시작 → 설정 → 시간 및 언어 → 언어 및 지역을 엽니다.
  2. 언어 목록에서 한국어가 설치되어 있는지 확인합니다.
  3. 한국어가 없다면 언어 추가에서 한국어를 선택해 설치합니다.
  4. 한국어가 있다면 옆의 … → 언어 옵션으로 들어갑니다.
  5. 키보드 항목에서 Microsoft IME가 등록되어 있는지 확인합니다.
  6. 필요한 키보드가 없다면 지원되는 추가 옵션을 확인합니다.
  7. Windows 키+스페이스바로 한국어 Microsoft IME를 선택합니다.
  8. 마지막으로 작업 표시줄의 A를 가로 바꾸고 입력을 시험합니다.

한국어 키보드 입력을 위해 반드시 Windows 표시 언어 전체를 한국어로 바꾸는 것은 아닙니다. 회사 PC처럼 영문 Windows를 사용해야 하는 환경에서도 입력 언어는 별도로 관리할 수 있습니다.

공식 자료: Microsoft — Windows 언어 및 키보드 입력 레이아웃 관리, Windows용 언어 팩

5. A/가 클릭은 되는데 물리적인 한영키만 안 된다면?

마우스로 A를 가로 바꾸면 정상적으로 한글이 입력되지만, 키보드에 있는 한/영 키만 반응하지 않는 상황입니다. 이 경우 한국어 IME가 작동하지 않는다고 단정할 필요는 없습니다.

  • 먼저 오른쪽 Alt 키로 전환이 되는지 시험합니다.
  • 노트북의 내장 키보드와 외장 키보드에서 각각 비교합니다.
  • 외장 키보드라면 키보드를 PC에 직접 연결하거나 다른 포트를 시험합니다.
  • 키 재할당 도구·게임 매크로 프로그램·제조사 전용 키보드 소프트웨어의 설정을 확인합니다.
  • 회사·학교 PC라면 조직에서 배포한 키보드 관리 정책이 있는지 문의합니다.

Microsoft의 공식 Korean IME 문서는 오른쪽 Alt로 한글·영문 입력 모드를 바꾸는 방법을 안내합니다. 다만 실제 물리 키보드는 모델, 101/103/106키 등 레이아웃, 제조사 설정에 따라 키 동작이 달라질 수 있습니다.

키캡에 한영키가 인쇄돼 있다는 사실과 Windows가 그 키를 실제로 어떤 입력으로 받는지는 별개의 문제입니다. 물리 키가 의심된다면 바로 Windows 재설치를 시작하지 말고 다른 키보드로 비교해 보세요.

6. 작업 표시줄의 언어 아이콘이 사라진 경우

한영 전환을 나타내던 A/가 또는 언어 아이콘이 갑자기 보이지 않는다고 입력기가 삭제된 것은 아닙니다.

Microsoft는 언어 표시줄과 작업 표시줄 입력 언어 아이콘의 관계를 설명하며 다음 경로를 안내합니다.

  1. 설정 → 시간 및 언어 → 입력으로 이동합니다.
  2. 고급 키보드 설정을 엽니다.
  3. 사용 가능한 경우 데스크톱 언어 표시줄 사용 항목을 확인합니다.
  4. 레거시 언어 표시줄 대신 작업 표시줄의 입력 언어 아이콘을 사용하려면 해당 설정을 해제할 수 있습니다.
  5. 작업 표시줄 표시 상태와 Win+Space 전환을 다시 확인합니다.

이 설정은 아이콘 표시 방식을 바꾸는 것이므로 물리적인 한영키 고장이나 특정 앱 문제까지 해결한다는 뜻은 아닙니다.

메뉴 이름이 다르게 보인다면 Windows 설정 검색창에서 고급 키보드 설정을 직접 검색하세요.

출처: Microsoft — 언어 및 키보드 설정 관리

7. 메모장에서는 되는데 게임에서만 한글 입력이 안 될 때

게임 채팅창이나 특정 프로그램에서만 한영키가 작동하지 않는다면 앱별 입력 처리 문제일 수 있습니다.

우선 다음과 같이 비교합니다.

  1. 메모장에서 한글이 입력되는지 확인합니다.
  2. 브라우저의 일반 검색 입력란에서도 입력해 봅니다.
  3. 문제가 발생한 게임이나 프로그램의 채팅창에서 다시 시험합니다.
  4. 해당 프로그램의 단축키·키보드 배치·텍스트 입력 모드 설정을 확인합니다.
  5. 앱 제작사가 제공하는 업데이트나 입력 관련 공지사항을 확인합니다.
  6. 프로그램을 정상 종료하고 다시 실행한 뒤 비교합니다.

메모장은 되지만 특정 프로그램만 실패한다면 문제의 범위를 좁힌 것입니다. 이때 모든 Windows 서비스 설정을 바꾸거나 한국어 입력기를 삭제하는 행동은 성급할 수 있습니다.

Microsoft는 기존 프로그램의 Windows 호환성 문제가 있을 때 앱 업데이트와 프로그램 호환성 문제 해결 방법을 안내합니다. 다만 한영키 문제의 원인이 반드시 호환성 오류는 아닙니다.

공식 자료: Microsoft — 기존 앱의 Windows 호환성 문제 해결

8. 로그인 화면에서 영어 키보드가 선택되는 문제

평소 Windows에서는 한글 입력이 정상인데 로그인 화면에서는 키보드가 평소와 다를 수 있습니다. Microsoft는 Windows 표시 언어를 변경하면 로그인 화면의 키보드 레이아웃이 달라질 수 있다고 안내합니다.

  1. 로그인 화면의 입력 언어 아이콘을 확인합니다.
  2. 비밀번호를 입력할 때 사용하는 키보드 배열을 선택합니다.
  3. 영문·숫자·특수문자의 위치가 평소와 다르지 않은지 살펴봅니다.
  4. 화면에 비밀번호 표시 기능이 있다면 다른 사람이 보지 않는 환경에서만 사용합니다.

한영키 오류 때문에 계정 암호를 바꾸거나 PC를 초기화하기 전에 로그인 화면의 현재 키보드 레이아웃부터 점검하세요.

공식 근거: Microsoft — 입력 언어 및 로그인 화면 키보드

9. 화면 키보드로 물리 키 문제를 분리하기

키보드 자체가 원인인지 확인하는 데는 Windows 화면 키보드가 도움이 됩니다. Microsoft의 Korean IME 공식 안내에 따르면 Windows 키+Ctrl+O로 화면 키보드(OSK)를 열 수 있습니다.

  1. 먼저 한국어 Microsoft IME를 선택합니다.
  2. 오른쪽 아래 입력 모드가 가로 되어 있는지 확인합니다.
  3. Windows 키+Ctrl+O로 화면 키보드를 실행합니다.
  4. 화면 키보드로 한글을 입력해 봅니다.
  5. 실제 외장·내장 키보드와 결과를 비교합니다.

화면 키보드에서는 한글이 되지만 특정 키보드에서만 안 된다면 하드웨어나 매핑의 영향 가능성이 있습니다. 반대로 화면 키보드에서도 한국어 IME가 선택되지 않는다면 언어·입력기 상태를 점검해야 합니다.

다만 이 시험 하나로 물리적인 키보드 고장을 100% 확정할 수는 없습니다.

10. Win+Space조차 작동하지 않을 때는 입력 관리 서비스 확인

Win+Space, 작업 표시줄 입력 아이콘, 한국어 모드 변경이 모두 동작하지 않는다면 입력 시스템 문제를 고급 단계에서 확인할 수 있습니다.

Microsoft Learn의 IME 문제 해결 문서에 따르면 텍스트 입력 관리 서비스가 비활성화되면 Ctfmon.exe 시작과 IME 초기화에 문제가 발생할 수 있습니다.

문서에서 안내하는 확인 순서는 다음과 같습니다.

  1. 중요한 작업을 저장합니다.
  2. Win+R을 누르고 services.msc를 입력합니다.
  3. 텍스트 입력 관리 서비스를 찾습니다.
  4. Windows 11 25H2 이전에는 터치 키보드 및 필기 패널 서비스로 표시될 수 있습니다.
  5. 시작 유형이 사용 안 함으로 설정되어 있는지 확인합니다.
  6. Microsoft 지침에 따라 사용 안 함이라면 수동 또는 자동으로 설정할 수 있습니다.
  7. 서비스가 실행 중이 아니라면 시작합니다.
  8. Windows에서 로그아웃했다가 다시 로그인하고 입력 전환을 확인합니다.

이것은 언어와 모드 모두 정상적으로 선택할 수 없는 경우에 검토하는 고급 진단입니다. 한영키만 반응하지 않는 모든 상황에 적용할 방법이 아닙니다.

관리되는 업무용 컴퓨터에서는 승인 없이 서비스 설정을 수정하지 마세요. 서비스를 무리하게 중단하거나 시스템 파일을 임의로 지우지 않는 편이 안전합니다.

11. Microsoft IME 이전 버전 사용은 언제 고려할까요?

Windows를 업데이트한 뒤 특정 입력기에서 호환성 문제가 생겼을 때 이전 버전의 Microsoft IME 사용이라는 설정을 보게 될 수 있습니다.

Microsoft는 해당 호환성 설정을 안내하면서 장기간 사용을 권장하지 않으며 임시 해결책으로 이용해야 한다고 명시합니다.

지원되는 입력기에서 옵션이 나타난다면 일반적으로 다음 흐름입니다.

  1. 설정 → 시간 및 언어 → 언어 및 지역을 엽니다.
  2. 사용 중인 언어의 언어 옵션을 엽니다.
  3. Microsoft IME의 키보드 옵션을 확인합니다.
  4. 일반 → 호환성 항목에 이전 버전 사용이 제공되는지 확인합니다.
  5. 증상을 기록하고 문제 앱에서만 필요한지 검토합니다.

다만 모든 한국어 IME와 Windows 버전에서 이 옵션이 동일하게 제공되는 것은 아닙니다. 다른 언어용 IME 해결법을 그대로 한국어 입력기에 적용하지 마세요.

A/가 모드가 잘못 선택된 상태라면 이 호환성 설정을 만질 이유가 없습니다.

12. IME를 바로 삭제하거나 Windows를 초기화하지 마세요

인터넷에서는 레지스트리 수정, 언어 팩 제거, 시스템 파일 삭제, 비공식 입력기 설치 등을 권하는 경우가 있습니다. 하지만 문제가 특정 앱에서만 발생하는지 또는 A 모드로 되어 있을 뿐인지 확인하기도 전에 이런 조치를 할 이유는 없습니다.

안전한 점검 순서는 아래와 같습니다.

  • 입력 언어가 한국어 Microsoft IME인지 확인합니다.
  • A/가 상태에서 가로 변경해 봅니다.
  • 마우스로 변경하면 되는지 확인합니다.
  • 메모장과 문제가 있는 앱을 비교합니다.
  • 실제 키보드 배열과 전용 매핑 프로그램을 확인합니다.
  • 언어 및 지역에서 한국어 IME 설치 여부를 점검합니다.
  • 필요할 때만 공식 서비스·호환성 진단으로 진행합니다.

이 순서를 지키면 가장 흔한 설정 문제를 확인하기도 전에 중요한 PC 설정을 바꾸는 일을 줄일 수 있습니다.

13. 네 가지 상황별 해결 사례

사례 A. 한국어로 바뀌었다고 뜨는데 영문만 나옵니다

Win+Space로 한국어 Microsoft IME를 선택한 뒤 A/가 아이콘을 확인합니다. A가 표시됐다면 가로 전환합니다. 두 단계가 다르다는 것이 핵심입니다.

사례 B. 한영키는 안 되지만 마우스로 가를 누르면 한글이 됩니다

Microsoft IME는 정상 작동할 가능성이 있습니다. 오른쪽 Alt 키와 다른 외장 키보드를 비교하고 키보드 매핑 프로그램을 점검합니다.

사례 C. 게임에서만 한글이 안 됩니다

메모장과 브라우저에서 먼저 시험합니다. 다른 앱에서는 정상이라면 문제 프로그램의 입력 설정, 업데이트, 공식 지원 안내를 확인합니다.

사례 D. 작업 표시줄 입력기 버튼과 Win+Space가 함께 멈춥니다

언어·레이아웃 상태를 확인한 뒤, Microsoft IME 문제 해결 문서가 설명하는 텍스트 입력 관리 서비스 상태를 검토합니다. 회사 PC라면 IT 관리자에게 확인합니다.

14. 자주 묻는 질문

Q1. 한영키가 갑자기 먹통이 된 이유가 뭔가요?

입력 언어 미선택, 한국어 IME의 A 모드, 키보드 매핑, 앱별 입력 충돌, 입력 관리 서비스 등 다양한 가능성이 있습니다. 원인은 실제 증상에 따라 구분해야 합니다.

Q2. Win+Space를 눌러도 계속 영어가 나옵니다.

한국어 Microsoft IME를 선택한 다음 A/가 아이콘이 A로 되어 있지 않은지 확인하세요. A가 가로 바뀌면 한글 입력이 가능합니다.

Q3. 오른쪽 Alt가 한영키 역할을 하나요?

Microsoft Korean IME 공식 문서에는 오른쪽 Alt로 A/가 모드를 전환하는 방법이 안내돼 있습니다. 실제 동작은 키보드 배열과 매핑에 따라 달라질 수 있습니다.

Q4. ENG만 보이면 Windows를 다시 설치해야 하나요?

아닙니다. 먼저 언어 및 지역에서 한국어와 Microsoft IME가 설치되어 있는지 확인하세요.

Q5. 회사 PC라서 서비스 설정이 잠겨 있습니다.

조직 정책을 우회하거나 시스템 서비스를 강제로 변경하지 말고 관리자에게 오류 문구와 재현 조건을 전달하세요.

Q6. 입력기 이전 버전을 사용해도 되나요?

지원되는 환경에서 호환성 문제의 임시 해결책으로 고려할 수 있습니다. Microsoft는 장기 사용을 권하지 않습니다.

Q7. 한글 입력은 되는데 한자 변환이 안 됩니다.

한자 변환은 한영 전환과 다른 기능입니다. Microsoft Korean IME는 오른쪽 Ctrl 또는 입력기 메뉴에서 한자 변환 방법을 안내합니다.

15. 최종 5분 검수표

  • ☐ 메모장에서 한영키 문제가 발생하는지 확인했다.
  • ☐ Windows 키+스페이스바로 한국어 Microsoft IME를 선택했다.
  • ☐ 작업 표시줄 입력 모드를 A에서 가로 바꿨다.
  • ☐ 마우스로 A/가 전환이 되는지 시험했다.
  • ☐ 오른쪽 Alt 및 키보드 배열을 확인했다.
  • ☐ Windows 언어 및 지역에서 한국어 IME 설치 상태를 확인했다.
  • ☐ 외장 키보드와 내장 키보드를 비교했다.
  • ☐ 게임·특정 프로그램에서만 문제인지 확인했다.
  • ☐ 입력 언어 표시줄 설정을 점검했다.
  • ☐ 고급 서비스 설정은 꼭 필요한 경우에만 검토했다.
  • ☐ 시스템 초기화·임의 레지스트리 조작을 먼저 하지 않았다.

결론: Windows 11에서 한영키가 먹통이라고 바로 고장이라고 판단하지 마세요. 한국어 Microsoft IME를 선택하는 것과 A/가 모드를 전환하는 것은 두 단계입니다. 먼저 이 차이를 확인하고, 문제가 계속될 때만 키보드 배열·특정 프로그램·입력 관리 서비스 순서로 진단하면 불필요한 재설치 없이 원인을 좁힐 수 있습니다.
