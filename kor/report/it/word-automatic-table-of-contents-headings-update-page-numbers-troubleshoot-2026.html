Word로 보고서·논문·업무 매뉴얼을 작성하다 보면 문서 앞쪽에 목차를 만들어야 할 때가 있습니다. 제목과 페이지 번호를 손으로 입력하면 본문을 수정할 때마다 페이지 번호가 어긋나기 쉽습니다. Microsoft Word의 자동 목차 기능을 사용하면 문서 제목을 읽어 목차 항목과 페이지 번호를 구성할 수 있습니다.

가장 중요한 준비 작업은 글자 크기나 굵게 표시만 바꾸는 것이 아니라 제목 1·제목 2·제목 3 스타일을 본문 제목에 적용하는 것입니다. 이 작업을 하지 않으면 제목이 눈에 보이더라도 자동 목차에서 누락될 수 있습니다.

이 글은 Microsoft의 공식 Word 지원 문서를 바탕으로 Windows용 Microsoft 365 Word·Word 2024를 기준으로 작성했습니다. Mac과 웹용 Word는 지원 범위와 메뉴 구성이 조금 다르므로 별도 항목에서 구분합니다.

1. 30초 요약: 워드 목차 만들기 기본 순서

  1. 본문에서 대제목을 선택하고 홈 → 스타일 → 제목 1을 적용합니다.
  2. 그 아래 소제목은 제목 2, 더 작은 소제목은 제목 3을 적용합니다.
  3. 문서 앞쪽의 목차를 넣을 위치에 커서를 놓습니다.
  4. 참조 → 목차 → 자동 목차 스타일을 선택합니다.
  5. 본문 수정 후에는 목차를 마우스 오른쪽 단추로 클릭해 필드 업데이트 또는 목차 업데이트를 실행합니다.
  6. 제목이 바뀌었거나 새 항목을 추가했다면 전체 목차 업데이트를 선택합니다.

2. 자동 목차를 만들기 전에 제목 스타일부터 적용하세요

자동 목차에서 가장 중요한 것은 제목의 시각적인 모양보다 스타일 정보입니다. 예를 들어 글씨를 16포인트로 키우고 굵게 표시했다고 해도 Word에서 해당 단락을 '일반' 스타일로 인식하면 자동 목차에 포함되지 않을 수 있습니다.

제목 스타일을 설정하는 방법

  1. 문서에서 장 제목에 해당하는 한 줄을 선택합니다.
  2. 상단 홈 탭에서 스타일 그룹을 찾습니다.
  3. 대제목에는 제목 1을 선택합니다.
  4. 같은 장 안의 소제목에는 제목 2를 적용합니다.
  5. 그 아래 세부 항목에는 제목 3을 적용합니다.
  6. 문서의 모든 주요 제목에 같은 방식으로 스타일을 지정합니다.
문서 구성사용 스타일예시
장(Chapter)제목 11. 사업 개요
절(Section)제목 21.1 시장 현황
세부 항목제목 31.1.1 조사 방법
일반 본문일반조사 결과 설명 문단

실무 팁: 제목을 하나하나 수동으로 굵게 만드는 대신 Word의 제목 스타일을 사용하면 목차 외에도 탐색 창에서 문서 구조를 확인하기 편해집니다.

공식 출처: Microsoft — Word 문서에 제목 추가

3. 워드 자동 목차 만드는 방법: 참조 → 목차

본문에 제목 스타일을 적용했다면 목차를 만드는 과정은 간단합니다.

  1. 목차를 넣고 싶은 위치를 클릭합니다. 보통 표지 다음이나 본문 시작 전입니다.
  2. 상단 메뉴에서 참조 탭을 엽니다.
  3. 목차를 클릭합니다.
  4. 목록에서 자동 목차 형식을 선택합니다.
  5. 제목 텍스트와 페이지 번호가 표시되는지 확인합니다.
  6. 본문에 있는 제목 1·2·3 순서와 목차 구성이 일치하는지 점검합니다.

주의: '수동 목차'를 선택하면 제목과 페이지 번호를 직접 관리해야 합니다. 제목 변경 후 자동으로 업데이트하려면 자동 목차를 선택해야 합니다.

자동 목차를 넣은 뒤 문서가 한 페이지 늘어났다면 목차 자체가 앞쪽 페이지를 차지하기 때문일 수 있습니다. 이 경우 목차를 업데이트해야 페이지 번호가 실제 위치와 일치합니다.

공식 출처: Microsoft — 목차 삽입

4. 문서를 수정했다면 목차 업데이트: 두 가지 선택의 차이

목차를 만든 뒤 본문을 수정하거나 새 소제목을 추가해도 인쇄 전에 목차를 갱신해야 할 수 있습니다.

가장 쉬운 업데이트 방법

  1. 기존 자동 목차 안쪽을 클릭합니다.
  2. 마우스 오른쪽 단추를 눌러 필드 업데이트 또는 목차 업데이트를 선택합니다.
  3. 나타나는 창에서 목적에 맞는 업데이트 범위를 선택합니다.
  4. 확인을 누릅니다.
선택반영되는 내용언제 사용할까?
페이지 번호만 업데이트기존 목차 항목의 페이지 위치 변화제목은 그대로이고 문장·사진 추가로 페이지가 바뀜
전체 목차 업데이트제목 변경·항목 추가·삭제·페이지 번호새 장을 추가했거나 제목 이름을 바꿈

중요: 새 장을 작성했는데 페이지 번호만 업데이트하면 새 제목이 목차에 나타나지 않을 수 있습니다. 새 항목이나 제목 수정이 있다면 전체 목차 업데이트가 적합합니다.

Microsoft는 참조 탭의 목차 업데이트 기능과 두 업데이트 방식의 차이를 공식 문서에서 설명하고 있습니다.

공식 출처: Microsoft — 목차 업데이트

5. '목차 항목을 찾을 수 없습니다' 또는 목차가 비어 있을 때

목차를 넣었는데 항목이 없거나 원하는 제목이 누락된다면 제목 스타일이 올바르게 적용돼 있는지 먼저 확인하세요.

원인별 확인 순서

  1. 본문에서 목차에 표시돼야 할 제목을 클릭합니다.
  2. 홈 → 스타일에서 현재 스타일이 무엇인지 확인합니다.
  3. '일반'이라면 제목 1 또는 제목의 계층에 맞는 스타일을 적용합니다.
  4. 나머지 제목도 같은 방식으로 점검합니다.
  5. 목차 영역에서 전체 목차 업데이트를 선택합니다.
  6. 새로운 항목이 표시되는지 확인합니다.

헷갈리는 부분: 본문 제목과 글꼴·크기가 같다고 Word에서 같은 '제목 스타일'로 처리되는 것은 아닙니다. 목차에는 Word가 인식할 수 있는 제목 계층이 필요합니다.

또한 사용자가 직접 타이핑한 수동 목차는 자동으로 제목 정보를 다시 끌어오지 않습니다. 이 경우 자동 목차로 다시 구성하는 편이 지속적인 수정에 유리합니다.

6. 목차에서 제목 2·제목 3이 안 보일 때

대제목은 표시되지만 소제목이 나오지 않는 경우에는 두 가지를 구분해야 합니다.

  • 본문 소제목에 제목 2·제목 3 스타일이 실제로 지정돼 있는지 확인합니다.
  • 자동 목차의 표시할 수준이 원하는 단계까지 설정되어 있는지 확인합니다.

목차에 표시할 수준 변경하기

  1. 참조 → 목차 → 사용자 지정 목차를 선택합니다.
  2. 표시할 수준을 확인합니다.
  3. 제목 1과 제목 2까지만 필요하면 2단계로, 제목 3까지 필요하면 3단계로 구성합니다.
  4. 확인한 뒤 기존 목차를 바꿀지 안내가 표시되면 변경 내용을 검토합니다.
  5. 목차를 다시 업데이트해 원하는 계층이 나오는지 확인합니다.

권장: 너무 많은 수준을 표시하면 목차가 지나치게 길어져 읽기 어려울 수 있습니다. 보고서의 실제 장·절 구조에 맞춰 2~3단계 정도부터 검토하세요. 이는 Word의 고정 제한이 아니라 가독성을 위한 편집 판단입니다.

공식 출처: Microsoft — Word 목차 서식 지정 및 사용자 지정

7. 목차 점선·페이지 번호·오른쪽 정렬 바꾸는 방법

자동 목차에서 제목과 페이지 번호 사이에 점선이 들어가게 하거나 페이지 번호를 표시하지 않게 만들 수 있습니다.

  1. 참조 → 목차 → 사용자 지정 목차를 엽니다.
  2. 페이지 번호 표시 여부를 결정합니다.
  3. 페이지 번호 오른쪽 맞춤 옵션을 확인합니다.
  4. 탭 채움선에서 점선 또는 원하는 표시 방식을 선택합니다.
  5. 표시할 수준도 함께 검토합니다.
  6. 확인한 뒤 목차 표시 결과를 확인합니다.

예를 들어 업무용 보고서라면 '1. 회사 개요 …… 3'과 같이 제목과 페이지 번호 사이를 점선으로 연결할 수 있습니다.

주의: 목차 안의 점선을 키보드로 직접 여러 개 입력하면 제목이 추가되거나 페이지 번호가 두 자릿수가 됐을 때 정렬이 어긋날 수 있습니다. 자동 목차라면 사용자 지정 목차의 탭 채움선을 사용하는 편이 관리하기 쉽습니다.

공식 출처: Microsoft — Word 목차 서식 지정 또는 사용자 지정

8. 목차 글꼴·크기·색상을 바꾸고 싶을 때

목차를 직접 드래그해 글꼴을 바꿀 수도 있지만, 목차 업데이트 후 원래 서식으로 돌아오거나 항목별 스타일이 달라질 수 있습니다. 지속적으로 형식을 유지하려면 목차 스타일을 수정하는 방식이 적절합니다.

목차 스타일 수정하기

  1. 참조 → 목차 → 사용자 지정 목차를 엽니다.
  2. 수정을 선택합니다.
  3. 수정 버튼이 비활성화돼 있다면 서식 목록을 서식 파일 기준(From template)으로 변경합니다.
  4. 표시되는 스타일 중 원하는 목차 수준을 선택합니다.
  5. 수정을 눌러 글꼴·크기·문단 서식 등을 변경합니다.
  6. 필요한 목차 수준마다 반복합니다.
  7. 확인한 후 목차 업데이트 결과에서도 서식이 유지되는지 확인합니다.

실무 예시: 대제목은 굵은 12포인트, 소제목은 일반 10포인트로 구성해 목차 계층을 구별할 수 있습니다. 수치는 예시이며 제출 양식 규정이 있다면 그 기준을 우선하세요.

공식 출처: Microsoft — Word 목차 서식 지정 또는 사용자 지정

9. 워드 탐색 창으로 제목 구조 먼저 검사하기

목차를 만들기 전에는 제목 스타일이 제대로 정리됐는지 탐색 창으로 확인하는 것이 유용합니다.

  1. Windows용 Word에서 Ctrl+F를 누르거나 보기 → 탐색 창을 선택합니다.
  2. 탐색 창의 제목 탭을 엽니다.
  3. 제목 1과 그 아래의 제목 2·3이 올바른 순서로 나타나는지 확인합니다.
  4. 항목을 클릭해 해당 본문 위치로 이동하는지 확인합니다.
  5. 목차에서 빠진 제목이 있다면 본문에서 제목 스타일을 수정합니다.

Microsoft는 탐색 창이 제목 스타일을 활용해 문서의 제목 구조를 표시한다고 안내합니다. 다만 표·텍스트 상자·머리글·바닥글 안의 제목은 탐색 창에 표시되지 않을 수 있습니다.

목차를 만들었는데 제목이 이상하게 나오면 단순히 목차 영역만 수정하기보다 본문 구조부터 확인해야 합니다.

10. 페이지 번호가 틀리거나 목차 업데이트가 안 될 때

증상가능한 원인해결 순서
본문은 10페이지인데 목차에는 9페이지본문 수정 후 갱신하지 않음페이지 번호 업데이트
새 제목이 나오지 않음새 제목 스타일 미설정 또는 전체 갱신 누락제목 1·2·3 적용 후 전체 목차 업데이트
제목이 옛 이름으로 표시됨페이지 번호만 업데이트했음전체 목차 업데이트
목차 갱신 메뉴가 기대대로 작동하지 않음수동 목차를 사용했음자동 목차로 다시 만들기 검토

Mac·웹에서 메뉴 위치 다름프로그램별 메뉴 구성 차이해당 버전의 참조/목차 메뉴 확인

Ctrl+A와 F9로 필드 업데이트하기

Windows용 Word에서는 경우에 따라 Ctrl+A → F9로 문서 전체의 필드를 업데이트할 수 있습니다. Microsoft는 목차·상호 참조·페이지 번호와 관련된 필드 갱신을 공식 문서에서 안내합니다.

다만 이 명령은 목차 외의 필드에도 영향을 줄 수 있으므로 복잡한 문서에서는 사본에서 실행하세요. 표 안의 일부 필드는 개별적으로 업데이트해야 할 수 있습니다. 목차만 바꾸고 싶다면 해당 목차를 클릭해 업데이트하는 방법이 더 명확합니다.

11. 웹용 Word·Mac용 Word에서도 자동 목차 만들 수 있나요?

가능한 기능은 버전별로 확인해야 합니다. Microsoft의 현재 '목차 삽입' 공식 안내에는 Windows·macOS·웹용 Word의 절차가 나와 있습니다.

Mac용 Word

  1. 제목 문단에 홈 → 스타일 → 제목 1·2·3을 적용합니다.
  2. 목차를 넣을 위치를 클릭합니다.
  3. 참조 → 목차에서 자동 목차를 선택합니다.
  4. 본문 수정 후 목차를 업데이트합니다.

웹용 Word

  1. 문서를 편집 가능한 상태로 엽니다.
  2. 제목에 스타일을 적용합니다.
  3. 참조 메뉴에서 목차 삽입 기능을 찾습니다.
  4. 필요한 항목을 추가한 뒤 목차를 업데이트합니다.

Microsoft의 최신 목차 안내는 웹용 Word에서도 목차를 삽입하는 절차를 제공합니다. 다만 오래된 Word Web App 지원 문서에는 목차를 표시·보존하지만 일부 편집 및 업데이트가 제한된다고 안내된 자료도 있습니다. 실제 계정·문서 형식·기능 제공 상태에 따라 메뉴가 다를 수 있으므로, 웹에서 필요한 메뉴가 제공되지 않으면 데스크톱 Word에서 최종 목차를 편집하는 방법을 사용하세요.

12. 보고서 예제로 직접 구성하기: 목차 누락 5분 테스트

아래와 같은 10페이지 내외의 사업 보고서를 만든다고 가정합니다.

본문 내용적용 스타일
1. 사업 개요제목 1
1.1 추진 배경제목 2
1.2 목적과 범위제목 2
2. 시장 분석제목 1
2.1 시장 규모제목 2
2.2 경쟁 현황제목 2
3. 실행 계획제목 1
3.1 일정제목 2
3.2 예상 비용제목 2
본문 설명 문단일반

실제 시험 순서

  1. 위 제목들이 올바른 스타일로 설정됐는지 확인합니다.
  2. 문서 앞쪽에 자동 목차를 삽입합니다.
  3. 본문에서 '2.2 경쟁 현황'을 '2.2 경쟁사 분석'으로 변경합니다.
  4. 목차에서 페이지 번호만 업데이트를 실행해 제목이 그대로인지 확인합니다.
  5. 이번에는 전체 목차 업데이트를 실행해 '경쟁사 분석'으로 바뀌는지 확인합니다.
  6. 새 제목 '3.3 위험 관리'를 추가하고 제목 2 스타일을 적용합니다.
  7. 전체 목차를 업데이트해 새 항목이 나타나는지 확인합니다.

이 테스트를 해보면 페이지 번호만 갱신하는 기능과 전체 항목을 다시 만드는 기능의 차이를 쉽게 이해할 수 있습니다.

13. 목차를 제출하기 전에 확인할 실수 7가지

  • 제목을 수동으로 굵게만 표시: 자동 목차에서 누락될 수 있습니다.
  • 수동 목차를 자동 목차로 착각: 제목을 바꿔도 자동 업데이트되지 않을 수 있습니다.
  • 새 제목 추가 후 페이지 번호만 업데이트: 신규 항목이 빠질 수 있습니다.
  • 목차 표시 수준을 지나치게 낮게 설정: 제목 2·3이 누락될 수 있습니다.
  • 목차의 점선과 번호를 직접 타이핑: 업데이트 때 정렬이 달라질 수 있습니다.
  • 목차 항목을 일일이 드래그해 글꼴 변경: 목차 스타일을 수정하는 편이 유지보수에 적합합니다.
  • PDF 내보내기 전에 미갱신: 잘못된 페이지 번호가 출력물에도 남을 수 있습니다.

보고서가 완성됐다면 먼저 전체 목차 업데이트를 실행하고, 파일을 저장한 다음 PDF 또는 인쇄 미리 보기에서 목차 페이지 번호와 실제 본문 페이지를 비교하세요.

14. 자주 묻는 질문

Q. Word 자동 목차는 어떤 메뉴에서 만들 수 있나요?

본문 제목에 제목 1·2·3 스타일을 적용한 뒤 참조 → 목차에서 자동 목차 형식을 선택합니다.

Q. 글꼴을 크게 하고 굵게 했는데 목차에 나오지 않아요.

문단에 Word의 제목 스타일이 적용되지 않았을 수 있습니다. 제목을 선택한 후 홈 → 스타일에서 제목 1이나 제목 2를 적용하세요.

Q. 목차 페이지 번호만 바꾸고 싶어요.

기존 목차에서 목차 업데이트 → 페이지 번호만 업데이트를 선택하세요.

Q. 제목을 추가했는데 목차에 안 나옵니다.

신규 제목에 제목 스타일을 적용했는지 확인하고 전체 목차 업데이트를 실행하세요.

Q. 목차에 점선과 페이지 번호가 나오게 하려면?

참조 → 목차 → 사용자 지정 목차에서 페이지 번호 표시·오른쪽 정렬·탭 채움선을 설정하세요.

Q. 목차의 소제목을 3단계까지만 표시할 수 있나요?

네. 사용자 지정 목차의 표시할 수준을 3으로 설정하면 해당 계층까지 표시하도록 구성할 수 있습니다.

Q. 자동 목차와 수동 목차의 차이는 무엇인가요?

자동 목차는 Word의 제목 스타일을 기반으로 생성되어 갱신할 수 있지만, 수동 목차는 제목과 페이지 번호를 직접 입력하고 수정해야 합니다.

Q. Word 온라인에서 목차를 만들 수 있나요?

Microsoft 최신 공식 도움말에는 웹용 Word의 목차 삽입 절차가 있습니다. 다만 일부 문서나 기능 환경에서는 편집·갱신이 제한될 수 있어, 메뉴가 없다면 데스크톱 Word에서 작업하세요.

15. 최종 체크리스트

  • ☐ 대제목에는 제목 1, 소제목에는 제목 2·3 스타일을 적용했다.
  • ☐ 참조 탭에서 수동 목차가 아닌 자동 목차를 선택했다.
  • ☐ 탐색 창에서 제목 구조가 올바른지 확인했다.
  • ☐ 새 항목을 추가한 뒤 전체 목차 업데이트를 실행했다.
  • ☐ 페이지 번호와 탭 채움선·표시 수준을 확인했다.
  • ☐ 문서 전체를 검토하고 PDF 또는 인쇄 미리 보기에서 페이지 번호를 확인했다.

결론: 워드 자동 목차는 '참조 → 목차'에서 시작하지만, 제대로 작동시키는 핵심은 본문에 제목 스타일을 정확히 지정하는 것입니다. 제목이나 문서 구성을 바꾼 뒤에는 전체 목차를 업데이트하세요. 이렇게 해두면 보고서의 내용이 길어져도 목차를 처음부터 다시 타이핑할 필요가 줄어듭니다.
