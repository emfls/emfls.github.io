집에서 노트북이나 새 휴대전화를 와이파이에 연결하려는데 비밀번호가 기억나지 않을 때가 있습니다. 이미 연결된 기기가 있다면 공유기를 초기화하기 전에 그 기기에 저장된 Wi-Fi 암호를 확인하는 편이 빠르고 안전합니다.

이 글은 2026년 11월 기준 Apple·Microsoft·Samsung·Google 공식 지원 문서를 대조해 아이폰, 갤럭시, 윈도우 11, 맥에서 암호를 찾는 방법과 QR 코드로 연결을 공유하는 방법을 구분했습니다. 운영체제 버전, 기종, 회사·학교의 관리 정책에 따라 메뉴와 사용 가능 여부가 달라질 수 있습니다.

1. 30초 요약: 사용하는 기기별로 어디를 누를까?

기기암호를 확인하거나 공유하는 경로중요한 차이
아이폰(iOS 16 이상)설정 → Wi-Fi → 연결된 네트워크의 정보(i) → 암호Face ID·Touch ID·기기 암호로 확인
아이폰(iOS 18 이상)암호 앱 → Wi-Fi → 네트워크 선택 → 암호이전에 연결했던 네트워크도 검색 가능
갤럭시설정 → 연결 → Wi-Fi → 연결된 네트워크의 설정(톱니바퀴) → QR 코드일반적으로 QR로 공유하며, 암호 글자 표시 여부는 모델마다 다름
윈도우 11설정 → 네트워크 및 인터넷 → 현재 연결된 Wi-Fi의 속성 → Wi-Fi 네트워크 암호 ‘표시’알려진 네트워크 관리에서도 저장된 암호 확인 가능
맥(macOS Ventura 이상)시스템 설정 → 네트워크 → Wi-Fi → 고급 → 저장된 네트워크의 더보기 → 암호 복사붙여넣기로 암호 확인

핵심: QR 코드를 보여주는 기능과 비밀번호를 문자로 보여주는 기능은 같지 않습니다. 갤럭시에서 QR만 표시되는 것은 이상이 아닐 수 있으며, QR을 스캔하는 기기는 비밀번호를 직접 입력하지 않고도 연결할 수 있습니다.

공식 기준: Apple 저장된 Wi-Fi 암호, Microsoft Wi-Fi 암호 찾기, Samsung Galaxy QR 공유

2. 아이폰에서 와이파이 비밀번호 확인하기

현재 연결된 Wi-Fi의 암호 확인

iOS 16 이상을 사용하는 아이폰에서는 다음 순서로 확인할 수 있습니다.

  1. 설정 앱을 열고 Wi-Fi를 누릅니다.
  2. 현재 연결된 네트워크 이름 오른쪽의 정보(i) 버튼을 누릅니다.
  3. 암호 항목을 누릅니다.
  4. Face ID, Touch ID 또는 기기 암호로 본인 인증을 합니다.
  5. 표시된 암호를 확인하거나 복사합니다.

예를 들어 집 공유기 이름이 HOME-5G라면, 연결 중인 HOME-5G의 상세 정보에 들어가야 합니다. 이웃집의 비슷한 이름을 선택하지 않도록 네트워크 이름(SSID)을 먼저 확인하세요.

이전에 연결했던 Wi-Fi 암호 확인

설정 → Wi-Fi → 편집에서 예전에 연결했던 네트워크를 찾아 정보 버튼과 암호 항목을 누르는 경로가 지원됩니다. iOS 18 이상에서는 암호 앱 → Wi-Fi에서도 저장된 네트워크를 확인할 수 있습니다.

최근 iPhone 사용 설명서는 암호 앱에서 Wi-Fi → 네트워크 선택 → 암호 필드를 누르는 방법과 네트워크 QR 코드 표시 기능도 안내합니다. 다만 iOS 버전에 따라 해당 버튼이 보이지 않을 수 있습니다.

공식 출처: Apple — iPhone 또는 iPad에서 저장된 Wi-Fi 암호 찾기, Apple — iPhone Wi-Fi 네트워크 암호 찾기 및 공유

다른 아이폰에 암호 공유하기

상대방이 근처에서 같은 Wi-Fi를 선택하면, 이미 연결된 내 아이폰에 암호 공유 알림이 표시될 수 있습니다. 양쪽에서 Wi-Fi와 Bluetooth를 켜고 Apple 계정에 로그인했는지, 서로의 Apple 계정 연락처 정보가 저장되어 있는지 확인합니다. 공유하는 쪽은 잠금 해제된 상태여야 합니다. 개인용 핫스팟이 켜져 있으면 끄세요.

공식 출처: Apple — Wi-Fi 암호 공유

3. 갤럭시에서 와이파이 QR 코드로 공유하기

삼성 갤럭시에서는 저장된 암호를 문자로 확인하는 대신 연결 정보가 포함된 QR 코드로 공유하는 방법이 편리합니다.

  1. 설정 → 연결 → Wi-Fi로 이동합니다.
  2. 현재 연결된 와이파이 이름 옆의 톱니바퀴(설정)를 누릅니다.
  3. 화면의 QR 코드 또는 Wi-Fi 공유 관련 메뉴를 선택합니다.
  4. 필요한 경우 화면 잠금 인증을 완료합니다.
  5. 연결할 다른 휴대전화에서 카메라 또는 QR 스캔 기능으로 코드를 읽습니다.
  6. 새 기기에 표시된 네트워크 연결을 확인하고 실제로 인터넷에 접속되는지 시험합니다.

One UI 버전과 갤럭시 모델에 따라 메뉴 위치 및 문자 암호 표시 여부가 다를 수 있습니다. QR 메뉴가 안 보이면 연결 중인 네트워크의 상세 설정을 열었는지 확인하세요.

주의: Wi-Fi 공유 QR은 단순한 장식 이미지가 아닙니다. 네트워크 접속에 필요한 정보를 전달하므로 공개 SNS, 커뮤니티나 여러 사람이 보는 단체 채팅방에 올리지 마세요. 또한 Wi-Fi QR 공유와 Quick Share 파일 전송 QR은 다른 기능입니다.

공식 출처: Samsung — 갤럭시 Wi-Fi 암호 QR 공유, Google — Android Wi-Fi 정보 공유

4. 윈도우 11에서 저장된 Wi-Fi 비밀번호 찾기

윈도우 11에서는 명령 프롬프트를 실행하지 않고도 설정 화면에서 암호를 표시할 수 있습니다.

지금 연결된 와이파이 암호

  1. 시작 → 설정을 엽니다.
  2. 네트워크 및 인터넷에서 현재 연결된 Wi-Fi 네트워크의 속성으로 이동합니다.
  3. Wi-Fi 네트워크 암호 항목의 표시를 누릅니다.
  4. 문자로 나타난 암호를 확인하고 연결하려는 기기에 입력합니다.

예전에 연결한 와이파이 암호

설정 → 네트워크 및 인터넷 → Wi-Fi → 알려진 네트워크 관리에서 대상 네트워크를 선택한 후, Wi-Fi 네트워크 암호 표시를 이용할 수 있습니다. Windows 빌드나 관리 정책에 따라 세부 메뉴가 다르면 설정 검색에서 '알려진 네트워크 관리'를 찾아보세요.

회사·학교에서 관리하는 PC에는 자격 증명 표시가 제한될 수 있습니다. 이런 경우 관리자에게 문의하는 것이 적절하며, 보안 통제를 우회하는 도구를 설치할 필요는 없습니다.

공식 출처: Microsoft — Windows에서 Wi-Fi 네트워크 암호 찾기

5. 맥북·아이맥에서 와이파이 암호 확인하기

macOS Ventura 및 이후 버전에서는 저장된 Wi-Fi 암호를 다음과 같이 복사할 수 있습니다.

  1. Apple 메뉴에서 시스템 설정을 엽니다.
  2. 네트워크 → Wi-Fi로 이동합니다.
  3. 아래로 내려 고급을 선택해 알려진 네트워크 목록을 엽니다.
  4. 필요한 네트워크 이름 옆의 더보기(…) 버튼을 누릅니다.
  5. 암호 복사를 선택합니다.
  6. 본인만 보는 메모 또는 안전한 입력 필드에 붙여넣어 확인합니다.

현재 연결된 네트워크와 저장된 네트워크는 구분해서 선택하세요. 복사한 암호가 클립보드에 남을 수 있으므로, 확인을 마친 뒤 민감한 정보가 아닌 다른 내용을 복사해 두는 것도 방법입니다. 운영체제에 따라 암호 앱이나 키체인 접근 등 다른 경로가 제공될 수도 있습니다.

공식 출처: Apple — Wi-Fi 암호와 관련하여 도움이 필요한 경우

6. 이미 연결된 기기가 하나도 없다면?

공유기 본체의 라벨, 설치 안내문, 인터넷 사업자 제공 앱 또는 공유기 제조사 공식 관리 화면을 확인합니다.

  • 공유기 라벨의 Wi-Fi Password / Wireless Key / 무선 암호는 출고 시 네트워크 암호일 수 있습니다. 사용자가 암호를 변경했다면 라벨의 암호는 현재 암호와 다릅니다.
  • Wi-Fi 이름(SSID)과 공유기 관리자 로그인 암호는 서로 다른 정보입니다. 관리자 암호를 와이파이 연결 창에 넣어도 접속되지 않을 수 있습니다.
  • 인터넷 사업자 제공 공유기는 전용 앱이나 고객센터의 인증 절차를 통해 정보를 확인할 수 있는지 문의합니다.
  • 공유기를 초기화하면 기존 네트워크 이름·암호·연결 기기 설정이 바뀔 수 있습니다. 여러 스마트홈 기기를 다시 설정해야 할 수 있으므로 초기화는 마지막 방법으로 남겨두세요.

관리 권한이 없는 카페·회사·숙소의 공유기라면 직원 또는 네트워크 관리자에게 문의해야 합니다.

7. 비밀번호가 맞는데도 연결이 안 될 때 점검표

증상확인할 원인먼저 할 일

QR을 읽어도 연결되지 않음오래된 QR·접속 제한·신호 부족현재 연결된 기기에서 QR 새로 생성

암호가 틀린 문제와 연결됐지만 인터넷이 없는 문제는 별도로 판단해야 합니다. 라우터를 공장 초기화하기 전에 다른 기기에서도 같은 문제가 나타나는지 확인하세요.

8. 자주 묻는 질문

Q. 갤럭시 QR 코드를 캡처해 보내도 되나요?

가능한 경우가 있지만 공개 게시에는 적합하지 않습니다. QR 코드를 받은 사람이 그 네트워크에 연결할 수 있으므로 신뢰하는 사람에게만 전달하세요. 캡처가 다른 앱의 사진 백업이나 단체방에 남는지도 고려해야 합니다.

Q. 아이폰에서 암호가 보이지 않는 이유는 뭔가요?

iOS 버전, 해당 네트워크의 저장 여부, 잠금 인증, 관리형 네트워크 정책을 확인하세요. iOS 16 미만에서는 설정 앱에 동일한 암호 표시 경로가 없을 수 있습니다.

Q. 윈도우에서 비밀번호를 확인하면 공유기 암호가 바뀌나요?

아닙니다. 저장된 암호를 보는 것과 공유기에서 암호를 변경하는 것은 서로 다른 작업입니다. 기존 암호를 확인하는 것만으로 다른 기기가 끊기지는 않습니다.

Q. QR로 연결한 다음 비밀번호를 다시 바꿔야 하나요?

가족 등 신뢰하는 사람과 공유했다면 반드시 바꿔야 하는 것은 아닙니다. 다만 QR이나 암호가 공개된 곳에 게시됐다면 공유기 관리자 화면에서 무선 암호를 변경하고 연결 기기 목록도 점검하세요. 가능하다면 별도 게스트 Wi-Fi 사용을 권장합니다.

9. 실제 사용 전 최종 체크리스트

  • ☐ 현재 연결된 네트워크의 이름(SSID)을 먼저 확인했다.
  • ☐ 기기와 OS 버전에 맞는 공식 메뉴를 선택했다.
  • ☐ QR 코드 공유와 비밀번호 문자 보기를 구분했다.
  • ☐ 비밀번호가 보이지 않는다고 공유기를 먼저 초기화하지 않았다.
  • ☐ 새 기기에서 실제로 인터넷에 연결되는지 시험했다.
  • ☐ Wi-Fi 비밀번호 또는 공유 QR을 공개 게시물에 올리지 않았다.
