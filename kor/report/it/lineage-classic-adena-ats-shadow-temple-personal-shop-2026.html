아이템 판매로 받은 아데나

드롭한 아이템이나 재료를 NPC 또는 게임 내 개인상점 등 허용된 방법으로 판매해 얻은 금액입니다. 단순히 아이템을 획득했다거나 높은 가격으로 등록했다는 이유만으로 판매가 확정되는 것은 아닙니다.

순아데나 = 직접 획득 아데나 + 실제 완료된 게임 내 아이템 판매액 - 물약·소모품·이동·수리 등 아데나 지출

리니지 클래식을 수동 플레이 중심의 옛날 게임으로 알고 있다면 **ATS(Ancient Threat Scanner)**라는 공식 자동 플레이 기능이 낯설 수 있습니다. 엔씨소프트는 2026년 2월 11일 정식 오픈 시점부터 육성 피로도를 줄이기 위해 특정 지역에 한정한 자동 플레이 지원 기능을 도입했다고 설명합니다.

ATS 실행하는 방법

  1. 게임의 행동창에서 ATS 아이콘을 찾습니다.
  2. 또는 키보드에서 ALT + G를 눌러 ATS를 활성화할 수 있습니다.
  3. 화면에 표시되는 ATS 잔여 이용 시간을 확인합니다.
  4. ALT + W 또는 ATS 행동창을 열어 자동 플레이 방식을 설정합니다.
  5. 해당 지역에서 ATS 사용이 허용되는지 확인합니다.
  6. 자동 전투가 실제 의도한 범위에서만 실행되는지 점검합니다.

ATS 행동창의 세 가지 주요 설정

버프: HP·MP 조건에 맞춰 물약을 사용하거나 버프 아이템을 등록하는 기능입니다. 다만 자동으로 사용되는 물약은 무료가 아니므로 소모량이 많아지면 아데나 순이익이 줄어들 수 있습니다.

전투: 사용 가능한 마법과 우선순위를 사냥 패턴에 맞게 설정할 수 있습니다. 스킬을 자주 사용하면 편리할 수 있지만 MP 회복·소모품 비용도 달라질 수 있습니다.

옵션: 자동 사냥의 탐색 범위와 아이템 획득 옵션을 설정할 수 있습니다. 놓치는 드롭과 과도한 이동을 줄이려면 실제 전투 결과를 확인해야 합니다.

ATS 3시간은 모든 사냥터에서 쓸 수 있나요?

그렇지 않습니다. 2월 11일 공식 안내의 일 3시간 기본 이용 시간은 당시 ATS와 오염된 축복의 땅 관련 사용 조건에 대한 설명입니다.

7월에 추가된 버림받은 자들의 땅과 10월 신규 그림자 신전 역시 ATS를 지원하지만, 각 사냥터의 입장 가능 시간과 ATS의 이용 가능 시간은 별도 개념입니다. 3시간짜리 ATS를 켰다고 그림자 신전의 기본 1시간 입장 제한이 자동으로 사라지지는 않습니다.

6. ATS 효율을 높인다는 말보다 물약비부터 확인하세요

자동 전투가 가능하면 장시간 사냥을 반복하기 쉬워지지만, 실제 게임 내 순수익은 자동으로 얼마나 오래 움직였는지가 아니라 그 사이 아데나가 얼마나 남았는지로 판단해야 합니다.

자동 전투 전 기록

  1. 현재 아데나 잔액을 확인합니다.
  2. 빨간 물약·파란 물약 등 소모품 수량과 구입 비용을 기록합니다.
  3. ATS 잔여 시간과 사냥터 잔여 시간을 따로 확인합니다.
  4. 장비 내구·수리 관련 비용이나 기타 소비가 있는지 살펴봅니다.
  5. 20분 또는 30분의 측정 구간을 정합니다.

자동 전투 후 기록

  1. 아데나 잔액이 얼마 증가했는지 확인합니다.
  2. 실제 획득한 드롭 아이템 수량을 기록합니다.
  3. 물약·기능성 아이템을 몇 개 사용했는지 세어 봅니다.
  4. 죽음·귀환·이동·전투 중단으로 실제로 공격하지 않은 시간이 얼마나 있었는지 확인합니다.
  5. 아이템을 판매했다면 실제 판매 완료한 금액만 반영합니다.

자동 사냥인데 왜 손해가 날까요?

강한 몬스터를 상대하면서 물약을 지나치게 소비하거나, 아이템 드롭이 거의 없거나, 전투가 자주 끊기면 아데나 증가보다 소모품 지출이 더 클 수 있습니다.

예를 들어 30분에 아데나 12만을 벌어도 물약·주문서 등에 14만이 들었다면 순아데나 변화는 -2만입니다. 자동으로 사냥했다는 사실만으로 수익이 발생한 것은 아닙니다.

효율이 낮을 때 바꿔볼 기준

  • 사용하는 물약의 조건이 지나치게 공격적인지
  • 몬스터 난이도가 현재 장비에 적합한지
  • 이동 시간이 전투 시간보다 긴지
  • 드롭 아이템이 실제 판매 가능한지
  • 빈번한 사망·귀환으로 경험치와 시간이 손실되는지

ATS 설정을 과하게 변경할수록 좋은 것은 아닙니다. 생존이 불안정한 사냥터보다 적정 난도의 사냥터가 실제 순아데나 면에서 효율적일 수도 있습니다.
