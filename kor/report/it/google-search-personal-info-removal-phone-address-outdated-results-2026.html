내 이름을 Google에 검색했더니 오래전에 사용하던 휴대전화 번호와 집주소가 나옵니다. 게시판 글을 이미 지웠는데 검색 결과에는 이름과 연락처가 계속 남아 있거나, 타인이 올린 사진이 이미지 검색에 나타날 수도 있습니다. 이때 무조건 “구글에서 삭제”만 검색하면 서로 다른 절차를 헷갈리기 쉽습니다.

가장 중요한 사실은 Google 검색 결과에서 링크를 제거하는 것과 원본 웹사이트에서 정보를 삭제하는 것은 별개의 작업이라는 점입니다. Google은 일정한 요건에 맞는 개인정보에 대해 검색 결과 삭제 요청을 접수하지만, 다른 사람이 운영하는 웹사이트의 원문을 직접 지워 주지는 못합니다. 반대로 원본 게시물을 이미 삭제한 경우라면 개인정보 삭제 요청보다 오래된 콘텐츠 새로고침 기능이 상황에 더 맞을 수 있습니다.

이 글은 2026년 11월 1일 확인한 Google 검색 고객센터와 Search Console 공식 문서를 바탕으로 작성했습니다. 독자가 원본 페이지 상태를 먼저 판별하도록 **‘검색 노출 3단계 대응표’와 ‘10분 증거 정리 실습’**을 자체적으로 구성했습니다. 이 점검법은 Google이 승인이나 처리 시간을 보증하는 공식 프로그램이 아니며, 실제 삭제 여부는 콘텐츠와 정책, 공개 가치 및 지역별 서비스 제공 조건에 따라 달라집니다.

2. 먼저 이해할 세 가지 장소: 원본 사이트·검색 결과·공유된 복사본

검색에서 개인정보가 나타나면 세 가지 장소를 나눠 생각해야 합니다.

첫째, 원본 웹사이트. 다른 사람이 올린 게시판 글, 주소록 형태의 사이트, 블로그, 이미지 게시물 등 실제 콘텐츠를 보관하는 곳입니다. 원본이 공개돼 있는 한 직접 주소를 입력하거나 다른 검색엔진을 이용해 계속 찾을 수 있습니다.

둘째, Google 검색 결과. Google은 원본 페이지의 링크와 제목·설명 등을 검색 결과로 보여 줍니다. Google의 정책에 따라 검색 결과 링크를 제한하더라도 웹사이트의 원문 자체가 제거되는 것은 아닙니다.

셋째, 다른 복사본. 같은 정보가 다른 사이트나 소셜미디어에 재게시됐거나, 누군가 파일·스크린샷으로 저장한 경우가 있습니다. 하나의 URL을 삭제한다고 별도의 복사본까지 자동 삭제되는 것은 아닙니다.

예를 들어 본인의 전화번호가 게시된 A사이트에 대해 Google 검색 결과 삭제가 승인됐더라도, A사이트에서 게시물이 유지되면 다른 검색엔진이나 공유 링크로 찾아갈 수 있습니다. 이것이 ‘검색에서 사라졌다’와 ‘인터넷에서 사라졌다’는 다른 뜻인 이유입니다.

Google은 검색 결과에서 콘텐츠를 제거할 수 있지만, 외부 사이트의 내용을 제거하려면 해당 사이트 소유자에게 요청해야 한다고 명시합니다.

3. 삭제 요청 전에 10분 동안 증거를 정리하세요

민감한 정보를 검색 결과에서 발견했을 때 당황해서 여러 양식에 같은 내용을 반복 제출하기보다 문제가 있는 URL과 현재 상태부터 정리하는 편이 좋습니다.

0~2분: 어떤 정보가 문제인지 구분

전화번호인지, 실제 집주소인지, 이메일인지, 신분증 번호인지, 은행 계좌번호인지 확인합니다. 검색 결과 제목에는 정보가 없어도 실제 페이지 안에 있을 수 있습니다.

2~4분: URL 확인

Google 검색 결과의 링크를 열어 문제가 있는 원본 웹페이지 주소를 기록합니다. 검색어를 입력한 Google 검색 화면의 주소와 개인정보가 포함된 게시물의 주소는 다릅니다.

4~6분: 원본이 살아 있는지 확인

원본 페이지에서 정보가 실제로 남아 있는지, 삭제됐는지, 로그인 후에만 나타나는지 확인합니다. 원본이 삭제됐다면 오래된 콘텐츠 새로고침 대상일 수 있습니다.

6~8분: 필요한 범위에서 화면 기록

Google의 공식 양식은 경우에 따라 스크린샷을 요청합니다. 문제가 되는 정보가 확인되는 화면을 필요한 범위만 캡처하되, 제3자의 개인정보나 불필요한 주변 내용을 포함하지 않도록 주의합니다.

8~10분: 요청 경로 결정

원본이 여전히 살아 있고 내 비공개 정보라면 개인정보 삭제 요청을, 원본이 이미 삭제·변경됐다면 오래된 콘텐츠 새로고침을, 내가 운영하는 사이트라면 사이트 자체 수정 및 Search Console을 우선합니다.

중요: 증거를 만들기 위해 주민등록번호나 금융계좌 비밀번호를 다른 문서에 반복 복사하거나 공개 게시판에 올리지 마세요. Google이 요청한 필수 정보만 공식 제출 화면에 입력하고 별도 기록에는 필요한 최소한의 정보만 남기는 것이 좋습니다.

4. 어떤 개인정보가 Google 삭제 요청 대상인가요?

Google의 개인정보 삭제 정책은 일부 비공개 개인 식별 정보에 대해 검색 결과 삭제를 요청할 수 있도록 합니다.

개인 연락처집주소, 휴대전화 번호, 이메일 주소본인의 정보인지 확인

이 목록에 있는 정보라고 해서 모든 페이지가 자동으로 삭제되는 것은 아닙니다. Google은 본인 또는 대리인이 요청한 URL을 검토하며, 개인정보의 공개 맥락과 공익성을 함께 고려할 수 있습니다.

특히 신상 털기(doxxing)는 실제 개인정보와 명시적·묵시적 위협이 있는지, 또는 정당한 목적 없이 상당한 양의 개인정보가 합쳐져 있는지를 살펴봅니다. 단지 기분이 나쁜 평가 글이라는 이유만으로 이 정책에 해당한다고 단정할 수 없습니다.

5. 내 전화번호와 집주소가 검색될 때: ‘나와 관련된 검색결과’

Google은 ‘나와 관련된 검색결과(Results about you)’ 기능을 통해 내 전화번호·집주소·이메일 등 연락처가 검색 결과에 나타나는지 확인하고, 일부 결과에 대해 삭제를 요청하는 절차를 안내합니다.

다만 Google 공식 문서에는 일부 기능이 특정 국가·지역에서 만 18세 이상 사용자에게 순차 제공 중이라는 설명이 있습니다. 따라서 한국의 모든 계정에서 같은 메뉴가 항상 보인다고 보장해서는 안 됩니다.

사용 가능한 계정에서 확인하는 방법

  1. Google 계정에 로그인합니다.
  2. Google 앱의 프로필 사진 또는 이니셜을 선택합니다.
  3. 메뉴에 **나와 관련된 검색결과(Results about you)**가 나타나는지 확인합니다.
  4. 기능이 제공된다면 시작하기(Get started) 또는 설정을 선택합니다.
  5. 검색에 사용할 본인 이름과 연락처 정보를 지정합니다.
  6. 발견된 결과 목록을 검토합니다.
  7. 공개를 원치 않는 결과에서 **삭제 요청(Request to remove)**을 선택합니다.
  8. 접수 상태와 Google의 이메일 안내를 확인합니다.

Google은 이 기능을 이용한 모니터링과 알림 설정을 안내하지만, 서비스 제공 여부와 지역별 사용 가능 기능은 실제 계정 화면에서 확인해야 합니다.

메뉴가 보이지 않는다면?

기능이 없다고 해서 개인정보 삭제를 요청할 수 없는 것은 아닙니다. 다음 절의 상세 비공개 정보 삭제 요청 양식으로 진행하세요. 만 18세 미만에 대한 신청이나 다른 사람을 대신한 요청도 상세 양식 안내를 확인해야 합니다.

6. Google 검색 결과에서 직접 삭제 요청하기

개인 연락처가 포함된 검색 결과를 발견한 경우, Google 공식 도움말은 검색 결과 자체의 옵션에서 삭제 요청을 시작하는 절차도 설명합니다.

  1. Google 계정으로 로그인합니다.
  2. 자신의 이름과 노출된 개인 연락처 등 관련 검색어로 검색합니다.
  3. 문제가 있는 검색 결과의 **더보기(점 3개)**를 선택합니다.
  4. 이 검색 결과 정보(About this result) 화면을 엽니다.
  5. 결과 삭제(Remove result) 항목이 제공되는지 확인합니다.
  6. 내 개인정보가 표시되어 삭제를 원함에 해당하는 사유를 선택합니다.
  7. 정보 유형을 선택하고 화면에 표시되는 질문에 답합니다.
  8. 요청 제출 후 이메일과 신청 상태를 확인합니다.

‘결과 삭제’ 버튼이 안 보일 때

Google은 뉴스·정부기관·학교·일부 기업 관련 페이지처럼 공개 가치가 있는 것으로 판단되는 결과에 대해서는 해당 버튼을 제공하지 않을 수 있다고 설명합니다. 사용 중인 국가, 나이, 계정 상태 및 콘텐츠 유형에 따라서도 절차가 달라질 수 있습니다.

이 경우 상세 삭제 요청 양식의 정책 조건을 확인하거나 사이트 운영자에게 원본 삭제를 요청하는 방법을 고려할 수 있습니다. 하지만 버튼이 보이지 않는다는 사실만으로 반드시 삭제할 수 없다고 단정하지 마세요.

공식 출처: Google — 검색 결과에서 개인정보 삭제 요청

7. 주민등록번호·계좌번호 등은 상세 비공개 정보 삭제 양식으로

비공개 신분증 번호, 계좌번호, 의료 기록, 비밀번호처럼 위험도가 높은 정보는 Google의 비공개 개인정보 삭제 요청 절차를 확인해야 합니다.

신청 전에 준비할 정보

  • 본인의 정보라는 것을 설명할 수 있는 기본 정보
  • 개인정보가 실제로 노출된 웹페이지 URL
  • Google이 요구하는 경우 필요한 범위의 스크린샷
  • 어떤 종류의 비공개 정보가 노출됐는지에 관한 설명
  • 신상 털기라면 해당 페이지에 포함된 위협의 맥락

공식 고객센터에서 시작하기

  1. Google의 비공개 정보 삭제 안내를 엽니다.
  2. 삭제 요청 시작을 선택합니다.
  3. 정보 종류와 노출 방식에 해당하는 항목을 고릅니다.
  4. 실제 콘텐츠 URL을 입력합니다.
  5. 필요한 경우 스크린샷과 설명을 첨부합니다.
  6. 제출한 내용을 확인하고 접수합니다.
  7. 안내 이메일을 보관하고 결과를 확인합니다.

공식 페이지: Google — 내 비공개 정보 삭제하기

주의: 비밀번호나 결제 카드 정보가 실제 노출됐다면 검색 결과 삭제 신청만으로 계정·금융 피해 위험이 즉시 사라지는 것은 아닙니다. 해당 계정의 인증정보 변경, 카드사·은행의 보호 조치 등 노출 정보 유형에 맞는 추가 조치를 함께 검토해야 합니다.

8. 삭제 요청에 올바른 URL을 제출하는 방법

Google의 공식 안내는 삭제 요청 시 **문제가 있는 콘텐츠의 주소(URL)**를 정확하게 제공해야 한다고 강조합니다.

  2. 실제 콘텐츠를 호스팅한 원본 페이지로 이동합니다.
  3. 주소 표시줄의 URL을 복사해 기록합니다.
  4. 페이지 안에 개인정보가 나타나는지 확인합니다.
  5. 필요한 경우 검색 결과 화면과 원본 페이지를 구분해 스크린샷을 준비합니다.

주의: 문제의 URL을 SNS나 공개 커뮤니티에 문의용으로 다시 올리면 오히려 개인정보 노출을 확대할 수 있습니다. 공식 신고 폼을 사용하고, 제삼자에게 보내는 자료는 최소화하세요.

9. 원본 사이트 관리자에게 직접 삭제 요청하기

검색 결과에서 링크가 안 보여도 원본 사이트에는 내용이 남아 있을 수 있습니다. Google은 원본 콘텐츠를 없애려면 웹사이트 소유자에게 연락하는 것이 가장 좋다고 안내합니다.

연락처 찾는 방법

  1. 문제가 있는 게시물의 웹사이트 메인 페이지로 이동합니다.
  2. 문의하기, 고객센터, 개인정보처리방침, 신고하기 항목을 찾습니다.
  3. 게시판·커뮤니티라면 해당 게시물의 신고 기능을 확인합니다.
  4. 소셜미디어라면 플랫폼의 게시물 삭제 또는 권리침해 신고 절차를 확인합니다.
  5. 소유자 연락처를 찾기 어렵다면 등록·호스팅 정보 조회를 검토할 수 있습니다.

운영자에게 전달할 핵심 내용

  • 문제의 게시물 URL
  • 본인 개인정보가 노출된 구체적인 부분
  • 삭제 또는 해당 부분의 비공개 처리를 요청한다는 취지
  • 조치 후 확인을 요청하는 연락 방법

권장 문장 예시

“귀 사이트의 다음 게시물에 제 개인 연락처 정보가 노출돼 있습니다. 개인정보가 포함된 부분의 삭제 또는 비공개 처리를 요청드립니다. 해당 URL은 [페이지 주소]이며, 조치 결과를 회신해 주시면 감사하겠습니다.”

비밀번호·주민등록번호·계좌번호 원문을 일반 문의 이메일에 반복해서 적는 것은 피하세요. 필요한 경우 안전한 공식 신고 채널에만 증빙 정보를 제출하는 편이 좋습니다.

10. 원본은 이미 지웠는데 Google 검색 설명이 남아 있다면

이 상황은 개인정보가 현재 살아 있는 페이지에 남아 있는 경우와 다릅니다.

예를 들어 커뮤니티 글을 삭제했고 해당 링크를 열면 ‘페이지를 찾을 수 없습니다’가 나타나는데, Google 검색에서는 옛 제목과 개인정보가 담긴 설명이 계속 보일 수 있습니다. 혹은 게시물을 수정해 전화번호를 지웠는데 검색 설명에는 여전히 이전 번호가 표시될 수 있습니다.

이때 Google의 오래된 콘텐츠 새로고침(Refresh Outdated Content) 도구를 검토하세요.

이 도구가 적합한 조건

  • 문제의 원본 웹사이트는 본인이 운영하지 않습니다.
  • 페이지나 이미지가 실제로 삭제됐거나, 중요 정보가 제거돼 현재 내용이 크게 달라졌습니다.
  • Google 검색 결과에 이전 정보가 남아 있습니다.

이 도구가 적합하지 않은 경우

  • 원본 페이지에 개인정보가 지금도 그대로 남아 있습니다.
  • 내용이 마음에 들지 않거나 사실과 다르다는 이유만으로 검색에서 없애고 싶습니다.
  • 본인이 Search Console에서 관리하는 웹사이트의 페이지입니다.
  • 현재 공개 중인 URL을 무조건 영구 삭제하고 싶습니다.

중요: 오래된 콘텐츠 새로고침은 모든 종류의 검색 결과 삭제 요청을 대신하는 기능이 아닙니다. 원본이 변하지 않았다면 이 도구의 사용 목적에 맞지 않습니다.

11. 오래된 콘텐츠 새로고침 요청 절차

  1. 검색 결과에 나타나는 오래된 페이지의 실제 URL을 기록합니다.
  2. 해당 URL을 직접 열어 변경·삭제된 사실을 확인합니다.
  3. Google의 오래된 콘텐츠 새로고침 공식 안내 페이지를 엽니다.
  4. 도움말에서 **도구 열기(Open the Refresh Outdated Content tool)**를 선택합니다.
  5. Google 계정에 로그인합니다.
  6. 요구되는 형식으로 페이지 또는 이미지 URL을 입력합니다.
  7. 페이지가 현재도 존재한다면, 요청 화면이 요구하는 경우 검색 설명에는 있지만 원본에서 삭제된 짧은 단어를 입력합니다.
  8. 요청을 제출하고 처리 상태를 확인합니다.

Google은 원본 페이지가 삭제된 경우 검색에서 해당 결과를 제거할 수 있고, 페이지가 살아 있지만 중요한 내용이 수정된 경우에는 검색 결과 설명을 갱신하는 방식으로 처리할 수 있다고 안내합니다.

처리 후에도 링크가 남는 이유

페이지가 여전히 공개돼 있고 내용만 일부 변경됐다면 검색에서 그 URL이 계속 나타날 수 있습니다. 이때는 오래된 검색 설명을 없애는 것과 URL 자체를 완전히 없애는 것의 차이를 이해해야 합니다.

주의: 원본이 삭제됐다는 사실을 확인하지 않고 실제 게시물 내용을 바꾸거나 검색 결과를 허위로 신고하지 마세요.

12. Google에서 개인정보 삭제가 승인되면 어떻게 바뀌나요?

삭제 요청이 승인됐다고 모든 경우에 동일한 결과가 나오는 것은 아닙니다. Google은 정책과 페이지 성격에 따라 완전 삭제 또는 일부 검색어에 대한 부분 삭제가 가능하다고 설명합니다.

승인 후 결과실제 의미주의할 점
완전 삭제해당 URL이 Google 검색 결과에서 더 이상 표시되지 않음원본 사이트와 다른 검색엔진에는 남을 수 있음
부분 삭제신고자의 이름·식별자 등이 포함된 검색어에서 결과 제한다른 검색어에서는 URL이 나타날 수 있음
오래된 콘텐츠 새로고침삭제된 페이지 또는 바뀐 검색 설명을 최신화살아 있는 URL은 계속 검색될 수 있음
거부 또는 미승인Google 정책에 따른 요청이 받아들여지지 않음원본 삭제·다른 정책 경로 검토 가능

승인 이메일을 보관하세요

Google은 ‘나와 관련된 검색결과’에서 삭제 요청의 상태를 확인할 수 있고, 검토 결과를 이메일로 알려 줄 수 있다고 설명합니다. 날짜·요청 URL·결과를 기록하면 반복 요청을 정리하기 쉽습니다.

승인 직후 결과가 계속 보인다면

승인된 요청이 검색 결과에 반영되기까지 약간의 차이가 있을 수 있습니다. 동일한 URL인지, 다른 주소의 복제 게시물인지 확인하고 Google의 상태 화면을 다시 살펴보세요.

13. 삭제가 거부될 수 있는 이유: 공익성과 게시 주체

Google은 개인 연락처 정보가 포함됐더라도 일부 게시물이 공개 가치가 있는 정보라면 삭제를 거부할 수 있다고 설명합니다.

예를 들어 정부기관, 교육기관, 언론매체, 기업 웹사이트 등 공공 정보가 포함된 페이지에서 특정 결과 삭제가 제한될 수 있습니다. 해당 사이트의 모든 글이 자동으로 예외라는 뜻은 아니지만, 단순히 본인의 전화번호가 포함됐다는 이유만으로 무조건 승인된다고 볼 수는 없습니다.

거절됐을 때 확인할 것

  1. Google이 제공한 거절 사유를 확인합니다.
  2. 신청한 개인정보 유형과 원본 URL이 정확했는지 점검합니다.
  3. 정책에 해당하는 민감 정보가 실제로 포함되는지 확인합니다.
  4. 원본 사이트 운영자에게 삭제를 요청할 수 있는지 검토합니다.
  5. 별도의 법적 근거가 있다면 Google의 법적 삭제 요청 안내를 검토합니다.

중요: 거절 사유를 이해하지 못한 채 같은 URL을 수십 번 반복 제출하는 것보다, 정책상 조건과 현재 원본의 공개 상태를 다시 확인하는 편이 효율적입니다.

공식 출처: Google — 개인정보 삭제 정책 및 공익성 예외

14. 이름만 검색되거나 부정적인 글이 나오는 경우는 다릅니다

검색 결과에 본인 이름이 있다는 사실만으로 개인 연락처·신분증·금융정보 삭제 정책에 해당하는 것은 아닙니다.

예를 들어 이름만 적힌 게시물, 개인에 대한 비판 글, 오래된 댓글, 동명이인 관련 내용은 신청자가 원하는 대로 Google이 반드시 삭제해야 하는 콘텐츠가 아닙니다. 공개된 내용이 사실과 다르거나 명예를 훼손한다고 생각하는 경우에는 사안에 따라 원본 운영자 신고, 플랫폼 권리침해 절차, 법률적 대응이 필요할 수 있습니다.

Google은 정책에 따른 개인정보 삭제 요청과 해당 지역의 법률을 근거로 하는 법적 삭제 요청을 구분합니다.

무엇을 먼저 판단할까요?

  • 실제로 비공개 개인정보가 포함됐나요?
  • 원본 웹사이트에서 이미 수정·삭제됐나요?
  • 게시물이 법률이나 플랫폼 정책을 위반한다고 판단할 구체적 근거가 있나요?
  • 다른 사람의 합법적인 공개 정보와 관련된 내용인가요?

법적 판단에는 구체적 사실관계가 중요합니다. 이 글의 검색 결과 삭제 절차를 모든 명예훼손·사생활 침해 문제에 적용할 수 있는 법률 자문으로 이해하면 안 됩니다.

15. 무단 게시된 사진은 이미지 검색과 원본 사이트를 모두 확인

본인이 원치 않는 사진이 Google 이미지 검색에 나타난다면 원본 게시물이 어디에 있는지 먼저 찾아야 합니다.

Google은 이미지 검색의 대부분의 이미지가 Google이 소유하지 않는 외부 사이트에서 가져온 것이므로, 일반적인 경우 원본 웹사이트의 소유자에게 사진 삭제를 요청하도록 안내합니다.

일반 사진 삭제 절차

  1. Google 이미지 검색에서 해당 이미지를 엽니다.
  2. 이미지를 게시한 원본 사이트를 확인합니다.
  3. 자신이 업로드한 소셜미디어 게시물이라면 원래 플랫폼에서 사진을 삭제합니다.
  4. 다른 사람이 올린 사진이라면 해당 플랫폼의 신고·삭제 절차를 확인합니다.
  5. 원본 이미지가 제거됐는데도 Google에 남아 있다면 오래된 이미지 새로고침을 요청합니다.

민감한 이미지라면

Google은 일부 비동의 사적인 성적 이미지와 인공적으로 생성된 민감한 이미지 등에 대해 별도 신고 절차를 안내합니다. 이런 종류의 이미지에 해당한다면 일반적인 ‘이미지 삭제’ 문의보다 관련 정책을 우선 확인해야 합니다.

주의: 미성년자의 성적 학대 이미지 등 불법적인 자료를 신고 과정에서 임의로 복사하거나 다른 사람에게 전송하지 마세요. Google의 공식 정책은 이러한 유형의 불법 이미지를 일반 신고 양식에 첨부하지 말고 적절한 별도 신고 절차를 이용하도록 안내합니다.

16. 내가 운영하는 사이트라면 Search Console 절차가 따로 있습니다

다른 사람의 웹사이트에서 내 정보를 삭제하는 것과 내가 관리하는 블로그의 글을 직접 지우는 것은 구분해야 합니다.

Google은 사이트 소유자가 검색 결과에서 페이지를 신속하게 숨기고 싶을 때 **Search Console의 삭제 도구(Removals tool)**를 사용할 수 있다고 안내합니다. 하지만 이것만으로 원본 콘텐츠가 영구 삭제되는 것은 아닙니다.

사이트 소유자의 기본 순서

  1. 문제가 있는 원본 페이지에서 개인정보를 삭제하거나 페이지 자체를 삭제합니다.
  2. 사이트에 다른 URL로 같은 정보가 남아 있는지 확인합니다.
  3. Search Console에서 사이트 소유권이 확인됐는지 확인합니다.
  4. 필요한 경우 검색 결과에서 신속하게 숨기는 삭제 도구를 사용합니다.
  5. 영구적인 제거에는 실제 페이지 변경과 적절한 색인 처리 방법을 적용합니다.
  6. 추후 Google 검색에서 문제가 해결됐는지 확인합니다.

robots.txt 차단만 하면 충분한가요?

Google의 사이트 운영자 문서는 페이지를 검색에서 영구 제거하려면 원본 콘텐츠를 삭제하거나 적절한 색인 방지 설정 등 공식 방법을 적용해야 한다고 안내합니다. 크롤링 차단만으로 이미 검색에 알려진 URL이 반드시 즉시 사라지는 것은 아닙니다.

주의: 본인이 운영하지 않는 페이지에 대해 사이트 소유자용 Search Console 도구를 사용할 수는 없습니다. 이때는 개인정보 정책 삭제 요청이나 오래된 콘텐츠 새로고침을 이용해야 합니다.

17. 다른 검색엔진과 SNS에도 같은 정보가 남아 있다면

Google에서 결과가 제거되더라도 다른 검색엔진, 커뮤니티, 메신저에 공유된 원본 링크가 자동으로 삭제되는 것은 아닙니다. Google의 자체 도움말도 다른 검색엔진 또는 소셜미디어 공유를 통해 원본이 여전히 발견될 수 있다고 설명합니다.

별도로 확인할 범위

  • 국내외 다른 검색엔진에 같은 URL이 나오는지
  • 원본 사이트 게시물이 실제로 비공개 또는 삭제됐는지
  • 같은 사진이 다른 URL에 재게시돼 있는지
  • 소셜미디어의 공개 게시물과 프로필에 연락처가 남아 있는지
  • 본인이 직접 관리하는 계정에서 공개 범위를 변경할 수 있는지

다른 사람의 개인정보를 수집·노출하는 목적으로 이 점검을 사용하지 마세요. 자신의 공개 정보가 노출된 범위를 확인하고 안전하게 삭제 요청하기 위한 절차입니다.

동일 내용이 여러 URL에 복사된 경우 각 게시물을 하나의 원본이라고 생각하지 말고 URL별로 확인·요청·처리 결과를 관리해야 합니다.

20. 자주 묻는 질문

Q. 구글 검색에서 내 전화번호를 지워 달라고 요청할 수 있나요?

Google은 개인 전화번호·집주소·이메일 등이 표시된 검색 결과에 대해 ‘나와 관련된 검색결과’ 또는 상세 삭제 요청 양식을 제공하고 있습니다. 서비스 제공 조건과 실제 페이지의 공개 맥락에 따라 심사 결과는 달라질 수 있습니다.

Q. Google에서 삭제해 주면 원본 사이트에서도 삭제되나요?

아닙니다. Google이 통제하는 것은 Google 검색 결과입니다. 원본 게시물을 삭제하려면 웹사이트 소유자 또는 플랫폼 운영자에게 따로 요청해야 합니다.

Q. 원본을 삭제했는데 Google에서 여전히 예전 제목이 검색됩니다.

원본이 실제로 사라졌거나 중요한 부분이 바뀌었다면 Google의 오래된 콘텐츠 새로고침 도구를 검토하세요. 원본이 여전히 살아 있고 내용도 그대로라면 해당 도구의 대상이 아닙니다.

Q. 내 주민등록번호나 신분증 사진도 삭제 요청할 수 있나요?

Google은 비공개 정부 발급 신분 정보와 신분증 사진 등을 비공개 정보 삭제 요청 대상으로 안내합니다. 공식 양식에 실제 노출 URL을 제공하고 정책 심사를 받아야 합니다.

Q. 사진이 Google 이미지 검색에 떠요. 어떻게 없애나요?

가능하다면 원본 사진이 있는 사이트에서 삭제를 요청하세요. 원본을 지웠는데도 검색에 남았다면 이미지에 대한 오래된 콘텐츠 새로고침을 이용할 수 있습니다. 민감한 이미지에는 별도 Google 정책이 적용될 수 있습니다.

Q. ‘나와 관련된 검색결과’ 메뉴가 제 계정에는 없습니다.

Google은 일부 기능을 특정 시장에서 만 18세 이상에게 순차적으로 제공한다고 안내합니다. 메뉴가 없으면 상세 개인정보 삭제 요청 양식이 사용 가능한지 확인하세요.

Q. Google이 삭제 요청을 거절하면 다시는 지울 수 없나요?

원본 삭제 요청, 다른 정책의 적용 여부, 특정한 법적 근거를 살펴볼 수 있습니다. 다만 Google이 공개 가치가 있는 정보라고 판단한 경우에는 같은 사유로 반복 신청해도 승인되지 않을 수 있습니다.

Q. Google에서 ‘부분 삭제’했다고 하는데 여전히 다른 검색어로 나타납니다.

Google은 신청자의 이름이나 식별자가 포함된 검색어에 한해 부분 삭제를 적용할 수 있다고 안내합니다. 정책상 부분 삭제가 승인된 경우 다른 검색어에서는 URL이 보일 수 있습니다.

Q. 제가 운영하는 사이트에 실수로 올린 전화번호를 지우려면?

먼저 원본 페이지에서 정보를 삭제하고, Search Console에 사이트 소유권이 있다면 공식 삭제 도구·색인 관리 방법을 사용하세요. 검색에서 숨기기만 하는 조치와 웹사이트에서 완전히 제거하는 작업은 다릅니다.

Q. 신청 상태는 어디에서 확인하나요?

‘나와 관련된 검색결과’ 기능에서는 삭제 요청(Removal requests) 화면과 이메일을 통해 신청 상태를 확인할 수 있습니다. 상세 양식과 오래된 콘텐츠 새로고침 도구는 각 신청 경로에서 제공하는 안내를 확인해야 합니다.

Q. 한 번 삭제되면 다른 검색엔진에서도 사라지나요?

아닙니다. Google의 조치는 다른 검색엔진이나 원본 사이트, SNS에 남아 있는 복사본을 자동으로 제거하지 않습니다. URL과 게시 위치별로 별도의 조치가 필요할 수 있습니다.
