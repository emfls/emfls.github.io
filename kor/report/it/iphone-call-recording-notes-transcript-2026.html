2. 아이폰 통화 녹음하는 방법: 전화 중 5단계

Apple의 iPhone 사용 설명서에 따른 조작 순서입니다.

  1. 전화 앱을 실행하고 녹음하려는 상대방에게 전화를 겁니다.
  2. 통화가 연결된 뒤 화면에서 더 보기(…) 버튼을 누릅니다.
  3. 통화 녹음을 선택합니다.
  4. 녹음이 시작되면 통화 양쪽에 녹음 안내 음성이 재생됩니다.
  5. 녹음을 마치려면 중단 버튼을 누르거나 통화를 종료합니다.

녹음 시작 전에 다른 통화 참여자의 동의 여부를 확인하라고 Apple은 안내합니다. 녹음 알림이 들린다는 사실만으로 녹음 파일을 외부에 공유해도 된다는 뜻은 아닙니다.

실전 확인: 처음 사용한다면 개인적인 테스트 통화를 진행할 때 상대방에게 미리 녹음 사실을 알리고, 종료 후 메모 앱에서 녹음 파일이 재생되는지 확인하세요. 통화 중 중요한 일을 하고 있다면 버튼을 찾느라 주의를 분산시키지 않도록 안전한 환경에서 조작합니다.

3. ‘상대방에게 통화가 녹음됩니다’라는 안내음을 끌 수 있나요?

Apple의 기본 통화 녹음은 상대방에게 녹음 사실을 알리는 방식입니다. 공식 설명서에 따르면 녹음을 시작하면 통화에 참여한 두 사람 모두에게 녹음 중이라는 음성 안내가 들립니다. Apple의 개인정보 보호 문서에는 통화 중 안내가 주기적으로 재생될 수 있다고도 설명합니다.

따라서 **‘상대방 안내음 없이 아이폰 기본 기능으로 몰래 녹음하기’**를 표준 설정으로 안내하는 글은 신뢰하기 어렵습니다. Apple 공식 설명서에는 기본 통화 녹음의 알림음을 제거하는 일반 설정을 안내하지 않습니다.

또한 다음 세 가지는 구분해야 합니다.

  • 녹음 기능 자체 끄기: 내 아이폰에서 기본 녹음 기능 사용을 제한하는 설정입니다.
  • 상대방이 녹음하는 것 막기: 내 기기에서 기능을 꺼도 상대방이 지원 장치·앱으로 녹음하는 것까지 막을 수는 없습니다.
  • 녹음 자료 외부 공개: 녹음 가능 여부와 별개로 개인정보·초상·음성·통신비밀 및 민사상 권리 침해 문제가 생길 수 있으므로 공개·배포 전 별도 검토가 필요합니다.

녹음 관련 법률은 실제 대화 참여 여부와 이용 목적, 녹음 자료의 처리 방식 등에 따라 판단이 달라집니다. 이 글은 특정 녹음·공개의 위법성을 일률적으로 판정하는 법률 자문이 아닙니다.

공식 근거: Apple 개인정보 보호 — iPhone에서 통화 녹음 및 전사문 생성하기.

4. 녹음된 통화 파일은 어디에 저장되나요?

많은 사용자가 음성 메모, 파일 앱의 다운로드, 사진 앱의 화면 기록에서 찾지만 기본 통화 녹음의 저장 위치는 다릅니다.

  1. 아이폰의 메모(Notes) 앱을 엽니다.
  2. 폴더 목록에서 통화 녹음 폴더를 찾습니다.
  3. 해당 녹음이 있는 메모를 선택합니다.
  4. 메모 안의 오디오 재생 버튼을 눌러 내용을 확인합니다.
  5. 전사문을 지원하는 경우 전사문 버튼 또는 관련 보기 옵션을 확인합니다.

Apple은 녹음을 시작한 사람의 메모 앱에 결과가 자동 저장된다고 명시합니다. 녹음 버튼을 누른 쪽이 아닌 상대방 아이폰에 자동으로 같은 파일이 저장되는 것은 아닙니다.

폴더가 보이지 않을 때: 메모 앱에서 폴더 목록으로 돌아와 다른 계정 폴더를 보고 있지 않은지 확인하고, 메모 앱을 업데이트하거나 검색 기능으로 관련 메모를 찾아보세요. 그래도 없다면 먼저 녹음을 시작한 기기에서 확인해야 합니다.

5. 통화 녹음 파일을 공유하거나 별도 보관하려면?

Apple의 통화 녹음 개인정보 보호 설명서는 메모 앱에서 녹음 및 전사문 관련 더 보기 메뉴를 통해 저장·공유·삭제 옵션을 제공할 수 있다고 설명합니다. 메뉴가 보이지 않는 경우 지원 iOS 버전과 해당 메모의 항목을 확인하세요.

중요한 통화의 내용을 장기 보존하려면 다음을 권장합니다.

  1. 메모 앱에서 저장된 녹음이 정상적으로 재생되는지 확인합니다.
  2. 필요하다면 화면의 공유 또는 오디오 저장 관련 옵션을 살펴봅니다.
  3. 파일을 내보낸 경우 실제 파일이 재생되는지 확인합니다.
  4. 업무 기록이나 계약 관련 통화라면 회사 보안정책과 개인정보 보호 규칙에 따라 보관합니다.
  5. 상대방의 전화번호·이름·민감한 상담 내용이 포함된 파일은 공개 공유 링크로 배포하지 않습니다.

‘파일 앱에 무조건 자동 저장된다’는 설명은 부정확합니다. 기본 자동 저장 위치는 메모 앱이며, 다른 위치로 옮기는 경우 사용자가 별도 조작하는 것입니다.

6. 통화 녹음은 되는데 전사문이 안 보이는 이유

녹음, 전사, AI 요약은 서로 다른 기능입니다.

Apple 공식 기능 지원 목록에는 한국어 전화 통화 녹음과 한국어(대한민국) 통화 전사문이 포함돼 있습니다. 하지만 사용자의 언어 설정·소프트웨어·기능 제공 조건이 맞지 않으면 전사문이 나타나지 않을 수 있습니다.

전사문이 보이더라도 자동 생성된 텍스트는 대화를 완벽하게 재현하지 않을 수 있습니다. 사람 이름·주소·금액·계좌정보·계약 조건은 반드시 실제 녹음 원본을 다시 듣고 대조하세요.

공식 근거: Apple — 전화: 통화 녹음 및 통화 전사문 지원 언어, Apple — 통화 녹음의 전사문과 원본 확인.

7. iPhone 13·14·15도 가능할까요? Apple Intelligence와 혼동하지 마세요

통화 녹음 기능은 iOS 18.1의 전화 앱 기능으로 소개됐습니다. 반면 통화 내용 AI 요약은 Apple Intelligence가 있어야 하며, 지원되는 아이폰 모델과 언어·지역 조건이 따로 적용됩니다.

따라서 ‘Apple Intelligence를 지원하는 최신 Pro 모델이 아니면 통화 자체를 녹음할 수 없다’는 설명은 기능을 혼동한 것입니다.

다만 모든 구형 아이폰에 무조건 같은 메뉴가 뜬다고 단정할 수도 없습니다. 실제 지원 여부는 다음 조건을 함께 확인해야 합니다.

  • 기기에 설치된 iOS 버전
  • 기기 모델의 해당 iOS 지원 여부
  • 전화 앱의 통화 녹음 설정
  • 사용 중인 국가·지역과 언어
  • 실제 전화 유형과 기능 제공 범위

Apple Intelligence가 아닌 기본 통화 녹음만 필요하다면 먼저 Apple이 안내하는 녹음 기능 지원 요건부터 확인하세요.

8. 통화 녹음 버튼이 없을 때 점검 순서

아이폰에서 ‘더 보기’나 ‘통화 녹음’이 표시되지 않으면 다음 순서대로 확인하세요.

① 통화가 실제 연결된 상태인지 확인

통화 화면에서 기능을 찾습니다. 단순히 연락처를 열어 둔 상태와 실제 통화 중 화면은 다릅니다.

② iOS 버전 확인

설정 → 일반 → 정보에서 설치된 iOS 버전을 확인하고, 필요하면 설정 → 일반 → 소프트웨어 업데이트에서 공식 업데이트 가능 여부를 확인합니다. Apple은 통화 녹음 기능을 iOS 18.1 업데이트의 일부로 소개했습니다.

③ 통화 녹음 설정 확인

Apple 공식 안내의 메뉴는 설정 → 앱 → 전화 → 오디오 통화 녹음입니다. 해당 옵션이 비활성화돼 있으면 기본 녹음 기능이 나타나지 않을 수 있습니다. 설정 위치는 iOS 버전에 따라 달라질 수 있습니다.

④ 국가·지역 지원 여부 확인

Apple 공식 기능 지원 여부 목록과 통화 녹음 설명서를 함께 확인하세요. 특정 국가·지역에서는 기능이 지원되지 않습니다. 한국어 지원 여부와 모든 국가에서의 사용 가능 여부는 별개입니다.

⑤ 일반 전화·FaceTime·외부 통화 앱을 구별

전화 앱에 제공되는 통화 녹음 기능을 카카오톡 보이스톡, WhatsApp 등 모든 타사 통화 앱에 그대로 적용할 수 있다고 생각하지 마세요. FaceTime 음성 통화에서도 일부 관련 기능이 안내되지만, 통화 유형과 지원 조건을 따로 확인해야 합니다.

⑥ 회사 지급 기기라면 관리 정책 확인

회사나 학교에서 관리하는 기기는 조직 보안 정책에 따른 제한이 적용될 수 있으므로 담당 관리자에게 문의하세요. 실제 제한 여부를 기기 없이 확정할 수는 없습니다.

9. 통화 녹음 기능을 아예 끄는 방법

녹음 버튼을 사용하지 않거나 실수로 누르지 않도록 하려면 Apple의 안내에 따라 다음 경로를 검토하세요.

  1. 설정 앱을 엽니다.
  2. 앱 → 전화를 탭합니다.
  3. 오디오 통화 녹음을 선택합니다.
  4. 오디오 통화 녹음을 끕니다.

Apple은 통화 녹음 기능이 기본적으로 켜진 상태일 수 있으며 사용자가 끌 수 있다고 설명합니다.

주의: 자신의 아이폰에서 녹음을 비활성화한다고 해서 타인이 다른 장치나 타사 앱으로 자신의 통화를 녹음하는 것을 기술적으로 차단하는 것은 아닙니다. 개인정보 침해가 우려된다면 통화 상대에게 녹음 여부를 확인하고 중요한 정보를 공유하지 않는 등 별도의 대응이 필요합니다.

10. 삭제 전에 확인할 것: 녹음 파일을 지우면 전사문도 사라집니다

Apple은 녹음된 오디오를 삭제하면 해당 전사문도 삭제된다고 안내합니다.

삭제 전에는 다음을 확인하세요.

  • 녹음 파일에 계약·상담·민원 처리 등 중요한 증빙이 포함되어 있나요?
  • 필요한 내용이 별도 파일로 보존되어 있나요?
  • 내보낸 파일을 실제로 재생해 봤나요?
  • 전사문만 복사해 둔 것은 아닌가요?
  • 다른 사람에게 공유된 자료가 있다면 접근권한을 관리했나요?

전사문이 편리하더라도 중요한 기록은 원본 오디오와 함께 검토하는 편이 좋습니다. 자동 전사는 이름이나 금액을 잘못 적을 수 있기 때문입니다.

11. 아이폰 통화 녹음 관련 자주 묻는 질문

Q1. 아이폰 통화 녹음은 유료 앱을 설치해야 하나요?

A. 지원되는 iOS·국가·지역이라면 Apple 기본 전화 앱에서 통화 녹음 기능을 이용할 수 있습니다. 별도 타사 앱을 설치하는 것이 필수는 아닙니다.

Q2. 통화 녹음을 시작하면 상대방도 알게 되나요?

A. 네. Apple 기본 통화 녹음은 양쪽 참여자에게 녹음 중이라는 음성 알림을 제공합니다. 알림 제거를 일반 설정으로 안내하지 않습니다.

Q3. 아이폰 녹음 파일은 ‘음성 메모’에 있나요?

A. 아닙니다. Apple 기본 전화 통화 녹음의 자동 저장 위치는 메모 앱의 통화 녹음 폴더입니다.

Q4. 모든 통화를 자동으로 녹음할 수 있나요?

A. Apple이 공식 안내하는 기본 방식은 통화 중 사용자가 ‘통화 녹음’을 선택해 녹음을 시작하는 절차입니다. 갤럭시의 자동 통화녹음 설정과 동일하게 설명하면 안 됩니다.

Q5. 전사문이 안 뜨는데 녹음 파일이 없어지는 건가요?

A. 전사 지원 여부와 오디오 저장은 별개의 기능입니다. 먼저 메모 앱에서 오디오 녹음이 존재하고 재생되는지 확인한 뒤 전사문 지원 언어·설정을 점검하세요.

Q6. 한국어로 통화했는데 글자가 잘못 나왔습니다.

A. 자동 전사 결과는 원본 음성을 정확하게 재현하지 않을 수 있습니다. 특히 고유명사, 숫자, 계약 조건 등은 녹음을 다시 들어 확인하세요.

Q7. 통화 녹음과 Apple Intelligence 요약은 같은 건가요?

A. 아닙니다. 녹음은 오디오 파일을 만드는 기능, 전사는 말한 내용을 문자로 바꾸는 기능, 요약은 AI가 내용을 줄여 보여주는 기능입니다. 지원 기기·언어·지역·설정이 다릅니다.

Q8. 녹음 중단 버튼을 누르지 않고 통화를 끊으면 어떻게 되나요?

A. Apple은 녹음 중단 버튼을 누르거나 통화를 종료하면 녹음이 중단된다고 안내합니다. 이후 메모 앱에서 결과를 확인하세요.

Q9. 제가 녹음한 파일을 SNS에 공개해도 되나요?

A. 녹음 가능 여부와 공개·공유의 적법성은 다른 문제입니다. 개인정보 및 관련 법령, 상대방의 권리 등을 검토해야 합니다. 공개 전에 관련자의 동의나 적절한 법률 상담을 고려하세요.

Q10. 상대방이 녹음한 내용을 내 아이폰에서도 볼 수 있나요?

A. 기본 기능으로 저장된 녹음은 녹음을 시작한 사람의 메모 앱에 저장됩니다. 상대방 기기에 파일이 자동으로 복제된다는 의미는 아닙니다.

12. 중요한 통화를 녹음하기 전 1분 체크리스트

  • ☐ 내 아이폰의 iOS가 통화 녹음을 지원하는지 확인했다.
  • ☐ 사용할 통화 유형과 국가·지역 지원 여부를 확인했다.
  • ☐ 상대방에게 녹음할 계획을 알리고 동의를 확인했다.
  • ☐ 통화 중 더 보기 → 통화 녹음 메뉴를 확인했다.
  • ☐ 상대방에게 안내 음성이 들릴 수 있다는 점을 이해했다.
  • ☐ 녹음 후 메모 앱의 통화 녹음 폴더에서 재생해 봤다.
  • ☐ 중요한 통화는 원본 오디오를 안전하게 보관했다.
  • ☐ AI 전사문에 오류가 있을 수 있어 필요한 대목을 직접 확인했다.

결론

아이폰 통화 녹음은 전화 앱의 통화 화면에서 더 보기 → 통화 녹음을 선택하는 방식이며, 결과는 메모 앱 → 통화 녹음 폴더에 자동 저장됩니다. 상대방에게 녹음 안내가 재생되고, 전사문과 Apple Intelligence 요약은 각각 별도의 지원 조건이 있습니다.

버튼이 보이지 않는다면 먼저 iOS 버전, 국가·지역, 통화 유형, 설정 → 앱 → 전화 → 오디오 통화 녹음을 순서대로 확인하세요. 녹음이 완료됐어도 자동 전사문은 틀릴 수 있으므로 중요한 정보는 원본과 대조하는 것이 안전합니다.
