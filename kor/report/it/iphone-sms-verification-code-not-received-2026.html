은행, 쇼핑몰, 간편결제 또는 회원가입 사이트에서 문자 인증번호를 요청했는데 아이폰에 문자가 오지 않는 경우가 있습니다. 인증번호를 여러 번 재전송해도 메시지 목록에 아무것도 보이지 않거나, 잠금화면 알림만 오지 않아 실제로 문자는 도착해 있는데도 '미수신'으로 생각하기 쉽습니다.

아이폰에서 인증번호 문자 문제를 해결하려면 먼저 세 가지를 구분해야 합니다. ① 문자가 도착했지만 스팸함·알 수 없는 발신자 폴더에 숨어 있는 경우, ② 문자는 왔지만 알림만 꺼진 경우, ③ SMS 자체가 통신망·회선·발송 서비스 문제로 도착하지 않은 경우입니다. 이 세 경우는 해결 방법이 서로 다릅니다.

특히 Apple은 iOS 26에서 메시지 스팸 필터링이 기본으로 켜져 있으며, 분류된 메시지는 알림 없이 스팸 폴더에 들어갈 수 있다고 안내합니다. 반면 알 수 없는 발신자 스크리닝은 기본적으로 꺼져 있지만, 예전 iOS에서 필터링 설정을 켰다면 업그레이드 뒤 켜져 있을 수 있습니다. 두 기능을 같은 것으로 설명하면 원인을 놓치기 쉽습니다.

이 글은 2026년 11월 4일 현재 Apple 공식 지원자료를 바탕으로 아이폰 인증문자 미수신을 5분 안에 분류하는 방법, iOS 26의 스팸·알 수 없는 발신자 확인, 듀얼 SIM·eSIM 회선 점검, Apple 계정 확인 코드와 쇼핑몰 SMS 인증의 차이, 통신사에 문의해야 할 시점을 정리했습니다.

2. 가장 먼저 '메시지 앱 → 스팸' 폴더를 확인하세요

iOS 26의 메시지 앱은 일부 문자를 스팸으로 자동 분류합니다. Apple에 따르면 스팸으로 분류된 메시지는 별도 폴더에 표시되고 알림은 제공되지 않습니다. 따라서 인증번호를 요청한 서비스의 메시지가 잘못 분류됐다면 받은 편지함과 잠금화면에는 표시되지 않을 수 있습니다.

iOS 26에서 스팸함 확인 방법

  1. 아이폰에서 메시지 앱을 엽니다.
  2. 대화 목록의 필터 버튼을 누릅니다.
  3. 스팸 폴더를 선택합니다.
  4. 인증번호를 요청한 시간대에 들어온 메시지가 있는지 확인합니다.
  5. 실제로 본인이 요청한 인증 메시지인지 발신자와 문맥을 확인합니다.
  6. 정상 문자임이 확실하다면 해당 메시지를 열고 스팸 아님을 선택합니다.
  7. 받은 편지함으로 이동 또는 받은 편지함으로 이동 및 스팸 아님으로 보고를 선택합니다.
  8. 일반 대화 목록에 다시 표시되는지 확인합니다.

주의: 스팸함의 메시지가 모두 정상인 것은 아닙니다. 모르는 번호에서 온 링크는 함부로 누르지 말고, 실제로 본인이 요청한 인증번호의 발신처·시각을 먼저 확인하세요.

Apple의 공식 설명은 이 기능이 iOS 26에서 기본적으로 켜져 있다고 명시합니다. 따라서 사용자가 필터를 직접 켠 기억이 없더라도 스팸 폴더를 확인할 필요가 있습니다.

공식 출처: Apple — iPhone에서 스팸 메시지 확인 및 복구하기.

3. '알 수 없는 발신자' 폴더는 스팸함과 다릅니다

스팸 필터링과 알 수 없는 발신자 스크리닝은 같은 기능이 아닙니다.

Apple은 iOS 26에서 알 수 없는 발신자 스크리닝은 기본적으로 꺼져 있다고 안내합니다. 다만 iOS 18에서 알 수 없는 발신자 필터링을 켜고 사용했다면 iOS 26으로 업데이트할 때 스크리닝이 활성화될 수 있습니다.

알 수 없는 발신자 확인

  1. 아이폰의 메시지 앱을 엽니다.
  2. 필터 버튼을 누릅니다.
  3. 알 수 없는 발신자를 선택합니다.
  4. 인증번호를 요청한 시간대에 도착한 문자가 있는지 확인합니다.
  5. 정상적인 발신자라면 대화를 열어 알고 있음으로 표시할 수 있습니다.
  6. 그러면 해당 발신자의 대화가 일반 목록에 표시될 수 있습니다.

필터 상태를 확인하거나 변경하려면

  1. 메시지 앱에서 필터 → 필터링 관리로 이동합니다.
  2. 알 수 없는 발신자 스크리닝이 켜져 있는지 확인합니다.
  3. 또는 설정 → 앱 → 메시지 → 알 수 없는 발신자에서 관련 옵션을 확인합니다.
  4. 인증번호를 계속 놓친다면 알림 허용의 메시지 유형을 살펴봅니다.
  5. 긴급한 확인 코드 관련 알림이 제공된다면 필요한 범위를 허용할 수 있습니다.

지역별 제한: Apple은 알 수 없는 발신자의 알림 유형을 조절하는 세부 옵션이 국가·지역에 따라 다를 수 있다고 안내합니다. '긴급·개인·거래·프로모션' 선택지가 모든 한국 사용자에게 반드시 똑같이 보인다고 단정하지 마세요.

공식 출처: Apple — 알 수 없는 발신자의 메시지 보기, Apple — iPhone에서 문자 메시지 스크리닝·필터링하기.

4. 문자는 들어왔는데 알림만 안 뜨는 경우

메시지 앱에서 인증번호를 직접 찾을 수 있다면 일단 SMS가 수신된 것입니다. 이 경우는 문자 수신 불량이 아니라 알림 표시 문제일 수 있습니다.

메시지 알림 확인

  1. 설정 앱을 엽니다.
  2. 앱 → 메시지 → 알림으로 이동합니다.
  3. 알림 허용을 확인합니다.
  4. 잠금화면·알림 센터·배너 등 원하는 알림 표시 위치를 확인합니다.
  5. 알림음·무음 상태를 점검합니다.
  6. 해당 대화를 열고 발신자 이름을 선택해 알림 가리기가 켜져 있는지 확인합니다.

Apple은 메시지 앱이 열려 있고 활성화된 상태에서는 메시지마다 알림을 따로 받지 않을 수 있다고 설명합니다. 또한 Apple Watch가 연결돼 있으면 알림이 iPhone이 아닌 Apple Watch로 전달될 수 있습니다.

핵심: 알림을 못 받았다는 이유만으로 인증문자가 발송되지 않았다고 단정하지 말고, 메시지 앱 안에 실제 대화가 들어와 있는지 확인하세요.

공식 출처: Apple — iPhone 또는 iPad에서 메시지 알림을 받지 못하는 경우.

5. 차단한 번호에서 인증번호가 오는 경우

인증번호를 보내는 발신자를 이전에 차단된 연락처로 추가했다면 메시지가 정상 전달되지 않을 수 있습니다.

iOS 26에서 차단 목록 확인

  1. 설정을 엽니다.
  2. 개인정보 보호 및 보안 → 차단된 연락처를 선택합니다.
  3. 실제로 인증번호를 보내는 번호가 차단돼 있는지 확인합니다.
  4. 차단 해제할 필요가 있고 발신자 신원이 확인됐다면 편집 → 차단 해제를 선택합니다.
  5. 인증번호 발송 서비스로 돌아가 새 코드를 요청합니다.

Apple은 연락처나 전화번호를 차단하면 해당 번호에서 보낸 메시지가 전달되지 않는다고 설명합니다. 단, 실제 서비스에서 사용하는 발신 번호는 바뀔 수 있으므로 모르는 번호를 무작정 차단 해제하거나 신뢰할 수 있는 번호라고 가정하지 마세요.

공식 출처: Apple — 전화번호·연락처 차단 및 관리.

6. 문자 인증번호가 실제로 전혀 오지 않는다면: SMS와 iMessage를 구분

아이폰 메시지 앱에 보이는 모든 메시지는 같은 방식으로 전송되는 것이 아닙니다.

SMS이동통신사 문자망전화번호·활성 회선·통신사 서비스 상태가 중요
MMS이동통신사 멀티미디어 메시지 서비스통신사 지원·연결 상태에 따라 다름
RCS통신사 지원과 네트워크 기반 메시지지원 통신사·OS·상대 기기 조건에 따라 다름

Apple은 SMS 메시지를 보내려면 셀룰러 네트워크 연결이 필요하고, Wi-Fi 통화가 켜져 있다면 Wi-Fi를 통해 SMS를 보낼 수도 있다고 설명합니다. 반면 iMessage는 Wi-Fi 또는 셀룰러 데이터 연결을 사용합니다.

'와이파이가 되니까 인증문자도 반드시 와야 한다'는 설명은 정확하지 않습니다. 문자 인증 서비스가 SMS를 보내는 경우에는 사용 중인 이동통신사의 SMS 서비스와 회선 상태가 중요합니다.

실제로 확인할 것

  1. 상태 막대에서 이동통신사 신호와 회선 상태를 확인합니다.
  2. 설정 → 셀룰러에서 사용 중인 전화 회선이 켜져 있는지 확인합니다.
  3. 일반 SMS도 들어오지 않는지 확인합니다.
  4. 메시지가 전혀 오지 않는다면 이동통신사에 SMS 수신 가능 상태를 문의합니다.
  5. iMessage가 잘 된다는 사실만으로 SMS 수신 상태가 정상이라고 판단하지 않습니다.

공식 출처: Apple — 메시지 송수신 오류, Apple — iMessage·RCS·SMS/MMS 차이.

7. 새 아이폰·eSIM·듀얼 SIM으로 바꾼 뒤 문자 인증이 안 될 때

기기 변경이나 번호 이동 뒤에 문제가 시작됐다면 실제로 SMS를 수신할 전화번호가 켜져 있는지 확인하는 편이 좋습니다.

점검 순서

  1. 설정 → 셀룰러를 엽니다.
  2. 이용 중인 회선이 실제로 활성화돼 있는지 확인합니다.
  3. SIM을 두 개 사용하는 경우 인증받을 전화번호의 회선이 켜져 있는지 확인합니다.
  4. 이동통신사·알뜰폰 회선 개통이 완료됐는지 확인합니다.
  5. 기존 번호와 새 번호 중 서비스에 등록된 전화번호가 어느 쪽인지 확인합니다.
  6. 필요하다면 이동통신사에 문자 수신 가능 여부를 문의합니다.

Apple은 새 기기를 설정한 뒤 메시지 문제가 생기면 설정 → 셀룰러에서 사용하려는 전화 회선을 확인하도록 안내합니다.

주의: 전화번호에 문제가 있다고 판단하고 SIM·eSIM을 무작정 삭제하지 마세요. eSIM 재발급·재활성화는 통신사 절차가 필요할 수 있습니다. 실제 회선 상태를 확인하기 전에는 기존 서비스를 해제하지 않는 것이 안전합니다.

공식 출처: Apple — 새 기기 설정 후 메시지 문제.

8. Apple 계정의 '6자리 확인 코드'만 안 오는 경우

Apple 계정 로그인용 이중 인증 확인 코드는 일반 쇼핑몰 SMS 인증번호와 경로가 다를 수 있습니다.

Apple 공식 지원에 따르면 Apple 계정 확인 코드는 신뢰하는 기기에 팝업으로 나타나거나, 신뢰하는 전화번호로 문자·전화 통화를 통해 받을 수 있습니다.

신뢰하는 기기가 있다면

  1. 다른 기기에서 Apple 계정으로 로그인합니다.
  2. 기존의 신뢰하는 iPhone·iPad·Mac·Apple Watch에 로그인 확인 알림이 나타나는지 확인합니다.
  3. 본인 로그인 시도라면 허용을 선택합니다.
  4. 표시된 코드를 새 기기에 입력합니다.

신뢰하는 기기가 없다면

  1. 로그인 화면에서 코드를 받지 못했습니까? 또는 기기에 접근할 수 없습니까?를 선택합니다.
  2. 신뢰하는 전화번호로 코드를 보내도록 선택합니다.
  3. 문자 메시지 외에 전화 통화로 받는 방법이 제공되는지 확인합니다.
  4. 알 수 없는 발신자 폴더에 해당 코드가 있는지 확인합니다.
  5. 등록된 번호 자체를 이용할 수 없다면 Apple의 계정 복구 안내를 따릅니다.

절대 다른 사람에게 인증번호를 알려주지 마세요. 본인이 시작하지 않은 로그인 시도에 대응할 때는 허용을 누르지 않는 것이 중요합니다.

공식 출처: Apple — 이중 인증 확인 코드 받기, Apple — 피싱과 사칭 예방.

9. 한 사이트에서만 인증번호가 안 올 때

네이버·쇼핑몰·은행 등 특정 서비스의 코드만 오지 않고 다른 SMS는 정상 수신된다면, 아이폰 전체 문자 기능의 장애인지부터 다시 생각해 볼 필요가 있습니다.

이런 점을 확인하세요

  • 해당 서비스에 입력한 휴대전화 번호가 정확한지
  • 이전에 등록한 번호와 현재 사용하는 번호가 다르지 않은지
  • 서비스의 인증 코드 발송 화면에서 오류·횟수 제한이 있는지
  • 요청한 코드가 문자(SMS)로 전송되는 것인지, 앱 알림·이메일 인증 방식인지
  • 해당 서비스의 발송 시스템에 일시적 지연·장애 공지가 있는지
  • 메시지 앱의 스팸·알 수 없는 발신자에 도착한 문자가 있는지

일반 문자와 다른 기관의 인증번호가 모두 정상이라면 특정 서비스의 발신·번호 등록·인증 요청 문제를 먼저 문의하는 편이 효율적입니다.

같은 인증번호를 짧은 시간에 계속 재전송하지 마세요. 일부 서비스는 재전송 제한이나 이전 코드 무효화 정책을 적용할 수 있습니다. 다만 제한 시간과 횟수는 서비스마다 달라 일률적인 수치를 제시할 수 없습니다.

10. 인증번호가 왔는데 '유효하지 않음'이라고 뜨는 경우

이 증상은 문자 미수신 문제가 아니라 인증 처리 실패입니다.

먼저 확인할 항목

  1. 가장 최근에 요청한 새로운 인증번호를 사용하고 있는지
  2. 인증번호의 유효시간이 지나지 않았는지
  3. 여러 번 발급한 경우 이전에 받은 코드를 사용하지 않았는지
  4. 다른 서비스·다른 로그인 화면의 코드를 잘못 복사하지 않았는지
  5. 코드 자동 완성이 표시한 값이 현재 요청한 서비스의 코드인지
  6. 서비스가 추가로 요구하는 계정·전화번호 입력과 일치하는지

예: 인증번호를 여러 번 요청한 뒤 처음에 도착한 번호를 입력하면 서비스 정책에 따라 거절될 수 있습니다. 마지막 요청 시각의 문자를 기준으로 확인하고, 정해진 재요청 제한을 준수하세요.

11. 알림이 뜨지 않았지만 인증번호가 이미 도착한 경우

아이폰의 메시지 알림은 메시지 앱 내부의 수신 내역과 별도입니다. 특히 iOS 26에서는 스팸으로 분류된 문자에 대해 알림을 표시하지 않는 기본 정책이 있습니다.

3가지 위치를 순서대로 확인

  1. 일반 대화 목록 — 실제 문자 수신 여부
  2. 필터 → 스팸 — 스팸으로 잘못 분류됐는지
  3. 필터 → 알 수 없는 발신자 — 별도 폴더에 이동했는지

그다음 설정 → 앱 → 메시지 → 알림과 해당 대화의 알림 가리기를 확인하세요.

Apple Watch가 연결된 경우에는 메시지 알림이 Watch에 표시되고 iPhone에는 따로 표시되지 않을 수 있습니다. 아이폰 잠금화면 알림이 없었다는 사실만으로 문자가 도착하지 않았다고 판단하지 마세요.

공식 출처: Apple — 메시지 알림을 받지 못하는 경우.

12. 삭제된 인증문자도 찾을 수 있나요?

문자가 수신됐지만 나중에 지워졌다면 메시지 앱의 최근 삭제된 항목을 확인할 수 있습니다.

확인 순서

  1. 메시지 앱을 엽니다.
  2. 대화 목록의 필터 버튼을 누릅니다.
  3. 최근 삭제된 항목을 선택합니다.
  4. 복구할 메시지가 포함된 대화를 선택합니다.
  5. 복구 → 메시지 복구를 선택합니다.

Apple은 iOS 16 이상에서 삭제된 메시지를 일정 기간 복구할 수 있다고 설명합니다. iOS 26 최신 사용 설명서에는 최대 30일의 복구 가능 기간이 안내되며, 공식 지원 문서에는 최근 30~40일이라는 범위로 표현된 자료도 있습니다. 복구 가능한 실제 메시지와 표시 기간은 기기 화면을 기준으로 확인하세요.

그러나 인증번호는 대개 제한된 시간에만 유효하므로 오래된 인증문자를 복구했다고 실제 로그인에 재사용할 수 있는 것은 아닙니다.

공식 출처: Apple — 삭제된 문자 메시지 복구하기, Apple — iPhone 메시지에서 삭제된 항목 복구.

13. iMessage를 껐다 켜면 인증문자가 해결되나요?

반드시 그렇지는 않습니다. Apple은 iMessage 활성화에 문제가 있을 때 관련 설정을 점검하도록 안내하지만, 대부분의 휴대전화 본인인증 SMS는 이동통신사의 문자 서비스와 관련됩니다.

문제무엇이 관련되나요?
Apple 기기끼리 파란 말풍선 iMessage 불가인터넷 연결·iMessage 활성화·계정 및 전화번호 설정
녹색 말풍선 SMS 수신 불가이동통신사 서비스·전화 회선·셀룰러 연결
인증문자만 안 보임스팸 폴더·알 수 없는 발신자·특정 서비스 발송
Apple 계정 로그인 확인 코드 불가신뢰하는 기기·전화번호·계정 복구

따라서 SMS 인증 문제를 해결하겠다고 iMessage를 반복해서 껐다 켜는 것을 첫 단계로 권하지 않습니다. Apple은 iMessage 활성화 중 전화번호 인증이 진행되는 경우 반복적으로 끄고 켤 필요가 없다고 명시하기도 합니다.

공식 출처: Apple — iMessage 활성화가 안 되는 경우, Apple — 메시지 송수신.

14. 알뜰폰·통신사에 문의해야 하는 경우

스팸·알 수 없는 발신자 폴더에 문자도 없고, 다른 일반 SMS까지 들어오지 않는다면 사용 중인 통신사에 수신 상태를 확인해야 합니다.

Apple은 SMS·MMS·RCS 메시지를 계속 송수신할 수 없다면 이동통신사에 문의하도록 공식적으로 안내합니다.

상담 전에 준비할 정보

  • 사용 중인 통신사 또는 알뜰폰 사업자
  • 아이폰 모델 및 현재 iOS 버전
  • 현재 번호가 일반 SIM인지 eSIM인지, 듀얼 SIM인지
  • 문자 수신 문제가 시작된 날짜·시각
  • 일반 SMS도 안 오는지, 특정 발신자·인증번호만 안 오는지
  • 메시지 앱의 스팸·알 수 없는 발신자 폴더 확인 결과
  • 기기 변경·번호이동·SIM 교체 등의 최근 이력

통신사에 물어볼 질문

"아이폰에서 휴대전화 본인인증 문자가 오지 않습니다. 메시지 앱의 스팸·알 수 없는 발신자 폴더도 확인했고, 일반 SMS 수신 여부는 ○○입니다. 현재 회선에서 SMS 수신이 정상적으로 가능한 상태인지와 차단·제한·개통 처리 여부를 확인해 주세요."

통신사별 정확한 차단·수신 제한 정책과 해제 방식은 다를 수 있으므로 일괄적인 고객센터 경로나 처리시간을 단정하지 않습니다.

공식 출처: Apple — 문자 메시지 송수신 문제에서 이동통신사 확인.

15. 인증번호를 받을 때 반드시 지켜야 할 보안 원칙

문자가 안 온다고 해서 모르는 사람이 안내하는 '대신 인증받기' 사이트에 들어가거나, 본인 확인 코드를 다른 사람에게 알려주면 계정 탈취 피해로 이어질 수 있습니다.

Apple은 피싱·사칭 방지 공식 문서에서 로그인 암호·이중 인증 코드·기기 암호를 타인에게 제공하지 말라고 경고합니다.

확인할 내용

  • 직접 로그인하거나 구매하지 않았는데 갑자기 인증번호가 왔다면 링크를 누르지 않기
  • 은행·회사 고객센터를 사칭해 인증번호를 불러 달라는 요청을 거부
  • 문자에 포함된 링크를 통해 로그인하기보다 공식 앱을 직접 열기
  • 보낸 번호가 익숙해도 발신 번호 위조 가능성을 고려
  • 알 수 없는 인증 요청이 반복된다면 해당 서비스에서 계정 보안·로그인 이력 확인

본인이 요청한 인증번호라도 다른 사람에게 전달하지 마세요. 정상적인 고객센터가 비밀번호나 인증번호 공유를 요구한다고 가정하지 않는 것이 안전합니다.

공식 출처: Apple — 피싱과 사칭 사기 예방.

17. 자주 묻는 질문(FAQ)

Q1. 아이폰 인증번호 문자만 안 오는 이유는 무엇인가요?

스팸·알 수 없는 발신자 자동 분류, 차단된 연락처, 특정 서비스의 등록 전화번호·발송 문제 또는 이동통신사의 SMS 수신 문제 등 원인이 다릅니다. 문자 자체가 도착했는지부터 확인하세요.

Q2. iOS 26에서는 문자 스팸함이 기본으로 켜져 있나요?

네. Apple에 따르면 메시지 스팸 필터링은 기본적으로 켜져 있으며, 스팸으로 분류된 메시지는 알림 없이 스팸 폴더에 들어갑니다.

Q3. 아이폰 스팸 문자함은 어디에 있나요?

메시지 앱 → 필터 → 스팸입니다. 실제로 요청한 인증문자가 있다면 정상 문자임을 확인한 뒤 스팸 아님으로 이동할 수 있습니다.

Q4. 알 수 없는 발신자 필터도 기본으로 켜져 있나요?

Apple은 iOS 26의 알 수 없는 발신자 스크리닝은 기본적으로 꺼져 있다고 안내합니다. 다만 이전 iOS에서 필터 기능을 켰다면 업그레이드 후에도 켜져 있을 수 있습니다.

Q5. 문자 알림은 안 오지만 메시지 앱에는 인증번호가 있습니다.

SMS 수신은 된 상태입니다. 설정 → 앱 → 메시지 → 알림, 대화별 알림 가리기, Apple Watch 알림 경로를 확인하세요.

Q6. Wi-Fi가 잘 되는데도 인증문자가 안 올 수 있나요?

그럴 수 있습니다. iMessage는 인터넷 기반, SMS는 이동통신사의 문자 서비스입니다. 사용하는 전화 회선과 셀룰러 연결·통신사 서비스를 확인하세요.

Q7. 새 아이폰·eSIM으로 바꾼 뒤 인증번호가 안 옵니다.

설정 → 셀룰러에서 사용하려는 전화번호의 회선이 켜져 있는지 확인하고, 번호이동·개통 완료 여부를 통신사에 문의하세요. 무작정 eSIM을 삭제하지 마세요.

Q8. Apple 계정 확인 코드만 안 옵니다.

Apple은 신뢰하는 기기의 알림, 코드를 받지 못했습니까?, 신뢰하는 전화번호로 문자 또는 전화 통화 등의 수단을 제공합니다.

Q9. 통신사에 바로 연락해야 하나요?

메시지 앱의 스팸·알 수 없는 발신자 폴더와 회선 상태를 먼저 확인하세요. 일반 SMS도 수신되지 않거나 SMS 수신 장애가 지속되면 통신사 문의가 적절합니다.

Q10. 인증번호를 여러 번 요청해도 괜찮나요?

서비스별로 재전송 제한·기존 코드 무효화 정책이 있을 수 있습니다. 요청한 서비스의 안내를 따르고 새 코드를 받았다면 가장 최근의 코드를 사용하세요.

Q11. 실수로 지운 인증문자를 복구할 수 있나요?

Apple은 메시지 앱의 최근 삭제된 항목에서 일정 기간 메시지 복구를 지원합니다. 다만 복구한 이전 인증번호가 유효기간 내라는 보장은 없습니다.

Q12. 인증번호를 고객센터 직원에게 알려줘도 되나요?

다른 사람에게 인증번호를 알려주지 마세요. Apple은 사칭·피싱을 예방하기 위해 비밀번호·보안코드 공유를 금지하도록 권고합니다. 본인이 직접 공식 로그인 화면에 입력해야 합니다.

18. 최종 10분 체크리스트

  • ☐ 메시지 앱의 일반 대화 목록에서 인증문자를 찾아봤다.
  • ☐ 필터 → 스팸을 확인했다.
  • ☐ 필터 → 알 수 없는 발신자를 확인했다.
  • ☐ 스팸 필터링과 알 수 없는 발신자 스크리닝이 별도 기능임을 구분했다.
  • ☐ 메시지 알림·대화 음소거·Apple Watch 알림을 확인했다.
  • ☐ 차단한 발신자 번호가 있는지 확인했다.
  • ☐ 설정 → 셀룰러에서 인증받을 회선이 켜져 있는지 확인했다.
  • ☐ 일반 SMS도 안 오는지, 특정 서비스 인증번호만 안 오는지 비교했다.
  • ☐ Apple 계정 인증이라면 신뢰하는 기기·전화 통화 옵션을 확인했다.
  • ☐ 등록 휴대전화 번호와 최신 인증 요청 시각을 확인했다.
  • ☐ 재전송 제한을 무시하고 연속 요청하지 않았다.
  • ☐ 일반 SMS 수신 장애가 지속되면 통신사에 문의할 정보를 정리했다.
  • ☐ 인증번호를 다른 사람에게 알려주지 않았다.

정리하면, 아이폰 문자 인증번호가 안 보일 때 가장 먼저 확인할 곳은 메시지 앱의 '스팸'과 '알 수 없는 발신자' 폴더입니다. iOS 26의 기본 스팸 필터는 일부 문자를 알림 없이 별도 폴더에 보낼 수 있습니다. 해당 폴더에도 없고 일반 SMS까지 수신되지 않는다면 전화 회선·SIM/eSIM 활성화·이동통신사 문자 서비스를 확인하세요. Apple 계정의 6자리 로그인 코드는 신뢰하는 기기·문자·전화라는 별도 수신 경로를 갖습니다.
