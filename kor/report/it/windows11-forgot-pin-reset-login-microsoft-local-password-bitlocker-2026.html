노트북을 켰는데 평소 입력하던 네 자리 PIN이 갑자기 기억나지 않나요? Windows 11 로그인 화면에서 'PIN을 사용할 수 없습니다'라고 표시되거나 'PIN을 잊어버렸습니다' 버튼이 보이지 않아 컴퓨터를 초기화해야 하는지 걱정될 수도 있습니다.

Windows Hello PIN과 Microsoft 계정 비밀번호는 서로 다릅니다. PIN을 잊어버렸다고 해서 Microsoft 계정의 비밀번호까지 바꿔야 하는 것은 아닙니다. 또한 Microsoft 계정으로 로그인하는 PC와 로컬 계정으로 로그인하는 PC는 복구 절차가 달라 같은 방법을 무조건 적용하면 안 됩니다.

이 글은 2026년 10월 25일 기준 Microsoft 공식 고객지원 문서를 바탕으로 로그인 화면에서 PIN을 다시 만드는 방법, 'PIN을 잊어버렸습니다'가 없을 때 비밀번호로 로그인하는 방법, Microsoft 계정 암호 재설정, 로컬 계정 보안 질문, Windows Hello 오류, BitLocker 복구 키까지 단계별로 설명합니다.

1. Windows Hello PIN과 Microsoft 계정 비밀번호의 차이

Windows Hello PIN은 PC에 로그인할 때 사용하는 인증 수단입니다. Windows 11은 PIN 외에도 얼굴 인식·지문 인식·비밀번호 등을 지원할 수 있습니다.

PIN은 Windows 로그인 수단입니다

일반적으로 PIN은 해당 장치에 연결되는 로그인 방법입니다. PC 로그인 화면에서 설정했더라도 Outlook.com·OneDrive 등에 로그인할 때 사용하는 Microsoft 계정 비밀번호와 동일한 정보가 아닙니다.

Microsoft 계정 비밀번호는 계정 자체의 인증 정보입니다

Outlook.com·OneDrive·Microsoft 계정 웹사이트 등에 사용하는 비밀번호입니다. 같은 Microsoft 계정을 여러 Windows 기기에서 사용해도 각 PC의 Windows Hello PIN은 별도로 설정할 수 있습니다.

로컬 계정 비밀번호는 또 다릅니다

Windows 로컬 계정은 특정 컴퓨터에만 적용되는 계정입니다. Microsoft 공식 안내에 따르면 로컬 계정은 인터넷 연결 없이 로그인할 수 있고, 온라인 Microsoft 계정의 암호 복구와는 다른 방법을 사용합니다.

따라서 로그인 화면에서 먼저 '내 계정이 Microsoft 계정인지 로컬 계정인지' 파악하는 것이 중요합니다. 계정 종류를 모르겠다면 로그인 화면에 이메일 주소가 표시되는지 확인하고, 이전에 해당 PC에서 Outlook 또는 Microsoft 계정으로 Windows에 로그인했는지 떠올려 보세요. 이메일이 보인다는 사실 하나만으로 계정 유형을 확정할 수는 없습니다.

2. 로그인 화면에서 PIN을 잊어버렸을 때 재설정하기

Windows 11에 아직 로그인하지 못했다면 로그인 화면의 'PIN을 잊어버렸습니다' 또는 유사한 재설정 항목을 먼저 확인하세요.

Microsoft 계정 사용자 기준 순서

  1. Windows 11 로그인 화면에서 내 사용자 계정을 선택합니다.
  2. PIN 입력란 아래에 'PIN을 잊어버렸습니다' 또는 PIN 재설정 관련 링크가 있는지 확인합니다.
  3. 해당 링크를 선택합니다.
  4. Microsoft 계정 로그인과 본인 확인 절차를 수행합니다.
  5. 휴대전화·이메일 등 화면에 제공되는 인증 방법을 선택합니다.
  6. 인증에 성공하면 화면 안내에 따라 새 PIN을 설정합니다.
  7. 새 PIN으로 Windows 로그인을 다시 시도합니다.

Microsoft 공식 문서에 따르면 로그인 화면의 'PIN을 잊어버렸습니다' 재설정 옵션은 로컬 계정이 아닌 Microsoft 계정에만 제공됩니다.

이 버튼이 안 보이면 어떻게 하나요?

버튼이 보이지 않는다면 먼저 로그인 옵션 → 비밀번호를 통해 로그인할 수 있는지 확인하세요. 비밀번호로 로그인한 뒤 Windows 설정에서 PIN을 다시 만들 수 있습니다.

주의: 인터넷 연결 또는 계정 확인에 필요한 인증 수단이 없으면 온라인 재설정이 진행되지 않을 수 있습니다. 신뢰할 수 있는 인터넷에 연결돼 있는지 확인하고, 본인 인증이 막힌 경우에는 공식 Microsoft 계정 복구 절차를 이용하세요.

3. 'PIN을 잊어버렸습니다'가 없으면 비밀번호로 로그인하세요

로그인 화면에 PIN 재설정 링크가 없다면 비밀번호가 기억나는지부터 확인하는 것이 좋습니다.

비밀번호 로그인으로 바꾸는 방법

  1. Windows 11 로그인 화면에서 대상 계정을 선택합니다.
  2. PIN 입력란 아래에 로그인 옵션이 있는지 확인합니다.
  3. 사용 가능한 로그인 방식 중 비밀번호 입력 아이콘을 선택합니다.
  4. 해당 Windows 계정의 비밀번호를 입력합니다.
  5. 로그인되면 설정 → 계정 → 로그인 옵션으로 이동합니다.
  6. PIN(Windows Hello) → PIN을 잊어버렸습니다를 선택해 재설정합니다.

로그인 방법이 여러 개 등록됐다면 얼굴 인식·지문 인식 등도 화면에 나타날 수 있습니다. 다만 해당 인증 방법이 실제로 설정돼 있고 기기가 지원해야 합니다.

비밀번호 아이콘도 보이지 않으면?

Microsoft는 이 장치에서 Microsoft 계정에 대한 Windows Hello 로그인만 허용 설정이 켜져 있으면 암호 기반 로그인이 사용되지 않을 수 있다고 안내합니다. 또한 조직 관리 정책이나 계정 설정에 따라 로그인 옵션이 다르게 표시될 수 있습니다.

따라서 비밀번호 로그인 아이콘이 안 보인다고 해서 비밀번호를 임의 우회할 수 있다는 뜻은 아닙니다. 공식 PIN 재설정·계정 확인 경로를 사용하거나 관리형 기기는 IT 담당자에게 문의하세요.

4. 로그인한 상태에서 PIN을 변경하거나 다시 설정하는 방법

Windows 11에 이미 로그인할 수 있다면 로그인 화면에서 작업할 필요 없이 설정 앱에서 Windows Hello PIN을 관리할 수 있습니다.

현재 PIN을 알고 있을 때 변경

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 계정 → 로그인 옵션으로 이동합니다.
  3. PIN(Windows Hello) 항목을 선택합니다.
  4. PIN 변경을 누릅니다.
  5. 현재 PIN과 새 PIN을 화면 안내에 따라 입력합니다.
  6. 저장 후 잠금 화면에서 새 PIN을 시험합니다.

Microsoft는 'PIN 변경'은 이전 PIN을 입력해야 하는 작업이라고 안내합니다. 기존 PIN을 기억하지 못한다면 변경 메뉴보다 아래의 **'PIN을 잊어버렸습니다'**를 이용해야 합니다.

Windows에 로그인은 되지만 현재 PIN이 기억나지 않을 때

  1. 설정 → 계정 → 로그인 옵션으로 이동합니다.
  2. **PIN(Windows Hello)**을 펼칩니다.
  3. PIN을 잊어버렸습니다를 선택합니다.
  4. 계정 본인 확인 화면이 표시되면 요구되는 인증을 진행합니다.
  5. 새로운 PIN을 만들고 확인합니다.
  6. 화면을 잠가 새 PIN으로 로그인되는지 확인합니다.

이 방식은 기존 계정 자체를 삭제하거나 파일을 제거하는 작업이 아닙니다. PIN을 다시 설정하기 위해 본인 확인이 필요할 수 있습니다.

설정 메뉴가 영어라면

한국어 **설정 → 계정 → 로그인 옵션 → PIN(Windows Hello)**은 영어 Windows에서 **Settings → Accounts → Sign-in options → PIN (Windows Hello)**에 해당합니다.

회사·학교가 관리하는 PC에서는 PIN 길이·복잡성·허용 여부가 조직 정책으로 제어될 수 있습니다.

5. Microsoft 계정 비밀번호까지 잊어버렸을 때 복구

PIN을 잊어버렸고 Windows 로그인에 사용할 Microsoft 계정 비밀번호도 기억나지 않는다면 PIN 재설정과 계정 비밀번호 재설정을 구분해야 합니다.

다른 기기에서 Microsoft 계정 비밀번호 재설정

  1. 본인이 신뢰하는 다른 스마트폰·PC에서 Microsoft 계정 암호 재설정 페이지를 엽니다.
  2. 로그인하려는 정확한 Microsoft 계정 이메일 주소를 입력합니다.
  3. 암호를 잊으셨나요? 또는 재설정 옵션을 선택합니다.
  4. 등록된 복구 이메일·휴대전화 등 가능한 본인 확인 방법을 선택합니다.
  5. Microsoft가 요구하는 확인 코드를 입력합니다.
  6. 새 계정 비밀번호를 설정합니다.
  7. Windows 로그인 화면으로 돌아가 비밀번호 또는 PIN 복구 경로를 다시 진행합니다.

직접 접속할 공식 사이트: Microsoft 계정, Microsoft 비밀번호 복구 공식 도움말

비밀번호를 바꿨는데 PIN까지 자동으로 바뀌나요?

자동으로 같은 번호가 되는 것은 아닙니다. PIN은 해당 장치의 Windows Hello 로그인 수단이고 Microsoft 계정 암호와 별개입니다. 비밀번호를 새로 설정한 뒤에도 필요하면 Windows에서 PIN 재설정 절차를 거쳐야 합니다.

계정을 잘못 선택하지 않도록 주의

컴퓨터에서 개인 Microsoft 계정과 회사·학교 계정이 모두 보이는 경우 로그인하려는 Windows 사용자 계정을 정확하게 확인하세요. 다른 계정의 비밀번호를 재설정하면 현재 PC에 로그인할 수 없는 상황은 그대로 남을 수 있습니다.

주의: 계정 복구를 대행해 준다는 광고·메신저 연락처로 비밀번호와 인증번호를 보내지 마세요. Microsoft는 고객지원 담당자가 계정 보안 절차를 우회해 임의로 계정 암호를 재설정해 줄 수 없다고 설명합니다.

공식 출처: Microsoft - Microsoft 계정 비밀번호를 잊은 경우, Microsoft - Windows의 계정 암호 재설정

6. Microsoft 인증번호가 안 오거나 복구 이메일을 못 쓸 때

Microsoft 계정 복구 도중 문자 인증번호가 오지 않거나 예전 이메일 주소가 표시될 수 있습니다.

먼저 확인할 항목

  1. 입력한 Microsoft 계정 이메일 주소가 맞는지 살펴봅니다.
  2. 등록한 복구 이메일 주소에 실제로 접속할 수 있는지 확인합니다.
  3. 이메일 스팸함·차단 목록에 Microsoft 확인 메일이 있는지 확인합니다.
  4. 문자 인증을 선택했다면 휴대전화 번호·국가번호·수신 상태를 점검합니다.
  5. 다른 등록 인증 수단이 있다면 Microsoft가 제공하는 옵션을 확인합니다.
  6. 사용할 수 있는 인증 수단이 없다면 공식 계정 복구 안내를 이용합니다.

복구 정보가 오래돼 더 이상 접근할 수 없다면 임의로 다른 사람의 번호나 이메일을 입력하지 마세요. Microsoft의 본인 확인 절차를 통과해야 계정 정보가 변경됩니다.

인증 메일이 늦게 오면

반복적으로 인증번호를 요청하기 전에 현재 화면에 표시된 유효시간과 재전송 제한을 확인하세요. 서비스 화면의 안내에 맞지 않는 오래된 코드를 여러 번 입력하면 정상 복구가 지연될 수 있습니다.

비밀번호가 아니라 Windows PIN만 문제라면?

이메일·계정 접근이 정상인 상황에서는 Windows PIN 재설정만 수행하는 편이 더 간단할 수 있습니다. 계정 전체 비밀번호를 변경하기 전에 현재 문제가 PIN인지 계정 로그인인지 확인하세요.

공식 출처: Microsoft - Windows 로그인 문제 해결, Microsoft - 계정 암호 복구 절차

7. 로컬 계정 PIN을 잊었을 때: Microsoft 계정과 다른 복구 절차

Windows를 Microsoft 계정이 아닌 로컬 계정으로 사용한다면 로그인 화면에서 'PIN을 잊어버렸습니다'가 제공되지 않을 수 있습니다. Microsoft 공식 문서는 이 PIN 재설정 링크가 Microsoft 계정에만 적용된다고 명시합니다.

로컬 계정 비밀번호를 알고 있다면

  1. Windows 로그인 화면에서 로그인 옵션을 찾습니다.
  2. 비밀번호로 로그인하는 방식을 선택합니다.
  3. 로컬 계정의 비밀번호를 입력합니다.
  4. Windows에 로그인합니다.
  5. **설정 → 계정 → 로그인 옵션 → PIN(Windows Hello)**을 엽니다.
  6. 제공되는 PIN 변경·재설정 절차를 확인합니다.

로컬 계정 비밀번호까지 잊었다면

Microsoft 공식 도움말은 로그인 화면에서 암호 입력 → 확인 → 암호 재설정 → 계정 생성 당시 설정한 보안 질문에 답하기를 안내합니다.

  1. 로그인 화면에서 비밀번호 입력 옵션을 선택합니다.
  2. 필요한 경우 비밀번호 입력 뒤 암호 재설정 항목이 나타나는지 확인합니다.
  3. 설정해 둔 보안 질문에 답변합니다.
  4. 확인에 성공하면 새 로컬 계정 비밀번호를 설정합니다.
  5. 변경된 비밀번호로 로그인한 뒤 PIN을 설정합니다.

단, 보안 질문을 사전에 등록하지 않았거나 계정 정책상 사용할 수 없는 경우에는 이 방법이 제공되지 않을 수 있습니다.

암호 재설정 디스크가 있는 경우

예전에 해당 로컬 계정으로 **암호 재설정 디스크(USB)**를 만들어 두었다면 로그인 화면의 해당 옵션을 사용할 수 있습니다. 지금 잠겨 있는 PC에서 디스크를 새로 만들 수 있다고 생각해서는 안 됩니다. 미리 만들어 둔 경우를 위한 복구 수단입니다.

공식 출처: Microsoft - 로컬 계정 비밀번호 재설정, Microsoft - 로컬 계정 암호 재설정 디스크

8. 'PIN을 사용할 수 없습니다' 오류가 나타날 때 해결 순서

PIN을 정확히 기억하는데도 'PIN을 사용할 수 없습니다', '보안 설정이 변경되어 PIN을 사용할 수 없습니다' 등의 문구가 나타나는 상황은 단순히 번호를 잊은 경우와 다를 수 있습니다.

Microsoft는 Windows Hello PIN 오류가 보안 업데이트 또는 시스템 변경 이후 발생할 수 있다고 설명합니다. 이런 경우 새로운 PIN을 만들도록 안내될 수 있습니다.

우선 해결 순서

  1. 오류 메시지의 전체 문구와 코드를 확인합니다.
  2. 인터넷 연결 상태와 로그인하려는 계정을 확인합니다.
  3. PIN 설정 또는 PIN 재설정 버튼이 있다면 정식 본인 확인 절차를 진행합니다.
  4. 로그인 옵션 → 비밀번호가 제공된다면 비밀번호로 로그인합니다.
  5. Windows에 접속했다면 **설정 → 계정 → 로그인 옵션 → PIN(Windows Hello)**에서 재설정합니다.
  6. Windows 업데이트에 재시작이 필요한 항목이 있는지 확인합니다.
  7. 동일 오류가 반복된다면 Microsoft Windows Hello 문제 해결 도움말을 확인합니다.

PIN 설정에 실패한다면?

Microsoft는 PIN을 새로 만드는 도중 오류가 발생하면 로그아웃했다가 다시 로그인한 후 PIN을 다시 만들어 보는 방법을 안내합니다. 다만 현재 아예 로그인할 수 없다면 이 방법은 사용할 수 없으므로 로그인 화면의 공식 PIN 재설정 경로 또는 다른 등록된 로그인 방법을 확인하세요.

Windows Hello 파일을 강제로 삭제해도 될까요?

인터넷에서 Ngc 폴더 소유권을 변경하거나 시스템 파일을 삭제하라는 방법이 검색될 수 있습니다. 이런 조치는 Microsoft의 일반 사용자용 첫 번째 복구 단계가 아니며, 보안 자격 증명과 로그인 상태에 영향을 줄 수 있습니다.

특히 디스크 암호화가 사용 중인 업무용·개인용 PC에서 관리되지 않은 조작을 시도하지 말고, 계정 확인·정식 PIN 재설정·관리자 지원을 우선하세요.

공식 출처: Microsoft - Windows Hello PIN 오류와 해결 팁, Microsoft - Windows 로그인 문제 해결

9. 지문·얼굴 인식은 되는데 PIN이 안 될 때

노트북에서 얼굴 인식이나 지문 인식이 가능하다면 로그인 수단을 변경해 정상 로그인 후 PIN을 재설정할 수도 있습니다.

다른 로그인 방법을 이용하기

  1. Windows 로그인 화면에서 로그인 옵션을 확인합니다.
  2. 사용 가능한 경우 지문 또는 얼굴 인식 아이콘을 선택합니다.
  3. 본인 인증을 완료해 Windows에 로그인합니다.
  4. **설정 → 계정 → 로그인 옵션 → PIN(Windows Hello)**을 엽니다.
  5. PIN을 잊어버렸습니다 또는 PIN 변경 옵션을 확인합니다.
  6. 화면의 계정 확인 과정을 거쳐 새 PIN을 설정합니다.

지문 인식이 갑자기 실패한다면

Microsoft는 지문 판독기를 깨끗하고 건조하게 유지하고, 가능하면 이전에 등록한 다른 손가락을 이용해 보는 방법을 안내합니다. 로그인에 성공한 뒤에는 **설정 → 계정 → 로그인 옵션 → 지문 인식(Windows Hello)**에서 지문을 다시 등록할 수 있습니다.

얼굴 인식에 실패한다면

카메라가 얼굴을 정확히 인식할 수 있는 환경인지 확인하고, 로그인 후 **얼굴 인식(Windows Hello)**의 인식 개선 또는 재설정을 검토하세요. 얼굴이나 지문 정보가 정상이라고 해도 PIN이 자동으로 복구되는 것은 아닙니다.

로그인 수단이 아예 없다면

지문·얼굴 인식이 등록돼 있지 않거나 장치에서 사용할 수 없다면 PIN 또는 비밀번호 복구 경로를 따라야 합니다. 인증을 생략하고 Windows에 들어가는 우회 프로그램을 사용하지 마세요.

10. 비밀번호 로그인 아이콘 자체가 사라진 이유

Windows 로그인 화면에 PIN만 나타나고 비밀번호 선택 아이콘이 보이지 않는 경우가 있습니다.

Microsoft는 Windows 11의 설정 → 계정 → 로그인 옵션 → 추가 설정에서 Microsoft 계정에 대해 이 장치에서 Windows Hello 로그인만 허용하도록 설정할 수 있다고 안내합니다.

이미 로그인할 수 있는 상태라면 확인

  1. 설정 → 계정 → 로그인 옵션을 엽니다.
  2. 아래로 내려가 추가 설정을 확인합니다.
  3. 이 장치에서 Microsoft 계정에 대한 Windows Hello 로그인만 허용 또는 유사한 설정이 있는지 살펴봅니다.
  4. 비밀번호 로그인 옵션이 필요한 상황이라면 설정을 변경할지 검토합니다.
  5. 로그아웃 전에 비밀번호 및 복구 수단을 실제로 알고 있는지 먼저 확인합니다.

이 설정은 Windows Hello를 이용해 암호 없이 장치를 사용할 수 있도록 해 보안을 강화하려는 목적도 있습니다. 비밀번호를 무조건 활성화해야 안전하다는 뜻은 아닙니다.

로그인이 안 되는 상태라면?

Windows 설정 화면 자체를 열 수 없다면 이 옵션을 직접 변경할 수 없습니다. PIN 재설정과 계정 복구의 공식 경로를 확인하고, 관리형 기기는 IT 담당자와 상담하세요.

관리형 기기에서 버튼이 비활성화돼 있다면

회사·학교 기기는 조직 정책으로 로그인 방법을 제어할 수 있습니다. 일반 사용자가 임의로 그룹 정책이나 레지스트리를 변경해 우회하도록 안내하는 것은 적절하지 않습니다.

11. 안전 모드로 들어가면 PIN 없이 로그인할 수 있나요?

Windows가 반복적으로 로그인 오류를 발생시킨다고 해서 안전 모드에 들어가면 아무 인증 없이 로그인할 수 있다고 생각해서는 안 됩니다.

Microsoft는 안전 모드에서 PIN과 생체 인식 로그인 옵션을 사용할 수 없고, Microsoft 계정이나 로컬 계정의 비밀번호가 필요하다고 명확하게 설명합니다.

안전 모드가 적합한 경우

  • 최근 설치한 장치 드라이버나 프로그램이 로그인 문제에 영향을 주는지 확인해야 할 때
  • Windows의 기본 장치·서비스 환경에서 문제를 구분해야 할 때
  • 실제로 비밀번호를 알고 있으며 문제 해결 목적으로 진입할 때

PIN도 비밀번호도 모른다면?

안전 모드로 바꾸는 것은 해결책이 아닙니다. 오히려 PIN 로그인 옵션이 없어져 접근하기 어려워질 수 있으므로 계정 복구나 PIN 재설정 경로를 우선하세요.

Microsoft가 안내하는 안전 모드 진입은 Shift를 누른 상태에서 전원 → 다시 시작해 복구 환경으로 들어가는 방식 등을 이용할 수 있지만, 초보자가 단순 PIN 분실 문제를 해결하려고 복구 환경을 반복 조작할 필요는 없습니다.

업무용 PC라면

안전 모드에서도 회사의 인증 설정이나 암호화가 영향을 줄 수 있습니다. IT 부서의 지원 없이 업무용 PC를 복구 모드로 변경하거나 정책을 무시하지 마세요.

공식 출처: Microsoft - Windows 로그인 장애와 안전 모드 제한

12. BitLocker 복구 키 48자리를 요구한다면 PIN 문제가 아닙니다

Windows 로그인 PIN을 입력하려고 했는데 파란 화면에 'BitLocker 복구' 또는 48자리 복구 키 입력 화면이 나타날 수 있습니다.

이 경우는 보통 Windows Hello PIN 분실과 별개의 디스크 암호화 복구 상황입니다. Microsoft는 BitLocker가 암호화된 드라이브를 자동으로 잠금 해제하지 못하면 48자리 숫자 복구 키가 필요하다고 설명합니다.

복구 키 찾는 공식 절차

  1. 화면에 표시된 복구 키 ID의 앞 8자리를 기록합니다.
  2. 다른 신뢰할 수 있는 기기의 브라우저에서 **Microsoft BitLocker 복구 키**로 접속합니다.
  3. 해당 PC의 디스크 암호화 키가 저장된 Microsoft 계정으로 로그인합니다.
  4. 여러 복구 키가 보이면 복구 키 ID로 대상 키를 구분합니다.
  5. 맞는 48자리 복구 키를 찾았다면 잠긴 PC의 복구 화면에 입력합니다.

회사·학교 PC의 복구 키

조직에서 관리하는 기기라면 복구 키가 회사·학교 계정에 저장돼 있거나 IT 관리자가 관리할 수 있습니다. Microsoft는 조직 계정의 복구 키 확인을 위한 회사·학교용 복구 키 경로도 제공합니다.

복구 키가 없으면 어떻게 되나요?

Microsoft는 지원 담당자도 분실된 BitLocker 복구 키를 검색·제공·새로 생성할 수 없다고 명시합니다. 키를 찾지 못해 드라이브에 접근할 수 없다면 초기화가 필요한 경우가 있고, 그 결과 저장된 파일이 제거될 수 있습니다.

위험한 실수: PIN을 되찾겠다며 TPM을 초기화하거나 펌웨어 설정을 함부로 변경하지 마세요. 암호화된 드라이브가 복구 키를 요구하게 되면 PIN과는 다른 문제가 생길 수 있습니다.

공식 출처: Microsoft - BitLocker 복구 키 찾기, Microsoft - 장치 암호화

PIN을 기억하지 못한다는 이유만으로 Windows 11 초기화를 먼저 실행하는 것은 권장하지 않습니다. Microsoft 계정 복구와 로컬 계정 보안 질문, 정상적인 로그인 옵션을 충분히 확인하는 것이 우선입니다.

'내 파일 유지'를 선택했다고 해서 모든 데이터와 모든 프로그램이 100% 유지된다는 보장은 없습니다. Microsoft도 초기화 전에 중요한 파일을 백업하도록 안내합니다.

초기화 전에 확인할 사항

  1. Microsoft 계정·로컬 계정 비밀번호 복구 방법을 다시 검토합니다.
  2. 파일 백업이 실제로 존재하고 열리는지 확인합니다.
  3. BitLocker가 활성화돼 있다면 복구 키를 확보합니다.
  4. 현재 사용하는 Office·업무 앱 등의 라이선스와 재설치 가능 여부를 확인합니다.
  5. 회사·학교의 관리형 기기라면 반드시 관리자에게 문의합니다.
  6. 초기화 선택지가 파일·앱·사용자 설정에 미치는 영향을 다시 읽습니다.

로그인할 수 없는 상태에서 초기화는 가능한가요?

Microsoft는 **Windows 복구 환경(Windows RE)**에서도 이 PC 초기화 기능을 제공한다고 설명합니다. 그러나 암호화된 기기는 BitLocker 복구 키가 필요할 수 있고, 사용자의 상황에 따라 재설치 후에도 원래 파일에 접근하지 못할 가능성이 있습니다.

따라서 로그인 문제만 해결하려면 공식 계정 복구 → PIN 재설정 → 필요 시 기술지원 순서를 먼저 따르는 편이 안전합니다.

14. 로컬 계정 사용자는 미리 암호 재설정 디스크 준비

지금 Windows 11에 정상 로그인되는 로컬 계정 사용자라면, 나중에 비밀번호를 잊어버렸을 때를 대비해 암호 재설정 디스크를 만들어 둘 수 있습니다.

USB 암호 재설정 디스크 만드는 방법

  1. 현재 로컬 계정으로 Windows에 로그인합니다.
  2. USB 저장장치를 PC에 연결합니다.
  3. 시작 메뉴에서 제어판을 검색해 실행합니다.
  4. 제어판 검색에서 암호 재설정 만들기를 입력합니다.
  5. 암호 재설정 디스크 만들기를 선택합니다.
  6. 표시되는 지침에 따라 USB 디스크를 설정합니다.
  7. 완료한 USB를 PC와 분리해 안전한 장소에 보관합니다.

Microsoft는 이 기능이 로컬 계정을 위한 수단이며 Microsoft 계정에는 적용되지 않는다고 설명합니다.

미리 만들지 않았다면?

로그인이 잠긴 상태에서 새 암호 재설정 디스크를 즉석에서 만들 수는 없습니다. 이미 준비한 디스크가 없다면 로컬 계정 보안 질문 및 공식 복구 경로를 검토하세요.

재설정 디스크 보안 관리

재설정용 USB는 해당 로컬 계정에 접근할 수 있는 복구 수단이므로 누구나 사용할 수 있는 곳에 두지 마세요. Microsoft는 비밀번호를 변경한 뒤에도 새 디스크를 만들 필요는 없다고 설명합니다.

15. 회사·학교 계정 PIN 오류라면 어떤 점이 다른가요?

업무용 Windows 11 컴퓨터나 학교에서 지급한 장치는 조직의 계정·보안 정책에 따라 Windows Hello 사용이 제한되거나 별도 인증이 요구될 수 있습니다.

우선 확인할 것

  • 로그인 중인 계정이 개인 Microsoft 계정인지 회사·학교 계정인지
  • PIN이 회사 보안 정책 때문에 재등록을 요구받는 상황인지
  • 장치에서 Microsoft Entra ID, 회사 보안 프로그램, 조직 VPN을 사용하는지
  • 해당 계정에 접근할 수 있는 다른 인증 수단이 남아 있는지
  • 장치가 BitLocker로 암호화돼 있고 복구 키를 조직이 보관하고 있는지

관리형 PC에서는 하지 말아야 할 일

PIN을 다시 사용하려고 조직 계정 연결 해제, TPM 초기화, 그룹 정책 변경, 레지스트리 우회, 무단 초기화를 시도하지 마세요. 이런 조치가 회사 보안 정책과 업무 데이터 접근에 영향을 줄 수 있습니다.

업무용 Windows Hello 문제는 회사·학교 IT 관리자에게 오류 화면, PC 모델, 업데이트 시점, 계정 유형을 전달해 처리하는 것이 적절합니다.

BitLocker 키도 회사 계정에 있을 수 있습니다

Microsoft는 조직이 관리하는 장치의 BitLocker 복구 키가 회사·학교 계정이나 IT 관리자에 저장될 수 있다고 안내합니다. 개인 Microsoft 계정 페이지에서 키가 없다고 해서 디스크 암호화가 해제된 것은 아닙니다.

16. PIN 재설정 후 다시 잠기지 않으려면 확인할 7가지

한 번 Windows 로그인 문제를 해결했다면 다음을 점검해 같은 문제에 대비할 수 있습니다.

① PIN과 비밀번호를 구분해 관리하세요

Windows Hello PIN은 PC 로그인에 사용하는 별도의 인증 수단입니다. PIN을 기억한다고 Microsoft 계정 암호를 알고 있는 것은 아닙니다. 공식 비밀번호 관리자 등을 이용해 계정 인증 정보를 안전하게 관리하세요.

② Microsoft 계정 복구 정보를 최신으로 유지하세요

등록된 복구 이메일·전화번호를 실제로 이용할 수 있는지 확인합니다. 오래된 번호나 접근할 수 없는 이메일만 있으면 PIN 재설정 때 계정 확인에 어려움을 겪을 수 있습니다.

③ 지문이나 얼굴 인식이 있다면 정상 작동을 점검하세요

지원되는 기기에서는 Windows Hello의 다른 로그인 방법을 함께 등록할 수 있습니다. 단, 다른 로그인 방식이 항상 PIN을 대체할 수 있다고 보장되는 것은 아니므로 비밀번호·복구 수단도 관리해야 합니다.

④ BitLocker 복구 키를 안전하게 보관하세요

다른 신뢰할 수 있는 기기에서 **복구 키 확인**으로 연결된 키가 있는지 검토하세요. 회사 기기는 IT 관리자와 확인합니다.

⑤ 백업은 Windows 로그인과 별개입니다

파일 백업을 했다면 정말 복원할 수 있는 사본인지 확인하세요. Windows 계정이 잠기는 것과 디스크가 고장 나는 것은 서로 다른 문제이고, 복구 키를 모르면 암호화된 저장장치에 접근하기 어려울 수 있습니다.

⑥ PIN을 다른 사람에게 알려주지 마세요

공용 PC가 아니라 개인 PC여도 PIN을 타인과 공유하지 않는 편이 좋습니다. PIN과 계정 비밀번호는 화면 공유·메신저·이메일로 전달하지 않는 것이 안전합니다.

⑦ Windows와 장치 펌웨어를 공식 경로로 업데이트하세요

Microsoft는 Windows Hello 문제가 업데이트나 시스템 변경으로 발생할 수 있다고 설명합니다. 운영체제를 업데이트할 때는 정상적인 재부팅·설치 안내를 따르고, 펌웨어 업데이트 전에는 BitLocker 복구 키 확보 및 제조사 지침 확인이 필요합니다.

자주 묻는 질문 FAQ

Q1. 윈도우11 PIN을 잊어버리면 컴퓨터를 초기화해야 하나요?

아닙니다. Microsoft 계정으로 로그인하는 PC라면 로그인 화면의 **'PIN을 잊어버렸습니다'**를 통해 재설정할 수 있습니다. 비밀번호로 로그인할 수 있다면 Windows 설정에서도 PIN을 다시 만들 수 있습니다.

Q2. 로그인 화면에 'PIN을 잊어버렸습니다' 버튼이 없습니다

Microsoft는 이 옵션이 Microsoft 계정에만 제공된다고 안내합니다. 로그인 옵션 → 비밀번호를 선택해 로그인한 뒤 **설정 → 계정 → 로그인 옵션 → PIN(Windows Hello)**에서 재설정하세요.

Q3. Windows Hello PIN과 Microsoft 계정 비밀번호는 같은가요?

아닙니다. Windows Hello PIN은 해당 장치의 로그인 수단이고, Microsoft 계정 비밀번호는 계정에 로그인하기 위한 별도 인증 정보입니다.

Q4. 현재 PIN을 기억하지 못해도 새 PIN으로 변경할 수 있나요?

이전 PIN을 요구하는 PIN 변경 메뉴 대신 **'PIN을 잊어버렸습니다'**로 진행합니다. Microsoft는 본인 확인 뒤 새 PIN을 설정할 수 있다고 안내합니다.

Q5. Microsoft 계정 비밀번호도 모르면 어떻게 해야 하나요?

**Microsoft 계정 암호 재설정 공식 안내**에서 본인 확인을 거쳐 비밀번호 복구를 진행하세요. 이후 Windows 로그인 방식에 따라 PIN을 다시 설정할 수 있습니다.

Q6. 로컬 계정인데 PIN을 잊어버렸습니다. 어떻게 하나요?

로컬 계정은 Microsoft 계정의 로그인 화면 PIN 재설정 링크를 이용할 수 없습니다. 로컬 계정 비밀번호로 로그인한 뒤 PIN을 재설정하거나, 비밀번호도 모르면 사전에 설정한 보안 질문·암호 재설정 디스크를 확인해야 합니다.

Q7. 'PIN을 사용할 수 없습니다' 오류는 왜 생기나요?

Microsoft는 보안 업데이트 또는 시스템 변경 뒤 기존 Windows Hello PIN이 재설정을 요구할 수 있다고 설명합니다. 오류 안내를 확인하고 공식 본인 확인·PIN 재설정을 시도하세요.

Q8. 안전 모드에 들어가면 PIN 없이 로그인되나요?

그렇지 않습니다. Microsoft는 안전 모드에서 PIN과 생체 인식 로그인 옵션을 사용할 수 없고 비밀번호가 필요하다고 안내합니다. PIN과 비밀번호를 모두 모른다면 안전 모드 진입만으로 문제가 해결되지 않습니다.

Q9. BitLocker 복구 키 48자리를 요구하는데 PIN을 입력하면 되나요?

안 됩니다. BitLocker 복구 키는 Windows PIN과 다른 정보입니다. 복구 화면의 키 ID를 기록하고 **aka.ms/myrecoverykey**에서 알맞은 48자리 복구 키를 확인하세요.

Q10. '내 파일 유지'로 Windows 11을 초기화하면 모든 데이터가 보존되나요?

모든 데이터와 앱이 보존된다고 보장할 수 없습니다. Microsoft는 '내 파일 유지'가 개인 파일을 유지하면서 Windows를 재설치하지만 앱과 설정을 제거할 수 있다고 안내합니다. 초기화 전에 백업과 BitLocker 복구 키를 확인하세요.

마무리: PIN 분실 문제는 공식 계정 복구부터 진행하세요

윈도우11 PIN을 잊어버렸다면 먼저 로그인 화면의 PIN 재설정, 그다음 비밀번호 로그인, 그리고 계정 유형에 맞는 Microsoft 계정·로컬 계정 복구 순서로 살펴보세요.

특히 로컬 계정은 Microsoft 계정의 로그인 화면 PIN 재설정 방법과 다르며, BitLocker 복구 키 화면은 또 다른 암호화 복구 문제입니다. 이 셋을 구분하면 파일을 지우거나 Windows를 다시 설치하지 않고 해결할 가능성이 높아집니다.

불필요한 초기화·보안 우회 프로그램 사용을 피하고, 문제가 해결된 뒤에는 복구 이메일·전화번호, BitLocker 복구 키, 중요 파일 백업을 점검해 두는 것이 좋습니다.
