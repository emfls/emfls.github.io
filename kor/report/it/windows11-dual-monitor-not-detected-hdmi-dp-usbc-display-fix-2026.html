Windows 11 PC에 두 번째 모니터를 연결했는데 화면이 검게 나오거나 ‘신호 없음(No Signal)’이라고 표시된다면 Windows 설정 문제라고 단정하기 전에 모니터의 입력 소스와 케이블, 그래픽 출력 기능부터 확인해야 합니다. 반대로 모니터 자체는 정상인데 Windows에 두 번째 화면이 나타나지 않는다면 Windows + P, 디스플레이 검색, 그래픽 드라이버 순서로 점검할 수 있습니다.

이 글은 Microsoft의 Windows 11 다중 모니터·외부 디스플레이 공식 고객지원과 Dell의 USB-C 영상 출력 및 데이지 체인 기술 자료를 바탕으로 작성했습니다. 설명은 2026년 11월 기준이며 실제 메뉴와 지원 가능한 해상도·주사율·모니터 수는 노트북·그래픽카드·도킹 스테이션 모델마다 달라질 수 있습니다.

먼저 기억할 핵심은 세 가지입니다. 모니터 전원이 켜지는 것, PC가 모니터를 감지하는 것, 그 모니터에 실제 화면을 출력하는 것은 서로 다른 단계입니다. 증상을 분리하면 불필요한 드라이버 삭제나 초기화를 피할 수 있습니다.

2. 모니터에 ‘신호 없음’이 표시되면 전원과 입력 소스부터

모니터의 전원 버튼에 불이 들어오고 설정 메뉴가 열린다고 해도 PC에서 영상 신호를 받고 있다는 뜻은 아닙니다.

  1. 모니터의 전원이 켜져 있고 전원 케이블이 안정적으로 연결됐는지 확인합니다.
  2. 모니터의 입력(Input), 소스(Source) 메뉴를 엽니다.
  3. PC에 연결한 포트가 HDMI 1, HDMI 2, DisplayPort, USB-C 중 무엇인지 확인합니다.
  4. 모니터 설정에서 해당 입력을 직접 선택합니다.
  5. 연결 케이블을 PC와 모니터 양쪽에서 분리했다가 단단히 다시 꽂습니다.
  6. 가능하면 다른 케이블 또는 다른 영상 출력 포트로 테스트합니다.

예를 들어 PC를 HDMI 2에 꽂아 두고 모니터는 HDMI 1로 설정했다면 실제 신호가 있어도 ‘신호 없음’이 나타날 수 있습니다. 이는 Windows 설정만 바꿔서는 해결되지 않습니다.

또한 케이블의 외형이 맞는다고 영상 출력이 항상 가능한 것은 아닙니다. 특히 USB-C의 경우 전원 충전이나 데이터 전송만 지원하고 화면 출력은 지원하지 않는 포트가 있습니다.

공식 출처: Microsoft Surface 외부 디스플레이 연결 문제 해결, Dell USB-C 화면 출력 오류

3. Windows + P로 복제·확장 모드 바꾸기

두 대의 화면이 물리적으로 연결됐더라도 Windows에서 PC 화면만 사용하도록 설정돼 있으면 외부 모니터가 검게 보일 수 있습니다.

  1. 키보드에서 Windows 키 + P를 누릅니다.
  2. 오른쪽에 표시되는 투영 메뉴를 확인합니다.
  3. 복제와 확장 중 원하는 기능을 선택합니다.
  4. 두 화면을 서로 다른 작업 공간으로 사용하려면 확장을 선택합니다.
  5. 보조 모니터에 영상이 표시되는지 확인합니다.

4. Windows 11에서 두 번째 모니터 수동 검색하기

Windows가 외부 화면을 자동으로 인식하지 못한다면 수동 검색을 시도할 수 있습니다.

  1. 바탕화면에서 마우스 오른쪽 버튼을 클릭합니다.
  2. 디스플레이 설정을 선택하거나 설정 → 시스템 → 디스플레이로 들어갑니다.
  3. 여러 디스플레이 항목을 펼칩니다.
  4. 검색(Detect) 버튼을 누릅니다.
  5. 새 모니터가 발견되면 화면 배열에서 번호를 확인합니다.
  6. **식별(Identify)**을 눌러 물리적으로 어떤 화면이 1번·2번인지 확인합니다.

Windows가 찾지 못했다는 메시지가 나오더라도 무조건 모니터가 고장 났다는 뜻은 아닙니다. 케이블·입력 소스·그래픽카드 출력 수·USB-C 영상 출력 가능 여부를 다시 점검하세요.

주의: Windows에 '디스플레이 2번'이 표시되는 상태와 모니터에 정상 영상이 나오는 상태는 다를 수 있습니다. Windows가 화면을 발견했다면 확장 모드, 해상도, 주사율을 추가로 확인해야 합니다.

5. 모니터 순서와 마우스 이동 방향 바꾸기

두 모니터에 화면이 나오더라도 마우스가 예상과 반대쪽으로 움직이거나 화면 사이를 자연스럽게 이동하지 않을 수 있습니다. 이때는 모니터를 다시 연결하기보다 Windows의 논리적 배치를 바꾸면 됩니다.

  1. 설정 → 시스템 → 디스플레이를 엽니다.
  2. 화면 배열에서 식별을 눌러 각 모니터 번호를 확인합니다.
  3. 상단의 모니터 사각형을 실제 책상 배치대로 드래그합니다.
  4. 좌우 위치뿐 아니라 높이가 다른 경우 위아래 위치도 맞춥니다.
  5. 적용을 누른 뒤 마우스를 화면 경계로 이동시켜 확인합니다.

예를 들어 실제 모니터는 왼쪽에 있는데 Windows 배치는 오른쪽에 있다면 커서를 반대쪽으로 이동해야 해당 화면에 들어갑니다. 두 번째 모니터가 사라진 것이 아니라 배치가 뒤집힌 문제일 수 있습니다.

6. HDMI와 DisplayPort 중 무엇을 확인해야 하나요?

HDMI와 DisplayPort는 모두 디지털 영상 연결에 쓰이지만, 사용 가능한 해상도·주사율·기능은 PC 출력 단자, 모니터 입력 단자, 케이블, 어댑터의 조합에 따라 달라집니다.

HDMI로 연결했는데 화면이 없을 때

  • 모니터에서 HDMI 입력을 올바르게 선택했는지 확인합니다.
  • HDMI 1·HDMI 2 중 실제 연결한 포트와 선택한 입력이 일치하는지 봅니다.
  • 다른 HDMI 케이블로 테스트합니다.
  • 가능하다면 같은 모니터를 다른 PC에 연결해 화면이 나오는지 확인합니다.

DisplayPort로 연결했는데 화면이 없을 때

  • PC의 DP 출력 단자와 모니터의 DP 입력 단자를 구분합니다.
  • 모니터의 입력 선택을 DP로 맞춥니다.
  • 케이블을 완전히 분리했다가 다시 연결하고 다른 포트나 케이블을 시험합니다.
  • 모니터 자체 메뉴에서 DisplayPort 관련 호환성 옵션이 제공되는지는 제조사 설명서를 확인합니다.

HDMI와 DP가 섞인 어댑터

포트 모양만 보고 모든 변환 어댑터가 양방향이라고 판단하면 안 됩니다. 변환 방향에 제약이 있는 제품도 있으므로 실제 케이블·어댑터의 지원 방향과 제조사 사양을 확인하세요.

공식 출처: Microsoft 외부 디스플레이 문제 해결, Microsoft Surface 외부 디스플레이 연결

7. USB-C로 충전은 되는데 외부 모니터 화면은 안 나올 때

USB-C 단자가 있다고 해서 모두 HDMI나 DP 영상 신호를 보낼 수 있는 것은 아닙니다. 일부 노트북 USB-C 포트는 데이터 전송과 충전만 지원할 수 있으며, 영상 출력에는 DisplayPort Alt Mode 또는 Thunderbolt/USB4의 영상 지원 기능이 필요할 수 있습니다.

확인 순서

  1. 노트북 모델명을 확인합니다.
  2. 제조사 공식 사양표에서 USB-C 단자의 영상 출력 지원 여부를 확인합니다.
  3. 모니터나 허브에 연결한 USB-C 단자가 영상 입력/출력용인지 확인합니다.
  4. USB-C 케이블이 영상 전송을 지원하는지 제품 사양을 확인합니다.
  5. 허브·도킹 스테이션을 제거하고 가능한 경우 노트북과 모니터를 직접 연결해 봅니다.
  6. 서로 다른 USB-C 포트가 있다면 각각의 기능 차이를 확인합니다.

Dell은 일부 모니터의 USB-C 포트가 충전·데이터 용도일 뿐 영상 입력을 받지 않는 경우가 있다고 설명합니다. 또한 일부 노트북의 USB-C 포트도 영상 출력을 지원하지 않는다고 명시합니다.

중요: 이 문제는 Windows의 검색 버튼이나 그래픽 드라이버를 반복 설치해도 해결되지 않을 수 있습니다. 먼저 하드웨어 사양에 영상 출력 기능이 있는지 확인해야 합니다.

공식 출처: Dell USB-C 모니터 영상 출력 문제, Dell 노트북 USB-C 단자 기능 차이

8. HDMI 분배기로 듀얼 모니터 확장이 안 되는 이유

HDMI 분배기(Splitter)를 이용해 하나의 PC 출력에서 두 모니터에 연결하면, 두 화면에 동일한 신호가 복제되는 경우가 일반적입니다. Microsoft는 이러한 분배기로 두 개의 독립적인 확장 디스플레이를 만드는 것은 불가능하다고 안내합니다.

따라서 모니터 두 대에 각각 다른 창을 띄우고 싶다면 PC가 서로 독립된 영상 출력 신호를 제공해야 합니다. 컴퓨터의 다른 출력 포트, 그래픽카드의 지원 포트 또는 다중 디스플레이를 지원하는 도크·어댑터를 사용해야 할 수 있습니다.

세 번째 모니터는 왜 안 될까요?

GPU와 노트북 모델별로 지원하는 화면 수가 다릅니다. 내부 노트북 화면과 외부 모니터 두 대를 동시에 켜는 구성을 지원하지 않을 수도 있습니다. 별도 도킹 스테이션을 사용한다 해도 PC와 도크가 지원하는 디스플레이 수와 해상도·주사율 조건을 모두 확인해야 합니다.

정리: 분배기와 다중 디스플레이 지원 도킹 스테이션은 같은 제품이 아닙니다. 광고 문구의 '2개 HDMI'만 보고 반드시 화면 확장이 가능하다고 판단하지 마세요.

공식 출처: Microsoft 외부 모니터 여러 대 연결 안내

9. DisplayPort 데이지 체인은 어떤 경우에 가능한가요?

DisplayPort 데이지 체인(Daisy Chain)은 PC에서 첫 번째 모니터로 연결한 뒤, 그 모니터의 DP 출력 단자에서 두 번째 모니터로 신호를 이어 보내는 방식입니다. 하지만 모든 모니터의 DP 단자가 이 기능을 지원하는 것은 아닙니다.

Dell은 해당 구성을 위해 DisplayPort MST(Multi-Stream Transport), DP Alt Mode 지원 USB-C 또는 Thunderbolt 등의 기술 지원이 필요하다고 설명합니다. PC와 첫 번째 모니터, 케이블의 호환성을 함께 확인해야 하며, 모니터의 DP 출력 단자 유무도 중요합니다.

실패했을 때 확인할 항목

  • PC가 MST 및 해당 수의 외부 디스플레이를 지원하는지
  • 첫 번째 모니터에 DP 출력이 실제로 있는지
  • 모니터 메뉴에서 MST 관련 설정이 필요한지
  • 해당 케이블과 포트의 규격·대역폭이 충분한지
  • 각 모니터에 전원이 별도로 공급되는지

단순히 모니터 두 대에 DP 포트가 있다는 이유로 데이지 체인이 가능한 것은 아닙니다. HDMI만으로 DP 데이지 체인과 같은 기능을 기대해서도 안 됩니다.

10. 갑자기 듀얼 모니터가 안 되면 그래픽 드라이버를 점검

이전까지 정상 작동하다가 Windows 업데이트나 그래픽 드라이버 변경 후 화면이 사라졌다면, 하드웨어 연결을 확인한 뒤 소프트웨어 문제를 살펴볼 수 있습니다.

Microsoft는 기존 외부 디스플레이 설정이 갑자기 작동하지 않는 경우 Windows + Ctrl + Shift + B 키를 이용해 그래픽 드라이버를 다시 설정하는 방법을 안내합니다. 이 동작 중 화면이 잠깐 깜박이거나 신호가 다시 잡힐 수 있습니다.

그래픽 드라이버 버전 확인하기

  1. 작업표시줄 검색에서 장치 관리자를 실행합니다.
  2. 디스플레이 어댑터를 펼칩니다.
  3. 장착된 그래픽 어댑터의 제조사와 모델을 확인합니다.
  4. 해당 어댑터의 속성 → 드라이버 탭에서 버전을 확인합니다.
  5. Windows 업데이트와 PC 또는 GPU 제조사의 공식 지원 페이지에서 호환 가능한 드라이버를 확인합니다.

업데이트 직후 문제가 생겼고 드라이버 롤백 옵션이 제공된다면 이전 버전으로 돌아가는 방법을 검토할 수 있습니다. 그러나 원인 분석 없이 드라이버를 무조건 제거하는 방식은 피하는 것이 좋습니다. 드라이버 재설치는 복구 경로와 작업 내용을 확보한 다음 진행하세요.

공식 출처: Microsoft 그래픽 드라이버 재설정·롤백 안내

11. 해상도와 주사율 때문에 화면이 깜박일 때

Windows가 모니터를 감지하지만 영상이 불안정하다면 연결 장치와 케이블이 감당할 수 있는 해상도·주사율의 조합인지 살펴봐야 합니다.

해상도 변경

  1. 설정 → 시스템 → 디스플레이로 이동합니다.
  2. 문제가 있는 모니터 번호를 선택합니다.
  3. 디스플레이 해상도 항목을 확인합니다.
  4. Microsoft가 권장하는 해상도를 기준으로 설정합니다.
  5. 화면이 비정상적이라면 모니터 제조사와 연결 규격에서 지원하는 해상도를 확인합니다.

Microsoft는 일반적으로 **권장(Recommended)**으로 표시된 해상도를 사용하는 것이 좋다고 안내합니다. 해상도를 지나치게 낮추면 글자가 흐릿하거나 화면이 늘어져 보일 수 있습니다.

주사율 변경

  1. 설정 → 시스템 → 디스플레이 → 고급 디스플레이를 엽니다.
  2. 문제가 있는 모니터를 선택합니다.
  3. 새로 고침 빈도(주사율) 항목을 확인합니다.
  4. 현재 높은 주사율에서 화면이 끊긴다면 해당 모니터에서 제공되는 낮은 주사율로 일시 테스트합니다.
  5. 안정적이라면 케이블·포트·허브가 원래 사용하려던 해상도와 주사율을 지원하는지 확인합니다.

Windows에 표시되는 주사율 선택지는 모니터와 연결 장치의 지원 기능에 따라 달라집니다. 어떤 제품에서나 144Hz나 240Hz를 선택할 수 있는 것은 아닙니다.

공식 출처: Microsoft 화면 해상도·레이아웃 설정, Microsoft Windows 모니터 주사율 변경

12. 노트북 덮개를 닫았더니 외부 모니터가 꺼질 때

외부 모니터가 잘 나오다가 노트북 덮개를 닫는 순간 화면까지 꺼지는 현상은 모니터 인식 문제와 별개로 노트북 전원·절전 설정의 영향을 받을 수 있습니다.

일부 Windows 노트북은 덮개를 닫을 때 절전 모드로 들어가도록 설정돼 있습니다. 외부 모니터만 사용하려는 경우에는 Windows의 전원 설정과 제조사 지원 자료에서 덮개 닫힘 동작을 확인하세요.

다만 외부 모니터를 장시간 연결한 상태에서 노트북의 통풍구를 막거나 과도하게 발열되는 상태로 사용하지 않아야 합니다. 특히 업무용 PC에는 조직의 보안 및 전원 관리 정책이 적용될 수 있으므로 임의 변경 전에 확인하는 것이 좋습니다.

시험 방법: 먼저 덮개를 연 상태에서 외부 모니터가 정상 출력되는지 확인한 다음 덮개를 닫았을 때만 발생하는 문제인지 구분합니다. 노트북 화면을 열어 둔 상태에서도 외부 모니터가 인식되지 않는다면 앞의 HDMI·DP·USB-C 및 장치 검색 단계를 먼저 적용하세요.

13. 노트북·데스크톱에서 점검할 부분이 다를 수 있습니다

노트북

  • USB-C 포트가 실제로 영상 출력을 지원하는지
  • 내장 디스플레이를 포함해 동시에 몇 대를 지원하는지
  • 도킹 스테이션과 연결된 모니터의 수가 허용 범위인지
  • 외부 모니터만 사용하도록 변경된 투영 모드가 있는지
  • 노트북 덮개·절전 조건에 따른 일시적 연결 해제가 있는지

데스크톱

  • 모니터 케이블이 실제로 사용하려는 그래픽 출력 포트에 연결됐는지
  • 포트가 PC의 그래픽 구성과 연결돼 사용 가능한 상태인지
  • 모니터 두 대를 GPU가 동시에 지원하는지
  • 케이블 및 포트에 물리적 손상이 없는지
  • 그래픽 드라이버가 정상 작동하는지

특히 데스크톱에 별도 그래픽카드가 있는 경우 PC 뒷면에 여러 종류의 영상 단자가 존재할 수 있습니다. 단자가 보인다는 사실만으로 모두 동시에 활성화되는 것은 아닙니다. 제조사의 사용 설명서를 확인하세요.

14. 이렇게 교차 테스트하면 고장 부위를 좁힐 수 있습니다

테스트결과판단에 도움 되는 내용
모니터 A를 같은 PC의 다른 포트로 연결새 포트에서 정상기존 포트 또는 연결 방식 문제 가능
같은 케이블로 다른 모니터 연결다른 모니터 정상원래 모니터의 입력·설정 문제 가능
다른 케이블로 같은 모니터 연결정상으로 변경기존 케이블 문제 가능

교차 테스트는 확정적인 고장 판정이 아니라 문제 범위를 좁히는 방법입니다. 케이블을 바꾼 동시에 포트나 출력 설정까지 변경했다면 어느 요소가 원인이었는지 알기 어려울 수 있으니 가능하면 한 번에 한 조건씩 바꿔 보세요.

15. 자주 묻는 질문

Q. HDMI 케이블을 꽂았는데 ‘신호 없음’이라고 표시됩니다.

모니터에서 실제 HDMI 입력을 선택했는지 확인하고 케이블을 양쪽에서 다시 꽂아 보세요. Windows + P로 확장 모드를 선택하고 다른 케이블이나 포트로 교차 테스트하세요. USB-C 어댑터를 사용 중이면 해당 포트가 영상 출력을 지원하는지도 확인해야 합니다.

Q. Windows 디스플레이 설정에 모니터 2번이 나타나지 않아요.

설정 → 시스템 → 디스플레이 → 여러 디스플레이 → 검색을 시도하세요. 검색해도 발견되지 않는다면 케이블·입력 소스·허브·도크 및 그래픽카드 지원 모니터 수를 확인하세요.

Q. 두 모니터에서 같은 화면만 나옵니다.

Windows + P에서 복제가 아니라 확장을 선택하세요. HDMI 분배기가 동일 신호만 복제하고 있는 구성이라면 Windows 설정만으로 두 개의 독립된 확장 화면을 만들 수는 없습니다.

Q. 노트북 USB-C 포트로 충전은 되는데 모니터가 안 됩니다.

USB-C 포트가 전원이나 데이터만 지원하고 영상 출력은 지원하지 않을 수 있습니다. 노트북과 모니터·허브 사양에서 DP Alt Mode, Thunderbolt 또는 영상 출력 지원 여부를 확인해야 합니다.

Q. 두 번째 모니터는 되는데 세 번째 모니터가 안 됩니다.

GPU와 노트북 모델에 따라 동시 디스플레이 수에 제한이 있습니다. 분배기는 복제만 지원할 수 있으므로, 그래픽 출력 기능·도크·MST 지원 여부와 내부 화면 포함 최대 모니터 수를 확인하세요.

Q. 144Hz 모니터인데 Windows에서는 60Hz만 보입니다.

모니터뿐 아니라 케이블, 포트, 어댑터와 그래픽 출력의 해상도·주사율 지원 조합을 확인하세요. 설정 → 시스템 → 디스플레이 → 고급 디스플레이에서 사용 가능한 주사율을 볼 수 있습니다. 특정 수치가 표시되지 않는다면 제조사 사양을 확인해야 합니다.

Q. 화면이 업데이트 후 갑자기 안 나옵니다.

케이블과 입력 소스를 확인한 다음 PC를 재시작하고, 필요하면 Windows + Ctrl + Shift + B로 그래픽 드라이버를 다시 설정할 수 있습니다. 업데이트 직후부터 문제가 반복된다면 장치 관리자에서 그래픽 드라이버 버전과 롤백 가능 여부를 확인하세요.

Q. 그래픽 드라이버를 지우면 바로 해결되나요?

보장할 수 없습니다. Microsoft는 필요한 상황에서 드라이버 롤백이나 재설치를 안내하지만, 기본적인 케이블·입력 소스·투영 모드 문제라면 재설치가 도움이 되지 않습니다. 업무용 PC에서는 관리자 정책과 복구 방법을 먼저 확인하세요.

16. 최종 체크리스트

  • ☐ 외부 모니터의 전원과 실제 입력(HDMI·DP·USB-C)을 확인했습니다.
  • ☐ 케이블을 분리했다가 정확한 포트에 다시 연결했습니다.
  • ☐ Windows + P에서 원하는 확장 또는 복제 모드를 선택했습니다.
  • ☐ Windows 디스플레이 설정에서 검색과 식별을 사용했습니다.
  • ☐ USB-C 포트와 허브의 영상 출력 지원 여부를 확인했습니다.
  • ☐ HDMI 분배기와 독립 화면 확장 장비를 혼동하지 않았습니다.
  • ☐ 그래픽카드·노트북의 동시 지원 모니터 수를 확인했습니다.
  • ☐ 필요한 경우 다른 케이블·다른 포트·다른 PC로 교차 테스트했습니다.
  • ☐ 그래픽 드라이버 상태와 Windows 업데이트를 점검했습니다.
  • ☐ 해상도와 주사율을 모니터가 지원하는 범위로 설정했습니다.
