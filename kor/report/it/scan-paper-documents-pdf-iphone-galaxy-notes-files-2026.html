이 글은 2026년 11월 4일 확인한 Apple·Samsung 공식 안내를 기준으로 스캔 → 여러 장 묶기 → PDF 저장 → 제출 전 확인까지 설명합니다. 기종·운영체제·앱 버전에 따라 버튼 이름과 위치는 일부 다를 수 있습니다.

1. 먼저 보는 기종별 가장 빠른 방법

사용하는 기기추천 경로결과물알아둘 점
아이폰: 파일을 바로 제출할 때파일 앱 → 더 보기(…) → 문서 스캔 → 저장선택한 위치의 스캔 파일저장 위치를 직접 지정하기 쉬움
아이폰: 메모와 함께 보관할 때메모 앱 → 첨부 → 문서 스캔메모 안의 스캔 문서스캔 결과를 열어 공유·주석 처리 가능
갤럭시: 종이 한 장 스캔카메라 → 문서 인식 시 ‘스캔’ → 저장갤러리의 스캔 이미지모델에 따라 바로 PDF가 아닌 이미지로 저장됨
갤럭시: PDF로 제출할 때카메라 스캔 → 삼성 노트에 이미지 첨부 → 파일로 저장 → PDF 파일PDF 문서일부 최신 모델은 카메라에서 PDF 직접 저장 가능

결론: 아이폰에서 ‘파일 제출’이 목적이면 처음부터 파일 앱을 이용하세요. 갤럭시는 카메라 스캔 결과의 확장자가 JPG인지 PDF인지 확인한 뒤 필요하면 삼성 노트에서 PDF로 내보내면 됩니다.

2. 아이폰 파일 앱으로 문서 스캔하고 PDF 저장하기

Apple 공식 지원 문서가 안내하는 절차입니다. 주민등록 관련 서류나 영수증처럼 다른 앱에 업로드할 독립된 파일이 필요한 경우 가장 이해하기 쉽습니다.

  1. 아이폰의 파일 앱을 엽니다.
  2. 화면의 더 보기(…) 버튼을 누릅니다.
  3. 메뉴에서 문서 스캔을 선택합니다.
  4. 종이를 평평한 곳에 놓고 모서리 네 개가 화면 안에 들어오게 합니다.
  5. 자동으로 촬영되면 결과를 확인합니다. 자동 촬영이 어려우면 셔터 버튼 또는 음량 버튼을 누릅니다.
  6. 모서리가 어긋났다면 손잡이를 드래그해 종이의 네 귀퉁이에 맞추고 스캔 항목 유지를 탭합니다.
  7. 여러 장이라면 다음 종이를 이어서 스캔합니다.
  8. 완료를 누르고 iPhone 내 / iCloud Drive 등 저장할 폴더를 선택한 다음 저장을 탭합니다.
  9. 저장된 문서를 열어 페이지가 빠짐없이 들어갔는지 확인합니다.

파일 앱에서 문서 스캔 메뉴가 안 보인다면 ‘최근 항목’이 아니라 ‘둘러보기’ 화면 또는 원하는 저장 위치로 이동해 더 보기 메뉴를 확인하세요. 화면 구성은 iOS 버전에 따라 달라질 수 있습니다.

공식 안내: Apple — iPhone 또는 iPad에서 문서를 스캔하는 방법.

3. 아이폰 메모 앱에서 문서 스캔하기

종이 문서에 설명을 함께 적거나 나중에 다시 확인하려면 메모 앱 방식이 적합합니다.

  1. 메모 앱을 열고 새 메모를 만들거나 기존 메모를 엽니다.
  2. 첨부 파일 버튼을 선택합니다.
  3. 문서 스캔을 누릅니다.
  4. 종이를 촬영하고 필요하면 가장자리를 조절합니다.
  5. 두 번째·세 번째 페이지도 계속 촬영합니다.
  6. 완료를 눌러 스캔 문서를 메모에 추가합니다.
  7. 스캔한 문서를 열어 공유 메뉴에서 제출용 파일로 내보낼 수 있는지 확인합니다. 확실한 저장 위치가 필요하다면 2번의 파일 앱 직접 스캔을 이용하는 편이 간단합니다.

Apple은 스캔한 문서에 마크업으로 서명을 추가하는 방법도 안내합니다. 다만 공공기관·계약 상대방이 요구하는 전자서명 인증 요건과 손가락으로 그린 서명은 동일하다고 단정할 수 없습니다.

주의: '텍스트 스캔'과 '문서 스캔'은 다릅니다. 텍스트 스캔은 인식한 글자를 메모에 입력하는 용도이며, 원본 서류 모양을 유지해 제출하려면 문서 스캔을 선택하세요.

공식 안내: Apple — 메모 앱에서 문서 스캔 및 서명, Apple — 메모 앱의 PDF 작업.

4. 갤럭시 카메라로 종이 문서 스캔하기

Samsung 공식 지원 문서에 따르면 Galaxy 카메라의 문서 스캔 기능은 종이 문서를 인식해 모서리를 보정하고 갤러리에 저장할 수 있습니다. 모델·소프트웨어에 따라 표시되는 기능은 다릅니다.

  1. 카메라 앱을 열어 일반 사진 촬영 화면을 띄웁니다.
  2. A4 용지나 영수증을 카메라 화면 중앙에 둡니다.
  3. 스캔 버튼이 나타나면 누릅니다.
  4. 미리보기에서 잘린 부분과 글씨 선명도를 확인합니다.
  5. 필요한 경우 다시 촬영하거나 영역을 조정합니다.
  6. 저장을 눌러 결과물을 갤러리에서 확인합니다.

‘스캔’ 버튼이 보이지 않을 때

  • 카메라 설정에서 문서 및 텍스트 스캔과 관련한 옵션이 있는지 확인합니다.
  • 빛 반사를 줄이고 종이 전체가 프레임 안에 들어오게 합니다.
  • 문서와 배경의 색 대비를 높이고 다시 카메라를 향합니다.
  • 기종에서 해당 기능을 지원하는지 확인합니다. 모든 갤럭시에서 메뉴 구조가 동일한 것은 아닙니다.
  • ‘QR코드 스캔’은 종이 문서 스캔과 별개 기능입니다.

중요: 갤럭시 카메라로 ‘스캔’을 눌렀다고 해서 파일이 무조건 PDF로 저장되는 것은 아닙니다. 우선 갤러리 또는 내 파일에서 형식을 확인하세요.

공식 안내: Samsung — Galaxy 휴대폰·태블릿에서 문서 스캔, Samsung — 카메라 모드 및 설정.

5. 갤럭시 스캔 이미지를 PDF로 바꾸는 방법

갤러리에 저장된 스캔 이미지를 삼성 노트(Samsung Notes)로 가져온 뒤 PDF로 내보내는 절차입니다.

  1. 삼성 노트 앱을 열고 새 노트 만들기를 탭합니다.
  2. 첨부(클립 모양) 또는 삽입 메뉴에서 이미지 → 갤러리를 선택합니다.
  3. 스캔한 이미지를 한 장 또는 필요한 순서대로 첨부합니다.
  4. 노트 안에서 이미지 배치와 페이지 순서를 확인합니다.
  5. 더 보기(세로 점 3개) → 파일로 저장을 누릅니다.
  6. 저장 형식으로 PDF 파일을 선택합니다.
  7. 저장할 폴더를 선택하고 파일 이름을 정해 저장합니다.
  8. 내 파일 앱에서 PDF를 다시 열어 페이지 누락과 글씨 잘림을 확인합니다.

Samsung 공식 안내에서는 노트를 PDF로 내보낼 때 More options → Save as file → PDF file 경로를 제시합니다. 실제 한국어 메뉴나 갤럭시의 앱 버전에 따라 표현은 다를 수 있습니다.

일부 최신 갤럭시에서 PDF 직접 저장이 제공된다면 카메라 스캔 화면에서 ‘PDF로 저장’ 옵션을 이용할 수 있습니다. 다만 구형 기기까지 모두 동일하게 지원한다고 가정하지 마세요.

공식 안내: Samsung — 삼성 노트에서 PDF 가져오기·내보내기, Samsung — Galaxy 문서 스캔과 편집.

6. 여러 장을 PDF 한 파일로 묶을 때 실수하기 쉬운 점

입학 서류, 근로계약서, 영수증 묶음처럼 여러 장을 제출할 경우에는 페이지 순서와 누락 여부가 가장 중요합니다.

문제예방·확인 방법
1쪽과 2쪽이 다른 파일로 저장됨새 스캔을 끝낼 때마다 저장하지 않고 같은 스캔 작업에서 페이지 추가
문서의 오른쪽 끝이 잘림저장 전에 모서리 조절 화면에서 네 모서리 확인
양면 서류 뒷면이 빠짐앞면과 뒷면을 각각 한 페이지로 촬영
갤럭시에서 여러 이미지 순서가 뒤섞임삼성 노트에 첨부한 뒤 미리보기로 순서 확인
스캔이 너무 어둡거나 빛 번짐밝은 간접광 아래에서 촬영하고 그림자 제거
JPG인데 PDF로 착각함파일 앱 또는 내 파일에서 확장자·파일 유형 확인
파일 크기가 제출 제한보다 큼압축·품질 조정을 고려하되 작은 글씨가 읽히는지 재확인

스캔 편집 중 저장 위치를 바꾸거나 앱을 종료하기 전에는 파일이 실제로 만들어졌는지 먼저 검증해야 합니다. 중요한 원본 사진이나 노트는 제출 완료 전 삭제하지 마세요.

7. PDF 업로드가 거부될 때 5가지 점검

① JPG·PNG 파일을 PDF라고 잘못 올린 경우 파일 이름에 '.pdf'를 덧붙이기만 하면 형식이 바뀌지 않습니다. 실제 PDF 형식으로 다시 내보내야 합니다.

② 업로드 화면에서 파일이 보이지 않는 경우 아이폰은 파일 앱에 저장한 위치, 갤럭시는 내 파일에서 저장 폴더를 확인합니다. 사진 보관함만 표시하는 업로드창과 PDF 선택창은 다를 수 있습니다.

③ 페이지가 하나만 제출된 경우 파일을 다시 열어 전체 페이지 수를 확인합니다. 서류가 여러 장이면 한 PDF에 포함해야 하는지, 기관이 개별 파일을 요구하는지 확인하세요.

④ 파일 용량 제한을 초과한 경우 제출 서비스의 허용 크기를 먼저 읽습니다. 컬러 사진·고해상도 스캔은 용량이 커질 수 있으니 텍스트 가독성을 해치지 않는 범위에서 조정합니다. 원본 문서와 축소본을 따로 보관하면 안전합니다.

⑤ 스캔본이 공식 증명서와 동일한 효력이 있다고 생각한 경우 사진을 PDF로 만들었다고 원본대조필·전자문서 인증·발급기관의 직인·유효한 전자서명이 자동으로 생기는 것은 아닙니다. 제출처가 전자증명서 원본이나 발급기관 PDF를 요구하면 그 방법을 따라야 합니다.

8. 개인정보가 포함된 서류를 스캔할 때

신분증·계좌·주민등록번호가 있는 문서는 일반 서류와 다르게 취급하는 것이 좋습니다.

  • 불필요한 외부 스캐너 사이트에 파일을 업로드하지 않고 먼저 기본 앱으로 처리합니다.
  • 문서를 공유할 때 수신인과 첨부 파일을 한 번 더 확인합니다.
  • 제출처가 허용하면 불필요한 민감정보를 가리는 방법을 검토합니다. 단, 요구된 증빙 내용을 임의로 가려 반려되지 않도록 주의합니다.
  • iCloud Drive·클라우드 동기화를 사용하는 경우 어떤 계정·기기와 동기화되는지 확인합니다.
  • 공용 기기라면 최근 항목·다운로드·공유 기록을 함께 점검합니다.

가림 처리가 필요한 경우엔 PDF 화면 위에 단순히 검은 사각형만 얹는 것이 아니라, 정보를 복구할 수 없도록 실제로 제거하는 편집 방식이 필요할 수 있습니다. 단순 표시 덮개는 안전한 비식별화와 다를 수 있습니다.

9. 자주 묻는 질문

Q. 아이폰에서 문서 스캔 앱을 따로 설치해야 하나요?

아니요. Apple의 파일 앱·메모 앱에서 기본 스캔 기능을 이용할 수 있습니다. 다만 기기에 설치된 iOS와 설정에 따라 보이는 메뉴는 달라질 수 있습니다.

Q. 갤럭시에서 스캔했는데 갤러리에 사진으로만 저장돼요.

일부 갤럭시는 카메라 문서 스캔 결과를 이미지 파일로 저장합니다. Samsung Notes에 삽입한 뒤 파일로 저장 → PDF를 선택하세요. 모델이 제공하는 PDF 직접 저장 기능을 쓸 수도 있습니다.

Q. 사진과 문서 스캔은 무엇이 다른가요?

일반 사진은 주변 배경과 원근감을 그대로 담기 쉽습니다. 문서 스캔은 문서 경계 인식·크롭·원근 보정 등 읽기 편한 결과를 만드는 데 초점을 둡니다. 스캔 후에도 글자가 선명한지 확인해야 합니다.

Q. PDF에서 글자를 선택하거나 복사할 수 없어요.

스캔 PDF는 이미지만 담은 PDF일 수 있어 글자 선택이 안 될 수 있습니다. 글자 추출·검색이 필요하면 OCR 기능이 별도로 필요할 수 있으며, 숫자·고유명사의 인식 결과는 직접 확인해야 합니다.

Q. 한 파일에 여러 페이지를 넣을 수 있나요?

아이폰 파일 앱과 메모 앱은 같은 스캔 작업에서 여러 페이지 추가가 가능합니다. 갤럭시의 경우 기기별 다중 스캔 지원 범위를 확인하고, 일반적인 방법으로는 삼성 노트에 필요한 이미지를 함께 배치해 PDF로 내보낼 수 있습니다.

Q. 스캔 PDF가 원본 서류를 대체하나요?

제출처 규정에 따라 다릅니다. 단순 첨부용은 스캔 PDF가 가능할 수 있지만, 발급기관의 전자증명서나 특정 인증된 문서를 요구한다면 스캔본으로 대체할 수 없습니다.

10. 제출 전 최종 체크리스트

  • ☐ 제출처가 PDF를 허용하는지 확인했다.
  • ☐ 파일이 실제로 .pdf 형식이며 다시 열 수 있다.
  • ☐ 첫 페이지부터 마지막 페이지까지 순서가 맞다.
  • ☐ 이름·날짜·금액·도장 등 중요 내용이 잘리지 않았다.
  • ☐ 원본이 양면이면 뒷면을 포함했다.
  • ☐ 제출처의 최대 파일 크기를 지켰다.
  • ☐ 개인정보와 수신처를 확인했다.
  • ☐ 제출이 끝날 때까지 원본과 사본을 보관한다.

핵심 요약: 아이폰은 파일 앱의 ‘문서 스캔’으로 바로 제출용 PDF를 저장하는 것이 간단합니다. 갤럭시는 카메라로 문서 스캔한 뒤 삼성 노트에서 PDF로 내보내는 방법을 기본으로 기억하세요. 어떤 기기든 최종 제출 전에는 파일 형식·페이지 수·가독성을 다시 확인하는 것이 중요합니다.
