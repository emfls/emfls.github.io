인쇄 버튼을 눌렀는데 프린터는 아무 반응이 없고 Windows 11에는 '오프라인', '오류', **'인쇄 중'**만 표시되나요? 방금 출력한 서류가 대기열에서 사라지지 않거나 프린터가 여러 개 등록돼 엉뚱한 기기로 인쇄되는 문제도 흔합니다.

이때 인쇄 드라이버를 모두 삭제하거나 프린터를 공장 초기화하는 것부터 시작할 필요는 없습니다. 프린터에 전원이 들어오지 않는 문제, PC와의 연결 문제, 잘못 선택한 기본 프린터, 멈춘 인쇄 작업, 인쇄 스풀러 서비스 오류는 원인과 해결 순서가 다릅니다.

이 글은 2026년 10월 25일 기준 Microsoft 공식 Windows 고객지원 문서를 확인해 작성했습니다. Windows 11의 프린터 설정 경로, 인쇄 대기열 취소, 스풀러 서비스 재시작, Wi-Fi 프린터 추가, USB 인식 오류, 네트워크 공유, 드라이버 복구와 ARM 기반 Copilot+ PC의 주의사항까지 순서대로 안내합니다.

1. '프린터 오프라인'과 '인쇄 대기 중'은 왜 다른가요?

프린터 오프라인은 Windows가 프린터와 정상적으로 통신하지 못한다고 판단했을 때 표시될 수 있습니다. 하지만 프린터가 실제로 꺼져 있는지, Wi-Fi 연결이 끊겼는지, USB 케이블 문제인지, 스풀러 오류인지는 따로 확인해야 합니다.

반대로 인쇄 대기 중은 문서를 보내는 인쇄 대기열에 작업이 남아 있다는 뜻입니다. 프린터가 온라인으로 보이더라도 먼저 보낸 작업이 멈춰 있으면 다음 문서가 진행되지 않을 수 있습니다.

세 가지 상황을 나누어 보세요

프린터 화면에도 오류가 있음: 용지 걸림, 덮개 열림, 토너·잉크 부족, 연결 오류 등 프린터 자체에서 표시되는 내용을 확인합니다.

Windows에서만 오프라인 표시: 다른 PC나 프린터 제어판에서는 정상 동작하는지 확인하고, PC 연결·공유기·설정·드라이버 문제를 점검합니다.

프린터는 인쇄할 수 있지만 특정 문서만 멈춤: 해당 앱이나 파일 문제인지, 인쇄 대기열에 이전 작업이 남았는지 살펴봅니다.

결론: '오프라인'이라는 글자 하나만 보고 프린터 고장이나 새 프린터 구매가 필요하다고 결정하지 마세요. Microsoft도 연결·대기열·스풀러·드라이버를 차례로 점검하도록 안내합니다.

2. 가장 먼저 프린터 본체와 연결 상태 확인

PC의 설정을 바꾸기 전에 프린터 본체에 출력할 준비가 돼 있는지 확인하는 것이 좋습니다.

프린터에서 확인할 것

  1. 전원 표시등 또는 제어 화면이 켜져 있는지 확인합니다.
  2. 용지함에 종이가 있고 용지 걸림 경고가 없는지 확인합니다.
  3. 잉크·토너·덮개 열림 등 오류 메시지를 살펴봅니다.
  4. USB 프린터라면 케이블이 양쪽에 제대로 연결됐는지 확인합니다.
  5. 무선 프린터라면 Wi-Fi 표시등과 연결 상태를 점검합니다.
  6. 공유 프린터라면 프린터가 연결된 호스트 PC도 켜져 있는지 확인합니다.

프린터 전원 재시작

  1. 다른 사람이 인쇄 중이지 않은지 확인합니다.
  2. 프린터를 정상적인 전원 버튼으로 끕니다.
  3. 필요하면 전원 플러그를 분리합니다.
  4. 약 30초 기다린 뒤 다시 연결합니다.
  5. 프린터 전원을 켜고 자체 준비 완료 표시를 기다립니다.
  6. Windows에서 프린터 상태를 다시 확인합니다.

Microsoft는 일시적인 연결 문제를 해결하기 위해 프린터 전원을 껐다 켜는 절차를 안내합니다. 일부 문제 해결 문서에서는 더 긴 재시작 시간을 제시할 수 있으므로 기종별 제조사 설명도 참고하세요.

주의: 정밀 프린터·대형 복합기·업무용 장비에서 인쇄·펌웨어 업데이트가 진행 중이라면 전원을 무작정 분리하지 마세요. 제조사와 사내 관리자 지침을 따라야 합니다.

3. Windows 11에서 올바른 프린터가 선택됐는지 확인하기

프린터가 정상 작동하는데도 문서가 나오지 않는다면 인쇄 대상이 다른 장치로 지정돼 있는 경우일 수 있습니다.

Windows 11 프린터 목록 열기

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. Bluetooth 및 장치 → 프린터 및 스캐너로 이동합니다.
  3. 현재 설치된 프린터 목록을 확인합니다.
  4. 출력하려는 프린터의 정확한 모델명을 선택합니다.
  5. 프린터 상태와 인쇄 대기열을 확인합니다.

Microsoft는 Windows 11에서 기본 프린터를 수동으로 지정하거나, 가장 최근에 사용한 프린터를 자동으로 기본값으로 설정하는 두 가지 방식을 제공합니다.

기본 프린터를 수동으로 설정하기

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너를 엽니다.
  2. **'Windows에서 내 기본 프린터를 관리하도록 허용'**을 끕니다.
  3. 실제 사용하려는 프린터를 선택합니다.
  4. 기본값으로 설정을 누릅니다.
  5. 다시 Word·PDF 등 문서에서 인쇄를 시도합니다.

'기본값으로 설정' 버튼이 안 보인다면?

Microsoft는 Windows에서 기본 프린터를 관리하도록 허용이 켜져 있으면 기본값 버튼이 표시되지 않을 수 있다고 설명합니다. 해당 옵션을 먼저 해제하고 확인하세요.

같은 이름의 프린터가 여러 개라면?

네트워크 프린터와 USB 프린터가 중복 설치됐거나 과거 프린터가 목록에 남아 있을 수 있습니다. 실제 프린터와 연결된 항목이 어느 것인지 먼저 확인해야 하며, 이름만 같다고 무조건 오래된 항목부터 삭제하면 안 됩니다.

4. Windows 11 인쇄 대기열 보기: 출력이 멈춘 문서 찾기

인쇄 버튼을 여러 번 눌렀다면 문제가 해결된 뒤 같은 문서가 여러 장 한꺼번에 출력될 수 있습니다. 먼저 인쇄 대기열에서 기존 작업이 남아 있는지 확인하세요.

인쇄 대기열 여는 순서

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너를 엽니다.
  2. 문제가 발생한 프린터를 선택합니다.
  3. 인쇄 큐 열기 또는 인쇄 대기열 열기를 누릅니다.
  4. 보류 중인 문서 이름과 상태를 확인합니다.
  5. 가장 먼저 멈춰 있는 작업이 있는지 살펴봅니다.

Microsoft 공식 도움말은 인쇄 대기열에 현재 인쇄를 기다리는 작업 목록이 표시된다고 설명합니다.

'대기열이 비어 있음'이면?

인쇄 대기열에 아무 문서도 없다면 기존 작업이 멈춘 것이 아니라 앱이 인쇄 명령을 보내지 않았거나 다른 프린터로 보냈을 가능성도 있습니다.

문서를 다시 열고 Ctrl + P를 눌러 인쇄 화면의 프린터 이름을 확인하세요. 'Microsoft Print to PDF'가 선택돼 있으면 실제 종이 프린터가 아니라 PDF 파일로 저장하려는 설정입니다.

공용 프린터라면 다른 작업도 표시될 수 있습니다

회사나 학교의 프린터는 다른 사람이 보낸 작업을 처리하고 있을 수 있습니다. 본인 작업만 취소할 수 있는지 확인하고 관리자 승인 없이 다른 사람의 인쇄 작업을 지우지 마세요.

5. 인쇄 대기열 삭제: 멈춘 문서만 취소하는 방법

인쇄 작업이 '오류', '삭제 중', '인쇄 중'으로 오래 남아 있으면 문서 하나를 취소해 대기열을 정리하는 것이 먼저입니다.

대기열에서 인쇄 취소

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너를 엽니다.
  2. 해당 프린터를 선택합니다.
  3. 인쇄 큐 열기를 누릅니다.
  4. 오류가 발생한 문서를 선택합니다.
  5. 문서를 마우스 오른쪽 버튼으로 클릭하거나 제공되는 메뉴에서 취소를 선택합니다.
  6. 문서가 목록에서 사라졌는지 확인합니다.
  7. 정상적인 간단한 문서 한 장으로 다시 인쇄를 시험합니다.

모든 문서를 취소해도 될까요?

Microsoft는 대기열이 멈췄다면 기존 작업을 취소하는 방법을 안내하지만, 회사·학교 등 공유 환경에서 모든 작업을 일괄 취소하는 것은 다른 사용자의 출력물에 영향을 줄 수 있습니다.

공동 프린터라면 어떤 문서가 누구의 작업인지 먼저 확인하세요. 본인의 작업만 취소할 수 있는 경우 그 범위에서 진행하는 것이 좋습니다.

취소했는데 '삭제 중'에서 멈춰 있다면?

인쇄 스풀러 서비스가 정지됐거나 작업 파일이 정상 처리되지 않았을 수 있습니다. 이때는 같은 취소 버튼을 반복 클릭하기보다 다음 단계의 스풀러 재시작을 시도하는 것이 좋습니다.

출력 버튼을 여러 번 누른 경우

기존 대기열이 복구되면 밀려 있던 문서가 연속으로 출력될 수 있습니다. 복구 전에 중복 등록된 작업이 없는지 확인하고 종이·잉크 낭비를 줄이세요.

공식 출처: Microsoft - Windows 인쇄 대기열 작업 취소

6. 인쇄 스풀러 다시 시작: Windows 서비스에서 해결

프린터가 연결돼 있고 대기열을 취소했는데도 인쇄가 멈춘다면 Windows의 인쇄 스풀러(Print Spooler) 서비스를 다시 시작할 수 있습니다.

인쇄 스풀러란?

스풀러는 Windows에서 프린터로 보내는 인쇄 작업을 관리하는 서비스입니다. 앱에서 인쇄 명령을 보내면 출력 작업을 대기열에 보관하고 순서대로 처리합니다.

Microsoft는 스풀러가 중지되거나 오류를 일으키면 문서가 대기열에서 멈추고 다음 작업까지 진행되지 않을 수 있다고 설명합니다.

Windows 11에서 스풀러 재시작

  1. Windows 키 + R을 누릅니다.
  2. 실행창에 services.msc를 입력하고 Enter 키를 누릅니다.
  3. Windows 서비스 목록이 나타나면 아래로 이동합니다.
  4. **인쇄 스풀러(Print Spooler)**를 찾습니다.
  5. 해당 항목을 오른쪽 클릭합니다.
  6. 다시 시작을 선택합니다.
  7. 서비스가 실행 상태인지 확인합니다.
  8. 프린터 대기열을 다시 열고 간단한 문서를 인쇄해 봅니다.

'다시 시작' 버튼이 없거나 회색이라면?

서비스가 이미 중지돼 있거나 관리자 권한이 필요할 수 있습니다. 시작 버튼이 제공되는지 확인하고, 회사·학교 PC라면 관리자에게 문의하세요.

무엇이 변경되나요?

스풀러를 다시 시작하면 인쇄 작업 처리 과정이 새로 시작됩니다. 작업을 재전송해야 할 수 있으며, 프린터 자체의 공장 설정이나 PC의 모든 데이터를 지우는 작업은 아닙니다.

다만 공동 인쇄 서버의 서비스를 재시작하면 다른 사용자에게 영향이 발생할 수 있으므로 서버·업무용 PC에서는 승인 없이 실행하지 마세요.

공식 출처: Microsoft - 인쇄 스풀러 실행 오류 해결

7. 인쇄 대기열이 지워지지 않으면 스풀 폴더 수동 정리

대기열에서 문서를 취소하고 스풀러도 다시 시작했는데 같은 작업이 계속 멈춘다면 Microsoft는 스풀러를 중지한 뒤 대기 중인 인쇄 파일을 수동으로 제거하는 절차를 안내합니다.

이는 일반적인 '파일 삭제'보다 영향이 크므로 앞선 간단한 방법이 실패했을 때만 진행하세요.

스풀 폴더 수동 정리 순서

  1. 지금 다른 사용자가 프린터를 사용 중이지 않은지 확인합니다.
  2. 필요한 경우 아직 출력되지 않은 문서의 원본을 별도로 저장합니다.
  3. **Windows 키 + R → services.msc**를 입력합니다.
  4. 인쇄 스풀러를 오른쪽 클릭하고 중지를 선택합니다.
  5. 파일 탐색기를 엽니다.
  6. 주소 표시줄에 아래 경로를 입력합니다.
C:\Windows\System32\spool\PRINTERS
  1. PRINTERS 폴더 안의 대기열 관련 파일만 삭제합니다.
  2. 폴더 자체 또는 다른 상위 Windows 폴더를 삭제하지 않습니다.
  3. 다시 서비스 → 인쇄 스풀러로 돌아갑니다.
  4. 시작을 누릅니다.
  5. 프린터 대기열이 비었는지 확인합니다.
  6. 필요한 문서를 원본 파일에서 새로 인쇄합니다.

폴더에 접근할 수 없다고 표시되면?

관리자 권한이 필요할 수 있습니다. 해당 PC의 소유자·관리자 권한이 있는지 확인하고, 회사 정책이 적용된 컴퓨터에서는 관리자에게 요청하세요.

왜 이 단계가 위험한가요?

스풀 폴더 안의 대기 중인 인쇄 데이터가 삭제되면 출력되지 않은 문서를 다시 보내야 할 수 있습니다. 특히 공용 인쇄 서버에서 처리하면 여러 사용자 작업에 영향을 줄 수 있습니다.

절대 금지: 인터넷 게시글의 명령을 그대로 복사해 Windows 시스템 폴더 전체를 삭제하거나 스풀러 관련 보안 설정을 끄지 마세요. Microsoft의 공식 안내는 인쇄 스풀러를 중지하고, 지정된 PRINTERS 폴더 안의 파일을 삭제하고, 스풀러를 다시 시작하는 절차입니다.

8. Windows 11 '도움말 보기' 프린터 문제 해결사 실행

Windows 11에는 Microsoft가 안내하는 프린터 자동 문제 해결사가 있습니다. PC 설정을 직접 많이 바꾸기 전에 공식 도구로 진단할 수 있습니다.

도움말 보기(Get Help) 실행

  1. 시작 메뉴를 엽니다.
  2. 검색창에 도움말 보기를 입력합니다.
  3. Microsoft 도움말 보기(Get Help) 앱을 실행합니다.
  4. 검색창이나 관련 화면에서 프린터 문제 해결을 선택합니다.
  5. 현재 인쇄되지 않는 프린터를 선택하라는 안내가 나오면 해당 장치를 확인합니다.
  6. 자동 진단이 안내하는 절차를 수행합니다.
  7. 오류 코드와 해결 결과를 기록합니다.
  8. 프린터와 PC를 다시 연결해 인쇄 여부를 확인합니다.

Microsoft는 Windows 11에서 도움말 보기 기반 자동 프린터 문제 해결사를 우선 시도하도록 안내합니다.

'기타 문제 해결사' 메뉴가 보이지 않는다면?

인터넷에는 Windows 10의 구형 문제 해결사 경로가 혼합돼 있을 수 있습니다. Windows 11 버전과 업데이트 상태에 따라 메뉴가 다르므로 현재 제공되는 도움말 보기 경로를 사용하는 것이 좋습니다.

해결사가 문제를 못 찾는다면?

문제 해결사가 '문제 없음'이라고 표시하더라도 프린터 전원·Wi-Fi 연결·실제 대기열·드라이버에 문제가 없다는 뜻은 아닙니다. 테스트 결과를 토대로 다음 항목을 계속 점검하세요.

9. 무선 프린터 연결 안 될 때: PC와 동일한 Wi-Fi 확인

Wi-Fi 프린터가 오프라인이거나 장치 검색에 나타나지 않을 때는 PC와 프린터가 실제로 같은 네트워크에 연결돼 있는지 확인해야 합니다.

같은 공유기를 사용한다고 같은 네트워크일까요?

반드시 그렇지는 않습니다. 집에서 일반 Wi-Fi와 게스트 Wi-Fi를 분리했거나, 여러 공유기·확장기·SSID를 사용한다면 서로 다른 네트워크로 연결돼 프린터가 검색되지 않을 수 있습니다.

Microsoft는 Wi-Fi 프린터를 추가하려면 프린터와 Windows PC가 동일한 무선 네트워크에 연결돼 있어야 한다고 공식적으로 안내합니다.

무선 연결 확인 절차

  1. 프린터 자체의 설정 또는 네트워크 메뉴를 엽니다.
  2. 현재 연결된 Wi-Fi 네트워크 이름을 확인합니다.
  3. Windows 11에서 설정 → 네트워크 및 인터넷 → Wi-Fi를 엽니다.
  4. PC가 연결된 Wi-Fi 이름을 확인합니다.
  5. 프린터와 PC가 동일한 로컬 네트워크에 있는지 비교합니다.
  6. 프린터가 네트워크를 잃어버렸다면 제조사 공식 무선 설정 절차로 다시 연결합니다.
  7. Windows에서 프린터 및 스캐너 → 장치 추가를 다시 실행합니다.

공유기 교체·비밀번호 변경 후 연결 안 되는 이유

프린터에 이전 공유기의 SSID·암호가 저장돼 있으면 새 Wi-Fi에 자동 연결되지 않을 수 있습니다. 이런 경우에는 Windows가 아니라 프린터 본체의 무선 연결 설정을 다시 진행해야 합니다.

2.4GHz·5GHz는 꼭 같아야 하나요?

프린터와 PC가 동일한 로컬 네트워크에서 서로 통신할 수 있다면 서로 다른 주파수 대역을 사용하더라도 연결될 수 있습니다. 하지만 공유기의 격리 기능·게스트 네트워크 정책이나 프린터 지원 대역에 따라 문제가 발생할 수 있습니다.

'2.4GHz와 5GHz가 다르니까 무조건 인쇄가 안 된다'는 설명은 정확하지 않습니다. 네트워크 구성과 프린터의 실제 연결 상태를 확인하세요.

10. Windows 11에 프린터 다시 추가하는 방법: USB·Wi-Fi 구분

새로 산 프린터가 Windows에 나타나지 않거나 제거한 프린터를 다시 설치하려면 Windows 11의 장치 추가를 이용할 수 있습니다.

무선·네트워크 프린터 추가

  1. 프린터 전원을 켭니다.
  2. 프린터가 PC와 동일한 네트워크에 연결됐는지 확인합니다.
  3. Windows 11에서 설정 → Bluetooth 및 장치 → 프린터 및 스캐너로 이동합니다.
  4. 프린터 또는 스캐너 추가 옆의 장치 추가를 누릅니다.
  5. Windows가 주변 장치를 검색할 때까지 기다립니다.
  6. 목록에서 해당 프린터 모델을 선택합니다.
  7. 장치 추가를 눌러 설치를 진행합니다.
  8. 설치 뒤 간단한 문서를 인쇄해 봅니다.

목록에 없는 프린터를 수동으로 추가

  1. 같은 화면에서 장치 검색을 실행합니다.
  2. 검색해도 원하는 장치가 나타나지 않는지 확인합니다.
  3. 원하는 프린터가 목록에 없음 또는 수동으로 추가를 선택합니다.
  4. 프린터 모델과 연결 방식에 맞는 선택지를 고릅니다.
  5. 제조사의 설치 안내와 Windows 화면 지침을 따릅니다.

수동 설치에서 IP 주소, 호스트 이름, 포트 등을 요구한다면 공유기나 프린터의 실제 설정값을 확인하세요. 인터넷 예시에 나온 임의 IP를 입력하면 연결되지 않을 수 있습니다.

USB 프린터 재연결

  1. Windows PC와 프린터가 정상 작동 중인지 확인합니다.
  2. USB 케이블을 프린터와 PC에 연결합니다.
  3. 가능하다면 다른 USB 포트로도 비교합니다.
  4. Windows가 자동으로 프린터를 설치하는지 확인합니다.
  5. 자동 설치되지 않으면 프린터 및 스캐너 → 장치 추가를 이용합니다.

Microsoft는 대부분의 프린터가 USB 연결 후 자동 설치될 수 있으며, 별도 프린터 드라이버가 필요한 경우 Windows 업데이트·제조사 제공 자료를 확인하도록 안내합니다.

무조건 삭제했다가 다시 설치해야 할까요?

그럴 필요는 없습니다. 기본 프린터 선택 오류나 멈춘 대기열 문제는 이미 설치된 프린터를 제거하지 않고도 해결할 수 있습니다. 새로 설치하기 전에는 앞선 단계를 먼저 확인하세요.

11. 기본 프린터가 자꾸 바뀌는 문제: Windows 자동 관리 해제

집에서 PDF를 저장한 뒤 회사로 이동해 인쇄했더니 기본 프린터가 다른 장치로 바뀌는 문제가 생길 수 있습니다.

Microsoft에 따르면 Windows는 마지막으로 사용한 프린터를 기본 프린터로 자동 설정하도록 구성할 수 있습니다. 사용자가 원치 않는다면 수동으로 고정할 수 있습니다.

기본 프린터 고정

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. Bluetooth 및 장치 → 프린터 및 스캐너로 들어갑니다.
  3. 프린터 기본 설정 아래의 Windows에서 내 기본 프린터를 관리하도록 허용을 찾습니다.
  4. 해당 설정을 끔으로 바꿉니다.
  5. 원하는 프린터를 선택합니다.
  6. 기본값으로 설정을 누릅니다.
  7. 다른 앱에서 인쇄 버튼을 누른 뒤 실제 기본 프린터를 확인합니다.

PDF로만 저장되는 경우

프린터 선택창에서 Microsoft Print to PDF를 선택하면 실제 종이에 인쇄하는 대신 PDF로 저장할 수 있습니다. 원래 프린터가 사라졌거나 기본값이 변경됐다면 원하는 물리 프린터를 다시 선택하세요.

기본값 변경과 오프라인 문제의 차이

기본 프린터를 바꾸더라도 원래 프린터의 네트워크 연결이나 스풀러 오류가 자동 해결되는 것은 아닙니다. 출력 대상이 잘못 선택된 상황에서 유효한 조치라는 점을 기억하세요.

12. 사무실 공유 프린터 연결 안 됨: 호스트 PC·네트워크 공유 확인

사무실에서 다른 직원은 잘 출력하는데 내 컴퓨터에서만 공유 프린터가 안 보이거나 접근 거부가 나타날 수 있습니다.

Windows 공유 프린터는 프린터가 연결된 호스트 PC, 네트워크 연결, 공유 권한, 장치별 드라이버에 영향을 받습니다.

먼저 확인할 네 가지

  • 프린터가 연결된 호스트 PC가 켜져 있는가?
  • 호스트 PC에서 해당 프린터가 실제로 인쇄되는가?
  • 내 PC와 호스트 PC가 동일한 회사 네트워크에 있는가?
  • 공유 프린터 접속에 필요한 계정 인증·자격 증명이 있는가?

호스트 PC 공유 설정 확인

  1. 공유 프린터를 실제로 연결한 호스트 PC에서 Windows 설정을 엽니다.
  2. Bluetooth 및 장치 → 프린터 및 스캐너를 선택합니다.
  3. 공유하려는 프린터를 선택합니다.
  4. 프린터 속성을 엽니다.
  5. 공유 탭을 누릅니다.
  6. 이 프린터 공유가 활성화돼 있는지 확인합니다.
  7. 표시되는 공유 이름을 기록합니다.

네트워크 검색 및 파일·프린터 공유

Microsoft 공식 절차에서는 설정 → 네트워크 및 인터넷 → 고급 네트워크 설정 → 고급 공유 설정에서 네트워크 검색과 파일 및 프린터 공유를 확인합니다.

보안 주의: 공용 Wi-Fi나 외부 네트워크에서 누구나 접근하도록 공유 설정을 무조건 켜면 안 됩니다. 회사의 신뢰할 수 있는 네트워크 정책과 관리자 지침을 따라야 합니다.

공유 프린터 수동 추가

  1. 클라이언트 Windows PC에서 프린터 및 스캐너 → 장치 추가로 이동합니다.
  2. 자동 검색되지 않으면 수동으로 추가를 선택합니다.
  3. 이름으로 공유 프린터 선택을 선택합니다.
  4. 아래 형태의 공유 경로를 정확하게 입력합니다.
\\ComputerName\PrinterShareName
  1. 요구되는 경우 호스트 PC 계정 자격 증명을 입력합니다.
  2. 추가한 뒤 테스트 인쇄를 진행합니다.

위의 PC 이름·프린터 이름은 예시이며 실제 공유 호스트와 공유 이름을 사용해야 합니다.

관리자 승인 없이 해결하려 하지 마세요

회사 PC에서는 보안 업데이트·서버 정책·드라이버 호환성에 따라 공유 연결이 제한될 수 있습니다. 인터넷에서 확인되지 않은 레지스트리 우회, 암호 없는 공유 강제 활성화, 방화벽 전체 해제는 권장하지 않습니다.

13. 프린터 드라이버 업데이트·재설치: 모델과 Windows 버전 확인

프린터는 목록에 나타나지만 실제 인쇄가 실패하거나, Windows 업데이트 뒤부터 '드라이버를 사용할 수 없음'이 표시될 수 있습니다.

Microsoft는 오래되거나 호환되지 않는 드라이버를 프린터 인식·인쇄 문제의 가능한 원인으로 설명합니다.

드라이버 점검 순서

  1. 프린터 본체 또는 제조사 안내에서 정확한 모델명을 확인합니다.
  2. 설정 → Windows 업데이트 → 업데이트 확인을 실행합니다.
  3. Windows 설정에서 프린터 및 스캐너에 장치가 등록돼 있는지 확인합니다.
  4. 장치 관리자를 열고 프린터 또는 인쇄 대기열 범주의 오류 표시를 확인합니다.
  5. 해당 프린터를 오른쪽 클릭해 드라이버 업데이트가 가능한지 살펴봅니다.
  6. 추가 드라이버가 필요하다면 제조사 공식 지원 사이트에서 모델·Windows 11 버전·시스템 종류와 호환되는 설치 파일을 찾습니다.
  7. 제조사의 공식 지침에 따라 설치하고 PC를 다시 시작합니다.

프린터 드라이버를 모두 삭제해도 되나요?

권장하지 않습니다. 현재 사용 중인 프린터뿐 아니라 다른 프린터와 연결된 드라이버까지 영향을 받을 수 있고, 프린터 공유 서버라면 다른 사용자의 출력에도 문제가 생길 수 있습니다.

문제가 특정 모델에 한정됐다면 그 모델의 연결·드라이버부터 점검하세요. 제조사 공식 드라이버를 확보하지 않은 상태에서 기존 드라이버를 제거하면 정상 상태로 복구하기 어려워질 수 있습니다.

제조사의 오래된 드라이버를 써도 될까요?

Microsoft는 지원되지 않는 Windows 버전용 드라이버를 임의로 사용하는 것을 주의하도록 안내합니다. 모델이 오래돼 Windows 11 공식 드라이버가 없다면 제조사의 호환성 안내와 Windows 기본 프린터 지원 범위를 확인하세요.

제조사 사이트와 자동 드라이버 광고 구분

인터넷 검색 광고에 등장하는 '프린터 드라이버 한 번에 복구' 프로그램이 반드시 공식 제품은 아닙니다. 제조사의 실제 도메인·지원 페이지에서 설치 파일의 출처를 확인하는 편이 안전합니다.

14. Copilot+ PC에서 프린터 설치 오류: ARM 장치 예외 확인

최근 출시된 일부 Windows 11 Copilot+ PC는 Intel·AMD가 아닌 ARM 기반 프로세서를 사용할 수 있습니다. 이 경우 설치 프로그램을 실행했는데 프린터가 추가되지 않는 문제가 발생할 수 있습니다.

Microsoft가 안내한 사항

Microsoft는 일부 ARM PC에서 프린터 제조사가 제공한 설치 관리자를 사용하면 프린터를 추가하거나 설치할 수 없는 문제가 있다고 공식 안내합니다.

따라서 해당 조건에 부합한다면 제조사 설치 프로그램을 반복 실행하기보다 Windows 자체의 '장치 추가' 경로를 이용하는 방법이 있습니다. 단, 제조사가 별도의 ARM용 공식 절차를 안내한다면 그 지침을 우선 확인하세요.

내 PC가 ARM 기반인지 확인

  1. 설정 → 시스템 → 정보로 이동합니다.
  2. 장치 사양을 찾습니다.
  3. 시스템 유형을 확인합니다.
  4. ARM 기반 프로세서라고 표시되는지 살펴봅니다.

ARM 기반 PC의 프린터 추가

  1. 프린터 전원을 켜고 USB 또는 무선 네트워크에 연결합니다.
  2. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너로 이동합니다.
  3. 장치 추가를 누릅니다.
  4. 검색된 프린터를 선택하거나 공식 수동 추가 절차를 진행합니다.
  5. Windows가 프린터를 설치한 뒤 간단한 출력으로 확인합니다.

ARM PC라면 모든 프린터를 사용할 수 없나요?

그렇지는 않습니다. Windows가 지원하는 프린터는 별도 제조사 설치 프로그램 없이도 추가될 수 있습니다. 특정 설치 프로그램이 작동하지 않는 것과 그 프린터 자체를 사용할 수 없는 것은 다른 문제입니다.

주의: 호환성이 확인되지 않은 x64 드라이버를 강제로 설치하거나 보안 설정을 낮추는 방법은 피하세요. 제조사·Microsoft 공식 지원 조건을 확인해야 합니다.

15. Word·Excel·PDF 중 특정 앱에서만 인쇄 안 될 때

Windows의 프린터 테스트는 정상인데 Word·Excel·브라우저에서만 문서가 출력되지 않는다면 개별 앱의 인쇄 설정이나 문서 자체를 확인해야 합니다.

비교 테스트

  1. Windows에서 프린터 설정을 열어 대상 장치가 정상 상태인지 확인합니다.
  2. 다른 앱에서 간단한 한 페이지 문서를 인쇄해 봅니다.
  3. 문제가 발생한 앱에서 Ctrl + P로 인쇄 창을 엽니다.
  4. 실제 프린터 이름이 올바른지 확인합니다.
  5. 용지 크기·방향·인쇄 범위·부수·컬러/흑백 설정을 살펴봅니다.
  6. 가능하다면 동일 파일을 PDF로 저장한 뒤 인쇄 가능 여부를 비교합니다.
  7. 특정 앱만 실패한다면 앱 업데이트·문서 손상·추가 기능의 영향을 점검합니다.

Word에서는 되는데 PDF만 안 되나요?

PDF 파일이 비밀번호로 보호돼 있거나 앱에서 인쇄 권한이 제한된 문서일 수 있습니다. 문서의 사용 권한과 앱의 실제 오류 메시지를 확인하세요.

PDF에서 고해상도 이미지가 많거나 인쇄 범위가 복잡하다면 처리 시간이 길어질 수도 있습니다.

Excel에서 일부 페이지만 출력되는 경우

인쇄 영역·선택한 시트·페이지 배율이 특정 범위로 설정됐을 수 있습니다. 인쇄 미리보기와 실제 페이지 수를 확인하세요. 프린터 자체의 오프라인 상태와는 별개의 문제일 수 있습니다.

테스트 페이지가 정상이라면?

프린터 하드웨어가 기본적으로 인쇄할 수 있다는 참고 자료가 됩니다. 그러나 특정 앱·드라이버·용지 설정 문제가 없다는 보장까지 되는 것은 아닙니다.

16. 출력은 되는데 느리거나 흐릿하면 다른 문제입니다

프린터가 종이를 출력하긴 하지만 너무 느리거나 글자가 흐리고 줄무늬가 생기는 문제라면 연결 복구와 다른 점검이 필요합니다.

인쇄 속도가 너무 느릴 때

  1. 용지 종류와 출력 품질이 필요 이상으로 높게 설정됐는지 확인합니다.
  2. 고해상도 사진이 많이 들어 있는 문서인지 살펴봅니다.
  3. Wi-Fi 프린터라면 네트워크 신호가 안정적인지 확인합니다.
  4. 제조사의 공식 펌웨어 업데이트를 검토합니다.
  5. 대용량 파일이 원인으로 의심된다면 문서 용량과 인쇄 설정을 점검합니다.

Microsoft는 인쇄 품질·용지 설정, 네트워크 지연, 문서 복잡성, 펌웨어 상태를 느린 인쇄의 점검 항목으로 안내합니다.

인쇄가 흐릿하거나 색이 빠졌다면

  1. 프린터의 잉크·토너 잔량과 카트리지 상태를 확인합니다.
  2. 용지 걸림이나 이물질이 없는지 살펴봅니다.
  3. 프린터 본체에서 자체 테스트 페이지를 출력할 수 있는지 확인합니다.
  4. 테스트 출력도 흐릿하다면 프린터 헤드·토너·정착기 등 기기 자체의 상태를 제조사 안내에 따라 점검합니다.
  5. 본체 테스트는 정상이지만 특정 앱에서만 흐리다면 Windows 인쇄 기본 설정의 품질·용지 종류를 확인합니다.

계속 스풀러를 재시작해도 해결되나요?

인쇄 스풀러는 출력 작업의 처리 상태를 관리하는 서비스입니다. 토너가 부족하거나 용지가 잘못 들어간 물리적 문제까지 해결하는 기능은 아닙니다.

주의: 레이저 프린터 내부의 정착기 등은 뜨거울 수 있습니다. 제조사의 안전 지침 없이 내부 부품을 만지거나 분해하지 마세요.

17. 복구 후 테스트 인쇄와 재발 방지 확인

문제가 해결됐다고 생각될 때는 인쇄 테스트와 설정 점검을 해서 동일한 문제가 재발하는지 확인하는 것이 좋습니다.

간단한 확인 순서

  1. Windows의 프린터 및 스캐너에서 프린터 이름이 정확히 표시되는지 확인합니다.
  2. 인쇄 대기열에 이전 작업이 남아 있는지 확인합니다.
  3. 시험용 한 페이지 문서를 열어 Ctrl + P를 누릅니다.
  4. 문서의 인쇄 대상이 실제 프린터인지 확인합니다.
  5. 한 부만 인쇄하도록 설정합니다.
  6. 출력이 정상 완료되고 대기열에서 작업이 사라지는지 확인합니다.
  7. 프린터를 껐다 켠 뒤에도 연결이 유지되는지 확인합니다.

반복되는 오류의 기록을 남기세요

특정 시간에만 문제가 생긴다면 프린터 모델, Windows 버전, 연결 방식, 오류 표시, 중단된 작업 이름과 발생 시각을 기록하세요.

네트워크 공유 프린터는 사내 서버나 보안 정책이 원인일 수 있고, USB 프린터는 특정 케이블·포트에서만 문제가 발생할 수 있습니다. 오류 기록은 원인을 구분하고 공식 지원을 받을 때 유용합니다.

인쇄 비용 낭비도 막으세요

인쇄 오류가 계속된다며 인쇄 버튼을 반복 누르면 복구 후 같은 문서가 여러 장 출력될 수 있습니다. 작업을 새로 보내기 전 인쇄 큐를 확인하세요.

자주 묻는 질문 FAQ

Q1. 윈도우11 프린터가 오프라인으로 표시되면 가장 먼저 무엇을 해야 하나요?

프린터 전원·용지·오류 표시, USB 연결 또는 PC와 동일한 Wi-Fi 사용 여부를 확인하세요. 프린터가 정상 연결돼 있는데도 오프라인이라면 설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 상태와 대기열을 점검하고 Windows 도움말 보기 문제 해결사를 실행하세요.

Q2. Windows 11에서 인쇄 대기열은 어디서 확인하나요?

설정 → Bluetooth 및 장치 → 프린터 및 스캐너 → 해당 프린터 → 인쇄 큐 열기에서 확인할 수 있습니다. 오래 멈춘 문서가 있다면 해당 작업을 선택한 뒤 취소하세요. 공용 프린터라면 다른 사용자의 출력 작업을 임의로 취소하지 않아야 합니다.

Q3. 인쇄 대기열 문서가 '삭제 중'에서 멈출 때 어떻게 하나요?

먼저 Windows 키 + R → services.msc → 인쇄 스풀러 → 다시 시작을 시도하세요. 그래도 대기열이 정리되지 않는다면 Microsoft 공식 안내에 따라 스풀러를 중지한 뒤 C:\Windows\System32\spool\PRINTERS 폴더 안의 대기열 파일만 삭제하고 스풀러를 다시 시작할 수 있습니다. 기존 인쇄 작업은 사라질 수 있습니다.

Q4. 인쇄 스풀러를 다시 시작하면 저장한 Word·PDF 파일이 삭제되나요?

일반적으로 인쇄 스풀러 서비스 재시작은 원본 문서를 삭제하는 작업이 아닙니다. 다만 기존에 대기 중이던 출력 작업을 다시 전송해야 할 수 있고, 스풀 폴더의 대기열 파일을 직접 삭제하면 해당 인쇄 작업은 지워집니다. 원본 문서는 별도로 저장해 두세요.

Q5. 무선 프린터가 Windows 11에서 검색되지 않는 이유는?

프린터가 공유기와 연결되지 않았거나, PC와 프린터가 서로 다른 게스트 Wi-Fi·격리된 네트워크에 있을 수 있습니다. 프린터 본체에서 네트워크 이름을 확인하고 Windows의 프린터 및 스캐너 → 장치 추가를 다시 실행하세요. 제조사 공식 무선 연결 설명도 확인해야 합니다.

Q6. 프린터를 기본값으로 설정하는 버튼이 안 보입니다

설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 **'Windows에서 내 기본 프린터를 관리하도록 허용'**을 끈 뒤 원하는 프린터를 선택하세요. 이 옵션을 끄면 기본값으로 설정 버튼을 이용해 원하는 프린터를 고정할 수 있습니다.

Q7. 회사 공유 프린터가 연결되지 않을 때는 어떻게 해야 하나요?

호스트 PC 전원과 프린터 공유 상태, 동일한 네트워크, 사용자 자격 증명을 확인해야 합니다. Microsoft는 네트워크 검색·파일 및 프린터 공유 확인과 공유 경로 **\\ComputerName\PrinterShareName**를 통한 수동 추가를 안내합니다. 회사의 보안 정책을 임의로 변경하지 말고 IT 관리자에게 문의하세요.

Q8. 프린터 드라이버를 모두 삭제하고 다시 설치하면 해결되나요?

무조건 그렇지는 않습니다. 전원·네트워크·기본 프린터·대기열 문제라면 드라이버와 관계없을 수 있습니다. 드라이버 오류가 의심되면 정확한 모델명을 확인해 Windows 업데이트 또는 프린터 제조사 공식 지원 사이트의 호환 드라이버를 이용하세요.

Q9. Copilot+ PC에서 프린터 제조사 설치 프로그램이 작동하지 않습니다

Microsoft는 일부 ARM 기반 Windows PC에서 프린터 제조사 설치 관리자가 설치에 실패할 수 있다고 안내합니다. 이때 설정 → Bluetooth 및 장치 → 프린터 및 스캐너 → 장치 추가를 통한 Windows 설치 경로를 우선 시도하고, 제조사의 ARM용 별도 지침이 있다면 확인하세요.

Q10. 프린터는 인쇄되는데 글씨가 흐리거나 너무 느린 이유는?

이 경우는 인쇄 대기열보다 잉크·토너·용지·품질 설정·네트워크 속도 등을 확인할 필요가 있습니다. 프린터 자체 테스트 페이지를 출력해 Windows 또는 하드웨어 문제인지 구분하세요. 고해상도 인쇄 설정·대용량 문서도 속도를 늦출 수 있습니다.

출력 오류 해결 전후 체크리스트

프린터가 아예 인쇄되지 않을 때

  • 프린터 전원·용지·토너·덮개·오류 메시지를 확인했나요?
  • USB 케이블 또는 Wi-Fi 연결 상태를 점검했나요?
  • 무선 프린터와 PC가 동일한 로컬 네트워크에 있나요?
  • Windows에서 올바른 기본 프린터를 선택했나요?
  • 프린터 인쇄 대기열에서 멈춘 작업을 확인했나요?
  • 도움말 보기 프린터 문제 해결사를 실행했나요?
  • 인쇄 스풀러 서비스 재시작을 시도했나요?

재설치·수동 삭제 전에

  • 아직 출력되지 않은 원본 문서를 저장했나요?
  • 프린터를 다른 사람이 사용 중이지 않나요?
  • 스풀 폴더 정리 시 대기 중인 인쇄 작업이 삭제될 수 있음을 이해했나요?
  • 드라이버 제거 전 제조사 공식 복구·설치 파일을 준비했나요?
  • 회사 관리 장비라면 관리자 승인을 받았나요?
  • ARM 기반 PC라면 Windows 자체 프린터 추가 기능을 검토했나요?

문제가 해결됐다면

  • 테스트 문서 한 부가 정상 출력됐나요?
  • 인쇄 대기열에 중복 작업이 남아 있지 않나요?
  • 프린터 전원을 다시 켠 뒤에도 연결이 유지되나요?
  • 실제 사용 앱에서 올바른 출력 대상을 지정했나요?

마무리: 대기열부터 확인하고, 스풀러 파일 삭제는 마지막에 하세요

Windows 11에서 프린터가 오프라인으로 표시되거나 인쇄가 안 될 때 가장 중요한 것은 원인을 작은 범위부터 좁히는 것입니다. USB·무선 연결이 문제인지, 기본 프린터가 잘못 선택됐는지, 인쇄 대기열이 멈춘 것인지 먼저 확인하세요.

기존 작업을 취소해도 해결되지 않으면 인쇄 스풀러 서비스 재시작을 시도할 수 있습니다. 스풀 폴더 수동 삭제는 Microsoft가 제공하는 공식 해결책이지만, 대기 중인 작업을 지우고 공동 프린터에도 영향을 줄 수 있으므로 다른 방법이 실패했을 때만 진행해야 합니다.

무선 프린터는 동일한 네트워크 연결, 공유 프린터는 호스트 PC와 권한, 드라이버 문제는 제조사 공식 호환성을 확인하는 것이 좋습니다. 복구 후에는 테스트 문서 한 부를 인쇄하고 대기열을 다시 살펴보면 같은 문서가 중복 출력되는 것도 예방할 수 있습니다.
