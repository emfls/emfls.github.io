1. '내 명의 보호' 기능이 새로 생긴 이유

본인인증 과정에서는 특정 카카오계정에 이용자의 실명 기반 본인인증 정보가 연결됩니다. 자신이 사용하지 않는 다른 계정에 내 명의가 등록되는 시도가 있다면 본인이 직접 확인할 기회가 필요합니다.

카카오 공식 보도자료에 따르면 '내 명의 보호'는 이미 동일한 명의가 등록된 카카오계정을 통해 추가 인증을 거치게 하는 방식입니다. 새로운 등록을 요청한 사람이 정말 명의자인지 기존 계정에서 한 번 더 확인할 수 있도록 설계됐습니다.

예를 들어 본인이 사용하지 않는 다른 카카오계정에 내 명의로 본인인증 정보를 등록하려는 요청이 발생했을 때, 보호 절차가 적용된다면 기존 계정의 카카오톡 메시지 또는 이메일을 통해 인증이 요구됩니다. 본인이 요청하지 않은 것이라면 승인하지 않는 것이 원칙입니다.

여기서 말하는 '명의 등록'과 '계정 로그인'은 다릅니다. 계정 로그인은 이메일·비밀번호 또는 다른 로그인 수단을 이용해 이미 존재하는 계정에 접근하는 과정이고, 본인인증 정보 등록은 계정에 실명 인증 정보를 새로 연결하는 절차입니다. 이 차이를 기억해야 계정 보안을 올바르게 관리할 수 있습니다.

2. 카카오톡 앱에서 '내 명의 보호' 설정하는 방법

카카오는 모바일 카카오톡의 카카오계정 → 계정보안 메뉴에서 기능을 설정·해제할 수 있다고 공식 안내했습니다.

스마트폰에서 따라 하는 순서

  1. 카카오톡 앱을 실행하고 본인이 사용하는 카카오계정에 로그인되어 있는지 확인합니다.
  2. 카카오톡 설정 화면을 엽니다. 앱의 메뉴 구성에 따라 더보기 탭 또는 프로필·설정 버튼을 거쳐 이동할 수 있습니다.
  3. '카카오계정' 메뉴로 들어갑니다.
  4. '계정보안' 항목을 선택합니다.
  5. '내 명의 보호'를 찾습니다.
  6. 화면에 안내되는 활성화 과정과 필요한 본인 확인 절차를 완료합니다.
  7. 설정 화면으로 다시 돌아와 기능의 현재 상태를 확인합니다.

이 경로 중 카카오계정 → 계정보안 → 내 명의 보호는 카카오의 공식 발표로 확인된 경로입니다. 마지막 활성화 화면의 버튼 배치, 추가 확인 단계와 기본 설정 상태는 계정·앱 버전에 따라 차이가 있을 수 있으므로 실제 화면 안내를 따르세요.

'설정을 켜면 이제 명의 도용은 무조건 막힌다'고 단정할 수는 없습니다. 이 기능은 카카오가 설명한 본인인증 정보 신규 등록 절차에 대한 추가 보호입니다. 비밀번호 유출, 피싱 사이트 접속, 악성 앱 설치를 대신 막아주는 기능으로 보아서는 안 됩니다.

공식 출처: 카카오 '내 명의 보호' 발표

3. PC·모바일 웹에서 설정하는 방법

스마트폰 앱에서 해당 메뉴를 찾기 어려운 경우 카카오계정 홈페이지에서도 이용할 수 있다고 안내되어 있습니다.

  1. 브라우저 주소창에 카카오계정 공식 홈페이지를 입력해 접속합니다.
  2. 본인 카카오계정으로 로그인합니다.
  3. 계정 관리 화면에서 '계정보안' 메뉴를 찾습니다.
  4. '내 명의 보호'를 선택합니다.
  5. 필요한 안내와 본인 확인 절차를 완료하고 상태를 다시 확인합니다.

직접 주소를 입력하는 이유는 피싱 사이트 때문입니다. 검색 광고나 문자 메시지에 포함된 링크를 무조건 눌러 인증번호를 입력하면 가짜 페이지에서 계정 정보를 탈취당할 수 있습니다. 되도록 자주 쓰는 공식 사이트를 북마크해서 접속하세요.

카카오는 앱과 카카오계정 홈페이지 양쪽에서 설정과 해제가 가능하다고 설명했지만, 모든 화면의 버튼 명칭과 배치까지 공식 보도자료에 공개한 것은 아닙니다. 특정 메뉴가 바로 보이지 않는다면 앱 업데이트, 로그인 계정, 계정의 본인인증 정보 상태를 먼저 확인하고 카카오 고객센터의 최신 안내를 참고하세요.

4. 내 명의 등록 인증 요청이 오면 무엇을 해야 하나요?

카카오의 공식 설명에 따르면 추가 인증은 다음 두 방식으로 진행될 수 있습니다.

  • 카카오톡 메시지 확인: 같은 명의가 등록된 기존 카카오계정으로 전달된 메시지에서 '허용하기'를 선택
  • 이메일 인증: 같은 기존 계정의 이메일로 전달된 인증번호 입력

중요한 것은 모든 알림에 허용을 누르는 것이 아니라 내가 직접 시작한 본인인증 절차인지 확인하는 것입니다.

본인이 새 카카오계정에 명의를 등록하는 중이라면

먼저 본인이 직접 새 계정의 본인인증을 시작했는지 확인합니다. 기존 카카오계정으로 전송된 안내가 실제로 자신이 진행 중인 절차와 관련된 것인지 살펴보고, 일치할 때에만 카카오가 제공하는 공식 화면에서 인증을 진행하세요. 인증번호는 다른 사람에게 읽어주거나 메신저로 전달하지 않는 것이 안전합니다.

신청한 적 없는 인증 요청이라면

자신이 시작한 적 없는 명의 등록 요청은 허용하지 마세요. 링크가 들어 있다면 무심코 열지 말고, 카카오톡 앱이나 공식 카카오계정 홈페이지로 직접 이동해 계정 상태를 확인합니다.

실수로 승인했거나 계정이 침해되었다고 의심된다면 비밀번호 변경, 2단계 인증 점검, 카카오 고객센터 문의를 우선 검토하세요. 다만 안내 메시지를 받았다는 사실만으로 명의도용이 확정됐다고 판단할 수는 없습니다. 어느 계정과 절차에서 요청이 발생했는지는 공식 지원을 통해 확인해야 합니다.

5. '내 명의 보호'와 2단계 인증, 무엇이 다른가요?

두 기능은 서로 대체제가 아니라 보완 관계에 있습니다.

'내 명의 보호'가 다루는 상황

다른 카카오계정에 내 명의의 본인인증 정보를 새로 등록하려 할 때, 같은 명의가 등록된 기존 계정에서 추가 확인이 필요하도록 하는 장치입니다. 실제 적용 조건과 인증 방법은 카카오의 서비스 정책과 계정 상황에 따라 확인해야 합니다.

'2단계 인증'이 다루는 상황

기존 카카오계정에 로그인할 때 계정 ID와 비밀번호 외에 추가 인증을 요구하는 장치입니다. 카카오는 비밀번호가 다른 사람에게 알려지더라도 추가 인증 없이 로그인을 마칠 수 없게 하는 보안 기능이라고 설명합니다.

카카오톡의 공식 2단계 인증 설정 경로는 설정 → 카카오계정 → 2단계 인증입니다. 계정 복구를 위해 비상 연락용 이메일을 등록할 수도 있다고 안내합니다. 두 기능의 설정 여부를 함께 확인하면 서로 다른 위험에 대비할 수 있습니다.

6. 카카오계정 보안을 강화하는 실천 방법 5가지

1) 2단계 인증 켜기

카카오톡 설정의 카카오계정에서 2단계 인증을 찾아 활성화합니다. 인증 수단은 자신이 실제로 사용할 수 있는 전화번호 또는 제공되는 방식으로 등록하세요. 번호를 변경하거나 기기를 분실했을 때를 대비해 복구 수단도 점검하는 것이 좋습니다.

2) 다른 사이트와 같은 비밀번호를 사용하지 않기

카카오 공식 안전 가이드는 다른 서비스에서 유출된 비밀번호를 카카오계정에도 똑같이 사용하는 것을 경고합니다. 특히 오래전에 여러 사이트에 가입하며 재사용한 비밀번호라면 새롭고 고유한 비밀번호로 바꾸는 편이 좋습니다.

설정 경로는 설정 → 카카오계정 → 계정 비밀번호 변경입니다. '안전해 보이는 복잡한 비밀번호 하나'를 여러 사이트에 공통 사용하기보다는 계정별로 다른 비밀번호를 사용하는 것이 중요합니다.

공식 출처: 카카오톡 안전 도구 - 비밀번호 변경

3) 인증번호는 요청한 본인만 입력하기

카카오 명의 등록 알림뿐 아니라 각종 문자·이메일 인증번호도 마찬가지입니다. '고객센터 직원', '친구', '가족'을 사칭한 사람이 인증번호를 요구할 수 있으므로 공유하지 않는 것이 안전합니다. 갑작스러운 인증 알림이 왔다면 먼저 자신이 요청한 것이 맞는지 확인하세요.

4) 현재 연락 가능한 휴대전화 번호와 이메일 유지하기
