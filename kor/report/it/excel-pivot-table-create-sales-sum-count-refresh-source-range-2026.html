거래처 매출표·쇼핑몰 주문 내역·재고 데이터를 엑셀로 정리할 때 지역별 합계, 월별 매출, 상품별 주문 건수를 계산하려고 복잡한 수식을 만들 필요는 없습니다. 피벗 테이블(PivotTable) 을 이용하면 기존 데이터의 열을 행·열·값 영역에 배치해 원하는 요약표를 만들 수 있습니다.

다만 처음 사용하면 '금액 합계'가 아니라 '금액 개수'가 나오거나, 원본에 새로운 주문을 추가했는데 매출 합계가 바뀌지 않아 당황하기 쉽습니다. 이 글은 Microsoft의 공식 사용법을 바탕으로 5분 실습 데이터 → 첫 피벗 테이블 → 값 필드 오류 → 데이터 새로 고침 → 원본 범위 변경 순서로 설명합니다.

설명 기준은 Windows용 Microsoft 365 Excel·Excel 2024입니다. Mac 및 웹용 Excel은 메뉴 구성이 다를 수 있고 일부 자동 새로 고침 기능은 버전·배포 상태에 따라 차이가 있습니다.

판매채널별 매출행: 채널 / 값: 매출액(합계)온라인·오프라인 총액

피벗 테이블은 원본 데이터를 직접 삭제하거나 정렬해 변경하지 않고 요약 결과를 보여 주는 기능입니다. 원본을 수정한 후에는 결과를 최신 상태로 갱신해야 할 수 있습니다.

다음 표를 엑셀 새 시트의 A1:D9에 그대로 입력하면 별도 파일 다운로드 없이 실습할 수 있습니다.

2026-10-03서울온라인120000

모든 값은 설명을 위한 가상 주문 데이터입니다. 실제 판매 자료나 통계가 아닙니다.

실습 데이터의 총합은 600,000원입니다. 지역별로 서울 360,000원·부산 240,000원, 채널별로 온라인 300,000원·오프라인 300,000원입니다. 피벗 테이블로 만든 뒤 이 숫자와 일치하면 집계가 정상인지 확인하기 좋습니다.

날짜 입력 주의: 날짜를 입력했는데 엑셀이 텍스트로 인식한다면 월별 그룹화가 제대로 되지 않을 수 있습니다. 단순히 날짜처럼 보이는 것과 엑셀의 실제 날짜 데이터인 것은 다릅니다.

3. 피벗 테이블 만들기 전에 원본 표를 정리하는 방법

Microsoft는 피벗 테이블을 만들기 전 데이터를 한 줄의 머리글(헤더) 이 있는 열 형태로 정리하도록 안내합니다.

  1. 첫 행에 '주문일·지역·채널·매출액'처럼 각 열 이름을 입력합니다.
  2. 한 열에는 같은 종류의 데이터를 넣습니다. 예를 들어 매출액 열에는 금액 숫자를 입력합니다.
  3. 제목 행에 빈 머리글을 두지 않습니다.
  4. 표 안에 병합된 셀이 있다면 가능하면 해제하고 각 행을 완전한 기록으로 정리합니다.
  5. 매출액 열에 '12만원' 같은 문자와 숫자 120000을 섞어 입력하지 않습니다.
  6. 별도 소계·총계 행이 원본 범위에 함께 들어 있으면 중복 합계가 발생할 수 있으므로 제거하거나 범위에서 제외합니다.

예를 들어 같은 매출액 열에 숫자 120000과 텍스트 120,000원이 섞여 있으면 피벗 테이블의 요약 방식이나 결과가 달라질 수 있습니다.

실무 팁: 데이터에 새로운 주문을 자주 추가한다면 원본을 Excel 표(Table)로 바꾸는 방법이 유용합니다. 목록 안의 셀을 선택하고 Ctrl+T를 눌러 표로 만든 다음 피벗 테이블을 생성하면 데이터 범위를 관리하기 편합니다.

4. 피벗 테이블 처음 만드는 방법: 삽입 → 피벗 테이블

앞의 실습 데이터로 바로 진행해 보겠습니다.

  1. 원본 데이터 범위인 A1:D9에서 아무 셀이나 클릭합니다.
  2. 상단 삽입 → 피벗 테이블을 선택합니다.
  3. 데이터 원본이 $A$1:$D$9 또는 해당 Excel 표로 설정돼 있는지 확인합니다.
  4. 피벗 테이블을 넣을 위치로 새 워크시트를 선택합니다.
  5. 확인을 누릅니다.
  6. 새 시트에서 빈 피벗 테이블과 피벗 테이블 필드 창이 나타나는지 확인합니다.

원본을 먼저 표(Table)로 만들었다면 데이터 범위 대신 표 이름이 표시될 수 있습니다. 예상과 다른 범위가 잡히면 그대로 진행하지 말고 원본 선택부터 확인하세요.

새 워크시트를 권장하는 이유: 처음에는 피벗 결과가 차지하는 크기를 예상하기 어렵습니다. 원본 시트의 빈 공간에 만들기보다 별도 시트에 두면 기존 주문 데이터나 수식을 덮어쓸 위험을 줄일 수 있습니다.

5. 지역별 매출 합계 만들기: 행·값 두 영역만 기억하세요

처음 피벗 테이블을 만들면 오른쪽에 필드 목록과 네 개의 배치 영역이 표시됩니다.

피벗 영역의미실습에 넣을 필드
필터표 전체에서 선택해서 볼 조건필요하면 채널
열가로 방향으로 나열할 분류필요하면 채널
행세로 방향으로 나열할 분류지역
값계산할 숫자 또는 항목매출액(합계)

실제 배치

  1. 필드 목록의 지역을 아래쪽 행 영역으로 끌어 놓습니다.
  2. 매출액을 값 영역으로 끌어 놓습니다.
  3. 값 필드가 '합계: 매출액'인지 확인합니다.

정상이라면 다음과 같은 집계가 나옵니다.

지역매출액 합계
부산240,000
서울360,000
총합계600,000

지역 표시 순서는 정렬 설정에 따라 달라질 수 있지만 총합계는 같아야 합니다. 총액이 다르다면 원본 값과 피벗 테이블에 적용된 필터를 먼저 확인하세요.

중요: 피벗 테이블의 합계 숫자는 자동으로 계산된 결과입니다. 그 숫자를 직접 수정하기보다 원본 데이터를 고치고 집계를 새로 고쳐야 합니다.

6. 지역 × 판매채널 교차표 만들기

이번에는 온라인·오프라인 매출을 지역별로 함께 비교하겠습니다.

  1. 기존 피벗 테이블에서 지역이 '행'에 있는지 확인합니다.
  2. 채널 필드를 열 영역에 놓습니다.
  3. 매출액 필드는 값 영역에 그대로 둡니다.
  4. 값 계산이 합계인지 확인합니다.

실습 데이터의 예상 결과는 다음과 같습니다.

지역온라인오프라인총합계
부산100,000140,000240,000
서울200,000160,000360,000
총합계300,000300,000600,000

열의 표시 순서는 자동 정렬에 따라 다를 수 있습니다. 부산 온라인 100,000원, 서울 온라인 200,000원, 총합계 600,000원을 확인하면 필드 배치가 의도대로 되었는지 빠르게 검증할 수 있습니다.

이 교차표는 단순히 SUMIF 수식 한 개로 합계를 구하는 경우와 달리 행·열의 기준을 바꿔 여러 관점에서 데이터를 탐색하기 쉽다는 장점이 있습니다.

7. 합계 대신 개수가 나오는 오류: 값 필드 설정

'매출액 합계'가 필요한데 피벗 테이블에 '개수: 매출액'이라고 표시되는 경우가 있습니다. 숫자로 계산되어야 할 열에 텍스트·빈값 등이 섞여 있을 때 요약 방식이 개수로 설정될 수 있습니다.

개수 → 합계로 바꾸는 방법

  1. 피벗 테이블의 값 영역에서 '매출액' 필드를 찾습니다.
  2. 필드 옆 메뉴를 열고 값 필드 설정을 선택합니다.
  3. 값 요약 기준에서 합계(Sum) 를 선택합니다.
  4. 확인을 누릅니다.
  5. 결과가 예제의 600,000원과 일치하는지 확인합니다.

그러나 매출액 열이 실제로 텍스트라면 단순히 '합계'를 선택해도 기대한 결과가 나오지 않을 수 있습니다.

숫자로 인식되지 않는 데이터 찾기

  • 120000처럼 일반 숫자로 입력된 값인지 확인합니다.
  • 120000원처럼 단위가 함께 입력된 텍스트는 숫자 데이터로 정리합니다.
  • 복사·붙여넣기 과정에서 생긴 앞뒤 공백이나 특수문자가 있는지 확인합니다.
  • 비어 있는 셀이 있다면 정말 미입력인지, 0원을 뜻하는지 구별합니다.
  • 수정 후 반드시 피벗 테이블을 새로 고침합니다.

주의: 0원과 빈칸을 임의로 같은 값으로 바꾸면 실제 거래·주문 건수 집계가 달라질 수 있습니다. 데이터의 업무상 의미를 먼저 확인하세요.

8. 주문 건수와 매출액 합계를 동시에 확인하는 방법

금액만이 아니라 주문 건수도 필요하다면 값 영역에 필드를 더 추가할 수 있습니다.

실습 데이터에는 별도의 주문번호가 없으므로 주문일을 값 영역에 추가해 '개수'로 설정하면 됩니다. 다만 같은 날짜에 여러 주문이 있는 경우에도 각 행이 하나의 주문이라는 전제에서만 주문 건수로 해석할 수 있습니다.

  1. 지역 필드는 '행'에 둡니다.
  2. 매출액은 '값'에 두고 합계로 설정합니다.
  3. 주문일을 '값' 영역에 한 번 더 추가합니다.
  4. 값 필드 설정에서 주문일의 요약 방식을 개수(Count) 로 변경합니다.
  5. 결과를 확인합니다.
지역매출액 합계주문일 개수
부산240,0004
서울360,0004
총합계600,0008

실제 주문 데이터에서는 주문번호를 별도 필드로 두고 그 개수를 집계하는 편이 의미가 명확합니다. 한 주문이 여러 상품 행으로 나뉜 데이터라면 '행 개수'와 '고유 주문 건수'는 다르므로 중복 주문번호 처리 기준을 먼저 정해야 합니다.

9. 월별 매출 합계 만들기: 날짜 그룹화 주의

피벗 테이블에서 주문일 필드를 '행'에, 매출액 필드를 '값'에 놓으면 날짜별 매출을 집계할 수 있습니다. 월별로 보려면 날짜 필드를 월 단위로 그룹화합니다.

날짜가 정상적인 Excel 날짜인 경우

  1. 새 피벗 테이블을 만듭니다.
  2. 주문일을 '행', 매출액을 '값'에 넣습니다.
  3. 피벗 결과의 날짜 셀을 선택하고 마우스 오른쪽 단추를 클릭합니다.
  4. 버전에 따라 그룹 메뉴를 선택합니다.
  5. 그룹 기준에서 월을 고릅니다. 데이터가 여러 해에 걸쳐 있다면 연도도 함께 선택해 서로 다른 해의 같은 달이 합쳐지지 않게 합니다.
  6. 확인한 뒤 월별 결과를 검토합니다.

실습 예제에서는 2026년 10월 350,000원, 11월 250,000원이 나와야 합니다.

그룹화할 수 없다는 오류가 나면

원본의 '주문일' 열에 다음과 같은 값이 있는지 확인하세요.

  • 빈 셀이나 오류 값
  • 날짜처럼 보이지만 실제로는 텍스트인 항목
  • 같은 열에 날짜와 일반 문자가 섞인 경우
  • 필터로 가려져 있었지만 원본 범위에 포함된 잘못된 값

실무 팁: 날짜의 표시 형식을 '2026-10'으로 바꿨다고 원본 날짜가 월별 집계 기준으로 바뀌는 것은 아닙니다. 실제 날짜 값과 표시 형식을 구별하는 것이 중요합니다.

10. 새 주문을 추가했는데 매출액이 안 바뀔 때: 새로 고침

원본에 새 데이터를 입력해도 피벗 테이블이 이전 집계 상태로 남아 있을 수 있습니다.

수동으로 새로 고치는 방법

  1. 피벗 테이블의 아무 셀이나 클릭합니다.
  2. 마우스 오른쪽 단추 → 새로 고침을 선택합니다.
  3. 또는 상단 피벗 테이블 분석 → 새로 고침을 클릭합니다.
  4. Windows에서는 Alt+F5 단축키를 사용할 수도 있습니다.
  5. 여러 피벗 테이블을 갱신하려면 모두 새로 고침을 선택합니다.

Microsoft 공식 문서는 로컬 통합 문서 데이터를 사용하는 일부 최신 버전에서 자동 새로 고침도 지원한다고 안내합니다. 하지만 구버전과 설정 상태에 따라 자동 적용 여부가 다를 수 있으므로, 원본 변경 후 실제 결과가 갱신됐는지 확인하는 방법이 안전합니다.

11. 새로 고쳐도 새 행이 빠진다면: 원본 범위부터 확인

기존 원본 범위를 $A$1:$D$9로 고정해 피벗 테이블을 만들었다면 A10:D10에 새 주문을 추가해도 기존 원본 범위 밖이기 때문에 포함되지 않을 수 있습니다.

데이터 원본 변경 방법

  1. 피벗 테이블 안쪽을 선택합니다.
  2. 피벗 테이블 분석 → 데이터 원본 변경을 선택합니다.
  3. 현재 원본 범위가 어디까지인지 확인합니다.
  4. 새로 추가한 행까지 포함되도록 범위를 변경합니다.
  5. 확인 후 새로 고침을 실행합니다.
  6. 총합계가 실제 원본 값과 같은지 확인합니다.

계속 늘어나는 데이터라면 Excel 표 사용

앞으로 데이터를 수십·수백 행씩 추가한다면 원본 데이터를 Ctrl+T로 Excel 표로 만든 뒤 그 표를 피벗 테이블의 원본으로 지정하는 편이 좋습니다. 표에 새 행이 포함되도록 확장됐는지 확인하고 피벗 데이터를 갱신하세요.

Microsoft는 기존 피벗 테이블의 원본을 다른 Excel 표나 범위로 변경할 수 있다고 설명합니다. 단, 데이터 모델 기반 등 일부 구성에서는 변경 방식이 제한될 수 있습니다.

공식 출처: Microsoft — 피벗 테이블의 원본 데이터 변경

12. 피벗 테이블 필드 목록이 사라졌을 때

지역·채널·매출액을 드래그해야 하는데 오른쪽 필드 목록이 사라졌다면 다음을 확인하세요.

  1. 피벗 테이블 바깥이 아니라 피벗 테이블 안쪽 셀을 선택합니다.
  2. 상단의 피벗 테이블 분석 탭이 표시되는지 확인합니다.
  3. 필드 목록 항목을 선택해 다시 표시합니다.
  4. 여전히 보이지 않으면 리본의 피벗 테이블 영역을 확인합니다.

피벗 테이블을 선택하지 않은 상태에서는 분석 탭이 나타나지 않을 수 있습니다. 워크시트의 빈 셀만 선택하고 있지 않은지부터 확인하세요.

13. 피벗 테이블 #SPILL! 오류가 나올 때

일부 Microsoft 365 Excel 환경에서는 피벗 테이블이 확장해야 할 영역에 다른 데이터나 병합 셀이 있어 제대로 확장하지 못하면 #SPILL! 오류가 표시될 수 있습니다.

Microsoft는 이런 상황의 예로 셀에 남은 데이터·수식, 병합 셀, 워크시트의 끝 경계를 들고 있습니다.

확인 순서

  1. 피벗 테이블이 확장될 아래쪽·오른쪽에 다른 값이 있는지 살펴봅니다.
  2. 새로 고침으로 지역이나 상품 목록이 늘어날 수 있다는 점을 고려합니다.
  3. 주변의 중요한 데이터는 삭제하지 말고 별도 위치로 이동하거나 백업합니다.
  4. 병합된 셀이 피벗 확장 범위를 막고 있다면 구조를 검토합니다.
  5. 공간이 충분한 새 시트에 피벗 테이블을 이동하거나 다시 만들어 봅니다.

주의: #SPILL! 오류가 나오더라도 원본 데이터가 없어졌다는 뜻은 아닙니다. 피벗 테이블이 결과를 펼칠 공간이 없는 상태일 수 있습니다. 모든 Excel 버전에서 같은 오류 표시가 제공되는 것은 아닙니다.

14. 합계가 틀렸을 때 실제로 확인할 6가지

피벗 테이블에 숫자가 나오기만 하면 분석이 끝났다고 생각하기 쉽지만, 원본의 의미와 범위를 확인하지 않으면 잘못된 합계가 만들어질 수 있습니다.

확인 사항잘못됐을 때 나타나는 현상해결 방향
매출액 데이터가 숫자인지금액 대신 개수 또는 0에 가까운 값 표시원본의 텍스트·공백 확인
원본 범위가 전체인지신규 주문이 합계에서 누락범위 수정·표 사용
데이터가 중복되었는지실제보다 큰 금액동일 주문 중복 여부 검증
필터가 걸려 있는지특정 지역·상품 합계만 표시필터 모두 해제 후 비교
소계 행을 원본에 포함했는지합계가 이중 계산됨소계·총계 행 제외
새로 고침이 되었는지오래된 데이터 표시수동 새로 고침 후 비교

예제 파일이라면 피벗 테이블의 총합계가 600,000원과 일치해야 합니다. 결과가 500,000원이라면 먼저 100,000원 매출 행이 원본 범위 밖에 있거나 필터로 제외됐는지 확인하는 방식으로 문제를 좁힐 수 있습니다.

실제 회사 데이터에서는 반품·취소·환불 금액을 매출에서 어떻게 처리할지도 일관되게 정의해야 합니다. 피벗 테이블은 합계를 계산할 뿐, 어떤 거래가 매출인지 자동으로 판단해 주지는 않습니다.

15. 피벗 테이블과 SUMIF 함수 중 무엇이 더 좋을까?

이전에 엑셀 수식을 사용했다면 두 방법의 차이가 궁금할 수 있습니다.

목적피벗 테이블SUMIF·SUMIFS
기준을 바꿔가며 탐색행·열 필드 드래그로 편리수식 기준을 수정해야 함
고정된 양식에서 특정 셀에 결과 표시별도 요약 영역을 관리필요한 셀에 직접 수식 배치 가능
여러 지역·상품의 전체 현황한 번에 교차표 구성여러 수식 작성 필요할 수 있음
원본 수정 후 반영새로 고침/자동 새로 고침 상태 확인계산 설정에 따라 수식 재계산
사용자 입력 오류 관리원본 데이터 정리 필수원본 데이터 정리 필수

추천 기준: 매출을 지역·월·채널별로 계속 바꾸어 보고 싶다면 피벗 테이블, 이미 완성된 정형 보고서의 특정 셀에 고정된 조건의 결과를 넣으려면 SUMIFS가 적합할 수 있습니다.

두 기능은 경쟁 관계가 아닙니다. 피벗 테이블로 데이터를 탐색하고 최종 보고서에는 필요한 집계 결과를 활용할 수도 있습니다.

16. Mac·웹용 Excel에서 사용할 때의 차이

Microsoft는 Mac용 Excel과 웹용 Excel에서도 피벗 테이블 사용을 지원하지만 화면 구성과 제공되는 옵션은 Windows 데스크톱 버전과 같지 않을 수 있다고 안내합니다.

Mac용 Excel

  • 원본 범위를 선택한 후 삽입 → 피벗 테이블로 시작합니다.
  • 필드를 행·열·값·필터에 배치하는 개념은 동일합니다.
  • 단축키와 리본 메뉴의 배치가 Windows와 다를 수 있으므로 표시되는 명령을 우선합니다.

웹용 Excel

  • 웹 스프레드시트에서 원본 데이터 범위를 선택합니다.
  • 삽입 → 피벗 테이블을 통해 새 시트나 기존 시트에 피벗 테이블을 만듭니다.
  • 일부 구독·환경에서는 권장 피벗 테이블 옵션이 제공될 수 있습니다.
  • 원본 변경 후 갱신이 필요하면 피벗 테이블을 선택해 새로 고침을 실행합니다.

예전에 작성된 도움말의 화면과 실제 메뉴가 다르다면 현재 사용 중인 버전의 지원 범위를 확인하세요. 특히 자동 새로 고침 동작은 엑셀 버전과 설정에 따라 차이가 있습니다.

17. 자주 묻는 질문

Q. 피벗 테이블을 가장 빨리 만드는 방법은?

헤더가 있는 원본 데이터를 준비하고 그 안의 셀을 선택한 뒤 삽입 → 피벗 테이블 → 새 워크시트 → 확인을 누릅니다. 그다음 원하는 열을 '행'과 '값' 영역에 배치하세요.

Q. 피벗 테이블 값이 개수로 나오는 이유는?

값 필드의 요약 방식이 '개수'로 설정됐을 수 있습니다. 값 필드 설정 → 합계를 확인하고, 원본 금액 열에 문자나 공백이 없는지도 점검하세요.

Q. 새 데이터를 추가했는데 피벗에 반영되지 않습니다.

원본 데이터의 범위에 새 행이 포함돼 있는지 확인하고 새로 고침을 실행하세요. 고정 범위를 사용 중이라면 데이터 원본 변경이 필요할 수 있습니다.

Q. 피벗 테이블은 원본 데이터가 바뀌면 자동으로 갱신되나요?

Excel 버전과 설정에 따라 다릅니다. 최신 Microsoft 365 일부 환경에서 로컬 데이터 자동 새로 고침을 지원하지만, 모든 Excel에서 항상 자동 갱신된다고 가정하지 마세요.

Q. 월별 매출을 만들려면 어떻게 하나요?

실제 날짜 형식의 주문일을 '행'에 넣고, 날짜를 월(필요하면 연도 포함) 단위로 그룹화한 뒤 매출액을 '값'의 합계로 배치합니다.

Q. 피벗 테이블 필드 목록이 보이지 않습니다.

피벗 테이블 안쪽 셀을 클릭하고 피벗 테이블 분석 → 필드 목록을 확인하세요.

Q. #SPILL! 오류가 나오는데 원본이 지워진 건가요?

반드시 그렇지는 않습니다. 일부 Microsoft 365 Excel에서는 피벗 결과가 확장될 영역에 데이터나 병합 셀이 있으면 #SPILL! 오류가 나타날 수 있습니다. 주변의 차단 영역을 확인하세요.

Q. 피벗 테이블을 만들면 원본 엑셀 표가 변경되나요?

피벗 테이블은 원본을 기준으로 별도 요약 결과를 만듭니다. 원본 데이터가 자동으로 정리·삭제되지는 않습니다. 결과를 수정하려면 원본부터 점검하는 것이 적절합니다.

18. 최종 1분 검수 체크리스트

  • ☐ 원본의 첫 행에 빈칸 없는 제목이 있다.
  • ☐ 매출액 열은 실제 숫자로 입력되어 있다.
  • ☐ 소계·총계 행을 원본 범위에 중복 포함하지 않았다.
  • ☐ 필요한 필드를 행·열·값 영역에 배치했다.
  • ☐ 값의 요약 방식이 합계 또는 의도한 개수인지 확인했다.
  • ☐ 새 행이 원본 범위에 들어 있는지 점검했다.
