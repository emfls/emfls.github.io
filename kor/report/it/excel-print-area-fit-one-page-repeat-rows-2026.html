엑셀에서 만든 견적서·매출표·출석부·급여대장을 인쇄하려고 했는데 마지막 열만 다음 장으로 넘어가거나, 빈 종이가 여러 장 나오거나, 두 번째 페이지부터 표 제목이 사라지는 경우가 있습니다. 이런 문제는 대부분 파일이 손상된 것이 아니라 인쇄 영역, 용지 방향, 배율, 페이지 나누기, 반복 제목행 설정이 서로 맞지 않아서 발생합니다.

가로 열만 한 장에 넣고 세로 행은 여러 페이지에 나누어 출력하려면, 모든 내용을 무조건 1페이지로 줄이지 말고 너비 1페이지·높이 자동을 선택하는 것이 핵심입니다. 반면 짧은 제출용 표를 종이 한 장에 완전히 맞추려면 너비 1페이지·높이 1페이지를 사용할 수 있습니다. 두 옵션을 혼동하면 표 글씨가 지나치게 작아집니다.

이 글은 2026년 11월 3일 기준 Microsoft 공식 도움말을 바탕으로 엑셀 365·2024·2021 및 Windows 11 데스크톱 Excel 중심으로 정리했습니다. 맥과 웹용 Excel은 제공 기능이 일부 다르므로 구분해 설명합니다.

공식 근거: Microsoft — 워크시트 인쇄와 미리 보기.

2. 엑셀 인쇄 영역 설정 방법: 필요한 셀만 출력

엑셀의 인쇄 영역은 워크시트 전체가 아니라 지정한 셀 범위만 출력하도록 저장하는 설정입니다.

예를 들어 A1:J35가 제출용 표이고 오른쪽 K열부터 계산용 메모가 있다면 A1:J35만 지정합니다.

  1. Excel에서 인쇄할 워크시트를 엽니다.
  2. 마우스로 A1:J35와 같이 출력할 셀 범위를 선택합니다.
  3. 상단 페이지 레이아웃 탭을 엽니다.
  4. 인쇄 영역 → 인쇄 영역 설정을 선택합니다.
  5. Ctrl+P를 눌러 필요한 범위만 표시되는지 확인합니다.
  6. 통합 문서를 저장합니다.

중요: Microsoft는 지정한 인쇄 영역이 통합 문서를 저장할 때 함께 저장된다고 안내합니다. 과거 다른 사람이 설정한 인쇄 영역 때문에 새로 추가한 데이터가 출력되지 않는 경우가 있습니다.

Microsoft 공식 안내 — 인쇄 영역 설정 및 지우기.

3. 엑셀 인쇄 영역 해제·변경 방법

선택한 셀만 출력되고 전체 표가 보이지 않는다면 먼저 인쇄 영역 지우기를 확인합니다.

  1. 문제가 발생하는 워크시트의 아무 셀이나 클릭합니다.
  2. 페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 지우기를 선택합니다.
  3. Ctrl+P를 눌러 전체 워크시트의 인쇄 미리 보기를 확인합니다.
  4. 필요한 범위만 다시 출력하려면 새 범위를 지정한 다음 인쇄 영역 설정을 다시 실행합니다.

다음도 구분해야 합니다.

  • 인쇄 영역 지우기: 저장된 인쇄 영역 설정을 해제합니다.
  • 인쇄 영역에 추가: 기존에 지정한 범위를 확장합니다.
  • 인쇄 영역 무시: 인쇄 화면에서 해당 인쇄 작업만 인쇄 영역을 무시할 수 있는 옵션입니다.
  • 선택 영역 인쇄: 현재 선택한 셀을 이번 인쇄 작업에 출력합니다.

Microsoft에 따르면 서로 떨어진 여러 인쇄 영역을 설정하면 각 영역이 별도 페이지에 인쇄될 수 있습니다. 엉뚱한 종이가 추가된다면 비연속 인쇄 영역이 여러 개 지정돼 있는지도 확인하세요.

4. 가로로 잘린 표를 한 페이지 너비에 맞추는 방법

가로 열이 많지만 행은 100개 이상인 보고서라면 모든 데이터를 한 장에 압축하는 것보다 가로만 맞추고 세로는 필요한 만큼 페이지를 늘리는 방법이 좋습니다.

  1. 해당 시트에서 페이지 레이아웃 탭을 엽니다.
  2. 방향 → 가로를 선택합니다.
  3. 크기에 맞게 조정 그룹에서 너비 = 1페이지로 설정합니다.
  4. 높이 = 자동으로 설정합니다.
  5. 용지는 제출처 기준에 맞게 A4 등을 선택합니다.
  6. Ctrl+P를 눌러 가로 열이 한 장에 들어오는지 확인합니다.

이렇게 하면 일반적으로 열은 한 페이지 너비에 맞고, 행은 필요에 따라 여러 페이지로 출력됩니다.

설정결과
너비 1페이지 + 높이 자동가로 열 전체를 맞추고 세로 페이지는 여러 장 허용
너비 1페이지 + 높이 1페이지가로·세로 모든 내용을 한 장으로 축소
너비 자동 + 높이 자동페이지 크기에 따라 여러 장으로 분할
인쇄 배율 직접 지정80%·90% 등 일정 비율로 축소·확대

실무 예시: A열부터 M열까지 있고 데이터가 150행인 판매실적표는 너비 1페이지·높이 자동을 먼저 권합니다. 모든 150행을 한 장에 맞추면 인쇄물의 숫자가 읽기 어려워질 수 있습니다.

공식 근거: Microsoft — 워크시트 크기 조정.

5. 표 전체를 A4 용지 한 장에 인쇄하는 방법

표의 행과 열이 모두 많지 않아 정말 1장짜리 제출용이어야 한다면 다음 순서를 따르세요.

  1. 먼저 필요한 인쇄 영역만 설정합니다.
  2. 페이지 레이아웃 → 크기 → A4를 선택합니다.
  3. 표가 가로로 넓다면 방향 → 가로로 바꿉니다.
  4. 크기에 맞게 조정 → 너비 1페이지·높이 1페이지를 선택합니다.
  5. Ctrl+P에서 글자 크기와 실제 페이지 수를 확인합니다.
  6. 너무 작다면 불필요한 열·여백을 줄이거나 두 장으로 나누는 방법을 검토합니다.

주의: '한 페이지에 시트 맞추기'를 적용해도 읽기 좋은 크기로 출력된다는 보장은 없습니다. Excel은 데이터가 맞도록 비율을 줄이기 때문에, 표가 클수록 글씨는 작아집니다.

추천 순서: ① 인쇄 영역 정리 → ② A4·가로 방향 → ③ 여백 조정 → ④ 너비만 1페이지 → ⑤ 꼭 필요할 때 높이도 1페이지.

6. 세로 한 장과 가로 한 장의 차이: 용지 방향·여백

세로 방향은 열이 적고 행이 많은 표에, 가로 방향은 열이 많은 표에 유리할 수 있습니다.

  • A~F열의 간단한 명단: 세로 방향부터 시도
  • A~N열의 월별 실적표: 가로 방향부터 시도
  • 표의 마지막 열만 잘리는 경우: 가로 방향·좁은 여백·너비 1페이지를 순서대로 점검

여백은 페이지 레이아웃 → 여백에서 기본·좁게 또는 사용자 지정 여백을 선택합니다. 헤더·푸터가 잘리는 경우에는 페이지 설정의 머리글·바닥글 여백도 확인합니다.

너무 좁은 여백은 프린터의 실제 인쇄 불가능 영역과 충돌할 수 있습니다. 미리 보기에서 맞더라도 프린터마다 가장자리 출력이 달라질 수 있으므로 계약서·제출서류처럼 중요한 문서는 시험 인쇄가 안전합니다.

공식 출처: Microsoft — 페이지 설정.

7. 2페이지부터 제목이 사라질 때: 행 반복 인쇄 설정

여러 장에 걸친 표에서는 첫 페이지에만 '이름·부서·합계'라는 제목이 보이면 뒷장의 숫자가 무슨 의미인지 알아보기 어렵습니다. Excel의 인쇄 제목으로 같은 행을 각 페이지 상단에 반복할 수 있습니다.

첫 번째 행만 반복하기

  1. 페이지 레이아웃 → 인쇄 제목을 선택합니다.
  2. 시트 탭에서 맨 위에 반복할 행을 찾습니다.
  3. 입력란에 $1:$1을 지정합니다.
  4. 확인을 누르고 파일 → 인쇄에서 두 번째 페이지를 확인합니다.

첫 번째와 두 번째 행을 반복하기

제목이 1~2행에 걸쳐 있다면 $1:$2를 지정합니다.

왼쪽 첫 열도 반복하기

가로로 여러 페이지를 인쇄하면서 첫 열의 항목명을 반복해야 한다면 왼쪽에서 반복할 열에 $A:$A를 지정할 수 있습니다.

반복 제목행과 데이터 필터의 머리글은 다른 기능입니다. 화면에 표 머리글이 보인다고 해서 다음 인쇄 페이지에 자동 반복되지는 않습니다.

공식 출처: Microsoft — 인쇄되는 모든 페이지에서 행·열 반복.

8. '인쇄 제목' 버튼이 회색이고 선택 안 될 때

Microsoft는 인쇄 제목 버튼이 비활성화되는 대표적인 상황을 공식 안내합니다.

  • 셀을 직접 편집하는 중인 경우
  • 차트가 선택된 경우
  • 프린터가 설치되어 있지 않은 경우
  • 여러 워크시트가 그룹으로 선택된 경우

해결 순서:

  1. Esc를 눌러 셀 편집을 종료합니다.
  2. 차트 밖의 일반 셀을 한 번 클릭합니다.
  3. 시트 탭에서 여러 시트가 선택돼 있다면 시트 그룹 해제를 합니다.
  4. Windows 설정에서 사용 가능한 프린터가 인식되는지 확인합니다.
  5. 다시 페이지 레이아웃 → 인쇄 제목을 실행합니다.

웹용 Excel은 데스크톱 Excel과 인쇄 제목·수동 페이지 나누기 등 기능이 다를 수 있습니다. 메뉴가 제공되지 않는다면 데스크톱 앱에서 열기가 필요한지 확인하세요.

공식 근거: Microsoft — 모든 페이지에 특정 행 반복.

9. '페이지 나누기 미리 보기'로 잘린 위치 직접 조정하기

Excel은 용지 크기·여백·배율·내용에 따라 자동 페이지 나누기를 삽입합니다. 사용자가 수동 페이지 나누기를 넣어 특정 위치에서 끊을 수도 있습니다.

  1. 인쇄하려는 시트를 선택합니다.
  2. 보기 → 페이지 나누기 미리 보기를 누릅니다.
  3. 현재 페이지 번호와 경계선을 확인합니다.
  4. 페이지가 예상과 다르게 나뉘었다면 페이지 레이아웃 → 나누기의 설정을 확인합니다.
  5. 필요하면 경계선이나 수동 페이지 나누기를 조정합니다.
  6. 다시 Ctrl+P로 인쇄 결과를 점검합니다.

Microsoft 공식 문서는 파선은 자동 페이지 나누기, 실선은 사용자가 삽입한 수동 페이지 나누기라고 설명합니다.

주의: Excel의 '크기에 맞게 조정'과 수동 페이지 나누기는 서로 영향을 줄 수 있습니다. Microsoft는 특정 배율 맞춤 옵션이 활성화되어 있을 때 수동 페이지 나누기가 의도대로 적용되지 않을 수 있다고 안내합니다. 페이지를 정확하게 나눠야 한다면 페이지 설정의 배율 옵션을 확인하세요.

공식 참고: Microsoft — 페이지 나누기 삽입·이동·삭제.

10. 엑셀 인쇄 시 빈 페이지가 추가되는 문제

'표는 두 장이면 되는데 7장으로 미리 보기 된다'면 먼저 인쇄 영역·페이지 나누기·불필요한 셀 범위를 확인합니다.

해결 순서

  1. 파일 → 인쇄에서 빈 페이지가 어느 위치에 생기는지 확인합니다.
  2. 페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 지우기를 실행합니다.
  3. 보기 → 페이지 나누기 미리 보기에서 별도로 설정된 페이지가 있는지 확인합니다.
  4. 불필요한 수동 나누기라면 페이지 레이아웃 → 나누기 → 페이지 나누기 모두 원래대로를 검토합니다.
  5. 실제 데이터 뒤쪽에 불필요한 서식·공백·도형이 있는지 확인합니다.
  6. 필요한 범위만 다시 인쇄 영역으로 지정한 뒤 미리 보기를 확인합니다.

추가 진단: Ctrl+End는 Excel이 현재 워크시트의 마지막 사용 셀로 인식하는 위치를 찾는 데 도움이 됩니다. 실제 표가 J40에서 끝나는데 마지막 사용 셀이 AZ5000처럼 멀리 있다면 불필요한 서식 등이 남았을 수 있습니다.

다만 셀 범위를 무작정 삭제하면 숨겨진 데이터·수식·표가 손상될 수 있습니다. 파일 복사본을 만든 다음 실제 데이터인지 확인하고 불필요한 부분만 정리하세요.

11. 일부 열이 안 나오거나 특정 데이터만 인쇄되는 경우

이때는 '인쇄가 잘린다'는 표현만으로 원인을 정하기 어렵습니다.

12. 인쇄 영역 설정과 '선택 영역 인쇄'는 어떻게 다른가요?

비교인쇄 영역 설정선택 영역 인쇄
설정 위치페이지 레이아웃파일 → 인쇄
주된 목적반복적으로 같은 셀 범위를 인쇄이번에 선택한 셀만 출력
저장 여부통합 문서 저장 시 함께 저장됨임시 출력 선택으로 이해하면 됨

매주 같은 양식을 인쇄한다면 인쇄 영역을 지정하는 것이 편리하고, 한 번만 일부 표를 출력한다면 선택 영역 인쇄를 활용할 수 있습니다.

Microsoft는 인쇄 영역이 설정되어 있어도 인쇄 옵션의 인쇄 영역 무시를 통해 전체 내용을 인쇄할 수 있다고 설명합니다.

공식 안내: Microsoft — 워크시트 인쇄 옵션.

13. 엑셀을 PDF로 저장했는데 표가 잘리는 이유

PDF로 저장했다고 인쇄 문제 자체가 자동으로 해결되지는 않습니다. Excel의 페이지 방향, 인쇄 영역, 배율 설정 등이 PDF 문서의 페이지 구성을 좌우할 수 있기 때문입니다.

  1. 원본 Excel 파일을 별도로 저장합니다.
  2. 시트에서 인쇄 영역과 페이지 배율·방향을 조정합니다.
  3. Ctrl+P에서 실제 인쇄 미리 보기를 확인합니다.
  4. 파일 → 내보내기·다른 이름으로 저장 → PDF 등 해당 버전에서 제공하는 PDF 기능을 선택합니다.
  5. 필요한 시트·페이지 범위와 인쇄 영역 포함 여부를 확인합니다.
  6. 저장된 PDF를 별도로 열어 페이지 수·열 잘림·표 제목·글꼴 크기를 검사합니다.

원본에서 보기 좋다고 PDF가 자동으로 한 장에 나오는 것은 아닙니다. 특히 여러 시트를 함께 PDF로 만들 때는 각 시트의 페이지 설정이 다를 수 있으므로 출력 결과를 시트별로 점검하세요.

14. 엑셀 웹 버전·맥에서도 똑같이 되나요?

기본 개념은 비슷하지만 메뉴와 제공 기능이 동일하지는 않습니다.

  • Windows 데스크톱 Excel: 인쇄 영역, 배율 조정, 반복 제목, 수동 페이지 나누기 등 주요 기능을 사용할 수 있습니다.
  • Mac용 Excel: 유사한 기능을 지원하지만 Windows와 메뉴 표시 및 인쇄 대화상자 구성이 다를 수 있습니다.
  • 웹용 Excel: 셀 선택 후 파일 → 인쇄에서 선택 영역을 인쇄할 수 있으나, Microsoft는 웹용 Excel에서 수동 페이지 나누기를 추가할 수 없다고 명시합니다. 복잡한 페이지 나누기 작업은 데스크톱 앱에서 열어야 합니다.

따라서 이 글의 Windows 메뉴를 무조건 웹용 Excel에 적용하지 말고, 사용 중인 Excel 환경을 먼저 확인하세요.

공식 근거: Microsoft — 웹용 Excel 인쇄, Microsoft — 페이지 나누기.

15. 자주 묻는 질문 10개

Q1. 엑셀에서 한 페이지만 인쇄하려면 무엇을 선택하나요?

짧은 표를 한 장에 모두 넣으려면 너비 1페이지·높이 1페이지로 조정합니다. 단, 글씨가 너무 작아지면 사용하지 않는 편이 좋습니다.

Q2. 가로로만 잘리는데 글씨는 크게 유지하려면?

너비 1페이지·높이 자동부터 적용하고 용지 방향을 가로로 바꾸세요. 세로 행을 여러 장으로 허용하면 과도한 축소를 줄일 수 있습니다.

Q3. 엑셀 인쇄 영역 지우는 방법은?

페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 지우기입니다. 저장된 영역 설정이 해제됩니다.

Q4. 인쇄 영역을 설정했는데 새 열이 출력되지 않습니다.

설정한 인쇄 영역이 새 열까지 확장되지 않았을 수 있습니다. 인쇄 영역을 지우거나 새 열까지 선택해 다시 지정하세요.

Q5. 표 제목을 다음 페이지마다 반복하려면?

페이지 레이아웃 → 인쇄 제목 → 맨 위에 반복할 행에 $1:$1을 입력합니다. 1~2행을 반복할 경우 $1:$2를 지정할 수 있습니다.

Q6. 인쇄 제목 메뉴가 회색입니다.

셀 편집 중인지, 차트가 선택됐는지, 여러 시트가 그룹 선택됐는지, 프린터가 설정됐는지 확인하세요.

Q7. 엑셀을 인쇄하면 빈 장이 여러 장 나옵니다.

인쇄 영역·페이지 나누기·불필요한 서식이 남은 사용 영역을 확인하세요. 범위 삭제 전에는 사본을 보관하는 것이 좋습니다.

Q8. 인쇄 미리 보기에서만 표가 잘려 보입니다.

미리 보기는 실제 페이지 설정에 따른 결과를 표시합니다. 방향·여백·배율·인쇄 영역과 프린터 선택을 확인하세요.

Q9. PDF로 저장할 때도 인쇄 영역이 적용되나요?

PDF 생성 방식과 저장 옵션에 따라 인쇄 영역·페이지 설정이 반영될 수 있습니다. 저장된 PDF를 다시 열어 결과를 확인하세요.

Q10. Excel 웹에서도 페이지 나누기를 설정할 수 있나요?

Microsoft는 웹용 Excel에서 수동 페이지 나누기를 추가하는 기능이 제공되지 않는다고 안내합니다. 필요하면 데스크톱 Excel을 이용하세요.

16. 제출·출력 전 최종 체크리스트

  • ☐ 원본 Excel 통합 문서를 복사해 보관했다.
  • ☐ 출력할 시트와 필요한 셀 범위를 확정했다.
  • ☐ 과거 저장된 인쇄 영역 때문에 빠진 열이 없는지 확인했다.
  • ☐ A4·세로·가로 방향과 여백을 점검했다.
  • ☐ 가로 열이 잘리면 너비 1페이지·높이 자동을 먼저 검토했다.
  • ☐ 한 장짜리 문서만 높이도 1페이지로 맞췄다.
  • ☐ 표 제목을 모든 페이지에 반복할지 결정했다.
  • ☐ 페이지 나누기와 빈 페이지를 점검했다.
  • ☐ 눈금선·표 테두리·숨긴 행과 열이 필요한지 확인했다.
  • ☐ PDF로 제출한다면 저장 후 별도로 열어 페이지 수·가독성을 확인했다.

정리

엑셀 인쇄가 잘릴 때 가장 먼저 전체를 1장으로 강제 압축하지 마세요. 인쇄 영역을 제대로 설정하고, 표가 가로로 긴 경우 너비 1페이지·높이 자동으로 시작해야 읽기 좋은 결과를 얻을 수 있습니다.

여러 장에 걸친 표라면 인쇄 제목으로 첫 행을 반복하고, 빈 페이지가 나올 때는 과거 인쇄 영역·페이지 나누기·사용 범위를 확인합니다. 마지막으로 인쇄 미리 보기와 실제 PDF를 검사하면 대부분의 제출 전 오류를 빠르게 발견할 수 있습니다.
