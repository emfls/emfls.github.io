1. 삼성 키보드 자동완성 끄는 방법

갤럭시의 기본 키보드가 삼성 키보드라면 다음 순서로 확인하세요.

  1. 휴대전화에서 설정을 엽니다.
  2. 일반 → 삼성 키보드 설정으로 이동합니다.
  3. 문구 추천을 찾습니다.
  4. 원치 않는 언어의 문구 추천을 끕니다. 모든 추천을 숨기고 싶다면 사용 중인 언어의 추천 여부를 각각 확인합니다.
  5. 메모 앱 또는 카카오톡 입력창에 돌아가 키보드 위의 추천 항목이 사라졌는지 확인합니다.

'문구 추천'은 예상 단어를 표시하는 기능입니다. 입력한 글자가 스페이스바를 누를 때 저절로 바뀌는 문제는 다음 절의 문구 자동 수정을 먼저 점검해야 합니다.

키보드가 표시된 상태에서 톱니바퀴 아이콘을 통해 삼성 키보드 설정에 접근할 수도 있습니다. 톱니바퀴가 보이지 않으면 휴대전화의 설정 앱에서 직접 이동하세요.

2. 스페이스바를 누르면 단어가 바뀔 때: 문구 자동 수정 끄기

삼성 키보드에는 추천 단어를 '보여주는' 기능과, 입력 내용을 자동으로 다른 단어로 바꾸는 기능이 별도로 있습니다.

  1. 설정 → 일반 → 삼성 키보드 설정으로 이동합니다.
  2. 문구 자동 수정 항목을 찾습니다.
  3. 자동 치환을 원하지 않는 언어를 선택하거나 해당 기능을 끕니다.
  4. 메모 앱에서 같은 문장을 입력해 봅니다. 원래 스페이스바 뒤에 의도하지 않은 치환이 나타났다면 변경 후에도 재현되는지 확인합니다.

삼성 담당자의 2025년 11월 답변은 문구 추천과 문구 자동 수정을 별도 경로로 제시합니다. 일부 사용자는 새 버전에서 '문구 자동 수정' 메뉴를 찾지 못했다고도 보고했습니다. 메뉴가 없다면 현재 기기에 없는 기능이라고 단정하거나 무작정 초기화하지 말고, 설정 내 검색창에서 '문구', '자동 수정'을 검색하고 기본 키보드 앱을 확인하세요.

공식 운영진 답변: 삼성 키보드 자동완성 문의

3. 키보드 위 추천 줄 자체가 없어졌다면: 키보드 툴바 확인

자동완성을 켜고 싶은데 추천 단어가 전혀 안 보이는 경우에는 아래 두 가지를 구분하세요.

  • 키보드 툴바가 보이지 않음: 설정 → 일반 → 삼성 키보드 설정 → 키보드 툴바를 켰는지 확인합니다.
  • 툴바는 있지만 단어 추천이 보이지 않음: 같은 화면에서 문구 추천의 해당 언어를 켰는지 확인합니다.

반대로 추천 단어가 부담스럽다면 문구 추천을 끄는 것이 우선입니다. 키보드 툴바에는 추천 단어 외의 기능도 표시되므로 툴바 전체를 끄는 것과 문구 추천을 끄는 것은 동일하지 않습니다.

일부 앱에서는 입력란 자체가 특수하게 설계되어 추천 기능이 다르게 보일 수 있습니다. 한 앱에서만 나타나는 증상이라면 메모 앱과 문자 앱을 비교하세요.

4. 자동 띄어쓰기 설정이 보이지 않을 때

설정 화면을 아무리 찾아도 '자동 띄어쓰기'가 없다면 업데이트로 완전히 제거된 기능이라고 단정하기 어렵습니다.

삼성 키보드 담당자가 2025년 12월 안내한 조건은 다음과 같습니다.

  1. 설정 → 일반 → 삼성 키보드 설정 → 문구 추천으로 이동합니다.
  2. 언어 하나 이상에 대해 문구 추천을 켭니다.
  3. 다시 삼성 키보드 설정의 기타 입력 옵션으로 이동합니다.
  4. 자동 띄어쓰기 항목이 나타나는지 확인합니다.
  5. 필요한 상태로 설정한 뒤 실제 키보드에서 입력 결과를 확인합니다.

삼성 담당자는 문구 추천이 모두 꺼져 있으면 자동 띄어쓰기 메뉴가 보이지 않을 수 있다고 설명합니다. 즉, 메뉴가 안 보이는 것과 사용자가 의도한 방식으로 띄어쓰기가 동작하는 것은 별개의 문제입니다.

공식 안내: 삼성 담당자, 자동 띄어쓰기 메뉴가 안 보이는 이유(2025.12.10)

5. 예전에 입력한 이상한 추천 단어만 지우는 방법

키보드에 오래전에 입력한 별명이나 오타가 계속 뜬다면 추천 기능을 모두 끌 필요 없이 학습된 입력 기록을 정리할 수 있습니다.

삼성 키보드의 공식 안내 경로는 다음과 같습니다.

설정 → 일반 → 삼성 키보드 설정 → 설정 초기화 → 개인 입력 데이터 삭제

다만 이 메뉴는 가볍게 누르지 마세요. 삼성 키보드 담당자는 2026년 3월 26일 답변에서 개인 입력 데이터를 삭제하면 키보드에 설정된 모든 언어의 입력 데이터가 초기화된다고 설명했습니다. 특정 언어의 단어 하나만 지우는 기능과 다릅니다.

특정 추천 단어만 문제라면 우선 추천 목록에서 해당 단어를 개별 삭제할 수 있는지 살펴보세요. 개별 제거 조작은 소프트웨어 버전이나 표시 상태에 따라 차이가 있을 수 있습니다.

또한 입력 데이터 삭제 후에도 키보드가 기본으로 제공하는 추천 단어는 남거나 다시 나타날 수 있습니다. 단어가 남아 있다는 이유만으로 개인정보 삭제가 반드시 실패했다고 판단할 수는 없습니다.

공식 안내: 삼성 키보드 담당자, 모든 언어의 입력 데이터 초기화 주의(2026.3.26), 삼성 담당자, 기본 추천 단어와 개인 입력 데이터 차이

6. 삼성 키보드가 아니라 Gboard를 사용하고 있다면

갤럭시에서도 Google Gboard가 기본 키보드로 지정되어 있을 수 있습니다. 이 상태에서 삼성 키보드의 문구 추천을 꺼도 Gboard의 추천은 그대로 보일 수 있습니다.

Gboard의 공식 도움말 기준으로는 다음과 같이 접근합니다.

  1. 문자나 메모 앱에서 텍스트 입력창을 눌러 Gboard를 표시합니다.
  2. 키보드 상단의 기능 메뉴 → 더보기 → 설정 → 텍스트 수정을 엽니다. 사용 중인 버전에서는 바로 설정 아이콘을 탭할 수도 있습니다.
  3. 추천란 표시, 자동 수정 등 현재 제공되는 옵션을 확인합니다.
  4. 필요한 옵션만 바꾸고 입력창에 돌아가 테스트합니다.

Google 도움말은 추천 단어를 길게 눌러 휴지통으로 드래그해 개별 추천을 제거하는 방법도 안내합니다.

Gboard의 언어별 추천·교정 기능은 제공 범위가 다릅니다. 영어 관련 최신 AI 교정 기능을 한국어에서도 동일하게 사용할 수 있다고 가정하면 안 됩니다. 메뉴 이름과 기능 지원 여부는 키보드 버전·언어를 기준으로 확인하세요.

공식 도움말: Google Gboard 추천 단어 사용 및 텍스트 수정, Gboard 관련 문제 해결

7. Gboard에서 학습한 단어 삭제하기

단어 추천은 유지하되 지금까지 학습된 단어를 초기화하려면 Gboard 공식 도움말의 경로를 이용합니다.

  1. Gboard 키보드를 열고 설정으로 이동합니다.
  2. 사전 → 학습한 단어 삭제를 선택합니다.
  3. 안내된 확인 번호를 입력하고 삭제를 확정합니다.
  4. 메모 앱에서 문제가 된 단어가 다시 추천되는지 확인합니다.

이 조치는 기기에서 학습된 Gboard 단어를 삭제하는 절차입니다. 삼성 키보드의 개인 입력 데이터 삭제와는 서로 다른 설정이며, 모든 추천 단어가 없어지는 것을 보장하지 않습니다.

공식 출처: Google Gboard 문제 해결 및 단어 삭제

주의: '삼성 키보드 설정 초기화', '개인 입력 데이터 삭제', '앱 데이터 삭제', '휴대전화 전체 초기화'는 서로 다른 수준의 조치입니다. 동일한 것으로 생각하고 여러 항목을 한꺼번에 지우면 원인 확인이 어려워집니다.

9. 실제 증상을 구분하는 2분 테스트

검색을 통해 흔히 접하는 '자동완성 끄기' 설명은 추천 표시와 자동 수정을 섞어서 안내하는 경우가 있습니다. 다음처럼 설정 한 가지씩 바꾸고 결과를 기록하면 어떤 기능이 원인인지 더 쉽게 구분할 수 있습니다.

  1. 테스트 A—단어 추천: 메모 앱에 '오늘 저녁'을 입력하고 상단에 예상 단어가 뜨는지 봅니다.
  2. 테스트 B—자동 수정: 자주 엉뚱하게 고쳐지는 단어를 입력하고 스페이스바를 누릅니다. 입력한 단어가 실제로 교체되는지 확인합니다.
  3. 테스트 C—앱 차이: 같은 문장을 메모 앱과 메시지 앱에 각각 입력합니다.
  4. 테스트 D—언어 차이: 한글과 영어 입력에서 결과가 같은지 확인합니다.
  5. 설정은 한 번에 하나만 바꿉니다. 어느 설정을 조정했을 때 증상이 달라지는지 적어 두면 불필요한 데이터 삭제를 피할 수 있습니다.

이 테스트는 기능 차이를 구분하기 위한 독자가 직접 따라 할 수 있는 점검 절차입니다. 모든 갤럭시 모델에서 직접 실험했다는 의미는 아닙니다.

자주 묻는 질문

Q1. 문구 추천을 꺼도 스페이스바를 누르면 단어가 저절로 바뀌어요.

추천을 표시하는 기능과 문구 자동 수정은 구별해야 합니다. 먼저 자동 수정 항목과 적용 언어를 확인하세요. 메뉴가 없으면 사용 중인 키보드 앱·버전도 확인해야 합니다.

Q2. 자동 띄어쓰기 옵션이 사라졌는데 One UI 업데이트 오류인가요?

반드시 오류는 아닙니다. 삼성 공식 담당자 답변에 따르면 문구 추천이 꺼져 있으면 해당 옵션이 숨겨질 수 있습니다. 문구 추천을 하나 이상의 언어에 대해 켠 뒤 기타 입력 옵션을 확인해 보세요.

Q3. 개인 입력 데이터 삭제를 하면 카카오톡 대화도 삭제되나요?

삼성 키보드의 이 메뉴는 키보드가 학습한 개인 입력 데이터에 대한 조치입니다. 카카오톡 대화 백업·삭제 기능과는 목적이 다릅니다. 그렇다고 무심코 다른 앱의 저장 데이터를 함께 지우면 안 됩니다.

Q4. 개인 입력 데이터만 삭제하면 추천 단어가 하나도 안 나오나요?

그렇지 않을 수 있습니다. 삼성 담당자는 사용자 입력 기반 추천 데이터가 삭제돼도 기본으로 제공되는 추천 단어는 나타날 수 있다고 설명합니다. 추천 자체를 숨기려면 문구 추천 설정을 확인하세요.

Q5. 삼성 키보드 설정이 없고 Gboard만 보입니다.

현재 기본 키보드 또는 설치된 키보드 목록이 다른 상태일 수 있습니다. 키보드 설정 메뉴에서 사용 중인 키보드를 확인하고 Gboard 설정 → 텍스트 수정으로 이동하세요.

Q6. 키보드 추천 기능을 꺼야 개인정보가 안전해지나요?

추천 기능 표시 여부와 개인정보 보안 상태를 동일시하면 안 됩니다. 중요한 것은 현재 사용 중인 키보드의 저장·학습 설정, 입력 권한, 설치 출처를 확인하는 것입니다. 다른 사람에게 보일 수 있는 화면에서 민감한 단어 추천을 숨기고 싶다면 문구 추천이나 학습 단어 정리를 고려할 수 있습니다.

결론: 삼성 키보드는 '추천'과 '자동 수정'을 따로 끄세요

  • 추천 단어 표시가 싫다: 삼성 키보드의 문구 추천을 확인합니다.
  • 내가 쓴 단어가 저절로 바뀐다: 문구 자동 수정을 먼저 확인합니다.
  • 자동 띄어쓰기 설정이 안 보인다: 문구 추천을 켜고 기타 입력 옵션을 살펴봅니다.
  • 이상한 학습 단어가 남는다: 필요하면 개인 입력 데이터 삭제를 검토하되 모든 언어에 미치는 영향을 알아둡니다.
  • 설정이 다르다: 삼성 키보드와 Gboard를 구별하고, 해당 앱 도움말을 적용합니다.

갤럭시 키보드 자동완성 문제의 핵심은 무조건 기능을 모두 끄는 것이 아니라, 실제로 불편한 동작을 일으킨 설정을 정확히 찾는 것입니다.
