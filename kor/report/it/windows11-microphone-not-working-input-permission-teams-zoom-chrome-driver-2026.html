화상회의에 들어갔는데 상대방이 내 목소리를 듣지 못하거나, Windows 11 노트북의 마이크 표시가 아예 움직이지 않나요? Teams에서는 음소거가 풀려 있는데 목소리가 전해지지 않고, 크롬에서 온라인 면접이나 음성 녹음을 시도하면 '마이크 접근 권한이 필요합니다'라는 경고가 나타날 수도 있습니다.

이럴 때 마이크가 Windows 자체에서 작동하지 않는지, 실제로는 정상인데 특정 앱에서만 사용하지 못하는지 먼저 구분해야 합니다. 두 상황은 해결 순서가 다릅니다. 또한 헤드셋의 물리적 음소거, 잘못 선택한 입력 장치, 입력 볼륨, 데스크톱 앱 권한, 드라이버 오류는 각각 별개의 원인입니다.

이 글은 2026년 10월 25일 기준 Microsoft Windows·Teams 공식 고객지원과 Google Chrome 고객센터의 안내를 근거로 Windows 11 내장·USB·Bluetooth 마이크 확인, 앱별 권한, 녹음 테스트, 입력 볼륨, 화상회의 설정, 음성 입력 오류, 드라이버 및 오디오 서비스 문제까지 실생활에서 확인하기 쉬운 순서로 정리했습니다.

1. 먼저 구분할 것: 마이크 입력과 스피커 출력은 다릅니다

Windows에서 '소리가 안 난다'는 표현에는 서로 다른 두 가지 문제가 섞여 있습니다.

입력 장치: 내 목소리를 녹음해 보내는 장치

마이크는 내 목소리를 컴퓨터에 입력합니다. 노트북 내장 마이크, USB 마이크, 이어폰에 달린 마이크, 웹캠 마이크 등이 여기에 해당합니다.

출력 장치: 내가 상대방 목소리를 듣는 장치

스피커·이어폰·헤드폰은 컴퓨터에서 재생하는 소리를 들려줍니다. 영상회의에서 상대의 목소리는 들리지만 상대가 나를 듣지 못한다면 입력 장치에 집중해야 합니다.

상황별 구분

  • 나는 상대 소리가 들리고 상대는 내 말을 못 들음: 입력 마이크·권한·음소거 점검
  • 상대는 내 말을 듣지만 나는 아무 소리도 못 들음: 스피커·출력 기기·볼륨 점검
  • 서로 아무 소리도 들을 수 없음: 회의 앱 연결·입출력 선택·통신 설정을 각각 점검
  • 녹음 앱에서도 내 목소리가 전혀 안 들림: Windows 자체의 입력 장치·권한·하드웨어 점검

화상회의에서 목소리가 전달되지 않을 때 헤드폰 출력 음량만 올려서는 문제가 해결되지 않습니다. Windows의 설정 → 시스템 → 소리 → 입력에서 마이크를 따로 선택해야 합니다.

공식 출처: Microsoft - 마이크 입력 테스트, Microsoft - 소리 및 오디오 문제

2. 헤드셋·노트북의 물리적 음소거부터 확인하세요

Windows의 마이크 설정을 바꿔도 헤드셋 본체에 음소거 스위치가 켜져 있으면 상대방이 내 목소리를 듣지 못할 수 있습니다.

30초 점검 순서

  1. USB 마이크·유선 헤드셋·Bluetooth 이어폰이 실제로 연결돼 있는지 확인합니다.
  2. 헤드셋 선에 있는 음소거 스위치를 확인합니다.
  3. 헤드셋 붐 마이크가 들어 올려져 있을 때 자동 음소거되는 모델인지 제조사 안내를 확인합니다.
  4. 노트북 키보드에 마이크 음소거 기능 키가 있는지 살펴봅니다.
  5. Teams·줌의 통화 화면에서도 마이크 아이콘에 사선이 표시되는지 확인합니다.
  6. 마이크를 입 근처에 적절하게 배치하고 테스트합니다.

Microsoft는 Teams 마이크 문제 해결에서 실제 마이크 음소거 버튼과 붐 마이크 위치를 가장 먼저 확인하도록 안내합니다.

마이크 표시등이 빨간색이라면?

일부 노트북이나 헤드셋은 마이크가 음소거됐을 때 표시등을 켭니다. 표시등 색상과 의미는 제조사마다 달라지므로 정확한 기기 설명서를 확인하세요.

USB-C 허브나 변환 젠더를 사용한다면

스마트폰용 USB-C 이어폰·3.5mm 젠더나 일부 USB 허브는 마이크 입력을 지원하지 않거나 장치 호환성이 다를 수 있습니다. 이어폰에서 소리가 정상 재생된다고 마이크도 반드시 연결됐다고 가정하면 안 됩니다.

중요: 물리적 음소거 문제인지 확인되지 않은 상태에서 Windows 보안 권한을 모두 켜거나 드라이버를 삭제할 필요는 없습니다.

공식 출처: Microsoft - Teams에서 물리적 마이크 확인, Microsoft - 헤드셋 마이크 연결 점검

3. Windows 11에서 올바른 마이크 입력 장치 선택하기

외장 웹캠·Bluetooth 헤드셋·USB 마이크를 함께 쓰는 PC에서는 의도하지 않은 마이크가 입력 장치로 선택돼 있을 수 있습니다.

Windows 설정에서 확인

  1. Windows 키 + I로 설정을 엽니다.
  2. 시스템 → 소리를 선택합니다.
  3. 입력 항목으로 이동합니다.
  4. 말하기 또는 녹음을 위한 장치 선택에서 사용하려는 마이크를 선택합니다.
  5. 노트북 내장 마이크·웹캠 마이크·헤드셋 마이크 등 목록을 비교합니다.
  6. 실제 사용하려는 마이크 이름을 눌러 속성을 엽니다.
  7. 장치가 허용·사용 상태인지 확인합니다.

장치 이름이 헷갈린다면?

예를 들어 '마이크 배열(Microphone Array)'은 노트북에 내장된 마이크를 의미할 수 있고, USB 장치는 제품명이나 'USB Audio Device'처럼 표시될 수 있습니다.

이름만으로 확정하기 어렵다면 한 번에 하나씩 연결해 Windows의 입력 목록 변화를 확인하세요. 사용 중인 제품의 실제 이름은 제조사 설명을 참조해야 합니다.

Teams나 줌에서 입력 장치를 별도 선택했을 수도 있습니다

Windows에서 올바른 마이크를 선택하더라도 회의 앱이 자체 설정에 이전 마이크를 저장했을 수 있습니다. 따라서 Windows에서 장치를 확인한 다음 각 앱의 오디오 설정도 살펴보는 것이 좋습니다.

공식 출처: Microsoft - Windows 11 마이크 기본 입력 장치

4. Windows 11 마이크 테스트: 테스트 시작·중지·재생

마이크가 Windows 자체에서 정상 작동하는지를 판단하는 가장 직접적인 방법은 Windows에 내장된 마이크 테스트입니다.

Windows 11 마이크 테스트 순서

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 입력에서 테스트할 마이크를 선택합니다.
  3. 마이크 속성 화면으로 이동합니다.
  4. 마이크 테스트 또는 입력 테스트 항목을 찾습니다.
  5. 테스트 시작을 누릅니다.
  6. 마이크에 대고 평소 음량으로 한두 문장 이야기합니다.
  7. 테스트 중지를 누릅니다.
  8. 녹음된 샘플 재생을 눌러 자신의 목소리가 들리는지 확인합니다.

Microsoft 공식 Windows 11 도움말은 바로 이 테스트 시작 → 말하기 → 테스트 중지 → 재생 절차를 안내합니다.

테스트에서 목소리가 잘 들린다면?

Windows 입력 장치 자체가 작동하고 있다는 근거가 됩니다. Teams·줌·Chrome에서만 문제가 생긴다면 앱별 권한·마이크 선택·음소거를 우선 확인하세요.

테스트에서 아무 소리도 안 들린다면?

Windows 마이크 권한, 물리적 음소거, USB·Bluetooth 연결, 올바른 장치 선택, 입력 볼륨, 오디오 장치 드라이버 순서로 점검해야 합니다.

주의: 테스트 결과가 정상이라도 특정 앱이 다른 마이크를 사용하도록 설정됐다면 회의 중에는 여전히 목소리가 전달되지 않을 수 있습니다. Windows 테스트와 앱 테스트는 별도로 확인해야 합니다.

공식 출처: Microsoft - Windows 11 마이크 테스트 시작·중지·재생

5. Windows 11 마이크 액세스 권한 켜기: 개인정보 및 보안

Windows 11에서는 마이크가 정상 장치로 인식되더라도 개인정보 보호 설정에서 앱의 접근을 막아 두면 통화나 녹음에 사용하지 못할 수 있습니다.

Windows의 마이크 접근 권한

  1. 설정 → 개인 정보 및 보안으로 이동합니다.
  2. 앱 사용 권한 아래 마이크를 선택합니다.
  3. 마이크 액세스가 켜져 있는지 확인합니다.
  4. 앱에서 마이크에 액세스하도록 허용을 켭니다.
  5. 해당 목록에 사용하려는 앱이 표시된다면 개별 허용 상태를 확인합니다.
  6. 아래로 스크롤해 데스크톱 앱이 마이크에 액세스하도록 허용도 확인합니다.
  7. Teams·줌·녹음 앱을 다시 열고 테스트합니다.

Microsoft는 Windows 11에서 마이크가 감지되지 않거나 앱이 사용할 수 없는 경우 해당 권한을 확인하도록 안내합니다.

데스크톱 앱이 개별 목록에 나타나지 않는 이유

Microsoft 공식 설명에 따르면 일반 데스크톱 앱은 Microsoft Store 앱처럼 개별 앱의 마이크 권한 목록에 나타나지 않을 수 있습니다.

따라서 설치형 줌·일부 Teams·Chrome이 목록에 없다는 사실만으로 이상이라고 판단하면 안 됩니다. '데스크톱 앱이 마이크에 액세스하도록 허용' 설정과 프로그램 내부 권한을 함께 확인하세요.

또한 Microsoft는 일반 데스크톱 앱을 이 화면에서 앱별로 각각 허용·차단할 수 없을 수 있다고 설명합니다.

회사·학교에서 설정이 회색이라면?

조직의 보안 정책으로 사용자가 권한을 변경하지 못하게 설정됐을 수 있습니다. 관리자에게 카메라·마이크 사용 목적과 해당 앱을 알려 주고 필요한 권한을 요청하세요.

모든 웹사이트의 마이크 사용을 무조건 허용할 필요는 없습니다. Windows 전체 접근 설정과 사이트별 권한은 구분해 관리해야 합니다.

공식 출처: Microsoft - Windows 11 마이크 앱 권한, Microsoft - 마이크에 대한 앱 권한

6. 마이크 소리가 작을 때: 입력 볼륨과 배치 조절하기

상대방이 내 목소리를 듣기는 하지만 아주 작거나 먼 곳에서 말하는 것처럼 들린다면 입력 장치의 볼륨과 실제 마이크 위치를 점검하세요.

입력 볼륨 변경

  1. 설정 → 시스템 → 소리 → 입력으로 이동합니다.
  2. 사용할 마이크를 선택합니다.
  3. 입력 볼륨 슬라이더가 너무 낮게 설정되지 않았는지 확인합니다.
  4. 조금씩 높인 뒤 테스트 시작을 누릅니다.
  5. 평소 말하는 거리에서 말하고 테스트를 중지합니다.
  6. 녹음된 샘플 재생으로 음량과 잡음이 적절한지 확인합니다.

볼륨을 무조건 100으로 해야 하나요?

그렇지 않습니다. 마이크 종류·주변 소음·실제 목소리 크기에 따라 적정 수준이 달라집니다. 입력 볼륨을 지나치게 높이면 키보드 소리·주변 잡음·음성 왜곡이 커질 수 있습니다.

외장 마이크 위치 점검

헤드셋 붐 마이크가 입에서 너무 멀리 떨어지면 목소리가 작게 들어갈 수 있습니다. 노트북 내장 마이크는 화면 또는 키보드 부근에 있을 수 있으므로 제품 설명서에서 실제 마이크 위치를 확인하세요.

'마이크 증폭' 메뉴가 없으면?

Microsoft는 일부 오디오 장치에서 마이크 증폭(Microphone Boost) 설정을 제공하지만, 모든 드라이버·기기에서 표시되는 것은 아닙니다.

지원 장치의 경우 설정 → 시스템 → 소리 → 추가 사운드 설정 → 녹음 → 마이크 속성 → 수준에서 확인할 수 있습니다. 증폭을 높이면 잡음도 증가할 수 있으므로 작은 폭으로 변경하며 녹음 테스트를 반복하는 것이 좋습니다.

공식 출처: Microsoft - 입력 볼륨 조절·테스트, Microsoft - 마이크 음량·증폭

7. Teams에서만 내 목소리가 안 들릴 때: 음소거·장치 테스트

Windows 11 기본 마이크 테스트가 정상인데 Microsoft Teams 회의에서만 목소리가 전달되지 않는다면 Teams의 앱 설정을 확인하세요.

회의 도중 먼저 확인하기

  1. Teams 회의 화면에서 마이크 아이콘을 확인합니다.
  2. 아이콘에 사선이 있다면 음소거 해제를 선택합니다.
  3. 마이크 옆 설정 또는 화살표를 열어 현재 입력 장치를 확인합니다.
  4. 사용하려는 USB·Bluetooth·노트북 내장 마이크가 선택됐는지 확인합니다.
  5. 정상 목소리로 말해 다른 참가자에게 들리는지 확인합니다.

회의 시작 전 Teams 마이크 변경하기

  1. Teams 앱의 설정 및 기타(더보기) 메뉴를 엽니다.
  2. 설정 → 장치를 선택합니다.
  3. 오디오 설정에서 마이크 드롭다운을 확인합니다.
  4. 올바른 마이크를 선택합니다.
  5. 제공되는 경우 테스트 통화 걸기를 실행합니다.
  6. 화면의 안내에 따라 짧은 말을 녹음합니다.
  7. 재생된 내용을 들어 마이크가 정상인지 확인합니다.

Microsoft 공식 Teams 도움말에 따르면 테스트 통화 기능은 웹용 Teams에서 제공되지 않으며, 일부 언어 지원도 제한될 수 있습니다. 따라서 웹브라우저에서 메뉴가 없으면 Windows 마이크 테스트 또는 회의 미리보기 설정을 이용하세요.

회사용 Teams에서만 안 된다면

Windows의 마이크 액세스·데스크톱 앱 액세스와 Teams 자체의 권한을 모두 확인해야 합니다. 일부 조직은 보안 정책으로 장치 사용을 제어하므로, 설정이 잠겨 있다면 회사 IT 담당자에게 문의하세요.

Teams에서 다른 참가자가 마이크를 차단했나요?

회의 주최자의 참석자 음소거·권한 제한도 영향을 줄 수 있습니다. Windows 테스트와 Teams 장치 테스트가 모두 정상인데 마이크 버튼을 켤 수 없다면 회의 운영 정책을 확인하세요.

공식 출처: Microsoft - Teams 마이크 작동 안 함

8. 줌(Zoom)에서 마이크 안됨: Windows 권한과 입력 장치 차이

줌 회의에서 영상은 나오는데 내 목소리가 안 들리는 경우에도 Windows 전체의 마이크 설정과 줌 내부의 마이크 선택을 따로 확인해야 합니다.

줌 회의에서 확인할 순서

  1. 화면 아래의 마이크 음소거 상태를 확인합니다.
  2. 음소거되어 있다면 음소거 해제합니다.
  3. 마이크 주변의 오디오 설정 메뉴를 엽니다.
  4. 사용 중인 마이크가 실제로 연결된 기기인지 확인합니다.
  5. 기기에서 입력 볼륨·오디오 테스트가 제공되면 실행합니다.
  6. Windows 설정 → 시스템 → 소리 → 입력의 마이크 선택도 확인합니다.
  7. Windows의 개인 정보 및 보안 → 마이크 → 데스크톱 앱 접근이 켜져 있는지 살펴봅니다.

줌은 버전·계정·회의 환경에 따라 메뉴 위치나 이름이 달라질 수 있습니다. 사용 중인 줌 앱의 현재 오디오 설정을 기준으로 따라가세요.

이어폰 스피커는 되는데 마이크만 안 된다면?

출력 장치는 이어폰인데 입력 장치는 노트북 내장 마이크로 선택됐을 수 있습니다. 스피커 선택과 마이크 선택은 별개이므로 줌의 오디오 설정에서 각각 확인하세요.

회의 도중 블루투스 연결이 끊겼다면?

Bluetooth 헤드셋 배터리가 부족하거나 다른 기기로 연결이 전환됐을 수 있습니다. 다른 앱에서도 같은 현상이 발생하는지 확인한 뒤 이어폰 제조사의 공식 재페어링 절차를 검토하세요.

드라이버 재설치보다 올바른 마이크 선택·음소거 해제·Windows 접근 권한부터 확인하는 편이 실용적입니다.

Zoom 공식 마이크 테스트 경로

Zoom 공식 고객센터에 따르면 설치형 Zoom 앱에서는 **프로필 사진 → 설정(Settings) → 오디오(Audio) → 마이크 테스트(Test microphone)**를 이용할 수 있습니다. 테스트 버튼을 누른 뒤 말하면 입력 음량 표시가 움직이고 녹음된 소리가 재생됩니다. **줌 회의 참가 전 '스피커 및 마이크 테스트'**를 이용하거나, 회의 중 음소거 버튼 옆 화살표에서 다른 마이크를 선택할 수도 있습니다. 메뉴 구성은 Zoom 버전에 따라 달라질 수 있습니다.

공식 출처: Zoom - 마이크·스피커 테스트, Microsoft - Windows 앱별 마이크 권한, Microsoft - 앱의 입력 장치 확인

9. Chrome에서 '마이크 사용 허용'이 안 되면 사이트별 권한 확인

온라인 면접, 웹용 Teams, Google Meet, 웹 녹음 사이트는 Chrome의 사이트별 마이크 권한이 필요할 수 있습니다.

Chrome 마이크 접근 설정

  1. Google Chrome을 엽니다.
  2. 오른쪽 위 더보기(점 세 개) → 설정으로 이동합니다.
  3. 개인 정보 보호 및 보안 → 사이트 설정을 선택합니다.
  4. 권한 → 마이크를 엽니다.
  5. 기본 동작에서 사이트의 마이크 사용 요청을 허용할지 확인합니다.
  6. 마이크 사용이 허용되지 않음 목록에 원하는 사이트가 있는지 확인합니다.
  7. 실제로 신뢰할 수 있는 공식 회의 사이트라면 허용으로 변경합니다.
  8. 목록 상단의 기본 마이크 장치도 올바르게 선택됐는지 확인합니다.

Google의 공식 설명에 따르면 사이트에서 마이크 사용을 요청할 때 이번만 허용·사이트를 사용하는 동안 허용·허용 안 함 등 선택지가 표시될 수 있습니다.

Windows 권한도 함께 확인

Chrome에서 사이트를 허용했더라도 Windows 마이크 액세스 또는 데스크톱 앱 마이크 액세스가 꺼져 있으면 실제 마이크를 사용할 수 없을 수 있습니다.

다른 사이트는 되는데 한 사이트만 안 된다면?

그 사이트에서 이전에 **'허용 안 함'**을 선택했을 수 있습니다. Chrome의 허용·차단 목록에서 해당 사이트를 찾거나 주소창 주변의 사이트 설정을 확인하세요.

마이크를 허용하면 사이트가 언제든 녹음하나요?

Google 고객센터는 웹사이트의 녹음 가능 범위와 권한을 설명합니다. 마이크 사용 요청은 신뢰할 수 있는 사이트에만 허용하고, 사용이 끝나면 필요한 경우 사이트 권한을 철회하세요.

공식 출처: Google - Chrome 카메라·마이크 권한 관리

10. 웹캠 마이크가 따로 있는 경우: 카메라 권한도 확인하세요

외장 웹캠에는 카메라 영상과 마이크 입력 기능이 함께 들어 있는 모델이 있습니다. 카메라는 정상으로 보이지만 음성이 녹음되지 않는 경우, 실제로 어떤 마이크가 선택됐는지 확인해야 합니다.

웹캠 마이크 확인 방법

  1. 웹캠이 USB로 제대로 연결돼 있는지 확인합니다.
  2. Windows 설정 → 시스템 → 소리 → 입력으로 이동합니다.
  3. 목록에서 웹캠에 내장된 마이크가 표시되는지 확인합니다.
  4. 웹캠 마이크를 선택해 테스트 시작·중지·재생을 진행합니다.
  5. 음성이 정상 녹음된다면 Teams·줌에서도 동일한 입력 장치를 선택합니다.

카메라 접근 권한까지 필요한 이유

Microsoft는 마이크가 포함된 카메라 장치의 경우 앱에 카메라 접근 권한도 부여해야 할 수 있다고 안내합니다.

따라서 웹캠 마이크가 작동하지 않을 때는 설정 → 개인 정보 및 보안 → 마이크와 함께, 필요하다면 설정 → 개인 정보 및 보안 → 카메라도 점검하세요.

영상은 나오는데 마이크가 없을 수도 있나요?

그럴 수 있습니다. 일부 외장 웹캠은 마이크가 없거나 별도의 오디오 장치로 인식될 수 있습니다. 제품명과 실제 사양을 확인하고, 장치 관리자에서 입력 장치가 어떻게 표시되는지 살펴보세요.

주의: 개인정보 보호를 위해 카메라를 일부러 꺼 둔 경우가 있습니다. 마이크 문제를 해결하기 위해 카메라 접근을 허용해야 하는지 여부는 실제 기기와 앱 요구 조건을 확인한 뒤 결정하세요.

공식 출처: Microsoft - 웹캠 내장 마이크와 카메라 접근 권한

11. USB 마이크·유선 이어폰 인식 안 될 때 확인할 순서

Windows의 입력 장치 목록에 마이크 자체가 보이지 않으면 물리적 연결과 호환성부터 점검하는 것이 좋습니다.

USB 마이크라면

  1. 마이크 USB 케이블이 정상 연결됐는지 확인합니다.
  2. USB 허브를 사용 중이라면 가능하면 PC의 다른 USB 포트에서 시험합니다.
  3. 전원이나 음소거 버튼이 있는 모델인지 확인합니다.
  4. PC가 장치를 연결한 직후 Windows의 설정 → 시스템 → 소리 → 입력 목록에 새 장치를 표시하는지 확인합니다.
  5. 제조사 공식 설명서에서 Windows 11 지원 여부와 드라이버 필요성을 살펴봅니다.
  6. 지원되는 다른 PC가 있다면 연결해 비교할 수 있습니다.

3.5mm 유선 헤드셋이라면

일부 PC는 헤드폰 출력 잭과 마이크 입력 잭이 분리돼 있고, 스마트폰용 이어폰은 하나의 4극 플러그를 사용합니다.

이때 소리는 들리지만 마이크가 입력 장치에 나타나지 않는 이유가 잭 규격 또는 변환 케이블 호환성 때문일 수 있습니다. 컴퓨터·헤드셋 제조사 사양에 맞는 연결 방식을 확인하세요.

USB-C 이어폰이라면

일부 USB-C 오디오 제품은 특정 기기에서만 정상 작동하거나 마이크를 지원하지 않을 수 있습니다. 제품이 지원하는 Windows·USB 오디오 규격을 확인해 보세요.

중요한 연결 점검 기준

출력 소리가 들린다고 입력 마이크까지 정상 작동한다고 확정할 수 없습니다. Windows의 입력 장치 목록에 실제 마이크가 표시되고 테스트 녹음이 가능한지 따로 확인해야 합니다.

공식 출처: Microsoft - 외장 마이크 연결·인식 문제

12. 블루투스 이어폰 마이크가 안 되는 이유: 장치 연결과 프로필

Bluetooth 이어폰으로 음악은 잘 듣는데 Teams 회의에서 목소리를 보내지 못한다면 Bluetooth 연결·장치 선택·마이크 지원 상태를 확인해야 합니다.

먼저 확인할 것

  1. 이어폰과 충전 케이스 배터리가 충분한지 확인합니다.
  2. 설정 → Bluetooth 및 장치에서 이어폰이 연결됐는지 확인합니다.
  3. 이어폰이 다른 휴대전화에 자동 연결돼 있지 않은지 살펴봅니다.
  4. Windows의 시스템 → 소리 → 입력에서 이어폰 마이크가 표시되는지 확인합니다.
  5. Windows 마이크 테스트로 녹음이 되는지 살펴봅니다.
  6. 이어폰을 실제로 사용하는 Teams·줌 앱에서도 동일한 마이크를 선택합니다.

음악 재생은 되는데 마이크 입력이 없는 경우

Bluetooth 장치의 연결 상태와 지원 오디오 기능에 따라 음악 재생용 연결은 되지만 통화용 마이크가 정상적으로 사용되지 않을 수 있습니다.

Windows 11은 Bluetooth 장치와 드라이버의 기능 지원에 따라 서로 다른 통화·오디오 모드를 활용할 수 있으므로 PC·이어폰 양쪽의 실제 호환 조건을 확인해야 합니다.

다시 페어링하는 방법

  1. 설정 → Bluetooth 및 장치에서 문제의 이어폰을 선택합니다.
  2. 장치 제거를 선택합니다.
  3. 이어폰 제조사의 공식 절차에 따라 페어링 모드로 전환합니다.
  4. Windows의 장치 추가 → Bluetooth를 누릅니다.
  5. 이어폰을 선택해 다시 연결합니다.
  6. 시스템 → 소리 → 입력에서 테스트합니다.

마이크를 사용하면 음악 음질이 달라질 수 있나요?

일부 Bluetooth 오디오 구성에서는 마이크를 사용하면서 재생 오디오의 품질이나 방식이 달라질 수 있습니다. 이는 이어폰의 지원 기능, Bluetooth 칩셋, 드라이버 및 Windows 버전과 관련이 있습니다.

장치가 Bluetooth LE Audio와 마이크 사용 중 스테레오를 지원하는지는 하드웨어별로 달라 모든 Windows 11 PC에서 같은 품질을 보장할 수 없습니다.

공식 출처: Microsoft - 마이크·Bluetooth 헤드셋 연결, Microsoft - Bluetooth 오디오 연결 점검

13. '입력 장치를 찾을 수 없음'이 표시되면 장치 관리자 확인

Windows 설정 → 시스템 → 소리에서 입력 장치가 전혀 보이지 않는다면 단순 Teams 음소거 오류보다 장치 인식·드라이버·하드웨어 문제를 살펴봐야 합니다.

장치 관리자에서 확인

  1. Windows 시작 버튼을 오른쪽 클릭합니다.
  2. 장치 관리자를 엽니다.
  3. 오디오 입력 및 출력 범주를 펼칩니다.
  4. 소리, 비디오 및 게임 컨트롤러 항목도 확인합니다.
  5. 마이크나 오디오 장치에 노란색 경고 표시가 있는지 살펴봅니다.
  6. 해당 장치가 사용 안 함이라면 디바이스 사용 메뉴가 제공되는지 확인합니다.
  7. 오류 코드와 실제 장치 이름을 기록합니다.

장치가 목록에 보이지 않을 때

장치 관리자에서 동작 → 하드웨어 변경 사항 검색을 실행해 Windows가 연결 상태를 다시 확인하도록 할 수 있습니다. 다만 하드웨어가 손상됐거나 호환 드라이버가 없으면 검색만으로 해결되지 않을 수 있습니다.

잘못된 장치를 삭제하지 마세요

오디오 입력·출력에는 노트북 내장 스피커, 모니터 오디오, Bluetooth 장치, 가상 오디오 드라이버 등이 함께 표시될 수 있습니다.

모든 오디오 장치를 한꺼번에 제거하면 정상적으로 작동하던 스피커·마이크까지 영향을 받을 수 있습니다. 정확히 어떤 장치에 문제가 있는지 확인한 뒤 제한된 범위에서 작업하세요.

공식 출처: Microsoft - 헤드셋·웹캠·마이크를 감지하지 못할 때

14. Windows 11 마이크 문제 해결사 실행하기

Windows의 기본 테스트와 권한·입력 장치 설정을 확인했는데도 문제가 계속되면 Microsoft의 오디오 문제 해결사를 이용할 수 있습니다.

Windows 소리 설정에서 진단

  1. 설정 → 시스템 → 소리를 엽니다.
  2. 아래쪽의 고급 또는 일반적인 소리 문제 해결 관련 항목을 찾습니다.
  3. 입력 장치 문제 해결을 선택합니다.
  4. 화면의 질문에 따라 현재 문제가 있는 마이크를 지정합니다.
  5. 자동 진단 결과를 확인합니다.
  6. 권장 조치를 적용한 뒤 마이크 테스트를 다시 실행합니다.

Microsoft의 Windows 마이크 도움말은 바로 설정 → 시스템 → 소리 → 고급 → 일반적인 소리 문제 해결 → 입력 장치 경로를 안내합니다.

도움말 보기(Get Help)와의 관계

일부 Windows 11 버전에서는 문제 해결 작업이 도움말 보기(Get Help) 앱으로 연결될 수 있습니다. Microsoft 공식 안내가 자동 진단 도구를 제공한다면 운영체제에 표시되는 경로를 따라 진행하세요.

문제 해결사가 '문제 없음'이라고 하면?

마이크 하드웨어가 100% 정상이라는 뜻은 아닙니다. Windows 기본 테스트·특정 앱 권한·USB·Bluetooth 연결·드라이버를 각각 확인해야 합니다.

업무용 PC에서는 자동 도구가 보안 설정을 바꾸도록 요구하면 관리자 승인 여부를 확인하는 것이 좋습니다.

15. 윈도우 업데이트 후 마이크 안됨: 오디오 드라이버 확인

Windows 11 업데이트 뒤 마이크가 갑자기 인식되지 않거나 입력 소리가 비정상적으로 작아졌다면 오디오 드라이버와 Windows 업데이트를 확인할 필요가 있습니다.

Windows 업데이트에서 드라이버 확인

  1. 설정 → Windows 업데이트를 엽니다.
  2. 업데이트 확인을 누릅니다.
  3. 오디오 관련 업데이트가 제공되는지 확인합니다.
  4. 고급 옵션 → 선택적 업데이트가 제공된다면 장치 드라이버 관련 항목도 살펴봅니다.
  5. 현재 기기와 호환되는 공식 업데이트를 설치합니다.
  6. 재시작 안내가 나오면 열린 작업을 저장하고 PC를 다시 시작합니다.
  7. 설정 → 시스템 → 소리 → 입력에서 마이크 테스트를 진행합니다.

Microsoft는 Windows 업데이트를 오디오 드라이버를 최신 상태로 유지하는 권장 방법으로 안내합니다. 업데이트가 제공되지 않는 경우에는 PC 제조사의 실제 모델명에 맞는 공식 드라이버를 확인하세요.

장치 관리자에서 업데이트

  1. 시작 메뉴를 오른쪽 클릭해 장치 관리자를 엽니다.
  2. 소리, 비디오 및 게임 컨트롤러를 펼칩니다.
  3. 현재 오디오 장치를 정확히 확인합니다.
  4. 해당 장치를 오른쪽 클릭해 드라이버 업데이트를 선택합니다.
  5. 드라이버 자동 검색을 실행합니다.
  6. 필요한 경우 제조사 공식 드라이버를 확인합니다.

드라이버 제거·재설치는 신중하게

Microsoft 공식 도움말은 다른 조치로 해결되지 않고 마이크가 아예 감지되지 않으면 오디오 드라이버 제거 후 PC 재시작을 검토할 수 있다고 안내합니다.

하지만 회사 PC·중요한 원격 작업 중인 PC·복구 파일을 준비하지 않은 개인 PC에서는 영향이 클 수 있습니다. 제거 전에는 제조사 공식 설치 파일을 확보하고, 현재 드라이버·장치 이름과 오류 코드를 기록하세요.

PC를 재시작하면 Windows가 드라이버를 자동으로 다시 설치하려 시도할 수 있지만 항상 성공한다고 보장할 수는 없습니다. 자동 복원 실패 시 공식 드라이버로 복구할 수 있도록 대비하세요.

업데이트 직후부터 오류가 시작됐다면?

드라이버 속성에 드라이버 롤백 버튼이 활성화돼 있는지 확인할 수 있습니다. 이전 드라이버가 저장돼 있지 않으면 해당 옵션이 제공되지 않을 수 있으므로 비공식 복구 파일을 무리하게 설치하지 마세요.

우선순위: Windows 마이크 테스트 → 입력 권한 → 앱 설정 → 공식 드라이버 업데이트 → 문제가 지속될 때 재설치 검토입니다.

공식 출처: Microsoft - Windows 오디오 드라이버 업데이트, Microsoft - 마이크 감지 실패·드라이버 재설치

16. Windows 음성 입력(Windows 키 + H)이 안 된다면?

Teams·줌 통화와 별도로 Windows 키 + H를 눌러 사용하는 음성 입력이 작동하지 않을 수 있습니다.

Microsoft의 공식 Windows 음성 입력(Voice Typing) 도움말은 이 기능이 Windows 11에서 지원되는 언어·마이크·인터넷 연결 등을 필요로 한다고 설명합니다.

기본 점검 순서

  1. 음성으로 글을 입력할 수 있는 텍스트 입력창을 선택합니다.
  2. Windows 키 + H를 눌러 음성 입력 창을 엽니다.
  3. Windows의 설정 → 시스템 → 소리 → 입력에 원하는 마이크가 선택돼 있는지 확인합니다.
  4. 설정 → 개인 정보 및 보안 → 마이크에서 접근 권한을 확인합니다.
  5. 실제 인터넷 연결이 정상인지 확인합니다.
  6. 사용하려는 언어가 음성 입력 기능에서 지원되는지 확인합니다.
  7. Windows 마이크 테스트로 소리가 녹음되는지 비교합니다.

'음성 입력에는 마이크에 대한 액세스 권한이 필요합니다'라고 나온다면?

마이크 개인정보 보호 설정이 꺼져 있을 수 있습니다. 설정 → 개인 정보 및 보안 → 마이크에서 필요한 권한을 확인하세요.

'음성 입력을 사용하는 동안 문제가 발생했습니다'라고 나온다면?

네트워크·언어·마이크 장치·Windows 음성 입력 서비스 상태가 원인일 수 있습니다. Microsoft 공식 오류 안내에 따라 문제를 구분하세요.

마이크 녹음은 되는데 Windows 키 + H만 작동하지 않으면?

마이크 하드웨어 고장이라고 단정하기 어렵습니다. 음성 입력 기능 자체에 필요한 언어 지원, 네트워크 상태 또는 앱·텍스트 입력 환경을 점검해야 합니다.

개인정보 주의: 민감한 고객 정보나 비밀번호를 음성 입력할 때는 사용 중인 서비스의 음성 처리·개인정보 정책을 확인하세요.

공식 출처: Microsoft - Windows 11 음성 입력이 작동하지 않을 때

17. 회사·학교 PC와 원격 데스크톱에서는 설정이 다를 수 있습니다

마이크 사용 권한이 회색으로 고정되거나, 개인 PC에서는 정상인데 회사 PC에서만 작동하지 않는다면 조직 보안 정책 또는 원격 연결 설정을 확인해야 합니다.

업무용 Windows의 권한 문제

회사·학교가 관리하는 PC에서는 마이크 접근 허용·장치 드라이버·앱 설치를 IT 관리자가 제한할 수 있습니다.

이럴 때 레지스트리·그룹 정책을 임의 편집해 마이크 사용을 강제로 허용하는 방식은 보안 정책과 충돌할 수 있습니다. 해당 회의·업무에 마이크가 필요하다는 사실을 관리자에게 전달하고 승인받는 것이 적절합니다.

원격 데스크톱에서만 마이크가 안 된다면?

Microsoft Teams의 공식 도움말은 원격 데스크톱 환경에서 로컬 컴퓨터의 마이크를 원격 세션으로 전달하는 설정을 확인하도록 안내합니다.

  1. Windows에서 원격 데스크톱 연결을 검색합니다.
  2. 로컬 리소스 탭을 엽니다.
  3. 원격 오디오 → 설정을 확인합니다.
  4. 원격 오디오 녹음 항목이 제공되는지 살펴봅니다.
  5. 업무 목적에 따라 관리자가 허용한 녹음 옵션을 선택합니다.
  6. 원격 세션을 다시 연결하고 마이크가 전달되는지 테스트합니다.

주의: 조직에서 원격 녹음을 차단한 이유가 개인정보·보안 정책일 수 있습니다. 무단으로 우회 설정을 적용하지 마세요.

상담 전에 기록하면 좋은 정보

  • Windows 11 버전·노트북 모델
  • 마이크 종류: 내장·USB·Bluetooth·웹캠
  • Windows 입력 장치 목록에 표시되는지
  • Windows 마이크 테스트 결과
  • 특정 앱에서만 오류가 발생하는지
  • 오류 메시지와 최근 업데이트 일자
  • 회사 관리 기기 또는 원격 연결 환경인지

이 정보를 정리하면 문제가 하드웨어·Windows·프로그램·조직 정책 중 어디에 있는지 더 빠르게 구분할 수 있습니다.

자주 묻는 질문 FAQ

Q1. 윈도우11 마이크가 안 될 때 가장 먼저 어디를 확인하나요?

설정 → 시스템 → 소리 → 입력에서 실제 마이크를 선택하고 테스트 시작 → 말하기 → 테스트 중지 → 재생을 실행하세요. Windows 테스트가 정상이라면 회의 앱의 음소거·입력 장치·접근 권한을 확인합니다.

Q2. Windows 11에서 마이크 사용 권한은 어떻게 켜나요?

설정 → 개인 정보 및 보안 → 마이크에서 마이크 액세스, 앱에서 마이크에 액세스하도록 허용, 데스크톱 앱이 마이크에 액세스하도록 허용을 확인하세요. 회사 관리 PC는 설정 변경이 제한될 수 있습니다.

Q3. 마이크는 연결됐는데 Teams에서 목소리가 안 들립니다

Teams의 마이크 음소거 상태, 설정 → 장치 → 마이크에서 사용 중인 장치를 확인하세요. 지원되는 Teams 앱에서 테스트 통화를 사용할 수 있지만 웹용 Teams에서는 제공되지 않을 수 있습니다.

Q4. 줌에서 내 목소리만 안 들리는 이유는?

줌 자체의 음소거, 입력 마이크 선택, Windows의 마이크 접근 권한이 원인일 수 있습니다. Windows 마이크 테스트가 정상인지 확인한 뒤 줌 오디오 설정에서 같은 장치를 선택하세요.

Q5. Chrome에서 마이크 사용을 허용했는데도 안 됩니다

Chrome의 설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 마이크에서 해당 사이트의 허용 상태와 기본 장치를 확인하세요. Windows의 데스크톱 앱 마이크 액세스도 켜져 있어야 할 수 있습니다.

Q6. 마이크 입력 볼륨을 100으로 해야 하나요?

아닙니다. 사용 중인 마이크의 민감도·입과의 거리·주변 소음에 따라 적절한 수준이 다릅니다. 설정 → 시스템 → 소리 → 입력에서 테스트 녹음을 들으며 볼륨을 조절하세요. 너무 높으면 잡음이나 왜곡이 증가할 수 있습니다.

Q7. 이어폰 소리는 잘 들리는데 마이크만 안 되는 이유는?

이어폰 출력과 마이크 입력은 별도로 선택됩니다. Windows의 입력 장치에 이어폰 마이크가 보이는지, 음소거 버튼·Bluetooth 연결·유선 잭·USB-C 호환성이 맞는지 확인하세요.

Q8. 윈도우11 마이크가 아예 장치 목록에서 사라졌습니다

USB·Bluetooth 연결을 확인하고 장치 관리자 → 오디오 입력 및 출력 / 소리, 비디오 및 게임 컨트롤러에서 장치 인식과 오류 코드를 살펴보세요. Windows 업데이트와 제조사 공식 드라이버를 점검하는 것이 좋습니다.

Q9. Windows 키 + H 음성 입력이 안 될 때도 마이크 고장인가요?

그렇다고 단정할 수 없습니다. 음성 입력에는 마이크 설정 외에 텍스트 입력창, 지원 언어·인터넷 연결 등이 영향을 줄 수 있습니다. Windows 기본 마이크 테스트 결과와 Microsoft 공식 음성 입력 오류 안내를 비교하세요.

Q10. 마이크 문제를 해결하려고 오디오 드라이버를 전부 삭제해도 되나요?

권장하지 않습니다. 마이크 권한이나 잘못된 입력 장치가 원인일 수 있고, 모든 드라이버를 제거하면 정상 스피커에도 영향을 줄 수 있습니다. 먼저 기본 점검을 진행한 뒤, 정확한 장치와 제조사 공식 복구 드라이버를 확인하고 필요한 경우에만 재설치를 검토하세요.

마무리: Windows 마이크 테스트가 정상인지부터 판단하세요

윈도우11에서 마이크가 작동하지 않을 때 가장 효율적인 첫 단계는 시스템 → 소리 → 입력에서 실제 마이크를 고르고 목소리를 테스트하는 것입니다. 여기서 정상적으로 녹음된다면 Teams·줌·Chrome의 개별 앱 설정과 권한을 먼저 점검하세요.

반대로 Windows에서 마이크 자체가 보이지 않거나 테스트 녹음에 아무 소리도 없다면 물리적 연결·음소거·입력 권한·장치 관리자·드라이버 순서로 원인을 좁혀야 합니다.

특히 마이크와 스피커는 다른 장치이므로 이어폰 소리가 들린다고 마이크까지 정상이라는 뜻은 아닙니다. Windows와 앱의 입출력 설정을 각각 확인하고, 드라이버를 제거해야 할 정도의 문제가 의심된다면 제조사 공식 복구 방법을 먼저 확보하는 것이 좋습니다.
