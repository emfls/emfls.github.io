갤럭시 화면이 15~30초 만에 꺼져서 레시피를 보거나 글을 읽을 때 불편할 수 있습니다. 반대로 화면을 사용하지 않는데 계속 켜져 있거나, 화면 자동 꺼짐 시간을 10분으로 설정했는데 다시 30초로 바뀌는 현상도 있습니다.

먼저 확인할 메뉴는 '설정 → 디스플레이 → 화면 자동 꺼짐 시간'입니다. 삼성 공식 안내에 따르면 일반적인 갤럭시 화면 자동 꺼짐 시간은 15초부터 최대 10분까지 선택할 수 있습니다. 화면을 읽는 동안 꺼지지 않게 하려면 별도의 '사용 중일 때 화면을 켠 채로 유지' 기능을 확인하세요. 화면이 어두워지는 문제와 잠금화면에서 비밀번호를 요구하는 시점은 서로 다르게 설정됩니다.

자료 검증일: 2026년 11월 4일. 삼성전자 공식 고객지원 자료를 기반으로 작성했습니다. 갤럭시 모델·One UI 버전·통신사에 따라 메뉴명과 지원 기능은 달라질 수 있습니다. 실제 기기에서 측정하지 않은 배터리 소모율이나 해결 성공률은 제시하지 않았습니다.

1. 갤럭시 화면 꺼짐 문제: 증상별 빠른 해결표

증상가장 먼저 확인할 설정의미
화면이 15~30초 만에 꺼짐디스플레이 → 화면 자동 꺼짐 시간선택된 대기 시간이 짧을 수 있음
화면이 10분 이상 켜졌으면 좋겠음사용 중일 때 화면을 켠 채로 유지화면 주시를 감지할 때 계속 켜기
설정한 시간이 다시 30초가 됨배터리 → 절전 모드일부 One UI에서 절전이 시간을 변경
화면이 꺼졌지만 시계는 표시됨잠금화면 및 AOD일반 화면이 아니라 Always On Display일 수 있음
밝기만 어두워지고 화면은 켜져 있음디스플레이 → 밝기 최적화자동 밝기 조절과 화면 끄기는 별개
화면은 꺼졌지만 한동안 잠금이 풀림보안 잠금 상세 설정꺼진 뒤 잠길 때까지의 시간 확인
통화할 때만 화면이 꺼짐근접 센서·케이스·보호필름통화 중 얼굴 접촉 방지 기능
케이스를 열거나 닫을 때 화면 변화유용한 기능 → 액세서리특정 커버의 자동 화면 켜기·끄기
갑자기 화면이 꺼지거나 멈춤재시작·업데이트·기기 상태단순한 대기시간 설정과 구분

진단 원칙: 화면이 어두워짐, 완전히 꺼짐, 잠김, AOD로 시계만 남음은 서로 다른 현상입니다. 어느 단계에서 문제가 생기는지 먼저 나눠야 불필요한 초기화를 피할 수 있습니다.

삼성 공식 근거: https://www.samsung.com/us/support/troubleshoot/TSG10001446/

2. 갤럭시 화면 자동 꺼짐 시간 설정하는 방법

가장 흔한 해결 방법입니다.

  1. 갤럭시에서 설정 앱을 엽니다.
  2. 디스플레이를 선택합니다.
  3. 화면 자동 꺼짐 시간을 누릅니다.
  4. 표시되는 옵션 가운데 원하는 시간을 선택합니다.
  5. 홈 화면으로 돌아가 화면을 건드리지 않고 실제로 꺼지는 시간을 관찰합니다.

일부 모델에서는 15초, 30초, 1분, 2분, 5분, 10분 같은 옵션이 제공됩니다. 선택 가능한 정확한 목록은 기종과 버전에 따라 다를 수 있습니다.

10분으로 바꿨다고 해서 전화나 영상 재생 등 모든 상황에서 반드시 정확히 10분 뒤 화면이 꺼지는 것은 아닙니다. 화면을 사용 중이거나 별도의 화면 유지 기능이 작동하면 실제 동작이 달라질 수 있습니다.

삼성 공식 안내는 일반적인 갤럭시 화면 자동 꺼짐 시간을 15초에서 최대 10분까지 조정할 수 있다고 설명합니다.

출처: https://www.samsung.com/ae/support/mobile-devices/adjusting-screen-timeout-on-my-samsung-phone/

3. 왜 30초가 기본으로 표시되나요?

삼성의 배터리 최적화 문서는 일부 갤럭시의 기본 화면 꺼짐 시간이 30초로 설정될 수 있다고 안내합니다. 이는 배터리를 덜 쓰도록 화면이 자동으로 꺼지는 전원 관리 기능입니다.

화면을 오래 켜둘수록 일반적으로 배터리 사용이 늘어날 수 있으므로, 시간을 변경할 때는 사용 목적을 기준으로 선택하는 편이 좋습니다.

사용하는 상황고려할 설정주의사항
메신저·짧은 확인 위주30초~1분배터리 절약에 유리할 수 있음
긴 기사·문서 읽기2~5분화면이 켜진 채 방치되지 않도록 확인
레시피·악보·작업 순서 보기5~10분화면 장시간 켜짐에 따른 배터리 사용
화면을 보고 있는 동안만 유지화면 주시 감지 기능지원 모델·감지 조건에 따라 다름
화면이 계속 켜진 채로 방치됨짧은 꺼짐 시간주변 사람의 화면 노출도 줄일 수 있음

표의 시간대는 사용 시나리오에 따른 예시이며, 삼성의 절대적인 권장 시간이나 측정된 배터리 수치는 아닙니다.

출처: https://www.samsung.com/us/support/answer/ANS10002534/

4. 갤럭시 화면 자동 꺼짐은 10분 이상 설정할 수 없나요?

삼성 공식 고객지원은 일반적인 화면 자동 꺼짐 시간의 최대값을 10분이라고 안내합니다. 따라서 해당 설정의 목록에 30분·1시간·항상 켜짐이 보이지 않는 것이 고장이라는 의미는 아닙니다.

무조건 10분 이상 켜두는 설정과 화면을 보고 있을 때 계속 켜두는 기능은 다릅니다. 일반적인 화면 꺼짐 시간 옵션 자체를 임의로 늘리는 비공식 앱·개발자 옵션을 무조건 추천하지 않습니다.

영상 재생·내비게이션·전자책처럼 특정 앱에서 화면을 유지하는 기능이 제공되는 경우, 실제 동작이 화면 자동 꺼짐 시간과 달라질 수 있습니다. 그러나 이를 모든 앱과 모든 모델에서 동일한 동작으로 일반화할 수 없습니다.

업무용·공용 기기 주의: 회사나 학교에서 화면 잠금 정책을 관리한다면 일반 사용자 설정으로 허용되지 않는 경우도 있습니다. 관리 정책을 우회하는 방법은 권장하지 않습니다.

출처: https://www.samsung.com/us/support/answer/ANS10003431/

5. 화면을 보는 동안 계속 켜두기: '사용 중일 때 화면을 켠 채로 유지'

삼성 공식 안내에는 Keep screen on while viewing 기능이 있습니다. 구형 소프트웨어에서는 Smart stay라고 표시됐을 수 있습니다.

켜는 방법

  1. 설정 앱을 엽니다.
  2. 설정 검색창에 '사용 중일 때 화면을 켠 채로 유지' 또는 유사한 표현을 입력합니다.
  3. 검색된 설정을 선택합니다.
  4. 기능이 제공된다면 스위치를 켭니다.
  5. 화면을 마주 보면서 일정 시간 기다려 작동 여부를 확인합니다.

이 기능은 기기의 전면 카메라 등을 이용해 사용자가 화면을 보고 있는지 감지해 화면을 유지하도록 설계돼 있습니다. 기종에 따라 유용한 기능 → 모션 및 제스처 안에 있는 경우도 있으므로 검색 기능으로 찾는 편이 정확합니다.

주의할 점

  • 모든 모델·One UI 버전에서 제공되지는 않습니다.
  • 전면 카메라가 가려져 있거나 사용자를 제대로 인식하지 못하면 예상대로 작동하지 않을 수 있습니다.
  • 화면을 보고 있지 않을 때까지 무조건 계속 켜두는 기능은 아닙니다.
  • 이 기능이 켜져 있다고 잠금화면 비밀번호 요구를 해제하는 것은 아닙니다.

출처: https://www.samsung.com/us/support/troubleshoot/TSG10001446/

6. 10분으로 설정했는데 다시 30초로 돌아가는 이유

설정한 화면 자동 꺼짐 시간이 갑자기 짧아졌다면 절전 모드를 확인하세요.

삼성의 One UI 7 공식 문제 해결 문서는 배터리 절전 모드에 '화면 자동 꺼짐 시간을 30초로 설정(Set Screen timeout to 30 seconds)' 옵션이 추가될 수 있다고 안내합니다.

절전 모드 확인 순서

  1. 설정 → 배터리로 이동합니다.
  2. 절전 모드를 선택합니다.
  3. 화면 자동 꺼짐 시간을 30초로 설정에 해당하는 옵션이 있는지 확인합니다.
  4. 평소보다 화면이 빨리 꺼지는 현상과 절전 모드가 켜진 시점을 비교합니다.
  5. 필요하다면 해당 절전 기능을 조정하고 디스플레이 → 화면 자동 꺼짐 시간을 다시 설정합니다.
  6. 이후 절전 모드를 다시 켰을 때 시간이 변하는지 확인합니다.

메뉴 제공 여부: 이 항목은 One UI 버전 및 모델에 따라 제공 여부가 다를 수 있습니다. 절전 모드를 끄면 다른 배터리 절약 기능도 함께 영향을 받을 수 있어, 필요한 경우 30초 설정 옵션만 조정할 수 있는지 확인하세요.

'설정이 자꾸 원래대로 돌아간다'는 증상을 소프트웨어 고장으로 단정하기 전에 가장 먼저 확인할 항목 중 하나입니다.

출처: https://www.samsung.com/us/support/troubleshoot/TSG10005233/

7. 화면이 어두워지는 것과 자동으로 꺼지는 것은 다릅니다

갤럭시 화면이 갑자기 어두워졌지만 여전히 터치·스크롤이 된다면 밝기 최적화(Adaptive brightness) 설정이 관여할 수 있습니다.

밝기 조절 확인

  1. 설정 → 디스플레이를 엽니다.
  2. 밝기 최적화 또는 Adaptive brightness가 켜져 있는지 확인합니다.
  3. 밝기가 지나치게 자주 변한다면 해당 기능을 잠시 꺼서 비교합니다.
  4. 밝기 슬라이더로 원하는 밝기를 설정합니다.
  5. 이후 화면이 어두워지는지, 실제로 꺼지는지를 구분해 관찰합니다.

삼성 공식 설명은 주변 밝기에 따라 화면이 밝아졌다 어두워지는 현상을 자동 밝기 조절의 정상 동작으로 설명합니다.

중요: 밝기 최적화를 꺼도 화면 자동 꺼짐 시간 자체가 변경되는 것은 아닙니다. 화면을 10분 유지하고 싶은 경우에는 디스플레이 → 화면 자동 꺼짐 시간을 따로 바꿔야 합니다.

출처: https://www.samsung.com/us/support/answer/ANS10003431/

8. 화면은 꺼지는데 시계가 남아 있으면: Always On Display 확인

화면 전체가 켜져 있는 것이 아니라 검은 배경에 시계·날짜·알림 정보만 보이는 경우라면 Always On Display(AOD)를 확인하세요.

AOD 설정 확인

  1. 설정 → 잠금화면 및 AOD로 이동합니다.
  2. Always On Display 항목을 엽니다.
  3. 지원 모델에서는 항상 표시·탭하여 표시·예약 시간에 표시·새 알림 시 표시 등 옵션을 확인할 수 있습니다.
  4. 원하는 표시 방식으로 변경하거나 기능을 끕니다.

AOD와 화면 꺼짐 시간의 차이

기능조정하는 것
화면 자동 꺼짐 시간일반 사용 화면이 비활동 후 꺼지는 시점
AOD일반 화면이 꺼진 뒤 잠금 상태에서 시계·정보가 표시되는 방식
자동 잠금 시간화면이 꺼진 후 PIN 등 잠금을 요구하는 시점

AOD가 켜져 있다고 해서 앱을 보는 일반 화면이 계속 켜진 것으로 볼 수는 없습니다. 특정 모델에서 AOD가 제공되지 않을 수도 있습니다.

출처: https://www.samsung.com/us/support/troubleshoot/TSG10001538/

9. 화면 꺼짐 시간과 '꺼진 뒤 잠기는 시간'의 차이

화면이 꺼진 뒤 다시 전원 버튼을 눌렀을 때 곧바로 PIN을 요구할 수도 있고 잠시 잠금 없이 열릴 수도 있습니다. 이는 화면을 끄는 시간과 잠금 보안 설정이 분리돼 있기 때문입니다.

삼성 공식 문서는 일부 기기에서 Auto lock when screen turns off(화면이 꺼진 후 자동 잠금) 기능을 안내합니다.

확인 방법

  1. 설정 → 잠금화면 및 AOD를 확인합니다.
  2. 보안 잠금 상세 설정(Secure lock settings)을 엽니다.
  3. 설정한 PIN·패턴·비밀번호로 본인 인증합니다.
  4. 화면이 꺼진 후 자동 잠금에 해당하는 항목을 확인합니다.
  5. 휴대전화를 분실하거나 자리를 비웠을 때의 보안 위험을 고려해 시간을 설정합니다.

주의: 화면 꺼짐 시간 5분을 선택했다고 잠금 해제 상태가 5분 동안 유지되는 것은 아닙니다. 또한 측면 버튼으로 즉시 잠금 설정이 켜져 있으면 보안 동작이 달라질 수 있습니다.

특히 휴대전화에 금융 앱·개인 문서가 많다면 편의를 위해 자동 잠금 시간을 무리하게 늘리는 것은 권장하지 않습니다.

출처: https://www.samsung.com/us/support/answer/ANS10003431/

10. 통화할 때만 화면이 꺼지는 경우

전화 통화 중 화면이 어두워지거나 꺼지는 것은 근접 센서가 얼굴이나 물체가 가까운지를 감지하기 때문일 수 있습니다.

삼성은 통화 중 화면이 예상과 다르게 꺼지거나 켜진다면 근접 센서 주변의 케이스·액정보호필름·먼지를 확인하도록 안내합니다.

확인할 항목

  1. 통화 중에만 문제가 생기는지, 일반 화면에서도 생기는지 구분합니다.
  2. 화면 상단 센서 주변에 두꺼운 필름·케이스·이물질이 있는지 살펴봅니다.
  3. 부드러운 극세사 천으로 오염된 부분을 조심스럽게 닦습니다.
  4. 통화하지 않는 일반 화면에서 화면 자동 꺼짐 시간이 정상 작동하는지 확인합니다.
  5. 통화 화면이 계속 비정상적으로 작동하면 공식 서비스에서 센서 상태를 점검합니다.

중요: 통화 중 화면이 꺼지는 현상을 해결하려고 일반 화면 자동 꺼짐 시간을 10분으로 늘려도, 센서 관련 문제를 해결하는 방법이 아닐 수 있습니다.

출처: https://www.samsung.com/us/support/answer/ANS10003431/

11. 케이스를 열거나 닫으면 화면이 저절로 꺼질 때

특정 갤럭시 커버나 액세서리는 덮개를 닫거나 열 때 화면을 자동으로 켜고 끄는 기능을 지원합니다. 이런 액세서리를 사용하면 화면 자동 꺼짐 시간과 관계없는 화면 전환이 발생할 수 있습니다.

점검 방법

  1. 사용 중인 케이스가 화면을 덮는 형태의 스마트 커버인지 확인합니다.
  2. 설정 → 유용한 기능 → 액세서리 메뉴가 있는지 확인합니다.
  3. 지원 제품이라면 자동 화면 켜기 및 끄기(Auto screen on and off) 옵션을 살펴봅니다.
  4. 케이스를 연 상태와 닫은 상태를 비교해 화면이 언제 꺼지는지 확인합니다.
  5. 안전하게 분리할 수 있는 케이스라면 케이스를 분리한 상태에서 짧게 비교해 봅니다.

삼성은 이 설정이 일부 특정 케이스를 사용할 때에만 나타난다고 명시합니다. 따라서 내 갤럭시에 액세서리 메뉴가 보이지 않는다고 오류라고 판단하면 안 됩니다.

출처: https://www.samsung.com/us/support/troubleshoot/TSG10001446/

12. 화면 꺼짐 시간이 계속 달라질 때: 재시작·업데이트

화면 자동 꺼짐 시간을 변경했지만 현상이 반복된다면 다음을 점검하세요.

  1. 배터리 → 절전 모드에서 화면 시간을 변경하는 옵션이 있는지 확인합니다.
  2. 유용한 기능 → 모션 및 제스처에서 화면 주시 관련 설정을 확인합니다.
  3. 케이스의 자동 화면 전환 기능을 사용하는지 확인합니다.
  4. 필요하면 정상 재시작한 뒤 같은 상황에서 다시 시험합니다.
  5. 설정 → 소프트웨어 업데이트에서 공식 업데이트를 확인합니다.
  6. 현상이 계속되면 Samsung Members를 이용해 모델·One UI 버전·발생 시각·화면 녹화 가능 여부 등을 정리해 문의합니다.

삼성의 2026년 공식 화면 문제 해결 문서는 일시적인 시스템 오류·오래된 소프트웨어·앱 호환성·물리적 손상이 비정상적인 화면 동작에 관여할 수 있다고 안내합니다.

공장 초기화는 우선 조치가 아닙니다. 화면 설정과 절전 모드, 업데이트·재시작 결과를 먼저 확인해야 합니다.

출처: https://www.samsung.com/us/support/troubleshoot/TSG10013258/

13. 화면이 꺼지지 않을 때도 먼저 설정을 확인하세요

반대로 화면이 사용하지 않는데 계속 켜져 있다면 확인 순서를 반대로 적용할 수 있습니다.

  1. 디스플레이 → 화면 자동 꺼짐 시간이 10분 등 긴 시간으로 설정돼 있는지 확인합니다.
  2. 사용 중일 때 화면을 켠 채로 유지가 활성화됐는지 확인합니다.
  3. 동영상·내비게이션 등 화면 유지 기능을 사용하는 특정 앱에서만 그런지 확인합니다.
  4. AOD 시계 표시를 일반 화면이 계속 켜진 것으로 오해한 것은 아닌지 살펴봅니다.
  5. 특정 앱을 종료한 뒤 일반 홈 화면에서도 계속 켜져 있는지 비교합니다.
  6. 계속 비정상적이면 재시작·공식 업데이트·서비스 점검을 검토합니다.

배터리와 개인정보 보호: 화면을 오래 켜 두면 배터리 사용량이 커질 수 있고 주변 사람에게 화면 내용이 노출될 수 있습니다. 보안이 필요한 환경이라면 짧은 화면 꺼짐 시간과 즉시 잠금 설정을 함께 고려하세요.

출처: https://www.samsung.com/us/support/answer/ANS10002534/

14. 잘못 알려진 설정 방법 5가지

오해 1: '화면 자동 꺼짐 시간'을 무제한으로 늘릴 수 있다. 삼성 공식 안내의 일반 화면 자동 꺼짐 최대값은 10분입니다. 화면 주시 감지나 앱별 동작은 별개입니다.

오해 2: 화면 밝기 최적화를 끄면 화면이 절대 꺼지지 않는다. 밝기 최적화는 주변 밝기에 따른 화면 밝기와 관련된 기능입니다.

오해 3: AOD를 켜면 화면에서 읽던 글이 계속 보인다. AOD는 잠금 상태에서 일부 시계·알림 정보를 표시하는 기능입니다.

오해 4: 화면이 꺼지는 시간과 PIN을 요구하는 시간은 같다. 자동 잠금의 보안 설정은 별개로 제공될 수 있습니다.

오해 5: 설정이 30초로 돌아가면 반드시 기기 고장이다. One UI 절전 모드에 화면 자동 꺼짐 시간을 30초로 설정하는 옵션이 제공될 수 있습니다.

이 다섯 가지를 구분하는 것만으로도 무리한 초기화나 비공식 화면 유지 앱 설치를 피할 수 있습니다.

15. 5분 진단 체크리스트

다음 시간은 작업 순서 예시이며, 문제 해결이나 업데이트가 반드시 5분 안에 끝난다는 뜻은 아닙니다.

순서확인할 곳확인할 내용
1분디스플레이 → 화면 자동 꺼짐 시간15초~10분 중 현재 값
2분설정 검색 → 사용 중일 때 화면을 켠 채로 유지화면 주시 감지 기능
3분배터리 → 절전 모드30초로 설정하는 옵션 여부
4분잠금화면 및 AOD / 보안 잠금 상세 설정시계 표시·잠금 시간 구분
5분밝기 최적화·케이스·통화 중 센서예상치 못한 화면 변화 분리

같은 조건에서 재시험하세요. 예를 들어 홈 화면에서 화면을 건드리지 않고 기다리는 결과와 동영상 앱에서 재생 중일 때의 결과를 직접 비교하는 것이 도움이 됩니다.

16. 자주 묻는 질문(FAQ)

Q1. 갤럭시 화면 자동 꺼짐 시간은 어디서 바꾸나요?

설정 → 디스플레이 → 화면 자동 꺼짐 시간에서 변경할 수 있습니다. 삼성 공식 안내는 일반적으로 15초~10분의 범위를 설명합니다.

Q2. 화면 자동 꺼짐을 30분이나 1시간으로 설정할 수 있나요?

일반적인 화면 꺼짐 시간 설정의 최대값은 10분입니다. 장시간 화면을 보며 사용해야 한다면 지원 모델에서 사용 중일 때 화면을 켠 채로 유지 기능을 확인하세요.

Q3. 10분으로 설정했는데 갑자기 30초로 바뀌어요.

삼성의 One UI 7 공식 지원 문서는 절전 모드의 '화면 자동 꺼짐 시간을 30초로 설정' 옵션을 안내합니다. 배터리 절전 설정을 먼저 점검하세요.

Q4. 화면을 보는 중인데 자꾸 꺼지는 이유는 뭔가요?

화면 자동 꺼짐 시간이 너무 짧거나 사용 중일 때 화면을 켠 채로 유지 기능이 꺼져 있을 수 있습니다. 화면을 보는 동안 유지 기능이 지원되는 모델인지 확인하세요.

Q5. '사용 중일 때 화면을 켠 채로 유지'가 없어요.

일부 모델·소프트웨어에서는 이 기능이 제공되지 않을 수 있습니다. 설정 검색에서 해당 문구나 과거 명칭 Smart stay를 확인해 보세요.

Q6. 화면이 어두워지는 것과 꺼지는 것은 같은가요?

다릅니다. 밝기 최적화는 주변 빛에 따라 화면 밝기를 조절하고, 화면 자동 꺼짐 시간은 일정 시간 사용하지 않을 때 화면을 끄는 기능입니다.

Q7. Always On Display가 켜져 있으면 화면 자동 꺼짐을 못 쓰나요?

아닙니다. AOD는 일반 화면이 꺼진 뒤 시계·알림을 표시하는 기능입니다. 일반 화면의 자동 꺼짐 시간과 다른 설정입니다.

Q8. 화면이 꺼졌는데 다시 켜면 PIN을 안 물어봅니다.

화면이 꺼진 후 자동 잠금과 측면 버튼 즉시 잠금 설정을 확인하세요. 화면 꺼짐 시간과 기기 잠금 시점은 같지 않을 수 있습니다.

Q9. 통화할 때만 화면이 꺼지고 안 켜져요.

통화 중 근접 센서가 작동한 것일 수 있습니다. 케이스·보호필름·센서 주변 오염을 확인하고 반복되면 공식 서비스를 이용하세요.

Q10. 화면을 10분 켜 두면 배터리가 많이 닳나요?

삼성 공식 자료는 화면을 더 오래 켜둘수록 배터리 사용량이 늘 수 있다고 안내합니다. 정확한 증가량은 밝기·앱·기종·배터리 상태에 따라 다르므로 일정한 퍼센트를 보장할 수 없습니다.

Q11. 케이스를 닫으면 저절로 화면이 꺼져요.

일부 액세서리 커버의 자동 화면 켜기·끄기 기능일 수 있습니다. 지원 기기라면 설정 → 유용한 기능 → 액세서리에서 확인할 수 있습니다.

Q12. 화면 자동 꺼짐 시간이 바뀌지 않으면 공장 초기화가 필요한가요?

우선 권장하지 않습니다. 절전 모드·화면 주시 기능·케이스 설정·재시작·공식 업데이트를 확인한 뒤 문제가 반복되면 삼성 공식 진단을 받는 편이 안전합니다.

결론

갤럭시 화면 자동 꺼짐 시간을 변경하려면 '설정 → 디스플레이 → 화면 자동 꺼짐 시간'에서 원하는 시간을 고르세요. 삼성 공식 안내의 일반적인 최대 시간은 10분이며, 글을 읽거나 화면을 보는 동안에는 지원 모델의 '사용 중일 때 화면을 켠 채로 유지' 기능이 유용할 수 있습니다.

설정이 다시 30초로 바뀌면 절전 모드의 화면 꺼짐 30초 옵션을 먼저 확인하세요. 화면이 어두워지는 현상은 밝기 최적화, 화면이 꺼진 뒤 시계가 남는 현상은 AOD, 다시 켤 때 PIN을 요구하는 시점은 보안 잠금 상세 설정과 구분해야 합니다.
