지금 시스템 보호를 켜더라도 이미 지나간 날짜의 복원 지점이 만들어지는 것은 아닙니다. 복원하려는 날짜에 해당하는 유효한 복원 지점이 없으면 해당 시점으로 되돌릴 수 없습니다.

따라서 문제가 생긴 뒤 복원 지점부터 만들기보다는 PC가 정상일 때 미리 활성화하는 것이 중요합니다.

rstrui.exe
  1. 시스템 복원 마법사에서 '다음'을 선택합니다.

복원 지점의 이름·날짜·만든 이유를 함께 확인하세요. '영향을 받는 프로그램 검색'을 통해 실제로 어떤 변경이 실행 취소될지 점검하는 것이 중요합니다.

PC가 부팅되지 않을 때: Windows 복구 환경(WinRE)

로그인 화면까지 진입할 수 없더라도 Windows 복구 환경이 열린다면 다음 경로를 사용할 수 있습니다.

문제 해결 → 고급 옵션 → 시스템 복원

장치에 BitLocker 또는 장치 암호화가 켜져 있으면 복구 키를 요구할 수 있습니다. 마이크로소프트 계정·회사 IT 관리자 등 키를 보관한 위치를 확인해야 하며, 복구 키를 모르는 상태에서 무작정 초기화부터 진행하지 않는 편이 좋습니다.

복구 환경 진입법은 현재 부팅 상태에 따라 달라집니다. Windows가 실행 중이라면 설정 → 시스템 → 복구 → 고급 시작 옵션에서 재시작을 선택할 수 있습니다. PC가 부팅되지 않는 경우 자동 복구 화면 진입이나 복구 미디어가 필요할 수 있습니다.

참고: 'Windows가 부팅되지 않음' 자체는 시스템 복원이 아닌 시동 복구·문제 업데이트 제거가 더 적합한 경우도 있습니다. 원인이 분명하지 않다면 복원 전에 문제 발생 시점을 기록하세요.

2026년 주의: '시스템 복원'과 '특정 시점 복원'은 다릅니다

Microsoft는 Windows 11에 특정 시점 복원(Point-in-time restore)을 새 복구 기능으로 안내하고 있습니다. 이것은 기존 제어판 기반의 시스템 복원과 달리 로컬 파일까지 이전 상태로 되돌릴 수 있는 복원 방식입니다.

비교기존 시스템 복원특정 시점 복원
되돌리는 대상시스템 파일·설정·앱시스템 드라이브의 운영체제·앱·설정·개인 파일 등

가장 위험한 혼동: '시스템 복원은 개인 사진·문서를 건드리지 않는다'는 설명을 새 특정 시점 복원에 그대로 적용하면 안 됩니다. 특정 시점 복원은 복원 지점 이후 저장한 로컬 파일, 앱 변경 및 일부 자격 증명 등을 잃을 수 있으므로 반드시 별도 백업과 영향을 확인해야 합니다.

Microsoft의 특정 시점 복원 설명은 Windows 11 버전 24H2 이상 환경을 다루며, 기능이 실제 제공되는지는 Windows 빌드, 디스크 용량, 장치 관리 정책 등으로 달라질 수 있습니다.

특정 시점 복원은 어떻게 켜나요?

지원되는 Windows 11에서 다음 메뉴가 표시된다면 확인할 수 있습니다.

  1. 설정 → 시스템 → 복구를 엽니다.
  2. 특정 시점 복원 항목이 있는지 확인합니다.
  3. 보기 또는 편집을 선택하고 권한 확인을 진행합니다.
  4. 기능이 제공되고 사용 가능한 상태라면 켜기·저장 공간 등 구성 항목을 확인합니다.
  5. 복구하려면 WinRE에서 문제 해결 → 특정 시점 복원으로 이동합니다.

일반 가정용 Windows Home·일부 Pro 장치에서는 기본 활성화될 수 있지만, OS 드라이브가 200GB보다 작거나 조직에서 관리하는 PC는 기본 설정이 다를 수 있습니다. 메뉴가 없으면 특정 시점 복원을 사용할 수 있는지 장치의 Windows 버전과 관리 상태를 확인하세요.

특정 시점 복원은 시스템 보호의 '복원 지점 만들기' 버튼과 같은 도구가 아닙니다. 기존 시스템 복원 안내를 참고해 수동 지점을 만든 뒤, 새 복원 기능에 바로 사용할 수 있다고 생각하면 안 됩니다.

새 복구 기능이 있다고 해도 모든 문제를 해결하거나 모든 파일을 복구할 수 있다는 뜻은 아닙니다. 원인에 따라 되돌리는 범위가 가장 작은 수단부터 검토하는 것이 합리적입니다.

복원하기 전·후 체크리스트

복원 전

  • ☐ 중요한 문서·사진·프로젝트 파일의 별도 백업을 확인했다.
  • ☐ 기존 시스템 복원인지, 파일까지 영향받는 특정 시점 복원인지 구분했다.
  • ☐ 문제 발생 날짜와 선택할 복원 지점을 비교했다.
  • ☐ 설치 앱·드라이버·업데이트 변경 목록을 확인했다.
  • ☐ 노트북을 전원에 연결하고 BitLocker 복구 키 보관 여부를 확인했다.

복원 후

  • ☐ Windows 로그인과 기본 장치 기능이 정상인지 확인했다.
  • ☐ 사용 중인 보안·업무 프로그램이 제대로 작동하는지 확인했다.
  • ☐ 보안 업데이트를 다시 검사했다.
  • ☐ 외부 장치·프린터·네트워크·드라이버가 정상인지 확인했다.
  • ☐ 특히 특정 시점 복원을 썼다면 최근 수정한 로컬 파일과 자격 증명에 영향이 없는지 점검했다.

자주 묻는 질문

Q1. 시스템 복원 지점만 만들면 삭제한 사진도 복구할 수 있나요?

아니요. 기존 시스템 복원은 개인 파일 백업 기능이 아닙니다. 실수로 삭제한 문서는 휴지통·OneDrive 버전 기록·파일 기록 또는 별도 백업에서 찾아야 합니다.

Q2. 시스템 보호가 꺼져 있었는데 오늘 켜면 어제 상태로 복원되나요?

기존 복원 지점이 없었다면 불가능합니다. 지금 만든 복원 지점은 현재 상태를 기록하는 것이므로 과거 기록을 거슬러 생성하지는 못합니다.

Q3. Win + R에 rstrui.exe를 입력하면 즉시 복원되나요?

아닙니다. 시스템 복원 마법사가 열리며, 사용자가 복원 지점을 선택하고 마지막 확인을 거쳐야 적용됩니다.

Q4. 복원 지점이 자동으로 생기나요?

기존 시스템 복원은 시스템 보호가 켜져 있을 때 특정 이벤트에서 자동 생성될 수 있지만, 항상 원하는 날짜에 만들어진다고 보장하지 않습니다. 중요 변경 전에는 수동 생성 여부를 직접 확인하세요. 새 특정 시점 복원은 별도의 자동 주기와 보존 정책이 있습니다.

Q5. 윈도우11에서 '특정 시점 복원' 메뉴가 보이지 않아요.

설치된 Windows 버전, OS 드라이브 크기 및 조직 관리 정책에 따라 기능 제공·기본 설정이 달라질 수 있습니다. 시스템 보호 기능과 혼동하지 말고 설정 → 시스템 → 복구에서 먼저 지원 여부를 확인하세요.

Q6. 복원 중 전원을 꺼도 되나요?

권장하지 않습니다. 복구가 중단되면 시스템이 불안정해질 수 있습니다. 전원 연결을 유지하고, 복원 종료 안내와 정상 부팅을 확인한 뒤 사용하세요.

결론

윈도우11의 '복원 지점 만들기'는 현재 시스템 구성을 저장해 향후 시스템 오류에 대비하는 방법입니다. 문제가 생기면 rstrui.exe로 적절한 지점을 골라 되돌릴 수 있습니다. 2026년의 새 '특정 시점 복원'은 개인 파일까지 변경할 수 있는 별도 기능이므로, 복구 메뉴의 이름과 대상 범위를 반드시 구분한 후 사용해야 합니다.

자주 묻는 질문 (FAQ)

윈도우11에서 복원 지점은 어떻게 만드나요?

시작 메뉴에서 '복원 지점 만들기'를 검색해 시스템 속성의 시스템 보호 탭으로 이동 후, 보호가 꺼져 있으면 켜고 '만들기' 버튼을 눌러 이름을 입력해 복원 지점을 생성합니다.

시스템 복원과 특정 시점 복원의 차이는 무엇인가요?

기존 시스템 복원은 시스템 파일과 설정만 되돌리지만, 특정 시점 복원은 운영체제뿐 아니라 개인 파일까지 과거 상태로 복원할 수 있는 새로운 기능입니다.

복원 지점이 없거나 만들기 버튼이 비활성화될 때 어떻게 해야 하나요?

시스템 보호가 꺼져 있거나 관리자 권한이 없을 수 있으니 보호 설정을 켜고, 회사·학교 PC라면 IT 정책을 확인하며, 저장 공간 부족 시 공간을 확보해야 합니다.
