아이폰을 무음으로 바꿨는데 전화가 와도 진동하지 않거나, 문자 메시지만 진동이 없고 키보드 입력할 때도 아무 느낌이 없다면 어디부터 확인해야 할까요? 진동과 관련된 설정은 한 군데에 모여 있지 않습니다. 사운드 및 햅틱, 손쉬운 사용의 진동, 앱 알림, 키보드 피드백, 집중 모드를 증상별로 구분해야 원인을 빠르게 찾을 수 있습니다.

가장 먼저 할 일: 전화·문자·키보드 중 어떤 상황에서 진동이 사라졌는지 확인하고, 설정 → 손쉬운 사용 → 터치 → 진동이 꺼져 있지 않은지 점검하세요. 키보드에서만 진동이 없다면 설정 → 사운드 및 햅틱 → 키보드 피드백 → 햅틱을 확인하면 됩니다.

2026년 11월 4일 기준 Apple 공식 지원 자료를 토대로 작성했습니다. iPhone 모델과 iOS 버전에 따라 일부 항목 이름·배치가 다를 수 있습니다.

1. 증상별로 먼저 확인할 설정

증상가장 먼저 확인할 곳원인 구별
전화·문자·키보드 모두 진동이 없음설정 → 손쉬운 사용 → 터치 → 진동시스템 전체의 진동 허용 여부
전화가 올 때만 진동이 없음설정 → 사운드 및 햅틱 → 벨소리 → 햅틱전화용 진동 패턴
문자만 진동이 없음설정 → 사운드 및 햅틱 → 메시지 수신음 → 햅틱메시지용 패턴·알림 설정
키보드 입력 시 진동이 없음설정 → 사운드 및 햅틱 → 키보드 피드백햅틱 피드백 스위치
특정 앱에서만 진동이 없음설정 → 알림 → 해당 앱앱의 알림 허용·사운드·집중 모드
무음 모드에서 진동이 없음무음 모드 상태 및 사운드·햅틱 설정무음과 진동은 서로 다른 설정

주의: ‘무음 모드’는 일반적으로 벨소리·알림음 등을 끄는 기능이지, 반드시 진동까지 차단하는 기능이 아닙니다. 반대로 진동 설정이 꺼져 있으면 무음 모드만 바꿔도 진동이 돌아오지 않을 수 있습니다.

2. 아이폰 진동이 전부 안 될 때: 손쉬운 사용 확인

Apple의 키보드 햅틱 공식 안내에서도 햅틱이 느껴지지 않을 경우 손쉬운 사용 → 터치의 진동 설정을 확인하도록 안내합니다.

  1. 아이폰에서 설정 앱을 엽니다.
  2. 손쉬운 사용을 선택합니다.
  3. 터치로 들어갑니다.
  4. 진동 항목이 꺼져 있다면 켭니다.
  5. 설정에서 나온 뒤 전화·문자·키보드 햅틱 중 한 가지를 다시 시험합니다.

이 설정은 단순한 메시지 진동 패턴과 달리 광범위한 진동 기능에 영향을 줄 수 있습니다. 진동을 아예 끄는 설정은 일부 긴급 경보의 진동에도 영향을 줄 수 있으므로, 문제 해결이나 진동 강도 비교를 위해 불필요하게 꺼두지 마세요.

진동을 켰는데도 어떤 상황에서도 반응이 없다면, 뒤의 기기 재시동 및 소프트웨어 점검으로 넘어갑니다. 아직 하드웨어 고장이라고 단정할 단계는 아닙니다.

3. 전화 올 때 아이폰 진동이 안 되는 경우

전화를 받는 소리는 들리지만 손에 진동이 느껴지지 않거나, 무음 상태에서 진동만 받고 싶을 때는 벨소리용 햅틱 패턴을 확인합니다.

  1. 설정 → 사운드 및 햅틱으로 이동합니다.
  2. 벨소리를 선택합니다.
  3. 햅틱 항목으로 들어갑니다.
  4. 없음이 아닌 기본 패턴을 선택하거나, 지원되는 경우 새로운 진동 생성으로 직접 패턴을 만듭니다.
  5. 다른 전화기로 자신의 번호에 전화를 걸어 실제 수신 진동을 확인합니다.

iOS 버전에 따라 사운드 및 햅틱 화면에 진동 재생 상황을 정하는 별도 햅틱 옵션이 표시될 수 있습니다. 해당 옵션이 보인다면 현재 벨소리·무음 모드에서 진동이 재생되도록 설정되어 있는지도 함께 확인하세요. 정확한 메뉴 이름은 사용 중인 버전의 화면을 기준으로 판단합니다.

특정 연락처에서만 진동하지 않는다면?

Apple은 연락처별로 벨소리와 메시지 수신음에 다른 사운드·진동을 지정하는 기능을 제공합니다. 연락처 → 해당 사람 → 편집 → 벨소리 또는 메시지 수신음에서 설정을 확인하세요. iOS 버전에 따라 편집 경로의 표시가 달라질 수 있습니다.

4. 문자 메시지만 진동이 안 되는 경우

전화는 진동하지만 문자·iMessage 알림만 진동하지 않으면 메시지용 햅틱 패턴과 앱 알림을 구분해야 합니다.

  1. 설정 → 사운드 및 햅틱 → 메시지 수신음을 엽니다.
  2. 햅틱을 선택한 뒤 ‘없음’이 아닌 패턴을 고릅니다.
  3. 설정 → 알림 → 메시지에서 알림 허용 상태를 확인합니다.
  4. 특정 대화만 조용하다면 메시지 앱에서 해당 대화의 알림 가리기 여부를 확인합니다.
  5. 집중 모드를 사용한다면 해당 시간에 메시지 알림이 중단되도록 설정했는지 확인합니다.

알림을 모두 꺼두었다면 진동 패턴을 정해 놓았더라도 수신을 알리지 않을 수 있습니다. 알림 자체가 도착하지 않는 문제는 진동 모터 문제와 구분해야 합니다.

문자 알림이 오는데 화면만 켜지고 진동이 없어요

실제 메시지 수신 시 햅틱 패턴이 없음으로 설정되어 있는지, 시스템 진동이 꺼져 있는지 순서대로 확인하세요. 다른 앱에서는 진동이 정상이라면 단순 하드웨어 고장보다 메시지 관련 설정을 먼저 살피는 편이 효율적입니다.

5. 아이폰 키보드 진동 켜는 방법

메시지를 입력할 때 키를 누를 때마다 손끝에 작은 반응이 느껴지도록 설정하고 싶다면 키보드 피드백의 햅틱을 켭니다.

  1. 설정을 엽니다.
  2. 사운드 및 햅틱 → 키보드 피드백으로 들어갑니다.
  3. 햅틱 스위치를 켭니다.
  4. 메모 앱 또는 메시지 입력창에서 글자를 입력해 봅니다.

키보드에서 소리와 햅틱은 별개의 옵션입니다. 소리를 끄더라도 햅틱을 켜둘 수 있습니다. Apple은 키보드 햅틱을 켜면 배터리 사용 시간에 영향을 줄 수 있다고 안내합니다.

햅틱을 켰는데도 반응하지 않으면 설정 → 손쉬운 사용 → 터치 → 진동이 활성화되어 있는지 다시 확인하세요. 다른 앱의 키보드나 서드파티 키보드는 동작이 다를 수 있으므로 기본 iOS 키보드에서도 비교해보는 것이 좋습니다.

6. 무음 모드와 진동은 어떻게 다를까?

무음 모드는 전화·알림 등의 사운드를 줄이거나 끄는 기능입니다. Apple은 무음 모드가 켜져 있더라도 진동이 항상 꺼지는 것은 아니라고 설명합니다.

  • 벨소리/무음 스위치가 있는 모델: 기기 측면의 스위치로 무음 상태를 확인합니다.
  • 동작 버튼이 있는 모델: 동작 버튼이 무음 모드에 할당되어 있다면 길게 눌러 상태를 변경할 수 있습니다.
  • 설정이나 제어 센터: 지원되는 모델·버전에서는 화면에서 무음 모드 상태를 확인하거나 변경할 수 있습니다.

혼동하기 쉬운 점: 시계 알람은 일반적인 전화 알림과 다르게 동작합니다. 무음 모드나 방해금지 모드가 켜져 있어도 알람 소리는 재생될 수 있습니다. 따라서 ‘알람이 울린다’는 이유만으로 전화·문자 진동 설정이 정상이라고 판단하면 안 됩니다.

7. 카카오톡 등 특정 앱에서만 진동하지 않을 때

설정 → 알림 → 해당 앱으로 이동해 알림 허용 여부를 먼저 확인합니다. 앱 자체의 알림 설정도 따로 있을 수 있습니다.

  1. 해당 앱의 알림 허용이 켜져 있는지 확인합니다.
  2. 시스템의 집중 모드가 현재 활성화돼 있는지 확인합니다.
  3. 특정 채팅방·대화가 무음으로 설정되어 있지는 않은지 확인합니다.
  4. 앱을 열어 실제 메시지를 수신했는지, 아니면 알림 표시 자체가 없는지 구분합니다.
  5. 앱과 iOS에 업데이트가 있다면 공식 업데이트를 확인합니다.

주의: 모든 앱에 동일한 진동 제어 메뉴가 있는 것은 아닙니다. 앱별로 제공하지 않는 진동 강도·패턴 항목이 있다고 가정하고 메뉴를 찾기보다는, 먼저 알림 자체가 허용되어 있는지 확인하세요.

8. 진동이 계속 없을 때 단계별 해결법

① 실제 진동이 발생하는 상황을 2~3개 비교

예를 들어 전화 수신, 메시지 수신, 기본 키보드 입력을 각각 테스트합니다. 한 가지에서만 실패하면 관련 앱·알림 설정을 우선 확인하고, 모두 실패하면 시스템 진동 설정과 기기 상태를 점검합니다.

② 아이폰을 재시동

중요한 작업을 저장한 후 아이폰을 정상적인 방법으로 껐다 켜세요. 재시동 후에도 증상이 계속되는지 확인합니다. 재시동만으로 모든 진동 문제가 해결된다는 뜻은 아닙니다.

③ iOS 업데이트 확인

설정 → 일반 → 소프트웨어 업데이트에서 설치 가능한 업데이트가 있는지 확인합니다. 업데이트 전에는 중요한 데이터 백업과 충분한 전원·저장 공간을 확보하는 편이 안전합니다. 업데이트로 문제가 반드시 해결된다고 단정할 수는 없습니다.

④ 하드웨어 점검이 필요한 경우

시스템 진동이 켜져 있고, 전화·문자·키보드 햅틱이 모두 올바르게 설정돼 있는데도 어떤 상황에서도 진동이 전혀 없고 재시동 뒤에도 변화가 없다면 Apple 지원을 통한 진단을 고려하세요. 낙하·침수 등 물리적 손상 가능성이 있다면 사설 앱으로 진동을 강제로 반복시키기보다 공식 점검을 받는 편이 좋습니다.

바로 ‘모든 설정 재설정’이나 기기 전체 초기화부터 실행하지 마세요. 원인을 구분하는 데 필요한 일반 설정 확인과 공식 진단이 우선입니다.

9. 자주 묻는 질문

Q. 아이폰을 무음으로 설정하면 진동도 없어지나요?

반드시 그렇지는 않습니다. 무음 모드와 진동 설정은 구분됩니다. 무음 상태에서 진동을 받고 싶다면 사운드·햅틱 설정과 시스템 진동 허용 상태를 확인해야 합니다.

Q. 전화만 진동하게 하고 키보드 진동은 끌 수 있나요?

전화용 햅틱과 키보드 피드백 → 햅틱은 별도의 설정입니다. 키보드 햅틱을 꺼도 전화용 진동 패턴까지 반드시 꺼지는 것은 아닙니다.

Q. 문자에는 진동이 없는데 전화는 정상이에요.

메시지 수신음 → 햅틱 패턴, 메시지 알림 허용, 집중 모드 및 대화별 알림 가리기를 먼저 확인하세요. 이 증상만으로 진동 부품 고장이라고 단정하기는 어렵습니다.

Q. 알람은 울리는데 전화가 진동하지 않아요.

시계 알람의 사운드와 일반 전화·문자 햅틱은 서로 다른 설정의 영향을 받을 수 있습니다. 진동 테스트를 알람 한 가지로만 판단하지 말고 전화 수신과 기본 키보드 햅틱을 함께 비교하세요.

Q. 진동 강도를 숫자로 조절할 수 있나요?

모든 iPhone에 일괄적인 숫자형 진동 강도 조절 옵션이 제공되는 것은 아닙니다. 전화·문자별 햅틱 패턴을 바꾸거나 사용자 설정 패턴을 생성하는 것이 공식적으로 안내되는 방법입니다. 인터넷의 ‘숨겨진 진동 강도 코드’처럼 출처가 불분명한 설정법은 따라 하지 않는 편이 안전합니다.

최종 점검표

  • ☐ 손쉬운 사용 → 터치 → 진동이 켜져 있다.
  • ☐ 전화용 벨소리 → 햅틱에 패턴이 지정돼 있다.
  • ☐ 문자용 메시지 수신음 → 햅틱에 패턴이 지정돼 있다.
  • ☐ 키보드 피드백 → 햅틱의 켜짐 여부를 확인했다.
  • ☐ 특정 앱 알림, 대화별 무음, 집중 모드를 확인했다.
  • ☐ 전화·문자·키보드를 서로 다른 테스트로 비교했다.
  • ☐ 재시동 후에도 모든 진동이 없으면 공식 진단을 검토한다.

결론

아이폰 진동 문제를 해결하려면 모든 진동이 안 되는지, 전화·문자 등 일부만 안 되는지, 키보드 햅틱만 안 되는지를 먼저 나눠야 합니다. 모든 진동이 없을 때는 시스템 진동 허용, 특정 알림만 문제일 때는 해당 알림의 햅틱 설정, 키보드만 문제라면 키보드 피드백을 확인하세요. 원인을 모르는 상태에서 기기 전체를 초기화할 필요는 없습니다.
