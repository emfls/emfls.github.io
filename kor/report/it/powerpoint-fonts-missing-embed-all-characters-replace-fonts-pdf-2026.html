파워포인트(PowerPoint)의 글꼴 깨짐은 단순히 한 글자만 다른 문제가 아닙니다. 글자 폭·줄바꿈·텍스트 상자 높이까지 바뀌면 슬라이드 전체 레이아웃이 흔들립니다. 해결책은 용도에 따라 달라집니다. 받는 사람이 수정해야 한다면 글꼴을 포함한 PPTX를 검토하고, 보기만 하면 된다면 PDF도 함께 제공하는 것이 실용적입니다.

이 글은 Microsoft의 공식 PowerPoint 안내를 바탕으로 Windows용 Microsoft 365·PowerPoint 2024를 중심으로 설명하고, Mac 및 웹용 버전의 차이도 별도로 다룹니다. 메뉴 이름은 버전·언어에 따라 달라질 수 있습니다.

2. 파워포인트 글꼴이 깨지는 이유

PPTX 파일은 화면의 글자를 사진처럼만 저장하는 형식이 아닙니다. 일반적인 텍스트 개체는 글꼴 이름·크기·서식 같은 정보를 가지고 있으며, 실제 표시 시 사용할 글꼴을 시스템과 PowerPoint가 찾아야 합니다.

원본에 사용된 글꼴이 받는 컴퓨터에 없다면 프로그램이 다른 글꼴로 대체할 수 있습니다. Microsoft는 이 때문에 다른 컴퓨터에서 문서·프레젠테이션이 다르게 보일 수 있다고 설명합니다.

예를 들어 원본 글꼴이 매우 좁은 글자 폭을 사용했는데 대체 글꼴은 폭이 넓다면 다음과 같은 현상이 생길 수 있습니다.

  • 한 줄이었던 제목이 두 줄로 바뀜
  • 텍스트 상자의 마지막 글자가 잘림
  • 도형 안의 숫자가 줄을 넘김
  • 표의 셀 높이가 달라 보임
  • 일부 특수기호가 빈 사각형처럼 표시됨

글꼴 대체와 파일 손상은 구분해야 합니다. 글꼴만 바뀌고 다른 내용은 정상이라면 글꼴 환경을 먼저 확인하세요. 파일 전체가 열리지 않는다면 다른 원인도 살펴봐야 합니다.

3. Windows 파워포인트 글꼴 포함 저장 방법

받는 사람이 원본 디자인을 유지하며 PPT를 열어야 한다면 파일에 글꼴을 포함하는 기능을 고려할 수 있습니다.

  1. 문제가 있는 PPTX를 열고 다른 이름으로 저장하여 원본을 보존합니다.
  2. 상단 파일 → 옵션을 선택합니다.
  3. 왼쪽 메뉴에서 저장을 엽니다.
  4. 아래쪽의 이 프레젠테이션을 공유할 때 충실도 유지 영역을 찾습니다.
  5. 파일에 글꼴 포함을 체크합니다.
  6. 표시되는 옵션 중 공유 목적에 맞는 항목을 선택합니다.
  7. 확인을 누른 뒤 PPTX 파일을 다시 저장합니다.
  8. 다른 컴퓨터에서 열어 실제로 글꼴·줄바꿈·레이아웃이 보존되는지 확인합니다.

주의: '파일에 글꼴 포함'을 켰다고 모든 글꼴이 반드시 포함되는 것은 아닙니다. 글꼴 제작자가 정한 포함 권한 또는 파일 형식의 제한 때문에 포함할 수 없는 글꼴도 있습니다.

4. '사용된 문자만 포함' vs '모든 문자 포함' 어떤 것을 선택할까?

글꼴 포함 설정에는 파일 크기와 나중 편집 가능성에 영향을 주는 선택지가 있습니다.

옵션적합한 상황특징
프레젠테이션에 사용된 문자만 포함문구를 추가하지 않고 원본을 보기 위주로 전달파일 크기가 상대적으로 작을 수 있음. 나중에 다른 글자를 같은 글꼴로 편집할 때 제약
모든 문자 포함받는 사람이 문장을 수정·추가해야 함편집에 유리하지만 파일이 커질 수 있음

실무 판단: 발표 당일 수정이나 번역 작업이 예정돼 있다면 '모든 문자 포함'을 우선 검토하세요. 최종본을 확인만 하는 용도라면 '사용된 문자만 포함'도 고려할 수 있지만, 결국 수신자의 실제 환경에서 열어보는 검증이 필요합니다.

Microsoft는 다른 사용자가 파일을 편집할 가능성이 있다면 모든 문자 포함을 권장합니다.

파일 크기가 너무 커질 때

글꼴 자체에 포함되는 문자 집합이 큰 경우 PPTX 파일 크기가 증가할 수 있습니다. 특히 여러 글꼴을 혼용하면 영향이 커질 수 있습니다. 용량 문제 때문에 글꼴 포함을 무조건 해제하기보다, 비표준 서체를 몇 개 사용했는지부터 확인하세요.

5. '일부 글꼴을 프레젠테이션과 함께 저장할 수 없습니다' 해결

글꼴 포함 옵션을 켜고 저장하는 과정에서 경고가 나타날 수 있습니다. Microsoft는 모든 TrueType 글꼴이 포함 가능한 것은 아니며 글꼴 제작자가 포함 권한을 지정할 수 있다고 안내합니다.

해결 순서는 다음과 같습니다.

  1. 경고에 표시된 글꼴 이름을 기록합니다.
  2. 해당 글꼴이 회사에서 별도로 설치한 상용·무료 글꼴인지 확인합니다.
  3. 글꼴 제공자의 라이선스 및 임베딩 허용 범위를 확인합니다.
  4. 포함이 불가능하거나 권한이 불명확하면 다른 글꼴로 바꾸기를 검토합니다.
  5. 글꼴을 변경한 뒤 모든 슬라이드의 줄바꿈과 배치를 다시 확인합니다.
  6. 새 파일을 저장하고 실제 수신 환경에서 테스트합니다.

공식 문서는 일반적으로 OpenType(.otf) 또는 TrueType(.ttf) 글꼴을 권장하고, 일부 오래된 PostScript 글꼴 사용은 피하도록 안내합니다. 그렇다고 .otf·.ttf 파일이라고 해서 모두 포함 가능한 것은 아닙니다.

중요: 포함 제한을 우회하거나 글꼴 파일을 무단 복제하는 방법은 올바른 해결책이 아닙니다. 글꼴 사용 조건에 맞는 대체 폰트를 사용하는 것이 안전합니다.

6. PPT 전체 글꼴을 한 번에 바꾸는 방법

자료를 급하게 전달해야 하고 원본 글꼴의 설치·포함이 어렵다면 프레젠테이션에서 사용 중인 글꼴을 통일하는 방법이 실용적입니다.

방법 A. 홈 탭의 글꼴 바꾸기

  1. 변경할 PPTX를 복사본으로 엽니다.
  2. 홈 → 바꾸기 → 글꼴 바꾸기를 선택합니다.
  3. 바꿀 글꼴에서 문서에 이미 사용 중인 글꼴을 선택합니다.
  4. 바꾼 결과에서 사용할 대체 글꼴을 선택합니다.
  5. 바꾸기를 누르고 대화 상자를 닫습니다.
  6. 제목·본문·도표·표의 글꼴이 바뀌었는지 확인합니다.

이 기능으로 기존 글꼴을 여러 슬라이드에서 한 번에 대체할 수 있습니다. 단, 그림 속에 들어 있는 글씨나 일부 특수한 개체는 직접 수정해야 할 수 있습니다.

방법 B. 슬라이드 마스터에서 테마 글꼴 변경

  1. 보기 → 슬라이드 마스터로 이동합니다.
  2. 왼쪽의 마스터 또는 변경할 레이아웃을 선택합니다.
  3. 슬라이드 마스터 → 글꼴에서 제목·본문에 사용할 글꼴 구성을 정합니다.
  4. 여러 개의 마스터를 사용하는 문서라면 각각 적용 상태를 점검합니다.
  5. 마스터 보기 닫기를 누르고 일반 슬라이드로 돌아갑니다.

마스터를 바꿨는데도 일부 글자가 그대로라면 해당 텍스트에 직접 서식을 적용했을 가능성이 있습니다. 이런 경우 글꼴 바꾸기나 해당 개체 편집으로 다시 확인하세요.

웹용 PowerPoint 제한: Microsoft 공식 안내에 따르면 프레젠테이션 전체 글꼴을 바꾸는 슬라이드 마스터 방식은 웹용 PowerPoint에서 제공되지 않습니다. 필요한 경우 데스크톱 PowerPoint에서 진행하세요.

공식 근거: Microsoft — Change the fonts in a presentation

7. 한국어 PPT에서 글자 폭과 줄바꿈이 달라질 때

한글이 □로 나타나거나 텍스트 상자에 문구가 더 이상 들어가지 않는다면 단순히 글꼴 이름만 바꾸는 것으로 문제가 완전히 해결되지 않을 수 있습니다.

실제 수정 순서는 다음과 같습니다.

  1. 원본과 수정본을 나란히 열어 텍스트 상자의 변경 위치를 확인합니다.
  2. 한글 글리프가 포함된 글꼴인지 확인합니다.
  3. 대체 글꼴로 변경한 뒤 제목·본문의 줄바꿈을 확인합니다.
  4. 줄바꿈이 달라졌다면 글꼴 크기·자간·텍스트 상자 너비·내부 여백을 점검합니다.
  5. 표와 그래프의 축 레이블, 각주, 차트 제목도 별도로 확인합니다.
  6. 전체 화면 슬라이드 쇼에서 잘린 글자가 없는지 재확인합니다.

예시: 원본에서는 '연간 매출 현황 분석'이 한 줄인데, 받은 사람의 PC에서는 두 줄이 됐다면 대체 서체의 폭이 달라졌을 수 있습니다. 이때 제목 상자만 무작정 넓히는 것보다 사용 글꼴이 동일한지부터 확인하는 편이 원인 분석에 도움이 됩니다.

문서가 여러 사람이 편집하는 공동 자료라면 처음부터 팀에서 사용 가능한 글꼴 목록을 정해 두는 것도 예방책입니다.

8. Mac에서 만든 PPT를 Windows에서 열면 글꼴이 바뀌는 이유

Mac과 Windows는 설치된 글꼴의 종류·이름 처리·지원 환경이 다를 수 있습니다. 따라서 한 컴퓨터에서는 정상으로 보이던 자료가 다른 컴퓨터에서는 다르게 렌더링될 수 있습니다.

Microsoft는 Mac용 Office의 글꼴 이름 저장 방식이 버전별로 달라져 일부 구버전과 교환할 때 글꼴이 대체돼 보일 수 있다고 안내한 바 있습니다. 특정 환경에서 문제가 반복된다면 다음을 확인하세요.

  • 두 컴퓨터에 같은 글꼴이 실제로 설치돼 있는지
  • PowerPoint 버전이 너무 오래되지 않았는지
  • 글꼴 이름이 같아도 서로 다른 버전의 파일을 사용하고 있지 않은지
  • PPTX를 새로 저장했을 때도 문제가 재현되는지
  • PDF 내보내기 결과에서도 같은 문제가 발생하는지

Mac에서도 글꼴 포함을 지원하는 버전이 있습니다. Microsoft는 Mac용 Microsoft 365 PowerPoint 및 Mac용 PowerPoint 2024·2021의 글꼴 포함 기능을 안내합니다. 다만 설정 위치와 세부 기능은 Windows와 다를 수 있으므로 Mac에서 Windows의 '파일 → 옵션' 경로를 그대로 찾지 마세요.

9. 수정 없이 보여 주기만 한다면 PDF로 함께 저장하기

발표 자료를 받는 사람이 편집할 필요가 없다면 원본 PPTX와 함께 PDF 파일을 전달하는 것이 편리합니다. PDF는 일반적으로 슬라이드의 배치와 서식을 고정해 보여 주는 데 적합합니다.

Windows용 PowerPoint

  1. PPTX 원본을 저장합니다.
  2. 파일 → 내보내기를 선택합니다.
  3. PDF/XPS 문서 만들기 → PDF/XPS 만들기를 선택합니다.
  4. 저장 위치와 파일 이름을 지정합니다.
  5. 출력 품질이 중요하다면 표준, 작은 파일 크기가 중요하다면 최소 크기를 고려합니다.
  6. 게시 후 PDF를 직접 열어 전체 슬라이드를 확인합니다.

Mac용 PowerPoint

Mac에서는 파일 → 다른 이름으로 저장 → PDF 또는 파일 → 내보내기 → PDF 방식이 안내돼 있습니다.

제한 사항: PDF로 저장하면 글꼴·배치를 정적으로 전달하기는 편하지만, PPTX의 애니메이션과 편집 기능을 그대로 유지하는 용도는 아닙니다. 클릭 동작, 전환 효과, 영상 재생 같은 요소가 중요하면 PPTX도 함께 제공해야 합니다.

또한 PDF 자체도 최종 확인이 필요합니다. 원본 파일에 글꼴 문제가 이미 생긴 상태에서 PDF를 만들면 잘못된 상태가 그대로 저장될 수 있습니다.

10. 파일에 글꼴을 포함했는데도 깨질 때

'글꼴 포함' 설정이 켜져 있다는 사실만으로 문제 해결이 완료된 것은 아닙니다. 글꼴의 라이선스, 폰트 파일 지원 방식, PDF 변환 환경, 받는 사람의 프로그램 버전에 따라 결과가 다를 수 있습니다.

5단계 재검증

  1. 글꼴 이름: 프레젠테이션에서 실제 사용하는 글꼴을 확인합니다.
  2. 글꼴 권한: 포함할 수 없는 글꼴로 경고가 나타나지 않는지 확인합니다.
  3. 포함 옵션: 받는 사람이 편집해야 한다면 '모든 문자 포함'을 검토합니다.
  4. 실제 열기: 원본 제작 PC가 아니라 다른 컴퓨터에서 PPTX를 열어 봅니다.
  5. 대체 산출물: 정적 공유용 PDF의 줄바꿈과 그림·표 배치를 비교합니다.

문제가 특정 컴퓨터 한 대에서만 반복된다면 그 PC의 글꼴 설치·PowerPoint 버전을 확인합니다. 여러 컴퓨터에서 공통으로 문제가 발생한다면 프레젠테이션 자체의 글꼴 선택이나 포함 설정을 먼저 살펴보세요.

일반적인 단순화: 프레젠테이션에 특수 서체를 10개 쓰는 것보다, 한글 지원이 확실하고 라이선스가 명확한 서체를 소수 사용하는 편이 공유·수정·인쇄 과정에서 확인할 요소를 줄일 수 있습니다.

11. PPT 글꼴 깨짐을 예방하는 배포 전 체크리스트

발표 당일 급하게 고치지 않으려면 제작이 끝난 다음 다음 순서로 확인해 보세요.

점검 항목직접 확인하는 방법
사용 글꼴 통일홈 → 글꼴 바꾸기에서 사용 글꼴 확인
마스터와 개별 슬라이드제목·본문 및 직접 서식 적용된 개체 점검
글꼴 포함 가능 여부파일 → 옵션 → 저장에서 포함 설정 및 경고 확인

특히 견적서·교육자료·채용 발표처럼 숫자와 도표가 중요한 파일에서는 글꼴을 변경한 후 데이터가 잘려 보이지 않는지도 확인하세요. 내용이 맞더라도 화면에 보이지 않으면 전달 과정에서 오류가 생길 수 있습니다.

12. 자주 묻는 질문

Q. 파워포인트 글꼴 포함 저장은 어디에서 설정하나요?

Windows에서는 파일 → 옵션 → 저장 → 파일에 글꼴 포함에서 설정할 수 있습니다. 설정 뒤 PPTX를 다시 저장하고 다른 PC에서 열어 보세요.

Q. '사용된 문자만 포함'과 '모든 문자 포함' 차이는 무엇인가요?

전자에서는 파일 크기를 줄일 수 있지만 새 문자를 같은 글꼴로 편집하는 데 제약이 생길 수 있습니다. 다른 사람이 내용을 수정해야 한다면 후자를 우선 고려하세요.

Q. 모든 글꼴을 포함할 수 있나요?

아닙니다. 폰트 제작자가 지정한 권한이나 지원 형식에 따라 일부 글꼴은 포함할 수 없습니다. 오류가 나면 포함을 우회하기보다 호환되는 대체 서체를 선택하세요.

Q. 전체 PPT 글꼴을 한 번에 변경할 수 있나요?

Windows 데스크톱 PowerPoint에서는 홈 → 바꾸기 → 글꼴 바꾸기 기능이 있습니다. 필요하다면 슬라이드 마스터의 테마 글꼴도 함께 점검하세요.

Q. PDF로 저장하면 PPT 글꼴 깨짐이 무조건 없어지나요?

PDF는 정적 공유용으로 유리하지만 저장 전에 잘못 표시된 글꼴까지 자동 복구하지는 않습니다. 원본을 먼저 정상화하고 PDF 내보내기 결과를 점검해야 합니다.

Q. 웹용 PowerPoint에서도 슬라이드 마스터 글꼴 변경이 가능한가요?

Microsoft 공식 안내에 따르면 프레젠테이션 전체 글꼴을 변경하는 해당 슬라이드 마스터 기능은 웹용 PowerPoint에서 제공되지 않습니다. 데스크톱 PowerPoint를 사용하세요.

Q. Mac에서 만든 PPT를 Windows로 보낼 때 가장 안전한 방법은?

수신자가 수정해야 하는지에 따라 글꼴 설치·글꼴 포함 지원 여부를 확인하고, 실제 Windows PC에서 열어 확인하세요. 보기만 하면 된다면 PDF를 함께 전달하는 방식을 권장합니다.

13. 결론: 공유 목적에 따라 해결책을 다르게 선택하세요

파워포인트 글꼴이 바뀌었다면 먼저 받는 컴퓨터에 원본 글꼴이 있는지 확인하세요. 파일의 텍스트·레이아웃이 밀리는 문제는 글꼴 대체 때문에 발생할 수 있습니다.

  • 편집용 전달: 글꼴 포함 가능 여부·포함 옵션을 확인하고 실제 수신 PC에서 PPTX 검증
  • 글꼴 포함 오류: 라이선스와 파일 형식을 확인하고 전체 글꼴 변경 검토
  • 보기·인쇄용 전달: 원본 PPTX를 보존하고 PDF도 내보내 전체 슬라이드 확인

최종 한 줄: '파일에 글꼴 포함'만 체크하고 끝내지 말고, 다른 컴퓨터에서 PPTX와 PDF를 실제로 열어 비교하는 것이 깨짐을 예방하는 가장 확실한 점검 절차입니다.
