PDF에서 마지막 빈 페이지를 없애거나, 12쪽짜리 문서의 4페이지만 삭제하거나, 제출용 파일에서 불필요한 부록을 빼고 싶을 때가 있습니다. 하지만 PDF는 Word나 한글 파일과 달리 페이지를 편집하는 방식이 프로그램마다 다릅니다.

윈도우11에서는 Microsoft Edge에서 남길 페이지만 선택해 PDF로 다시 저장하는 방법이 실용적입니다. 맥에서는 기본 제공되는 미리보기(Preview) 앱에서 페이지 썸네일을 골라 직접 삭제·이동할 수 있습니다. Adobe Acrobat에서는 '페이지 구성' 도구로 페이지를 지우거나 재배열할 수 있지만, 이용 가능한 기능과 구독 조건은 제품·플랜에 따라 다릅니다.

한 가지는 반드시 구별해야 합니다. 페이지를 '실제로 편집해 삭제'하는 것과 '남길 페이지만 PDF로 다시 인쇄하는 것'은 다릅니다. 특히 전자서명·입력 가능한 양식·책갈피·링크가 포함된 PDF라면 다시 인쇄하는 과정에서 속성이 손실되거나 서명 검증 상태가 바뀔 수 있습니다.

이 글에서는 Windows 11 / Mac / Adobe Acrobat의 페이지 삭제 방법, 특정 쪽만 빼고 저장하는 방법, 페이지 순서 바꾸기, 삭제 버튼이 없을 때, 민감한 서류를 안전하게 다루는 방법을 정리합니다.

기준일: 2026년 11월 4일. 앱 버전·운영체제에 따라 메뉴 위치와 지원 기능이 다를 수 있습니다.

1. 30초 비교: PDF 페이지 삭제는 어떤 방법이 좋을까?

상황우선 추천비용·제약핵심 주의
윈도우11에서 10쪽 중 4쪽만 제외Edge → 인쇄 → 나머지 페이지 지정 → PDF 저장추가 편집 프로그램 없이 가능한 경우가 많음원본 PDF를 다시 생성하는 방식
맥에서 4쪽만 삭제미리보기 → 썸네일 → 4쪽 선택 → Delete기본 앱 활용삭제한 페이지의 주석도 함께 없어짐
맥에서 6쪽과 7쪽 순서 바꾸기미리보기 썸네일 드래그기본 앱 활용저장 전 결과 확인
Acrobat에서 여러 쪽 삭제모든 도구 → 페이지 구성 → 페이지 삭제편집 가능 권한·플랜 확인Adobe는 최소 한 페이지 유지 안내
민감한 개인정보 포함 문서가능하면 로컬 오프라인 작업웹 업로드 서비스 주의외부 서버에 제출 문서 업로드 여부 확인
전자서명·양식·책갈피가 있는 PDF편집 목적을 검토하고 원본 보존단순 재인쇄는 부적절할 수 있음서명·대화형 기능이 바뀔 수 있음

핵심 결론: '특정 쪽을 뺀 새로운 PDF가 필요하다'면 페이지 선택 PDF 인쇄로 해결할 수 있고, '원본 문서의 PDF 페이지 구조를 편집하고 싶다'면 미리보기 또는 Acrobat의 페이지 구성이 더 적합합니다.

공식 자료: Microsoft Edge에서 인쇄, Apple 미리보기에서 PDF 페이지 추가·삭제·이동, Adobe Acrobat PDF 페이지 삭제.

2. 윈도우11 무료 방법: Edge에서 특정 페이지를 빼고 저장

Windows에서 페이지 편집 도구가 없더라도 남길 페이지만 선택해 다시 PDF로 저장하는 방법을 사용할 수 있습니다.

예를 들어 원본 PDF가 총 10페이지이고, 4페이지만 제외하고 싶다고 가정해 봅니다. 남길 페이지는 1~3쪽과 5~10쪽입니다.

순서대로 따라 하기

  1. 원본 PDF 파일을 복사해 백업합니다.
  2. PDF를 Microsoft Edge로 엽니다. 기본 앱이 아니라면 PDF를 마우스 오른쪽 단추로 눌러 '연결 프로그램 → Microsoft Edge'를 선택할 수 있습니다.
  3. 키보드에서 Ctrl+P를 눌러 인쇄 화면을 엽니다.
  4. 프린터·대상에서 PDF로 저장 또는 Microsoft Print to PDF 등 PDF 출력 대상을 선택합니다. 실제 항목 이름은 환경에 따라 다를 수 있습니다.
  5. 페이지 항목을 사용자 지정으로 변경합니다.
  6. 남길 페이지를 다음과 같이 입력합니다.
1-3,5-10
  1. 인쇄 미리 보기에서 4페이지를 제외한 9페이지가 선택됐는지 확인합니다.
  2. 인쇄 또는 저장을 눌러 다른 파일명으로 PDF를 생성합니다.
  3. 생성된 PDF를 다시 열고 총 페이지 수·본문·표·서명·링크 등을 확인합니다.

Microsoft는 Edge의 인쇄 화면에서 1-5와 같은 범위나 3,6,8과 같은 개별 쪽 번호를 지정할 수 있다고 안내합니다.

주의: 이 방법은 원본 PDF에서 내부 페이지 객체만 직접 삭제하는 기능과 동일하지 않습니다. 인쇄 결과를 새 PDF로 만드는 것입니다. 저장 후 문서의 기능·서식·링크 등을 검증해야 합니다.

공식 근거: Microsoft Edge에서 인쇄할 페이지 선택.

특정 페이지를 제외하려면 삭제할 쪽이 아니라 남길 쪽 번호를 입력합니다.

표의 쪽 번호는 파일을 처음부터 세었을 때의 실제 PDF 페이지 순서입니다. 문서 내부에 인쇄된 '본문 1쪽' 번호와 PDF 뷰어의 '현재 4/10페이지'는 다를 수 있습니다.

4쪽만 따로 저장하고 싶다면?

삭제가 아니라 4쪽만 추출하려는 것이므로 페이지 지정에 다음처럼 입력할 수 있습니다.

4

PDF로 출력한 뒤 1페이지짜리 파일이 만들어졌는지 확인하면 됩니다.

빈 페이지가 앞뒤에 있는 경우

'빈 페이지'처럼 보이더라도 실제로는 스캔한 빈 종이, 주석, 흰색 배경의 개체가 포함될 수 있습니다. 따라서 인쇄 미리 보기와 새 파일을 열어 실제 결과를 확인하세요.

4. Mac에서는 앱 설치 없이: 미리보기에서 페이지 직접 삭제

Apple은 Mac의 미리보기(Preview) 앱에서 PDF 페이지를 추가·삭제·이동할 수 있다고 공식 안내합니다.

특정 페이지만 지우기

  1. Finder에서 PDF 파일을 찾습니다.
  2. 원본을 보존하려면 파일 복사본을 먼저 만듭니다.
  3. PDF를 미리보기 앱으로 엽니다.
  4. 상단 메뉴에서 보기 → 썸네일을 선택합니다.
  5. 왼쪽 사이드바에서 삭제하려는 페이지를 클릭합니다.
  6. 키보드의 Delete 키를 누르거나 편집 → 삭제를 선택합니다.
  7. 삭제 후 페이지가 원하는 순서로 이어졌는지 확인합니다.
  8. 파일 → 저장으로 변경 내용을 저장합니다.

Apple은 삭제한 PDF 페이지에 달린 주석(annotation)도 함께 제거된다고 명시합니다. 주석·서명 이미지·메모가 필요한 파일이라면 복사본으로 작업해야 합니다.

공식 근거: Apple — Add, delete, or move PDF pages in Preview on Mac.

5. Mac에서 여러 페이지를 한꺼번에 삭제하기

Apple 미리보기에서는 썸네일 보기에서 여러 페이지를 선택한 뒤 Delete를 눌러 삭제할 수 있습니다.

예: 10쪽 파일에서 3·5·7쪽 삭제

  1. 원본 PDF를 복제합니다.
  2. 복제한 파일을 미리보기에서 엽니다.
  3. 보기 → 썸네일로 페이지 목록을 표시합니다.
  4. 삭제할 페이지 썸네일을 여러 개 선택합니다. 연속되지 않은 페이지를 선택할 때는 Mac의 일반적인 다중 선택 키 조합을 사용할 수 있습니다.
  5. 선택된 페이지가 정확히 3·5·7쪽인지 다시 확인합니다.
  6. Delete 키를 누릅니다.
  7. 남은 페이지 수가 7쪽인지 확인하고 저장합니다.

삭제 후 순서가 바뀌었다면?

미리보기에서는 페이지 썸네일을 드래그해 원하는 위치로 옮길 수 있습니다. 원본에서 순서를 확인하고 저장 전 미리보기를 한 번 더 비교해 보세요.

주의: 전체 페이지를 삭제하려는 경우에는 도구가 제한하거나 저장 결과가 예상과 다를 수 있습니다. 중요한 자료는 반드시 1페이지 이상 남길 목적으로 정상 파일을 생성하는지 확인해야 합니다.

공식 근거: Apple — PDF 페이지 삭제·이동.

6. PDF 페이지 순서 바꾸기: 삭제와는 다릅니다

PDF가 표지 → 본문 2쪽 → 본문 1쪽 → 부록처럼 뒤섞여 있다면 페이지 삭제가 아니라 순서 변경이 필요합니다.

Mac 미리보기

  1. 보기 → 썸네일을 엽니다.
  2. 잘못 배치된 페이지를 선택합니다.
  3. 썸네일을 드래그해 원하는 위치로 옮깁니다.
  4. 1쪽부터 끝쪽까지 내용을 확인합니다.
  5. 새 파일명으로 저장합니다.

Apple은 이 방법으로 PDF의 페이지 순서를 변경할 수 있다고 설명합니다.

Adobe Acrobat

  1. PDF를 Acrobat에서 엽니다.
  2. 모든 도구 → 페이지 구성으로 들어갑니다.
  3. 페이지 축소판을 원하는 순서로 재배치합니다.
  4. PDF를 저장합니다.

Adobe는 데스크톱 및 웹 버전에서 페이지 구성 기능을 안내하지만, 기능 이용 가능 여부·로그인·구독 조건은 제품에 따라 달라질 수 있습니다.

Windows의 페이지 선택 인쇄로 순서를 바꿀 수 있을까요?

원본 페이지를 골라 다시 저장하는 기능은 삭제·추출 용도에 적합하지만, 인쇄 기능만으로 페이지 순서를 임의 변경하는 작업은 프로그램과 인쇄 설정의 지원 여부에 따라 다릅니다. 순서를 꼭 바꿔야 한다면 페이지 재정렬을 공식적으로 지원하는 편집 도구를 사용하는 것이 더 확실합니다.

공식 참고: Adobe — 웹용 Acrobat 페이지 구성.

7. Adobe Acrobat에서 페이지 직접 삭제하는 방법

Acrobat의 페이지 구성(Organize Pages) 기능은 인쇄해 재생성하는 대신 PDF 문서의 페이지를 직접 편집하는 방법입니다.

Adobe의 공식 절차:

  1. 데스크톱 Acrobat에서 PDF를 엽니다.
  2. 모든 도구 → 페이지 구성을 선택합니다.
  3. 페이지 축소판이 표시되는지 확인합니다.
  4. 개별 페이지라면 해당 썸네일에서 삭제를 선택합니다.
  5. 여러 페이지라면 페이지 번호나 범위를 지정합니다.
  6. 삭제를 확정하고 PDF를 저장합니다.

Adobe는 다음과 같은 선택 방식을 안내합니다.

  • 개별 쪽 번호: 2,4
  • 연속 범위: 6-8에 해당하는 범위

중요: Acrobat에서는 문서에 최소 한 페이지를 남겨야 하며, 모든 페이지를 삭제할 수 없다고 안내합니다.

삭제가 불가능하다면?

Adobe의 안내대로 파일 → 문서 속성 → 보안에서 편집이 허용되는 PDF인지 확인합니다. 보안상 수정이 제한된 문서는 정당한 권한을 가진 소유자에게 편집 가능한 버전을 요청해야 합니다.

Acrobat Reader의 무료 열람·인쇄 기능과 Acrobat의 유료 편집 기능을 동일하게 생각하면 안 됩니다. 편집 도구가 보이지 않는다면 현재 사용하는 제품과 플랜을 확인하세요.

공식 근거: Adobe — 데스크톱 Acrobat에서 PDF 페이지 삭제.

8. Acrobat 웹 버전으로 삭제할 때 가장 중요한 차이

Adobe의 웹용 Acrobat은 편집 → 페이지 구성에서 PDF 파일을 선택하고 페이지 썸네일을 삭제·이동하는 기능을 안내합니다.

하지만 절차에는 파일 업로드가 포함됩니다. Adobe 공식 문서에 따르면 수정된 PDF가 Adobe 클라우드 스토리지에 저장되는 동작도 있습니다.

이 점 때문에 주민등록번호·계좌번호·의료기록·계약서·회사 기밀이 들어 있는 PDF를 단지 한 페이지 삭제하려고 온라인 서비스에 업로드하는 것은 신중해야 합니다.

  • 주민등록증 사본·급여명세서·의료서류: 온라인 업로드를 피하고 로컬 처리 권장
  • 회사 기밀·고객정보: 조직의 문서 보안 정책을 따르기
  • 전자서명 PDF: 서명 유효성·원본성 요구사항 확인

'무료 PDF 편집'이라는 광고만 보고 파일을 업로드하지 마세요. 실제 무료 범위, 로그인 필요 여부, 보관 정책을 확인해야 합니다.

공식 근거: Adobe — 웹용 Acrobat에서 PDF 페이지 구성.

9. PDF 페이지가 삭제되지 않는 6가지 원인

증상가능한 이유확인할 항목
Delete 키를 눌러도 반응이 없음페이지 썸네일이 아닌 문서 본문을 선택미리보기의 보기 → 썸네일
삭제 버튼이 아예 없음PDF 뷰어가 열람 전용이거나 해당 제품의 편집 기능 제한사용하는 앱과 구독·권한

PDF가 암호로 보호된 경우

PDF 열람 암호를 알고 있어도 편집 권한이 별도로 제한될 수 있습니다. 권한이 없는 문서를 보호 기능을 우회해 수정하려 하지 말고, 문서 소유자에게 적절한 편집본을 요청하세요.

삭제한 페이지를 다시 되살릴 수 있나요?

저장 전에는 실행 취소가 가능한 경우가 있습니다. 저장 후에도 원본 파일을 따로 두었다면 원본에서 다시 추출할 수 있습니다. 그러나 원본까지 덮어써 저장했다면 복구가 보장되지 않으므로 사본으로 시작하는 것이 가장 확실합니다.

10. '페이지 삭제'와 '개인정보 삭제'는 같지 않습니다

문서를 제출하기 전 주소·계좌번호가 포함된 페이지 한 장을 완전히 빼는 것과, 일부 페이지의 특정 글자만 검게 가리는 것은 별개 문제입니다.

특히 PDF 화면 위에 검은 사각형만 그려놓으면 아래의 텍스트가 여전히 추출될 수 있습니다. 개인정보 가리기는 정식 교정(redaction) 기능을 이용한 뒤, 텍스트 추출·검색·파일 속성까지 검증해야 합니다.

상황별 구별

  • 불필요한 부록 1장 제거: 페이지 삭제 또는 남길 페이지만 새 PDF로 출력
  • 전체 문서에 있는 이름만 가리기: 페이지 삭제가 아니라 적절한 PDF 교정 작업
  • 주민등록번호 일부만 가리기: 검은 박스 덮기가 아닌 정보 제거 검증 필요
  • 서명된 계약서 일부 삭제: 문서 진본성·서명 검증 문제를 먼저 확인
  • 편집 제한된 문서: 권한 있는 원본 요청

민감한 정보가 포함된 파일은 삭제한 결과를 다른 PDF 뷰어에서 다시 열어 확인하는 것이 좋습니다.

11. 전자서명·입력 양식이 들어 있는 PDF라면

인쇄로 PDF를 다시 저장하면 단순한 화면 내용은 남아도 입력할 수 있는 양식 필드, 내부 링크, 책갈피, 디지털 서명 검증 정보 등이 원본과 다르게 처리될 수 있습니다.

예를 들어 다음과 같은 PDF는 주의가 필요합니다.

  • 정부·기관에서 내려받은 작성 가능한 신청서
  • 공인된 디지털 서명이 포함된 계약서
  • 책갈피와 내부 이동 링크가 많은 매뉴얼
  • 첨부 파일이 포함된 PDF 문서
  • 접근성 태그 등 구조 정보가 필요한 문서

실무 원칙: 단순 제출용 출력 사본을 만드는 작업이 아니라면 페이지 선택 PDF 인쇄로 저장한 결과를 원본과 동등하다고 가정하지 마세요.

전자서명이 붙은 문서는 페이지를 바꾸는 행위 자체가 서명 검증에 영향을 줄 수 있으므로, 필요한 경우 발급 기관·서명자에게 수정된 정본을 요청하는 것이 안전합니다.

12. 5분 실전 점검: 10쪽 PDF에서 4쪽만 빼기

예제 PDF가 10쪽이라고 가정합니다.

Windows 11

  1. 원본.pdf 복사 → 작업본.pdf
  2. 작업본.pdf를 Edge로 열기
  3. Ctrl+P → PDF 출력 대상을 선택
  4. 페이지를 1-3,5-10으로 지정
  5. 작업본_4쪽제외.pdf로 저장
  6. 열어서 9쪽인지, 4쪽이 제외됐는지 확인

Mac

  1. 원본.pdf 복사 → 작업본.pdf
  2. 미리보기로 열기 → 보기 → 썸네일
  3. 4번째 페이지 썸네일 클릭
  4. Delete
  5. 저장
  6. 파일을 다시 열어 9쪽인지, 제거할 내용이 없어진 것인지 확인

Acrobat

  1. 원본 PDF 사본 열기
  2. 모든 도구 → 페이지 구성
  3. 4쪽을 삭제 대상으로 선택
  4. 삭제 확인 후 별도 저장
  5. 9쪽인지와 문서 내부 기능을 확인

중요: 실제 업무 문서에는 표지·목차 등 때문에 내부 인쇄된 페이지 숫자와 PDF 뷰어의 페이지 번호가 다를 수 있습니다. 반드시 실제 삭제 대상 페이지 내용을 확인하세요.

13. 자주 묻는 질문

Q1. PDF 페이지 삭제를 프로그램 설치 없이 무료로 할 수 있나요?

Windows 11에서는 Edge의 인쇄 화면에서 남길 페이지를 골라 새로운 PDF로 저장하는 방법을 검토할 수 있습니다. Mac에서는 기본 미리보기 앱의 페이지 삭제 기능을 사용할 수 있습니다. 다만 Windows의 방식은 원본 PDF 내부를 직접 편집하는 것과 다릅니다.

Q2. PDF 10쪽에서 4쪽만 빼려면 어떤 페이지 번호를 입력하나요?

Edge의 사용자 지정 페이지 선택 방식에서는 **1-3,5-10**처럼 남길 페이지를 입력합니다. 결과는 총 9쪽입니다.

Q3. PDF 마지막 빈 페이지 삭제는 어떻게 하나요?

10쪽이 마지막 빈 페이지라면 Windows에서 **1-9**만 새 PDF로 출력할 수 있습니다. Mac 미리보기에서는 마지막 페이지의 썸네일을 선택하고 Delete를 누를 수 있습니다.

Q4. Acrobat Reader 무료 버전에서 페이지 삭제 메뉴가 없어요.

PDF 열람용 프로그램과 편집 기능이 있는 Acrobat 제품의 기능은 다를 수 있습니다. 현재 앱과 플랜을 확인하세요. 페이지 삭제·재정렬 도구가 보이지 않는다는 이유만으로 오류라고 단정할 수 없습니다.

Q5. Mac 미리보기에서 삭제하면 원본도 수정되나요?

원본 파일을 그대로 열어 저장하면 원본에 변경이 반영될 수 있습니다. 작업 전에 Finder에서 파일을 복사하거나 적절한 사본을 만들어 작업하세요.

Q6. PDF 순서 변경도 Edge 인쇄로 가능한가요?

특정 쪽만 골라 새 PDF로 저장하는 작업과 페이지를 자유롭게 재정렬하는 작업은 다릅니다. 순서를 확실하게 바꾸려면 미리보기·Acrobat처럼 썸네일 재정렬을 지원하는 도구가 적합합니다.

Q7. PDF에 전자서명이 있는데 한 쪽을 삭제해도 되나요?

서명된 PDF를 수정하면 전자서명 검증에 영향을 줄 수 있습니다. 계약·증명 서류라면 원본 보존과 발급·서명 기관 확인을 우선하세요.

Q8. 인터넷 무료 PDF 편집기에 파일을 올려도 괜찮나요?

온라인 도구는 파일이 외부 서버로 전송·보관될 수 있습니다. Adobe 웹용 Acrobat 공식 문서도 업로드 및 Adobe 클라우드 스토리지 저장 과정을 안내합니다. 개인정보·기밀 문서라면 온라인 업로드보다 로컬 처리를 우선하세요.
