온수만 안 나올 때는 온수 지원 여부와 잠금부터

  1. 모델이 온수를 지원하는지 확인하고 온수 표시 옆 자물쇠나 잠금 표시등을 봅니다. 온수 기능을 별도로 끌 수 있는 모델이면 온수 기능도 켜져 있는지 확인하세요.
  2. 설명서에 적힌 버튼으로 잠금을 풀고 컵을 놓은 뒤 온수를 선택해 출수합니다. 코웨이 엘리트 얼음정수기 RO(CHPI-7521L)는 설정 버튼을 3초 누른 뒤 온수 잠금을 변경합니다. SK매직 WPUIAC403SMG는 온수 버튼을 눌렀을 때 잠금 램프가 깜박이면 잠금 버튼을 3초 눌러 해제합니다. 컵을 받칠 때 손을 출수구 아래에 두지 말고, 확인 후 어린이가 있는 집은 잠금을 다시 켜세요.
  3. 온수 준비 표시가 있으면 완료까지 기다리세요. 저장 가열 방식은 연속 사용 직후 온수가 다시 데워지는 시간이 필요할 수 있습니다. 준비가 끝나도 계속 차갑거나 아예 나오지 않으면 표시 상태를 기록해 점검을 요청하세요.

겨울에 직수형 순간온수만 가늘어지는 이유

같은 온도의 온수를 만들려면 들어오는 물이 차가울수록 가열에 필요한 열이 늘어납니다. 가열 용량이 한정된 순간온수 모델은 물이 지나가는 속도를 줄이거나 출수 준비 시간이 길어질 수 있습니다. 정수는 평소대로 나오고 온수도 설정 온도에 가깝게 꾸준히 나온다면 모델의 유량 제어로 설명될 수 있습니다. 평소보다 현저히 가늘거나 흐름이 끊기고, 온도가 오르지 않거나 오류가 뜨면 제조사에 문의하세요.

정수도 약하면 주방 냉수와 원수밸브 확인

  1. 주방 수도꼭지 냉수와 비교합니다. 수전도 약하면 단수, 건물 급수 또는 한파 뒤 배관 동결 여부를 관리사무소 등에 먼저 확인하세요. 한파 뒤 급수가 끊겼고 동결이 의심되면 전원 재연결을 보류하세요.
  2. 싱크대 아래에서 정수기 호스가 연결된 원수밸브를 찾습니다. 일반적인 90도 레버형 볼밸브는 손잡이가 밸브 내부 물길과 일자(평행)면 열림, 직각이면 잠김입니다. 벽이나 바닥을 기준으로 판단하면 배관 방향에 따라 헷갈릴 수 있습니다. 손잡이 형상이 다르면 밸브 각인과 설치 안내를 따르세요.
  3. 원수밸브 주변과 호스를 눈으로 확인합니다. 누수 없이 밸브가 잠겨 있고 정상 위치가 확실할 때만 엽니다. 호스가 가구에 눌렸는지, 필터 교체 시기가 지났는지 확인하고 호스 연결부를 분리하거나 밸브를 억지로 돌리지 마세요. 최근 필터 교체 직후 약해졌다면 교체일과 출수 상태를 서비스 담당자에게 알려 주세요.

얼음이 안 나오면 제빙 OFF와 얼음 잠금을 따로 확인

제빙 OFF는 새 얼음 만들기를 멈추고, 얼음 잠금은 저장된 얼음의 토출을 막습니다. 겨울에 꺼둔 기능을 다시 쓸 때는 제빙을 켜고 토출 잠금을 따로 확인하세요. 제품에 따라 ‘계절 잠금’이라는 메뉴 없이 제빙 켜기·끄기와 잠금으로 나뉘어 있습니다.

SK매직 WPUI100·110·200·210은 공식 FAQ에서 얼음 ON/OFF 또는 얼음잠금 버튼을 각각 5초 이상 조작하도록 안내합니다. 얼음 부족 표시가 켜져 있으면 해당 기종 안내에 따라 약 1시간 뒤 확인하세요. LG 퓨리케어 냉동얼음정수기 WD721RH는 상단 커버가 닫혔는지, 저장 얼음을 모두 썼는지부터 확인하도록 안내합니다.

만빙 표시가 있는데도 나오지 않으면 설명서의 출빙 버튼 조작 방식을 확인하세요. 같은 증상이 계속되면 출빙구에 손가락이나 도구를 넣어 얼음을 빼려 하지 말고 서비스에 문의하세요.

점검등 점멸과 전원 재연결 순서

누수·탄 냄새·스파크·차단기 작동이 있으면 사용을 중단하세요. 젖거나 손상된 플러그와 콘센트는 만지지 마세요. 누수 시 안전하게 접근할 수 있고 위치가 확실한 원수밸브를 잠근 뒤 서비스에 연락하세요.
  1. 점멸 위치, 색, 코드, 발생 시점을 기록합니다. 출수 중에만 깜박이거나 필터 교체·살균 상태를 알리는 모델도 있으니 사용설명서에서 표시를 확인하세요.
  2. 급수가 정상이고 이상 징후가 없으며, 제조사가 모델에 대해 전원 재연결을 허용할 때만 한 번 시도합니다. 작동이 끝난 뒤 마른 손으로 플러그 몸체를 잡아 뽑고, 설명서나 상담에서 지정한 시간만큼 기다리세요. 대기 시간이 불명확하면 해당 모델 고객센터에 재연결 절차를 확인하세요.
  3. 초기 동작이 끝난 뒤 정수로 급수를 확인하고 원래 증상을 다시 확인하세요. 같은 코드가 재발하거나 전원이 다시 꺼지면 반복 리셋을 중단하고 접수하세요.

흔히 말하는 ‘전원 하드 리셋’은 이 글에서 전원을 끊었다가 다시 연결하는 1회 재시동을 뜻합니다. 필터 수명 표시 초기화나 공장 초기화는 모델 설명서의 해당 절차를 따르세요.

자주 묻는 질문

정수기 온수가 안 나오는데 정수는 잘 나와요. 무엇부터 확인하나요?

온수 잠금과 온수 기능이 켜져 있는지 확인하세요. 모델 설명서에 따라 잠금을 풀고 온수를 선택한 뒤 컵을 놓고 출수하세요. 표시가 정상인데 계속 찬물만 나오거나 온수가 전혀 나오지 않으면 제조사에 문의하세요.

겨울에 직수 정수기 온수 물줄기만 약한 건 정상인가요?

찬 원수를 같은 목표 온도로 데우려면 물 1리터당 더 많은 열이 필요합니다. 순간온수 모델은 유량을 줄이거나 준비 시간이 길어질 수 있습니다. 평소보다 현저히 약해졌거나 정수까지 약해졌다면 점검이 필요합니다. 오류가 반복될 때도 제조사에 문의하세요.

정수기 원수밸브는 일자가 열림인가요?

일반적인 90도 레버형 볼밸브는 손잡이가 밸브의 물길과 나란하면 열림, 직각이면 잠김입니다. 다른 형태의 밸브는 각인과 설치 안내를 따르고, 뻑뻑하거나 새는 밸브는 억지로 돌리지 마세요.

얼음 잠금과 제빙 OFF는 같은 설정인가요?

얼음 잠금은 얼음 토출을 제한하고, 제빙 OFF는 새 얼음을 만드는 기능을 끕니다. 겨울에 설정을 바꿨다면 두 상태를 각각 확인하고, 제빙을 다시 켠 뒤 모델 설명서에 적힌 시간 동안 기다리세요.

정수기 점검등이 깜박이면 전원을 다시 연결해도 되나요?

먼저 표시를 기록하고 모델 설명서에서 의미를 확인하세요. 위험 징후가 없고 제조사가 전원 재연결을 허용할 때만 한 번 시도하세요. 대기 시간과 재연결 순서는 모델 설명서나 고객센터 안내를 따르세요. 점멸이 재발하면 서비스에 문의하세요.
