2. 가장 먼저 할 일: 세로 화면 방향 고정 끄기

Apple은 아이폰 화면이 회전하지 않을 때 가장 먼저 제어 센터의 '세로 화면 방향 고정' 상태를 확인하라고 안내합니다.

Face ID 지원 아이폰에서

  1. 화면 오른쪽 상단 모서리에서 아래로 쓸어내려 제어 센터를 엽니다.
  2. 자물쇠를 둘러싼 원형 화살표 모양의 세로 화면 방향 고정 버튼을 찾습니다.
  3. 버튼이 빨간색이면 잠금이 켜진 상태이므로 탭해서 해제합니다.
  4. 버튼이 회색이면 잠금이 해제된 상태입니다.
  5. 제어 센터를 닫고 Safari 또는 계산기 앱에서 기기를 옆으로 돌려봅니다.

홈 버튼이 있는 아이폰에서

홈 버튼이 있는 일부 모델에서는 화면 하단 가장자리에서 위로 쓸어올려 제어 센터를 엽니다. 그다음 같은 회전 잠금 버튼의 상태를 확인합니다.

주의할 점: 버튼이 회색으로 바뀌었다는 사실은 '회전을 허용한다'는 뜻이지, 모든 앱을 강제로 가로 화면으로 바꾸는 명령이 아닙니다. 앱 자체가 가로 화면을 지원하지 않으면 회전하지 않을 수 있습니다.

3. 회전 잠금 버튼이 제어 센터에 없을 때

버튼이 보이지 않는다고 해서 회전 기능이 기기에서 삭제된 것은 아닙니다. Apple은 제어 센터에서 제어 항목을 추가·재정렬·삭제할 수 있다고 안내합니다.

버튼 찾기와 추가하기

  1. 제어 센터를 열어 다른 제어 항목 그룹에 버튼이 있는지 확인합니다.
  2. 여전히 보이지 않으면 제어 센터를 열고 추가(+) 또는 편집 기능을 선택합니다.
  3. '제어 항목 추가'를 누릅니다.
  4. 항목 목록에서 '세로 화면 방향 고정' 또는 '회전 잠금'에 해당하는 제어 항목을 찾습니다.
  5. 버튼을 제어 센터에 추가하고 편집을 마칩니다.
  6. 다시 버튼을 눌러 빨간색 잠금 상태를 해제한 뒤 회전을 시험합니다.

제어 센터의 편집 방식은 iOS 버전에 따라 버튼을 길게 눌러 편집을 시작하거나 추가 버튼을 누르는 방식으로 표시될 수 있습니다. 제어 항목이 다른 그룹에 배치되어 있을 수도 있습니다.

하지 말아야 할 일: 회전 버튼이 없다는 이유로 아이폰 전체 설정을 초기화하거나 앱을 일괄 삭제하지 마세요.

4. 가장 중요한 구별: 앱이 가로 화면을 지원하는가?

Apple 공식 지원 문서는 모든 앱이 가로·세로 화면 전환을 지원하지는 않는다고 명시합니다. 따라서 한 앱에서 화면이 회전하지 않는 것은 설정이나 센서 고장이 아닐 수도 있습니다.

다른 앱으로 비교하는 방법

  1. 회전 잠금을 해제합니다.
  2. 문제가 발생한 앱에서 기기를 가로로 돌립니다.
  3. 동일한 상태로 Safari에서 웹페이지를 엽니다.
  4. 계산기 앱에서도 화면 방향 반응을 확인합니다.
  5. 다른 지원 앱에서는 정상 회전하지만 특정 앱에서만 실패한다면, 해당 앱의 가로 모드 지원 및 현재 화면 구성을 확인합니다.

Apple은 지원 문서에서 Safari 또는 계산기를 가로 모드 반응을 확인하기 위한 비교 앱으로 제시합니다.

테스트 결과의미다음 조치
Safari·계산기에서는 가로로 바뀜기기에서 방향 전환이 작동할 가능성 높음원래 앱의 지원 여부 확인
문제 앱만 회전 안 됨앱별 가로 화면 미지원 또는 앱 상태 문제 가능앱 도움말·업데이트 확인
모든 회전 지원 앱에서 실패전역 회전 잠금·시스템·방향 감지 문제 가능수준기 테스트 및 재시동
앱의 특정 화면에서만 실패앱 내부 화면 유형에 따른 제한 가능다른 화면에서도 비교

앱에 전체 화면 버튼이나 화면 방향을 수동으로 바꾸는 기능이 있는 경우, 그 동작을 iOS 전체의 자동 회전과 혼동하지 마세요.

5. 홈 화면만 가로로 안 돌아가면 고장일까?

홈 화면은 화면 방향 오류를 판단하는 표준 시험 장소가 아닙니다. iPhone은 앱·화면에 따라 가로 방향 지원 여부가 달라질 수 있습니다.

특히 웹페이지나 사진·동영상을 볼 때는 가로로 회전하더라도, 홈 화면 또는 앱의 특정 메뉴가 같은 방식으로 회전해야 하는 것은 아닙니다. 기종과 시스템 버전에 따라 화면 구성도 달라질 수 있습니다.

이런 경우에는 다음처럼 확인하세요.

  1. 제어 센터에서 회전 잠금이 회색(해제)인지 확인합니다.
  2. 홈 화면을 벗어나 Safari로 이동합니다.
  3. 웹페이지를 연 상태로 아이폰을 옆으로 돌립니다.
  4. Safari에서 가로 회전이 된다면, 홈 화면이 회전하지 않는다는 이유만으로 센서 고장이라고 판단하지 않습니다.

결론: 홈 화면 문제와 아이폰의 모든 화면에서 회전이 불가능한 문제를 별도로 다뤄야 합니다.

6. 유튜브 전체 화면은 돌아가는데 다른 화면은 세로일 때

동영상 앱의 전체 화면 버튼과 아이폰의 자동 회전 잠금은 서로 다른 동작일 수 있습니다.

  • 동영상 플레이어의 전체 화면 기능으로 가로 형태의 영상이 보이는 것은 앱이 직접 제공하는 기능일 수 있습니다.
  • 회전 잠금을 해제해도 앱의 피드·메뉴·댓글 영역은 세로 레이아웃만 지원할 수 있습니다.
  • 반대로 특정 동영상에서만 가로 전환이 안 된다면 그 앱·영상 화면에 한정된 문제일 수 있습니다.

따라서 유튜브 앱에서 전체 화면으로 들어간 뒤 회전된다는 결과 하나만으로 모든 방향 감지 기능을 검증했다고 생각하지 마세요.

추천 비교 방법은 제어 센터의 회전 잠금 상태 확인 → Safari 가로 회전 시험 → 문제가 생긴 앱 시험입니다.

7. 아이폰의 방향 감지 기능 확인: '측정' 앱 수준기

Apple은 화면 회전이 제대로 작동하지 않을 때 '측정(Measure)' 앱의 '수준기(Level)'를 이용해 기기가 방향 변화를 감지하는지 확인할 것을 권장합니다.

공식 진단 절차

  1. 아이폰의 측정 앱을 엽니다.
  2. 앱 안에서 '수준기'를 선택합니다.
  3. 기기를 안전하게 잡고 평평한 물체 또는 안정적인 표면을 기준으로 기울기를 바꿔봅니다.
  4. 수준기의 숫자·표시가 방향 변화에 따라 달라지는지 관찰합니다.
  5. 정상적인 기울기 변화가 반영된다면 방향 감지 기능이 어느 정도 반응하고 있는 것으로 해석할 수 있습니다.
  6. 수준기 자체가 멈추거나 반응하지 않으면 Apple 안내에 따라 아이폰을 재시동하고 다시 확인합니다.

Apple 공식 문서에는 수준기를 액자 등 물체에 대고 움직여 기울기를 비교하는 방법이 설명돼 있습니다.

진단 해석의 한계: 수준기가 반응한다는 이유만으로 모든 관련 부품이 100% 정상이라고 확정할 수 없고, 수준기가 한 번 멈췄다는 이유만으로 센서 교체가 필요하다고 판단할 수도 없습니다. 다른 앱의 회전 결과와 함께 비교해야 합니다.

공식 근거: Apple — '측정' 앱 수준기로 기기 방향 확인

8. 화면 회전이 갑자기 멈췄다면 앱 종료 후 다시 열기

일부 앱에서만 일시적으로 반응이 멈추는 경우에는 그 앱을 종료했다가 다시 실행하는 방법을 검토할 수 있습니다.

  1. 앱 전환기를 열고 문제가 생긴 앱을 찾습니다.
  2. 앱 미리보기를 위로 쓸어올려 앱을 종료합니다.
  3. 홈 화면 또는 앱 보관함에서 같은 앱을 다시 엽니다.
  4. 회전 잠금이 해제된 상태에서 가로 회전을 다시 확인합니다.
  5. 이어서 Safari에서도 정상적으로 회전하는지 비교합니다.

Apple은 앱이 정상적으로 작동하지 않을 때 앱 종료·재실행을 먼저 시도하도록 안내합니다.

주의: 모든 앱을 매번 강제로 종료하는 습관이 아이폰 성능이나 배터리를 무조건 개선한다는 근거는 아닙니다. 현재 문제가 발생한 앱에 한해 시행하면 됩니다.

공식 근거: Apple — iPhone에서 앱 종료하고 다시 열기

9. 회전 잠금이 꺼져 있는데도 계속 안 되면 재시동

Apple 공식 화면 회전 도움말은 회전 잠금을 해제하고 다른 앱에서 시험했는데도 실패하거나 측정 앱의 수준기가 멈춘 경우 재시동을 권장합니다.

Face ID 지원 아이폰 재시동 방법

  1. 측면 버튼 + 음량 버튼 중 하나를 함께 길게 누릅니다.
  2. 전원 끔 슬라이더가 나타나면 밀어서 기기를 끕니다.
  3. 기기가 완전히 종료된 뒤 다시 켭니다.
  4. 잠금 암호를 입력해야 하는 경우 본인의 암호로 인증합니다.
  5. 제어 센터에서 회전 잠금 상태를 다시 확인합니다.
  6. Safari·계산기와 측정 앱의 수준기를 차례로 재시험합니다.

모델에 따라 측면 버튼 또는 상단 버튼을 길게 눌러 전원 끔 슬라이더를 표시합니다. Apple 지원 문서에서 모델별 정상 재시동 절차를 확인하세요.

기기 강제 재시동은 일반적인 정상 재시동과 다릅니다. 화면이 먹통인 상황이 아니라면 먼저 정상적인 전원 종료·재시작을 선택하세요.

10. 특정 앱에서만 회전이 안 될 때 업데이트 확인

Safari·계산기 등에서는 방향 전환이 작동하는데 제3자 앱만 회전하지 않거나 오류가 반복되는 경우, 해당 앱의 업데이트 여부를 확인할 수 있습니다.

  1. App Store를 엽니다.
  2. 계정 프로필에서 해당 앱의 업데이트가 있는지 확인합니다.
  3. 업데이트가 있다면 공식 경로로 설치합니다.
  4. 문제가 계속된다면 iPhone 설정 → 일반 → 소프트웨어 업데이트에서 제공되는 업데이트를 확인합니다.
  5. 업데이트 이후에도 같은 앱에서만 재현된다면 앱 개발자의 지원 문서를 확인합니다.

다만 앱이 원래 가로 모드를 지원하지 않는다면 업데이트를 해도 회전하지 않는 것이 정상 동작일 수 있습니다. 설정의 오류인지, 애초에 지원되지 않는 화면인지 먼저 구별하세요.

Apple은 비정상적인 앱 동작에 대해 앱 업데이트와 기기 소프트웨어 업데이트 확인을 권장합니다.

11. 화면 회전 때문에 아이폰을 초기화해야 할까?

공장 초기화는 첫 해결책이 아닙니다. Apple의 공식 화면 회전 안내는 먼저 회전 잠금 해제, 지원 앱 시험, 측정 앱 수준기 테스트, 재시동을 제시합니다.

따라서 아래 작업은 우선적으로 권장하지 않습니다.

  • 사진·메시지·앱 데이터의 보존 여부를 확인하지 않은 전체 초기화
  • 원인 확인 없이 모든 앱을 삭제하고 재설치
  • 센서 고장을 확정하지 않은 상태에서 임의 수리·분해
  • 출처 불명의 회전 강제 앱이나 비공식 iOS 수정 도구 설치
  • 앱에 없는 가로 모드를 억지로 활성화하려는 우회 방법 사용

Apple 공식 문서도 앱 삭제 시 앱에 저장된 데이터가 손실될 수 있음을 안내합니다. 화면 회전 문제가 있는 앱을 재설치해야 할 때에는 동기화·백업 여부를 먼저 확인하세요.

12. Apple 지원을 받아야 하는 경우

아래 조건이 함께 나타난다면 Apple 공식 지원에 문의할 근거가 충분합니다.

  • 회전 잠금이 꺼져 있고 Safari·계산기 같은 지원 앱에서도 회전이 계속 실패함
  • 측정 앱 수준기도 기울기 변화에 반응하지 않거나 반복적으로 멈춤
  • 정상 재시동·앱 업데이트·소프트웨어 업데이트 이후에도 동일하게 발생함
  • 낙하·침수·수리 등 물리적 손상이 의심되는 시점부터 오류가 시작됨

상담 전에는 아이폰 모델명, 설치된 iOS 버전, 오류를 보인 앱, 회전 잠금 버튼 상태, 수준기 테스트 결과, 발생 시점을 간단히 기록하세요.

14. 자주 묻는 질문(FAQ)

Q1. 아이폰 화면 회전 잠금은 어디서 해제하나요?

Face ID 모델은 화면 오른쪽 상단에서 아래로 쓸어내려 제어 센터를 열고, 자물쇠 모양 회전 잠금 버튼이 빨간색이라면 탭해 해제하세요. 홈 버튼 모델은 제어 센터를 여는 동작이 다를 수 있습니다.

Q2. 회전 잠금 아이콘이 빨간색이면 켜진 건가요?

네. Apple 사용 설명서 기준 빨간색은 화면 방향 잠금, 회색은 잠금 해제 상태입니다.

Q3. 회전 잠금 버튼이 제어 센터에 없어요.

제어 센터의 다른 제어 항목 그룹을 확인하고, 없다면 편집 → 제어 항목 추가에서 회전 잠금 버튼을 추가하세요.

Q4. 홈 화면은 안 돌아가는데 Safari는 돌아가요.

홈 화면과 Safari의 가로 방향 지원은 동일하지 않을 수 있습니다. Safari에서 방향 전환이 된다면 홈 화면만으로 센서 고장을 판단하지 마세요.

Q5. 유튜브 영상은 가로로 나오는데 다른 앱은 그대로예요.

동영상 앱의 전체 화면 기능과 iPhone의 전역 화면 방향 전환은 다를 수 있습니다. Safari·계산기에서 다시 비교하세요.

Q6. Safari도 계산기도 회전되지 않으면 어떻게 하나요?

회전 잠금이 실제로 해제됐는지 확인한 뒤 측정 앱의 수준기에서 방향 변화가 감지되는지 시험하세요. 다음 단계는 정상 재시동입니다.

Q7. 측정 앱의 수준기가 움직이지 않으면 센서 고장인가요?

한 번의 결과만으로 확정할 수 없습니다. Apple은 수준기가 멈추면 재시동을 시도하라고 안내합니다. 재시동 후에도 여러 앱의 방향 전환과 수준기 모두 문제가 있다면 공식 지원을 받아보세요.

Q8. 아이폰을 옆으로 돌리면 모든 앱이 가로로 바뀌나요?

아닙니다. Apple은 일부 앱은 가로·세로 회전을 지원하지 않는다고 명시합니다. 앱별 지원 여부가 다릅니다.

Q9. 화면 회전이 안 되면 공장 초기화해야 하나요?

필요하다고 단정할 수 없습니다. 제어 센터 → 지원 앱 비교 → 수준기 → 재시동을 먼저 수행하세요. 원인 확인 없이 초기화하면 데이터 손실 위험만 커질 수 있습니다.

Q10. 아이폰과 아이패드의 자동 회전 설정은 똑같나요?

두 제품 모두 회전 잠금 기능이 있지만 멀티태스킹·앱 지원 화면·UI 구성은 다를 수 있습니다. 이 글은 iPhone을 대상으로 하므로 iPad의 회전 문제는 해당 제품의 별도 지원 안내를 확인하세요.

결론

아이폰 화면이 안 돌아가면 '회전 잠금 버튼(빨강)'부터 해제하고, Safari·계산기에서 가로 회전을 시험하세요. 특정 앱만 회전하지 않는다면 앱의 가로 모드 지원 여부를 확인합니다. 여러 지원 앱에서도 실패한다면 측정 앱의 수준기 → 재시동 → 업데이트 → Apple 지원 순서로 확인하는 것이 합리적입니다.

화면 회전 오류는 대부분 원인을 먼저 구분해야 효율적으로 점검할 수 있습니다. 한 앱이나 홈 화면이 회전하지 않는 현상만으로 센서 고장이나 초기화 필요성을 판단하지 마세요.
