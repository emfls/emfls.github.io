2026년 기준 Windows 11에서 바로 시도할 수 있는 순서와 해결되지 않을 때의 진단법을 정리했습니다. 실제 개인 PC를 테스트했다는 체험담이 아니라 Microsoft 공식 지원 문서·업데이트 안내를 대조한 가이드입니다.

1. 먼저 증상부터 구분하세요: 썸네일과 미리보기 창은 다릅니다

화면에서 보이는 현상우선 확인할 원인먼저 할 일
JPG·PNG 파일이 전부 사진 대신 그림 아이콘으로 표시썸네일 표시 옵션·보기 크기·캐시파일 탐색기 폴더 옵션에서 아이콘만 표시 설정 해제
사진은 잘 보이는데 선택해도 오른쪽 큰 미리보기가 없음미리보기 창이 꺼짐파일 탐색기 보기 메뉴에서 미리보기 창 활성화
다운로드한 PDF에 “미리 보려는 파일이 컴퓨터에 손상을 줄 수 있습니다” 경고인터넷 출처 표시(Mark of the Web) 관련 보안 제한파일 출처 검증, 보안 차단을 함부로 끄지 않기
특정 PNG·HEIC·영상만 아이콘으로 표시파일 형식·코덱·원본 손상다른 JPG와 비교 후 지원 앱·확장기능 확인
OneDrive 폴더의 일부 사진만 미리보기가 비거나 지연클라우드 동기화·로컬 파일 상태파일의 동기화 상태 확인
파일 탐색기 자체가 멈추거나 폴더를 열 수 없음탐색기 프로세스·저장장치 등 다른 문제탐색기 재시작 및 Windows 업데이트 확인

이 글의 핵심: 한 문제의 해결법을 다른 문제에 무작정 적용하지 마세요. 특히 보안 경고는 단순 썸네일 캐시 문제와 다릅니다.

2. 사진이 아이콘으로만 나온다면: 1분 설정 확인

Windows 11에서 JPG나 PNG가 기본 앱 아이콘으로만 나타나는 경우 우선 아래 방법을 시도하세요.

  1. Windows 키 + E를 눌러 파일 탐색기를 엽니다.
  2. 오른쪽 위 점 세 개(…) 메뉴에서 옵션을 엽니다.
  3. 보기 탭으로 이동합니다.
  4. 항목 중 “항상 아이콘 표시, 미리 보기 표시 안 함” 또는 이와 비슷한 뜻의 옵션(영문: Always show icons, never thumbnails)이 체크돼 있으면 체크를 해제합니다.
  5. 적용 → 확인을 누른 뒤 사진 폴더를 다시 엽니다.
  6. 파일 탐색기의 보기에서 큰 아이콘 또는 아주 큰 아이콘으로 바꿔 비교합니다.

주의: 이 옵션은 체크를 ‘해야’ 하는 것이 아니라 체크를 ‘해제’해야 합니다. 이 설정은 의도적으로 파일 종류별 아이콘을 보여 주고 미리보기 이미지는 생략하는 기능입니다. 회사에서 관리하는 PC라면 관리 정책으로 제한됐을 수 있으므로 임의로 레지스트리를 수정하지 마세요.

Microsoft Q&A의 2026년 5월 사례에서도 바로 이 체크 해제로 해결됐고, 담당자는 이 옵션이 성능·관리 목적에 따라 축소 그림 생성을 중지하는 설정이라고 설명합니다.

참고: Microsoft Q&A — Windows 11 사진 썸네일 표시 문제(2026.5)

3. 미리보기 창 자체가 없다면: 보기 메뉴에서 켜기

축소 그림이 보이는 것과 오른쪽 큰 파일 미리보기가 보이는 것은 서로 다른 기능입니다.

  1. 파일 탐색기에서 사진이나 문서가 있는 폴더를 엽니다.
  2. 상단의 보기 메뉴를 엽니다.
  3. 표시 아래 미리 보기 창을 선택합니다. Windows 버전에 따라 메뉴 배열이나 표현이 조금 다를 수 있습니다.
  4. 파일 하나를 클릭해 오른쪽 영역에 내용이 나타나는지 확인합니다.
  5. 여전히 비어 있다면 일반 JPG 파일과 인터넷에서 다운로드한 PDF를 따로 시험해 보세요.

세부 정보 창은 파일명·크기·수정 날짜 등을 보여 주는 영역으로, 미리 보기 창과 기능이 다릅니다. 세부 정보만 보인다고 해서 PDF 본문 미리보기가 켜진 것은 아닙니다.

파일 탐색기 기본 사용 안내: Microsoft 공식 Windows 파일 탐색기

4. 썸네일 캐시가 꼬였다면: 사진을 지우지 않고 다시 만들기

썸네일 캐시는 원본 사진이 아니라 폴더에 표시하기 위한 작은 미리보기 데이터를 저장합니다. 이 캐시가 제대로 갱신되지 않으면 원본 파일은 정상인데 미리보기만 비어 있거나 예전 그림이 표시될 수 있습니다.

안전한 정리 순서

  1. 사진 파일이 정상적으로 열리는지 확인합니다. 중요한 파일은 별도 백업해 두면 더 안전합니다.
  2. 시작 메뉴 검색에서 디스크 정리를 실행합니다.
  3. 일반적으로 시스템 드라이브인 C:를 선택합니다.
  4. 항목에서 미리 보기 사진(Thumbnails)만 선택합니다.
  5. 다운로드, 휴지통, 이전 Windows 설치 등 다른 항목은 필요하지 않으면 체크하지 않습니다.
  6. 확인 → 파일 삭제를 실행하고 파일 탐색기를 다시 엽니다.
  7. 같은 폴더에 돌아가 축소 그림이 다시 생성되는지 확인합니다.

이 작업은 원본 JPG·PNG 자체를 삭제하는 것이 아니라 캐시를 정리하는 절차입니다. 폴더에 사진이 많다면 다시 표시될 때까지 시간이 걸릴 수 있습니다.

참고: Microsoft — Windows 드라이브 공간 확보, 디스크 정리의 Thumbnails 항목

캐시를 지워도 안 된다면?

Windows 키 + R → sysdm.cpl → 고급 → 성능 설정 → 시각 효과에서 “아이콘 대신 미리 보기로 표시”(영문: Show thumbnails instead of icons)가 꺼져 있는지 확인할 수 있습니다. 기기·관리 정책에 따라 설정 메뉴가 다를 수 있습니다. 폴더 옵션이 정상이라면 같은 PC에서 JPG, PNG, 동영상의 결과를 따로 비교해 보세요.

레지스트리 변경, 임의의 썸네일 DB 파일 삭제 명령, 출처가 불명확한 최적화 프로그램은 일반적인 첫 해결책으로 권장하지 않습니다.

5. “파일을 미리 보면 컴퓨터에 손상을 줄 수 있습니다” 경고의 정체

2025년 10월 14일 이후 Windows 보안 업데이트에서는 인터넷에서 다운로드한 파일 가운데 인터넷 출처 표시(MotW)가 붙은 파일에 대해, 파일 탐색기 미리보기 창이 보안상 제한되는 동작이 도입됐습니다. Microsoft는 미리보기 과정에서 외부 네트워크 경로를 참조할 때 발생할 수 있는 인증정보 노출 위험을 줄이기 위한 조치라고 설명합니다.

따라서 다음처럼 진단합니다.

  • 내 PC에서 새로 만든 사진은 잘 미리보이지만 이메일 첨부나 웹에서 내려받은 PDF만 안 된다면 썸네일 캐시보다 출처별 보안 제한을 먼저 의심합니다.
  • “잠재적으로 위험한 파일” 경고가 표시되면 바이러스나 파일 손상이 확정된 것은 아니지만, 안전하다는 뜻도 아닙니다.
  • 파일 출처가 불명확하면 차단을 해제하지 않습니다. 필요한 경우 발신자에게 안전한 경로로 재전송을 요청하거나 보안 담당자에게 확인합니다.

신뢰할 수 있는 파일 하나만 예외로 처리하는 방법

Microsoft는 출처와 안전성을 충분히 확인한 경우에 한해 파일을 마우스 오른쪽 클릭해 속성 → 차단 해제(Unblock)를 선택하는 방법을 안내합니다. 다만 모든 파일에 이 버튼이 표시되는 것은 아니며, 적용 반영에 다시 로그인해야 할 수 있습니다.

주의: 이는 해당 파일에 대한 보안 제한을 완화하는 작업입니다. 인터넷 전체, 네트워크 공유 폴더 전체를 일괄적으로 신뢰 영역에 추가하거나 모든 파일을 한꺼번에 차단 해제하지 마세요.

2026년에는 이 동작이 변경되는 새 미리보기 방식도 시험되고 있습니다. 예를 들어 Microsoft의 2026년 10월 Insider 빌드 안내에는 HTML 파일에 대한 ‘Preview anyway’ 버튼과 일부 비HTML 파일의 자동 미리보기 변경이 명시돼 있습니다. 다만 Insider·Release Preview의 기능은 모든 일반 사용자 PC에 같은 시점에 적용된다는 뜻이 아닙니다. 버튼이 보이지 않는다고 고장으로 판단하지 말고 현재 설치된 Windows 버전과 업데이트 배포 상태를 확인하세요.

6. JPG는 되는데 PNG·HEIC·MP4만 미리보기가 안 된다면

모든 파일이 아닌 일부 형식에서만 문제가 생기면 전역 썸네일 설정 외 원인을 확인해야 합니다.

파일 유형우선 확인다음 조치
JPG/JPEG여러 장 모두 정상인지새 JPG 파일과 기존 JPG 비교
PNG특정 PNG만 문제인지그림판 등에서 열어 원본 이상 유무 확인, 사본으로 다시 저장해 비교
HEIC/HEIF앱에서 실제 열리는지해당 형식을 지원하는 앱·확장 기능 필요 여부 확인
MP4/MOV영상은 재생되는데 썸네일만 없는지코덱·앱 지원 여부, Windows 업데이트 확인
PDF파일 탐색기 미리보기 창만 비는지지원 PDF 앱과 인터넷 출처 보안 제한 확인

확장자를 단순히 .heic에서 .jpg로 바꾸는 것은 사진 형식 변환이 아닙니다. 이름만 바꿔 저장하면 오히려 열기 오류를 유발할 수 있습니다. 파일이 손상됐는지 판단하려면 먼저 해당 형식을 지원하는 앱에서 열어 보세요.

Microsoft의 2026년 2월 Windows 업데이트 기록에도 특정 EXIF 메타데이터가 포함된 동영상의 탐색기 썸네일 문제를 개선했다는 설명이 있습니다. 동영상에서만 증상이 반복된다면 Windows 업데이트 적용 여부도 점검할 근거가 됩니다.

공식 기록: Microsoft — 2026년 2월 Windows 11 File Explorer 썸네일 개선

7. OneDrive 사진만 미리보기가 안 보이는 경우

클라우드와 동기화된 폴더에서는 파일이 PC에 완전히 저장돼 있지 않거나 동기화가 진행 중일 수 있습니다. 이때 썸네일이 늦게 뜨는 문제를 곧바로 원본 삭제로 판단하면 안 됩니다.

  1. 파일 탐색기에서 문제가 있는 사진의 상태 표시와 OneDrive 동기화 메시지를 확인합니다.
  2. 인터넷 연결과 계정 로그인 상태를 점검합니다.
  3. 중요한 사진을 동기화 폴더 밖에 복사본으로 보관할 계획이라면, 먼저 파일이 실제로 PC에 내려받아졌는지 확인합니다.
  4. 파일이 정상적으로 열리지만 미리보기만 안 되면 앞의 썸네일 설정·캐시 단계를 확인합니다.
  5. 클라우드 동기화 상태가 불안정할 때 사진을 대량 이동·삭제하거나 동기화 폴더를 무작정 초기화하지 않습니다.

8. 해결 방법을 적용해도 안 될 때: 5분 분기 진단

테스트결과의심할 범위
같은 폴더의 새 JPG 파일과 오래된 JPG를 비교새 파일만 정상오래된 특정 파일·메타데이터·캐시 문제
JPG는 정상인데 동영상만 아이콘형식별 차이 존재코덱·동영상 썸네일 처리 문제
PC에서 만든 PDF는 정상인데 다운로드 PDF만 경고출처별 차이 존재MotW 미리보기 보안 정책
OneDrive 밖에서는 정상클라우드 위치별 차이동기화·로컬 파일 상태
모든 폴더에서 탐색기 자체가 멈춤미리보기 외 기능도 장애탐색기·Windows 업데이트·시스템 문제

문제가 반복되면 설정 → Windows 업데이트에서 업데이트를 확인하고 재부팅합니다. 업무용 PC는 회사 정책이나 문서 보안 프로그램이 영향을 줄 수 있으므로 관리자에게 문의하세요. 사진 파일을 강제로 확장자 변경하거나 포맷하는 방식으로 해결하려 해서는 안 됩니다.

9. 자주 묻는 질문

Q1. 썸네일 캐시를 삭제하면 사진도 지워지나요?

디스크 정리에서 ‘미리 보기 사진(Thumbnails)’ 항목만 선택했다면 원본 이미지가 아니라 생성된 축소 그림 캐시를 제거하는 동작입니다. 다만 다른 청소 항목을 함께 선택하지 않도록 주의해야 합니다.

Q2. PDF는 열리는데 파일 탐색기에서만 경고가 뜹니다. 파일이 손상된 건가요?

반드시 그런 것은 아닙니다. 2025년 10월 이후 보안 업데이트의 인터넷 출처 표시 관련 미리보기 제한일 수 있습니다. 먼저 출처와 보안 정책을 확인하세요.

Q3. ‘항상 아이콘 표시, 미리 보기 표시 안 함’에 체크해야 하나요?

아닙니다. 사진 축소 그림을 보려면 체크를 해제해야 합니다.

Q4. 회사 파일 서버의 PDF도 미리보기가 안 됩니다.

서버 주소가 어떤 보안 영역으로 분류되는지, 회사의 파일 보안 정책이 무엇인지에 따라 다릅니다. 공유 서버 전체를 사용자가 임의로 신뢰 목록에 등록하지 말고 IT 관리자에게 문의하는 것이 안전합니다.

Q5. ‘Preview anyway’ 버튼이 없으면 업데이트를 잘못한 건가요?

그렇지 않습니다. 해당 버튼 관련 변경은 2026년 Insider·미리보기 빌드 안내에 포함됐으며 일반 배포와 적용 시점이 다를 수 있습니다. 설정에서 현재 Windows 버전과 업데이트 상태를 확인하세요.

10. 최종 5분 체크리스트

  • ☐ 문제는 썸네일인지, 오른쪽 미리보기 창인지 구분했다.
  • ☐ 탐색기 옵션의 ‘항상 아이콘 표시’ 체크를 해제했다.
  • ☐ 큰 아이콘 보기로 사진 폴더를 다시 확인했다.
  • ☐ 필요한 경우 디스크 정리에서 ‘미리 보기 사진’ 캐시만 삭제했다.
  • ☐ 인터넷에서 받은 PDF는 보안 경고의 의미와 파일 출처를 확인했다.
  • ☐ 원본 JPG·PNG 파일이 실제로 정상 열리는지 확인했다.
  • ☐ OneDrive, HEIC, MP4 등 특정 위치·형식에 한정된 문제인지 구분했다.

결론: Windows 11 미리보기가 안 된다고 해도 사진이 사라졌다는 뜻은 아닙니다. 아이콘만 보이면 표시 옵션과 캐시, 미리보기 창이 없으면 보기 설정, 다운로드 문서에 경고가 뜨면 보안 정책을 먼저 확인하세요. 화면 증상에 맞춰 조치하는 편이 원본을 안전하게 지키면서 더 빠르게 원인을 찾는 방법입니다.
