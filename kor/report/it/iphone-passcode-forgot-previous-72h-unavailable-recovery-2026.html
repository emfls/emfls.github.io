아이폰 잠금화면에서 암호를 입력했는데 틀렸다는 안내가 계속 나옵니다. Face ID도 작동하지 않고 ‘iPhone을(를) 사용할 수 없음’ 또는 ‘보안상 잠김’이 표시된다면 무조건 초기화해야 할까요?

반드시 그런 것은 아닙니다. iOS 17 이상에서 최근 72시간 이내에 잠금화면 암호를 변경했다면 이전 암호를 이용한 재설정이 가능할 수 있습니다. 반면 오래전부터 사용하던 암호를 완전히 잊었다면, 일반적으로 기기를 지운 뒤 백업에서 복원하는 절차가 필요합니다. 두 경우를 혼동하면 불필요하게 사진이나 앱 데이터를 삭제할 수 있습니다.

이 글은 잠금화면 암호(기기 암호)를 잊었을 때의 공식 해결 절차입니다. Apple 계정 비밀번호, 스크린 타임 암호, SIM PIN은 서로 다른 것이므로 구분해야 합니다.

작성·검증 기준: 2026년 11월 5일. Apple 공식 한국어 지원 문서를 기준으로 정리했습니다. iOS 버전·기기 상태에 따라 표시되는 버튼이 다를 수 있으며, 실제 기기를 직접 잠그거나 초기화해 시험한 후기가 아닙니다.

1. 아이폰 암호 분실, 먼저 이 표에서 내 상황 찾기

현재 상황데이터 삭제 없는 방법다음으로 확인할 방법
최근 72시간 이내에 암호를 바꿈. 이전 암호 기억남이전 암호로 암호 재설정 기능 확인기능이 보이지 않으면 Apple 공식 재설정 조건 확인
암호 변경 후 72시간 지났거나 이전 암호도 모름일반적인 이전 암호 재설정 불가기기에서 재설정 또는 컴퓨터 복원
'암호를 잊어버렸습니까?' 버튼이 표시됨이전 암호 입력 선택지가 있는지 먼저 확인없거나 실패하면 기기 재설정 시작 안내 검토
'iPhone을(를) 사용할 수 없음'이라고 뜸상황에 따라 이전 암호 기능 확인Apple 계정과 인터넷 연결 조건 확인
화면에 재설정 버튼이 없고 암호도 전혀 모름통상적인 기기 내 재설정 불가Mac/Windows에서 복구 모드로 복원
복원 후 Apple 계정 로그인 화면이 나옴기기 암호와 별도기존 소유자의 Apple 계정 또는 정당한 소유권 확인
사진·메시지를 보존해야 함기기 지우기를 누르지 않기기존 iCloud/컴퓨터 백업·동기화 여부 확인

중요: 잠금 해제에 실패한 상태에서 암호를 무작정 반복 입력하지 마세요. Apple은 특정 설정에서 암호 입력 시도가 10회 실패하면 기기 데이터가 자동 삭제되도록 설정할 수 있다고 설명합니다.

2. '아이폰 잠금 암호'와 다른 비밀번호를 구분하세요

이름어디에 쓰는가잊었을 때의 처리
아이폰 잠금화면 암호재시동 후 또는 Face ID 실패 시 기기 잠금 해제최근 변경 시 이전 암호 재설정, 그 외 기기 복원 필요 가능
Apple 계정 암호iCloud, 기기 활성화, App Store, 기기 지우기 인증신뢰하는 기기 또는 iforgot.apple.com에서 재설정
스크린 타임 암호사용 시간 제한·자녀 보호 설정 변경Apple 계정 또는 가족 공유 관리 절차 확인

예시: iPhone 잠금화면을 열지 못하는데 Apple 계정 비밀번호를 알고 있다고 해서 잠금화면 암호를 즉시 대체 입력할 수 있는 것은 아닙니다. Apple 계정 인증은 기기 초기화·복원 과정에서 별도로 사용됩니다.

또 Face ID는 잠금화면 암호 자체를 대체하는 복구 수단이 아닙니다. 아이폰을 켜거나 재시동한 뒤 등 일부 상황에서는 다시 기기 암호가 필요합니다.

3. 72시간 이내라면: 이전 암호로 재설정하는 방법

가장 먼저 시도할 공식 방법입니다. iOS 17 이상에서 잠금화면 암호를 변경한 뒤 72시간 이내이고, 변경하기 전의 암호를 기억하고 있는 경우에 적용할 수 있습니다.

진행 순서

  1. 잠금 화면에서 암호를 잘못 입력해 ‘iPhone을(를) 사용할 수 없음’ 화면이 나타나면 하단을 확인합니다.
  2. ‘암호를 잊어버렸습니까?’를 탭합니다.
  3. ‘이전 암호 입력’ 또는 이전 암호를 이용하는 재설정 항목이 표시되는지 확인합니다.
  4. 직전에 사용했던 기기 잠금 암호를 입력합니다. Apple 계정 암호가 아닙니다.
  5. 안내에 따라 새 잠금화면 암호를 설정합니다.
  6. 정상적으로 홈 화면에 접근할 수 있는지 확인합니다.

이 방법은 기기를 지우지 않고 다시 접근하도록 설계된 Apple 공식 기능입니다.

버튼이 없는 경우

아래 조건을 확인합니다.

  • 기기가 iOS 17 이상인지
  • 기기 암호를 72시간 안에 변경한 상황이 맞는지
  • 이전 암호의 유효 기간을 이미 수동 만료시키지 않았는지
  • 기기가 잠겨 있고 셀룰러 또는 Wi-Fi에 연결되어 있는지
  • Apple 계정 로그인·나의 찾기 등 화면 표시 조건이 충족되는지

‘암호를 잊어버렸습니까?’가 보인다고 반드시 이전 암호 복구가 가능한 것은 아닙니다. 같은 화면에서 기기 자체를 재설정하는 선택지가 제공될 수 있습니다. 이전 암호 입력과 기기 재설정 시작을 혼동하지 마세요.

공식 근거: Apple — 새 암호를 잊은 경우 이전 암호 사용

4. 이전 암호가 72시간 이내인데도 안 되는 이유

'이전 암호 지금 만료시키기'를 사용한 경우

Apple은 변경 전 암호를 72시간이 지나기 전에 만료시키는 기능도 제공합니다. 사용자가 이 설정을 실행했다면 이전 암호를 이용한 재설정을 기대할 수 없습니다.

메뉴는 기기에 접근 가능한 상태에서 설정 → Face ID 및 암호(또는 Touch ID 및 암호) → 이전 암호 지금 만료시키기로 안내됩니다.

암호가 아니라 Apple 계정 비밀번호를 바꾼 경우

72시간 재설정 기능은 아이폰의 잠금화면 암호를 바꾼 상황에 대한 기능입니다. Apple 계정 로그인 암호를 변경했다는 이유만으로 적용되지 않습니다.

새 암호로 바꾼 지 오래된 경우

72시간이 지나면 이전 암호로 재설정할 수 있는 기간이 만료됩니다. 암호를 여러 개 연속 변경했다면 기억나는 과거 암호를 무작정 반복 시도하지 말고 공식 안내에서 지원되는 이전 암호 조건을 확인하세요.

공식 근거: Apple — 이전 암호 만료 시점 앞당기기

5. 'iPhone을 사용할 수 없음' 상태에서 컴퓨터 없이 재설정하기

이전 암호 재설정을 쓸 수 없다면, iOS 15.2 이상에서는 조건을 갖춘 기기에서 컴퓨터 없이 아이폰을 지우고 다시 설정할 수 있습니다.

실행 전에 반드시 알아둘 점: 이 과정은 암호만 바꾸는 기능이 아닙니다. 아이폰에 저장된 데이터와 설정을 삭제합니다. 사진·대화 내용이 현재 기기에만 있고 백업이나 동기화본이 없다면 복구할 수 없을 수 있습니다.

필요한 조건

  • iOS 15.2 이상(iOS 버전에 따라 화면 구성 다름)
  • 기기에 활성화되어 있던 '나의 찾기'
  • 사용 가능한 Wi-Fi 또는 셀룰러 연결
  • 기존 Apple 계정과 암호
  • 기기의 정당한 소유권과 필요한 인증 정보

iOS 17 이상 기본 절차

  1. 잠금 화면에서 ‘iPhone을(를) 사용할 수 없음’이 나타난 상태를 확인합니다.
  2. ‘암호를 잊어버렸습니까?’ 버튼이 제공되면 누릅니다.
  3. 이전 암호를 이용할 수 있는지 먼저 확인합니다.
  4. 이전 암호 방법을 사용할 수 없다면 ‘iPhone 재설정 시작’을 선택할 수 있습니다.
  5. 기존 Apple 계정 암호를 입력합니다.
  6. ‘iPhone 지우기’를 선택하면 모든 데이터와 설정이 삭제됩니다.
  7. iPhone이 재시동된 뒤 ‘안녕하세요’ 설정 화면에서 초기 설정을 진행합니다.
  8. 기존 백업이 있다면 해당 백업에서 데이터와 설정을 복원합니다.

eSIM을 쓰는 경우

Apple은 iOS 17 이상에서 eSIM을 사용하는 기기를 지울 때 eSIM을 유지하면서 데이터 지우기와 eSIM까지 삭제하고 데이터 지우기를 선택할 수 있다고 안내합니다. 회선 복구 방법을 확인하지 않은 상태에서 eSIM 삭제를 선택하지 마세요.

iOS 15.2~16에서는 화면에 ‘iPhone 지우기’라는 다른 버튼이 나타날 수 있습니다. 화면에 제공되는 옵션을 확인하되, 삭제 여부를 충분히 이해한 뒤 진행해야 합니다.

공식 근거: Apple — 컴퓨터 없이 암호 분실 iPhone 재설정

6. 버튼이 없거나 인터넷에 연결되지 않으면: 컴퓨터로 복구 모드 사용

기기 안에서 재설정하는 항목이 없거나 해당 조건을 충족하지 못한다면 Mac 또는 Windows PC에서 Apple 공식 절차로 기기를 복원할 수 있습니다.

주의: 복구 모드의 ‘복원’은 iPhone을 지웁니다. 데이터를 살리는 잠금 해제 도구가 아닙니다.

준비물

  • 인터넷 연결이 가능한 Mac 또는 Windows PC
  • 정상적인 USB 연결 케이블
  • 자신의 Apple 계정 정보
  • 복원 뒤 사용할 iCloud 또는 컴퓨터 백업이 있다면 해당 접근 정보

아이폰을 복구 모드로 전환하는 버튼

  1. 아이폰의 전원을 끕니다.
  2. 케이블의 한쪽을 컴퓨터에 연결합니다.
  3. 케이블의 다른 쪽을 아이폰에 연결하는 즉시 모델별 버튼을 누른 채 유지합니다.
  4. Apple 로고가 나타나도 버튼을 놓지 않습니다.
  5. 컴퓨터와 케이블 그림이 나타나면 복구 모드로 진입한 것입니다.
아이폰 모델케이블 연결 직후 계속 누를 버튼
Face ID 지원 모델측면 버튼
iPhone 8·8 Plus·SE 2세대·SE 3세대측면 버튼
iPhone 7·7 Plus음량 낮추기 버튼
iPhone 6s 및 이전·SE 1세대홈 버튼

모델 확인 주의: 아이폰 종류를 잘못 판단해 버튼을 임의로 반복 조작하지 말고 Apple 공식 모델별 절차를 확인하세요.

Mac에서 복원

  1. Mac의 Finder를 엽니다.
  2. 사이드바 위치에서 연결된 iPhone을 선택합니다.
  3. 복원 또는 업데이트 선택지가 나오면 ‘복원’을 선택합니다.
  4. 기기 지우기와 소프트웨어 설치가 완료될 때까지 공식 안내를 따릅니다.
  5. 기기 화면의 ‘안녕하세요’가 나오면 필요한 Apple 계정으로 활성화·설정을 진행합니다.

Windows PC에서 복원

  1. Microsoft Store에서 Apple이 제공하는 ‘Apple 기기’ 앱을 준비합니다.
  2. 복구 모드로 연결된 iPhone을 앱에서 선택합니다.
  3. 일반 → 복원을 선택하고 안내를 따릅니다.
  4. 초기 설정이 완료되면 백업 복원 가능 여부를 확인합니다.

오래 걸리는 경우: Apple은 다운로드가 15분 이상 걸리면서 복구 모드 화면이 종료될 수 있다고 설명합니다. 이때 다운로드가 완료된 뒤 기기를 끄고 복구 모드 진입을 다시 진행합니다.

7. 데이터는 없어지나요? 지우기 전에 확인할 핵심 사항

사용자가 가장 중요하게 확인할 부분은 '현재 저장된 데이터가 다른 곳에 남아 있는가'입니다.

데이터 종류복원 가능성을 판단하는 핵심
iCloud 사진을 동기화한 사진·동영상다른 기기나 iCloud에 정상적으로 동기화되어 있는지
iCloud 기기 백업 대상 데이터초기화 전에 만들어진 유효한 백업이 있는지
Mac/Windows 컴퓨터 백업해당 컴퓨터에 이전에 만든 백업 파일이 있는지
메신저 대화 기록앱 자체의 백업·복원 조건을 충족하는지
아이폰 내에만 저장한 파일별도 백업·동기화가 없으면 삭제될 수 있음
eSIM지우기 과정에서 유지/삭제 선택 여부와 통신사 정책

iCloud에 로그인했다는 사실만으로 모든 사진·문자·앱 데이터가 백업되었다는 뜻은 아닙니다. iCloud 사진 동기화와 iCloud 기기 백업도 같은 기능이 아닙니다.

가능하다면 다른 신뢰할 수 있는 기기나 컴퓨터에서 iCloud에 동기화된 자료·기존 백업 존재 여부를 확인하세요. 단, 분실한 잠금화면 암호를 우회해 데이터를 빼내는 방법이 보장되지는 않습니다.

실제 사례로 보는 차이

  • 사례 A: 어제 암호를 바꿨고 이전 암호를 기억함 → 72시간 기능이 가능하면 기기 삭제 없이 새 암호 설정 가능.
  • 사례 B: 오래전부터 쓰던 암호를 완전히 잊음, 최근 iCloud 백업 있음 → 공식 초기화 후 그 백업을 사용해 복원 가능성 있음.
  • 사례 C: 오래된 기기인데 백업·사진 동기화가 없고 암호도 모름 → 재설정 후 기기에만 있던 자료는 복구되지 않을 수 있음.

Apple의 복원 안내도 암호를 잊었을 때 기기 데이터가 지워지며, 기존 백업이 있다면 복원할 수 있다는 점을 명확히 설명합니다.

공식 근거: Apple — 컴퓨터 복원 시 데이터 삭제, Apple — 기기 재설정 후 백업 복원

8. 초기화 후 Apple 계정 암호가 기억나지 않거나 '활성화 잠금'이 나올 때

iPhone을 초기화했다고 해서 Apple 계정 인증까지 건너뛸 수 있는 것은 아닙니다. 기존에 나의 찾기 등을 사용했다면 재설정 후 활성화 잠금과 관련된 인증이 요구될 수 있습니다.

Apple 계정 암호를 모른다면

  1. 계정 이메일 주소 또는 전화번호를 확인합니다.
  2. 다른 신뢰하는 Apple 기기에 이미 로그인되어 있다면 해당 기기에서 Apple 계정 암호 변경이 가능한지 확인합니다.
  3. 신뢰하는 기기를 사용할 수 없다면 **iforgot.apple.com**을 이용해 공식 계정 복구 절차를 진행합니다.
  4. 계정 복구 대기 기간이 발생하면 Apple의 공식 안내를 따릅니다.

중고 아이폰이라면: 이전 소유자의 계정과 연결돼 있는 상태를 임의의 '우회 프로그램'으로 해결하려 하지 마세요. 정당한 구매 사실과 소유권을 확인하고 이전 소유자 또는 Apple 공식 지원 경로를 이용해야 합니다.

서로 다른 암호에 유의: iPhone 잠금화면 암호 6자리와 Apple 계정 로그인 비밀번호는 서로 다릅니다. 하나의 암호로 모든 단계를 해결할 수 있다고 가정하지 마세요.

공식 근거: Apple — Apple 계정 암호 분실, Apple — Apple 계정 암호 변경

9. '암호를 잊어버렸습니까?' 버튼이 안 보이는 경우

화면에 버튼이 없으면 꼭 고장이라고 볼 수는 없습니다. 다음을 순서대로 확인합니다.

  1. iOS 버전: 72시간 이전 암호 방식은 iOS 17 이상, 기기에서 직접 지우기 기능은 iOS 15.2 이상에서 지원됩니다.
  2. 네트워크 상태: Apple이 안내하는 기기 자체 재설정은 셀룰러 또는 Wi-Fi 연결이 필요합니다.
  3. 나의 찾기: 해당 기기에서 이전에 활성화됐는지 확인해야 합니다.
  4. Apple 계정: 기존에 기기에 로그인되어 있었고 필요한 계정 암호를 알아야 합니다.
  5. 회사·학교 관리형 기기: 조직의 기기 관리 정책이 있을 수 있으므로 담당자에게 문의합니다.
  6. 버튼만 없는 경우: 공식 문서의 Mac/Windows 복구 모드 절차를 검토합니다.

화면의 문구가 다르다고 비공식 잠금 해제 앱·유료 암호 우회 서비스를 먼저 사용하지 마세요. 암호 보호와 데이터 암호화를 우회한다고 주장하는 서비스의 성공·안전성을 이 글에서 보장하지 않습니다.

10. 많이 묻는 질문(FAQ)

Q1. 아이폰 암호를 5번 틀렸는데 바로 초기화해야 하나요?

아닙니다. 먼저 최근 72시간 이내에 암호를 변경했는지 확인하세요. 이전 암호를 기억하고 iOS 17 이상의 공식 재설정 조건을 충족한다면 기기를 지우지 않고 암호를 다시 설정할 수 있습니다.

Q2. 이전 암호도 모르고 백업도 없다면 사진을 살릴 수 있나요?

공식 재설정은 기기 데이터 삭제를 동반할 수 있습니다. 기기에만 저장된 사진은 복구되지 않을 수 있으며, 이미 다른 곳에 동기화된 사진이 있는지부터 확인해야 합니다.

Q3. Face ID가 되는데 암호를 몰라도 되나요?

그렇지 않습니다. 재시동 등 일부 상황에서는 Face ID 대신 기기 암호를 반드시 입력해야 합니다. Face ID만을 영구적인 암호 대체 수단으로 생각하지 마세요.

Q4. '암호를 잊어버렸습니까?' 버튼을 누르면 사진이 바로 삭제되나요?

버튼을 누르는 것 자체와 실제 기기 지우기를 확정하는 것은 다릅니다. 이어서 나타나는 항목에서 이전 암호로 재설정인지 기기 재설정·지우기인지 정확히 확인하세요. 마지막 삭제 동작을 승인하면 데이터가 지워집니다.

Q5. Windows 컴퓨터로도 아이폰 복원이 되나요?

네. Apple의 공식 Apple 기기 앱으로 복구 모드 상태의 iPhone을 복원할 수 있습니다. 다만 복원은 기기를 지우는 작업입니다.

Q6. 72시간이 지났는데 이전 암호를 입력하면 풀리나요?

Apple의 공식 이전 암호 재설정 기능은 기본적으로 암호 변경 후 72시간 이내에 사용할 수 있습니다. 기간이 지났다면 해당 방식으로 잠금 해제가 가능하다고 기대해서는 안 됩니다.

Q7. Apple ID 비밀번호를 바꾸면 아이폰 잠금화면 암호도 바뀌나요?

아닙니다. Apple 계정 비밀번호와 잠금화면 암호는 별개입니다. Apple 계정 비밀번호 재설정은 초기화·활성화 과정에서 필요할 수 있지만, 기기 잠금화면 암호 자체를 직접 지워주지는 않습니다.

Q8. eSIM을 쓰는 아이폰인데 초기화하면 전화번호가 사라지나요?

iOS 17 이상의 기기 재설정 화면에서는 eSIM 유지 또는 삭제 옵션이 제공될 수 있습니다. 통신사 회선 복구에 필요한 안내를 확인한 뒤 선택하세요. eSIM을 임의로 삭제하면 재발급이나 재활성화가 필요할 수 있습니다.

Q9. 중고로 산 아이폰이 '활성화 잠금' 상태인데 복구 모드로 지우면 해결되나요?

기기를 복원하는 것과 기존 Apple 계정의 활성화 잠금을 해제하는 것은 별개입니다. 정당한 소유권 증빙과 공식 절차를 확인해야 하며, 이전 소유자가 기기에 연결되어 있다면 판매자에게 해제 협조를 요청하세요.

Q10. 컴퓨터도 없고 화면에 재설정 버튼도 없으면 어떻게 하나요?

Apple은 컴퓨터를 사용하거나 빌릴 수 없을 때 Apple Store 또는 Apple 공인 서비스 제공업체에 도움을 요청하라고 안내합니다. 기기와 정당한 소유권 확인 자료를 준비하세요.

  • ☐ 최근 72시간 이내에 기기 암호를 변경했는지 확인했다.
  • ☐ 기억나는 이전 암호가 있다면 공식 이전 암호 재설정 방법을 먼저 검토했다.
  • ☐ '이전 암호 입력'과 '기기 재설정 시작'이 다른 기능이라는 점을 이해했다.
  • ☐ iCloud 사진 동기화 또는 기존 백업 유무를 확인했다.
  • ☐ Apple 계정 이메일·전화번호와 비밀번호를 확인했다.
  • ☐ eSIM을 사용한다면 유지·재발급 조건을 확인했다.
  • ☐ 데이터 삭제가 필요한 경우 지우기 전에 결과를 이해했다.
  • ☐ 비공식 암호 우회 프로그램이나 출처 불명 APK를 사용하지 않았다.
  • ☐ 정당한 소유권과 필요한 인증 수단을 준비했다.
