이 글은 2026년 11월 3일 기준 Microsoft의 Windows 복구 환경(WinRE), 복구 옵션, 시동 복구, 시스템 복원, PC 초기화, BitLocker 복구 키 공식 자료를 바탕으로, 데이터에 미치는 영향이 작은 조치부터 점검하는 순서를 정리했습니다. Windows 11의 에디션·버전, 제조사 복구 화면, 장치 암호화 여부에 따라 보이는 메뉴는 조금씩 다릅니다.

2. 복구하기 전에 절대 바로 하지 말아야 할 4가지

  1. '모든 항목 제거'를 누르지 않습니다. 이는 개인 파일·앱·설정을 지우는 초기화 옵션입니다.
  2. 인터넷에서 복사한 부트 영역 수정 명령어를 무작정 실행하지 않습니다. EFI·부트 구성은 PC별 구조가 다르고, 잘못 조작하면 상태가 악화될 수 있습니다.
  3. BitLocker 복구 키를 찾기도 전에 파티션을 삭제하거나 포맷하지 않습니다. 암호화된 데이터를 복구하기 어려워질 수 있습니다.
  4. 컴퓨터가 복구 작업 중일 때 강제로 여러 차례 끄지 않습니다. 복구 환경 진입을 위해 허용된 제한적 절차와, 진행 중인 복구 작업을 중단하는 것은 다릅니다.

Microsoft는 복구 옵션마다 개인 파일·앱·설정에 미치는 영향이 다르므로, 먼저 백업을 고려하고 가장 덜 파괴적인 방법부터 적용하도록 안내합니다.

3. 자동 복구 화면에서 '고급 옵션'으로 들어가기

이미 '자동 복구' 또는 'PC를 올바르게 시작하지 못했습니다' 화면이 떠 있다면 고급 옵션을 선택합니다. 일반적으로 문제 해결 → 고급 옵션으로 이동해 시동 복구·업데이트 제거·시스템 복원 등을 선택할 수 있습니다.

복구 화면 없이 재부팅만 계속되는 경우 Microsoft가 안내한 Windows 복구 환경 진입 방법을 사용할 수 있습니다.

  1. 전원을 켜고 Windows 부팅이 시작되는 시점을 확인합니다.
  2. Windows 로드가 완료되기 전에 전원 단추를 길게 눌러 종료합니다.
  3. 위 중단 절차를 총 두 번 수행합니다.
  4. 세 번째 시작 때 자동 복구 화면으로 들어가는지 확인합니다.
  5. 화면이 나타나면 고급 옵션을 선택합니다.

이 절차는 Windows 복구 환경이 열리지 않을 때 제한적으로 시도하는 방법입니다. BIOS 업데이트·펌웨어 설치·디스크 복구 중에는 수행하지 마세요. 이미 Windows가 복구 작업을 진행 중이라면 기다리는 편이 안전합니다.

Windows 화면이나 로그인 화면까지 진입할 수 있다면 Shift 키를 누른 채 전원 → 다시 시작을 선택하거나 설정 → 시스템 → 복구 → 고급 시작에서 들어갈 수 있습니다.

공식 근거: Microsoft — Windows 복구 환경 진입 방법

4. 첫 번째 시도: 시동 복구

**시동 복구(Startup Repair)**는 Windows가 시작되지 못하게 만드는 일부 일반적인 문제를 자동으로 진단하고 복구하는 기능입니다.

  1. 복구 환경의 문제 해결을 엽니다.
  2. 고급 옵션 → 시동 복구를 선택합니다.
  3. 표시되는 Windows 설치 또는 계정이 있다면 안내에 따라 선택합니다.
  4. 진단과 복구 결과가 나타날 때까지 기다립니다.
  5. 완료 후 정상 부팅되는지 확인합니다.

시동 복구는 모든 오류를 해결하는 만능 기능이 아닙니다. **'시동 복구로 PC를 복구하지 못했습니다'**라고 표시되면 같은 조치를 무작정 반복하기보다 아래의 변경 사항 되돌리기 절차로 넘어갑니다.

복구 과정에서 로그인 암호 또는 BitLocker 키를 요청할 수 있습니다.

공식 근거: Microsoft — Windows 복구 환경의 도구

5. 업데이트 후 시작된 오류: 최근 업데이트 제거

Windows 업데이트를 설치한 직후부터 부팅이 되지 않는다면 복구 환경 → 문제 해결 → 고급 옵션 → 업데이트 제거를 확인합니다.

화면에 따라 최신 품질 업데이트 제거와 최신 기능 업데이트 제거 등 선택지가 표시될 수 있습니다. 일반적인 월별 업데이트 직후 생긴 문제라면 우선 해당 업데이트 제거 항목을 검토합니다. 큰 버전 업그레이드 뒤에 문제가 생겼다면 기능 업데이트 되돌리기 가능 여부를 확인합니다.

주의할 점은 다음과 같습니다.

  • 업데이트를 제거할 수 없는 경우도 있습니다. 모든 업데이트가 복구 화면에서 제거되는 것은 아닙니다.
  • 중요한 보안 업데이트를 제거한 상태로 장기간 사용하면 취약해질 수 있습니다. 정상 부팅 후 최신 패치와 공식 알려진 문제를 확인해야 합니다.
  • 업데이트를 제거한 뒤 정상 부팅됐다면 업데이트 기록과 문제가 발생한 날짜를 기록해 두세요.
  • '업데이트 설치가 0%에서 멈춤'과 '업데이트 후 Windows가 부팅되지 않음'은 다른 문제입니다. 이 글은 후자를 다룹니다.

Microsoft는 최근 업데이트 뒤 시작된 문제에서 업데이트 제거를 복구 선택지로 안내합니다.

근거: Microsoft — Windows 복구 옵션: PC가 시작되지 않을 때

6. 최근 드라이버·프로그램을 설치했다면: 시스템 복원

시스템 복원은 PC 상태를 이전 복원 지점의 시스템 파일·설정으로 되돌리는 기능입니다. 최근 설치한 앱이나 드라이버, 업데이트의 영향으로 부팅이 실패했다면 검토할 수 있습니다.

  1. 복구 환경에서 문제 해결 → 고급 옵션 → 시스템 복원을 찾습니다.
  2. 복원 지점이 존재하는지 확인합니다.
  3. 오류가 발생하기 이전 날짜의 복원 지점을 선택합니다.
  4. 영향을 받는 프로그램을 확인할 수 있다면 목록을 확인합니다.
  5. 복원 과정을 시작하고 결과를 확인합니다.

Microsoft는 시스템 복원으로 개인 파일은 유지되지만 복원 지점 이후 설치한 앱, 드라이버 및 시스템 설정이 영향을 받을 수 있다고 안내합니다. 복원 지점이 없다면 이 방법을 사용할 수 없습니다.

최신 Windows 11 일부 버전에서는 특정 시점 복원이라는 별도 기능도 제공할 수 있습니다. 이는 시스템 복원과 복원 대상·데이터 영향이 다를 수 있으므로, 화면에 제시된 유지·변경 범위를 반드시 확인하고 선택하세요.

근거: Microsoft — 시스템 복원

7. 안전 모드로 들어갈 수 있으면 해야 할 일

Windows 복구 환경에서 문제 해결 → 고급 옵션 → 시작 설정 → 다시 시작으로 이동하면 시작 옵션이 표시될 수 있습니다. 일반적으로 4 또는 F4는 안전 모드, 5 또는 F5는 네트워킹을 사용하는 안전 모드입니다. 제조사와 입력 환경에 따라 실제 안내되는 번호를 확인합니다.

안전 모드 진입에 성공했다면 바로 초기화하지 말고 다음 항목을 살펴보세요.

  • 오류 시작 직전에 설치한 프로그램 또는 드라이버가 있는가?
  • 장치 관리자에 경고 표시가 생긴 장치가 있는가?
  • 최근 업데이트 기록에 문제가 시작된 날짜와 일치하는 항목이 있는가?
  • 바탕화면·문서 등 중요한 파일을 외부 저장장치로 백업할 수 있는가?

안전 모드에서 최근 설치한 문제가 의심되는 프로그램을 제거하거나, 이전에 정상 작동하던 드라이버로 되돌리는 방법을 검토할 수 있습니다. 원인이 확인되지 않은 장치 드라이버를 무작정 다 지우지 마세요.

안전 모드로도 진입할 수 없다면 아래의 BitLocker·복구 미디어 단계로 넘어갑니다.

8. BitLocker 복구 키 48자리를 요구한다면

윈도우 복구 화면에서 BitLocker 복구 키를 요청하는 것은 별도의 중요한 분기입니다. 키는 일반적인 로그인 암호나 PIN과 다릅니다. Microsoft에 따르면 복구 키는 48자리 숫자이며, 부팅 변경이나 보안 관련 문제로 요청될 수 있습니다.

개인 Microsoft 계정이라면

  1. 다른 스마트폰이나 PC에서 https://aka.ms/myrecoverykey에 접속합니다.
  2. 해당 PC를 설정할 때 사용했던 Microsoft 계정으로 로그인합니다.
  3. 복구 화면의 키 ID 앞 8자리와 계정에 저장된 키 ID를 대조합니다.
  4. 일치하는 48자리 복구 키가 있다면 화면 지침대로 입력합니다.

회사·학교 PC라면

기관의 IT 관리자 또는 회사·학교 계정의 복구 키 보관 위치를 확인해야 합니다. 본인이 관리하지 않는 장치의 보안 설정을 임의로 바꾸지 마세요.

키를 찾을 수 없을 때는 인쇄물이나 별도로 보관된 USB 등 이전에 백업한 위치도 확인합니다. Microsoft는 분실한 복구 키를 대신 찾아주거나 재생성할 수 없다고 명시합니다. 특히 중요한 파일이 있다면 키를 찾지 못한 상태에서 초기화부터 진행하면 안 됩니다.

공식 출처: Microsoft — BitLocker 복구 키 찾기

9. 복구 화면 자체가 안 열릴 때: 설치 USB 사용

복구 환경에 진입할 수 없는 경우에는 정상적으로 작동하는 다른 PC에서 Microsoft 공식 Windows 설치 미디어를 만들어 복구 환경을 실행하는 방법이 있습니다.

  1. 정상 PC에서 Microsoft 공식 Windows 설치 미디어 안내를 확인합니다.
  2. 안내에 따라 부팅 가능한 USB를 만듭니다. USB에 중요한 파일이 있다면 미리 별도 백업합니다.
  3. 문제가 있는 PC를 끄고 USB를 연결합니다.
  4. 제조사별 부팅 메뉴를 이용해 해당 USB로 시작합니다.
  5. Windows 설치 화면에서 설치를 즉시 진행하지 말고 '내 PC 복구' 항목을 찾습니다.
  6. Windows 복구 환경으로 진입해 시동 복구·업데이트 제거 등을 검토합니다.

복구 USB로 부팅하는 것 자체와 드라이브를 포맷해 Windows를 새로 설치하는 것은 전혀 다릅니다. 설치 대상 드라이브·파티션 선택 화면에서 실수로 기존 데이터를 삭제하지 않도록 주의하세요.

공식 안내: Microsoft — Windows 복구 환경: 설치 미디어 사용

10. '내 파일 유지' 초기화는 정말 파일이 안전할까?

Windows 복구 기능의 이 PC 초기화에는 대표적으로 두 가지 선택지가 있습니다.

항목내 파일 유지모든 항목 제거
Windows 다시 설치예예
개인 파일유지하도록 설계제거
설치한 앱제거됨제거됨
Windows 설정초기화됨초기화됨
데이터 백업 필요성필수적으로 권장특히 중요

'내 파일 유지'는 백업과 동일하지 않습니다. Microsoft는 초기화를 시작하기 전에 중요한 파일을 백업하고 BitLocker 키를 확인하라고 권고합니다. 저장장치 자체에 문제가 있거나 예상하지 못한 오류가 발생한다면 원하는 결과를 보장할 수 없기 때문입니다.

중요한 업무 문서·사진이 남아 있다면 가능한 한 먼저 파일을 확보하고, 시동 복구·업데이트 제거·시스템 복원과 같은 방법을 검토한 뒤 마지막 단계로 초기화를 판단하세요.

11. 복구를 중단하고 수리·진단을 받아야 하는 신호

소프트웨어 복구로 해결되지 않는 모든 문제가 Windows 손상 때문인 것은 아닙니다.

  • BIOS/UEFI에서 저장장치가 아예 보이지 않는 경우
  • SSD/HDD의 이상 소음 또는 반복적인 장치 인식 실패
  • 갑작스러운 전원 차단, 충전 불량, 과열이 반복되는 경우
  • 복구 도구가 계속 실패하고 저장장치 관련 오류가 나타나는 경우
  • 암호화된 드라이브의 키를 찾지 못했으며 데이터가 중요한 경우
  • 업무용·학교용 관리 PC에서 관리자 권한이나 보안 설정이 필요한 경우

이때는 기기 제조사의 하드웨어 진단 또는 전문 수리 상담을 먼저 검토합니다. 데이터 보존이 최우선이라면 수리 의뢰 전에 포맷·공장초기화·저장장치 교체에 동의하지 않는다는 의사를 명확히 전달하는 것이 좋습니다.

12. 자주 묻는 질문

Q. 자동 복구 무한반복이면 무조건 윈도우를 다시 설치해야 하나요?

아닙니다. Microsoft가 제공하는 시동 복구, 업데이트 제거, 시스템 복원 같은 옵션을 먼저 검토할 수 있습니다. 원인에 따라 복구 가능 여부가 다릅니다.

Q. 'PC를 올바르게 시작하지 못했습니다'가 뜨면 파일이 삭제된 건가요?

그 메시지 자체가 파일 삭제를 의미하지는 않습니다. 다만 실제 파일 손상 여부는 별도로 확인해야 하므로 중요한 자료가 있다면 백업을 우선 고려하세요.

Q. 안전 모드만 켜져도 고칠 수 있나요?

최근 드라이버나 프로그램 문제라면 원인을 확인하고 수정할 기회가 있습니다. 그러나 하드웨어 고장이나 심각한 시스템 손상은 안전 모드만으로 해결되지 않을 수 있습니다.

Q. BitLocker 복구 키는 Microsoft가 알려주나요?

Microsoft 지원에서 분실된 키를 임의로 제공하거나 재생성해 주지는 않습니다. 연결된 Microsoft 계정·회사 계정·인쇄물 등 기존 백업 위치를 확인해야 합니다.

Q. 자동 복구를 계속 실행하면 언젠가 성공할까요?

동일한 실패 화면을 반복한다면 같은 작업을 무제한 반복하는 것보다 실패 결과를 기록하고 다음 복구 방법으로 넘어가는 편이 합리적입니다.

Q. 부팅이 되면 바로 무엇을 해야 하나요?

중요한 개인 파일을 백업한 뒤 설정 → 시스템 → 복구, Windows 업데이트 기록, 장치 관리자, 저장장치 상태를 점검하고 같은 문제가 재발하는지 확인합니다.

13. 데이터 손실 위험을 줄이는 최종 체크리스트

  • ☐ 현재 화면을 촬영하고 정확한 오류 메시지를 기록했다.
  • ☐ 복구 작업 중인 PC를 무작정 강제 종료하지 않았다.
  • ☐ 필요하지 않은 USB 등 외부 장치를 분리해 봤다.
  • ☐ Windows 복구 환경의 고급 옵션에 진입했다.
  • ☐ 시동 복구를 먼저 검토했다.
  • ☐ 최근 업데이트 후 발생한 문제라면 업데이트 제거를 검토했다.
  • ☐ 이전 시스템 복원 지점이 있는지 확인했다.
  • ☐ BitLocker 화면이 뜨면 키 ID를 적고 공식 경로에서 복구 키를 찾았다.
  • ☐ 중요한 파일 백업 전에는 모든 항목 제거·포맷·재설치를 실행하지 않았다.
  • ☐ 저장장치 이상 징후가 있으면 데이터 보존을 우선했다.

핵심 정리: 자동 복구 무한반복은 곧바로 초기화할 이유가 아닙니다. 화면 상태를 확인한 다음 WinRE 진입 → 시동 복구 → 업데이트 제거·시스템 복원 → 안전 모드·복구 미디어 → 초기화 여부 판단 순서로 접근하세요.
