모니터에 뜬 오류 메시지, 온라인 강의 영상의 자막, 거래처가 보낸 사진 속 주소를 복사하려고 마우스로 드래그했는데 아무것도 선택되지 않는 경우가 있습니다. 화면에는 분명 글자가 보이는데 일반적인 복사 기능으로는 텍스트가 잡히지 않는 것입니다. 이때 반드시 글자를 손으로 다시 입력할 필요는 없습니다. Windows 11의 캡처 도구, Microsoft PowerToys의 Text Extractor, Mac 사진 앱의 라이브 텍스트를 이용하면 이미지에 들어 있는 글자를 인식해 복사할 수 있습니다.

그러나 글자 복사에 성공했다는 사실과 원본 내용이 정확하게 보존됐다는 사실은 다릅니다. 숫자 0과 알파벳 O, 숫자 1과 소문자 l, 하이픈과 긴 대시, 한글의 비슷한 글자는 OCR 과정에서 잘못 읽힐 수 있습니다. 주문번호나 입금 계좌, 제품 모델명처럼 한 글자만 달라도 문제가 되는 자료라면 반드시 대조해야 합니다.

이 글은 2026년 11월 1일 기준 Microsoft와 Apple의 공식 사용 설명서를 바탕으로 작성했습니다. 무료 또는 운영체제에 포함된 기능을 먼저 활용하고, 실제 업무에서 확인해야 할 '글자·숫자·문단 구조' 검수법까지 정리합니다. 앱 버전, 운영체제, 설치된 언어, 기기 지원 여부에 따라 화면에 표시되는 메뉴가 다를 수 있습니다.

1. 먼저 확인: OCR이 필요한 상황인지부터 구분하기

OCR(Optical Character Recognition)은 이미지에 있는 글자 모양을 인식해 텍스트로 바꾸는 기술입니다. 그러나 모든 복사 문제에 OCR이 필요한 것은 아닙니다.

핵심은 선택 가능한 텍스트와 이미지로 보이는 문자를 구별하는 것입니다. 일반 웹페이지의 본문이라면 OCR을 거치지 않는 일반 복사가 더 간단하고, 이미지로 저장된 글자라면 OCR을 고려할 수 있습니다.

이 글의 중심은 스크린샷·사진·영상 화면에 보이는 글자입니다. 별도의 PDF 스캔본 편집이나 암호화된 문서의 복사 제한 해제는 같은 문제로 취급하지 않습니다.

공식 자료: Microsoft — 캡처 도구, Microsoft — PowerToys Text Extractor

2. 설치 없이 시작하기: Windows 11 캡처 도구 OCR

Windows 11에서 먼저 확인할 방법은 기본 캡처 도구(Snipping Tool)입니다. Microsoft는 캡처 도구의 텍스트 작업(Text actions)을 이용해 캡처한 이미지에서 원하는 글자나 모든 글자를 복사할 수 있다고 설명합니다.

진행 순서:

  1. 글자를 복사하려는 화면을 엽니다.
  2. 키보드에서 Windows 키 + Shift + S를 누릅니다.
  3. 화면이 어두워지면 필요한 글자 영역을 마우스로 드래그해 선택합니다.
  4. 캡처 도구에서 캡처 화면을 열어 결과를 확인합니다. 알림 또는 앱 창 표시 방식은 Windows 설정에 따라 다를 수 있습니다.
  5. 도구 모음에서 텍스트 작업을 선택합니다.
  6. 원하는 일부 글자만 선택해 복사하거나 모든 텍스트 복사를 선택합니다.
  7. 메모장이나 문서에 붙여 넣고 인식된 결과를 확인합니다.

지원되는 캡처 도구 버전에서는 이메일 주소나 전화번호를 가리는 빠른 수정(Quick redact) 기능도 제공됩니다. 하지만 이 기능으로 가릴 수 있는 정보가 모든 개인정보를 포함한다는 뜻은 아닙니다. 이미지 공유가 목적이라면 민감한 내용이 남지 않았는지 직접 확인해야 합니다.

Microsoft는 캡처 도구의 텍스트 인식 처리가 장치 내부에서 로컬로 수행된다고 안내합니다. 따라서 글자 인식을 위해 반드시 외부 OCR 웹사이트에 사진을 업로드할 이유는 없습니다. 다만 이후 사용자가 공유·클라우드 저장·다른 앱에 붙여 넣기를 하는 행위는 별도의 문제입니다.

공식 자료: Microsoft — 캡처 도구로 스크린샷 캡처, 텍스트 작업과 로컬 처리

3. 텍스트 작업 버튼이 보이지 않을 때

화면을 캡처했는데 텍스트 작업 아이콘을 찾을 수 없다면 기능이 고장 났다고 단정하지 마세요. 아래 항목부터 확인합니다.

  1. 현재 PC가 Windows 11인지 확인합니다.
  2. 캡처한 이미지가 클립보드에만 남아 있는지, 캡처 도구 편집 창이 실제로 열렸는지 확인합니다.
  3. 시작 메뉴에서 캡처 도구를 검색해 앱을 실행합니다.
  4. Microsoft Store에서 캡처 도구의 업데이트가 있는지 확인합니다.
  5. 회사·학교 PC라면 관리 정책 때문에 앱 업데이트나 설치가 제한됐는지 확인합니다.
  6. 그래도 해당 기능이 없다면 PowerToys의 Text Extractor처럼 별도 도구 사용 가능 여부를 검토합니다.

일부 인터넷 설명에는 텍스트 작업과 Copilot+ PC 전용 기능을 하나로 묶어 설명하는 경우가 있습니다. 그러나 Microsoft의 캡처 도구 설명은 여러 기능을 구분해 안내합니다. 특정 버튼이 없다는 이유로 PC를 새로 구매해야 한다고 결론 내리지 마세요. 먼저 Windows 및 캡처 도구 버전을 확인하는 편이 합리적입니다.

공식 자료: Microsoft — 캡처 도구 기능 및 단축키

4. PowerToys Text Extractor: 화면 아무 곳에서나 빠르게 복사

화면 일부를 선택하고 곧바로 글자만 복사하는 작업이 잦다면 Microsoft PowerToys의 Text Extractor도 선택지입니다.

Microsoft 공식 안내에 따르면 PowerToys Text Extractor는 이미지나 영상에 나타난 글자를 포함해 Windows 화면의 텍스트를 OCR로 인식할 수 있습니다. 기본 활성화 단축키는 Windows 키 + Shift + T입니다.

사용 순서:

  1. Microsoft PowerToys가 설치돼 있는지 확인합니다.
  2. PowerToys 설정에서 Text Extractor가 활성화됐는지 살펴봅니다.
  3. 글자가 보이는 앱이나 영상을 화면에 표시합니다.
  4. Windows 키 + Shift + T를 누릅니다.
  5. 화면에 나타난 선택 오버레이에서 글자가 있는 영역을 드래그합니다.
  6. 마우스를 놓으면 인식된 텍스트가 클립보드에 복사됩니다.
  7. 메모장에 Ctrl + V로 붙여 넣고 결과를 검토합니다.

캡처 모드에서 취소하려면 Esc를 누를 수 있습니다. Microsoft는 Text Extractor를 설명하면서 화면 캡처를 목적으로 한다면 캡처 도구 사용을 권장하기도 합니다. 즉 화면 캡처와 편집은 캡처 도구, 반복적인 화면 영역의 글자 추출은 Text Extractor가 편리할 수 있습니다.

이 도구는 별도로 설치해야 하므로 설치가 불가능한 관리형 PC에서는 사용할 수 없는 경우도 있습니다.

공식 자료: Microsoft Learn — PowerToys Text Extractor 사용법

5. PowerToys를 안전하게 설치하는 방법

Microsoft는 PowerToys를 Microsoft Store, 공식 GitHub 릴리스, WinGet 등의 방법으로 설치할 수 있다고 안내합니다. 유사한 이름의 비공식 다운로드 사이트를 찾아 설치할 필요는 없습니다.

일반 사용자라면 Microsoft Store에서 PowerToys 검색 → 게시자 및 앱 확인 → 설치 순서를 우선 고려할 수 있습니다.

Windows 패키지 관리자를 사용하는 경우 Microsoft가 안내하는 명령은 다음과 같습니다.

  • 명령: winget install --id Microsoft.PowerToys --source winget
  • 실행 환경: Windows 터미널 또는 PowerShell 등 WinGet이 사용 가능한 환경
  • 설치 후: PowerToys 설정에서 Text Extractor 활성화 여부 확인

Microsoft가 안내하는 최소 지원 범위는 Windows 11 또는 Windows 10 버전 2004 이상, 64비트 x64·ARM64 시스템입니다. 실제 기기의 설치 가능 여부는 관리 정책과 관련 구성 요소 상태에 따라 달라집니다.

설치와 실행이 완료됐다면 공식 앱 안에서 다른 도구들도 보일 수 있지만, 이 글의 목적을 위해 모든 PowerToys 기능을 켤 필요는 없습니다.

공식 자료: Microsoft Learn — PowerToys 설치 안내

6. PowerToys에서 한글이 제대로 인식되지 않을 때

Text Extractor가 실행되더라도 한글 인식 결과가 이상하거나 특정 언어가 표시되지 않을 수 있습니다. Microsoft는 이 도구가 Windows에 설치된 OCR 언어 팩을 사용한다고 설명합니다.

진단 순서:

  1. PowerToys 설정에서 Text Extractor의 선호 언어(Preferred language)를 확인합니다.
  2. 선택하려는 언어가 목록에 있는지 살펴봅니다.
  3. Windows에 해당 OCR 언어 리소스가 설치돼 있는지 확인합니다.
  4. 한글·영문이 섞인 이미지를 먼저 한 줄만 테스트합니다.
  5. 글자와 배경의 대비가 높은 이미지로 다시 시도합니다.
  6. 누락이 반복되는 글자는 원본을 보며 직접 수정합니다.

OCR 언어 목록에 없으면 이미지 확대만으로 모든 문제가 해결되는 것은 아닙니다. Microsoft는 Text Extractor가 설치된 OCR 언어 팩이 있는 언어만 인식할 수 있다고 명시합니다.

영문은 읽히는데 한글만 유독 틀린다면 글자 크기뿐 아니라 언어 설정과 OCR 팩도 확인해 볼 이유가 있습니다. 반면 특정 특수기호나 작은 글자가 틀리는 것은 언어 팩만으로 해결되지 않을 수 있습니다.

공식 자료: Microsoft Learn — Text Extractor 지원 언어 및 OCR 팩

7. Mac에서는 사진 앱 라이브 텍스트 이용하기

Mac 사용자라면 Apple의 라이브 텍스트(Live Text) 기능을 확인하세요. Apple은 지원되는 Mac의 사진 앱에서 이미지 속 문자를 복사하거나 검색·번역 등의 동작에 이용할 수 있다고 안내합니다.

사진 앱에서 수행하는 순서는 다음과 같습니다.

  1. Mac에서 사진(Photos) 앱을 엽니다.
  2. 텍스트가 포함된 사진을 선택해 엽니다.
  3. 포인터를 이미지 속 글자 위에 놓습니다.
  4. 글자를 선택한 다음 Control-클릭 → 텍스트 복사를 이용합니다. 지원되는 경우 Command + C로 복사할 수도 있습니다.
  5. 메모장 역할을 하는 텍스트 편집기나 문서 앱에 붙여 넣습니다.
  6. 원본 사진을 보면서 띄어쓰기와 숫자, 특수기호를 확인합니다.

Apple은 선택된 내용에 따라 단어 찾기, 번역, 웹 검색, 전화번호 사용과 같은 동작이 제공될 수 있다고 설명합니다. 기능과 언어는 국가·지역 및 소프트웨어 지원 상태에 따라 달라질 수 있습니다.

이 글은 Mac 사진 앱에서의 공식 지원 경로를 기준으로 합니다. 모든 이미지 뷰어·웹브라우저·Mac 모델에서 동일한 메뉴가 보인다고 단정하지 않습니다.

공식 자료: Apple 지원 — Mac에서 라이브 텍스트로 사진 속 텍스트 사용하기

9. 오류 메시지를 복사할 때는 무엇이 좋은가요?

업무 중 자주 접하는 상황을 예로 들어 보겠습니다. 프로그램 실행 중 창에 오류 메시지가 나타났는데 선택이나 복사가 되지 않습니다.

이런 경우에는 오류 코드와 메시지 전체를 함께 보존하는 것이 좋습니다.

  1. 전체 오류 창을 먼저 스크린샷으로 남깁니다.
  2. Windows 캡처 도구의 텍스트 작업이나 PowerToys로 글자를 추출합니다.
  3. 오류 코드가 원본에서 보이는 그대로인지 대조합니다.
  4. 프로그램 이름, 오류 발생 시각, 조작 순서를 별도로 기록합니다.
  5. 문의나 검색에 사용할 때 개인정보·계정 토큰 등이 들어 있지 않은지 확인합니다.

예를 들어 코드의 숫자 0과 영어 대문자 O는 OCR에서 혼동될 수 있습니다. 에러 코드 한 글자만 틀리면 검색 결과나 기술지원 안내가 완전히 다른 문제를 가리킬 수 있습니다.

또한 일회성 오류 메시지만으로 해결 원인을 단정하기보다, 프로그램 버전과 발생 조건을 함께 제시해야 정확한 문제 해결에 도움이 됩니다.

10. 온라인 강의나 영상의 글자 추출은 어떻게 할까?

영상에 나오는 슬라이드, 표, 코드, 자막은 일반적인 텍스트 선택이 불가능할 수 있습니다. Microsoft는 PowerToys Text Extractor가 영상 안에 보이는 텍스트도 화면에서 읽을 수 있다고 안내합니다.

방법은 다음과 같습니다.

  1. 강의 영상을 필요한 장면에서 일시 정지합니다.
  2. 인식할 글자가 충분히 크게 보이도록 영상 창의 크기나 재생 품질을 조정합니다.
  3. 캡처 도구 또는 Text Extractor로 해당 부분을 선택합니다.
  4. 텍스트를 붙여 넣고 줄바꿈과 기호를 확인합니다.
  5. 코드라면 영문 대소문자, 밑줄, 괄호, 따옴표를 반드시 재검토합니다.

OCR은 화면에 실제로 나타난 문자만 인식하는 도구입니다. 화면에 보이지 않는 영상 대본이나 생략된 내용을 알아내는 기능은 아닙니다. 강의에 공식 자막·대본 다운로드 기능이 있다면 그것이 더 적합할 수 있습니다.

유료 강의나 저작권 보호 자료는 본인의 학습·접근 목적으로 이용하더라도 복제·배포 규정을 따로 확인해야 합니다. 추출된 텍스트를 허가 없이 공개하거나 대량 재게시하는 것은 피하세요.

사람의 눈에는 비슷하게 보이지만 컴퓨터에서는 다른 문자들이 있습니다. OCR 결과가 겉으로 자연스러워도 특정 업무에선 치명적인 차이가 될 수 있습니다.

계좌번호·주민등록번호·인증 코드 등 민감한 정보는 별도 보안 정책과 원본 확인 방법을 적용하세요. 특히 송금이나 계약처럼 결과가 중대한 작업에는 OCR 결과만 믿고 실행하지 않는 편이 좋습니다.

12. 원고에서 제안하는 '3층 검수법'

문서가 길어질수록 OCR 결과를 처음부터 끝까지 모두 육안으로 대조하기 어렵습니다. 실수 가능성이 높은 지점을 우선 검수하도록 아래와 같은 방법을 제안합니다.

1층 — 글자 검수

한글 이름, 회사명, 영어 제품명, 숫자, 특수문자가 원본과 같은지 확인합니다. 업무상 중요한 값은 원본을 확대해 한 글자씩 대조합니다.

2층 — 숫자 검수

금액·날짜·전화번호·주문번호·모델번호처럼 의미가 바뀌기 쉬운 항목을 따로 확인합니다. 특정 코드를 다른 시스템에 입력해야 한다면 복사한 값의 길이와 구분 기호도 함께 점검합니다.

3층 — 구조 검수

줄바꿈, 표의 열 구분, 목록 번호, 제목과 본문 사이의 관계가 유지됐는지 확인합니다. OCR은 표 이미지를 그대로 구조화된 스프레드시트로 변환한다는 보장이 없습니다.

이 3층 검수법은 공식 도구가 제공하는 별도 인증 기능이 아니라 글쓴이가 제안하는 실용적인 품질 검토 방법입니다. 표나 계약서처럼 형식까지 중요한 자료를 다룰 때 인식된 문장을 그대로 복사해 사용하는 것보다 안전하게 판단할 수 있도록 돕습니다.

13. 개인정보가 있는 이미지는 어떻게 다뤄야 할까?

업무상 문서에는 고객 이름, 주소, 전화번호, 이메일, 사내 계정 정보 등이 포함될 수 있습니다. OCR 도구를 선택할 때는 기능뿐 아니라 데이터가 어디에서 처리되는지도 고려하세요.

Microsoft는 캡처 도구의 텍스트 작업 인식 자체가 장치에서 로컬로 실행된다고 명시합니다. 이는 OCR을 위해 외부 웹사이트에 이미지를 업로드하지 않고 작업할 수 있다는 점에서 유용합니다.

그렇다고 작업 전체가 자동으로 안전해지는 것은 아닙니다. OCR 결과를 회사 공용 채팅에 붙여 넣거나, 캡처한 이미지를 클라우드 동기화 폴더에 저장하거나, AI 사이트에 전송한다면 정보 노출 범위가 달라집니다.

따라서 다음을 권장합니다.

  • OCR을 실행하기 전에 불필요한 개인정보가 화면에 포함되지 않았는지 확인합니다.
  • 가능한 한 필요한 부분만 영역을 선택합니다.
  • 텍스트를 복사한 뒤 다른 앱에 붙여 넣기 전에 내용을 확인합니다.
  • 스크린샷을 공유할 때는 식별 가능한 개인 정보가 남아 있지 않은지 다시 점검합니다.
  • 공용 PC나 조직에서 관리하는 PC에서는 저장·클립보드·화면 캡처 관련 정책을 따릅니다.

Microsoft의 빠른 수정 기능은 이메일 주소와 전화번호를 식별해 가릴 수 있는 기능이지만, 모든 민감정보를 자동으로 탐지하고 안전하게 삭제하는 완전한 개인정보 보호 장치가 아닙니다.

14. 텍스트가 틀리거나 순서가 섞일 때 개선 순서

OCR 품질은 원본 이미지 상태에 크게 영향을 받습니다. 작은 글자, 흐릿한 사진, 낮은 대비, 기울어진 이미지, 여러 열로 배치된 표는 인식 결과에 영향을 줄 수 있습니다.

다음은 특정 인식률을 보장하는 공식 수치가 아니라, 오인식 여부를 점검하기 위한 실무 절차입니다.

  1. 텍스트 영역을 필요 이상으로 넓게 캡처하지 않습니다.
  2. 작은 글자는 화면 확대 후 다시 시도합니다.
  3. 흐리거나 흔들린 사진이라면 원본보다 선명한 사진이 있는지 확인합니다.
  4. 한글만 틀린다면 PowerToys의 언어 팩과 선호 언어를 살펴봅니다.
  5. 표는 한꺼번에 인식한 뒤 열 순서를 믿지 말고 행별로 비교합니다.
  6. 글자 사이 띄어쓰기와 줄바꿈이 임의로 바뀌었는지 확인합니다.
  7. 중요한 데이터는 원본 이미지와 한 글자씩 대조합니다.

이미지 해상도를 무작정 올리거나 인식 도구를 여러 번 실행하는 것만으로 정답이 보장되지는 않습니다. 처음부터 원본이 식별하기 어려운 글자라면 같은 오류가 반복될 수 있습니다.

15. 도구를 선택할 때 자주 하는 실수

실수 1. 스크린샷만 찍으면 자동으로 텍스트가 복사된다고 생각

Windows 키 + Shift + S는 기본적으로 화면을 캡처하는 동작입니다. 캡처된 화면에서 글자를 복사하려면 지원되는 캡처 도구의 텍스트 작업을 사용해야 합니다. PowerToys의 Windows 키 + Shift + T는 별도 설치 및 기능 활성화가 필요합니다.

실수 2. OCR이 표를 완벽하게 복원한다고 생각

OCR의 주된 역할은 글자를 인식하는 것입니다. 표의 셀 병합·열 구조·주석·서식까지 그대로 복원되는 것은 아닙니다. 표를 정리하려면 별도의 구조 확인이 필요합니다.

실수 3. 원본이 틀리게 인식됐는데 자동 번역 결과까지 신뢰

OCR에서 단어가 잘못 읽힌 뒤 번역을 진행하면 오역이 추가될 수 있습니다. 번역 전에 인식된 원문을 검토하세요.

실수 4. 보안에 민감한 이미지를 아무 OCR 웹사이트에 업로드

OCR이 필요하더라도 반드시 외부 서비스에 업로드해야 하는 것은 아닙니다. 로컬에서 동작하는 지원 기능이 있는지 먼저 확인하고 조직의 정보 보호 규칙을 따르세요.

실수 5. 복사한 숫자를 검증 없이 송금·결제·계약 업무에 사용

오인식은 보기 좋은 문장을 만들 수도 있습니다. 실제 거래에 영향을 주는 숫자는 공식 문서나 원본 시스템과 다시 비교해야 합니다.

16. 상황별 실전 활용 예시

사례 A. 오류 창에 뜬 영어 문장을 고객센터에 전달하기

오류 화면을 캡처하고 텍스트 작업으로 문구를 복사합니다. 오류 코드, 애플리케이션 이름, 발생 시각을 원본과 대조합니다. 개인정보가 없음을 확인한 뒤 공식 고객센터의 문의 양식에 입력합니다.

사례 B. 유튜브 강의에서 화면에 표시된 명령어 옮기기

영상을 일시 정지하고 Text Extractor로 복사합니다. 영문 대소문자, 특수문자, 괄호, 공백을 대조한 다음 실제 사용합니다. 화면 밖에 있는 코드나 설명이 자동으로 추출되는 것은 아닙니다.

사례 C. Mac에서 사진 속 전화번호를 메모하기

지원되는 Mac 사진 앱에서 사진을 열고 라이브 텍스트로 번호를 선택합니다. 전화번호를 이용하는 기능이 표시될 수도 있지만, 실제로 걸기 전에 번호를 원본과 비교하는 것이 좋습니다.

사례 D. 거래처가 보낸 상품 라벨의 모델명 복사하기

라벨을 크게 표시하고 모델명 영역만 선택합니다. O와 0, I와 1, 하이픈을 주의해서 점검합니다. 제품 식별 코드가 다르면 주문이나 부품 검색 결과도 달라질 수 있으므로 원본과 비교합니다.

17. 자주 묻는 질문

Q. 윈도우11에서 별도 프로그램 설치 없이 이미지 속 글자를 복사할 수 있나요?

지원되는 캡처 도구 버전이라면 가능합니다. Windows 키 + Shift + S로 필요한 영역을 캡처하고 캡처 도구의 텍스트 작업에서 복사할 수 있습니다. 기능이 보이지 않는다면 앱과 Windows의 버전을 확인하세요.

Q. Windows 키 + Shift + T가 작동하지 않습니다.

Microsoft PowerToys가 설치되어 있는지, Text Extractor 기능이 활성화돼 있는지, 다른 프로그램과 단축키가 충돌하는지 확인하세요. 이 단축키는 기본 Windows 캡처 도구 단축키가 아닙니다.

Q. 한글은 잘못 읽고 영어는 정상인데 고장인가요?

반드시 고장은 아닙니다. PowerToys Text Extractor는 설치된 Windows OCR 언어 팩에 영향을 받습니다. 선호 언어와 지원 언어를 확인하고 원본 이미지의 선명도도 점검하세요.

Q. 화면에 보이는 영상 자막도 복사할 수 있나요?

PowerToys Text Extractor는 영상 화면에 표시된 글자도 OCR로 인식할 수 있다고 Microsoft가 안내합니다. 다만 화면에 나오지 않는 전체 영상 대본을 자동 생성하는 기능은 아닙니다.

Q. OCR 결과를 복사하면 줄바꿈과 표도 똑같이 보존되나요?

보장되지 않습니다. OCR은 글자를 읽는 기능이며, 표의 구조·줄바꿈·칸 구분은 달라질 수 있습니다. 여러 열이 있는 문서는 반드시 원본 레이아웃과 비교하세요.

Q. Windows 캡처 도구에서 OCR을 쓰면 이미지가 인터넷으로 전송되나요?

Microsoft는 캡처 도구의 텍스트 인식 처리가 로컬로 수행된다고 설명합니다. 다만 이후 스크린샷을 공유하거나 온라인 저장소에 업로드하면 별도의 데이터 전송이 발생할 수 있습니다.

Q. Mac은 아무 사진이나 드래그해서 복사할 수 있나요?

지원되는 Mac과 앱에서 라이브 텍스트가 인식하는 사진 속 글자라면 선택·복사를 시도할 수 있습니다. 하지만 모든 운영체제 버전, 기기, 이미지 뷰어, 언어에서 동일하게 작동한다고 볼 수는 없습니다.

Q. 제품 코드 한 글자만 틀려도 문제가 될까요?

그럴 수 있습니다. 제품 모델명, 주문번호, 오류 코드, 계좌번호처럼 문자가 식별에 사용되는 값은 원본과 정확히 같아야 합니다. OCR 결과의 유사 글자와 기호를 다시 대조하세요.

최종 정리

이미지 속 글자를 복사하려면 Windows 11은 캡처 도구의 텍스트 작업, 화면 글자 추출을 자주 한다면 Microsoft PowerToys Text Extractor, Mac 사진 앱을 사용한다면 라이브 텍스트를 먼저 살펴보세요.

작업의 완성도는 복사 버튼을 누른 순간이 아니라 원본 대조를 끝냈을 때 결정됩니다. 글자, 숫자, 표·문단 구조를 각각 검수하고 개인정보가 포함된 화면의 공유 범위까지 확인하면 빠른 OCR 기능을 훨씬 안전하고 실용적으로 활용할 수 있습니다.
