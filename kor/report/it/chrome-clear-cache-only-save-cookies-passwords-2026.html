2026 크롬 캐시 삭제 방법: PC·갤럭시·아이폰, 쿠키·비밀번호 유지하고 새로고침

크롬에서 웹사이트 이미지가 깨지거나, 수정한 화면이 예전 상태 그대로 보이거나, 로그인 화면이 계속 반복된다면 캐시(Cache) 또는 쿠키·사이트 데이터를 확인할 필요가 있습니다. 다만 캐시를 지우는 것과 쿠키를 지우는 것은 전혀 다른 작업입니다. 둘을 구분하지 않고 한꺼번에 삭제하면 로그인 상태나 사이트 설정이 초기화돼 오히려 불편할 수 있습니다.

가장 먼저 기억할 원칙은 문제가 한 페이지만 발생하면 강력 새로고침을 먼저 시도하고, 캐시 삭제가 필요하다면 '캐시된 이미지 및 파일'만 선택해 지우는 것입니다. 쿠키, 방문 기록, 비밀번호, 자동완성 정보는 필요할 때 별도로 다루는 것이 안전합니다.

이 글에서는 윈도우11·Mac·갤럭시(안드로이드)·아이폰 크롬 캐시 삭제 경로, 쿠키는 남겨두는 방법, Ctrl+Shift+R, 특정 사이트 데이터만 지우는 방법, 삭제 후 로그인 풀림과 비밀번호 보존을 Google Chrome 공식 도움말 기준으로 정리했습니다.

검토일: 2026년 11월 4일. 메뉴 표시와 위치는 Chrome 버전·운영체제·관리자 정책에 따라 달라질 수 있습니다.

1. 캐시, 쿠키, 방문 기록, 비밀번호는 각각 무엇인가요?

Chrome의 '인터넷 사용 기록 삭제'에는 서로 다른 종류의 데이터가 표시됩니다. 지우려는 항목을 정확히 체크하는 것이 중요합니다.

항목역할삭제할 때 주의할 점
캐시된 이미지 및 파일이미 내려받은 페이지 이미지·리소스를 재사용해 로딩 속도 개선다음 방문 때 파일을 다시 받으므로 일시적으로 느려질 수 있음
쿠키 및 기타 사이트 데이터로그인 상태·사이트 설정 등 저장사이트에서 로그아웃되거나 설정이 초기화될 수 있음
인터넷 사용 기록방문한 사이트 주소 목록기록·추천이 변경되고 동기화 계정에 영향이 있을 수 있음
저장된 비밀번호·패스키로그인 자격 증명 관리별도로 삭제하면 재로그인에 문제가 생길 수 있음
자동완성 양식 데이터주소·결제정보·폼 입력 이력주소·입력 추천 정보가 사라질 수 있음
사이트 설정카메라·마이크·알림 등의 개별 사이트 권한허용·차단 선택을 다시 해야 할 수 있음

Google은 캐시된 이미지 및 파일을 페이지 일부의 사본으로 설명합니다. 쿠키 및 사이트 데이터는 로그인 상태나 사이트별 설정과 관련된 별도 항목입니다. 따라서 화면 문제를 해결하려고 모든 체크박스를 선택할 필요는 없습니다.

출처: Google Chrome 고객센터 — 인터넷 사용 기록 삭제.

2. PC 크롬에서 캐시만 지우는 가장 안전한 방법

Windows 11·Windows 10 기준

  1. Chrome 브라우저를 엽니다.
  2. Ctrl+Shift+Delete를 누릅니다.
  3. '인터넷 사용 기록 삭제' 화면이 열리면 기간을 선택합니다.
  4. 캐시된 이미지 및 파일에 체크합니다.
  5. 쿠키 및 기타 사이트 데이터, 인터넷 사용 기록, 비밀번호 등 지우고 싶지 않은 항목이 체크되어 있지 않은지 확인합니다.
  6. 데이터 삭제를 클릭합니다.
  7. 문제가 있었던 사이트를 다시 열고 화면을 확인합니다.

Mac용 Chrome 기준

  1. Chrome을 실행합니다.
  2. Command(⌘)+Shift+Delete를 누릅니다.
  3. 기간을 선택한 후 캐시된 이미지 및 파일만 선택합니다.
  4. 필요하지 않은 항목은 체크 해제하고 삭제합니다.
  5. 사이트를 다시 열어 문제가 해결됐는지 확인합니다.

단축키가 작동하지 않는 경우, Chrome 오른쪽 위 더보기(점 세 개) → 인터넷 사용 기록 삭제로 이동할 수 있습니다.

권장: 처음에는 '지난 1시간' 등 문제가 발생한 기간부터 시도해 보고, 해결되지 않으면 더 긴 기간으로 확대할 수 있습니다. 다만 오래전에 생성된 캐시가 원인이라면 짧은 기간 삭제만으로는 해결되지 않을 수 있습니다.

출처: Google — Windows·Mac Chrome 단축키, Google — Chrome 인터넷 사용 기록 삭제.

3. '캐시만 삭제하면 로그인과 비밀번호가 유지되나요?'

캐시된 이미지 및 파일만 선택한다면 해당 삭제 작업에서 비밀번호·쿠키 항목을 직접 지우는 것은 아닙니다. 하지만 Chrome의 로그인 세션 상태, 웹사이트 자체의 정책, 계정 보안 점검 등 다른 이유로 로그인이 풀릴 가능성까지 없다고 보장할 수는 없습니다.

삭제 전 체크할 항목

  • '쿠키 및 기타 사이트 데이터'를 해제했는가?
  • 비밀번호·패스키 관련 항목을 선택하지 않았는가?
  • 방문 기록을 실수로 함께 선택하지 않았는가?
  • 회사·학교 계정의 로그인 유지가 중요한 상황인가?
  • 현재 작업 중인 입력 폼·작성 글·결제 과정을 먼저 저장했는가?

특히 작성 중인 긴 문서나 결제 페이지에서 새로고침을 하면 저장하지 않은 입력 내용이 사라질 수 있으므로, 작업을 마무리한 다음 진행하세요.

자주 하는 실수

문제가 있는 사이트를 빨리 고치려고 '전체 기간' + 모든 항목 체크를 선택하는 것입니다. 이 경우 필요 없는 데이터까지 삭제할 수 있습니다. 삭제 목적이 화면 오류 해결이라면 캐시부터 확인하세요.

출처: Google — 삭제 항목별 영향.

4. 캐시를 지우기 전에: Ctrl+Shift+R 강력 새로고침

문제가 한 개 사이트의 현재 페이지에서만 발생한다면 전체 캐시를 삭제하기 전에 캐시 콘텐츠를 무시하고 현재 페이지를 새로고침하는 방법을 시도할 수 있습니다.

환경강력 새로고침
Windows·Linux의 ChromeCtrl+Shift+R 또는 Shift+F5
Mac의 ChromeCommand(⌘)+Shift+R
일반 새로고침Windows Ctrl+R 또는 F5

Google의 공식 Chrome 단축키 문서에서 Windows의 Ctrl+Shift+R·Shift+F5와 Mac의 ⌘+Shift+R을 '캐시 콘텐츠를 무시하고 새로고침'하는 단축키로 안내합니다.

어느 상황에서 유용할까요?

  • 방금 수정한 웹사이트의 CSS·이미지가 예전 버전으로 보임
  • 페이지 버튼이나 메뉴가 바뀌었는데 내 브라우저에만 옛날 화면이 보임
  • PC에서만 일부 이미지·글꼴이 깨짐
  • 동일 주소를 다른 브라우저에서 열면 정상적으로 보임

주의: 강력 새로고침은 그 페이지의 리소스를 새로 요청하도록 하는 동작이지, 브라우저에 저장된 모든 기간의 캐시·쿠키를 일괄 삭제하는 기능은 아닙니다.

출처: Google — Chrome 웹페이지 단축키.

5. 갤럭시에서 크롬 캐시 삭제: Android

갤럭시와 다른 Android 휴대전화의 Chrome에서도 인터넷 사용 기록 삭제 화면에서 데이터 종류를 선택할 수 있습니다.

단계별 방법

  1. 갤럭시에서 Chrome 앱을 엽니다.
  2. 주소 표시줄 옆의 더보기(점 세 개)를 누릅니다.
  3. 인터넷 사용 기록 삭제를 선택합니다.
  4. 기본 기간이 지난 15분 등으로 표시될 수 있으므로 기간을 확인합니다.
  5. 추가 옵션으로 이동해 삭제할 데이터 종류를 확인합니다.
  6. 캐시된 이미지 및 파일을 선택합니다.
  7. 필요하지 않은 쿠키 및 사이트 데이터·방문 기록 등은 체크 해제합니다.
  8. 데이터 삭제를 누른 다음 해당 사이트에 다시 접속합니다.

Google의 공식 Android 도움말에 따르면, 기본 삭제 화면 외에 '추가 옵션(More options)'에서 삭제할 기록의 종류를 더 구체적으로 선택할 수 있습니다.

갤럭시에서 '앱 캐시 삭제'와 'Chrome 인터넷 사용 기록 삭제'는 같나요?

두 방법은 설정 위치와 처리 범위가 다릅니다. Android의 설정 → 앱 → Chrome → 저장공간에는 캐시 관련 메뉴가 있을 수 있지만, 사용자가 원한 것이 '웹사이트 이미지·파일 캐시만 정리하기'라면 Chrome 앱 내부에서 삭제 항목을 직접 선택하는 방법이 더 명확합니다.

특히 앱 저장공간 화면의 '데이터 삭제' 또는 '저장공간 삭제'는 캐시 삭제와 다를 수 있으므로 실수로 선택하지 마세요. 앱 설정과 로컬 데이터에 영향을 줄 수 있습니다.

출처: Google — Chrome Android 인터넷 사용 기록 삭제.

6. 아이폰 크롬 캐시 삭제: Safari와 헷갈리지 않기

아이폰에서는 Chrome의 캐시와 Safari의 웹사이트 데이터를 별도로 다뤄야 합니다. Chrome 문제를 고치려는 상황에서 iPhone 설정의 Safari 기록 삭제로만 이동하면 원하는 Chrome 데이터를 지우지 못할 수 있습니다.

아이폰의 Chrome 앱에서 처리하기

  1. 아이폰에서 Chrome을 엽니다.
  2. 더보기(점 세 개) → 인터넷 사용 기록 삭제로 이동합니다.
  3. 삭제할 기간을 확인합니다.
  4. 필요한 경우 인터넷 사용 기록 종류(Browsing Data)를 열어 세부 항목을 선택합니다.
  5. 캐시된 이미지 및 파일을 선택하고, 필요 없는 항목은 해제합니다.
  6. 확인 또는 뒤로 가기로 목록 선택을 마칩니다.
  7. 인터넷 사용 기록 삭제를 눌러 실행합니다.

Google의 iPhone용 안내에 따르면 기본 시간 범위는 버전에 따라 지난 15분으로 표시될 수 있습니다. 화면에 나타난 값을 보고 변경하세요.

주의: 메뉴 이름은 '인터넷 사용 기록 삭제'이지만, 그 안에서 캐시만 선택할 수 있는지 확인해야 합니다. 기록·쿠키까지 함께 삭제할 필요는 없습니다.

출처: Google — Chrome iPhone·iPad 인터넷 사용 기록 삭제.

7. 특정 사이트에서만 문제가 생겼다면: 해당 사이트의 쿠키·데이터 삭제

모든 사이트의 쿠키를 삭제하면 여러 서비스에서 다시 로그인해야 할 수 있습니다. 문제가 특정 사이트의 로그인 상태·사이트별 설정과 관련된다면 해당 사이트 데이터만 삭제하는 편이 영향을 좁히는 데 도움이 됩니다.

PC Chrome에서 특정 사이트 데이터 삭제

  1. Chrome 오른쪽 위 더보기 → 설정을 엽니다.
  2. 개인정보 보호 및 보안으로 이동합니다.
  3. 서드 파티 쿠키(제3자 쿠키) 메뉴를 엽니다.
  4. 모든 사이트 데이터 및 권한 보기를 선택합니다.
  5. 문제가 있는 사이트의 도메인을 검색합니다.
  6. 사이트 옆의 삭제를 선택합니다.
  7. 삭제 경고를 확인하고 실행합니다.
  8. 해당 사이트를 다시 열어 로그인·화면·동작을 확인합니다.

Google은 공식 문서에서 이 경로를 특정 사이트 쿠키 삭제 방법으로 안내합니다.

주의: 이는 '캐시된 이미지 및 파일만 삭제'하는 작업과 다릅니다. 해당 사이트의 로그인 상태와 저장된 설정에 영향을 줄 수 있으므로 필요한 계정 정보를 확인하고 진행하세요.

Android의 특정 사이트 데이터 삭제

Google의 Android Chrome 안내에 따르면 사이트를 연 상태에서 주소 표시줄의 페이지 정보 → 쿠키 및 사이트 데이터로 이동해 해당 사이트의 저장 데이터를 삭제할 수 있습니다. 메뉴 구성은 Chrome 버전에 따라 다를 수 있습니다.

출처: Google — Chrome에서 특정 사이트 쿠키 삭제, Google — Android 특정 사이트 쿠키 삭제.

캐시로 해결되지 않으면 쿠키까지 삭제해야 하나요?

쿠키를 삭제하면 사이트 로그인 상태와 설정이 초기화될 수 있으므로 전체 삭제는 최후의 점검 단계로 고려합니다. 특정 사이트에서만 문제가 생긴다면 앞 절의 사이트별 데이터 삭제를 먼저 검토하세요. 여러 사이트의 인증·세션 오류가 동시에 반복되는 경우에도 서버 장애, 계정 정책, 확장 프로그램 문제를 먼저 구분하는 편이 안전합니다.

PC Chrome에서 전체 쿠키 삭제가 필요하다면 더보기 → 인터넷 사용 기록 삭제에서 기간을 정하고 쿠키 및 기타 사이트 데이터를 선택합니다. 저장된 비밀번호·자동완성 데이터까지 함께 선택되지 않았는지 확인한 뒤 삭제하세요. 이때 여러 사이트에서 다시 로그인해야 할 수 있으며, 장바구니나 작성 중인 양식 등 로컬 저장 데이터가 영향을 받을 수 있습니다.

갤럭시·아이폰의 Chrome 앱도 더보기 → 인터넷 사용 기록 삭제에서 기간과 데이터 종류를 선택합니다. 앱 버전에 따라 추가 옵션이나 선택 화면이 다릅니다. 아이폰의 Safari 설정을 변경해도 Chrome 앱의 데이터가 동일하게 삭제되는 것은 아닙니다. 휴대전화 설정의 앱 데이터 전체 삭제는 Chrome에서 개별 항목을 지우는 것보다 범위가 넓으므로 먼저 실행하지 마세요.

공식 참고: Google Chrome — PC 인터넷 사용 기록 삭제, Android Chrome, iPhone·iPad Chrome.

8. '캐시 삭제'와 '로그아웃'을 구분해야 하는 이유

쿠키는 웹사이트가 저장하는 작은 데이터로, 로그인 상태나 사이트 환경을 기억하는 데 사용될 수 있습니다.

캐시만 삭제: 사이트의 이미지·파일을 다시 다운로드하므로 화면 오류를 진단하는 데 도움이 될 수 있습니다.

쿠키·사이트 데이터 삭제: 특정 사이트에서 로그아웃되거나 설정이 초기화될 수 있습니다. 다만 Google 계정이나 사이트의 서버에 있는 모든 정보가 사라진다는 의미는 아닙니다.

비밀번호 삭제: Chrome 비밀번호 관리자에서 보관하는 로그인 정보를 삭제하는 별도 작업이므로 캐시 삭제와 혼동하면 안 됩니다.

비밀번호를 다시 입력해야 한다면?

캐시를 삭제한 직후 로그인 화면이 표시되더라도 비밀번호가 Chrome 비밀번호 관리자에서 실제로 삭제됐다고 단정하지 마세요. 쿠키 만료, 사이트의 보안 정책, 다른 기기 로그아웃 등도 로그인 상태에 영향을 줄 수 있습니다.

사용자가 비밀번호를 잊어버린 상태라면 쿠키 삭제 전에 계정 복구 수단을 점검하는 것이 안전합니다.

출처: Google — Chrome 쿠키 이해하기, Google — 인터넷 사용 기록 삭제 항목.

9. 크롬 캐시를 지워도 사이트가 안 열리면 무엇을 확인할까?

캐시 삭제는 여러 문제의 진단 단계 중 하나일 뿐입니다. 오류 원인이 서버·네트워크·확장 프로그램·계정 정책이라면 캐시만 지워도 해결되지 않을 수 있습니다.

증상우선 확인다음 단계
이미지·스타일이 예전 상태강력 새로고침캐시된 이미지 및 파일 삭제
특정 사이트 로그인 무한 반복쿠키·사이트 데이터 또는 로그인 환경해당 사이트의 데이터만 선택 삭제 고려
모든 사이트가 느림인터넷 연결·메모리·확장 프로그램Chrome 업데이트와 확장 프로그램 점검
특정 사이트만 접속 불가서버 장애·주소·보안·쿠키 정책다른 브라우저·네트워크에서 비교
Chrome에서만 동영상 재생 안 됨확장 프로그램·사이트 권한·미디어 설정오류 메시지와 개별 사이트 설정 확인
삭제 후 인증이 계속 풀림쿠키 차단·브라우저 정책·사이트 보안쿠키 설정과 조직 정책 확인

5분 점검 순서

  1. 문제가 있는 사이트 주소가 정확한지 확인합니다.
  2. 다른 사이트도 비슷한지 점검합니다.
  3. 해당 사이트에서 강력 새로고침을 시도합니다.
  4. 필요하면 캐시만 삭제합니다.
  5. 로그인이 문제라면 특정 사이트의 쿠키만 점검합니다.
  6. 그래도 해결되지 않으면 확장 프로그램·Chrome 업데이트·네트워크를 확인합니다.
  7. 은행·공공기관·회사 서비스라면 제공처의 장애 공지와 보안 프로그램 요구 사항도 확인합니다.

중요: 문제 해결을 위해 모든 비밀번호를 삭제하거나 브라우저 전체를 초기화하는 것은 초기 대응으로 권장하지 않습니다.

10. Chrome 동기화 중일 때 삭제한 정보는 다른 기기에도 영향을 줄까?

Google은 Chrome에서 계정에 로그인해 기록·자동완성 등의 정보를 Google 계정에 저장하는 경우, 이를 삭제하면 다른 기기나 계정에도 영향이 있을 수 있다고 안내합니다.

하지만 모든 데이터가 동일한 방식으로 동기화되는 것은 아닙니다. 특히 캐시된 이미지와 파일의 정리와 동기화된 방문 기록 또는 계정 데이터의 삭제를 같은 결과로 설명하면 안 됩니다.

안전한 구분

  • 캐시 삭제: 각 기기의 페이지 파일 저장 상태를 정리하는 목적
  • 방문 기록 삭제: Chrome에서 계정 동기화 상태에 따라 여러 기기에 영향 가능
  • 저장 비밀번호 삭제: Chrome 비밀번호 관리자 및 동기화 상태 확인 필요
  • 쿠키 삭제: 사이트 로그인·환경 설정 영향 가능
  • Google 검색 활동 삭제: Google 계정의 '내 활동'과 별도의 영역을 확인해야 함

결론: 문제가 한 기기에서만 나타난다면 우선 그 기기의 Chrome에서 최소 범위의 삭제를 시도하고, Google 계정에 연결된 데이터를 무작정 전체 삭제하지 마세요.

출처: Google — Chrome 삭제 데이터와 계정 동기화.

11. 실전 사례: 회사 사이트에서 로그인만 반복될 때

가상의 업무 사이트에서 로그인을 완료했는데 다시 로그인 창이 뜨는 상황을 가정해 보겠습니다.

사례 A. 화면은 옛날인데 로그인은 정상

  1. Chrome에서 사이트를 엽니다.
  2. Ctrl+Shift+R을 눌러 강력 새로고침합니다.
  3. 개선되지 않으면 캐시된 이미지 및 파일만 삭제합니다.
  4. 화면이 실제로 최신으로 바뀌었는지 확인합니다.

이때 쿠키를 먼저 삭제할 필요는 없습니다.

사례 B. 로그인 뒤 다시 로그인 화면으로 돌아옴

  1. 계정 자체의 장애·비밀번호 오류인지 확인합니다.
  2. 사이트의 로그인 세션이 실제로 정상인지 확인합니다.
  3. 다른 브라우저에서도 재현되는지 비교합니다.
  4. Chrome의 특정 사이트 쿠키·사이트 데이터를 점검합니다.
  5. 삭제 전 계정 복구 수단과 로그인 정보를 확인합니다.
  6. 해당 사이트 데이터만 삭제한 후 다시 로그인합니다.

단, 회사 내부 업무 사이트라면 IT 관리자 정책이나 SSO(통합 로그인) 구성이 원인일 수 있습니다. 회사 보안 기능을 임의로 끄거나 다른 계정으로 우회하지 마세요.

12. 삭제 후 저장 공간이 줄지 않는 이유

'캐시를 삭제하면 몇 GB가 무조건 줄어든다'는 보장은 없습니다. Chrome의 캐시 저장 규모는 사용자 환경에 따라 다르고, 삭제 직후 사이트를 다시 방문하면 이미지·파일이 다시 저장될 수 있기 때문입니다.

특히 다음을 구분해야 합니다.

  • Chrome 캐시: 웹사이트를 빠르게 표시하기 위한 일부 리소스
  • 다운로드 폴더: 실제 내려받은 PDF·사진·ZIP 등 파일
  • Google 계정 저장공간: Gmail·Google 드라이브·Google 포토 등의 별도 용량
  • 휴대전화 앱 저장공간: Chrome 앱 및 다른 앱 데이터의 총합

Google은 다운로드 기록을 삭제해도 실제 내려받은 파일 자체가 삭제되지는 않는다고 안내합니다. 반대로 실제 다운로드 파일 정리를 원한다면 해당 폴더에서 파일을 확인해야 합니다.

주의: 디스크 용량이 부족하다고 앱 전체 데이터 삭제를 바로 실행하지 마세요. 캐시 정리와 개인 데이터 초기화는 영향이 다릅니다.

13. 자주 묻는 질문

Q. 크롬 캐시 삭제 단축키가 뭔가요?

Windows는 Ctrl+Shift+Delete, Mac은 Command+Shift+Delete로 삭제 옵션을 열 수 있습니다. Chrome의 공식 단축키 안내에 있는 기능입니다.

Q. Ctrl+Shift+R과 Ctrl+Shift+Delete는 무슨 차이인가요?

Ctrl+Shift+R은 현재 페이지의 캐시 콘텐츠를 무시하고 새로고침합니다. Ctrl+Shift+Delete는 인터넷 사용 기록 삭제 옵션 화면을 엽니다. 서로 다른 기능입니다.

Q. 캐시만 지우면 크롬 비밀번호가 삭제되나요?

캐시된 이미지 및 파일만 선택하면 저장 비밀번호를 직접 삭제하는 항목을 고른 것은 아닙니다. 삭제 화면에서 비밀번호 관련 옵션이 선택되지 않았는지 반드시 확인하세요.

Q. 쿠키를 지우면 사이트 로그인이 풀리나요?

가능합니다. Google은 쿠키 삭제 시 로그인 상태와 사이트 설정에 영향을 줄 수 있다고 설명합니다. 필요한 사이트의 쿠키만 지우는 방식도 검토하세요.

Q. 갤럭시에서 'Chrome 앱 캐시 삭제'와 'Chrome 데이터 삭제'는 같나요?

아닙니다. 캐시 삭제와 앱 저장 데이터 삭제는 범위와 영향이 다를 수 있습니다. 웹 브라우저의 캐시만 정리하려면 Chrome 내부의 인터넷 사용 기록 삭제에서 항목 선택을 우선하세요.

Q. 아이폰 Chrome에서 캐시만 삭제할 수 있나요?

Chrome 앱의 인터넷 사용 기록 삭제 → 데이터 유형 선택에서 캐시된 이미지 및 파일을 선택하는 방법을 사용할 수 있습니다. Chrome 메뉴와 iPhone의 Safari 설정을 혼동하지 마세요.

Q. 특정 사이트의 쿠키만 지울 수 있나요?

PC Chrome에서는 설정 → 개인정보 보호 및 보안 → 서드 파티 쿠키 → 모든 사이트 데이터 및 권한 보기에서 해당 사이트를 찾아 삭제할 수 있습니다.

Q. 삭제했는데 다시 같은 오류가 생깁니다.

웹사이트 자체 문제, 확장 프로그램, 네트워크, 쿠키 정책, 계정 권한 등 캐시 이외의 원인을 확인해야 합니다. 동일 문제가 다른 브라우저에서도 나타나는지 비교하면 도움이 됩니다.

14. 최종 체크리스트: 문제를 최소한의 삭제로 해결하기

  • ☐ 문제가 한 사이트인지 모든 사이트인지 구분했는가?
  • ☐ PC라면 Ctrl+Shift+R 또는 Command+Shift+R을 먼저 시도했는가?
  • ☐ 캐시 삭제 화면에서 기간을 확인했는가?
  • ☐ 캐시된 이미지 및 파일만 체크했는가?
  • ☐ 쿠키 및 기타 사이트 데이터를 실수로 선택하지 않았는가?
  • ☐ 저장 비밀번호·방문 기록·자동완성 데이터를 유지할지 확인했는가?
  • ☐ 웹사이트에 입력 중인 저장되지 않은 글과 결제 정보를 보호했는가?
  • ☐ 특정 사이트 문제라면 그 사이트의 데이터만 지우는 대안을 검토했는가?
  • ☐ 삭제 후 실제 페이지 로딩·로그인 상태가 개선됐는지 재확인했는가?

결론: 크롬 캐시 삭제는 무조건 전체 기록을 지우는 작업이 아닙니다. 현재 페이지 새로고침 → 캐시된 이미지 및 파일만 삭제 → 필요할 때 특정 사이트 쿠키만 삭제의 순서로 접근하면 로그인과 저장 정보를 불필요하게 건드릴 위험을 줄일 수 있습니다.
