2. 캡처 도구로 윈도우11 화면 녹화하는 방법

캡처 도구는 화면을 정지 이미지로 저장하는 기능뿐 아니라 선택한 영역을 동영상으로 기록하는 기능도 제공합니다. 프로그램 메뉴를 클릭하는 순서, 브라우저에서 설정 변경하는 방법, 짧은 안내 영상을 제작할 때 적합합니다.

  1. Windows 시작 버튼을 누르고 캡처 도구를 검색해 실행합니다.
  2. 앱 상단에서 카메라 모양의 이미지 캡처가 아닌 녹화(Record) 기능을 선택합니다.
  3. **새로 만들기(New)**를 누릅니다.
  4. 마우스로 녹화할 화면 영역을 직사각형으로 지정합니다.
  5. 표시되는 설정과 오디오 옵션이 있으면 원하는 상태인지 확인합니다.
  6. **시작(Start)**을 눌러 화면 기록을 진행합니다.
  7. 필요한 작업을 마친 뒤 **중지(Stop)**를 눌러 녹화를 종료합니다.
  8. 미리보기에서 재생한 다음 저장하거나 지원되는 경우 Clipchamp에서 편집을 선택합니다.

더 빠른 단축키

Windows + Shift + R을 누르면 캡처 도구의 동영상 캡처 오버레이를 바로 열 수 있습니다. 반대로 Windows + Shift + S는 기본적으로 정지 화면 캡처입니다. 비슷한 단축키를 혼동하는 일이 많으니 구분해 두세요.

녹화 범위에 관한 주의점

영역을 선택하면 그 범위 안의 화면 변화가 기록됩니다. 따라서 중요한 버튼이나 팝업이 선택 영역 밖에 나타날 경우 영상에 포함되지 않을 수 있습니다. 녹화를 시작하기 전 표시할 창을 적절히 배치하고, 필요하면 영역을 넓게 선택하세요.

공식 안내: Microsoft 캡처 도구 — 비디오 캡처

3. Xbox Game Bar로 게임·앱 화면 녹화하는 방법

Xbox Game Bar는 Windows에서 게임 플레이 또는 지원되는 앱 사용 장면을 기록하기 위한 기본 기능입니다.

  1. 녹화하려는 게임이나 앱을 실행합니다.
  2. Windows + G를 눌러 Xbox Game Bar를 엽니다.
  3. 캡처(Capture) 창을 확인합니다.
  4. 녹화 대상 앱이 활성화된 상태에서 녹화 시작을 선택하거나 Windows + Alt + R을 누릅니다.
  5. 게임 또는 앱에서 필요한 작업을 진행합니다.
  6. 녹화를 종료하려면 다시 Windows + Alt + R을 누릅니다.
  7. 저장된 결과를 동영상 폴더의 Captures(캡처) 폴더에서 확인합니다.

Microsoft의 공식 안내에서 시작·종료 단축키는 모두 Windows + Alt + R입니다. 키를 여러 번 누르면 녹화 시작과 종료가 반복될 수 있으므로 화면의 녹화 상태를 확인하세요.

캡처 메뉴가 보이지 않으면

먼저 Windows + G가 정상적으로 열리는지 확인하세요. 앱이나 장치 설정에 따라 Xbox Game Bar가 비활성화돼 있을 수 있습니다. Windows의 설정 검색에서 Xbox Game Bar 관련 옵션을 확인하고, 필요한 경우 Microsoft Store에서 앱 설치·업데이트 상태를 점검하세요.

공식 안내: Microsoft — Xbox Game Bar 화면 녹화

4. 화면 녹화 단축키 6가지 정리

단축키동작
Windows + Shift + R캡처 도구의 동영상 녹화 영역 선택
Windows + Shift + S캡처 도구의 정지 이미지 캡처
Windows + GXbox Game Bar 열기
Windows + Alt + RGame Bar 녹화 시작·중지
Windows + Alt + MGame Bar 녹화 중 마이크 켜기·끄기

동영상 녹화와 스크린샷 저장은 다른 기능입니다. 화면을 한 장의 이미지로 저장하려면 Windows + Shift + S가 유용하고, 실제 움직임을 기록해야 할 때는 Windows + Shift + R이나 Windows + Alt + R을 사용합니다.

노트북에 따라 Function(Fn) 키와 Print Screen 키 조합이 다를 수 있습니다. 특정 단축키가 실행되지 않더라도 시작 메뉴에서 해당 앱을 직접 열어 기능이 동작하는지 확인하세요.

공식 안내: Microsoft 캡처 도구 단축키, Microsoft Game Bar 단축키

5. ‘녹화했는데 소리가 안 나와요’ 원인부터 구분

소리가 없는 영상은 다음 네 가지 상황 중 어느 쪽인지 구분하는 것이 빠릅니다.

  • 화면만 기록되고 컴퓨터에서 재생 중인 소리가 포함되지 않은 경우
  • PC의 소리는 있는데 내 목소리나 마이크 입력이 빠진 경우
  • 영상에는 소리가 들어 있지만 재생 음량 또는 출력 장치가 잘못된 경우
  • 특정 앱이 오디오 캡처를 제한하거나 지원되지 않는 경로를 사용하는 경우

먼저 10초 테스트를 해보세요

  1. 녹음해도 되는 일반 앱을 열고 시험용 오디오를 재생합니다.
  2. 화면 녹화 도구의 오디오·마이크 관련 설정을 확인합니다.
  3. 짧은 영상을 녹화하고 종료합니다.
  4. 저장된 파일을 기본 동영상 재생 앱에서 열어 봅니다.
  5. 재생 장치의 볼륨을 확인하고 다른 이어폰·스피커로도 비교합니다.
  6. PC 소리만 없는지, 내 목소리만 없는지, 둘 다 없는지 나눠 적습니다.

중요: 소리가 없다는 이유로 곧바로 마이크 드라이버를 삭제하지 마세요. 미디어 오디오 캡처와 마이크 입력은 각각 다른 설정의 영향을 받으며, 영상 파일이 무음인지 재생 환경만 무음인지를 구분해야 합니다.

6. Xbox Game Bar에서 PC 소리와 마이크 설정하기

Game Bar에서는 녹화 중 마이크를 켜거나 끌 수 있고, 캡처할 오디오 범위를 설정할 수 있습니다.

마이크 켜기·끄기

녹화 중 Windows + Alt + M을 누르면 마이크를 켜거나 끌 수 있습니다. 따라서 화면은 정상적으로 녹화됐는데 목소리가 빠졌다면 마이크를 녹화 중 꺼놓았는지 확인하세요.

컴퓨터 소리 포함하기

  1. Windows + G로 Game Bar를 엽니다.
  2. 설정에서 캡처(Capturing) 또는 오디오 관련 설정을 찾습니다.
  3. 필요에 따라 **모두(All)**와 같은 녹음 범위 옵션을 검토합니다.
  4. 마이크를 이용한 설명이 필요하면 마이크가 켜져 있는지 확인합니다.
  5. 짧게 녹화한 뒤 결과 파일의 게임 소리와 목소리를 비교합니다.

Microsoft는 Game Bar의 캡처 설정에 시스템·앱 소리를 포함하는 모두(All) 옵션을 설명합니다. 다만 실제로 녹음되는 콘텐츠와 오디오 동작은 앱·하드웨어·설정의 영향을 받을 수 있으므로 중요한 작업 전에 시험 녹화가 필요합니다.

7. 캡처 도구의 소리 설정은 어디에서 확인하나요?

캡처 도구는 동영상 녹화와 정지 이미지 캡처를 구분해서 제공합니다. 사용 중인 버전에 시스템 오디오와 마이크를 켜거나 끄는 컨트롤이 있다면 녹화를 시작하기 전에 각각 확인하세요.

  1. 캡처 도구의 녹화 모드로 들어갑니다.
  2. 영역을 선택한 뒤 녹음 관련 아이콘이나 설정이 표시되는지 확인합니다.
  3. 컴퓨터 소리를 포함할지, 마이크 소리를 포함할지 목적에 맞게 선택합니다.
  4. 짧게 시험 녹화합니다.
  5. 완료된 결과를 재생해 필요한 오디오가 실제로 포함됐는지 확인합니다.

Microsoft 지원 문서의 기본 설명은 캡처 도구로 화면 영역을 동영상으로 녹화하는 절차를 중심으로 안내합니다. 오디오 관련 버튼이나 기본값은 Windows 11과 캡처 도구 버전에 따라 차이가 날 수 있으므로, 확인되지 않은 설정 항목을 반드시 표시된다고 단정하지 않는 것이 좋습니다.

오디오 기능이 보이지 않는다면 Microsoft Store에서 캡처 도구 업데이트를 확인하세요. 조직에서 관리하는 PC의 경우 앱 업데이트가 제한돼 있을 수 있으므로 IT 담당자에게 문의합니다.

공식 안내: Microsoft — 캡처 도구 비디오 녹화

8. 마이크 권한 문제라면 Windows 설정부터 확인

목소리만 녹음되지 않는다면 Windows의 마이크 개인정보 설정을 점검하세요.

  1. 설정 → 개인정보 및 보안 → 마이크로 이동합니다.
  2. 마이크 액세스가 필요한 용도에 맞게 켜져 있는지 확인합니다.
  3. 앱에서 마이크에 액세스하도록 허용 설정을 확인합니다.
  4. 사용 중인 앱이 데스크톱 앱이라면 데스크톱 앱의 마이크 액세스 허용도 확인합니다.
  5. 설정 → 시스템 → 소리 → 입력에서 사용할 마이크를 선택하고 입력이 감지되는지 테스트합니다.

Microsoft는 카메라·마이크 개인정보 설정에 따라 일부 Windows 앱과 데스크톱 앱의 입력 장치 사용이 제한될 수 있다고 안내합니다. 개인 PC에서는 권한을 확인할 수 있지만 회사나 학교의 보안 정책이 적용된 장치라면 관리자 지침을 먼저 확인하세요.

권한이 켜져 있는데도 소리가 없다면 USB 마이크, 블루투스 헤드셋, 내장 마이크 중 어느 입력 장치가 실제로 선택돼 있는지 확인해야 합니다. 마이크 음소거 버튼이나 물리적 스위치도 함께 확인하세요.

공식 안내: Microsoft — Windows 카메라·마이크 개인정보 설정

9. 녹화한 영상 저장 위치: Game Bar와 캡처 도구는 다릅니다

녹화를 마친 후 파일을 찾지 못하는 경우가 많습니다. 우선 어떤 도구로 녹화했는지 떠올리면 저장 장소를 좁힐 수 있습니다.

Xbox Game Bar 저장 경로

Microsoft의 공식 안내에서 Game Bar는 동영상을 비디오(Videos) → Captures 폴더에 MP4 파일로 저장합니다.

  1. Windows의 파일 탐색기를 엽니다.
  2. 왼쪽에서 비디오 폴더를 찾습니다.
  3. Captures(캡처) 폴더를 엽니다.
  4. 녹화 시각이나 게임·앱 이름이 포함된 MP4 파일을 찾습니다.
  5. 최근 파일을 먼저 확인해 녹화한 내용이 맞는지 재생해 봅니다.

파일 이름에는 일반적으로 게임이나 앱 이름과 녹화 날짜·시간이 포함됩니다. 사용자 계정이나 폴더 이동 설정에 따라 실제 경로가 다를 수 있으므로 '비디오' 라이브러리에서 확인하세요.

캡처 도구에서 저장

캡처 도구는 동영상 녹화를 마치면 미리보기 화면에서 저장 또는 다른 이름으로 저장을 통해 위치를 확인할 수 있습니다. 따라서 Game Bar와 같은 Captures 폴더에 반드시 저장된다고 생각하지 마세요.

아직 캡처 도구 창이 열려 있다면 결과 파일을 저장하기 전에 종료하지 않는 편이 안전합니다. 저장 위치를 직접 선택할 수 있는 경우 알아보기 쉬운 이름과 폴더를 지정한 뒤 실제 파일이 있는지 확인하세요.

공식 안내: Microsoft — Game Bar 녹화 파일 위치, Microsoft — 캡처 도구 녹화 저장

10. Windows + Alt + R을 눌러도 녹화가 시작되지 않을 때

Xbox Game Bar 단축키가 작동하지 않는다면 바로 Windows를 재설치할 필요는 없습니다.

순서대로 확인하기

  1. Windows + G를 눌러 Game Bar가 열리는지 확인합니다.
  2. 녹화하려는 게임이나 앱을 활성화합니다.
  3. 캡처 창에서 녹화 시작 버튼이 활성화돼 있는지 봅니다.
  4. Windows 설정에서 Xbox Game Bar 관련 기능이 사용 가능한지 확인합니다.
  5. Microsoft Store에서 Game Bar와 관련 앱의 업데이트 상태를 확인합니다.
  6. PC를 재시작하고 다른 정상적인 앱을 대상으로 시험합니다.
  7. Game Bar에서 원하는 대상이 지원되지 않는다면 캡처 도구로 영역을 녹화합니다.

Microsoft는 Game Bar를 게임·앱 클립 녹화 도구로 설명합니다. 따라서 바탕화면이나 파일 탐색기를 대상으로 같은 방법이 항상 작동해야 한다고 기대하면 안 됩니다. 이런 경우 특정 영역을 지정할 수 있는 캡처 도구가 더 적합합니다.

회사 PC에서는 보안 정책으로 화면 기록 기능이 제한될 수 있습니다. 정책을 우회하려고 임의 프로그램을 설치하거나 보안 설정을 해제하지 말고 담당 관리자에게 문의하세요.

공식 안내: Microsoft — Xbox Game Bar 화면 기록

11. Windows + Shift + R이 안 될 때 캡처 도구 점검

캡처 도구 단축키가 반응하지 않으면 앱 자체가 정상적으로 실행되는지 확인하세요.

  1. 시작 메뉴에서 캡처 도구를 직접 검색합니다.
  2. 앱을 열어 녹화 버튼이 보이는지 확인합니다.
  3. 앱에서 새로 만들기로 녹화 영역을 지정해 봅니다.
  4. 앱이 열리지 않거나 녹화 기능이 없다면 Windows 업데이트 및 Microsoft Store 앱 업데이트를 확인합니다.
  5. 지원되는 Windows 11 환경인지, 회사 기기에서 앱 설치가 제한돼 있지 않은지 확인합니다.

Microsoft는 캡처 도구를 Windows 기본 녹화 대안으로 소개하면서, 기기에 설치돼 있지 않다면 Microsoft Store에서 찾을 수 있다고 설명합니다. 단축키를 외우지 못해도 앱에서 직접 녹화 시작 버튼을 누르면 됩니다.

주의: Windows + Shift + S는 정지 이미지 캡처용 단축키입니다. 동영상을 만들려던 상황에서 이 단축키가 실행되면 기능이 잘못된 것이 아니라 다른 캡처 모드를 연 것입니다.

공식 안내: Microsoft — 캡처 도구 사용, Microsoft — 단계 레코더 지원 종료 및 대체 도구

12. 화면 녹화가 검은 화면으로 저장될 때

녹화 결과를 재생했는데 특정 부분이 검게 보인다고 해서 녹화 프로그램만 고장 났다고 단정할 수는 없습니다.

먼저 일반 화면으로 테스트

  1. 개인정보가 없는 일반 앱이나 브라우저의 테스트 화면을 준비합니다.
  2. 캡처 도구로 10초 분량의 화면을 녹화합니다.
  3. 해당 영상이 정상적으로 보이는지 확인합니다.
  4. 같은 도구로 문제가 발생한 앱을 테스트합니다.
  5. 특정 앱에서만 검게 나온다면 해당 앱의 녹화 정책·기술적 제한이 있는지 확인합니다.

일부 영상 서비스, 회사 보안 프로그램, 원격 데스크톱 환경, 보호된 콘텐츠는 녹화 기능에 제한이 있을 수 있습니다. 이런 제한을 해제하는 비공식 수단을 쓰기보다 해당 서비스가 제공하는 공식 내보내기·다운로드·회의 기록 기능을 확인하는 편이 안전합니다.

녹화할 수 있는 업무 화면이라면 창 크기와 배치, GPU·디스플레이 설정을 확인하고 캡처 도구와 Game Bar의 녹화 결과를 비교할 수 있습니다. 원인 진단 전부터 그래픽 드라이버를 일괄 제거하는 것은 권장하지 않습니다.

13. 영상 편집·자막까지 필요하면 Clipchamp 사용

짧은 화면 녹화를 넘어 설명 영상으로 편집할 계획이라면 Microsoft의 Clipchamp를 검토할 수 있습니다.

Clipchamp가 적합한 경우

  • 녹화한 영상의 앞뒤 불필요한 부분을 자르고 싶을 때
  • 설명 문구, 자막 또는 제목을 붙이고 싶을 때
  • 화면 영상과 웹캠 영상의 배치를 조정하고 싶을 때
  • 오디오 트랙을 분리하거나 음량을 조정하고 싶을 때
  • 편집 결과를 MP4 동영상으로 저장하고 싶을 때

Microsoft는 Clipchamp에서 화면 녹화와 편집, 오디오 분리, 자막 추가, 내보내기를 지원한다고 안내합니다. 다만 일부 기능은 사용 중인 계정이나 앱 버전에 따라 제공 범위가 달라질 수 있으므로 실제 화면의 기능 목록을 확인하세요.

캡처 도구와 연결하기

캡처 도구에서 녹화를 마친 후 Clipchamp에서 편집(Edit in Clipchamp) 옵션을 선택할 수 있습니다. 이미 저장한 MP4 파일이 있다면 Clipchamp에 가져와 편집할 수도 있습니다.

별도의 편집이 필요 없는 짧은 작업 기록은 캡처 도구에서 바로 저장하는 편이 더 단순할 수 있습니다.

공식 안내: Microsoft — Clipchamp 화면 녹화 및 편집, Microsoft — 캡처 도구와 Clipchamp

14. 녹화할 때 개인정보와 저작권 주의하기

화면에는 녹화하려던 대상뿐 아니라 알림, 개인 메시지, 로그인된 계정, 파일 이름, 브라우저 주소창 등의 정보가 나타날 수 있습니다.

공유 전에 지켜야 할 점

  • 메신저나 이메일의 팝업 알림에 개인정보가 포함되지 않도록 미리 정리합니다.
  • 비밀번호 입력, 일회용 인증번호, 은행 계좌번호 등이 녹화되지 않도록 주의합니다.
  • 업무용 자료를 녹화한다면 소속 조직의 화면 기록 및 외부 공유 규정을 확인합니다.
  • 타인과의 회의·통화는 앱의 공식 녹화 기능, 참석자 안내 및 적용 법규를 먼저 확인합니다.
  • 저작권 보호 영상이나 스트리밍 콘텐츠는 이용 약관상 녹화·재배포가 제한될 수 있습니다.
  • 편집 과정에서 모자이크를 적용했다면 실제로 민감 정보가 보이지 않는지 결과를 다시 확인합니다.

중요: 화면을 녹화할 수 있다는 기술적 가능성과 그 영상을 외부에 공유할 수 있다는 권리는 별개입니다. 특히 타인의 화면·개인정보를 포함한 파일은 목적과 수신자를 확인해야 합니다.

15. 자주 묻는 질문

Q. 윈도우11 화면 녹화는 무료인가요?

Windows 11의 기본 캡처 도구와 Xbox Game Bar를 이용하면 별도 유료 녹화 프로그램 없이 지원되는 화면을 녹화할 수 있습니다. 다만 녹화 대상과 기능은 도구별로 다르고, 일부 편집 기능은 별도 앱에서 제공될 수 있습니다.

Q. Windows + Shift + R과 Windows + Alt + R은 무엇이 다른가요?

Windows + Shift + R은 캡처 도구의 영역 녹화 오버레이를, Windows + Alt + R은 지원되는 게임·앱에 대한 Xbox Game Bar 녹화 시작 또는 중지를 실행합니다.

Q. 전체 바탕화면을 게임 바로 녹화할 수 있나요?

Xbox Game Bar는 주로 게임과 앱 클립 녹화에 맞춰진 기능입니다. 바탕화면이나 파일 탐색기 등은 녹화 대상 제한이 있을 수 있으므로 화면의 원하는 부분을 녹화할 때는 캡처 도구를 사용하는 편이 적합합니다.

Q. 화면 녹화 파일은 어디에 저장되나요?

Game Bar는 기본적으로 비디오 → Captures에 MP4 파일을 저장합니다. 캡처 도구는 녹화 완료 후 결과를 확인하고 저장하는 화면에서 파일 위치를 선택하거나 확인하세요.

Q. Game Bar에서 제 목소리가 녹음되지 않습니다.

Windows + Alt + M으로 마이크가 꺼져 있지 않은지 확인하세요. Windows의 설정 → 개인정보 및 보안 → 마이크에서 권한을 확인하고, 사용할 입력 장치가 실제로 선택돼 있는지도 점검합니다.

Q. 화면 녹화는 됐는데 컴퓨터 소리가 없습니다.

Game Bar의 캡처 오디오 설정과 앱·시스템 소리 포함 옵션을 확인하세요. 캡처 도구에서는 실제로 제공되는 오디오 컨트롤을 확인하고 시험 녹화하세요. 일부 앱은 오디오 녹화가 제한될 수 있습니다.

Q. 녹화한 영상을 자르고 자막을 넣을 수 있나요?

네. Microsoft Clipchamp는 녹화된 영상을 편집하고 자막을 추가하거나 MP4로 내보내는 기능을 제공합니다. 지원 여부와 사용 가능한 기능은 앱·계정에 따라 확인해야 합니다.

Q. ‘단계 레코더(PSR)’를 화면 녹화 대신 사용해도 되나요?

Microsoft는 기존 단계 레코더(Steps Recorder/PSR)를 사용 중단 대상으로 안내하고 캡처 도구, Game Bar, Clipchamp를 대안으로 제시합니다. 따라서 새 화면 기록 작업은 지원되는 도구를 선택하는 편이 좋습니다.

16. 실제 녹화 전후 점검표

  • ☐ 이번 작업이 게임·앱 녹화인지, 화면 일부의 설명 녹화인지 구분했습니다.
  • ☐ 캡처 도구의 Windows + Shift + R과 Game Bar의 Windows + Alt + R을 구분했습니다.
  • ☐ 10초 정도 시험 녹화해 화면이 정상적으로 보이는지 확인했습니다.
  • ☐ PC 소리와 마이크 소리 중 무엇을 넣어야 하는지 정했습니다.
  • ☐ Xbox Game Bar의 마이크 토글과 캡처 오디오 설정을 확인했습니다.
  • ☐ 필요한 경우 Windows의 마이크 개인정보 설정과 입력 장치를 확인했습니다.
  • ☐ 개인정보가 표시될 수 있는 알림·창·주소를 정리했습니다.
  • ☐ 화면 녹화 제한이 있는 앱이나 콘텐츠가 아닌지 확인했습니다.
  • ☐ 녹화 종료 후 영상 파일을 실제로 열어 재생해 봤습니다.
  • ☐ Game Bar의 Captures 폴더 또는 캡처 도구의 저장 위치를 확인했습니다.
  • ☐ 공유할 영상에 불필요한 구간이 있으면 편집했습니다.
  • ☐ 회사나 타인의 자료가 포함됐다면 공유 가능 여부를 확인했습니다.

결론: 윈도우11에서 별도 프로그램 없이 화면을 녹화할 때 가장 먼저 확인할 도구는 캡처 도구와 Xbox Game Bar입니다. 영역을 지정하려면 Windows + Shift + R, 게임·앱을 기록하려면 Windows + Alt + R을 사용하세요. 소리가 없거나 저장 위치를 찾을 수 없다면 사용한 녹화 도구를 먼저 구분하고 오디오 설정과 파일 경로를 확인하면 문제 해결이 빨라집니다.

공식 출처 및 확인 기준

  1. Microsoft — 캡처 도구를 사용하여 화면 및 비디오 캡처: 녹화 영역 선택, Windows + Shift + R 단축키, 저장 및 Clipchamp 편집.
