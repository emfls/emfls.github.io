앱에 새 메시지나 알림이 쌓여 있는데 아이폰 잠금화면에는 아무것도 뜨지 않거나, 휴대전화는 조용한데 애플워치만 진동하는 경우가 있습니다. 원인을 모두 '푸시 오류'로 묶으면 해결 순서를 놓치기 쉽습니다. 알림을 실제로 받지 못한 것인지, 받았지만 화면에 표시되지 않은 것인지, 다른 기기로 전달된 것인지부터 구분해야 합니다.

이 글은 Apple의 공식 iPhone 알림·집중 모드·Apple Watch 안내를 기준으로 2026년 11월 3일 확인한 설정 경로를 정리했습니다. 카카오톡 앱 내부의 채팅방별 알림 문제를 다루는 별도 글과 달리, 아이폰 운영체제 전체의 알림 전달·표시 문제를 중심으로 설명합니다. 기기에 설치된 iOS 버전과 앱에 따라 메뉴의 세부 문구는 조금 다를 수 있습니다.

1. 30초 증상 분류: 알림이 안 오는 이유는 다릅니다

나타나는 증상우선 확인할 항목이유
특정 앱 한 개만 알림이 없음설정 → 알림 → 해당 앱앱별 알림 허용이 꺼져 있을 수 있음
알림 센터에는 있으나 잠금화면에 없음앱별 잠금화면 표시·잠금화면 표시 방식'개수' 표시나 앱별 표시 위치 문제
새 알림이 몇 시간 후 한꺼번에 옴시간 지정 요약즉시 전달 대신 요약 시간이 설정될 수 있음
밤·출근 중에만 알림이 조용함집중 모드·자동화·연결된 잠금화면시간·장소·화면에 따라 집중 모드가 켜질 수 있음
아이폰은 조용하고 애플워치에만 알림이 옴Apple Watch 알림 전달아이폰 잠금 상태에서 워치로 전달되는 정상 동작일 수 있음
화면 배너는 뜨는데 소리가 없음앱별 사운드·무음·사운드 및 햅틱표시와 소리 재생은 별도 설정
메일·메신저 앱을 열어야 새 내용이 보임앱 설정·연결·서버 측 알림·업데이트앱이 새 데이터를 가져오거나 푸시하는 경로를 추가 확인해야 함

먼저 테스트하는 방법: 알림이 오지 않는 앱을 하나 정해 다른 기기나 가족에게 테스트 메시지를 보내 달라고 요청합니다. 그다음 화면 잠금 상태와 잠금 해제 상태를 각각 비교하세요. 전화·SMS·인터넷 기반 앱 알림은 서로 다른 서비스이므로 한 종류만으로 전부를 판단하지 않습니다.

2. 첫 번째: '알림 허용'과 표시 위치 확인

  1. 아이폰에서 설정 → 알림으로 이동합니다.
  2. '알림 스타일' 또는 앱 목록에서 문제가 있는 앱을 선택합니다.
  3. 알림 허용이 켜져 있는지 확인합니다.
  4. 알림의 표시 위치에서 잠금 화면·알림 센터·배너 중 필요한 항목이 선택돼 있는지 확인합니다.
  5. 소리가 필요하면 앱별 사운드 설정을 확인하고, 홈 화면 아이콘 숫자가 필요하면 배지도 확인합니다.
  6. 테스트 알림을 다시 보내 결과를 비교합니다.

중요한 차이: '알림 허용'이 켜져 있어도 '잠금 화면' 표시가 꺼져 있다면 잠금화면에는 보이지 않을 수 있습니다. 반대로 배지가 없어도 배너는 표시될 수 있습니다. 서로 다른 기능이므로 모두 같은 스위치로 취급하지 마세요.

일부 앱에는 알림 종류를 따로 고르는 옵션이나 해당 앱으로 이동하는 알림 설정 링크가 있습니다. 운영체제 설정에서 문제가 없다면 앱 내부 설정도 확인해야 합니다.

공식 근거: Apple — iPhone에서 알림 설정 변경하기.

3. 두 번째: 알림이 사라진 게 아니라 '개수'로 접힌 경우

잠금화면 하단에 알림 숫자만 보이거나 다른 알림과 겹쳐 있으면 실제로는 전달됐지만 눈에 띄지 않을 수 있습니다.

  1. 설정 → 알림으로 이동합니다.
  2. '다음으로 표시' 또는 잠금화면 알림 표시 방식에서 개수 / 스택 / 목록을 확인합니다.
  3. 누락 여부를 시험할 때는 목록 표시로 바꾸고 새 알림을 기다려 봅니다.
  4. 잠금화면의 알림을 위아래로 쓸어보거나, 알림 스택을 펼쳐 봅니다.
  • 개수: 잠금화면 하단의 숫자 중심
  • 스택: 앱별 또는 시간대별 알림이 쌓여 보이는 방식
  • 목록: 여러 알림을 풀어 보여 주므로 누락 여부를 확인하기 쉬운 방식

또한 설정 → 알림 → 미리보기 표시가 '잠겨있지 않을 때' 또는 '안 함'이면 잠금화면에서 메시지 본문이 보이지 않을 수 있습니다. 이는 알림 자체가 오지 않는 것과 다릅니다. 개인정보 노출을 원치 않으면 미리보기 표시를 무조건 '항상'으로 변경할 필요는 없습니다.

공식 근거: Apple — iPhone 또는 iPad에서 알림 사용하기.

4. 세 번째: '시간 지정 요약' 때문에 늦게 오는지 확인

알림이 오전·저녁처럼 특정 시간에 몰려서 온다면 네트워크 장애보다 시간 지정 요약을 먼저 확인하는 것이 효과적입니다.

  1. 설정 → 알림 → 시간 지정 요약으로 이동합니다.
  2. 기능이 켜져 있는지, 알림을 묶어 받는 시간이 언제인지 확인합니다.
  3. 문제가 있는 앱이 요약 대상에 포함돼 있다면 해당 앱의 알림 전달을 즉시 전달로 변경합니다.
  4. 변경 후 같은 조건에서 테스트 알림을 보내 봅니다.

시간 지정 요약은 알림을 모아 지정한 시간에 보여 주기 위한 기능입니다. 따라서 새 메시지가 실제로 도착했는데도 알림 배너가 즉시 나타나지 않을 수 있습니다. 긴급하게 확인할 앱까지 전부 요약 대상으로 넣는 것은 피하는 편이 좋습니다.

공식 근거: Apple — iPhone에서 알림 설정 변경하기.

5. 네 번째: 집중 모드가 자동으로 켜지는지 확인

알림이 평소에는 잘 오다가 밤, 업무 시간, 특정 위치에서만 조용해진다면 집중 모드가 원인일 수 있습니다.

  1. 아이폰 제어 센터를 열고 집중 모드가 켜져 있는지 확인합니다.
  2. 켜져 있다면 잠시 끄고 테스트 메시지를 받아 봅니다.
  3. 설정 → 집중 모드에서 방해금지 모드·수면·업무·개인 시간 등의 설정을 열어봅니다.
  4. 문제가 생기는 시간이나 장소에 해당하는 일정 설정·자동화를 확인합니다.
  5. 집중 모드 안의 사람·앱 알림 허용 또는 무음 설정 목록을 확인합니다.
  6. 특정 잠금화면 배경을 선택할 때만 문제가 생긴다면 그 배경화면에 집중 모드가 연결돼 있는지 확인합니다.

특히 잠금화면과 연결된 집중 모드는 사용자가 배경을 바꾼 것만으로 켜질 수 있습니다. 집중 모드를 전부 지우기보다, 원인이 된 일정 또는 배경화면 연결을 조정하는 방법을 먼저 검토하세요.

예외: 특정 앱은 '긴급한 알림'을 지원하거나 집중 모드에서 별도로 허용될 수 있습니다. 모든 앱이 같은 방식으로 차단된다고 단정하면 안 됩니다.

공식 근거: Apple — 집중 모드에서 알림 허용하기, Apple — 방해금지 모드 설정.

6. 다섯 번째: 애플워치를 차고 있을 때 아이폰에 안 뜨는 이유

애플워치를 사용한다면 정상 동작을 오류로 오해하기 쉽습니다. Apple은 기본적으로 알림이 애플워치 또는 아이폰 중 한 기기에 표시되고, 둘 모두에 동시에 표시되지는 않는다고 설명합니다.

상황일반적인 알림 전달 위치
아이폰 잠금 해제 상태아이폰
아이폰 잠금 상태 또는 잠자기 상태 + 애플워치 잠금 해제 상태애플워치
애플워치가 잠겨 있거나 알림 전달 조건을 충족하지 않는 상황아이폰 등 상황별 설정 확인

따라서 아이폰 화면을 잠갔을 때만 휴대전화 진동이 없어졌다면 워치 화면에 알림이 쌓였는지 먼저 확인해 보세요.

애플워치의 개별 앱 알림 설정을 확인하려면 아이폰의 Watch 앱 → 나의 시계 → 알림으로 이동합니다. 해당 앱이 워치에서 알림을 어떻게 표시하도록 되어 있는지 비교하면 원인을 찾는 데 도움이 됩니다.

워치가 알림을 가로채는 것으로 보인다고 해서 기기를 초기화할 필요는 없습니다. 잠금 상태, 워치의 알림 설정, 집중 모드 설정부터 확인하는 편이 안전합니다.

공식 근거: Apple — Apple Watch의 알림, Apple — Apple Watch 알림 설정 변경하기.

7. 여섯 번째: '알림은 뜨는데 소리·진동만 없다'면

알림 배너나 아이콘 배지는 정상인데 소리가 나지 않는다면 알림 수신 실패가 아니라 사운드 설정 문제일 수 있습니다.

  • 설정 → 알림 → 해당 앱 → 사운드를 확인합니다.
  • 아이폰의 무음 모드가 켜져 있지 않은지 확인합니다. 모델에 따라 측면 스위치 또는 동작 버튼 설정 방식이 다릅니다.
  • 설정 → 사운드 및 햅틱에서 알림음·햅틱 관련 설정을 확인합니다.
  • 집중 모드가 켜져 있으면 특정 알림이 조용하게 전달될 수 있으므로 5번 절의 설정도 점검합니다.
  • 일부 앱은 내부에서 메시지 종류별 알림 소리를 별도로 관리합니다.

알람과 앱 푸시 알림은 다릅니다. 이 글은 알림 수신·표시 문제를 다루며, 시계 앱 알람이 울리지 않는 문제를 같은 방식으로 진단하면 안 됩니다.

공식 근거: Apple — iPhone 또는 iPad에서 알림 사용하기.

8. 특정 앱만 문제라면: 앱 내부 알림·네트워크·업데이트 확인

아이폰의 알림 권한·집중 모드·시간 지정 요약을 확인했는데도 한 앱에서만 문제가 지속된다면 다음을 차례대로 점검합니다.

  1. 문제가 있는 앱을 열어 앱 자체 알림 설정을 확인합니다. 메신저라면 채팅방별 알림 무음, 이메일이라면 계정별 알림 설정이 다를 수 있습니다.
  2. 인터넷 연결이 정상인지 확인합니다. 와이파이만 사용할 때 문제인지, 모바일 데이터에서 같은 문제가 재현되는지 비교합니다.
  3. App Store에서 해당 앱의 업데이트가 있는지 확인합니다.
  4. 아이폰을 재시동하고 테스트 알림을 다시 받아 봅니다.
  5. iOS 업데이트가 있는 경우 기기의 여유 공간·백업 상태를 확인하고 정식 업데이트를 검토합니다.
  6. 앱 서비스 자체 장애가 의심되면 해당 앱의 공식 공지·고객센터에서 서버 상태를 확인합니다.

앱 삭제·재설치는 마지막 수단으로 남겨 두는 편이 안전합니다. 일부 앱은 재설치 과정에서 로컬 데이터·대화·2단계 인증 상태가 영향을 받을 수 있습니다. 먼저 복원 가능 여부를 확인하세요.

'저전력 모드를 끄면 모든 푸시 알림이 반드시 해결된다', '백그라운드 앱 새로고침을 켜야 모든 알림이 도착한다' 같은 단정적인 설명도 피해야 합니다. 앱마다 사용하는 알림·데이터 갱신 방식이 다릅니다.

9. 10분 점검표: 변경은 한 번에 하나씩

순서확인·조치테스트 기준

10. 자주 묻는 질문

Q1. 아이폰에서 '알림 허용'을 켰는데도 잠금화면에 안 뜹니다.

해당 앱의 표시 위치에서 잠금 화면이 켜져 있는지, 잠금화면 표시 방식이 '개수'로 되어 있지 않은지 확인하세요. 이어서 시간 지정 요약과 집중 모드를 점검합니다.

Q2. 아이폰을 켜고 사용할 때는 알림이 뜨는데 잠그면 조용합니다.

애플워치를 착용 중인지 확인하세요. Apple 공식 안내에 따르면 아이폰 잠금 상태에서 워치가 잠겨 있지 않으면 알림이 워치로 전달되는 경우가 일반적입니다.

Q3. 알림이 몇 시간 뒤 한꺼번에 오는 것은 버그인가요?

반드시 버그는 아닙니다. 시간 지정 요약 대상인 앱의 알림은 설정한 시간에 모아서 도착할 수 있습니다. 해당 앱을 즉시 전달하도록 변경해 비교해 보세요.

Q4. 집중 모드를 껐는데 다음 날 같은 시간에 또 조용해집니다.

집중 모드의 일정 설정·자동화, 수면 집중 모드, 연결된 잠금화면을 확인하세요. 자동으로 다시 켜지는 설정이 남아 있을 수 있습니다.

Q5. 카카오톡만 알림이 안 오면 이 글의 방법으로 해결되나요?

아이폰 알림 권한과 집중 모드 등 공통 시스템 설정을 먼저 확인할 수 있습니다. 그러나 특정 채팅방의 무음 설정이나 카카오톡 자체 알림 설정은 카카오톡 앱 안에서 별도로 점검해야 합니다.

Q6. 배지는 뜨는데 알림 배너가 보이지 않습니다.

배지와 배너는 다른 표시 방식입니다. 해당 앱의 설정 → 알림에서 배너가 켜져 있는지 확인하세요. 집중 모드와 시간 지정 요약도 배너 표시 시점에 영향을 줄 수 있습니다.

Q7. 아이폰을 공장초기화해야 하나요?

아닙니다. 초기화는 데이터 손실 위험이 큰 조치입니다. 앱별 권한, 시간 지정 요약, 집중 모드, 애플워치, 앱 내부 설정과 연결 상태를 먼저 확인해야 합니다. 필요시 공식 Apple 지원을 통해 추가 진단을 받아보세요.

마무리: 가장 빨리 확인할 세 가지

아이폰 알림이 안 올 때는 ① 앱별 알림 허용 및 잠금화면 배너 → ② 시간 지정 요약·집중 모드 → ③ 애플워치 알림 전달 순서로 확인하세요. 특히 워치를 착용한 상태에서 아이폰이 잠기면 워치로 알림이 가는 현상은 정상 동작일 수 있습니다.

모든 앱이 동시에 문제인지, 한 앱만 문제인지, 배너만 없는지에 따라 확인해야 하는 설정도 달라집니다. 원인을 특정한 뒤 해당 항목만 변경하는 것이 안전하고 효율적입니다.
