2. 가장 먼저 확인할 것: 한국어 두벌식 입력 소스 추가

맥북은 Windows처럼 한영키가 물리적으로 없더라도 한국어 입력 소스만 등록되면 한글을 입력할 수 있습니다.

설정 순서

  1. 화면 왼쪽 위 Apple 메뉴()를 누릅니다.
  2. 시스템 설정으로 이동합니다.
  3. 사이드바에서 키보드를 선택합니다.
  4. 텍스트 입력 항목 옆 편집을 누릅니다.
  5. 입력 소스 목록에 한국어·두벌식이 있는지 확인합니다.
  6. 없으면 추가(+)를 누릅니다.
  7. 한국어를 선택한 뒤 두벌식을 고릅니다.
  8. 추가 → 완료로 설정을 마칩니다.
  9. 메뉴 막대 오른쪽의 입력 메뉴에서 두벌식을 선택하고 메모 앱에 한글을 입력해 봅니다.

Apple은 한글 입력 방식으로 두벌식, 세벌식, 세벌식(390), 공진청 로마자, 한컴 로마자 등을 제공한다고 안내합니다. 일반적인 한국어 PC 키보드 사용자는 두벌식부터 확인하면 됩니다.

영어 입력 소스도 필요합니다. 한국어와 함께 ABC·영어 등 라틴 문자 입력 소스를 등록했는지 확인하세요. 입력 소스가 하나밖에 없다면 '언어 전환'이 예상대로 작동하지 않을 수 있습니다.

공식: Apple — Mac용 한국어 입력기 사용 설명서, Apple — 다른 언어로 쓰기.

4. Caps Lock으로 한영 전환이 안 될 때

Caps Lock 키는 한글과 영어를 바꾸도록 설정할 수 있지만 해당 옵션이 꺼져 있다면 대문자 입력 키로만 동작할 수 있습니다.

설정 방법

  1. 시스템 설정 → 키보드로 이동합니다.
  2. 텍스트 입력 → 편집을 선택합니다.
  3. 한국어 두벌식과 ABC 등 라틴 입력 소스가 모두 있는지 확인합니다.
  4. 'Caps Lock 키로 [마지막으로 사용한 라틴 입력 소스] 전환' 옵션을 찾습니다.
  5. 이 옵션을 켭니다.
  6. 메모 앱을 열어 영문이 입력되는 상태에서 Caps Lock을 짧게 눌러 봅니다.
  7. 한국어로 바뀌었다면 다시 눌러 영어로 전환되는지 확인합니다.

옵션 자체가 없다면? Apple은 이 설정이 라틴이 아닌 입력 소스를 추가한 경우 표시된다고 안내합니다. 한국어 두벌식이 등록돼 있는지부터 확인하세요.

Caps Lock 키를 길게 누르면? Apple 공식 설명은 연속 대문자 입력을 활성화하려면 Caps Lock 기호가 나올 때까지 길게 누를 수 있다고 안내합니다. 짧은 누름과 긴 누름을 구분해 사용해야 예상치 못한 대문자 고정을 줄일 수 있습니다.

Caps Lock이 Control이나 다른 키로 재설정됐을 수도 있습니다. 이 경우 아래 보조 키 설정도 함께 확인하세요.

공식: Apple — 입력 소스 설정 및 Caps Lock 기능.

5. Fn·지구본 키를 눌렀는데 이모지 창만 나올 때

Fn 키 또는 지구본 키는 기본적으로 여러 동작 중 하나에 연결될 수 있습니다. 한영 전환이 목적이라면 '입력 소스 변경'을 지정해야 합니다.

  1. 시스템 설정 → 키보드로 이동합니다.
  2. 'fn 키를 누를 때 실행할 동작' 또는 '지구본 키를 누를 때 실행할 동작'을 찾습니다.
  3. 드롭다운 목록에서 입력 소스 변경을 선택합니다.
  4. 메모 앱에서 Fn 또는 지구본 키를 눌러 전환되는지 확인합니다.
  5. 목록에서 다른 언어가 먼저 나온다면 입력 소스 구성을 확인합니다.

같은 설정에는 이모지 및 기호 보기, 받아쓰기 시작 같은 다른 동작도 있으므로, Fn 키가 이모지를 연다고 해서 키보드 고장으로 판단할 필요는 없습니다.

주의: 일부 외장 키보드에는 Fn 키가 없거나 Mac이 기대하는 지구본 키와 다르게 동작할 수 있습니다. 이 경우 Control+Space를 먼저 테스트하는 편이 좋습니다.

공식: Apple — Mac 키보드 설정.

6. Control+Space가 안 될 때: 단축키 충돌과 입력 소스 확인

입력 메뉴에서는 한국어로 바뀌는데 Control+Space가 먹지 않는다면 입력 소스 단축키가 다른 기능으로 변경됐거나 현재 앱에서 가로채고 있을 가능성을 확인해야 합니다.

확인 순서

  1. 시스템 설정 → 키보드 → 키보드 단축키를 엽니다.
  2. 왼쪽 메뉴에서 입력 소스를 선택합니다.
  3. 이전 입력 소스 선택 등 입력 소스 전환 항목의 단축키를 확인합니다.
  4. 원래 의도한 Control+Space가 지정됐는지 살펴봅니다.
  5. 다른 앱·기능과 동일한 단축키를 쓰는지 확인합니다.
  6. 단축키 설정을 바꿨다면 메모 앱에서 다시 테스트합니다.
  7. 시스템 설정 → 키보드 → 텍스트 입력 → 편집에서 한국어와 영어 입력 소스가 실제 등록돼 있는지 확인합니다.

충돌 검증: 문제가 발생하는 앱을 종료한 뒤 메모 앱과 Safari 주소 입력창에서 같은 단축키를 테스트해 보세요. 특정 앱에서만 안 된다면 그 앱의 키보드 단축키와 입력기 호환성을 확인해야 합니다.

다른 앱의 단축키를 변경할 때는 업무용 도구에 이미 할당된 단축키를 무심코 덮어쓰지 마세요. 먼저 기존 설정을 기록한 후 조정하는 것이 안전합니다.

공식: Apple — macOS 키보드 단축키 사용하기, Apple — 다른 언어로 쓰기.

7. 한글로 바꿨는데 앱을 이동하면 영어로 돌아가는 이유

같은 맥북에서 메모 앱은 한글인데 브라우저는 영어로 입력되는 현상이 있습니다. 버그일 수도 있지만, 먼저 문서별 입력 소스 기억 기능을 확인하세요.

Apple 설정에는 '문서의 입력 소스로 자동으로 전환' 옵션이 있습니다. 이 기능을 켜면 서로 다른 문서에 입력했던 언어가 기억돼, 문서를 다시 열었을 때 해당 입력 소스로 돌아갈 수 있습니다.

확인 방법

  1. 시스템 설정 → 키보드 → 텍스트 입력 → 편집을 엽니다.
  2. 문서의 입력 소스로 자동으로 전환 항목을 찾습니다.
  3. 설정이 켜져 있다면 앱·문서를 바꿔 가며 현상을 관찰합니다.
  4. 모든 앱에서 일관된 입력 소스를 사용하고 싶다면 해당 옵션을 꺼서 비교 테스트합니다.
  5. 메모·브라우저·문서 편집기에서 한영 전환이 어떻게 바뀌는지 확인합니다.

주의: 이 설정은 둘 이상의 입력 소스를 추가했을 때 나타납니다. 문서별 언어 기억 기능을 끈다고 모든 앱의 입력기 문제가 자동 해결되는 것은 아닙니다.

공식: Apple — 입력 소스 설정: 문서의 입력 소스로 자동 전환.

8. 외장 키보드의 한영키가 맥북에서 안 먹을 때

Windows용 USB·블루투스 키보드를 Mac에 연결하면 오른쪽 Alt·한영 키·Caps Lock 위치 때문에 혼란이 생길 수 있습니다. 키 캡에 한영이라고 적혀 있어도 macOS가 그 키를 입력 소스 전환 단축키로 반드시 인식하는 것은 아닙니다.

진단 순서

  1. 맥북 내장 키보드에서 Control+Space가 작동하는지 확인합니다.
  2. 외장 키보드에서 Control+Space도 작동하는지 확인합니다.
  3. 외장 키보드의 Caps Lock이 대문자 전환으로 인식되는지 확인합니다.
  4. 시스템 설정 → 키보드 → 키보드 단축키 → 보조 키에서 현재 키보드별 설정을 확인합니다.
  5. 특정 보조 키가 다른 동작으로 지정돼 있다면 기존 배치를 기록한 뒤 조정합니다.
  6. Mac에 연결된 키보드를 다시 선택하고 입력 소스 전환을 테스트합니다.
  7. 키보드 제조사의 Mac 모드·Windows 모드 전환 안내가 있는지 확인합니다.

중요: 오른쪽 Alt를 무조건 Mac의 한영키로 바꾸는 보편적인 설정이 있는 것은 아닙니다. 제조사·배열·드라이버에 따라 키가 인식되는 방식이 달라집니다.

Apple은 키보드별로 Control·Option·Command·Caps Lock 등의 보조 키 동작을 재할당할 수 있다고 안내합니다. 우선 기본값으로 복원으로 키보드 맵핑 이상이 해결되는지도 비교할 수 있습니다.

9. 맥에서 한글이 자모로 분리되거나 글자가 이상하게 나올 때

한영 전환 자체가 안 되는 문제와 한글 입력 후 글자가 자음·모음으로 분리되는 문제는 별개입니다.

예를 들어 '안녕하세요'를 입력했는데 특정 앱·웹사이트에서 자모가 분리되거나 조합이 깨져 보인다면 다음을 확인합니다.

  1. 메뉴 막대의 입력 소스가 한국어 두벌식인지 확인합니다.
  2. 메모 또는 텍스트 편집기 같은 다른 앱에서도 같은 현상이 나타나는지 확인합니다.
  3. 특정 브라우저 입력창에서만 발생하면 해당 브라우저를 최신 버전으로 업데이트해 테스트합니다.
  4. 외부 서체·웹 입력기·확장 프로그램이 간섭하는지 확인합니다.
  5. 입력 소스를 ABC → 두벌식으로 다시 전환해 봅니다.
  6. 일시적인 문제라면 앱 종료·재실행 또는 Mac 재시동 후 비교합니다.

앱에 따라 한글 조합 처리 방식이 다를 수 있으므로 무조건 두벌식 입력 소스를 삭제하는 것보다 정상 동작하는 앱과 문제가 있는 앱의 차이를 확인하는 편이 좋습니다.

10. 두벌식 대신 로마자 입력으로 바뀌었다면?

맥의 한글 입력 소스에는 일반적인 두벌식 외에 여러 입력 방식이 있습니다. 사용자가 실수로 공진청 로마자나 한컴 로마자를 골랐다면 키 입력 결과가 기대와 다를 수 있습니다.

두벌식으로 돌아가는 법

  1. 시스템 설정 → 키보드 → 텍스트 입력 → 편집을 엽니다.
  2. 입력 소스 목록에서 현재 한국어 입력 방식 이름을 확인합니다.
  3. 필요하다면 한국어 → 두벌식을 추가합니다.
  4. 메뉴 막대 입력 메뉴에서 두벌식을 직접 선택합니다.
  5. 메모 앱에서 r → ㄱ, k → ㅏ 등 익숙한 두벌식 배열로 입력되는지 확인합니다.
  6. 사용하지 않는 한국어 입력 소스는 신중하게 제거해 전환 순서를 단순화할 수 있습니다.

한국어 입력 방식을 삭제하면 기존 문서가 지워지지는 않지만, 해당 입력기에서 사용하던 단축키나 설정이 달라질 수 있으니 현재 구성을 확인하고 진행하세요.

공식: Apple — 한국어 입력 소스 종류와 두벌식 설정.

11. 키보드 뷰어로 실제로 어떤 키가 눌리는지 확인

키보드 뷰어를 사용하면 현재 Mac이 인식한 입력 소스의 키 배열을 화면에서 확인할 수 있습니다.

  1. 메뉴 막대의 입력 메뉴를 클릭합니다.
  2. 키보드 뷰어 보기를 선택합니다.
  3. 현재 ABC 또는 두벌식 중 어느 입력 소스가 선택됐는지 확인합니다.
  4. 물리 키보드의 Shift·Option을 누를 때 화면의 키 배열이 어떻게 바뀌는지 관찰합니다.
  5. 입력 메뉴에서 두벌식으로 전환한 후 한글 입력 결과를 확인합니다.

키보드 뷰어는 한글 입력 소스가 제대로 선택되었는지, 실제 레이아웃이 기대와 맞는지 확인하는 데 유용합니다. 다만 모든 외장 키보드의 하드웨어 불량을 진단하는 검사도구는 아닙니다.

공식: Apple — Mac에서 키보드 레이아웃 보기.

12. 설정을 바꿔도 계속 안 되면: 안전한 해결 순서

문제가 해결되지 않을 때는 변경 범위가 작은 조치부터 큰 조치 순서로 진행하세요.

우선순위조치이유
1입력 메뉴에서 두벌식 직접 선택한국어 입력기 자체가 정상인지 확인
2Control+Space 테스트기본 입력 소스 전환 기능 확인
3Caps Lock·Fn 동작 설정 확인키보드 단축키 매핑 오류 구별
4메모·다른 앱에서 재시험특정 앱에 국한된 문제 파악
5외장 키보드 분리 후 테스트외부 키보드·배열 원인 확인
6입력 소스 구성 단순화불필요한 입력기와 전환 순서 제거
7앱·macOS 업데이트 후 재시험수정된 입력 관련 오류 반영
8Apple 지원 문의기기·운영체제 수준 문제 확인

임의로 시스템 라이브러리 파일을 삭제하거나, 출처 불명의 키보드 매핑 프로그램을 설치하는 방법은 권장하지 않습니다. 기본 macOS 기능과 공식 설정만으로 먼저 해결 가능한지 확인하세요.

특히 업무용 Mac이라면 회사의 보안·관리 정책에 의해 설정 변경이 제한될 수 있습니다. 시스템 설정 항목이 회색으로 표시되는 경우 IT 관리자에게 문의해야 할 수 있습니다.

13. 자주 묻는 질문 FAQ

Q1. 맥북 한영 전환 단축키는 무엇인가요?

Apple 공식 안내의 대표 단축키는 Control+Space입니다. Control+Option+Space로 다음 입력 소스를 선택할 수도 있고, Caps Lock·Fn/지구본 키를 사용하도록 설정할 수 있습니다.

Q2. Caps Lock을 눌러도 대문자만 나오고 한글로 안 바뀝니다.

시스템 설정 → 키보드 → 텍스트 입력 → 편집에서 한국어 입력 소스가 추가되어 있는지 확인하고 Caps Lock 키로 라틴 입력 소스 전환 옵션을 켜세요.

Q3. Fn 키를 누르면 이모지 선택창이 나옵니다.

시스템 설정 → 키보드에서 Fn/지구본 키 동작을 '입력 소스 변경'으로 바꾸세요.

Q4. 왜 Command+Space를 누르면 Spotlight만 열리나요?

macOS에서 Command+Space는 Spotlight 검색의 기본 단축키입니다. 한국어·영어 전환은 Control+Space 등의 입력 소스 단축키를 확인하세요.

Q5. 시스템 설정에 한국어 두벌식이 아예 없습니다.

시스템 설정 → 키보드 → 텍스트 입력 → 편집 → 추가(+) → 한국어 → 두벌식으로 등록하세요.

Q6. 한글 전환이 되는데 앱을 바꾸면 영어로 돌아갑니다.

'문서의 입력 소스로 자동으로 전환' 설정을 확인하세요. 여러 문서에서 입력 소스를 따로 기억하는 기능 때문에 그렇게 보일 수 있습니다.

Q7. 윈도우 키보드의 한영키를 맥북에서도 그대로 쓸 수 있나요?

키보드 모델과 Mac의 키 인식 방식에 따라 다릅니다. 먼저 Control+Space로 전환이 가능한지 확인하고 보조 키 설정·키보드 Mac/Windows 모드를 점검하세요.

Q8. 한글이 자음과 모음으로 분리됩니다. 한영 전환 문제인가요?

항상 그렇지는 않습니다. 한글 입력 후 조합·렌더링 문제일 수 있으니 메모 앱과 문제가 발생한 앱에서 비교해 입력 소스와 앱별 동작을 확인하세요.

Q9. 한국어 두벌식이 여러 개 나오는데 하나만 남겨도 되나요?

일반적으로 사용하지 않는 입력 소스는 제거해 목록을 단순화할 수 있습니다. 다만 기존 입력기별 설정과 사용자 단축키가 달라질 수 있으므로 현재 설정을 기록하고 진행하세요.

Q10. 업데이트 후에만 한영키가 안 됩니다. 초기화해야 하나요?

초기화는 우선순위가 아닙니다. 입력 소스 등록, Caps Lock·Fn 설정, 키보드 단축키, 문서별 자동 전환을 먼저 확인하세요. 그래도 해결되지 않으면 업데이트 상태와 Apple 지원 문서를 검토하세요.

  • ☐ ABC·영어 등 다른 입력 소스도 있다.
  • ☐ 메뉴 막대 입력 메뉴에서 두벌식 직접 선택이 된다.
  • ☐ Control+Space로 한영 전환을 시도했다.
  • ☐ Caps Lock 입력 소스 전환 옵션을 확인했다.
  • ☐ Fn·지구본 키 동작이 '입력 소스 변경'인지 확인했다.
  • ☐ Command+Space(Spotlight)와 혼동하지 않았다.
  • ☐ 문서별 입력 소스 자동 전환을 확인했다.
  • ☐ 문제가 특정 앱에서만 일어나는지 메모 앱과 비교했다.
  • ☐ 외장 키보드를 사용한다면 내장 키보드·보조 키 설정·Mac 모드를 점검했다.

  • macOS 업데이트 후 입력 소스 및 단축키 설정이 초기화될 수 있으므로, 변경사항 발생 시마다 설정을 재확인하고, 필요시 스크린샷 등 증빙을 남겨두세요.

설정 변경 전후 한영 전환 성공률이나 입력 오류 감소율을 직접 퍼센트로 계산해보면, 개선 효과를 수치로 확인할 수 있습니다.

자주 묻는 질문 (FAQ)

맥북에서 한글이 전혀 입력되지 않을 때 어떻게 해야 하나요?

시스템 설정 → 키보드 → 텍스트 입력에서 한국어 두벌식 입력 소스가 등록되어 있는지 확인하고, 없으면 추가해야 합니다.

Caps Lock 키로 한영 전환이 안 될 때 해결 방법은 무엇인가요?

시스템 설정 → 키보드 → 텍스트 입력에서 'Caps Lock 키로 마지막으로 사용한 라틴 입력 소스 전환' 옵션을 켜고, 한국어 두벌식과 영어 입력 소스가 모두 등록되어 있어야 합니다.

Fn(지구본) 키를 눌렀을 때 이모지 창만 열리는 문제는 어떻게 해결하나요?

시스템 설정 → 키보드에서 Fn 또는 지구본 키의 동작을 '입력 소스 변경'으로 지정해야 한영 전환 기능으로 사용할 수 있습니다.
