그런데 최근 아이폰에서는 스크린샷을 찍을 때 화면 전체가 편집 화면으로 뜨거나, 긴 웹페이지를 한 번에 저장하고 싶은데 ‘전체 페이지’가 나타나지 않는 문제가 있습니다. 이 글에서는 일반 캡처 → 저장 위치 확인 → 긴 페이지 저장 → 버튼 없이 찍기 → 안 될 때 점검까지 한 번에 정리했습니다.

확인 기준: 2026년 11월 4일. Apple 공식 지원 문서에 근거하며, 설명 중 iOS 26과 그 이전 버전의 화면 구성 차이를 구별합니다. 메뉴는 설치된 소프트웨어 버전과 기기에 따라 조금 다를 수 있습니다.

가장 흔한 실수는 버튼을 오래 누르는 것입니다. 캡처하려는 두 버튼을 길게 유지하지 말고 짧게 누른 뒤 바로 놓으세요. 측면 버튼을 오래 누르면 다른 기능이 나타날 수 있습니다.

2. iOS 26에서 스크린샷 찍으면 화면 전체가 뜨는 이유

iOS 26에서는 스크린샷의 기본 미리보기 방식이 달라졌습니다. Apple에 따르면 캡처 직후 화면에 스크린샷이 크게 나타나고, 이 화면에서 자르기·마크업·공유·저장 등의 작업을 수행할 수 있습니다. 반면 iOS 18 및 이전 버전에서는 왼쪽 아래에 작은 썸네일이 잠깐 보이는 방식이 일반적이었습니다.

이 화면이 불편하다면 작은 썸네일 미리보기로 바꿀 수 있습니다.

  1. 설정 앱을 엽니다.
  2. 일반을 선택합니다.
  3. 화면 캡처를 선택합니다.
  4. 전체 화면 미리보기를 끕니다.
  5. 다시 캡처해 왼쪽 아래에 작은 미리보기가 나타나는지 확인합니다.

이렇게 바꾸더라도 캡처 버튼 조합 자체가 변하는 것은 아닙니다. 다만 촬영 후 화면을 다루는 방식이 달라집니다.

Apple 공식 설명: iPhone 화면 캡처 설정 변경하기, iPhone에서 스크린샷 찍기.

3. 스크린샷 저장 위치는 어디인가요?

일반적인 스크린샷은 사진 앱의 스크린샷 항목에서 찾을 수 있습니다.

  1. 사진 앱을 엽니다.
  2. 모음을 탭합니다.
  3. 아래로 내려가 미디어 유형의 스크린샷을 선택합니다.
  4. 방금 촬영한 이미지가 있는지 확인합니다.

사진 앱의 화면 구성은 버전에 따라 다를 수 있습니다. 스크린샷 미리보기 화면에서 ‘파일에 저장’을 직접 선택했다면, 사진 앱 대신 파일 앱에서 선택한 저장 폴더를 확인해야 합니다.

중요한 구분: 일반 화면 캡처 이미지를 저장하는 것과, 사파리의 긴 웹페이지를 PDF 파일로 저장하는 것은 같은 작업이 아닙니다. 제출이나 공유 목적이라면 반드시 최종 파일 형식을 확인하세요.

Apple 공식 설명: iPhone에서 스크린샷 찍기.

4. 긴 웹페이지를 전체 페이지 스크린샷으로 저장하기

웹페이지에서 화면에 보이는 부분뿐 아니라 아래로 이어지는 내용을 한 번에 캡처하려면 전체 페이지 기능을 활용할 수 있습니다. Apple은 Safari 웹페이지를 대표적인 사용 사례로 안내합니다.

  1. Safari에서 저장할 웹페이지를 엽니다.
  2. 측면 버튼과 음량 높이기 버튼을 함께 짧게 누릅니다.
  3. 나타나는 스크린샷 미리보기를 엽니다.
  4. 편집 화면에서 전체 페이지를 선택합니다.
  5. 오른쪽의 긴 미리보기 영역을 위아래로 이동해 저장 범위를 확인합니다.
  6. 필요한 경우 자르기로 범위를 조정합니다.
  7. 저장 또는 공유 메뉴에서 제공되는 형식과 위치를 선택해 저장합니다.
  8. 결과 파일을 다시 열어 마지막 문단까지 포함되었는지 확인합니다.

PDF로 저장하려면?

긴 웹페이지를 문서 형태로 제출하거나 보관하려면 저장 옵션 중 PDF와 파일 앱 저장이 가능한지 확인하세요. 전체 페이지 캡처를 지원하는 앱·iOS 버전에 따라 화면에 표시되는 저장 형식과 위치가 다를 수 있습니다. 반드시 결과 파일을 열어 확장자가 PDF인지 확인해야 합니다.

‘전체 페이지’ 버튼이 안 보이는 경우

  • 먼저 Safari의 일반 웹페이지에서 같은 기능이 보이는지 시험합니다.
  • 카카오톡·은행 앱·게임 등 모든 앱이 긴 페이지 캡처를 지원하는 것은 아닙니다.
  • 웹페이지라 해도 동적으로 화면이 바뀌거나 일부 콘텐츠가 별도 영역에 스크롤되는 경우 원하는 범위를 얻기 어려울 수 있습니다.
  • 전체 페이지 항목이 없다면 일반 화면 캡처를 여러 장 찍는 방식과 혼동하지 마세요.

대표적인 오해: 스크린샷 전체 페이지 기능은 ‘어떤 앱이든 끝까지 자동 스크롤해서 저장하는 기능’이 아닙니다. 앱이 제공하는 화면 콘텐츠와 지원 범위에 좌우됩니다.

Apple 공식 설명: 전체 페이지 스크린샷과 편집.

5. 버튼 없이 스크린샷 찍기: 뒷면 탭 설정

전원 버튼이나 음량 버튼을 누르기 어렵다면 뒷면 탭에 스크린샷 동작을 지정할 수 있습니다. Apple은 이 기능을 iPhone 8 및 이후 지원 모델에서 안내하고 있습니다.

  1. 설정 → 손쉬운 사용 → 터치로 이동합니다.
  2. 뒷면 탭을 엽니다.
  3. 이중 탭 또는 삼중 탭을 선택합니다.
  4. 동작 목록에서 스크린샷을 선택합니다.
  5. 화면을 캡처하고 싶을 때 아이폰 뒷면을 두 번 또는 세 번 빠르게 탭합니다.

뒷면 탭이 작동하지 않는다면?

  • 모델이 기능을 지원하는지 먼저 확인합니다.
  • ‘이중 탭’과 ‘삼중 탭’ 중 어느 동작에 지정했는지 다시 확인합니다.
  • 두꺼운 케이스가 있으면 잠시 분리해 테스트합니다.
  • 의도치 않은 캡처가 잦다면 삼중 탭으로 변경하거나 사용하지 않는 동작을 없음으로 설정해 보세요.

뒷면 탭 기능은 화면 캡처에만 쓰는 기능은 아닙니다. 다른 손쉬운 사용 동작을 이미 지정했다면 기존 설정을 변경한다는 점을 확인하세요.

Apple 공식 설명: iPhone에서 뒷면 탭 사용하기.

6. 버튼이 고장 났을 때: AssistiveTouch로 캡처

AssistiveTouch는 화면에 띄운 가상 버튼으로 하드웨어 버튼 동작 일부를 대신할 수 있는 손쉬운 사용 기능입니다.

  1. 설정 → 손쉬운 사용 → 터치 → AssistiveTouch로 이동합니다.
  2. AssistiveTouch를 켭니다.
  3. 화면에 나타난 가상 버튼을 탭합니다.
  4. 메뉴에 스크린샷 항목이 없다면 상위 레벨 메뉴 사용자화에서 스크린샷 동작을 추가하거나 기존 항목에 배정합니다.
  5. 스크린샷 동작을 탭해 화면이 캡처되는지 시험합니다.

가상 버튼의 한 번 탭·두 번 탭·길게 누르기 등에도 사용자 지정 동작을 설정할 수 있습니다. 다만 기존에 사용하던 메뉴 동작이 바뀌지 않도록 주의하세요.

7. 스크린샷이 안 찍힐 때 원인별 해결 순서

증상 A: 화면이 꺼지거나 잠깁니다. 두 버튼을 동시에 짧게 누르는지 확인하세요. 측면 버튼이 먼저 길게 눌리면 원하는 캡처가 이루어지지 않을 수 있습니다. 버튼 대신 뒷면 탭으로 찍히는지 확인하면 버튼 조합 문제를 구분하는 데 도움이 됩니다.

증상 B: 버튼을 눌러도 아무 반응이 없습니다. 홈 화면처럼 일반적인 화면에서 다시 촬영해 보세요. 특정 앱에서만 나타나는 현상인지 확인하고, 기기를 다시 시작한 후 재시험합니다. 버튼 자체가 물리적으로 눌리지 않는다면 무리해서 강하게 누르지 마세요.

증상 C: 캡처는 됐는데 사진 앱에 없습니다. 먼저 스크린샷 미리보기에서 저장·공유·삭제 중 어떤 동작을 선택했는지 확인합니다. 파일 앱의 특정 폴더에 저장했다면 사진 앱의 스크린샷 항목에 보이지 않을 수 있습니다. 파일 앱과 사진 앱을 각각 확인하세요.

증상 D: 찍을 때마다 화면 전체가 편집 화면으로 뜹니다. 오류가 아니라 iOS 26의 전체 화면 미리보기 설정일 수 있습니다. 설정 → 일반 → 화면 캡처에서 전체 화면 미리보기를 끄면 작은 썸네일 형태로 전환할 수 있습니다.

증상 E: 화면의 특정 콘텐츠만 검게 나타납니다. 앱이나 콘텐츠의 보안·저작권 보호 정책으로 일부 캡처에 제한이 있을 수 있습니다. 모든 검은 화면이 카메라나 디스플레이 고장을 뜻하는 것은 아닙니다. 해당 서비스가 허용하는 공유·저장 방식을 이용하세요.

증상 F: 화면은 캡처되지만 ‘전체 페이지’가 없습니다. 일반 캡처 기능과 긴 문서 캡처 지원은 별개입니다. 우선 Safari에서 웹페이지를 열고 같은 문제가 발생하는지 비교하세요.

8. 스크린샷 자르기·글씨 표시·개인정보 가리기

스크린샷을 찍은 후에는 미리보기 또는 사진 앱의 편집 기능으로 다음 작업을 할 수 있습니다.

  • 자르기: 상단 주소창·불필요한 여백을 제거합니다.
  • 마크업: 문제를 설명할 부분에 동그라미·화살표·텍스트를 추가합니다.
  • 공유: 메시지·메일 등 원하는 앱으로 보냅니다.
  • 저장: 사진 앱 또는 파일 앱의 저장 위치를 확인합니다.

개인정보 주의: 계좌번호, 주소, 연락처, 인증번호, 예약번호가 포함된 화면은 공유 전에 반드시 확인하세요. 단순히 그림을 덧씌우는 표시 방식은 원본 데이터의 완전한 삭제를 보장하지 않습니다. 기밀성이 중요한 이미지라면 민감한 영역이 파일 자체에서 제거되거나 복원 불가능하도록 적절히 처리했는지 확인해야 합니다.

9. 자주 묻는 질문

Q. 아이폰 15·16·17에서도 캡처 버튼은 같나요?

홈 버튼이 없는 Face ID 아이폰의 기본 버튼 조합은 측면 버튼 + 음량 높이기입니다. 특정 기종의 카메라 제어 버튼과 혼동하지 마세요.

Q. 아이폰 SE는 왜 측면 버튼과 음량 높이기를 눌러도 안 되나요?

홈 버튼이 있는 모델은 일반적으로 홈 버튼과 측면 버튼을 함께 누릅니다. 일부 오래된 기종은 상단 버튼과 홈 버튼 조합을 사용합니다.

Q. 화면에 뜨는 큰 스크린샷 미리보기를 끌 수 있나요?

iOS 26에서는 설정 → 일반 → 화면 캡처 → 전체 화면 미리보기 끄기로 임시 썸네일 방식으로 변경할 수 있습니다.

Q. 버튼 없이 찍을 수 있나요?

지원되는 아이폰에서는 뒷면 탭이나 AssistiveTouch를 사용하세요. 버튼을 반복해서 강하게 누르기 전에 이 방법을 시험하는 것이 좋습니다.

Q. 긴 카카오톡 대화를 한 장으로 캡처할 수 있나요?

Safari의 전체 페이지 기능이 모든 앱의 대화 목록에 그대로 적용되지는 않습니다. 특정 앱에 전체 페이지 옵션이 없으면 지원하지 않을 수 있습니다. 사설 스크롤 캡처 도구를 쓰기 전에는 대화 내용과 개인정보 유출 위험을 고려하세요.

Q. 캡처 이미지가 JPG인지 PNG인지 어디에서 보나요?

사진 앱에서 이미지 정보를 확인하거나 파일 앱에 저장한 후 파일 유형·확장자를 확인하세요. 표시 형식은 스크린샷 설정과 저장 방식에 따라 달라질 수 있으므로 확장자를 추측하지 마세요.

Q. 스크린샷과 화면 녹화는 다른 기능인가요?

네. 스크린샷은 한 순간의 정지 화면이고 화면 녹화는 화면의 움직임을 동영상으로 저장합니다. 각각 저장 위치와 소리 설정이 다를 수 있습니다.

10. 스크린샷이 목적대로 저장됐는지 마지막 체크

  • ☐ 내 아이폰에 홈 버튼이 있는지 확인했다.
  • ☐ 버튼 두 개를 동시에 짧게 눌렀다.
  • ☐ iOS 26의 전체 화면 미리보기와 기존 썸네일 방식을 구분했다.
  • ☐ 화면 전체 캡처가 필요하다면 Safari 전체 페이지 지원 여부를 확인했다.
  • ☐ 파일을 다시 열어 마지막 내용까지 포함되는지 확인했다.
  • ☐ 사진 앱 또는 파일 앱에서 저장 위치·파일 형식을 확인했다.
  • ☐ 다른 사람에게 공유하기 전에 개인정보를 점검했다.

한 줄 결론: 홈 버튼 없는 아이폰은 측면 버튼 + 음량 높이기, 홈 버튼 있는 아이폰은 측면/상단 버튼 + 홈 버튼입니다. 긴 웹페이지는 Safari의 전체 페이지를, 버튼 없는 촬영은 뒷면 탭이나 AssistiveTouch를 이용하세요.

자주 묻는 질문 (FAQ)

아이폰에서 스크린샷을 찍는 기본 버튼 조합은 무엇인가요?

Face ID가 있는 아이폰은 측면 버튼과 음량 높이기 버튼을 동시에 짧게 누르고, 홈 버튼이 있는 아이폰 SE 등은 홈 버튼과 측면 또는 상단 버튼을 함께 짧게 눌러 찍습니다.

iOS 26에서 스크린샷 미리보기 방식이 어떻게 달라졌나요?

iOS 26에서는 스크린샷 직후 화면 전체가 크게 뜨는 미리보기 방식으로 바뀌었으며, 설정에서 작은 썸네일 미리보기로 변경할 수 있습니다.

긴 웹페이지를 전체 페이지 PDF로 저장하려면 어떻게 해야 하나요?

사파리에서 웹페이지를 연 뒤 스크린샷을 찍고 미리보기에서 '전체 페이지'를 선택해 범위를 조정한 후 PDF 형식으로 저장하면 됩니다.
