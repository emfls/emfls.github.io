Windows 11에서 Ctrl+C로 복사한 내용은 붙여넣어지는데 Windows 키+V를 눌러도 이전 기록이 보이지 않는 경우가 있습니다. 반대로 기록창은 열리지만 필요한 문장이 사라지거나, 두 컴퓨터 사이에서 복사한 내용이 동기화되지 않는 문제도 발생합니다. 이때는 복사 자체가 고장 난 상황과 클립보드 기록 기능이 꺼져 있는 상황을 먼저 구분해야 합니다.

Microsoft는 Windows 11 클립보드 기록을 통해 여러 개의 복사 내용을 다시 선택하고, 자주 쓰는 항목을 고정하며, 지원되는 항목을 계정과 연결된 다른 장치에 동기화할 수 있다고 안내합니다. 하지만 기록은 무제한 보관함이 아닙니다. 항목당 4MB, 최대 25개 항목 제한이 있고, PC 재시작 후에는 고정하지 않은 기록이 사라집니다.

이 글은 2026년 11월 1일 기준 Microsoft 공식 지원 문서를 토대로 설정, 오류 분류, 삭제 및 개인정보 보호 방법을 설명합니다. Windows의 메뉴 표기는 설치 언어와 업데이트 버전에 따라 조금 다를 수 있습니다.

2. Win+V로 클립보드 기록 켜는 방법

단축키로 켜기

  1. 메모장이나 브라우저 등 일반적인 Windows 프로그램을 엽니다.
  2. 키보드에서 Windows 로고 키+V를 함께 누릅니다.
  3. 클립보드 기록 기능이 꺼져 있다면 켜기 버튼을 선택합니다.
  4. 메모장에 ‘첫 번째 문장’과 ‘두 번째 문장’을 차례대로 입력합니다.
  5. 각 문장을 선택해 Ctrl+C로 순서대로 복사합니다.
  6. 다시 Windows+V를 눌러 기록 목록에 두 문장이 있는지 확인합니다.
  7. 붙여넣을 입력창에 커서를 두고 기록창에서 원하는 항목을 선택합니다.

Ctrl+V와 Windows+V는 다릅니다. Ctrl+V는 현재 복사된 항목을 붙여넣는 기본 명령이고, Windows+V는 과거에 복사한 여러 항목 중 하나를 선택하는 기록창을 엽니다.

Windows 설정에서 켜기

  1. 시작 → 설정을 엽니다.
  2. 시스템 → 클립보드를 선택합니다.
  3. 클립보드 기록 스위치를 켭니다.
  4. 이후 텍스트를 새로 복사해 기록에 나타나는지 확인합니다.

기록 기능을 켜기 전에 이미 복사했던 항목이 모두 소급해 저장되는 것은 아닙니다. 켜기 이후 새로 복사한 내용으로 테스트해야 합니다.

3. Ctrl+C와 Ctrl+V는 되는데 Win+V만 안 될 때

이 경우 키보드 전체가 고장 났다고 생각하기보다 기록 기능의 사용 가능 여부를 확인해야 합니다.

  1. 설정 → 시스템 → 클립보드에서 기록이 켜져 있는지 확인합니다.
  2. 설정이 꺼져 있다면 켜고 새 텍스트를 복사합니다.
  3. 메모장처럼 단순한 입력 환경에서 Windows+V를 시험합니다.
  4. 다른 Windows 단축키가 반응하는지 점검합니다. 예를 들어 Windows+I로 설정 앱을 열 수 있는지 확인합니다.
  5. 특수 키보드, 키 매핑 프로그램, 원격 접속 환경을 사용한다면 해당 키 입력이 다른 기능에 지정돼 있지 않은지 확인합니다.
  6. PC를 재시작한 뒤 다시 시험합니다. 단, 재시작으로 고정하지 않은 기존 기록은 사라질 수 있습니다.

설정 스위치가 회색으로 표시되거나 ‘조직에서 관리’와 같은 문구가 나오면 회사·학교의 보안 정책 때문일 수 있습니다. 이런 경우 관리 정책을 무리하게 우회하지 말고 장치 관리자나 IT 담당자에게 문의하세요.

중요: 클립보드 기록을 껐다 켜거나 Windows를 재시작하는 작업은 기록 보존 측면에서 손실이 발생할 수 있습니다. 필요한 문장이 기록에 남아 있다면 먼저 안전한 문서로 옮겨 두세요.

4. 복사한 내용이 바로 사라지는 이유: 기록 최대 25개

Microsoft는 클립보드 기록이 최대 25개의 복사 항목을 저장한다고 설명합니다. 새 항목이 계속 추가되면 고정되지 않은 오래된 항목이 자동으로 제거될 수 있습니다.

예를 들어 문서에서 주소, 전화번호, 안내 문구를 차례로 복사해 작업하다가 여러 번 새로운 텍스트를 복사하면 오래된 내용은 목록에서 빠질 수 있습니다.

자주 쓰는 문장은 고정하세요

  1. Windows+V를 눌러 기록창을 엽니다.
  2. 보관하고 싶은 문장을 찾습니다.
  3. 항목의 고정 아이콘이나 **더보기(…) → 고정(Pin)**을 선택합니다.
  4. 이후 Windows를 재시작하거나 다른 항목을 많이 복사해도 해당 항목이 고정 상태인지 확인합니다.

고정은 기록을 무제한으로 보관한다는 뜻이 아닙니다. 보관 가능한 목록과 앱·버전에 따른 동작 제한은 여전히 존재할 수 있습니다. 꼭 보존해야 하는 업무용 문구는 일반 문서나 안전한 텍스트 관리 도구에도 저장하세요.

오래된 항목이 없어진 뒤에는?

새 항목으로 밀려나거나 PC 재시작으로 삭제된 고정하지 않은 기록은 Windows 클립보드 기록창에서 다시 확인할 수 없을 수 있습니다. 복사했던 원본 문서나 이메일, 웹페이지로 돌아가 다시 복사하는 방법이 가장 현실적입니다.

5. ‘이미지를 복사했는데 기록에 안 남아요’: 4MB 제한

Microsoft의 공식 문서에 따르면 클립보드 기록에 추가되는 개별 항목의 크기 제한은 4MB입니다. 지원 형식에는 텍스트, HTML, 비트맵 이미지가 포함됩니다.

복사한 데이터기록에 남을 가능성점검 기준
일반 문자와 숫자지원되는 형식4MB 제한, 앱 정책
웹페이지에서 복사한 HTML지원되는 형식원본 서식·붙여넣는 앱의 지원
비트맵 이미지지원되는 형식이미지 데이터 크기
매우 큰 이미지제한에 걸릴 수 있음4MB를 넘는지 확인
파일 탐색기의 파일 자체일반적인 기록 목록과 구분 필요파일 복사와 클립보드 기록의 형식 차이
보안상 복사가 제한된 앱기록이 안 될 수 있음앱의 정책 확인

이미지가 기록에 없을 때 실험

  1. 메모장에서 짧은 문장을 복사해 기록되는지 확인합니다.
  2. 작은 이미지 한 장을 복사합니다.
  3. Windows+V에서 이미지 항목이 표시되는지 확인합니다.
  4. 큰 이미지에서만 실패한다면 항목 크기 제한이 원인일 수 있습니다.
  5. 목적이 이미지 공유라면 복사 대신 이미지 파일로 저장해 필요한 곳에 첨부합니다.

4MB는 파일의 확장자 이름으로 판단할 수 있는 수치가 아닙니다. 실제 클립보드에 들어가는 데이터 형식과 크기가 영향을 주므로, 이미지 파일의 압축 저장 용량과 클립보드 항목 크기를 동일하게 생각하면 안 됩니다.

6. 재부팅 후 기록이 사라지는 것은 정상인가요?

Microsoft는 PC를 재시작할 때 고정하지 않은 클립보드 기록은 삭제된다고 설명합니다. 따라서 아침에 복사했던 문장이 밤에 재부팅한 뒤 보이지 않는 것은 시스템 오류가 아니라 기본 보관 방식일 수 있습니다.

재부팅 전 확인할 사항

  • 꼭 필요한 문장은 문서에 따로 저장합니다.
  • 자주 쓰는 주소나 문구는 기록에서 고정할 수 있습니다.
  • 고객 정보나 계정 관련 비밀정보는 고정하지 않습니다.
  • 기록이 사라진 원인이 재부팅인지, 25개 초과로 밀려난 것인지 구분합니다.

고정된 항목은 왜 남나요?

클립보드 기록의 고정(Pin) 기능은 일반 기록과 다르게 유지되도록 설계됐습니다. 하지만 고정된 항목도 개인 정보 보호를 위해 필요할 때 사용자가 직접 고정 해제하고 삭제해야 합니다.

참고: 전원을 껐는지, 재시작했는지, 계정이 변경됐는지에 따라 실제 관찰되는 기록 목록이 다를 수 있습니다. 잃어버리면 안 되는 내용이라면 클립보드 기록만을 유일한 저장 장소로 사용하지 않는 것이 안전합니다.

7. 클립보드 항목 고정·삭제·전체 지우기

클립보드는 편리하지만 누군가 PC를 함께 사용한다면 개인정보가 의도치 않게 남을 수 있습니다. 필요 없는 기록은 정리하세요.

항목 하나만 삭제

  1. Windows+V를 눌러 기록을 엽니다.
  2. 지울 내용 옆의 **더보기(…)**를 선택합니다.
  3. 삭제를 누릅니다.
  4. 해당 항목이 목록에서 사라졌는지 확인합니다.

기록 전체 지우기

  1. 설정 → 시스템 → 클립보드로 이동합니다.
  2. 클립보드 데이터 지우기 항목에서 지우기를 선택합니다.
  3. 또는 Windows+V 기록창에서 모두 지우기를 선택할 수 있습니다.

고정된 항목은 따로 확인

Microsoft는 전체 지우기를 사용해도 고정된 항목은 제외된다고 설명합니다. 민감한 내용을 완전히 정리하려면 고정 목록을 확인하고 필요한 항목을 고정 해제한 뒤 개별 삭제하세요.

보안 관련 중요사항: 클립보드 기록을 삭제했다고 해서 이미 붙여넣은 문서, 채팅, 웹 서비스, 스크린샷, 다른 사용자의 복사본까지 삭제되는 것은 아닙니다. 삭제 범위는 클립보드에 보관된 기록을 중심으로 이해해야 합니다.

공식 출처: Microsoft — 클립보드 데이터 지우기

8. 다른 Windows PC와 클립보드 기록 동기화하기

Windows 11의 클립보드 기록은 지원되는 설정과 계정 조건에서 클라우드를 통해 다른 장치에 동기화할 수 있습니다.

  1. 설정 → 시스템 → 클립보드를 엽니다.
  2. 장치 간 클립보드 기록 또는 이와 유사한 동기화 항목을 확인합니다.
  3. 동기화 스위치를 켬으로 변경합니다.
  4. Microsoft 계정 또는 회사 계정으로 로그인 상태를 확인합니다.
  5. 두 Windows 장치에서 동일한 계정을 사용하는지 점검합니다.
  6. 보이는 경우 복사하는 텍스트 자동 동기화 또는 수동 동기화 옵션 중 원하는 방식을 선택합니다.
  7. 기밀 정보가 아닌 시험용 텍스트를 복사해 다른 장치에 나타나는지 확인합니다.

자동 동기화와 수동 동기화의 차이

자동 동기화는 지원되는 텍스트 항목을 복사할 때 다른 장치로 동기화하는 방식입니다. 수동 동기화를 선택한 경우에는 Windows+V를 열어 동기화하려는 항목의 동기화 버튼을 별도로 눌러야 할 수 있습니다.

공식 설명은 수동 동기화 시 텍스트가 클라우드에 업로드된다고 명시합니다. 즉, 기능을 사용하면 일부 복사 내용이 PC 내부에만 남는 것이 아니라 계정과 연결된 서비스로 전송될 수 있습니다.

중요: 기기 간 동기화 메뉴 자체가 나타나지 않는다면 현재 Windows 버전, 로그인 계정, 회사·학교 정책과 기능 제공 조건을 확인해야 합니다. 앱마다 같은 내용이 반드시 동기화되는 것은 아닙니다.

9. 동기화했는데 다른 PC에서는 왜 보이지 않을까요?

‘클립보드 기록 사용’과 ‘다른 장치와 동기화’는 서로 다른 설정입니다. 로컬 기록이 정상이어도 클라우드 동기화가 꺼져 있거나 로그인 계정이 다르면 다른 PC에 기록이 나타나지 않을 수 있습니다.

순서대로 점검

  1. 두 컴퓨터 모두 Windows+V에서 로컬 기록이 정상 표시되는지 확인합니다.
  2. 설정 → 시스템 → 클립보드의 동기화 옵션을 확인합니다.
  3. 두 장치가 동일한 Microsoft 계정 또는 허용된 회사 계정으로 로그인돼 있는지 확인합니다.
  4. 네트워크가 정상적인지 확인합니다.
  5. 수동 동기화 방식이라면 복사 후 항목별 동기화 조작이 필요한지 확인합니다.
  6. 테스트는 짧은 일반 텍스트를 이용합니다. 큰 이미지나 앱에서 보호하는 콘텐츠는 비교 대상으로 적합하지 않을 수 있습니다.
  7. 회사 PC의 동기화 기능이 비활성화돼 있다면 관리 정책을 확인합니다.

모든 복사 내용이 무조건 전송되는 것은 아닙니다

Microsoft 공식 설명은 동기화 방식과 항목의 형식·크기 등에 제약이 있음을 안내합니다. 단순히 두 PC에서 같은 계정을 쓰는 것만으로 모든 복사 내용이 저장되거나 복원된다고 기대해서는 안 됩니다.

또한 공유 컴퓨터나 공공장소 PC에서는 클립보드 동기화를 함부로 활성화하지 마세요. 민감한 업무 데이터는 내부 규정에서 허용하는 방식으로만 전송해야 합니다.

10. 갤럭시 스마트폰과 Windows 클립보드 동기화는 같은 기능인가요?

Windows의 두 PC 사이 클립보드 기록 동기화와 휴대전화의 장치 간 복사·붙여넣기는 연결 방식과 지원 조건이 다른 기능입니다.

휴대전화와 연결(Phone Link)을 사용하는 경우

일부 지원되는 Android 장치에서는 Microsoft의 휴대폰과 연결과 Windows와 연결(Link to Windows) 기능을 이용해 PC와 휴대전화 사이의 복사·붙여넣기를 사용할 수 있습니다.

  1. PC에서 휴대폰과 연결 앱을 실행합니다.
  2. 지원되는 Android 기기를 연결합니다.
  3. 앱의 설정 → 기능에서 장치 간 복사 및 붙여넣기 기능이 제공되는지 확인합니다.
  4. 지원 기기에서 기능을 활성화합니다.
  5. 휴대전화에서 간단한 문장을 복사한 뒤 PC에 붙여넣기를 시험합니다.

Microsoft는 이 기능을 지원되는 특정 삼성·OPPO 등의 Android 기기에서 제공한다고 안내합니다. 모든 갤럭시·모든 Android 스마트폰에 동일한 기능이 있는 것은 아닙니다.

동기화 오류일 때

Microsoft는 지원 기기에서 양쪽 앱을 다시 열고 연결 상태를 확인한 뒤, 필요하면 PC를 재시작해 보라고 설명합니다. 큰 텍스트가 전달되지 않으면 더 작은 내용으로 나눠 시험하는 방법도 제시합니다.

주의: 휴대전화와 연결의 복사·붙여넣기가 작동하더라도 Windows의 Win+V 기록 전체가 그대로 휴대전화에 표시된다는 뜻은 아닙니다. 기능 설명과 지원 단말 조건을 구분해야 합니다.

11. Ctrl+V 자체가 안 될 때는 클립보드 기록 오류와 구분

Win+V 기록이 안 보이는 문제와 현재 복사한 항목도 Ctrl+V로 붙여넣지 못하는 문제는 다릅니다.

기초 비교 테스트

  1. 메모장을 엽니다.
  2. 간단한 한글 또는 영문 문장을 입력합니다.
  3. 해당 문장을 선택하고 Ctrl+C로 복사합니다.
  4. 아래 빈 줄에서 Ctrl+V로 붙여넣습니다.
  5. 메모장에서는 정상인데 다른 앱에서만 실패하면 해당 앱의 입력 제한·권한·서식을 점검합니다.
  6. 메모장에서도 실패한다면 복사·붙여넣기 키가 제대로 입력되는지와 원격 접속·키보드 프로그램 상태를 확인합니다.

서식이 바뀌는 경우

웹페이지에서 복사한 문장이 다른 앱에 붙여넣어질 때 글꼴이나 링크 형태가 달라질 수 있습니다. Microsoft는 장치 간 복사·붙여넣기 설명에서 앱마다 텍스트 서식 처리 능력이 달라 서식이 손실될 수 있다고 안내합니다.

따라서 서식이 다른 것이 곧 복사 실패는 아닙니다. 서식이 중요하면 원본 앱의 붙여넣기 옵션이나 문서 파일 자체를 이용하세요.

비밀번호 입력창에서는 다르게 동작할 수 있습니다

일부 보안 입력창, 원격 화면, 특수 프로그램은 복사·붙여넣기 또는 기록 표시를 제한할 수 있습니다. 이런 제한을 해제하는 비공식 프로그램을 설치하기보다 해당 앱의 정상 지원 범위를 확인해야 합니다.

12. 클립보드에 개인정보가 남지 않도록 관리하기

클립보드 기록은 문장이나 이미지의 재사용을 편하게 해 주지만, 잘못 관리하면 개인정보 노출 위험이 생길 수 있습니다. 특히 복사한 비밀번호·인증번호·주민등록번호·계좌번호·고객 연락처가 기록에 남아 있는지 주의해야 합니다.

사용 전 고려할 점

  • 민감한 문자열을 클립보드에 장기간 고정하지 않습니다.
  • 다른 PC와 클립보드 동기화가 필요 없다면 장치 간 동기화 기능을 끕니다.
  • 회사나 공용 PC에서는 조직의 정책과 개인정보 처리 규정을 우선합니다.
  • 클립보드 기록 전체를 지워도 고정된 항목이 남을 수 있으므로 목록을 별도로 확인합니다.
  • 기밀 정보를 붙여넣은 문서나 메신저 대화는 클립보드에서 지워도 그대로 남을 수 있습니다.
  • 긴 비밀번호는 가능한 경우 신뢰할 수 있는 암호 관리자를 이용합니다.

중요한 구분: Microsoft 공식 안내는 Windows 클립보드의 기록 삭제 방법을 설명하지만, 이것이 모든 응용 프로그램에 남은 복사본까지 삭제해 주는 기능은 아닙니다. 민감한 내용을 잘못 전송했다면 해당 앱에서 별도로 삭제·회수 가능 여부를 검토해야 합니다.

13. 자주 묻는 질문

Q. Windows+V를 누르면 아무것도 없다고 나옵니다.

설정 → 시스템 → 클립보드 → 클립보드 기록이 켜져 있는지 확인하고, 메모장에서 새 문장 두 개를 차례로 복사해 보세요. 기존 복사 내용이 자동으로 기록에 소급 저장되지는 않을 수 있습니다.

Q. Win+V와 Ctrl+V는 왜 다른가요?

Ctrl+V는 현재 복사한 내용을 붙여넣는 기능이고, Win+V는 이전에 복사한 여러 항목 중 하나를 선택하는 클립보드 기록창을 여는 기능입니다.

Q. 기록은 몇 개까지 저장되나요?

Microsoft 공식 안내 기준 최대 25개입니다. 새로운 내용이 추가되면 고정되지 않은 오래된 항목은 제거될 수 있습니다.

Q. 4MB가 넘는 이미지를 복사할 수 없나요?

현재의 기본 복사 동작과 클립보드 기록에 저장되는 것은 다를 수 있습니다. Microsoft는 기록의 개별 항목 크기 제한을 4MB라고 설명합니다. 큰 이미지를 재사용할 목적이라면 이미지 파일로 저장하는 방법을 고려하세요.

Q. 재시작하면 클립보드 기록이 전부 사라지나요?

Microsoft 안내에 따르면 고정하지 않은 항목은 재시작할 때 지워집니다. 고정된 항목은 유지될 수 있지만, 이것도 중요한 문서의 유일한 백업 수단으로 이용해서는 안 됩니다.

Q. 전체 지우기를 했는데 어떤 항목은 계속 보여요.

전체 지우기는 고정된 항목을 제외할 수 있습니다. 고정 상태를 해제하고 해당 항목을 개별 삭제해 보세요.

Q. 클립보드 기록을 Google Drive나 메일처럼 다른 기기에서 볼 수 있나요?

지원되는 Windows의 장치 간 동기화를 설정하면 일부 텍스트를 동일한 계정의 다른 장치에서 사용할 수 있습니다. 하지만 모든 복사 내용이 보관되는 범용 클라우드 저장소와 같지는 않습니다.

Q. 갤럭시에서도 Windows의 기록 25개를 그대로 볼 수 있나요?

일부 지원 기기에서 휴대폰과 연결의 장치 간 복사·붙여넣기가 가능하지만, PC의 Win+V 목록 자체가 스마트폰에 똑같이 제공되는 기능이라고 단정하면 안 됩니다.

Q. 회사 PC에서 클립보드 동기화 버튼이 비활성화돼 있습니다.

회사·학교 관리 기기에서는 관리자 정책에 따라 기능이 제한될 수 있습니다. 장치에서 허용되지 않은 설정을 임의로 우회하지 말고 IT 관리자에게 문의하세요.

14. 문제 해결 순서와 최종 체크리스트

  • ☐ Win+V가 열리는지, Ctrl+V만 되는지 구분했습니다.
  • ☐ 설정 → 시스템 → 클립보드에서 기록을 켰습니다.
  • ☐ 기능을 켠 뒤 새 문장을 복사해 목록에 나타나는지 테스트했습니다.
  • ☐ 기록이 사라졌다면 25개 제한이나 PC 재시작 여부를 확인했습니다.
  • ☐ 기록되지 않은 큰 항목이 4MB 제한에 해당할 수 있는지 확인했습니다.
  • ☐ 자주 쓰는 일반 문구만 고정하고 비밀번호·인증번호는 고정하지 않았습니다.
  • ☐ 삭제할 때 전체 지우기뿐 아니라 고정된 항목도 확인했습니다.
  • ☐ 다른 PC 동기화가 필요하면 계정과 동기화 방식을 확인했습니다.
  • ☐ 수동 동기화 방식이라면 항목별로 별도 동기화가 필요한지 확인했습니다.
  • ☐ 회사·학교 PC라면 관리 정책을 우회하지 않았습니다.
  • ☐ 스마트폰과 복사·붙여넣기는 별도의 지원 기기 조건이 있음을 확인했습니다.
  • ☐ 정말 중요한 문장은 클립보드가 아닌 안전한 별도 문서에 저장했습니다.

결론: 윈도우11 클립보드 기록이 보이지 않으면 먼저 Windows+V의 ‘켜기’ 또는 설정 → 시스템 → 클립보드를 확인하세요. 기록이 갑자기 사라졌다면 25개 항목 제한이나 PC 재시작이 원인일 수 있고, 다른 PC로 내용이 넘어가지 않는다면 동기화 설정과 로그인 계정을 따로 점검해야 합니다. 기록 전체 지우기를 실행할 때도 고정된 항목은 별도로 정리해야 한다는 점을 기억하는 것이 좋습니다.
