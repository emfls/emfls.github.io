MacBook 또는 iMac의 Wi-Fi는 연결됐는데 Safari에서 인터넷이 열리지 않거나, 집 공유기의 이름이 안 보이거나, 비밀번호를 제대로 입력해도 연결할 수 없을 때가 있습니다. 이때 무선 네트워크에 연결하지 못하는 문제와 공유기까지는 연결됐지만 외부 인터넷이 안 되는 문제를 먼저 나눠야 합니다. 한 번에 DNS, 보안 설정, 네트워크 위치를 모두 변경하면 원인 파악이 어려워지기 때문입니다.

Apple 공식 고객지원은 Mac의 Wi-Fi 문제에서 네트워크 상태 확인, 다른 네트워크 테스트, 재시동, VPN 및 보안 소프트웨어 점검, 공유기 설정, 무선 진단 등을 안내합니다. 이 글은 2026년 11월 1일 기준 공식 자료를 바탕으로, 위험도가 낮은 점검부터 DHCP·DNS 및 기타 세부 설정까지 순서대로 설명합니다.

2. Wi-Fi를 껐다 켜고 다른 기기로 비교하는 5분 점검

  1. Mac 메뉴 막대 또는 제어 센터에서 Wi-Fi가 켜져 있는지 확인합니다.
  2. 연결하려는 네트워크 이름(SSID)이 맞는지 확인합니다.
  3. Wi-Fi를 껐다가 다시 켭니다.
  4. 같은 Wi-Fi에 연결된 휴대전화로 일반 웹페이지를 열어봅니다.
  5. Mac에서는 다른 웹사이트와 다른 앱에서도 인터넷이 안 되는지 확인합니다.
  6. 가능하면 모바일 핫스팟이나 다른 공유기를 이용해 교차 테스트합니다.
  7. 중요한 작업을 저장한 뒤 Mac을 정상 재시동합니다.

Mac에서 와이파이 표시가 연결됨으로 나와도 공유기의 외부 인터넷 회선이 끊겼다면 웹페이지는 열리지 않을 수 있습니다. Wi-Fi 연결과 인터넷 연결은 별개의 상태입니다.

핫스팟에서 정상 작동한다면 해당 공유기나 네트워크 구성을 의심할 근거가 생기지만, Mac의 모든 문제가 없다는 뜻은 아닙니다. 핫스팟 이용에는 통신사 데이터 요금과 사용량 제한이 있을 수 있습니다.

3. macOS 시스템 설정에서 네트워크 상태를 확인하는 방법

  1. Apple 메뉴 → 시스템 설정을 엽니다.
  2. 왼쪽에서 네트워크를 선택합니다.
  3. Wi-Fi 서비스가 활성화돼 있고 현재 연결 상태인지 확인합니다.
  4. Wi-Fi와 현재 네트워크의 세부사항을 차례로 확인합니다.
  5. 사용 중인 IP 주소와 라우터 주소가 표시되는지 확인합니다.
  6. VPN 또는 이더넷 연결이 동시에 있는지도 살펴봅니다.

Apple은 네트워크 상태를 서비스마다 표시하며 정상적으로 연결된 서비스는 초록색으로 나타날 수 있다고 설명합니다. 다른 색상은 활성화 상태나 구성 상태를 구분할 때 사용됩니다.

하지만 초록색이라고 해서 웹사이트나 인터넷 서비스 제공업체의 연결까지 검증됐다는 의미는 아닙니다. Safari가 웹페이지를 열 수 있는지, 공유기와 통신사 상태가 어떤지도 함께 확인해야 합니다.

4. 비밀번호는 맞는데 계속 연결이 안 될 때

Wi-Fi 암호를 여러 번 입력해도 실패한다면 다음 내용을 확인하세요.

  • 공유기 이름이 비슷한 다른 네트워크를 선택하지 않았는지
  • 최근 공유기 관리자나 통신사가 암호를 변경했는지
  • 대문자·소문자와 특수문자·숫자를 정확히 입력했는지
  • 사용 중인 Mac과 라우터가 같은 보안 방식을 지원하는지
  • 회사·학교 무선망이 별도의 계정 인증이나 인증서를 요구하는지
  • 숨겨진 네트워크라면 SSID와 암호를 직접 입력해야 하는지

Apple은 정확한 비밀번호와 무선 보안 유형, 네트워크 범위, MAC 주소 접근 제어 여부 등을 확인하도록 안내합니다. 가정용 공유기의 비밀번호를 입력하는 방식과 기업용 802.1X 인증은 다를 수 있으므로 함께 취급하면 안 됩니다.

암호가 확실하고 기존 연결 정보가 오래된 상태라면 다음 절에서 설명하는 네트워크 지우기 후 재연결을 시도할 수 있습니다. 그러나 다시 입력할 비밀번호를 모르는 상황이라면 먼저 관리자에게 확인해야 합니다.

5. 저장된 Wi-Fi 네트워크를 지우고 다시 연결하기

  1. Apple 메뉴 → 시스템 설정 → Wi-Fi로 이동합니다.
  2. 연결된 네트워크의 **세부사항(Details)**을 클릭합니다.
  3. **이 네트워크 지우기(Forget This Network)**를 선택합니다.
  4. 사용 가능한 Wi-Fi 목록으로 돌아갑니다.
  5. 올바른 네트워크를 다시 선택합니다.
  6. 비밀번호를 다시 입력하고 연결합니다.
  7. 웹사이트나 다른 인터넷 앱이 정상 작동하는지 확인합니다.

현재 연결되지 않은 과거 네트워크를 제거하려면 시스템 설정 → Wi-Fi → 고급 → 알고 있는 네트워크의 해당 이름 옆 더보기 메뉴에서 목록에서 제거를 선택할 수 있습니다.

네트워크 지우기는 Mac에 저장된 해당 네트워크의 접속 정보를 없애는 절차입니다. 공유기 자체를 초기화하거나 모든 주변 Wi-Fi를 삭제하는 것과 다릅니다. 비밀번호나 회사 인증 정보를 먼저 확보하고 진행하세요.

공식 출처: Apple — Wi-Fi 네트워크 설정 재설정 또는 제거

6. 공유기 또는 인터넷 회선에 문제가 있을 때

휴대전화와 다른 PC까지 같은 Wi-Fi에서 인터넷에 접속하지 못한다면 통신사나 공유기 문제를 먼저 확인해야 합니다.

  1. 공유기·모뎀의 전원과 케이블을 확인합니다.
  2. 인터넷(WAN) 연결 표시등이 정상인지 제조사 설명서를 살펴봅니다.
  3. 본인이 관리하는 장치라면 제조사가 안내한 방법으로 정상 재시동합니다.
  4. 모뎀과 라우터가 완전히 부팅된 후 다시 연결합니다.
  5. 유선 이더넷을 쓸 수 있다면 유선 인터넷도 테스트합니다.
  6. 같은 증상이 계속되면 **인터넷 서비스 제공업체(ISP)**에 회선 장애가 있는지 문의합니다.
  7. 라우터 펌웨어가 오래됐다면 제조사 공식 안내에 따라 업데이트를 검토합니다.

Apple은 네트워크 연결이 안 될 때 모뎀·라우터 등 외장 기기를 점검하고, 라우터가 최신 펌웨어와 권장 설정을 사용하도록 안내합니다.

공용·기업 네트워크에서 사용하는 공유기를 허락 없이 껐다 켜면 여러 사용자의 업무가 중단될 수 있습니다. 공유기를 소유하거나 관리하는 권한이 없는 경우 네트워크 관리자에게 문의하세요.

7. Wi-Fi 권장 사항과 무선 진단 실행하기

Mac에는 네트워크 상태를 점검할 수 있는 무선 진단(Wireless Diagnostics) 도구가 있습니다. Apple은 Wi-Fi에 연결할 수 있지만 웹페이지나 이메일, 스트리밍 사용에 문제가 있는 경우 이를 활용하도록 안내합니다.

Wi-Fi 권장 사항 확인

  1. 메뉴 막대에서 Wi-Fi 아이콘을 클릭합니다.
  2. Wi-Fi 권장 사항이 나타나는지 확인합니다.
  3. 표시된다면 선택해 설명과 권장 조치를 읽습니다.

Wi-Fi 권장 사항이 항상 나타나는 것은 아닙니다. Apple은 개인용 핫스팟이나 일부 기업용 네트워크에서는 제공되지 않는다고 설명합니다.

무선 진단 사용

  1. 작업 내용을 저장한 뒤 가능한 경우 열린 앱을 종료합니다.
  2. 문제가 되는 Wi-Fi에 연결을 시도합니다.
  3. Option 키를 누른 채 메뉴 막대의 Wi-Fi 아이콘을 클릭합니다.
  4. 무선 진단 열기를 선택합니다.
  5. 화면 안내에 따라 네트워크 분석을 진행합니다.
  6. 결과의 오류 요약과 권장 해결 방법을 확인합니다.

Apple은 무선 진단이 네트워크 설정을 직접 변경하지 않는다고 안내합니다. 따라서 출처 불분명한 네트워크 초기화 명령을 실행하기보다 먼저 시도하기 좋은 방법입니다.

필요한 경우 /var/tmp 위치에 저장되는 WirelessDiagnostics 진단 보고서를 관리자나 Apple 지원에 제공할 수 있습니다. 보고서에는 네트워크 환경 정보가 있을 수 있으므로 공개 게시판에는 함부로 게시하지 않는 편이 안전합니다.

8. IP 주소가 이상하면 DHCP 임대 갱신

Mac이 공유기에 연결된 것으로 표시되지만 IP 주소 할당이나 라우터 주소가 비정상적이라면 DHCP 설정을 살펴볼 수 있습니다. DHCP는 일반적으로 공유기에서 연결된 장치에 IP 주소를 자동 할당하는 기술입니다.

갱신 순서

  1. 시스템 설정 → 네트워크 → Wi-Fi로 들어갑니다.
  2. 사용 중인 네트워크의 세부사항을 클릭합니다.
  3. TCP/IP 항목을 선택합니다.
  4. IP 주소와 라우터 주소를 확인합니다.
  5. DHCP를 사용하는 환경이라면 DHCP 임대 갱신을 누릅니다.
  6. 변경 내용 적용 후 웹사이트 접속을 다시 시험합니다.

Apple의 TCP/IP 설정 문서는 IPv4 자동·수동 구성과 DHCP 임대 갱신을 설명합니다. 임대 갱신은 주소 할당 문제를 점검하는 방법이지 DNS·ISP 장애·VPN 문제를 모두 해결하는 기능은 아닙니다.

업무용 Mac 주의: 회사에서 고정 IP나 특수 네트워크 프로필을 제공한 경우 ‘자동’으로 임의 변경하면 연결이 끊길 수 있습니다. 관리자와 확인한 뒤 진행하세요.

9. DNS 서버 문제는 언제 확인해야 하나요?

DNS는 도메인 이름을 주소로 변환할 때 사용됩니다. 특정 사이트 이름으로 접속할 때만 문제가 있거나, VPN 및 네트워크 설정을 변경한 직후부터 웹 접속이 불안정하다면 DNS를 점검할 수 있습니다.

안전한 점검 순서

  1. 다른 웹사이트도 열리지 않는지 확인합니다.
  2. 다른 브라우저 또는 앱에서 같은 문제가 나타나는지 비교합니다.
  3. DNS를 수동 설정한 적이 있는지 확인합니다.
  4. 시스템 설정 → 네트워크 → Wi-Fi → 세부사항 → DNS를 엽니다.
  5. 현재 등록된 DNS 서버 주소를 기록합니다.
  6. 사용자가 직접 변경한 값이라면 원래 설정으로 복원할 필요가 있는지 검토합니다.
  7. 기업·학교 네트워크라면 DNS를 바꾸기 전에 관리자에게 문의합니다.

Apple은 네트워크 서비스의 DNS 설정에서 서버를 추가·제거하는 방법을 안내합니다. 하지만 인터넷이 안 된다고 무조건 공개 DNS 주소를 바꾸면 해결된다는 뜻은 아닙니다.

주의: 회사 내부 시스템, 학교 사이트, VPN 전용 주소, 자녀 보호 필터 등은 지정된 DNS 구성을 요구할 수 있습니다. 이유를 모르는 설정값을 무작정 제거하지 마세요.

10. VPN·보안 앱으로 인한 접속 오류 구분하기

Mac의 VPN, 타사 방화벽, 콘텐츠 차단기, 네트워크 감시 앱은 인터넷 연결에 영향을 줄 수 있습니다. Apple은 일부 소프트웨어가 Wi-Fi, iCloud 백업, App Store, FaceTime 또는 같은 네트워크의 다른 기기와의 통신을 차단할 수 있다고 설명합니다.

확인할 범주

  • VPN 앱 및 프로필
  • 네트워크 감시 기능이 있는 백신
  • 별도 방화벽 앱
  • 콘텐츠 차단 및 DNS 필터
  • 학교·기업에서 설치한 기기 관리 프로그램

개인 Mac에서의 점검

  1. 네트워크 오류가 발생한 시점을 기록합니다.
  2. 최근 설치 또는 업데이트한 VPN·보안 앱이 있는지 확인합니다.
  3. 해당 앱의 공식 지원 설명에서 알려진 네트워크 문제가 있는지 살펴봅니다.
  4. 개인적으로 관리하는 장치라면 설정 변경 전 기존 상태를 기록합니다.
  5. 허용된 환경에서 기능을 잠시 중지해 증상이 달라지는지 비교할 수 있습니다.

회사·학교 Mac에서는 관리자가 요구한 VPN이나 보안 프로그램을 임의로 끄거나 제거하지 마세요. IT 담당자에게 연결 오류를 전달해야 합니다.

11. Wi-Fi 네트워크 이름이 아예 안 보일 때

무선 네트워크 목록에 특정 공유기의 이름만 나타나지 않는다면, 비밀번호보다는 무선 신호·라우터 설정·기기 호환성을 확인해야 합니다.

  1. Mac에서 Wi-Fi가 켜져 있는지 확인합니다.
  2. 휴대전화에서 해당 SSID가 나타나는지 확인합니다.
  3. Mac을 공유기 가까이 옮겨 다시 검색합니다.
  4. 공유기가 켜져 있고 무선 기능이 작동 중인지 확인합니다.
  5. 라우터의 Wi-Fi 네트워크 이름을 숨겨 놓은 경우인지 확인합니다.
  6. 숨겨진 네트워크라면 관리자가 제공한 이름과 비밀번호로 연결합니다.

Apple은 신호 범위와 무선 네트워크의 **접근 제어(MAC 주소 등록)**에 따라 연결 가능 여부가 달라질 수 있다고 설명합니다.

듀얼밴드·트라이밴드 공유기는 2.4GHz·5GHz·6GHz 중 Mac 모델과 라우터가 공통 지원하는 대역에서 연결해야 합니다. 무작정 보안을 해제하거나 대역을 변경하기보다 제조사 권장 설정과 하드웨어 지원 사양을 확인하세요.

12. 공유기 WPA2·WPA3 보안 설정 확인하기

13. 아이폰 핫스팟에서는 되는데 집 Wi-Fi만 안 될 때

문제 범위를 좁히는 좋은 방법은 다른 네트워크를 이용한 교차 테스트입니다.

  1. 집 Wi-Fi에 연결해 문제가 재현되는지 확인합니다.
  2. iPhone 또는 Android 기기에서 모바일 핫스팟을 켭니다.
  3. Mac을 핫스팟에 연결해 웹페이지를 열어 봅니다.
  4. 핫스팟은 되지만 집 Wi-Fi만 실패한다면 해당 공유기의 연결 정보를 점검합니다.
  5. 집 공유기에서 다른 휴대전화가 정상 작동하는지 확인합니다.
  6. 비밀번호·보안 프로토콜·DHCP·라우터 표시등을 살펴봅니다.
  7. 모든 장치가 실패하면 ISP 또는 공유기 제조사에 문의합니다.

이 실험은 집 공유기와 Mac의 특정 조합에 문제가 있을 가능성을 좁힐 뿐 원인을 확정하지는 않습니다. 다른 네트워크에서 된다고 Mac이 완벽하게 정상이라는 뜻도 아닙니다.

핫스팟으로 대용량 업데이트나 파일 전송을 하면 모바일 데이터가 사용될 수 있습니다. 요금제와 사용량을 미리 확인하세요.

14. 호텔·카페·공항 Wi-Fi에서 인터넷이 안 될 때

확인 순서

  1. 시설에서 안내한 정확한 Wi-Fi 이름을 확인합니다.
  2. Mac에서 해당 네트워크에 연결합니다.
  3. 브라우저에 인증·로그인 안내가 나오는지 확인합니다.
  4. 로그인 화면이 안 보이면 시설에서 제공하는 접속 안내를 확인합니다.
  5. 객실번호나 이용권이 필요한 경우 안내된 공식 경로를 사용합니다.
  6. 인증 완료 뒤 일반 웹사이트를 열어 테스트합니다.

보안 주의: 시설의 공식 무선망과 비슷한 이름의 가짜 네트워크일 수 있으므로 중요 비밀번호와 결제정보를 입력하기 전에 SSID를 확인하세요. 회사 장치에서 공용 네트워크를 사용할 때는 조직의 보안 정책을 따릅니다.

Apple은 공용 무선망과 관리형 네트워크를 별도 범주로 구분하며, 기기의 자동 연결 우선순위도 네트워크 유형과 설정에 따라 달라진다고 설명합니다.

15. 날짜와 시간, 소프트웨어 업데이트 확인하기

Mac의 날짜와 시간대가 크게 잘못 설정돼 있다면 일부 보안 연결과 인증 기능이 정상 동작하지 않을 수 있습니다. Apple은 VPN 및 네트워크 연결 문제 해결에서 날짜·시간 확인, 소프트웨어 최신 상태, 장치 재시동을 기본 점검 항목으로 제시합니다.

  3. 가능한 환경에서 자동 날짜·시간 설정이 정상적인지 확인합니다.
  4. 운영체제 업데이트가 필요한 상태인지 확인합니다.
  5. 중요한 작업과 백업을 마친 후 지원되는 업데이트를 진행합니다.

17. 복잡한 네트워크 설정은 새 위치로 비교할 수 있습니다

일반적인 연결 재시도로 해결되지 않고 과거에 DNS, 프록시, VPN, 수동 IP를 여러 차례 변경했다면 기존 설정의 어떤 부분이 충돌하는지 살펴봐야 합니다.

Apple은 Mac의 네트워크 문제 해결에서 새 네트워크 위치를 사용해 설정을 비교하거나 재설정하는 방법을 설명합니다.

  1. 현재 Wi-Fi 암호 및 연결할 네트워크 이름을 확인합니다.
  2. 고정 IP, 수동 DNS, 프록시, VPN 등의 값을 기록합니다.
  3. 시스템 설정 → 네트워크를 엽니다.
  4. 네트워크 위치 관리 메뉴가 제공되는지 확인합니다.
  5. 기존 설정을 삭제하기보다 비교용 새 위치를 생성할 수 있는지 살펴봅니다.
  6. 새 위치에서 일반 Wi-Fi 연결을 시험합니다.
  7. 기존 위치와 차이가 있는지 점검합니다.

이 방법은 모든 Mac에서 반드시 실행해야 하는 초기화 절차가 아닙니다. 직장·학교 장치, 특수 업무용 VPN에는 필수 설정이 있을 수 있으므로 관리자의 확인 없이 변경하지 마세요.

같은 와이파이의 모든 장치가 실패한다면 ISP나 공유기 제조사에 먼저 문의하고, Mac만 여러 네트워크에서 지속적으로 실패한다면 Apple 지원을 우선 검토할 수 있습니다.

19. 자주 묻는 질문

Q. 맥북 Wi-Fi는 연결됐는데 인터넷이 없습니다.

같은 무선망의 다른 기기로 먼저 확인하세요. 모든 기기가 안 되면 공유기와 회선 상태를 확인하고, Mac에서만 안 되면 VPN·DNS·네트워크 연결 기록을 점검하세요.

Q. 맥북에서 Wi-Fi 비밀번호가 계속 틀렸다고 합니다.

올바른 SSID와 비밀번호를 확인하고, 최근 공유기의 암호나 보안 방식이 바뀌었는지 살펴보세요. 저장된 정보를 새로 등록하려면 시스템 설정 → Wi-Fi → 세부사항 → 이 네트워크 지우기를 사용할 수 있습니다.

Q. 무선 진단은 어디에서 실행하나요?

**Option 키를 누른 상태로 Wi-Fi 아이콘을 클릭해 ‘무선 진단 열기’**를 선택합니다. Apple은 이 도구가 네트워크 설정을 자동으로 변경하지 않는다고 안내합니다.

Q. DHCP 임대 갱신은 왜 하나요?

DHCP로 할당받은 IP 주소 정보를 다시 갱신하는 기능입니다. 네트워크 → Wi-Fi → 세부사항 → TCP/IP에서 사용할 수 있습니다. 회선 자체 장애에는 도움이 되지 않을 수 있습니다.

Q. DNS 서버를 공개 DNS로 바꾸면 해결되나요?

보장할 수 없습니다. 회사 내부 주소나 VPN 전용 시스템에는 기존 DNS가 필요할 수 있으므로 임의 변경에 주의해야 합니다.

Q. VPN을 끄면 인터넷이 됩니다. 계속 꺼둬도 되나요?

회사·학교의 보안 정책이 적용된 VPN이라면 사용 중단 여부를 관리자가 결정해야 합니다. 개인 VPN은 제공자 공식 지원에서 설정을 점검하세요.

Q. iPhone 핫스팟은 연결되는데 집 Wi-Fi만 실패합니다.

집 공유기 비밀번호·보안 프로토콜·DHCP·인터넷 회선부터 확인하세요. 다른 장치가 집 Wi-Fi를 정상적으로 이용하는지 비교하면 진단에 도움이 됩니다.

Q. 비공개 Wi-Fi 주소를 끄면 해결되나요?

일반적으로 무조건 끌 이유는 없습니다. 기기 MAC 주소 등록이 필요한 회사·학교 네트워크라면 관리자와 상의하세요.

Q. 카페 Wi-Fi에서 연결은 되는데 인터넷이 안 됩니다.

시설의 공식 네트워크인지 확인하고 로그인 또는 이용약관 동의 화면이 필요한지 살펴보세요. 시설 직원이나 네트워크 관리자에게 공식 접속 방법을 확인하는 것이 좋습니다.

Q. 공유기를 재부팅해야 하나요?

자신이 관리하는 공유기라면 제조사의 정상 재시동 절차를 따를 수 있습니다. 단, 회사나 공공 네트워크 장비는 허락 없이 변경하거나 재시작해서는 안 됩니다.

20. 최종 점검 체크리스트

  • ☐ Mac Wi-Fi가 켜져 있고 정확한 네트워크 이름을 선택했습니다.
  • ☐ 같은 와이파이에서 다른 기기의 인터넷 접속 상태를 비교했습니다.
  • ☐ 다른 Wi-Fi 또는 모바일 핫스팟으로 교차 테스트했습니다.
  • ☐ 저장한 네트워크를 지울 경우 재연결 비밀번호를 확보했습니다.
  • ☐ 공유기·모뎀의 전원과 인터넷 회선 상태를 확인했습니다.
  • ☐ Option+Wi-Fi 메뉴에서 무선 진단을 사용할 수 있는지 확인했습니다.
  • ☐ 네트워크 서비스의 IP와 라우터 주소를 확인했습니다.
  • ☐ 필요할 때만 DHCP 임대 갱신을 검토했습니다.
  • ☐ DNS 값을 바꾸기 전 기존 설정을 기록했습니다.
  • ☐ VPN·보안 앱·날짜·시간·macOS 업데이트 상태를 확인했습니다.
  • ☐ WPA3 또는 적절한 WPA2/WPA3 보안 설정을 확인했습니다.
  • ☐ WEP·TKIP 등 구형 보안으로 무작정 낮추지 않았습니다.
  • ☐ 비공개 Wi-Fi 주소 기능을 이유 없이 해제하지 않았습니다.
  • ☐ 회사·학교 Mac에서는 IT 관리자 정책을 우회하지 않았습니다.
  • ☐ 증상이 계속되면 오류·네트워크·기기별 비교 결과를 기록했습니다.

정리: 맥북 Wi-Fi 문제는 ‘공유기까지 접속하지 못함’과 ‘공유기에 접속했지만 인터넷이 안 됨’을 구분하는 것이 핵심입니다. 다른 기기 비교 → Wi-Fi 다시 연결 → 무선 진단 → 공유기·DHCP·DNS·VPN 점검 순서로 진행하면 무작정 시스템을 초기화하지 않고도 원인을 좁힐 수 있습니다.
