윈도우11에서 C드라이브가 빨간색으로 표시되거나 “디스크 공간이 부족합니다”라는 알림이 나타난다면 프로그램을 무조건 삭제하기 전에 무엇이 공간을 차지하고 있는지 확인하는 것이 우선입니다. Windows 자체에서 제공하는 **저장소 센스(Storage Sense)**와 **정리 권장 사항(Cleanup recommendations)**을 활용하면 임시 파일, 휴지통, 오래 사용하지 않는 파일 등을 구분해 정리할 수 있습니다.

그러나 정리 항목을 잘못 선택하면 필요한 다운로드 파일이나 이전 Windows 버전으로 돌아갈 수 있는 복구 데이터가 없어질 수 있습니다. 특히 다운로드 폴더, 이전 Windows 설치(Windows.old), OneDrive 클라우드 파일은 삭제의 의미가 서로 다르기 때문에 반드시 주의해야 합니다.

이 글은 2026년 11월 1일 기준 Microsoft 공식 Windows·OneDrive 지원 문서를 바탕으로, 자료를 보호하면서 저장 공간을 확보하는 순서를 안내합니다. PC마다 Windows 11 버전과 저장 장치 구성, 관리 정책이 다르므로 실제 화면에 표시되는 항목을 확인하며 진행하세요.

1. 증상별로 먼저 선택할 방법

현재 증상먼저 확인할 항목권장 조치
C드라이브가 빨간색이고 남은 공간이 적음설정 → 시스템 → 저장소사용량 범주 확인, 정리 권장 사항
Windows 업데이트 설치 공간 부족임시 파일·업데이트용 공간저장소 센스와 정리 권장 사항
설치된 앱이 대부분의 용량 차지설치된 앱 목록사용하지 않는 앱만 제거
다운로드 폴더가 지나치게 큼파일별 필요 여부필요한 설치 파일·문서 선별 후 이동
휴지통이 커짐휴지통 안의 파일필요한 파일 복원 후 비우기
Windows.old가 크게 표시됨이전 버전 복원 필요 여부되돌리기 필요 없을 때만 삭제
OneDrive 폴더 용량이 큼로컬·온라인 전용 상태‘공간 확보’로 로컬 사본만 정리
D드라이브만 가득 참다른 드라이브 사용량C드라이브와 분리해 정리
정리 후에도 용량이 계속 줄어듦신규 다운로드·동기화·앱 동작원인 앱과 폴더를 반복 확인

권장 순서: 저장 공간 사용량 확인 → 휴지통·임시 파일 검토 → 다운로드·대용량 개인 파일 점검 → 불필요한 앱 정리 → 저장소 센스 자동화 → 클라우드 파일과 Windows.old는 별도로 판단. 정체를 모르는 시스템 폴더를 직접 지우는 방식은 피하는 편이 안전합니다.

공식 출처: Microsoft — Windows 저장소 설정, Microsoft — Windows 드라이브 공간 확보

2. C드라이브에 무엇이 쌓였는지 확인하는 방법

파일 몇 개를 지워도 공간이 늘어나지 않는 이유는 저장 공간을 많이 차지하는 것이 사진과 문서가 아니라 설치된 앱, 캐시, 업데이트 파일 등일 수 있기 때문입니다.

  1. Windows 키+I를 눌러 설정을 엽니다.
  2. **시스템 → 저장소(Storage)**로 이동합니다.
  3. Windows가 표시하는 C드라이브의 전체 용량과 사용량을 확인합니다.
  4. 설치된 앱, 임시 파일, 시스템 및 예약, 기타 등 범주별 사용량을 살펴봅니다.
  5. 사용량이 큰 범주를 먼저 선택해 자세한 내용을 확인합니다.
  6. 삭제할 항목을 정하기 전 중요한 데이터의 보관 위치를 확인합니다.

Microsoft는 저장소 설정에서 파일과 앱의 사용량을 범주별로 보여 주며, 시스템 예약 공간은 업데이트나 임시 데이터와 같은 Windows 동작을 지원한다고 설명합니다.

‘시스템 및 예약’이 크면 전부 지울 수 있나요?

아닙니다. 이 범주에는 Windows가 정상 작동하거나 업데이트를 진행하는 데 필요한 공간이 포함될 수 있습니다. 해당 용량이 크다는 이유만으로 Windows 시스템 폴더를 직접 삭제하면 안 됩니다.

D드라이브도 볼 수 있나요?

설정 → 시스템 → 저장소 → 고급 저장소 설정 → 다른 드라이브에서 사용한 저장 공간을 통해 다른 드라이브의 사용량을 확인할 수 있습니다. C드라이브와 D드라이브가 별도 저장 공간이라면 서로 다른 원인을 진단해야 합니다.

공식 출처: Microsoft — Storage settings in Windows

3. ‘정리 권장 사항’으로 비교적 안전하게 시작하기

Windows 11에는 자동 정리를 바로 켜지 않고도 삭제 후보를 검토할 수 있는 **정리 권장 사항(Cleanup recommendations)**이 있습니다.

  1. 설정 → 시스템 → 저장소를 엽니다.
  2. 정리 권장 사항을 선택합니다.
  3. 임시 파일 항목과 예상 확보 용량을 확인합니다.
  4. 크거나 사용하지 않는 파일, 클라우드와 동기화된 파일, 사용하지 않는 앱 등 항목을 살펴봅니다.
  5. 실제로 불필요하다고 판단된 항목만 선택합니다.
  6. 삭제 대상과 예상 확보 공간을 다시 확인한 뒤 **정리(Clean up)**를 실행합니다.
  7. 작업을 마친 후 저장소 화면에서 남은 용량을 확인합니다.

Microsoft는 정리 권장 사항에 임시 파일·큰 파일·사용하지 않는 앱·클라우드 동기화 파일 등 범주가 포함될 수 있다고 안내합니다.

중요: ‘정리 권장’이라는 이름이 붙었다고 해당 항목이 사용자에게 반드시 불필요한 것은 아닙니다. 예를 들어 오래 열지 않은 동영상이라도 가족 영상이나 계약 자료일 수 있습니다. 파일 이름·저장 위치를 먼저 확인하세요.

공식 출처: Microsoft — Free up drive space in Windows

4. 임시 파일 삭제 단계에서 확인할 사항

임시 파일은 Windows 및 프로그램이 작업 과정에서 생성하는 데이터로, 일부는 불필요해졌을 때 삭제할 수 있습니다. 다만 임시 파일 목록에는 복구 목적으로 남겨 둔 데이터가 함께 표시될 수도 있습니다.

삭제 절차

  1. 설정 → 시스템 → 저장소로 이동합니다.
  2. **임시 파일(Temporary files)**을 엽니다.
  3. 화면에 표시된 항목 이름과 용량을 확인합니다.
  4. 필요하지 않은 항목만 선택합니다.
  5. **파일 제거(Remove files)**를 선택합니다.
  6. 정리 작업이 완료되면 남은 드라이브 공간을 확인합니다.

삭제하기 전에 특히 확인할 항목

Windows가 표시하는 범주와 기본 선택 상태는 버전·시스템 상태에 따라 달라질 수 있습니다. 전체 항목 일괄 선택보다 용량과 역할을 확인하는 방식이 안전합니다.

5. 저장소 센스(Storage Sense) 켜는 방법

저장소 센스는 불필요한 임시 파일과 휴지통의 오래된 항목을 정리해 디스크 공간을 확보하도록 돕는 Windows 기능입니다.

  1. 시작 → 설정 → 시스템 → 저장소를 엽니다.
  2. 저장소 센스(Storage Sense) 스위치를 켭니다.
  3. 저장소 센스 항목을 선택해 상세 설정을 엽니다.
  4. 실행 빈도와 휴지통 항목 삭제 조건을 확인합니다.
  5. 다운로드 폴더 자동 정리는 필요한 경우에만 별도로 설정합니다.
  6. 클라우드 파일을 온라인 전용으로 변경하는 설정도 목적에 맞게 검토합니다.

Microsoft 설명에 따르면 저장소 센스가 기본 설정으로 실행되면 디스크 공간이 부족할 때 불필요한 임시 파일을 정리할 수 있습니다. 하지만 다운로드 폴더와 OneDrive 파일을 기본 설정에서 일괄 삭제하는 것으로 이해해서는 안 됩니다.

저장소 센스가 꺼져 있는데도 알림이 왔어요

Microsoft는 저장소 센스가 기본적으로 꺼져 있을 수 있지만, 디스크 공간이 부족하고 사용자가 기존에 관련 설정을 조정하지 않은 상황에서는 제한된 임시 파일 관리를 위해 Windows가 기능을 켠 후 알릴 수 있다고 설명합니다.

원하지 않는 경우 저장소 설정에서 상태를 확인하고 필요에 맞게 조정할 수 있습니다.

공식 출처: Microsoft — Manage drive space with Storage Sense

6. 저장소 센스를 켜면 다운로드 폴더도 자동으로 지워지나요?

기본 설정만으로 다운로드 폴더를 모두 지우는 것은 아닙니다. Microsoft는 사용자가 다운로드 폴더 삭제 조건을 명시적으로 구성하지 않는 한 이 폴더를 건드리지 않는다고 안내합니다.

다운로드 자동 삭제 조건 확인

  1. 설정 → 시스템 → 저장소 → 저장소 센스를 엽니다.
  2. 다운로드 폴더에 있는 파일이 열리지 않은 기간과 관련된 설정을 확인합니다.
  3. 중요한 설치 파일, 계약서, 영수증 등이 다운로드 폴더에 있는지 먼저 확인합니다.
  4. 자동 삭제를 원하지 않으면 해당 기능을 끄거나 실행하지 않는 설정으로 유지합니다.
  5. 삭제를 허용하려면 어떤 기간과 기준으로 파일이 제거될지 읽어본 다음 설정합니다.

다운로드 폴더를 따로 확인해야 하는 이유

다운로드 폴더는 임시 설치 파일뿐 아니라 온라인 발급 서류, 사진, 개인 문서, 업무 자료를 보관하는 장소로 사용되는 경우가 많습니다. 오래 열지 않았다는 이유가 해당 자료가 불필요하다는 증거는 아닙니다.

권장 방식: 다운로드 폴더의 파일을 날짜와 크기별로 정렬한 후, 필요한 것은 문서·사진 폴더나 외부 저장 장치로 옮기고 중복 파일·불필요한 설치 프로그램만 직접 정리하세요.

공식 출처: Microsoft — 저장소 센스의 다운로드 폴더 관리

7. 휴지통 비우기 전에 복원할 파일이 없는지 확인

휴지통 안의 파일도 실제로는 드라이브 공간을 차지할 수 있습니다. 하지만 휴지통을 비운 뒤에는 단순한 휴지통 복원으로 되돌릴 수 없으므로 필요한 항목을 먼저 확인해야 합니다.

  1. 바탕화면에서 휴지통을 엽니다.
  2. 삭제 날짜와 이름을 기준으로 파일을 검토합니다.
  3. 실수로 삭제한 파일이 있으면 마우스 오른쪽 버튼을 눌러 복원합니다.
  4. 더 이상 필요하지 않은 항목만 남았는지 확인합니다.
  5. 휴지통 비우기를 실행합니다.
  6. C드라이브의 남은 용량을 다시 확인합니다.

저장소 센스에서 휴지통 파일 자동 삭제 기간을 설정해 놓았다면 오래된 파일이 자동으로 제거될 수 있습니다. 중요한 파일은 휴지통을 장기 보관 장소로 사용하지 않는 편이 좋습니다.

주의: 휴지통을 비웠다고 모든 드라이브의 모든 종류의 삭제 파일을 완전히 복구 불가능한 수준으로 보안 삭제했다는 뜻은 아닙니다. 보안 삭제와 일상적인 용량 확보는 다른 작업입니다.

공식 출처: Microsoft — 저장소 센스와 휴지통 정리 조건

8. Windows.old 삭제해도 되나요? 10일 복구 기간 주의

Windows 업그레이드 후 이전 Windows 설치 또는 Windows.old라는 항목이 표시될 수 있습니다. 이 폴더에는 이전 Windows 버전으로 돌아가기 위해 필요한 파일이 포함될 수 있습니다.

언제 삭제를 검토할까요?

  • 최근 Windows 업그레이드를 마친 뒤 현재 버전에서 필요한 프로그램과 장치가 정상 작동하는지 확인한 경우
  • 이전 버전으로 되돌릴 계획이 없는 경우
  • 정리 권장 사항 또는 임시 파일 화면에서 이전 Windows 설치 항목이 제공되는 경우

공식 삭제 방법

  1. 설정 → 시스템 → 저장소 → 임시 파일을 엽니다.
  2. 이전 Windows 설치(Previous Windows Installation(s)) 항목을 찾습니다.
  3. 이전 Windows 버전으로 돌아갈 필요가 정말 없는지 확인합니다.
  4. 해당 항목을 선택하고 파일 제거를 실행합니다.

Microsoft는 Windows 업그레이드 후 10일이 지나면 이전 버전의 Windows 파일이 자동으로 제거된다고 안내합니다. 10일이 되기 전에 직접 Windows.old를 삭제하면 이전 Windows 버전으로 되돌리는 기능을 사용할 수 없으며, 작업을 되돌릴 수 없다고 명시합니다.

핵심: 용량을 확보하기 위해 Windows.old를 바로 지우기보다 새 Windows 버전의 장치 호환성, 프로그램 동작, 개인정보와 기존 파일을 먼저 확인하세요. 폴더를 파일 탐색기에서 강제로 지우는 대신 Windows가 제공하는 공식 정리 기능을 사용하는 것이 좋습니다.

공식 출처: Microsoft — Delete your previous version of Windows

9. OneDrive의 ‘공간 확보’와 ‘삭제’는 완전히 다릅니다

OneDrive 파일을 PC에 동기화해 사용한다면 파일이 클라우드와 로컬 저장 공간을 함께 사용할 수 있습니다. 이때 공간 확보(Free up space) 기능을 이용하면 파일의 로컬 사본을 정리하고 온라인 전용으로 유지할 수 있습니다.

OneDrive 아이콘으로 상태 구분

아이콘 상태의미오프라인에서 열기
파란 구름온라인 전용 파일인터넷 연결 필요
흰 바탕의 초록 체크기기에 다운로드된 로컬 사용 가능 파일가능
초록색 원·흰색 체크‘항상 이 장치에 유지’로 지정한 파일가능

Microsoft는 온라인 전용 파일이 PC에 전체 데이터를 저장하지 않고 자리표시자를 표시하며, 필요할 때 인터넷을 통해 다운로드된다고 설명합니다.

로컬 공간을 확보하려면

  1. 파일 탐색기에서 OneDrive 폴더를 엽니다.
  2. 로컬 공간을 차지하지만 자주 열지 않는 파일을 선택합니다.
  3. 마우스 오른쪽 버튼을 눌러 **공간 확보(Free up space)**를 선택합니다.
  4. 파란 구름 아이콘으로 바뀌는지 확인합니다.
  5. 실제 온라인 파일이 계속 존재하는지 OneDrive 웹사이트에서 확인합니다.

절대 혼동하지 말아야 할 기능

공간 확보는 클라우드에 보관된 파일을 유지하면서 로컬 사본을 제거하는 동작입니다. 반면 OneDrive 동기화 폴더에서 파일 자체를 삭제하면 클라우드에서도 삭제가 동기화될 수 있습니다. 중요한 문서라면 단순 삭제 대신 공간 확보 기능을 사용하세요.

공식 출처: Microsoft — OneDrive Files On-Demand, Microsoft — OneDrive 아이콘의 의미

10. 저장소 센스가 OneDrive 파일을 관리하는 방식

Microsoft는 OneDrive 등 클라우드 파일의 로컬 보관 기간을 저장소 센스에서 지정할 수 있다고 설명합니다. 이 설정의 목적은 클라우드 파일을 영구적으로 삭제하는 것이 아니라 장기간 열지 않은 파일의 로컬 사본을 온라인 전용으로 변경해 저장 공간을 확보하는 것입니다.

기본 설정에 관한 중요한 설명

Microsoft는 Windows 11 버전 22H2 이후 OneDrive 파일에 대해 30일 동안 열지 않은 항목을 온라인 전용으로 변경하는 기본 조건을 문서화했습니다. 하지만 실제로 적용되는 시점과 기능 상태는 저장소 센스 활성화 여부, 클라우드 계정 로그인, 사용자 설정 등에 영향을 받습니다.

‘항상 이 장치에 유지’는 제외

사용자가 OneDrive 파일을 **항상 이 장치에 유지(Always keep on this device)**로 표시했다면 해당 항목은 저장소 센스의 일반적인 온라인 전용 전환 대상에서 제외됩니다.

따라서 여행이나 출장 등 인터넷 연결이 불안정한 환경에서 반드시 필요한 문서라면 해당 파일을 오프라인에서도 열 수 있는지 미리 확인해 두어야 합니다.

자동 실행되지 않는다면?

Microsoft는 저장소 센스가 동작하려면 사용자가 로그인 상태이고 온라인 상태여야 하며, 관련 실행 조건을 충족해야 한다고 안내합니다. 따라서 PC를 켠 즉시 또는 오프라인 상태에서 무조건 정리가 실행된다고 기대해서는 안 됩니다.

공식 출처: Microsoft — 저장소 센스의 클라우드 파일 관리

11. 설치된 앱이 용량을 많이 차지한다면

저장소 설정에서 설치된 앱이 큰 비중을 차지한다면 실제 사용하지 않는 앱을 찾는 것이 효과적일 수 있습니다.

  1. 설정 → 앱 → 설치된 앱으로 이동합니다.
  2. 앱 목록에서 크기 또는 사용 여부를 확인합니다.
  3. 삭제하려는 앱이 현재 필요한 프로그램인지 확인합니다.
  4. 업무·학교·금융·보안 관련 프로그램이라면 삭제 전에 담당자에게 확인합니다.
  5. 제거 가능한 앱에 대해 **제거(Uninstall)**를 진행합니다.
  6. 재부팅이 필요하다면 저장 중인 작업을 마친 뒤 진행합니다.

앱 제거 전 체크: 프로그램 안에만 저장된 프로젝트, 게임 세이브 데이터, 라이선스 정보, 사용자의 환경 설정이 있을 수 있습니다. 앱을 제거하면 이런 데이터가 함께 삭제될 수 있으므로 백업과 다시 설치할 방법을 확인해야 합니다.

모르는 프로그램을 용량이 크다는 이유만으로 무작정 지우면 PC가 정상적으로 작동하는 데 필요한 구성 요소까지 손상될 수 있습니다. Windows가 제공하는 공식 앱 제거 경로를 사용하세요.

공식 출처: Microsoft — Windows 저장 공간의 앱 사용량 확인

12. 대용량 영상·사진·다운로드 파일 정리하기

설치된 앱이나 임시 파일을 정리해도 공간이 부족하다면 개인 파일 중 크기가 큰 항목을 찾는 것이 다음 단계입니다.

파일 탐색기로 큰 파일 확인

  1. 파일 탐색기를 엽니다.
  2. 이 PC의 다운로드, 동영상, 사진, 문서 폴더를 확인합니다.
  3. 폴더에서 보기 → 자세히로 전환합니다.
  4. 파일 크기 또는 수정 날짜로 정렬합니다.
  5. 불필요한 항목만 삭제하고, 필요한 자료는 외장 드라이브나 백업 위치로 옮깁니다.
  6. 이동 후 목적지의 파일을 실제로 열 수 있는지 확인합니다.
  7. 중요한 파일을 안전하게 백업한 뒤 원본 정리 여부를 판단합니다.

Microsoft는 동영상·음악·사진·문서와 다운로드 폴더에서 큰 파일을 찾아 삭제하거나 외장 USB·SD 카드 등에 옮기는 방법을 안내합니다.

옮긴 뒤에도 용량이 줄지 않아요

파일을 복사한 것인지 이동한 것인지 확인해야 합니다. 외장 드라이브로 복사만 했다면 원래 C드라이브의 파일은 남아 있으므로 용량이 그대로일 수 있습니다.

주의: 폴더를 단순히 다른 위치로 이동하는 과정에서도 같은 물리 디스크의 다른 폴더로 옮겼다면 실제 사용 공간이 줄어들지 않습니다. 정말 별도 드라이브에 옮겼는지 확인해야 합니다.

공식 출처: Microsoft — 대용량 개인 파일 찾아 공간 확보

13. C드라이브 대신 D드라이브에 새 파일 저장하기

C드라이브가 가득 차는 현상을 줄이려면 앞으로 생성하는 파일의 기본 저장 위치를 다른 드라이브로 지정할 수 있습니다.

  1. 설정 → 시스템 → 저장소로 이동합니다.
  2. 고급 저장소 설정을 펼칩니다.
  3. **새 콘텐츠가 저장되는 위치(Where new content is saved)**를 선택합니다.
  4. 문서·사진·음악·동영상 또는 앱 등 표시되는 콘텐츠 종류를 확인합니다.
  5. 사용 가능한 경우 여유 공간이 많은 드라이브를 선택합니다.
  6. 설정을 적용하고 실제 새 파일의 저장 위치를 테스트합니다.

Microsoft는 이 기능으로 새로 생성되는 콘텐츠의 기본 저장 위치를 조정할 수 있다고 설명합니다.

기존 파일도 자동으로 옮겨지나요?

일반적으로 새 콘텐츠의 저장 경로 변경은 이미 C드라이브에 존재하는 모든 파일을 자동으로 옮기는 작업과 다릅니다. 따라서 기존 자료를 정리하려면 파일 탐색기에서 별도로 확인하고 필요한 파일만 안전하게 이동해야 합니다.

D드라이브가 C드라이브와 같은 물리 저장 장치를 분할한 파티션이라면, 별도의 외장 장치로 백업하는 것과는 다릅니다. 저장 공간 분산과 데이터 백업은 구분하세요.

공식 출처: Microsoft — 새 콘텐츠 저장 위치 변경

14. Windows 업데이트 공간 부족 오류가 날 때

Windows는 기능 업데이트와 보안 업데이트를 설치하기 전에 필요한 저장 공간을 확인합니다. 여유 공간이 부족하면 업데이트를 완료하지 못할 수 있습니다.

우선 실행할 공식 순서

  1. 설정 → 시스템 → 저장소로 이동합니다.
  2. 저장소 센스를 켜고 불필요한 임시 파일을 정리합니다.
  3. 정리 권장 사항에서 삭제해도 되는 항목을 확인합니다.
  4. 다운로드 폴더·대용량 개인 파일을 별도로 점검합니다.
  5. Windows 업데이트 화면으로 돌아가 다시 시도합니다.

Microsoft는 업데이트 공간 확보에 저장소 센스, 정리 권장 사항, 디스크 정리 및 외부 저장 장치 사용을 공식 방법으로 소개합니다. 일부 업데이트 상황에서는 충분한 공간이 있는 외부 USB 저장 장치가 설치 과정에 도움이 될 수 있습니다.

주의: 외장 드라이브를 연결했다고 C드라이브의 공간이 전혀 필요하지 않게 되는 것은 아닙니다. Microsoft는 외부 저장 장치를 사용해도 내부 드라이브에서 추가 공간 확보를 요구할 수 있다고 안내합니다.

업데이트에 필요한 공간은 PC 구성과 기능 업데이트 방식, 선택적 기능 및 언어 설치 상태에 따라 달라집니다. 누구나 반드시 확보해야 하는 고정된 GB 수치를 단정하는 것은 정확하지 않습니다.

공식 출처: Microsoft — Windows 업데이트용 공간 확보

15. 디스크 정리(Disk Cleanup)도 사용할 수 있나요?

Windows에는 이전부터 제공되는 디스크 정리(Disk Cleanup) 도구가 있습니다. Microsoft는 저장소 센스를 사용할 수 없는 상황에서 임시 파일이나 시스템 파일을 정리하는 대안으로 안내합니다.

  1. 작업 표시줄 검색창에서 디스크 정리를 찾습니다.
  2. 도구를 실행하고 정리할 드라이브를 선택합니다.
  3. 목록에서 삭제 후보와 설명을 확인합니다.
  4. 실제로 불필요한 항목만 선택합니다.
  5. 필요하면 **시스템 파일 정리(Clean up system files)**를 선택해 추가 항목을 확인합니다.
  6. 삭제 전 이전 Windows 설치나 복구 관련 데이터가 포함되는지 점검합니다.

다만 이 도구에서 모든 항목에 체크했다고 해서 모든 데이터가 안전하게 삭제되는 것은 아닙니다. 특히 이전 Windows 버전 관련 파일은 되돌리기 옵션을 잃을 수 있습니다.

무작정 폴더를 찾아 삭제하는 방법보다 공식 정리 메뉴를 우선하세요. 시스템 폴더의 이름이나 크기만으로 삭제 가능 여부를 판단하기 어렵기 때문입니다.

공식 출처: Microsoft — Disk Cleanup

16. 용량을 정리했는데도 계속 줄어드는 경우

임시 파일을 삭제한 뒤 얼마 지나지 않아 C드라이브가 다시 가득 찬다면 실제로 어떤 데이터가 다시 증가하는지 확인해야 합니다.

비교 방법

  1. 설정 → 시스템 → 저장소에서 사용량을 확인합니다.
  2. 현재 사용량을 메모하거나 화면 캡처합니다.
  3. 일정 시간 정상적으로 PC를 사용한 후 같은 메뉴를 다시 확인합니다.
  4. 설치된 앱, 임시 파일, 시스템 및 예약, 문서, 동영상 중 어떤 범주가 증가했는지 살펴봅니다.
  5. 최근 설치한 앱, 대용량 다운로드, 녹화 파일, 동기화 앱이 있는지 확인합니다.
  6. 불명확한 폴더나 시스템 파일을 직접 지우지 않고 제조사 및 Microsoft 공식 지원 문서를 확인합니다.

OneDrive 동기화 중이라면

온라인 전용으로 두었던 파일을 열면 로컬에 다시 내려받아 공간을 사용할 수 있습니다. 또한 사용자가 항상 이 장치에 유지를 선택한 파일은 계속 로컬 공간을 차지합니다.

저장소 사용량 표시가 의문이라면

저장소 설정의 분류는 파일을 볼 수 있도록 돕는 정보이지 모든 하위 파일의 삭제 가능성을 설명하는 목록은 아닙니다. 확인되지 않은 운영체제 캐시나 시스템 예약 공간을 강제로 삭제하지 마세요.

악성코드가 의심되는 경우

Microsoft는 악성코드가 파일을 손상시키거나 저장소 공간을 비정상적으로 사용하도록 만들 수 있다고 안내합니다. 의심스러운 증상이 있다면 Windows 보안 등 신뢰할 수 있는 공식 보안 도구로 검사하는 것을 검토하세요.

17. 자주 묻는 질문

Q. 저장소 센스를 켜면 내 다운로드 파일이 자동 삭제되나요?

기본 설정에서는 다운로드 폴더를 자동으로 정리하지 않지만, 사용자가 다운로드 파일 삭제 조건을 따로 지정하면 해당 규칙이 적용될 수 있습니다. 저장소 센스 설정을 열고 다운로드 항목의 조건을 확인하세요.

Q. Windows.old 폴더는 지워도 되나요?

Windows 업그레이드 후 현재 버전이 안정적으로 작동하고 이전 버전으로 돌아갈 계획이 없다면 공식 정리 기능으로 삭제를 검토할 수 있습니다. 단, 삭제하면 이전 Windows 버전으로 돌아가는 기능을 잃을 수 있고 되돌릴 수 없습니다.

Q. OneDrive 파일에서 ‘공간 확보’를 누르면 인터넷에서도 삭제되나요?

Microsoft의 OneDrive 파일 온디맨드 기능에서 공간 확보는 로컬 사본을 온라인 전용으로 변경하는 동작입니다. 클라우드 파일 자체를 삭제하는 명령과 다릅니다. 다만 오프라인 상태에서는 온라인 전용 파일을 열 수 없으므로 중요한 자료는 다운로드 여부를 확인해야 합니다.

Q. 왜 저장소 센스는 C드라이브만 정리하나요?

Microsoft는 저장소 센스가 **Windows가 설치된 시스템 드라이브(C드라이브인 경우가 일반적)**에서 작동한다고 설명합니다. 다른 드라이브의 공간은 저장소 설정의 다른 드라이브에서 사용한 저장 공간에서 별도로 확인하세요.

Q. 휴지통을 비웠는데 용량이 거의 늘어나지 않았어요.

휴지통에 있던 파일 크기가 작았거나, 저장 공간을 많이 차지하는 원인이 설치된 앱·개인 영상·다른 드라이브에 있는 경우일 수 있습니다. 설정 → 시스템 → 저장소에서 실제 사용량 범주를 비교해 보세요.

Q. 임시 파일 삭제를 눌렀는데 일부 파일이 안 지워져요.

일부 파일은 현재 Windows나 앱이 사용 중이어서 정리되지 않을 수 있습니다. 컴퓨터를 정상 재시작한 뒤 공식 저장소 설정에서 다시 확인할 수 있습니다. 원인을 모르는데도 시스템 폴더를 강제로 삭제하는 것은 권장하지 않습니다.

Q. C드라이브가 가득 차면 Windows 업데이트가 안 되나요?

여유 저장 공간이 충분하지 않으면 업데이트를 완료하지 못할 수 있습니다. Microsoft는 저장소 센스, 정리 권장 사항, 디스크 정리, 외부 저장 장치 등을 해결 방법으로 안내합니다. 필요한 공간은 업데이트 종류와 PC 구성에 따라 달라집니다.

Q. 중요한 문서를 D드라이브로 이동하면 백업도 된 건가요?

저장 위치를 옮기는 것과 독립된 백업 사본을 만드는 것은 다릅니다. C와 D가 같은 물리 드라이브의 파티션일 수도 있으므로 중요한 자료는 별도 저장 장치나 신뢰할 수 있는 백업 서비스에도 보관하는 것이 안전합니다.

Q. 저장소 센스는 항상 실행되나요?

저장소 센스의 실행 시점은 사용자 설정과 시스템 상태, 로그인 및 온라인 조건에 영향을 받습니다. Microsoft는 기본 설정에서는 저장 공간이 부족할 때 실행할 수 있다고 설명합니다. 필요한 경우 저장소 센스의 실행 빈도를 확인하고 Windows가 제공하는 실행 옵션을 사용하세요.

Q. 공간이 부족한데 용량 정리 프로그램을 별도 구매해야 하나요?

우선 Windows 11의 기본 저장소 센스·정리 권장 사항·디스크 정리를 사용해 보세요. 이 기능만으로도 많은 종류의 임시 파일을 관리할 수 있습니다. 외부 정리 프로그램을 쓰더라도 개인정보 접근 권한과 시스템 파일 삭제 위험을 확인해야 합니다.

18. 데이터 손실을 피하기 위한 최종 체크리스트

  • ☐ 설정 → 시스템 → 저장소에서 실제 사용량을 확인했습니다.
  • ☐ 임시 파일을 삭제하기 전에 항목 이름과 예상 확보 용량을 읽었습니다.
  • ☐ 다운로드 폴더 안에 중요한 서류나 설치 파일이 없는지 확인했습니다.
  • ☐ 휴지통을 비우기 전에 복원해야 할 파일을 점검했습니다.
  • ☐ 저장소 센스의 다운로드 폴더 자동 삭제 조건을 확인했습니다.
  • ☐ Windows.old를 지우면 이전 버전으로 돌아갈 수 없다는 점을 이해했습니다.
  • ☐ OneDrive에서는 공간 확보와 파일 삭제를 구분했습니다.
  • ☐ 오프라인에서 필요한 파일은 온라인 전용으로 만들지 않았습니다.
  • ☐ 사용하지 않는 앱을 제거하기 전에 필요한 자료를 백업했습니다.
  • ☐ C드라이브와 다른 드라이브의 사용량을 구분해 확인했습니다.
  • ☐ 새 파일 저장 위치를 변경할 때 기존 파일이 자동 이동된다고 생각하지 않았습니다.
  • ☐ 작업을 마친 후 Windows 업데이트와 저장 공간 상태를 다시 확인했습니다.
  • ☐ 정체를 모르는 시스템 폴더나 복구 파일을 직접 삭제하지 않았습니다.

결론: 윈도우11 C드라이브 공간 부족은 먼저 저장소 사용량 확인 → 정리 권장 사항 → 저장소 센스 순서로 접근하는 것이 좋습니다. 개인 자료의 손실을 피하려면 다운로드 폴더, Windows.old, OneDrive 클라우드 파일을 같은 방식으로 취급하지 않는 것이 중요합니다. 확보 가능한 공간과 반드시 보존해야 하는 파일을 구분한 뒤 정리하는 편이 장기적으로 더 안전합니다.
