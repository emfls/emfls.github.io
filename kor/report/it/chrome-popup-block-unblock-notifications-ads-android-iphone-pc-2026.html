1. 크롬 팝업과 광고 알림이 다른 이유

Chrome의 팝업은 웹페이지가 새 창이나 별도의 대화창을 열려고 할 때 발생합니다. 로그인, 파일 선택, 결제 인증 같은 정상적인 기능에 사용되기도 하지만, 광고나 원치 않는 사이트 이동에도 이용될 수 있습니다.

반면 사이트 알림은 사용자가 과거에 '알림 허용'을 선택한 웹사이트가 브라우저의 알림 기능을 통해 새 소식을 보내는 방식입니다. Chrome을 사용하는 도중뿐 아니라 OS의 알림 영역에도 표시될 수 있으므로, 팝업 차단을 켜 두었는데 광고가 계속 뜰 수 있습니다.

'방해가 되는 광고'와 '멀웨어'도 구분해야 합니다

Chrome에는 오해의 소지가 있거나 사용자에게 방해가 되는 광고를 관리하는 별도 설정이 있습니다. 그리고 홈페이지·검색엔진이 갑자기 바뀌거나 원치 않는 확장 프로그램이 생기고 광고 탭이 계속 열리는 상황은 원치 않는 소프트웨어 또는 멀웨어의 가능성도 고려해야 합니다.

따라서 광고가 떠 있다는 이유만으로 휴대전화나 PC가 감염됐다고 확정할 수는 없습니다. 정상 사이트 팝업인지, 허용된 사이트 알림인지, 브라우저 설정을 바꾸는 프로그램인지 순서대로 살펴보는 것이 정확합니다.

2. PC에서 크롬 팝업 차단·해제하는 방법

Windows 11·Windows 10·Mac 컴퓨터의 데스크톱 Chrome에서는 개인 정보 보호 및 보안 → 사이트 설정 → 팝업 및 리디렉션을 이용합니다.

기본 팝업 설정 바꾸기

  1. 컴퓨터에서 Chrome을 엽니다.
  2. 오른쪽 위의 **점 세 개(더보기)**를 누릅니다.
  3. 설정을 선택합니다.
  4. 개인 정보 보호 및 보안으로 이동합니다.
  5. 사이트 설정 → 팝업 및 리디렉션을 선택합니다.
  6. 기본 동작에서 사이트에서 팝업을 전송하거나 리디렉션을 사용할 수 없음을 선택하면 차단합니다.
  7. 특별한 사유가 있는 경우에만 기본 동작을 변경하거나 아래의 사이트별 예외 허용을 이용합니다.

Chrome 주소 표시줄에 chrome://settings/content/popups를 직접 입력하면 관련 설정 화면으로 이동하는 방법도 있습니다. 경로가 달리 표시된다면 Chrome의 설정 메뉴에서 직접 찾아보세요.

팝업 차단을 아예 끄는 것은 권장하지 않습니다

정상적인 쇼핑몰이나 금융기관에서 결제창이 열리지 않을 때 모든 사이트 팝업 허용으로 바꾸기보다 해당 공식 사이트만 예외로 허용하는 편이 좋습니다. 팝업을 전부 허용하면 방문하는 다른 사이트의 새 창·리디렉션도 열릴 수 있기 때문입니다.

3. 결제창·본인인증창이 막혔을 때 PC에서 특정 사이트만 허용

온라인 쇼핑몰 주문 버튼이나 로그인 인증 버튼을 눌렀는데 아무 반응이 없다면 주소 표시줄의 팝업 차단 아이콘부터 확인하세요.

사이트별 팝업 일시 허용

  1. 실제로 이용하려는 공식 쇼핑몰 또는 본인인증 사이트에 접속합니다.
  2. 결제나 인증 버튼을 눌렀을 때 주소 표시줄에 팝업 차단됨 표시가 나타나는지 확인합니다.
  3. 해당 아이콘을 누릅니다.
  4. 차단된 팝업 링크 목록이 보이면 필요한 창을 선택합니다.
  5. 신뢰할 수 있는 사이트에서 반복적으로 팝업이 필요한 경우에만 해당 사이트의 팝업 및 리디렉션을 항상 허용을 선택한 뒤 완료합니다.

이미 허용한 사이트를 다시 차단하려면

  1. 설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 팝업 및 리디렉션으로 이동합니다.
  2. 팝업 전송 및 리디렉션 사용이 허용됨 목록에서 해당 사이트를 찾습니다.
  3. 오른쪽의 더보기 메뉴를 누릅니다.
  4. 차단을 선택합니다.

Google은 정상 웹사이트가 웹 콘텐츠를 팝업으로 제공할 수 있다고 명시합니다. 다만 팝업을 허용해도 사이트 자체의 서버 장애·결제 시스템 오류·확장 프로그램 문제까지 해결되는 것은 아닙니다.

4. 갤럭시 Android에서 크롬 팝업 차단·해제하는 방법

갤럭시와 다른 Android 휴대전화에서도 Chrome 자체의 팝업 차단 기능을 설정할 수 있습니다.

Android Chrome 팝업 차단

  1. Chrome 앱을 실행합니다.
  2. 주소 표시줄 오른쪽의 **점 세 개(더보기)**를 누릅니다.
  3. 설정을 탭합니다.
  4. 사이트 설정 → 팝업 및 리디렉션을 엽니다.
  5. 팝업 및 리디렉션을 사용 중지하면 팝업 차단이 적용됩니다.

공식 Android 도움말은 이 화면에서 팝업 및 리디렉션을 사용 중지하는 것이 차단 방법이라고 안내합니다. 사용자에게 표시되는 스위치 색이나 문구만 보고 혼동하지 말고 실제 설정 설명을 확인하세요.

갤럭시에서 정상 사이트 팝업만 열려면

  1. Chrome에서 해당 공식 사이트를 엽니다.
  2. 팝업이 차단되면 화면 아래쪽의 팝업 차단됨 안내를 확인합니다.
  3. 항상 표시를 선택하면 그 사이트의 차단된 팝업을 표시할 수 있습니다.
  4. 작업 후에는 해당 사이트의 팝업 권한을 다시 검토합니다.

Chrome 앱의 사이트별 권한은 웹주소 왼쪽 사이트 정보 보기 → 권한에서도 확인할 수 있습니다. 허용한 뒤 계속 광고창이 나타나면 해당 사이트를 다시 차단하세요.

5. 아이폰·아이패드 Chrome에서 팝업 차단·해제하는 방법

아이폰의 Chrome은 갤럭시와 메뉴 위치가 다릅니다. Google의 iPhone·iPad 공식 도움말은 설정 → 콘텐츠 설정 → 팝업 차단 경로를 안내합니다.

아이폰 Chrome 팝업 차단

  1. 아이폰에서 Chrome 앱을 엽니다.
  2. Chrome의 **더보기(점 세 개)**를 누릅니다.
  3. 설정을 선택합니다.
  4. 콘텐츠 설정 → 팝업 차단을 엽니다.
  5. 팝업 차단을 켭니다.

아이폰에서 필요한 팝업 열기

  1. Chrome 앱으로 실제 이용하려는 공식 웹사이트에 접속합니다.
  2. 팝업이 차단된 페이지에서 **화면 하단의 '팝업 차단됨'**을 확인합니다.
  3. 해당 안내에서 **'항상 표시'**를 선택합니다.
  4. 팝업이 열리는지 확인합니다.

아이폰의 기본 설정 앱에서 Safari의 팝업 차단을 변경하는 것은 Safari에 대한 설정입니다. 아이폰 Chrome에서 팝업을 허용하려면 Chrome 앱의 콘텐츠 설정을 확인하는 것이 맞습니다.

닫을 수 없는 이상한 팝업이 아이폰에 뜬다면?

Google은 iPhone·iPad Chrome에서 팝업이나 대화상자가 사라지지 않는 경우 비행기 모드를 켜고 Chrome을 종료한 뒤, 문제가 발생한 탭을 닫는 방법을 안내합니다. 이 과정에서 수상한 경고 화면의 '확인', '전화 연결', '보안 앱 설치' 버튼을 누르지 마세요.

6. 팝업 차단을 켰는데도 광고 알림이 계속 뜨는 이유

크롬을 실행하지 않았는데 윈도우 화면 오른쪽 아래나 갤럭시 알림창에 '쿠폰 지급', '바이러스 감염', '휴대전화 정리' 등의 광고가 보인다면 웹사이트에 알림 전송을 허용했는지 확인하세요.

Google은 Chrome 팝업 차단과 사이트 알림 권한이 별도 기능이라고 설명합니다. 따라서 팝업 차단을 켜더라도 예전에 알림 수신에 동의한 사이트가 메시지를 보낼 수 있습니다.

광고 알림의 출처를 확인하는 법

  1. 알림을 누르기 전에 어떤 앱 또는 웹사이트에서 보냈는지 확인합니다.
  2. Chrome의 사이트 알림으로 확인된다면 다음 단락의 알림 권한 설정으로 이동합니다.
  3. 실제 발신자를 모르는 상황에서는 알림에 포함된 결제·보안점검 링크를 클릭하지 않습니다.
  4. 정상적인 주문 배송 알림이나 업무 메시지와 혼동하지 않도록 필요한 사이트는 따로 남깁니다.

알림을 차단한다고 이미 설치된 악성앱이 치료되는 것은 아닙니다. 알림 설정을 바꿨는데도 홈페이지가 바뀌거나 광고 탭이 자동으로 열리면 확장 프로그램과 설치 앱을 추가로 점검해야 합니다.

7. PC 크롬 웹사이트 광고 알림 끄기: 사이트별 차단

정상적인 이메일이나 업무 알림까지 모두 차단할 필요는 없습니다. 문제가 되는 웹사이트의 알림 권한만 끄는 방법부터 사용하세요.

PC에서 개별 사이트 알림 차단

  1. PC Chrome 오른쪽 위의 더보기 → 설정을 엽니다.
  2. 개인 정보 보호 및 보안 → 사이트 설정 → 알림으로 이동합니다.
  3. 알림 전송이 허용됨 목록에서 수상한 사이트를 확인합니다.
  4. 사이트 옆의 더보기에서 차단 또는 삭제를 선택합니다.
  5. 정상적으로 필요한 서비스의 알림까지 꺼지지 않았는지 확인합니다.

Chrome 공식 도움말은 사이트별 알림 허용·차단을 지원한다고 안내합니다. 알림을 모두 차단하고 싶다면 기본 알림 설정을 변경할 수 있지만, 회의·메일·협업 도구 알림을 이용한다면 불편할 수 있습니다.

지금 열린 사이트의 알림만 끄기

  1. 해당 웹사이트에 접속합니다.
  2. 주소 표시줄 왼쪽 사이트 정보 보기 아이콘을 누릅니다.
  3. 알림 권한을 찾습니다.
  4. 차단으로 변경합니다.

일부 Chrome 버전에서는 사이트 정보 보기 후 사이트 설정으로 들어가야 할 수 있습니다. Chrome의 설정 메뉴에서 사이트 설정 → 알림을 찾아도 같은 권한을 관리할 수 있습니다.

'조용한 알림 메시지'는 무엇인가요?

Chrome은 웹사이트가 알림 허용을 요청할 때 크게 방해하지 않도록 조용한 메시지 사용 옵션을 제공합니다. 이는 모든 사이트 알림을 무조건 허용하거나 차단하는 것과는 다릅니다.

8. 갤럭시에서 크롬 광고 알림 끄기

갤럭시에서 특정 사이트의 광고 알림이 반복된다면 Chrome 앱 내부의 사이트 설정 → 알림부터 확인하세요.

모든 웹사이트의 알림 요청을 관리하는 방법

  1. 갤럭시에서 Chrome 앱을 엽니다.
  2. 주소 표시줄 오른쪽의 더보기 → 설정으로 이동합니다.
  3. 사이트 설정 → 알림을 엽니다.
  4. 화면 위쪽의 기본 알림 사용 또는 사용 중지 상태를 확인합니다.
  5. 필요한 경우 전체 웹사이트 알림 요청을 끕니다.
  6. 정상적인 서비스 알림이 필요한 경우에는 해당 사이트만 허용하는 방법을 검토합니다.

수상한 사이트 한 곳만 차단하는 방법

  1. 알림을 보낸 것으로 의심되는 웹사이트의 실제 주소를 확인합니다.
  2. Chrome에서 해당 사이트 → 주소 표시줄 왼쪽 사이트 정보 보기 → 권한으로 이동합니다.
  3. 알림을 선택합니다.
  4. 알림을 차단하거나 사이트 권한을 재설정합니다.

Chrome은 스팸으로 판단한 사이트 알림에서 **'수신 거부'**와 **'Chrome에 스팸 신고'**를 제공할 수도 있습니다. 이때 스팸 신고를 선택하면 알림 내용과 사이트 URL이 Google에 전송될 수 있다는 점도 공식 도움말에 명시되어 있습니다.

Chrome에서 웹사이트 알림은 차단했지만 갤럭시 알림이 계속 뜬다면

알림을 보낸 앱이 Chrome이 아닌 다른 앱일 수도 있습니다. 갤럭시 설정의 앱별 알림 목록을 확인해 실제 발신 앱을 식별하세요. 무조건 모든 시스템 알림을 꺼 버리기보다는 광고를 발생시키는 앱을 정확히 찾는 것이 중요합니다.

9. 정상 사이트에서 알림·팝업이 다시 필요할 때 복구하기

회사 협업 서비스, 은행의 정상 인증 화면, 화상회의 도구 등에서는 필요한 팝업과 알림까지 차단하면 서비스가 제대로 작동하지 않을 수 있습니다.

팝업만 다시 허용하려면

설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 팝업 및 리디렉션으로 이동한 후 실제 사용하는 신뢰할 수 있는 사이트를 예외 허용 목록에 추가하세요.

알림만 다시 허용하려면

설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 알림에서 해당 사이트의 알림 권한을 허용으로 바꿀 수 있습니다.

Android 사이트 권한을 재설정했다면

Chrome에서 해당 사이트로 이동해 사이트 정보 보기 → 권한에서 다시 필요한 항목만 허용하면 됩니다. 설정을 되돌렸더라도 사이트가 작동하지 않는다면 사이트 자체의 오류나 쿠키·로그인 상태 등 다른 원인을 확인해야 합니다.

사용하지 않는 사이트의 권한이 자동 삭제되기도 하나요?

Google은 한동안 방문하지 않은 사이트의 알림 권한을 Chrome이 자동으로 제거할 수 있다고 설명합니다. 따라서 이전에는 알림이 오던 사이트에서 다시 허용 요청이 나오는 일이 반드시 보안 사고인 것은 아닙니다. Chrome의 안전 확인에서 제거된 권한을 검토할 수 있습니다.

10. 광고 새 탭·홈페이지 변경이 계속된다면 확장 프로그램 확인

단순히 웹사이트 팝업을 허용했기 때문이 아니라 Chrome 확장 프로그램이나 컴퓨터의 원치 않는 소프트웨어가 설정을 변경했을 수 있습니다.

Google Chrome 공식 도움말은 다음 증상을 원치 않는 소프트웨어 또는 멀웨어 관련 징후로 소개합니다.

  • 팝업 광고와 새 탭이 좀처럼 사라지지 않음
  • 홈페이지나 기본 검색엔진이 사용자 동의 없이 계속 바뀜
  • 설치한 기억이 없는 확장 프로그램·툴바가 표시됨
  • 모르는 사이트로 자동 리디렉션됨
  • 브라우저에서 바이러스 감염을 주장하는 경고가 반복됨

PC Chrome 확장 프로그램 확인 방법

  1. Chrome 오른쪽 위의 더보기 → 확장 프로그램 → 확장 프로그램 관리를 엽니다.
  2. 현재 설치된 확장 프로그램 목록을 살펴봅니다.
  3. 본인이 직접 설치하지 않았거나 출처가 불분명한 확장 프로그램이 있는지 확인합니다.
  4. 수상한 확장 프로그램을 사용 중지하고 증상이 사라지는지 살펴봅니다.
  5. 확실히 불필요한 확장 프로그램은 제거를 검토합니다.

주의: 업무용 프로그램 또는 회사에서 정책상 설치한 확장 프로그램을 임의 삭제하지 마세요. 회사·학교에서 관리하는 브라우저라면 관리자에게 문의하는 편이 안전합니다.

컴퓨터의 설치된 앱도 확인

Windows에서는 시작 → 설정 → 앱 → 설치된 앱, Mac에서는 Finder → 응용 프로그램에서 원치 않는 프로그램을 확인할 수 있습니다. 최근 설치된 프로그램 가운데 출처가 의심스럽거나 동의 없이 설치된 항목은 제거를 검토하세요.

단순히 이름을 모른다고 시스템 필수 앱을 삭제하면 다른 기능에 문제가 생길 수 있습니다. 앱의 게시자와 설치 경로를 확인하고 불확실하다면 공식 지원을 이용하세요.

11. 크롬 설정 초기화는 언제 해야 하나요? 북마크·비밀번호는?

사이트의 팝업·알림 권한을 조정하고 원치 않는 확장 프로그램을 점검했는데도 홈페이지나 검색엔진이 계속 바뀐다면 Chrome 설정 초기화를 검토할 수 있습니다.

PC Chrome 설정을 기본값으로 복원하기

  1. Chrome 오른쪽 위에서 더보기 → 설정을 엽니다.
  2. 왼쪽 메뉴에서 설정 초기화를 선택합니다.
  3. 다음 설정을 기본값으로 복원을 선택합니다.
  4. 변경될 항목을 확인합니다.
  5. 설정 초기화를 실행합니다.
  6. 브라우저를 다시 열어 팝업·알림 설정과 확장 프로그램 상태를 확인합니다.

Google 공식 도움말에 따르면 이 초기화로 저장한 북마크와 비밀번호는 삭제되거나 변경되지 않습니다. 그러나 기본 검색엔진, 홈페이지·시작 페이지, 고정 탭, 콘텐츠 설정, 확장 프로그램 사용 상태 등에는 영향을 줄 수 있습니다.

따라서 설정 초기화와 인터넷 사용 기록·쿠키 전체 삭제, Chrome 앱 제거, Google 계정 삭제는 서로 다른 작업입니다. 작업을 시작하기 전에 필요한 로그인 정보·장바구니 상태 등 변동 가능성을 고려하세요.

초기화 후 확장 프로그램은?

일부 확장 프로그램이 비활성화될 수 있습니다. 이후 정말 필요한 신뢰 가능한 확장 프로그램만 다시 활성화하세요. 문제가 해결되지 않는다면 PC에 설정을 다시 변경하는 프로그램이 남아 있는지 확인해야 합니다.

12. '바이러스 감염' 팝업을 눌렀다면 어떻게 하나요?

웹페이지가 갑자기 **'휴대전화가 감염되었습니다', '지금 보안 프로그램을 설치하세요', '계좌 보안을 위해 인증번호를 입력하세요'**라고 경고할 수 있습니다. 하지만 웹페이지에서 표시된 경고만으로 실제 기기가 악성코드에 감염됐다고 단정할 수는 없습니다.

경고를 보기만 한 경우

  1. 경고창의 다운로드·전화 연결·결제 버튼을 누르지 않습니다.
  2. 해당 페이지나 탭을 닫습니다.
  3. Chrome의 사이트 알림 권한에서 수상한 사이트가 허용돼 있는지 확인합니다.
  4. 최근에 알 수 없는 앱이나 확장 프로그램을 설치했는지 살펴봅니다.
  5. 이후 광고가 계속 나타나는지 확인합니다.

알림을 클릭해 설치 파일을 다운로드한 경우

다운로드만 했는지 실제로 실행·설치했는지를 구분해야 합니다. 파일을 실행하거나 앱 권한을 허용했다면 단순 사이트 알림보다 위험 수준이 높을 수 있습니다. Chrome의 세이프 브라우징·운영체제 보안 기능으로 점검하고, 필요하면 제조사나 공신력 있는 보안 상담 채널을 이용하세요.

계정·결제정보를 입력했다면

가짜 페이지에서 비밀번호, 인증번호, 카드정보를 입력했다면 악성앱을 설치하지 않았더라도 피싱 피해 위험이 있습니다. 다른 안전한 기기에서 실제 서비스의 공식 사이트로 직접 이동해 계정 보안 조치를 하고, 금융정보를 입력했다면 카드사·은행 공식 고객센터에 즉시 문의하세요.

Google은 수상한 업데이트·다운로드 팝업을 클릭하지 말고 해당 프로그램 공식 사이트에서 다운로드하도록 권고합니다. 출처가 불명확한 '광고 제거 프로그램'을 추가로 설치하는 행동은 피하세요.

13. 갤럭시 광고가 계속 뜬다면 Android 앱도 검사해야 할까요?

크롬 팝업을 차단하고 사이트 알림까지 껐는데도 광고가 계속 뜬다면 다른 Android 앱에서 발생시키는 광고일 수 있습니다.

Google은 Android의 원치 않는 광고·팝업 해결 안내에서 문제를 일으키는 앱을 삭제하고, Play 프로텍트가 활성화돼 있는지 확인하는 방법을 설명합니다.

점검 순서

  1. 광고가 나타날 때 알림이나 화면에 표시된 앱 이름이 무엇인지 확인합니다.
  2. 최근 설치한 앱 가운데 사용 목적이 불분명한 앱을 확인합니다.
  3. Google Play 스토어 → 프로필 → Play 프로텍트로 들어가 검사 상태를 확인합니다.
  4. 유해 앱 경고가 있다면 Google의 안내에 따라 조치합니다.
  5. 감염 의심이 강한 경우 공식 Android·휴대전화 제조사 지원 경로를 참고합니다.

Google은 상황에 따라 Android 안전 모드에서 문제 앱을 제거하는 방법도 안내합니다. 다만 안전 모드 진입·종료 방법은 제조사와 기기마다 다를 수 있고, 정상 시스템 앱을 삭제하면 문제가 커질 수 있습니다. 원인을 확신하지 못하면 무리하게 조작하지 말고 공식 서비스센터에 상담하세요.

Chrome 앱의 팝업 차단 기능과 Android에서 설치한 다른 앱의 전체 화면 광고는 같은 설정이 아닙니다. 실제 원인을 확인한 뒤 그 앱이나 사이트의 권한을 관리해야 합니다.

14. 팝업이 꼭 필요한 정상 사이트 이용 시 5가지 확인사항

은행·공공기관·온라인쇼핑몰에서는 보안 프로그램 안내나 결제창 때문에 팝업 관련 문제를 겪을 수 있습니다. 하지만 팝업 차단을 해제해도 모든 본인인증 문제가 해결되는 것은 아닙니다.

  1. 실제 접속한 URL이 공식 기관·사업자의 주소인지 확인합니다.
  2. 주소 표시줄의 팝업 차단 아이콘이 있는지 확인합니다.
  3. 팝업이 차단됐다면 해당 공식 사이트에 한해 허용합니다.
  4. 계속 작동하지 않으면 다른 확장 프로그램·쿠키·사이트 자체 오류 가능성을 점검합니다.
  5. 업무를 마친 뒤 사이트별 팝업 허용 목록에 불필요한 예외가 남아 있는지 확인합니다.

회사·학교의 관리형 Chrome이라면?

Google은 회사나 학교에서 관리하는 Chrome에서는 관리자가 팝업 정책을 지정할 수 있다고 설명합니다. 설정이 회색으로 표시되거나 저장되지 않는 경우, 기관이 허용하는 범위에서만 변경해야 하므로 IT 관리자에게 문의하세요.

무조건 '모든 팝업 허용'이 필요한가요?

아닙니다. Google은 정상 사이트도 팝업을 이용할 수 있으나 사이트별로 팝업 허용이 가능하다고 안내합니다. 필요한 사이트만 선택하는 방식이 보안과 편의성의 균형에 도움이 됩니다.

자주 묻는 질문 FAQ

Q1. 크롬 팝업 차단은 PC에서 어디서 켜나요?

Chrome 설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 팝업 및 리디렉션에서 기본 동작을 차단으로 설정합니다. Chrome은 기본적으로 팝업을 차단합니다.

Q2. 갤럭시에서 크롬 팝업 차단을 해제하는 방법은?

Chrome 앱의 더보기 → 설정 → 사이트 설정 → 팝업 및 리디렉션을 확인합니다. 정상 사이트 하나만 허용하려면 페이지 하단의 팝업 차단됨 → 항상 표시를 이용할 수 있습니다.

Q3. 아이폰 크롬에서 팝업 차단 해제는 어디에 있나요?

iPhone Chrome 앱에서 더보기 → 설정 → 콘텐츠 설정 → 팝업 차단으로 이동해 설정을 바꿀 수 있습니다. Safari의 팝업 차단 설정과는 별개입니다.

Q4. 팝업 차단을 켰는데도 광고 알림이 계속 뜨는 이유는?

웹사이트 알림을 별도로 허용했을 수 있습니다. Chrome 설정 → 사이트 설정 → 알림에서 알림 전송을 허용한 사이트를 확인하고 차단하세요.

Q5. 크롬에서 쇼핑몰 결제창이 안 뜨면 모든 팝업을 허용해야 하나요?

그럴 필요는 없습니다. 공식 사이트에서 주소 표시줄의 팝업 차단 아이콘을 눌러 해당 사이트만 허용할 수 있습니다. 결제 시스템 자체 오류는 별도로 확인해야 합니다.

Q6. 갤럭시에 '바이러스가 발견됐다'는 광고가 계속 뜨면 실제 감염인가요?

광고 알림이나 가짜 웹페이지 경고만으로 감염이 확정된 것은 아닙니다. 출처를 확인하고 사이트 알림을 차단하세요. 수상한 앱·파일을 설치했다면 Play 프로텍트와 제조사 보안 지원을 이용해 점검해야 합니다.

Q7. 크롬 사이트 알림을 전부 끄면 이메일 알림도 안 오나요?

Chrome의 웹사이트 알림을 모두 차단하면 해당 브라우저에서 웹사이트가 보내는 알림도 제한될 수 있습니다. 정상적인 메일·업무 사이트 알림까지 필요하다면 특정 수상한 사이트만 차단하는 것이 좋습니다.

Q8. 크롬 설정 초기화하면 북마크와 비밀번호가 삭제되나요?

Google 공식 안내에 따르면 설정 초기화로 저장된 북마크와 비밀번호는 삭제되거나 변경되지 않습니다. 다만 홈페이지, 검색엔진, 사이트 권한, 확장 프로그램 등 다른 설정은 변경될 수 있습니다.

Q9. 팝업 차단 기능을 끄면 광고도 전부 표시되지 않나요?

반대입니다. 팝업 차단을 끄면 사이트의 팝업이나 리디렉션이 더 많이 표시될 수 있습니다. 원치 않는 광고를 줄이는 것이 목적이라면 팝업 차단을 켜고 웹사이트 알림은 별도로 관리하세요.

Q10. 크롬 팝업 설정이 계속 바뀌는데 어떻게 해야 하나요?

설치를 기억하지 못하는 확장 프로그램이나 원치 않는 PC 소프트웨어가 설정을 변경했을 수 있습니다. 해당 프로그램을 점검하고 필요하면 Chrome 설정 초기화를 검토하세요. 회사 관리 PC에서는 관리자 정책 여부도 확인해야 합니다.
