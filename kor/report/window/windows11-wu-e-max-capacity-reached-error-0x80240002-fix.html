Windows 11 0x80240002 WU_E_MAX_CAPACITY_REACHED 해결 가이드

핵심 요약 (Key Takeaways)
  • Windows 11에서 0x80240002 WU_E_MAX_CAPACITY_REACHED 오류는 업데이트 시스템이 최대 용량에 도달했을 때 발생하며, 디스크 공간 부족과 업데이트 캐시 오버플로우가 주요 원인입니다.
  • 디스크 정리, Windows Update 캐시 및 배달 최적화 캐시 정리, 임시 파일 삭제, 시스템 복원 지점 관리, 페이지 파일 크기 조정 등 단계별 해결 방법을 따라야 합니다.
  • 각 방법별 소요 시간과 난이도를 고려해 우선 디스크 공간 확보와 캐시 정리를 진행하고, 필요 시 외부 저장소 활용으로 용량 문제를 완벽히 해결하세요.
30초 요약

먼저 디스크 여유 공간을 확인하세요. 공간이 부족하면 임시 파일과 업데이트 캐시, 배달 최적화 캐시 정리를 검토하세요.

⚠️ 주의사항: 이 오류는 Windows Update 시스템에서 최대 용량에 도달했을 때 발생하는 오류입니다. 디스크 공간 부족이나 업데이트 캐시 오버플로우가 주요 원인입니다.

🔍 오류 개요

0x80240002 WU_E_MAX_CAPACITY_REACHED는 Windows 11에서 업데이트 시스템이 최대 용량 한계에 도달했을 때 발생하는 오류입니다. 이 오류는 주로 다음과 같은 원인으로 발생합니다:

  • 시스템 드라이브(C:) 디스크 공간 부족
  • Windows Update 캐시 폴더 오버플로우
  • 임시 파일 누적으로 인한 공간 부족
  • 업데이트 다운로드 폴더 용량 한계
  • 시스템 복원 지점 과다 생성
  • 페이지 파일 크기 부족
  • 배달 최적화 캐시 오버플로우
  • Windows.old 폴더 누적

🛠️ 해결 방법

방법 1: 디스크 공간 확보

1 디스크 정리 도구 실행:
  • Windows + R 키를 누르고 cleanmgr 입력
  • 시스템 드라이브(C:) 선택
  • 다음 항목들을 체크하여 삭제:
    • 임시 파일
    • 시스템 오류 메모리 덤프 파일
    • Windows Update 정리
    • 이전 Windows 설치 (Windows.old)
    • 휴지통
    • 임시 인터넷 파일
2 저장소 센스 활성화:
  • 설정 → 시스템 → 저장소
  • "저장소 센스" 활성화
  • "저장소 센스 구성" 클릭
  • 자동 정리 주기를 "매주" 또는 "매월"로 설정
  • "지금 정리" 클릭하여 즉시 정리

방법 2: Windows Update 캐시 정리

1 Windows Update 서비스 중지:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어들을 순서대로 실행:
net stop wuauserv
net stop cryptSvc
net stop bits
net stop dosvc
2 업데이트 캐시 폴더 정리:
  • 다음 명령어로 캐시 폴더 내용 삭제:
del /f /s /q %windir%\SoftwareDistribution\Download\*.*
del /f /s /q %windir%\SoftwareDistribution\DataStore\*.*
rd /s /q %windir%\SoftwareDistribution\Download
rd /s /q %windir%\SoftwareDistribution\DataStore
3 서비스 재시작:
  • 다음 명령어들을 실행하여 서비스 재시작:
net start wuauserv
net start cryptSvc
net start bits
net start dosvc

방법 3: 배달 최적화 캐시 정리

1 배달 최적화 설정 확인:
  • 설정 → 업데이트 및 보안 → 배달 최적화
  • "고급 옵션" 클릭
  • 현재 캐시 사용량 확인
  • 필요시 캐시 크기 제한 설정
2 배달 최적화 캐시 삭제:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어 실행:
net stop dosvc
del /f /s /q %windir%\ServiceProfiles\NetworkService\AppData\Local\Microsoft\Windows\DeliveryOptimization\Cache\*.*
net start dosvc

방법 4: 임시 파일 정리

1 시스템 임시 파일 삭제:
  • 다음 명령어들을 실행하여 임시 파일 삭제:
del /f /s /q %temp%\*.*
del /f /s /q %windir%\Temp\*.*
del /f /s /q %windir%\Prefetch\*.*
del /f /s /q %windir%\Logs\*.*
2 사용자 임시 파일 정리:
  • Windows + R 키를 누르고 %temp% 입력
  • 임시 파일 폴더에서 모든 파일 선택 후 삭제
  • 삭제할 수 없는 파일은 건너뛰기

방법 5: 시스템 복원 지점 정리

1 시스템 복원 설정 확인:
  • 제어판 → 시스템 및 보안 → 시스템 → 시스템 보호
  • "구성" 버튼 클릭
  • 현재 디스크 사용량 확인
  • 최대 사용량을 적절히 조정 (5-10%)
2 이전 복원 지점 삭제:
  • "삭제" 버튼 클릭
  • "가장 오래된 복원 지점을 제외한 모든 복원 지점 삭제" 선택
  • 또는 명령 프롬프트에서 다음 명령어 실행:
vssadmin delete shadows /all /quiet
wmic shadowcopy delete

방법 6: 페이지 파일 크기 조정

1 가상 메모리 설정 확인:
  • 제어판 → 시스템 및 보안 → 시스템 → 고급 시스템 설정
  • "고급" 탭 → "성능" 섹션의 "설정" 클릭
  • "고급" 탭 → "가상 메모리" 섹션의 "변경" 클릭
2 페이지 파일 크기 조정:
  • "모든 드라이브에 대한 페이징 파일 크기 자동 관리" 체크 해제
  • 시스템 드라이브 선택 후 "사용자 지정 크기" 선택
  • 초기 크기: RAM 크기 × 1.5
  • 최대 크기: RAM 크기 × 3
  • "설정" → "확인" 클릭 후 재부팅

방법 7: 디스크 압축 및 정리

1 시스템 파일 압축:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 시스템 파일 압축:
compact /c /s:C:\ /i /a
compact /c /s:C:\Windows /i /a
  • 압축 완료까지 기다리기 (시간 소요)
2 WinSxS 폴더 정리:
  • 다음 명령어로 구성 요소 저장소 정리:
DISM /Online /Cleanup-Image /StartComponentCleanup
DISM /Online /Cleanup-Image /StartComponentCleanup /ResetBase
DISM /Online /Cleanup-Image /SPSuperseded

방법 8: 외부 저장소 활용

1 업데이트 다운로드 위치 변경:
  • 외부 USB 드라이브 또는 추가 하드 드라이브 연결
  • 충분한 여유 공간 확보 (최소 20GB)
  • 임시로 업데이트 파일을 외부 저장소에 다운로드
2 사용자 폴더 이동:
  • 문서, 사진, 비디오 등 사용자 폴더를 외부 드라이브로 이동
  • 각 폴더 우클릭 → "속성" → "위치" 탭
  • "이동" 버튼 클릭하여 새 위치 지정
  • 시스템 드라이브 공간 확보

  • cleanmgr /sagerun:1: 자동 디스크 정리 실행

시스템 정리 명령어

  • sfc /scannow: 시스템 파일 검사

디스크 정리 시 주의점

  • 중요한 파일은 미리 백업하세요
  • 시스템 복원 지점 삭제 시 신중하게 결정하세요
  • 페이지 파일 크기 변경 후 시스템 성능을 모니터링하세요
  • 디스크 압축은 시스템 성능에 영향을 줄 수 있습니다
  • 외부 저장소 사용 시 안정적인 연결을 유지하세요
  • 정리 작업 중에는 다른 프로그램 사용을 자제하세요

언제 전문가의 도움이 필요한가?

  • 시스템 드라이브 용량이 극도로 부족한 경우
  • 하드웨어 업그레이드가 필요한 경우
  • 디스크 오류가 발생한 경우
  • 시스템 파일이 심각하게 손상된 경우

  • 시스템 드라이브에 최소 20% 여유 공간 유지
  • 불필요한 프로그램 정기적 제거
  • 대용량 파일은 외부 저장소에 보관
  • 시스템 복원 지점 개수 제한 설정
  • 임시 파일 자동 정리 설정

💡 추가 팁

자주 묻는 질문 (FAQ)

0x80240002 WU_E_MAX_CAPACITY_REACHED 오류는 무엇인가요?

이 오류는 Windows 11 업데이트 시스템이 최대 용량 한계에 도달했을 때 발생하며, 주로 디스크 공간 부족과 업데이트 캐시 폴더 오버플로우가 원인입니다.

이 오류를 해결하기 위한 첫 번째 단계는 무엇인가요?

첫 번째 단계는 디스크 정리 도구를 사용해 임시 파일, 이전 Windows 설치 파일, 휴지통 등을 삭제하여 시스템 드라이브(C:)의 공간을 확보하는 것입니다.

Windows Update 캐시를 어떻게 정리하나요?

관리자 권한 명령 프롬프트에서 Windows Update 관련 서비스를 중지한 후 SoftwareDistribution 폴더 내 Download와 DataStore 폴더 내용을 삭제하고, 서비스를 다시 시작하면 됩니다.

이 가이드를 통해 Windows Update 용량 한계 문제가 해결되기를 바랍니다. 디스크 공간 관련 문제가 지속되면 하드웨어 업그레이드를 고려하시기 바랍니다.
