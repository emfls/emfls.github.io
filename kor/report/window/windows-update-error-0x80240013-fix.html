Windows 0x80240013 WU_E_DUPLICATE_ITEM 오류 해결 가이드

⚠️ 주의사항: 이 오류는 Windows Update 과정에서 중복된 업데이트 항목이 감지되었을 때 발생하는 문제입니다. 업데이트 목록의 중복 항목이나 손상된 업데이트 메타데이터가 원인일 수 있으므로 신중하게 해결 방법을 적용하시기 바랍니다.

🔍 오류 개요

0x80240013 (WU_E_DUPLICATE_ITEM)는 Windows Update 시스템에서 중복된 업데이트 항목이 감지되었을 때 발생하는 오류입니다. 이 오류는 주로 다음과 같은 원인으로 발생합니다:

  • Windows Update 목록에 중복된 업데이트 항목 존재
  • 손상된 Windows Update 데이터베이스
  • 업데이트 메타데이터의 중복 정보
  • Windows Update 캐시 파일의 중복 항목
  • 이전 업데이트 설치 실패로 인한 잔여 데이터
  • 업데이트 서버에서 전송된 중복 데이터
  • 시스템 파일 손상으로 인한 중복 인식 오류
  • 타사 소프트웨어의 Windows Update 간섭
  • 레지스트리 손상으로 인한 중복 항목 생성
  • WSUS 서버 설정 오류로 인한 중복 항목

🛠️ 해결 방법

방법 1: Windows Update 문제 해결사 실행

1 Windows Update 문제 해결사 실행:
  • 설정 → 업데이트 및 보안 → 문제 해결
  • "Windows Update" 선택
  • "문제 해결사 실행" 클릭
  • 자동 진단 및 수정 과정 완료
2 고급 문제 해결사 및 중복 항목 검사:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어 실행:
msdt.exe -id WindowsUpdateDiagnostic
msdt.exe -id SystemMaintenanceDiagnostic
msdt.exe -id WindowsUpdateDiagnostic -advanced

방법 2: Windows Update 중복 항목 제거

1 모든 Windows Update 관련 서비스 중지:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어들을 순서대로 실행:
net stop wuauserv
net stop cryptSvc
net stop bits
net stop msiserver
net stop appidsvc
net stop dosvc
net stop UsoSvc
net stop WaaSMedicSvc
net stop TrustedInstaller
2 Windows Update 중복 데이터 및 캐시 완전 삭제:
  • 다음 명령어들을 실행하여 중복 데이터 제거:
rd /s /q C:\Windows\SoftwareDistribution
rd /s /q C:\Windows\System32\catroot2
rd /s /q %ALLUSERSPROFILE%\Microsoft\Network\Downloader
rd /s /q %windir%\WindowsUpdate.log
del /f /s /q %windir%\Logs\WindowsUpdate\*
del /f /s /q %temp%\*
del /f /s /q %windir%\Temp\*
del /f /s /q %ALLUSERSPROFILE%\Microsoft\Windows\WER\*
del /f /s /q %windir%\Prefetch\*
3 Windows Update 서비스 재시작 및 데이터 재생성:
  • 다음 명령어들을 실행:
net start wuauserv
net start cryptSvc
net start bits
net start msiserver
net start appidsvc
net start dosvc
net start UsoSvc
net start WaaSMedicSvc

방법 3: DISM 및 SFC 시스템 복구

1 DISM 시스템 이미지 복구:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어들을 순서대로 실행:
DISM /Online /Cleanup-Image /CheckHealth
DISM /Online /Cleanup-Image /ScanHealth
DISM /Online /Cleanup-Image /RestoreHealth /Source:C:\Windows\WinSxS /LimitAccess
DISM /Online /Cleanup-Image /StartComponentCleanup /ResetBase
DISM /Online /Cleanup-Image /AnalyzeComponentStore
2 SFC 시스템 파일 검사 및 복구:
  • DISM 명령 완료 후 다음 명령어 실행:
sfc /scannow
sfc /verifyonly
sfc /scanfile=C:\Windows\System32\wuaueng.dll
sfc /scanfile=C:\Windows\System32\wuapi.dll
sfc /scanfile=C:\Windows\System32\wups.dll
sfc /scanfile=C:\Windows\System32\wucltux.dll
  • 스캔 완료 후 시스템 재부팅

방법 5: Windows Update 레지스트리 완전 재설정

1 레지스트리 백업:
  • Windows + R 키를 누르고 regedit 입력
  • 파일 → 내보내기로 전체 레지스트리 백업
  • 안전한 위치에 백업 파일 저장
2 Windows Update 중복 항목 관련 레지스트리 키 삭제:
  • 다음 경로들의 키를 삭제:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Validation
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\wuauserv\Parameters
3 Windows Update 정책 및 중복 처리 레지스트리 재설정:
  • 다음 경로의 키들을 삭제:

  • 레지스트리 편집기 종료 후 재부팅

방법 6: 중복 업데이트 수동 제거 및 설치

1 설치된 업데이트 목록 확인:
  • 관리자 권한으로 PowerShell 실행
  • 다음 명령어로 설치된 업데이트 확인:
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 20
dism /online /get-packages | findstr "Install"
wmic qfe list brief /format:table
2 중복 업데이트 식별 및 제거:
  • Microsoft Update Catalog에서 업데이트 정보 확인
  • 중복된 업데이트 식별
  • 필요시 중복 업데이트 제거:
wusa /uninstall /kb:[KB번호] /quiet /norestart
dism /online /remove-package /packagename:[패키지명]
3 업데이트 순차 재설치:
  • 서비스 스택 업데이트부터 순차적으로 설치:
wusa.exe [서비스스택업데이트].msu /quiet /norestart
shutdown /r /t 60
wusa.exe [누적업데이트].msu /quiet /norestart
shutdown /r /t 60

방법 7: 네트워크 및 보안 설정 최적화

1 네트워크 설정 재설정:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어들을 순서대로 실행:
ipconfig /flushdns
ipconfig /registerdns
ipconfig /release
ipconfig /renew
netsh winsock reset
netsh int ip reset
netsh winhttp reset proxy
netsh winhttp reset tracing
2 보안 소프트웨어 및 방화벽 설정:
  • Windows Defender 방화벽에서 Windows Update 허용
  • 타사 보안 소프트웨어 임시 비활성화
  • 프록시 서버 설정 확인 및 해제
  • VPN 연결 해제 후 업데이트 시도
  • DNS 서버를 Google DNS (8.8.8.8, 8.8.4.4)로 변경

방법 8: PowerShell을 이용한 고급 복구

1 PowerShell Windows Update 모듈 설치 및 설정:
  • PowerShell을 관리자 권한으로 실행
  • 다음 명령어들을 실행:
Set-ExecutionPolicy RemoteSigned -Force
Install-Module PSWindowsUpdate -Force
Import-Module PSWindowsUpdate
Add-WUServiceManager -ServiceID 7971f918-a847-4430-9279-4a52d1efe18d -Confirm:$false
Set-WUSettings -AcceptTrustedPublisherCerts
2 중복 항목 검사 및 업데이트 설치:
  • 다음 명령어들을 실행:
Get-WindowsUpdate -Verbose | Group-Object Title | Where-Object {$_.Count -gt 1}
Get-WindowsUpdate -Verbose | Select-Object Title, Size, RebootRequired, Categories
Install-WindowsUpdate -AcceptAll -IgnoreReboot -Verbose
Get-WindowsUpdateLog -LogPath C:\WindowsUpdate.log
Get-WUHistory | Where-Object {$_.Result -eq "Failed"}
Reset-WUComponents -Verbose

중복 항목 오류 해결 시 주의점

  • 시스템 복구 지점을 미리 생성하세요
  • 중요한 데이터는 백업 후 작업하세요
  • 레지스트리 수정 전 반드시 백업을 생성하세요
  • 업데이트 제거 시 시스템 안정성을 고려하세요
  • 중복 업데이트 식별 시 신중하게 판단하세요
  • 업데이트 설치 순서를 정확히 따르세요
  • 각 업데이트 설치 후 반드시 재부팅하세요
  • DISM 및 SFC 스캔은 시간이 오래 걸릴 수 있습니다

언제 전문가의 도움이 필요한가?

  • 모든 해결 방법을 시도했지만 문제가 지속되는 경우
  • 중복 항목 제거 시 시스템 불안정이 발생하는 경우
  • 기업 환경에서 WSUS 또는 그룹 정책 관련 문제
  • 시스템 파일 손상이 심각하여 복구가 불가능한 경우
  • 업데이트 제거 후 시스템 기능에 문제가 발생하는 경우
  • 하드웨어 호환성 문제로 인한 업데이트 실패
  • 시스템 전체 재설치가 필요한 경우

✅ 예방 방법

  • 정기적인 Windows Update 자동 설치 설정
  • 업데이트 설치 전 중복 항목 확인
  • 서비스 스택 업데이트 우선 설치
  • 안정적인 인터넷 연결 환경 유지
  • 시스템 복구 지점 정기 생성
  • 보안 소프트웨어 정기 업데이트
  • 디스크 공간 충분히 확보 (최소 20GB 이상)
  • 정기적인 시스템 파일 검사 (월 1회)
  • 업데이트 설치 후 시스템 안정성 확인

💡 추가 팁

  • 중복 항목 오류는 주로 업데이트 메타데이터 손상으로 발생합니다
  • 서비스 스택 업데이트는 다른 업데이트보다 반드시 먼저 설치해야 합니다
  • 업데이트 설치 중 시스템을 강제 종료하지 마세요
  • 중요한 업데이트는 개별적으로 설치하는 것이 안전합니다
  • 업데이트 기록을 정기적으로 확인하세요
  • 이벤트 뷰어에서 상세한 오류 로그를 확인하세요
  • 정기적인 디스크 정리 및 최적화를 수행하세요
  • 업데이트 실패 시 Windows Update 로그를 분석하세요

🛠️ 고급 해결 방법

중복 항목 검사 스크립트

  • PowerShell을 관리자 권한으로 실행
  • 중복 업데이트 검사:
$Updates = Get-WindowsUpdate -Verbose
$Duplicates = $Updates | Group-Object Title | Where-Object {$_.Count -gt 1}
if ($Duplicates) {
    Write-Host "중복된 업데이트 발견:" -ForegroundColor Red
    $Duplicates | ForEach-Object {
        Write-Host "- $($_.Name) ($($_.Count)개)" -ForegroundColor Yellow
    }
} else {
    Write-Host "중복된 업데이트가 없습니다." -ForegroundColor Green
}

업데이트 기록 분석

  • 설치된 업데이트 기록 분석:
Get-WUHistory | Group-Object Title | Where-Object {$_.Count -gt 1} | ForEach-Object {
    Write-Host "중복 설치: $($_.Name)"
    $_.Group | Select-Object Date, Result, Size | Format-Table
}

🔄 중복 항목 처리 가이드

중복 항목 유형 이해

  • 동일한 KB 번호의 중복: 같은 업데이트가 여러 번 나타남
  • 유사한 기능의 중복: 비슷한 기능을 가진 업데이트들
  • 버전 차이의 중복: 다른 버전의 같은 업데이트
  • 언어팩 중복: 동일한 언어팩이 여러 번 나타남
  • 드라이버 중복: 같은 하드웨어용 드라이버 중복
