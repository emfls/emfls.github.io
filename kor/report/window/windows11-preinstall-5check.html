Windows 11 설치 전 반드시 확인해야 할 5가지

핵심 요약 (Key Takeaways)
  • Windows 11 설치 전 TPM 2.0과 Secure Boot 활성화가 필수이며, 시스템 최소‧권장 사양 충족 여부를 반드시 확인해야 합니다.
  • 드라이버 최신 버전 확인, 하드웨어·소프트웨어 호환성 점검, 데이터 완전 백업, 설치 미디어 준비 등 5가지 체크리스트를 모두 완료해야 합니다.
  • 모든 준비가 완료되면 chkdsk, sfc, DISM 명령어로 최종 진단 후 Windows 11 설치를 진행해 데이터 손실과 호환성 문제를 최소화하세요.

시스템 사양과 TPM 2.0·보안 부팅을 확인하세요. 드라이버 호환성을 점검하고 백업과 설치 미디어를 준비하세요.

2

TPM 2.0 & Secure Boot 활성화

TPM 2.0 활성화 방법

  1. Win+R → tpm.msc 입력 후 버전 확인
  2. BIOS/UEFI 진입 → Intel PTT / AMD fTPM 설정을 Enabled

Secure Boot 활성화 방법

  1. BIOS에서 CSM(레거시 지원)을 Disabled
  2. Secure Boot 항목을 Enabled
  3. 부팅 모드를 UEFI로 고정
주의! Secure Boot 활성화 시 구형 OS·드라이버는 부팅되지 않을 수 있습니다.
3

하드웨어‧소프트웨어 호환성·드라이버 업데이트

필수 드라이버 최신 버전 확인

  • 그래픽: NVIDIA/AMD/Intel 최신 Game Ready·Adrenalin·ARC 드라이버
  • 칩셋 & 스토리지: Intel RST, AMD Chipset, Samsung/NVMe SSD
  • 네트워크·오디오: 제조사 공식 최신 드라이버

중요 소프트웨어 호환성

  • 안티바이러스/방화벽 프로그램: Windows 11 지원 버전인지 확인
  • 업무용 앱(Adobe, CAD, 개발툴): 최신 패치 적용 후 테스트
4

자주 묻는 질문 (FAQ)

Windows 11 설치를 위해 반드시 활성화해야 하는 보안 기능은 무엇인가요?

Windows 11 설치 전 TPM 2.0과 Secure Boot를 반드시 활성화해야 합니다. BIOS/UEFI 설정에서 Intel PTT 또는 AMD fTPM을 Enabled로 설정하고, Secure Boot를 활성화해야 합니다.

Windows 11 설치 전 어떤 드라이버와 소프트웨어를 점검해야 하나요?

그래픽, 칩셋, 스토리지, 네트워크, 오디오 등 주요 하드웨어 드라이버를 최신 버전으로 업데이트하고, 안티바이러스 및 업무용 앱이 Windows 11을 지원하는지 확인해야 합니다.

Windows 11 설치 전 데이터 백업은 어떻게 준비해야 하나요?

문서, 사진, 동영상, 브라우저 북마크, 이메일 데이터, 프로그램 라이선스 등 개인 데이터를 백업하고, 전체 시스템 이미지를 만드는 것이 권장됩니다. 외장 HDD, 클라우드, 시스템 이미지 도구를 활용하세요.
