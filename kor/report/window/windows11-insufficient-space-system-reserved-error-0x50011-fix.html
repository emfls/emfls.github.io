Windows 11 0x50011 INSUFFICIENT_SPACE_SYSTEM_RESERVED 해결 가이드

핵심 요약 (Key Takeaways)
  • Windows 11에서 0x50011 INSUFFICIENT_SPACE_SYSTEM_RESERVED 오류는 시스템 예약 파티션 또는 EFI 시스템 파티션의 공간 부족으로 발생합니다.
  • 디스크 관리 및 명령 프롬프트를 통해 파티션 상태를 확인하고, 불필요한 파일 삭제, 복구 환경 관리, 파티션 확장 등으로 공간을 확보해야 합니다.
  • 시스템 파티션 작업 전 반드시 전체 백업을 생성하고, 신중하게 단계별 해결 방법을 따라 오류를 완벽히 해결하세요.
30초 점검

디스크 관리에서 파티션별 여유 공간을 확인하세요. 파티션 변경이 필요하면 먼저 백업하고 전문가에게 문의하세요.

⚠️ 주의사항: 이 오류는 시스템 예약 파티션(System Reserved Partition) 또는 EFI 시스템 파티션의 공간이 부족할 때 발생하는 오류입니다. 부팅 관련 중요한 파티션이므로 신중하게 작업해야 합니다.

🔍 오류 개요

0x50011 INSUFFICIENT_SPACE_SYSTEM_RESERVED는 Windows 11에서 시스템 예약 파티션이나 EFI 시스템 파티션의 여유 공간이 부족할 때 발생하는 오류입니다. 이 오류는 주로 다음과 같은 원인으로 발생합니다:

  • 시스템 예약 파티션(100MB~500MB) 공간 부족
  • EFI 시스템 파티션(ESP) 용량 부족
  • 부팅 파일 및 복구 환경 파일 누적
  • Windows Update 파일이 시스템 파티션에 저장됨
  • 언어 팩 설치로 인한 공간 부족
  • 복구 이미지 파일 크기 증가
  • 부팅 로그 파일 누적
  • 타사 부팅 관리자 파일 축적

🛠️ 해결 방법

방법 1: 시스템 파티션 상태 확인

1 디스크 관리에서 파티션 확인:
  • Windows + X 키를 누르고 "디스크 관리" 선택
  • 시스템 예약 파티션 또는 EFI 시스템 파티션 확인
  • 파티션 크기 및 여유 공간 확인
  • 일반적으로 다음과 같은 크기:
    • 시스템 예약 파티션: 100MB~500MB
    • EFI 시스템 파티션: 100MB~260MB
2 명령 프롬프트로 파티션 정보 확인:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 파티션 상태 확인:
diskpart
list disk
select disk 0
list partition
list volume

방법 2: 시스템 파티션 정리

1 EFI 시스템 파티션 마운트:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 EFI 파티션 마운트:
diskpart
list volume
select volume [EFI 볼륨 번호]
assign letter=Z
exit
2 불필요한 파일 삭제:
  • 마운트된 EFI 파티션에서 다음 파일들 확인 및 정리:
dir Z:\ /s
cd Z:\EFI\Microsoft\Boot\Fonts
dir *.ttf
del /f /q *.ttf (불필요한 폰트 파일 삭제)
cd Z:\EFI\Microsoft\Boot\Resources
dir
(사용하지 않는 언어 폴더 삭제)
3 부팅 로그 파일 정리:
  • 다음 명령어로 부팅 관련 로그 파일 정리:
del /f /q Z:\bootmgr.efi.log
del /f /q Z:\EFI\Microsoft\Boot\*.log
del /f /q Z:\EFI\Boot\*.log

방법 3: Windows RE(복구 환경) 관리

1 Windows RE 상태 확인:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 복구 환경 상태 확인:
reagentc /info
2 Windows RE 임시 비활성화:
  • 공간 확보를 위해 임시로 복구 환경 비활성화:
reagentc /disable
  • 복구 이미지 파일(winre.wim) 삭제 또는 이동
  • 작업 완료 후 다시 활성화:
reagentc /enable

방법 4: 시스템 파티션 크기 확장

1 인접한 파티션에서 공간 확보:
  • 디스크 관리에서 시스템 파티션 옆의 파티션 확인
  • C: 드라이브에서 공간을 축소하여 여유 공간 생성
  • 다음 명령어로 파티션 축소:
diskpart
list volume
select volume C
shrink desired=1024 (1GB 축소)
exit
2 시스템 파티션 확장:
  • 타사 파티션 관리 도구 사용 권장 (예: GParted, AOMEI Partition Assistant)
  • 또는 다음 명령어로 확장 시도:
diskpart
list volume
select volume [시스템 예약 볼륨 번호]
extend size=1024
exit

방법 5: 부팅 파일 정리 및 최적화

1 BCD 저장소 정리:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 부팅 구성 데이터 정리:
bcdedit /enum all
bcdedit /cleanup
bcdedit /deletevalue {bootmgr} displayorder
bcdedit /set {bootmgr} displayorder {current}
2 불필요한 부팅 항목 제거:
  • 시스템 구성 유틸리티 실행:
msconfig
  • "부팅" 탭에서 불필요한 부팅 항목 삭제
  • 기본 부팅 항목만 유지

방법 6: 언어 팩 및 기능 정리

1 불필요한 언어 팩 제거:
  • 설정 → 시간 및 언어 → 언어
  • 사용하지 않는 언어 팩 제거
  • 또는 PowerShell로 언어 팩 확인 및 제거:
Get-WindowsPackage -Online | Where-Object {$_.PackageName -like "*Language*"}
Remove-WindowsPackage -Online -PackageName [패키지명]
2 선택적 기능 제거:
  • 제어판 → 프로그램 → Windows 기능 켜기/끄기
  • 사용하지 않는 기능 비활성화
  • 특히 다음 기능들 확인:
    • Internet Explorer 11
    • Windows Media Player
    • XPS 뷰어
    • Fax 및 스캔

방법 7: 시스템 파일 압축

1 시스템 파티션 파일 압축:
  • 관리자 권한으로 명령 프롬프트 실행
  • 다음 명령어로 시스템 파일 압축:
compact /c /s:Z:\ /i /a
compact /c /s:Z:\EFI /i /a
2 압축 효과 확인:
  • 다음 명령어로 압축 결과 확인:
compact /q /s:Z:\
dir Z:\ /s

방법 8: 새로운 시스템 파티션 생성 (고급)

1 백업 및 준비:
  • 중요한 데이터 전체 백업
  • Windows 설치 미디어 준비
  • 시스템 복구 디스크 생성
2 파티션 재구성:
  • 타사 파티션 관리 도구 사용
  • 더 큰 크기의 EFI 시스템 파티션 생성 (512MB 권장)
  • 부팅 파일 복사 및 BCD 재구성
  • 부팅 테스트 및 검증

  • compact /c /s:Z:\ /i: 파일 압축
  • bootrec /fixboot: 부팅 섹터 복구

⚠️ 주의사항

시스템 파티션 작업 시 주의점

  • 시스템 파티션 작업 전 반드시 전체 시스템 백업을 생성하세요
  • EFI 시스템 파티션의 중요한 파일을 삭제하지 마세요
  • 파티션 크기 변경 시 데이터 손실 위험이 있습니다
  • 부팅 파일 수정 시 시스템이 부팅되지 않을 수 있습니다
  • Windows 복구 디스크를 미리 준비해두세요
  • 작업 중 전원이 차단되지 않도록 주의하세요

언제 전문가의 도움이 필요한가?

  • 파티션 테이블이 손상된 경우
  • 부팅이 완전히 불가능한 경우
  • 중요한 업무용 시스템인 경우
  • RAID 구성이나 복잡한 디스크 구조인 경우
  • 모든 해결 방법을 시도했지만 문제가 지속되는 경우

✅ 예방 방법

  • 정기적인 시스템 파티션 공간 모니터링
  • 불필요한 언어 팩 설치 자제
  • Windows RE 크기 정기적 확인
  • 부팅 로그 파일 정기적 정리
  • 시스템 설치 시 충분한 크기의 EFI 파티션 생성
  • 정기적인 부팅 구성 데이터 정리
  • 타사 부팅 관리자 사용 시 주의

💡 추가 팁

  • EFI 시스템 파티션은 최소 260MB 이상 권장
  • 시스템 예약 파티션은 500MB 이상 권장
  • 언어 팩 설치 전 시스템 파티션 공간 확인
  • Windows 업데이트 후 시스템 파티션 공간 확인
  • 파티션 관리 도구 사용 시 신뢰할 수 있는 도구 선택
  • 정기적인 시스템 백업으로 데이터 보호
관련 점검
  • 윈도우 11 0x60000 저장 공간 확인
  • 윈도우 11 설치 전 확인할 5가지

🔍 관련 오류 코드

유사한 시스템 파티션 관련 오류들

  • 0x80070070: 디스크 공간이 부족합니다
  • 0x80070002: 지정된 파일을 찾을 수 없습니다
  • 0x80070003: 지정된 경로를 찾을 수 없습니다
  • 0xC0000225: 부팅 구성 데이터 누락
  • 0xC000000F: 부팅 선택 실패
  • 0x80300024: 파티션 생성 실패

⚠️ 놓치면 손해보는 2026 핵심 실행 체크리스트
  • 디스크 관리 및 명령어 작업 전 반드시 전체 시스템 백업을 완료해야 데이터 손실 및 부팅 불가 사고를 예방할 수 있습니다.
  • EFI 파티션 및 시스템 예약 파티션 내 파일 삭제 시, Microsoft 공식 문서 기준 불필요 파일만 선별적으로 삭제하고, 삭제 전 목록을 캡처·기록해 복구 가능성을 확보하세요.
  • 파티션 확장, 복구 환경 비활성화 등 작업 후에는 반드시 재부팅 및 Windows Update 정상 동작 여부를 확인해 추가 오류(0x50011, 0x80070070 등) 발생을 사전에 차단하세요.

정확한 파티션 증설 전후 용량 증감률과 확보 공간을 직접 시뮬레이션하여, 불필요한 확장이나 데이터 손실 위험 없이 최적의 공간 확보 전략을 세울 수 있습니다.

자주 묻는 질문 (FAQ)

0x50011 INSUFFICIENT_SPACE_SYSTEM_RESERVED 오류는 왜 발생하나요?

이 오류는 Windows 11에서 시스템 예약 파티션이나 EFI 시스템 파티션의 여유 공간이 부족할 때 발생하며, 부팅 파일 누적, Windows 업데이트, 언어 팩 설치 등이 원인입니다.

시스템 예약 파티션 공간 부족 문제를 어떻게 해결할 수 있나요?

디스크 관리에서 파티션 상태를 확인하고, EFI 파티션 마운트 후 불필요한 파일 삭제, 부팅 로그 정리, Windows RE 임시 비활성화, 파티션 크기 확장 등을 통해 공간을 확보할 수 있습니다.

시스템 파티션 작업 시 주의할 점은 무엇인가요?

작업 전 반드시 전체 시스템 백업을 생성해야 하며, EFI 시스템 파티션의 중요한 파일을 삭제하지 않고, 파티션 크기 변경 시 데이터 손실 위험에 주의해야 합니다.

이 가이드를 통해 시스템 예약 공간 부족 문제가 해결되기를 바랍니다. 파티션 관련 문제가 지속되면 전문 기술자나 Microsoft 지원팀에 문의하시기 바랍니다.
