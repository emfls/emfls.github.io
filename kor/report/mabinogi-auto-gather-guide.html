마비노기 모바일 채집: 가까운 위치 찾기·생활도구 공식 가이드

최근 확인: 2026-08-09 · 업데이트에 따라 기능과 보상이 바뀔 수 있습니다.

먼저 답: 채집물을 찾을 때는 게임이 제공하는 가까운 위치 찾기와 아이템 카드의 구하는 방법을 사용하세요. 광맥·낚시터·논밭·버섯·약초·양 방목지 등은 생활도구가 필요하며, 생활 능력치가 높은 도구일수록 한 번에 더 많은 결과물을 얻을 수 있습니다.
외부 자동화 금지: 자동 클릭 앱, 매크로, 입력 반복 장치 등 비인가 프로그램이나 비정상 플레이 패턴은 운영정책상 보안 시스템 적발 시 영구 게임 이용제한 대상이 될 수 있습니다. 이 페이지는 게임 안에 공식 제공된 기능만 설명합니다.

공식 채집 기능 찾기

가까운 위치 찾기

  1. 프로필 → 생활 스킬을 엽니다.
  2. 채집 유형의 상세 정보에서 원하는 채집물을 선택합니다.
  3. 채집물 카드 왼쪽 아래의 가까운 위치 찾기를 누릅니다.

원하는 아이템부터 찾기

아이템 카드의 구하는 방법을 누르고 목록에서 채집을 선택하면 해당 아이템을 얻을 수 있는 채집물을 게임이 찾아갑니다.

생활도구 선택

도구가 필요한 채집에는 해당 생활도구를 준비합니다. 공식 가이드는 생활 능력치가 좋은 도구일수록 보상량이 늘어난다고 안내합니다.

업데이트 확인

재료·보상·도구 효과는 패치로 바뀔 수 있습니다. 오래된 커뮤니티 루틴보다 최신 업데이트와 게임 내 설명을 우선하세요.

효율을 높이는 안전한 순서

  1. 제작·퀘스트에 필요한 아이템을 먼저 정합니다.
  2. 아이템 카드의 구하는 방법으로 채집 종류를 확인합니다.
  3. 필요한 생활도구와 인벤토리 공간을 준비합니다.
  4. 가까운 위치 찾기로 이동해 직접 채집하고 결과를 확인합니다.
  5. 도구 변경 전 게임 내 생활 능력치와 획득 결과를 비교합니다.
