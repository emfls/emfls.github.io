핵심 요약: 원하는 목적에 따라 설정이 달라집니다

  • 내 새로운 대화를 모델 개선에 쓰지 않게 하려면: 설정 → 데이터 제어 → '모두를 위한 모델 개선' 끄기
  • 대화를 기록에 남기지 않고 질문하려면: 새 채팅에서 '임시'를 선택하고 필요하면 '개인 맞춤 미적용' 선택
  • 기존 대화를 지우려면: 채팅의 더보기 메뉴에서 삭제. 보관은 삭제가 아닙니다
  • 이전 대화 정보를 개인화에 사용하지 않게 하려면: 설정 → 개인화 → 메모리에서 사용 가능 항목 확인
  • 남아 있는 내 정보까지 정리하려면: 메모리뿐 아니라 원본 채팅, 관련 파일, 연결된 앱의 정보도 확인

1. 챗GPT 대화 학습 끄기: 웹과 모바일에서 설정하기

컴퓨터 웹 브라우저에서 끄는 방법

  1. ChatGPT 공식 사이트에 로그인합니다.
  2. 계정 메뉴를 열고 '설정'을 선택합니다.
  3. '데이터 제어' 메뉴로 이동합니다.
  4. '모두를 위한 모델 개선'을 선택해 끕니다.
  5. 확인 화면이 나타나면 '완료'를 눌러 저장합니다.

OpenAI 공식 설명에 따르면 이 옵션을 끈 이후의 새로운 대화는 모델 학습에 사용되지 않습니다. 다만 이미 저장된 채팅을 자동으로 삭제하거나 숨기는 설정은 아닙니다. 사용 중인 기기에서 '꺼짐' 상태가 유지되는지도 확인하세요.

아이폰·안드로이드 앱에서 끄는 방법

  1. ChatGPT 앱에서 사이드바를 엽니다.
  2. 프로필 아이콘을 눌러 설정을 엽니다.
  3. '데이터 제어'에 들어갑니다.
  4. '모두를 위한 모델 개선'을 끕니다.

로그인한 계정에서 바꾼 이 설정은 같은 계정으로 접속하는 다른 기기에도 적용됩니다. 로그인하지 않고 웹에서 사용할 때에는 브라우저별로 설정이 저장될 수 있으므로 사용 환경을 따로 확인해야 합니다.

화면의 버튼 이름이나 배치는 앱 업데이트, 요금제, 계정·워크스페이스 정책에 따라 다를 수 있습니다. 해당 메뉴를 찾기 어렵다면 설정 검색이나 공식 도움말을 이용하세요.

2. 임시 채팅 사용법: 기록 없이 질문하고 싶을 때

일반 대화는 나중에 다시 찾을 수 있지만, 모든 질문을 기록에 남길 필요는 없습니다. 잠깐 확인할 정보처럼 보관할 이유가 없는 대화에는 '임시 채팅'이 적합합니다.

새 채팅을 열고 '임시'를 선택한 다음, 첫 메시지를 보내기 전에 개인 맞춤 설정 여부를 고릅니다. **'개인 맞춤 미적용'**을 선택하면 기존 메모리·맞춤 지침·플러그인을 개인화에 사용하지 않습니다. **'개인 맞춤형'**을 선택하면 기존 메모리와 설정을 참조할 수 있지만, 임시 상태에서는 새로운 메모리를 생성하거나 업데이트하지 않습니다.

임시 채팅을 저장하지 않으면 채팅 기록에 표시되지 않고, 대화에서 나간 뒤 기록에서 다시 열 수 없습니다. 임시 상태의 대화는 모델 개선에 사용되지 않습니다. 다만 '기록에 보이지 않는다'는 것과 '서버에 즉시 흔적이 전혀 남지 않는다'는 것은 다릅니다. OpenAI는 안전을 위해 임시 채팅 사본을 최대 30일 보관할 수 있다고 안내합니다.

또 한 가지 주의할 점은 임시 채팅도 나중에 일반 채팅으로 저장할 수 있다는 것입니다. 저장하면 일반 채팅으로 바뀌어 계정의 개인화 및 모델 개선 설정이 적용됩니다. 따라서 보관할 생각이 없다면 저장하지 않는 편이 목적에 맞습니다.

임시 채팅에서 외부 서비스로 데이터를 전달하는 기능을 사용했다면 그 정보에는 제3자 서비스의 개인정보 처리 기준도 적용될 수 있습니다. 임시 채팅이라고 해서 주민등록번호, 계정 비밀번호, 카드 보안정보를 입력해도 안전하다는 뜻은 아닙니다.

3. 대화 기록 삭제와 보관의 차이: 가장 많이 헷갈리는 부분

과거 대화를 사이드바에서 보이지 않게 하는 '보관'과 '삭제'는 다릅니다. 보관하면 대화가 계정에 남고, 삭제하면 계정 화면에서 즉시 사라집니다.

대화 1개만 삭제하기

  1. ChatGPT 채팅 기록에서 지울 대화를 찾습니다.
  2. 채팅 제목의 더보기 메뉴(점 세 개)를 엽니다.
  3. '삭제'를 선택하고 확인합니다.

삭제된 대화는 ChatGPT 화면에서 복원할 수 없습니다. OpenAI는 이미 비식별 처리되었거나 보안·법적 보존 의무가 있는 예외를 제외하고, 해당 채팅을 30일 이내 시스템에서 영구 삭제하도록 처리한다고 설명합니다. 여기서 30일은 사용자가 30일 동안 복구할 수 있다는 뜻이 아닙니다.

여러 대화를 한꺼번에 지우려면

'설정 → 데이터 제어'로 이동해 '모든 채팅 삭제' 옵션을 확인합니다. 이 작업은 프로젝트 안의 채팅에도 영향을 줄 수 있고 실행 취소할 수 없으므로, 중요한 자료를 먼저 별도로 보관하세요.

'모든 채팅 보관'은 목록 정리용입니다. 보관된 대화는 설정의 데이터 제어에서 '보관된 채팅' 관련 메뉴를 통해 다시 확인하거나 삭제할 수 있습니다.

채팅은 지웠는데 파일이 남아 있다면?

대화 삭제와 별도 라이브러리에 저장된 파일 삭제도 구분해야 합니다. 라이브러리에 파일 사본이 남아 있다면 해당 파일을 별도로 정리해야 합니다. 프로젝트에 올린 파일이나 외부 연결 앱의 원본 파일도 채팅 하나를 삭제했다고 모두 없어지는 것은 아닙니다.

4. 메모리 끄기: 챗GPT가 이전 정보를 참고하지 않게 하려면

'학습 끄기'와 '메모리 끄기'는 목적이 다릅니다. 모델 학습 설정은 콘텐츠를 모델 개선에 사용할지 결정합니다. 메모리 설정은 과거 대화 등에서 얻은 맥락을 앞으로의 응답에 활용할지 제어합니다.

메모리 설정은 일반적으로 '설정 → 개인화 → 메모리'에서 확인합니다. 계정에 따라 메모리 켜기·끄기, 메모리 요약 또는 관리와 같은 항목이 표시될 수 있습니다. 일부 기기나 요금제에서는 메뉴 구성이 다를 수 있습니다.

메모리 기능을 끄면 개인화를 제한할 수 있지만 이전에 작성한 대화가 자동으로 삭제되지는 않습니다. 나중에 메모리를 다시 켤 경우 남아 있는 이전 대화가 새로운 개인화 정보의 출처가 될 수도 있습니다.

특정한 개인 정보를 더는 참고하지 않게 하려면 메모리 요약에서 수정하거나 해당 정보를 앞으로 사용하지 말라고 요청할 수 있습니다. 다만 '다시 언급하지 않기'는 원본 파일이나 채팅을 삭제하는 기능이 아닙니다. 정보를 실제로 정리하려면 메모리 요약의 관리 기능과 해당 내용이 등장한 원본 대화·파일을 함께 확인하세요.

메모리 요약이 모든 기억의 상세 목록인 것도 아닙니다. 이전 채팅, 라이브러리 파일, 연결된 앱의 자료가 개인화 맥락으로 쓰일 수 있으므로 삭제 목적이라면 출처까지 점검하는 것이 중요합니다.

5. 대화 내용을 공유했거나 파일을 올렸다면 추가로 확인하세요

개인정보 관리에서는 모델 학습 설정뿐 아니라 '누가 정보에 접근할 수 있는가'도 중요합니다.

첫째, 이전에 누군가에게 대화 공유 링크를 보냈다면 '데이터 제어'의 공유 링크 관리 옵션이나 해당 대화의 공유 메뉴를 확인하세요. 공유 링크는 비밀번호처럼 취급하지 않아도 되는 비공개 저장소가 아닙니다. 공유된 내용에 민감한 정보가 있는지 먼저 검토해야 합니다.

둘째, 회사 문서·고객 명단·계약서 등을 업로드했다면 원본 문서에 개인정보나 업무상 기밀이 포함되어 있는지 확인하세요. 파일을 별도로 저장하는 기능을 이용했다면 채팅 기록 삭제 외에 파일 관리도 필요합니다.

셋째, 외부 앱이나 서비스가 연결된 상태라면 연결을 끊을지 검토하세요. 연결 해제는 이후 접근에 영향을 주지만 과거 대화에 이미 포함된 데이터나 원래 앱에 남아 있는 자료까지 전부 삭제한다는 뜻은 아닙니다.

민감한 정보를 처리해야 하는 직장에서는 개인 계정의 설정만 믿기보다 조직의 정보보호 정책, 허용된 업무 도구, 워크스페이스 관리 방침을 먼저 따르는 것이 좋습니다.

6. 삭제하기 전 내 대화 내보내기

오래 사용한 계정이라면 일괄 삭제 전에 필요한 대화를 따로 보관하는 편이 안전합니다. 개인용 계정에서 지원되는 경우 '설정 → 데이터 제어 → 데이터 내보내기'를 통해 데이터 사본을 요청할 수 있습니다.

요청한 자료는 계정의 연락 수단으로 다운로드 안내가 전달될 수 있으며, 다운로드 링크에는 유효기간이 있습니다. Android 앱 공식 안내는 발급된 링크가 24시간 후 만료된다고 설명합니다. 내보내기 항목과 제공 방식은 계정 환경에 따라 다르므로 화면의 안내를 우선하세요.

대화 내보내기를 했다고 기존 채팅이 자동으로 삭제되거나 학습 설정이 변경되는 것은 아닙니다. 내보낸 파일 자체에도 개인 정보가 들어 있을 수 있으므로 공용 PC나 공개 클라우드 폴더에 그대로 보관하지 않는 것이 좋습니다.

7. 목적별 체크리스트: 지금 무엇을 바꿀까?

앞으로의 대화를 AI 학습에 쓰지 않게 하고 싶다면

  • '모두를 위한 모델 개선'을 끕니다.
  • 같은 계정의 다른 기기에도 설정이 적용되는지 확인합니다.
  • 이미 있는 채팅을 지우고 싶다면 삭제 기능을 따로 사용합니다.

일회성 질문을 기록에 남기고 싶지 않다면

  • 처음부터 새 임시 채팅을 시작합니다.
  • 개인화가 필요 없다면 '개인 맞춤 미적용'을 선택합니다.
  • 나중에 저장하면 일반 채팅 규칙으로 바뀐다는 점을 기억합니다.
