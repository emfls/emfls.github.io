When to use it

Use component encoding for a query value, path segment, or form value. It also encodes reserved characters, so do not use it blindly on an entire already-structured URL. Encoding does not prove that a link is trustworthy.

FAQ

Why does a space become %20?

Percent encoding represents bytes that are not safe or unambiguous in a URL component.

Why can decoding fail?

A percent sign must be followed by two hexadecimal digits and the bytes must form valid text.
