FAQ – Image Format Converter

Is my image uploaded?
No, all image conversion happens in your browser. Your images are never uploaded.
Which formats can I convert?
PNG, JPG, JPEG, GIF, BMP, and WebP are all supported. Animated GIFs will only convert the first frame.
Can I batch convert multiple images?
Yes! You can select or drag in many files and all will be converted at once.
Is there a file size or quantity limit?
There is no set limit, but your browser memory may limit huge batches. For best results, try 20-30 images at once.
Are there any fees or watermarks?
No – this tool is 100% free, no watermark, and no sign-up required.
Can I convert animated GIFs?
Animated GIFs are partially supported – only the first frame will be converted. Multi-frame/animated output is not supported yet.

Related Calculators & Quick Guide

The Image Format Converter previews and downloads one still frame from each file labeled as an image that your browser can decode, with PNG, JPEG, WebP, GIF and BMP output options that fall back to PNG data under the chosen extension when the browser cannot encode the requested format.

Which format should I choose to keep a transparent background?
Choose PNG when you need transparency. JPEG does not preserve it.
What happens when I change the output format after loading files?
Changing the format reconverts any files still in the file picker, even after a drop. If you only dropped files, choose the new format and drop them again.
