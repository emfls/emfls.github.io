How the count works

Why Jan 1 to Jan 3 can be 2 or 3 days: the elapsed gap is 2 days. When you turn on Include end date in range counts, the selected range contains 3 calendar dates.

Elapsed days and weeks use the absolute date-only gap. Weekdays (Mon–Fri) and weekend days use the selected range; public holidays are not excluded.

Calendar span is not the same as dividing total days into fixed 30-day months. This tool uses a deterministic calendar decomposition with month-end clamping. Date-only calculations use UTC calendar components, so daylight-saving changes do not alter a whole-day result.

This is a general calendar-planning estimate, not an official legal, court, tax or contractual deadline calculation.

FAQ

Does the count include the end date?

Only when you select Include end date in range counts. Otherwise the selected range uses the elapsed gap.

Are weekends counted?

Yes. Weekday and weekend rows count calendar dates in the selected range.

Are public holidays excluded?

No. Weekdays are a simple Mon–Fri estimate and public holidays are not excluded.

Why can calendar months differ from total days?

Calendar spans use actual month lengths and a month-end clamp, not fixed 30-day months.

Does daylight saving time affect this?

No. The calculator uses date-only UTC math rather than local midnight durations.

What if the end date is earlier?

The direction and signed elapsed result reverse, while absolute range counts stay the same.
