How the Calculation Works & Mathematical Formula

The Case Converter tool operates by processing the text inputted by the user and applying specific transformation techniques to alter the case of the text. This tool supports five styles of text case conversion: UPPERCASE, lowercase, Capitalize Each Word, Sentence case, and toggle case.

Input Variables

  • Text Input: This is the string of text that the user provides for conversion. The input can include any mix of characters.

Mathematical Formulation

While text case conversion isn't a mathematical operation in the traditional sense, we apply the following rules for each type of case:

  1. UPPERCASE: Transform every character to its upper-case equivalent.
  2. lowercase: Transform every character to its lower-case equivalent.
  3. Capitalize Each Word: Make the first character of each word uppercase, and the rest lowercase.
  4. Sentence case: Make the first character of the first word uppercase, and all others lowercase.
  5. toggle case: Change every upper-case character to lower-case and every lower-case character to upper-case.

Example

Suppose a user enters the text hello world into the tool.

  1. If the user selects UPPERCASE: Output will be HELLO WORLD.
  2. If the user selects lowercase: Output will be hello world.
  3. If the user selects Capitalize Each Word: Output will be Hello World.
  4. If the user selects Sentence case: Output will be Hello world.
  5. If the user selects toggle case: Output will be HELLO WORLD to hello world.
