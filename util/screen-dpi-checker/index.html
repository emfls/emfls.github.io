Frequently asked questions

What do screen size, viewport size, and device pixel ratio measure?

Screen size is the display size reported by the browser in CSS pixels. Viewport size is the inner window size in CSS pixels, including any scrollbars. Device pixel ratio (DPR) gives the number of device pixels per CSS pixel along one axis and can change with page zoom, display scaling, or a move to another display.

Can the browser detect my physical DPI or PPI automatically?

Physical screen density requires the display’s native pixel resolution and its diagonal in inches. Browser-reported CSS dimensions and DPR describe how the browser renders the page. Enter the native resolution and diagonal from your display specifications to calculate PPI.

How are PPI, dot pitch, megapixels, and aspect ratio calculated?

PPI is the diagonal pixel count divided by the diagonal size in inches. Dot pitch is 25.4 divided by PPI in millimeters. Megapixels are width times height divided by one million. Aspect ratio reduces width and height by their greatest common divisor.

What does the Retina viewing distance estimate mean?

The calculator estimates the distance where one pixel subtends one arcminute, a common idealized threshold for 20/20 vision. It divides the pixel pitch by the tangent of one arcminute. Individual vision, contrast, and the display’s subpixel layout can affect whether pixels are visible.
