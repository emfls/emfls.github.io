How aspect ratios work

An aspect ratio is the relationship between width and height. Resolution is the actual pixel count: 1920×1080 and 1280×720 are different resolutions with the same 16:9 ratio.

Changing width and height independently can stretch or squeeze an image or video. This calculator uses the GCD(width, height) to simplify dimensions, such as 1920÷120 : 1080÷120 = 16:9.

FAQ

What is an aspect ratio?

It describes the proportional relationship between width and height.

How do I calculate height for 16:9?

Choose Resize by ratio, select 16:9, choose I know width, and enter the width.

Why is 3440×1440 not exactly 21:9?

Its exact reduced ratio is 43:18. 21:9 is a common category label, not the mathematical result for every ultrawide display.

Does this resize an image?

No. It calculates dimensions only; use an image tool afterward to resize or compress a file.

Are my values uploaded?
