    Frequently asked questions

    Can GetUsageLinesEstimatedCost accept 501 usage lines?

    The API accepts 1 to 500 usage lines per request. Split 501 lines into two requests of 500 and 1, keep the same rate type, and reconcile priced lines and errors by key.

    Which rateType values does the API accept?

    BEFORE_DISCOUNTS uses public On-Demand rates. AFTER_DISCOUNTS applies account discounts. AFTER_DISCOUNTS_AND_COMMITMENTS also applies Savings Plans and Reserved Instances. Your account preferences limit available modes. Billing transfer bill source accounts can use only BEFORE_DISCOUNTS.

    Does the API support AWS GovCloud (US) or AWS China?

    AWS excludes GovCloud (US) and China from the launch. The checker flags us-gov-* and cn-* region codes. AWS documents the Pricing Calculator API endpoint in us-east-1.

    Does this call cost money or save an estimate to my account?

    AWS charges $0 for the API call and returns an estimate without saving it to your account. Actual resource usage is billed at applicable rates. The estimate excludes taxes.
