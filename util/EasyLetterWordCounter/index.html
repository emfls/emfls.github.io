What each result means

  • Characters (with spaces): every JavaScript string character, including whitespace and line breaks.
  • Characters (no spaces): the same text after whitespace is excluded.
  • Words: non-empty groups separated by whitespace.
  • Sentences: non-empty text segments ending in a period, question mark or exclamation mark, plus a final segment without punctuation.
  • Paragraphs: non-empty blocks separated by one or more blank lines.

Counts are useful for essays, application limits, social posts, subtitles and drafting. A publisher's own counting rules may differ, so use its required tool for final submission.

FAQ

The counter does not save or submit the contents of the text box. Refreshing the page clears it.
Editors may handle hyphens, emojis, contractions and sentence endings differently. This page states its simple rules above.
Character counts work with any text. Word counting uses whitespace, so languages that do not separate words with spaces may need a language-specific analyzer.
