Bitte geben Sie einen mehrzeiligen Text ein oder fügen Sie ihn ein.
Wandeln Sie ihn sofort in zufällige (Shuffle)-, aufsteigende (A→Z)- oder absteigende (Z→A)-Reihenfolge um!
Alle Vorgänge werden im Browser ausgeführt. Kein Upload erforderlich – 100 % Datenschutz.

Was kann dieses Tool?

Mit diesem Tool können Sie eine Liste von Textzeilen sofort zufällig (Shuffle), aufsteigend (A→Z) oder absteigend (Z→A) sortieren.

Wie benutzt man es?

Geben Sie einen mehrzeiligen Text ein oder fügen Sie ihn ein und klicken Sie einfach auf die gewünschte Schaltfläche, um ihn zu mischen, auf- oder absteigend zu sortieren. Das Ergebnis kann kopiert oder gelöscht werden.

Funktioniert es auch offline?

Ja. Alle Operationen werden direkt im Browser ausgeführt, daher ist keine Internetverbindung oder ein Upload erforderlich.

Ist der Text sicher?

Absolut sicher. Der eingegebene Text wird nicht an externe Server gesendet und vollständig lokal verarbeitet.

Wofür kann es verwendet werden?

Vielseitig einsetzbar, z. B. zum Zufällig-Erstellen von Quizfragen, zufälligen Zuweisen von Schülernamen, Organisieren von Einkaufslisten oder Anzeigen von Protokollen/Skripten in umgekehrter Reihenfolge.
