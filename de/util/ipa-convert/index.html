FAQ – Englisches IPA-Aussprache-Tool

Ist das echtes IPA?
Nein. Dieses Tool verwendet vereinfachte Regeln, um die englische Aussprache grob darzustellen. Es ist nicht für linguistische oder Prüfungszwecke gedacht, sondern zum Lernen und Spaß haben.
Wird der eingegebene Text an einen Server gesendet?
Nein. Alle Umwandlungen erfolgen lokal im Browser. Es wird nichts an externe Server übertragen.
Welcher englische Akzent wird verwendet?
Eine Mischung aus amerikanischem und britischem Englisch, vereinfacht. Es entspricht nicht exakt einer bestimmten Dialektvariante.
Kann ich ganze Sätze eingeben?
Ja. Sowohl Wörter als auch Sätze können eingegeben werden. Jedes Wort wird separat umgewandelt.
Ist dieses Tool kostenlos?
Ja. Dieses Tool ist zu 100 % kostenlos und für jeden frei zugänglich.
