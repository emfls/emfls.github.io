🖼️ Outil HTML → Image/PDF
Convertissez une page web ou votre propre code HTML en PNG/JPG ou PDF. Fonctionne entièrement dans votre navigateur.
Gratuit et sans filigrane.
Note : Les URL externes peuvent être limitées par CORS et les sites avec du JavaScript dynamique peuvent ne pas s’afficher correctement.
Pour de meilleurs résultats, utilisez du HTML simple.

Foire aux questions

À quoi sert cet outil ?
Il permet de convertir des pages web (URL) ou du code HTML en images PNG/JPG ou en fichiers PDF, directement dans votre navigateur.
Mes données sont-elles envoyées ou stockées ?
Non. Tout est traité localement dans votre navigateur : rien n’est envoyé sur un serveur.
Est-ce que ça marche avec tous les sites ?
La plupart des sites publics fonctionnent, mais certains peuvent être restreints par le CORS ou du JavaScript dynamique.
Quels formats puis-je exporter ?
Vous pouvez télécharger une prévisualisation en PNG ou PDF.
Pourquoi le rendu diffère-t-il du site réel ?
Les scripts dynamiques, les polices externes et les politiques CORS peuvent empêcher certains éléments de s’afficher.
Est-ce vraiment gratuit ?
Oui, 100 % gratuit, sans inscription ni filigrane.
