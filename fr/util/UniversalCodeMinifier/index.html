❓ FAQ – Minificateur de Code
Quels types de code sont pris en charge ?
JavaScript, CSS et HTML. Les commentaires sont détectés et supprimés automatiquement.
Tous les commentaires sont-ils supprimés ?
Oui, les commentaires JS, CSS et HTML sont supprimés pour réduire la taille et masquer le code.
Mon code est-il envoyé sur un serveur ?
Non. Tout est traité localement dans votre navigateur, rien n’est envoyé.
Le code peut-il être cassé ?
Il s'agit d'une minification basique. Vérifiez toujours votre projet avant de déployer si vous utilisez des frameworks complexes.
Peut-on revenir en arrière ?
Non. La minification est irréversible. Sauvegardez toujours une copie de votre code original.
