# emfls Autonomous Work Plan

## 최종 목표

기존 검색 자산과 URL을 보존하면서 자동 운영 가능한 한국어 검색형 콘텐츠 사이트로 발전시킨다.

## Phase 1–2

Python 한국어 콘텐츠 인덱스와 8개 카테고리 home-feed, 블로그형 홈페이지 및 검색 lazy loading을 유지·검증한다.

## Phase 3

최신 origin/main 반영 여부, 인덱스, 테스트, diff와 예상 파일을 확인하고 feature에 commit/push한다. 완료 후 `READY_FOR_MAIN_REVIEW`로 전환한다.

## Approval Gate

main merge·push와 배포는 사용자 승인을 받은 뒤 진행한다.
