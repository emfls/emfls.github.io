# 수원·시흥 상단 앵커 가림 복구 — 정확 버전 승인

2026-11-07 사용자는 실제 광고 가림의 재현·최소 복구·정상 보호 승인/QA/배포를 사전 승인했다. 기존 위임 문서와 같은 정확 파일+before/after blob 절차를 적용한다. 승인 PR을 먼저 병합하고 별도 콘텐츠 PR에서 소비한다.

공개 시흥의 갯골 바로가기 직후 Google 상단 앵커가 카드 제목을 덮었다. 320/390/430px의 같은 페이지 리사이즈 관측에서 상단 광고 높이 약114px를 기록했다. 기존 390px 공개 캡처에서도 재현됐다. 이는 본문 광고의 공간 배치나 사이트 홈 버튼이 만든 상단 가림과 구분한다. 초기 광고 미노출, 광고 표시 후 스크롤/점프를 별도 기록한다.

현재 AdSense 사이트 자동광고와 앵커 광고는 켜져 있음을 설정 UI에서 읽기 전용으로 확인했다. 사이트 전체 UI 설정은 바꾸지 않고 두 페이지의 기존 async 로더에 Google 공식 `data-overlays="bottom"` 하나만 추가한다. 광고 iframe/단위/밀도·다른 형식·본문·canonical·GA4·제목은 바꾸지 않는다. 이 속성은 앵커가 꺼진 경우에도 켤 수 있어 기존 사용 여부를 먼저 확인했다.

실제 OPS 원본·고정 증거의 관측 자료는 과거 기준이며 전역 완전성 UNKNOWN을 보존한다. 오늘 본문 복구 관측과 별도 개입으로 적용 시각/버전을 기록하고 11/8~14 대10/31~11/6 비교에 여러 개입이 있음을 명시한다. OBSERVING·COOLDOWN·다른 WINNER 및 역방향/변형 버전은 계속 차단한다. PR589 Draft/HOLD와 논산 테스트는 그대로 둔다.

되돌리기는 이 속성만 제거하는 정확 역방향 전이를 별도 승인 등록한 정상 revert PR/QA/Pages 절차로 수행한다. 사이트 전체 설정을 덮어쓰지 않는다. 배포/광고 표시 상태 확인은 후속 공개 기록이며 이 문서는 수익 효과나 실기 휴대폰 검증을 주장하지 않는다.

## 공개 검증 후 추가 확인과 정확한 홈 버튼 복구

PR605 소스는21:44:47 KST 공개 배포됐고 정확 blob2/2가 일치했다. 그러나 새390px 모바일 로드/스크롤에서도 상단0·높이258px의 Google 앵커가 표시돼 소스 속성만으로 해결됐다고 판단하지 않는다.

공식 AdSense UI에서21:51:49 KST 앵커 게재위치 `상단 또는 하단`→`하단만`을 저장했다. 자동광고/앵커/사이드레일/전면광고/동적/넓은화면/빈도 설정은 유지했다. 실험 신규 생성 대신 즉시 적용을 선택했다. Google 완료 안내는 반영 최대1시간이다. 적용 범위는 **emfls.github.io 전체의 해당 앵커 광고**이며 두 HTML 변경과 별도 개입이다. 원래 여섯 페이지 기준과 관측을 덮어쓰지 않고, 이후 결과를 한 수정의 인과효과로 주장하지 않는다. UI 복구는 같은 사이트에서 원래 `상단 또는 하단`만 복원하며 다른 옵션을 바꾸지 않는다. 저장과 실제 게재 검증은 별개다.

추가 공개430px 수원 검증에서 실제 예약 버튼 중앙(y약800px)이 사이트 고정 홈 버튼에 막혔다(elementFromPoint=A.home-button). Google 광고와 별개인 게시자 요소 충돌이다. 같은 두 페이지의 기존 홈 버튼 컨테이너만 정적 문서 흐름으로 돌리고 불필요한 모바일 bottom15px 규칙을 없앤다. 마크업의 원래 맨 위 위치·홈URL·버튼 크기·광고·GA4·메타·본문은 유지한다. 홈 버튼은 함께 스크롤되는 정상 내비게이션이 되며 임의 광고 높이/iframe 숨김/자르기를 추가하지 않는다.
