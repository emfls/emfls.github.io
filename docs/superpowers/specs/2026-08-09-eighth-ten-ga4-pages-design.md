# Eighth GA4 Priority Batch Design

## Goal and selection

Improve the next ten previously untouched pages with verified GA4 traffic: Chinese CRC and nickname tools, a Korean Maple Planet leveling article, the Manado travel guide, Russian and English barcode tools, English CRC, Japanese Gomoku, English Connect Four, and the Korean game directory.

## Design

- Preserve all existing interactive behavior and add concise reviewed-date, purpose, privacy, and limitation copy.
- State that CRC is error detection rather than encryption, generated nicknames need availability/trademark checks, and generated barcodes require scanner and check-digit validation before operational use.
- Qualify game leveling results as patch- and character-dependent observations.
- Make the Manado guide route travelers to official Indonesian immigration and tourism sources rather than promising fixed prices, visa approval, or conditions.
- Correct directory-page canonicals, apply purpose-specific schema, add related internal links, and constrain responsive ad frames to the viewport.
- Validate the ten-page contract, JavaScript, JSON-LD, links, and the complete repository test suite.

## Success criteria

- Every page has a unique `emfls.github.io` canonical, `2026-08-09` reviewed date, appropriate schema, honest limitation, relevant internal links, and mobile ad protection.
- Existing tool/game functions remain syntactically valid.
- Focused and full tests plus `git diff --check` pass.
