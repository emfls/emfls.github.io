# 안동 캠핑 페이지 수익·검색 신뢰도 개편 설계

## 목표와 기준선

`kor/report/camp/andong.html`을 공식 등록 야영장과 예약 판단 중심으로 개편한다. Search Console 기준선은 클릭 5, 노출 114, CTR 4.39%, 평균순위 9.18이며 2026-08-30에 검색 클릭·실제 Organic Search 세션·페이지뷰·예상수익·페이지 RPM을 함께 비교한다.

## 선택한 접근

공식 등록 야영장 중심 전면 개편을 사용한다. 노지 장소를 경관지로 남기는 절충안은 검색 의도를 흐리고, 기존 무료·차박 허용 주장을 유지하는 방식은 사실성과 안전 위험이 크므로 제외한다.

## 콘텐츠와 출처

- 첫 화면에서 안동시 운영·등록 시설을 예약하는 것이 가장 확실하다고 답한다.
- 단호샌드파크 캠핑장을 대표 선택지로 두고 한국관광공사 고캠핑 상세정보와 안동시 통합예약을 연결한다.
- 임하호 캠핑 수상레저타운은 안동시 공지에서 2026년 행사 운영 사실을 확인할 수 있으나 일반 예약·요금은 운영처 재확인을 요구한다.
- 계명산자연휴양림 야영장은 고캠핑에 `현재 휴업 중`으로 표시되므로 운영 재개를 확인하기 전 예약 가능한 선택지로 추천하지 않는다.
- 길안천지생태공원, 금소생태공원, 낙동강·임하호 주변을 무료 야영·차박 장소로 단정한 문구를 제거한다.

## 화면·검색·측정

- 제목과 H1은 `안동 캠핑장`, `단호샌드파크`, `예약` 의도에 맞춘다.
- `WebPage`와 본문 일치 `FAQPage`, 최근 확인일 2026-08-02, 공식 출처를 제공한다.
- GA4, AdSense, canonical을 유지하고 광고 클릭 유도는 하지 않는다.
- 모바일 안전 그리드, 일반 흐름 홈 링크, 자동광고 `aswift` 폭 제한을 적용한다.
- 전용 테스트, 전체 테스트, 우선순위 검사, 공개 375px 검사, Search Console 색인 상태를 검증한다.

## 중단 조건

28일 후 CTR·실제 검색 세션·수익 기여가 모두 개선되지 않으면 같은 캠핑 페이지 방식의 대량 확장을 멈추고 검색 의도와 대상 키워드를 재검토한다.
