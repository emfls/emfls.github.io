# Search Console 성장 후보 6차 개선 설계

## 목표와 기준선

최근 3개월 Search Console에서 노출은 크지만 클릭 또는 순위가 낮은 다섯 페이지를 검색 의도에 맞게 보강한다.

| 페이지 | 클릭 | 노출 | CTR | 평균 순위 |
|---|---:|---:|---:|---:|
| MBTI 게임 | 0 | 403 | 0% | 70.97 |
| 싱가포르 비자 | 0 | 215 | 0% | 42.68 |
| 세르비아 비자 | 1 | 90 | 1.11% | 6.99 |
| 마비노기 모바일 직업 | 0 | 59 | 0% | 47.36 |
| 필리핀 비자 | 2 | 52 | 3.85% | 47.46 |

## 적용 방식

- MBTI는 16문항 간이 오락용 테스트임을 제목·첫 화면·결과 주변에 명시하고, 네 선호쌍의 다수 응답으로 결과가 정해진다는 산정법과 한계를 설명한다.
- 싱가포르는 여권 6개월, 도착일 포함 3일 이내 무료 SG Arrival Card, 입국 후 e-Pass의 실제 허용 체류일까지 한 화면에서 판단하도록 한다.
- 세르비아는 한국 일반여권 최대 90일 무비자, 90/180 규칙, Visa D 90~180일과 장기체류 경로를 공식 외교부 자료에 맞춘다. 출처가 불명확한 고정 비용·처리기간은 제거한다.
- 마비노기는 공식 6개 시작 계열(전사·궁수·마법사·힐러·음유시인·도적)을 역할별로 비교하고, 무기 또는 엠블럼과 전직 단계에 따른 클래스 교체 조건을 설명한다. 비공식 영구 티어는 만들지 않는다.
- 필리핀은 한국 일반여권 30일 비자 면제, 30일 이내 출국 항공권, 도착 전 72시간 이내 무료 eTravel과 체류 연장 확인 경로를 명확히 한다.

## 공통 안전장치

- canonical과 GA4 `G-QP5Q67GE5B`를 유지한다.
- 콘텐츠 페이지의 AdSense 설정과 위치를 유지하되 광고를 추가하지 않는다.
- MBTI 게임의 AdSense 비활성 상태를 유지한다.
- 공식 출처로 확인한 항목만 `2026-08-12`로 갱신한다.
- 검사 결과, 비자 승인·입국, 게임 성능·직업 우위 또는 체류 연장을 보장하지 않는다.

## 검증과 성과 판정

전용 테스트를 먼저 실패시킨 뒤 다섯 HTML을 수정한다. 관련 테스트와 전체 `pytest`, diff 검사를 통과시킨 후 `main`에 배포한다. 2026-09-09 이후 동일 URL의 최근 28일 클릭·노출·CTR·평균 순위를 비교한다.
