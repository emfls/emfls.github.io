# 가평 캠핑 페이지 수익·검색 신뢰도 개편 설계

## 목표

검색 결과 1페이지 하단에 있는 `kor/report/camp/gapyeong.html`을 공식 확인 가능한 등록 야영장과 예약 판단 중심의 페이지로 바꾼다. 검증되지 않은 무료 노지·차박 허용 주장을 제거해 독자 안전과 사이트 신뢰도를 높이고, 28일 동안 검색 클릭과 실제 검색 세션 및 수익 변화를 측정한다.

## 기준 성과

- Search Console 기준선: 클릭 4, 노출 109, CTR 3.67%, 평균 게재순위 9.94
- 28일 후 비교: 검색 클릭, 노출, CTR, 평균 게재순위, 실제 Organic Search 세션, 페이지뷰, 예상수익, 페이지 RPM
- 단기 목표: CTR과 실제 검색 유입의 동반 상승
- 중단 조건: 28일 후 CTR·검색 세션·수익 기여가 모두 개선되지 않으면 같은 유형의 대량 확장을 멈추고 키워드 의도를 재검토한다.

## 선택한 접근

공식 정보만 남기는 전면 개편을 사용한다. 노지 장소를 경관 방문지로 남기는 절충안은 검색 의도를 흐릴 수 있고, 기존 무료 노지 주장을 유지하는 방식은 사실성·안전성 위험이 크므로 제외한다.

## 콘텐츠 구조

1. 첫 화면에서 “공식 등록 야영장을 예약하고, 하천변·계곡·공터는 허용 표지나 관리기관 확인 없이 야영하지 않는다”는 답을 즉시 제공한다.
2. 자라섬 캠핑장을 대표 선택지로 소개하고 주소, 연락처, 시설 유형, 공식 정보 확인 링크를 제공한다.
3. 한국관광공사 고캠핑에서 확인 가능한 가평 등록 야영장을 목적별 대안으로 제시한다. 변동 가능한 가격·운영일은 단정하지 않고 예약 직전 운영처에서 확인하도록 안내한다.
4. 노지 검색자의 의사결정을 돕는 합법·안전 확인 순서를 제공한다: 등록 여부 확인 → 운영처 공지 확인 → 현장 금지 표지 확인 → 기상·하천 수위 확인 → 쓰레기·화기 규칙 준수.
5. 공식 출처와 최근 확인일을 눈에 띄게 표시하고, 실제 캠핑 관련 내부 링크만 제공한다.

## 사실성 및 표현 원칙

- `완전무료`, `무료 노지 캠핑장`, `차박 가능`, `취사 가능`처럼 공식 근거가 없는 허용 표현을 제거한다.
- 양평군 용문산처럼 가평군 밖 장소를 제거한다.
- 자라섬 캠핑장 정보는 한국관광공사 고캠핑의 등록 관광사업자 정보와 운영처 확인을 기준으로 한다.
- 가격, 예약 가능일, 반려동물, 화로, 전기 사용 같은 변동 정보는 확인 링크와 함께 “예약 직전 확인”으로 표현한다.

## 검색·수익 설계

- 제목과 설명에는 `가평 캠핑장`, `자라섬 캠핑장`, `예약`, `노지 캠핑 전 확인`의 실제 검색 의도를 자연스럽게 반영한다.
- 첫 화면에 핵심 답변과 공식 확인 버튼을 배치해 검색 만족도와 유효 클릭을 높인다.
- GA4, AdSense, canonical은 유지한다. 광고 클릭을 유도하는 문구나 광고 인접 CTA는 만들지 않는다.
- `WebPage`와 `FAQPage` 구조화 데이터를 실제 본문과 일치시킨다.

## 화면 및 상호작용

- 기존 청록색 시각 정체성은 유지하되 카드 최소폭을 모바일 안전값으로 바꾼다.
- 고정 홈 버튼은 콘텐츠를 가리지 않는 일반 링크로 변경한다.
- 공식 링크는 새 탭에서 열리고 `rel="noopener noreferrer"`를 사용한다.
- 자주 묻는 질문은 기본 HTML로 모두 읽을 수 있게 제공해 자바스크립트 실패 시에도 핵심 정보가 남도록 한다.

## 검증

- 전용 테스트로 메타데이터, canonical, GA4, AdSense, 공식 출처, 최근 확인일, JSON-LD, 모바일 CSS, 금지 표현 부재를 검사한다.
- 전체 테스트와 우선순위 페이지 검사를 실행한다.
- 공개 배포 후 375px 모바일 폭, 가로 넘침, 링크 동작, 제목·본문·측정 코드 노출을 확인한다.
- Search Console에서 공개 URL 검사 및 색인 요청을 시도하고, 할당량 초과 시 성장 로그에 재요청 필요를 기록한다.
