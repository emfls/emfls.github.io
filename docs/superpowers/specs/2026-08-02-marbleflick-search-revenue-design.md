# MarbleFlick 검색·수익 개선 설계

## 배경과 목표

- Search Console 기준선: 클릭 1, 노출 42, CTR 2.38%, 평균순위 8.98.
- 목표 검색 의도: `마블 플릭 게임`, `구슬 튕기기 게임`, `무료 2인용 게임`, `AI 보드게임` 검색자가 게임 방식과 실행 가능 여부를 즉시 이해하고 플레이하게 한다.
- 성공 기준: 검색 제목과 설명이 게임 내용을 구체적으로 표현하고, 첫 화면에서 무료·무설치·2인/AI·조작법을 확인할 수 있으며, 기존 게임 규칙과 플레이 감각은 유지된다.

## 선택한 접근

SEO·첫 사용 경험을 개선하고 이미 확인된 중복 오류만 수정한다. 제목·설명만 바꾸는 최소안은 검색 후 플레이 전환 개선이 제한적이고, 전면 UI·게임플레이 개편은 현재 검색 성과 기준선을 훼손할 위험이 있어 제외한다.

## 화면과 콘텐츠

- 문서 제목: `마블 플릭 게임 | 무료 2인용·AI 구슬 튕기기`.
- H1은 게임명을 명시하고, 첫 화면에 `다운로드 없이 무료`, `한 기기 2인`, `AI 대전`을 짧게 표시한다.
- 게임판 바로 위에 `내 구슬을 뒤로 당겼다가 놓아 상대 구슬을 원 밖으로 밀어내세요`라는 한 문장 조작법을 둔다.
- 기존 긴 FAQ는 한국어 제목과 간결한 답변으로 정리하되 게임판 아래에 유지한다.
- 다른 게임 목록으로 돌아가는 기존 동선은 유지한다.

## 검색·측정 계약

- canonical, GA4 `G-QP5Q67GE5B`, AdSense `ca-pub-8830524482034754`를 유지한다.
- `VideoGame`과 `FAQPage` JSON-LD를 별도 스크립트로 제공하고 화면에 실제 표시되는 내용만 기술한다.
- 최근 확인일 `2026-08-02`를 표시한다.
- 자동 삽입 광고 요소가 모바일 화면 너비를 넘지 않도록 페이지 범위 CSS를 적용한다.
- 사이트 검색 기능이 없으므로 `SearchAction`은 추가하지 않는다.

## 오류 수정 범위

- 중복된 `id="turn"` 요소 하나를 제거한다.
- 승리 시 `showWinner`가 연속 두 번 호출되는 중복을 제거한다.
- 게임 규칙, 말 배치, 충돌·마찰 계수, 드래그 임계값, AI 선택 로직과 난이도는 변경하지 않는다.

## 검증

- 정적 계약 테스트: 제목·설명·H1, canonical, 측정 코드, JSON-LD, 모바일 광고 폭, 중복 ID와 중복 승리 호출 부재.
- 브라우저 동작 점검: 2인/AI 모드 전환, 드래그 입력, 다시 시작, 다른 게임 이동, 단일 턴 표시.
- 모바일 점검: 375px 화면에서 가로 넘침 없이 게임판·버튼·광고가 화면 안에 표시되는지 확인한다.
- 전체 회귀 테스트와 `git diff --check`를 통과한 뒤 `main`에 배포한다.

## 측정과 중단 기준

- 2026-08-30에 클릭·노출·CTR·평균순위, Organic Search 세션, 참여시간과 수익을 기준선과 비교한다.
- 노출 증가 없이 CTR·플레이 참여가 악화되면 추가 게임 페이지 확장 전에 검색어와 첫 화면 구성을 재검토한다.
