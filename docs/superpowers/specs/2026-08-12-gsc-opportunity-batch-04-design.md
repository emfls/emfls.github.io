# Search Console 성장 후보 4차 개선 설계

## 목표

최근 90일 Search Console에서 노출 10회 이상이며 평균 순위가 7~13위인 잔여 후보 5개를 개선한다. 기존 URL의 검색 신호와 광고·측정 설정을 보존하면서 검색결과 클릭률과 첫 화면 유용성을 높인다.

## 대상과 기준선

| 페이지 | 클릭 | 노출 | CTR | 평균 순위 |
|---|---:|---:|---:|---:|
| 슬로베니아 비자 | 0 | 91 | 0% | 7.91 |
| 공주 캠핑 | 0 | 24 | 0% | 12.71 |
| 네팔 비자 | 0 | 21 | 0% | 7.86 |
| 남수단 비자 | 0 | 19 | 0% | 8.74 |
| 우간다 비자 | 0 | 13 | 0% | 9.77 |

슬로베니아는 노출 규모와 1페이지 순위를 고려해 가장 먼저 처리한다. 나머지 네 페이지는 노출 표본이 작으므로 과도한 제목 변경보다 첫 답변 정확성과 공식 근거를 우선한다.

## 적용 방식

1. canonical URL과 기존 페이지 구조를 유지한다.
2. 제목과 description은 페이지에서 실제로 답하는 조건만 반영한다.
3. 첫 화면에 한국 여권 또는 캠핑 예약 기준의 결론과 다음 행동을 2~4문장으로 배치한다.
4. 슬로베니아는 90/180일 단기 무비자, ETIAS 현재 상태, 취업·장기체류 구분을 공식 자료로 확인한다.
5. 공주 캠핑은 등록 야영장, 실제 운영·예약 상태, 노지 야영 허용 여부 확인 순서를 고캠핑·지자체 자료로 검증한다.
6. 네팔은 도착비자 대상, 15·30·90일 수수료, 온라인 사전 양식과 여권 조건을 이민국 자료로 확인한다.
7. 남수단은 eVisa 공식 포털, 승인서와 입국 심사의 구분, 황열·여행 안전 정보를 정부·공식 기관 자료로 확인한다.
8. 우간다는 eVisa 사전 승인, 공식 수수료, 황열 증명서와 East Africa Tourist Visa 조건을 이민국 자료로 확인한다.
9. 관련 국가·지역 페이지로 문맥형 내부 링크를 유지하거나 보강한다.
10. 실제 확인한 내용만 `2026-08-12`로 갱신한다.

## 사실 정확성 원칙

- 정부·이민국·공식 관광기관·지자체·한국관광공사의 현재 원문만 변동 정보의 최종 근거로 사용한다.
- 검색 결과 요약이나 여행 블로그만으로 수수료·운영 상태·처리기간을 확정하지 않는다.
- eVisa 신청·결제·승인을 최종 입국 허가와 동일시하지 않는다.
- 캠핑장은 등록 사실과 현재 예약 가능 상태를 구분한다.
- 남수단처럼 안전 위험이 큰 목적지는 여행경보를 비자 편의보다 앞에 둔다.

## 정책 및 품질 안전장치

- GA4 `G-QP5Q67GE5B`, AdSense `ca-pub-8830524482034754`, canonical과 기존 광고 위치를 유지한다.
- 광고를 추가하거나 클릭을 유도하지 않는다.
- 비자 승인, 입국, 안전, 캠핑장 운영·예약 가능을 보장하지 않는다.
- 키워드 반복, 과장 제목, 확인되지 않은 고정 비용·처리시간을 사용하지 않는다.
- 정보가 충돌하면 공식 신청·예약 화면에서 출발 또는 결제 직전 재확인을 요구한다.

## 검증과 성과 판정

전용 계약 테스트로 canonical, GA4·AdSense, 최신 확인일, 첫 답변, 공식 출처, 내부 링크와 고위험 정보 안전성을 검증한다. 기존 페이지별 테스트와 전체 `pytest`도 실행한다.

배포 28일 후인 2026-09-09 이후 동일 URL의 클릭, 노출, CTR과 평균 순위를 비교한다. 노출 표본이 작으므로 하루 수익이나 단기 순위 변화만으로 성공을 판단하지 않는다.

## 범위 밖

URL·도메인·광고 위치 변경, 신규 페이지 발행, 대량 문장 치환, Search Console 수동 색인 요청은 이번 배치에 포함하지 않는다.
