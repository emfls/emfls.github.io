# 북마케도니아 비자 페이지 검색·정확성 개선 설계

## 목표

`/kor/report/visa/northmacedonia.html`의 현재 URL과 시각 디자인을 유지하면서, 한국 여권 사용자의 검색 의도에 더 빠르게 답하고 최신 공식 정보에 맞게 부정확한 단정을 제거한다. 변경 전 Search Console 기준선은 클릭 4회, 노출 104회, CTR 3.85%, 평균순위 5.65위다.

## 범위

- 검색 제목, 메타 설명, Open Graph·Twitter 메타데이터
- 첫 화면 제목, 요약 답변, 최근 확인일
- 무비자 방문, 단기 비자, 장기체류·취업·유학 설명
- FAQ와 공식 확인처
- 관련 비자 내부 링크
- Article 또는 WebPage 구조화 데이터
- 기존 검색 필터 기능과 반응형 화면의 회귀 검사

## 제외 범위

- URL 변경과 리디렉션
- 사이트 공통 CSS 또는 광고 배치 변경
- 다른 비자 페이지의 동시 수정
- 확인되지 않은 처리기간·수수료·필수 서류의 추정

## 콘텐츠 설계

### 검색 결과

제목은 한국 여권, 북마케도니아 비자, 90일 무비자, 장기체류를 우선순위에 따라 담되 과도한 키워드 반복과 `완벽`, `최신` 같은 보장 표현을 사용하지 않는다. 설명은 단기 방문과 취업·유학·장기체류의 차이를 한 문장으로 요약한다.

### 첫 화면

H1 바로 아래에서 한국 여권의 단기 방문 가능 여부와 허용 기간을 먼저 답한다. 체류기간 계산 방식과 입국 목적 제한은 공식 출처로 확인한 범위만 명시한다. 취업·유학·가족결합 등은 무비자 방문과 별개라는 경고를 함께 둔다.

### 본문

기존 카드형 구성을 유지하되 다음 순서로 재정리한다.

1. 한국 여권 단기 방문
2. 입국 전 확인사항
3. C형 단기 비자와 D형 장기 비자의 역할
4. 취업·유학·가족결합 등 임시거주 절차
5. 공식 확인처와 관련 페이지
6. FAQ

여행자보험, 범죄경력증명, 여권 잔여기간, 단기 취업 가능 여부처럼 현재 페이지가 필수로 단정한 항목은 공식 근거가 확인될 때만 유지한다. 비자와 취업허가·임시거주 허가를 동일한 제도로 표현하지 않는다.

## 출처 원칙

- 북마케도니아 외교부의 비자·입국 안내
- 북마케도니아 내무부 또는 정부의 외국인 체류 안내
- 대한민국 외교부 해외안전여행의 북마케도니아 입국 정보
- 필요한 경우 북마케도니아 관할 공관의 신청 안내

공식 출처 간 내용이 다르면 최신 날짜와 적용 대상을 비교하고, 해결되지 않는 차이는 출발 전 관할 공관 확인이 필요하다고 표시한다.

## 기술 설계

- canonical URL과 GA4·AdSense 측정 코드를 유지한다.
- 존재하지 않는 사이트 검색 기능을 광고하는 `WebSite/SearchAction` 구조화 데이터는 제거한다.
- 페이지 본문과 일치하는 `Article` 또는 `WebPage` JSON-LD를 사용한다.
- 내부 링크는 실제 존재하는 관련 비자 페이지로만 연결한다.
- 기존 `style.css`와 페이지 검색 스크립트를 유지하며 불필요한 공통 코드 변경은 하지 않는다.

## 오류 처리

- 공식 근거가 없는 요건은 삭제하거나 `목적별 체크리스트 확인`으로 바꾼다.
- 공식 페이지 접근이 불가능하면 해당 사실을 확정 정보로 작성하지 않는다.
- 외부 링크가 실패하거나 다른 내용을 가리키면 배포 전에 교체한다.

## 검증 기준

- HTML 정적 검사와 기존 우선순위 페이지 검증 스크립트 통과
- `git diff --check` 통과
- 제목·설명·canonical·JSON-LD·GA4·AdSense 코드 확인
- 공식 출처 링크의 응답과 본문 주장 일치 확인
- 모바일 폭에서 가로 넘침과 고정 요소의 콘텐츠 가림 없음
- 공개 URL HTTP 200 및 변경한 제목·본문·출처 확인
- 배포 후 Search Console 색인 생성 요청

## 성공 판정

배포 자체는 콘텐츠 정확성·기술 검증 완료로 판정한다. 검색 성과는 28일 뒤 변경 전 기준선과 클릭·노출·CTR·평균순위를 비교하되 적은 표본의 단기 변동으로 성과를 단정하지 않는다.
