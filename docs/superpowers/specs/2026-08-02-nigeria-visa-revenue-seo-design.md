# 나이지리아 비자 페이지 수익·검색 신뢰도 개편 설계

## 목표

한국 여권 소지자의 나이지리아 입국·비자 신청 의도를 공식 자료로 즉시 해결한다. 기준선은 클릭 1, 노출 67, CTR 1.49%, 평균순위 9.01이며 2026-08-30에 검색·수익 지표를 비교한다.

## 선택한 접근

나이지리아 이민청, 주한 나이지리아대사관, 나이지리아 보건부·WHO 중심 전면 재작성 방식을 사용한다. 기존 코드표 유지나 메타만 수정하는 방식은 낡은 수수료·처리기간·운영 중단 오정보를 남기므로 제외한다.

## 콘텐츠

- 한국 여권은 입국 전에 목적에 맞는 비자가 필요하다는 답을 첫 화면에 둔다.
- 단기 방문 e‑Visa와 대사관 단기비자, 취업·거주 비자를 구분하고 e‑Visa가 모든 단기비자의 유일한 경로라고 단정하지 않는다.
- 비자별 서류는 달라진다는 이민청 원칙과 공통 서류만 요약한다.
- 취업은 단기 상용비자로 허용되지 않으며 목적에 맞는 취업·거주 절차와 입국 후 정규화가 필요하다고 안내한다.
- 황열병은 나이지리아 보건부와 WHO의 공식 요구·권고를 안내하되 개인별 접종 적합성은 의료기관 상담을 요구한다.
- 주한 대사관 운영 중단 주장을 삭제하고 예약 방문·연락처를 연결한다.
- 고정 수수료, 잔고 USD 5,000, 추정 처리기간, 한국 비자 포털, 대행 수수료를 제거한다.

## 기술·검증

canonical·GA4·AdSense·검색·FAQ를 유지하고 `WebPage`·`FAQPage`, 최근 확인일, 공식 링크, 모바일 자동광고 폭 제한을 적용한다. 전용·전체 테스트, 우선순위 검사, 공개 375px 검사와 Search Console 상태를 검증한다. 28일 후 CTR·실제 검색 세션·수익이 모두 개선되지 않으면 같은 유형 확장을 멈춘다.
