## 선정

Search Console 2026-08-01 최근 90일 자료에서 남은 미개선 콘텐츠 8개를 우선하고, 10개를 채우기 위해 GA4 2026-07-04~07-31 방문 페이지에서 실제 세션이 있는 미개선 콘텐츠 2개를 추가한다.

2. 일본어 비밀번호 생성기 — GSC 1노출

4. Card Match — GSC 1노출
5. 한국어 비자 목록 — GSC 1노출

## 방식

- 권장안은 검색 잔여 URL과 실제 방문 URL을 결합하는 하이브리드 방식이다. 검색 노출만 따르면 표본이 모두 1회이고, GA4만 따르면 이미 개선한 페이지와 비정상 반복 세션이 섞일 수 있다.
- 여행 페이지는 정부 관광청·교통·입국 자료로 짧은 실제 동선과 안전 판단을 제공하고 고정 가격·운영시간을 제거한다.
- 게임·도구는 기존 기능을 유지하면서 실제 조작·규칙·제한·개인정보와 외부 통신을 설명하고 canonical 슬래시를 통일한다.
- 비자 목록은 개별 국가 조건을 재단정하지 않고 국가 검색, 최근 확인일의 의미, 공식 확인 절차와 안전 경고를 명확히 한다.
- 모든 페이지는 `2026-08-09`, canonical, GA4, AdSense, 적절한 구조화 데이터, 모바일 광고 폭 보호를 적용한다.

## 검증·성공 기준

- 페이지군별 실패 테스트 후 구현한다.
- 전체 unittest, JavaScript 구문, 우선 페이지 검사, `git diff --check`를 통과한다.
- 변경과 기준선을 성장 로그에 기록하고 main에 직접 배포한다.
- Pages 작업 성공과 실제 공개 HTML을 확인한다.
- 성과는 보장하지 않으며 2026-09-06에 GSC·GA4·AdSense를 비교한다.

## 자체 검토

- 동일 URL 중복 없이 10개 파일을 확정했다.
- 신규 대량 페이지 생성 없이 기존 기능·URL 개선으로 범위를 제한했다.
- 미정 항목과 사실 확인 없는 가격·효과 보장은 포함하지 않았다.
