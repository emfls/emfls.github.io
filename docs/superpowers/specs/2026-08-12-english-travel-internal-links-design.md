# English Travel Internal Links Design

## Goal

영어 여행 상세 페이지를 국가별로 묶고, 검색엔진과 사용자가 `여행 메인 → 국가 허브 → 도시 상세` 구조를 정적 HTML 링크로 탐색할 수 있게 한다.

## Scope

- 대상: `report/travel/*.html`의 영어 여행 상세 페이지
- 기존 상세 URL과 canonical URL은 변경하지 않는다.
- 영어 페이지끼리만 관련 콘텐츠를 연결한다.
- 기존 본문과 광고 배치는 유지한다.
- 허브 및 관련 링크는 JavaScript가 없어도 탐색 가능한 `<a href>`로 출력한다.

## Selected Approach

국가별 허브와 같은 국가의 관련 도시 링크를 함께 생성한다. 한 페이지에 모든 도시를 나열하는 단일 허브는 링크 수와 유지보수 비용이 지나치게 커 제외하고, 국가 허브만 만드는 방식은 상세 페이지 사이의 문맥 연결이 약해 제외한다.

## Classification

각 상세 페이지의 canonical URL, 제목, 첫 번째 `h1`, 구조화 데이터의 `addressCountry`, 파일명을 읽어 국가와 도시를 판별한다. 구조화 데이터 값을 우선 사용하고, 값이 없거나 불명확하면 제목과 파일명으로 보완한다. 끝까지 확정할 수 없는 파일은 임의 분류하지 않고 예외 목록에 기록한다.

국가 식별자는 URL에 안전한 소문자 ASCII 슬러그를 사용한다. 국가 허브 URL은 `report/travel/country/<country-slug>/index.html`로 고정한다.

## Generated Structure

### Travel Main Hub

`report/travel/index.html`에 국가 디렉터리를 추가한다. 각 항목은 국가명, 포함된 도시 수, 국가 허브 링크를 제공한다. 국가명 오름차순으로 정렬한다.

### Country Hubs

각 국가 허브는 다음 정보를 제공한다.

- 영어 여행 메인으로 돌아가는 breadcrumb
- 국가명과 포함된 도시 수
- 도시 상세 페이지 카드 목록
- 100개를 초과하는 경우 페이지를 나눈 정적 목록
- 자체 canonical, title, description

### City Detail Pages

각 상세 페이지의 본문 끝과 기존 footer 사이에 `Explore more destinations` 섹션을 넣는다.

- `All travel guides`: 영어 여행 메인
- `<Country> travel guides`: 해당 국가 허브
- `Related cities in <Country>`: 같은 국가의 도시 3개

관련 도시는 국가 내 정렬 순서의 앞뒤를 순환하는 결정적 방식으로 선택한다. 같은 입력으로 다시 생성해도 링크가 바뀌지 않으며, 각 도시가 다른 도시에서 링크를 받게 한다. 국가에 도시가 3개 미만이면 존재하는 도시만 표시한다.

## Generator Boundaries

- 분류기: HTML에서 국가·도시·canonical 정보를 추출한다.
- 링크 계획기: 국가 그룹과 관련 도시 목록을 계산한다.
- 렌더러: 국가 허브 및 상세 페이지 링크 블록을 만든다.
- 적용기: 생성 마커 사이만 교체해 재실행 시 중복을 방지한다.
- 검사기: 링크 대상 존재 여부, canonical, 언어 경계, 중복 블록을 검증한다.

## Failure Handling

- 국가를 확정하지 못한 페이지는 수정하지 않고 예외 CSV에 기록한다.
- canonical이 없거나 `report/travel/` 밖을 가리키는 페이지는 수정하지 않는다.
- 링크 대상 파일이 존재하지 않으면 생성 작업을 실패시킨다.
- 전체 생성은 임시 출력 검증이 통과한 뒤 실제 파일에 적용한다.

## Acceptance Criteria

- 분류 가능한 모든 영어 여행 상세 페이지에 여행 메인과 국가 허브 링크가 있다.
- 도시가 2개 이상인 국가의 각 상세 페이지는 같은 국가의 다른 도시 링크를 최소 1개 받는다.
- 도시가 4개 이상인 국가의 각 상세 페이지는 관련 도시 링크 3개를 제공한다.
- 생성된 내부 링크의 404가 0개다.
- 일본어·한국어 상세 페이지 링크가 관련 도시 블록에 포함되지 않는다.
- 생성기를 두 번 실행해도 두 번째 실행에서 파일 변경이 없다.
- 기존 canonical URL과 본문 콘텐츠가 유지된다.

## Verification

자동 테스트로 분류 우선순위, 하이픈이 포함된 국가명, 소규모 국가, 관련 도시 순환, 중복 방지, 허브 페이지 나누기, 깨진 링크 검사를 검증한다. 전체 적용 후 모든 영어 여행 페이지를 다시 스캔해 고립 페이지 수와 유입 링크 분포를 재계산한다.
