# Search Console 성장 후보 7차 개선 설계

## 목표와 기준선

검색 1페이지에서 실제 클릭을 만드는 상위 페이지의 순위를 보호하면서 첫 화면 의사결정을 강화한다.

| 페이지 | 클릭 | 노출 | CTR | 평균 순위 |
|---|---:|---:|---:|---:|
| 청주 캠핑 | 23 | 489 | 4.70% | 7.87 |
| 김포 캠핑 | 26 | 315 | 8.25% | 6.37 |
| 담양 캠핑 | 27 | 301 | 8.97% | 6.72 |
| 루마니아 비자 | 8 | 214 | 3.74% | 7.65 |
| 슬로바키아 비자 | 6 | 198 | 3.03% | 5.54 |

## 적용 방식

- 캠핑 3개 페이지는 제목을 유지하고 첫 화면에 `공식 예약시설 / 일반 방문지·노지 후보 / 출발 전 확인`의 판단 순서를 제공한다. 등록 정보와 현재 예약 가능 상태를 구분한다.
- 청주는 문암생태공원 공식 예약·이용안내, 김포·담양은 고캠핑 등록 정보와 운영자 예약 채널을 우선한다.
- 루마니아는 솅겐 전체 합산 90/180일, 입·출국일 계산과 EES 적용을 명확히 한다.
- 슬로바키아는 솅겐 전체 합산 90/180일, 국가비자와 체류허가의 차이를 첫 화면 표로 정리한다.
- 기존 canonical, 제목, GA4, AdSense와 광고 위치를 유지한다.
- 운영·예약·입국·체류를 보장하지 않으며 공식 확인 항목만 `2026-08-12`로 갱신한다.

## 검증과 판정

전용 테스트를 RED→GREEN으로 실행하고 관련·전체 테스트 및 diff 검사를 통과시킨다. 2026-09-09 이후 최근 28일 클릭·노출·CTR·평균 순위를 비교하며, 기존 CTR이나 순위가 하락하면 제목 변경 없이 본문만 재검토한다.
