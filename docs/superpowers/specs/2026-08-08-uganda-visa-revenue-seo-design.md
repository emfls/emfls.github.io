# 우간다 비자 페이지 개선 설계

- 목표: `우간다 비자`, `한국 여권`, `eVisa` 검색 의도에 첫 화면에서 답하고 미색인 페이지의 품질을 높인다.
- 핵심 답변: 한국 일반 여권은 출발 전 공식 포털에서 비자를 신청하고 승인서를 받아야 하며 도착비자는 발급되지 않는다.
- 공식 사실: 단수 관광비자 US$50, 최대 3개월, 최소 출발 10일 전 신청 권고, 여권 6개월, EATV US$100·90일·우간다/케냐/르완다.
- 구조: WebPage/FAQPage 스키마, 신청 단계, 준비물, EATV, 황열, 연장·취업 구분, 공식 출처, 관련 글.
- 제거: 250KB 고정 제한, US$1.5 고정 수수료, 14일 처리, 무료 3개월 연장, 크루즈 비자 등 근거가 약하거나 오래된 표현.
- 측정: 기존 GA4·AdSense·canonical 유지. 배포 후 공개 HTML과 전체 테스트를 확인한다.
