# 스위스 비자 페이지 수익형 검색 개선 설계

## 목표

`/kor/report/visa/switzerland.html`의 URL과 기존 시각 디자인을 유지하면서 한국 여권 사용자의 단기 방문, ETIAS, 취업·유학 검색 의도에 공식 정보로 답한다. Search Console 기준선은 클릭 1회, 노출 97회, CTR 1.03%, 평균순위 10.71위다. 이 페이지의 직접 목표는 검색 클릭과 실제 독자 유입을 늘리는 것이며 일 수익 100달러를 보장하지 않는다.

## 수익 가설과 판정

현재 페이지는 노출 대비 CTR이 낮고 제목·첫 답변에 낡은 연도 표현이 있어 개선 여지가 있다. 정확한 제목과 답변으로 검색 클릭을 늘리고, 취업·유학처럼 정보 탐색이 긴 의도를 함께 충족하면 페이지뷰와 광고 노출이 증가할 수 있다는 가설을 검증한다.

- 28일 뒤 클릭, 노출, CTR, 평균순위를 변경 전 기준선과 비교한다.
- GA4–AdSense에 페이지 수익이 표시되면 해당 URL의 실제 검색 세션, 참여시간, 페이지뷰, 예상 수익, 페이지 RPM을 함께 본다.
- 노출만 늘고 CTR·참여·수익이 개선되지 않으면 같은 형태의 스위스 콘텐츠 확장을 중단한다.
- 하루 수익 변동이나 자동화로 의심되는 Direct 트래픽은 성장 근거로 사용하지 않는다.

## 범위

- 검색 제목, 메타 설명, Open Graph·Twitter 메타데이터
- 첫 화면 한국 여권 무비자 답변과 최근 확인일
- 180일 내 90일 계산, ETIAS 현재 상태, 입국 전 확인사항
- C형 단기 비자와 D형 장기 비자 구분
- 한국 국적자의 취업·유학 등 목적별 허가 안내
- FAQ, 공식 확인처, 유럽 관련 비자 내부 링크
- `WebPage` 구조화 데이터와 모바일 가로 넘침 방지
- 기존 검색 필터, FAQ, GA4, AdSense의 회귀 검사

## 콘텐츠 설계

### 검색 결과와 첫 화면

제목은 `스위스 비자`, `한국 여권`, `90일 무비자`, `ETIAS`, `취업·유학` 중 핵심 검색 의도를 자연스럽게 담고 `완벽`, `최신`, 특정 연도 보장 표현을 제거한다. H1 아래에서 한국 여권은 스위스·쉥겐 지역에서 180일 내 최대 90일 무비자라는 답을 먼저 제공한다. 무비자는 취업이나 90일 초과 체류 허가가 아니며 입국은 국경 당국의 심사를 받는다는 범위를 함께 표시한다.

### 본문 순서

기존 카드형 `.visa-category` 구조를 다음 순서로 재편한다.

1. 한국 여권 90일 무비자 방문
2. 180일 내 90일 계산과 입국 전 확인
3. ETIAS 현재 상태
4. C형 쉥겐 비자와 D형 국가 비자
5. 한국 국적자의 취업 허가
6. 유학·가족결합 등 장기체류
7. 공식 출처와 관련 유럽 비자 페이지
8. FAQ

### 정확성 원칙

- 주한 스위스대사관 공식 안내에 따라 대한민국 국적은 쉥겐 단기비자가 필요 없고 180일 내 최대 90일 체류할 수 있다고 쓴다.
- ETIAS는 2026년 4분기 운영 예정이며 현재 여행자가 할 일은 없다는 EU 공식 상태로 표시한다. 구체적 시행일은 발표되지 않았다고 명시한다.
- 비자 면제와 입국 요건, 비자, 체류허가, 취업허가를 서로 다른 제도로 설명한다.
- 한국 국적자는 비EU/EFTA 제3국 국민이라는 전제에서 취업허가가 필요하고, 일반적으로 고숙련 요건·쿼터·스위스 또는 EU/EFTA 노동시장 우선 원칙이 적용되며 미래 고용주가 관할 당국에 신청한다고 안내한다.
- 현재 페이지의 L·B·G·C 허가증별 고정 기간·요건은 일반화하지 않는다. 특히 G 허가는 인접국 영주권과 국경지역 거주 조건이 있는 특수 제도임을 고려해 핵심 검색 답변에서 제외한다.
- 하루 CHF 100, 학생 CHF 30 같은 입국 재정 기준은 적용 대상과 공식 근거가 본문에서 명확할 때만 사용한다.
- 추정 처리기간, 모든 신청자에게 동일한 범죄경력·보험·출국서약 요건은 삭제한다.

## 공식 출처

- 주한 스위스대사관 `Do I need a Schengen visa?`
- 스위스 연방 이민청(SEM)의 입국·취업·비EU/EFTA 국민 안내
- EU 공식 ETIAS 안내
- 장기체류 신청 절차가 필요할 때 주한 스위스대사관 공식 비자·영사 안내

출처가 다른 대상이나 목적을 설명하면 한 문장으로 합치지 않는다. 내용이 충돌하거나 적용 대상을 확정할 수 없으면 출발 전 대사관·관할 칸톤 당국 확인이 필요하다고 표시한다.

## 기술 설계

- canonical `https://emfls.github.io/kor/report/visa/switzerland.html`을 유지한다.
- GA4 `G-QP5Q67GE5B`와 AdSense `ca-pub-8830524482034754`를 유지한다.
- 존재하지 않는 사이트 검색용 `WebSite/SearchAction`을 제거하고 본문과 일치하는 `WebPage` JSON-LD와 `dateModified: 2026-08-02`를 사용한다.
- 본문을 `<main>`으로 감싸고 `최근 확인: 2026-08-02`와 HTTPS 공식 링크를 제공한다.
- 기존 `style.css`, `searchInput`, `toggleFAQ(element)` 인터페이스를 유지한다.
- 페이지 범위에서 자동삽입 광고가 모바일 문서 폭을 확장하지 못하도록 가로 넘침을 차단한다.
- 내부 링크는 실제 존재하는 프랑스, 독일, 이탈리아, 오스트리아, 리히텐슈타인 비자 페이지만 사용한다.

## 오류 처리

- 공식 페이지가 접근 불가능하거나 최신 상태를 확인할 수 없으면 해당 내용을 확정 문구로 작성하지 않는다.
- ETIAS 일정이 변경되면 EU 공식 페이지를 우선하며 `예정`과 `시행 중`을 구분한다.
- 목적·국적·칸톤별로 달라지는 요건은 고정 체크리스트 대신 담당기관 확인 단계로 안내한다.
- 공개 배포에서 자동 광고가 모바일 폭을 넘기면 페이지 범위 CSS로 차단하고 375px에서 재검증한다.

## 검증 기준

- 페이지 전용 회귀 테스트를 먼저 작성하고 기존 페이지에서 실패하는지 확인한다.
- 전용 테스트와 공통 `validate_priority_pages.py` 검사를 통과한다.
- 제목·설명·canonical·최근 확인일·`WebPage` JSON-LD·GA4·AdSense·공식 링크를 확인한다.
- `완벽`, `2025년부터 ETIAS`, 추정 처리기간, 존재하지 않는 `SearchAction`이 남지 않아야 한다.
- 관련 내부 링크 파일이 모두 존재해야 한다.
- 공개 URL HTTP 200, 새 제목·첫 답변·공식 링크·검색 필터·FAQ 동작을 확인한다.
- 375px 화면에서 문서 가로 넘침이 없어야 한다.
- Search Console URL 검사에서 색인 생성을 재요청하고 실제 결과를 성장 로그에 기록한다.

## 성공 판정

배포 성공은 콘텐츠 정확성, 자동 검사, 공개 화면과 기능, 색인 요청 완료로 판정한다. 수익 성공은 2026-08-30에 실제 검색 유입과 페이지 수익을 기준선과 비교해 별도로 판정하며, 단일 페이지가 일 100달러 목표를 달성한다고 주장하지 않는다.
