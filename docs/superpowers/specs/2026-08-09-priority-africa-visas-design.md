# 남수단·탄자니아·토고 비자 우선 페이지 개선 설계

- 한국 여권의 관광 단기 방문을 첫 답변으로 제공하고, 정부 공식 신청 포털과 최신 지침만 핵심 근거로 사용한다.

- 기존 페이지의 근거 없는 처리기간·도착비자·수수료·장기체류 단정을 제거한다.
- WebPage/FAQPage, 공식 자료 최근 확인일, 관련 가이드, 모바일 광고 폭 보호를 적용한다.
