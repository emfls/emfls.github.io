# Image Compressor 색인·정확성 개선 설계

- JPEG·PNG·WebP 일괄 선택, 품질 슬라이더, 개별/ZIP 저장 기능을 유지한다.
- 출력은 JPEG이며 긴 변은 최대 1600px, PNG 투명도와 애니메이션은 유지되지 않는다는 핵심 조건을 첫 화면에 설명한다.
- 무조건 50~90% 감소한다는 주장을 제거하고 결과가 커질 때도 정확한 용량 변화를 표시한다.
- 이미지 처리는 기기 내에서 하지만 분석·광고 스크립트는 통신한다고 정확히 안내한다.
- WebApplication/FAQPage, 갱신일, 모바일 광고 폭 보호를 추가한다.
