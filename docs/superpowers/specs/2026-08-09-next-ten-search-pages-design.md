## 설계

- 게임은 실제 동작과 질문 수·결과 산식을 확인하고 검색 제목, 사용법, 개인정보 설명, WebApplication/FAQPage를 보강한다.
- 게임·직업 정보는 공식 운영사 자료를 우선하고 자동화·허위 확률·확정적 추천을 제거한다.
- 비자는 정부 이민국·외교부·대사관의 현재 자료로 한국 여권 단기 방문의 첫 답변, 신청 경로, 금지 활동과 입국 재량을 정리한다.
- 여행은 정부 관광청·교통기관·내무부 자료로 실제 명소와 이동 방법을 확인하고 고정 환율·운임·운영시간 단정을 제거한다.
- 모든 페이지는 `2026-08-09` 최근 확인일, canonical, GA4, AdSense, WebPage 또는 WebApplication과 FAQPage, 모바일 광고 폭 보호, 관련 내부 링크를 갖춘다.
- 페이지별 전용 테스트를 먼저 실패시킨 후 최소 변경으로 통과시키고, 전체 회귀 테스트와 공통 우선 페이지 검증기를 실행한다.
- 변경 내용과 기준 노출을 성장 로그에 저장하고 각 검증 단위가 끝날 때 main에 커밋·배포한다.

## 성공 기준

- 사실이 변하기 쉬운 주장은 최신 공식 출처로 뒷받침된다.
- 기존 핵심 기능은 유지되며 발견한 실행 오류는 재현 테스트와 함께 수정된다.
- 전용 테스트, 전체 테스트, `git diff --check`, 적용 가능한 공통 검증기가 통과한다.
- GitHub Pages 배포가 성공한다.
