# 세네갈 비자 검색·수익 개선 실행 계획

1. 공식 출처로 한국 여권 비자 면제, 여권 유효기간, 황열 조건을 교차 확인한다.
2. 사용자 의도·페이지 계약·잘못된 문구 제거를 검증하는 회귀 테스트를 먼저 작성하고 실패를 확인한다.
3. 첫 답변, 체크리스트, 장기체류 구분, 공식 링크, FAQ를 갖춘 정적 페이지로 교체한다.
4. 집중 테스트, 우선순위 페이지 검증기, 전체 테스트를 실행한다.
5. 성장 로그에 기준 지표·출처·변경·검증·색인 상태를 기록한다.
6. `main`에 푸시하고 GitHub Pages 공개 페이지에서 새 콘텐츠와 측정 코드를 확인한다.
