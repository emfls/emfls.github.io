## 검증·측정·복구

승인 전 실제 Guard는 PROTECTED_WINNER_CHANGED로 차단했다. 정확 pair만 허용하고 이웃 버전·역전·다른 WINNER·OBSERVING은 계속 차단하는 테스트를 추가한다. 관련 기능·기존 보호·SEO 테스트, 정확 시작 main 대비 SEO 회귀, 모바일320/390/430px·공개 본문 및 링크를 확인한다. 기존 전체 SEO 오류와 오래된 나주/하동 제목 기대값 실패를 새 회귀와 구분하며 검사·기준을 약화하지 않는다. 공개 배포 전에는 배포 완료로 기록하지 않는다.

배포 혼합일11/8은 제외한다. 신규 세 URL은 전11/1~7 대 후11/9~15,11/16 이후 원천 종료일을 확인한 기존09·18시 실행에서 관측한다. URL별 네이버 동일기간이 없으면 NOT_AVAILABLE/NOT_READY로 두고 겹치는30일 창으로 대체하지 않는다. 실제 모바일 클릭 절대량·노출·계산CTR을 함께 보고, GA4 네이버 유입·사이트 단독 AdSense는 별도 지표다. 기존7개와 사이트전체 광고 개입을 덮어쓰지 않는다. 자동화 갱신·실제 수집·미래 비교 완료는 다른 상태다. 기능·검색 클릭 회복·수익 효과는 각각 별도 판정한다.
