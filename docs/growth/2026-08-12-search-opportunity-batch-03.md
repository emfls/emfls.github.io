# 검색 기회 페이지 3차 개선 기록

## 목적

최근 90일 Search Console에서 검색 노출이 있으나 클릭률 또는 평균 순위 개선 여지가 있는 5개 URL을 2026-08-12 공식 정보 기준으로 보강했다. URL과 기존 측정 신호는 유지했다.

## 적용 내용

- 스위스: 90/180일 단기 방문, 현재 ETIAS 신청 미개시, 취업·장기체류 분리를 첫 답변에 명시했다.
- 르완다: 모든 국적의 도착비자 선택지, 온라인 사전 신청, 6개월 여권과 황열 조건을 정리했다.
- 토고: 근거가 불명확한 도착비자 중단 단정을 제거하고 Togo Voyage의 최소 5일 전 신청 안내와 7일 전 권장을 반영했다.
- 탄자니아: Ordinary Visa의 공식 수수료·최대 유효기간, eVisa·도착비자 선택지, 여권·항공권 서류를 유지하고 최신 확인일을 맞췄다.
- 애들레이드: 공항 Stop 10의 J1·J2, 센트럴 마켓 휴장일, 2박 3일 동선과 Australian ETA 앱 신청을 첫 화면부터 연결했다.

## AdSense·품질 안전장치

- AdSense 게시자 ID와 기존 광고 배치를 유지하고 광고를 추가하지 않았다.
- GA4 측정 ID, canonical URL과 기존 페이지 URL을 유지했다.
- 비자 승인·입국을 보장하지 않았고 변동 정보는 출발 직전 공식 재확인을 안내했다.
- 광고 클릭 유도, 과장 제목, 키워드 반복과 광고·내비게이션 혼동 요소를 추가하지 않았다.

## 성과 확인

2026-09-09 이후 동일 5개 URL의 최근 28일 클릭·노출·CTR·평균 순위를 이 기준선과 비교한다. 표본이 작으므로 일별 AdSense 수익만으로 성공 또는 실패를 판단하지 않는다.
