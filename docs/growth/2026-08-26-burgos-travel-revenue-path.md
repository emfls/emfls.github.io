# 부르고스 여행 수익 경로 개선

## 선정 근거

- 기존 GA4 점검에서 실제 수익 신호가 있었지만 조회 표본이 작아 보류했던 페이지다.
- 고정 여행비·열차 시간·안전도·시설 운영시간 단정이 남아 있었다.
- 보류 수익 후보를 순차적으로 정밀 개선하되 소표본 수익은 확대 근거로 사용하지 않는다.

## 적용

- `부르고스 여행 가이드 2026`과 대성당·아타푸에르카·마드리드 교통 의도로 제목과 설명을 정리했다.
- 입국·교통·운영시간·예약·안전의 출발 전 확인 순서를 추가했다.
- 부르고스 관광청, Renfe, 스페인 외교부와 한국 외교부를 공식 확인 경로로 연결했다.
- 고정 여행비·열차 소요시간·안전도·시에스타 단정을 최신 확인형으로 전환했다.
- 마드리드·산티아고·빌바오 내부 링크를 추가했다.
- 광고 배치는 변경하지 않았다.

## 측정

- 배포 후 7일·28일의 자연검색 유입, 참여시간과 페이지 수익을 비교한다.
