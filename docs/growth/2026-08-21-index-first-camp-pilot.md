# 2026-08-21 색인 우선 캠핑 파일럿

## 목적

미색인 페이지는 검색 유입과 광고수익을 만들기 어렵다는 원칙을 반영해, Google 검색 반응이 이미 확인된 캠핑 페이지 5개를 허브 상단에서 직접 연결한다.

## 변경

- 대상: 청주, 담양, 김포, 경기도 광주, 부산 캠핑 가이드
- 캠핑 허브 상단에 검색 반응 확인 페이지 섹션 추가
- 허브에 남아 있던 부산·담양의 과장되거나 오래된 카드 문구를 현재 본문과 일치시킴
- 5개 페이지와 실제 수익이 확인된 남양주 페이지를 양방향 관련 링크로 연결
- 캠핑 허브 구조화 데이터의 수정일을 2026-08-21로 갱신
- 광고 코드와 광고 위치는 변경하지 않음

## 색인 조건 점검

- 5개 페이지 모두 self-canonical과 `index,follow` 또는 차단 없는 기본값 사용
- 5개 페이지 모두 `/kor/report/camp/sitemap.xml`에 포함
- 루트 사이트맵이 캠핑 사이트맵을 참조
- 캠핑 허브에서 일반 HTML 링크로 직접 접근 가능
