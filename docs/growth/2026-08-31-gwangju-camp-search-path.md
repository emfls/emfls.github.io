# 경기도 광주 캠핑 검색 경로 개선

- 근거: 최근 Search Console 4클릭, 73노출, CTR 5.48%, 평균순위 7.67
- 기존 본문과 검색 문구는 2026-08-24에 이미 개선되어 재작성하지 않았다.
- 경기도 캠핑 허브에서 광주 페이지로 가는 링크를 추가했다.
- 광주 페이지의 무관한 원거리 추천을 성남·용인·이천·양평 인접 지역으로 교체했다.
- 광고 배치와 광고 클릭 유도 요소는 변경하지 않았다.

## 측정

배포 후 14일 동안 광주 페이지의 Google 클릭·노출·평균순위와 내부 이동을 비교한다.
