# 영암 캠핑 수익 경로·신뢰도 개선

## 선정 근거

- 최근 GA4 점검에서 실제 페이지 수익 신호가 있었지만 조회 표본이 작아 우선 보류했던 URL이다.
- 최근 별도 정밀 개선 기록이 없고, 2025년 제목·노지 숙박 가능 단정·고정 요금과 전화번호가 남아 있었다.
- 신규 페이지 발행보다 이미 수익이 확인된 페이지의 검색 의도와 신뢰 개선을 우선한다.

## 적용

- 제목·설명·공유 및 구조화 데이터를 `영암 캠핑·차박 가이드 2026` 의도에 맞췄다.
- 야영·차박 허용 여부, 등록 캠핑장, 출발 당일 확인 순서를 상단에 추가했다.
- 하느제 숙박 가능 단정, 고정 요금·시설 포함·전화번호 정보를 제거하거나 최신 확인형으로 전환했다.
- 고캠핑 등록시설 검색과 영암군 공식 홈페이지를 확인 경로로 연결했다.
- 전남·목포·화순 캠핑 페이지와 캠핑 전체 목록을 연결·갱신했다.
- 광고 배치는 변경하지 않았다.

## 측정

- 배포 후 7일·28일의 자연검색 유입, 조회수, 참여시간과 페이지 수익을 비교한다.
