# 송지호 오토캠핑장 예약 검색 의도 개선

## 선택 근거

- Google Trends 후보 조사에서 `송지호오토캠핑장 예약` 관련 검색이 급등 신호를 보였다.
- 기존 `kor/report/camp/goseong.html`에 송지호 구역이 있으므로 새 URL을 만들지 않고 기존 canonical을 강화했다.
- 고성군 공공캠핑장 공식 페이지에서 운영 주체, 예약 경로, 다음 시즌 오픈 일정과 시설 정보를 확인했다.

## 적용 내용

- 제목과 H1을 `송지호 오토캠핑장 예약`으로 시작하도록 변경했다.
- 첫 화면에서 고성군 통합예약 온라인 예약임을 바로 답했다.
- 공식 안내의 `매월 셋째 주 화요일 10시`, `다음 달 1일부터 말일까지` 조건을 반영했다.
- 실시간 잔여 사이트와 운영 공지를 공식 예약 화면에서 확인하도록 연결했다.
- `예약 필수`, `성수기 비쌈` 같은 근거가 약한 단정을 제거했다.
- WebPage와 FAQPage 구조화 데이터를 2026-08-13 기준으로 갱신했다.
- canonical, GA4, AdSense 로더와 기존 광고 정책 보호를 유지했다.
- 최근 업데이트 RSS를 재생성했다.

## 정책·품질 안전

- 특정 날짜의 예약 가능 여부와 요금을 보장하지 않는다.
- 해변·주차장 소개가 무료 또는 합법 야영 허가를 의미하지 않는다는 기존 경고를 유지했다.
- 광고 클릭을 유도하거나 예약 버튼과 광고를 혼동시키는 요소를 추가하지 않았다.
