# 진주 캠핑 수익 경로·본문 일관성 개선

## 선정 근거

- GA4 기간: 2026-08-19~2026-08-25
- 페이지 실적: 조회 13, 활성 사용자 13, 누적 참여 795초, 총수익 약 $0.026
- 기존 상단 안전 요약과 경남 내부링크는 적용돼 있었지만 제목·본문에는 무료 차박·선착장 숙박 단정이 남아 있었다.
- 같은 수익대 후보 중 활성 사용자 표본이 안정적인 페이지였다.

## 적용

- 제목·설명·공유 및 구조화 데이터를 `진주 캠핑·차박 가이드 2026` 의도에 맞춰 통일했다.
- 기존 상단 요약을 재사용해 야영·차박 허용 여부, 등록 캠핑장, 출발 당일 확인 흐름을 명확히 했다.
- 와룡지구 친수생태공원과 진양호 선착장을 무료·스텔스 차박 장소로 단정한 표현을 제거했다.
- 고캠핑 등록 시설 검색과 진주시 공식 홈페이지를 최신 확인 경로로 연결했다.
- 경남·하동·김해 내부링크를 유지하고 캠핑 허브의 진주 설명을 갱신했다.
- 기존 URL, 애드센스와 GA4를 보존하고 광고 배치는 변경하지 않았다.

## 측정

7일 이상 지난 뒤 조회수, 평균 참여시간, 경남 지역 페이지 이동, 활성 사용자당 조회수와 총수익을 비교한다. 광고 CTR은 최적화 기준으로 사용하지 않는다.
