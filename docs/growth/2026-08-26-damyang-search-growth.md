# 담양 캠핑 검색 성장 경로 개선

## 선정 근거

- Search Console 2026-07-24~08-20: 클릭 6, 노출 106, CTR 5.66%, 평균순위 8.55.
- 첫 페이지 상단 진입 가능성이 있는 URL로 신규 페이지보다 기존 검색 경로 개선 가치가 높다.
- 안전 안내는 있었지만 전남 인접 페이지 대신 전국의 무관한 지역 링크가 연결돼 있었다.

## 적용

- 제목을 `담양 캠핑·차박 가이드 2026` 검색 의도에 맞췄다.
- 상단에 장소·주차·화장실·취사·요금·허용 여부·최종 검토 정보를 구조화했다.
- 전남·장성·화순 가이드로 지역 내부 링크를 교체했다.
- 하천·주차장·계곡을 숙박 장소처럼 보이게 하던 잔여 표현을 제거했다.
- 구조화 데이터와 캠핑 목록 설명을 갱신하고 광고 배치는 유지했다.

## 측정

- 배포 후 7일·28일의 Google 클릭, 노출, 평균순위, GA4 조회와 페이지 수익을 비교한다.
