# 일 $100 프로젝트 수익 최우선 운영 전환

작성일: 2026-08-21

## 판정

기술 SEO와 정책 안전 기반은 충분히 구축됐다. 앞으로는 수익 증거 없이 페이지를 계속 개선하거나 대량 발행하지 않는다. 마지막 확인 실적은 최근 7일 $2.75, 일평균 약 $0.39이며 Google 검색 클릭은 7일 8회였다. 현 단계의 병목은 페이지 수나 metadata 보급률이 아니라 검색 수요·유입 규모·수익 기여 페이지 식별이다.

## 최우선 KPI

1. 28일 AdSense 총수익과 일평균 수익
2. Organic landing sessions와 수익 발생 페이지뷰
3. 수익/1,000페이지뷰와 페이지뷰/세션

가드레일은 AdSense 정책센터 상태, 비정상 CTR, 무효 트래픽 신호다. 광고 CTR 자체는 성장 KPI로 사용하지 않는다.

## 작업 우선순위

### P0 — 최신 28일 수익 기준선 재구축

- AdSense 최근 28일과 직전 28일: 날짜·사이트·국가·기기·플랫폼·유입소스·가능한 페이지별 수익/PV/RPM
- GA4 같은 기간: landing page·source/medium·organic sessions·views·engagement
- Search Console 같은 기간: page·query·clicks·impressions·position
- 세 소스를 URL 또는 페이지군 단위로 묶어 `수익 증가`, `트래픽만 증가`, `무성과`로 분류

### P1 — 대량 개선·대량 발행 중단

- 최신 데이터가 나오기 전 수백·수천 페이지 개선 금지
- 노출·세션·수익이 없는 페이지는 작업 대상에서 제외
- 광고 배치 추가와 CTR 상승 실험 금지

### P2 — 실제 수익 페이지 상위 20개 집중

- 상위 20개가 만드는 수익·PV·유입소스 비중 계산
- 각 페이지의 검색어와 이탈 지점을 확인
- 같은 검색 의도의 기존 페이지 3~5개만 연결·개선
- 승자 페이지와 직접 연결되지 않는 사이트 전체 개선은 보류

### P3 — Naver/Bing/Google 채널별 승자 확대

- 2026-08-15 자료에서 Naver가 7일 수익 $1.82로 가장 큰 유입원이었다.
- Naver에서 유입되는 실제 URL과 검색어를 먼저 식별해 같은 의도의 후속 콘텐츠·도구를 소규모 확장
- Google은 4~20위이면서 의미 있는 노출이 있는 페이지에만 1회 개선
- Bing은 영어 도구·계산기 중 이미 유입이 있는 유형만 확장

### P4 — 반복 사용 도구의 페이지뷰/세션 확대

- QR·날짜·텍스트·금융 계산기 중 실제 사용 페이지를 선별
- 결과 화면에서 관련 가이드·다음 도구 2~4개로 자연스럽게 연결
- 광고는 입력·실행·결과 버튼과 충분히 분리
- `tool_use`, 내부 이동, 재방문이 증가한 도구만 후속 도구 제작

### P5 — 수요 검증 신규 콘텐츠 실험

- 한 번에 5개만 발행
- 기존 Search Console 검색어, Naver 유입 검색어 또는 실제 도구 사용과 직접 연결된 주제만 허용
- 28일 뒤 노출·클릭·세션·수익 중 실질 신호가 없으면 같은 유형 생산 중단
- 금융·세금·정부지원은 공식 출처와 검토일이 있을 때만 발행

### P6 — 수익 단계 목표

1. 28일 평균 일 $1
2. 28일 평균 일 $3
3. 28일 평균 일 $10
4. 월 100,000 PV와 RPM 검증
5. 이후 일 $30, 일 $100 확장성 재판정

## 중단 기준

- 60일 동안 검색 노출과 자연검색 세션이 사실상 없는 페이지군은 추가 개선 중단
- 28일 실험에서 유입 또는 참여 신호가 없는 신규 유형은 후속 발행 중단
- 수익 증가 없이 광고 CTR만 상승하면 즉시 정책 안전 감사
- 전체 페이지 수, 수정 페이지 수, 테스트 개수는 수익 성과로 보고하지 않음

## 다음 실행

첫 작업은 최신 28일 AdSense·GA4·Search Console 데이터를 같은 기간으로 다시 수집하고 `수익 페이지 상위 20개`를 확정하는 것이다. 그 전에는 추가 콘텐츠 개선을 진행하지 않는다.
