# 인천 캠핑 수익 경로·신뢰도 개선

## 선정 근거

- GA4 기간: 2026-08-18~2026-08-24
- 페이지 실적: 조회 6, 활성 사용자 5, 활성 사용자당 조회 1.2, 평균 참여 13초, 총수익 $0.02
- 실제 수익이 발생했지만 같은 후보군에서 참여시간이 가장 낮았다.
- 기존 상단에는 안전 안내가 있었으나 본문에는 `2025`, 무료 야영·무료 주차, 차박 성지와 고정 요금 단정이 남아 있었다.

## 적용

- 제목·설명·공유 메타데이터를 2026년 검색 의도에 맞게 갱신했다.
- 해변 주차와 야영·차박·취사 허용 여부가 서로 다름을 상단에서 먼저 안내했다.
- 해변과 섬의 무료 야영·차박 보장 표현 및 공립 캠핑장 고정 요금을 제거했다.
- 한국관광공사 고캠핑과 인천광역시를 공식 확인 경로로 연결했다.
- 경기·고양·평택 캠핑 내부링크와 캠핑 허브의 인천 설명을 유지·갱신했다.
- 기존 URL, 광고와 GA4 코드는 유지하고 광고 배치는 변경하지 않았다.

## 측정

7일 이상 지난 뒤 조회수, 평균 참여시간, 활성 사용자당 조회수, 다음 페이지 이동과 총수익을 비교한다. 광고 CTR은 최적화 기준으로 사용하지 않는다.
