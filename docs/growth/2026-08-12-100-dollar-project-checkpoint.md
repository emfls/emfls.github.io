현재 단계는 `기반 정비 완료 → 성과 검증 대기`다. 다음 핵심 업무는 페이지를 더 많이 수정하는 것이 아니라 2026-08-15 7일 측정과 2026-08-31 28일 측정에서 살아남을 콘텐츠군을 고르는 것이다.

## 일 $100과의 거리

마지막 실적 기준 최근 7일 수익은 $1.60, 일평균 약 $0.23이다. 따라서 반올림 방식에 따라 일 $100까지 약 435~438배가 필요하다.

- 페이지 RPM $4.02 가정: 약 24,900 페이지뷰/일 필요
- 실현 RPM 약 $1.64 가정: 약 61,000 페이지뷰/일 필요
- 당시 일 페이지뷰 152 기준: 약 164~401배 트래픽 확대 필요
- 최근 90일 Google 검색은 클릭 172, 노출 4,540으로 검색 수요 포착 규모가 아직 매우 작다.

따라서 광고 수나 위치 조정만으로 달성할 수 없다. 검색 수요가 검증된 주제 확장, 반복 방문형 도구, 색인·내부 링크, 페이지당 수익 개선이 함께 필요하다.

## 잘 나아가고 있는 부분

1. **계정 보호를 성장보다 앞에 둔 판단은 맞다.** 정책 센터, CMP와 게임 광고 제외를 먼저 처리해 치명적인 수익 중단 위험을 낮췄다.
2. **무작정 신규 발행에서 실제 노출 페이지 개선으로 전환한 방향은 맞다.** 최근 아산·청주·김포·담양 캠핑과 비자 페이지처럼 이미 검색 신호가 있는 URL에 집중했다.
3. **영어 여행 내부 링크 구조는 실질적으로 개선됐다.** 고립 페이지 0개는 발견성과 사용자 이동의 기반이다.
4. **정확성 위험을 줄였다.** 무료 노지캠핑·입국·예약 가능을 보장하던 문구를 제거하고 공식 확인 경로를 강화했다.

## 아직 부족하거나 위험한 부분

1. **성과 검증보다 작업량이 앞섰다.** 수천 페이지를 개선했지만 수정 전후 페이지군의 수익·검색·참여 변화가 아직 없다.
2. **Google 검색 성장 증거가 없다.** 마지막 비교에서는 클릭·노출·CTR·평균순위가 모두 악화됐다.
3. **19,060개 페이지에 비해 검색 노출 페이지가 극히 적다.** 대량 페이지 수가 수익 자산으로 전환됐다고 보기 어렵다.
4. **대량 여행 콘텐츠의 질적 위험은 남아 있다.** 200개 표본의 형식 검사는 통과했지만 사실 정확성·중복성·검색 의도 만족을 보증하지 않는다.
5. **사이트맵 문제는 완전히 해결되지 않았다.** RSS와 허브는 보조책이지 Search Console의 사이트맵 정상 수집을 입증한 것은 아니다.
6. **계정 화면 데이터가 상시 연결되지 않았다.** 최신 AdSense·GA4·Search Console을 직접 읽을 수 없어 잘못된 방향을 늦게 발견할 수 있다.

- Search Console: 클릭, 노출, CTR, 평균순위, 검색어, 페이지, 색인 상태
- 최근 9개 개선 묶음과 나머지 사이트를 분리해 비교한다.

### P1 — 성과 없는 대량 수정을 중단

- 노출 0 페이지군은 신규 확장보다 통합·noindex·광고 제외 여부를 검토한다.

### P2 — 목표를 단계화

1. 일 $1을 28일 평균으로 달성한다.
2. 일 $5를 달성할 때까지 검색 유입 상위 2~3개 주제군만 확장한다.

4. 일 $100은 트래픽과 RPM이 함께 검증된 뒤 확장 목표로 유지한다.

### P3 — 다음 확장은 검증된 유형만

- 한국어 캠핑·비자처럼 이미 검색 노출과 클릭이 확인된 주제는 정확성·예약/입국 판단형 콘텐츠로 확장한다.
- 영어 도구·계산기는 기존 30개의 실제 검색 노출·사용·수익이 확인된 유형만 추가한다.
- 영어 여행은 국가 전체 대량 발행보다 노출이 생긴 도시와 실제 검색어 중심으로 재편한다.

### P4 — 검색 수요 기반 신규 페이지를 병행

현재 페이지가 검색되지 않는 원인은 `색인 실패`와 `검색 수요 부족`이 섞여 있을 수 있다. 따라서 기존 페이지 개선만으로는 부족하며, 신규 발행의 시작점을 실제 검색 수요로 바꾼다.

- 신규 작업의 70%는 Search Console에서 이미 노출된 검색어의 하위·인접 질문에 배정한다.
- 20%는 Google Trends의 상승 검색어, 계절성, 지역별 관심도를 바탕으로 소규모 실험한다.
- 10%는 반복 방문 가능성이 높은 계산기·체크리스트·비교 도구를 실험한다.
- Google Trends 점수만으로 발행하지 않는다. Trends는 절대 검색량이 아닌 상대 관심도이므로 Search Console 노출, 자동완성·관련 질문, 경쟁 결과 품질, 콘텐츠 정확성, 수익 의도를 함께 확인한다.
- 한 묶음은 5~10페이지로 제한하고 14~28일 뒤 노출·클릭·자연검색 세션을 판정한 후에만 확대한다.
- 승자 기준은 `색인됨`이 아니라 실제 노출·클릭·참여·수익이다. 수요가 확인되지 않은 템플릿의 대량 복제는 중단한다.

후보 점수는 `수요 40 + 경쟁 가능성 25 + 수익 가능성 20 + 사이트 적합성 15`의 100점으로 관리하고, 70점 이상만 제작 후보로 올린다. 건강·법률·재정처럼 정확성과 책임이 큰 주제는 현재 사이트의 대량 확장 대상에서 제외한다.
