# 사이트 품질 점수 시스템 적용 기록

## 목적

- 19,063개 색인 가능 페이지를 같은 기준으로 평가한다.
- 검색 성과가 확인된 URL을 추정치만 있는 URL보다 먼저 개선한다.
- AdSense 클릭률을 높이지 않고 검색 유입, 콘텐츠 가치, 신뢰도와 내부 탐색을 개선한다.

## 적용 내용

- 페이지별 8개 영역 점수, 근거 상태, 상한 규칙과 개선 권장사항
- GSC·GA4 성과 결합 우선순위와 URL별 미연결 수익 데이터 명시
- 사이트 종합 점수, 등급 분포, $100/day 필요 PV 계산
- 로컬 전용 필터 대시보드와 Markdown/JSON 결과물
- SEO QA 실행 시 품질 점수도 재생성하는 GitHub Actions 단계

## 2026-08-31 기준 결과

- 평가 페이지: 19,063
- 평균 페이지 점수: 75.80
- 80점 이상: 34.7%
- 60점 미만: 3.2%
- SITE_SCORE: 59/100
- GSC·GA4: 마지막 데이터가 30일을 초과해 `STALE_DATA`
- AdSense: 2023-08-01~2026-08-01 전체 기간 일평균으로 표시하며 현재 일수익으로 해석하지 않는다.

## 해석과 다음 우선순위

1. 최신 GSC·GA4·AdSense CSV를 가져와 현재 수익·색인·검색 기회를 다시 계산한다.
2. 검색 성과가 확인된 visa·camp 페이지의 breadcrumb와 검증 출처를 보강한다.
3. 55점 상한이 적용된 금융 페이지에 공식 출처와 기준일을 우선 추가한다.
4. 대규모 일괄 수정은 점수만으로 실행하지 않고 실제 검색 성과와 중복 여부를 함께 확인한다.

## 제한

- URL별 AdSense 수익과 RPM은 연결되지 않아 추정하지 않는다.
- 실제 모바일 UX, 경쟁 페이지 대비 가치, AI·복붙 여부는 자동 판정하지 않는다.
- 낮은 점수만으로 삭제, 통합 또는 noindex 처리하지 않는다.
