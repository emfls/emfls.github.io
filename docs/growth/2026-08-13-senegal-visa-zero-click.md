# 세네갈 비자 검색 기회 개선 기록

## 선택 근거

- Search Console 최근 조회에서 `세네갈 비자`는 클릭 0, 노출 2, 평균 순위 4.5였다.
- 표본은 작지만 첫 페이지 상단에 이미 노출되므로, 새 URL을 만드는 것보다 기존 URL의 검색결과 답변 명확성을 높이는 작업을 우선했다.
- 과거 집계에서는 이 페이지가 클릭 4, 노출 53, CTR 7.55%, 평균 순위 7.55를 기록했다. 기간이 다른 수치이므로 직접 전후 비교에는 사용하지 않는다.

## 적용 내용

- 제목과 H1을 `세네갈 비자 필요할까?`로 시작해 검색 의도와 직접 맞췄다.
- 첫 문장에서 대한민국 일반여권의 3개월 미만 방문은 사전 비자가 필요하지 않다고 답했다.
- 3개월 미만, 3개월 이상, 취업·유학·장기체류, 황열 위험국 경유의 네 가지 판단 경로를 추가했다.
- 세네갈 외교부의 현재 방문 안내 페이지로 기존 중복 링크를 교체했다.
- 오래된 WHO 2020 발생 보고서와 고정적인 환승 시간 단정을 제거하고, WHO 국가별 목록과 2026년 안내로 교체했다.
- 국제예방접종증명서의 평생 유효 안내를 추가하되, 개인별 접종 판단은 의료진 상담으로 분리했다.
- canonical URL과 기존 AdSense 광고 단위 수·위치는 변경하지 않았다.

## 정책·품질 방어

- 입국 허가를 보장하지 않고 최종 국경 심사와 공관 확인을 명시했다.
- 건강 관련 정보는 WHO 1차 자료에 연결하고, 경로별 요건과 의료 판단을 단정하지 않았다.
- 광고를 콘텐츠나 메뉴처럼 보이게 만드는 요소를 추가하지 않았다.
- 정보형 본문을 확대한 만큼 광고 밀도는 증가하지 않았다.
