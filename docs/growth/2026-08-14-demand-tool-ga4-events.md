- 목적: 페이지 조회와 실제 도구 사용을 구분해 후속 확장 판단

## 대상

- 캠핑 준비물 체크리스트
- 일본 여행 준비물 체크리스트

- 차박 가능 여부 확인 체크리스트

## 이벤트 정의

- 이벤트명: `tool_complete`
- 매개변수: `tool_name`, `result_type`
- 초기 화면 자동 계산·목록 생성은 제외하고 사용자가 버튼을 누른 경우만 기록
- 입력한 여행일수, 사용시간, 체크 항목, 장소명 등 사용자 값은 전송하지 않음
- 허용 목록 밖의 도구명과 결과값은 측정 함수에서 거부

## 분석 기준

- 페이지별 `tool_complete / page_view` 비율로 실제 사용률 비교
- 최소 14일 표본을 모은 후 검색 노출과 함께 판단
- 사용률과 검색 유입이 모두 없는 도구 유형은 추가 복제하지 않음
- 광고 클릭이나 광고 인접 행동은 이벤트로 수집하지 않음

## 검증

- 공통 측정 함수의 허용·거부 동작을 Node 환경에서 확인
