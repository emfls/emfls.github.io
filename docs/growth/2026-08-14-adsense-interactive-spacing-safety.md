# 인터랙티브 페이지 AdSense 오클릭 방지

- 적용일: 2026-08-14
- 배경: 당일 AdSense 클릭 22회 관찰 후 정책 안전성 우선 점검

## 점검 결과

- 저장소에는 `ad_click`을 직접 전송하거나 광고 클릭을 감지하는 맞춤 코드가 없다.
- 광고 클릭을 요청하는 문구도 확인되지 않았다.
- 다만 3D 주사위 페이지는 실행 버튼 아래 약 30px, 운세 페이지는 실행·복사 영역 아래 약 12px에 수동 광고 단위가 있어 모바일 오클릭 가능성을 줄일 필요가 있었다.

## 적용 범위

- 3D 주사위 13개 언어 페이지
- 운세 도구 13개 언어 페이지
- 합계 26페이지

## 적용 내용

- 인터랙티브 컨트롤과 광고 사이 위쪽 간격을 80px로 확대
- 광고 영역 위에 중립적인 `Advertisement` 표시 추가
- 광고 컨테이너에 `aria-label="Advertisement"` 추가
- 광고 코드, 슬롯, 크기, 클릭 동작은 변경하지 않음

## 정책 원칙

- 클릭률을 높이기 위해 버튼과 광고를 가깝게 배치하지 않는다.
- 광고를 메뉴·결과·다운로드·도구 버튼처럼 보이게 만들지 않는다.
- 본인 또는 관계자의 광고 클릭을 요청하거나 테스트하지 않는다.
- 클릭 수만이 아니라 페이지 CTR, CPC, RPM, 무효 트래픽 차감과 정책 알림을 함께 관찰한다.

## 검증

- 26페이지 모두 80px 안전 간격, 가시적 광고 표시와 접근성 라벨 확인
- 26페이지 모두 광고 클릭 유도·맞춤 `ad_click` 추적 코드 부재 확인
- `git diff --check` 통과
