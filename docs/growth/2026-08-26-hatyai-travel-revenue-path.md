# 핫야이 여행 수익 경로·안전 개선

## 선정 근거

- 기존 GA4 수익 점검에서 실제 수익 신호가 있었지만 조회 표본이 작아 보류했던 페이지다.
- 고정 입국 조건·현지 가격과 함께 송클라주 남부 국경 당일여행을 권하는 오래된 내용이 남아 있었다.
- 외교부는 송클라주 42번 국도 이남을 여행경보 3단계 지역으로 안내한다.

## 적용

- 제목과 설명을 `핫야이 여행 가이드 2026` 및 송클라 안전 확인 의도로 정리했다.
- 국경 당일여행 일정을 제거하고 핫야이 시내 일정으로 교체했다.
- 태국관광청, 태국 e-Visa, 외교부 태국 안전정보를 연결했다.
- 고정 비자 기간·교통비·입장료·일일 예산을 최신 확인형으로 전환했다.
- 방콕·페낭·여행 허브 내부 링크를 추가했다.
- 광고 배치는 변경하지 않았다.

## 측정

- 배포 후 7일·28일의 자연검색 유입, 참여시간과 페이지 수익을 비교한다.
- 안전경보 지역을 검색 유입이나 수익 확대 소재로 사용하지 않는다.
