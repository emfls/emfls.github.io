# Search Console 2차 개선 후보 20개

## 결론

최근 3개월 Search Console 검색 실적에서 이미 개선한 10개 URL을 제외하고, 평균순위 4~15위·노출 10회 이상인 페이지를 대상으로 2차 개선 후보 20개를 선정했다. 상위 10개는 비자 5개, 캠핑 4개, 게임 1개이며 먼저 이 묶음을 개선한다.

## 선정 기준

- 원본: `https___emfls.github.io_-Performance-on-Search-2026-08-01.zip`의 페이지 보고서
- 기간: 지난 3개월, 검색 유형 웹
- 대상: 평균순위 4~15위, 노출 10회 이상
- 제외: 1차 개선을 완료한 청주·담양·김포·아산 캠핑과 루마니아·슬로바키아·카타르·노르웨이·세르비아·슬로베니아 비자
- 보수적 목표 CTR: 순위 4~5.99는 8%, 6~7.99는 6%, 8~9.99는 4%, 10~15는 2.5%
- 우선순위 점수: `노출 × (1 + 목표 CTR 대비 부족 비율)`. 현재 CTR이 목표 이상이면 노출과 같은 점수로 처리
- 동점 처리: 노출, 클릭, 기존 검색 성과가 확인된 비자·캠핑 주제 묶음 순서

## 실행 묶음

1. 상위 10개를 먼저 개선하고 개별 URL 색인 요청까지 완료한다.
2. 11~20위는 상위 10개 배포 후 같은 검증 절차로 진행한다.
3. 각 페이지는 검색 제목·설명, 첫 화면 답변, 최신 공식 출처, 내부 링크, 모바일 화면, 구조화 데이터 순서로 점검한다.
4. 변경 전 수치는 이 표를 기준선으로 유지하고 28일 뒤 같은 URL의 클릭·노출·CTR·평균순위를 비교한다.

## 한계

- 페이지 보고서는 URL별 검색어를 함께 제공하지 않아, 실제 수정 전에는 각 URL의 Search Console 검색어와 현재 콘텐츠를 별도로 확인해야 한다.
- CTR 목표는 후보 정렬을 위한 보수적 내부 기준이며 Google이 보장하는 기준값이 아니다.
- 노출이 작은 13~20위 후보는 한두 번의 클릭으로 CTR이 크게 움직이므로 절대 수치보다 검색 의도와 정보 정확성을 우선한다.
