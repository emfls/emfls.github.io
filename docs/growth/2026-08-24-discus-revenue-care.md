# 디스커스 후속 수익 경로 개선 — 2026-08-24

## 선택 근거

- 직전에 개선한 러미노즈테트라 페이지에서 연결되는 관상어 후속 콘텐츠
- 기존 페이지의 과장 제목, 고정 비용, 일률적인 고온 처방 표현은 검색 신뢰와 사육 안전에 위험
- 신규 페이지를 늘리지 않고 기존 관상어 유입이 두 번째 페이지로 이동할 경로를 강화

## 변경

- 상단에 수질·온도·공간·여과·급여·이상 징후 6단계 점검 추가
- 입수 전 암모니아·아질산 0 확인과 판매처 사육 조건 확인 안내
- 먹이 거부·체색 변화에 무조건 수온을 30도로 올리던 문구 제거
- 진단 없는 고온 처방과 약물 사용을 피하고 수질·산소·최근 환경 변화부터 확인하도록 수정
- OATA 디스커스 관리 자료와 Merck Veterinary Manual 연결
- 러미노즈테트라·메다카·관상어 허브 내부링크 추가
- 제목·설명·Article 수정일 갱신
- 기존 URL, AdSense, GA4 유지

## 측정

배포 후 14일 동안 관상어 페이지뷰/세션, 디스커스 유입, 평균 참여시간과 페이지 수익을 이전 14일과 비교한다.
