# 원주 캠핑 수익 경로·신뢰도 개선

## 선정 근거

- GA4 기간: 2026-08-18~2026-08-24
- 페이지 실적: 조회 6, 활성 사용자 5, 활성 사용자당 조회 1.2, 평균 참여 26초, 총수익 $0.02
- 실제 수익이 발생했지만 `2025`, 완전무료 야영, 고정 요금과 개인 전화번호가 남은 미처리 페이지였다.
- 원주시의회 공개자료는 섬강두꺼비 캠핑장 부지에 대해 하천구역·침수 위험과 야영장업 등록기준 문제로 재이용이 어렵다고 설명한다.

## 적용

- 2026년 제목·설명·공유 메타데이터로 갱신했다.
- 야영·차박 허용 여부, 등록 캠핑장, 출발 당일 수위·기상 확인 순서를 상단에 추가했다.
- 섬강두꺼비의 운영 중단·재이용 제약을 공식 자료와 연결했다.
- 완전무료 야영, 고정 요금과 개인 전화번호를 제거했다.
- 고캠핑 원주시 등록시설과 강원·횡성·평창 캠핑 페이지를 연결했다.
- 캠핑 허브의 원주 설명을 갱신하고 기존 URL, 광고와 GA4를 보존했다.

## 측정

7일 이상 지난 뒤 조회수, 평균 참여시간, 활성 사용자당 조회수, 다음 페이지 이동과 총수익을 비교한다. 광고 CTR은 최적화 기준으로 사용하지 않는다.
