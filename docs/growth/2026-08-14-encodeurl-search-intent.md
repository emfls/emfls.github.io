# `encodeurl` 검색 의도 보강

- 적용일: 2026-08-14
- 근거: Search Console 최근 7일 `encodeurl` 3회 노출, 0클릭
- 대상: `/util/url-encoder/`

## 판단

URL 인코더는 제목, 설명, canonical, 실제 인코딩·디코딩 기능과 관련 도구 링크를 이미 갖추고 있었다. 따라서 새 페이지나 중복 도구를 만들지 않고, 검색어가 암시하는 JavaScript 함수명 혼동에 직접 답하도록 보강했다.

## 적용 내용

- `encodeURL`은 표준 JavaScript 내장 함수가 아니라는 직접 답변 추가
- 전체 URL에는 `encodeURI`, 단일 값·경로 조각에는 `encodeURIComponent`를 사용하도록 구분
- 같은 질문과 답변을 화면 FAQ와 FAQ 구조화 데이터에 함께 추가
- 검토일과 구조화 데이터 수정일을 2026-08-14로 갱신

## 정책 안전성

- 광고 클릭 유도나 광고 배치 변경 없음
- 입력값은 계속 브라우저에서만 변환
- 개인정보·URL 입력값을 별도 이벤트 매개변수로 수집하지 않음
