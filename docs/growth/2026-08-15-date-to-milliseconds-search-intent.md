# Date to milliseconds 검색 의도 개선

## 근거

- Search Console 관찰 기간: 2026-08-06~2026-08-12
- `date to milliseconds`: 노출 4회, 클릭 0회
- 기존 페이지는 양방향 변환을 지원했지만 제목, 첫 설명, 첫 입력 영역이 `milliseconds to date`를 우선했다.

## 적용 내용

- 제목과 H1을 `Date to Milliseconds` 우선으로 변경했다.
- 첫 설명과 첫 입력 영역을 날짜 → 밀리초 변환 순서로 재배치했다.
- 역방향 밀리초 → 날짜 변환, 계산 로직, canonical, 분석 및 광고 코드는 유지했다.
- 실제 수정일에 맞춰 구조화 데이터와 화면 검토일을 2026-08-15로 갱신했다.

## 측정 계획

- 2026-08-29 이후 Search Console에서 해당 URL과 두 검색어의 노출, 클릭, CTR, 평균 게재순위를 비교한다.
- 표본이 작은 동안 광고 위치를 추가하거나 클릭을 유도하는 문구는 사용하지 않는다.
