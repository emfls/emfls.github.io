# 김포 캠핑 검색 CTR·수익 경로 개선

## 선정 근거

- Search Console 2026-07-24~08-20: 클릭 2, 노출 89, CTR 2.25%, 평균순위 8.61.
- 첫 페이지권 순위에 비해 CTR이 낮아 신규 글보다 제목·검색 설명 개선의 기대값이 높다.
- 캠핑 허브에는 페이지 본문과 다른 2025년 과장 제목이 남아 있었다.

## 적용

- 제목과 목록 설명을 `김포 캠핑·차박 가이드 2026` 의도로 통일했다.
- 상단에 장소·주차·화장실·취사·요금·허용 여부·최종 검토 정보를 구조화했다.
- 경기·고양·인천 페이지로 지역 내부 링크를 연결하고 기존 청주 유입 링크를 보존했다.
- 전류리포구를 차박 명소처럼 단정하던 잔여 표현과 검색 키워드를 제거했다.
- 광고 배치는 변경하지 않았다.

## 측정

- 배포 후 7일·28일의 Google CTR, 클릭, 평균순위, GA4 조회와 페이지 수익을 비교한다.
