# 부산 노지캠핑 검색 노출 개선

## 기준

- 최근 7일 서치콘솔: `부산 노지캠핑` 4회 노출, 클릭 0회
- 대상: `/kor/report/camp/busan.html`

## 적용

- 제목과 첫 답변을 `부산 노지캠핑 가능할까?` 검색 의도에 맞춤
- 해수욕장·공원·주차장은 공식 캠핑장이 아니라는 안전 안내를 첫 화면에 배치
- 부산시 공식 예약 캠핑장 5곳 비교는 유지
- 캠핑 준비물 체크리스트 내부 링크 추가
- 수정일과 구조화 데이터 날짜를 2026-08-13으로 갱신

## 정책 안전성

- 무료 또는 허가된 노지캠핑으로 오인시키는 표현을 넣지 않음
- 광고 수와 배치는 늘리지 않음
- 광고 클릭 유도 문구를 넣지 않음
- 공식 부산시 출처와 예약 확인 절차를 유지

## 검증

- 관련 자동 검증 13개 통과
- 배포 및 서치콘솔 색인 요청 상태는 배포 후 아래에 추가 기록
