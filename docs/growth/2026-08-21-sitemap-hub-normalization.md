# 2026-08-21 사이트맵 허브 URL 정규화

## 문제

22개 디렉터리 허브의 canonical은 `/디렉터리/`인데 사이트맵에는 `/디렉터리/index.html`이 등록돼 있었다. Search Console이 캠핑 허브의 참조 사이트맵을 감지하지 못한 것과 같은 유형의 불일치다.

## 적용

- 22개 하위 사이트맵에서 `index.html` 허브 URL을 canonical 슬래시 URL로 통일
- 콘텐츠 파일, URL 경로, 광고와 분석 코드는 변경하지 않음
- `tests/test_sitemap_audit.py`에 사이트맵의 `/index.html` 허브 항목을 금지하는 회귀 테스트 추가

## 검증

- 수정 전 회귀 테스트: 22개 불일치를 검출하며 실패
- 수정 후 사이트맵 감사: 알 수 없는 URL 0, 비표준 URL 0, XML 오류 0
- 루트 사이트맵에서 누락된 하위 사이트맵 0

## 기대 효과와 한계

Google이 사이트맵 URL과 페이지 canonical을 같은 주소로 인식하도록 해 허브 발견과 신호 통합을 돕는다. 이 수정은 색인을 보장하지 않으며, Search Console에서 각 중요 허브의 실제 색인 전환을 별도로 확인해야 한다.
