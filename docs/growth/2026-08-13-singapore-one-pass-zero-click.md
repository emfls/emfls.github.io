# 싱가포르 ONE Pass 0클릭 검색 개선

## 기준 데이터

- Search Console 최근 3개월
  - `싱가포르 해외 네트워크 전문가 비자`: 클릭 0, 노출 20, 평균 게재순위 25.3
  - `싱가포르 해외네트워크 전문가 비자`: 클릭 0, 노출 6
- 확인된 최소 합계: 클릭 0, 노출 26
- 연결 URL: `/kor/report/visa/singapore.html`

## 공식 확인

- 검색어의 공식 명칭은 `Overseas Networks & Expertise Pass(ONE Pass)`
- 일반 급여 경로: 신청 직전 12개월 연속 한 고용주로부터 월 고정급 S$30,000 이상 또는 싱가포르 적격 회사의 예정 고용
- 적격 회사: 시가총액 US$500 million 이상 또는 연 매출 US$200 million 이상
- 스포츠·예술문화·학계·연구의 탁월한 성취 경로는 관계 기관 종합 심사
- 후보자 직접 신청 가능, 최초·갱신 각각 최대 5년이나 갱신은 별도 기준 적용

## 적용 내용

- 제목·설명·H1에 ONE Pass와 한국어 검색 표현 반영
- ONE Pass 전용 자격 섹션과 EP 비교 경고 추가
- 급여 경로, 회사 규모, 성취 경로, 신청 주체와 기간을 분리
- MOM 공식 자격·주요 사실·신청 절차 링크 추가
- FAQ 구조화 데이터와 화면 FAQ에 ONE Pass 질문 추가
- 기존 관광 무비자·SG Arrival Card·EP·S Pass 안내 유지
- GA4·애드센스 코드와 광고 수는 변경하지 않음

## 검증

- ONE Pass 신규 계약 테스트 및 싱가포르·비자 관련 회귀 테스트 총 8개 통과
