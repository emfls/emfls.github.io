# 2026-08-21 실제 수익 우선 점검

## 결론

- 수익은 정체가 아니라 증가 중이다. AdSense 기준 최근 7일 `$4.91`(직전 7일 대비 `+94%`), 최근 28일 `$10.04`(직전 28일 대비 `+226%`)다.
- 다만 최근 7일 일평균은 약 `$0.70`로, 일 `$100`까지는 약 `143배`가 필요하다. 광범위한 일괄 개선은 중단하고 이미 수익과 검색 반응이 확인된 묶음에만 자원을 집중한다.
- 현재 가장 강한 수익 묶음은 한국 지역별 캠핑·차박 가이드다. 금융 콘텐츠 확대는 실제 유입과 수익이 확인될 때까지 2순위 실험으로 둔다.

- GA4 연동 Search Console: 2026-07-24~08-20
- GA4 총수익 `$8.15`와 AdSense 예상수익 `$10.04`는 집계 방식과 귀속 차이로 일치하지 않는다. 페이지별 수익은 방향성 판단용이며, 조회수 5 미만 페이지의 높은 수익은 확대 근거에서 제외한다.

## 다음 작업 순서

1. 캠핑 수익 상위 페이지와 위 Google 후보 5개의 URL·본문 품질·현행 내부링크를 점검한다.
2. 남양주/경기 페이지를 중심으로 광역→시군→인접 지역의 양방향 링크를 연결한다.
3. 청주·김포의 제목과 검색 설명을 실제 검색 의도에 맞게 소폭 수정한다.
4. 변경은 5페이지 단위로만 배포하고 14일간 페이지별 PV, 검색 클릭, GA4 광고수익을 비교한다.
5. 수익 또는 검색 클릭이 증가한 형식만 다음 20페이지에 복제한다.
6. 광고 배치와 CTR을 높이는 변경은 하지 않는다. 최근 CTR 수준에서는 정책 안전성이 우선이다.

## 중단할 작업

- 근거 없는 100~1,000페이지 일괄 개선
- 색인되지 않은 모든 페이지의 반복 수정
- 조회수만 보고 저수익 다국어 게임 페이지 확대
- 실적 확인 전 금융/YMYL 콘텐츠 대량 생성
- 광고 클릭률을 높이기 위한 UI 변경
