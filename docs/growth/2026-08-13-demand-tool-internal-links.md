# 수요형 도구 내부링크 강화

## 적용 결과

- 공통 한국어 도구 목록 상단에 캠핑 준비물, 일본 여행 준비물, 일본 eSIM 계산기 3개를 추가했다.
- 캠핑 장비 허브에서 캠핑 준비물 체크리스트로 연결했다.
- 도쿄·오사카·교토 여행 가이드의 준비물 구간에서 일본 여행 준비물 체크리스트와 eSIM 데이터 계산기로 연결했다.
- 링크는 모두 정적 `<a href>`이며, 광고 클릭을 유도하는 문구나 광고 인접 배치를 추가하지 않았다.

## 적용 후 링크 출발 문서 수

저장소 HTML 기준으로 대상 URL을 포함하는 문서 수는 다음과 같다. 대상 페이지 자체의 횡링크도 포함된 단순 문서 수이므로 Search Console의 외부 색인 상태와는 다르다.

| 대상 | 링크를 포함한 HTML 문서 수 |
|---|---:|
| 캠핑 준비물 체크리스트 | 4 |
| 일본 여행 준비물 체크리스트 | 6 |
| 일본 eSIM 데이터 계산기 | 6 |
