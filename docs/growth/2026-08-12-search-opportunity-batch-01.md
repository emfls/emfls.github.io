# Search Console 성장 후보 개선 1차 기록

## 목적

최근 90일 동안 이미 노출이 발생한 페이지 중 평균 순위 8~30위 구간의 후보를 개선했다. 새 URL을 늘리는 대신 검색 결과 클릭률과 사용자의 첫 화면 만족도를 높이는 작업이다.

## 기준선

Search Console 조회 구간은 2026-05-10~2026-08-09이며 사이트 전체는 클릭 170회, 노출 4,557회, CTR 3.7%, 평균 순위 17.4위다.

| 페이지 | 클릭 | 노출 | CTR | 평균 순위 |
|---|---:|---:|---:|---:|
| 부산 캠핑 | 5 | 112 | 4.5% | 12.1 |
| 노르웨이 비자 | 3 | 149 | 2.0% | 10.2 |
| 카타르 비자 | 3 | 164 | 1.8% | 9.1 |
| 안동 캠핑 | 3 | 102 | 2.9% | 9.5 |
| 스웨덴 비자 | 4 | 51 | 7.8% | 10.7 |

## AdSense 안전 확인

- 기존 게시자 ID와 자동광고 코드를 유지했다.
- 광고 개수·위치·형식을 늘리거나 클릭 유도 문구를 추가하지 않았다.
- 입국과 시설 운영을 보장하는 표현을 사용하지 않았다.
- 오래되거나 출처가 불명확한 혜택·처리기간·예약 가능 표현을 제거했다.
- canonical URL과 GA4 측정 ID를 유지했다.

## 성과 판정

2026-09-09 이후 동일한 Search Console 페이지 기준으로 클릭, 노출, CTR, 평균 순위를 비교한다. 28일 동안 노출이 유지되면서 CTR 또는 평균 순위가 개선되었는지 페이지별로 판단한다. 일별 AdSense 수익만으로 이 작업의 성공 여부를 판단하지 않는다.

## 다음 후보 선정 원칙

같은 방식으로 최근 90일 노출 10회 이상, 평균 순위 8~30위 페이지를 우선한다. 공식 근거가 부족하거나 검색 의도와 현재 페이지 내용이 맞지 않는 후보는 개선 전에 사실 확인부터 수행한다.
