# 두바이 고용 비자 검색 노출 개선

## 기준

- Search Console 최근 3개월: `두바이 고용 비자` 클릭 0, 노출 17
- 평균 게재순위 35.1
- 대상: `/kor/report/visa/uae.html`

## 적용

- 제목과 H1을 두바이 고용 비자·UAE 취업허가 검색 의도에 맞춤
- 일반적인 민간기업 취업은 UAE 고용주가 신청한다고 즉답
- 정식 일자리 제안과 고용계약 확인 필요성 명시
- 취업허가 → 입국·신분변경 → 건강검진·Emirates ID → 거주허가 기본 흐름 추가
- 관광 목적 90일 비자 면제로 취업할 수 없음을 명시
- UAE 정부 취업 목적 거주비자·민간기업 고용 절차와 GDRFA Dubai 공식 링크 추가
- 수정일과 구조화 데이터 날짜를 2026-08-13으로 갱신

## 정책·검증

- UAE 정부와 GDRFA Dubai 공식 자료 사용
- 취업·비자 승인 보장 표현 없음
- 광고 수와 배치 변경 없음
- 관련 자동 검증 8개 통과
- 오늘 Search Console 수동 요청 할당량 소진으로 다음 요청일 대상에 추가
- GitHub Pages 배포 커밋: `69787a62f0f3332426ecb395e3966a6f17fb64fd`
- 공개 페이지에서 새 제목, 고용주 신청 답변, 취업·거주 절차, GDRFA 링크 반영 확인
