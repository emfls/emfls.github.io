# 일본 여행 도구 내부 링크 보강

- 적용일: 2026-08-14
- 목적: 일본 여행 검색 방문자를 준비물·통신 수요형 도구로 연결해 실제 이용 표본 확보

## 적용 페이지

- 일본 여행 종합 가이드
- 일본 혼자 여행 가이드
- 일본 기후 가이드
- 후쿠오카 여행 가이드
- 삿포로 여행 가이드

각 페이지에 다음 두 링크를 여행 준비 문맥으로 추가했다.

- `/kor/util/japan-travel-packing-checklist/`
- `/kor/util/japan-esim-data-calculator/`

도쿄·오사카·교토 페이지에는 기존 연결이 있어 중복 수정하지 않았다.

## 운영 원칙

- 광고와 구분된 편집 콘텐츠 영역에만 배치한다.
- 구매나 광고 클릭을 유도하지 않고 무료 도구의 기능을 명확한 앵커로 안내한다.
- 관련성이 낮은 페이지까지 일괄 삽입하지 않는다.

## 검증

- 우선 페이지 5개의 두 도구 링크와 앵커 자동 검사 추가
- 검색 수요 도구 및 GA4 회귀 검사 포함 6개 통과
- `git diff --check` 통과
