Perguntas frequentes – Conversor de formatos de dados

                    

                        
Que formatos são suportados?

                        
Suporta conversão e visualização de JSON, XML e CSV.

                        
Meus dados são enviados ou armazenados?

                        
Não. Todo o processamento ocorre no seu navegador e nenhum dado é enviado externamente.

                        
Posso usar arquivos grandes?

                        
Otimizado para dados de tamanho pequeno a médio; arquivos muito grandes podem ser limitados pela memória do navegador.

                        
Há destaque de sintaxe?

                        
Sim, utiliza highlight.js para destacar a saída.

                        
Posso copiar ou baixar os resultados?

                        
Sim, use os botões Copiar ou Baixar após a conversão.
