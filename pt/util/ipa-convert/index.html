FAQ – Conversor IPA para inglês

É IPA real?
Não. Usa regras simples para aproximar a pronúncia. Não é adequado para estudos linguísticos nem exames.
Meu texto é enviado para um servidor?
Não. Toda a conversão é realizada no seu navegador; nada é enviado para a nuvem.
Que sotaque usa?
Mistura regras de inglês americano e inglês britânico de forma simplificada.
Posso digitar frases completas?
Sim. Converte qualquer texto; cada palavra é processada individualmente.
